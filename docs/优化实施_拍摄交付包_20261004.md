# 拍摄交付包实施记录

本地实现，未部署，不调用模型，不新增数据库迁移或导出 API。

## 接入

```tsx
import { ProductionPack } from '@/components/works/ProductionPack';
<ProductionPack work={detail} userId={ownerId} />
```

work 接收已有 WorkDetail 和可选 creation_brief（Record<string, unknown>）；userId 可省略，组件自身读取当前会话并监听账号切换。来源作品应由带身份验证的原作品接口提供，组件不重新获取其他作品。

## 已有能力

- 导出中文 Markdown 完整交付包和 UTF-8 口播 TXT，使用浏览器 Blob 下载。
- 手机大字稿可调整 22–48 字号，手动滑动阅读。
- 镜头清单可以逐项标为拍完；本机存储 key 包含用户、档案、作品。账号切换时不沿用其他账号标记，内容变化后按新镜头 ID 重新匹配。
- 优先最新可识别审稿交付稿，诊断里引用原稿不入口播；其次脚本，最后已有分镜真实台词。回退旧版本或分镜早于稿件均提醒核对。
- 口播只取明确纯文字栏目、台词标签或台词表格列。表头按实际列名解析，换列序和转义竖线可识别；道具表不会被误作口播表。
- 清单保留已有画面、台词、景别、运镜、时长、拍摄要点。缺分镜显示待生成，不能解析则展示原文，不自行创造镜头。
- 拍摄准备只来自明确栏目、标签和已有拍摄条件，不自动填写灯光、道具、出镜人，也不宣称许可已获得。
- 保留原玻璃卡片风格；小屏表格转为镜头卡片，并提供去生成缺失阶段的作品链接。

## 验证

tests/production-pack.test.ts 的 11 项行为测试通过；与质量、复盘测试合并共 54 项通过。共享树 TypeScript 检查通过。

测试覆盖最新审稿优先、错误原文排除、空稿回退提示、版本不同步、表格与段落分镜、台词列重排、多表格隔离、纯文字栏目、准备信息、真实来源导出、账号/档案/作品本机隔离以及旧镜头标记清理。

## 边界

- 镜头标记本机保存，不宣称跨设备同步。存储禁用或失败会明确提示仅本页面有效。
- 非标准模型输出可能无法自动提取，只展示原文并提示补齐，不能把解析成功等同于事实正确。
- 不提供自动滚动、视频剪辑、语音合成、平台发布或默认确认素材权利；本模块只组织当前已有创作成果。
- 浏览器真实下载、手机视口及线上作品接口接入，仍需主任务集成后验收。
