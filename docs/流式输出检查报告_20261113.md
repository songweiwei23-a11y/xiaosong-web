## ❓ 如果感觉不是流式的

可能的原因：

1. **网络延迟** - 如果网络慢，整个响应会一起返回，看起来像非流式
2. **内容较短** - 如果生成内容很短，流式输出太快，看不出效果
3. **服务器性能** - 如果AI模型响应快，也会显得像一次性返回
4. **浏览器缓存** - 可能看到的是旧版本，需要强制刷新（Ctrl+F5）

## 🔧 验证方法

打开浏览器开发者工具（F12）→ Network 标签：

1. 生成选题/脚本
2. 查看请求
3. 如果看到 `text/event-stream` 类型，就是流式输出
4. Response 标签会显示数据是分批到达的
