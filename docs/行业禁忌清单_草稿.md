# 行业禁忌清单（草稿，待产品方过目）

> **2026-10-02 更新**：已按这份草稿落到代码里，另外补了医美 / 医疗、保健品、金融理财、酒类、宠物、汽车、房产 7 个高风险行业，每个行业都加了「不能拍的方向」。
> **以代码为准**：`lib/taboos.ts`。要增删改哪一条，改那份，这份文档不再同步。

> 用途：第二步「禁忌与红线」上线时，系统按档案的**赛道 / 产品品类**自动带出对应行业的禁忌，写进所有板块的提示词，生成完再由代码扫一遍、标出可能违规的词。
> 依据：《广告法》常见红线、短视频平台社区规范里的常见限流点，加上我们自己做实体店代运营的经验。**以平台最新规则为准**，这份清单是"尽量避开"，不是法律意见。
> 每条格式：**不能说 / 不能拍** —— 为什么 —— 换成怎么说。

## ① 平台通用红线（所有账号常开，不能关）

| 不能说 / 不能拍 | 为什么 | 换成怎么说 |
|---|---|---|
| 最、第一、顶级、极致、全网最低、国家级、独家、唯一 | 广告法绝对化用语 | 说具体事实："开了 9 年""一天卖 300 串" |
| 100% 有效、保证、绝对、永久、无副作用 | 虚假承诺 | 说"大多数客人反馈……""我们的做法是……" |
| 点赞抽奖、转发送、评论区扣 1 领福利（以互动换奖励） | 诱导互动，易限流 | 用内容本身引评论："你们那边也这样吗？" |
| 加微信、加 V、私信发你价格、主页有联系方式（口播或字幕） | 站外导流，易限流 | 引到平台内：团购链接、到店地址、评论区回复 |
| 贬低同行、点名竞品、"隔壁那家都是……" | 不正当竞争、易被举报 | 只讲自己怎么做 |
| 冒用权威：央视推荐、专家认证、政府指定（没有就不说） | 虚假宣传 | 不说 |
| 拍到顾客、路人正脸未经同意；拍到未成年人 | 隐私、未成年人保护 | 背影、手部、打码 |
| 时政、宗教、民族、地域歧视的话 | 通用红线 | 不碰 |
| 虚构经历、编造数据（销量、播放量、客户数） | 虚假宣传；也是我们一直在防的"编数字" | 没有依据写成 X 或【换成你的：……】 |
