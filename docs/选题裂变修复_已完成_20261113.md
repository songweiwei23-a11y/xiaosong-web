## 🎯 问题描述

**用户反馈**：
> 选题问题依然没有解决。核心原因是没有根据方向（地基）去裂变创作带有爆款元素的选题。现在产出的都是根据方向套用的模板公式。只要用了这个方向，产出的内容就是同质化的模板，一毛一样的那种。我要的是基于地基去裂变不一样的爆款元素选题。

**具体表现**：
选择"地域差异"方向后，生成10条选题：
```
❌ 全部都是："XX人去XX被XX震惊"
1. 南乐人去郑州买菜被价格震惊
2. 南乐人去郑州吃早餐被份量震惊
3. 南乐人去郑州坐公交被规矩震惊
4. 南乐人去郑州逛商场被繁华震惊
...
```

**根本原因**：
旧代码只告诉AI"不要模板化"，但没有教它"如何裂变"。

---

## ✅ 解决方案

### 核心思路

**方向（地基）= 底层机制 + 爆款元素库的裂变**

不是让AI"套公式"，而是：
1. 理解方向的**底层机制**（为什么有流量）
2. 从**5个维度**裂变出不同的爆款元素组合
3. 通过**强制自检清单**确保每条都不同

### 5个裂变维度

1. **认知维度**：认知缺口/反认知/冷知识/身份反差
2. **情绪维度**：好奇/震惊/共鸣/焦虑/爽感
3. **冲突维度**：文化冲突/认知冲突/身份冲突/利益冲突
4. **场景维度**：不同场景+人物组合+时间节点
5. **价值维度**：实用避坑/谈资/认同/情感治愈/知识增量

### 强制自检清单

生成后AI必须自检：
- ✅ 每条的爆款元素组合是否不同？
- ✅ 每条的场景是否具体且不重复？
- ✅ 每条的人物身份是否有变化？
- ✅ 标题结构是否多样？如果有3条以上标题句式相同→立即重写！

## 💡 关键洞察

### 问题的本质
AI不是不愿意创新，而是**不知道如何创新**。

### 解决的关键
不是告诉AI"不要做什么"，而是**教AI具体怎么做**。

### 方法论
**方向 = 地基**（底层机制）  
**爆款元素 = 砖**（可组合的单元）  
**选题 = 房子**（不同的砖的组合）

同一个地基，用不同的砖，搭出不同的房子！

## 🎓 经验总结

### 提示词工程的3个层次

**第1层（失败）**：否定式要求
- "不要模板化"
- "要多样化"
→ AI不知道怎么做

**第2层（部分成功）**：正面要求
- "每条要有独特的人物、场景、冲突"
→ AI知道要做什么，但不知道怎么做

**第3层（成功）**：方法论+清单+示例
- 5个裂变维度
- 强制自检清单
- 正反示例对比
→ AI知道怎么做，能做好

**我们现在在第3层！**
