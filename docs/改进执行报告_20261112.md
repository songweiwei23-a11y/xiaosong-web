## 🎯 如何继续执行

### 立即可做的事（本周）

#### 1. 应用PageLoading组件到页面

在每个页面的加载状态处添加：

```typescript
// 在页面顶部导入
import { PageLoading } from '@/components/ui/page-loading';

// 替换原有的 loading 判断
if (loading) {
  return <PageLoading message="正在加载档案信息..." />;
}
```

**影响的20个页面**：
- `app/dashboard/page.tsx`
- `app/dashboard/topic/page.tsx`
- `app/dashboard/script/page.tsx`
- ... (详见实施指南)

**预计时间**: 2-3 天

---

#### 2. 应用GeneratingIndicator到AI生成

在AI生成任务中添加：

```typescript
// 导入
import { GeneratingIndicator } from '@/components/ui/generating-indicator';

// 使用
{isGenerating && (
  <GeneratingIndicator 
    taskName="AI 正在生成脚本"
    estimatedSeconds={120}
    onCancel={handleCancel}
  />
)}
```

**预计时间**: 1 天

---

#### 3. 替换API调用为统一客户端

```typescript
// 原来
fetch('/api/script-history').catch(() => null)

// 改为
import { apiCallWithNotify } from '@/lib/api-client';
const data = await apiCallWithNotify('/api/script-history', {}, '历史记录加载失败');
```

**预计时间**: 1 天
