1. **这是什么号**：本地实体店（A类·餐饮）—— 南乐开地摊的成都川菜厨师，卖川味串串火锅、川味烧烤、川菜
2. **给谁看**：18-40岁本地年轻人和白领蓝领：下班想撸串、周末约朋友、想吃正宗川味又怕踩雷的小镇青年和新锐白领
3. **人设标签**：成都来的9年川菜厨师，在南乐地摊上把川味做正宗
4. **主打内容**：流量45% / 人设25% / 变现30%；主力形式是**晒过程**（地摊场景天然有烟火气和真实感，起号快）+ 教知识（川味怎么吃、怎么选）
5. **怎么赚钱**：看视频 → 团购下单/评论区问 → 到店消费（一元火锅引流，烧烤+串串火锅+川菜成交）
6. **第一条拍什么**：晒过程·变现型 —— 拍下午4点开档备菜穿串，用「36计·第19计 对比改造」：空地→搭棚摆摊→食材上桌→第一桌客人来，结尾落在"实在不坑"（价格透明、食材看得见）
7. **最该避开的坑**：别只拍成品和吃播（没有信任证据）；别把三个品类合并成"川味馆"（每个品类都要单独拍出来）；别学网红店搞噱头（地摊最大的卖点就是真实接地气）
8. **多久能看出跑没跑通**：30条内（约2-3周）：单条播放稳定破1000、评论区开始问地址和价格、到店核销团购订单每周5单以上 = 跑通

### 1. 人设定位

#### 原料在哪

档案里这几句是真材料：
- "出镜人是成都来的川菜厨师，做川菜9年，来南乐发展才半年，是店内川味正宗的核心保障"
- "地摊式露天经营，冬季有帐篷覆盖全年可营业"
- "门店在片区内已具备相当知名度，'这条街我们自带流量'"

档案里"真实、接地气、情感、亲切朋友式"这些是**形容词原料**，不是人设。翻译成具体行为：
- "真实接地气" → 就在露天地摊、客人能看见你洗菜穿串的全过程
- "情感、亲切朋友式" → 和老客能开玩笑、记得住常客爱吃什么

#### 人设标签句

**成都来的9年川菜厨师，在南乐地摊上把川味做正宗**

（19字，能被复述；客人会这么跟朋友说："那家老板是成都厨师，手艺正"）

#### 用了哪个入口

**地域身份 + 从业年限 + 场景反差**
- 地域身份：成都（川菜发源地）来南乐（三四线县城）—— 地域本身就是信任背书
- 从业年限：9年（不是新手，但也不是"30年老师傅"那种遥不可及）
- 场景反差：川菜厨师 × 地摊（通常认知里川菜馆要么高档要么苍蝇馆子，地摊上做正宗川菜是反差）

#### 验证

**为什么立得住：**
1. **地域可验证**：成都口音、手法、配方细节（比如油碟怎么调、毛肚烫几秒）一开口、一示范就能证明
2. **从业年限可持续讲细节**：9年够讲几十条经验（不同食材处理、川菜里的门道、成都和南乐客人口味差异）
3. **场景每天都在发生**：地摊不是摆拍，下午到深夜天天营业，素材源源不断
4. **客人能到店验证**：本地生意，吹牛一次就崩；老客愿意出镜本身就是活证据

**线下能否保持**：能。出镜人就是实际掌勺的厨师，不是演员；地摊场景就是真实经营场地。

#### 在同类账号里的位置

同行（本地川菜馆、烧烤店）常见人设：
- **老板娘型**：强调自家好吃、实惠，但缺专业背书（我也觉得我家好吃,凭什么信你）
- **探店达人型**：第三方视角,但商家自己做没法用这个角度
- **大厨展示型**：后厨掌勺、刀工特写,但通常在室内明厨,少了烟火气

**你的位置差在哪**：
- **地域背书 + 地摊场景** = 专业正宗(成都来的) + 接地气真实(地摊看得见全过程) —— 这两个通常只能占一头,你同时占了
- 同行要么在店里(专业但距离感),要么在地摊(亲切但缺背书);你是"有背书的地摊",填补了空白

#### 证据链

接下来靠这4类内容持续证明：
1. **晒过程·备菜穿串**：下午开档,食材处理全程,证明"真材实料、看得见"
2. **教知识·川味吃法**：毛肚烫几秒、油碟怎么调、为什么成都火锅和重庆不一样 → 证明"成都厨师、懂行"
3. **讲故事·老客互动**：常客来了直接说"老样子",或者"上次那个菜今天有没有" → 证明"本地认、口碑好"
4. **场景展示**：地摊从空地到摆摊、帐篷里冬天热气、客人坐满 → 证明"生意好、接地气"

#### 边界

**什么话一说人设就崩**（结合档案禁忌）：
- ❌ 说"最好吃""全南乐第一" —— 绝对化用语,违反禁忌;且和"实在厨师"人设冲突
- ❌ 诋毁同行"别家都不正宗" —— 档案明确禁止;且地摊老板这么说会被认为low
- ❌ 摆拍成高档场景、穿厨师服打领结 —— 和地摊场景、接地气人设冲突
- ❌ 承诺"吃了养生/去火" —— 餐饮红线;且厨师人设应该讲的是味道和手艺,不是功效
- ✅ 应该说的话："这个在成都叫XX,我们那边都这么做" / "今天X斤牛肉,下午3点进的货" / "这位大哥一周来三次,他最爱吃XX"

### 2. 用户定位

#### 一句话画像

**18-40岁南乐本地年轻人、白领蓝领：周中下班想撸串喝点小酒解压、周末约三五朋友聚会、想吃点有特色的川味又怕外地馆子踩雷、发工资那天想犒劳自己但预算有限(人均50-100)的小镇青年和新锐白领。**

（具体到能在脑子里想起一个真人：比如在县城商场上班的95后女孩,晚上约闺蜜想拍照发圈又要吃得爽,问你"辣不辣、多少钱、在哪"）

#### 为什么是他们、不是另一批

**优先服务**：
- 小镇青年(18-30岁,社交活跃,朋友聚会、约会、发圈) —— 他们是地摊烧烤串串的核心消费群,频次高、传播强
- 新锐白领 / 都市蓝领(25-40岁,职场消费、下班解压、发工资犒劳) —— 有一定消费力,认正宗手艺,不是只图便宜

**明确不服务**（不是歧视,是资源和场景不匹配）：
- **资深中产、精致妈妈** —— 他们要的是环境、卫生、体面接待,地摊场景满足不了(他们会去室内川菜馆);内容配比里不把他们当主攻人群,但偶尔可以拍"带父母来吃、老人家说正宗"做人设内容
- **只想安静吃饭、介意露天环境的** —— 地摊就是热闹、烟火气,服务不了要安静优雅的
- **只认连锁品牌、要开发票的商务宴请** —— 场景不符

#### 他们心里真正在想什么

嘴上说的："这家好吃吗?""辣不辣?""多少钱?""在哪?"

**心里真正的顾虑**（档案里"客人最担心"的翻译）：
- "地摊会不会不干净、食材不新鲜?" (怕质量有问题)
- "菜单一大堆,我也不懂川菜,点错了不好吃怎么办?" (分辨不出好坏、选择太多挑花眼)
- "外地师傅开的店,会不会专坑本地人、价格不透明?" (要价格透明、要真材实料)
- "朋友来了,带去地摊吃会不会显得我小气?" (要有面子、要有特色体验 —— 所以要强调"成都厨师9年手艺",把地摊从"便宜"升级成"有特色")

**他们想要的不只是吃饱**：
- 小镇青年要的是"能拍照发圈、朋友觉得这地方有意思" (有特色体验、颜值)
- 白领蓝领要的是"下班放松、吃得爽、价格实在" (性价比、口味、氛围)

#### 决策链路

**从刷到你到到店,中间会做什么**：
1. **刷到视频(第1次)** → 停留看完,心里记住"南乐有个成都厨师摆地摊"
2. **刷到第2-3条** → 开始关注,可能点进主页看看还有什么内容
3. **刷到晒过程 / 老客互动的内容** → 评论区问"在哪?""多少钱?",或者直接搜团购
4. **看到团购链接 / 地址** → 截图发给朋友"周末去试试?"
5. **第一次到店** → 用团购核销,点一两个推荐菜试试
6. **好吃 + 老板真的是视频里那个人** → 下次直接来、不用团购,成为复购客

**这决定内容要铺多长的信任**：
- 前3-5条(第一周)要让人记住"成都厨师、地摊、正宗" (流量型 + 人设型)
- 第5-15条开始密集铺"食材过程、怎么吃、老客反馈" (变现型),这时开始有人到店
- 持续做下去,老客出镜、复购场景本身就是最强信任状

**本地生意的特点**：不需要全国十万播放,只要本地1000个人看到、50个人到店试过、10个人成复购客,这个号就成了。

#### 什么时刻会想起你

**具体场景和时间点**：
- 周五下午5点下班,同事在群里问"晚上去哪吃?"
- 周六中午睡醒,想约朋友晚上出来,刷手机找地方
- 发工资那天(每月10号或15号),想犒劳自己吃顿好的
- 天气转凉 / 突然嘴馋川味,想吃火锅串串但懒得去远的商场
- 外地朋友来南乐,想带他吃点本地有特色的 (不是连锁店那种)
- 刷到其他烧烤店视频,评论区有人提到"那个成都师傅的摊子" → 搜你的号

**这决定了内容发布时间**：
- **下午4-6点**(下班路上刷手机,正好种草晚上去)
- **晚上8-10点**(吃完饭刷手机,记下来周末去)
- **周四、周五**(周末聚会提前做决策)
- 每月10号、15号前后(发工资日)可以发"犒劳自己"主题的内容

#### 他在平台上搜什么

**真会打出来的关键词**（决定了主页简介、视频标题、话题标签要埋什么词）：
- 南乐美食 / 南乐烧烤 / 南乐串串
- 南乐哪里吃火锅 / 南乐宵夜
- 地摊烧烤 / 地摊火锅
- 成都火锅 / 正宗川菜 / 四川串串
- (看了视频后) 一元火锅 / 锦园地摊

**标签策略**：每条视频带 #南乐美食 #地摊烧烤 #成都串串 + 1个内容相关标签(如 #晚上吃什么)

### 3. 内容定位

#### 长期提供什么价值

**让南乐年轻人找到一个有正宗川味、价格实在、能看见全过程的地摊宵夜去处**

(25字;价值落在"找到一个地方"而不是"学会做川菜")

#### 内容方向

**多元四类**（晒过程为主 + 教知识 + 讲故事 + 观点做流量）

**为什么不选单一主题**：
- 单一主题(如"接受网友挑战吃遍菜单""以物换物")需要高策划能力、且要保证任务能持续执行;现在是起号期,老板刚做短视频,先用**多元四类跑通、积累素材和网感**,更稳
- 地摊场景本身素材丰富(备菜、客人、老客互动、川味知识),不需要人为制造任务也有的拍
- **阶段策略**：起号前30条用多元四类,跑通后(粉丝破5000、流量稳定)可以在晒过程里做一个固定栏目(如"每周一道成都菜")当王牌系列

#### 当前阶段配比（严格按五步推导）

**第一步·看账号阶段,定作用配比**：
- 账号现状：0粉、还没发过,典型的**新号起号期**
- 这一阶段任务：拿到稳定流量和正反馈,从0做到1000粉且流量稳定
- 作用配比：**流量型 45% / 人设型 25% / 变现型 30%**

**为什么是这个比例**（解释）：
- **流量45%是最大块** —— 新号必须先让本地人刷到、记住,没有曝光后面都是空谈;地摊烧烤串串这个品类,本地年轻人是海量需求,用流量型内容(地域特色、川味冷知识、吃法)扩大覆盖面
- **人设25%** —— 从第一条就要立住"成都厨师、9年手艺",不能等流量起来再做人设,那时再建信任成本更高
- **变现30%从第一周就开始** —— 本地生意,有人到店试了、觉得好,比十万播放有用;前期变现内容(晒食材过程、老客反馈)本身也能拿流量,不是纯硬广

**第二步·看用户目标,调整配比**：
- 档案里变现方式:到店消费(主)、团购核销、私域引流 → 典型的**本地实体店变现逻辑**
- 用户目标:没有明确说要"大流量、做博主",而是"让观众产生信任(信任变化)" → **说明不是纯流量号,是要变现的**
- 调整:维持上述配比(流量45%已经够起号用,变现30%已经够每周铺2-3条建信任的内容)

**第三步·看数据,定主力形式**：
- 档案里"数据最好的内容类型":还没发过 → **没有历史数据可参考**
- **推测主力形式:晒过程** —— 依据:
  1. 地摊场景天然适合晒过程(备菜穿串、开档摆摊、客人来、收摊,每个环节都是真实发生的事件)
  2. 晒过程是"起号快、涨粉快"的类型(知识库原话),且离变现最近(评论多是"我该怎么弄""在哪")
  3. 餐饮行业晒过程 = 晒食材、晒手艺,直接解决客人的信任问题(怕不干净、怕不新鲜)
  4. 一个人、一部手机就能拍,执行成本低
- **为什么不用教知识做主力**:教知识(川菜做法、调料配方)受众相对窄(想学做菜的),且容易变成"教程号"而不是"来吃的理由";教知识作为**辅助形式**,讲"怎么吃最值、怎么点菜"更合适

**第四步·看变现产品和成交理由,补够信任内容**：
- 卖的是:川味串串火锅、川味烧烤、川菜 (非标品、体验型、需要决策)
- 成交理由(档案):有特色、实在不坑、口碑好、专业强(9年川菜厨师经验)、性价比高、质量好、选择多
- 客人为什么买你:靠**手艺(专业强)+ 过程(实在不坑)+ 人品(口碑好)**
- **变现型那30%用什么形式做**:
  - **晒过程**(占变现型的大头):备菜、穿串、上菜、老客来 → 证明"实在不坑、质量好"
  - **教知识**(占变现型的小头):川味怎么吃、怎么点、毛肚烫几秒 → 证明"专业强、有特色"
  - **讲故事**(占变现型的极少部分):老客的故事、为什么从成都来南乐 → 证明"口碑好、老板好"

**第五步·看题材,定"人群垂直"的比例**：
- 主赛道:川味串串火锅、川味烧烤、川菜 (餐饮·地摊宵夜)
- 目标人群的兴趣(档案):美食探店、朋友聚餐、夜宵烧烤、地摊文化
- 题材配比:**主赛道(三个品类) 60% + 目标人群兴趣(地摊文化、朋友聚餐场景) 40%**
  - 主赛道60%:串串怎么烫、烧烤怎么烤、川菜怎么炒、食材怎么选 (具体到品类)
  - 人群兴趣40%:地摊从空地到摆满、一桌朋友干杯、老客带新客来、南乐vs成都吃法差异 (这部分通常是流量型内容,能覆盖更广的"爱吃地摊烧烤"的人群,不只是"想吃川菜"的)

**三层配比总结表**：

| 维度 | 占比 | 说明 |
|---|---|---|
| **作用配比** | 流量45% / 人设25% / 变现30% | 新号起号期,流量是最大块;变现从第一周就要有 |
| **形式配比** | 晒过程40%(流量15% + 变现20% + 人设5%) <br> 教知识30%(流量15% + 变现10% + 人设5%) <br> 讲故事20%(人设15% + 流量5%) <br> 观点10%(流量10%) | 晒过程是主力(地摊场景适合);教知识做辅助;讲故事做人设;观点做纯流量 |
| **题材配比** | 主赛道(三个品类)60% <br> 人群兴趣(地摊文化、聚餐场景)40% | 主赛道保证专业性;人群兴趣扩大覆盖面 |

#### 主力形式

**晒过程**(占40%,是最大的一块)

**为什么是它**：
1. 档案里"数据最好的内容类型"是空(还没发过),但地摊餐饮行业,晒过程是**最快建立信任、最容易起号**的形式
2. 地摊场景天然适合:下午开档备菜、穿串、摆摊、客人来、收摊,每天都在真实发生,素材源源不断

#### 每类内容管哪一段路

把用户从「不认识你」到「找你到店」拆成5步,每类内容负责哪一步：

| 阶段 | 用户状态 | 内容类型 | 典型选题 | 目标动作 |
|---|---|---|---|---|
| **1·刷到** | 本地年轻人刷同城,还不知道有你 | **流量型·观点/冷知识** | "南乐人吃火锅和成都人差在哪?""地摊烧烤为什么比店里香?" | 停留看完、记住"南乐有个成都厨师摆地摊" |
| **2·记住** | 刷到过1-2次,开始有印象 | **人设型·讲故事/晒过程** | "成都厨师为什么来南乐摆地摊?""9年川菜厨师的一天" | 关注、点进主页看看 |
| **3·信任** | 关注了,但还没决定要不要来 | **变现型·晒过程/教知识** | "下午3点进货、4点穿串,你看得见""毛肚这么烫才是成都吃法""这位大哥一周来三次" | 评论区问"在哪""多少钱",或搜团购 |
| **4·到店** | 决定试试,第一次来 | **变现型·晒结果/老客反馈** | "团购19.9三人餐都有啥""老客说这个必点" | 用团购核销、到店消费 |
| **5·复购** | 来过一次,要变成常客 | **人设型·关系互动** | "这桌老哥每次都加这个菜""冬天帐篷里吃串串,南乐人的快乐" | 下次直接来、带朋友来、评论区互动 |

**说明**：
- 流量型和人设型管**前两步**(刷到、记住),让陌生人变成关注者
- 变现型管**第三步**(信任 → 到店),这是转化的关键,所以变现型占30%
- 人设型和变现型共同管**第四、五步**(到店后的复购和传播),老客出镜、互动本身就是最强背书

#### 第一条该发什么

**类型**:变现型·晒过程  
**目的**:让本地人第一次刷到就知道"这是个地摊、卖串串火锅烧烤、能看见全过程、老板是成都厨师"

- **脚本结构·晒过程·火车节**:起因(下午开档) → 关键步骤(备菜穿串摆摊) → 结果(客人来了)

**具体怎么拍**（可执行方案）：
- **时间**:下午4点开始拍,拍到晚上6点第一桌客人来(实际拍摄2小时,剪成40-60秒)
- **机位**:手机固定在摊位对面,延时摄影拍全景(空地→摆满的过程);关键步骤(穿串、点火、客人来)用手持特写
- **文案**(口播配音,成都口音):  
  开篇钩子(金钱型+盲盒型):"这个地摊,从空地到坐满人,只用了两小时。"(3秒内抓住)  
  中间(火车节结构):下午4点,空地一块 → 搭棚、摆桌、洗菜、穿串(特写:牛肉、毛肚、鸭肠) → 点火、调油碟 → 晚上6点,第一桌客人来了,点了一元火锅和五串烤肉  
  结尾(落在成交理由"实在不坑"):地摊从0到开张,你看得见全过程,这就是我们的实在。(结尾金句≤20字)  
  行动指令:"团购搜'锦园地摊',19.9三人餐,来试试。"(只要一个动作)
- **字幕**:关键信息字幕放大(下午4点、两小时、第一桌客人、19.9三人餐)
- **BGM**:轻快节奏感强的(如《桥边姑娘》《孤勇者》纯音乐版),配合延时摄影的快节奏
- **时长**:40-60秒(抖音黄金时长,完播率高)
- **话题标签**:#南乐美食 #地摊烧烤 #成都串串 #下班吃什么

**为什么是它开场**：
1. **对比改造这一计天然有"看得见全过程"的信任感** —— 第一条就要解决客人的核心顾虑(怕不干净、怕不透明)
2. **地摊从空地到坐满,视觉冲击强** —— 抖音前3秒决定生死,空地→坐满人,对比强烈,容易被刷停
3. **同时传递三个核心信息**:地摊(场景)、串串火锅烧烤(品类)、过程透明(成交理由) —— 第一条就要把定位说清楚
4. **变现型打头** —— 虽然是新号,但本地生意,第一条就要让人知道"在哪、卖啥、怎么去",而不是先做纯流量、再慢慢转变现(那样浪费本地精准流量)
5. **执行成本低** —— 不需要提前策划选题,就是拍每天都在做的事(开档摆摊);一个人、一部手机、两个机位就能拍

**它只担一个目的**:变现型 —— 虽然这条也能拿流量(对比改造有看点),但**主目的是让本地人看完知道怎么找到你、愿意来试试**,所以结尾行动指令是"搜团购",不是"关注我"。

### 4. 呈现定位

**主要形式**:口播(真人出镜配音) + Vlog(实拍过程配音)  
**拍摄资源**:一部手机 + 一个固定手机支架 + 自然光/摊位灯光(不需要额外补光)

**为什么是这个**:地摊场景、一个人运营,最现实的就是手机拍、自己配音;Vlog配音比纯口播对着镜头讲更自然(你本来就在干活,边干边讲);不需要情景剧(没有演员),不需要图文(餐饮必须要动态画面)。

### 5. 风格调性

**三个气质词**:接地气、真实、有烟火气  
**固定视觉**:地摊场景(露天/帐篷)、成都厨师围裙、食材特写(牛肉纹理、毛肚、炭火)  
**语言腔调**:成都口音(普通话但带川普)、大白话、朋友聊天式("你晓得不嘛""巴适得很")

**为什么是这个**:地摊最大的卖点就是真实、接地气,如果包装成"高档""精致",反而自相矛盾;成都口音本身就是人设标签,必须保留;大白话、朋友式,符合档案里"亲切朋友式"的风格要求。

### 6. 变现定位

**产品**:川味串串火锅、川味烧烤、川菜(三个品类并列,不分主次)  
**客单**:人均50-100元(一元火锅是引流款,实际消费靠烧烤+串串+川菜拉高客单)  
**成交路径**:看视频 → 团购下单/评论区问地址 → 到店核销/直接到店  
**必须建立的信任证据**:  
1. 过程透明(晒食材、晒穿串、晒备菜) → 证明"实在不坑、质量好"
