# 🎬 人设型选题方案（5条）

## 选题1：国庆过完店里人少了一半，但真正懂行的客人都是这时候来

**承接**：直接承接原方向中的核心选题示例"国庆过完店里人少了一半,但真正懂行的客人都是这时候来"，把它从标题落实为可拍的完整一期

**0️⃣ 视频目的**  
人设型——建立"当过教师、会帮你挑、站在客户角度说真话"的信任感，让观众记住"节后去他店里能得到手把手教"

**🅰 打法**  
四大脚本·讲故事·平凡英雄型：普通人（一个在冷清店里的老板）→ 一件不普通的小事（主动承认冷清并解释为什么节后才是对的时间）→ 细节验证（用三个具体动作证明"人少=服务好"）→ 感悟（真正为客户省心的店不怕淡季）

**1️⃣ 爆款元素**  
- 反差：节后冷清本是劣势，翻转为优势
- 成本：时间成本（节后省时间）+ 决策成本（有人帮着挑不用自己纠结）

**2️⃣ 开篇钩子**  
"国庆过完这一周，店里明显冷清了，但说实话，真正懂行的客人，都是节后来。"

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：站在空荡的店里，用三个具体动作证明"节后人少=我有时间手把手教你挑"
- **核心问题与观众价值**：为什么节后买家具更省心？目标人群（装修接近尾声、不着急但怕买错的年轻家庭）最怕挑花眼、怕被忽悠、希望有人帮着把关
- **取材与内容推进**：  
  1. 开场站在店里，背景能看见空荡的店面、整齐的家具、明亮灯光，直接承认"人少了"  
  2. 第一个动作：走到那套新中式沙发前，蹲下掀开坐垫，边掀边说"节前人多我根本没时间给你看这里，现在我能把每个细节都讲透"  
  3. 第二个动作：走到床边拿尺子量床板厚度/床体高度，说"节后我能带你量三遍，确保尺寸适合你家"  
  4. 第三个动作：拿出手机给看效果图（或带观众在不同风格区域走动），说"节后我能带你在六大品类里挨个对比，帮你搭配出最适合你家的组合"  
  5. 结尾回到开场位置，说一句感悟："真正为客户省心的店，不怕淡季。"
- **事实边界**：店面冷清是真实现状（国庆后客流减少），三个动作（掀坐垫、量尺寸、看效果图/走动对比）是真实服务流程；不编造客户对话，不承诺具体优惠金额
- **关键画面（3个）**：  
  ① 蹲在沙发前掀开坐垫特写（手部动作+口播"现在我能把每个细节都讲透"）  
  ② 床边拿尺子量尺寸（尺子贴床板/床腿，口播"我能带你量三遍"）  
  ③ 手机屏幕展示效果图或带观众走动画面（切换不同区域，口播"帮你搭配出最适合的组合"）
- **场景设置**：店内，选一个能同时拍到新中式沙发、床、其他家具的位置，保证背景有空间感、灯光明亮

**4️⃣ 脚本结构**  
讲故事·平凡英雄型：  
1. 普通人——开场站在冷清店里，承认"国庆过完人少了"  
2. 不普通的小事——主动翻转"人少=我有时间手把手教你"  
3. 细节验证——三个具体动作（掀坐垫→量尺寸→看效果图/走动对比）  
4. 感悟——"真正为客户省心的店，不怕淡季"

**5️⃣ 结尾行动指令**  
关注我，节后需要挑家具的时候，你知道该来哪。

**6️⃣ 执行要点**  
- 拍摄时段：选工作日上午或下午客流少的时段，背景自然冷清
- 设备：手机即可，固定机位拍开场和结尾，手持跟拍三个动作
- 注意事项：三个动作要真做（掀坐垫、量尺寸、看手机/走动），不能只口播不做；口播语速放慢，体现"教师式讲解"的耐心感

## 选题2：节后买家具的三个隐藏好处，第三个很多人不知道

**承接**：承接原方向中的选题示例"节后买家具的三个隐藏好处,第三个很多人不知道"，把它从标题落实为可拍的完整一期

**0️⃣ 视频目的**  
人设型——通过拆解三个具体好处，建立"我站在客户角度、愿意说真话、有经验"的专业可信形象

**🅰 打法**  
四大脚本·教知识·推荐型：美好愿景（买家具不踩坑、省心省钱）→ 圈定人群（装修快结束、不着急但怕买错的）→ 引发好奇（三个好处逐条讲）→ 推荐理由按获得感排列（简单→难→简单：时间充裕→能砍价→能看到真实服务）

**1️⃣ 爆款元素**  
- 成本：时间成本（不用排队）+ 金钱成本（能砍价）
- 内幕：第三个"能看到真实服务"是很多人不知道的

**2️⃣ 开篇钩子**  
"节后买家具有三个隐藏好处，第三个是我当了这么久家具城老板才发现的。"

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：站在店里，用三个递进的理由拆解"为什么节后买更省心"
- **核心问题与观众价值**：节后买家具到底好在哪？目标人群（装修接近尾声、预算有限、怕被忽悠）最需要"有人告诉我什么时候买最划算"
- **取材与内容推进**：  
  1. 开场站在店里，直接抛出"三个隐藏好处"  
  2. 第一个好处：时间充裕——切画面：你带观众在不同区域走动，说"节前人挤人，你根本没时间慢慢看；节后我能带你把六大品类挨个看，每套都能坐下来试"  
  3. 第二个好处：价格有空间——切画面：你站在某套家具前，说"节前我忙得顾不上砍价，节后我有时间跟你慢慢聊，价格上确实能给你多留点空间"  
  4. 第三个好处（高潮）：能看到真实服务——切画面：你指着店里的日常（比如擦家具、整理样品），说"节前人多，你看到的都是表面；节后你来，能看到我平时怎么维护这些家具、怎么对待每件货，这才是真实的我"  
  5. 结尾总结：真正懂行的客人，都是节后来
- **事实边界**：三个好处都是真实服务流程（时间充裕、价格空间、日常维护）；不编造具体优惠金额，不承诺"一定便宜多少"
- **关键画面（3个）**：  
  ① 带观众在不同区域走动（体现"时间充裕"）  
  ② 站在某套家具前口播"价格上能多留点空间"（不说具体数字）  
  ③ 指着店里日常维护场景（擦家具/整理样品），口播"这才是真实的我"
- **场景设置**：店内，选能拍到多个区域、日常维护动作的位置

**4️⃣ 脚本结构**  
教知识·推荐型：  
1. 美好愿景——买家具不踩坑、省心省钱  
2. 圈定人群——装修快结束、不着急但怕买错的  
3. 引发好奇——三个好处逐条讲  
4. 推荐理由（按获得感排列）——时间充裕（简单）→ 价格有空间（难）→ 看到真实服务（简单且是高潮）

**5️⃣ 结尾行动指令**  
关注我，等你节后需要的时候，再来翻这条视频。

**6️⃣ 执行要点**  
- 拍摄时段：选工作日，能拍到店里日常维护动作（擦家具、整理样品）
- 设备：手机即可，手持跟拍为主
- 注意事项：第三个好处要拍到真实动作（不能只口播"能看到真实服务"），比如你正在擦某套家具、整理样品，这个画面要自然不做作

## 选题3：为什么老师傅都劝你节后再买家具？今天统一说清楚

**1️⃣ 爆款元素**

**4️⃣ 脚本结构**  
36计·第8计 加入人物关系：  
1. 主任务——解释为什么节后买更好  
2. 关系角色出镜——提到哥哥15年经验（或哥哥出镜补充）  
3. 互动结果——两人共同验证"节后买"的合理性（我的教师背景 + 哥哥的行业经验）  

叠加 教知识·解题型：  
1. 场景难题——节前买还是节后买？  
2. 放大危机——节前买容易踩坑

## 选题5：6000平的店,节后这段时间我一个人都能给你讲透

**承接**：承接原方向中"店里人少了"的真实现状,从"6000平全品类"这个差异化优势出发,把"人少=我有时间带你全店看"落到具体动作上

**0️⃣ 视频目的**  
人设型——通过"6000平全品类 + 节后人少我有时间"的组合,建立"我能帮你一家搞定、省心省事"的专业形象

**🅰 打法**  
四大脚本·晒过程·过程展示：起因(节后人少,我有时间带你全店看) → 关键步骤经过(带观众走六大品类,每个品类点一个关键细节) → 结果(6000平一家搞定,不用跑三家)

**1️⃣ 爆款元素**  
- 成本：时间成本(一家搞定) + 决策成本(不用跑三家)
- 规模大：6000平

**2️⃣ 开篇钩子**  
"6000平的店,节前我根本顾不上带你全看一遍;节后这段时间,我一个人都能给你讲透。"

**3️⃣ 内容方向及目的(重中之重!)**  
- **核心内容方向**：用一镜到底或分段走动的方式,带观众走完六大品类,每个品类点一个关键细节,体现"节后我有时间带你全店看"
- **核心问题与观众价值**：为什么要选大店?为什么节后来更划算?目标人群(装修接近尾声、想一家配齐、怕跑多家店麻烦)最需要"有人带我把所有选项都看一遍"
- **取材与内容推进**：  
  1. 开场站在店门口或某个能看到店面全景的位置,说"6000平的店,节前我根本顾不上带你全看一遍"  
  2. 开始走动,每到一个品类停下来讲一个关键细节:  
     - 沙发区:掀开坐垫,说"这个填充物要这样看"  
     - 床区:量床板厚度,说"这个尺寸要这样选"  
     - 餐桌区:敲桌面,说"实木要这样辨别"  
     - 茶几区:指着玻璃面,说"这种花纹千万别选"  
     - 电视柜区:比划尺寸,说"插座位置要提前量"  
     - 衣柜区:拉开柜门,说"板材要看这里"  
  3. 结尾回到开场位置,说"6000平全品类,节后我一个人都能带你看完,一家搞定,不用跑三家"

- **场景设置**：店内,选一条能串联多个品类的动线

**4️⃣ 脚本结构**  
晒过程·过程展示(火车节模型):  
1. 起因(带钩子)——节后人少,我有时间带你全店看  
2. 关键步骤经过——走六大品类,每个品类点一个关键细节  
3. 结果——6000平一家搞定,不用跑三家

**5️⃣ 结尾行动指令**  
关注我,节后需要配全屋的时候,我带你一家搞定。

**6️⃣ 执行要点**  
- 拍摄时段：选工作日客流少的时段,背景自然冷清
- 设备：手机手持拍摄,建议用稳定器
- 注意事项：走动过程要流畅,每个品类停留时间不要太长(每个5-10秒即可);六个品类不一定全拍,至少拍3个,其他可以口播带过;每个品类的动作要真做(掀、量、敲、指、比划、拉),不能只口播
