# 方向拓展分析

这个方向的核心是**把"节后冷清"从劣势翻转为优势**——不靠降价促销，而是把冷清期包装成"真正懂行的客人才会选的黄金窗口"，筛出有真实需求、愿意花时间的精准客户。能起量的关键在于**反常识切入+具体利益点**：节前抢着买的都急，节后才是从容挑、细细看、买对不买贵的好时候。

这个账号做它的最大优势：**6000平六大品类全覆盖+当过教师会讲**——店大货全，节后确实有充足时间一对一讲透；教师背景让"带你挑"这件事可信度高。最大短板：**一人全包、只能挤空档拍**——不能设计需要多机位、长时段跟拍或大量客户配合的方向,必须是口播为主、碎片时间能拍的。

# 第1步：脚本策略卡

## 核心问题与目的
**要回答的核心问题**：节后家具城冷清时来买有什么实际好处？  
**目标人群为什么关心**：25-40岁装修接近尾声的年轻家庭，怕挑错、怕被忽悠、希望有人帮着把关，但不确定节后去是不是好时机  
**视频目的**：人设型——建立"当过教师、会帮你挑、站在客户角度说真话"的信任感，让观众记住"节后去他店里能得到手把手教"

## 采用的形式与原因
**形式**：讲故事·平凡英雄型 + 教知识·解题型的混合  
**为什么这样做**：
- 用"站在冷清店里直接承认人少"制造反差（平凡英雄的"不普通小事"），翻转劣势为优势
- 用三个具体动作（掀坐垫、量尺寸、看效果图/走动对比）验证"人少=我有时间手把手教你"这个承诺
- 教师背景天然适合"逐条拆解"的讲法，亲切朋友式口吻降低距离感
- 一人全包、碎片时间可拍，口播为主配3-5个动作画面即可完成

## 内容如何递进
1. **开场承认冷清** → 直接说"店里人少了"，不回避
2. **翻转认知** → "但真正懂行的客人都是节后来"
3. **三个具体好处+配套动作验证**：
   - 好处1：有时间把每个细节讲透 → 动作：蹲下掀开沙发坐垫，边掀边讲
   - 好处2：能反复确认尺寸不出错 → 动作：拿尺子量床板/床体高度
   - 好处3：能带你对比六大品类搭配全屋 → 动作：看手机效果图或带观众在不同区域走动
4. **感悟收束** → "真正为客户省心的店，不怕淡季"

## 事实边界
- **可以说的真实情况**：国庆后客流减少是事实，店面6000平六大品类全覆盖是事实，李国才当过5年教师是事实
- **三个动作是真实服务流程**：掀开坐垫查看填充和框架、用尺子量尺寸确认、看效果图或带客户在不同品类区域走动对比——这些是日常真实操作
- **不能说的**：不承诺具体优惠金额，不编造客户对话（"有位顾客说……"），不说"全阜南最便宜""今天最后一天"等绝对化用语
- **占位项**：如需具体优惠信息用【待确认：节后是否有优惠活动】

## 关键画面来源
- 背景：店内空荡但整齐明亮的场景（真实现状）
- 道具：新中式沙发（店内真实货品）、床（店内真实货品）、卷尺（日常使用工具）、手机（日常使用）

## 拍摄执行要点
- **语速控制**：比日常说话慢20%，体现"教师式讲解"的耐心感；每句话之间留0.5-1秒停顿便于剪辑
- **动作真实性**：三个动作必须真做（掀坐垫要真掀开、卷尺要真拉开贴上、走动要真走），不能只口播不做或假装做
- **眼神交流**：固定机位口播时看镜头，手持拍摄动作时可自然看向操作对象（如看沙发内部、看卷尺刻度），营造"我在给你讲"的现场感
- **背景音**：如店内有背景音乐或其他声音，拍摄时尽量选安静时段，或后期降噪处理

## 剪辑优化建议
- **节奏控制**：三个动作段落（掀坐垫、量尺寸、走动/看手机)是核心画面，每段保留完整操作过程不要剪碎；过渡口播可适当加快或删减停顿
- **字幕**：全程加字幕，关键词（"每个细节都讲透""量三遍""六大品类"）可加粗或变色强调
- **BGM**：选轻松、温和的背景音乐，不要太燃或太煽情，音量控制在人声下方不压台词
- **转场**：动作切换用自然转场（淡入淡出或直接切），不用花哨特效

## 发布后观察重点
- **完播率**：能否听完三个理由？如前5秒流失高，考虑开场画面是否够吸引（可尝试先放掀坐垫或量尺寸的动作画面做钩子，再回到口播）

- **点赞收藏比**：如点赞多收藏少，说明情绪有了但实用性弱，后续可考虑补充"节后具体怎么挑"的步骤类内容

## 🚫 违规与风险词

- **禁用「揭秘」**：容易招同行举报，也容易被判定为夸大。改用：教你看懂、带你了解、对比分析
- **禁用「震惊」**：典型标题党用词，平台会降权。改用：用具体数字替代情绪词
- **禁用「第一/最好/最强」**：绝对化用语违反广告法，会被限流。改用：我用过最顺手的、我个人最推荐的
- **禁用「100%/彻底根治」**：绝对化承诺，有违规风险。改用：大多数情况下、我这几次都有效
- ⚠️ **卡名不是豁免**：钩子库里有「内幕揭秘」这张卡，指的是「用信息不对称制造价值感」这个机制，不是允许你在标题里写「揭秘」二字。机制照用，词要换——写成「干了十年装修，我只看这 3 个地方」，而不是「装修行业内幕大揭秘」。

## 📏 每个标题的自查项（不达标就重写，不要输出不达标的）

1. **前 8 个字是否已经有钩子**——信息流里经常只显示这么多
2. **有没有一个具体的锚点**——数字、时间、身份、场景，四者至少占一个
3. **是否避免了形容词堆砌**——「很棒」「超赞」「绝了」不算信息
4. **换个人能不能用**——如果这个标题套在任何视频上都成立，它就太空了
5. **是否命中风险词**
6. **钩子卡是真用上了，还是只贴了个名字**——机制要能在标题里看出来
