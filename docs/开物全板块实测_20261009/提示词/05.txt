## 内容方向：多元四类还是单一主题

**选A·多元四类**（知识/故事/晒过程/观点都发）

**为什么**：
- **素材来源不可控**：你现在一人全包、只能挤空档拍，客人什么时候来、愿不愿意出镜、来的客人预算和需求是否适合拍案例，这些都是变量。硬做单一主题（比如"接受粉丝挑战配全屋100期"）会被素材卡死——客人不来就断更，客人来了但不愿出镜也拍不了
- **家具品类需要多角度建立信任**：6000平、六大品类（新中式家具·复古美式家具·宋式美学家具·现代轻奢家具·通货大众款家具·办公家具），每个品类的受众和决策点不同；知识证明你专业（怎么挑），过程证明你真在做（帮客人配齐），故事证明你这个人靠谱（教师转行、不糊弄），观点拉流量（家装、省钱大众话题）——四类配合比单押一类更稳
- **容错率高**：有客人来就拍晒过程，没客人来就拍教知识或讲个人故事，哪种都能产出，不会因为某一种素材断档就停更

**为什么不选B·单一主题**：
- 单一主题对策划和执行能力要求高，需要**可控的、源源不断的素材**（比如你每周真的能接到10个粉丝挑战、或者每周都有愿意出镜的客人愿意拍全程）。你现在是起号期、一人全包、客流不可控，还没到能稳定驾驭单一主题的阶段
- 但可以在多元四类里做**系列化尝试**（比如"×个预算配全屋"系列、"教你看懂××"系列），用系列增强记忆点，等跑通一个系列、有稳定素材后，再考虑把它升级成主题型王牌栏目

### 题材配比

- **主赛道（家具本身）：60%**
  - 六大品类（新中式家具、复古美式家具、宋式美学家具、现代轻奢家具、通货大众款家具、办公家具）轮着拍，每个品类都要有露出
  - 前20条先集中拍"新中式家具"和"通货大众款家具"（一个是利润支柱、一个是走量引流），把账号标签立起来；20条之后再逐步加入其他品类，每次加一个、拍3-5条
  - 不要把6个品类拍成6个独立账号的感觉——用"全品类"当变现型内容的卖点（"来我店里，新中式、美式、现代你都能看到，不用跑三家"），而不是让每个品类都当流量入口

- **目标人群的兴趣（大众话题）：40%**
  - 这部分是流量型内容的主要来源，用大众入口把人拉进来，再用家具内容做转化
  - **具体是哪几类**：
    1. **家装避坑**：装修后期最容易忽略的三件事、买家具前必须知道的5个坑、硬装结束后先买什么后买什么
    2. **省钱实用**：3万/5万/10万预算怎么配齐全屋、哪些家具可以买平替、怎么判断性价比
    3. **本地生活**：阜南/南乐/濮阳人买家具都去哪、方圆30公里哪家家具城最大、本地装修完多久能买家具（结合本地气候、习俗）
  - 这40%的内容不限于"正在选家具的人"，覆盖所有装修到后期的家庭，流量上限比纯家具知识高得多

### 配比核验

1. **流量型是不是和账号阶段匹配（新号是不是最大的一块）？**
   - **是**。流量型45%，是三类里最大的，符合新号起号期"拿稳定流量"的核心任务

2. **主力形式是不是档案里数据最好的那一类？**
   - **是**。档案里"入户视频（偶尔爆款）"="晒过程"数据好，占比35%排第一；"蹭热点段子"="观点/泛流量话题"数据好，观点占25%排第二。两者都保留了

3. **用户要大流量的话，行业干货是不是没当主力？**
   - **是**。档案里写了"让人长见识、有情绪"，说明要大流量。流量型的主力是观点（25%）和晒过程里覆盖人群广的角度（如"6000平家具城一天能卖多少钱"），教知识只占20%且聚焦决策相关知识，不是"家具材质科普"这种窄干货

4. **题材有没有给目标人群的兴趣留出30-40%？**
   - **是**。题材配比是"家具60% + 家装避坑/省钱/本地生活40%"，符合要求。40%的大众话题保证流量型内容有足够的覆盖面

5. **每个数字都能说出"为什么是这个比例"吗？**
   - **是**。上面每个数字都有对应的理由：账号阶段（新号需要流量）、用户目标（要长见识有情绪）、数据验证（晒过程和观点数据好）、品类特性（家具决策周期长、需要多角度建立信任）、资源匹配（一人全包、6000平实体店、有教师表达能力）

## 三种视频怎么拍

### 流量型：让更多新用户看到账号

**目的**：扩曝光、拉新粉，让本地及周边（阜南、南乐县、山东莘县、濮阳市）装修到后期的家庭第一次刷到你

**拍什么方向**：
1. **家装避坑 + 省钱实用**（大众入口）：装修后期最容易忽略的事、买家具前必须知道的坑、××预算怎么配齐全屋——不限于"正在选家具的人"，覆盖所有装修到后期的家庭
2. **本地化话题 + 观点共鸣**：阜南/南乐人买家具的习惯、买家具要不要听父母的、小夫妻意见不统一怎么办——引发本地人和目标人群（年轻家庭）的共鸣和讨论

#### 四大脚本（薛老师）

**主力结构1：聊观点·争议开篇**
- **骨架**：否定句开场（"我不认为……"）→ 3个论据（权衡利弊/不同视角/无奈之举） → 总结归纳
- **套到这个号**：
  - 开场否定常见误区或争议观点（"我不认为买家具一定要选大品牌""买家具不是越贵越好"）
  - 三个论据（第一，大品牌溢价高、本地售后不一定方便；第二，同样的材质和工艺，本地家具城性价比更高；第三，关键是要会挑、会搭配，不是只看牌子）
  - 总结回到用户（"所以买家具，先看实物、再看服务，牌子不是第一位"）
- **叠爆款元素**：人群（"装修到后期的年轻人必看"）、成本（"大品牌的钱一半交了品牌税"）
- **示范**：
  - 标题：《我不认为买家具一定要选大品牌》（叠元素：人群"装修的年轻人" + 反认知）
  - 怎么拍：站在店里某套新中式家具前，开场"我不认为买家具一定要选大品牌，三个理由"，逐条讲（大品牌溢价高、本地售后不方便、关键是要会挑不是只看牌子），结尾"所以来我店里，我教你怎么看实物、怎么判断性价比，牌子不是第一位"

**主力结构2：聊观点·观点并列**
- **骨架**：提出观点 → 论据1/2/3（从不同维度支撑观点）→ 总结强化
- **套到这个号**：
  - 提出观点（"装修后期最容易忽略的三件事"）
  - 三个论据（第一，家具尺寸没提前量好、买回去摆不下；第二，插座位置没规划、沙发挡住了；第三，颜色没统一、客厅像大杂烩）
  - 总结（"这三件事做好了，你家至少省一半折腾"）
- **叠爆款元素**：盘点（"三件事"）、损失（"不做你会后悔"）
- **示范**：
  - 标题：《装修后期最容易忽略的三件事，不做你会后悔》（叠元素：盘点 + 损失）
  - 怎么拍：口播，开场"装修到后期，有三件事很多人都忽略了，等买完家具才发现来不及"，逐条讲（尺寸、插座、颜色），每条配一个具体案例（"上周有对小夫妻，沙发买回去发现插座被挡住了，只能退"),结尾"所以买家具前，先把这三件事确认好，周末来店里我帮你现场量、现场规划"

#### 起号36计（小黄）

**第29计·吐槽奇葩现象**：具体现象 → 受害场景 → 为什么荒谬 → 建议/提问
- **套到这个号**：
  - 事件：吐槽同行的错误做法（"现在好多家具店，你一进门就跟着你、一直推销、不买不让走"）+ 展示自己的做法（"来我店里，你随便看，不买没关系，我该干嘛干嘛"）
  - 受害场景：客人的真实感受（"很多人跟我说，去某某店看家具，老板一直跟着介绍、站旁边盯着，压力太大、根本选不好"）
  - 为什么荒谬：买家具是要看、要比、要想的，不是冲动消费，强推销只会让人反感
  - 建议：来我店里体验一下，不强推、不盯着，你自己慢慢看、有问题随时问
- **示范**：
  - 标题：《现在好多家具店都这样，难怪客人不愿意去》（叠元素：共鸣 + 奇葩现象）
  - 怎么拍：站在店里，开场"最近好多客人跟我吐槽，说去某某店看家具，老板一直跟着、不买不让走，压力太大"，吐槽为什么这样不对（"买家具是要看、要比、要想的，不是买菜，强推销只会让人反感"），展示自己怎么做（"来我店里，你随便看，我在那边，有问题随时叫我，不买也没关系"），结尾"评论区说说，你们遇到过这种情况吗

⚠️ 起号打法是用来把上面这个方向**打开**的：优先挑能拍它的主力形式、能喂它的主系列的打法。
真要偏离它，先用一句话说明为什么。

## 📚 判断依据

### 选择矩阵：先选适合自己的，而非最炫的

| 资源条件 | 优先尝试 | 暂缓 |
|---|---|---|
| 单人、低预算、专业强 | 行业避坑、内幕揭秘、冷知识、推荐建议、暴躁态度、Rap+行业 | 街访、多人剧情、大型改造 |
| 有产品 / 门店 | 情境还原、以物换物、正确做法VS错误做法、街头采访、推荐建议 | 与转化无关的纯娱乐 |
| 有表演与搭档 | 一人分饰多角、角色扮演、整蛊、模仿电影片段、互换身份 | 只做静态知识口播 |
| 有真实项目过程 | 对比改造、接受网友挑战、互联网嘴替/替网友做、扮猪吃虎 | 编造成功结果 |
| 擅长故事 / 文案 | 借物喻人、一句话设定故事感、加入人物关系、怀旧复古、宠妻/宠夫反差 | 高频硬干货 |

⚠️ 这张表是这一步的核心。**用户看完 37 计的第一反应是挑最有意思的，
而不是挑自己拍得出来的**——单人低预算的号去学多人剧情，拍两条就撑不住。
你要按他档案里的真实条件（团队几个人、有什么设备、有没有门店、
擅长讲故事还是讲干货）去匹配，不是按哪一计更酷。

### 37 计速览

- **反向操作**【流量型】（常规A → 反向B → 真实反应/结果）：把行业常规动作、角色或结论倒过来。适合：服务、教学、美食、摄影
- **扮猪吃虎**【变现型】（低预期 → 质疑/冲突 → 实力展示 → 爽感回收）：隐藏实力，先被轻视再用能力完成反转。适合：技能、体育、职场、艺术
- **以物换物**【人设型】（提出交换 → 协商 → 体验 → 挖掘人物 → 情感结果）：用实体物品建立陌生人交流入口，交换故事与善意。适合：实体商品、探店、手工、地方文化
- **借物喻人**【人设型】（物的事件 → 双关对应 → 情绪推进 → 人生落点）：借物体状态、动作或关系隐喻人的处境与情感。适合：情感、哲理、数码、生活
- **跨界硬组合**【流量型】（主信息A + 视觉/听觉B → 双倍信息密度）：同一时间并置两个无直接逻辑关系的赛道。适合：窄赛道、知识、故事、才艺
- **软组合：用A方式做B事**【流量型】（方式A × 任务B → 新行为）：把另一行业的行为模式嵌入本行业动作。适合：服务、餐饮、宠物、门店
- **一句话设定故事感**【人设型】（普通动作 + 目标/困境/关系设定 → 故事期待）：用一句背景文案赋予普通画面动机与关系。适合：穿搭、做饭、设计、唱歌、Vlog
- **加入人物关系**【人设型】（主任务 + 关系角色出镜 + 互动结果）：让关系中的期待、反应与冲突成为看点。适合：家庭、教学、健身、探房、美食
- **一人分饰多角**【流量型】（角色A观点 ↔ 角色B回应 → 知识/反转）：一人承担多角色，通过对话演绎知识或冲突。适合：知识、品牌测评、段子、内幕
- **情境还原**【变现型】（真实任务 → 对话/纠错 → 旁观学习 → 结果）：把知识放进其自然发生的现场。适合：专业服务、教学、亲子、带货
- **Rap+行业**【流量型】（知识要点 → 节奏分句 → 押韵记忆 → 结论）：把行业文案改成押韵和节奏表达。适合：枯燥知识、内幕、汽车、教育
- **借势点评**【流量型】（热点事实 → 专业拆解 → 判断/建议 → 回到用户）：借热点对象的关注，用专业视角提供增量解释。适合：服装、医美、咖啡、减脂等
- **跟着博主做**【流量型】（选择样本 → 跟做 → 展示差异/结果 → 评价）：亲自复现已经被验证的动作或流程。适合：教程、美食、运动、穿搭、测评
- **模仿电影片段**【流量型】（识别名场面 → 替换角色目标 → 行业台词改写 → 回收梗）：用经典戏剧结构演绎行业日常。适合：品牌、门店、剧情、职场
- **正确做法VS错误做法**【变现型】（错误示范 → 后果 → 正确示范 → 原理/适用条件）：用鲜明对比降低理解成本。适合：健身、育儿、英语、沟通
- **整蛊**【流量型】（铺垫 → 误判 → 反应升级 → 揭晓）：设置无伤害误导，让真实反应与反转产生喜剧。适合：家庭、办公室、产品剧情
- **互联网嘴替/替网友做**【变现型】（征集问题 → 选择任务 → 亲测过程 → 结果与建议）：替粉丝完成想做但没条件做的任务。适合：实验、测评、美食、穿搭、减脂
- **求助网友**【流量型】（展示困惑 → 给出已知信息 → 明确问题 → 后续采纳）：主动示弱或提出问题，把观众变成参与者。适合：知识探索、亲子、乐器、产品共创
- **对比改造**【变现型】（改造前 → 目标/预算 → 关键步骤 → 改造后 → 复盘）：展示从问题状态到理想状态的可视化变化。适合：装修、美妆、理发、汽修、健身
- **拟人化**【流量型】（物/动物角色 → 人类欲望/冲突 → 对话 → 结果）：赋予物品或动物人格、关系和台词。适合：美食、宠物、数码、家居
- **拟物化**【流量型】（人的处境 → 物的机制 → 荒诞对应 → 情绪/笑点）：把人或人的状态当作某种物品/商品来表达。适合：健身、生活、宠物、段子
- **行业避坑**【变现型】（点名坑 → 后果 → 识别信号 → 替代方案）：利用趋利避害，帮助用户避免明确损失。适合：所有有决策成本的行业
- **内幕揭秘**【变现型】（表面现象 → 幕后机制 → 谁获利/谁承担 → 识别与应对）：解释行业利益链、流程和隐蔽套路。适合：服装、二手车、租车、加盟
- **懒人学习**【变现型】（低门槛承诺 → 演示 → 立即验证 → 延伸）：承诺极低时间或步骤成本，快速交付一个小结果。适合：技能、健康常识、美妆、美食、读书
- **暴躁态度**【流量型】（痛点事件 → 高情绪表达 → 干货判断 → 行动出口）：用强烈、稳定的情绪重新演绎行业知识或观点。适合：教育、工程、评论、行业吐槽
- **推荐建议**【变现型】（圈人/利益 → 清单 → 每项理由 → 适用与不适用）：向目标人群筛选值得选择的人事物。适合：工具、账号、书影、产品
- **互换身份**【流量型】（身份A进入角色B → 模仿典型行为 → 冲突/洞察 → 回归）：让人物承担与原身份不同的社会角色。适合：职场、探店、关系、剧情
- **怀旧复古**【流量型】（年代入口 → 细节复原 → 当时体验 → 今昔连接）：用老歌、旧物、服化道和年代故事唤起记忆。适合：音乐、美食、服装、探店、地方文化
- **吐槽奇葩现象**【流量型】（具体现象 → 受害场景 → 为什么荒谬 → 建议/提问）：针对目标群体共同遭遇的不合理现象表达态度。适合：服装、教育、职场、地域生活
- **角色扮演**【流量型】（角色目标冲突 → 对话升级 → 反转/知识 → 回收）：通过两个或多个明确角色制造场景与戏剧张力。适合：医疗科普、职场、古装、情侣、品牌
- **南北/地域差异**【流量型】（同一任务两地做 → 差异反应 → 原因/文化 → 交流）：比较地域语言、价格、份量、习惯与服务。适合：美食、市场、婚俗、生活服务
- **换个视角**【流量型】（常规事件 + 新POV → 新信息/情绪）：改变摄像机位置或叙事主体，获得新鲜感和代入。适合：宠物、亲子、服务、生活纪录
- **宠妻/宠夫反差**【人设型】（硬话塑造表象 → 家务/育儿行动 → 细节证明 → 温情回收）：嘴上强硬，行动温柔，用反差展示关爱。适合：家庭、育儿、生活带货
- **接受网友挑战**【变现型】（展示挑战 → 规则/赌注 → 执行 → 结果 → 征集下一题）：把评论区要求转化为下一集任务。适合：运动、租房、探店、运营、旅行
- **街头采访**【流量型】（一句好问题 → 追问 → 人物故事/观点 → 行业连接）：用真实人物回答和现场反应创造内容。适合：租房、情感、数码、美食、穿搭
- **冷知识**【流量型】（反常识结论 → 证据/例子 → 原理 → 应用）：提供鲜为人知、反常识且可转述的信息。适合：历史、珠宝、法律、生活、行业知识
- **赠送：身份反差**【人设型】（身份预期A → 行为B → 环境自洽 → 能力/情绪结果）：让职业/性别/环境预期与实际行为形成反差。适合：音乐、服装、职业知识、才艺
