# 选题裂变修复方案 - 从地基真正裂变出不同的爆款元素

## 🎯 问题诊断

### 当前问题
用户反馈：**选择"地域差异"方向后，生成的10条选题都是同质化模板，一模一样**

例如：
```
❌ 错误示范（模板化）：
1. 南乐人去郑州买菜被价格震惊
2. 南乐人去郑州吃早餐被份量震惊  
3. 南乐人去郑州坐公交被规矩震惊
4. 南乐人去郑州逛商场被繁华震惊
...全是"南乐人去郑州XXX被XXX震惊"
```

### 根本原因

**当前代码只告诉AI"不要模板化"，但没有教它"如何裂变"**

```typescript
// 当前代码（lib/boards/topic-query.ts:515-519）
query += `⚠️ 这 ${topicCount} 条选题要符合这个方向，但**表现形式必须多样化**：\n`;
query += `- 公式是创意的起点，不是固定模板。同一方向可以有完全不同的切口和表现\n`;
query += `- 每条都要有独特的人物、场景、冲突，避免只改几个词的同质化选题\n`;
query += `- 拍不出新意的选题不要给——宁可大胆创新，也不要机械套公式\n`;
```

**问题：这些都是"否定句"和"空泛要求"，AI不知道具体怎么做！**

---

## ✅ 解决方案：教AI如何从地基裂变

### 核心思路

**方向（地基）= 底层机制 + 爆款元素库**

不是让AI"套公式"，而是：
1. 给AI方向的**底层机制**（为什么这个方向有流量）
2. 给AI**可组合的爆款元素库**（认知缺口、情绪钩子、反转、冲突...）
3. 教AI**如何从同一个地基，组合出不同的爆款元素**
