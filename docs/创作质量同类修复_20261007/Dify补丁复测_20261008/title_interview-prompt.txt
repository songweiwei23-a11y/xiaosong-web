## 第1步：脚本策略卡

**核心问题**  
国庆前后，同一条街上不同门店的生意到底发生了什么变化？变化的具体表现是什么？老板们各自的判断依据是什么？

**用户目的**  
流量型。让全国实体店老板产生共鸣和讨论欲，通过真实多样的一线声音引发关注，不做获客广告。

**目标人群**  
全国实体店老板、关注县城消费趋势的创业者、对实体经济有观察兴趣的人群。

**所选形式**  
街访式实地采访。沿一条街依次走访不同类型门店，向每家老板提出同一核心问题，记录真实回答的差异与共性。

**材料递进逻辑**  
- 开篇抛出问题，建立观察范围（这条街）
- 逐店提问，保留不同答案：可能有人说变好、有人说变差、有人说没变化
- 每个回答后追问具体依据：是客流、客单、时段还是其他可观察现象
- 进一步追问可分享的具体事例或老板自己的判断原因
- 最后自然收束，不预设结论

**事实边界**  
尚未采访，无账本数据、营收数字、已知答案。所有受访者回答均为待采集状态。不编造"问了一圈""答案各不相同""老板沉默"等已完成报道的描述。不预设变化方向、不替老板编台词、不把个别感受包装成县城趋势。

**时间口径**  
用户原意为"国庆前后"对比,具体日期范围待拍摄前统一确认。采访时统一使用同一时间段口径,例如"跟国庆前那段时间比,国庆后这几天您店里..."。不擅自改为同比、往年或平时。

## 第4步:执行与优化建议

### 拍摄前准备

1. **确定时间口径**  
   统一"国庆前"和"国庆后"的具体日期范围,例如"国庆前指9月25日-30日,国庆后指10月8日-12日"。所有采访使用同一口径提问。

2. **选定街道与店铺**  
   - 选择本地一条有代表性的商业街,店铺类型多样(餐饮、服装、日用、服务等)
   - 提前观察至少5-6家店,确保老板在店且愿意受访
   - 准备备选店铺,防止临时拒访

3. **设备检查**  
   - 手机电量充足,准备充电宝
   - 领夹麦电量测试,备用电池
   - 测试收音效果,街边噪音大时考虑靠近店内安静处拍摄

4. **采访流程演练**  
   - 主问题保持一致,但追问要根据回答灵活调整
   - 允许老板回答"没什么变化""不太清楚",这也是真实状态
   - 不要引导答案方向,不要追问"是不是变差了"这类带倾向性的问题

### 现场拍摄要点

1. **每家店的标准流程**  
   - 先拍门头或环境镜头(2秒)
   - 礼貌问好并说明来意
   - 提出主问题,完整录制回答
   - 根据回答内容选择1-2个追问深入
   - 记录过程中出现的可用环境细节(空桌、忙碌的店员、商品陈列等)

2. **收音注意**  
   - 领夹麦夹在老板衣领,距离嘴15-20厘米
   - 街边车流大时,可请老板往店内走几步
   - 每次换店重新测试收音

3. **镜头建议**  
   - 主持人与老板同框时,手机横屏,双人中景或特写
   - 老板单独回答时,可切换到老板特写
   - 不必每句话都切镜头,完整回答比频繁切换更真实

4. **采访数量**  
   - 建议至少完成3家店的完整采访
   - 如果前3家回答雷同,继续拍第4-5家寻找差异
   - 如果前3家已有明显差异(变好/变差/没变),可收工剪辑

### 剪辑原则

1. **保留真实差异**  
   - 不同答案都保留,不强行统一口径
   - 如果所有店都说"没变化",也如实呈现,这本身就是有价值的观察

2. **追问剪辑**  
   - 每家店保留1-2轮最有信息量的追问
   - 删掉重复的"嗯""就是"等语气词,但不改变原意
   - 如果老板给出了具体事例,优先保留这部分

3. **节奏控制**  
   - 每家店控制在60-90秒
   - 开场+收尾控制在20秒内
   - 总时长3-5分钟为宜,内容讲透优先于压缩时长

### 后续可延展方向(非本条任务)

- 未来可做同一条街不同时间节点的持续观察(如双十一前后、春节前后)
- 不在本条内容中植入课程、服务推广

## 🪝 钩子机制库（开篇 36 计）

标题和开头是同一门手艺。下面 36 张卡是钩子的底层机制，
**每个标题挑 1 张主卡**——堆钩子等于没钩子。

- **圈定人群**（相关性）：人群标签 + 痛点/欲望 + 继续观看理由
- **直接提问**（相关性）：问题 + 意外事实/冲突 + 答案承诺
- **自我否定**（认知缺口）：我本以为A，没想到B；本来不想说，但C
- **反认知**（认知缺口）：大众认为A → 我的结论非A/B → 证据预告
- **高价值展示**（价值与损失）：结果/经历/投入 + 要讲的方法 + 适用对象
- **直击痛点**（相关性）：想要X但怕Y/正在遭遇Z + 低门槛解法
- **损失厌恶**（价值与损失）：别人都告诉你A，却没人告诉你B；问题发生是因为缺少C

## 📱 抖音的标题逻辑

- 推荐流场景：用户是被动刷到的，标题要在 1 秒内制造点击冲动
- 前 8 个字最重要——信息流里经常只显示这么多，钩子必须前置
- 善用数字、对比、反常识；疑问句比陈述句点击率高
- 长度 12-20 字为宜，太长会被截断

## 🚫 违规与风险词

- **禁用「揭秘」**：容易招同行举报，也容易被判定为夸大。改用：教你看懂、带你了解、对比分析
- **禁用「震惊」**：典型标题党用词，平台会降权。改用：用具体数字替代情绪词
- **禁用「第一/最好/最强」**：绝对化用语违反广告法，会被限流。改用：我用过最顺手的、我个人最推荐的
- **禁用「100%/彻底根治」**：绝对化承诺，有违规风险。改用：大多数情况下、我这几次都有效
- ⚠️ **卡名不是豁免**：钩子库里有「内幕揭秘」这张卡，指的是「用信息不对称制造价值感」这个机制，不是允许你在标题里写「揭秘」二字。机制照用，词要换——写成「干了十年装修，我只看这 3 个地方」，而不是「装修行业内幕大揭秘」。

## 📏 每个标题的自查项（不达标就重写，不要输出不达标的）

1. **前 8 个字是否已经有钩子**——信息流里经常只显示这么多
2. **有没有一个具体的锚点**——数字、时间、身份、场景，四者至少占一个
3. **是否避免了形容词堆砌**——「很棒」「超赞」「绝了」不算信息
4. **换个人能不能用**——如果这个标题套在任何视频上都成立，它就太空了
5. **是否命中风险词**
6. **钩子卡是真用上了，还是只贴了个名字**——机制要能在标题里看出来
