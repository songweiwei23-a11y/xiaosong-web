## 已上线的调整

| 板块 | 问题原因 | 实际调整 |
|---|---|---|
| 脚本生成 | 默认教知识/营销角色先于原意判断；强制波点、金句、CTA | 非广告稿通过适配生成器，按主线与材料选择采访、记录、观点、演示或故事；保留明确手选，采访补主问、条件追问与取证方式 |
| 审稿优化 | 同一格式清单决定所有稿件得分与改写 | 改为目的落实、信息递进、事实证据、口吻、执行、收束六维；无金句/CTA/情绪符号不算缺项，不以目标分数驱动改稿 |
| 创作方向 | 从零生成要求“目的不同”；自动配比扩大目的 | 各方向服务同一用户目的，用户明确多目的才兼顾；形式按手选执行；内容配比默认关闭，用户仍可开启 |
| 标题封面 | 缺失设置被填成疑问/为什么公式；脚本类型又反推出标题公式 | 默认按原稿自动选择；移除类型到标题公式的隐式映射；手选公式仍保留；候选不再强凑不同动机/钩子卡 |
| 分镜脚本 | 统一近景开场、三秒两镜、六秒上限；程序固定比例误报 | 默认按原稿自动选内容类型；允许必要环境及完整长问答；比例与镜头长度只记录，不单凭比例判失败；时长与台词能否念完仍检查 |
| 开篇钩子 | 强凑六种卡；生成适配规则前没有完整连续设置 | 自动模式最多给合适候选，同卡的不同成熟表达可用；手选各卡继续回应；在规则选择前就带完整原意 |
| 自由对话重新生成 | 按钮自动要求换角度 | 默认改善同一目的、主线、角度、人群与限制；仅用户明确要求才换角度 |

跨板块共享规则进一步锁定主体、两个比较时段、核心行动、材料是否已取得，以及未采访回答的边界。用户要前后比较，不能只在策略卡保留“前后”，正文改成年同比。只给前后但没日期时留拍前统一，不代编日期。没有前期录像时可记录回忆及当下证据，不安排回到过去补拍。

自动事实检查补入“创作方向”，并检查没有“问了”字样的预设采访结果，如“每家答案不一样”“有人说回暖有人说冷清”“店里突然安静下来”。条件分支、问题、明确可能性和用户真实原话不按这类虚构结果处理。正则检测有边界，没发现问题不等于事实全部可靠。
