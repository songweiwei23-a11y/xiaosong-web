# 「开物 · 截屏带入」浏览器插件（2026-11-01）

看对标账号的抖音主页时，把看到的画面一键带进开物的对标拆解。代码在 `browser-extension/kaiwu-capture/`，网站上的下载包是 `public/kaiwu-capture.zip`（改了插件代码要重新打包）。

## 用户怎么用（尽量少操作）

1. **装插件**：打开开物「对标 & 热点」页，没装插件时页面会自动提示，点「下载插件」，照四步装好（解压 → 打开 chrome://extensions 或 edge://extensions 的开发者模式 → 加载已解压的扩展程序 → 回来刷新）。上架商店以后变成点一下「添加」。
2. **打开对标账号的抖音主页**：右下角自动出现「开物 · 拆对标账号」小面板，一步步提示截哪一屏：
   - 第 1 步：主页第一屏（头像、简介、粉丝、获赞）；
   - 第 2 步：往下翻，作品列表截 2～4 张；
   - 第 3 步：打开点赞最高的一条，截一屏评论区；
   - 截够了：点「带进开物拆解」。
   截图按钮在面板上（截图时面板自己藏起来，不会截进去），也可以按快捷键 **Alt+Shift+K**；浏览器右上角的插件图标显示已截几张。
3. **带进开物**：开物认出截图来自哪个主页，**自动放进对应的对标账号**；没加过这个账号就**按主页的名字和链接自动新建**。用户只需要勾选「材料可以合法使用」、点「开始拆解」。想拆得更细，可以再传一两条爆款视频。

## 插件做什么、不做什么

| 做 | 不做 |
|---|---|
| 编导点按钮或按快捷键时，截当前标签页**看得见的画面** | 不自动滚动、不自动翻页、不自动打开作品 |
| 在抖音页面右下角显示步骤面板 | 不读抖音页面上的任何文字和数据，不调抖音的接口，不用 Cookie |
| 截图存在编导自己电脑上，带进开物后清空 | 不把截图传到开物以外的地方，不在后台定时运行 |

权限只有：截当前标签页（activeTab）、本机存储（storage）、在 www.douyin.com 上显示面板。测试 `tests/capture-extension-20261101.test.ts` 守着：插件代码里没有滚动、读页面、发网络请求、定时任务这些写法，权限不多出来。

## 上架 Chrome / Edge 扩展商店（要产品方用自己的开发者账号提交）

- **Edge 加载项**（免费）：partner.microsoft.com 注册开发者 → 提交 `kaiwu-capture.zip`。
- **Chrome 应用商店**（一次性注册费 5 美元）：chrome.google.com/webstore/devconsole 注册 → 上传 zip。
- 要准备：插件图标（128×128）、两三张截图、一段说明（可用 manifest 里的 description）、隐私说明（截图只存在本机，带进开物后清空；不收集个人信息、不读网页内容）。
- 上架以后，开物页面的安装提示改成直接跳商店的「添加」链接。
