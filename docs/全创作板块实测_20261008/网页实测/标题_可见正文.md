1. 挑衣柜别只看柜门，抽屉打开才知道挡不挡床
字数：22字
目的：流量型（让更多本地装修家庭看到这个避坑角度）
用的钩子：警告避坑（千万别做X + 后果 + 规避承诺）
赌的动机：恐惧——正在装修的人担心买回去才发现问题，"挡不挡床"这个具体后果让他们停下来看
核心卖点：衣柜抽屉拉开后占多少空间，现场演示给你看，避免买回去打不开
埋的关键词：无（推荐流场景，依靠内容匹配而非搜索）
适合场景：起号初期，需要快速拉新、建立"实用避坑"人设时优先用
2. 卧室放衣柜，先别急着看款式，抽屉能不能拉开？
字数：23字
目的：流量型
用的钩子：直接提问（问题 + 意外事实 + 答案承诺）
赌的动机：好奇 + 认同——"先别急着看款式"打破常规选家具的顺序，"抽屉能不能拉开"是个大多数人没想过的盲区
核心卖点：提醒用户买衣柜时要先考虑开合位置而非外观，店里样柜可以现场验证
埋的关键词：无
适合场景：前一个标题数据好但完播率不够高时换这个，疑问句能拉住犹豫的用户

埋的关键词：无
