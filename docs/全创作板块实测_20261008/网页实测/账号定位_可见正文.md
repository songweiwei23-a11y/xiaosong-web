一句话定位

县城展厅老板，沙发能试坐、床和衣柜现场演示开门抽屉位置，30秒解决装修家庭尺寸担心。

1. 人设定位
原料在哪

档案里的真材料：

"接地气"（风格）
"挑衣柜时观察柜门与抽屉打开后的位置；样柜真实演示"（已有内容方向）
"客人最担心：买回去挡门、抽屉打不开、尺寸不合适"
"他们真正想要：到店看真实样柜的开门与抽屉位置，沙发可以试坐"

前两条是形容词和动作描述，要翻译成人设标签。"接地气"翻译过来是：不讲专业术语、不画图纸、直接拉给你看；"样柜真实演示"翻译过来是：有真货在手、不靠嘴说。

人设标签句

不画图纸、现场拉给你看的家具老板

19字，可复述，具体到能想象出画面：一个人站在展厅里，直接上手把柜门、抽屉拉开，量给你看占多少位置。

用了哪个入口

痛点+职业：客人最怕尺寸问题（痛点），我有真实样柜能现场演示（解决能力）

验证
是否是高频真痛点？ 是。县城装修家庭的房子普遍80-120平，主卧10-15平，放床、衣柜、床头柜后过道只剩60-80cm，衣柜抽屉拉开占40-50cm，真的会挡。客人在店里看静态样柜看不出来，买回去才发现——这是真实高频痛点，不是伪需求。
能否持续讲细节？ 能。店里有沙发、床、衣柜三类样柜，每类至少2-3款（推测），每款的开门方式、抽屉位置、占地尺寸都不同，可以拍出至少15-20条不重复的演示内容。后续还能接着拍：不同户型怎么选、两种柜子对比、客人常犯的错、到店实拍客人试坐试开。
在同类账号里的位置

同城家具店账号大多是三种人设：

产品展示型："新款到货""全屋定制""工厂直供"，像图册，没有人
老板讲解型：对着镜头讲材质、工艺、价格，专业但距离感强
装修知识型：讲风格搭配、色彩选择，覆盖人群广但不聚焦成交

你这个和他们的差别：不讲材质工艺（那是选购后期的事），不讲风格搭配（那是设计师的活），只讲尺寸这一件事，用真实样柜演示。同行要么不讲尺寸，要么嘴上说"放心我们量过"——你是拉开给他看，这是动作，不是承诺。

证据链

接下来靠这4类内容持续证明人设：

晒过程·演示开门抽屉：每条拍一个具体动作（衣柜抽屉拉开、床头柜开门、沙发靠背调节），手持测量工具或直接用身体做参照（"你看，拉开后我只能侧身过"）
教知识·避坑：《挑衣柜别只看柜门》《床头柜放左边还是右边》《沙发深度多少坐着不累》，每条讲一个客人常忽略的尺寸细节
讲故事·客户案例（待积累真实案例后）：《有个客人买回去发现抽屉打不开，后来我们……》，讲你怎么帮他解决的
流量型·地域差异/冷知识：《县城的房子和市里的房子，家具尺寸要求完全不同》
边界

什么话一说人设就崩：

不能说"我们是大品牌""全国连锁"——人设立在"本地老板、真实样柜"，一说大品牌就变成产品展示型了
不能讲"零甲醛""终身质保"（档案禁忌：环保等级、售后承诺都未核实）
不能拍"客户见证视频"（档案禁忌：不安排顾客配合表演）——只能拍自然发生的互动，或者你自己讲客户的事
2. 用户定位
一句话画像

本地装修家庭，刚量完房或已经在看家具，去过三五家店但还没定，主卧10-15平、担心买回去抽屉打不开或者挡门，想先在店里看真货开门试试的那批人。

这句话具体到能想起某个真实客户：35岁左右，手里拿着户型图，问的第一句话是"我家卧室这么大，放得下吗"。

为什么是他们、不是另一批

你不服务的人：

还没量房、只是随便看看的：他们还在看风格和价格，尺寸问题排不上号，看你的视频也记不住
已经定了品牌、来比价的：你的差异化在演示尺寸，不在价格，他们不是你的菜
租房的、买二手家具的：客单价和决策周期不匹配

为什么是装修家庭、不是设计师或工长：设计师和工长看的是图纸和报价，他们不担心尺寸（那是业主担心的事）；你的内容是给最终使用者看的，帮他们建立"这家店靠谱、可以去看看"的信任。

他们心里真正在想什么

嘴上说的是"我想看看款式"，心里那句是："买回去万一不合适，退货麻烦死了，还是多看几家保险。"

被尺寸问题坑过的人（上一套房买的衣柜抽屉打不开）心里那句是："销售当时说没问题,结果……这次我得自己看清楚。"

决策链路

从刷到你到联系你，中间会做这几件事：

刷到视频 → 停留看完（如果前3秒演示的尺寸问题正好是他担心的）
评论区问"我家卧室X平,能放吗" → 你回复"可以,到店我给你现场量一下"
翻看主页 → 看有没有更多演示视频、这个老板是不是真懂
潜水观察1-2周 → 看你是不是稳定更新、评论区有没有别人问同样的问题
到店 → 看真实样柜、试坐试开、问价格、回去再比两家
二次到店或直接定 → 如果你店里的样柜演示让他放心了,会回来成交

这决定内容要铺多长的信任：至少20-30条稳定更新,前10条建立"这个老板懂尺寸问题"的专业感,后10-20条建立"这个老板实在、不忽悠"的人品信任。变现型内容不能急,前期流量型和人设型要铺够。

什么时刻会想起你

具体场景和时间点：

量完房后的那一周 → 拿着户型图开始看家具,心里盘算"卧室这么小,放得下吗"
周末逛了三四家店 → 销售都说"没问题放心",但他自己心里没底,晚上刷手机时看到你的演示视频
晚上8-10点 → 装修最焦虑的时间段,躺床上刷抖音,看到"衣柜抽屉打不开"这种标题会停下来
朋友说起自己家尺寸踩坑的经历 → 他想起来"对了之前刷到过一个老板专门讲这个",翻记录或者搜"本地+家具+尺寸"
他在平台上搜什么

真会打出来的关键词：

"卧室小 衣柜怎么选"
"衣柜抽屉 打不开"
"家具尺寸 怎么量"
"[你所在县城名]+家具"
"沙发 床 衣柜"（同时搜三个品类的人,就是你的精准用户）

主页简介和视频标题里要自然出现这些词,不要刻意堆砌但也不能完全不提。

3. 内容定位
长期提供什么价值

让装修家庭在买之前,看清楚家具真实尺寸和使用后的样子。

内容方向

多元四类（知识/故事/过程/观点都发）

理由：刚起号,策划能力按一人全包的实际情况,不适合单一主题（"接受粉丝挑战""探访老店"需要外出拍摄和多人配合,你现在只有店内样柜和一部手机）。多元四类可以从多个角度立住"懂尺寸、实在"这个人设,并且配合流量型60%的配比,前期需要多种内容类型来测试哪个方向流量最稳定。

待验证：如果"晒过程·演示尺寸"这一种跑出稳定流量（前20条平均播放500+）,可以在第30-50条时考虑升级为单一主题："每天演示一个家具尺寸细节,拍100期",那时品牌感会更强、涨粉更快。

当前阶段配比

作用配比（已定,直接用）：

流量型 60%：刚起号,定位未确定,先拿稳定流量和正反馈。流量型内容覆盖"所有装修家庭"这个大人群,不只是"已经在看家具"的那批——用大众关心的装修避坑、尺寸冷知识打开入口
人设型 25%：建立"这个老板实在、懂行"的人格信任,为后期转化铺垫
变现型 15%：从第一周就有,但只占小头,避免像广告号。这15%是精准推动到店的那几条,其余85%是铺流量和信任

为什么这个比例适合这个号：

账号阶段是"刚起号,定位未确定" → 流量型必须是最大的一块,变现型不能急
用户补充说明里写了"只用已确认事实,不安排顾客表演" → 变现型素材来源有限（只有样柜演示,没有客户案例）,前期占比不能高,要靠流量型和人设型把量做起来
一人手机拍摄 → 多元四类比单一主题更现实,流量型内容可以蹭热点（"这几天好多人问XX")、做对比（"两种衣柜开门方式"),素材好凑

每一块用什么形式做：

作用	占比	主力形式	为什么	辅助形式
流量型	60%	晒过程（演示对比）	档案里"数据最好的内容类型：还没发过",但"已有内容方向"是样柜真实演示,这就是晒过程。起号期用晒过程做流量型：演示尺寸对比(两种衣柜拉开后占地差多少)、错误VS正确做法(挑家具常见错误),覆盖"所有装修家庭",比纯讲知识流量上限高	教知识·冷知识（"衣柜抽屉为什么都在下面"）
人设型	25%	讲故事	讲你自己的经历（为什么开这家店、帮客户解决过什么问题）,或者讲客户的故事（有个客人买回去尺寸不对,后来我们…）。待积累真实素材后,这一块会成为最强的信任来源	晒过程·日常（进货/摆货/一天接待X批客人）
变现型	15%	教知识·解题型	场景难题(卧室小,衣柜和床怎么摆) → 放大危机(摆错了每天侧身过) → 低成本解决(到店看真实样柜,我给你现场量) → 操作步骤。这一块直接推动到店	晒过程·火车节（一个客人从进店到定家具的过程,待有真实案例后拍）

题材配比：

主赛道（家具尺寸、选购）60-70%：沙发深度怎么选、床头柜放哪边、衣柜开门方式、小卧室家具摆放
目标人群兴趣（装修避坑、省钱、生活方式）30-40%：县城装修和市里装修的区别、家具城水有多深、怎么跟销售砍价（这部分是流量型内容的主要来源,覆盖"还没到选家具阶段"的装修家庭）

主力形式：晒过程

档案里"数据最好的内容类型：还没发过/还看不出来",但"已有内容方向：挑衣柜时观察柜门与抽屉打开后的位置；样柜真实演示,30秒以内" → 这就是晒过程的描述。你手上有真实样柜,可以拍开门、拉抽屉、试坐,这是最直接的过程展示,也是起号最快的形式（比口播讲知识门槛低、比讲故事素材好凑、比观点更有画面）。

为什么不换成教知识：教知识需要口播能力和系统化知识储备,一人拍摄、基础剪辑的情况下,晒过程更容易出片、更容易拿到完播（动作比语言更抓眼球）。教知识作为辅助形式,占流量型和变现型里的一部分,但不当主力。

每类内容管哪一段路

把用户从"不认识你"到"找你"拆成四步：

刷到（流量型·晒过程）：用"衣柜抽屉打不开""床头柜挡开关"这种所有装修家庭都担心的尺寸问题做钩子,演示给他看,让他停下来看完 → 管拉新
记住（流量型·教知识 + 人设型·讲故事）：翻主页时看到你每条都在讲尺寸、每条都有真实演示,记住"这个老板懂这事" → 管记忆点
信（人设型·讲故事 + 变现型·教知识）：看到你讲"有个客人买回去尺寸不对,我们帮他换了一套"（讲故事）,或者"到店我给你现场量,不合适不收钱"（教知识·解题型） → 管信任
联系（变现型·教知识）：看到"卧室小怎么选衣柜"这种正好是他的问题,结尾你说"评论区告诉我你家多大,或者到店我给你量",他留言或到店 → 管转化

缺了哪一步：如果只有流量型,他记不住你；如果只有变现型,他不信你；如果只有人设型,他不知道你能帮他解决什么。三类内容必须都有,每周都发,这就是"配比"的意义。

三种视频各怎么拍
流量型：让更多新用户看到账号

四大脚本怎么做：

方向：尺寸冷知识（"为什么衣柜抽屉都在下面"）、装修避坑（"家具城最坑的三句话"）、地域差异（"县城的房子和市里的房子,家具尺寸要求完全不同"）
用哪个脚本结构：
聊观点·观点并列：《挑家具,别只看颜值》→ 论据1:尺寸不对每天别扭 / 论据2:开门方式不对撞墙 / 论据3:高度不对腰疼 → 总结:先看尺寸再看颜值
教知识·冷知识：《衣柜抽屉为什么都在下面,不在上面》→ 原理:上面放衣服、下面放重物,重心稳 → 应用:买的时候别要求改,改了反而不好用
结尾行动指令：关注或评论,二选一。示例："你家衣柜抽屉在哪?评论区说说" / "关注我,每天一个装修避坑"

起号36计怎么做：

第15计·正确做法VS错误做法【变现型】：错误示范(挑衣柜只看柜门,不看抽屉) → 后果(买回去抽屉拉开挡床) → 正确示范(现场拉开抽屉,量一下占多少位置) → 原理(卧室小的话,抽屉位置比柜门更重要)
套到这个号：拍两组镜头,第一组只拍柜门开关(错误做法),第二组拉开抽屉、用身体或卷尺做参照(正确做法),画面上打字"很多人挑衣柜只看这个↑,其实应该看这个↓"
第31计·南北/地域差异【流量型】：县城的房子(卧室10-15平) vs 市里的房子(卧室18-20平) → 同样的衣柜,县城放着刚好、市里放着显小 → 原因:户型面积不同 → 交流:"你家多大?评论区说"
套到这个号：分屏或前后对比,左边/前段拍小卧室(样柜摆在店里一角,模拟小空间),右边/后段拍大卧室(样柜摆在店里中间,模拟大空间),同一个柜子,视觉效果完全不同
人设型：让看过的人记住你、信你这个人

四大脚本怎么做：

方向：为什么开这家店、帮客户解决过什么问题、和客户的关系细节（"有个客人买回去发现抽屉打不开,后来我们…"）
用哪个脚本结构：
讲故事·平凡英雄：普通人(一个客人,装修新手) → 一件不普通的小事(买的衣柜抽屉打不开,每天只能侧身过,憋屈了半年) → 细节验证(他后来找到我,我去他家量了一下,确实挡) → 感悟(所以我现在每个客人来,都让他先看抽屉位置)
讲故事·知恩图报：伪缺点(我这个人话不多,不太会推销) → 事件验证(但每个客人来,我都会把柜门抽屉全拉开一遍,让他自己看) → 感悟(后来很多客人说,就是因为我不推销,他们才信我) → 实际回报(现在X成客人是老客户介绍来的)【X处待真实数据,没有就删掉这句】
结尾行动指令：关注,或者引导看主页。示例:"关注我,每天一个家具店老板的真心话" / "主页还有更多客户故事"

起号36计怎么做：

第7计·一句话设定故事感【人设型】：普通动作(摆货、擦样柜、接待客人) + 目标/困境/关系设定(开店X年,见过太多客人买回去尺寸不对,我现在每个客人都…) → 故事期待
