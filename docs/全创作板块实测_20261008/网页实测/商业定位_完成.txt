    - text: 的生意。县城客户装修周期长达1-3个月,沙发、床、衣柜这三大件通常在水电结束、墙面完工后开始选,客人会跑3-5家店比价、比样式、比尺寸是否合适。
  - heading "毛利结构" [level=3]
  - list:
    - listitem: 沙发毛利通常30-50%,布艺比皮质低10个点
    - listitem: 床的毛利25-40%,床垫和床架分开算,床垫毛利更高
    - listitem: 衣柜如果是成品柜毛利20-35%,定制柜可达40-60%但交付周期长、纠纷多
  - heading "获客成本卡在哪" [level=3]
  - paragraph:
    - text: 县城家具店最大的问题是
    - strong: 信任门槛高、决策周期长
    - text: ":"
  - list:
    - listitem: 客人担心尺寸不合(柜门打不开、挡门、抽屉拉不出来)
    - listitem: 担心质量看不出(板材、五金、承重)
    - listitem: 担心售后找不到人(开裂、塌陷、异味)
  - paragraph: 传统获客靠门店位置+熟人介绍,一个月能成交5-10单就算正常。抖音同城如果拍对了,能把"路过看到"变成"专门来看",月增10-20个到店咨询是合理预期。
  - heading "决策周期" [level=3]
  - paragraph:
    - text: 从第一次进店到成交,快的3天(着急入住、看中现货),慢的2-3周(要跟家人商量、对比其他店、等发工资)。
    - strong: 客人不会看完视频马上下单
    - text: ",抖音的作用是让他\"想起你、专门来一趟\"。"
  - heading "淡旺季" [level=3]
  - list:
    - listitem: 旺季:3-5月(春季装修)、9-11月(秋季装修)、春节前1个月(换新)
    - listitem: 淡季:6-8月(太热懒得动)、12-2月(年底没钱、工人放假)
    - listitem: 县城节奏比城市晚半个月,春节、国庆前一周是集中成交期

    - strong: 只拍成品不拍过程
    - text: :一堆精修图+价格,看着像电商详情页,客人觉得假
    - strong: 不敢展示真实尺寸限制
    - text: :怕说"这个衣柜要3.2米墙才能放"吓跑客人,结果客人来了发现放不下,白跑一趟还埋怨你
    - strong: 把所有品类一条视频里塞完
    - text: :"我们有沙发床衣柜餐桌茶几…" 什么都说等于什么都没说

    - strong: 模仿大品牌拍高级感
    - text: :慢镜头、光影、文案矫情,本地客户要的是"实在",不是"高级"

  - heading "主推产品" [level=2]
  - paragraph:
    - strong: 建议主推:沙发
  - heading "为什么是它" [level=3]
  - list:
    - strong: 信任门槛最低
    - text: :沙发能现场试坐,软硬、大小、舒适度当场就能感知,不像衣柜要等装完才知道合不合适
    - strong: 视频最好拍
    - text: :15-30秒展示"客人坐下去的反应""沙发能坐几个人""搬进门有多宽"就够,一个人一部手机完全能拍
    - strong: 成交周期最短
    - text: :客人装修到刷墙结束就开始看沙发,比衣柜(要量尺寸、等定制)早2-4周进入视野
    - strong: 复购和转介绍机会大
    - text: :客人买完沙发满意了,卧室的床、衣柜大概率回来找你;而先买衣柜的,不一定会想起你还卖沙发
    - strong: 符合已有方向
    - text: :档案里写的"样柜真实演示,30秒以内",沙发最适合这个——拉开柜门需要解说,坐沙发一个动作就看懂
  - heading "为什么不是床或衣柜" [level=3]
  - list:
    - strong: 床
    - text: :拍摄点不如沙发直观(躺上去测试不适合短视频),且客人通常是"沙发+床"一起看,单独推床没有入口优势
    - strong: 衣柜
    - text: :决策链路最长(量尺寸→选样式→等生产→装完验收),新账号前期靠它变现,客人等不及就跑了;但衣柜是毛利最高的,等账号成熟、信任建立后,它是拉高客单价的主力

  - heading "成交路径" [level=2]
  - heading "1. 第一次接触:刷到视频(同城流量)" [level=3]
  - paragraph:
    - strong: 看到什么
    - text: :老板在店里,拍某个沙发/床/衣柜的"真实使用动作"(坐下去、拉抽屉、开柜门),配一句话解决一个具体担心
  - paragraph:
    - strong: 会流失掉什么人
    - text: ":"
  - list:
    - listitem: 已经买完家具的(流失无所谓,本来就不是目标)
    - listitem: 还没开始装修的(流失可惜,但会记住你,等他装修到那一步会想起来)
    - listitem: 看着像广告、不真实的(这是最大的流失,所以必须拍得像"随手记录",不能摆拍)
  - heading "2. 产生兴趣:戳中一个具体担心" [level=3]
  - paragraph:
    - strong: 靠什么
    - text: :不是讲"我家质量好",而是讲"很多人担心沙发买回去太宽,门口转不进来——我教你怎么量"
  - paragraph:
    - strong: 会流失掉什么人
    - text: ":"
  - list:
    - listitem: 这条讲沙发,正在挑床的人会划走(所以要3个品类轮着发,覆盖不同阶段的人)
    - listitem: 觉得"这不就是常识吗"的人(流失无所谓,说明他不是小白客户)
  - heading "3. 沉淀在哪里" [level=3]
  - paragraph:
    - strong: 主页
    - text: (看你还发了什么、是不是只发这一种、店在哪里)→
    - strong: 评论区
    - text: (问具体问题:有没有X颜色、X尺寸多少钱、能不能送货)→
    - strong: 到店
    - text: (真人来看、试、量尺寸)
  - paragraph:
    - strong: 为什么不走私信和微信
    - text: ":"
  - list:
    - listitem: 家具这种大件,县城客户不敢线上成交,必须到店看实物
    - listitem: 私信回复成本高(一个人忙不过来),且客人问的问题重复(多少钱、有什么颜色),不如评论区公开回答,其他人也能看到
  - paragraph:
    - strong: 这一步会流失掉什么人
    - text: ":"
  - list:
    - listitem: 主页只有3-5条视频,客人觉得你不正规(所以起号前两周要集中发,攒到15-20条再开始引导到店)
    - listitem: 主页看着是纯广告(全是产品+价格),客人觉得你急着卖货不可信(所以要有流量型和人设型内容穿插)
    - listitem: 地址太远、不顺路(县城就这么大,这个流失没法避免)
  - heading "4. 临门一脚:到店后" [level=3]
  - paragraph:
    - strong: 是什么
    - text: ":"
  - list:
    - listitem: 看到视频里那个沙发/床/衣柜就在眼前,能摸能坐,和视频里一样(真实感)
    - listitem: 老板本人和视频里是同一个人,说话方式也一样(人设一致)
    - listitem: 能现场解决视频里没讲的问题(尺寸、价格、送货、售后)
  - paragraph:
    - strong: 这一步会流失掉什么人
    - text: ":"
  - list:
    - listitem: 只是来看看、还没到决策期的(正常流失,但会记住你,过两周再来)
    - listitem: 价格超预期的(说明视频里没打好预防针,后面要在视频里模糊提一下价格带)
    - text: 现场和视频感觉不一样的(比如视频拍得很专业、到店发现就是个普通小店,落差大)——
    - strong: 所以视频必须拍得"就是这个店",不能过度包装

  - heading "信任证据清单" [level=2]
  - paragraph: "家具这行,客人不信嘴、只信眼睛和手。以下每条都要拍成15-30秒短视频,分开发:"
  - list:
    - paragraph:
      - strong: 样柜能开能动
      - text: (证明:真实、不是摆设)
    - list:
      - listitem: 拍法:手伸过去,拉开衣柜抽屉,柜门打开90度、120度,镜头能看清里面的板材切面
      - listitem: 台词:"很多人问我们的柜子是不是样品,我直接给你拉开看"
    - paragraph:
      - strong: 沙发试坐反应
      - text: (证明:舒适度、承重)
    - list:
      - listitem: 拍法:客人(或老板自己)坐下去的瞬间,能看到沙发下陷程度、坐姿是否自然
      - listitem: 台词:"这个沙发软硬度怎么样,你看他坐下去的表情就知道了"
      - listitem: ⚠️ 如果没有客人配合,老板自己坐,或者拍一个空镜:手按沙发垫,能看到回弹
    - paragraph:
      - strong: 尺寸实测
      - text: (证明:专业、不糊弄)
    - list:
      - listitem: 拍法:卷尺拉开,实测沙发宽度、床的长宽、衣柜进深,数字拍清楚
      - listitem: 台词:"买之前一定要量,这个沙发2米2,你家客厅不到3米就别考虑了"
    - paragraph:
      - strong: 搬运进门演示
      - text: (证明:能送到、不是只能放展厅)
    - list:
      - listitem: 拍法:搬沙发/床进门的过程,能看到门框宽度、转角怎么过
      - listitem: 台词:"最怕买回去进不了门,我们送货师傅X年了,这个门他看一眼就知道行不行"
      - listitem: ⚠️ 待确认:有没有送货师傅、送不送货上门。没有就不拍这条
    - paragraph:
      - strong: 老客户回头/带人来
      - text: (证明:口碑、复购)
    - list:
      - listitem: 拍法:客人进店,老板说"你上次买的床怎么样",客人回答,然后说"今天来看沙发"
      - listitem: 台词:客人说的,不是老板说的
      - listitem: ⚠️ 待确认:有没有老客户愿意出镜。没有就换成"店里来了X个人,有3个是老客户介绍来的"(旁白,不拍脸)
    - paragraph:
      - strong: 店面实景
      - text: (证明:有门店、不是网上倒货)
    - list:
      - listitem: 拍法:从门口拍进去,能看到店名、陈列、光线,15秒扫一圈
      - listitem: 台词:"我们店在XX路XX号,X点到X点都在,随时过来看"
    - paragraph:
      - strong: 板材/面料细节
      - text: (证明:质量不糊弄)
    - list:
      - listitem: 拍法:手摸衣柜板材切面、沙发面料,镜头怼近拍纹理
      - listitem: 台词:"这个板材你看切面,没有刺鼻味,手摸上去是X(平滑/有纹理)"
      - listitem: ⚠️ 不说"零甲醛""E0级",没有检测报告不能说
