目的拆解与账号条件分析

他的目的拆成三件事：1）让本地装修家庭知道挑衣柜时要看柜门、抽屉打开后的位置；2）用现有样柜真实演示给他们看；3）控制在30秒内，一人手机拍完。

这个账号做这件事的最大优势：有能开门、拉抽屉的真实样柜，可以直接演示；老板自己上手，口语自然，不绕弯子。

最大短板：没有客户案例支撑，不能讲"有位业主家门口只有80公分结果柜门打不开"这类真实故事；也不能说尺寸标准，只能靠视觉演示让人看懂。

方向1：问题场景 + 实地演示对比
对应目的：让装修家庭知道要观察开门位置，并通过样柜演示看懂
核心思路：开篇抛出一个装修家庭常遇到的具体场景（柜门挡门、抽屉拉不出来），立刻用样柜演示"开对开门观察够不够位置""拉抽屉看会不会卡床边"，对比"这样行、这样不行"
拍什么：
镜头1：手推开衣柜对开门,旁白"挑衣柜别光看关上的样子"
镜头2：拉开抽屉,演示抽屉拉出来的长度,"这个拉出来40多公分,你家床边留够了吗"
镜头3：再演示一次柜门完全打开后占的空间,"门全开是这么宽,量一下你家过道"
为什么能达到目的：问题场景让人有代入感,样柜演示是真实可见的动作,不用说尺寸数字观众也能看懂"原来要看这个"
方向2：手把手教学 + 第一人称视角
对应目的：用自然口语教会装修家庭挑衣柜时的观察动作
核心思路：老板第一人称,像跟朋友聊天一样说"挑衣柜我教你看两个地方",边说边做,手机跟拍手部动作和柜子,全程口语化不背稿
拍什么：
镜头1：手放在柜门把手上,"第一个,开门看看够不够位置"
镜头2：柜门推开,手比划一下门板占的空间,"你家门口窄的话这个就挡路了"
镜头3：拉抽屉,手拉到底,"第二个,抽屉拉出来这么长,你家床边卡不卡"
为什么能达到目的：第一人称视角亲切,手部动作清楚,口语表达不用专业术语,装修家庭看完能学会在别家店也这么试
方向3：避坑提醒 + 静态对比演示
对应目的：提醒装修家庭别只看衣柜关上的样子,要看打开后的状态
核心思路：开篇说"很多人挑衣柜踩这个坑",然后拍两个状态对比:关上时、打开后,强调"关上好看没用,打开后才知道合不合适"
拍什么：
镜头1：衣柜关着的正面,"关上的时候看着挺好"
镜头2：推开柜门定格,"门一开发现占这么大地方"
镜头3：拉开抽屉定格,"抽屉拉出来才知道够不够用"
字幕辅助标注:柜门占地范围、抽屉伸出长度(不写具体厘米,只画箭头示意)
为什么能达到目的：避坑角度引起重视,静态对比视觉冲击强,不用说话太多,画面本身就能让人看懂区别
我推荐先做：方向1「问题场景 + 实地演示对比」

为什么是它：装修家庭最怕买回去不合适,开篇抛具体场景(柜门挡门、抽屉卡床边)能立刻抓住他们的注意力;样柜演示是真实动作不用编,对比"这样行、这样不行"信息密度高,30秒能说清楚;老板一人拍,手机拍柜门、抽屉动作足够,不需要其他资源

第一周怎么开始：

第一天先自己对着样柜练一遍完整动作:推开柜门-拉抽屉-再推柜门,把要说的话口语化顺一遍,控制在25秒以内
第二天找光线好的时段拍3条,每条开篇问题换个说法("你家门口够不够宽""买衣柜别光看外观""挑衣柜要看打开后"),选自己说得最自然的那条
第三天基础剪辑:删掉停顿和口误,关键动作(开门、拉抽屉)可以放慢0.8倍让人看清楚,加字幕标注"柜门打开占多宽""抽屉拉出来多长",发布时定位本地、带话题#装修避坑

其他方向什么时候做：方向2「手把手教学」适合做成系列第二条,教"除了看开门位置还要看什么"(比如柜子进不进得了电梯、门框);方向3「避坑提醒」可以等发了5-8条教学类内容后,作为总结篇拍"挑家具最容易踩的3个坑",把衣柜、床、沙发的避坑点串起来讲
