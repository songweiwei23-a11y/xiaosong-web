# 🚀 起号方案

## 📌 先说结论

- **建议主攻**：第22计 行业避坑【变现型】，因为他只有一个人、只能手机拍、老板的核心优势就是"帮客户避开尺寸坑"，这一计能把优势直接变成内容
- **备选**：第15计 正确做法VS错误做法【变现型】、第19计 对比改造【变现型】、第10计 情境还原【变现型】——都是单人可拍、用展厅现有条件就能做、直接推动到店
- **明确不做**：第34计 街头采访（需要出门拍陌生人，一周两小时没法执行）、第9计 一人分饰多角（需要表演能力和多套服化道，老板不擅长）
- **多久能看出跑没跑通**：连发 15 条（按每周拍两次、每次出2条的节奏，大约一个月），如果第10条开始有本地人评论区问"老板你店在哪""这个我家也遇到了"，就是跑通了

## 🧮 起号期内容配比

**起号期（到一千粉、流量稳定之前）**：
- **变现型 70%**（第22计 行业避坑 + 第15计 正确做法VS错误做法）
  - 脚本结构：教知识·解题型（场景难题 → 放大危机 → 低成本解决 → 操作步骤12345）
  - 结尾行动指令：**到店**（"不确定自己家怎么量，带上户型图来店里，我帮你看"）
  
- **流量型 20%**（第36计 冷知识）
  - 脚本结构：反常识结论 → 证据/例子 → 原理 → 应用
  - 结尾行动指令：**评论**（"你家踩过哪些坑？评论区说说"）
  
- **人设型 10%**（第7计 一句话设定故事感）
  - 脚本结构：普通动作 + 目标/困境/关系设定 → 故事期待
  - 结尾行动指令:关注**（"关注我，每天分享一个家具避坑小知识"）

**配比逻辑**：
- 主打变现型，因为家具是低频高客单决策，客户搜到你、看完视频就想马上知道"我该怎么办"——这时候给到店指令,转化率最高
- 少量流量型拉新用户进来，但不能多——家具不是高频内容,纯泛知识涨的是泛粉
- 人设型最少,因为起号期先把"我能帮你避坑"这件事证明清楚,人设慢慢立

**过线之后**（一千粉之后）：
- 变现型降到 50%,补上**晒过程·客户案例型**（用第10计 情境还原拍"客户来店里、我帮他现场量、他自己做决定"的全过程）
- 人设型提到 20%,补**讲故事·平凡英雄型**（开店9年遇到的真实故事,证明"这人实在"）
- 流量型保持 20%,继续用冷知识拉新
- 剩下 10% 做固定栏目测试（如"每周一个真实案例"）

**和已定内容定位对上**：
- 定位里说"主力形式是晒过程（现场演示）+ 教知识（避坑）"——变现型的两计就是在做这个
- 定位里说"主打内容:流量50% + 变现40% + 人设10%"——那是账号成熟后的配比;起号期要反过来,**先用变现型证明你能帮到人**,流量型再拉新进来

## 🎯 主攻打法：第22计 行业避坑【变现型】

### 为什么是你能拍的

逐条对照真实资源:
1. **团队一个人**✅ 这一计是老板一个人对着镜头讲,不需要第二个人配合
2. **只有手机**✅ 固定机位拍老板口播 + 手机拍特写镜头（柜门、卷尺、开门动作）,不需要稳定器和灯光
3. **场地是展厅**✅ 展厅里有真实的柜子、沙发、床,可以现场演示"门开不了""床头柜塞不进去"这些坑
4. **每周只能拍两小时**✅ 一条避坑视频拍摄时间 15-20 分钟（摆好手机、讲一遍、拍几个特写）,两小时能出 4-5 条素材
5. **擅长什么**：档案里老板说"先看家里门能不能开,再看柜子摆得好不好看"——**这就是避坑思维**,他日常就在做这件事,只是没拍下来

### 结构公式（套到家具店上）

**点名坑 → 后果 → 识别信号 → 替代方案**

具体展开:
- **点名坑**（前3秒）：买衣柜/床/沙发时大多数人会犯的一个错
- **后果**（第4-10秒）：买回去会怎么样（柜门打不开、床头柜塞不进去、沙发搬不进电梯）
- **识别信号**（第11-25秒）：怎么判断你家会不会踩这个坑（量哪几个地方、看什么参数）
- **替代方案**（第26-40秒）：正确做法是什么（买之前量X、到店试X、选X款式）
- **行动指令**（最后5秒）：不确定自己家怎么量,带上户型图来店里,我帮你看

### 配什么脚本讲

**教知识·解题型**

为什么配它:
- 行业避坑这一计管的是"讲什么坑",教知识·解题型管的是"话怎么讲"——把坑当成"场景难题",把后果当成"放大危机",把识别信号和替代方案当成"低成本解决 + 操作步骤"
- 补上的是**成交理由**：每条视频落在一个成交理由上（专业强、实在不坑、服务好）,结尾给到店指令,完成"看完想来"的转化

### 前3条具体拍什么

#### 第1条：买衣柜前先量这三个地方，不然柜门开不了你就等着哭吧

**爆款元素**：成本（踩坑的代价是柜门开不了、退货麻烦）

**拍摄要点**：
- 开场（3秒）：老板站在衣柜前,手里拿着卷尺，开口第一句"买衣柜前先量这三个地方，不然柜门开不了你就等着哭吧"
- 后果（7秒）：老板走到衣柜侧面,演示"你看,这个柜门要打开90度,至少要空出60公分,好多人家里墙角、床边根本没这个距离,买回去柜门只能开一半,衣服都拿不出来"
- 识别信号（15秒）：
  - 第一个地方：柜子要放的位置到旁边家具/墙的距离（拿卷尺现场量展厅里的距离）
  - 第二个地方：门的宽度（演示"平开门至少要X公分,推拉门可以省空间"）
  - 第三个地方：家里走廊和电梯宽度（"柜子买回去搬不进去,这个最冤"）
- 替代方案（10秒）：买之前拿卷尺把这三个地方量了,拍照记下来;不确定的带户型图来店里,我帮你看
- 结尾（5秒）：我在【换成你的：县城名】开了X年家具店,见过太多买错的,关注我,每天一个避坑小知识

**镜头清单**（一人一机可完成）：
1. 固定机位：老板站在衣柜前口播（手机架在三脚架上,或者放在展厅桌子上垫高）
2. 特写1：卷尺量柜子侧面到墙的距离（手机拿起来近距离拍）
3. 特写2：手拉开柜门的动作（从侧面拍,看得清门打开的幅度）
4. 固定机位：老板总结 + 行动指令

---

#### 第2条：床买1.8米还是2米？先看你家这个地方够不够宽

**爆款元素**：人群（要买床的人）+ 奇葩（很多人不知道要看床头柜位置）

**拍摄要点**：
- 开场（3秒）："床买1.8米还是2米?好多人只看睡得舒不舒服,其实应该先看你家这个地方够不够宽"
- 后果（7秒）：老板走到展厅的床边,"你看,2米的床,两边各要放一个床头柜,每个床头柜宽X公分,再加上人要能走过去,至少要留X公分,整个卧室宽度要有X米。好多人床买回去,床头柜塞不下,或者人只能侧着身走"
- 识别信号（15秒）：
  - 先量卧室宽度（拿卷尺现场演示）
  - 减去床的宽度
  - 看剩下的够不够放两个床头柜 + 两边走人（"一边至少要X公分,不然你半夜起来上厕所都得跳下床"）
- 替代方案（10秒）：卧室宽度不够,1.8米的床就够了,或者床头柜换成窄一点的;拿不准的来店里,我帮你算
- 结尾（5秒）：不确定自己家怎么量,带上户型图来店里,我帮你看

**镜头清单**：
1. 固定机位：老板站在床边口播
2. 特写1：卷尺量床头柜到墙的距离
3. 特写2：老板侧着身从床和墙之间走过（演示"空间不够就得这样"）
4. 固定机位：总结 + 行动指令

---

#### 第3条：沙发不要只看好不好看，先看你家电梯进不进得去

**爆款元素**：最差（买回去搬不进电梯,最冤）

**拍摄要点**：
- 开场（3秒）："买沙发千万别只看好不好看,我见过最冤的,沙发买回去电梯进不去,只能从楼梯扛上去,加了X百块搬运费"
- 后果（7秒）：老板站在展厅的L型沙发前,"你看这种L型沙发、贵妃榻,长度经常超过X米,好多老小区电梯只有X米宽,根本转不过来。就算能进电梯,到你家门口那个拐角,也不一定转得进去"
- 识别信号（15秒）：
  - 先量沙发最长的那一段（现场拿卷尺量展厅的沙发）
  - 再看你家电梯轿厢的宽和深（"大多数电梯宽X米、深X米,你家是多少?不知道的回去量一下"）
  - 还要看家里门口、走廊有没有直角拐角（"拐角最容易卡住"）
- 替代方案（10秒）：买之前问商家能不能拆装(有些沙发可以拆成两段),或者选直排沙发、小一点的尺寸;不确定的拍个视频给我,我帮你看
- 结尾（5秒）：我在【换成你的:县城名】开了X年家具店,见过太多搬不进去的,关注我,买家具不踩坑

**镜头清单**：
1. 固定机位：老板站在L型沙发前口播
2. 特写1：卷尺量沙发最长的那一段
3. 特写2：老板用手比划电梯轿厢和沙发的相对大小（"这么长的沙发,电梯这么宽,你看转不转得过来"）
4. 固定机位：总结 + 行动指令

---

### 边界

**第22计 行业避坑的通用边界**：
- ❌ 不能编造坑：讲的坑必须是真实高频的,不能为了拍视频夸大其词
- ❌ 不能点名同行：不能说"某某店卖的柜子全是坑",只讲"买柜子时大多数人会遇到的坑"
- ❌ 不能说"百分之多少的人会踩坑"：档案里没有数据,不能编
- ✅ 可以说的边界："好多人""大多数人""我见过最多的"——这些是经验判断,不是数据承诺

**对这个号适用的边界**：
- ❌ 不能说"全县最懂尺寸""第一个教你量的"——违反绝对化用语禁忌
- ❌ 不能说"装修公司都不告诉你""商家故意不说"——不能抹黑同行
- ✅ 可以说"好多人不知道""买之前要注意"——帮客户避坑,不是指责别人坑人

## 🔄 备选打法

### 备选1：第15计 正确做法VS错误做法【变现型】

**什么情况下切过去**：
- 第22计 行业避坑拍了10条,观众开始觉得"道理都懂,但还是不会操作"——这时候切到这一计,**现场演示一遍**,手把手教
- 或者发现评论区好多人问"具体怎么量""柜门怎么开才对",说明需要更直观的演示

**怎么套到这个号上**：
错误做法（买衣柜只看款式,不量尺寸）→ 后果（柜门开不了）→ 正确做法（老板现场演示怎么量、怎么开门）→ 原理（为什么要量这几个地方）

**配哪个四大脚本结构讲**：教知识·解题型（和第22计一样,只是呈现方式从"口播讲"变成"现场演示"）

---

### 备选2：第19计 对比改造【变现型】

**什么情况下切过去**：
- 有真实客户案例了（客户买回去发来照片、或者客户来店里现场量完做了决定）——这时候可以拍"改造前:客户家里乱摆、不知道怎么选 → 改造后:我帮他量完、重新规划,现在用得很舒服"
- 或者起号期过了,要补**晒过程·客户案例型**内容,用这一计最合适

**怎么套到这个号上**：
改造前（客户家里家具摆放有问题/想买新家具但不知道怎么选）→ 目标/预算（客户想要什么、预算多少）→ 关键步骤（我帮他现场量、给建议）→ 改造后（客户买回去/摆好的实拍图）→ 复盘（为什么这么选、其他人能学到什么）

**配哪个四大脚本结构讲**：晒过程·火车节（起因:客户来店里 → 关键步骤:我帮他量、他自己做决定 → 结果:买回去用得好）

---

### 备选3：第10计 情境还原【变现型】

**什么情况下切过去**：
- 老板逐渐适应镜头了,可以拍"客户来店里、老板和客户对话"的真实场景——这一计比前两计更自然,但对老板的表现力要求稍高,起号期不建议先用
- 或者有真实客户愿意出镜配合拍摄(征得同意、不拍正脸)

**怎么套到这个号上**：
真实任务（客户来店里挑沙发/床/衣柜）→ 对话/纠错（客户说"我想买这个",老板问"你家电梯多宽?门口有拐角吗?"）→ 旁观学习（观众跟着客户一起听老板讲解）→ 结果（客户做出选择/或者回去量完再来）

**配哪个四大脚本结构讲**：晒过程·火车节（和备选2一样,只是呈现方式从"改造前后对比"变成"现场对话"）

## 🧪 怎么测

### 一次只改哪个变量

**第1-5条**：固定用第22计 行业避坑,只改**选题**（衣柜、床、沙发、餐桌、茶几……每条讲一个品类的坑）
- 目的：测哪个品类的坑观众最关心、评论最多

**第6-10条**：选题固定在数据最好的那个品类,只改**开场钩子**（试3种不同的第一句话）
- 例如都讲"买衣柜的坑",但第一句分别试：
  - "买衣柜前先量这三个地方"（指令型）
  - "好多人买衣柜只看款式,结果柜门开不了"（后果型）
  - "你家衣柜门能打开90度吗?打不开的都是踩了这个坑"（提问型）
- 目的：测哪种开场钩子的前5秒完播率最高

**第11-15条**：开场钩子固定用数据最好的那种,只改**结尾行动指令**
- 分别试："来店里我帮你看"（到店）、"评论区说说你家踩过哪些坑"（评论）、"关注我每天一个避坑知识"（关注）
- 目的:测哪个指令的转化率最高（到店咨询数、评论数、关注数）

### 每计测几条、看什么指标

- **第22计 行业避坑**：至少测10条,看**评论区有没有本地人问地址、说"我家也遇到这个问题"**——这两个信号说明你圈到目标用户了
- **第15计 正确做法VS错误做法**：测3-5条,看**收藏数和完播率**——收藏说明观众觉得有用、想回看,完播说明愿意看完整个演示过程
- **第19计 对比改造**：测3条,看**主页访问量和私信咨询数**——改造前后对比最能建立信任,观众会想"我也想让他帮我看看"

### 什么信号算"这计行",什么信号算"换掉"

| 信号 | 判断 |
|---|---|
| 评论区有本地人问地址、说"我家也这样" | ✅ 这计行,继续 |
| 播放量不低,但评论全是"学到了""有道理"这种泛泛的话,没人问地址 | ⚠️ 选题太泛,要换成更具体的坑（不是讲"买家具要注意尺寸",而是讲"买衣柜柜门开不了"） |
| 前3秒完播率低于40% | ⚠️ 开场钩子没抓住人,重写第一句话（参考"前3条拍什么"里的开场设计） |
| 播放量高、点赞多,但没人咨询、没人到店 | ⚠️ 结尾行动指令不清晰,或者圈到的不是目标用户——检查是不是讲的坑太泛（全国人都关心的）,要换成本地人更关心的坑（如"老小区电梯窄""县城户型小"） |
| 连发5条,每条播放量都低于500 | ❌ 可能是账号标签没打上或者被限流,先检查:①有没有违规（标题、画面）②账号资料是否完整③是否用了违禁词。排查完再发3条,还不行就换备选计 |

## 📅 30天节奏

**按他的真实产能排**：每周拍两次,每次两小时出4条素材,一周发4条,一个月发16条

### 第1-7天：定位 + 素材准备

**任务**：
- 完成账号五件套设置（头像、昵称、简介、背景图）
- 列出展厅里所有可以拍的家具品类（衣柜、床、沙发、餐桌、茶几、电视柜……）
- 每个品类列出3个高频坑（问自己:客户来店里最常问什么、买回去最容易出什么问题）
- 看20个同行账号,收集他们讲过的坑、没讲过的坑

**交付物**：
- 账号搭建完成（可以对外发布）
- 选题池30条（每条一句话：《买X前要注意X,不然会X》）

---

### 第8-14天：第一轮测试（测选题）

**任务**：
- 第1-2次拍摄：每次拍4条,固定用第22计 行业避坑,只改选题（衣柜、床、沙发、餐桌各一条）
- 发布节奏：每天发1条,连发4天,休息3天,再发4条
- 每条发布后24小时记录数据：播放量、点赞数、评论数、评论里有没有本地人、有没有人问地址

**交付物**：
- 发布8条视频
- 数据记录表（标出哪条播放量最高、哪条评论最多、哪条有本地人互动）

---

### 第15-21天：第二轮测试（测开场钩子）

**任务**：
- 选出第一轮数据最好的那个品类（假设是"衣柜"）

## 📊 跑不通先查哪里

### 情况1：播放量低（每条低于500）

**先怀疑**：
- 账号标签没打上（系统不知道推给谁）
- 或者开场3秒没抓住人

**下一步做什么实验**：
- 检查账号资料:简介里有没有写清"家具店""本地县城"这些关键词
- 检查视频标题和话术:有没有出现"买家具""装修""衣柜""沙发"这些行业关键词（系统靠这些关键词给你打标签）
- 重写开场第一句话:对比上面"前3条拍什么"里的开场设计,看你的第一句话是不是太平淡、没有钩子
- 实验:用同一个选题,只改开场第一句话,发3条不同版本,看哪条播放量高

### 情况2：播放量不低,但评论全是泛泛的"学到了",没人问地址

**先怀疑**：
- 讲的坑太泛（全国人都关心）,没有圈到本地人
- 或者结尾行动指令不够具体

**下一步做什么实验**：
- 把选题从"买家具要注意尺寸"改成"老小区电梯窄、买沙发要注意X"——加上本地特征（老小区、县城户型小、X路那一片的楼……）
- 结尾行动指令从"来店里我帮你看"改成"我在【换成你的:县城名】X路开了X年家具店,不确定自己家怎么量,带上户型图来店里,我帮你看"——说清位置,让本地人知道"这人就在我家附近"
- 实验:发3条带本地特征的选题,看评论区有没有本地人出现

### 情况3：有人咨询,但到店的少

**先怀疑**：
- 视频里只讲了"坑",没讲"我能帮你解决"
- 或者主页承接没做好（观众点进主页,不知道你是谁、在哪、怎么联系）

**下一步做什么实验**：
- 在每条视频结尾加一句"不确定自己家怎么量,带上户型图来店里,我帮你看"——明确告诉观众"我能帮你"
- 检查主页:置顶视频是不是选了数据最好、最能代表"我能帮你避坑"的那一条;简介里有没有写清地址、营业时间
- 实验:私信咨询的人,主动问"你家具体是什么情况?方便的话来店里,我帮你现场看看"——把线上咨询转到线下,测试到店转化率
