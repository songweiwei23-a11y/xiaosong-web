# 【本轮内容落实规则确认】

- **原始目的**：流量型观察内容，给全国实体店老板看县城真实生意变化，不是代运营广告
- **比较对象**：国庆前 vs 国庆后（具体日期待拍前统一）
- **当前状态**：尚未采访，无实录、无数字、无已知答案
- **开头锁定**：国庆前后，这条街上的生意到底有什么变化？（逐字保留）
- **资源约束**：一人手机，90秒内，同一条街多家店
- **禁止事项**：不预写商家回答、不编造营收数据、不假装已完成采访、不推销服务

## 第1步：脚本策略卡

**核心问题**：国庆前后这条街上不同类型门店的生意实际发生了什么变化？

**为什么受众关心**：全国实体店老板都在经历类似的节假日波动，想知道别人店里是什么情况、自己的判断是否准确、变化背后可能的原因。

**采用形式**：街头多店采访 + 现场观察记录
- 同一条街选3-4家不同业态门店（如餐饮、服装、便利店等）
- 对每家店主问同一个核心问题：跟国庆前那段时间比，国庆后这几天您店里生意有什么变化？
- 根据回答追问具体维度（来客/客单/时段）、具体事例、判断依据
- 记录可见现象：店内客流、排队情况、店主状态等作为佐证

**材料递进逻辑**：
1. 开篇定位街道和采访任务
2. 第一家店：抛出主问题，获得第一个答案（好/差/没变都成立）
3. 第二、三家店：呈现相同问题下的不同或相似回答
4. 对比中浮现的共同点或差异点
5. 收束：这条街的真实状况就是这样，没有预设结论

**事实边界**：
- 所有店主回答均为"按现场真实回答"，不预设台词
- 不编造"问了一圈发现规律""有人说好有人说差"等采访后结论
- 不把个别店主感受包装成县城趋势或统计数据
- 具体日期（国庆前/后各指哪几天）拍前与店主统一口径
- 可见画面如实记录，不摆拍繁忙或冷清场景

## 第2步：纯文字文案

国庆前后，这条街上的生意到底有什么变化？

我准备问问这条街上几家不同类型的店。

【第一家店-主问】
老板您好，跟国庆前那段时间比，国庆后这几天您店里生意有什么变化？

【第一家店-追问备选】
具体是来的人数、还是每单消费额、还是忙的时段有变化？

能说一件让您这样判断的具体事吗？

您觉得主要原因是什么？

【第二家店-主问】
老板您好，跟国庆前那段时间比，国庆后这几天您店里生意有什么变化？

【第二家店-追问备选】
跟您预期的一样吗？

这个变化从哪天开始的？

有什么应对办法吗？

【第三家店-主问】
老板您好，同样的问题，跟国庆前比，国庆后这几天您这儿生意怎么样？

【第三家店-追问备选】
您店里国庆期间是什么情况？

现在这个状态能持续多久？

【收束】
这就是这条街上，几家店老板的真实感受。

不同店情况不一样，但都是真实的。
