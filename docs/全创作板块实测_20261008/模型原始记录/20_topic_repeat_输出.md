# 📋 3条短视频选题方案

## 选题1：买衣柜,先把这两个位置的门都开一遍

**0️⃣ 视频目的**
流量型——用一个装修家庭都会遇到但容易忽略的细节问题,吸引正在装修的本地用户关注,建立"实在、懂行"的初步印象

**🅰 打法**
36计·第15计 正确做法VS错误做法：错误示范(只看柜子不开门) → 后果演示(柜门/抽屉打不开、卡墙卡床) → 正确示范(开门测试流程) → 原理说明(预留开合空间的重要性)

**1️⃣ 爆款元素**
- 反认知：大多数人以为"合适"就是尺寸能放进去,忽略了开合需要的额外空间
- 低成本避坑：一个动作就能避免买错退货的麻烦

**2️⃣ 开篇钩子**
"买衣柜别光量尺寸,你得把这两个位置的门都开一遍"

**3️⃣ 内容方向及目的（重中之重！）**
- **核心内容方向**：演示挑衣柜时必须测试的开门动作,避免买回去门打不开的问题
- **核心问题与观众价值**：很多人量了尺寸觉得能放下就买,结果装好发现柜门打开会撞墙、抽屉拉不出来,退换货麻烦;这条教他们在店里就能测出来的方法
- **取材与内容推进**：
  - 先拍错误场景:只用卷尺量柜子宽度,觉得能放就行
  - 再拍后果演示:打开柜门演示会撞到墙/床头柜的情况,拉开抽屉演示空间不够的情况
  - 给出正确做法:在展厅现场演示——先开柜门看需要多宽,再开抽屉看向外伸出多长
  - 口播提示:回家量的时候,不光量柜子能不能放,还得量门和抽屉打开后的位置有没有障碍物
- **事实边界**：
  - 已有素材:展厅里的衣柜样柜
  - 需现场获得:柜门打开的实际宽度、抽屉拉出的实际长度(用手机拍摄真实演示,不标注具体厘米数)
  - 不编造:不说"X%的客户犯过这个错",不虚构"有个客户买回去退了三次"
- **关键画面(3个)**：
  1. 手拉开柜门,柜门呈90度打开的状态(展示需要的横向空间)
  2. 手拉开抽屉到底,抽屉完全伸出的状态(展示需要的纵向空间)
  3. 用手比划墙/床的位置,演示如果这里有东西就会卡住
- **场景设置**：家具展厅内,选一组有柜门+抽屉的衣柜样柜,自然光或展厅灯光,手机固定机位拍摄

**4️⃣ 脚本结构**
教知识·解题型：
1. 场景难题(3秒):点出"量了尺寸觉得能放,结果门打不开"这个常见错误
2. 低成本解决(10秒):现场演示正确动作——打开柜门看横向空间,拉开抽屉看纵向空间
3. 具体操作步骤(15秒):
   - 第一步:把柜门完全打开,看需要多宽的位置
   - 第二步:把抽屉全拉出来,看向外伸多长
   - 第三步:回家量的时候,确认这两个位置没有墙/床/门挡着
4. 收尾(2秒):一句话强化"别光看柜子,要看门"

**5️⃣ 结尾行动指令**
"你家衣柜位置量过这两个地方吗?评论区说说"(引导评论互动)

**6️⃣ 执行要点**
- 一人操作:手机架在三脚架或稳定物上,自己走到柜子前演示开门、拉抽屉动作
- 画面简洁:只拍手部动作+柜子,不需要拍全身出镜
- 口播自然:边做边说,语速正常,不需要背稿
- 时长控制:总时长25-30秒,开门+抽屉各演示一次即可,不重复
- 注意事项:不说具体厘米数,不承诺"免费上门量尺寸",只讲方法

## 选题2：网上看着好看的衣柜,为什么我不建议你直接下单

**0️⃣ 视频目的**
流量型——用一个普遍的装修困惑(网购家具靠不靠谱)引发共鸣,强化"到店看实物"的必要性,覆盖更多正在纠结线上线下的用户

**🅰 打法**
四大脚本·聊观点(观点正反型):提出观点(网上图片看不出真实效果) → 正反对比(图片VS实物的3个关键差异) → 强化结论(到店试才能避开的坑)

**1️⃣ 爆款元素**
- 对立/选择:线上买VS线下买,装修人群的高频纠结点
- 共鸣痛点:图片好看但不知道摆家里什么样,怕买错

**2️⃣ 开篇钩子**
"网上看着好看的衣柜,我为什么不建议你直接下单?"

**3️⃣ 内容方向及目的(重中之重！)** 
- **核心内容方向**:对比网购图片与到店实物的差异,讲清为什么挑家具需要现场看
- **核心问题与观众价值**:很多人在网上看图片觉得好看就下单,收到货发现颜色不对/尺寸想象不出/质感差,退换货成本高;这条告诉他们图片看不出的3个关键点
- **取材与内容推进**:
  - 开场抛出观点:网上图片再好看,这3个东西你看不出来
  - 第一个差异:颜色——手机屏幕和家里光线不一样,实物色差你想象不到
  - 第二个差异:尺寸感——图片里看着刚好,摆你家可能显大或显小
  - 第三个差异:开合顺畅度——滑轨响不响、柜门关严不严,图片里看不出来
  - 收尾观点:不是说网上不能买,但家具这种东西,还是得摸摸看看试试
- **事实边界**:
  - 已有素材:展厅样柜
  - 需现场获得:拍一组衣柜的真实颜色、真实大小感、开关门的真实动作
  - 不编造:不说"网上的都是假的",不点名任何电商平台,只讲实物和图片的客观差异
- **关键画面(3个)**:
  1. 手机展示一张网购衣柜的商品图(可用任意电商平台截图打码品牌)
  2. 镜头切到展厅里的实物衣柜,手抚摸柜门表面
  3. 手开关柜门、拉抽屉的动作特写(展示"试"的过程)
- **场景设置**:家具展厅内,选一组样柜,手机拍摄,切换手机屏幕和实物两个画面

**4️⃣ 脚本结构**
聊观点·观点正反型:
1. 提出观点(5秒):网上图片好看,但这3个东西你看不出来
2. 正反对比(20秒):
   - 常见误区:觉得图片上看着合适就下单
   - 正确认知:颜色/尺寸感/开合质量,图片都不准
   - 现场演示:拍实物颜色、拍实际大小、拍开关门动作
3. 强化结论(5秒):家具还是得到店摸摸看看,试了才知道合不合适

**5️⃣ 结尾行动指令**
"你觉得家具能网购吗?评论区聊聊"(引发讨论,增加互动)

**6️⃣ 执行要点**
- 一人操作:手机自拍模式,先拍手机屏幕上的商品图,再切外拍展厅实物
- 画面对比:手机屏幕图片 VS 展厅实物的视觉对比要明显
- 口播语气:不批判网购,只讲客观差异,语气中立、实在
- 时长控制:30秒内,每个差异点点到为止,不展开过多细节
- 注意事项:不说"网上都是骗人的",不诋毁电商,不说"只有我们家才能看实物"

## 选题3：买衣柜,别只看柜子里面——这个地方更重要

**0️⃣ 视频目的**
流量型——用一个反常识角度(大家都看柜内,其实该看柜外空间)制造记忆点,覆盖更多首次装修、不知道怎么挑家具的用户

**🅰 打法**
36计·第36计 冷知识:反常识结论(挑衣柜别只看里面) → 证据(现场演示柜外空间影响使用) → 原理(开合需要额外空间) → 应用(到店怎么测、回家怎么量)

**1️⃣ 爆款元素**
反认知:大家挑衣柜都看内部格局,忽略了柜外开合空间才是决定能不能用的关键

**2️⃣ 开篇钩子**
"买衣柜,90%的人都只看里面——其实这个地方更重要"

**3️⃣ 内容方向及目的(重中之重！)**
- **核心内容方向**:颠覆"挑衣柜看内部"的惯性思维,强调柜外开合空间才是避坑关键
- **核心问题与观众价值**:大多数人挑衣柜关注内部有几层、格局怎么分,结果买回去发现门打不开、抽屉卡住,才知道柜外空间没留够;这条告诉他们一个容易被忽略但很关键的点
- **取材与内容推进**:
  - 开场抛反常识:大家挑衣柜都看里面几层、怎么分,其实柜外这个地方更重要
  - 现场演示:拍一组柜门打开、抽屉拉出的动作,强调"这些都需要额外空间"
  - 讲清原理:柜子再好看,门打不开就是废的;柜外空间不够,柜内格局再合理也没用
  - 给出方法:到店试的时候,把所有门和抽屉都打开一遍;回家量的时候,确认这些位置没障碍物
- **事实边界**:
  - 已有素材:展厅样柜
  - 需现场获得:柜门/抽屉打开的真实画面,不标注具体数据
  - 不编造:不说"90%的客户都犯过这个错"(标题用了也要在执行中替换成"不少人""大多数人"等模糊表达)
- **关键画面(3个)**:
  1. 手指着衣柜内部(代表"大家都看这里")
  2. 镜头拉到柜门打开的位置,手比划"其实这里才重要"
  3. 手依次打开柜门、拉开抽屉,展示需要的额外空间
- **场景设置**:家具展厅内,选一组衣柜样柜,手机固定拍摄或手持跟拍

**4️⃣ 脚本结构**
教知识·拆解型:
1. 反常识开篇(5秒):大家挑衣柜都看里面,其实柜外更重要
2. 讲清原理(10秒):门和抽屉打开需要额外空间,柜外空间不够,柜子就是摆设
3. 操作示范(12秒):
   - 现场演示:把柜门打开,强调"这个位置不能有墙"
   - 现场演示:把抽屉拉出,强调"这个位置不能有床"
   - 口播提示:到店试、回家量,都别忘了这一步
4. 收尾(3秒):一句话强化"柜外比柜内更重要"

**5️⃣ 结尾行动指令**
"关注我,装修少走弯路"(引导关注,积累精准粉丝)

**6️⃣ 执行要点**
- 一人操作:手机固定机位,自己走到柜子前演示
- 口播重点:强调"柜外空间"这个核心概念,重复2-3次加深记忆
- 画面节奏:开篇快速抛观点,中段放慢演示动作,结尾快速收
- 时长控制:30秒内,不啰嗦,每个动作演示一次即可
- 注意事项:标题里的"90%"在口播时改成"不少人""大多数人",避免绝对化表达;不说"只有我知道",不贬低其他商家

## ✅ 选题总结

**三条选题的差异化布局:**
- **选题1(第15计·正确VS错误)**:教具体动作,实操性强,适合快速建立"懂行"印象
- **选题2(观点正反)**:线上线下对比,覆盖更广泛的纠结人群,引发讨论
- **选题3(第36计·冷知识)**:反常识角度,制造记忆点,强化"柜外空间"核心概念

**执行可行性:**
- 全部一人+手机即可完成,无需外拍或他人配合
- 全部使用展厅现有样柜,无需额外道具
- 全部控制在30秒内,符合用户要求
- 无编造数据、无虚构案例、无绝对化承诺

**流量型目的达成:**
- 覆盖装修人群的高频痛点(尺寸/网购/挑选)
- 结尾行动指令均为评论或关注,不引导成交
- 具备传播性:反常识+实用性,适合转发收藏
