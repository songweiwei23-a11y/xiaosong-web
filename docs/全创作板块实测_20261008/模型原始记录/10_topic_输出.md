# 📋 短视频选题方案

根据您的需求，为**青禾家具店**设计了3条**流量型**选题，围绕"衣柜开合空间"这个核心痛点展开。所有选题均基于**一人+手机+展厅样柜**的真实条件，30秒内可完成拍摄。

---

## 选题1：买衣柜前，先看家里门能不能开

**0️⃣ 视频目的**
流量型——用大众都会遇到的真实痛点（家具挡门）吸引正在装修的本地家庭，建立"这家店老板懂生活"的第一印象

**🅰 打法**
36计·第15计 正确做法VS错误做法：错误示范（只看柜子好不好看）→ 后果（柜门打开挡住房门）→ 正确示范（先开柜门模拟，再看摆放）→ 原理（开合空间比外观更影响使用）

**1️⃣ 爆款元素**
反认知——大多数人挑衣柜先看颜值，忽略了开合空间这个"买回去才后悔"的硬伤

**2️⃣ 开篇钩子**
"买衣柜之前，你在店里做过这个动作吗？"
（边说边拉开柜门，往后退一步模拟房门位置）

**3️⃣ 内容方向及目的（重中之重！）**
- **核心内容方向**：用样柜现场演示"柜门+房门"的开合冲突，教会观众一个在店里就能自查的动作
- **核心问题与观众价值**：买回去的衣柜会不会挡门？目标人群（正在装修的家庭）最怕尺寸不合适，这个问题现场就能避免
- **取材与内容推进**：
  1. 选展厅里一个靠墙摆放的衣柜样柜
  2. 第一遍：只拉开柜门，用手机镜头展示柜门打开后占据的空间宽度
  3. 第二遍：往后退一步，用脚或手比划"假设这里是房门"，展示两者重叠的位置
  4. 第三遍：换个角度拉开抽屉，同样演示"抽屉拉出来会不会挡路"
- **事实边界**：只用展厅现有样柜，不编具体厘米数（如"需要预留80cm"），不虚构"有个客户买回去装不下"的案例；如果样柜恰好能演示冲突更好，演示不出来就口播"这个位置要是有门就打不开了"
- **关键画面（3个）**：
  1. 手拉开柜门的特写，镜头跟随门板移动
  2. 人往后退，脚/手比划房门位置，与柜门重叠
  3. 拉开抽屉，俯拍抽屉伸出的长度
- **场景设置**：展厅内，选一个靠墙且周围空间相对狭窄的样柜（更容易模拟真实家庭场景）

**4️⃣ 脚本结构**
教知识·拆解型（按36计的公式走，话这样讲）：
- 开头（3秒）：钩子+错误做法——"买衣柜之前，你在店里做过这个动作吗？很多人只看好不好看"
- 中间（20秒）：
  - 演示错误后果："柜门一开，家里的门就推不动了"（边说边拉开柜门，往后退比划）
  - 正确做法："先开柜门走一遍，再看抽屉拉出来占多大地方"（连续演示柜门+抽屉）
  - 讲清原理："摆得好不好看是其次，能不能用才是关键"
- 结尾（7秒）：金句+行动指令——"先看家里门能不能开，再看柜子摆得好不好看。你家遇到过这种情况吗？评论区说说"

**5️⃣ 结尾行动指令**
评论互动："你家遇到过这种情况吗？评论区说说"

**6️⃣ 执行要点**
- 拍摄前先在展厅找一个靠墙、周围相对拥挤的样柜（更容易演示冲突感）
- 手机固定在三脚架或稳定器上，腰平机位拍摄；拉开柜门时镜头跟随移动
- 不需要测量具体厘米数,全程用"这个位置""这么大地方"等口语表达
- 30秒节奏：开头3秒抓眼球 → 中间20秒演示2-3个动作 → 结尾7秒强化记忆+引导评论
- 收音注意：展厅如果有背景音乐,拍摄时暂时关掉或选安静时段

## 选题2：为什么我劝你别只在图片上挑衣柜

**0️⃣ 视频目的**
流量型——用"图片VS现实"的反差制造共鸣,吸引线上看图选家具的潜在客户,引导他们意识到"到店试用"的必要性

**🅰 打法**
36计·第1计 反向操作：常规做法（网上看图片选衣柜）→ 反向演示（到店开柜门、拉抽屉）→ 真实反应（发现图片看不出的问题）

**1️⃣ 爆款元素**
对比——线上图片 VS 到店实操的差异;反认知——"好看"不等于"好用"

**2️⃣ 开篇钩子**
"网上看图片,这个衣柜挺好看的。但我站在它面前,做了三个动作,发现完全不一样。"

**3️⃣ 内容方向及目的（重中之重！）**
- **核心内容方向**：用同一个样柜,先展示静态外观（对应线上图片）,再演示开合动作,对比"看"与"用"的差异
- **核心问题与观众价值**：图片上好看的衣柜,买回去为什么不好用？目标人群（习惯线上选购的年轻家庭）需要理解"到店试用"能避免哪些坑
- **取材与内容推进**：
  1. 选一个外观有设计感的样柜,先拍静态全景（模拟线上图片的视角）
  2. 镜头推进,开始演示三个动作:拉开柜门、拉开抽屉、蹲下看柜底空间
  3. 每个动作配口播点出图片看不到的细节:"柜门打开占多大地方""抽屉够不够深""下面能不能塞扫地机器人"
- **事实边界**：只用现有样柜演示,不编"有客户网上下单退货"的案例;如果样柜某个设计确实不合理（如抽屉太浅）可真实指出,如果没问题就说"这个还行,但得亲自试"
- **关键画面（3个）**：
  1. 样柜静态全景,模拟线上图片视角（竖屏构图,光线明亮）
  2. 手拉开柜门,镜头从侧面拍摄门板打开的幅度
  3. 蹲下拍摄柜底空间,用手比划高度
- **场景设置**：展厅内,选光线好、背景干净的位置,突出样柜外观;演示时走近样柜

**4️⃣ 脚本结构**
教知识·拆解型（按36计的公式走）：
- 开头（3秒）：钩子+常规做法——"网上看图片,这个衣柜挺好看的"（展示样柜静态全景）
- 中间（20秒）：
  - 反向演示:"但我站在它面前,做了三个动作"
  - 动作1:拉开柜门——"第一,柜门打开占多大地方,图片看不出来"
  - 动作2:拉开抽屉——"第二,抽屉够不够深,叠好的衣服放不放得下"
  - 动作3:蹲下看柜底——"第三,下面能不能塞扫地机器人,这些都得现场试"
  - 讲清原理:"图片只能看外观,用起来顺不顺手,得亲自动手"
- 结尾（7秒）：金句+行动指令——"衣柜不是买来看的,是买来用的。你挑家具会到店试吗?评论区聊聊"

**5️⃣ 结尾行动指令**
评论互动:"你挑家具会到店试吗?评论区聊聊"

**6️⃣ 执行要点**
- 开头静态画面模拟线上图片:竖屏构图,样柜居中,光线明亮,背景干净
- 三个演示动作要连贯,镜头跟随人的移动（从站姿拍全景 → 推进拍手部特写 → 蹲下拍低角度）
- 口播语速适中,每个动作配一句解释,不拖沓
- 如果展厅有其他顾客或员工入镜,提前沟通或选人少时段拍摄
- 30秒节奏:开头3秒静态画面 → 中间20秒三个动作 → 结尾7秒强化观点

## 选题3：衣柜抽屉能不能全拉开?这个细节90%的人不看

**0️⃣ 视频目的**
流量型——用冷知识型反认知点（抽屉能否全拉开）制造"原来还有这个讲究"的传播动机,吸引对家具品质有要求的中高端人群

**🅰 打法**
四大脚本·教知识·拆解型:反常识开篇（大多数人只看抽屉外观）→ 讲清原理（抽屉轨道决定能否全拉开,影响拿取深处物品）→ 操作示范（现场演示全拉VS半拉的区别）

**1️⃣ 爆款元素**
- 冷知识——抽屉能否全拉开是个专业细节,多数人不知道
- 反认知——以为所有抽屉都能拉到底,其实很多只能拉一半
- 痛点——买回去才发现抽屉拉不到底,深处的衣服拿不出来

**2️⃣ 开篇钩子**
"买衣柜的时候,你有没有把抽屉全拉开过?很多人回家才发现,抽屉只能拉一半。"

**3️⃣ 内容方向及目的（重中之重！）**
- **核心内容方向**：用展厅样柜现场演示"全拉轨道VS半拉轨道"的区别,教会观众一个判断衣柜品质的具体动作
- **核心问题与观众价值**：抽屉能不能拉到底,为什么重要?目标人群（注重生活品质的家庭）需要知道这个细节影响日常使用体验,且在购买前就能检查
- **取材与内容推进**：
  1. 选展厅里两个样柜:一个是三节轨道（能全拉开）,一个是两节轨道（只能拉一半）;如果只有一种,就用同一个柜子演示"能拉多少"
  2. 先演示半拉轨道:拉到一半就卡住,口播"这种只能拉一半,深处的东西拿不出来"
  3. 再演示全拉轨道:抽屉完全拉出,口播"这种能全拉开,底下的衣服也能轻松拿"
  4. 给出判断方法:"买之前,每个抽屉都拉到底试试,别光看外观"
- **事实边界**：只用现有样柜演示,不编"三节轨道一定贵XX元"的价格标准,不说"我们家全是三节轨";如果展厅样柜恰好都是全拉轨道,就演示"拉到底"的动作,口播"有些店的柜子只能拉一半,你们遇到过吗"
- **关键画面（3个）**：
  1. 手拉开抽屉,拉到一半卡住,侧面拍摄抽屉与柜体的距离
  2. 手继续用力拉,抽屉完全拉出,俯拍抽屉内部空间
  3. 手指指向轨道位置（特写）,口播"就看这里,三节的能全拉"
- **场景设置**：展厅内,选光线充足的位置,镜头聚焦抽屉与轨道细节

**4️⃣ 脚本结构**
教知识·拆解型:
- 开头（3秒）：反常识钩子——"买衣柜的时候,你有没有把抽屉全拉开过?很多人回家才发现,抽屉只能拉一半"
- 中间（20秒）：
  - 演示问题:"你看,这种拉到这儿就卡住了"（演示半拉）
  - 对比方案:"这种就能全拉开,底下的衣服也能轻松拿"（演示全拉）
  - 讲清原理:"区别就在轨道,两节的只能拉一半,三节的能全拉出来"
  - 操作方法:"买之前,每个抽屉都拉到底试试,别光看外观"
- 结尾（7秒）：金句+行动指令——"抽屉能不能全拉开,用一次就知道差别。你家衣柜抽屉能拉到底吗?评论区说说"

**5️⃣ 结尾行动指令**
评论互动:"你家衣柜抽屉能拉到底吗?评论区说说"

**6️⃣ 执行要点**
- 如果展厅有不同轨道的样柜,提前标记好位置,拍摄时连续演示对比
- 如果只有一种轨道,就演示"能拉多少",口播时点出"有些只能拉一半"作为对比
- 拍摄角度:侧面拍抽屉拉开的过程,俯拍抽屉内部空间,特写拍轨道细节
- 不说具体轨道品牌或价格差异,只讲使用体验的区别
- 30秒节奏:开头3秒抛问题 → 中间20秒演示+对比+方法 → 结尾7秒强化记忆+引评论
- 收音提示:拉抽屉时可以保留轨道滑动的声音,增强真实感

## 📊 三条选题的组合逻辑

1. **选题1（正确VS错误做法）**：最贴合用户原始需求,用"柜门+房门冲突"这个最直观的痛点建立信任
2. **选题2（反向操作）**：扩大覆盖面,吸引习惯线上选购的年轻人群,引导他们意识到"到店试用"的价值
3. **选题3（冷知识）**：深挖专业细节,建立"懂行"人设,吸引对品质有要求的中高端客户

三条均为流量型,覆盖不同认知层次的目标人群,且全部基于**一人+手机+展厅样柜**可完成,30秒内节奏完整。
