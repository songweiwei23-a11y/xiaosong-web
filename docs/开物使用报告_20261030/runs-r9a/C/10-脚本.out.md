【本轮内容落实规则】

- **本条目的**：流量型，围绕“换房后挑沙发，不能只看陈列外观”，引导观众思考家里谁坐得多、平时怎么使用。
- **主体**：门店布艺沙发，出镜人为老周，一人完成演示。
- **比较对象**：  
  - A：只站在沙发前看颜色、款式和摆放效果。  
  - B：把下班回家、家人来家里、客厅活动等使用场景带进来观察。  
  本条不比较两张沙发，也不把坐法差异说成产品性能结论。
- **时间范围**：单条视频60秒，围绕一次门店现场演示完成。
- **取材方式**：门店布艺沙发陈列区，拍整体、坐下、靠背、换位置及周边空间；不拍顾客，不虚构家庭案例。
- **说话人**：老周本人出镜，台词统一使用“我”“我们”“你”。
- **方法**：36计·第32计 换个视角。  
- **说明**：本次对比公式要求数字型极端案例，但现有材料没有可用的对比数字，因此不编造数字，改用“只看外观”和“带入使用场景”的观察差异完成内容。

### 第1步：脚本策略卡

- **核心问题**：换房挑沙发，除了看摆出来的样子，还要先想清楚谁坐得多、平时怎么坐、周边需要留出什么位置。
- **用户目的**：让28—45岁的新婚家庭、换房业主停留，并评论家里沙发平时谁坐得最多。
- **所选形式**：36计·第32计 换个视角。用同一张布艺沙发，从“看陈列”切换到“看家庭使用场景”。
- **材料递进**：  
  1. 先拍沙发整体，呈现常见的挑选视角。  
  2. 再由老周模拟回家坐下、靠背、换位置。  
  3. 最后拍沙发周边空间，引导观众思考家里的真实使用方式。
- **事实边界**：坐法和家庭场景是拍摄演示，不代表老周家庭真实经历，也不代表所有家庭都适合同一种坐法；不补充尺寸、材质性能和顾客反馈。
- **出发点**：围绕**场**｜三有中的**有用处、 有共鸣**｜爆款元素：**人群**，设计在开头点明“换房家庭”，中段把“谁坐、怎么坐、周边怎么活动”拍出来。

### 第2步：纯文字文案

换房挑沙发，很多人先看摆出来好不好看。

但真正要挑之前，你得先想清楚：家里谁坐得最多，平时又是怎么坐。

很多人是这么挑的，站在沙发前看颜色、款式和摆放效果，觉得顺眼，就继续往下看。

但如果只看这一面，家里的使用场景还没有带进来。

你可以先模拟一下，下班回家会不会直接坐下。

是坐在中间，还是喜欢靠着一边。

再想想家里人来坐的时候，常用的是哪个位置，靠背和周边活动会不会有不同。

如果家里还有日常活动，就别只盯着沙发本身，也看看前后左右要不要留出位置。

我做家具12年，现场看沙发时，我会先把这些使用问题问清楚。

不是哪种坐法适合所有人，而是你家怎么用，要先想明白。

你家沙发平时是谁坐得最多？

### 第3步：完整分镜脚本

#### 【镜头1】0—6秒

- **画面**：手机从门店布艺沙发整体开始，缓慢靠近老周和沙发，画面保留周边陈列。
- **台词**：  
  “换房挑沙发，很多人先看摆出来好不好看。”
- **拍摄/收音要点**：第一句直接进入主题，不拍“大家好”。手机靠近沙发时动作放慢，避免环境噪音盖住口播。

#### 【镜头2】6—13秒

- **画面**：老周站在沙发前，手指向沙发整体，再扫过颜色、款式和摆放效果。
- **台词**：  
  “但真正要挑之前，你得先想清楚：家里谁坐得最多，平时又是怎么坐。”
- **情绪波点**：从“看起来好不好看”转到“家里怎么用”，形成第一个信息转折。
- **拍摄/收音要点**：手指到哪里，镜头跟到哪里，不补拍未确认的细节。

#### 【镜头3】13—22秒

- **画面**：镜头从老周正面切到沙发侧面，老周站在沙发前观察，不急着坐下。
- **台词**：  
  “很多人是这么挑的，站在沙发前看颜色、款式和摆放效果，觉得顺眼，就继续往下看。”
- **拍摄/收音要点**：保持站立观察的状态，画面不要加入顾客或其他人物。

#### 【镜头4】22—29秒

- **画面**：老周从站立状态坐到沙发上，镜头拍坐下动作和沙发整体。
- **台词**：  
  “但如果只看这一面，家里的使用场景还没有带进来。”
- **情绪波点**：从“看外观”切到“进入使用场景”。
- **拍摄/收音要点**：坐下动作自然，不夸张表现舒适或不舒适。

#### 【镜头5】29—38秒

- **画面**：老周模拟下班回家坐下，再拍一个靠着沙发的位置；保持同一张沙发。
- **台词**：  
  “你可以先模拟一下，下班回家会不会直接坐下。”
- **拍摄/收音要点**：只拍动作，不把演示说成真实顾客经历。若现场空间允许，可用侧面机位呈现坐下过程。

#### 【镜头6】38—46秒

- **画面**：老周在同一张沙发上换一个位置坐，镜头从中景切近景，拍位置变化和靠背接触处。
- **台词**：  
  “是坐在中间，还是喜欢靠着一边。”
- **拍摄/收音要点**：两个坐法连续拍出，避免快速转场导致动作看不清。

#### 【镜头7】46—53秒

- **画面**：镜头从沙发拉开，拍沙发前后左右的活动空间；老周用手示意周边位置，不测量、不报尺寸。
- **台词**：  
  “再想想家里人来坐的时候，常用的是哪个位置，靠背和周边活动会不会有不同。”
  
  “如果家里还有日常活动，就别只盯着沙发本身，也看看前后左右要不要留出位置。”
- **拍摄/收音要点**：只展示现场看得到的空间关系，不下“这样一定更合适”的结论。

#### 【镜头8】53—60秒

- **画面**：老周坐在沙发旁或站在沙发边，正对镜头；最后回到沙发整体画面。
- **台词**：  
  “我做家具12年，现场看沙发时，我会先把这些使用问题问清楚。”
  
  “不是哪种坐法适合所有人，而是你家怎么用，要先想明白。”
  
  “你家沙发平时是谁坐得最多？”
- **情绪波点**：收回前面的“只看外观”，落到“先想清楚自己家怎么用”。
- **拍摄/收音要点**：最后一句单独留一点停顿，作为评论引导。只保留一个行动指令：评论回答问题。

### 第4步：执行与优化建议

1. **拍摄前准备**
   - 只选门店里一张周边空间较清楚的布艺沙发。
   - 清理沙发周边杂物，保证坐下、换位置和拉远拍摄都安全。
   - 预先确认沙发前后左右能否拍全，避免镜头里出现无法判断的空间死角。

2. **拍摄顺序**
   - 先拍沙发整体和颜色款式。
   - 再拍站立观察、坐下、靠背、换位置。
   - 最后拉远拍沙发周边空间。
   - 建议先拍无口播动作素材，再拍老周完整口播，后期按台词顺序剪辑。

3. **画面优化**
   - 开头用近景或中景，不要一开始拍太远。
   - “只看外观”段落保持正面陈列视角。
   - “带入使用场景”段落改用侧面、俯拍或拉远镜头，让视角变化被看见。
   - 不用夸张表情，不拍未经同意的顾客和路人。

4. **资料缺口**
   - 如果后续想讲具体尺寸、坐深、摆放距离，需要现场实际测量后再补。
   - 如果要加入某类家庭的真实使用案例，需要先取得当事人同意，并记录真实回答。
   - 本条不需要补充木料种类、沙发性能或顾客反馈，避免把观察演示写成产品结论。
