# 口播盲评：6 对，每对选一个（2026-11-01）

每对是同一个选题写出来的两版口播，顺序随机，不标哪版是新的。
只看一件事：**哪一版更像出镜人本人当面在说话、你更愿意拿去拍**。回复格式：`1甲 2乙 3甲 4乙 5甲 6乙`。觉得差不多可以写「平」。
