## 🔍 先说这一行

- **归口**：本地实体店中的 **B服装鞋包类**，主业是大码女装，成交发生在县城商业街门店内。

- **这行的钱怎么赚**：  
  大码女装不是纯靠“一件衣服卖多贵”，而是靠“顾客愿不愿意持续回来试”。这类客人在线上买错尺码、版型不合适的概率更高，线下门店的价值在于：能摸面料、看上身、当场换尺码。  
  这家店目前最能成立的成交理由不是“款式多”或“价格低”——档案没有依据，而是**50码以上有可试穿款**。这解决的是“看着能穿，实际没码”的问题。  
  获客成本卡在一个地方：大码女生很多不是没需求，而是不想进店后被一句“没有你的码”劝退。短视频要先让她确认：这里能试、有人懂、去了不尴尬。

- **客人的决策链路**：  
  大多数不是刷到就立刻下单，而是经历“刷到内容—看主页有没有类似身材的试穿—看门店位置—约朋友或下班路过—进店试穿—现场决定”。  
  连衣裙、外套、裤装都属于需要看版型的品类，决策通常比买基础内搭更长。尤其裤装，腰、臀、腿围和裤长是否合适，顾客更倾向到店确认。

- **时间规律**：  
  服装店的内容和到店高峰通常围绕换季、节前、婚礼宴席、家庭聚会、开学、出游等具体穿衣场景出现。县城门店还要关注下午下班后、周末逛街时段。  
  但“什么时候最旺、什么货卖得最快”目前没有真实数据，待确认后再决定重点拍连衣裙、外套还是裤装。

- **这行老板普遍会犯的错**：  
  1. 把视频拍成“今日上新展示”，镜头里全是衣架和价格，观众看完不知道这件和自己有什么关系。  
  2. 只拍瘦模特或均码模特，大码顾客会默认“我穿不出这个效果”。  
  3. 反复教穿搭技巧，却没证明店里哪件衣服能解决什么问题。顾客学会搭法，不一定会到店。  
  阿梅这个号目前最该防的是第三种：内容可以讲场景，但镜头重点必须回到**不同商品本身上身后的区别**。

- **同行现在都在拍什么**：  
  常见内容是对镜转圈、衣架扫款、喊“显瘦”“遮肉”“显高”、直播切片。大多没效果，不是衣服不能卖，而是缺少可验证的信息：什么尺码能试、哪类身材适合、同一个人换不同商品后哪里不同、到店能不能解决问题。  
  这个号的空档不在于拍得更花，而在于把“试穿这件事”拍具体：**顾客为什么犹豫、阿梅怎么拿码、上身后看哪里、最后怎么判断。**

  - **我的推测**：最有可能成立的回答不是“你家衣服最好看”，而是“终于有能让我试的尺码”“不用站在门口问有没有码”。依据是门店已确认的硬卖点为50码以上可试穿。  
  - 待老板确认。

  - **我的推测**：6年经验会沉淀在“先问什么、先拿哪一类衣服、从哪里看合不合身”这些动作里。它比“我很专业”更适合拍出来。  
  - 待老板确认。

## 一句话定位

**县城阿梅做大码女装，只拍能进试衣间试的50码以上款。**

这句话的立场是：不靠挂图制造想象，直接把“能不能试、穿上是什么样”摆出来。阿梅不是泛泛推荐衣服，而是替大码女生减少“进店没码”的尴尬和反复买错的麻烦。

## 六维地基

### 1. 人设定位

- **原料在哪**：  
  真材料有三句：  
  1. “店主阿梅，老板本人出镜”；  
  2. “做大码女装6年”；  
  3. “50码以上可试穿”。  

  其中，“做了6年”是经历，“老板本人”是身份，“50码以上可试穿”是能反复被镜头证明的经营动作。  
  目前没有“性格好、嘴毒、特别会聊天、特别敢说”等事实，不能擅自给阿梅加性格标签。所谓“专业”，要翻译成未来镜头里的具体行为：顾客问尺码时，阿梅怎么拿衣服；试穿后，阿梅先看哪里；哪件不适合时会不会直接说。

- **人设标签句**：  
  **“做了6年大码女装的阿梅。”**

- **用了哪个入口**：  
  **特殊经历 + 痛点职业**。  
  她不是“卖女装的老板”，而是持续做大码女装6年、面对过“买不到合身衣服”这一具体问题的人。

- **验证**：  
  这个人设立得住，因为6年是已确认事实；大码女装、连衣裙、外套、裤装和50码以上试穿也都有稳定素材来源。  
  但“她很懂各种身材”暂时不能写死，必须靠后续真实试穿、顾客提问和阿梅的判断过程慢慢证明。

- **在同类账号里的位置**：  
  同行常见是“上新主播型”：拿一件衣服讲颜色、价格、显瘦词。  
  阿梅不走“天天喊上新”的路，走的是**“试衣间实拍型店主”**：让观众看到一件衣服从衣架、尺码到上身的完整过程。  
  差别在于：同行让人看款，阿梅让人确认“我到底有没有衣服可穿”。

- **证据链**：  
  1. **真实试穿过程**：同一出镜人换不同商品，镜头看版型和活动空间。  
  2. **尺码问题回答**：围绕真实留言或到店高频问题，一次回答一个。  
  3. **阿梅的选货边界**：待前采确认后，讲真实发生过的选货判断。  
  4. **顾客回访故事**：必须取得顾客同意，且按真实经过拍，不补戏。

- **边界**：  
  不说“谁穿都显瘦”“穿上立刻小一圈”“全县最大码最全”这类无依据的话。  
  不拿顾客身材开玩笑，不把“大码”拍成需要被纠正的缺点。  
  不攻击其他店“没码”“不懂大码”，只讲阿梅店里已经具备的试穿条件。

### 2. 用户定位

- **一句话画像**：  
  **下班路过商业街、想买件能穿出门的衣服，却总在别家问完尺码就转身离开的县城宝妈和上班族。**

- **主攻人群**：  
  1. **精致妈妈**：她们有家庭聚会、接送孩子、走亲访友等具体穿衣需求，买衣服不只看好不好看，更在意合身、活动方便、到店能不能一次试明白。  
  2. **新锐白领**：她们下班后和周末会逛商业街，想要通勤、聚餐、约会都能穿的衣服，对“到店试穿”的接受度更高。

- **为什么是她们，不是另一批**：  
  不主攻纯追逐潮流、只买极低价快时尚的Z世代，因为目前店内已确认的优势不是新品速度、潮流稀缺或价格。  
  也不把银发族作为第一优先级，因为档案没有说明该店的版型、风格是否覆盖这一群体。  
  先抓“有线下试穿需求、常遇尺码问题、就在本地活动”的人，成交链路更短。

- **她们心里真正在想什么**：  
  “我不是不想打扮，我只是懒得再经历一次：看着喜欢，问尺码，店员说没有。”  
  还有一句不会明说的话：“别让我进店以后，变成那个让人尴尬的顾客。”

- **决策链路**：  
  刷到一条和自己身材处境相似的视频后，她会先翻主页：看是不是持续拍真实试穿、有没有自己常穿的连衣裙/外套/裤装、门店是不是本地。  
  接着她可能收藏位置，等下班、逛街、换季或参加活动前到店。她不一定私信，但会在进店时问：“抖音上那个能试50码的，是你家吗？”  
  所以信任要铺在主页，不靠单条硬转化。

- **什么时刻会想起你**：  
  换季翻衣柜发现旧衣服穿不上；临时要参加聚餐、婚礼、家长会；下班逛商业街；线上退了一件不合身的衣服之后。

- **她会搜什么**：  
  - “县城大码女装”  
  - “附近大码女装店”  
  - “大码连衣裙试穿”  
  - “大码裤子哪里买”  
  - “50码女装”  
  地域名称待确认后，应加进昵称、简介和视频标题中。

### 3. 内容定位

- **长期提供什么价值**：  
  **让大码女生先看真实试穿，再决定要不要进店。**

- **内容方向**：  
  选 **A多元四类打底 + 一个单一主题王牌栏目**。  
  原因：阿梅是新号，现阶段还不知道她最适合强口播、故事还是纯试穿；先用多种真实内容测试更稳。  
  但不能全号散着拍，王牌栏目固定为：**《50码以上试衣间实拍》**。  
  不直接选纯单一主题起号，是因为目前未知顾客能否长期出镜、阿梅的表达能力如何、货品更新频率如何；硬做“每天挑战”类栏目，真实素材未必撑得住。

- **当前阶段配比**：

  **第一层：作用配比**  
  - **流量型 55%**：账号处于0—1000粉起号期，首要是让本地陌生用户刷到并记住“这家能试大码”。  
  - **人设型 15%**：阿梅有6年行业经历，但可用的真实故事尚未前采确认，比例不能高，否则容易变成空泛自述。  
  - **变现型 30%**：从第一周就要建立“能试、怎么试、店在哪”的成交认知，但不能一上来每条都像促销广告。

  **第二层：每一块用什么形式做**  
  - **流量型**：以过程型、轻观点、一人分饰两角情景为主。原因是试衣间、衣架、拿码、换装本身就有可拍画面，不必靠长口播。  
  - **人设型**：以真实职业故事、阿梅面对镜头的观点为主。只拍已确认的经历和经营边界，不编顾客故事。  
  - **变现型**：以晒过程、对比试穿、问题解答为主。重点证明商品本身的尺码和版型差异，而不是教观众“怎么搭”。

  **第三层：题材配比**  
  - **主赛道75%：大码女装**。其中连衣裙、外套、裤装轮流出现：连衣裙约25%，外套约25%，裤装约25%。  
  - **目标人群兴趣25%：县城女性的出门、上班、见家长、聚餐、换季等穿衣场景。**  
  这样拍的是“她为什么需要这件衣服”，不是只报款号。

- **主力形式**：  
  档案没有填写“数据最好的内容类型”，新号也没有足够数据，因此不能假定某类已经被验证。  
  起步主力暂定为 **视频配音Vlog式试穿过程**，原因是最贴合门店、试衣间和商品实拍资源，也降低阿梅强口播的压力。  
  连续测试20条后，再看是“过程试穿”还是“痛点口播”更能拉来本地访问和问询。

- **每类内容管哪一段路**：  
  - **刷到**：流量型。让陌生人因为“买不到码”“试衣间实拍”“县城逛街”停下来。  
  - **记住**：人设型。让人知道这不是随便卖衣服的人，而是做了6年大码女装的阿梅。  
  - **信**：变现型。让人看到连衣裙、外套、裤装真实上身和可试尺码。  
  - **联系/到店**：变现型结尾明确说一次到店，不在每条内容里同时要关注、评论、私信。

- **三种视频各怎么拍**：

  **流量型**  
  - 四大脚本：**晒过程型 + 身份确认**。方向是“县城大码女生逛街最怕听到的一句话”。开头演出站在衣架前犹豫的瞬间，接真实拿码和试衣间画面，结尾只引导评论：**“你买衣服最怕卡在哪？评论说说。”**  
  - 起号36计：**第9计·一人分饰多角**：阿梅分饰“想买衣服的顾客”和“店主”，顾客问“有我穿的吗”，店主不空答，转身从50码以上试穿区拿出对应商品。事件重点是身份共鸣，不报价格、不推成交。

  **人设型**  
  - 四大脚本：**讲故事·职业经历型**。方向是“阿梅为什么做大码女装6年”。只讲能确认的真实节点，例如【换成你的真实经历：第一次意识到顾客买不到衣服的事件】。结尾只说：**“想看阿梅店里的日常，关注我。”**  
  - 起号36计：**第7计·一句话设定故事感**：阿梅在整理试衣间，第一句是“这间试衣间，留给每次问我‘有我能穿的吗’的人。”随后只拍一天里真实发生的拿码、挂衣、整理过程。前提是顾客出镜须同意，不同意就只拍阿梅和衣服。

  **变现型**  
  - 四大脚本：**教知识·推荐型**。方向是“买大码裤装，到店试穿先看哪三处”。不是教搭配，而是通过同一人试穿不同裤装，展示腰部、臀腿活动和裤长的差异。结尾只说：**“想试穿的，直接到店。”**  
  - 起号36计：**第19计·对比改造**：同一出镜人、同一试衣间，先后试两条不同的大码裤装，只变商品，镜头记录腰头、臀腿和裤长的区别，阿梅说清各自适用情况。不能把同一条裤子靠换上衣、换姿势来做前后对比。

- **配比核验**：  
  1. **流量型是否与阶段匹配：是。** 新号流量型55%，是最大板块。  
  2. **主力形式是否是已验证数据类型：待验证。** 档案没有历史数据，先用最贴现场的试穿过程测试。  
  3. **大流量是否占主力：是。** 55%的内容围绕大码女生、人货场和“尺码焦虑”展开。  
  4. **题材是否给目标人群兴趣留位置：是。** 25%落在上班、出门、聚餐、换季等真实场景。  
  5. **每个数字能否说明原因：是。** 起号先曝光，真实人设素材不足，变现内容保留但不压过流量。

- **第一条该发什么**：  
  **标题方向：《进店先别问“显不显瘦”，先问有没有能试的码》**  
  - **目的**：流量型。  
  - **打法**：第9计·一人分饰多角。  
  - **事件**：阿梅扮演顾客站在衣架前：“这件最大多少？”随后切回店主身份，带镜头走到50码以上可试穿款区域，拿出一件大码连衣裙挂到试衣间门口。  
  - **为什么第一条拍它**：这条不需要顾客出镜、不需要编案例、不依赖阿梅长篇表达；一秒就把“很多大码女生买不到能试的衣服”这个共同处境拍出来，也让本地用户知道店里有什么。  
  - **结尾**：**“你买衣服最常卡在哪个尺码？”**

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：视频配音Vlog式试穿过程，辅以短口播。阿梅不必一开始硬背长文案，先用拿衣服、看尺码、进试衣间等真实动作说话。  
- **产能**：待确认团队和时间，暂不承诺周更数量。若阿梅单人拍摄，建议先按一次集中拍摄、拆成多条成片的方式执行。  
- **在哪拍**：门店门头、50码以上试穿区、衣架前、试衣间门口。少用白墙口播，场景本身就是可信度。  

### 5. 风格调性（只给结论，≤200字）

- **正向匹配**：选正向匹配。县城实体店要先让人看懂“这是能来试衣服的店”，不需要硬做夸张反差。  
- **气质关键词**：直接、松弛、不回避尺码。  
- **会说的一句话**：“这件先别急着拿，咱们进试衣间看腰和臀腿合不合适。”  
- **不会说的一句话**：“穿上它立刻瘦一圈，谁穿都好看。”  

### 6. 变现定位（只给结论，≤250字）

- **卖什么 + 客单价区间**：大码女装，包含大码连衣裙、大码外套、大码裤装；客单价区间待确认。  
- **成交路径**：抖音本地刷到试穿内容 → 看主页确认门店与尺码 → 到县城商业街门店试穿 → 现场购买。  
- **最缺的信任证据是什么**：不同商品的真实上身过程，以及50码以上具体哪些款能试。  
- 完整的变现拆解请用「商业定位」板块。

## 🧠 记忆点设计

1. **场景记忆点：试衣间门口挂衣动作**  
   - 怎么重复：每条试穿类视频，都从阿梅把一件衣服挂到试衣间门口开始。  
   - 为什么有关：这不是装饰动作，而是在重复“这里能试穿”的核心价值。  
   - **待验证**：看评论区是否自然出现“试衣间”“能试码”等词。

2. **语言记忆点：“先别急着拿，先试。”**  
   - 怎么重复：只用于试穿内容开头或中段，不要每条强塞。  
   - 为什么有关：它表达阿梅和纯挂版卖货的区别——先验证合不合适，再决定买不买。  
   - **待验证**：如果评论区觉得口头禅生硬，就保留动作、不保留语言。

3. **道具记忆点：尺码牌特写**  
   - 怎么重复：每条涉及商品的变现视频，给尺码牌一个短特写，再进入上身。  
   - 为什么有关：大码用户最先关心的是“有没有我的码”，不是先听一串形容词。  
   - **待验证**：不能每条只怼尺码牌；必须和商品实拍、试穿过程连起来。

## ⚡ 差异化：A + 变量B

### 1. 挂版上新 + 试衣间实拍

- **常规A**：同行拿着衣服对镜展示，讲颜色、款式、价格。  
- **变量B**：情境类的 **换场景**，把主画面从衣架前换到试衣间门口。  
- **A+B长什么样**：  
  一条大码连衣裙不是“挂着讲完”，而是“衣架特写—尺码牌—挂到试衣间—上身走两步—坐下和抬手动作—阿梅说适合什么场景”。  
  它服务的是目标用户“我能不能穿”的判断，不是为了拍出所谓高级感。

### 2. 尺码问答 + 一人分饰多角

- **常规A**：口播回答“这件最大到多少码”。  
- **变量B**：人物类的 **一人多角**。  
- **A+B长什么样**：  
  阿梅左边演顾客：“有我能穿的吗？”右边演自己：“先不猜，拿两件进试衣间。”然后进入真实试穿。  
  它服务的是那些不敢进店问尺码的人，先替她把问题问出来。一个人、一部手机就能完成。

### 3. 纯穿搭建议 + 对比改造

- **常规A**：同一件衣服换不同鞋、包、上衣，教怎么搭。  
- **变量B**：行为类的 **对比改造**。  
- **A+B长什么样**：  
  同一出镜人、同一试衣间，连续试两件不同的大码外套，其他条件不变。阿梅只说两件外套在肩背、衣长、活动空间上的不同。  
  这条的主角是卖的衣服，不把效果归给搭配技巧，也更接近到店成交。

## ✅ 自洽检验

1. **遮住字幕，还能看出这个账号的气质吗？**  
   目前有机会做到，但前提是大量画面必须在门店、衣架和试衣间里拍。若长期在白墙前口播，就看不出这是大码女装店。  
   **补救方向**：每条至少保留“拿货—尺码—试衣间”其中两个现场镜头。

2. **只听声音，还能判断出人物性格吗？**  
   目前不过关。档案只确认了阿梅的身份和经历，没有确认她是快人快语、温和还是幽默，不能先替她定腔调。  
   **补救方向**：前3—5条保留阿梅自然说话的原声，观察哪种表达最顺，再决定固定语言风格。

3. **头像、主页简介、单条视频放在一起，会不会像三个不同的账号？**  
   目前容易不过关：如果头像是商品、简介写得很泛、视频又拍成纯穿搭教学，用户会搞不清是卖衣服、教穿搭还是做直播。  
   **补救方向**：三处统一重复“阿梅本人 + 大码女装 + 50码以上可试穿 + 本地门店”四个信息。

## ⚠️ 这个号最大的风险

1. **把“试穿”拍成流水账。**  
   如果只是不断换衣服、转圈、配音乐，观众会看几条就划走。每条必须有一个明确问题：今天解决尺码、版型、场景中的哪一个，而不是把所有衣服都展示一遍。

2. **人设素材不足时硬煽情。**  
   目前阿梅能确认的人设事实只有“老板本人、做了6年、本地开店3年”。没有真实顾客故事、经营边界和个人经历前，不要急着拍“感动顾客”“创业苦难”类内容。先拍真实试穿和真实问答，等前采补齐再做人设故事。
