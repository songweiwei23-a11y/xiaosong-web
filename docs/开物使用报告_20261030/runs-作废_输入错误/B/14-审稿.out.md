### 4. 优化后的完整脚本

## 第1步：脚本策略卡

- **核心问题**：大码女生挑外套时，不能只看颜色和尺码，还要看肩线、前襟、衣摆是否顺。
- **内容目的**：变现型，引导本地大码女生到店试穿。
- **目标人群**：25—40岁的大码女生，尤其是宝妈、上班族。
- **主体**：阿梅本人，以及店内两件真实的大码外套。
- **比较对象**：同一个人、同一个位置、同一站姿，只更换两件外套；不比较穿法和搭配。
- **所选形式**：对比型公式。先拍常见误区，再用两件真实外套对比肩线、前襟和衣摆。
- **取材方式**：选择店内两件实际可试穿、但肩线、前襟或衣摆状态有明显差异的外套。具体哪件呈现什么效果，以现场试穿画面为准。
- **材料边界**：只使用“做大码女装6年”“本地开店3年”“50码以上可以试穿”等已确认事实，不补充价格、顾客反馈或效果承诺。

## 第4步：执行与优化建议

1. **提前选两件真实外套**  
   选择两件都能实际试穿、但肩线、前襟或衣摆状态有明显差异的外套。具体哪件呈现什么效果，以现场试穿画面为准。

2. **固定比较条件**  
   - 同一个试穿者  
   - 同一机位  
   - 同一站姿  
   - 同一光线  
   - 不更换内搭，不增加配饰  
   这样观众才能看出差异主要来自外套本身。

3. **优先拍三个近景**  
   - 肩线：拍衣服与肩部的连接位置  
   - 前襟：拍衣服自然垂落的状态  
   - 衣摆：拍正面和侧面是否形成横向切割感  

4. **素材缺口**  
   当前没有具体外套的颜色、面料、版型和尺码信息，因此脚本没有预设哪件外套一定更适合。拍摄后可根据真实画面，把“第一件”和“第二件”替换成对应款式名称。

5. **剪辑节奏**  
   开头快速切两件外套；中段用相同顺序对比三个部位；结尾保留试衣间和“50码以上可以试穿”的事实信息。不要用夸张瘦身特效或前后拉伸画面。
