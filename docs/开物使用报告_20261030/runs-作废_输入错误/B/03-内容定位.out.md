# 💎 内容定位方案

## 长期价值主张
**让县城大码女生进店前，先看懂大码女装能不能试、合不合身。**

## 内容方向：多元四类还是单一主题

**选：A 多元四类打底 + B 王牌栏目。**

- **A 多元四类**：用晒过程、轻情景、知识问答、真实职业观点，先测试阿梅更适合配音、原声还是短口播。
- **B 王牌栏目**：固定做 **《50码以上试衣间实拍》**。

**为什么这样选：**  
这家店每天真实会发生“顾客问尺码—阿梅拿货—进试衣间—看上身”的工作流，素材稳定，且和大码女装的成交直接相关。新号又没有历史数据，不能一上来赌阿梅的口播能力或顾客出镜资源，所以先用多种形式测试；但全号不能散，必须靠“试衣间实拍”把用户记忆钉住。

**为什么不只做单一主题：**  
如果全号只拍换装、转圈和衣架扫款，十条以后会变成流水账。单一主题能成立，但必须每集都解决一个不同问题，例如尺码、腰臀腿、通勤、聚餐、换季，而不是只换一件衣服。

**为什么不只做多元四类：**  
只做多元内容，用户刷完可能知道阿梅卖衣服，但记不住她和别家有什么差别。王牌栏目要反复强化一个事实：**这里有50码以上可试穿的大码女装。**

## 内容配比

### 作用配比

| 作用 | 占比 | 为什么 |
|---|---:|---|
| 流量型 | 55% | 账号处于起号期，先解决“本地大码女生刷不到这家店”的问题。流量内容围绕尺码焦虑、进店尴尬、县城逛街等大众处境展开，不直接推成交。 |
| 人设型 | 15% | 阿梅有“做大码女装6年、开店3年”的真实基础，但暂时没有足够的顾客故事、选货边界和个人经历，比例不能高，否则容易拍成空泛自述。 |
| 变现型 | 30% | 从第一批内容就要让用户知道：大码女装不是只能挂着看，店里有连衣裙、外套、裤装可试。但新号不能三条里两条都像促销。 |

**切换条件：**  
连续发布20条后，如果本地非关注播放有起色、主页访问增加，但到店问询很少，流量型降到45%，变现型升到40%；如果变现内容带来的主页访问、到店问询明显更多，则保留30%流量型测试，但把更多篇幅给“试穿过程+商品判断”。

### 形式配比

| 形式 | 占比 | 负责哪种作用 | 为什么 |
|---|---:|---|---|
| 晒过程 | 40% | 变现型为主，部分流量型 | 门店最有说服力的不是衣架，而是“拿码—试穿—看版型”的过程。它能把50码以上可试穿拍成看得见的证据。 |
| 情景/段子 | 25% | 流量型 | 用一人分饰“顾客”和“阿梅”，把不敢问尺码、问完没码就走的处境演出来，降低陌生用户理解门槛。 |
| 知识 | 20% | 变现型 | 不讲泛穿搭教学，重点讲大码连衣裙、大码外套、大码裤装到店试穿时该看哪里，让用户知道阿梅不是只会报尺码。 |
| 观点 | 10% | 人设型 | 只讲阿梅真实遇到过的职业判断，例如【换成阿梅真实经历后再拍：为什么某类版型不留货】。 |
| 故事 | 5% | 人设型 | 暂时只留给真实顾客回访或阿梅真实经历。前采没有确认前，不把故事当主力。 |

**为什么主力不是长口播：**  
档案没有“数据最好的内容类型”，所以不能假设阿梅适合强表达。门店、衣架、试衣间和尺码牌都是现成画面，先用配音Vlog和短原声降低拍摄难度；20条后再根据完播和咨询判断是否增加口播。

### 题材配比

- **主赛道75%：大码女装。**  
  大码连衣裙、大码外套、大码裤装轮流拍，各自都有试穿、对比和问答位置，不能长期只拍其中一种。

- **目标人群兴趣25%：县城宝妈和上班族的真实出门场景。**  
  重点不是泛聊生活，而是围绕她们会买衣服的时刻：
  1. 下班路过商业街，临时想试一件衣服；  
  2. 家庭聚会、接送孩子、见家长前，不想再穿“凑合能穿”的旧衣服；  
  3. 换季整理衣柜，发现线上买的衣服尺码不合适。  

### 配比核验

1. **流量型是否与账号阶段匹配：是。** 起号期流量型55%，是最大板块。  
2. **主力形式是否有历史数据支撑：待验证。** 没有历史数据，先选最贴合门店资源的晒过程测试。  
3. **大流量内容是否占主力：是。** 流量内容围绕“大码女生买衣服卡尺码”的身份共鸣，并设计人群、反差等看点。  
4. **题材是否给目标人群兴趣留了位置：是。** 25%内容落在上班、带娃、聚餐、换季等真实场景。  
5. **每个数字是否有依据：是。** 新号先拿曝光，真实人设故事不足，变现内容保留但不压过流量内容。

## 三种视频怎么拍

### 一、流量型

**拍什么方向：**

1. **大码女生进服装店最怕听到的一句话。**  
   拍的是“问尺码前的犹豫”，不是拍卖点。观众会因为“这说的不就是我”停下来。

2. **县城逛街时，哪些人会先在店门口看一眼再走。**  
   拍“想买又不敢问”的真实处境，货只是画面里的载体，不讲价格、不催到店。

#### 四大脚本（薛老师）

- **晒过程型 + 身份确认**  
  骨架：进店犹豫 → 问尺码 → 阿梅拿两件不同尺码 → 进试衣间前停顿 → 留下评论问题。  
  可叠加爆款元素：**人群、反差**。  
  **示范标题：**《大码女生进店前，最怕店员先问这句话》  
  **一句话怎么拍：**阿梅先演站在衣架前不敢问的顾客，再切到店主身份拿衣服，最后不报卖点，只问“你们进店最怕听到哪句？”

- **轻观点型**  
  骨架：亲身观察 → 说出一个判断 → 给出门店现场画面 → 邀请讨论。  
  可叠加爆款元素：**人群、反差**。  
  **示范标题：**《很多大码女生不是不爱逛街，是不想再问“有没有我的码”》  
  **一句话怎么拍：**阿梅在试衣间门口整理衣服，用原声讲一句真实观察，再切尺码牌和试衣间门口动作。

#### 起号36计（小黄）

- **第9计·一人分饰多角：**  
  顾客角色问“这件最大多少？”→ 阿梅角色不直接回答“有”或“没有” → 拿两件不同尺码到试衣间门口 → 顾客角色松一口气。  
  **示范标题：**《“有我穿的吗？”这句话，很多人站店门口都没敢问》  
  **一句话怎么拍：**固定机位拍左右分屏，阿梅演完两句对话后，直接进入拿码动作。

- **第32计·换个视角：**  
  用“试衣间门口一件衣服”的视角，拍它从衣架被取下、看尺码、挂到试衣间门口的过程。  
  **示范标题：**《从衣架到试衣间，一件大码女装会经历什么》  
  **一句话怎么拍：**镜头始终跟着一件衣服走，用配音讲“它先被看款，再被看尺码，最后才轮到上身。”

**结尾行动指令：**  
**“你买衣服最常卡在哪？评论区说说。”**

### 二、人设型

**拍什么方向：**

1. **阿梅做大码女装6年后，形成的一个真实判断。**  
   前提：先补前采，确认她确实有具体选货边界或拿码逻辑。

2. **试衣间里一件小事，让阿梅记住了什么。**  
   前提：必须是已发生的真实顾客事件，顾客不愿出镜就只拍阿梅复述和现场空镜。

#### 四大脚本（薛老师）

- **讲故事·职业经历型**  
  骨架：一个结果或问题 → 当时发生的具体事 → 阿梅怎么做 → 她后来形成的判断。  
  **示范标题：**《做了6年大码女装后，我不太愿意先说“显瘦”》  
  **一句话怎么拍：**阿梅站在试衣间门口，讲【换成真实事件】后，她为什么改成先看腰、臀腿和活动空间。

- **观点立场型**  
  骨架：亲身经历 → 我的判断 → 一个现场动作证明 → 收住。  
  **示范标题：**《我不太建议大码女生只看衣架上的效果》  
  **一句话怎么拍：**先给衣架挂版，再给同一件衣服进试衣间前后的真实变化，阿梅只讲自己的职业判断。

#### 起号36计（小黄）

- **第7计·一句话设定故事感：**  
  阿梅整理试衣间 → 一句话抛出真实困境或关系 → 跟拍当天一个具体工作片段。  
  **示范标题：**《这间试衣间，留给每次问“有我能穿的吗”的人》  
  **一句话怎么拍：**从阿梅把衣服挂到试衣间门口开始，记录当天真实的拿码和整理动作，不补拍顾客对白。

- **第37计·赠送：身份反差：**  
  “女装店老板”这一预期 → 阿梅不急着推款，而是先劝顾客试 → 回到她为什么这么做。  
  **示范标题：**《顾客问我哪件好看，我先让她别急着买》  
  **一句话怎么拍：**只拍阿梅真实说的“先试”，再讲【待确认：一件真实事件】。

**结尾行动指令：**  
**“想看阿梅店里的日常，关注我。”**

### 三、变现型

**拍什么方向：**

1. **同一个人试两件不同大码女装，区别到底看哪里。**  
   变的必须是店里卖的货，人、试衣间、镜头位置保持一致，不能靠换发型、换姿势制造差别。

2. **大码连衣裙、大码外套、大码裤装，到店试穿先确认什么。**  
   重点是帮助用户减少“带回家才发现不合适”的情况，成交理由落在“50码以上可试穿”。

#### 四大脚本（薛老师）

- **晒过程·火车节模型**  
  骨架：顾客提出具体需求 → 阿梅拿两件商品 → 上身看关键部位 → 说清适用情况。  
  **示范标题：**《大码裤装别只看尺码，进试衣间先看这三处》  
  **一句话怎么拍：**同一人试两条不同大码裤装，镜头分别拍腰头、臀腿活动、裤长，阿梅说各自适合什么情况。

- **教知识·推荐型**  
  骨架：圈定人群 → 一个常见难题 → 商品试穿证明 → 适用条件。  
  **示范标题：**《要上班又要接孩子的大码女生，外套先试这两个位置》  
  **一句话怎么拍：**只拿两件大码外套，一件一件试，拍抬手和坐下的活动空间，不教搭配。

#### 起号36计（小黄）

- **第19计·对比改造：**  
  同一人、同一试衣间 → 试穿商品A → 试穿商品B → 只比较肩背、腰臀腿、衣长等商品差异 → 给出适用条件。  
  **示范标题：**《同一个人试两件大码外套，差别不只在颜色》  
  **一句话怎么拍：**镜头位置固定，人物不换，依次穿两件外套，只让商品发生变化。

- **第15计·正确做法VS错误做法：**  
  错误做法：只看吊牌尺码直接带走 → 后果：回家发现不合适；正确做法：到店试穿并确认具体位置 → 解释原因。  
  **示范标题：**《大码连衣裙别只看“能穿”，这一步要进试衣间确认》  
  **一句话怎么拍：**阿梅先拿同一件衣服演示“只看尺码”的判断局限，再拍试穿后要看的肩背、腰部和坐下状态。

**结尾行动指令：**  
**“想试穿的，直接到店。”**

## 内容系列（2个）

### 系列一：《50码以上试衣间实拍》
**一句话讲清：**每集用一件大码女装，解决进试衣间前最容易犹豫的一个问题。

- **出发点：**  
  - 站在：精致妈妈、新锐白领。她们在下班、聚餐、换季、临时出门前，会担心买到“能套上但不合适”的衣服。  
  - 围绕：**货**。每集的核心变量是不同大码女装。  
  - 符合：**有用处**。用户看完知道到店试哪一类、看哪里。  
  - 爆款元素：以**人群、反差、成本**为主，放在标题和前3秒钩子里。例如“能穿”和“穿着合适”的反差。  

- **定量 / 变量：**  
  - 定量：尺码牌特写 → 试衣间上身 → 固定看一个关键部位 → 阿梅给适用判断。  
  - 变量：大码连衣裙、大码外套、大码裤装，以及每集要解决的不同试穿问题。  

- **用哪套打法：**  
  **四大脚本系列**，固定使用“晒过程·火车节模型”或“教知识·推荐型”。

- **目的和结构：**  
  主目的为**变现型**。  
  结构是“顾客处境—试穿过程—商品差异—适用条件”，每集结尾统一：**“想试穿的，直接到店。”**

- **让观众发生哪种变化：**  
  **信任变化。** 用户看到的不是“显瘦”形容词，而是这件衣服具体能否试、上身后哪里不同。

- **变量自检：**  
  变量是：不同的大码连衣裙、大码外套、大码裤装，以及不同的上身判断任务。  
  看点不是单纯试穿、挑选或穿搭技巧，而是“这件商品能解决什么具体试穿问题”。

#### 前10集标题

1. 《大码连衣裙不是能套上就行，进试衣间先看肩背》（人群）  
2. 《同一个人试两条大码裤装，腰和臀腿差别很明显》（反差）  
3. 《下班直接去聚餐的大码女生，外套先试抬手舒服不舒服》（人群）  
4. 《大码连衣裙坐下以后，腰这里会不会勒，试一次就知道》（反差）  
5. 《网上买裤子总退？到店试穿先别跳过裤长这一步》（成本）  
6. 《两件大码外套挂着差不多，上身后肩背不一样》（反差）  
7. 《接孩子、上班都要穿，大码裤装先看活动空间》（人群）  
8. 《大码连衣裙进试衣间，别只照正面镜子》（成本）  
9. 《同一间试衣间，试两件大码外套到底差在哪》（反差）  
10. 《不想再买回家才发现不合适，大码女装先来试》（成本）  

#### 立项检验

- **一句话讲清：成立。** 用户一眼知道是“真实试穿判断”栏目。  
- **追看理由：成立。** 连衣裙、外套、裤装和每次卡住的部位不同，用户会等和自己需求相近的一集。  
- **30集可持续：成立。** 可按品类×问题拆分，例如连衣裙的肩背、腰部、坐下、抬手；外套的肩背、衣长、扣上后的空间；裤装的腰头、臀腿、裤长、坐下状态。  
- **真实性：成立。** 只拍店内真实可试穿款，不用假装顾客随机到店。  
- **和变现联系：成立。** 每集都在证明“50码以上可试穿”，自然指向到店。  
- **元素和句式分布：成立。** 前10集使用人群、反差、成本三类元素，同一句式未连续重复超过3集。

### 系列二：《大码女生不敢问的那句话》
**一句话讲清：**阿梅一人分饰两角，把大码女生进店前不敢问的问题先替她问出来。

- **出发点：**  
  - 站在：精致妈妈、新锐白领，以及有过“问完没码就走”经历的大码女生。  
  - 围绕：**人**。核心是顾客的心理处境和阿梅的回应。  
  - 符合：**有共鸣**。让用户产生“这不就是我”的身份确认。  
  - 爆款元素：以**人群、反差、奇葩**为主，放在开头冲突和标题里。这里的“奇葩”只指尴尬的消费场景，不指向任何同行。  

- **定量 / 变量：**  
  - 定量：顾客角色抛一个不敢问的问题 → 阿梅角色回应 → 用门店真实动作收尾。  
  - 变量：每集换一个真实高频问题或不同消费场景。  

- **用哪套打法：**  
  **36计系列**，固定使用 **第9计·一人分饰多角**。

- **目的和结构：**  
  主目的为**流量型**。  
  结构是“顾客角色的顾虑 ↔ 阿梅角色的回应 → 一个真实动作或反转”。每集结尾统一：**“你买衣服最常卡在哪？评论区说说。”**

- **让观众发生哪种变化：**  
  **身份确认。** 先让用户承认“我也有这个尴尬”，再愿意持续看账号。

- **变量自检：**  
  变量是：不同的顾客问题、不同的生活场景、不同的大码女装需求。  
  看点不是试穿动作本身，而是“这句话到底敢不敢问、问完会发生什么”。

#### 前10集标题

1. 《“有我穿的吗？”这句话，很多人站门口没敢问》（人群）  
2. 《顾客问最大多少码，阿梅没有先回答“有”》（反差）  
3. 《大码女生试衣服，最怕的不是镜子，是这句追问》（人群）  
4. 《“我先看看”背后，可能不是不想买》（反差）

## ⚠️ 不要做什么

1. **不要把账号拍成“今日上新播报”。**  
   衣架扫一排、报颜色和款式，用户无法判断和自己有什么关系。阿梅的核心不是“又来新货”，而是“这里有大码女装可以试”。

2. **不要做“同一件衣服换十种搭法”的主系列。**  
   这样证明的是搭配技巧，不是这家店卖的大码连衣裙、大码外套、大码裤装本身。用户学会技巧后，不一定需要来店。

3. **不要硬拍顾客感人故事或创业苦情。**  
   现阶段没有确认过的老客故事、矛盾经历和个人节点，拍出来容易失真。先把真实试穿、真实问题、真实职业动作拍扎实，故事素材等前采补齐再用。
