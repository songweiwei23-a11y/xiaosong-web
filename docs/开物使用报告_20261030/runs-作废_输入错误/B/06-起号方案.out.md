# 🚀 起号方案

## 📌 先说结论

- **建议主攻：36计·第9计 一人分饰多角。**  
  先集中拍《大码女生不敢问的那句话》。阿梅本人出镜，在店内分别演顾客和店主，围绕“喜欢一件衣服，却担心没有合适尺码”的处境展开。它贴合已定的流量主系列，也不依赖真实顾客出镜。

- **备选 3 计：**
  1. **36计·第32计 换个视角**：分饰多角测满3—5条，阿梅仍不适应对话表演，或同一批作品的前段流失持续偏高时切换。
  2. **36计·第15计 正确做法VS错误做法**：需要补充到店理由时使用，承接《50码以上试衣间实拍》。
  3. **36计·第7计 一句话设定故事感**：阿梅确认了一件自己的真实职业经历后使用，补充人设；没确认前不拍故事。

- **明确不做：**
  1. **街头采访**：没有确认街采人员、收音设备和受访者资源，容易占用经营时间，也不适合拿来做第一批主力。
  2. **整蛊**：没有确认搭档和双方同意的拍摄条件；大码女生的试衣顾虑本身已有共鸣，不需要靠让人尴尬制造反应。

- **多久能看出跑没跑通：**  
  每计先测满 **3—5条**，看得出初步反馈，但不能据此保证起号成功。以**零粉到一千粉、且连续作品流量比较稳定**为参考里程碑；到线的时间无法预先确定，还要看本地目标用户互动、主页访问和有效问询。

## 🧮 起号期内容配比

沿用已定定位，起号期到“一千粉、流量稳定”之前按以下比例排：

| 目的 | 比例 | 拍什么 |
|---|---:|---|
| **流量型** | **55%** | 主拍大码女生问尺码、进试衣间前的顾虑，用人群共鸣吸引陌生人。 |
| **人设型** | **15%** | 拍阿梅本人做大码女装6年的真实职业片段，先补前采，不编故事。 |
| **变现型** | **30%** | 拍店里真实的50码以上可试穿款，让用户看到商品和试穿判断。 |

**集中测试的执行办法：**前20条先以《大码女生不敢问的那句话》作为最集中的主系列，流量内容优先用“一人分饰多角”；其间穿插少量试衣过程和已确认的人设内容。这样不是一开始四种形式平均铺开，也没有放弃原有定位。

### 每一种怎么拍

#### 1. 流量型：第9计 一人分饰多角

- **出发点：**人是担心尺码不合适的大码女生；货是大码女装；场是县城门店。爆款元素选**人群**，看点是“想问尺码，却先说了一句我再看看”的熟悉处境。
- **结构：**顾客角色提出顾虑 → 店主角色回应 → 顾客角色把真正想问的问题说出来。
- **结尾只留一个动作：**“你买衣服时最常卡在哪？评论区说说。”
- **边界：**不报50码以上可试穿这个卖点，不引导到店；对话是情景演绎，不冒充真实顾客原话。

#### 2. 人设型：第7计 一句话设定故事感

- **出发点：**让观众认识做大码女装6年的阿梅，重点拍她真实做过的一个职业动作，不预设她的性格。
- **结构：**一句真实经历的背景 → 阿梅在店内做过的具体事 → 她现在怎么看这件事。
- **拍前必问：**“做这行6年里，有没有一次顾客问尺码或试衣，让你后来调整了自己的做法？当时具体发生了什么？”
- **结尾只留一个动作：**“想看阿梅的门店日常，关注我。”

#### 3. 变现型：第15计 正确做法VS错误做法

- **出发点：**人是想确认衣服合不合身的大码女生；货是店里真实在卖的连衣裙、外套或裤装；场是试衣间。  
  **唯一成交理由：店里有50码以上可试穿款。**
- **结构：**只看吊牌作判断的局限 → 拿出真实可试穿商品 → 进试衣间看一个具体位置 → 如实说这件衣服的试穿结果。
- **结尾只留一个动作：**“想试穿的，直接到店。”
- **前提：**当期商品确实有50码以上可试穿款；不承诺所有款式、所有尺码都有，也不保证所有人都合身。

### 过线之后

先不自动改比例。连续发布20条后按已定定位复盘：

- 本地非关注播放和主页访问起来了，但到店问询少：流量型从55%降到**45%**，变现型从30%升到**40%**，人设型保持15%。
- 如果变现内容已带来较多主页访问和到店问询，逐步把流量型降至**30%**，增加已验证的试穿过程；人设与变现的具体比例，按真实素材和问询结果再定。

## 🎯 主攻打法：36计·第9计 一人分饰多角

### 为什么是阿梅能拍的

- **出镜人已确认：**阿梅是店主本人，不需要找店员或顾客出演。
- **场景已确认：**县城商业街门店、衣架和试衣间都是现成场景。
- **素材有依据：**前采确认，很多大码女生在别的店买不到合身的衣服；第一批只围绕“担心尺码、合身与否”展开。
- **表演能力未知：**不安排长台词和复杂剧情，每个角色只说短句，先用固定机位分别拍，再剪接；在画面标注“情景演绎”。
- **团队和设备未知：**不假设有摄影师或支架。开拍前确认是否有手机及稳定摆放位置；没有稳定机位，先解决机位再拍，不安排复杂运镜。

### 结构公式

**顾客角色的顾虑 → 店主角色回应 → 顾客说出真正的问题 → 留一个讨论口。**

例如：顾客看着裤装说“我先看看” → 店主回应“好，你慢慢看” → 顾客停一下问“这条最大多少码？” → 结束在问题上。

这里的台词是**基于已确认处境的情景演绎**，不是宣称真实顾客说过。

### 配什么脚本讲

配**四大脚本·晒过程型**：看衣服 → 犹豫 → 开口问尺码 → 留下评论问题。

第9计负责让两种角色之间发生对话；晒过程负责把“看、停、问”的动作拍清楚，减少靠长口播解释。此系列只承担流量目的，不补成交理由。

### 前3条具体拍什么

| 标题 | 拍摄要点 | 为什么会让人停下 |
|---|---|---|
| **《大码女生看中一条裤子，开口先说“我再看看”》（人群）** | 阿梅演顾客，在裤装前拿起又放下；切店主回应“好，你慢慢看”；再切顾客问“这条最大多少码？” | 看点是想问却先绕开问题的犹豫。 |
| **《买大码连衣裙时，“有合适尺码吗”为什么这么难开口？》（人群）** | 顾客角色在连衣裙前看尺码牌、停顿；店主角色问“你想看哪件？”；顾客终于指着衣服问尺码。 | 看点是喜欢一件衣服，却担心不能穿的处境。 |
| **《大码女生试外套前，先想确认的那件事》（人群）** | 顾客角色拿起外套，对店主角色说“我想试试，先问一下尺码”；店主回应“你指的是这件吗？”画面停在确认衣服上。 | 看点是进试衣间之前，先要把尺码问明白。 |

三条分别覆盖裤装、连衣裙、外套；每条只用一个处境，不把衣服拍成卖点展示。

### 边界

- 角色转换只是演绎，**不写成真实顾客原话，也不安排别人扮演顾客**。
- 店主和顾客都不演成反面角色，不靠嘲笑身材制造戏剧冲突。
- 不虚构顾客到店、试穿反馈和成交结果。
- 流量视频不讲价格、不报库存优势、不引导私信或到店。

## 🔄 备选打法

### 1. 36计·第32计 换个视角｜流量型备选

- **切换条件：**第9计测满3—5条后，短对话仍让阿梅明显不适应，或前段流失持续偏高；先排除首帧和台词问题，再切换。
- **为什么阿梅能拍：**只用店里的衣服、衣架和试衣间；阿梅完成拿衣、看尺码、停在试衣间门口的动作，不需要顾客出镜。设备和固定机位仍需先确认。
- **第一条拍什么：**《站在试衣间门口，大码女生还想先确认什么？》（人群）  
  从“准备试衣的人”的视角，看一件外套的尺码牌，再走到试衣间门口；配一句“喜欢是一回事，能不能合身，还得试过才知道”。最后问：“你试衣服前最想先确认什么？评论区说说。”
- **四大脚本：**配**晒过程型**，按“看衣服 → 看尺码 → 走到试衣间 → 留问题”讲清过程。
- **换掉条件：**同样测满3—5条，目标人群互动持续弱，且调整首帧后没有改善，就暂停这一视角，不把衣架和试衣间拍成重复空镜。

### 2. 36计·第15计 正确做法VS错误做法｜变现型备选

- **切换条件：**从第一批内容起穿插使用；当流量内容有本地关注，但用户持续问“能不能试”“衣服合不合身”时，提高这一计的占比。
- **为什么阿梅能拍：**店里有试衣间，且有50码以上可试穿款；阿梅能拿真实商品展示。**试穿人及该件具体尺码待拍前确认**，不假设阿梅本人适合所有款。
- **第一条拍什么：**《大码连衣裙只看吊牌还不够，进试衣间先看肩背》（人群）  
  先拍只看吊牌无法判断肩背活动空间；再展示真实的50码以上可试穿连衣裙，由确认合适且同意出镜的人试穿，拍正常抬手时肩背的状态，如实说明这一件的结果。画面中的尺码牌须与商品对应。
- **四大脚本：**配**晒过程·火车节模型**：“为什么要试 → 拿实际商品 → 试穿看肩背 → 这件的真实结果”。它补上可见的试穿证据和成交理由。
- **换掉条件：**测满3—5条后，地址或试穿问询仍少，先检查是否拍到了对应尺码、上身过程和结果；证据补齐仍无改善，再暂停这一表达，换试穿问题，不编造效果。

### 3. 36计·第7计 一句话设定故事感｜人设型备选

- **切换条件：**阿梅讲出并确认一件具体职业经历后，再插入发布；没有事件就暂缓，不为凑人设编故事。
- **为什么阿梅能拍：**她本人做大码女装6年、在本地开店3年，店内整理衣服和试衣间的工作场景真实存在；不依赖顾客出镜。
- **第一条拍什么：**《做大码女装6年，阿梅记住的一次试衣经历》  
  开拍前先问：“是哪一次？顾客提出了什么问题？你当时做了什么？后来有没有改变做法？”确认后，用阿梅整理衣服的真实动作作画面，讲清那件事；未确认前不写具体情节。
- **四大脚本：**配**讲故事·职业经历型**：“具体事件 → 阿梅的动作 → 她的判断”，补的是对阿梅本人的认识，不讲成交卖点。
- **换掉条件：**测满3—5条后，观众记不住具体事件、关注反馈弱，先删掉空泛感悟；若仍缺真实细节，就暂停故事，回到真实职业动作，不虚构波折。

## 🧪 怎么测

### 一次只改一个核心变量

先固定第9计的角色结构、场景和结尾，**第一轮只测试开篇问题**：同样从顾客角色开口进入，观察哪一种尺码顾虑更能让人停留。不要同时换拍法、时长、表演方式和结尾。

第一轮之后，再单独测呈现方式：例如保留同类问题，只比较原声对话与后期配音。每轮记录变化项，避免把结果全归因于打法。

### 每计测几条、看什么

| 打法 | 样本 | 主要看什么 |
|---|---:|---|
| 第9计 一人分饰多角 | 3—5条 | 非关注播放、前段留存、完播；评论是否来自有大码试衣需求的人。 |
| 第32计 换个视角 | 3—5条 | 同样看非关注播放、前段留存、完播和目标人群互动。 |
| 第15计 正确做法VS错误做法 | 3—5条 | 关于具体尺码、试穿、地址的有效问询，以及实际到店反馈。 |
| 第7计 一句话设定故事感 | 3—5条，且每条事件先确认 | 主页访问、关注和观众对阿梅本人或具体事件的反馈。 |

**算“这计行”：**连续几条相对本号其他作品表现更稳定，并且评论或问询来自目标人群；流量型不只看播放，变现型不只看点赞。

**算“该换掉”：**测满3—5条后，先按诊断树改一个问题；再次测试仍持续弱、且没有目标用户反馈，就暂停这计，切到对应备选。样本未满时只修改单条执行，不给打法判死刑。

## 📅 30天节奏

**产能待确认：**档案没有团队人数、设备和每周可拍次数。以下按“每周集中拍摄一次、营业间隙完成”的**排期假设**执行；先问阿梅能否留出这段时间，做不到就顺延，不以日更为目标。

| 时间 | 任务 | 交付物 |
|---|---|---|
| **第1周** | 确认手机、稳定机位、阿梅可拍时段；核对当期50码以上可试穿商品；准备并拍第9计首批。 | 3条第9计素材；记录每条开篇与商品品类。 |
| **第2周** | 发布首批，按前段留存和评论检查开篇；继续拍同一系列，不同时改变多个变量。 | 第9计累计达到3—5条；一份逐条反馈记录。 |
| **第3周** | 根据结果决定继续第9计还是测试第32计；穿插拍第15计真实试穿。 | 备选流量素材与试穿素材；记录真实尺码、试穿人授权和结果。 |
| **第4周** | 复盘本地目标用户互动及试穿问询；完成一次阿梅职业经历前采，有真实事件再拍第7计。 | 留下表现较稳定的流量形式；整理下一批试穿问题；人设事件确认稿或“待补素材”清单。 |

**发布数量以实际完成量为准。**30天内未测满某计的3—5条，就延续测试，不为了赶进度降低真实性。

## 📊 跑不通先查哪里

| 现象 | 先怀疑什么 | 下一步做什么实验 |
|---|---|---|
| **有曝光，开头很快流失** | 第一秒没出现顾虑，角色介绍太长。 | 保留同一情景结构，只改首句，把“这条最大多少码？”放到第一句，再测一批。 |
| **播放和评论有了，但大多不是目标用户** | 话题太泛，只有逛街情绪，没有大码试衣处境。 | 保留第9计形式，只把问题改成具体的“大码裤装、连衣裙或外套尺码顾虑”，观察评论质量。 |
| **有人看试穿，却很少问尺码或到店** | 画面没证明对应尺码能试，或只拍了衣架、没拍试穿结果。 | 保留同一类试穿问题，补拍对应尺码牌、试穿关键位置和真实结果；只保留“直接到店”一个结尾指令。 |
