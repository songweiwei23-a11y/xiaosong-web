2. **“先判断，再推荐”的顺序。** 能让观众先获得判断方法，也适合阿梅展示专业能力。
3. **镜前试衣的具体场景。** 门店有试衣间，档案也确认有50码以上可试穿款，具备承接条件。
4. **用损失提醒收尾的机制。** 可以提醒“价格高不等于适合”，但不必用绝对化的「白搭」。

### 需要优化

1. **核实客人原话。** 未核实前，不把「第一句话就是」写成阿梅店里的经营事实。
2. **把“站不对”说清楚。** 原稿看不出是站姿不对、位置不对，还是衣服剪裁不合适；建议改为“只看价格，不看合不合身”。
3. **补上能操作的判断。** 比如镜前看肩部、腰腹和活动时的舒适度，让“看看剪裁”有具体落点；这些是试穿判断建议，不是对所有人的统一审美标准。
4. **去掉绝对结论。**「买再贵也白搭」可改为“价格高，也不代表适合自己”。
5. **补一个变现行动。** 既然主目的判断为变现型，完整脚本结尾可只保留一个动作，例如“到店试穿”。
