## 4. 🧰 拍摄清单

- **必备**：手机 + 手机支架或三脚架 + 两件店内真实可试穿的大码外套 + 干净衣架 + 试衣间外一块固定站位。
- **加分项**：  
  - 领夹麦：解决试衣间附近环境声、街道声影响口播清晰的问题。  
  - 小补光灯：放在阿梅正前方偏左或偏右的位置，补亮肩线、前襟褶皱；没有补光灯就站在门口自然光较亮的位置拍。  
  - 蓝牙遥控器或手机定时拍摄：阿梅一个人也能完成固定机位下的换外套和全身镜头。  
- **道具与场地**：两件外套、同一套内搭、试衣间、试衣间外墙面或地面标记、衣架区域。地面可贴一小段不显眼的胶带，标出阿梅每次站立的位置。

## 5. ⚠️ 这条片子最容易翻车的 3 个地方

- 【比较条件变了】第一件和第二件拍摄时，阿梅站位、内搭、手机高度变了，观众无法判断变化来自哪件外套 →【怎么避】先用胶带标出脚尖位置，手机支架全程不挪，拍完第一件的正面和侧面后再换第二件。  
- 【为了做效果硬拉衣服】拍肩线、前襟或衣摆时用手拉平、收腰，画面呈现的就不是外套自然状态 →【怎么避】阿梅只用手指指出位置，手离开后停一秒再拍，让布料自然垂落。  
- 【标签或字幕出现未确认数字】衣服尺码标签、字幕里出现脚本和档案之外的尺寸信息，造成事实不一致 →【怎么避】镜头4的标签保持虚焦；字幕只使用“肩线”“前襟”“衣摆”“50码以上可试穿款”。
