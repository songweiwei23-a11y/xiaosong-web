# 🚀 起号方案

## 📌 先说结论

- **建议主攻：第1计 反向操作**
- **主系列：**《下午四点，成都厨师出摊了》
- **主力形式：**晒过程型
- **主攻目的：**流量型
- **为什么选它：**  
  这个账号目前最稳定的真实素材，是每天备菜、掌勺、下午四点出摊。第1计不需要顾客配合、不需要演员、不需要复杂设备，只要把“大家想先看成品”的观看顺序倒过来，先拍空摊、备菜和操作，再拍出摊结果，就能形成看点。

- **备选：**
  1. **第36计 冷知识**：当现场确实有顾客问过、厨师也能现场证明的做法时切入。
  2. **第10计 情境还原**：一元火锅的具体规则、真实点单流程确认后，用于变现内容。
  3. **第31计 南北/地域差异**：补采到成都与南乐之间真实存在的口味、吃法差异后再使用。

- **明确不做：**
  1. **街头采访**：当前没有确认拍摄人员、采访安排和受访者授权，无法稳定生产。
  2. **角色扮演、整蛊、多人剧情**：团队人数和演员资源未确认，且会偏离“真实出摊”的内容定位。

- **多久能看出跑没跑通：**  
  主打法先连续测 **5条**，备选打法各测 **3—5条**。以“零粉到一千粉、流量逐步稳定”为阶段线，同时看非关注播放、完播、评论质量和主页访问。单条播放高，不能直接判定打法跑通。

### 2. 三种视频具体怎么拍

#### 流量型：用第1计 反向操作

- **出发点：**  
  人：成都来的川菜厨师；  
  货：川味串串火锅、川味烧烤、川菜；  
  场：下午四点出摊现场；  
  爆款元素：反差、人群。
- **事件结构：**  
  观众以为先看成品 → 先展示空摊和准备过程 → 拍关键操作 → 最后完成出摊。
- **配合脚本：**  
  **晒过程型·任务挑战结构**  
  “今天要完成什么出摊准备” → “中间完成哪一步” → “最后是否准时出摊”。
- **结尾指令：**  
  “你下班前最想先看哪一种？评论区说说。”

#### 人设型：用第37计 赠送：身份反差

- **出发点：**  
  “做川菜9年”的厨师身份，与每天重复整理、备菜、出摊的真实动作形成生活化反差。
- **事件结构：**  
  先给掌勺画面 → 切到出摊前的细碎准备 → 说清来南乐半年后的真实工作状态 → 回到下午四点出摊。
- **配合脚本：**  
  **聊观点型·观点立场结构**  
  亲身工作现场 → 厨师本人判断 → 用一个真实动作证明 → 收回到当天出摊。
- **结尾指令：**  
  “想继续看我下午四点出摊，关注我。”

#### 变现型：用第10计 情境还原

- **出发点：**  
  人：掌勺厨师；  
  货：实际售卖的三类品品类；  
  场：真实出摊和点单现场；  
  成交理由：**手艺看得见**或**一元火锅规则讲得清**，一条只选一个。
- **事件结构：**  
  真实点单问题或实际出品任务 → 厨师现场处理 → 展示出品 → 说清已确认的到店信息。
- **配合脚本：**  
  **晒过程型·火车节模型**  
  起因 → 关键操作 → 出品结果 → 到店指令。
- **结尾指令：**  
  “想看今天的出品，下午四点后到店问我。”

> 一元火锅具体对应什么、如何计价、是否存在其他规则，目前档案没有完整说明。规则确认前，不用“一元怎么点”做变现标题。

### 4. 和已定内容定位的对应关系

## 🎯 主攻打法：第1计 反向操作

### 1. 为什么是你能拍的

目前确认的真实资源有：

- 有固定出镜人：成都来的川菜厨师本人；
- 有固定工作场景：店内、操作台、出摊现场；
- 有固定发生时间：每天下午4点出摊；
- 有固定可拍内容：备菜、掌勺、出摊；
- 有三个可轮换的真实品类：川味串串火锅、川味烧烤、川菜；
- 不依赖顾客出镜，不需要演员配合；
- 不需要复杂剧情，一部手机即可完成基础拍摄。

目前没有确认团队人数、相机、灯光、收音设备和每周拍摄次数，所以执行方案按“单人手机跟拍”设计。设备升级前，不增加复杂调度。

### 2. 结构公式

**常规预期：先看成品、再介绍味道**  
→ **反向呈现：先拍空摊和出摊前准备**  
→ **真实操作推进**  
→ **最后展示完成的出摊状态**

套到这个账号上就是：

> “下午四点要出摊，但第一镜头不拍成品，先从还没准备好的现场开始，跟着成都厨师把当天的一项出摊任务拍完。”

反差来自观看顺序，不编造冲突，也不把任何同行、顾客写成反面角色。

### 3. 配什么脚本讲

- **第1计 反向操作**负责：片子里先发生什么、后发生什么。
- **晒过程型·任务挑战结构**负责：把当天出摊任务讲清楚。
- **它补上的内容：**
  - 反向操作补流量入口；
  - 晒过程补真实过程；
  - 下午四点出摊补系列记忆点；
  - 三类品类轮换补账号的长期内容供给。

这条打法暂时不承担成交，不在流量视频里讲价格、优惠、到店和卖点。

### 4. 前3条具体拍什么

#### 第1条

**标题：**  
《下午四点出摊，先不拍成品，看看成都厨师从空摊开始忙什么》（反差）

**拍摄要点：**

1. 首帧拍还没有完成准备的操作台，不先放成品特写。
2. 出镜人说：  
   “下午四点要出摊，今天先不拍成品，跟我看出摊前这一段。”
3. 连续拍当天真实发生的准备动作。
4. 不替动作命名，不清楚的步骤直接由厨师现场说。
5. 最后拍完成后的摊位和出摊动作。
6. 结尾：  
   “你下班前最想先看哪一种？评论区说说。”

#### 第2条

**标题：**  
《做川菜9年的人，下午四点出摊前先拍哪一步？》（人群）

**拍摄要点：**

1. 首帧拍厨师正在操作，不先讲履历。
2. 旁白补充已确认事实：  
   “他是成都来的川菜厨师，做川菜9年，每天下午四点出摊。”
3. 只拍当天真实的一项准备过程。
4. 中段让厨师说清楚这一步在当天出摊里起什么作用。
5. 最后切到川味串串火锅、川味烧烤或川菜中的当天品类。
6. 结尾：  
   “你还想看出摊前哪一步？评论区说说。”

#### 第3条

**标题：**  
《川味串串火锅出摊前，先把准备过程拍给你看》（头牌）

**拍摄要点：**

1. 第一镜头拍当天实际准备的串串火锅相关操作。
2. 不先报价格，不先讲“一元”。
3. 用近景拍手部、食材状态和操作台变化。
4. 只保留一条主线：从准备开始，到出摊前完成。
5. 结尾展示已经完成的现场，但不加入顾客评价。
6. 结尾：  
   “你吃串串时，最想先看哪一步？评论区说说。”

### 5. 边界

- 不把“反向操作”拍成虚假的突发事件；
- 不为了反差故意延误出摊；
- 不把没有确认的动作说成固定流程；
- 不用“一元”制造悬念后却不解释规则；
- 不用“最正宗”“全南乐最好”等无法证明的结论；
- 不安排店员假扮顾客；
- 不编顾客反应、顾客评价和顾客故事；
- 不把流量视频改成促销视频。

## 🔄 备选打法

### 备选一：第36计 冷知识

#### 什么情况下切过去

连续发布第1计内容后，评论区出现真实的做法问题，例如用户询问某一步为什么这样处理，且厨师能在现场演示并解释。

#### 一句话套法

> 从一个外行容易忽略的做菜细节切入，现场展示这一步，再回到当天的川味串串火锅、川味烧烤或川菜。

#### 配合脚本

**教知识型·拆解结构：**

常见误区 → 现场操作 → 厨师解释 → 回到消费者能看懂的结果。

#### 示例标题

《川味烧烤上火前，为什么不急着做下一步？》（反差）

标题里的具体动作必须先由厨师确认。未确认前，不把“哪一步”写死。

#### 换掉条件

如果连续3条都只能靠口头解释，没有清晰动作和现场证据，暂停这计，回到第1计拍过程。

### 备选二：第10计 情境还原

#### 什么情况下切过去

一元火锅的具体规则、实际点单方式、到店时间和顾客常问问题全部确认后使用。

#### 一句话套法

> 把真实点单问题放到出摊现场，由厨师边准备边讲清楚，最后展示实际出品。

#### 配合脚本

**晒过程型·火车节模型：**

点单问题 → 厨师准备 → 出品过程 → 规则和到店信息。

#### 示例标题

《一元火锅怎么点，先把真实规则讲清楚》（成本）

#### 成交理由

只突出一个：**低门槛点单规则**。  
前提是“一元”具体规则已经由店方确认，视频字幕和口播保持一致。

#### 结尾指令

“想按这个规则吃，下午四点后到店问我。”

#### 换掉条件

如果评论区连续出现规则追问，而视频无法在一条内讲清，先暂停强引导标题，补拍规则说明和主页信息。

### 备选三：第31计 南北/地域差异

#### 什么情况下切过去

补采到真实的成都与南乐口味、吃法或点单差异，并确认厨师本人确实经历过。

#### 一句话套法

> 同一道川味菜品或同一个吃法，先说成都厨师自己的做法，再展示南乐本地用户的真实反馈，不做高低判断。

#### 配合脚本

**聊观点型·观点立场结构：**

亲身经历 → 厨师判断 → 现场操作 → 邀请本地用户表达习惯。

#### 示例标题

《成都厨师来到南乐，吃串串时先看哪一处？》（人群）

“先看哪一处”必须对应一个真实动作，不能空讲个人偏好。

#### 换掉条件

如果只能说“成都和南乐口味不一样”，没有具体事件、具体动作和具体差异，暂停使用。

## 🧪 怎么测

### 1. 主打法怎么测

- **第1计 反向操作：测5条**
- 前5条只固定：
  - 出镜人；
  - 下午四点出摊场景；
  - 晒过程结构；
  - 结尾评论指令。
- 每条只更换一个变量：当天品类或出摊任务。

### 2. 一次只改哪个变量

第一轮只改**开场画面和第一句话**，不同时更换标题、时长、剪辑节奏和结尾。

例如：

- 空摊开场；
- 手部操作开场；
- 出摊倒计时开场。

其他内容保持同一套结构。

### 3. 看什么指标

重点看：

- 非关注用户播放占比；
- 前段停留；
- 完播率；
- 评论里是否出现“南乐”“几点出摊”“今天卖什么”等本地相关问题；
- 主页访问；
- 新增关注。

### 4. 什么信号算行

满足以下信号，继续放大第1计：

- 5条中至少有3条带来真实非关注播放；
- 评论不只是“看起来好吃”，而是出现出摊时间、品类和现场操作问题；
- 主页访问逐步增加；
- 三类品类轮换后，用户仍能认出“成都厨师、下午四点出摊”。

### 5. 什么信号算换

出现以下情况，换开场，不立刻换打法：

- 有播放但前3秒流失明显：先改首帧和第一句；
- 完播低：删掉重复操作，提前放出当天任务；
- 播放高但没有本地评论：加强“南乐”和“下午四点出摊”的画面识别；
- 连续5条都没有有效停留：切第36计，用具体问题做开场；
- 变现内容有人咨询但规则说不清：暂停第10计，先补信息。

## 📊 跑不通先查哪里

### 情况一：曝光少，非关注播放低

- **先怀疑：**开场只是拍厨房日常，没有让陌生人马上知道发生什么。
- **下一步实验：**保留第1计不变，把第一镜头改成“空摊→下午四点任务字幕”，第一句话直接说今天要完成的出摊任务。

### 情况二：前3秒有人看，后面完播差

- **先怀疑：**准备过程太散，观众不知道什么时候结束。
- **下一步实验：**开头明确“今天只拍一项准备”，中间删掉重复动作，最后提前露出完成后的出摊状态。

### 情况三：播放有，但主页访问和本地评论少

- **先怀疑：**用户看到了做菜，却没有记住南乐、下午四点和三类品类。
- **下一步实验：**不增加硬广，只在首帧、字幕和结尾各出现一次已确认信息：南乐、下午四点出摊、当天具体品类。
