# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

这是一个典型的**本地餐饮到店生意**：短视频的任务不是把菜卖到全国，而是让南乐本地人在“今晚吃什么、和谁去吃、怎么点不踩空”时想起这家店，并愿意到现场消费。

餐饮的钱通常由两部分组成：一是单次消费，二是复购和同行加点。对这家店来说，**川味串串火锅、川味烧烤、川菜**的消费理由并不完全一样：

- 川味串串火锅更适合承担“先来试试”的入口，尤其是“一元火锅”这个信息容易让人停下来问规则；
- 川味烧烤更容易承接下班、朋友小聚、晚间加菜等场景；
- 川菜更能承接“正经吃顿饭”“带家人吃晚饭”的需求。

所以账号不能只拍一元火锅，也不能只拍厨师做菜。只拍一元火锅，用户会误以为店里只有一个低价项目；只拍手艺，用户又不知道自己到店具体能吃什么。正确做法是：**用一元火锅吸引第一次停留，用川味串串火锅、川味烧烤、川菜共同承接到店消费。**

这行的获客成本，卡在“附近的人有没有在吃饭前刷到你”和“刷到以后能不能立刻看懂”。餐饮用户通常不会为一家陌生店研究很久，但会在以下节点迅速流失：

1. 看不懂“一元火锅”到底怎么点、对应什么规则；
2. 看不清店里除了火锅还有什么；
3. 不知道下午四点出摊以后，自己什么时候适合来；
4. 主页没有地址、菜单或清晰到店信息；
5. 只看到成品和优惠，没看到食材、掌勺、出品过程，担心是普通广告。

我推测，这家店的消费高峰更可能集中在下午出摊后到晚间用餐时段；但具体客流高峰、天气影响、周末与工作日差异，必须用实际收银和到店记录确认，不能凭经验下结论。

同行常见的问题，是拍一桌成品、配一个价格、再说“正宗川味”。这类内容信息密度低，观众看完仍不知道：谁做、怎么做、店里有什么、自己怎么点。你们现有最有价值的资源不是“正宗”两个字，而是**成都来的川菜厨师，每天下午四点真实出摊**。这件事能持续拍，也能让手艺有画面。

**一句话定位：成都厨师做川味串串火锅、川味烧烤、川菜，让南乐人晚饭点明白。**

## 变现全景

### **现在能卖什么**

1. **川味串串火锅**  
   作用：承担第一次到店尝试、朋友聚餐和晚饭加菜需求。  
   其中“一元火锅”是重要的低门槛入口，但具体计价规则、适用菜品和最低消费，待确认后才能写进视频。

2. **川味烧烤**  
   作用：承接晚间消费、下班后临时约饭、串串火锅之外的加点需求。  
   它不能只作为镜头里的陪衬，要单独拍食材、烤制和出品，让用户知道这是一项稳定可点的品类。

3. **川菜**  
   作用：承接家庭晚饭、多人点菜、想坐下来吃一顿饭的需求。  
   川菜的内容重点不是泛泛展示菜名，而是让用户看清“这是一道什么菜、适合几个人吃、和串串烧烤是什么消费场景”。

### **各自的客单价与毛利大致区间**

目前不能给出可靠的客单价和毛利数字。原因是档案未提供菜单、食材成本、份量、人工、房租、酒水占比及实际消费小票。

但经营上可以先按逻辑区分：

- **川味串串火锅**：通常是低门槛进店、靠组合点单拉高实际消费的品类；要重点看每桌平均拿串数量、锅底及附加品类的消费情况。
- **川味烧烤**：通常依赖加点和晚间消费场景；要看单品出品速度、损耗、顾客是否会与火锅或川菜搭配点。
- **川菜**：通常更适合多人桌、家庭桌；要看桌均消费、出品时间和复点率。

**待确认的第一组经营数据：**
- 川味串串火锅、川味烧烤、川菜各自的菜单价格；
- 顾客最常点的组合；
- 顾客一桌通常点几类；
- 哪些菜卖得快、哪些备货容易剩；
- 一元火锅的实际消费规则。

没有这组信息，不能判断哪个品类利润更高，也不能把“一元”包装成低价承诺。

### **决策难度**

整体属于**低到中等决策**：

- 一个人下班、临时约朋友：低决策，看清位置、菜品、价格规则后可能直接到店；
- 宝妈安排家庭晚饭、多人聚餐：中等决策，需要先弄清菜品选择、是否适合家人一起吃；
- 第一次刷到一元火锅的用户：兴趣产生快，但规则不清就会立刻流失。

因此，视频不是只负责“勾人”，还要负责把第一层疑问讲清楚。

## 主推产品

**主推：一元火锅对应的川味串串火锅消费入口。**

不是因为它一定更赚钱，而是因为它是现有资料里最容易让陌生人停下来问一句“怎么吃”的明确钩子。起号期最缺的不是复杂介绍，而是一个让本地用户愿意点进主页、愿意评论、愿意到店确认的信息入口。

但要注意：**主推入口，不等于只卖这一样。**

它在内容里的正确位置是：

- 视频前段：用“一元火锅到底怎么点”吸引停留；
- 视频中段：拍真实选串、下锅、出品；
- 视频后段：自然带出当天还有川味烧烤、川菜可点；
- 到店后：由菜单和实际点单承接完整消费。

这样做的原因是：一元火锅负责降低第一次尝试的心理门槛，川味烧烤和川菜负责增加不同场景下的选择。三类品类都要在一批内容里稳定出现，不能让用户形成“这里只卖一元串串”的错误认知。

前提是先确认“一元火锅”的完整规则。规则未确认前，不能用“随便吃”“一元吃到饱”“全场一元”这类容易误导的话。

## 成交路径

### 1. 第一次接触看到什么

用户刷到的首屏，不该先是店名和优惠，而应是一个看得懂的现场动作：

- 下午四点，厨师开始摆串、开火、备料；
- 锅底翻滚、串串下锅、烧烤上炉、川菜下锅；
- 字幕只交代一个事实：“成都来的川菜厨师，下午四点出摊。”

**这一层的目的**：让陌生人停住，先知道这是南乐本地、是真实出摊、不是素材拼接的广告。

**会流失的人**：对餐饮内容没兴趣的泛用户。  
**为什么会流失**：这部分人本来就不是本地到店客，不必为了留住他们去拍脱离门店的泛娱乐内容。

### 2. 靠什么产生兴趣

兴趣不能只靠“好吃”，要靠具体问题被回答：

- 一元火锅怎么点；
- 串串、烧烤、川菜当天分别有什么；
- 下班几个人去，怎么点更清楚；
- 厨师实际在做哪一步；
- 成都厨师做川味菜时，现场能看见什么动作和差别。

**这一层的核心**：让用户产生“我去现场能吃到什么”的确定感。

**会流失的人**：只想看热闹、但不在南乐的人；以及觉得规则讲不清的人。  
**为什么会流失**：本地餐饮成交靠近距离和明确规则，模糊表达会放大顾虑。

### 3. 在哪里沉淀

优先顺序应是：**视频 → 主页 → 到店**。

现阶段不建议把链路拉得太长，不要一开始就强行把用户引到多个平台。餐饮到店本身属于短路径，主页要承担“补齐信息”的作用：

- 门店真实名称；
- 确认后的地址；
- 每天下午四点出摊；
- 川味串串火锅、川味烧烤、川菜；
- 一元火锅规则；
- 到店方式或私信入口。

**会流失的人**：点进主页仍找不到位置、规则、品类信息的人。  
**为什么会流失**：用户不是不想来，而是不愿意为一顿饭反复猜。

### 4. 临门一脚是什么

临门一脚不是“赶紧来吃”，而是**让用户在到店前把最担心的问题看明白**：

- 一元火锅具体怎么计价；
- 菜品是否当天实际供应；
- 到店时间；
- 地址；
- 第一次来可以怎么点。

变现视频结尾只保留一个行动：**到店**。

示例表达：  
“规则我放主页了，想吃就下午四点后到店看当天现串。”

不同时要评论、私信、关注、到店。用户只会记住一个动作。

## 信任证据清单

以下证据都要能拍到，不能只写在文案里。

1. **下午四点真实出摊的连续画面**  
   - 证明：真实、稳定经营  
   - 怎么拍：操作台整理、食材摆放、开火、第一锅出品，拍同一时段的连续动作。  
   - 为什么重要：比一张成品图更能证明“这个人真的每天在做”。

2. **厨师本人处理食材、下锅、调味、出锅的画面**  
   - 证明：专业、手艺  
   - 怎么拍：手部特写加半身操作，不必讲夸张术语，只讲正在做哪一步。  
   - 为什么重要：成都川菜厨师这个身份，要靠操作落地，不靠自我介绍。

3. **川味串串火锅的真实点单与出品流程**  
   - 证明：消费规则清楚  
   - 怎么拍：待确认规则后，拍“怎么选、怎么下、怎么上桌”。  
   - 缺口：一元火锅规则未确认，暂时不能拍成解释型变现视频。

4. **川味烧烤的原料到烤制过程**  
   - 证明：真实、出品能力  
   - 怎么拍：当天实际售卖的食材从处理、上炉到出品，别只拍撒料慢镜头。  
   - 为什么重要：让用户知道烧烤不是摆在菜单上的附带项目。

5. **川菜单道出锅过程**  
   - 证明：品类完整、专业  
   - 怎么拍：一条视频只拍一道当天真实在售川菜，从下锅到装盘。  
   - 为什么重要：川菜更适合承接家庭晚饭和多人点菜，要让用户看见“坐下来吃饭”的理由。

6. **真实菜单、明确价格和到店规则**  
   - 证明：实在、不绕弯  
   - 怎么拍：菜单局部、点单牌、店内实际展示；发布前核对当天有效。  
   - 缺口：菜单、地址、规则待补齐。

7. **真实顾客提问与老板实际回答**  
   - 证明：服务、现场感  
   - 怎么拍：取得顾客同意后，记录“这个怎么点”“一元火锅怎么算”等真实对话。  
   - 为什么重要：用户最信和自己一样的人问的问题。  
   - 注意：不安排演员，不代写顾客评价。

8. **老客再次到店的真实记录**  
   - 证明：结果、复购  
   - 怎么攒：先问老板“哪位客人回来过、第一次因为什么来、后来又点了什么”，征得本人同意后再拍。  
   - 缺口：目前没有真实老客故事，不能提前写成案例。

## 变现型内容怎么排

### **占比建议**

起号期先维持：**流量型60%、人设型20%、变现型20%。**

变现型只占20%，不是因为它不重要，而是零到一千粉阶段，账号先要让更多南乐本地陌生人认识“下午四点出摊的成都川菜厨师”。一上来连续发菜单、价格、到店视频，账号很容易变成广告栏。

但变现内容不能等账号做大后才开始。第一周就要发，只是每周保持少量、清楚、能承接到店的内容。

品类安排上，变现内容应轮换：
- 川味串串火锅：约一半，承担一元火锅规则和首次到店入口；
- 川味烧烤：约四分之一，承担晚间加点和下班场景；
- 川菜：约四分之一，承担家庭晚饭和多人点菜场景。

这不是给品类排高低，而是按当前已知钩子和消费场景做起步测试。跑出实际到店咨询后，再按顾客问得最多、点得最多的品类调整。

### **方向一：一元火锅到底怎么点**

- **对应路径**：兴趣产生 → 消除顾虑 → 到店  
- **成交理由**：低门槛、规则清楚  
- **先给的价值**：让第一次刷到的人看懂消费规则，避免到店前猜测。  
- **四大脚本**：晒过程·火车节  
  - 起因：镜头拍一把串，“很多人问，一元火锅到底是怎么点的？”  
  - 关键步骤：按确认后的真实规则，拍选串、计价、下锅、上桌；  
  - 结果：一句话说清适用范围和到店时间。  
- **36计拍法**：**第10计·情境还原：套到这个号上是一次真实点单，顾客问怎么点，厨师按实际规则说明并完成出品。**  
- **结尾行动**：到店。  
- **前提**：必须先确认一元火锅规则；规则没确认，这条不拍。

### **方向二：下班后，两个人来店里怎么点**

- **对应路径**：看见菜品 → 想象消费场景 → 到店  
- **成交理由**：选择清楚、场景适配  
- **先给的价值**：不是推荐用户“多点”，而是帮第一次来的用户看懂串串、烧烤、川菜可以如何搭配。  
- **四大脚本**：教知识·推荐型  
  - 圈人：“下班临时约饭，不知道点串串还是点菜的”；  
  - 推荐：以当天真实可售菜品为准，展示一种两人点法；  
  - 适用条件：明确这是适合什么人数、什么场景的点法，不说成唯一方案。  
- **36计拍法**：**第26计·推荐建议：套到这个号上是按“下班两人吃”“家庭晚饭”等真实场景，分别展示当天可选的川味串串火锅、川味烧烤、川菜。**  
- **结尾行动**：到店。  
- **待确认**：不同人数的真实常见点单组合。

### **方向三：一份川菜从下锅到上桌**

- **对应路径**：产生兴趣 → 建立手艺信任 → 到店  
- **成交理由**：专业强、真实出品  
- **先给的价值**：让用户看见一道菜不是成品图，而是厨师现场完成的过程。  
- **四大脚本**：晒过程·火车节  
  - 起因：先给油温、下锅或翻炒的动作；  
  - 关键步骤：拍一道当天在售川菜的关键操作；  
  - 结果：出锅后说明适合什么用餐场景。  
- **36计拍法**：**第15计·正确做法VS错误做法：套到这个号上是只针对一项可验证操作，先拍会影响口感或出品状态的常见错误，再拍厨师实际采用的做法，并说明适用条件。**  
- **结尾行动**：到店。  
- **注意**：不贬低同行，不把个人做法说成行业唯一标准。

### **方向四：烧烤为什么要从备料开始拍**

- **对应路径**：建立真实感 → 形成到店意愿  
- **成交理由**：过程看得见、当天实际在做  
- **先给的价值**：让用户看见烧烤从处理到上炉的完整路径，减少“只拍成品像广告”的距离感。  
- **四大脚本**：晒过程·过程展示  
  - 选择当天一种真实在售食材；  
  - 拍处理、上炉、翻烤、出品；  
  - 厨师只解释一个用户能听懂的操作点。  
- **36计拍法**：**第34计·接受网友挑战：套到这个号上是征集“想看哪一种当天实际在售烧烤怎么烤”，选择一条真实留言拍完整过程，再征集下一种。**  
- **结尾行动**：评论。  
- **说明**：这条虽然服务后续变现，但当集以征集需求为主，结尾只要评论，不同时引导到店。

## 定价与节奏

### **起步阶段怎么定价**

现阶段不建议因为要做短视频，立刻新设低价套餐、限时折扣或复杂团购。原因很简单：规则没理清之前，低价信息会吸来大量只问价格的人，反而让真正能到店的用户搞不懂怎么消费。

起步先做三件事：

1. **把已有的一元火锅规则讲明白**；  
2. **把川味串串火锅、川味烧烤、川菜的实际菜单和价格整理出来**；  
3. **观察顾客到店后最常点什么组合，而不是先凭感觉造套餐。**

如果后续确实要设置引流款，应满足三个条件：

- 顾客看一眼就能懂规则；
- 不会挤压正常品类的消费空间；
- 厨房在客流高峰时能稳定出品。

否则，宁可先不做。餐饮最怕视频带来一波人，却因为规则复杂、出品跟不上，让第一次体验变差。

### **什么时候可以调整价格**

不能按“账号涨粉了”涨价。价格调整至少要有以下依据：

- 某个品类长期出现供不应求或备货压力；
- 原料、人工或出品成本发生持续变化；
- 顾客对份量、组合、价格的真实反馈；
- 菜单结构已经清楚，用户能理解价格对应的内容；
- 调价后仍能保证出品稳定。

账号数据只能作为辅助证据：如果某类内容带来的到店咨询增加，可以说明用户对该品类兴趣更高；但不等于可以直接涨价。

### **30天验证节奏**

**第1周：补信息、找可拍动作**  
确认地址、菜单、一元火锅规则、各品类供应时间；连续拍备菜、出摊、下锅等过程，先测试哪些动作能让人停留。

**第2周：测试三类品类的到店表达**  
分别发川味串串火锅、川味烧烤、川菜的变现内容，观察评论里大家问的是价格、地址、规则，还是具体菜品。

**第3周：围绕最高频问题连发**  
如果评论总问“一元火锅怎么算”，就连续拍规则和真实点单；如果总问“还有什么菜”，就拍不同场景下的真实点法。

**第4周：复盘成交链路**  
不要只看播放量，要记录：
- 哪条视频带来主页访问；
- 哪类视频有人问地址；
- 哪类视频有人问规则；
- 实际到店顾客是看了哪条来的；
- 到店后主要点了川味串串火锅、川味烧烤还是川菜。

没有“看视频来的”这一步记录，后面无法判断内容到底有没有带来生意。

## ⚠️ 风险

### 1. 一元火锅规则模糊，吸引来的不是顾客而是误解

这是当前最需要先解决的问题。用户一看到“一元火锅”，会自然追问：什么一元、哪些一元、有没有条件、还能点什么。如果视频不说清，评论越多，误解也越多。

**处理方式**：先把规则写成老板确认版，再拍情境还原；未确认前，只拍真实备菜和出品，不拿“一元”做夸张标题。

### 2. 内容只拍串串，其他两类品类被用户忽略

如果账号长期只有串串镜头，用户会默认这是一家单品店，川味烧烤和川菜即使实际在卖，也无法进入消费者的选择范围。

**处理方式**：每周内容排期中，必须分别安排川味串串火锅、川味烧烤、川菜。单条只讲一个品类即可，但一批内容里三个都要轮流出现。

### 3. 视频有播放，到店却不增长

这通常不是“流量不够”，而是成交路径断了：用户看完不知道地址、不知道几点出摊、不知道怎么点，或者主页没有承接。

**下一次优先排查：**
- 播放低：把开头换成更具体的出摊动作，不要先讲店铺介绍；
- 前三秒流失：把下锅、烤制、出锅等结果前置；
- 评论多但不问到店：检查内容是不是只好看、没有讲清本地和品类；
- 有人问地址但没来：检查主页是否缺规则、菜单和到店信息；
- 到店的人只问一元火锅：补拍川味烧烤、川菜的真实出品和消费场景。

这条变现路线最终不是靠喊“来吃”，而是靠持续把三件事拍清楚：**谁在做、做什么、你来了怎么点。**
