# 💎 内容定位方案

## 长期价值主张
**看川味串串火锅、川味烧烤、川菜怎么出摊做。**

这不是“介绍菜单”的账号，而是让南乐本地人通过真实操作，看明白今天能吃到什么、厨师怎么做出来。原因是这家店最能持续拍、也最能建立信任的素材，不是空口介绍，而是每天都会发生的备菜、掌勺和下午四点出摊。

## 内容方向：多元四类还是单一主题

**选择：A 多元四类打底 + B 王牌栏目。**

- **A 多元四类**：晒过程为主，补知识、故事、观点。
- **B 王牌栏目**：**《下午四点，成都厨师出摊了》**——围绕每天真实发生的备菜、掌勺、出摊，轮流拍川味串串火锅、川味烧烤、川菜。

**为什么这样选：**

1. 店里卖三个品类，若全号只拍一个主题，容易让本地用户误以为店里只卖一种东西；多元内容能把**川味串串火锅、川味烧烤、川菜**都持续讲清楚。
2. “下午四点出摊”是已经确认、每天可发生的真实任务，适合做成固定栏目。它不用编故事，也不依赖顾客配合，手机跟拍就能完成。
3. 厨师来南乐半年，现有可确认的人设故事素材还不够多，不能一上来强做“逆袭故事”“人物关系”类内容。

**为什么不纯做单一主题：**  
纯主题号需要稳定的新人物、新任务或新结果。目前能确认的稳定变量主要是当天食材、菜品和出摊准备，能撑起栏目，但不足以把全号锁死在一种拍法里。先以多元内容测试，再把跑出反馈的“下午四点出摊”做成账号记忆点，更稳。

## 内容配比

### 作用配比

| 作用 | 占比 | 为什么 |
|---|---:|---|
| 流量型 | 60% | 账号处于0—1000粉起号期，第一任务是让南乐本地陌生用户刷到。流量内容围绕厨师、食材、出摊现场做大众能看懂的反差、地域差异和过程看点，不带到店引导。 |
| 人设型 | 20% | “成都来的川菜厨师”“做川菜9年”“下午四点出摊”是现有最硬的人设资产，但素材必须来自真实工作和真实经历，不能为了立人设硬编。 |
| 变现型 | 20% | 本地餐饮最终要到店消费，起号第一周就要让用户逐渐看清卖什么、怎么点、什么时候能来；但比例不能过高，否则新号像促销号。 |

**什么数据出现时切换配比：**  
连续测试3—5条同类流量内容后，如果“下午四点出摊”相关内容能稳定带来非关注播放、评论和主页访问，同时变现内容开始出现真实的地址、点单规则、到店咨询，配比调整为**流量50%、人设20%、变现30%**。  
如果流量内容有播放但主页访问低，先不增加变现比例，优先强化“南乐、四点出摊、三类品类”的账号识别。

### 形式配比

| 形式 | 占比 | 负责哪种作用 | 为什么 |
|---|---:|---|---|
| 晒过程 | 55% | 流量型、变现型 | 当前没有“数据最好的内容类型”可参考，不能假称某种形式已验证。晒过程是最适合先测试的形式：每天备菜、掌勺、出摊真实发生，能拍出手艺，也能轮换展示川味串串火锅、川味烧烤、川菜。 |
| 知识 | 15% | 流量型、变现型 | 用外行能听懂的方式讲一处食材处理、一处川味做法或点单规则。不能讲成厨师同行课，重点是让本地消费者“看明白”。 |
| 故事 | 15% | 人设型 | 只讲真实职业经历、来南乐后的具体现场和顾客真实互动。故事的作用是让人记住掌勺的人，不是煽情。 |
| 观点 | 10% | 人设型 | 以厨师本人真实经历为基础，表达对出品、备菜、火候等问题的判断。没有具体经历就不拍。 |
| 段子 | 5% | 流量型 | 只做低成本的一人分饰两角或食客常见问题演绎，测试本地用户互动；不做多人剧情，因为当前团队和演员资源待确认。 |

### 题材配比

- **主赛道80%**：围绕**川味串串火锅、川味烧烤、川菜**轮换拍摄。建议起步阶段各占大致三分之一，避免账号被单一品类绑死。
- **目标人群兴趣20%**：围绕新锐白领、精致妈妈的晚饭决策场景展开，但不把账号拍成泛生活号。

具体可长期测试的兴趣话题：

1. **下班前不知道吃什么**：新锐白领刷视频时最容易代入，适合做“今天四点出什么”的过程内容。
2. **一家人晚饭怎么安排**：精致妈妈关心菜品是否看得懂、选择是否清楚，适合拍真实菜品和点单规则。
3. **南乐本地吃饭去哪儿**：本地用户在临时约饭、朋友碰面时会搜索或浏览，适合用地域差异、出摊现场切入。

### 配比核验

1. **是**：流量型占60%，是起号期最大的一块，符合新号先拿陌生流量的目标。  
2. **是，但需说明**：档案没有历史数据最好的内容类型，因此用“可持续、可验证”的晒过程先跑，不把假设当结果。  
3. **是**：流量内容不只是拍做菜，会加入人群、反差、地域差异、成本等大众看点。  
4. **是**：保留20%题材给下班晚饭、家庭晚饭、本地吃饭场景，避免全是厨师同行才看得懂的内容。  
5. **是**：每个比例都对应起号阶段、真实拍摄资源和本地到店目标，不是通用模板。

## 三种视频怎么拍

### 一、流量型

**拍什么方向：**

1. **成都厨师和南乐本地食材、吃法的差异**：重点不是争谁对谁错，而是让用户看见不同做法和真实操作。
2. **下午四点出摊前的反常识步骤**：找一个观众以为“随手做就行”、实际要提前处理的动作，形成过程反差。

**四大脚本（薛老师）**

- **晒过程型·任务挑战结构**：  
  当天任务 → 出摊前要完成的关键准备 → 过程中的变化 → 准时开火。  
  适合拍“下午四点前，今天这锅底要先完成哪几步”。

- **教知识型·拆解结构**：  
  常见误区 → 厨师现场操作 → 为什么这样做 → 留一个大众能讨论的问题。  
  不讲复杂术语，避免讲成同行教学。

**可叠加爆款元素：反差、人群、成本。**

**示范标题：**  
《下午四点出摊前，成都厨师先忙的不是开火》（反差）  
**一句话怎么拍：** 从空操作台开始，连续拍处理食材、摆放、开火前准备，最后停在出摊动作上，不介绍价格、不引导到店。

**起号36计（小黄）**

- **第1计·反向操作：**  
  常规以为“出摊先开火” → 厨师先做一项真实的备菜动作 → 镜头展示这一步完成后的出摊准备。  
  前提：动作必须是老板确认过、符合实际操作的做法。

- **第31计·南北/地域差异：**  
  南乐本地常见的吃法或口味提问 → 成都厨师自己的做法 → 说清“这是我的做法” → 评论区问本地人习惯。  
  不把地域差异拍成高低比较。

**示范标题：**  
《南乐朋友问我：川味串串火锅这一步要不要这么做？》（人群）  
**一句话怎么拍：** 厨师边做边回答一个真实被问过的问题；如果该问题尚未确认，先向老板补采，不能虚构“顾客常问”。

**结尾行动指令：**  
“你们家吃串串时，更在意哪一步？评论区说说。”

### 二、人设型

**拍什么方向：**

1. **成都厨师来到南乐后，每天下午四点开始的一天。**
2. **做川菜9年后，仍然坚持亲自完成的一步。**  
   待确认：具体是哪一步、为什么坚持、有没有真实发生过的事件能支撑。

**四大脚本（薛老师）**

- **讲故事型·小有成就结构：**  
  现在的掌勺现场 → 来南乐后的真实适应问题 → 一次具体转机或变化 → 继续每天出摊的原因。  
  没有真实的阻碍和转机，就不写成“励志故事”。

- **聊观点型·观点立场结构：**  
  亲身操作经历 → 厨师的一个判断 → 现场动作证明 → 一句收住。  
  例如只能在老板确实有这类判断时拍：“有些东西我宁愿多花时间，也不想省掉这一步。”

**示范标题：**  
《来南乐半年后，我还是每天四点出摊》（人群）  
**一句话怎么拍：** 跟拍厨师收拾操作台、备菜、推出摊位，用本人配音讲“我是谁、现在每天做什么”，不讲卖点、不介绍优惠。

**起号36计（小黄）**

- **第7计·一句话设定故事感：**  
  普通动作“收拾出摊工具” + 人物设定“成都来的川菜厨师” + 固定目标“下午四点出摊” → 形成下一步期待。

- **第37计·赠送：身份反差：**  
  “做川菜9年的厨师”这个身份预期 → 不摆拍、不讲大道理，直接蹲在操作台前处理当天食材 → 用真实动作回收身份。  
  这不是硬造反差，而是“厨师身份”与“重复、细碎的出摊准备”之间的生活化落差。

**示范标题：**  
《做川菜9年的人，下午四点前都在干什么》（反差）  
**一句话怎么拍：** 先给厨师掌勺的画面，再切到他整理、备料、检查出摊准备的细节，最后准时出摊。

**结尾行动指令：**  
“想继续看我下午四点出摊，关注我。”

### 三、变现型

**拍什么方向：**

1. **把一份实际售卖的川味串串火锅、川味烧烤或川菜，从准备拍到出品。**  
   成交理由是“厨师手艺看得见”，不是口头说“正宗”。
2. **把一元火锅的真实点单规则讲清楚。**  
   待确认：一元具体对应什么、计价方式、是否有其他消费规则。规则没有确认前，不发相关变现内容。

**四大脚本（薛老师）**

- **晒过程型·火车节模型：**  
  当天有顾客要吃的一道菜/一类品类 → 关键操作 → 出品结果 → 到店指令。  
  重点拍手艺和菜品，不代写顾客夸奖。

- **教知识型·推荐结构：**  
  圈定“下班想吃热乎饭的人”或“带家人吃饭的人” → 展示实际品类 → 说明已确认的选择和点单信息 → 到店。  
  一条只突出一个理由，例如“看得见的现做过程”或“低门槛点单规则”。

**示范标题：**  
《一份川味烧烤，从备料到上桌要过哪几步？》（反差）  
**一句话怎么拍：** 跟拍一种实际售卖的食材处理、烤制和装盘，字幕只写已确认的信息，结尾说明“想吃可以到店看当天出品”。

**起号36计（小黄）**

- **第10计·情境还原：**  
  真实点单或老板本人模拟说明已确认的点单流程 → 厨师按流程准备 → 出品 → 告诉用户到店如何问。  
  没有真实顾客授权时，不拍顾客正脸，也不编顾客台词。

- **第15计·正确做法VS错误做法：**  
  仅用于手艺本身可被验证的内容。  
  同一份食材 → 不同处理方式 → 展示口感或状态上的可见差异 → 说明这是店内实际做法。  
  不贬低同行，不说“别人都不对”。

**示范标题：**  
《一元火锅怎么点，先把规则讲明白》（成本）  
**一句话怎么拍：** 先放清晰规则字幕，再由厨师在真实出摊现场边操作边说明；规则未确认前，此条不拍。

**结尾行动指令：**  
“想吃今天这份，下午四点后到店问我。”

## 内容系列（3个）

### 系列一：《下午四点，成都厨师出摊了》

**一句话讲清：** 每天跟着成都厨师看一项出摊前必须完成的真实任务。

- **出发点：**  
  面向下班前刷抖音的新锐白领和准备晚饭的精致妈妈；围绕“场”——下午四点前后的真实出摊现场；满足“有兴趣”，因为观众会想知道路边摊和火锅出摊前到底在忙什么；主要使用**反差、成本、人群**，放在标题和开场动作里。

- **定量 / 变量：**  
  定量是“下午四点前，完成一个出摊任务”的结构；变量是当天准备的货、当天做的菜、当天最关键的一个动作。

- **用哪套打法：**  
  四大脚本系列，固定使用**晒过程型·任务挑战结构**。

- **目的和结构：**  
  主目的为流量型。  
  结构：出摊倒计时 → 一个关键任务 → 完成准备 → 四点出摊。  
  每集结尾行动指令：“你们下班前最想看哪一锅？评论区说说。”

- **让观众发生哪种变化：**  
  **身份确认**——让本地用户觉得“这就是我下班前会刷到、会关心的晚饭现场”。

- **变量自检：**  
  变量是：当天要准备的**川味串串火锅、川味烧烤、川菜**及其对应任务。  
  看点不是试吃、挑选或吃法技巧，而是“出摊前能否完成这项真实任务”。

**前10集标题：**

1. 《下午四点前，川味串串火锅先要准备什么？》（反差）  
2. 《今天出摊前，这份川味烧烤要先过这一关》（反差）  
3. 《一份川菜上灶前，厨师先把哪里收拾出来？》（人群）  
4. 《下午四点快到了，今天的串串还差哪一步？》（成本）  
5. 《成都厨师出摊前，先检查的不是锅底》（反差）  
6. 《下班前想吃热乎的，看看今天川菜怎么备》（人群）  
7. 《这份川味烧烤出摊前，食材要怎么摆才顺手？》（奇葩）  
8. 《下午四点出摊，串串火锅这一盆今天先上》（成本）  
9. 《一锅川菜开做前，厨师先做的动作有点意外》（反差）  
10. 《南乐下午四点的摊位上，今天先忙川味烧烤》（人群）  

**立项检验：**

- 一句话能讲清：固定时间、固定人物、固定任务，用户容易理解。
- 有追看理由：观众会想知道第二天准备什么、今天能否准时出摊。
- 能撑30集：三个品类轮换，每类都有备料、处理、摆放、开火、出品等真实任务。
- 真实性：全部来自当天实际经营，不假装随机、不制造冲突。
- 和变现联系：流量内容不推销，但连续出现的真实菜品和出摊场景会给后续到店内容提供信任基础。
- 前10集元素和句式已轮换，含反差、成本、人群、奇葩四类，同一句式未连续堆叠。

### 系列二：《成都厨师，今天做给你看》

**一句话讲清：** 每集只讲一处真实做法，拍清楚川味串串火锅、川味烧烤、川菜的一步操作。

- **出发点：**  
  面向想吃得明白、想看现场做菜的本地消费者；围绕“货”——当天真实在卖的一类菜品；满足“有用”，让观众看懂一道菜在做什么；主要用**反差、成本、头牌**，放在开场问题和操作结果上。

- **定量 / 变量：**  
  定量是“一个问题 + 一步现场操作 + 一个结果”；变量是每集讲的菜品、食材和具体做法。

- **用哪套打法：**  
  36计系列，固定使用**第36计·冷知识**。  
  公式：一个外行会意外的问题 → 现场证据/例子 → 厨师解释 → 回到吃这件事。

- **目的和结构：**  
  主目的为流量型。  
  结构：反常识问题 → 现场操作 → 厨师解释 → 评论提问。  
  每集结尾行动指令：“你吃这类菜时会注意这一步吗？评论区聊聊。”

- **让观众发生哪种变化：**  
  **认知变化**——观众看完知道一处原来没注意过的做菜细节。

- **变量自检：**  
  变量是：每集更换一种真实在卖的菜品或食材处理问题。  
  看点不是教观众回家复制，而是通过店内真实手艺，让人看懂这家卖的东西为什么这样做。

**前10集标题：**

1. 《川味串串火锅下锅前，为什么这一步不能急？》（反差）  
2. 《川味烧烤好不好吃，先看食材处理这一下》（头牌）  
3. 《川菜出锅前，厨师为什么还要停一下？》（反差）  
4. 《一元火锅里的菜，摆放顺序会影响什么？》（成本）  
5. 《同样是串串，成都厨师先看的是哪一处？》（人群）  
6. 《川味烧烤上火前，为什么不急着撒料？》（反差）  
7. 《一份川菜里，厨师最怕漏掉哪一步？》（奇葩）  
8. 《下班来吃串串的人，常忽略这一口》（人群）  
9. 《川味烧烤的香味从哪一步开始出来？》（头牌）  
10. 《川菜装盘前，厨师还会看什么？》（反差）  

**立项检验：**

- 一句话清楚：每集回答一个做菜问题。
- 有追看理由：用户会继续好奇下一种菜、下一步操作。
- 能撑30集：三个品类各自有食材处理、火候、调味、出品等多个真实问题。
- 真实性：解释只讲老板确认过的店内实际做法，不把个人经验说成绝对标准。
- 和变现联系：过程本身是手艺证据，后续可自然承接到店。
- 前10集包含反差、头牌、成本、人群、奇葩五类元素，句式有变化。

### 系列三：《四点出摊的人，说句实话》

**一句话讲清：** 成都厨师在真实出摊现场，说一件做川菜这些年形成的判断。

- **出发点：**  
  面向愿意记住“谁在做饭”的本地用户；围绕“人”——成都来的川菜厨师；满足“有共鸣”，因为下班、赶时间、做饭和坚持一件手艺都是普通人能理解的生活处境；主要使用**人群、怀旧、反差**，放在人物经历和开场场景里。

- **定量 / 变量：**  
  定量是“一个真实现场 + 一个亲身判断 + 一个动作证明”；变量是当天的工作场景、厨师的真实经历和观点。

- **用哪套打法：**  
  四大脚本系列，固定使用**聊观点型·观点立场结构**。

- **目的和结构：**  
  主目的为人设型。  
  结构：现场发生的事 → 我的判断 → 为什么这么看 → 回到当天出摊。  
  每集结尾行动指令：“想继续看一个成都厨师在南乐出摊，关注我。”

- **让观众发生哪种变化：**  
  **信任变化**——不是信“口号”，而是通过现场和判断逐渐信任这个掌勺的人。

- **变量自检：**  
  变量是：每集一个真实发生的工作场景或已确认的职业经历。  
  看点不是换动作、换机位，而是“这位厨师为什么会形成这个判断”。

**前10集标题：**

1. 《做川菜9年后，我还是不想省掉这一步》（反差）  
2. 《来南乐半年，我每天四点出摊没变过》（人群）  
3. 《下班前最忙的时候，厨师最怕什么？》（人群）  
4. 《以前在成都做川菜，现在到南乐出摊》（怀旧）  
5. 《一锅菜做完，我先看它哪里？》（反差）  
6. 《四点出摊的人，最不想听见哪句话？》（奇葩）  
7. 《做川味烧烤时，我为什么不喜欢赶这一步？》（反差）  
8. 《川菜做久了，我越来越在意这一件小事》（怀旧）  
9. 《出摊前有人催，我会先把什么做好？》（人群）  
10. 《一个成都厨师在南乐，今天又是四点出摊》（人群）  

**立项检验：**

- 一句话清楚：每集都是“真实工作现场里的一个判断”。
- 有追看理由：用户会想知道厨师还有哪些坚持、哪些真实想法。
- 能撑30集：前提是补采至少30个真实事件、操作习惯或职业判断；目前素材不足，必须先采访，不够就暂停这个系列。
- 真实性：没有具体经历、具体动作、具体现场，就不拍；不把“专业、认真”当人设。
- 和变现联系：不直接卖菜，但人物信任会支撑后续的到店内容。
- 前10集含人群、反差、怀旧、奇葩四类元素，避免连续重复同一句式。

## 选题来源

### 1. 知识储备

**长期挖掘来源：**

- 厨师每天都会做、但顾客看不到的一处准备。
- 顾客实际问过的食材、火候、点单问题。

**例子：**  
《川味烧烤上火前，为什么不急着撒料？》

### 2. 经历与故事

**长期挖掘来源：**

- 成都来南乐后，第一次遇到的真实差异。  
- 做川菜9年里形成的一项工作习惯。  
  待确认：必须补具体发生过的事件，不能只说“我很坚持”。

**例子：**  
《来南乐半年后，我每天四点出摊没变过》

### 3. 热门话题与观点

**长期挖掘来源：**

- 本地用户对“晚饭吃什么”“串串怎么点”的真实讨论。
- 成都和南乐在口味、食材、吃法上的真实差异。

**例子：**  
《南乐朋友吃串串，更在意锅底还是蘸料？》（需先确认这是可讨论、无攻击性的真实话题）

### 4. 实操记录

**长期挖掘来源：**

- 每天下午四点前的备菜、摆摊、开火。

**例子：**  
《下午四点快到了，今天的串串还差哪一步？》

## 前30条节奏

### 第1—10条：先跑“下午四点出摊”主系列

- **目标：** 让平台和本地用户先认识“成都厨师 + 下午四点出摊 + 真实做菜现场”。
- **做哪个系列：** 主做《下午四点，成都厨师出摊了》，穿插2条《成都厨师，今天做给你看》。
- **加什么：** 每条只加一个明确看点：反差、成本或人群，不加优惠、不讲复杂菜单。
- **主要用哪套形式：** 四大脚本的晒过程型·任务挑战结构；搭配第1计·反向操作和第36计·冷知识。
- **验收标准：** 看非关注播放占比、前段停留、评论是否出现“这是什么菜”“几点出摊”“南乐哪里”等真实问题；若连续内容无人停留，优先改开场动作，不急着换赛道。

### 第11—20条：测试三个品类与地域差异

- **目标：** 验证川味串串火锅、川味烧烤、川菜中，哪类内容更能让本地人停留、评论、访问主页。
- **做哪个系列：** 三个系列交替；流量内容仍占大头，人设内容补2—3条。
- **加什么：** 增加“成都做法和本地吃法”“下班晚饭”“家庭吃饭”这类目标用户兴趣题材。
- **主要用哪套形式：** 第31计·南北/地域差异、第36计·冷知识；四大脚本用晒过程型和聊观点型。
- **验收标准：** 看不同品类的非关注播放、主页访问、评论质量；如果某品类只带来泛围观、不带主页访问，也不能直接判为主力变现内容。

### 第21—30条：补清楚到店信息与真实信任

- **目标：** 在不破坏流量的前提下，开始让用户看懂店里卖什么、怎么点、什么时候能来。
- **做哪个系列：** 保留跑得最好的流量系列，新增已确认规则后的变现型过程内容。
- **加什么：** 川味串串火锅、川味烧烤、川菜的实际出品；确认后一元火锅规则；真实顾客常问问题。
- **主要用哪套形式：** 四大脚本的晒过程型·火车节模型；第10计·情境还原、第15计·正确做法VS错误做法。
- **验收标准：** 看主页访问后是否有地址、时间、点单规则相关咨询；如果用户反复问同一个规则，说明主页和视频字幕没有说清，应先补信息，不靠私信逐个解释。

## ⚠️ 不要做什么

1. **不要连续拍成品特写加价格字幕。**  
   原因：这类内容无法体现“成都川菜厨师”“下午四点出摊”的人设，也很难让观众知道川味串串火锅、川味烧烤、川菜和普通菜单展示有什么差别。

2. **不要为了热闹硬拍多人情景剧、顾客反应或夸张挑战。**  
   原因：当前团队、演员、顾客授权情况都未确认。硬演会破坏真实感，也会影响厨房和出摊节奏。

3. **不要在一元火锅规则未确认前，用“一元”做强引导标题。**  
   原因：用户会直接追问一元对应什么、怎么收费、有没有附加规则。解释不清会损伤信任。先补齐真实规则，再做变现内容。
