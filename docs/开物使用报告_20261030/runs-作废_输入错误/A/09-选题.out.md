## 选题1：下午4点出摊前，生意的变化会先出现在哪个动作上？

【方向】下午四点，今天先忙什么  
【目的】流量型  
【结尾动作】评论  
【成交步骤】—

**承接**：取自方向1“每天下午4点出摊”“先拍实际先做的一项准备，不把所有内容塞进同一条”的思路。

**0️⃣ 视频目的**  
流量型。用“出摊前到底先忙什么”这个人人能看懂的现场问题，让南乐本地用户先记住这个固定场景。

**🅰 打法**  
- **36计·第35计 街头采访**：先问本店掌勺人及征得同意的周边店主“前后时段生意有没有变化”→追问变化有没有先反映在出摊准备上→切回下午4点前的一个真实准备动作→保留不同现场回答。

**1️⃣ 爆款元素**  
- **奇葩**：套用句式「外行人绝对不知道的X」  
- 应用：外行以为摆摊就是开火，实际先拍当天真实发生的一项准备工作。

**2️⃣ 开篇钩子**  
“下午4点才出摊，但今天得先去问问：生意前后有变化，最先变的到底是不是出摊前这些活？”

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：通过街头短访谈和掌勺人真实备摊动作，观察生意变化是否会改变下午4点前的准备节奏。  
- **核心问题与观众价值**：很多人看到摊位开火才觉得“开始营业”，这条片子要让本地用户知道，经营变化可能先出现在备串、摆菜、整理台面这些看不见的环节。  
- **取材与内容推进**：  
  - 采访对象：本店掌勺人；如附近店主愿意出镜，可增加同街、同一时段营业的店主，但不评价同行好坏。  
  - **主问题（原目的）**：“跟【待确认：前一时段】比，现在店里生意有什么变化？具体变在哪里？”  
  - **本条深入的问题**：“这种变化，会不会让你下午4点前先多准备、少准备，或者改掉原来的准备顺序？”  
  - 追问：“今天出摊前你先做的是哪件事？”“这个动作以前和现在有什么不同？”“能不能用今天现场的情况举个例子？”  
  - 内容推进：先放“还没开火”的台面和食材，再放问题与原话，最后用掌勺人的实际动作回应问题。  
- **事实边界**：目前已确认的是掌勺人每天下午4点出摊；前后生意是否变化、准备量是否变化，均需现场采访获得。若受访者说没变化，也保留原话，并拍当天正常准备流程。  
- **关键画面（3个）**：  
  - 手机拍下午4点前，掌勺人整理操作台或摆放当天食材。  
  - 镜头外提问，受访者回答位置保留现场原话。  
  - 掌勺人完成一项准备后，拉近拍手部和操作台变化。  
- **场景设置**：摊位出摊前的操作台旁；采访不要挡住对方经营通道。

**4️⃣ 脚本结构**  
- **街头采访结构**：  
  - 问题前置：“生意前后有变化，下午4点前的准备会不会先变？”  
  - 采访本店掌勺人，保留现场原话。  
  - 追问具体动作与当天依据。  
  - 切入真实备摊画面，不用旁白替受访者下结论。  
  - 收尾提问：让本地用户说说，自己下班前最常看到路边摊忙哪一步。

**5️⃣ 结尾行动指令**  
“你觉得出摊前最忙的是哪一步？评论区说说。”

**6️⃣ 执行要点**  
- 手机竖拍，一人负责提问和拍摄即可。  
- 下午4点前提前到位，先拍空台面，再拍整理后的状态，形成前后画面。  
- 采访前先说明用途并征得发布同意。  
- 收声尽量靠近受访者，避开烧烤风机、车辆经过时提问。  
- 当天只选备串、摆菜、整理台面中的一项拍透，不混拍多个任务。

## 选题2：外行人绝对不知道，一份川味为什么这一步不急着下锅？

【方向】一份川味，先做哪一步  
【目的】流量型  
【结尾动作】评论  
【成交步骤】—

**承接**：取自方向2“外行容易误会的问题”“只解释店里实际怎么做，不把个人做法说成唯一标准”的思路。

**0️⃣ 视频目的**  
流量型。用厨房里看得见的细节，让陌生用户停在“为什么不立刻下锅”这个问题上。

**🅰 打法**  
- **36计·第35计 街头采访**：先采访掌勺人和愿意受访的餐饮经营者，问前后生意变化有没有影响当天备料与出品节奏→追问“赶时间时，哪一步仍不能省”→用当天一道实际出品验证回答。

**1️⃣ 爆款元素**  
- **奇葩**：套用句式「外行人绝对不知道的X」  
- 应用：把“不能急着下锅的步骤”拍成现场验证，而不是只讲厨师术语。

**2️⃣ 开篇钩子**  
“生意忙起来，做川味是不是就得更快下锅？今天去问问掌勺的人，哪一步反而不能急。”

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：围绕当天实际制作的一份串串火锅、川味烧烤或川菜，记录掌勺人认为不能跳过的一步。  
- **核心问题与观众价值**：观众能看懂一道菜从食材状态到出品状态的差别，也知道“快”不等于每一步都省掉。  
- **取材与内容推进**：  
  - 采访对象：本店掌勺人优先；如附近餐饮从业者愿意接受采访，只问自身经营与出品流程，不比较菜品优劣。  
  - **主问题（原目的）**：“跟【待确认：前一时段】比，现在店里生意有什么变化？具体变在哪里？”  
  - **本条深入的问题**：“如果出品节奏变快了，做这份川味时，哪一步你还是不会省？”  
  - 追问：“不做这一步，成品会出现什么看得见的不同？”“今天这份具体怎么做？”“这是你的个人做法，还是不同做法各有不同？”  
  - 内容推进：问题→受访者原话→食材处理或调味动作→下锅、烤制或出锅前的状态变化→成品近景。  
- **事实边界**：只拍当天真实在卖、真实制作的品类；不宣称某种做法唯一正确，不讲未经确认的配方、成本或食材来源。  
- **关键画面（3个）**：  
  - 掌勺人面对镜头回答“哪一步不能急”，保留现场原话。  
  - 食材处理、调味或烤制中的一个关键手部动作。  
  - 出锅前后同一份食材的状态变化。  
- **场景设置**：干净整理后的操作台、灶台或烤炉旁；镜头避开杂乱区域。

**4️⃣ 脚本结构**  
- **冷知识结构**：  
  - 提出反常识问题：“忙的时候，为什么反而不能立刻下锅？”  
  - 采访回答：保留掌勺人的实际判断。  
  - 现场验证：只拍一个关键步骤。  
  - 解释可见变化：例如颜色、受热状态或调味附着情况，以当天真实画面为准。  
  - 结尾抛问：观众吃串串、烧烤或川菜时，会不会注意这一步。

**5️⃣ 结尾行动指令**  
“你吃川味时，最想看哪一步？评论区告诉我。”

**6️⃣ 执行要点**  
- 拍前先确认当天要做哪个品类，避免临时没素材。  
- 手机固定拍关键动作，再补一段近距离手持特写。  
- 油烟较大时，手机镜头不要贴近锅口或烤炉。  
- 采访回答尽量拍完整一句，剪辑时不要断章取义。  
- 不拍配方比例、未公开经营信息或可能引起误解的后厨画面。

## 选题3：成都做法和南乐吃法，大家更在意锅底、蘸料还是菜品？

【方向】成都做法，南乐朋友怎么看  
【目的】流量型  
【结尾动作】评论  
【成交步骤】—

**承接**：取自方向3“成都人来到南乐半年后，在口味、吃法、晚饭习惯上真实感受到的不同取材”“交流差异，不比较高低”的思路。

**0️⃣ 视频目的**  
流量型。用成都人与南乐本地用户对“吃串串更在意什么”的不同选择，带动本地评论互动。

**🅰 打法**  
- **36计·第35计 街头采访**：先问不同受访者同一个吃串串问题→追问选择背后的具体吃法→由成都来的掌勺人展示自己的实际做法→不判定哪种更好。

**1️⃣ 爆款元素**  
- **反差**：套用句式「南方人 vs 北方人」  
- 应用：不做地域高低比较，改为呈现“成都做法”和“南乐本地吃法”的中性差异。

**2️⃣ 开篇钩子**  
“成都人做串串更盯着锅底，南乐朋友吃串串更在意什么？今天去问个明白。”

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：围绕“吃串串时更在意锅底、蘸料还是菜品”做本地街访，记录不同真实选择。  
- **核心问题与观众价值**：让南乐本地用户有一个能参与、能表达自己吃法的问题，也让陌生用户理解不同地方吃同一种食物时关注点可能不同。  
- **取材与内容推进**：  
  - 采访对象：愿意出镜的南乐本地成年人；可优先选择下班路过、准备吃晚饭的人，不拍未成年人。  
  - **主问题（原目的）**：“跟【待确认：前一时段】比，现在店里生意有什么变化？具体变在哪里？”  
  - **本条深入的问题**：“如果你吃串串，只能先选一个最在意的点，你会选锅底、蘸料还是菜品？为什么？”  
  - 追问：“你一般怎么搭配？”“有没有一种你不太习惯的吃法？”“你这个习惯是自己一直这样吃，还是身边人带出来的？”  
  - 内容推进：先由掌勺人说自己来自成都、来南乐半年；再给街访答案；最后拍掌勺人当天实际准备的锅底、蘸料或食材中的一项。  
- **事实边界**：成都人、做川菜9年、来南乐半年为已知事实；街访对象的偏好、店里前后生意变化均以现场原话为准。不把少量街访当成南乐所有人的结论。  
- **关键画面（3个）**：  
  - 掌勺人站在摊位旁提出问题。  
  - 受访者回答位置保留现场原话，未经同意不拍正脸。  
  - 锅底、蘸料或菜品的真实准备画面，三者只选一项做重点。  
- **场景设置**：摊位附近不影响通行的位置；风噪大时改在店内入口或安静一侧采访。

**4️⃣ 脚本结构**  
- **地域差异结构**：  
  - 成都掌勺人的个人吃法或关注点。  
  - 街访同一问题，呈现不同选择。  
  - 追问“为什么”，让回答有具体内容。  
  - 回到当天实际制作画面。  
  - 收尾不站队：“吃法不同，坐一桌才有意思。”

**5️⃣ 结尾行动指令**  
“吃串串你最先看锅底、蘸料还是菜品？评论区选一个。”

**6️⃣ 执行要点**  
- 先准备一句简短说明：“我们拍个南乐吃串串习惯的小采访，可以出镜吗？”  
- 拒绝就立刻结束，不追问。  
- 采访问题统一，方便剪辑时做真实对照。  
- 采访回答短也可以保留，不强迫对方说出“有反差”的答案。  
- 避免“成都更正宗”“南乐吃法不对”等表达，只做交流。

## 选题4：做川菜9年的人，生意前后变化时先改的不是手艺，是哪件小事？

【方向】掌勺的人，四点前也在忙  
【目的】人设型  
【结尾动作】关注  
【成交步骤】—

**承接**：取自方向4“掌勺、翻锅、烤制等有职业感的镜头，再切到整理操作台、摆食材等细碎动作”“不把普通劳动拍成苦情”的思路。

**0️⃣ 视频目的**  
人设型。让用户记住这位成都来的川菜厨师，不只会掌勺，也会把当天出摊前的小事一件件做好。

**🅰 打法**  
- **36计·第35计 街头采访**：用掌勺人自己的真实回答作为主线，询问经营前后变化后自己会先调整哪件准备小事→再用当天动作证明，而不编奋斗故事。

**1️⃣ 爆款元素**  
- **反差**：套用句式「曾经 vs 现在」  
- 应用：对比“大家以为掌勺只负责翻锅”和“现实中出摊前先整理、准备、收拾”的身份反差，不虚构过去经历。

**2️⃣ 开篇钩子**  
“做川菜9年，生意前后有变化时，我先改的不是锅里的火候，而是出摊前这件小事。”

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：用掌勺人亲口讲述经营节奏变化时，自己怎样从一件小事开始调整当天准备。  
- **核心问题与观众价值**：观众能从一个真实劳动细节认识出镜人：他不把“掌勺”当成只站在灶前的工作，而是把准备、操作和收尾连在一起。  
- **取材与内容推进**：  
  - 采访对象：本店掌勺人本人；如店主另有其人，涉及经营判断前先确认是否允许公开。  
  - **主问题（原目的）**：“跟【待确认：前一时段】比，现在店里生意有什么变化？具体变在哪里？”  
  - **本条深入的问题**：“这种变化出现后，你出摊前最先调整的是哪件小事？”  
  - 追问：“为什么先动这一件？”“以前怎么做，现在怎么做？”“今天能不能直接拍给大家看？”  
  - 内容推进：掌勺镜头→采访原话→整理台面、摆食材或备料中的一项→回到开火前的状态。  
- **事实边界**：可使用“成都来的川菜厨师、做川菜9年、来南乐半年、每天下午4点出摊”这些已确认信息；经营变化和调整动作必须根据当天真实回答拍摄。  
- **关键画面（3个）**：  
  - 掌勺人翻锅、烤制或处理食材的职业镜头。  
  - 采访中说出“先改哪件小事”的现场原话。  
  - 他低头整理操作台或准备食材的连续动作。  
- **场景设置**：下午4点前的摊位或操作区，人物站在自己真实工作的地方回答。

**4️⃣ 脚本结构**  
- **观点立场结构**：  
  - 亲身经历：掌勺人说出自己观察到的经营变化。  
  - 我的判断：变化出现时，先别急着只盯灶台。  
  - 具体论据：当天先做哪件准备小事、为什么这样做。  
  - 动作验证：拍当天真实准备。  
  - 感悟收束：掌勺是开火前就开始的事。

**5️⃣ 结尾行动指令**  
“想看这位成都掌勺人每天4点前都忙什么，关注我。”

**6️⃣ 执行要点**  
- 不要求掌勺人背稿，只提前告知问题，让他按自己的话回答。  
- 先拍工作动作，再补采访，人物状态更自然。  
- 不拍疲惫卖惨镜头，不把普通工作包装成苦难叙事。  
- 若当天经营没有明显变化，就改问“没有变化时，你一直坚持先做哪件小事”，如实呈现。

## 选题5：第一次来吃川味串串，生意前后变化会让当天这份怎么准备？

【方向】今天这份从备料到出品  
【目的】变现型  
【结尾动作】到店  
【成交步骤】到店消费

**承接**：取自方向5“准备食材→关键操作→完成出品”“每条只拍一个品类或一道实际在卖的菜”的思路。

**0️⃣ 视频目的**  
变现型。让第一次到店的本地用户，通过一份真实出品过程看明白店里当天卖的是什么、怎么做出来。

**🅰 打法**  
- **36计·第35计 街头采访**：先问掌勺人前后生意变化是否影响当天这份出品的准备方式→追问真实流程如何调整→完整拍一份实际在卖的串串火锅、川味烧烤或川菜。

**1️⃣ 爆款元素**  
- **人群**：套用句式「第一次体验X的人」  
- 应用：圈定第一次到店、还不知道三类品类怎么呈现的南乐用户。

**2️⃣ 开篇钩子**  
“第一次来吃川味串串，今天这份到底从哪一步开始？先去问问掌勺的人，生意前后变化会不会改掉它的准备流程。”

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：选择当天真实在卖的一份出品，用采访回答串起从准备食材到完成出品的过程。  
- **核心问题与观众价值**：第一次来的人能看到真实品类、真实制作和真实成品，降低“店里到底卖什么”的陌生感。  
- **取材与内容推进**：  
  - 采访对象：本店掌勺人；不需要虚构顾客体验或顾客台词。  
  - **主问题（原目的）**：“跟【待确认：前一时段】比，现在店里生意有什么变化？具体变在哪里？”  
  - **本条深入的问题**：“这种变化会让今天这份菜从备料到出品的哪个环节调整？”

- **成本**：套用句式「花小钱办大事」  
- 应用：只解决“第一次来怎么选更不容易点乱”的时间与决策成本；不承诺具体价格、优惠或低价套餐。

**2️⃣ 开篇钩子**  
“第一次来店里，想吃热乎的、想吃烧烤、还想点川菜，到底怎么选才不容易点乱？今天去问问掌勺的人。”

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：围绕第一次到店用户的真实选择难题，用本地采访和当天可供应的品类，讲清不同吃饭场景下的选择思路。  
- **核心问题与观众价值**：用户不用先背菜单，能先按“下班想吃热乎的、朋友临时碰面、带家人吃饭”等场景理解自己该问什么、看什么。  
- **取材与内容推进**：  
  - 采访对象：本店掌勺人；可补充愿意受访的南乐本地成年人，询问其第一次去一家新店时最怕点不明白什么。
