  - 待老板确认

- **问题**：哪位老客回来过？第一次怎么来的，第二次来时说了什么或点了什么？

  - 待老板确认

- **问题**：顾客进店或点单时最常问哪句话？你通常怎么回答？

  - 待老板确认

- **问题**：这个月店里发生过哪件具体小事？谁在场、先发生什么、你做了什么、最后怎样？
  - **我的推测**：出摊备菜、临时调整、顾客点单或设备状况，都可能形成真实内容；先问事，不预设戏剧冲突。
  - 待老板确认

- **问题**：顾客说过哪句原话，能说明他为什么选这里而不是别家？你亲手做的哪一步，顾客能直接看见差别？
  - **我的推测**：老板认为的差异可能是配方和手艺，顾客感受到的也可能是口味、点单体验或价格；需要顾客原话和具体操作佐证。
  - 待老板确认

## 一句话定位

**南乐成都川菜厨师，每天出摊做川味串串火锅、川味烧烤、川菜，带你看一锅一菜怎么做。**

## 六维地基

### 1. 人设定位

- **原料在哪**：可用的真实材料是“成都来的川菜厨师”“做川菜9年”“来南乐半年”“每天4点出摊”。这些是身份、经历和固定动作，不是形容词。正宗配方、低门槛属于经营卖点，不能直接替代人设。
- **人设标签句**：**每天四点出摊的成都川菜厨师。**
- **用了哪个入口**：特殊经历（成都来南乐）+职业身份（川菜厨师）。
- **验证**：标签能由籍贯、职业和固定出摊时间直接验证；但要长期拍得住，需稳定记录备菜、掌勺和出摊，不靠编故事。
- **在同类账号里的位置**：推测同类餐饮号常见做法是老板介绍菜品或单纯拍吃播。这个号可以把“厨师本人持续做菜”作为辨识点；是否与南乐同行形成明显差异，待竞品研究后确认，不能仅凭档案断言别人没有。
- **证据链**：
  1. 拍真实备菜、掌勺和出摊过程；
  2. 讲川菜经验时用现场食材和操作说明；
  3. 分别记录串串火锅、烧烤、川菜的真实出品；
  4. 用顾客真实提问和老板实际回应补充内容，取得授权后再拍。
- **边界**：不把“正宗”说成无可争议的结论；不编顾客评价、经营成绩或性格故事；不说未确认的口味、食材、价格与出摊之外的营业信息。

### 2. 用户定位

- **一句话画像**：南乐本地下班后想吃顿热乎饭的白领，或需要安排一家人晚餐、想先弄清菜品和点单方式的宝妈。
- **为什么是他们、不是另一批**：白领与宝妈是档案明确的目标职业，且本地餐饮消费能直接到店。先不把内容主要做给外地美食爱好者、厨师同行或泛美食观众；他们可能带来播放，却未必能到南乐消费。主攻白领和宝妈的先后比例，待后台受众和实际顾客情况验证。
- **他们心里真正在想什么**：推测白领会想“下班去吃，价格和菜品是不是一眼能看明白？”宝妈可能想“带家人吃，能不能选到合适的东西？”这些是待验证的用户假设，不当作顾客原话。
- **决策链路**：刷到短视频 → 确认南乐本地与出摊时间 → 看见具体品类、出品和价格规则 → 与同行或家人商量 → 到店。具体地址、价格、营业规则尚未提供，发布前必须补齐，不能用模糊信息引导到店。
- **什么时刻会想起你**：推测是下班前计划晚饭、临时约朋友吃饭、安排家庭晚餐时。可围绕这些时刻拍内容，但要用实际发布数据验证，不宣称这是已证实的客流规律。
- **他在平台上搜什么**：建议测试“南乐串串”“南乐烧烤”“南乐川菜”“南乐一元火锅”等本地搜索词；店铺地址和名称要与实际信息一致。

### 3. 内容定位

- **长期提供什么价值**：让南乐本地人看见三类川味菜品的真实制作和出摊现场。
- **内容方向**：多元四类打底，设“每天四点出摊”作为可反复记录的固定栏目。选择多元而不是全号单一主题，是因为经营品类有三类，且目前没有证据证明单一主题有足够连续素材；固定出摊栏目则能稳定提供现场素材。
- **当前阶段配比**：
  - **作用配比：流量型60%、人设型20%、变现型20%。** 起号期优先让陌生本地用户看到；人设内容用真实职业过程建立记忆；变现内容从开始就保留，但避免账号看起来全是促销。比例是起步测试假设，后续按非关注播放、主页访问和到店咨询调整。
  - **形式分配**：流量型以晒过程和大众美食知识为主，需加成本、反差或具体场景等看点，不能只讲行内技巧；人设型以真实职业经历和现场过程为主；变现型以出品过程、菜品展示和真实规则说明为主，核心理由是厨师手艺与一元火锅低门槛，具体价格和适用规则需核实后再说。
  - **题材分配：主赛道80%、目标人群兴趣20%。** 主赛道轮换写清**川味串串火锅、川味烧烤、川菜**，三类都要有位置；其余围绕白领下班、宝妈安排晚饭等具体生活场景。该比例是起号测试建议，不代表观众偏好已被证实。
- **主力形式**：档案没有“数据最好的内容类型”，因此不能称任何一种已被验证。起步先用晒过程作为测试主力：掌勺和下午出摊是已有事实，拍摄素材明确，较容易持续；跑出数据后再调整，不能把假设写成结论。
- **每类内容管哪一段路**：流量型负责刷到；人设型负责记住厨师本人、形成信任；变现型负责让本地用户看清具体菜品与消费方式，再决定到店。
- **三种视频各怎么拍**：
  - **流量型**
    - 四大脚本：用晒过程结构，拍“下午出摊前，厨师先处理哪一步”；画面要有明确动作或意外信息，避免流水账。结尾：评论。
    - 起号36计：第1计·反向操作：先拍常见备菜动作，再由厨师做一个可解释的反向操作，现场展示真实结果；具体操作须老板确认安全、合理后再拍。
  - **人设型**
    - 四大脚本：用个人经历结构，讲“成都来的川菜厨师，来南乐半年后，每天下午四点出摊”；中间只补老板确认的真实细节。结尾：关注。
    - 起号36计：第7计·一句话设定故事感：镜头从准备出摊开始，字幕写“一个成都来的川菜厨师，下午四点准时开始一天的出摊”；拍真实动作，不编困境。结尾：看主页。
  - **变现型**
    - 四大脚本：用晒过程·火车节，拍一份实际在售菜品的制作过程，说明已确认的点单或价格规则。结尾：到店。
    - 起号36计：第10计·情境还原：拍一次真实点单场景，由老板说明客人如何点一元火锅、随后如何出品；不安排虚构顾客，不代写顾客评价。结尾：到店。
- **配比核验**
  1. 是：起号期流量型占最大比例，符合阶段优先拿陌生流量的判断。
  2. 否：最好内容类型未提供，晒过程只是待验证的起步选择。
  3. 是：流量型占60%，但每条仍需实际设计大众看点与至少一个爆款元素。
  4. 是：保留20%目标人群生活场景题材，避免全是厨师同行才看得懂的内容。
  5. 是：比例依据起号阶段和本地到店目标设定，属于测试配比，不是业绩保证。
- **第一条该发什么**：拍一条**流量型**视频，用“四大脚本·晒过程”：从备菜开始，拍厨师收拾操作台、处理食材、准备出摊的连续动作，字幕交代“成都来的川菜厨师，每天下午四点出摊”。第一条只承担让本地陌生人停留观看，不讲优惠、不喊到店；画面里只拍一类当日真实在卖的品类。开场看点应来自具体操作，拍摄前先确认哪一步最有辨识度，不能凭空造反差。

### 4. 呈现定位

主要形式：现场视频配音Vlog，便于记录备菜、掌勺和出摊；辅以简短口播解释。档案未说明团队、设备和每周可投入时间，**产能待确认**，不虚报周更条数。主要在真实备菜和出摊现场拍，先确认拍摄不影响食品操作与顾客隐私。

### 5. 风格调性

正向匹配：以真实出摊和做菜现场配合厨师身份，避免硬造网红反差。气质关键词：直接、实在、烟火气。  
会说的一句话：“这一步我现在做给你看。”  
不会说的一句话：“来我这吃，保证你吃过就忘不了。”——承诺无法由单次镜头证明。

### 6. 变现定位

- **卖什么**：川味串串火锅、川味烧烤、川菜；客单价区间待确认，需老板补充各品类实际售价或常见消费范围。
- **成交路径**：抖音内容 → 主页查看地址与规则 → 到店消费。
- **最缺的信任证据是什么**：可见的真实出品过程、准确地址与消费规则；目前地址、菜单和价格信息未提供。

## 🧠 记忆点设计

1. **场景**：固定拍下午四点前后的真实出摊准备；每次从同一处操作台或出摊动作开场。与固定出摊事实相连，便于重复。**待验证**：看评论是否主动提到“四点出摊”。
2. **动作**：每条过程内容保留一个自然、重复出现的掌勺动作，不要求刻意设计手势。它能把厨师身份落在画面里。**待验证**：看观众是否开始识别这一步。
3. **语言**：尝试用“这一步我做给你看”引出实际操作，只有适合内容时才说，不做强制口号。**待验证**：评论出现相关表达或观众能复述后再保留。

## ⚡ 差异化：A + 变量B

以下是行业推测，需结合南乐同类账号观察修正：

1. **常规A**：拍成品特写、配价格和店名。
   - **变量B**：行为——过程展示。
   - **A+B 长什么样**：镜头从当日某一份川味串串火锅的准备过程拍到出品，不只给成品；服务想先看清楚吃什么、怎么做的本地消费者，不编顾客反应。

2. **常规A**：口播介绍“我们是做川菜的”。
   - **变量B**：情境还原。
   - **A+B 长什么样**：拍一段真实备菜到出摊的流程，让厨师边操作边解释一处关键步骤；解释内容由老板确认，避免把个人做法说成行业普遍标准。

3. **常规A**：只围绕招牌或单一菜品持续拍。
   - **变量B**：换场景、换题材但保留同一厨师视角。
   - **A+B 长什么样**：不同视频轮流拍**川味串串火锅、川味烧烤、川菜**，每条聚焦一种；用同一出摊现场和掌勺者串起账号，避免只让观众误以为店里只卖一个品类。

## ✅ 自洽检验

1. **遮住字幕，还能看出账号气质吗？** 部分可以：备菜、掌勺、出摊能呈现厨师身份；但若镜头只是成品特写，仍无法辨认是谁在做。补救：稳定拍到出镜人和连续操作。
2. **只听声音，还能判断人物性格吗？** 目前不能确认，档案没有声音、表达习惯或性格信息。补救：先采录真实操作讲解，不要求表演；根据自然表达再定语言风格。
3. **头像、主页简介、单条视频放一起，像同一个账号吗？** 方向上可以，但地址、价格规则和现有视觉风格未提供，现阶段不完全过关。补救：确认门店信息后统一头像、简介和出摊现场画面，视频内容轮换呈现三个品类。
