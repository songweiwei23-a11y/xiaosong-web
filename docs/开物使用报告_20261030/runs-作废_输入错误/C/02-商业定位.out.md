# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

这是 **A 本地实体店｜D 家居家电类** 的生意，家具成交不是“刷到就下单”，而是“刷到先记住—到店再判断—带家人商量后成交”。

家具店的收入主要靠两件事：一是实木家具的单件或组合销售；二是布艺沙发按尺寸、款式、坐感与家庭空间匹配成交。它不是高频复购生意，顾客一旦买错，通常会用很多年，所以比起“便不便宜”，更怕“材质看不懂、尺寸放不下、坐着不舒服、家里人不认可”。

**获客成本卡在信任建立。**  
县城用户往往会先去几家店看，再问装修师傅、亲戚或邻居。线上内容的作用不是替代到店，而是先让用户知道：这家店能看到木料、有人能讲清楚，值得专门去一趟。

**决策周期我推测偏长，待确认。**  
新婚家庭可能在装修收尾、搬家前集中看家具；换房业主则常在旧家具处理、新房软装确定后开始比较。多数人会先看款、量尺寸、问家人意见，再回来定。  
待确认：顾客从第一次进店到成交通常隔几天、是否会二次到店、谁是家庭最终付款决策人。

**淡旺季不是绝对固定，但节点很明确。**  
更容易出现家具需求的节点是交房、装修收尾、结婚、搬家、旧房翻新，以及春节前想把家里收拾利索的阶段。周末和下班后更适合承接到店，因为夫妻或家人有机会一起看、一起坐、一起讨论。

**这行最常见的自嗨，是把视频拍成“家具电子画册”。**  
一排餐桌、一圈沙发、配上“新款到店”“工厂直供”，用户看完只知道店里有货，不知道自己该如何判断。尤其家具属于高决策产品，用户真正愿意停下来的，是“我家这种情况该看哪里”，不是“这张桌子看起来不错”。

老周真正该占的位置，不是“又一家卖家具的”，而是：**顾客到店前看不懂的地方，老周能在工坊和门店里拿实物讲明白。**

**一句话定位：**  
**县城老周现场看料，帮你选实木家具、布艺沙发。**

## 变现全景

### 现在能卖什么

1. **实木家具**  
   包含实木餐桌椅等现有经营品类。用户购买时更关注木料、结构、尺寸、与家里空间是否协调。  
   **为什么能卖：**自家有木工工坊，能把“木料从哪里看、结构怎么看”变成到店前可理解的证据。

2. **布艺沙发**  
   顾客已有明确高频问题：“沙发怎么挑不踩坑”。  
   **为什么能卖：**这不是只靠展示款式的产品，用户需要试坐、看尺寸、结合家里谁用和怎么用来选；门店实物体验比纯线上图片更有优势。

3. **到店看料、试坐与选购沟通**  
   这不是额外收费项目，而是短视频最应该卖出去的“第一次到店动作”。  
   **为什么重要：**家具成交前，用户先得敢进店、愿意花时间看。老周的内容要先把“到店会被硬推销”的顾虑降下来。

4. **待确认：送货、安装、定制或搭配类服务**  
   档案没有写是否提供，暂不写成卖点。  
   **先补一条信息：**顾客成交后，门店实际承担哪些环节？送货、安装、售后分别由谁做，最近一次真实处理过程是什么？

### 各自的客单价与毛利大致区间

现有资料没有采购价、零售价、运输安装成本、毛利和本地竞品价格，**不能替门店编客单价与毛利区间**。

但运营上可以先按决策难度判断：

| 产品/服务 | 决策难度 | 为什么 |
|---|---|---|
| 实木家具 | 高决策 | 用户会比较材质、尺寸、风格、结构和预算，通常需要到店看料。 |
| 布艺沙发 | 高决策 | 用户要试坐、看尺寸、考虑耐不耐用和家庭使用方式。 |
| 到店看料、试坐、选款沟通 | 低门槛动作 | 用户不必当场买，但愿意先来确认材料和坐感。 |

**第一周必须补齐的经营数据：**  
- 实木餐桌椅常卖的价格带；  
- 布艺沙发常卖的价格带；  
- 各品类大致毛利；  
- 顾客进店后最容易成交与最容易犹豫的产品；  
- 从看款到成交平均要几次到店。  

这些数据不只是财务问题，决定后续视频该把用户引向哪一类产品、什么程度的咨询才算有效线索。

## 主推产品

**主推转化入口：实木餐桌椅为主的实木家具。**

这不是把布艺沙发降成配角，而是起号期先用实木家具承担“把人带进店”的任务；布艺沙发同样保持独立内容线和变现内容线，轮流承接不同需求。

**为什么先推实木家具：**

1. **工坊资源能直接成为证据。**  
   老周能拿真实木料、拍工坊动作、拍局部结构。相比只在展厅介绍成品，更容易让陌生用户停下来，也更容易建立“现场能看料”的记忆。

2. **实木家具的用户问题更适合起号。**  
   “木头到底看哪里”“餐桌尺寸怎么留”“看颜色之外还要看什么”，都是新房、换房家庭普遍会遇到的问题，覆盖面比单纯介绍某一张桌子更大。

3. **它能把用户自然带到门店。**  
   木料、纹理、边角、连接位置不适合靠一张图说完；短视频看出问题后，用户更容易产生“我去现场摸一摸、看一眼”的下一步。

4. **生产与内容节奏更匹配。**  
   工坊里只要有真实的选料、打磨、检查、搬运、成品过程，就能拆成多条视频；不需要额外找演员或搭复杂场景。

**布艺沙发怎么放：**  
布艺沙发不跟实木家具强行同框。每周至少保留独立的“试坐、尺寸、家庭使用场景”内容，让用户知道这家店不仅能看木料，也能把沙发怎么选讲清楚。

## 成交路径

### 1. 第一次接触看到什么

用户刷到的不是产品报价，而是一个具体问题：

- 老周拿一块木料说：“买实木餐桌，别只问这是什么木，先看这儿。”
- 一个人在沙发上只坐一下就起身，老周说：“这样试坐，回家后才发现不对劲。”
- 工坊里正在处理一块料，字幕写：“这一步不看，做成餐桌后才发现不顺眼。”

**靠什么产生兴趣：**  
靠用户原本就怕判断错的地方，而不是靠“店里新到一批货”。

**这一步会流失谁：**  
只想看低价、只想一条视频替自己做全部决定的人。  
**为什么：**账号不需要承接所有人，先吸引愿意为“看明白再买”花时间的人，后面的成交更稳。

### 2. 看完后为什么愿意继续点主页

主页要连续给出两类证据：

- **实木家具线：**木料、结构、餐桌椅尺寸、工坊关键过程；
- **布艺沙发线：**试坐、尺寸、家里谁用、不同需求怎么问。

用户点主页后要能快速确认三件事：  
“这是本地店”“老板本人长期在讲”“不是只拍一次广告”。

**这一步会流失谁：**  
刷到一条内容但主页看不出卖什么、在哪里、能提供什么的人。  
**为什么：**家具用户不会因为一条视频就马上到店，他们要先判断这家店是不是持续做这件事。

### 3. 在哪里沉淀

**优先沉淀到门店到店场景，私信只做预约和问题收集。**

原因是实木家具和布艺沙发都需要摸、看、坐、量。私信里能解决的是“你家大概多大”“准备买餐桌还是沙发”“什么时候方便来看看”，不能替代现场判断。

建议主页承接统一写清：  
- 老周是谁；  
- 做什么品类：实木家具、布艺沙发；  
- 用户来店能做什么：看木料、试坐、看款。  

**这一步会流失谁：**  
只在私信里反复问价格、却不愿提供空间和需求信息的人。  
**为什么：**家具价格脱离尺寸、材质、款式和配置没有可比性。前端内容要先把用户带进“按需求判断”的沟通方式，避免客服陷入无限报价。

### 4. 临门一脚是什么

不是“今天不买就没有”，而是用户到店后亲自完成一次判断：

- 看木料和成品的对应关系；
- 坐在布艺沙发上，按家庭使用方式试坐；
- 把家里的空间尺寸、装修进度、使用人数说清楚；
- 与家人一起确认。

**真正的临门一脚，是“我看明白了，这个更适合我家”。**

**这一步会流失谁：**  
尺寸没量、装修没到阶段、家庭意见还没统一的顾客。  
**为什么：**这不是销售话术不够的问题，而是用户还不在成交窗口。此类人应留下真实需求，后续在对应节点再联系，不能硬催。

## 信任证据清单

高决策家具不靠“质量好”这类词，靠用户能看到、摸到、复述出来的证据。

| 可拍证据 | 证明什么 | 当前状态与怎么拍 |
|---|---|---|
| 老周在工坊拿真实木料，手指指出具体位置 | 专业、真实 | 已具备。拍近景：手、木纹、切面、边角，不只拍木头堆。 |
| 木料与成品实木餐桌椅的对应关系 | 真实、过程 | 已具备基础条件。待确认哪些产品确实与工坊过程有关，不能暗示所有货都由工坊制作。 |
| 工坊里真实的选料、打磨、检查动作 | 过程、专业 | 已具备。每次只拍一个动作，并说清它和使用有什么关系。 |
| 顾客到店试坐布艺沙发的真实步骤 | 专业、体验 | 待拍。需要顾客授权；没有授权时，先由店员或老周本人演示，不伪装成顾客反馈。 |
| 同一空间内，不同尺寸沙发的摆放差异 | 产品适配能力 | 待确认是否有可拍样板空间。只展示“尺寸变化带来的空间感受”，不承诺适用于所有户型。 |
| 顾客最常问的原话与老周现场回答 | 真实、沟通能力 | 待积累。拍摄时记录真实问答，征得对方同意后再发布。 |
| 最近一次售后或不满意处理过程 | 售后、责任边界 | 待确认。先问一件真实事件：发生了什么、怎么处理、最后结果如何。没有事实不拍。 |
| 一位回头客第二次来的原因 | 结果、信任 | 待确认。必须拿到顾客原话和真实购买过程，不能由老板代替顾客下结论。 |

**优先补的三条证据：**  
1. 顾客买实木家具时实际会问什么；  
2. 顾客买布艺沙发时实际会犹豫什么；  
3. 一次真实的成交后或售后后反馈。  

因为这三条最能决定变现内容该讲什么，而不是凭行业印象拍。

## 变现型内容怎么排

### 变现型内容占比建议 + 理由

**起号期建议：变现型内容占 25%。**

原因不是变现不重要，而是这个账号现在是 0—1000 粉的起号期。前期如果连续拍“到店看看”“这款多少钱”，用户会直接把账号识别成广告号，陌生流量起不来。

但家具又是高决策产品，不能只靠流量内容，所以从第一周开始就必须有变现内容，承担两件事：

- 让用户知道到店后能获得什么判断；
- 让真正有装修、结婚、换房需求的人知道该怎么联系、怎么来店。

剩下的内容按已定地基执行：  
- 流量型 60%；  
- 人设型 15%；  
- 变现型 25%。  

实木家具、布艺沙发在变现内容中轮流出现，不把任何一个品类长期缺席。

### 方向一：实木餐桌到店先看什么

- **对应成交路径：**从主页建立信任后，推动第一次到店看料。  
- **成交理由：**自家工坊、木料可现场看。  
- **观众变化：**从“我只会问价格”变成“我知道进店该看什么”。  
- **为什么值得拍：**用户一旦知道店里不是只摆成品，而是能看木料、问具体问题，到店门槛会降低。

**四大脚本拍法：教知识·解题型**  
场景难题：“新房快装完了，餐桌看了好几家，越看越不知道差在哪。”  
→ 放大危机：“只看颜色和款式，回家后才发现和自己想的不一样。”  
→ 给到店前的低门槛动作：“到店先别急着问价格，先看一块料和成品怎么对应。”  
→ 老周指向一个真实观察位置，讲清“为什么看这里”。  
→ **结尾行动：到店。**  
“想现场看料，再来店里找老周。”

**36计拍法：第15计·正确做法VS错误做法：**  
事件是：先拍“只站远处看餐桌颜色、马上问价”的常见看法；再拍老周把木料和成品放在一起，让顾客看具体位置；最后说明这不是万能判断，仍要结合自己家的尺寸和使用需求。  
**不拍成同行对立，不说谁家的不好。**

---

### 方向二：买布艺沙发，试坐别只坐一下

- **对应成交路径：**从兴趣到到店试坐。  
- **成交理由：**门店能现场试坐、看实物、按家庭使用场景沟通。  
- **观众变化：**从“喜欢这个颜色就够了”变成“我得按家里谁用、怎么用来试坐”。  
- **为什么值得拍：**前采已确认顾客常问“沙发怎么挑不踩坑”，这是已有真实需求，不是编出来的选题。

**四大脚本拍法：教知识·解题型**  
场景难题：“家里沙发买回去，才发现坐久了不习惯。”  
→ 具体原因：“很多人到店只看一眼颜色、坐一下就走。”  
→ 给三个可执行问题：  
1. 家里主要是谁坐；  
2. 平常是短坐、躺靠还是一家人一起坐；  
3. 先量空间，再看尺寸。  
→ 老周在沙发区用真实动作演示试坐与量位置。  
→ **结尾行动：到店。**  
“准备买沙发的，到店坐一坐再定。”

**36计拍法：第10计·情境还原：**  
事件是：还原一个真实但不指向具体顾客的到店情境——“顾客说只想挑个颜色好看的”；老周不否定，而是追问家里几个人坐、空间多大、平常怎么用；随后演示试坐和看尺寸。  
前提：对话必须来自老周真实常见问答；没有真实原话，就用旁白描述，不摆拍成真实顾客。

---

### 方向三：工坊里的这一步，和餐桌进家后有什么关系

- **对应成交路径：**从“看热闹”走到“认可这家有现场证据”。  
- **成交理由：**自家工坊，顾客能现场看木料和过程。  
- **观众变化：**从“工坊就是机器和木头”变成“我知道这一步和我将来用餐桌有关”。  
- **为什么值得拍：**工坊是账号最大的场景资产，但只有和用户未来使用连接起来，才不至于拍成流水账。

**四大脚本拍法：晒过程·火车节**  
起因钩子：“这块料今天进工坊，不是直接做成桌面。”  
→ 关键步骤：拍老周真实检查、处理或确认的一个环节。  
→ 结果：镜头回到对应成品或半成品，老周说明“顾客来店里，也可以直接看这类料”。  
→ **结尾行动：到店。**  
“想看实木家具用的料，到店找老周。”

**36计拍法：第17计·互联网嘴替/替网友做：**  
事件是：从评论区或私信挑一个真实问题，例如“买实木餐桌到底该看哪里”；老周在工坊里拿当天正在处理的料做回答，拍他实际看、实际指的位置，最后给出适用条件。  
没有真实评论时，先不写“网友问我”，可改成“今天工坊里正好有块料，我拿它讲一个进店常问的问题”。

---

### 方向四：准备换房的人，餐桌和沙发别分开想

- **对应成交路径：**从用户有模糊需求，进入到店看款、量尺寸。  
- **成交理由：**实木家具与布艺沙发都能在同一家门店看实物、结合空间一起判断。  
- **观众变化：**从“先买哪个都一样”变成“我要先弄清空间、使用人数和主要需求”。  
- **为什么值得拍：**换房用户常常不是只买一件家具，而是面对一整个空间的取舍。但内容只讲“如何厘清需求”，不承诺一条视频解决全屋选择。

**四大脚本拍法：教知识·推荐型**  
美好愿景：“换房后，家里吃饭和坐着休息的地方别互相挤。”  
→ 圈人：“准备换房、准备添置餐桌和沙发的家庭。”  
→ 引发好奇：“先决定的不是款式，而是家里哪块空间最常用。”  
→ 推荐判断顺序：  
1. 先量实际空间；  
2. 看家里日常几个人用；  
3. 决定餐桌椅和布艺沙发各自要留出的活动位置；  
4. 再到店看实物。  
→ **结尾行动：到店。**  
“尺寸量好了，带着来店里看实木家具、试布艺沙发。”

**36计拍法：第26计·推荐建议：**  
事件是：老周在门店分别站在实木餐桌椅区和布艺沙发区，用“换房家庭先准备什么”做一份到店前清单；每条建议都落到空间、人数、使用习惯，不报泛泛款式。  
注意：这条讲的是购买准备，不拍成“来我家一次配齐”的硬广。

**提醒：**  
变现内容先让用户多一个判断，再给一个到店动作。不能开头就扫一排产品、最后催用户下单；那样只会让真正需要家具的人划走。

## 定价与节奏

### 起步阶段建议怎么定价

**不建议为了短视频专门造一个低价“引流款”，除非门店本来就有真实、稳定、可持续销售的产品。**

原因有三点：

1. 家具是高决策品，低价钩子引来的用户容易只盯价格，不利于建立“现场看料、按需求选”的定位。  
2. 如果引流款与真实主销产品差异大，到店后用户会觉得预期不一致，反而增加沟通成本。  
3. 现阶段没有真实价格带和毛利数据，不能拍“低价福利”或承诺价格优势。

**起步阶段更适合卖“到店前的判断理由”。**  
例如：  
- 看实木家具前，先来摸料、看结构；  
- 买布艺沙发前，带家里尺寸来试坐；  
- 装修接近收尾时，到店把餐桌椅和沙发的使用需求说清。  

这不是免费咨询噱头，而是本来就该发生的成交前沟通，被短视频提前讲清楚。

### 什么时候可以涨价、涨价的依据是什么

现阶段先不谈涨价，因为缺少现有价格、毛利、供货和成交数据。

如果未来价格需要调整，依据不能是“视频播放高了”，而应同时满足以下真实条件：

- 原材料、运输、人工或安装成本确实发生变化；  
- 门店能给出用户看得见的材料、工艺、售后或服务差异；  
- 到店客户不再只比较价格，而是开始明确问“这款适不适合我家”；  
- 某类产品持续缺货、排期紧或供给成本上涨。  

**先补数据，再定策略。**  
连续记录 X 周：到店人数、实木家具询价与成交、布艺沙发询价与成交、未成交原因、成交周期。没有这张表，涨价或做促销都只是猜。

## ⚠️ 风险

### 1. 只拍工坊过程，没讲用户为什么该看

风险表现：视频里切料、打磨、搬运画面很多，但用户看完只觉得“挺忙”，不知道和自己买实木家具有什么关系。

**解决：**每条工坊视频拍前先写一句：  
“用户看完能少担心什么？”  
如果答案只是“知道我们有工坊”，这条不发；必须落到木料、结构、使用或到店判断上。

### 2. 为了卖货，把内容拍成连续报价

风险表现：起号期连续发产品陈列、价格字幕、到店促销，陌生用户会把账号划成广告，流量和主页访问都会弱。

**解决：**坚持流量 60%、人设 15%、变现 25%的节奏。变现内容也要先给一个判断动作，再引导到店；不靠制造紧迫感催成交。

### 3. 把“自家工坊”拍成无法证实的承诺

风险表现：用户看到工坊，就以为店内所有实木家具都由工坊制作；如果事实不完全如此，后续会产生信任落差。

**解决：**拍什么就说什么。  
工坊制作的，拍真实制作过程；工坊仅承担某些环节的，明确拍具体环节；来源待确认的产品不拿工坊背书。真实比说得大更重要。
