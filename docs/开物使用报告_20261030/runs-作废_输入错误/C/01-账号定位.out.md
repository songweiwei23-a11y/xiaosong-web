## 🔍 先说这一行

- **归口**：本地实体店，属于 **D 家居家电类**，主业是家具零售，工坊是核心信任场景。  
  **为什么**：成交发生在线下门店，用户买的是实木家具、布艺沙发，需要到店看材质、看尺寸、试坐和比价，不是线上下单即成交的标准化货。

- **这行的钱怎么赚**：家具是典型的中高决策、低频消费。实木家具通常靠单件及成套销售拉高客单，布艺沙发靠款式、坐感、尺寸和空间匹配推动成交；成交不一定靠一次讲完，而是靠顾客多次比较后回来。  
  获客成本卡在两件事：一是同城顾客不知道门店和工坊；二是顾客看不懂木料、沙发内部和尺寸，只能靠“价格”“感觉”比较，最后容易拖着不决定。  
  **为什么**：家具不是即时消费，顾客担心买错后长期使用不舒服，也担心材质与自己理解的不一致。

- **客人的决策链路**：刷到视频只是第一步，通常会经历“先收藏/发给家人→看主页→到店摸料试坐→量家里空间或问装修进度→和家人商量→再决定”。  
  **判断**：不能把视频当场成交当目标，账号首先要缩短“我敢不敢进店看”的心理距离。  
  **待确认**：目前缺少真实到店周期、客单区间、主要成交品类，无法判断平均决策时长。

- **时间规律**：需求常跟结婚、交房、装修完工、旧房翻新、春节前家庭整理等节点走。一天里，到店咨询更可能集中在下班后和周末；短视频宜在用户有空和家庭讨论前出现。  
  **为什么**：家具购买通常由家庭共同决策，用户需要有时间带家人到店，而不是看到就立即下单。  
  **待确认**：本地装修交房季、门店周末客流、春节前后成交变化，需要从老板的销售记录验证。

- **这行老板普遍会犯的错**：把镜头全对准“这张桌子好看”“这套沙发很大气”，却没回答顾客真正会问的事：木料怎么看、尺寸怎么判断、沙发怎么试坐、放进家里会不会不合适。  
  这个客户目前已有“选家具常识、木料辨认、工坊过程”的方向，**没有明显中招**；但如果只拍木头堆、机器和成品陈列，依然会变成老板自嗨。

- **同行现在都在拍什么**：常见是成品走一圈、报款式、拍门店全景、配“工厂直供”字幕，或者把家具摆拍成静态产品图。  
  **为什么大多没效果**：陌生人看不出差异，也没有“我为什么要停下来”的问题；用户看完不知道该怎么判断，更不知道这家店和别家有何关联。  
  **空档**：把“工坊真实过程”和“顾客到店前最怕判断错的点”连起来。不是炫机器，而是让老周拿一块料、一个连接部位、一张沙发坐垫，讲清用户到店该看什么。

## 🗣 我会先问老板的几个问题

- **问题**：最近一次顾客对家具或沙发不满意，具体是因为什么？当时怎么处理、说了什么、最后结果如何？
  - **我的推测**：家具店常见分歧不在“顾客故意挑刺”，而在尺寸、颜色、坐感或预期理解不一致。这个事件最能看出老周的售后边界和做事方式。
  - 待老板确认

- **问题**：有没有明确不卖、不接或不建议顾客买的货？是哪次经历让你定下这条规矩？
  - **我的推测**：老周做了12年家具，应该有自己不愿妥协的材质、做法或需求；这比说“我们质量好”更能立住人。
  - 待老板确认

- **问题**：顾客进门问得最多的一句话是什么？老周每次会指着什么、怎么回答？
  - **我的推测**：“这木头是什么木？”“沙发怎么挑？”“这个尺寸放我家行不行？”出现频率会较高，因为前采已明确顾客常问沙发怎么挑不踩坑。
  - 待老板确认

- **问题**：有没有一位回头客？第一次为什么买，第二次又为什么回来？请讲清买了什么、隔了多久、他说过什么。
  - **我的推测**：回头不是单纯因为便宜，而是上一次的看料、沟通、安装或使用体验让对方敢再来。顾客原话比老板判断更有价值。
  - 待老板确认

- **问题**：老周亲手做、亲自盯的哪一步，别人接手后最容易出现差别？
  - **我的推测**：可能在选料、看木料纹理、结构连接或沙发选型判断上，但不能先替老周下结论，必须拍到真实动作。
  - 待老板确认

- **问题**：顾客为什么选这里而不是别家？请给我一句顾客原话，不要“质量好、服务好”这类概括。
  - **我的推测**：真正差异化很可能不是“自家有工坊”本身，而是顾客能现场看到木料、问到人、摸到东西，减少猜测。是否成立，要以顾客原话验证。
  - 待老板确认

## 一句话定位

**县城老周在工坊，带你看懂实木家具、布艺沙发怎么选。**

## 六维地基

### 1. 人设定位

- **原料在哪**：真实材料是“老板老周”“做家具12年”“本地人”“自家有木工工坊”“现场看木料”。  
  这些是可拍、可验证的事实。  
  “专业、靠谱、实在”这类词目前都只是形容词，不能直接当人设。它们要翻译成镜头行为：老周能否把一块木料拿到镜头前，指出他让顾客现场看的位置；能否在顾客犹豫时说明适用条件，而不是只催成交。

- **人设标签句**：**在工坊里教你看木料的老周**

- **用了哪个入口**：**特殊经历 + 痛点+职业**。  
  12年家具从业是经历；“顾客不知道木料怎么看、沙发怎么挑”是高频购买痛点；“工坊现场看料”是解决场景。

- **验证**：这个人设能立住。  
  原因不是“做了12年”本身，而是他有工坊这一稳定证据场，能够反复拍到选料、制作、看结构、成品落地等真实过程。只要每次都由老周本人讲自己正在做的事，内容就有连续性，不是一次性资历展示。

- **在同类账号里的位置**：  
  同行常见人设是“家具老板报款型”“工厂价格型”“装修知识口播型”。  
  老周不抢“谁更便宜”，而占住“**你到店前看不懂的东西，我在工坊里拿给你看**”。  
  差别在于：别人展示成品和价格，老周展示顾客购买前缺失的判断过程。

- **证据链**：  
  1. 老周拿真实木料讲“顾客现场会问什么”；  
  2. 工坊里拍一件家具从材料到成品的关键节点；  
  3. 围绕布艺沙发，演示顾客试坐和看尺寸时该问什么；  
  4. 待确认后，记录真实顾客问题与处理过程。  
  这四类内容能持续证明“老周在现场、懂材料、讲人话”，而不是靠自夸。

- **边界**：  
  不说无法证明的“全县最便宜”“什么户型都能配”“买了绝不后悔”；不贬低同行；不把客户案例编成戏剧冲突；不把工坊拍成“所有家具都亲手制作”的暗示，除非老板确认事实。

### 2. 用户定位

- **一句话画像**：  
  **家里正等装修收尾的新婚夫妻，或准备换房的业主，刷到家具时先存下来，周末会带家人来摸木料、试沙发，却怕自己看不明白。**

- **主攻人群**：  
  1. **小镇青年**：新婚、交房、布置第一个家，关心空间好不好看、朋友来家里坐着是否得体。  
  2. **资深中产**：换房或改善居住，更愿意为看得见的材料、坐感和长期使用做判断。  
  **为什么选他们**：两类人都与实木家具、布艺沙发的家庭场景高度相关，且会到店体验，不是只看低价。

- **不优先服务谁**：  
  不优先做“只问网上最低价、只想一条视频替他决定全部家具”的泛流量人群；也不把内容主力放在银发族的泛养生式家居话题。  
  **为什么**：账号资源有限，先抓正处于购买窗口、愿意到店看料和试坐的人，成交链路才接得住。

- **他们心里真正在想什么**：  
  “看着都差不多，怕花了钱才发现材质不对、尺寸不合适，家里人还会说我没选好。”  
  这不是单纯追求便宜，而是害怕自己没有判断依据。

- **决策链路**：  
  刷到“木料/沙发问题”→收藏或转给伴侣→翻主页看老周是不是持续在工坊讲同一件事→周末进店看料试坐→回家量尺寸、商量预算→再次到店或联系。  
  所以账号要铺出一批稳定的“判断证据”，而非指望一条硬广成交。

- **什么时刻会想起你**：  
  装修群里开始讨论家具时；油工、保洁结束后；准备搬家前；父母或朋友来家里时发现旧沙发坐着不舒服、餐桌不够用时。

- **他在平台上搜什么**：  
  “县城实木家具”“实木餐桌怎么选”“布艺沙发怎么挑”“家具店看木料”“本地家具店”“新房家具怎么买”。

### 3. 内容定位

- **长期提供什么价值**：  
  **让本地家庭到店前先看懂木料和沙发。**

- **内容方向**：**多元四类打底 + 工坊看料为王牌栏目。**  
  **为什么不做纯单一主题**：工坊过程可持续，但仅拍制作容易变成流水账；家具购买还需要沙发选择、真实问题和老周的职业判断补齐。  
  **为什么不只做多元散发**：起号期必须让用户快速记住“这人是在工坊讲家具的”，因此“工坊看料”要反复出现，承担记忆锚点。

- **当前阶段配比**

  **第一层：作用配比**
  - **流量型 60%**：起号期首要任务是让同城陌生用户刷到并停下，必须是最大块。  
  - **人设型 15%**：老周的人设需要建立，但现阶段真实故事素材不足，不能硬编。  
  - **变现型 25%**：家具决策重，第一周就要有到店理由，但比例不能高到像连续广告。

  **第二层：每块怎么做**
  - **流量型**：以冷知识、反常识、过程反差为主，拍木料纹理、结构、同一空间换不同家具后的视觉变化；实木家具和布艺沙发轮流出现。  
    **为什么**：用户容易因“原来这里还能看”停下，不需要先认识店。  
  - **人设型**：以真实工坊日常、老周做事边界、待确认的顾客事件为主，用短故事或观点呈现。  
    **为什么**：人设要靠真实行为累积，不能只靠“12年经验”反复口播。  
  - **变现型**：以解题型知识、到店看料过程、沙发试坐判断为主；实木家具突出“木料可现场看”，布艺沙发围绕“怎么挑不踩坑”。  
    **为什么**：成交理由必须在镜头里看得见，不是字幕里喊出来。

  **第三层：题材配比**
  - **主赛道题材 75%**：实木家具、布艺沙发、木料、工坊过程、家庭空间。  
  - **目标人群兴趣 25%**：新房收尾、夫妻共同选家具、搬家前准备、父母来家里坐哪里等。  
  **为什么**：只讲材料会窄，只聊新婚生活又接不住成交；两者结合，用户才能从“有共鸣”走到“知道该去哪看”。

- **品类位置**：  
  - **实木家具**：流量型重点拍木料、结构和工坊过程；变现型重点拍现场看料与餐桌椅选购判断。  
  - **布艺沙发**：流量型拍“试坐时大家忽略的动作”；变现型拍坐感、尺寸、使用场景和顾客常问问题。  
  两类产品轮流做内容，不强行同框，避免账号被误解为只卖餐桌或只卖沙发。

- **主力形式**：**视频配音Vlog式工坊过程 + 老周短口播。**  
  档案没有“数据最好的内容类型”，新号无已验证数据，不能假装有主力数据。先以真实工坊过程作为低成本测试主力，连续跑满20条后，根据完播、评论和主页访问再调整。

- **每类内容管哪一段路**
  - **刷到**：流量型用“反常识问题+工坊画面”让陌生人停留。  
  - **记住**：人设型让用户记住老周不是摆拍卖货，而是每天在工坊做事的人。  
  - **信**：变现型用看料、试坐、选购判断建立“这家能让我看明白”的信任。  
  - **联系**：变现型给明确到店指令，承接同城需求。

- **三种视频各怎么拍**

  **流量型**
  - 四大脚本：教知识·拆解型。方向是“为什么有些木料看着接近，现场看时却要多看一个位置”；结尾只留：**“你家餐桌最在意什么？评论区说说。”**
  - 起号36计：**第36计·冷知识：**老周拿一块真实木料→说一个大众常忽略的观察点→镜头给局部细节→说它和家里长期使用的关联→评论提问。  
  这条不报价、不推到店、不讲店铺卖点，只用材料作为画面里的货。

  **人设型**
  - 四大脚本：讲故事·观点立场。方向是“做家具12年后，老周为什么仍坚持让顾客先看木料”；前提是补到真实经历后再拍；结尾只留：**“关注我，工坊里慢慢讲。”**
  - 起号36计：**第7计·一句话设定故事感：**老周在工坊处理当天的一块料→字幕设定“这块料，顾客进店时最容易只看表面”→他按真实工作步骤检查→落在个人判断。  
  不做虚构顾客冲突，不植入成交理由。

  **变现型**
  - 四大脚本：教知识·解题型。方向是“准备买布艺沙发的人，到店别只坐一下就走，先问这三个和你家有关的问题”；结尾只留：**“想现场试坐看款，到店找老周。”**
  - 起号36计：**第15计·正确做法VS错误做法：**同一位体验者、同一门店位置，先演示只看外观就决定的常见做法→再演示试坐、看尺寸、问使用场景的做法→老周说明适用条件→到店指令。  
  成交理由是“能现场试坐、看见实物并得到判断”，不夸大效果。

- **配比核验**
  1. **流量型与阶段匹配：是。**新号流量型60%，是最大块。  
  2. **主力形式有数据依据：暂不具备。**新号没有历史数据，以工坊过程作低成本起点，20条后看数据。  
  3. **大流量是否占主力：是。**60%流量型均要有人货场、爆款元素和具体事件。  
  4. **是否留出人群兴趣：是。**25%围绕新房、搬家、家庭决策等生活场景。  
  5. **每个数字能否解释：是。**流量为起号、人设受限于真实素材、变现承担本地到店承接。

- **第一条该发什么**：  
  **《买实木餐桌，别只问“这是什么木”，老周先让你看这一处》**  
  - **目的**：流量型，只承担“让陌生人停下来、评论”。  
  - **打法**：起号36计·第36计“冷知识” + 教知识·拆解型。  
  - **事件**：老周在工坊拿一块木料，镜头先给局部，再讲一个待老板确认后才能落地的真实观察点。  
  - **为什么先拍它**：木料是工坊最直观、最有现场感的资产；它同时让用户迅速知道老周是谁、在哪里拍，但不急着卖货。

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：视频配音Vlog为主，配老周短口播；工坊里的真实动作比坐在店里讲课更有说服力。  
- **产能**：待确认团队人数、老板可出镜时间、是否有固定拍摄人；目前不能承诺周更数量。若只有一人手机拍摄，先以“半天集中拍素材、拆成多条”执行。  
- **在哪拍**：木工工坊、门店实木餐桌椅区、布艺沙发试坐区；少用白墙口播。

### 5. 风格调性（只给结论，≤200字）

- **正向匹配**：工坊、木料、工具、成品家具与“现场看料”的定位一致，不需要故意制造身份反差。  
- **气质关键词**：朴实、清楚、有现场感。  
- **会说的一句话**：“你到店看这块料，先别急着问价格。”  
- **不会说的一句话**：“这款谁买谁满意，今天不买就没了。”  
  原因：前者是帮助判断，后者制造压力，会破坏老周“讲明白再选”的人设。

### 6. 变现定位（只给结论，≤250字）

- **卖什么 + 客单价区间**：实木家具、布艺沙发；客单价区间**待确认**。  
- **成交路径**：抖音刷到内容 → 看主页建立判断 → 私信/电话询问 → 到店看木料、试坐、看款 → 家庭决策成交。  
- **最缺的信任证据是什么**：真实顾客为什么回来、现场看料具体看什么、布艺沙发如何按家庭使用场景选，现阶段都缺可拍证据。  
- 完整的变现拆解请用「商业定位」板块。

## 🧠 记忆点设计

- **道具：固定拿一块木料讲问题**  
  每次讲实木家具时，老周先拿料、镜头给木纹或切面，再开始说。  
  **为什么有效**：道具直接连着“现场看木料”，不是为了摆造型。  
  **待验证**：评论区若用户反复叫它“老周的木头课”，可固定下来。

- **动作：手指落在具体位置再解释**  
  不空讲“你要注意”，而是每次用手指出纹理、边角、连接位置或沙发坐垫对应位置。  
  **为什么有效**：让专业判断变成肉眼看得见的动作，也利于短视频前3秒抓画面。  
  **待验证**：看完播是否优于纯口播。

- **场景声音：保留一两秒工坊原声**  
  如推料、打磨、工具工作声，随后再进配音。  
  **为什么有效**：真实现场声比模板音乐更能说明“人在工坊里做事”。  
  **待验证**：声音不能盖住人声，也要避开过度嘈杂的时段。

## ⚡ 差异化：A + 变量B

### 1. 成品展示 + 换视角

1. **常规A**：同行站在成品前介绍“这是某木、这张桌子多大”。  
2. **变量B**：情境类的**换个视角**。  
   **为什么选它**：老周有工坊，能从“顾客看成品”换到“木工看材料”，不增加演员和复杂制作。  
3. **A+B 长什么样**：  
   镜头先从餐桌成品切到同类木料，老周说：“顾客看餐桌先看颜色，我在工坊先看这里。”随后用手指向真实位置。  
   **服务用户的点**：给准备买实木家具的人一个到店前能带走的观察角度，不是单纯炫工坊。

### 2. 沙发口播 + 正确做法VS错误做法

1. **常规A**：镜头扫一排沙发，配“新款到店、欢迎来看”。  
2. **变量B**：行为类的**正确做法VS错误做法**。  
   **为什么选它**：前采明确顾客常问“沙发怎么挑不踩坑”，题材已经有真实需求。  
3. **A+B 长什么样**：  
   同一位体验者、同一个沙发区，先坐一下只看颜色；再按“家里谁坐、坐多久、空间多大”试坐和询问。老周只讲适用条件。  
   **服务用户的点**：减少用户因只看外观而犹豫，不把“选法”拍成万能答案。

### 3. 工坊过程 + 一句话设定故事感

1. **常规A**：木工工坊流水账，切料、打磨、装车。  
2. **变量B**：表达类的**一句话设定故事感**。  
   **为什么选它**：不需要编故事，只要把当天真实任务加上一个用户会关心的目标。  
3. **A+B 长什么样**：  
   开场字幕：“这块料，今天要变成一张给一家人吃饭用的餐桌。”  
   镜头拍真实工序中的一个节点，老周说清为什么在这里停下来检查。  
   **服务用户的点**：让过程不再只是机器画面，用户知道每一步和自己未来使用有关。

## ⚠️ 这个号最大的风险

1. **把工坊当素材，不把用户问题当内容。**  
   机器、木头、成品拍再多，用户仍不知道和自己买家具有什么关系。每条工坊视频都要先回答：顾客看完能多懂什么、少担心什么？

2. **老周不稳定出镜，或表达不自然。**  
   账号的人设核心是“老周在工坊里讲”，如果长期变成员工配音、产品混剪，人设就断了。  
   解决办法不是硬背长稿，而是先拍短句、手部动作和真实问答；待确认老周每周可出镜时间后，再定稳定产能。
