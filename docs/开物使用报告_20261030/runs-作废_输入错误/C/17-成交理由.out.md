## 适用的成交理由

### 1. 有特色 · 9分

**为什么成立**：这家店不只是卖成品家具，自家还有木工工坊，客户能到现场看木料，这是普通家具店不一定具备的购买体验。

**怎么拍**：
- 老周带客户走进自家木工工坊，手指着不同木料说：“买实木家具，先别急着看成品，先到这里看木料。”
- 拍木料、加工设备和正在制作的家具，再切到门店里的实木餐桌椅，形成“木料—制作—成品”的完整画面。

### 2. 专业强 · 8分

**为什么成立**：老板老周做家具12年，本地人，还拥有自家木工工坊，能够围绕木料辨认、家具制作和选购问题进行讲解。

**怎么拍**：
- 老周拿起两块木料，现场讲清楚看木料时要观察的位置、纹理和细节，镜头拍手部和木料特写。
- 拍老周在工坊查看家具制作细节，再回到门店回答“实木餐桌怎么挑”“沙发怎么挑不踩坑”等客户常问问题。

### 3. 质量好 · 7分

**为什么成立**：店里的实木家具可以追溯到自家工坊，木料还能现场查看，客户至少能看到材料和制作过程，质量判断不是只靠销售口头介绍。

**怎么拍**：
- 老周把客户带到木料旁边，先看木料，再看对应的实木餐桌椅，拍出材料与成品之间的对应关系。
- 拍工坊里的加工细节，比如木料打磨、桌面处理或结构连接；具体拍哪一步，以现场实际有的工序为准。

### 4. 实在不坑 · 7分

**为什么成立**：客户可以现场看木料，购买前能多了解材料和制作过程，减少只看宣传图片、只听口头介绍的情况。但“实在不坑”仍需要持续拍出透明沟通，不能只靠口号。

**怎么拍**：
- 老周面对镜头说：“买实木家具，先把木料看明白，再决定要不要买。”随后带客户现场查看木料。
- 拍客户询问沙发怎么挑不踩坑，老周逐项说明适合什么家庭、不适合什么情况，不回避产品的使用限制。

## 建议主打

建议组合“有特色＋专业强＋实在不坑”主打。用自家工坊和现场看木料建立差异，用老周做家具12年的经历解释木料和家具怎么选，再通过真实答疑回应“沙发怎么挑不踩坑”，既能让客户看见店铺不同，也能建立对老板判断的信任。
