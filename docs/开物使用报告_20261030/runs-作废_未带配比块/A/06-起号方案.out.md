# 🚀 起号方案

## 📌 先说结论

- **建议主攻：36计·第31计 南北/地域差异。**  
  用“成都厨师在南乐做晚饭”这个天然身份差异，拍同一种食材、同一个备餐动作在川味处理上的不同。它同时符合账号已经定好的主线：**下午四点、成都厨师、南乐晚饭、真实厨房**。  
  这不是拍“谁做得更对”，而是拍“我在成都学的是这样做，南乐这边你们怎么做”，用本地互动打开陌生流量。

- **备选：**
  1. **36计·第7计 一句话设定故事感**：当地域差异内容评论弱、观众更愿意看下午四点的备餐现场时，切到它。
  2. **36计·第36计 冷知识**：当厨师能把某个真实动作讲明白，且画面能直接证明时，切到它。
  3. **36计·第10计 情境还原**：当菜单、辣度、人数点法已经确认，且评论开始出现“怎么点”“辣不辣”时，切到它做变现承接。

- **明确不做：**
  1. **第35计 街头采访**：档案没有稳定采访人员、收音条件和路人授权条件。硬拍会拖慢更新，也容易拍成无效闲聊。
  2. **第16计 整蛊 / 第30计 角色扮演**：需要演员、顾客配合或较强表演。这个号最值钱的是下午四点真实备料，不该为了搞笑离开真实厨房。

- **多久能看出跑没跑通：**  
  先连续测试 **20—30条**，再判断主攻打法是否成立。参考线不是单条爆不爆，而是：账号从零粉逐步接近一千粉、非关注播放更稳定、南乐本地评论持续出现、观众开始记住“下午四点那个成都厨师”。  
  每一计至少连续测 **3—5条**，不能因为一条播放低就换打法。

### 1. 流量型怎么拍

- **出发点：**
  - **人：**成都来的川菜厨师；
  - **货：**川味串串火锅、川味烧烤、川菜里的真实食材和手艺；
  - **场：**下午四点的备料区、锅边、烧烤炉前；
  - **爆款元素：**反差 + 人群；
  - **三有：**有共鸣——下班前大家在想晚饭，厨师已经开始准备晚饭。

- **用什么形式：**  
  **36计·第31计 南北/地域差异 + 晒过程型·任务挑战结构。**

- **脚本结构：**  
  同一种当天真实食材或动作 → “我在成都做这一步会这样处理” → 现场完成动作 → 解释口感方向，不评价高低 → 问南乐本地观众怎么做。

- **结尾行动指令：**  
  **“南乐这边怎么做？评论区告诉我。”**

- **关键边界：**  
  档案没有确认“南乐当地具体做法”，前期不能替南乐人下定义。  
  先用“你们这边会怎么做”“我想听听南乐人的做法”收评论；等收集到真实留言和现场反馈后，再拍下一集回应。

### 2. 人设型怎么拍

- **出发点：**
  - **人物事实：**成都人、做川菜9年、来南乐半年、每天下午4点出摊；
  - **要记住的人：**不是“厉害厨师”这种空标签，而是一个每天四点提前开始忙、把晚饭前准备做在前面的人。

- **用什么形式：**  
  **36计·第7计 一句话设定故事感 + 讲故事型·职业经历结构。**

- **脚本结构：**  
  下午四点的一个普通动作 → 今天要赶上的晚饭任务 → 这一步为什么不能拖 → 厨师的工作判断 → 开炉、下锅或完成备料收住。

- **结尾行动指令：**  
  **“想看我每天四点都在忙什么，就关注我。”**

- **不拍什么：**  
  不编“创业吃苦”“顾客感动”“刚来南乐多难”等故事。档案只确认了来南乐半年，没确认其他经历，就只拍真实工作。

- **出发点：**

- **用什么形式：**  
  **36计·第10计 情境还原 + 教知识型·解题结构。**

- **脚本结构：**  
  新客真实困惑 → 厨师先问人数、辣度、想吃锅还是烤还是菜 → 按真实菜单给选择路径 → 上桌或出品画面 → 到店行动指令。

- **结尾行动指令：**  
  **“晚上到店，按你们人数我帮你配。”**

- **前提：**  
  **待确认：真实菜单、具体菜品、辣度规则、是否有固定搭配。**  
  这些没确认前，不拍“几个人怎么点”的具体组合，不编菜名和价格。

## 🎯 主攻打法：36计·第31计 南北/地域差异

### 为什么是你能拍的

档案没有提供团队人数、设备和固定拍摄频率，因此不把多人剧情、街访、复杂转场写进方案。这个打法按最低配置就能开拍：

- **出镜人明确：**本人就是成都来的川菜厨师，不需要另外找演员；
- **身份差异真实：**成都人、做川菜9年、来南乐半年，这就是天然的地域视角；
- **拍摄场地稳定：**每天下午4点出摊，备料区、锅边、烧烤炉都是现成场景；
- **素材每天发生：**串串备料、烧烤上炉、川菜下锅都是真实工作，不必设计假任务；
- **对口播要求低：**只要厨师能说清“我为什么这样做”，再用现场动作证明即可；
- **一人一机能完成：**拍手部动作、食材近景、锅边声音和厨师一句解释，不依赖顾客出镜。

**待确认：现场是否有固定拍摄手机、三脚架、领夹麦。**  
没有领夹麦时，先拍环境声较小的备料动作，厨师后期补配音，不在炒锅、油烟机最响的时候硬录口播。

---

### 结构公式：套到这个号上

**同一种当天真实食材 / 动作**  
→ **“我在成都做这一步，习惯先这样处理”**  
→ **镜头拍完整动作和锅边结果**  
→ **只讲口感方向，不说谁高谁低**  
→ **“南乐这边会怎么做？”**

注意：前期的“地域差异”不是替本地人宣布答案，而是让本地观众把答案说出来。

---

### 配什么脚本讲

**第31计·南北/地域差异 + 晒过程型·任务挑战结构。**

- **第31计管事件：**同一种食材、两种地域处理思路，制造反差和评论欲；
- **晒过程型管表达：**从下午四点的真实任务开始，拍出处理、下锅、起锅的连续动作；
- **它补上的内容：**  
  不靠空讲“正宗川味”，而是让观众从处理动作、火候和出品过程里看到厨师的手艺。

这组内容是**流量型**，不讲一元火锅的价格优势，不引导到店，只留评论指令。

---

### 前3条具体拍什么

#### 第1条  
**标题：**《同样是串串食材，我在成都下锅前会先做这一步，南乐这边呢？》（反差）

- **拍摄要点：**
  1. 首帧直接拍厨师手部处理当天真实串串食材；
  2. 厨师一句话：“这一步我在成都做串串时会先做，不是为了摆样子，是为了后面下锅更稳。”
  3. 镜头拍处理完成、放入备料盆、锅边画面；
  4. 结尾问：“南乐这边会怎么处理？评论区告诉我。”

- **为什么会让人停下：**  
  同一种大家认识的串串食材，成都厨师却在下锅前多做一个动作，动作反差清楚。

---

#### 第2条  
**标题：**《川味烧烤上炉前，我先不点火，成都厨师要先看这一处》（反差）

- **拍摄要点：**
  1. 首帧是烧烤食材和还没点着的炉子；
  2. 厨师对镜头说：“很多人以为烧烤第一步是点火，我在成都做这口，先看的是这个。”
  3. 拍真实检查、处理、上炉过程；
  4. 出现烤制状态后，说清这一步影响的是哪种口感方向；
  5. 结尾：“南乐这边烤这口，会先看什么？”

- **为什么会让人停下：**  
  “做烧烤却先不点火”违背观众的常规预期，首帧就有反差。

---

#### 第3条  
**标题：**《下午四点做川菜，我在成都学的第一步，到南乐半年也没改》（人群）

- **拍摄要点：**
  1. 首帧拍下午四点的工作台和当天要做的真实川菜食材；
  2. 厨师说：“下午四点，这一步我得先做，不然后面晚饭点容易赶。”
  3. 连续拍备料、下锅前准备、锅边动作；
  4. 不讲“正宗”“秘方”，只说这一步服务的是后面哪道出品；
  5. 结尾：“你们家做这口，是不是也先忙这一步？”

- **为什么会让人停下：**  
  “别人下班前想晚饭，厨师下午四点已经开始准备”的时间反差，能击中下班前刷视频的人。

---

### 边界

1. **不把南乐做法和成都做法拍成高低对立。**  
   只说“不同”“口感方向不同”“我在成都习惯这样做”，不说“这样才对”。

2. **不编本地口味。**  
   没有顾客真实反馈前，不说“南乐人都怕麻”“南乐人更能吃辣”。

3. **不拍假的对比。**  
   不能同一份食材随便换个摆法，就说“成都做法更香”。要讲差异，必须拍得出真实动作和实际出品过程。

4. **不把流量片拍成广告。**  
   不报价格、不喊到店、不强调一元火锅。流量片只做互动和身份记忆。

5. **不为了镜头重复造假动作。**  
   每条都跟着当天真实备餐任务走，拍什么取决于当天真的在做什么。

## 🔄 备选打法

### 备选一：36计·第7计 一句话设定故事感

- **什么情况下切过去：**  
  连续测3—5条地域差异内容后，前3秒不差，但评论区很少出现南乐本地做法讨论；反而“下午四点”“备晚饭”这类时间场景更容易被看完，就切到这计。

- **为什么你能拍：**  
  每天下午4点出摊是固定真实事件，厨师本人、工作台、食材和锅边都现成，不需要额外人物或剧情。

- **怎么套到这个号：**  
  **下午四点的普通动作 + 今晚要赶上的晚饭任务 → 过程 → 完成。**  
  例如：下午四点先处理一盆当天的串串食材，因为晚饭点前要完成备料。

- **配哪个四大脚本结构：**  
  **讲故事型·职业经历结构。**  
  补的是人设：让观众记住“做川菜9年、来到南乐半年、每天四点开始忙”的这个人。

---

### 备选二：36计·第36计 冷知识

- **什么情况下切过去：**  
  厨师能把某个真实操作讲明白，且镜头能拍出证据；例如一个处理、火候判断或下锅顺序，观众看完能复述“原来这一步是为了这个”。

- **为什么你能拍：**  
  厨师做川菜9年，串串火锅、川味烧烤、川菜三个品类每天都有实际操作；只取真实发生的一步，不需要虚构知识。

- **怎么套到这个号：**  
  **反常识结论 → 现场动作证明 → 说清原因 → 问观众家里怎么做。**  
  例如：“这口不是起锅时才有味道，下午四点这一步就已经定下来了。”

- **配哪个四大脚本结构：**  
  **教知识型·拆解结构。**  
  补的是信息密度，让过程不只是洗菜、穿串、开火的流水账。

- **边界：**  
  只讲厨师能现场证明的内容，不讲健康功效，不用“所有人都”“一定要”这种绝对说法。

---

### 备选三：36计·第10计 情境还原

- **什么情况下切过去：**  
  评论区和线下开始出现“几个人怎么点”“怕辣怎么选”“串串、烧烤、川菜怎么搭”的明确问题，并且真实菜单已确认。

- **为什么你能拍：**  
  店里本身卖川味串串火锅、川味烧烤、川菜，厨师本人能站在真实菜单前回答新客问题；不需要找顾客扮演，只用厨师自问自答还原常见问题。

- **怎么套到这个号：**  
  **第一次来的新客困惑 → 厨师先问关键问题 → 按真实菜单给路径 → 出品画面。**

- **配哪个四大脚本结构：**  
  **教知识型·解题结构。**  
  补的是变现承接：让一元火锅成为第一次尝试的入口，同时让用户知道还有烧烤和川菜可选。

- **边界：**  
  菜单、价格、辣度、营业时间未确认前，不拍具体承诺；不把第一次来的顾客说成“不会点”“乱点”，只说“第一次来常见的正常犹豫”。

## 🧪 怎么测

### 一次只改一个核心变量

首轮只测一个变量：**开篇的看点。**

- 其他不变：都在下午四点拍、都拍真实备餐、时长尽量接近、结尾都只引导评论；
- 只变化：
  1. “地域差异”开篇；
  2. “下午四点赶晚饭”开篇；
  3. “一个反常识动作”开篇。

不要这一条换食材、下一条换场景、再下一条换文案和配乐。变量全变了，就不知道观众到底在看什么。

---

### 每计测几条、看什么

| 打法 | 连续测试量 | 重点看什么 |
|---|---:|---|
| 第31计·南北/地域差异 | 5条 | 非关注播放、前3秒留存、南乐本地评论、评论是否愿意说自己的吃法 |
| 第7计·一句话设定故事感 | 3条 | 完播率、主页访问、关注转化、是否有人记住“下午四点的成都厨师” |
| 第36计·冷知识 | 3条 | 前段留存、评论提问、收藏或转述型评论 |
| 第10计·情境还原 | 3条 | 主页访问、评论里的到店问题、线下是否有人提到刷到视频 |

---

### 什么信号算“这计行”

**第31计·南北/地域差异有效：**

- 连续多条有南乐本地用户留言自己的做法；
- 评论不只是“看着香”，而是出现“我们这边会先……”“我家是这样做的”；
- 非关注播放和前3秒留存优于同周期的人设片；
- 用户开始在评论里认出“成都来的厨师”。

**什么信号算“换掉”：**

- 连续5条都只有厨师单方面讲做法，评论区没有本地互动；
- 观众频繁追问“到底做的啥”，说明开篇太虚、动作不够清楚；
- 每条都要解释很久才能讲明白，前段流失严重。

出现这些信号，不换赛道，直接切到第7计：保留下午四点和真实过程，把“地域对比”换成“今天要完成的晚饭任务”。
