# 行业建议：阿梅大码女装店起号期药方

## 1. 本阶段判断

当前账号处于**起号期**，既定目的为**大流量**，阶段目标是先让县城本地陌生人看见。

现状与目标之间，主要差在三点：

1. **还没有作品数据，无法判断哪种内容已经跑通。**  
   目前没有稳定播放、完播、评论、主页访问、私信或到店提及等数据，因此不能直接认定“试穿过程”或“情境演绎”已经是有效主力，只能先做低成本测试。

2. **账号有明确的真实资源，但本地陌生人还没有足够理由停留。**  
   门店有试衣间，且有“50码以上可试穿款”；阿梅做大码女装6年、在本地开店3年。这些是可拍事实，但如果只拍衣服挂板或报款号，陌生人不一定能立刻把内容和自己的买衣服困扰联系起来。

3. **现阶段最需要验证的，不是成交规模，而是本地用户是否产生身份确认。**  
   先观察陌生人是否评论“我也遇到过”“有没有我的码”“店在哪里”，以及是否愿意进入主页。只有本地用户开始主动询问，才说明内容已经从泛泛看衣服，走到了本地需求。

因此，当前药方不是马上加大卖货，而是：

> **用大码女生的真实买衣服场景拿流量，用真实试穿建立记忆，再观察本地用户是否开始主动问店铺和尺码。**

## 2. 本阶段重心方向

以下比例是起号期的建议分配，用户已经确定的方向优先，后续应以实际数据调整。

### 方向一：流量型情境共鸣

- **本阶段负责目的：**流量
- **建议占比：45%**
- **为什么选它：**  
  账号当前目标是让本地陌生人先看见。档案中已经明确，很多大码女生在其他店买不到合身的衣服；她们进店前常有“有没有我能穿的”“去了会不会又白跑”的顾虑。  
  这些不是单件衣服的信息，而是目标人群共同经历过的买衣服场景，更适合做陌生人停留和评论入口。
- **建议怎么拍：**  
  优先使用**第9计·一人分饰多角**或**聊观点·观点立场**。  
  每条围绕一个具体瞬间，例如：
  - 看中衣服后先问有没有大码；
  - 进试衣间前先观察尺码；
  - 参加聚会前临时找不到合身衣服；
  - 网购退回后不敢再随便买。
- **注意：**  
  重点是还原处境，不要把目标用户的身材当笑点，也不要把内容拍成对同行的评价。
- **判断方向是否有效：**  
  看评论里是否出现目标人群的自述、补充经历和本地相关提问；如果只有泛泛点赞，没有大码女生的真实回应，说明场景还不够具体。

### 方向二：《先上身，再说合不合适》

- **本阶段负责目的：**以流量为主，兼顾变现
- **建议占比：35%**
- **为什么选它：**  
  这是内容定位里已经确定的王牌栏目，也最贴合档案中的真实资源：门店有试衣间，主卖大码连衣裙、大码外套、大码裤装，并且有50码以上可试穿款。  
  对起号期来说，真实上身比挂板更容易让本地用户判断“这里是不是有我能试的衣服”。
- **建议怎么拍：**  
  每条只拍一件大码女装，并只回答一个试穿问题：
  - 连衣裙看腰腹、肩背或长度；
  - 外套看肩背、袖口或内搭空间；
  - 裤装看腰腹、臀腿、裤腿或裤长。
- **建议叠加的流量入口：**  
  开头不要先报款号，而是先说目标用户正在担心的问题，例如：
  - “大码裤子试穿，先别急着看好不好看，先看这里。”
  - “这件外套，肩背活动空间要先试出来。”
- **判断方向是否有效：**  
  看观众是否从“衣服好不好看”进一步问“有没有我的尺码”“这件适合什么情况”“店在哪里”。如果只得到单纯的款式评价，说明试穿观察点还不够清晰。

### 方向三：阿梅的职业经历

- **本阶段负责目的：**人设
- **建议占比：20%**
- **为什么选它：**  
  阿梅目前最硬的人设事实是“做大码女装6年”。这个事实可以帮助观众记住她，但真实顾客故事和具体服务动作仍待前采补充，所以本阶段不宜把人设内容做得过重。
- **建议怎么拍：**  
  以真实工作动作和职业观察为主，例如：
  - 整理试衣间；
  - 按尺码整理衣服；
  - 讲做大码女装6年后，顾客进店最常问什么；
  - 讲自己为什么长期做大码女装，但必须基于已确认的真实经历。
- **暂不建议：**  
  没有具体事件前，不要直接编写“某位顾客被感动”“某次经历改变了阿梅”等故事。
- **判断方向是否有效：**  
  看评论里是否开始有人直接称呼“阿梅”、询问店内日常，或对她的做事方式产生讨论。若观众只关注衣服，不记得出镜人，说明人设证据还不够具体。

## 3. 每类目的的结尾动作

### 流量型

- **唯一结尾动作：评论**
- **建议话术：**  
  **“你买衣服时，也遇到过这句话吗？评论区说说。”**
- **适用场景：**  
  情境共鸣、买衣服前的犹豫、进试衣间前的顾虑。
- **目的：**  
  让目标人群补充自己的经历，帮助账号继续收集本地用户的真实表达。

### 人设型

- **唯一结尾动作：关注**
- **建议话术：**  
  **“想看阿梅店里的真实日常，关注我。”**
- **适用场景：**  
  阿梅整理试衣间、讲做大码女装6年的职业观察、记录真实工作过程。
- **目的：**  
  让观众记住出镜人，而不是只记住某一件衣服。

### 变现型

- **唯一结尾动作：私信问尺码**
- **对应商业定位步骤：**  
  **“沉淀：主页和私信解决‘我能不能来’”**
- **建议话术：**  
  **“想确认自己能不能试，私信问尺码。”**
- **适用场景：**  
  《先上身，再说合不合适》中的真实试穿、尺码问题解答。
- **注意：**  
  每条变现型只保留这个动作，不同时要求评论、关注、到店和私信。

## 4. 本阶段暂停什么

### 1. 暂停只拍挂板、排货和单纯报款号

- **依据：**内容定位中已经明确，不能把账号拍成电子挂板；商业定位也指出，只拍挂板上新，解决不了顾客“有没有我的尺码、值不值得跑一趟”的顾虑。
- **调整方式：**  
  如果出现衣服画面，至少补充一个真实试穿观察点，并让镜头进入试衣间或全身镜场景。

### 2. 暂停把泛泛穿搭技巧当主线

- **依据：**内容定位已明确，不主打“显瘦技巧教学”；阿梅店真正能提供的是大码女装和线下试穿，不是泛穿搭知识。
- **调整方式：**  
  从“怎么改变身材视觉”改成“这件大码女装上身后，腰腹、肩背、臀腿或长度实际是什么状态”。

### 3. 暂停没有事实支撑的顾客故事和服务承诺

- **依据：**档案只确认了阿梅做大码女装6年、本地开店3年、店内有试衣间和50码以上可试穿款；具体顾客故事、复购原因、阿梅独有的服务动作均待确认。
- **调整方式：**  
  先拍阿梅本人、门店、衣服和试穿过程。涉及顾客时，必须基于真实发生并取得授权；没有素材，就暂时不把它写成故事。

## 5. 30天执行规则

### 规则一：每条视频前5秒先说具体场景或具体顾虑

不要从“今天给大家看一款新衣服”开始。

开头应先让目标用户听见自己的处境，例如：

- “参加聚会前，最怕试衣服时先听到一句什么？”
- “大码裤子上身，先别急着看颜色，先看腰腹这里。”
- “很多人进店前，第一句不是问款式。”

场景必须落到上班、聚会、带娃出门、换季或试衣间等具体情境，不能只说“大码女生要自信”。

### 规则二：每条只解决一个问题，只保留一个观察点

一条视频不要同时讲尺码、颜色、价格、搭配、场合和优惠。

本条拍大码裤装，就只讲腰腹或裤腿；本条拍大码外套，就只讲肩背或袖口；本条拍情境共鸣，就只还原一个买衣服瞬间。

这样便于判断：观众到底是被哪一个问题吸引，而不是把所有信息混在一起。

### 规则三：每条都要出现一个可验证的现场证据

根据内容类型选择证据：

- 流量型：出现真实试衣间、衣架、镜子或阿梅的现场动作；
- 人设型：出现阿梅正在做的具体工作，不只对镜头讲感受；
- 变现型：出现真实上身、尺码细节或阿梅指出的试穿位置。

不要用空泛结论替代证据。没有实际尺码、价格或库存依据时，用【待确认】处理，不在视频里自行补数字。

## 6. 复诊条件

### 进入下一阶段的迹象

当出现以下迹象时，可以考虑从单纯测试，进入更稳定的本地承接阶段：

- 不同选题下，陌生评论开始反复出现“店在哪里”“有没有我的码”“能不能试”等本地需求；
- 观众评论中出现与县城生活、上班、带娃、聚会相关的具体场景，而不是只评价衣服颜色；
- 观众开始主动进入主页，连续查看试穿内容，或在评论中提到看过之前的视频；
- 私信内容从泛泛询问，变成具体询问连衣裙、外套、裤装和尺码；
- 到店顾客主动提到“在抖音看到了试穿”或能说出视频里的具体衣服；
- 《先上身，再说合不合适》与流量型情境内容之间，开始出现稳定的承接关系：先评论共鸣，再进入主页看试穿。

### 换阶段后的重心调整

进入下一阶段后，可将重心从“测试哪些场景能让本地人停留”，逐步转向：

- 保留能持续带来本地评论和主页访问的流量型情境；
- 增加《先上身，再说合不合适》的稳定更新比重；
- 根据真实私信和到店问题，细分大码连衣裙、大码外套、大码裤装的试穿主题；
- 在有完整事实和授权的前提下，增加阿梅的职业经历与真实顾客过程；
- 变现内容重点从“证明店里有得试”，转向商业定位中的**“临门一脚：到店试穿，减少白跑”**。

如果只有播放或泛评论增加，但本地用户没有问店铺、尺码和试穿，暂时不换阶段，应继续调整选题场景和开头表达。
