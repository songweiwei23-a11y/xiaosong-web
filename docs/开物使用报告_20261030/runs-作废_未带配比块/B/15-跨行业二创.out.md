原片的核心机制是：先接住目标顾客最常说的一句自我否定，再用“我不急着卖货，我先做一件反常规的事”制造停留，最后把原因落回专业判断。它能跨行业借，是因为“顾客卡住→先纠正一个关键动作→再给解决方向”的结构，适合门店服务和试穿场景。

### 方案 1：先别急着说没衣服穿
**一句话**：原片“先让顾客站到镜子前看剪裁” → 你店里“先让顾客进试衣间试一试，再聊适不适合”

**借了**：开篇句式、顾客困境→反常规动作→专业解释的结构、门店口播+试穿呈现形式。  
**换成自己的**：阿梅在县城商业街门店，面对“买不到合身衣服”的大码女生，带她试大码连衣裙、大码外套或大码裤装。

#### 迁移对照
| 层 | 原片 | 你的版本 |
|---|---|---|
| 开篇 | 顾客进店先说“我穿不了” | 顾客进店先说“我在哪儿都买不到合身的” |
| 结构 | 先不推荐衣服→看剪裁→解释站不对会白买 | 先不着急拿衣服→先进试衣间试→解释合不合身要穿上才知道 |
| 呈现形式 | 店主面对镜头口播，穿插镜子前的顾客场景 | 阿梅站在试衣间外口播，穿插拿衣服、挂衣服、试衣间门口等画面 |
| 事件/主角 | 店主帮大码顾客找到适合她的剪裁 | 阿梅帮来店试穿的大码女生，先从“能不能试”走到“穿上看合不合身” |

#### 开头（前 3 秒）
**第一句话**：  
“很多大码姐妹一进店就说：‘阿梅，我在哪儿都买不到合身的。’”

**画面**：  
阿梅站在门店大码女装区域，手里拿着一件大码连衣裙，镜头快速切到试衣间门口，再切回阿梅说话。

#### 口播要点
- **顾客困境**：阿梅说，做大码女装这些年，常听到顾客还没开始挑，就先说自己“没衣服穿”。  
- **反常规动作**：今天不急着推荐哪一件，先把能试穿的款拿进试衣间。  
- **关键解释**：大码女生买衣服，不能只看挂着时显不显瘦；肩、腰、臀、裤腿这些地方，穿上活动一下才知道卡不卡。  
- **门店场景证明**：镜头拍阿梅从大码连衣裙、大码外套、大码裤装里，拿出适合试穿的款，顾客进试衣间。  
- **收束**：买衣服不是先问“我能不能穿”，而是先穿上，看它适不适合你。  
- **行动指令**：县城商业街附近想试大码女装的姐妹，来店里试穿。

#### 注意
- 原片的“镜子前看剪裁”可以借逻辑，但不要复刻其台词和镜头顺序；这里的核心动作换成“进试衣间实际试”。  
- 顾客如果不愿出镜，只拍阿梅拿衣服、衣架、试衣间门口、顾客背影或手部即可。  
- **这条不是搬运**：人物是阿梅，场景是县城商业街门店，事件是大码顾客试穿连衣裙、外套、裤装，表达和画面都围绕本店真实服务展开。

### 方案 2：别在衣架前给自己下结论
**一句话**：原片“别急着推荐衣服，先看剪裁” → 你店里“别隔着衣架说不行，先把衣服拿下来试”

**借了**：开篇冲突句式、先否定旧习惯再给新动作的结构、店主口播配实景演示的呈现形式。  
**换成自己的**：阿梅用门店里50码以上可试穿的真实条件，回应大码女生“看着就穿不了”的顾虑。

#### 迁移对照
| 层 | 原片 | 你的版本 |
|---|---|---|
| 开篇 | 顾客一进店先否定自己能不能穿 | 顾客站在衣架前，隔着衣服先判断“这件我肯定不行” |
| 结构 | 先打断“直接推荐”的常规流程→给关键判断方法 | 先打断“只看衣架”的习惯→让顾客进试衣间实际判断 |
| 呈现形式 | 镜子前的专业解释 | 衣架前拿款、试衣间前等候、阿梅口播解释 |
| 事件/主角 | 店主引导顾客看衣服是否帮到自己 | 阿梅引导大码顾客不靠目测，靠试穿判断连衣裙、外套、裤装是否合身 |

#### 开头（前 3 秒）
**第一句话**：  
“大码姐妹，别站在衣架前就给自己下结论：‘这件我肯定穿不了。’”

**画面**：  
特写：阿梅从衣架上取下一件大码女装；镜头拉远，阿梅站在试衣间前，手指向试衣间。

#### 口播要点
- **抛出常见场景**：有些顾客一看衣服挂着的样子，就觉得自己穿不了，连试都不愿试。  
- **反常规动作**：阿梅不先说“这件显瘦”“那件好看”，而是先说：拿进去试一下。  
- **解释原因**：衣服挂在衣架上是一个样，穿在人身上、走两步、抬抬手，又是另一个样。  
- **实景演示**：拍阿梅分别拿大码连衣裙、大码外套、大码裤装，字幕标注“先试，不靠猜”。  
- **情绪回收**：别让一句“我穿不了”，把你想试的衣服直接挡在试衣间门外。  
- **行动指令**：想试50码以上女装的姐妹，直接来阿梅店里试。

#### 注意
- 不要承诺“穿上就显瘦”“谁都能穿”，只说真实可验证的：店里有50码以上可试穿款。  
- 画面重点是“取衣服—递衣服—试衣间”，不需要模特、不需要复杂转场，一部手机就能拍。  
- **这条不是搬运**：原片讲“剪裁判断”，这条讲“不要隔着衣架否定自己”；产品、动作、场景和口播信息全部是阿梅门店自己的。

### 方案 3：先试裤子，别先问尺码
**一句话**：原片“先看哪种剪裁在帮你” → 你店里“先试裤装的上身感觉，再决定要不要带走”

**借了**：顾客一句典型顾虑切入、店主先不卖货而是先做判断的结构、镜子/试衣间实景口播形式。  
**换成自己的**：阿梅用大码裤装试穿过程，解决顾客担心“尺码不合、穿着不舒服”的问题。

#### 迁移对照
| 层 | 原片 | 你的版本 |
|---|---|---|
| 开篇 | 顾客说“我穿不了” | 顾客问“这条裤子有我能试的吗？” |
| 结构 | 不直接推荐→先做关键观察→说明错误判断的代价 | 不直接报尺码→先让顾客试穿活动→说明只问尺码容易买回去闲置 |
| 呈现形式 | 店主口播+镜子前演示 | 阿梅口播+拿裤装+试衣间外等待+顾客活动细节 |
| 事件/主角 | 店主帮顾客判断剪裁 | 阿梅帮顾客试大码裤装，判断腰部、臀部、走动时的舒适度 |

#### 开头（前 3 秒）
**第一句话**：  
“来买大码裤子的姐妹，别一上来只问：‘最大到多少码？’”

**画面**：  
阿梅站在裤装区域，一手拿一条大码裤装，另一手指向试衣间；首帧字幕：“先试，再问合不合身。”

#### 口播要点
- **顾客困境**：很多姐妹来店里，最关心的是有没有自己能穿的尺码，因为在别的店经常找不到合身的。  
- **反常规动作**：阿梅不会只隔着衣架报尺码，而是先拿可试穿的裤装，让顾客穿上走两步、坐一下。  
- **关键判断**：裤子合不合身，不只是能不能拉上；走路时会不会卡、坐下舒不舒服，试过才知道。  
- **门店证据**：拍阿梅整理大码裤装、带顾客去试衣间、顾客试穿后的局部动作；不拍正脸也能完成。  
- **收束金句**：尺码是参考，穿着自在才是答案。  
- **行动指令**：想试大码裤装的姐妹，来店里自己走两步、坐一下再决定。

#### 注意
- 这个方案不讲“显瘦技巧”，避免把焦点放在身材焦虑上，而是聚焦“合身、舒适、能试穿”。  
- 如果当天没有顾客配合，可由阿梅自己演示“拿裤子—指试衣间—讲判断点”，顾客试穿画面后补拍。  
- **这条不是搬运**：原片的核心是“先纠正购买前的错误判断”，这条换成“大码裤装必须实际上身活动”，产品和服务过程都来自阿梅店内。
