## 🔍 先说这一行

- **归口**：本地实体店中的 **B服装鞋包类**，主业是大码女装零售，不是泛穿搭博主。  
  原因是收入最终来自本地顾客到店试穿、购买大码女装；短视频只是把“看见合身衣服”这件事前置给顾客看。

- **这行的钱怎么赚**：  
  大码女装不是靠顾客随手买一件就结束，更依赖“试到合身以后”的连带购买和复购。连衣裙、大码外套、大码裤装都需要顾客亲身确认腰腹、臀腿、肩背等位置是否舒服。  
  获客成本卡在一个现实问题：大码女生常常已经在线上买过不合身的衣服，也逛过“尺码写得大、实际版型不对”的店，所以她不是缺衣服信息，而是缺“我去了能不能真的试到”的确定性。

- **客人的决策链路**：  
  通常不是刷到视频当天立刻买。她会先看主页有没有真实试穿、有没有和自己接近的身形、店在哪、尺码够不够，再私信问“我这个体重能穿吗”“裤子会不会卡腿”。离店近、刚好要参加聚会、换季添衣、上班需要穿得体时，决定会更快。  
  所以账号不能只拍漂亮成衣图，要持续降低“白跑一趟”的顾虑。

- **时间规律**：  
  推测换季前后、节假日前、婚礼宴请前、开学和返工前，是顾客集中找衣服的时段；下班后与周末更适合看店内试穿内容。  
  待确认：当地实际客流高峰、连衣裙/外套/裤装各自的销售旺季。

- **这行老板普遍会犯的错**：  
  常见自嗨是把新款挂满一排、配上“新款到店”，老板觉得货很多，顾客却看不出“这件跟我有什么关系”。  
  阿梅店目前已有“50码以上可试穿”这个具体优势，方向没有错；但如果视频只拍衣服、不拍试穿结果，优势会被埋掉。

- **同行现在都在拍什么**：  
  多数服装号在拍上新、挂板、转场换装、直播切片和泛泛的“显瘦穿搭”。这类内容容易同质化：要么看不出尺码范围，要么模特身形与目标顾客距离太远。  
  空档在于：把“大码女生进店时真正怕什么、试穿时具体看哪里、不同单品实际穿上是什么状态”拍清楚。不是教观众靠技巧改造自己，而是让她知道店里有能实际试的**大码女装**。

## 🗣 我会先问老板的几个问题

- **问题**：最近一次顾客试穿后没有买，原因是什么？她当时说了哪一句话？  
  - **我的推测**：她可能不是单纯嫌贵，而是担心某个位置不舒服、版型不适合，或觉得“穿出去不像自己”。这是大码女装决策里最常见的临门顾虑。  
  - 待老板确认。

- **问题**：最近一次顾客不满意，你怎么处理的？当时说了什么、做了什么？  
  - **我的推测**：真实处理过程比“服务好”更能建立信任。比如顾客对尺码、颜色或版型犹豫时，阿梅实际会如何建议，才是可拍内容。  
  - 待老板确认。

- **问题**：哪位老客回来买过？她初次进店为什么来，后来为什么还来？  
  - **我的推测**：老客复购的原因，可能不是“款多”，而是她记得这里能试到合身尺码、不必反复网购退换。  
  - 待老板确认。

- **问题**：顾客进门最常问哪一句？你通常怎么回答？  
  - **我的推测**：高频可能是“我这个身材有能穿的吗”“50码以上有吗”“裤子会不会勒肚子”。这些原话能直接变成视频开头。  
  - 待老板确认。

- **问题**：顾客为什么选这里，不去别家？请给我一句她的原话。  
  - **我的推测**：真正的差异化不是老板认为“款式好”，而是顾客感受到“我不用在试衣间里因为穿不上而尴尬”。这需要顾客原话验证。  
  - 待老板确认。

- **问题**：阿梅亲手做的哪一步，店员不一定能替代？  
  - **我的推测**：可能是根据顾客试穿状态判断版型、帮她拿相邻尺码，或记得老客以前穿过的版型；但不能把它写成事实，必须先确认具体事件。  
  - 待老板确认。

## 一句话定位

**县城阿梅，替大码女生找到能到店试穿的大码女装。**

这句话的立场是：不空讲“显瘦秘籍”，而是替本地大码女生解决“进店有没有合身衣服可试”的现实问题；阿梅做了6年大码女装，门店有50码以上可试穿款，这件事有事实支撑。

## 六维地基

### 1. 人设定位

- **原料在哪**：  
  可用的真实材料是：“店主阿梅本人出镜”“做大码女装6年”“本地开店3年”“很多大码女生在别的店买不到合身的衣服”“50码以上可试穿”。  
  “专业、懂大码、服务好”这类词不能直接当人设，因为谁都能说，观众也无法验证。  
  把“懂大码”翻译成可拍行为，应是：顾客进店试穿时，阿梅根据衣服实际版型、顾客试穿状态给出具体建议。具体怎么做，待前采确认。

- **人设标签句**：  
  **做了6年大码女装的阿梅。**

- **用了哪个入口**：  
  **特殊经历 + 痛点职业。**  
  她不是泛服装店老板，而是连续做大码女装6年的人；对应的是真实痛点——不少顾客在别处难找到合身尺码。

- **验证**：  
  这个人设立得住，因为“做大码女装6年”可持续讲细节：日常到货、挂货、顾客试穿、尺码咨询、不同单品的版型差异。  
  但“阿梅很会搭配”“阿梅特别会劝顾客买衣服”目前没有事实，不能立成标签。后续必须从真实接待事件里找可验证的行为。

- **在同类账号里的位置**：  
  同行常见人设是“身材很好、穿什么都好看的女店主”或“每天播上新”的销售型老板。  
  阿梅不适合硬走这条。她的差异是：**站在大码女生实际试穿需求一边，拍真实的尺码与版型问题。**  
  这不是靠夸张情绪取胜，而是靠“顾客终于有衣服可试”的确定感建立信任。

- **证据链**：  
  1. 真实试穿过程：一条只拍一种大码女装。  
  2. 顾客常问问题：用真实高频提问做开头。  
  3. 到货与整理过程：展示阿梅如何按尺码、版型准备试穿。  
  4. 真实老客故事：仅在征得顾客同意、事实完整时拍。

- **边界**：  
  不说“穿上立刻瘦X斤”“谁穿都显瘦”“包你满意”之类无法证实的话。  
  不把顾客的身材当笑点，不评价“胖瘦好坏”，不拿同行做反面角色。  
  不虚构顾客故事、成交记录或试穿反应。

### 2. 用户定位

- **一句话画像**：  
  **住在县城、下班后或周末想买件能穿出门的衣服，却在线上退过货、在别家店找不到合身尺码的宝妈或上班族。**

- **主攻谁**：  
  主攻两类：  
  1. **精致妈妈**：接送孩子、聚会、节日见亲友时，希望穿得体面，也不想为了买衣服跑很多店。  
  2. **新锐白领**：上班、同事聚餐、参加活动时需要一套不局促的衣服，更在意试穿效率与是否适合日常。  
  她们与“50码以上可试穿”的卖点连接最直接，购买场景也高频。

- **为什么不是另一批**：  
  不主攻只追求低价、只想线上比价且不愿到店试穿的人；也不主攻只看潮流噱头、不关心尺码体验的泛穿搭用户。  
  因为店的核心优势是线下试穿，不是靠全网最低价竞争。  
  同时不接“希望看一条视频就解决所有身材焦虑”的预期，衣服需要实际试穿确认。

- **她们心里真正在想什么**：  
  “我不是不想穿得好看，我是怕进店又没有我的码，试半天还尴尬。”  
  这句话比“我想显瘦”更接近她们到店前的心理门槛。

- **决策链路**：  
  刷到“这说的不就是我”→翻主页确认有真实试穿→看店铺位置与尺码信息→私信问自己情况能否试→抽时间到店→试穿后决定。  
  她会潜水观察，不会只凭一条视频就来，因此主页需要连续积累试穿证据。

- **什么时刻会想起阿梅**：  
  换季整理衣柜时；准备参加婚礼、聚餐、节日见亲友时；网购衣服退货后；上班发现原有裤装、外套穿着不舒服时。

- **她在平台上会搜什么**：  
  “县城大码女装”“附近大码女装店”“50码女装”“大码连衣裙试穿”“大码裤子哪里买”“大码外套试穿”。

### 3. 内容定位

- **长期提供什么价值**：  
  **让本地大码女生少跑冤枉路，先看清再到店试。**

- **内容方向**：  
  选择 **多元四类打底 + 一个试穿栏目做王牌**。  
  原因：目前没有足够事实支撑单一剧情主题长期更新；但店内真实发生的试穿、上新、尺码咨询可以稳定产出。  
  不直接做纯单一主题，是因为若只有“每天试一套”，很快会变成流水账；必须加入顾客问题、真实场景和阿梅的职业经历。

- **王牌栏目**：  
  **《这件大码女装，试穿前先看这里》**  
  单集只讲一件：大码连衣裙、大码外套或大码裤装轮流拍。看点是衣服本身换了以后，同一个人穿着状态的具体变化，不靠同一件衣服换动作制造差别。

- **当前阶段配比**：  

  **作用配比：流量型60% / 人设型15% / 变现型25%。**  
  - 流量型占60%：账号处于0—1000粉起号期，先让本地陌生人停下来；内容要围绕大码女生真实处境，加入人群、反差、成本等爆款元素。  
  - 人设型占15%：阿梅的人设目前只有“做了6年大码女装”的硬事实，先少量出现，用真实经历慢慢补证据，不能一上来编很多故事。  
  - 变现型占25%：从起号初期就要拍，但不能把主页拍成电子货架。核心是不断证明“50码以上可试穿”不是一句口号。

  **每块用什么形式做：**  
  - 流量型：以短口播、情境还原、一人分饰多角为主，讲大码女生在买衣服时的高频处境；让观众获得身份确认或情绪共鸣。  
  - 人设型：以真实职业故事、轻观点为主，讲阿梅做大码女装6年见到的真实变化；必须由具体事件支撑。  
  - 变现型：以试穿过程、对比展示、顾客问题解答为主；拍清大码连衣裙、大码外套、大码裤装各自的可试穿事实与版型差异。

  **题材配比：主赛道75% / 目标人群兴趣25%。**  
  - 75%围绕大码女装、试穿、尺码、进店场景。  
  - 25%围绕目标人群在意的上班、见亲友、带娃出门、参加聚会等穿衣场景。  
  原因是只讲衣服容易窄，加入生活场景才能让她觉得“这件事和我有关”。

- **主力形式**：  
  档案未提供“数据最好的内容类型”，因此目前不存在被数据验证过的主力形式。  
  起步先把**试穿过程视频**作为测试主力：它最贴合店内真实资源，也最能证明“50码以上可试穿”。连续测试X条后，再根据本地播放、主页访问、私信询问和到店提及判断是否保留为主力。

- **每类内容管哪一段路**：  
  - **刷到**：流量型用大码女生都懂的场景，让陌生人停下。  
  - **记住**：人设型让观众知道阿梅不是泛卖衣服，而是做了6年大码女装的人。  
  - **信**：变现型通过实际试穿、尺码咨询和门店场景，让观众确认店里真的能试。  
  - **联系**：变现型视频只引导一个动作——私信问尺码，或直接到店试穿。

- **三种视频各怎么拍**：

  **流量型**  
  - 四大脚本：**聊观点·观点立场**。方向是“大码女生买衣服，不是挑不到喜欢的，是常常没有机会试到合身的”；用阿梅做店6年的真实观察举例。结尾只留：**“你也遇到过吗？评论区说说。”**  
  - 起号36计：**第9计·一人分饰多角**：阿梅分别演“拿着喜欢的衣服却问有没有码的顾客”和“习惯回答没有的店员”，最后切回阿梅说“所以店里专门留了50码以上可试穿款”。这条只拍处境共鸣，不报价格、不引导到店。

  **人设型**  
  - 四大脚本：**讲故事·个人成就型**。方向是“阿梅为什么做大码女装6年”；必须补齐真实的阻碍、转机和具体事件后再拍。结尾只留：**“想看阿梅店里日常，关注我。”**  
  - 起号36计：**第7计·一句话设定故事感**：阿梅整理试衣间，字幕是“今天又有人问：我这个码，真的能试吗？”再跟着真实发生的店内过程走。不能摆拍成顾客真实到店。

  **变现型**  
  - 四大脚本：**晒过程·火车节模型**。方向是“一位顾客来找能穿去聚会的大码连衣裙”；起因是需求，过程拍试穿与观察点，结果只呈现顾客实际确认的状态。结尾只留：**“想试尺码，私信我。”**  
  - 起号36计：**第19计·对比改造**：同一位出镜人、同一间试衣间，先试一件常见但不适合她需求的衣服，再试店内对应的大码连衣裙/大码外套/大码裤装；讲清差别来自衣服版型和尺码，不归功于换姿势或搭配技巧。

- **配比核验**：  
  1. **流量型是否匹配起号阶段：是。** 60%是最大块，先跑陌生人播放。  
  2. **主力形式是否为数据最好的类型：待验证。** 档案没有历史数据，先用试穿过程做低成本测试。  
  3. **用户需要大流量时，流量内容是否为主力：是。** 每条流量内容都以大码女生处境、身份确认或反差为出发点。  
  4. **是否留出目标人群兴趣题材：是。** 25%内容落在上班、聚会、带娃、换季等生活场景。  
  5. **每个比例能否说明原因：是。** 起号期先获取本地曝光，再用试穿内容承接信任与咨询。

- **第一条该发什么**：  
  **题目：《大码女生进服装店，最怕听到的不是“没新款”》**  
  - 目的：**流量型**。  
  - 形式：**起号36计·第9计 一人分饰多角**。  
  - 事件：阿梅一人演两句真实场景——“这件有大码吗？”“这个版型没有合适的。”随后切到店内50码以上衣架与试衣间门口，不报款、不讲价格、不推销。  
  - 结尾：**“你买衣服时，也问过这句话吗？”**  
  - 为什么先拍它：它不要求顾客出镜、不需要虚构成交，单人手机在店内就能完成；并且能让本地大码女生迅速确认“这个号在说我”。

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：短口播+试穿过程Vlog。阿梅在衣架、试衣间、镜子前讲，画面同步给到衣服细节和试穿状态，比坐着空讲更可信。  
- **产能**：待确认团队与时间，暂不承诺周更数量；若仅阿梅一人出镜，应先以一次集中拍摄、多条拆分的方式测试。  
- **在哪拍**：县城商业街门店内，重点固定在大码衣架区、试衣间门口、全身镜前；这些场景直接证明“有店、能试穿”。

### 5. 风格调性（只给结论，≤200字）

- **正向匹配**：选正向匹配。阿梅是实体店老板，画面就该在真实门店里，朴实、清楚、能看清衣服。  
- **气质关键词**：直接、松弛、体面。  
- **会说的一句话**：**“别急着看吊牌，先上身试试这里。”**  
- **不会说的一句话**：**“这件谁穿都显瘦，闭眼入。”**  
原因：前者在解决试穿问题，后者无法被验证，也容易制造不切实际期待。

### 6. 变现定位（只给结论，≤250字）

- **卖什么 + 客单价区间**：大码女装，包括大码连衣裙、大码外套、大码裤装；客单价区间**待确认**。  
- **成交路径**：抖音内容种草 → 私信问尺码/款式 → 到店试穿 → 购买 → 老客复购。  
- **最缺的信任证据是什么**：不同身形顾客能否在店内实际试到合身衣服的连续证据。
