# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

大码女装店卖的不是“挂在衣架上的衣服”，而是顾客**不用反复网购退货、进店也不用担心没有尺码可试**的确定性。

这门生意的成交有两个特点：

1. **单次客单由场景带动，复购靠“记住版型”**
   - 顾客不会每天买衣服，但一旦在店里试到某条裤装不勒腰腹、某件外套肩背活动舒服，后续换季、聚会、上班、走亲戚时会优先想起这家店。
   - 大码女装的复购，不只是因为“款式更新”，更因为顾客知道自己来这里不容易白跑。这也是线下店比纯线上更有机会建立关系的地方。

2. **获客成本卡在“到店前的不确定”**
   - 顾客在抖音看到一件衣服，不会马上出门；她会先判断：有没有我的尺码、上身会不会卡、店在哪、值不值得专门跑一趟。
   - 所以视频必须持续给“可试穿”的证据。只拍挂板上新，解决不了她最在意的问题；只讲显瘦技巧，顾客学完也未必需要来店里。

3. **决策链路属于中等决策，不是随手下单**
   - 连衣裙、外套、裤装都涉及腰腹、臀腿、肩背、袖口、长度等实际穿着感受。顾客大多会先刷视频、翻主页、私信问尺码，再找时间到店。
   - 这意味着账号的任务不是追求每条视频都直接成交，而是让顾客在需要买衣服时，先想到“去阿梅店里能试”。

4. **销售节奏通常跟换季和生活节点走**
   - 我推测：换季、返工前、节假日前、参加婚礼聚会前、孩子开学和家长会前，会更容易出现集中试衣需求。
   - 待确认：当地连衣裙、大码外套、大码裤装各自的实际销售高峰，以及顾客最常到店的时间段。这个要从收银记录、顾客聊天记录和阿梅本人经验里核实，不能凭感觉定。

5. **同行最常犯的错，是把“货多”当成“顾客有选择”**
   - 一排衣服加一句“新款到店”，顾客只会看到款式，不会知道哪件和自己有关。
   - 大码女装客户更需要看到：这件衣服哪里有空间、哪里要重点试、什么场景适合穿。不是把身材焦虑放大，而是让她判断值不值得来试。

**一句话定位：**  
**县城阿梅，替大码女生试到合身的大码女装。**

理由：身份是“县城阿梅”，特点是“做大码女装的人”，价值不是泛泛卖衣服，而是帮本地顾客先解决“能不能试到合身款”这件具体事。

## 主推产品

### 主推：**大码裤装试穿**

不是因为裤装一定最贵，而是因为它最能体现门店“50码以上可试穿”的价值。

原因有三点：

1. **顾客痛点最具体。**  
   连衣裙可以靠宽松版型覆盖一部分尺码差异，但裤装容易卡在腰腹、臀腿、裤长。顾客会有明确问题，视频也更容易拍出“为什么要到店试”。

2. **更适合做连续内容。**  
   同一个试衣间、同一个镜子前，可以持续拍不同裤型、不同腰腹空间、不同裤腿状态。每条只讲一个观察点，不会沦为“今天又上一条裤子”。

3. **更容易带动连带购买。**  
   顾客为了裤装进店，往往还会顺带试上衣、外套或连衣裙；但是否存在真实连带购买，仍需看店内数据确认，不能先写成既成事实。

### 明确不做什么

- **不把低价清仓当账号主线。**  
  原因：没有价格优势和库存数据支撑，长期拍低价容易吸来只比价、不愿到店试穿的人，反而稀释“可试穿”的核心价值。

- **不主打“显瘦技巧教学”。**  
  原因：技巧不是店里真正卖的东西；内容重心应该是不同大码女装本身的版型、尺码和试穿状态。

- **不在起号期做复杂多人剧情。**  
  目前确认资源只有阿梅本人、门店、试衣间和衣服。一人一机能拍清楚试穿，就不要为了热闹硬加顾客演员。

## 成交路径

### 1. 第一次接触：刷到大码女生的真实处境

**她看到什么：**  
例如“买裤子时，最怕的不是不好看，是拉到一半拉链卡住”“进服装店前先问一句：有我能试的吗？”

**目的：**让她停下来，产生身份确认。  
**内容类型：**流量型。  
**会流失谁：**不属于大码女装需求的人、纯看潮流穿搭的人。  
**为什么会流失：**内容本来就不是讨好所有人，而是让本地真正有试穿需求的人认出自己。

### 2. 产生兴趣：确认店里是不是“真的有得试”

**她继续看什么：**  
- 试衣间门口的尺码准备；
- 镜子前的真实试穿；
- 阿梅指着腰腹、肩背、裤腿说具体观察点；
- 连衣裙、大码外套、大码裤装轮流出现。

**目的：**从“这说的是我”变成“这店可能值得去”。  
**会流失谁：**只想线上比价、只看折扣、不愿到店的人。  
**为什么会流失：**门店最强的能力是线下试穿，不能为了留住所有人而改成纯价格竞争。

### 3. 沉淀：主页和私信解决“我能不能来”

**主页必须承接的内容：**
1. 阿梅是谁、店在哪、卖什么；
2. 50码以上可试穿款的事实；
3. 连衣裙、外套、裤装各有真实试穿视频；
4. 高频问题，如“来之前怎么问尺码”“到店怎么试更省时间”。

**私信承接方式：**  
顾客先发自己的需求，不要求她一开始讲复杂信息。阿梅可先问：“你这次主要想找裤装、外套还是连衣裙？”再根据真实库存回复是否建议到店试。

**会流失谁：**需求不明确、距离太远、只想要线上发货但门店暂不提供的用户。  
**为什么会流失：**这是正常筛选。不要为了回复量好看，承诺自己做不到的服务。

### 4. 临门一脚：到店试穿，减少“白跑”

**真正推动成交的不是一句促销话术，而是：**
- 顾客到店能看到和视频一致的试穿场景；
- 有对应尺码或相邻尺码可拿；
- 阿梅能根据上身情况建议继续试哪一件；
- 顾客能在镜子前自己确认舒适度和出门场景。

**成交理由：**  
**50码以上有可试穿款。**

**会流失谁：**门店没有适合其身形、风格或预算的顾客。  
**为什么会流失：**不能为了成交硬推。一次不合适但如实说清，比顾客买回去不愿再来更有价值。

## 信任证据清单

| 可拍证据 | 证明什么 | 怎么拍 | 目前状态 |
|---|---|---|---|
| 试衣间门口与全身镜 | 真实、有线下试穿条件 | 从阿梅拿衣服到顾客试衣区域的固定动线拍起 | 已具备 |
| 50码以上衣架或吊牌细节 | 可试穿尺码范围 | 镜头扫过具体尺码，再进入试穿环节 | 已具备 |
| 同一出镜人先后试两条不同裤装 | 产品版型差异 | 人、镜子、场景不变，只换裤装 | 可执行 |
| 阿梅指出腰腹、臀腿、肩背等位置 | 真实试穿观察 | 不说空泛“显瘦”，只讲镜头看得见的位置 | 已具备基础条件 |
| 顾客进门高频提问 | 懂用户真实顾虑 | 用顾客原话做字幕或阿梅复述，先征得同意 | 待确认原话 |
| 顾客试穿后最终选择过程 | 结果与服务 | 不强拍顾客脸，可只拍衣服、手部、镜前局部 | 待顾客授权 |
| 老客再次到店的原因 | 复购与信任 | 讲完整真实过程：第一次为什么来、后来为什么回来 | 待前采确认 |
| 阿梅处理一次尺码犹豫的过程 | 专业判断与边界 | 真实记录，不摆拍，不把顾客当案例道具 | 待积累 |

### 证据怎么攒

- 每次顾客试穿，如果对方愿意，拍一段不露脸的“拿衣服—进试衣间—镜前确认”素材；
- 每天记录顾客问得最多的一句话；
- 阿梅用手机备忘录写下“今天哪条裤子为什么没卖掉”，这类未成交原因比硬夸产品更有价值；
- 老客故事必须先问清楚事实和授权，不能把普通复购编成感人故事。

### 变现型内容占比：**25%**

理由：账号在起号期，流量型仍要占大头，不能一打开主页全是卖货视


## 输出要求

行业建议只管「这个阶段怎么打」，不重复定位。账号是谁（账号定位）、长期拍什么（内容定位）、靠什么成交（商业定位）已经定好，这里只引用它们的原名。按下面的结构输出 Markdown，每一节都落到这个账号和这个阶段上：

1. **本阶段判断**：这个阶段和目的下，现状和目标之间差在哪里，依据是档案和作品数据。数据不够就直说不够。
2. **本阶段重心方向**：给 2–3 个建议方向，优先引用内容定位里已有的系列原名。每个写清：这一阶段它负责哪个目的（流量、人设、变现）、占本阶段的比例、为什么选它（对准哪个真实需求，依据档案的哪条事实）。这是建议，用户自己选定的方向优先。
3. **每类目的的结尾动作**：流量、人设、变现各一个结尾动作，每类只留一个。变现型的动作要对应商业定位里的哪一步，写出原步骤名。
4. **本阶段暂停什么**：2–3 条，每条写依据（禁忌、档案，或内容定位里的排除项）。
5. **30 天执行规则**：3 条，只约束选题和脚本怎么做（例如「每条都要在前 5 秒说出位置」），不重述定位。
6. **复诊条件**：出现哪些迹象就该换阶段，换的时候重心怎么变。只写可以观察的迹象（例如「连续几条都有陌生人在评论区问地址」），用这个号自己过去的数据比；**不写任何具体数字**（播放量、新客人数、连续条数都不写）。

## 硬约束

- 药方是建议，不是命令。用户选定的方向优先：用户的方向不在内容定位里，就照用户的方向给建议，并说明它和内容定位、本阶段重心的差距，不阻止、不改写。
- 不替用户新增或改写内容定位。如果本阶段反复需要内容定位里没有的方向，只写「建议把它加进内容定位」，由用户决定。
- 拍小票、结账、价格画面时，金额一律用【待确认】或「金额打码」，档案里没有的数字不写。
- 不重述账号定位（这个号是谁、说给谁、凭什么信）、内容定位（长期拍什么）、商业定位（靠什么赚钱）的内容，只引用原名。
- 内容定位已有，第 2 节优先引用它的原系列名。
- 商业定位已有，第 3 节的变现动作写出原步骤名。
- 不编造任何数字、案例、客户故事、效果承诺。缺的事实用【待确认】标出
- 价格、价位、人均、营业时间、地址、作息、门店活动，只有档案或素材里写了才能用。档案里没有的，写成「价格摆在明面」这类做法即可，具体数字用【待确认】占位，不要替它定价
- 阈值类数字（完播率、播放量、咨询人数、转化率）一律不给具体合格线，例如「完播低于 X% 就换」。改成和这个号自己过去的数据比较；没有历史数据就写「待建立」
- 档案里写着「未填」「待补充」或留空的项，不当作事实使用，也不凭行业印象补成具体值；推断出来的内容要标明是推断
- 与账号档案的事实冲突时以档案为准
- 禁忌里写的不能说、不能拍，方案里一律不出现
- 不输出寒暄和过程说明，只输出方案正文
