# 🚀 起号方案

## 📌 先说结论

- **建议主攻：36计·第9计 一人分饰多角。**  
  阿梅用一个人演“大码女生的顾虑”和“阿梅的回答”，固定拍在店里的衣架、试衣间、全身镜前。它最贴合王牌流量系列《大码女生进店前，先替你问一句》：不需要真实顾客出镜，不需要搭档，不需要编故事，靠大码女生真实会犹豫的那一句话拿共鸣和评论。

- **备选：**
  1. **36计·第29计 吐槽奇葩现象**：当一人分饰多角的角色感太重、完播偏低时切换，用阿梅本人直说“吊牌大码但不敢试”这类现象。
  2. **36计·第10计 情境还原**：当评论和私信开始集中问“裤子会不会卡腿”“外套肩背紧不紧”时切换，承接到《先上身，再说合不合适》。
  3. **36计·第7计 一句话设定故事感**：前采补到阿梅做大码女装6年里的具体真实事件后启用，补人设内容。

- **明确不做：**
  1. **第35计 街头采访**：需要陌生人配合、现场收音和授权，县城商业街拍摄不稳定；阿梅单人执行时，内容质量撑不住。
  2. **第16计 整蛊**：大码女生买衣服本来就容易有尺码焦虑，用误导和玩笑做看点，容易伤害目标顾客的感受，也偏离账号“先看清、少白跑”的定位。

- **多久能看出跑没跑通：**  
  先连续发布一批围绕第9计的内容，再按单变量复盘。**零粉到一千粉、作品流量逐渐稳定**是起号阶段的参考线；同时要看本地用户评论、主页访问、尺码咨询，不能只看单条播放。

## 🧮 起号期内容配比

### 到一千粉、流量稳定之前

| 内容目的 | 占比 | 核心任务 |
|---|---:|---|
| 流量型 | 60% | 先让县城大码女生刷到后产生“这说的就是我”的感觉 |
| 人设型 | 15% | 让人知道阿梅做大码女装6年，不是临时上款的账号 |
| 变现型 | 25% | 持续证明“50码以上有可试穿款”，承接尺码咨询 |

这套比例和已定定位一致：**流量靠《大码女生进店前，先替你问一句》打开，变现靠《先上身，再说合不合适》承接。**

### 每一种怎么拍

#### 1. 流量型：主打第9计·一人分饰多角

- **出发点：**
  - 人：25—40岁、买衣服时总先担心“有没有我能穿的”的大码女生；
  - 场：县城商业街服装店、衣架、试衣间、全身镜；
  - 三有：有共鸣；
  - 爆款元素：**人群、反差**。
- **形式：**  
  **36计·第9计 一人分饰多角 + 聊观点·观点立场。**
- **脚本结构：**  
  顾客角色说出一句顾虑 → 阿梅角色回应 → 回到真实门店画面，说一句职业观察 → 评论。
- **结尾行动指令：**  
  **“你也遇到过吗？评论区说说。”**
- **边界：**  
  不报价格、不讲具体卖点、不引导私信或到店。衣服、衣架、试衣间只作为真实场景存在。

#### 2. 人设型：先用阿梅真实职业经历立住人

- **出发点：**
  - 人：阿梅本人；
  - 已确认的真实材料：做大码女装6年、本地开店3年；
  - 要让观众记住的点：她长期在看大码女生买衣服时的真实顾虑。
- **形式：**  
  **聊观点·观点立场。**
- **脚本结构：**  
  阿梅做大码女装6年的真实观察 → 明确判断 → 解释为什么这么看 → 关注。
- **结尾行动指令：**  
  **“想看阿梅店里的真实日常，关注我。”**
- **边界：**  
  不编顾客故事，不把常见场景说成某个顾客真实经历。  
  待确认后再拍故事：**阿梅做大码女装6年里，哪一件具体小事让她印象最深？当时发生了什么？**

#### 3. 变现型：固定证明“50码以上可试穿”

- **出发点：**
  - 人：怕白跑、怕网购不合适的本地大码女生；
  - 货：大码连衣裙、大码外套、大码裤装；
  - 场：店内试衣间、全身镜；
  - 成交理由：**50码以上有可试穿款。**
- **形式：**  
  **晒过程·火车节模型 + 36计·第10计 情境还原。**
- **脚本结构：**  
  常见需求钩子 → 拿一件真实货品 → 试穿时看一个位置 → 正常动作验证 → 镜前结果。
- **结尾行动指令：**  
  **“想试尺码，私信阿梅。”**
- **边界：**  
  不把同一件衣服换穿法当作对比。要拍反差时，同一个人、同一面镜子、同一组动作，只换店内两件不同版型的真实货品。

### 过线之后怎么调

当账号达到“接近一千粉、流量稳定”，且评论和私信持续出现“店在哪”“有我码吗”“能不能试”的本地需求时，调整为：

| 内容目的 | 占比 | 调整原因 |
|---|---:|---|
| 流量型 | 50% | 保持新客进入 |
| 人设型 | 15% | 持续建立阿梅本人信任 |
| 变现型 | 35% | 增加真实试穿、尺码咨询、不同场景选款内容 |

主力形式不变：  
- 流量继续围绕**第9计·一人分饰多角**；  
- 变现继续围绕**晒过程·火车节模型**；  
- 王牌栏目继续做**《先上身，再说合不合适》**。

## 🎯 主攻打法：36计·第9计 一人分饰多角

### 为什么是阿梅能拍的

1. **只用阿梅一个人出镜。**  
   不调用店员、顾客、家人，也不需要找人配合演戏。

2. **门店本身就是现成场景。**  
   衣架、试衣间、全身镜，正好对应大码女生买衣服最熟悉的现场。

3. **阿梅有真实职业观察。**  
   做大码女装6年，能围绕“很多大码女生在别的店买不到合身衣服”说出真实处境，不需要编段子。

4. **拍摄执行简单。**  
   一机固定机位，两次录制：第一次演“顾客”，第二次演“阿梅”。剪辑时左右切换或前后切换即可。  
   开拍前必须确认：**手机、固定支架、收音条件。** 这三项没有确认前，不排复杂走位。

### 结构公式

**角色A的顾虑 ↔ 阿梅的回答 → 回到真实门店的一句职业判断 → 评论互动**

套到阿梅账号：

> “这件我挺喜欢的，但有我能试的吗？”  
> “先别急着问喜不喜欢，很多人连拿进试衣间都要犹豫。”  
> 镜头切回试衣间门口：  
> “大码女生买衣服，很多时候不是挑款，是先确认自己能不能试。”  
> **“你也遇到过吗？评论区说说。”**

### 配什么脚本讲

**第9计·一人分饰多角 + 聊观点·观点立场。**

- **第9计负责事件：** 把“买衣服前不敢问”的瞬间演出来，让观众先停下。
- **观点立场负责收束：** 用阿梅做大码女装6年的职业观察，给观众一句能说出心里话的判断。
- **它补上的内容：** 补的是共鸣和人物可信度，不补成交理由。流量型不把“50码以上可试”讲成卖点。

### 前3条具体拍什么

#### 第1条  
**标题：**《每次看中一件衣服，我都得先问这一句》（人群）

- **第一句：**“这件挺好看的，但有我能试的吗？”
- **怎么拍：**
  1. 阿梅站在衣架前，演“顾客角色”，手停在一件衣服前；
  2. 切到阿梅站在试衣间门口，演“店主角色”；
  3. 最后回到真实镜头，拍试衣间门和全身镜。
- **停留点：** 目标用户对这句问话太熟悉，前三秒就能完成身份确认。
- **结尾：**“你也遇到过吗？评论区说说。”

#### 第2条  
**标题：**《吊牌写着大码，我为什么还是不敢拿去试？》（反差）

- **第一句：**“明明写着大码，我还是会先把它挂回去。”
- **怎么拍：**
  1. 顾客角色拿起衣服，看吊牌；
  2. 停顿后又把衣服挂回衣架；
  3. 阿梅角色说：“很多人怕的不是吊牌小，是怕进了试衣间才发现不合适。”
  4. 切试衣间门和镜子空镜。
- **停留点：** “写着大码却不敢试”的反差，能让目标用户继续看原因。
- **结尾：**“你买衣服时也会这样吗？评论区说说。”

#### 第3条  
**标题：**《参加聚会前，我不是怕没衣服，是怕没得试》（人群）

- **第一句：**“聚会前翻衣柜最难受的，不是没衣服。”
- **怎么拍：**
  1. 顾客角色站在连衣裙衣架前，拿起又放下；
  2. 阿梅角色接话：“是看中了一件，却不知道自己能不能穿。”
  3. 切到试衣间门口和全身镜，阿梅正面说一句：“很多人进店前，先替自己把答案说成了不行。”
- **停留点：** 聚会前找衣服是宝妈、上班族都懂的场景，话题不局限于服装从业者。
- **结尾：**“你参加聚会前，最怕哪一步？评论区说说。”

### 边界

- 不把演绎包装成真实顾客到店记录。
- 不拿体型做笑点，不说“胖”“丑”“穿不上就不该穿”这类话。
- 不让“店员”“同行”成为反面角色。
- 不在流量视频里报价格、讲促销、引导私信。
- 不连续拍“换衣服—照镜子—夸好看”的静态内容，变量必须是每集不同的真实顾虑。

## 🔄 备选打法（3计）

### 1. 36计·第29计 吐槽奇葩现象

- **什么情况下切过去：**  
  连续测完第9计至少5条后，评论有共鸣但前段流失明显，说明观众认可话题，却不习惯角色切换。
- **为什么阿梅能拍：**  
  阿梅本人、衣架、试衣间就能完成，不需要搭档。
- **怎么套到这个号：**  
  拍“吊牌写得大，上身位置却不一定合适”这类现象，不点名任何店、不攻击同行。
- **配的四大脚本：**  
  **聊观点·观点并列。**
- **固定结构：**  
  具体场景 → 这件事为什么让人犹豫 → 阿梅做大码女装6年的观察 → 评论。
- **示范标题：**  
  《衣服尺码写得很大，为什么我还是不敢拿去试？》

### 2. 36计·第10计 情境还原

- **什么情况下切过去：**  
  评论区开始出现具体需求，例如“裤子坐下会勒吗”“外套肩背紧不紧”“连衣裙长度够不够”。
- **为什么阿梅能拍：**  
  店内有真实货品、试衣间和全身镜；阿梅本人就能示范站立、坐下、抬手、走动等正常动作。
- **怎么套到这个号：**  
  用“常见需求”开头，不假装有顾客正在店里。  
  例如：“上班坐一天的大码裤装，试穿时先看这里。”
- **配的四大脚本：**  
  **晒过程·火车节模型。**
- **固定结构：**  
  场景需求 → 拿款 → 看一个位置 → 正常动作验证 → 镜前结果 → 私信。
- **示范标题：**  
  《上班坐一天的大码裤装，先坐下再看腰腹》

### 3. 36计·第7计 一句话设定故事感

- **什么情况下切过去：**  
  前采补到阿梅本人真实职业经历，且事件具备清楚的“发生了什么—阿梅怎么做—她为什么记住”。
- **为什么阿梅能拍：**  
  阿梅在门店整理衣架、准备试衣间、本地开店日常都是现成画面。
- **怎么套到这个号：**  
  普通工作动作，加上一句真实的职业背景。  
  例如：  
  **“做大码女装第6年，我最不想听到的一句话，还是‘我这个身材就别试了’。”**
- **配的四大脚本：**  
  **讲故事·个人成就型。**
- **前置条件：**  
  待确认：阿梅要先补一件真实发生过的具体事件，不能只靠一句感慨撑完整条视频。

## 🧪 怎么测

### 一次只改一个变量

第9计测试时，固定以下内容：

- 固定场景：衣架区、试衣间、全身镜；
- 固定结构：顾客顾虑 → 阿梅回应 → 职业判断 → 评论；
- 固定时长：同一批视频保持接近；
- 固定结尾：评论互动。

**每次只换一个变量：**

1. 顾虑内容：有没有码 / 不敢试 / 怕卡腿 / 怕肩背紧；
2. 开篇句式：疑问句 / 否定句 / 场景句；
3. 首帧画面：拿衣服停顿 / 试衣间门口 / 镜前表情。

### 每计测几条、看什么指标

| 打法 | 最少测试量 | 核心看什么 |
|---|---:|---|
| 第9计·一人分饰多角 | 5条 | 非关注播放、前段停留、评论共鸣、主页访问 |
| 第29计·吐槽奇葩现象 | 3条 | 前段停留、评论讨论、完播 |
| 第10计·情境还原 | 3条 | 私信尺码咨询、评论中的到店问题、主页访问 |
| 第7计·一句话设定故事感 | 3条 | 关注、主页访问、评论里是否有人记住阿梅本人 |

### 什么信号算“这计行”

**第9计有效：**

- 评论出现“我就是这样”“这句我每次都问”“说到我了”；
- 本地用户开始问店在哪、有没有自己的尺码；
- 同类内容连续几条都有稳定非关注播放和主页访问；
- 观众会在评论区主动补充新的顾虑，为下一条提供题材。

**什么信号算“换掉”**

- 连测5条，角色切换导致大量用户在前几秒划走；
- 评论只夸演得像，没有人讨论“大码买衣服”的真实处境；
- 播放有，但主页访问和目标用户互动持续偏弱；
- 同一句式连拍后，观众开始觉得重复。

出现这些信号，不是马上推翻“大码女生顾虑”这个方向，而是先切到第29计，把角色对话改成阿梅本人直说。

## 📊 跑不通先查哪里

| 现象 | 先怀疑什么 | 下一步实验 |
|---|---|---|
| 有曝光，但前三秒流失快 | 第一角色说得太绕；观众没立刻听懂“大码女生的顾虑” | 把开篇改成一句直接的问题，例如“有我能试的吗？”；首帧直接拍衣架前犹豫的动作 |
| 播放有，评论和主页访问少 | 内容只有情绪，没有让人认出这是阿梅和实体门店 | 每条结尾前增加一秒试衣间、镜子、衣架的真实门店画面，但不报款、不推销 |

阿梅这个号起号阶段最重要的不是急着展示多少件衣服，而是先让本地大码女生刷到时认出一句话：**“原来有人知道我买衣服时卡在哪里。”**
