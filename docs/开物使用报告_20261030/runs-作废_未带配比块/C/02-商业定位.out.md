# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

**主体判断：本地实体店，归口家居家电。** 账号的交易对象是县城里准备置家、换房的家庭，视频的任务不是把人教成木工，而是让顾客愿意带着自己的空间、预算和问题来了解家具。

这门生意通常不是靠同一户人家高频购买，而是靠一笔家具销售获得毛利；顾客是否愿意介绍别人，可能影响后续客源，但**本店是否主要依靠转介绍，待确认**。

家具的毛利不能只看“卖价减材料价”。实木家具可能涉及木料、加工、损耗、门店、运输安装和售后；布艺沙发则要核对实际采购或生产方式，以及相应的配送、售后成本。**两类商品哪类更赚钱，目前没有依据。**

我推测，这行获客容易卡在“看了但还没到购买节点”和“咨询后还要回家商量”这两步：家具要考虑空间、款式、预算和家庭成员的使用感受。顾客可能看完视频就来，也可能隔一段时间再比较；**本店实际决策周期待确认**，先问最近一笔成交从首次了解至付款隔了多久。

时间上，我推测交房、装修完工、婚期和搬家，比单纯的日历月份更接近购买节点；节假日可能有人集中看店，但不能直接认定本店旺季。先核对近期到店和成交记录。

这行容易出现一个内容偏差：**老板花很多时间介绍木料或工序，顾客却还没弄明白这件家具跟自己家有什么关系。** 本地同行账号尚未实查，不能说他们拍得如何；正式接手后要看同城家具账号的产品展示、报价和评论提问，判断哪些问题还没有被讲清楚。

**一句话定位：做家具12年的老周，带你现场看懂实木家具和布艺沙发。**

这个定位的区别不靠宣称别人做不了，而靠老周本人、门店实物和可现场看的木料共同兑现；沙发内容也必须有自己的现场展示，不能借工坊画面替代。

**接手前，我会补问这几件事：**

1. 最近一次顾客对家具不满意，具体是哪一处？顾客怎么说，老周做了什么，最后怎么处理？  
   *推测：尺寸、坐感或交付预期可能存在分歧；待老板确认。*
2. 有没有明确没接的单或没卖给顾客的货？对方原本要什么，为什么没继续？  
   *推测：可能有超出实际服务范围的需求；待确认，不能预设老周的经营边界。*
3. 最近一位再次进店的老客，第一次为什么来，后来又为什么回来？  
   *推测：可能是添家具或陪家人选购；待确认，不等于已经复购。*
4. 除了“沙发怎么挑不踩坑”，最近一位顾客还问过哪句话？老周当时指着什么、怎么答？
5. 这个月门店或工坊发生过什么小事？谁做了什么，最后怎么处理？
6. 有没有顾客亲口说过为什么选择这里？请回忆具体商品、当时场景和原话。  
   *推测：顾客可能在意现场看货，也可能在意其他事情；不能把老板认定的优势直接当成顾客理由。*
7. 老周亲手做过哪一步？最近一次是什么时候，为什么由他做？若说做法与别人不同，区别是什么？  
   *待确认；在拿到事实前，不写“别人做不了”。*

## 变现全景

目前可直接围绕在售商品做内容和咨询承接，不额外虚构定制、上门设计等服务。

| 可变现商品 | 客单价与毛利 | 决策难度及原因 |
|---|---|---|
| **实木餐桌椅** | 客单价、单笔毛利和毛利率均待确认：先核对近期成交价及对应材料、加工、配送等成本 | **相对高决策**：要核对餐厅空间、款式、材质信息和家庭需求 |
| **布艺沙发** | 客单价、单笔毛利和毛利率均待确认：先核对近期成交价、采购或生产成本及配送售后费用 | **相对高决策**：要考虑客厅空间、坐感、外观及家庭成员意见 |

**为什么不先给区间：** 没有本店成交记录、成本结构，也没有本轮市场调查；直接报数字会影响定价判断。先请老板各拿一笔近期成交，逐项核对实际售价、成本和是否包含配送安装。

## 主推产品

**不把实木家具或布艺沙发中的任何一个降为配角。** 账号整体继续两类并列、轮流展示；起步阶段如果要确定一条先拍、先测试的变现内容，我会先拍**实木餐桌椅的现场看木料过程**。

原因不是它更赚钱，而是当前已有的证据更完整：自家有木工工坊，木料可现场看，老周可以用实物解释顾客能看到什么。信任门槛较高的家具，先让观众看到实际材料，比空讲“品质”更容易判断。

**布艺沙发同步推进，不能等木料内容跑通后才开始。** 顾客常问沙发怎么挑，说明有明确问题入口；但具体款式、尺寸、面料资料及接待方式还没核实。接手时先请老周拿出一款实际在售沙发，讲清楚能确认什么，再拍对应变现内容。

**生产能力边界：** 工坊存在不等于可以随时拍到完整制作，更不等于所有在售实木家具都由工坊制作。拍摄前要确认这次展示的木料与哪件商品有关；关系说不清，就只展示材料，不暗示对应关系。

## 成交路径

现阶段承接路径：**抖音视频 → 主页继续了解 → 私信说明需求 → 到店看货 → 确认商品和交易条件 → 付款。** 这是运营设计，不是已验证的实际成交路径。

### 1. 第一次接触：视频里先看到什么

- **实木家具：** 老周面对实际木料，回答一个顾客会问的问题，例如“来店里能看到什么材料”。
- **布艺沙发：** 从已知问题“沙发怎么挑”进入，展示一款真实在售沙发，说明哪些信息可以当面核对。
- **为什么这样做：** 家具决策涉及具体商品；镜头先给问题和实物，比门店全景加口号更容易让有需求的人判断是否与自己有关。
- **会流失谁：** 暂时没有置家计划的人，或不是本地、无法到店的人。这部分流失不必靠夸大服务范围挽回。

### 2. 产生兴趣：顾客为什么继续看

让顾客看到**问题如何被回答**：木料展示到什么位置、哪些信息现场能确认；沙发款式和尺寸资料是否清楚、能否在店内试坐。

- **会流失谁：** 想立即知道完整价格、规格和交付条件，但视频没有提供的人。
- **处理：** 不必一条视频塞完所有信息；对视频涉及的商品，发布前先准备好可核实的资料，避免观众来问时答不上来。

### 3. 沉淀：主页和私信分别负责什么

- **主页：** 保留老周本人、实木家具现场展示、布艺沙发具体问题三类作品，让顾客判断这是不是自己要找的店。
- **私信：** 先问对方看的是餐桌椅还是沙发，再了解空间尺寸、大致预算和预计购买时间；商品资料和价格以核实后的实际信息回复。
- **会流失谁：** 没有尺寸、还没确定需求，或者暂时不想提供预算的人。
- **处理：** 不强迫一次问齐。先回答对方已提出的问题；没有尺寸时说明哪些信息暂时无法判断，不替顾客决定。

### 4. 临门一脚：到店后怎样走到付款

到店后让顾客看实际商品，核对尺寸、材料或面料等已知信息；有试坐条件就实际试坐。准备购买时，再确认**具体款式、价格、交付时间、配送安装范围和售后约定**，以实际订单为准。

- **会流失谁：** 到店后发现尺寸、款式、预算或交付条件不匹配的人。
- **为什么不急着催单：** 这些不匹配不是靠话术就能解决的。先问清没成交的具体原因，才能区分是商品不合适、信息不清楚，还是顾客尚未到购买节点。
- **待确认：** 店里的实际付款方式、配送范围、安装与售后约定。未确认前不在视频里承诺。

## 信任证据清单

以下是**可以拍的证据方向，不等于每项都已有素材**。所有客户现场需取得同意；没有真实记录就不摆拍冒充。

| 证据画面 | 证明什么 | 当前状态与怎么攒 |
|---|---|---|
| 老周本人在工坊，指着实际木料说明现场能看什么 | **真实、专业**：店里确有可展示的材料，老周能说明已知信息 | 已有工坊和现场看木料的事实；拍前核对木料名称及与商品的关系 |
| 实木餐桌椅的实际尺寸、结构部位和现场材料展示 | **专业、真实**：顾客看到的是具体商品，不是泛泛讲木头 | 先选实际在售商品；尺寸和材质以可核实资料为准 |
| 一款在售布艺沙发的外观、实际尺寸及可确认的面料信息 | **真实**：观众知道店内具体有什么 | **待确认资料**；先整理商品标签或其他可靠资料，不能仅凭画面判断材质 |
| 老周依据真实顾客问题，对着沙发回答“怎么挑” | **专业、服务过程**：让顾客看到他如何解释问题 | 沙发问题已由前采确认；具体回答先请老周现场讲，并核对涉及的商品信息 |
| 顾客实际看货或试坐的过程，以及对方当时关注的问题 | **服务过程** | **暂无已确认素材**；征得顾客同意后记录，不虚构顾客反馈 |
| 一笔真实订单从确认款式到交付的记录 | **结果**：证明这笔商品实际完成了哪些环节 | **暂无已确认素材**；先问最近一笔订单能否展示，隐去个人信息，不把单次结果推广为全部订单 |
| 一次真实售后沟通与处理过程 | **售后**：展示遇到问题后实际做了什么 | **暂无已确认案例**；先访谈最近一次处理经过，获得同意后再使用，不编造完美结局 |

## 变现型内容怎么排

沿用定位地基：**变现型占30%**。起号期仍让流量型占最大一块；但家具购买需要看货和建立信任，变现内容不能等账号有流量后才补。

**品类位置：实木家具、布艺沙发在变现内容中轮流出现，先按各半测试。** 这不是销售占比判断，而是目前没有咨询量、毛利或库存依据，不能偏废任何一类。作用层面仍维持流量50%、人设20%、变现30%；形式上以现场过程为暂定主力，知识和真实经历辅助。题材层面沿用主赛道80%、目标人群相关兴趣20%。

下面每个方向都只承担变现目的：先回答顾客问题，再给一个私信入口。

### 方向一：来店里能现场看什么木料？

- **对应路径：** 第一次接触 → 产生兴趣。
- **成交理由：** 木料可现场看。画面要拍到实际材料；只能说明已确认的信息，不把所有家具都说成由这批木料制作。
- **观众变化：** 从“只听名称”变成“知道到现场可以看什么、还要问什么”。
- **四大脚本·晒过程·火车节：** 顾客关心材料 → 老周带镜头看实际木料 → 指出能确认的部位和信息 → 说明对应商品是否已核实。
- **第10计·情境还原：** 先确认真实顾客曾问过的木料问题，老周在现场还原自己的回答，镜头拍到材料与解释；注明是对真实问题的讲解，不冒充正在接待。
- **结尾唯一行动：** “想了解实木家具，私信我。”

### 方向二：这张实木餐桌椅，能给家里核对哪些信息？

- **对应路径：** 产生兴趣 → 私信咨询。
- **成交理由：专业判断**——限于老周能对实际商品说明的尺寸、材料和适用条件，不把“做家具12年”扩大成无条件保证。
- **观众变化：** 知道看一套具体餐桌椅时，哪些信息需要结合自家空间确认。
- **四大脚本·教知识·解题型：** 家里准备选餐桌 → 只看图片不知尺寸是否合适 → 拿店内实物说明尺寸和需要核对的空间信息 → 提醒不同家庭按实际情况判断。
- **第26计·推荐建议：** 选择一套资料已核实的餐桌椅，先说明适合参考的空间条件，再说明哪些情况需要重新核对；不把它推荐给所有家庭。
- **结尾唯一行动：** “想了解这套餐桌椅，私信我。”

### 方向三：顾客问“布艺沙发怎么挑”，老周怎么回答？

- **对应路径：** 第一次接触 → 产生兴趣 → 私信。
- **成交理由：专业判断**——通过对实际沙发的解释建立信任；能否成立，以老周现场回答及商品资料核实结果为准。
- **观众变化：** 知道挑选不能只看外观，至少要把实际空间和试坐需求带进判断。
- **四大脚本·晒过程·过程展示：** 用前采确认过的问题开场 → 老周对着一款真实沙发讲需要核对的信息 → 展示实际尺寸和可试坐部位 → 说明哪些信息还需确认。
- **第10计·情境还原：** 按真实出现过的“沙发怎么挑”问题，老周对着实物还原回答；如果记不清某次具体接待，就直接说“客人常问”，不编人物和对话。
- **结尾唯一行动：** “想了解布艺沙发，私信我。”

### 方向四：两款布艺沙发，同一个人试坐有什么不同？

- **对应路径：** 产生兴趣 → 到店前建立对具体商品的了解。
- **成交理由：专业判断**——不是证明哪款更好，而是让顾客看到老周如何结合实际差异说明试坐时可以关注什么。
- **观众变化：** 明白不同沙发的坐感不能只靠图片判断；一次试坐结果只代表这次体验。
- **四大脚本·晒过程·测评型：** 选两款真实在售、可试坐的沙发 → 老周在同一空间、以相近坐姿依次试坐 → 记录脚部落地和靠背接触等可见差异 → 如实说出本次感受及适用限制。
- **第26计·推荐建议：** 基于两款实物和已核实资料，说明各自值得试坐的人群需求及不宜直接下判断的情况；没有明显差异就如实说，没有依据就不分优劣。
- **结尾唯一行动：** “想了解这两款沙发，私信我。”

## 定价与节奏

### 起步阶段怎么定价

**先不新造低价引流款。** 两个品类都要正常展示，不把其中一类压成只负责吸引咨询的商品。原因是目前不知道实际成本、库存、配送和售后费用，先用低价吸引人，可能让咨询预期与到店价格脱节，也无法判断是否覆盖成本。

先把每件准备拍摄的商品整理成一张内部资料卡：

- 实际款式、规格及可核实的材料信息；
- 实际售价，以及价格包含和不包含什么；
- 预计交付、配送安装和售后条件；
- 对应的采购或材料加工成本、其他必要费用。

缺一项就标待确认。顾客问到时，**能答的答，不能确认的先核实再回复**。

### 什么时候可以涨价

不按粉丝增加或某条视频播放好就涨价。只有当**实际成本变化、商品配置变化，或原价格核算发现难以覆盖成本**等情况出现时，才重新核价。

涨价前先核对：

1. 哪件商品、哪一项成本或配置发生变化；
2. 调整后的价格是否覆盖已确认成本；
3. 对已沟通或已下单顾客如何按原约定处理；
4. 新价格、包含的服务及生效时间能否向顾客说清。

## ⚠️ 风险

### 1. 只把工坊拍热闹，布艺沙发没有转化证据

**为什么会发生：** 木料和工坊更容易形成连续画面，但沙发同样在卖，顾客也确实常问怎么挑。

**处理：** 两类变现内容轮流排；先补沙发实际款式、尺寸、面料和试坐条件。若资料不足，就暂停涉及该信息的判断，不靠木工画面给沙发背书。

### 2. 私信有人问，到店和成交却接不上

**可能原因是推测，待核实：** 商品资料不全、价格或交付条件没有说清，或顾客只是提前比较，并非马上购买。

**处理：** 记录每条真实咨询来自哪类商品、问了什么、是否到店及未继续的原因；先追问最近几位未到店或未成交者的具体顾虑，不把所有流失都归咎于内容。

### 3. 把“能现场看”说成了未经核实的质量承诺

**为什么危险：** 看得到木料，不自动证明所有商品的材质、结构和使用效果；一笔真实交付也不代表所有订单都一样。

**处理：** 每条视频只说该件商品和现场能核实的信息；关联不明、资料缺失或售后规则未确认时明确说明。先核对事实，再发布。
