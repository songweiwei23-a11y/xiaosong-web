## 适用的成交理由

### 1. 有特色 · 9分

**为什么成立**：店里卖实木家具，老周自家还有木工工坊，顾客能现场看木料，不只是对着成品听介绍。

**怎么拍**：
- 老周把餐桌木料平码在工坊里，镜头从木料纹理推近到正在制作的桌腿。
- 顾客在店里摸成品餐桌，转场到工坊里看同类木料，老周指着木料说：“这张桌子，用的就是这批料。”

### 2. 实在不坑 · 8分

**为什么成立**：木料能现场看，顾客可以先看材料再看成品，减少“只看成品、不知道里面用什么”的顾虑。

**怎么拍**：
- 顾客问“这桌子是什么木头”，老周不直接回答，带着顾客走进工坊看对应木料。
- 镜头拍老周把木料、半成品桌面和店内成品摆在一起，一一对应展示。

### 3. 专业强 · 8分

**为什么成立**：老周做家具12年，且自己经营木工工坊，具备实木家具和木料辨认的实际经验。

**怎么拍**：
- 老周拿起两块不同木料，拍手感、纹理、边缘细节，讲清楚新婚家庭选餐桌时要先看哪几个地方。
- 在工坊拍老周检查桌腿、桌面和连接位置的过程，镜头跟着他的手走，不只拍口播。

### 4. 质量好 · 7分

**为什么成立**：自家工坊制作、木料可现场看，能让顾客看到家具从木料到成品的过程；但具体质量还需要持续用制作细节和客户使用反馈证明。

**怎么拍**：
- 拍一张实木餐桌从木料、切割、打磨到摆进门店的连续过程。
- 特写拍桌面边缘、桌腿连接处、椅子受力位置，老周边检查边讲：“买实木桌，别只看桌面，先看这里。”

## 不太适用

- 颜值高（6分）：目前只知道卖实木餐桌椅和布艺沙发，没有门店陈列、产品设计或顾客打卡画面的依据证明“颜值高”。

- 效果好（5分）：家具的使用效果需要真实入住后的空间搭配、使用反馈或前后对比，目前没有相关事实。

- 选择多（4分）：档案只明确有实木家具和布艺沙发，未提供款式、材质、尺寸或颜色丰富度的依据。

- 便利性（3分）：没有配送、送装、距离近、上门量尺或售后响应等事实支撑。

- 老板好（4分）：老周是本地人、做家具12年，但这些还不足以证明他的性格、做事方式或待客态度。

- 服务好（3分）：目前没有接待、送货安装、售后处理或客户评价等具体服务事实。

- 案例多（2分）：没有提供新婚家庭、换房业主的成交案例或客户家实拍案例。

- 有面子（4分）：实木家具可能具备一定的待客属性，但目前没有高档空间、宴客场景或客户认可的事实。

- 性价比（3分）：没有价格、配置、材质对比或同类产品比较依据，不能直接说划算。

- 生意好（1分）：没有客流、订单、排队、复购等事实依据。

- 好评多（1分）：没有顾客评价、复购、转介绍或平台评分等依据。

- 规模大（3分）：有自家木工工坊是生产能力的基础，但没有工坊面积、设备、人员或门店数量等依据证明规模大。

- 稀缺唯一（5分）：现场看木料和自家工坊有区分度，但没有“本地唯一”或独家产品的事实，不能往唯一上说。

## 建议主打

主打“有特色 + 实在不坑 + 专业强”。用“顾客能进工坊看木料”做最直观的画面钩子，再由老周12年的家具经验讲清楚木料和成品怎么对应，既能和普通家具店拉开差异，也能回应新婚家庭、换房业主怕买错家具的顾虑。
