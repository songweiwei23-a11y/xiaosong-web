1. **这是什么号**：本地家具店，讲实木家具和布艺沙发
2. **给谁看**：准备置家、换房的县城家庭

4. **主打内容**：流量50%、人设20%、变现30%；过程为主

7. **最该避开的坑**：只拍木料，把沙发落下

## 🔍 先说这一行

**归口：A 本地实体店，主属 D 家居家电。** 收入来自家具销售，账号要面对的是县城里准备置家的消费者，不是来学木工的同行。

**这行的钱怎么赚：** 家具通常靠单笔销售获得毛利，而不是靠同一家庭频繁复购。毛利不能只看售价减进货或材料款，还要考虑工坊加工、门店、运输安装、售后等成本；布艺沙发和实木家具的成本构成也可能不同。**这家店各项成本、毛利和客单均待确认，不能先断言哪类更赚钱。**

获客成本容易卡在两处：一是顾客看了不一定马上买，需要多次比较；二是从线上咨询到实际到店、选款之间会流失。视频的价值，是让顾客到店前先知道“这里有什么、哪些问题可以当面看”。

**客人的决策链路：** 我推测，多数家庭不会刷到一条视频就决定买家具，而是先看尺寸、预算和外观，再比较材质、坐感，和家人商量，碰到交房或搬家节点才定。**具体多久决定待确认**：先问最近一笔成交，从第一次进店到下单隔了多久，中间比较了什么。

**时间规律：** 这类消费更可能跟交房、装修完工、婚期和搬家节点走；节假日也可能带来集中看店机会，但不能直接认定本店旺季。营业时段内什么时候更忙、节日前后是否明显增加，先向老板核对近期到店和成交记录。

**老板容易自嗨的地方：** 把木种名称、工坊设备或工序讲得很细，却没回答顾客最初的问题：这张桌子能不能放进我家？这款沙发坐着适不适合家里人？**目前只能说有这个风险，不能认定老周已经中招**；他已有的家具常识方向，应从顾客场景切入，而不是先讲术语。

**同行内容的初步判断：** 未做本地竞品实勘，以下是行业常见形式的推测：门店走拍、产品报价、木料讲解、工坊加工。它们不一定没效果，但如果画面只是展示货，缺少顾客为何要看这一条的具体问题，陌生人容易划走。可测试的空档是：**把家庭选家具时的具体犹豫放到画面开头，再让商品或现场过程回答它。** 本地同行是否真有这个空档，要看过账号才知道。

## 🗣 我会先问老板的几个问题

- **问题**：最近一次顾客买完后有不满意的地方，是哪件家具、哪一处？对方原话是什么，你后来怎么处理？
  - **我的推测**：家具进家后才发现尺寸、坐感或使用细节不合预期的情况值得问，因为门店体验和家庭使用场景不同。
  - 待老板确认。

- **问题**：有没有一单你明确没接，或者一件货你没有卖给顾客？当时顾客要什么，你为什么这么决定？
  - **我的推测**：如果确有边界，它会比一句“我做生意实在”更能说明老周如何判断；但现在没有事实，不能先替他立这个人设。
  - 待老板确认。

- **问题**：最近一位再次进店的老客，第一次为什么来、后来为什么回来？他说过什么？
  - **我的推测**：家具复购周期可能较长，再次进店也可能是换房、添置或陪家人看，并不一定意味着再次购买。
  - 待老板确认。

- **问题**：除了“沙发怎么挑不踩坑”，顾客进店最近一次还问了什么？老周当时指着哪件东西、怎么回答的？
  - **我的推测**：沙发的尺寸、坐感和面料可能是具体问题，但先录下真实原话，比我们替顾客写问题更有价值。
  - 待老板确认。

- **问题**：有没有顾客亲口说过“为什么在这里选”？请回忆具体哪位、看了哪件东西、他说的原话是什么。
  - **我的推测**：老板认为现场看木料是优势，但顾客可能更在意当面看、坐感、款式或其他因素。**真正差异化要以顾客感受到的为准，不能先替他回答。**
  - 待老板确认。

- **问题**：这个月工坊或门店发生过什么小事？老周亲手做了哪一步，为什么当时由他做？若认为与别人做法不同，具体差在哪里？
  - **我的推测**：真实工作中的判断和动作可能成为可持续的人设素材；但“别人做不了”目前没有证据，不预设这个结论。
  - 待老板确认。

## 一句话定位

**做家具12年的老周，带你现场看懂实木家具和布艺沙发。**

立场是“现场看懂”，不是隔着镜头替顾客下结论；凭据是老周本人从业12年、门店和工坊有可拍现场。它是账号承诺，不宣称别家做不到。

## 六维地基

### 1. 人设定位

**原料在哪：** 可直接使用的材料是“老板老周”“做家具12年”“本地人”“自家有木工工坊”“现场看木料”。这些是身份、经历和场景，不是对性格的评价。档案没有确认“耐心、直爽、重感情”等特质，暂不写进人设。

“带你看懂”要翻译成镜头里能看见的行为：顾客问一个具体问题，老周指着现场材料或商品解释；能确认多少说多少，不靠形容词补结论。

**人设标签句：** 做家具12年的本地老周。

**入口：痛点＋职业。** 老周做家具，面对的是家庭选家具时看不懂、拿不准的问题；已知客人常问沙发怎么挑，说明这个切口有实际来源。

**验证：** 职业和12年经历已有事实卡支持；沙发问题也来自前采。木料辨认能讲到什么程度、能否持续回答其他高频问题，需要拍摄前请老周现场讲一遍，再决定哪些内容能发。**不把“12年”自动等同于对所有家具问题都有权威答案。**

**在同类账号里的位置：** 未实查当地同行，不能断言他们都是什么人设。可先把常见的“站在产品前讲参数”当作对照假设：老周不先扮演讲台上的专家，而是以店老板身份，站在实物前回答家庭会遇到的问题。差别在**本人、现场、具体问题**的组合；是否足够稀缺，竞品研究后再判断。

**证据链：**

1. 老周本人在工坊里完成真实工作，讲清自己正在做哪一步。
2. 取自真实接待的顾客问题，经确认后由老周对着实物回答。
3. 回顾12年里一件真实职业经历，细节先访谈，不预设起伏和结局。
4. 若确有不接的单或处理分歧的经历，用当时的动作和原话说明判断。

其中，人设内容只讲老周的经历和行为，不顺带推销；实物和工坊可以作为背景。

**边界：** 不编顾客评价、不把普通工序说成独家；不承诺某款家具适合所有家庭，也不评价其他商家的产品。没有真实事件支撑，就不编“他是个什么样的人”。

### 2. 用户定位

**一句话画像：** 县城里准备新婚置家，或换房后添家具的人：手里有户型和大致预算，想把餐桌、沙发带回家，但还要跟家人商量尺寸、坐感和价格。

**主攻两类：**

- **小镇青年**：新婚置家是明确场景，会关心家具放进家里是什么样、家人能否接受。
- **精致妈妈**：作为人群词根使用，不预设每位妈妈都负责采购；优先覆盖换房或为家庭添置家具时，关注材料信息、日常使用和家庭成员体验的决策者。

**为什么不是另一批：** 起号阶段不把主要内容做给想学木工技艺的同行，也不以远地只求线上成交的人为主——本号可展示的现场看货和本地到店更能服务当前目标。不是拒绝这些人购买，而是选题优先照顾本地置家家庭。

**他们心里可能在想什么：** “镜头里看着都差不多，我得知道拿回家合不合适，也想弄明白自己花钱买的是什么。”这是推测，不冒充顾客原话。

**决策链路：** 可能先刷到视频，再点主页看其他家具和老板怎么讲；有具体需求后问尺寸、款式或价格，和家人商量，再决定是否到店。**潜水多久、是否先比价、谁来拍板都待确认**，先问最近成交顾客的实际经过，因此前期不要假设一条视频就能成交。

**会想起老周的时刻：** 新房量完客厅尺寸，准备选沙发；餐厅空间确定后开始找餐桌椅；搬家前发现旧家具与新空间不匹配。具体哪个节点最常带来询盘，待核对。

**可能搜索的词：** “县城名＋家具店”“实木餐桌怎么选”“布艺沙发怎么选”“沙发尺寸怎么选”。其中县城名用真实地名替换；实际搜索词还需结合后续咨询和平台数据确认。

### 3. 内容定位

**长期提供的价值：** 帮置家家庭看懂实木家具和布艺沙发。

**内容方向：多元四类打底。** 用知识、过程、真实故事和观点，从不同角度服务同一批置家家庭。工坊和门店提供了拍摄现场，但目前没有确认足够稳定的真实事件源、拍摄人员和时间，**不选整个号只围绕一个固定任务**；先测试可重复的拍法，再决定是否把其中一种做成栏目。

**五步推导与当前配比：**

| 层次 | 决定 | 为什么 |
|---|---|---|
| 作用 | **流量型50%** | 起号期先争取陌生人看到，做最大一块；围绕家庭选家具的具体场景设计成本、人群或商品差异等看点，不带成交理由。 |
| 作用 | **人设型20%** | 老周本人出镜，需要让观众记住他；但真实故事尚待前采，不宜为了配比硬编。 |
| 作用 | **变现型30%** | 家具需要看货、比较，第一周就要有能通向咨询的内容；仍小于流量型，避免主页一开始像产品目录。 |
| 形式 | **过程展示为暂定主力**；知识、真实故事、观点辅助 | 门店和工坊有可拍实物，过程比空口讲更容易回答“具体怎么看”。但档案没有“数据最好的内容类型”，因此这是起步假设，不是数据结论；先累计测试20—30条，再按实际表现调整。 |
| 题材 | **主赛道80%，目标人群兴趣20%** | 大部分围绕实木家具、布艺沙发；一部分进入置家时的空间、家庭决策等相关话题，扩大入口，但仍与家具和场景相连。 |
| 品类位置 | 主赛道内，**实木家具与布艺沙发轮流安排，暂按各半测试** | 两类都在卖，现无销售额、库存和咨询量依据把任一类降为辅助；后续按实际咨询和内容表现调整。 |

**配比切换条件：** 不按某一天或单次高播放切换。先看一批内容里，非关注用户播放、完播、新关注是否持续有反馈；同时看本地相关咨询是否出现。若流量稳定而咨询少，先检查变现内容有没有展示具体商品、回答实际问题，再考虑提高变现占比。现无历史数据，不能预设达标数字。

**从刷到到联系，谁负责哪一段：**

- **刷到：流量型**用置家时看得懂的情境和可见看点，争取陌生人停留。
- **记住：人设型**靠老周的真实经历与动作，让人记得这是哪位店老板。
- **相信能解决问题：变现型**展示具体商品、现场材料或真实服务过程；信任来自能核实的内容，不来自口号。
- **联系：变现型**给一个明确私信指令，后续由真实接待承接。

**三种视频各怎么拍：**

**流量型**
- **四大脚本·晒过程／任务展示：** 同一个人、同一空间、同一坐姿，先后试坐两款店内布艺沙发，观察坐下后膝部和靠背接触位置有什么不同。人是置家者，货是两款沙发，场是门店；**反差**来自两款商品的实际差异，满足“有用”。不评价哪款更好，不讲卖点。结尾只问：“你选沙发会先看什么？评论告诉我。”
- **36计·第18计 求助网友：** 老周在门店展示两款可实际拍到的布艺沙发，说明各自的外观或尺寸等可核实信息，提出“你会先试哪款”；后续仅在收到真实评论后采纳并展示，不伪造网友意见。此处看点是**人群选择差异**，不是推销。

**人设型**
- **四大脚本·讲故事：** 访谈后选择老周12年里确实发生过的一次工作经历，按“当时遇到什么—他做了什么—后来怎样”讲。没有事件前不写成完整故事。结尾只引导**关注**。
- **36计·第7计 一句话设定故事感：** 拍老周正在做的一项真实工作，以他真实说出的目标或当下困惑开场，再拍动作和实际结果；例如“今天要完成【真实工作】”，不能编造顾客和期限。结尾只引导**关注**。

**变现型**
- **四大脚本·晒过程：** 围绕实木家具，拍顾客关心材料时，老周如何在现场展示木料、说明能确认的信息；成交理由是**木料可现场看**，画面要拍到实际材料。结尾只引导**私信**。
- **36计·第26计 推荐建议：** 围绕布艺沙发，先问清实际空间和使用需求，再展示店内真实可选的款式及各自适用条件；不提前宣称坐感、品质或价格优势。结尾只引导**私信**。涉及沙发的具体成交理由，需先核实商品资料或真实服务过程。

**配比核验：**

1. **是**：新号流量型50%，是最大一块。
2. **待验证**：没有已知数据最好的类型；过程展示只是根据现场资源作的起步选择。
3. **是**：虽未单独提出博主目标，流量仍为主力；每条要有具体人货场、三有之一和可拍的爆款元素。
4. **是**：20%留给置家人群相关兴趣，但不脱离家庭选家具场景。
5. **是，属于测试配比**：数字基于起号阶段、双品类和信任需要，不是已经验证的效果；资源与数据补齐后可调整。

**第一条该发什么：流量型；四大脚本·晒过程／任务展示。**

在门店找两款**确实可供试坐**的布艺沙发，手机固定机位；老周以同样坐姿依次坐下，镜头交代双脚、膝部与靠背位置，最后并排展示两次画面。开头可说：“同一个人坐两款沙发，坐姿不变，看看差在哪。”

为什么先拍它：顾客常问沙发怎么挑，坐感差异容易理解；只需本人、手机和店内两款实物。**实测差异不明显就如实呈现，不强说一款更舒适**；它只负责吸引讨论，不引导购买。

### 4. 呈现定位

**主要形式：** 现场口播结合过程画面；有实物可指，老周不必长时间背稿。  
**产能：** 团队、设备和可投入时间均未填，暂不能承诺周产量；先确认谁拍、谁剪、老周每周可拍多久，再定稳定条数。  
**在哪拍：** 木料及工作过程在工坊，餐桌椅和沙发体验在门店；不制造虚假的客户现场。

### 5. 风格调性

**正向匹配：** 老板本人在真实门店、工坊讲现场问题，比刻意扮演讲师更自洽。  
**气质关键词：** 朴实、清楚、现场感。它们是呈现目标，不是已确认的性格。  
**会说：**“这款你可以坐下来，看看脚能不能自然落地。”  
**不会说：**“不用试，这款适合所有人。”

### 6. 变现定位

- **卖什么及客单：** 实木家具、布艺沙发；客单价区间待确认，先核对近期实际成交价。
- **成交路径：** 抖音视频 → 私信询问 → 到店看货 → 选购。
- **最缺的信任证据：** 不同家庭需求对应的真实商品展示和接待过程，尤其是布艺沙发的具体可核实信息。
- 完整的变现拆解请用「商业定位」板块。

## 🧠 记忆点设计

以下均为**待验证建议**，先观察观众是否自然提及，不要求每条机械重复。

1. **场景：工坊里的木料或工作台。** 涉及木料的话题在真实现场开拍；它对应“现场看”的定位，也让观众一眼知道这不是纯口播号。沙发内容则回到门店，不强行统一背景。
2. **动作：提出问题后，指向正在讨论的实物部位。** 每次只指与问题有关的位置，让动作帮助观众找到信息；它是讲解辅助，不是视频的看点本身。
3. **语言：先说“咱们现场看”。** 适合确实能现场展示的问题；说完必须给画面，不把它当空口号。是否保留，看评论里有没有人主动提到。

## ⚡ 差异化：A + 变量B

以下“常规A”都是**未实查本地竞品前的行业假设**，不是对当地同行的判断。

### 组合一：木料介绍＋换视角

- **常规A：** 镜头对着木料，口播名称和特点。
- **变量B：换视角。** 从第一次进工坊的顾客视角看，减少陌生人听术语的负担。
- **A+B：** 手机从入口跟随老周走到实际木料前，老周回答一个真实顾客问题，再指给镜头看。只解释现场能核实的部分。服务的是“想知道自己在看什么”的置家者，不是展示工坊有多忙。

### 组合二：沙发展示＋求助网友

- **常规A：** 镜头扫过门店沙发，逐款介绍。
- **变量B：求助网友。** 把观看变成对具体选择的讨论，一个人可拍。
- **A+B：** 固定机位拍店内两款真实沙发，交代可核实尺寸或外观，问“给家里选，你会先试哪款？”有真实回复后再选问题回应。它帮助了解顾客在意什么；不把虚构评论当素材，也不在流量内容中推销。

### 组合三：家具知识＋情境还原

- **常规A：** 老板正对镜头讲一条选购常识。
- **变量B：情境还原。** 把抽象知识放进真实接待中出现过的问题。
- **A+B：** 前采确认某次顾客问过餐桌尺寸后，老周在门店用实际桌椅演示当时如何说明；视频注明是对真实问题的讲解，不冒充正在发生的接待。它服务准备置家的家庭，也能自然衔接咨询。**真实问题未确认前不拍此版本。**

每组先各拍低成本样片，比较开头是否留人、评论是否围绕问题，再决定保留哪个变量；不能仅凭一条表现否定整个方向。

## ⚠️ 这个号最大的风险

1. **工坊画面容易拍成单品类账号。** 木料和加工过程有画面，但布艺沙发同样在卖。如果一直拍木工，观众会不知道店里还有沙发。按品类轮流测试，并先补齐沙发真实款式、尺寸、面料和接待信息。
2. **拍摄资源与真实故事尚不清楚。** 老周是否能稳定出镜、谁拍谁剪、每周有多少时间都未确认；人设故事也缺具体事件。先核实资源和前采，再承诺产量；素材不足时宁可少拍，不伪造顾客、经历或结果。
