# 🚀 起号方案

## 📌 先说结论

- **建议主攻：36计·第1计 反向操作**
  - 主打《老周现场看家具》：**别人先讲参数，老周先不讲，让同一个人用同一个动作体验两件真实家具，画面先把差异拍出来。**
  - 它最贴合现有资源：老周本人、门店里的实木餐桌椅和布艺沙发、自家工坊，固定机位就能拍，不依赖演员、顾客配合或复杂剧情。
  - 第一批先集中用这一计拍 **20—30条中的主力流量内容**，把“现场看家具”打进观众记忆。

- **备选：**
  1. **36计·第18计 求助网友**：反向操作有播放但评论少时切入，用“你家会先选哪一款”的具体问题拉评论。
  2. **36计·第36计 冷知识**：两件家具放一起拍不出可见差异时切入，改拍木料、桌椅、沙发的一个反常识观察点。
  3. **36计·第10计 情境还原**：第21条后，确认有真实顾客高频问题时加入，承担本地咨询承接。

- **明确不做：**
  1. **第35计 街头采访**：当前只有老周、门店和工坊的确定资源，没有稳定外拍人员和采访对象。硬上街采，拍摄成本高，内容也容易偏离“现场看家具”。
  2. **第30计 角色扮演 / 第9计 一人分饰多角**：需要表演、写台词和多机位切换。老周最有价值的是12年做家具和真实在工坊做事，不把账号做成演段子。

- **多久能看出跑没跑通：**
  - 用前 **20—30条** 判断，不用单条播放判死刑。
  - 起号参考线是：**从零粉做到一千粉，且连续发布的流量开始稳定。**
  - 这条线之外，同时看：非关注播放是否增长、评论是否开始问尺寸/坐感/木料、主页访问和本地咨询是否出现。

## 🧮 起号期内容配比

已定定位原本是流量50%、人设20%、变现30%。但起号前20—30条必须先集中验证一个主力形式，因此前期调整为：

| 类型 | 起号期占比 | 这阶段为什么这样排 |
|---|---:|---|
| 流量型 | 70% | 用《老周现场看家具》先让陌生的新婚家庭、换房业主认识“现场比较家具”的内容。 |
| 人设型 | 10% | 只拍老周真实在门店、工坊做事的片段；真实事件没补齐前，不扩大故事比例。 |
| 变现型 | 20% | 从第一周开始保留，但只做小头，先验证本地人会不会从“看内容”走到“问实物”。 |

### 流量型：70%

- **出发点**
  - 人：做家具12年的老周；
  - 货：实木餐桌椅、布艺沙发；
  - 场：门店、工坊；
  - 三有：有用；
  - 爆款元素：**人群 + 反差**。
- **用的形式**
  - 主用：**36计·第1计 反向操作**
  - 补充：**36计·第18计 求助网友**、**36计·第36计 冷知识**
- **脚本结构**
  - 家庭选购问题 → 不先讲参数 → 同一人/同一动作体验两件家具 → 拍出可见差异 → 只说这一轮能观察什么。
- **结尾行动指令**
  - **“你家选家具最在意哪一点？评论区说说。”**

> 流量型不讲“自家工坊”“木料可现场看”这些成交理由，不引导私信或到店。货只负责提供画面和比较对象。

### 人设型：10%

- **出发点**
  - 拍老周本人做家具12年的真实工作状态；
  - 让观众记住：这是一个在县城门店接待顾客、也会回工坊做事的家具老板。
- **用的形式**
  - **36计·第37计 赠送：身份反差**
  - 搭配四大脚本：**讲故事／平凡英雄型**
- **脚本结构**
  - 门店里的老周 → 回到工坊完成一项真实工作 → 讲清这件事为什么要自己看一眼或做一步 → 一句个人判断。
- **结尾行动指令**
  - **“想继续看老周在门店和工坊怎么做，关注我。”**
- **真实性边界**
  - 没有具体事件、时间、动作或现场物件，不拍成故事。
  - 待确认：老周在工坊里亲手做的固定步骤是什么；先拍到真实动作，再写文案。

### 变现型：20%

- **出发点**
  - 人：准备新婚置家、换房添置家具的县城家庭；
  - 货：实木餐桌椅、布艺沙发；
  - 场：门店实物、工坊木料；
  - 成交理由：**实木家具的木料可现场看。**
- **用的形式**
  - **36计·第10计 情境还原**
  - 搭配四大脚本：**晒过程／过程展示**
- **脚本结构**
  - 一个真实高频问题 → 老周站到实物前说明要看什么 → 展示现场能确认的信息 → 说清不能凭这一眼确认什么 → 私信承接。
- **结尾行动指令**
  - **“想看店里实物，私信发户型和大致尺寸。”**

### 过了一千粉、流量开始稳定之后

比例回到已经定好的长期方向：

- **流量型50%**：继续做《老周现场看家具》，扩大陌生人覆盖。
- **人设型20%**：补入老周12年里确认过的真实工作事件。
- **变现型30%**：增加《到店前，先把这件事说清楚》，把尺寸、空间、坐感、木料现场看这些问题接到私信。

### 和已定内容定位怎么对上

- **主力形式**：晒过程 + 教知识，不做空口讲家具。
- **主系列**：主攻《老周现场看家具》。
- **品类安排**：实木家具、布艺沙发轮换，不把账号拍成只讲木料的木工号。
- **账号记忆点**：不是“卖家具的老周”，而是“站在实物前，帮县城家庭现场看家具的老周”。

## 🎯 主攻打法：36计·第1计 反向操作

### 为什么是你能拍的

1. **出镜人明确**
   - 老周本人出镜，不需要再找主播、演员或顾客扮演者。
   - 老周做家具12年，讲解不是背稿，而是站在实物前回答一个具体问题。

2. **货够用**
   - 店里同时有实木餐桌椅、布艺沙发。
   - 反向操作的核心是“同一条件下换货”，刚好能让两件真实家具轮流成为对比对象。

3. **场景够用**
   - 门店负责拍试坐、坐姿、尺寸、桌椅距离；
   - 工坊负责拍木料、加工中的家具和成品前后的真实过程。

4. **拍摄门槛低**
   - 固定一个手机机位，老周自己试坐、拉椅子、靠背、伸腿、摆放物品。
   - 不用街采，不用复杂运镜，不用多人表演。
   - 拍摄前提：要有一个能固定手机的支架或稳定摆放位置。**如果连固定机位都无法保证，这一计先停，改拍第36计冷知识。**

5. **最符合主系列**
   - 《老周现场看家具》的固定动作就是：不先讲，让观众先看。
   - 这比“站在家具旁边介绍款式”更容易让陌生人停下来。

### 结构公式

**常规做法：先听介绍、看颜色、看款式  
→ 反向做法：先不听介绍，固定条件体验两件真实家具  
→ 真实结果：让镜头拍出这一次坐下、起身、靠背、桌椅距离的变化  
→ 老周收住：这只能帮助你比较，最终还要结合自家空间和使用习惯。**

落到账号里就是：

> “先别问这张沙发软不软。老周先坐两张，坐姿不变，你看膝盖、腰和起身这几个地方。”

### 配什么脚本讲

- **36计管事件**：第1计·反向操作——先不讲参数，先做同条件体验。
- **四大脚本管表达**：教知识／拆解型。
- **补上的内容**：避免视频只有“坐两下”的画面，而是让老周把观众真正该观察的位置讲清楚。
- **这条的主目的**：流量型。
- **注意**：不讲“我家工坊”“我家木料”，不引导私信，不把流量视频拍成广告。

### 前3条具体拍什么

#### 1.《新婚置家选沙发，先别看颜色，坐下后看这三个地方》——（人群）

**拍摄要点：**

- 首帧：老周站在两张真实布艺沙发中间，把两张沙发的说明牌先放到一边。
- 固定机位拍老周以同样坐姿坐上第一张，再坐第二张。
- 镜头只抓三个位置：
  1. 脚是否能自然落地；
  2. 膝部位置；
  3. 背部和靠背的接触位置。
- 老周只说：“先别急着问哪张更好，先看你坐下以后，这三个地方是什么状态。”
- 结尾：**“你家选沙发最在意哪一点？评论区说说。”**

**为什么会让人停下：**  
新婚置家是明确人群，开头否定“先看颜色”这个常见动作，观众会想知道坐下后到底该看哪里。

---

#### 2.《同一把椅子，靠近餐桌和离开餐桌一点，坐下后的感觉不一样》——（反差）

**拍摄要点：**

- 同一张实木餐桌、同一把椅子、同一个老周。
- 第一段：椅子按门店常规距离摆放，老周坐下。
- 第二段：椅子离桌子更近或更远一点，再坐一次。
- 画面拍清手臂、腿部和桌沿的距离。
- 老周说：“餐桌椅不能只看桌子长不长，真正坐下吃饭，椅子推得开不开也得看。”
- 不下“这样摆一定最好”的结论，只提醒到店时要按自家使用方式试。
- 结尾：**“你家吃饭时，椅子推不开最难受吗？评论区说说。”**

**为什么会让人停下：**  
很多人买餐桌时先量桌面，忽略坐下后的动作空间；同一把椅子位置一变，画面能立刻看出区别。

---

#### 3.《两张布艺沙发看着差不多，老周只做同一个起身动作》——（反差）

**拍摄要点：**

- 选两张店内布艺沙发，画面中同时出现。
- 老周先坐第一张、双手自然放在腿侧、起身；再用同样动作坐第二张、起身。
- 不剪成“哪张胜出”，只拍动作节奏、身体支撑和靠背位置。
- 老周说：“沙发别只按一下就问软不软。你家谁天天坐，坐多久，起身顺不顺，这些都得自己试。”
- 结尾：**“家里选沙发，是年轻人坐得多，还是老人孩子坐得多？评论区说说。”**

**为什么会让人停下：**  
同一个动作换两件货，反差来自镜头里看得见的变化，不靠夸张结论。

### 边界

- 不把一次试坐说成“所有人都适合”。
- 不说“哪张一定更舒服”“这样选绝不踩坑”。
- 不为了做对比，拿同一张沙发换靠垫、换摆法来拍；必须换成店里不同的真实家具。
- 不让店员假装随机顾客。
- 不讲未经确认的材质、参数、价格、耐用年限。
- 不让老周硬演情绪，镜头里只保留真实动作和真实判断。

## 🔄 备选打法

### 备选一：36计·第18计 求助网友

**什么情况下切过去：**  
第1计有播放，但评论很少；观众看完就划走，没有留下自己家的家具问题。

**为什么是你能拍的：**

- 只要门店里有两件真实家具，老周一个人就能拍；
- 不需要街访，也不需要安排人表演；
- 县城新婚、换房人群对“家里到底怎么选”有表达欲，评论区能反过来提供选题。

**怎么套到这个号上：**

> 展示两张真实布艺沙发或两张餐桌的已知信息  
> → 老周只讲一个家庭使用条件  
> → 提出一个明确选择题  
> → 下一条从评论里选一个真实问题回应。

**示范首条：**  
《客厅空间不大，这两款布艺沙发你会先坐哪一张？》——（人群）

**配的四大脚本：**  
晒过程／任务展示。

**它补上的是什么：**  
补评论和选题来源，不补成交。结尾只让评论，不让私信。

---

### 备选二：36计·第36计 冷知识

**什么情况下切过去：**  
店内两件家具的体验差异不够直观，或者反向操作连拍3—5条后首帧吸引力下降。

**为什么是你能拍的：**

- 工坊和门店有真实木料、餐桌椅、布艺沙发；
- 老周做家具12年，适合站在实物边把一个具体观察点说清；
- 不依赖顾客出镜，不需要多人协作。

**怎么套到这个号上：**

> 一个反常识观察点  
> → 老周直接指向实物  
> → 解释为什么要看这里  
> → 回到“到店时你可以自己看一眼”。

**示范首条：**  
《看实木餐桌，别只盯着桌面，先蹲下来看看这里》——（反差）

> 待确认：具体要看哪一处，必须由老周指向真实桌子后确定；不能编成行业统一标准。

**配的四大脚本：**  
教知识／拆解型。

**它补上的是什么：**  
补“老周现场看家具”的专业解释，让账号不只靠两件家具的比较。

---

### 备选三：36计·第10计 情境还原

**什么情况下切过去：**  
第21条后，评论和私信里反复出现同一类真实问题，例如“沙发怎么挑不踩坑”“餐桌尺寸怎么量”；此时把问题还原到门店实物前，开始承接本地咨询。

**为什么是你能拍的：**

- 门店和工坊就是问题发生的真实场；
- 老周本人既能提问，也能站在实物前回答；
- 不需要请人演顾客：老周可以明确说“有顾客问过我这个问题”，前提是这句话确实问过。

**怎么套到这个号上：**

> 真实顾客问题  
> → 老周指向店内实物说明  
> → 观众旁观并得到准备清单  
> → 私信发户型和大致尺寸。

**示范首条：**  
《顾客问沙发怎么挑，老周先问家里谁每天坐》——（人群）

**配的四大脚本：**  
晒过程／过程展示。

**它补上的是什么：**  
补变现型内容需要的成交理由和咨询承接。实木家具重点拍“木料可现场看”；布艺沙发重点拍“根据使用条件现场比较”。

**边界：**

- 顾客问题必须真实发生过；
- 没有真实原话时，改成：“如果你准备到店看沙发，先把这件事想清楚。”
- 不把客户问题拍成客户不懂行，更不贬低同行。

## 🧪 怎么测

### 一次只改一个核心变量

前期只改下面其中一项，其他不动：

1. **商品变量**：实木餐桌椅 / 布艺沙发。
2. **家庭任务变量**：新婚置家 / 换房后客厅变小 / 一家人日常吃饭。
3. **开篇变量**：先否定常见动作 / 先给同动作对比画面。
4. **体验动作变量**：试坐 / 起身 / 拉椅子 / 靠背 / 放进空间。

不要一条里同时换商品、换场景、换讲法、换结尾。否则数据出来，也不知道是哪一步有效。

### 每计怎么测

| 打法 | 至少测几条 | 重点看什么 |
|---|---:|---|
| 第1计 反向操作 | 5条 | 非关注播放、前5秒停留、完播、评论里是否出现具体家具问题 |
| 第18计 求助网友 | 3条 | 评论数量、评论是否有真实家庭场景、下条能否从评论继续拍 |
| 第36计 冷知识 | 3条 | 收藏、完播、评论是否追问“那还要看什么” |
| 第10计 情境还原 | 3条 | 本地私信、私信是否带户型/尺寸/到店意向，而非只问价格 |

### 什么信号算“这计行”

- **第1计行**：同一结构连续5条里，至少有多条的非关注播放和前段停留比纯产品展示更稳定；评论开始出现“我家就是这样”“那小户型怎么看”。
- **第18计行**：评论区出现真实选择理由，且能连续接出下一条选题。
- **第36计行**：收藏和追问比单纯试坐类视频更高，观众开始记住“老周讲现场怎么看”。
- **第10计行**：私信里开始出现户型、大致尺寸、品类或到店时间，而不只是泛泛问价。

### 什么信号算“换掉”

- 同一计连续拍满3—5条，首帧已清楚、画面也有动作，但前段持续流失；
- 评论只停留在“多少钱”“在哪”，没有人围绕选家具的问题互动；
- 同类视频越拍越像，只是在换家具，没有新的家庭问题；
- 变现型内容有观看但没有本地咨询，先回查是否真的拍到了实物和现场证据。

## 📅 30天节奏

按**每周2次集中拍摄、每次拍3条、每周发布3条**安排。门店和工坊一次拍足，不要求天天拍。

### 第1—7天：把“反向操作”拍成固定样子

**任务：**

- 固定一个门店拍摄位置；
- 固定首帧动作：老周把说明牌放一边，先试坐/拉椅子/靠背；
- 拍3条第1计反向操作；
- 实木家具、布艺沙发各至少出现1次。

**交付物：**

- 3条《老周现场看家具》样片；
- 1套固定镜头清单；
- 1张记录表：标题、首帧、商品、家庭任务、数据、评论问题。

### 第8—14天：测“人群”还是“反差”更能带停留

**任务：**

- 再拍3条第1计；
- 一组标题直接写“新婚置家/换房”；

## 📊 跑不通先查哪里

### 1. 现象：有曝光，但前3秒就划走

- **先怀疑：** 首帧只是家具陈列，老周第一句太慢，观众没看到“今天要比较什么”。
- **下一步实验：**
  - 同一个选题重拍5个首帧；
  - 把“两件家具 + 同一个动作”放到第一秒；
  - 第一口就说清人群或冲突，例如：“新婚置家，先别问哪张更软。”

### 2. 现象：播放有了，评论很少

- **先怀疑：** 视频讲完了，但没有留给观众一个具体、容易回答的问题。
- **下一步实验：**
  - 切第18计求助网友；
  - 每条只问一个问题，例如“客厅不大，你会先试哪一张？”
  - 不问“你觉得怎么样”这种太泛的问题。

### 3. 现象：有人看，也有人问家具，但没有本地咨询

- **先怀疑：** 内容停留在泛知识，观众没看到门店真实货和老周如何对应家庭条件。
- **下一步实验：**
  - 切第10计情境还原；
  - 一条只解决一个到店前问题；
  - 实木家具拍木料现场能确认的部分；
  - 布艺沙发拍空间、使用人数、坐感如何现场比较；
  - 结尾只保留：**“想看店里实物，私信发户型和大致尺寸。”**
