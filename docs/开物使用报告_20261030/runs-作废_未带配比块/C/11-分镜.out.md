## 4. 🧰 拍摄清单

- **必备**：手机、手机支架或三脚架、两张当天能展示的布艺沙发、干净的地面、老周当天试坐穿的日常鞋。
- **加分项**：  
  - 领夹麦：解决门店环境声、顾客说话声影响口播的问题。  
  - 小型补光灯：门店自然光不足时补亮人物面部和沙发布料纹理。  
  - 白色反光板或浅色泡沫板：放在人物脸部阴影一侧，减轻窗边拍摄的阴阳脸。  
- **道具与场地**：选两张可正常试坐的布艺沙发；沙发周围留出坐下、靠背、起身的活动空间；清走画面里的包装纸、杂物和与本条无关的价签。

## 5. ⚠️ 这条片子最容易翻车的 3 个地方

- 【两次动作不一致】第一张慢慢坐、第二张快速坐，观众看不出是在比较什么 →【怎么避】先完整练一遍“坐下、靠背、起身”，两张沙发都按同样顺序、相近速度完成。  
- 【脚部和腰背镜头拍不清】全程只拍上半身，台词讲膝盖、脚落地、腰背接触却没有画面证据 →【怎么避】单独补拍低机位脚部镜头和侧后方腰背镜头，后期对应插入。  
- 【硬判定哪张更好】现场差别不明显，却用字幕或表情说其中一张更舒服 →【怎么避】只保留真实坐姿、靠背和起身动作，结论始终落在“自己试出来”，不替观众下判断。
