## 选题1：外行人绝对不知道的实木餐桌木料对照，现场到底能看出什么？

**承接**：方向1“准备买实木餐桌的人，到工坊到底看什么”，以及“拿出真实木料和对应家具”这条拍摄思路。

**0️⃣ 视频目的**  
变现型：让准备买实木家具的人看见到店能现场核对什么，降低到店沟通门槛。

**🅰 打法**  
36计·第10计 情境还原：准备买实木餐桌的人带着“木料怎么看”的问题到工坊 → 老周拿出真实木料并指向对应餐桌 → 逐项指出现场能看到的部位 → 说明哪些还需结合实际使用判断。

**1️⃣ 爆款元素**  
奇葩——套用“外行人绝对不知道的X”，这里的X是“到店看实木餐桌木料时能核对的细节”；不预设答案，现场只讲实际能看到的部分。

**2️⃣ 开篇钩子**  
“准备看实木餐桌，木料拿到眼前，哪些地方能现场看明白？”

**3️⃣ 内容方向及目的**  
- **核心内容方向**：老周用工坊里的真实木料和对应餐桌，演示到店看木料时能核对哪些具体位置。  
- **核心问题与观众价值**：新婚置家、换房的人看实木餐桌时，如何把“我想看看木料”变成现场能问、能对照的问题。  
- **取材与内容推进**：先选当天确实能拿出、且能对应到家具的木料；请老周指明木料和家具对应的位置。追问：“这块木料能看到什么？”“桌子上哪一处能对照？”“哪些判断不能只靠眼前这一块木料？”只保留现场可以核实的说明。  
- **事实边界**：已知有自家木工工坊、实木餐桌椅，木料可现场看；具体木种、加工工艺、性能结论需现场确认，不提前写成事实。  
- **关键画面（3个）**：①老周拿起当天可展示的木料；②手指木料，再切到对应家具位置；③老周说明“能现场确认”和“还需结合使用判断”的具体边界，保留现场原话。  
- **场景设置**：自家木工工坊，木料与对应家具同场拍摄。

**4️⃣ 脚本结构**  
按计的公式走：提出到店问题 → 拿出真实木料和对应餐桌 → 老周逐处说明可观察内容 → 收束到“哪些能看、哪些不能只凭这一处下结论”。

**5️⃣ 结尾行动指令**  
“准备看实木家具的，带上家里的大致尺寸来店里对照看看。”

**6️⃣ 执行要点**  
手机拍摄即可。拍前确认木料与家具确实对应；收音时避开工坊明显噪声，关键说明补拍手部特写。不要补演工序，也不要在无法确认时替木料下结论。

**7️⃣ 成交理由**  
- **体现的理由**：便利性——自家工坊的木料可现场看。  
- **转化路径**：观看→准备尺寸→到店看实物

## 选题2：同一个人试坐两张布艺沙发，坐姿和起身时有哪些不同？

**承接**：方向2“同一个人，试坐两张布艺沙发”，以及“相同坐姿试坐两张店内真实沙发；拍膝盖位置、腰背接触、起身动作”的做法。

**0️⃣ 视频目的**  
流量型：用同一个人、相同动作的直观对比，吸引正在挑沙发的本地用户停留。

**🅰 打法**  
36计·第1计 反向操作：常规做法是站在沙发旁介绍款式 → 反过来先不讲款式，让同一个人用相同坐姿试坐两张店内沙发 → 对照膝盖位置、腰背接触和起身动作 → 老周只描述镜头实际拍到的差别。

**1️⃣ 爆款元素**  
反差——套用“曾经 vs 现在”之外的反差句式不合适；此处不另造句式，直接使用给定的“穷人 vs 富人”不适用。故本条不叠加爆款元素，流量看点来自同人同动作的现场对比。

**2️⃣ 开篇钩子**  
“先别听我介绍款式，同一个人坐两张沙发，膝盖、腰背和起身动作有什么不同？”

**3️⃣ 内容方向及目的**  
- **核心内容方向**：同一个人用相同坐姿试坐两张真实布艺沙发，观察画面里能看到的动作差异。  
- **核心问题与观众价值**：挑沙发时，为什么不宜只看外观；观众能学会带着坐姿和使用习惯现场比较。  
- **取材与内容推进**：选店内两张真实沙发，固定拍摄角度；同一人依次用相同坐姿坐下、靠背、起身。老周追问：“这两次坐下后膝盖位置有什么变化？”“腰背接触的位置能从画面看出来吗？”“起身时动作是否不同？”观察结果不一致也照实呈现，不判断哪款适合所有人。  
- **事实边界**：已知店内经营布艺沙发，方向材料给出对比维度；具体坐感和适用人群须通过现场试坐确认。  
- **关键画面（3个）**：①同一人坐下，两张沙发分别取同角度画面；②两次靠背时拍腰背接触位置；③两次起身动作并列剪辑，保留老周现场观察。  
- **场景设置**：门店沙发陈列区，两张沙发之间无需切换场景。

**4️⃣ 脚本结构**  
按计的公式走：先不讲款式 → 同人同姿势试坐两张沙发 → 对照拍下的膝盖、腰背和起身动作 → 只总结镜头能支持的差别。

**5️⃣ 结尾行动指令**  
“你挑沙发时最想比较哪一处？评论区说说。”

**6️⃣ 执行要点**  
老周一人可完成演示，手机固定机位即可。两次坐姿、机位和拍摄距离尽量一致；不加顾客出演，不用未经核实的舒适度或质量结论。

## 选题3：准备换沙发的家庭，到店前要说清哪几件事？

**承接**：方向4“准备换沙发的家庭”，以及到店前整理空间、使用人数、主要使用习惯，再说明这些信息影响什么比较方向的思路。

变现型：帮助换沙发的家庭整理到店沟通信息，让到店试坐和比较更有针对性。

**🅰 打法**  
36计·第26计 推荐建议：圈定准备换沙发的家庭 → 按空间、使用人数、主要使用习惯列出到店前可准备的信息 → 老周在真实沙发前逐项说明这些信息会影响哪些比较方向 → 补充不同家庭情况要现场核对。

**1️⃣ 爆款元素**  
成本——套用“花小钱办大事”的句式不贴合本条，也没有依据谈花费；本条不叠加爆款元素，重点是可执行的到店准备清单。

**2️⃣ 开篇钩子**  
“准备换沙发的家庭，到店前先把这几件事想清楚，比较时更容易说到点上。”

**3️⃣ 内容方向及目的**  
- **核心内容方向**：老周在店内沙发前讲清换沙发的家庭到店前可以准备哪些信息，以及这些信息会影响什么比较方向。  
- **核心问题与观众价值**：观众到店前要准备哪些家庭情况，才能让现场沟通不只停留在“有没有某款”。  
- **取材与内容推进**：按顺序说出空间情况、日常使用人数、主要使用习惯；每说一项，就由老周在沙发前解释“这会影响现场比较什么”。追问：“空间信息要带什么？”“平时谁会用、常怎么坐？”“这些信息能帮助我们比较什么，还不能直接决定什么？”  
- **事实边界**：该清单是拍摄建议，不是店铺既定服务承诺；不延伸到未确认的户型方案、尺寸标准、价格和产品参数。  
- **关键画面（3个）**：①老周在沙发前提出第一项准备信息；②逐项说出使用人数和习惯，并指向对应比较部位；③将纸上或手机备忘录里的待准备事项拍清楚，不展示任何顾客隐私。  
- **场景设置**：门店布艺沙发旁，店内完成。

**4️⃣ 脚本结构**  
推荐型：先圈定准备换沙发的家庭 → 提出到店前准备空间、使用人数和习惯 → 老周逐项说明对应的比较方向 → 提醒这些信息帮助沟通，但不能替代现场试坐和实际核对。

**5️⃣ 结尾行动指令**  
“准备换沙发的，到店前把空间和使用习惯记下来，带来店里一起比较。”

**6️⃣ 执行要点**  
手机拍摄，备忘录或普通纸笔即可。不要展示真实顾客的户型、地址或联系方式；未确认的尺寸标准不写进字幕。

**7️⃣ 成交理由**  
- **体现的理由**：专业强——老周在真实沙发前，按家庭情况说明比较方向。  
- **转化路径**：观看→整理需求→到店比较

**5️⃣ 结尾行动指令**
