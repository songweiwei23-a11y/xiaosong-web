## 4. 优化后的完整脚本

### 第1步：脚本策略卡

- **核心问题**：挑布艺沙发时，除了看外观，现场试坐该比较什么？
- **用户目的**：流量型，让准备置家或换沙发的人带走一套试坐观察方法。
- **目标人群**：县城本地的新婚家庭、换房业主。
- **所选形式**：对比型。用“只看外观”和“同人同动作试坐”两种挑选方式形成对照；实际演示时，同一个人依次试坐两张店内布艺沙发。
- **出发点**：围绕**货——布艺沙发**｜三有：**有用处**｜爆款元素：**反差**，贯穿开头提出的问题和中段两张沙发的试坐对照。
- **材料递进与事实边界**：从只看外观可能遗漏使用感受，推进到观察膝盖位置、腰背接触和起身动作。两张沙发的实际差异以现场画面为准；不同也好、没有明显不同也好，都不预设结果。

### 第2步：纯文字文案

同一个人，试坐两张沙发，挑出来的感觉可能不一样，差在哪儿？

买沙发时，有人先看颜色、款式，觉得摆在客厅好看，就准备定下来。

可沙发放进家里，天天要坐、要靠、要起身，光站着看，没法知道自己坐上去是什么感觉。

我用同样的动作，坐一下这两张布艺沙发，你挑的时候也可以照着试。

先坐下，看看脚能不能自然踩地，膝盖位置舒不舒服。

再往后靠，留意腰背和靠背接触在哪里，自己是不是习惯这个坐姿。

接着起身，感受一下动作顺不顺，再换另一张，用同样的动作试一遍。

试完别急着分好坏，回想一下自己平时是坐着聊天多，还是喜欢往后靠，再让家里常坐的人也试试。

这就是为什么挑沙发不能只看外观：坐着合不合适，要靠自己试出来。

你挑沙发时，会留意哪一处？评论区说说。

### 第3步：完整分镜脚本

**【镜头一】开场钩子｜0—8秒**

- **画面**：手机固定，老周站在两张布艺沙发附近，手势示意两张沙发。
- **台词**：  
  “同一个人，试坐两张沙发，挑出来的感觉可能不一样，差在哪儿？”
- **拍摄／收音要点**：正对镜头说，重读“同一个人”和“两张沙发”，用问题带出对比。

**【镜头二】A方案：只看外观｜8—25秒**

- **画面**：老周站在沙发旁看颜色、款式，再坐下，镜头带到靠背和起身动作。
- **台词**：  
  “买沙发时，有人先看颜色、款式，觉得摆在客厅好看，就准备定下来。  
  可沙发放进家里，天天要坐、要靠、要起身，光站着看，没法知道自己坐上去是什么感觉。”
- **情绪波点 😓**：从“看着好看”转到“每天怎么用”，语气稍停，突出容易遗漏的地方。
- **拍摄／收音要点**：画面只做动作示意，不演顾客成交，也不声称这种挑选方式已经造成了什么结果。

**【镜头三】B方案：同人同动作试坐｜25—45秒**

- **画面**：固定机位，老周依次坐在两张沙发上，按相同顺序坐下、靠背、起身。拍全身侧面，必要时补拍腰背接触位置。
- **台词**：  
  “我用同样的动作，坐一下这两张布艺沙发，你挑的时候也可以照着试。  
  先坐下，看看脚能不能自然踩地，膝盖位置舒不舒服。  
  再往后靠，留意腰背和靠背接触在哪里，自己是不是习惯这个坐姿。  
  接着起身，感受一下动作顺不顺，再换另一张，用同样的动作试一遍。”
- **情绪波点 💡**：从“光看不够”转到“现场可以这样比较”，语速清楚，动作与台词对应。
- **拍摄／收音要点**：两次尽量保持机位、距离和坐姿一致；若腰背接触被遮挡，调整角度补拍，不凭画面猜测。

**【镜头四】比较回收｜45—52秒**

- **画面**：两次试坐画面交替剪辑，保留真实的坐姿与起身动作；随后切回老周。
- **台词**：  
  “试完别急着分好坏，回想一下自己平时是坐着聊天多，还是喜欢往后靠，再让家里常坐的人也试试。  
  这就是为什么挑沙发不能只看外观：坐着合不合适，要靠自己试出来。”
- **情绪波点 ⚡**：从比较画面落回家庭实际使用，不替观众判定哪张更合适。
- **拍摄／收音要点**：现场如果差别不明显，就如实保留；不加“更舒服”“更好起身”等未经确认的字幕。

**【镜头五】行动召唤｜52—60秒**

- **画面**：老周坐在沙发上看向镜头，机位固定。
- **台词**：  
  “你挑沙发时，会留意哪一处？评论区说说。”
- **拍摄／收音要点**：语气放松，留出自然停顿。剪辑时可让上一镜的总结句延续到这里，给画面和结尾留足时间。

### 第4步：执行与优化建议

1. **拍前准备**：在店内选两张当天能展示的布艺沙发，固定手机，尽量让两张沙发的取景角度和拍摄距离一致。
2. **先拍完整动作**：老周分别完成坐下、靠背、起身，再补拍脚部、膝盖及腰背位置。逐句口播可另录，避免演示时收音不清。
3. **需要现场核对**：两张沙发的具体差别、腰背接触位置和起身动作，以实拍为准；没有明显差别也可以保留，不必强行剪出反转。
4. **控制时长**：按正常偏快的口播节奏录制，剪辑时以完整念清为准；若演示动作占时较长，可让动作画面覆盖对应口播，而不是额外增加台词。
