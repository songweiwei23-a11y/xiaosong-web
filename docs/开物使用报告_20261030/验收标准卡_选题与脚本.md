# 验收标准卡：选题与脚本

- 2026-11-01 产品方选定：选题 4 条、脚本 4 条。依据知识库「编导知识大全」原文。
- 评估器（`evals/judge.eval.ts`）按这份判，原文在 `evals/rubrics.ts`；11-01 按产品方对选题、脚本的判断收紧过。

## 选题

### T1 出发点清楚
- **判什么**：先做路人测试：把标题和开头念给一个不在这个行业的路人听，他听得懂吗？想点开吗？再看说不说得清给谁看、为什么会看、要达到什么目的。
- **合格**：路人一听就懂、觉得跟自己有关；一句话说得清给哪类人看、落在人货场的哪一个上、符合三有的哪一条；目的只有一个（大流量、人设、变现）。
- **不合格**：切口太专业，路人听了发懵或觉得跟自己无关（产品方 11-01 判的主因，例：「第一次体验下午4点出摊的川味烧烤，先看懂一份食材怎么准备」「外行人绝对不知道的大码试衣视角：同一件衣服，先看转身」）；套了爆款元素的句式，内容仍是内行视角；说不清给谁看；混了几个目的。
- **出处**：三种目的_大流量人设型变现型_说明（二、六）；流量型与大流量_修正说明（三）；第17节 选题三大原则

### T2 爆款元素一眼认得出
- **判什么**：用上了八大爆款元素（成本、人群、头牌、奇葩、最差、反差、怀旧、荷尔蒙）里的哪一个？光看标题认不认得出？
- **合格**：标题里就有这个元素的句式（如「最难用的」「当年最火的」「南方人 vs 北方人」「花十分之一的钱」），而且元素落在这个行业、这个人、这个场上。
- **不合格**：元素只写在说明里，标题看不出；为了用元素硬套（小店去做「头牌」）；标题平淡，看不出看点。
- **注意**：大流量必须有。人设型、变现型有更好，是否也必须，待产品方确认。
- **出处**：八大爆款元素选题；5.正确使用八大爆款元素的选题技巧；流量型与大流量_修正说明（三）

### T3 只有这家店拍得出来
- **判什么**：换一家同行，这个选题还成立吗？
- **合格**：用上了这个号自己的东西：档案里的人、在卖的货、店里的场景、独特的做法或真实经历（如「剪前先聊脸型」「旧件当面拆给你看」）；或者比观众多一步认知（新证据、新解释、新视角）。
- **不合格**：放之四海皆准，任何同行都能原样发（「装修避坑 5 个点」）；老掉牙、烂大街的说法。
- **出处**：第9节 差异化；第17节 选题三大原则（第三条标准）；第12节 视频记忆点

### T4 拍得出来
- **判什么**：这个号现有的人、场地、设备和素材，能把它拍出来吗？
- **合格**：一部手机、现有的场地和人手就能拍；要用的素材档案里有，或者现场拍得到；不需要编故事、编数字来撑。
- **不合格**：要明星、大场面或档案里没有的资源；靠编出来的客户故事、数字才成立；碰了档案里的禁忌。
- **出处**：三种目的_大流量人设型变现型_说明（2.1 第5步 落地检查）；流量型与大流量_修正说明（三.5）；第40节 起号三十六计说明书

## 脚本

### S1 钩子兑现
- **判什么**：前 3 秒抓不抓人？后面有没有兑现开头的承诺？
- **合格**：开头 3 秒就给出和目的对应的钩子（大流量：看点、噱头、反差；人设：一段经历；变现：一个问题或一个效果），后面的内容正好兑现开头抛出的问题或承诺。
- **不合格**：开头是自我介绍、寒暄或空话；开头承诺的东西后面没给（标题党）；钩子和目的对不上（大流量开头就讲卖点）。
- **出处**：开篇36计_完整知识体系精编版；10.晒过程1（六大钩子）；三种目的_大流量人设型变现型_说明（六.7）

### S2 结构落在事件上
- **判什么**：有没有按选题定的打法和结构，把选题里那件事本身写出来（谁、在哪、做了什么、说了什么）？那件事是不是真的、拍得到？产品方 11-01 判的主因：结构段落是编出来的描述，没按选题的结构写好事件（例：选题是反向操作，脚本写成「A方案：只看图 / B方案：先说习惯」的讲解）。
- **合格**：结构的每个节点都有具体的事和人、货、场：晒过程有起因（带钩子）→ 关键步骤 → 结果；讲故事有困境和转机；教知识有具体的问题和做法；聊观点有观点和至少 3 个论据；用了某一计，那一计的公式在事件里走完。
- **不合格**：只在标题或策略卡里写了计名，正文没有那个结构；节点只是空标题；结构和内容对不上（写「对比改造」却没有改造前后）。
- **出处**：流量型与大流量_修正说明（四）；小黄脚本结构与流量来源；短视频脚本创作全案手册；10.晒过程1（火车节模型）

### S3 像本人说的话
- **判什么**：把口播念出来：像不像他在店里跟一个客人面对面聊天？说的是不是真事？
- **合格**：像聊天：有「我」在做的事、他自己的口头说法，一句接一句有来由；大白话，有画面（具体的动作和东西）；身份对；具体的东西来自档案、访谈或现场拍得到的画面。
- **不合格**：像旁白念稿或说明文：一句一顿的讲解句、「一种做法……另一种做法……」这类结构句、收尾的道理金句（产品方 11-01 判的主因，例：「一种做法，只盯着两边短、顶部高。」「发型图给感觉，日常习惯才是沟通的起点。」）；书面腔、成语、「赋能」「打造」；身份不对；编出来的经历、客户故事、数字（「昨天来了个妈妈」「有人花 3 万做收纳」）。
- **注意**：知识库要求文案有画面感（描述法），但具体要来自真实材料；编出来的具体细节不算画面感。
- **出处**：7.文案写作基础课（画面感 + 力量感）；第13节 口播表现力；三种目的_大流量人设型变现型_说明（素材必须真实）

### S4 有落点
- **判什么**：看完能记住什么？结尾有没有把前面收成一句让人记住的话（一个判断、这个人的记忆点或成交理由）？只抛一句「评论区说说」不算落点（产品方 11-01 判：脚本普遍没有落点）。
- **合格**：看完记住的是「这个人、这家店」的一个具体东西（他的做法、他的判断、店里的人货场），并且和这条的目的对上（大流量：一个让人想转给别人的看点；人设：这个人；变现：一个看得见的成交理由）；结尾只给一个动作。
- **不合格**：结尾只是一句谁都能说的道理（「日常习惯才是沟通的起点」）加一句「评论区说说」，记不住这个人和这家店；没回到这条的目的；同时要好几个动作；大流量结尾推产品；变现的成交理由只写在标题里，画面里看不见。
- **出处**：三种目的_大流量人设型变现型_说明（二.4、三.4、四）；第12节 视频记忆点
