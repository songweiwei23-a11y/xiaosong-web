### 1. 一句话定位
县城老周带你现场看料、试坐，把家具看明白。

### 2. 人设与口吻
- **我是谁**：老板老周，带顾客进工坊看木料的人。  
- **说话什么调**：像在店里跟熟人解释，常用“先别急”“你先看这儿”“按家里平时怎么用来试”；一句只讲一个判断。  
- **会说的一句话**：“这块料你到店可以自己看。”  
- **不会说的一句话**：“不懂家具的人都容易买错。”  

### 3. 说给谁听
- **画像**：28—45岁的县城新婚家庭、换房业主，手机存了家具图，周末想带家人到店摸料、试坐再定。  
- **他最怕什么**：①只看图片，买回家尺寸不合适；②看不懂实木家具的木料和制作；③沙发只看颜色，坐久后才发现不符合家里使用习惯。  
- **他最想要什么**：①到店知道先看什么；②实木家具能看到木料；③沙发能按家里人的日常坐法试坐。  
- **他会搜什么词**：县城实木餐桌、本地家具店、实木家具怎么看木料、布艺沙发怎么选、沙发怎么试坐、家具店地址【县城名】。  

### 4. 内容方向
- **三种视频的配比**：流量型45%（家具误区、家庭场景、工坊冷知识）+ 人设型25%（老周做家具12年的现场判断和工作片段）+ 变现型30%（现场看木料、到店试坐）。  
- **各自的结尾指令**：流量型：“评论区说说，你买家具最怕看不懂哪一点。”；人设型：“关注老周，后面带你看更多家具现场。”；变现型：“带上户型尺寸，到店看料、试坐。”  
- **两套打法各用什么**：四大脚本主打教知识·拆解型、教知识·解题型、晒过程·火车节模型、聊观点·观点立场；起号36计主打第36计·冷知识、第15计·正确做法VS错误做法、第10计·情境还原、第7计·一句话设定故事感。  
- **能长期挖的选题来源**：①当天木料和加工任务，如“这块料最后用在哪”；②实木餐桌尺寸沟通，如“带尺寸看桌子先问什么”；③沙发真实试坐，如“坐两秒少看了哪一步”；④顾客常问问题，如“沙发怎么挑不踩坑”；⑤真实到店沟通。【待确认：先记录顾客原话和允许拍摄的事件】  
- **明确不做的方向**：①纯成品展示和连续报价，拍成线上目录；②虚构顾客故事、老客回购和创业经历，事实不足；③泛装修段子、多人情景剧，与本地家具到店决策无关。  

### 5. 凭什么信你
- **核心卖点**：①自家有木工工坊，实木家具的木料可现场看；②实木家具从木料、加工到成品有真实现场；③布艺沙发可按家庭日常使用场景到店试坐。  
- **可以拍成画面的证据**：老周拿当天真实木料；手掌顺着木纹检查；锯木、打磨、测量等工坊动作；木料与成品局部对应；从门店走进工坊的真实动线；同一人在沙发上坐下、靠背、起身、换位。  

### 6. 怎么拍
- **呈现形式**：视频配音Vlog为主、短口播为辅；先拍木料、工具、打磨、试坐动作，再由老周用一句话解释。  
- **真实条件**：一部手机即可拍；实木内容在工坊，沙发内容在门店试坐区；以老周本人和手部操作出镜为主；【待确认：缺团队人数、老周可出镜时间和剪辑能力，暂不定每周条数】。  
- **视觉调性**：保留木料原色和工坊环境光，镜头以手部近景、木纹特写、人物半身和连续走动镜头为主，不长期拍白墙口播。  

### 7. 记忆点
- **木料开场【待验证】**：实木内容前两秒先拍老周手里当天真实在用的木料，再说“今天这块料，最后会去哪”。  
- **顺木纹动作【待验证】**：每次讲实木家具，先拍手掌顺着木纹走，再切对应成品局部。  
- **工坊原声【待验证】**：前两秒保留锯木、打磨或敲击声，再进入人声；根据评论和完播判断是否固定。  

### 8. 绝对不能说
- 不说“谁家都不如我”“看一眼就能判断所有家具”。  
- 不说“买了永远不会出问题”“一次试坐就能保证适合全家”。  
- 不说未经确认的木料名称、等级、性能、客单价、交期和售后范围。  
- 不把一次顾客体验说成所有家庭都会有同样结果。  
- 不编顾客原话、成交案例、老客回购、售后事件和老周性格经历。  
- 不贬低同行，不制造“别人都不靠谱”的焦虑。  
- 不说“一招挑对沙发”“不用到店也能把家具选明白”。  
- 不用“最好、顶级、百分百、绝对、永久”等绝对化表述。
