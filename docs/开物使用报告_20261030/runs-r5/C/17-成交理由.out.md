## 适用的成交理由

### 1. 有特色 · 10分

**为什么成立**：店里有自家木工工坊，客户能现场看木料；这不是只在门店看成品，还能看到家具从木料到制作的过程。

**怎么拍**：
- 老周把一块准备做餐桌的木料搬到工作台上，镜头从木纹、边角扫到工坊里的设备。
- 客人进店问“这桌子是什么木头”，老周直接带他走进工坊，指着正在加工的木料讲解。

### 2. 专业强 · 9分

**为什么成立**：老板老周做家具12年，且一直在做实木家具和布艺沙发；木料辨认、家具挑选本身就是账号已有的内容基础。

**怎么拍**：
- 老周拿两块不同木料放在桌上，用手摸纹理、看切面，讲“看实木先别急着看颜色，先看这里”。
- 在沙发区拍客户常问的问题：“布艺沙发怎么挑不踩坑？”老周从面料、坐感、拆洗等实际观察点逐一演示。

### 3. 质量好 · 8分

**为什么成立**：自家有木工工坊，木料能够现场看，家具制作过程也能被拍出来；相比只展示成品，更容易让客户看到材料和制作环节。

**怎么拍**：
- 镜头拍木料进工坊、木工处理木料、半成品餐桌打磨，再切到门店里的成品餐桌。
- 拍一张餐桌的桌面、桌腿连接处和边角细节，老周用手指着位置说：“这几个地方，进店看实木桌别跳过。”

### 4. 实在不坑 · 7分

**为什么成立**：客户可以现场看木料，也能看到自家工坊在制作，材料和制作环节相对更直观；这个理由适合通过“看得见”来建立信任，不宜只靠嘴说。

**怎么拍**：
- 客人问“这套桌椅里面到底是什么料”，老周不直接回答，带着镜头去看对应木料和加工中的半成品。
- 拍老周把木料、半成品和门店成品放在同一条视频里，对着镜头说：“买实木家具，别只看摆在店里的这一面。”

## 不太适用

- 颜值高（5分）：目前没有门店环境、产品设计风格或客户拍照反馈的具体依据，不能直接主打颜值。
- 效果好（4分）：没有客户入住后的摆放效果、改造前后对比或使用反馈，暂时缺少证明。
- 选择多（5分）：已知在卖实木餐桌椅和布艺沙发，但没有明确款式、尺寸、颜色或库存数量的依据。
- 便利性（4分）：只知道门店在县城本地，没有送货、安装、距离近或一站式服务等具体信息。
- 老板好（5分）：老周是本地人、做家具12年，但没有能体现待人方式或处理客户问题的真实事件。
- 服务好（4分）：没有售前挑选、送货安装、售后处理等服务细节，暂时不能作为卖点。
- 案例多（3分）：没有客户案例、成交数量或真实使用场景的资料支撑。
- 有面子（4分）：实木家具可能有这类消费需求，但没有高端设计、品牌背书或客户招待场景的事实依据。
- 性价比（3分）：没有价格、配置对比或套餐信息，不能判断同类产品中的价格优势。
- 生意好（2分）：没有客流、订单、排队或复购等事实，不能硬拍“生意好”。
- 好评多（1分）：没有客户评价、转介绍或回访记录，不能使用。
- 规模大（3分）：有自家木工工坊，但没有门店面积、员工数量、设备规模或多店经营等依据。
- 稀缺唯一（6分）：现场看木料和自家工坊在县城家具店中有辨识度，但没有证据证明本地只有这一家能做到，不能使用“唯一”表述。

## 建议主打

建议主打“有特色 + 专业强 + 质量好”。先用“现场看木料、自家工坊”把人带进视频，再由老周12年的木料辨认和挑选经验建立信任，最后用木料、制作过程和成品细节，让客户自己看见家具是怎么做出来的。
