- **一句话结论**：这稿子可以拍，主题和视角都清楚；拍摄前建议修正一处相互矛盾的景别提示，并通过试录确认成片节奏。
- **本轮改动范围**：只修有依据的问题句；开头、口播、结尾、段落顺序及其余镜头内容原样保留。
- **值得保留**：
  - “同一张沙发，只看陈列样子，和想清家里怎么用，挑法不一样。”比较对象和维度清楚，始终在讲挑选顺序。
  - “下班回家，你习惯坐哪儿？父母来时，坐哪儿？”用不同使用场景带观众进入客厅视角，不冒充老周的家庭经历。
  - “再坐下、靠背、换个位置”，配合沙发周边空间的画面，能把抽象的“怎么用”落到可拍的动作上。

## 3. 问题清单

🟡 **建议改｜拍摄标注缺失**

【问题】镜头五拍摄提示：“第一段用中景，第二段切近景，避免相邻景别连续切换。”

→【为什么不行】前半句要求中景切近景，后半句又要求避免相邻景别切换，执行时容易产生歧义。

→【改成】“第一段用中景，第二段切近景，切换时注意画面衔接。”

**时长执行建议：**镜头区间合计为目标时长，但每段口播与动作是否能落在对应区间，需要试录判断。若口播较快，优先利用原有坐下、靠背、换位置及现场声音留出呼吸；若某段超时，先调整语速和剪辑衔接，不必为了凑时长新增情节。

## 4. 优化后的完整脚本

### 【镜头1】0—7秒｜开场钩子

- **画面**：中景。老周站在门店布艺沙发旁，手扶沙发靠背，正对镜头说话。镜头从沙发整体轻推到人物近景。
- **台词**：  
  第一次给换房后的客厅挑沙发，先想好家里平时是谁坐得最多。
- **情绪**：平稳直接，像把观众拉进“准备换房”的具体场景。
- **拍摄/收音要点**：沙发周边提前整理干净；手机竖拍，人物占画面三分之二，收音靠近人物。

### 【镜头2】7—13秒｜抛出对比

- **画面**：镜头横移扫过沙发颜色、靠垫和整体陈列，再切到老周看向沙发侧面的画面。
- **台词**：  
  同一张沙发，只看陈列样子，和想清家里怎么用，挑法不一样。
- **情绪波点**：⚡从“看样子”转到“怎么用”，形成认知转折。
- **拍摄/收音要点**：横移速度慢，画面重点是沙发整体，不要拍成产品硬推。

### 【镜头3】13—20秒｜A方案：只看陈列

- **画面**：老周坐在沙发上，简单看一眼靠垫、扶手，再起身。
- **台词**：  
  第一种，先进店看颜色、款式，坐一下，觉得差不多。
- **情绪**：口气自然，不批评观众，像还原一个常见的挑选过程。
- **拍摄/收音要点**：中景拍完整坐下和起身动作；保留坐垫受力的现场声音。

### 【镜头4】20—25秒｜A方案的遗漏

- **画面**：镜头切换为客厅活动视角。拍沙发前方、两侧及周边空出的区域；老周站在沙发边，手指向不同位置。
- **台词**：  
  放进客厅后，谁会常坐、平时怎么靠、周边留不留活动位置，又得重新想。
- **情绪波点**：😓把“门店看着合适”和“放进家里怎么用”之间的落差说出来。
- **拍摄/收音要点**：不要用尺寸线、数字或“标准距离”等未经确认的信息；只拍得到什么说什么。

### 【镜头5】25—34秒｜B方案：先过一遍生活场景

- **画面**：老周坐到沙发一侧，模拟下班回家坐下；随后换到另一侧坐下。两个坐法用机位变化区分，不需要换服装或找演员。
- **台词**：  
  第二种，先把家里的画面过一遍。  
  下班回家，你习惯坐哪儿？  
  父母来时，坐哪儿？
- **情绪**：语速放慢，连续提问，让观众自动代入自己家。
- **拍摄/收音要点**：第一段用中景，第二段切近景，切换时注意画面衔接。

### 【镜头6】34—45秒｜B方案：把动作和空间一起看

- **画面**：老周靠背、换位置、起身，再从沙发前方走过；镜头跟随动作，带到周边活动区域。
- **台词**：  
  孩子会不会在周边活动？  
  客厅还要留哪块活动位置？  
  再坐下、靠背、换个位置，看看这些动作在同一张沙发上顺不顺。
- **情绪波点**：💡从“挑一张沙发”推进到“把它放进一家人的日常里想”。
- **拍摄/收音要点**：用跟拍镜头即可，不必复杂运镜；动作按实际可拍范围完成，注意地面和通道安全。

### 【镜头7】45—52秒｜差异揭示

- **画面**：近景。老周坐在沙发上，手轻拍坐垫或扶手，停顿后看向镜头。
- **台词**：  
  这就是为什么，挑沙发别只盯着陈列那一面。
- **情绪波点**：⚡语气收紧，作为整条视频的观点落点。
- **拍摄/收音要点**：这一句前留半秒停顿；背景不要有嘈杂人声。

### 【镜头8】52—60秒｜结尾互动

- **画面**：镜头拉到中景，老周起身站在沙发旁，画面保留沙发和周边空间。
- **台词**：  
  先想清楚家里怎么用，再看眼前这张沙发。  
  你家沙发平时谁坐得最多？评论告诉我。
- **情绪**：语气放松，把问题交给评论区。
- **拍摄/收音要点**：最后一句看镜头说完，停留一秒再结束，方便添加字幕。
