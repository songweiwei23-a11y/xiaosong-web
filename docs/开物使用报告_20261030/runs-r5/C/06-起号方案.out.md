# 🚀 起号方案

## 📌 先说结论

- **建议主攻：第36计·冷知识**
- **主攻理由：**老周有真实木料、木工工坊和成品家具，能用一部手机拍出“成品—木料—加工位置”的现场关系；这个打法不需要演员、不需要顾客配合，也不用编故事。
- **备选：**
  1. **第15计·正确做法VS错误做法**：用于布艺沙发试坐和家庭购买误区。
  2. **第10计·情境还原**：有真实顾客到店沟通并获得授权时使用。
  3. **第4计·借物喻人**：拿到老周真实经历后，用于补人物记忆点。
- **明确不做：**
  1. **第35计·街头采访**：档案没有拍摄人员、采访对象和外拍资源，容易变成泛家居话题，接不住本地到店需求。
  2. **第30计·角色扮演**：当前没有演员和固定剧情资源，硬拍会削弱老周、工坊和家具本身的真实感。
- **多久能看出跑没跑通：**先按30天、20条内容完成第一轮判断。最终参考线是：**零粉到一千粉，并且连续发布后流量表现逐步稳定**。这不是承诺时限，判断还要结合目标用户评论、主页访问和有效咨询。

## 🧮 起号期内容配比

### 1. 作用配比

| 内容目的 | 占比 | 20条对应数量 | 核心任务 |
|---|---:|---:|---|
| 流量型 | 45% | 9条 | 让陌生人因为“买家具、看木料、家庭使用”停下来 |
| 人设型 | 25% | 5条 | 让观众记住老周做家具12年后的判断方式 |
| 变现型 | 30% | 6条 | 让观众知道实木家具能现场看木料，布艺沙发能到店试坐 |

这个比例直接沿用已经确定的定位。流量型仍然是主力，但不能把账号拍成只讲木料的知识号；人设内容补老周，变现内容同时覆盖实木家具和布艺沙发。

### 2. 每种内容怎么拍

#### 流量型：45%

- **出发点：**
  - 人：准备成家、换房的县城家庭；
  - 货：实木餐桌椅、布艺沙发；
  - 场：自家木工工坊和门店；
  - 爆款元素：人群、反差。
- **采用形式：**第36计·冷知识。
- **配套脚本：**教知识·解题型。
- **结构：**家庭购买场景→一个常见误区→现场木料或家具证据→家庭到店时的确认动作。
- **结尾指令：**评论区说说，你买家具最怕看不懂哪一点。

流量型不讲地址、不讲价格、不引导到店，只让陌生人先对家具选择产生兴趣。

#### 人设型：25%

- **出发点：**
  - 老周本人；
  - 做家具12年的职业经历；
  - 本地老板在工坊和门店里的真实判断；
  - 只拍已经发生或正在发生的事情。
- **采用形式：**第4计·借物喻人，或第7计·一句话设定故事感。
- **配套脚本：**聊观点·论证型、讲故事·平凡英雄型。
- **结构：**真实工作事件→老周的处理方式→为什么这样判断→老周自己的落点。
- **结尾指令：**关注老周，后面带你看更多家具现场。

目前没有老周创业低谷、顾客纠纷或家庭故事资料，不拍虚构故事。需要故事时，先补问一个真实事件：**“有没有哪次顾客准备买家具，但你先让他回去确认尺寸、使用人数或木料问题？”**

#### 变现型：30%

- **实木家具出发点：**
  - 人：准备买实木家具的本地家庭；
  - 货：实木餐桌椅；
  - 场：自家木工工坊；
  - 成交理由：木料可以现场看。
- **布艺沙发出发点：**
  - 人：新婚家庭、换房业主；
  - 货：布艺沙发；
  - 场：门店沙发区；
  - 成交理由：能到店真实试坐。
- **采用形式：**
  - 第15计·正确做法VS错误做法；
  - 第10计·情境还原。
- **配套脚本：**教知识·解题型、晒过程·事件体验。
- **结构：**具体购买问题→错误判断的遗漏→现场演示→适用条件→一个到店动作。
- **结尾指令：**带上户型尺寸，到店看料、试坐。

每条只突出一个成交理由。实木家具拍“现场看料”，布艺沙发拍“到店试坐”，不能一条视频里两个都讲。

### 3. 过线之后怎么调整

达到“零粉到一千粉、流量表现逐步稳定”后，内容调整为：

- 流量型：40%
- 人设型：30%
- 变现型：30%

补充内容：

1. 增加老周真实沟通、工作边界和判断过程；
2. 把评论区反复出现的问题做成固定栏目；
3. 实木家具继续保留工坊看料；
4. 布艺沙发继续保留真实试坐；
5. 暂不扩展到泛装修、泛生活内容。

### 4. 和既定定位怎么对上

- **主力形式：**晒过程，占主要画面来源；
- **第二形式：**知识，负责把木料和试坐讲明白；
- **辅助形式：**观点、故事，负责建立老周的人物记忆；
- **主系列：**《老周带你进工坊看料》；
- **补充系列：**《沙发别只看颜色》《老周今天怎么处理这个问题》。

主攻打法不是另起一套，而是把“工坊、木料、成品家具”拍成固定入口，再用布艺沙发试坐补齐经营品类。

# 🎯 主攻打法：第36计·冷知识

## 1. 为什么是老周能拍的

1. **出镜人明确：**老板老周本人，不需要店员或演员。
2. **场景现成：**门店和自家木工工坊都在档案中确认过。
3. **货品现成：**实木餐桌椅、木料和加工过程都能进入画面。
4. **拍摄门槛低：**按单人手机拍摄设计，镜头只需要老周、木料、成品和工坊动作。
5. **内容来源稳定：**选家具常识、木料辨认、工坊过程本来就是已有方向。
6. **不依赖虚构事实：**只讲镜头里看得到的木料、成品对应关系和顾客常问问题。
7. **适合起号：**陌生人不认识老周，但能先被“买家具时到底看什么”吸引。

团队人数和设备档案没有提供，第一轮统一按“老周一人、手机拍摄、门店与工坊取景”执行。若现场有第二个人，只负责固定机位和收音，不让其扮演顾客。

## 2. 结构公式

**反常识结论 → 现场木料或成品证据 → 解释这个证据与家具的关系 → 家庭购买时怎么确认 → 评论互动**

套到县城木工家具店：

- **反常识结论：**买实木家具，不能只隔着屏幕看成品图；
- **现场证据：**老周拿出真实木料，拍木纹、厚度、加工位置和对应成品；
- **解释关系：**说明观众现场能看到什么，不能看到什么；
- **家庭应用：**告诉准备买家具的人，到店要带什么问题来问；
- **互动出口：**只让观众评论一个自己看不懂的问题。

不能把“看木料”扩大成“看一眼就能判断家具全部品质”。镜头拍到什么，结论就说到什么范围。

## 3. 配什么脚本讲

- **第36计·冷知识：**负责事件怎么发生——老周拿木料、走工坊、对应成品。
- **教知识·解题型：**负责话怎么讲——家庭买家具遇到什么问题，现场怎么确认。
- **补上的内容：**把“看料”从一句卖点变成可观察的现场过程，同时保持流量型内容不带成交指令。

## 4. 前3条具体拍什么

### 第1条

**标题：**《准备买实木餐桌的人，先别只看颜色》（人群）

**拍摄要点：**

1. 第一帧拍成品餐桌桌面，老周手掌从画面外按住桌面；
2. 老周第一句：  
   **“准备买实木餐桌，先别只盯着颜色看。”**
3. 镜头切到工坊里的真实木料；
4. 老周分别拍木料表面、加工位置和对应的成品位置；
5. 只讲三件镜头能证明的事：成品能看到什么、木料能看到什么、到现场要问什么；
6. 结尾：  
   **“你买家具最怕看不懂哪一点，评论区说说。”**

**停留看点：**把观众熟悉的“看成品”切换成工坊里的“看木料”。

### 第2条

**标题：**《一张实木餐桌摆出来之前，老周先带你看后面的木料》（反差）

**拍摄要点：**

1. 先拍成品餐桌，不露老周全脸；
2. 老周把镜头从门店带到工坊；
3. 拍真实木料和正在进行的加工动作；
4. 老周说清“这一步正在看什么”，不说未经确认的木材性能；
5. 再回到成品餐桌，拍木料与成品的对应位置；
6. 结尾仍然只引导评论。

**停留看点：**观众以为要看成品，画面却先带他走进工坊。

### 第3条

**标题：**《换房准备买家具，现场先看木料还是先看尺寸？》（人群）

**拍摄要点：**

1. 第一帧拍老周拿着卷尺和木料，二选一的画面直接出现；
2. 老周第一句：  
   **“换房买家具，先别急着只看款式，先把尺寸和木料问题分开看。”**
3. 用同一间门店现场演示：
   - 尺寸要确认什么；
   - 木料要现场看什么；
   - 两者不能混成一个问题。
4. 不编造具体户型、金额和顾客案例；
5. 结尾：  
   **“你家现在最卡的是尺寸，还是材料？评论区说一个。”**

**停留看点：**把换房家庭常见的“款式选择”拆成两个具体问题。

## 5. 边界

- 不用未经确认的木材名称、检测结论和性能结论；
- 不把一次现场观察说成所有家具都适用；
- 不把“现场能看木料”说成“看一眼就能判断全部质量”；
- 不拍虚构顾客，不替顾客写原话；
- 不用同行、客户或其他老板做反面角色；
- 不在流量型内容里报价、留联系方式或引导到店；
- 不把同一张桌子换角度、换摆法拍成“前后效果对比”；
- 需要做对比时，必须保持人物和场景一致，变化的是店里实际出售的家具。

# 🔄 备选打法

## 备选一：第15计·正确做法VS错误做法

### 什么情况下切过去

当评论区连续出现“布艺沙发怎么挑”“坐多久才知道合不合适”“家里人意见不一样怎么办”等问题时，切到这套打法。

### 怎么套到这个号

同一个人、同一门店、同一拍摄位置，先演示只坐一下，再演示按照家庭真实坐姿进行试坐。重点不是改变坐姿让同一张沙发变好，而是让观众知道：购买布艺沙发时，现场试坐是确认这件商品是否适合自己的步骤。

### 配套脚本

**教知识·解题型**

结构：

**快速下决定的错误示范 → 漏掉的使用问题 → 门店试坐的正确步骤 → 哪些家庭更需要现场确认 → 到店试坐**

### 为什么老周能拍

- 门店已有布艺沙发；
- 老周本人可以演示；
- 不需要顾客配合；
- 试坐动作本身就能形成画面；
- 能补齐账号不能只被看成实木家具店的问题。

### 换掉条件

连续3—5条都只有泛泛的“坐一坐”，没有真实家庭问题、评论和主页访问，就停掉这套拍法，先回到具体的客厅尺寸、家庭成员和使用场景。

## 备选二：第10计·情境还原

### 什么情况下切过去

出现真实顾客到店，并且获得出镜或录音授权；或者老周能明确复盘一件已经发生的真实咨询。

### 怎么套到这个号

把一次到店问题完整拍下来：

**顾客提出购买需求 → 老周追问使用场景 → 带顾客看实木家具或试坐沙发 → 根据现场信息继续沟通。**

没有授权时，不把演示拍成顾客案例，改成老周面对镜头复盘真实问题。

### 配套脚本

**晒过程·事件体验**

结构：

**真实到店问题 → 老周提问 → 现场看料或试坐 → 顾客实际反馈 → 下一步沟通**

### 为什么老周能拍

- 门店是现成的服务场景；
- 实木家具和布艺沙发都需要现场确认；
- 老周本人就是沟通主体；
- 内容能展示实际过程，不依赖长口播。

### 换掉条件

如果连续出现顾客不愿授权、现场噪声影响收音或无法完整记录沟通，就不拍顾客过程，改为老周复盘已确认的真实问题。

---

## 备选三：第4计·借物喻人

### 什么情况下切过去

前采拿到老周真实的职业经历、工作边界或一次具体处理事情的事件后使用。

### 怎么套到这个号

从一块真实木料的状态讲起，再落到老周做家具时的判断方式。例如，木料不能只看表面，老周为什么形成“先看清楚再给建议”的工作习惯。不能从木料硬编人生故事。

### 配套脚本

**聊观点·论证型**

结构：

**真实木料事件 → 老周的判断 → 这次判断和他工作经历的关系 → 老周的个人落点**

### 为什么老周能拍

- 木料是店里现成的实物；
- 老周有做家具12年的真实职业经历；
- 一人一机即可拍；
- 能把“老板本人”从讲产品推进到讲做事方式。

### 换掉条件

如果拿不到具体真实事件，只剩“木头像人生”这类空泛表达，就停用，不拍虚构故事。

# 🧪 怎么测

## 1. 一次只改一个变量

第36计·冷知识的前5条固定：

- 同一个出镜人：老周；
- 同一个大场景：工坊或门店；
- 同一种拍法：成品→木料→现场解释；
- 同一个结尾：评论一个看不懂的问题；
- 每条只改一个核心变量：人群、木料问题或家具部位。

不能同时换标题、场景、时长、剪辑节奏和结尾，否则判断不出问题出在哪。

## 2. 每计测几条

- 第36计·冷知识：先测5条；
- 第15计·正确做法VS错误做法：测3条；
- 第10计·情境还原：有真实事件后测3条；
- 第4计·借物喻人：拿到真实经历后测3条。

样本不足3条，不否定打法。

## 3. 看什么指标

### 流量型

- 非关注用户播放占比；
- 前3秒流失；
- 完播情况；
- 评论是否出现具体购买问题；
- 新增关注和主页访问。

### 人设型

- 主页访问；
- 关注率；
- 评论里是否出现“老周”“工坊”“想继续看”等人物记忆；
- 观众是否开始主动提问老周的判断。

### 变现型

- 主页访问；
- 评论中的地址、看料、试坐问题；
- 私信或到店咨询；
- 咨询是否明确指向实木家具或布艺沙发。

## 4. 什么信号算这计行

第36计·冷知识满足以下条件时继续：

- 连续5条里，有多条能吸引非关注用户；
- 评论从“不错”变成具体家具问题；
- 主页访问开始增加；
- 观众能复述“老周带人看木料”这个栏目印象；
- 至少能连续找到新的真实木料、加工或家具问题。

## 5. 什么信号算换掉

- 连续5条前3秒流失都明显；
- 观众只问价格，不关心木料和家具判断；
- 工坊素材重复，无法拍出新的现场信息；
- 播放有了，但目标家庭评论和主页访问没有增长。

换掉时先改开篇和人群入口，不直接否定整个账号定位。

# 📅 30天节奏

按老周还要经营门店的现实，采用**每周2次集中拍摄、每次拍3条左右、30天完成20条左右**的节奏。拍摄时优先批量拍同一场景，减少来回布置。

## 第1—7天：完成主打法样片

### 任务

- 拍第36计·冷知识5条；
- 其中3条实木家具，2条围绕家庭购买问题；
- 固定工坊和门店两个场景；
- 每条只讲一个问题。

### 交付物

- 5条成片；
- 每条记录标题、人群、拍摄场景、木料或家具部位；
- 发布后记录前3秒流失、完播、评论和主页访问。

## 第8—14天：保留主打法，补布艺沙发线

### 任务

- 第36计·冷知识3条；
- 第15计·正确做法VS错误做法2条；
- 实木家具和布艺沙发都必须出现；
- 沙发内容统一落在真实试坐，不拍纯静态展示。

### 交付物

- 5条成片；
- 实木家具和布艺沙发各自的评论问题清单；
- 判断观众更容易停留在木料问题还是家庭试坐问题。

## 第15—21天：补老周的人物内容

### 任务

# 📊 跑不通先查哪里

## 情况一：曝光少，前3秒就流失

- **先怀疑：**标题和首帧太像家具展示，陌生人不知道自己为什么要看。
- **下一步实验：**保持同一个木料和场景不变，只重写5个开头，分别从“准备买实木家具的人”“换房家庭”“只看成品图”三个入口切入。

## 情况二：有人看，但完播差

- **先怀疑：**老周在讲术语，现场证据出现太晚，或者一条视频塞了两个问题。
- **下一步实验：**把木料、成品和关键动作放到前3秒；每条只保留一个问题，删掉重复解释。

## 情况三：播放有增长，但没有主页访问和有效咨询

- **先怀疑：**流量内容和门店品类连接不够，或者变现内容没有把“现场看料”和“到店试坐”拍出来。
- **下一步实验：**保留原来的流量开头，另拍3条变现内容：
  - 1条只拍实木家具现场看料；
  - 1条只拍布艺沙发真实试坐；
  - 1条拍老周根据家庭使用问题做现场判断。  
  三条分别使用一个行动指令，不在同一条里同时推两个品类。
