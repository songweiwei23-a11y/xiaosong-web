## 2. 📊 节奏自检

- 景别分布：特写 2 个 / 近景 2 个 / 中景 6 个 / 全景 6 个 / 远景 2 个
- 特写占比：12%（用于呈现扶手、坐垫等与“怎么坐”直接相关的细节，不抢口播信息）
- 运动镜头占比：6%（仅镜头2使用摇镜，适合单人手机执行）
- 最长镜头：6s（镜头1、5、12分别保留开场场景、活动视角和完整坐靠换位动作）
- 开场 3 秒内镜头数：1 个
- 总时长：60s
- 是否存在同一景别连续超过 3 个：否

## 4. 🧰 拍摄清单

- **必备**：手机、手机支架或三脚架、干净抹布、充电宝。  
- **加分项**：  
  - 领夹麦：解决门店空旷、环境杂音导致口播不清的问题。  
  - 小补光灯：阴天或店内偏暗时，补亮老周正脸和沙发靠背纹理。  
- **道具与场地**：  
  - 一组整理干净的布艺沙发；  
  - 靠垫、扶手区域保持整洁；  
  - 沙发前方和两侧预留可走动通道；  
  - 地面可用不显眼的小标记确定“活动视角”手机位置；  
  - 拍摄前关闭或避开持续噪声较大的设备。  

## 5. ⚠️ 这条片子最容易翻车的 3 个地方

- 【“换个视角”只换了机位】会变成普通沙发口播，看不出“先看陈列”和“先想怎么用”的区别 →【怎么避】镜头5、6、10、11必须拍到沙发前方、侧边和通道，手机不要始终只对着老周。  
- 【把门店演示拍成真实家庭故事】会让“下班回家、父母来时、孩子活动”像在编老周的家庭经历 →【怎么避】全程按“模拟使用场景”拍，老周只做坐下、靠背、换位置、走动等通用动作。  
- 【沙发区周边太乱】观众看不清通道，活动空间这个核心信息就失效 →【怎么避】开拍前清走沙发前方和两侧的杂物，镜头5和11先检查画面里是否能一眼看到周边区域。
