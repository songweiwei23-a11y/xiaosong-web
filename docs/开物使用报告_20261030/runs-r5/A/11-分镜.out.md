## 📊 节奏自检

- 景别分布：特写 12 个 / 近景 4 个 / 中景 3 个 / 全景 1 个 / 远景 1 个
- 特写占比：57%（本条核心是食材备料状态、下锅声音和表面变化，特写承担证据作用）
- 运动镜头占比：0%（单人单手机拍摄，全部固定机位更稳，也方便做同条件对照）
- 最长镜头：3s（备料动作、下锅声音和翻炒状态需要完整保留，避免快剪掩盖判断过程）
- 开场 3 秒内镜头数：2 个
- 总时长：60s
- 是否存在同一景别连续超过 3 个：是。镜头 6—8 连续使用特写，用于完整呈现备料动作和判断点；镜头 11—15 连续使用特写，用于对照两份食材的下锅与翻炒状态。
- 压缩预案：本表按可执行口播节奏已排入全部原台词。若现场口播明显超时，优先删减镜头 7 的“看着只是多动一下手，但我不是随便做。”以及镜头 17 的“至于差别是什么，现场炒出来再说，不提前替它下结论。”；其余台词保留，避免破坏“冷知识”的判断逻辑。

## 🧰 拍摄清单

- **必备**：手机、手机支架或三脚架、干净抹布、当天实际使用的锅铲、刀具、备料容器、两份同批食材。
- **加分项**：  
  - 领夹麦：用于镜头 3、9、20 的口播，减少油烟机和锅铲声干扰。  
  - 小补光灯：用于备料台食材特写，解决室内顶光造成的手部阴影。  
  - 备用手机或录音设备：可单独贴近锅边收录下锅“滋啦”声；没有也可直接用主手机收音。
- **道具与场地**：干净备料台、当天实际出摊灶台、同一批食材、标记“刚切好”“完成准备后”的剪辑字幕位置、当天真实完成出品。

## ⚠️ 这条片子最容易翻车的 3 个地方

- 【备料动作未确认】镜头拍完才发现出镜人说不清“在看什么、做到什么状态停” →【怎么避】开拍前先让本人用当天实际操作补全三个【待确认】内容，再录口播。  
- 【对比条件不一致】两次下锅的油量、火力、调料或翻炒方式不同，观众无法判断差异来自备料动作 →【怎么避】两份食材同批分开，使用同一口锅，并尽量让两次操作保持一致；做不到就取消差异结论，只拍一份真实备料流程。  
- 【下锅声音没录到】油烟机、环境说话声盖住关键“滋啦”声，冷知识的观察点无法兑现 →【怎么避】下锅时暂停口播和配乐，手机固定在安全距离收现场声；后期先保留锅声，再叠低音量音乐。
