# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

这是典型的**本地晚餐、夜间餐饮生意**：顾客不是提前很久规划，而是在下班前、接完孩子后、朋友约饭时，临时决定“今晚去哪吃”。因此，短视频的任务不是把所有菜都讲明白，而是让南乐本地人在这个时刻能想起这家店。

餐饮利润通常不靠一项低门槛产品单独支撑，而是靠一桌人的完整点单结构：有人因一元火锅愿意第一次进来，但是否形成有效消费，要看顾客会不会继续点川味串串火锅、川味烧烤、川菜及店内其他真实售卖品。  
所以，一元火锅适合做“降低第一次进店顾虑”的入口，不能长期拍成“只要便宜就值得来”的价格广告。否则会吸引大量只问价格、不形成复购的人。

这行真正卡获客成本的地方有两个：

1. **顾客刷到后记不住。**  
   同城餐饮号大多是菜品特写、门头、团购字幕、老板招呼，画面热闹但没有记忆锚点。用户晚上要吃饭时，想不起是哪一家。

2. **第一次到店前有小顾虑。**  
   顾客会想：一元火锅怎么点？辣不辣？除了串串还有什么？带孩子或朋友去能不能吃？这些问题没人提前讲清，就容易停在“刷到过”而不是“去一次”。

我推测，这家店的高频消费时段是晚餐和夜间；下午四点出摊前后的备料、开灶、第一轮出餐，是最适合稳定生产内容的时间线。午间是否经营、是否有外卖、是否存在高峰排队，均待确认，不能提前写成卖点。

同行常犯的错，是把“菜多、价格低、老板忙”当成内容本身。顾客看到这些，只会觉得又是一家餐饮店。这个号真正该占的位置是：**成都厨师每天四点在南乐开灶，把本地人的一顿川味晚饭做出来。**

**一句话定位：成都厨师四点开灶做川味串串火锅、川味烧烤、川菜，管南乐晚饭。**

## 变现全景

### **现在能卖什么**

1. **川味串串火锅**  
   适合下班晚饭、朋友小聚、多人围桌吃饭。画面上最好拍“拿串—下锅—出锅”的完整过程，减少第一次尝试者“不知道怎么点”的顾虑。

2. **川味烧烤**  
   适合晚间加餐、朋友聊天、想吃点有烟火气的顾客。它不能只拍成品盘子，要拍烤炉、翻烤、刷料、出炉等动作，让“现烤”成为能看见的理由。

3. **川菜**  
   适合家庭晚饭、带孩子、招待亲友，以及不想只吃串串或烧烤的人。它承担的是“多人一桌吃什么都能接住”的消费场景，不应被短视频忽略。

4. **一元火锅首次尝试入口**  
   这不是独立的长期主角，而是降低首次进店门槛的机制。它必须讲清真实规则：哪些品类适用、怎么点、是否有最低消费或搭配要求，均待店内确认后再拍。

### **各自的客单价与毛利大致区间**

门店没有提供实际菜单、进货成本、人工和房租数据，**不能替店里编客单价或毛利率数字**。目前只能先按经营结构判断：

- **川味串串火锅**：通常靠多人点单、串品数量和搭配消费形成单桌收入；
- **川味烧烤**：通常依赖加点、晚间续单和多人分享；
- **川菜**：通常承担桌餐中的补充点单，提高一桌人“坐下来吃正餐”的完整度；
- **一元火锅**：承担首次到店转化，不宜单独作为利润判断依据。

**待确认，优先补三项：**  
1. 顾客一桌实际点单区间；  
2. 一元火锅的真实点单规则；  
3. 串串、烧烤、川菜里复点率较高的具体品项。  

没有这三项，后续团购、套餐、价格表达都不能定。

### **决策难度**

整体属于**低到中等决策**：

- 看完视频就可能想去，但通常不会立刻付款；
- 顾客会先看主页确认位置、营业时间、品类和评论；
- 再等到“今天晚上吃什么”的具体时刻，和同事、家人一起决定；
- 首次进店门槛不高，但复购取决于实际口味、出餐体验和是否方便点单。

因此，账号不能只做促销，也不能只做后厨纪录片。要同时完成“让人想起你”和“让人敢进来”的两件事。

## 主推产品

**主推：一元火锅的首次到店体验。**

这不是把川味串串火锅、川味烧烤、川菜分出高低，也不是把其中任何一个降成配角；它只是现阶段最适合做**首次转化入口**的表达方式。

选择它有三个原因：

1. **信任门槛最低。**  
   新号没有老顾客评论、案例积累和稳定认知时，陌生人最怕的不是“不知道这家有没有菜”，而是“我去了会不会点不明白、花得不值”。低门槛机制更容易让人愿意第一次到店。

2. **能自然带出三类品类。**  
   顾客进店后，川味串串火锅、川味烧烤、川菜需要轮流接住不同人的需求。短视频不能只举价格牌，而要拍清楚“第一次怎么点、同行的人还能吃什么”。

3. **生产成本低，拍摄稳定。**  
   每天下午四点开灶后，就能拍备料、拿串、下锅、烤制、出川菜等真实动作，不依赖演员、复杂剧情或虚构顾客反馈。

明确不做：  
- 不把“一元”拍成全账号唯一记忆点；  
- 不承诺“花很少的钱就能吃得怎样”；  
- 不在未确认规则前，用模糊话术吸引顾客到店后再解释。

## 成交路径

### 1. 第一次接触看到什么

顾客先刷到的，应是“成都厨师下午四点开灶”的现场，而不是价格海报。

例如：  
- 空锅点火；  
- 手上正在穿的串；  
- 烤炉上的翻烤动作；  
- 一道川菜刚下锅的瞬间；  
- 厨师说一句真实判断：“这一步要是急了，晚上这一锅味道就不对。”

**这一环节会流失的人：**  
只想看纯搞笑、与吃饭无关内容的泛流量。  
**为什么允许流失：**  
本地餐饮号不需要讨好所有人，先留下会在南乐吃晚饭的人。

### 2. 靠什么产生兴趣

兴趣不只靠“便宜”，而是靠三层信息同时建立：

- **身份反差**：成都厨师来到南乐掌勺；
- **场景共鸣**：下班、接孩子、朋友约饭时，晚饭已经有人开始准备；
- **降低顾虑**：第一次来的人，知道川味串串火锅、川味烧烤、川菜分别怎么选。

**这一环节会流失的人：**  
对川味、晚饭场景完全无需求的人。  
**为什么会流失：**  
这是正常筛选，强留泛人群只会让账号播放和到店脱节。

### 3. 在哪里沉淀

沉淀主阵地是**主页 + 到店前私信或评论问答**，不建议起号期把路径拉得太长。

主页必须让顾客一眼确认四件事：

- 这是成都厨师本人掌勺；
- 卖川味串串火锅、川味烧烤、川菜；
- 下午四点开灶；
- 地址和营业信息以店内真实情况为准。

评论区和私信只回答真实规则，例如：  
“第一次来怎么点？”  
“带孩子能吃什么？”  
“烧烤和川菜有没有？”  
“一元火锅具体怎么算？”

**这一环节会流失的人：**  
问完规则仍觉得不适合自己的人。  
**为什么会流失：**  
提前讲清规则，比顾客到店后产生误解更重要。

### 4. 临门一脚是什么

临门一脚不是催单，而是解决“今晚去不去”的最后一个问题：

- 下班后想吃点热乎的；
- 朋友约饭不想只吃一种；
- 接完孩子不想回家再做饭；
- 第一次来不知道怎么点。

最合适的行动是：  
**“下午四点后，想吃川味晚饭就到店。”**

**这一环节会流失的人：**  
距离远、时间不合适、口味偏好不匹配的人。  
**为什么会流失：**  
餐饮到店有天然地域和时段限制，不能靠短视频承诺覆盖所有人。

## 信任证据清单

以下证据必须拍成画面，不能只写在字幕里。

| 可拍证据 | 证明什么 | 当前状态 / 怎么攒 |
|---|---|---|
| 厨师本人下午四点开始备料、开灶 | 真实、本人掌勺 | 已有硬事实，可固定拍 |
| 川味串串火锅从备料到下锅的一个完整环节 | 手艺、真实出品 | 可立即拍，但先选一个固定动作 |
| 川味烧烤的翻烤、刷料、出炉过程 | 现做过程、制作能力 | 可立即拍，避免只拍成品 |
| 川菜下锅、翻炒、出餐的关键动作 | 厨师能力、品类真实存在 | 可立即拍，每周至少保留一个川菜主角 |
| 新顾客第一次点单时最常问的问题 | 降低首次消费顾虑 | 待确认：先记录连续一周真实提问 |
| 一元火锅的真实点单规则 | 透明、实在不坑 | 待确认：必须先由老板逐条确认 |
| 顾客吃完后的真实反馈 | 结果、口碑 | 待积累；须经顾客同意，不摆拍、不代写原话 |
| 一位老客第一次来与再次来的真实原因 | 复购理由 | 待老板提供具体顾客和原话 |

优先级上，先攒“本人掌勺、三类品类真实出餐、点单规则”三类证据。  
顾客反馈和老客故事是后续加分项，不能在没有真实素材时硬拍。

## 变现型内容怎么排

### **变现型内容占比建议：30%**

起号期不建议超过这个比例。

原因是账号现在粉丝少、陌生人对厨师和门店都没建立认识。变现内容太密，会让主页看起来像连续广告；完全不做变现，又会让刷到的人不知道该怎么进店。  
30%的作用，是每发出约三条流量或人设内容，就安排一条把真实点单、真实出餐、真实场景说清楚的内容。

变现型内容只承担一件事：**让顾客更容易做出第一次到店决定。**

### 方向一：第一次来，一元火锅到底怎么点

- **成交路径**：解决“看见过，但不敢进店”的阶段。  
- **成交理由**：低门槛、规则清楚、实在不坑。  
- **先给的价值**：让第一次来的顾客看懂真实点单流程，减少到店尴尬。  
- **四大脚本**：晒过程·火车节  
  - 钩子：顾客第一次来，最常卡在“这个怎么点”；  
  - 过程：菜单、拿串、下锅或搭配其他品类；  
  - 结果：说明适合什么人、怎么选更清楚。  
- **起号36计**：**第10计·情境还原：**用店内真实点单流程还原“第一次来的人怎么从看菜单到坐下吃”。  
- **结尾行动**：**到店。**  
  “规则想当面看清，下午四点后到店。”  
- **前提**：一元火锅规则必须先确认，不能用模糊说法代替。

### 方向二：一桌人吃川味晚饭，怎么选串串、烧烤和川菜

- **成交路径**：解决“想去，但同行人吃什么”的阶段。  
- **成交理由**：选择多、场景全。  
- **先给的价值**：帮朋友聚餐、家庭晚饭的人把点单思路理清。  
- **四大脚本**：教知识·推荐型  
  - 圈定人群：下班聚餐、带家人吃饭的人；  
  - 推荐逻辑：按真实点单习惯讲，不编套餐、不强行凑菜；  
  - 适用条件：根据实际人数、口味、店内规则说明。  
- **起号36计**：**第26计·推荐建议：**围绕“几个人来、想吃什么”展示店内真实可选的川味串串火锅、川味烧烤、川菜。  
- **结尾行动**：**到店。**  
  “今晚人多不知道怎么选，到店再按你们口味点。”  
- **注意**：不是一条视频把所有菜堆满，而是每次围绕一个具体就餐场景，三类品类在一批内容里轮流出现。

### 方向三：成都厨师做川菜，哪一步不能省

- **成交路径**：解决“为什么值得专门来吃”的阶段。  
- **成交理由**：专业强、厨师本人掌勺。  
- **先给的价值**：让观众看见一道川菜从下锅到出餐中，真正影响口感的一个动作。  
- **四大脚本**：教知识·拆解型  
  - 常见误区：大家以为川味只要放辣；  
  - 原理：只讲一个真实可验证的处理步骤；  
  - 演示：拍本人操作，不讲无法证明的口号。  
- **起号36计**：**第15计·正确做法VS错误做法：**同一份食材，用普通处理和店内真实做法进行对照；人、食材、场景保持一致，变化的是厨师手艺。  
- **结尾行动**：**到店。**  
  “这道菜想吃现做的，下午四点后到店。”  
- **前提**：老板先确认“哪一步别人做得不一样”，否则不拍成专业判断。

### 方向四：烧烤为什么要盯着火候，不是烤熟就行

- **成交路径**：从“感兴趣”走到“相信他在做”。  
- **成交理由**：专业强、真实现做。  
- **先给的价值**：给顾客一个看烧烤制作过程的具体观察点。  
- **四大脚本**：晒过程·过程展示  
  - 钩子：镜头直接进烤炉，不先拍成品；  
  - 过程：翻烤、观察状态、出炉；  
  - 结果：落在这一份烧烤为什么要在这个时刻出炉。  
- **起号36计**：**第17计·互联网嘴替/替网友做：**从真实评论或顾客常问中挑一个问题，例如“烧烤是先烤什么、什么时候出炉”，现场做给观众看。  
- **结尾行动**：**到店。**  
  “想吃刚出炉这一口，下午四点后到店。”  
- **前提**：评论问题必须真实存在；没有真实提问时，改为老板确认过的高频顾客问题。

**提醒：**变现内容不是举着产品喊卖点。先让观众看懂一个点单问题、一个制作动作或一个就餐场景，再给一次到店出口即可。

## 定价与节奏

### 起步阶段建议怎么定价

账号起步阶段，**不建议为了短视频再额外打出没有核算过的低价活动**。

原因很直接：  
一元火锅已经是低门槛入口，如果再叠加不清楚成本的活动，可能吸来大量只冲价格来的顾客，却无法验证他们会不会点川味串串火锅、川味烧烤、川菜，也无法判断活动到底有没有利润。

起步阶段先做两件事：

1. **把现有真实规则拍清楚。**  
   一元火锅怎么点、三类品类各适合什么场景、下午几点能到店吃，先让顾客不迷糊。

2. **记录首次顾客的真实消费结构。**  
   记录但不公开夸大：顾客通常几个人来、怎么点、会不会加点、最常问什么。  
   这些数据是后续是否做套餐、怎么设计团购的基础。

### 什么时候可以涨价

目前没有菜单、成本和销售数据，不能建议具体涨价时间或涨价幅度。

只有满足以下条件后，才讨论调整价格：

- 连续一段时间的食材成本、人工和损耗能算清；
- 顾客复购和点单结构稳定，不只冲低价而来；
- 某些品类出现稳定需求，且顾客不是只问价格；
- 调整前先通过真实顾客反馈确认，是否会影响常来顾客的选择。

涨价依据不是“视频播放高了”，而是**成本结构、复购情况、出品能力和真实需求共同成立**。

## ⚠️ 风险

### 1. 低价内容吸来人，却留不下人

如果连续拍“一元”，观众会把这家店等同于便宜，而不会记住成都厨师、川味串串火锅、川味烧烤、川菜。这样顾客只会问价格，不会产生完整消费和复购。

**处理：**  
一元火锅内容控制在变现型内容中的一部分；其余变现内容轮流证明串串、烧烤、川菜的制作和就餐价值。

### 2. 三个品类都拍了，但观众仍不知道自己该什么时候来

只拍“今天做串串”“今天烤烧烤”“今天炒川菜”，内容会变成后厨流水账。

**处理：**  
每条都绑一个真实场景：下班晚饭、带孩子、朋友见面、多人聚餐。顾客看到的不是一道菜，而是“我今天刚好能用上”。

### 3. 没确认规则就急着拍转化视频

一元火锅的规则、价格、适用范围、是否需要搭配消费，如果老板本人没有说清，视频讲得越多，误解风险越大。

**处理：**  
第一周先完成规则确认：拿出菜单，老板逐条口述顾客怎么点；编导整理成统一口径；之后再拍情境还原和点单内容。未经确认的价格、套餐、顾客反馈，一律不写。
