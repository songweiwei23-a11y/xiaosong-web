## 选题一：串串备料时，这个动作到底在调整什么？

**承接**：方向“一件备料小事，看看川味从哪一步开始”——从当天真实备料中选一个本人能讲清楚的知识点。

**0️⃣ 视频目的**  
流量型。用一个看得见的备料动作，让陌生观众愿意停下来听解释。

**视频任务**  
让观众看懂一个备料动作的作用，并在评论区提出想看的制作过程。

**🅰 打法**  
36计·第36计 冷知识：先展示一个容易被忽略的备料动作 → 厨师说清自己为什么这样做 → 展示动作前后的食材状态 → 说明这个判断在什么情况下适用。

**1️⃣ 爆款元素**  
奇葩；套用句式“内行人的神奇操作”。不预设动作稀奇，靠厨师能解释清楚的真实细节吸引人。

**2️⃣ 开篇钩子**  
“串串下锅之前，这个备料动作到底在调整什么？”

**【方向】**一件备料小事，看看川味从哪一步开始  
**【目的】**流量  
**【结尾动作】**评论  
**【成交步骤】**—

**3️⃣ 内容方向及目的**

- **核心内容方向**：拍当天串串火锅的一项真实备料动作，讲清本人这样做的原因。
- **核心问题与观众价值**：这个动作改变了什么？观众能看到川味备料并非只有加调料，还能理解一个具体判断。
- **取材与内容推进**：开拍前请本人从当天任务里挑动作，问：“这一步你在看什么？做到什么状态会停？不这么做会有什么区别？”只选本人能确认、愿意公开的内容；拍操作前的状态、动作和完成后的状态，再配本人解释。
- **事实边界**：串串火锅和本人掌勺已确认；具体动作、原因和效果需本人现场确认。讲成“我这里是这样做的”，不当作川菜通用标准。
- **关键画面**：备料前的食材状态；本人操作的手部近景；完成后的状态与本人解释，保留现场原话。
- **场景设置**：店内收拾干净的备料台。

**4️⃣ 脚本结构**  
按计的公式走。

**5️⃣ 结尾行动指令**  
“你还想看串串的哪个制作过程？评论区告诉我。”

**6️⃣ 执行要点**  
手机固定拍手部，再补拍本人解释；收声避开油烟机和锅具碰撞。若当天没有能说清的知识点，就先留素材，不硬下结论。

## 选题三：第一次看成都厨师做川菜，怎样接住南乐客人的口味？

**承接**：方向“只比一件事：成都做法与南乐实际口味怎么接上”——选本人在南乐真实遇到、能讲清的一件差异。

**0️⃣ 视频目的**  
流量型。用具体饮食习惯的讨论吸引观众，不评判哪种做法更好。

**视频任务**  
让观众看明白一个真实的口味处理差异，并评论自己的习惯。

**🅰 打法**  
36计·第31计 南北/地域差异：本人先讲自己熟悉的一种做法 → 呈现到南乐后实际遇到的不同需求 → 用同一道川菜展示本人如何处理 → 请观众说自己的习惯。

**1️⃣ 爆款元素**  
人群；套用句式“第一次体验X的人”，落到“第一次看成都厨师处理不同口味需求的人”。

**2️⃣ 开篇钩子**  
“同一道川菜，碰到不一样的口味需求，我会怎么处理？”

**【方向】**只比一件事：成都做法与南乐实际口味怎么接上  
**【目的】**流量  
**【结尾动作】**评论  
**【成交步骤】**—

**3️⃣ 内容方向及目的**

- **核心内容方向**：从本人实际遇到的口味需求中选一件，用同一道川菜讲清自己的处理。
- **核心问题与观众价值**：当吃饭的人口味不一样时，厨师会调整什么？观众能看到具体做法，而不是听抽象的地域印象。
- **取材与内容推进**：先问本人：“来南乐后，你有没有实际遇到过和自己原先习惯不同的口味需求？具体是哪道菜、哪一步？”再追问：“原来怎么做？遇到这个需求后怎么处理？为什么这样处理？”现场用同一项食材或操作展示，剪进本人确认过的解释。
- **事实边界**：成都来南乐、本人掌勺已确认；具体差异和遇到的需求须本人确认。**没有真实观察，就先不拍这一条**；不能概括成“南乐人都这样吃”。
- **关键画面**：本人指出要比较的食材或操作；原先熟悉的做法与实际处理方式的示意；本人说明依据，保留现场原话。
- **场景设置**：店内干净操作台，用当天实际在做的川菜取材。

**4️⃣ 脚本结构**  
按计的公式走。

**5️⃣ 结尾行动指令**  
“这道菜你更习惯怎么吃？评论区说说。”

**6️⃣ 执行要点**  
先确认有可讲的真实观察，再架手机拍操作；不必为了对比额外制作不售卖的菜。没有证据解释差异原因时，只说本人实际做法，不推断地域原因。
