# 🚀 起号方案

## 📌 先说结论

- **建议主攻：第32计 换个视角**
  - 原因：这个账号最稳定的真实资源是——成都厨师本人、每天4点出摊、店内有备料和出餐过程。
  - 不需要编顾客、不需要搭剧情、不需要多人配合，只要把“顾客平时看不到的下午4点灶台”拍出来，就能和普通菜品展示号拉开区别。
  - 主线直接接上已定栏目《下午四点，成都厨师在南乐开灶》。

- **备选：**
  1. **第31计 南北/地域差异**：当店里能确认真实的成都与南乐口味、吃法或晚饭习惯差异时切入。
  2. **第10计 情境还原**：当顾客常问的一元火锅规则、点单流程和真实咨询内容补齐后，用于变现内容。
  3. **第36计 冷知识**：当老板能现场证明某个川菜、串串或烧烤动作背后的原因时切入。

- **明确不做：**
  1. **街头采访**：档案没有拍摄团队、采访人员和固定采访对象，单人一部手机难以稳定执行。
  2. **角色扮演、整蛊、多人剧情**：需要搭档、表演和调度，和“成都厨师真实开灶”的账号记忆点不一致。

- **多久能看出跑没跑通：**
  - 先按连续发布20—30条观察。
  - 参考线是：**零粉到一千粉，且发布的视频流量逐步稳定**。
  - 同时看非粉丝播放、3秒留存、完播、关注、主页访问和有效咨询，不能只看单条播放量。

## 🧮 起号期内容配比

### 1. 作用配比

| 类型 | 占比 | 执行方式 |
|---|---:|---|
| 流量型 | 45% | 以第32计 换个视角为主，拍“下午4点，成都厨师如何开始一顿川味晚饭” |
| 人设型 | 25% | 以第7计 一句话设定故事感和真实职业经历为主 |
| 变现型 | 30% | 以第10计 情境还原为主，拍清一元火锅真实点单与三类品类出餐 |

这个比例直接沿用已经确定的起号方案。流量型负责让南乐陌生用户认识“成都厨师、下午4点、川味晚饭”；人设型负责让观众记住掌勺的人；变现型负责把观看接到串串火锅、川味烧烤和川菜上。

### 2. 每种内容怎么拍

#### 流量型：45%

- **出发点：**
  - 人：成都来的川菜厨师。
  - 货：川味串串火锅、川味烧烤、川菜。
  - 场：每天下午4点的店内灶台。
  - 爆款元素：人群、反差、地域差异。
  - 三有：让下班白领、接娃后的宝妈产生“晚饭已经开始准备了”的共鸣。

- **形式：**第32计 换个视角。
- **脚本结构：**晒过程·火车节。
- **结构：**下午4点开灶的起因 → 一个具体备料或烹饪任务 → 中间出现一个动作变化或判断 → 完成结果。
- **结尾行动指令：**“你们一般几点开始准备晚饭？”

#### 人设型：25%

- **出发点：**
  - 只拍成都厨师本人、做川菜9年的职业经历、来到南乐半年的真实适应。
  - 不使用没有确认过的顾客故事、困难经历和性格评价。

- **形式：**第7计 一句话设定故事感。
- **脚本结构：**讲故事·平凡英雄型。
- **结构：**一个普通的开灶动作 → 真实职业背景 → 一件已经确认的具体事件 → 这件事让老板形成的判断。
- **当前缺口：**老板还没有提供具体事件，不能直接写成完整故事。
- **先补的问题：**“来南乐半年，哪一次真实发生的小事，让你重新想了一遍自己做川菜这件事？当时谁说了什么，你具体做了什么？”
- **结尾行动指令：**“想看我每天四点怎么开灶，关注我。”

#### 变现型：30%

- **出发点：**
  - 人：本人掌勺。
  - 货：川味串串火锅、川味烧烤、川菜。
  - 场：真实门店和出餐台。
  - 成交理由：一元火锅低门槛；每条只讲一个理由。
  - 画面必须出现真实菜单、实际点单流程或真实出餐过程。

- **形式：**第10计 情境还原。
- **脚本结构：**教知识·解题型。
- **结构：**第一次到店不知道怎么点 → 按店内真实规则说明 → 现场完成一类品类的点单或出餐 → 给出一个到店动作。
- **当前缺口：**一元火锅的具体点单规则、菜品范围、是否有时间或适用条件，档案没有提供。
- **拍摄前必须确认：**“顾客到店后第一步怎么点？一元是按什么计算？有哪些不能直接对外说的条件？”
- **结尾行动指令：**“下午四点后到店，按店内规则现场点。”

### 3. 过线之后怎么调整

达到“零粉到一千粉、流量稳定”后：

- 流量型从45%降到40%左右，继续保留《下午四点，成都厨师在南乐开灶》。
- 人设型从25%增加到25%—30%，前提是已经补齐真实职业事件、顾客原话和老板个人判断。
- 变现型从30%增加到35%左右，重点补充：
  - 一元火锅真实点单；
  - 川味串串火锅出餐；
  - 川味烧烤出炉；
  - 川菜制作过程。
- 形式上仍以晒过程为主，不直接改成站立口播号。

## 🎯 主攻打法：第32计 换个视角

### 为什么是你能拍的

1. **人物条件成立**
   - 出镜人就是店主本人，也是掌勺的成都川菜厨师。
   - 有做川菜9年的职业背景，不需要找演员替代。

2. **场景条件成立**
   - 店里有固定灶台、备料区、出餐区。
   - 每天下午4点出摊，时间和场景都固定，容易形成系列记忆。

3. **内容素材稳定**
   - 每天都能拍食材准备、串签、炒料、烧烤、川菜出餐。
   - 川味串串火锅、川味烧烤、川菜可以轮流成为主角，避免每天只拍同一个锅。

4. **拍摄难度低**
   - 核心是第一视角、固定机位和近景细节。
   - 不需要顾客配合，不需要店员扮演角色，不需要多人剧情。
   - 当前团队人数和设备没有确认，因此方案只按“老板本人+门店+手机固定拍摄”设计；是否有支架、收音设备和剪辑人员，需接手前确认。

5. **和账号定位完全一致**
   - 账号长期价值是“让南乐人看见每天四点开始的川味晚饭”。
   - 第32计直接把镜头放到顾客平时看不到的开灶视角，和主栏目完全重合。

### 每条视频的看点

每条只押一个看点：

> **顾客还没开始想晚饭时，成都厨师已经在下午4点开灶。**

这个看点成立的原因不是夸张结果，而是时间、人物和动作都能在画面里直接看见。

### 结构公式

**常规晚饭视角 → 换成下午4点厨师视角 → 备料、点火、烹饪过程 → 一项具体结果 → 评论互动**

套到本账号：

- 常规视角：顾客看到的是端上桌的川味菜。
- 新视角：观众跟着成都厨师，从下午4点开始看一顿晚饭如何准备。
- 过程：当天只拍一个任务，不把串串、烧烤、川菜全部塞在同一条里。
- 结果：拍清楚这一项任务完成到哪一步。
- 互动：只问一个和晚饭时间或口味有关的问题。

### 配什么脚本讲

- **第32计 换个视角**：负责片子里发生什么。
- **晒过程·火车节**：负责让过程有起因、变化和结果。
- 这个组合补上的是：
  - 流量型的观看理由；
  - 真实开灶的连续性；
  - 账号固定栏目记忆。
- 它不承担成交理由，因此流量片里不讲“正宗”“低价”“好吃”，一元火锅只在画面需要时自然出现，不把视频拍成价格广告。

### 前3条具体拍什么

#### 第1条

**标题：**《下班前，南乐人的川味晚饭已经从下午四点开始了》（人群）

**拍摄要点：**

1. 第一帧：手机固定在备料台，画面出现时间信息或老板开始备料的动作。
2. 老板出镜第一句：  
   **“你们还没想好今晚吃什么，我下午四点已经开始准备这顿川味晚饭了。”**
3. 连续拍同一个任务：备料 → 点火 → 锅内变化。
4. 只拍一个品类，第一条优先拍川味串串火锅。
5. 结尾拍完成后的锅或备好的串，不拍虚构顾客反应。
6. 结尾台词：  
   **“你们一般几点开始准备晚饭？”**

#### 第2条

**标题：**《成都厨师来南乐半年，下午四点先从哪一步开灶？》（反差）

**拍摄要点：**

1. 第一帧拍老板手上的具体动作，不从门头或自拍开场。
2. 第一秒字幕直接交代身份：  
   **“成都来的川菜厨师，下午四点先做这一步。”**
3. 拍川味烧烤当天的一项真实准备工作。
4. 老板只解释一个动作为什么放在前面，不能扩写成普遍规律。
5. 没有真实依据时，不说“这样才正宗”，改说：  
   **“我今天先按自己的做法处理这一处。”**
6. 结尾台词：  
   **“你们吃烧烤时，最先看什么？”**

#### 第3条

**标题：**《朋友下班聚餐前，川菜从下午四点开始准备什么》（人群）

**拍摄要点：**

1. 第一帧拍川菜当天实际准备的食材或锅具。
2. 开场台词：  
   **“朋友下班还没到，今天这道川菜已经从下午四点开始准备了。”**
3. 只拍一道川菜的准备过程，不虚构聚餐人数。
4. 记录一个能看见的过程变化：食材处理、下锅、收汁或出锅。
5. 如果当天没有朋友聚餐场景，不使用这个标题，改成：  
   **《下午四点，今天这道川菜先从哪一步开始准备》（人群）**
6. 结尾台词：  
   **“你们下班聚餐更想吃川菜，还是烧烤？”**

### 边界

- 不把第一视角拍成假装顾客体验。
- 不让店员扮演顾客提问。
- 不用“南乐人都喜欢”“大家都说好吃”这类没有依据的话。
- 不把一次出餐过程说成所有顾客都会满意。
- 不用没有确认过的辣度、份量、等餐时间和价格信息。
- 不把一元火锅反复做成流量标题，否则账号会只剩低价记忆。
- 不使用“成都人一定这样吃”“南乐人都那样吃”的绝对判断。

## 🔄 备选打法

### 备选一：第31计 南北/地域差异

#### 什么情况下切过去

当老板确认了一个真实的地域差异，包括：

- 成都和南乐在辣度、吃法、晚饭时间或点菜习惯上的具体不同；
- 真实顾客提出过的问题；
- 老板实际做过的调整。

没有真实差异前，不拍“成都和南乐到底谁更能吃辣”这种空比较。

#### 怎么套到这个号

**同一个晚饭任务 → 成都厨师的做法 → 南乐顾客熟悉的做法 → 解释差异来源 → 问观众当地习惯**

#### 配套脚本

**晒过程·火车节**

- 起因：下午4点准备一类川味晚饭。
- 过程：老板展示自己的成都做法。
- 变化：说明南乐顾客实际反馈后，哪一步做了调整。
- 结果：拍出这一锅或这一盘的完成状态。
- 结尾：**“你们那边吃川味，最在意辣度还是口味？”**

#### 为什么是他能拍的

- 成都籍贯是真实事实。
- 做川菜9年，具备讲地域口味的职业背景。
- 南乐生活半年，具备观察本地晚饭习惯的时间基础。
- 但具体差异和顾客原话还没有，必须先补事实。

### 备选二：第10计 情境还原

#### 什么情况下切过去

当店内确认以下资料后切换：

- 一元火锅的真实点单规则；
- 顾客最常问的一句话；
- 串串火锅、川味烧烤、川菜各自的实际点单流程；
- 店内真实营业时间和到店位置表达方式。

#### 怎么套到这个号

**真实顾客常问的问题 → 老板按店内规则说明 → 拍一类品类的实际出餐 → 让第一次到店的人知道下一步做什么**

#### 配套脚本

**教知识·解题型**

- 场景难题：第一次到店不知道怎么点。
- 放大不确定：一元火锅具体怎么计算、串串怎么拿、烧烤和川菜怎么选，必须用真实规则说明。
- 解决过程：拍菜单、取串、下锅或出餐。
- 结尾：**“下午四点后到店，按店内规则现场点。”**

#### 为什么是他能拍的

- 店主本人掌勺，能同时讲清出品和实际流程。
- 三类产品都在售，能够分别制作内容。
- 店内就是拍摄现场，不需要外景。
- 但规则没有在档案里写全，补齐前不发布具体点单话术。

---

### 备选三：第36计 冷知识

#### 什么情况下切过去

当老板能从9年川菜经验里确认一个：

- 外行容易忽略；
- 能在店里现场演示；
- 不需要夸大结论；
- 和川味串串火锅、川味烧烤或川菜直接相关的动作。

#### 怎么套到这个号

**一个反常识动作 → 现场展示 → 解释这一步只影响什么 → 回到当天出品**

#### 配套脚本

**教知识·解题型**

- 误区：观众习惯用某个表面现象判断食材或火候。
- 现场展示：老板按自己的实际做法演示。
- 原因解释：只说明这一步直接影响的口感、熟度或出品状态。
- 结尾：**“你们平时做这道菜时，先做哪一步？”**

#### 为什么是他能拍的

- 做川菜9年，具备稳定的现场动作素材。
- 备料、炒料、烧烤和出餐每天都能产生题材。
- 一人固定手机即可完成。
- 没有现场证据的知识不拍，不把个人习惯说成行业统一标准。

## 🧪 怎么测

### 1. 一次只改一个变量

主攻第32计时，前6条只改以下变量中的一个：

- 第1轮只换品类：串串火锅、川味烧烤、川菜。
- 第2轮只换人群入口：下班白领、接娃后的宝妈、朋友聚餐。
- 第3轮只换开场：下午4点时间钩子、成都厨师身份钩子、晚饭场景钩子。

人物、店内场景、视频时长、字幕样式和结尾指令保持一致。

### 2. 每计测几条

- 第32计 换个视角：至少6条。
- 第31计 南北/地域差异：至少3条。
- 第10计 情境还原：至少3条。
- 第36计 冷知识：至少3条。

样本不足3条时，只能判断单条执行情况，不能直接否定打法。

### 3. 看什么指标

#### 流量型

- 非粉丝播放占比；
- 3秒留存；
- 完播率；
- 评论是否出现“南乐、成都、四点、晚饭”等记忆词；
- 新增关注。

#### 人设型

- 主页访问；
- 关注率；
- 评论里是否主动提到老板本人；
- 是否有人追问经历、做菜方式或下一集内容。

#### 变现型

- 主页访问；
- 私信或评论中的到店问题；
- 对一元火锅规则、位置、营业时间的有效咨询；
- 实际到店反馈。

### 4. 什么信号算这计行

第32计出现以下信号时，继续加大主力：

- 同一类开灶视角连续出现稳定的非粉丝播放；
- 评论开始主动提到“下午四点”“成都厨师”；
- 观众开始问下一次拍串串、烧烤还是川菜；
- 播放不只来自同行或泛美食用户，而是南乐本地用户。

### 5. 什么信号算换掉

- 连续6条都有清晰开场，但前段留存持续低；
- 评论和关注没有出现本地、厨师、晚饭相关词；
- 三类品类都拍过，观众仍只把内容当普通菜品展示；
- 第32计比普通菜品展示没有明显改善。

这时先切到第31计或第36计，不换赛道，只换看点来源。

## 📅 30天节奏

按每周3条、每月约12条执行。每天4点都有素材，但不要求每天发布。

### 第1周：建立固定开灶视角

**发布：**

- 2条第32计 换个视角，分别拍串串火锅、川味烧烤。
- 1条人设型，拍成都厨师本人和下午4点开灶的真实身份。

**任务：**

- 确认手机固定位置；
- 找出备料台、灶台、出餐台三个稳定机位；
- 测试人声是否清楚；
- 每次只拍一个品类。

**交付物：**

- 3条成片；
- 每条记录非粉丝播放、3秒留存、完播和评论关键词；
- 一份“顾客常问问题”现场记录表。

## 📊 跑不通先查哪里

### 情况一：曝光少

- **先怀疑：**标题和开场只写“今天做菜”，没有把“南乐、下午4点、成都厨师、下班晚饭”中的一个入口说清楚。
- **下一步实验：**连续3条保持同一拍法，只把第一句分别改成：
  - 下午4点时间入口；
  - 下班晚饭人群入口；
  - 成都厨师身份入口。

### 情况二：有曝光，前3秒流失

- **先怀疑：**第一帧是空镜或门头，观众还没看见人物和动作。
- **下一步实验：**下一条从手部动作、锅内变化或食材处理开始，第一句话直接说清“谁在几点做什么”。

### 情况三：播放有了，主页访问和咨询少

- **先怀疑：**内容只展示了锅和菜，没有让观众知道这是哪个人、在哪个时间、卖哪三类东西。
- **下一步实验：**变现型改用第10计 情境还原，拍清一元火锅真实规则；流量型仍不加入到店指令，避免把两种目的混在一条里。

### 情况四：一元火锅咨询多，但川味烧烤和川菜没人问

- **先怀疑：**价格记忆压过了三类品类，账号被看成单一低价火锅号。
- **下一步实验：**连续3条不把一元放进标题，分别拍川味串串火锅、川味烧烤、川菜的真实出餐过程；一元信息只保留在变现型内容中。
