  2. **精致妈妈**：接孩子后、周末带家人、招待亲友时，需要一个能兼顾口味选择和就餐便利的晚饭去处。

  白领心里可能是：“别让我下班还要研究半天，找个能坐下来好好吃的地方。”

#### 当前阶段配比

- **作用配比：流量型45% / 人设型25% / 变现型30%**  
  这是起号期合理的结构：流量型是最大块，负责让陌生人先认识“成都厨师+川味晚饭”这个符号；人设型不能太少，否则账号只剩菜品；变现型保留30%，从起步阶段就建立到店理由，但不把主页做成广告墙。

- **每一块用什么形式做**：  
  - **流量型45%**：以晒过程、轻知识、地域差异为主，少量段子或一人分饰多角。重点拍“成都厨师在南乐做晚饭”带来的反差、晚饭共鸣、锅气和现场感。  
  - **人设型25%**：以真实故事、职业观点、开灶日常为主。重点不是卖苦，而是让人记住这位厨师为什么从成都来到南乐、做菜时坚持什么。缺少真实事件的部分，先不拍。  
  - **变现型30%**：以晒过程和教知识为主。每条只证明一个成交理由：比如一元火锅的低门槛、厨师本人掌勺的手艺、三类品类能覆盖不同晚饭场景。画面必须有过程，不靠空口夸味道。

- **题材配比：主赛道75% / 目标人群兴趣25%**  
  - 主赛道75%中，**川味串串火锅25%、川味烧烤25%、川菜25%**，三个品类轮流成为单条主角，保持并列，不互相降级。  
  - 目标人群兴趣25%围绕“下班晚饭、带娃吃饭、朋友聚餐、周末解压、南乐本地生活”展开。  
  这样做不是偏离餐饮，而是先让观众觉得“这说的是我今晚的处境”，再接住这三类产品。

- **主力形式**：  
  档案没有提供“数据最好的内容类型”，因此目前不能把某种形式说成已验证主力。  
  **暂定以晒过程为主力形式，连续测试20—30条。** 原因是现有硬资源最明确：本人掌勺、下午四点出摊、三类产品都具备制作过程；它比强口播、剧情表演更容易稳定产出。  
  如果后续数据显示知识口播或地域话题的完播、关注明显更高，再调整主力，但不能靠感觉替换。

# 💎 内容定位方案

## 长期价值主张

一句话：**让南乐人看见每天四点开始的川味晚饭。**

## 内容方向：多元四类还是单一主题

### 选哪条

选择：**A打底+B王牌栏目**

- **A多元四类打底**：知识、故事、晒过程、观点都保留，因为这个账号既有厨师经验，也有每天备菜、开灶、出餐的持续素材。
- **B王牌栏目**：固定做《下午四点，成都厨师在南乐开灶》，把每天真实发生的备料、炒料、穿串、烧烤、川菜出餐，变成持续内容。

### 为什么不选单一主题

只做“每天四点开灶”容易出现画面重复：点火、备菜、出锅连续拍几次后，观众可能只记住动作，记不住账号价值。

但完全做多元四类，又容易变成普通餐饮号，今天讲配方，明天拍菜品，后天讲故事，缺少统一记忆点。

所以用“下午四点开灶”统一账号，再让**川味串串火锅、川味烧烤、川菜**轮流成为每条视频的主角。三类品类同等重要，不在单条视频里强行同框。

### 主题一句话

**每天四点，记录一个成都厨师在南乐把川味串串火锅、川味烧烤、川菜做上桌。**

### 接手前先补的事实

以下是我根据餐饮账号规律做的推测，必须由老板用真实事件确认：

1. **最近一次顾客不满意是什么事？**  
   我推测可能和辣度、等餐、点单不清有关，但不能直接写进内容。请老板说清当时顾客原话、自己做了什么、最后怎么处理。  
   **待确认：具体事件、原话、处理动作。**

2. **有没有明确不做的事？**  
   比如不接哪类临时要求、不卖哪种食材、不为了省时间省掉哪一步。  
   **待确认：一次真实经历，以及老板当时为什么这样决定。**

3. **哪位老客回来过？**  
   第一次是被什么吸引，第二次又因为什么回来。重点要问顾客原话，不先假设是因为价格或味道。  
   **待确认：两次到店的原因和顾客原话。**

4. **顾客进店最常问哪句话？**  
   我推测可能是“一元火锅怎么点”“辣不辣”“除了串串还有什么”，但需要从实际咨询中核对。  
   **待确认：出现频率高的一句原话和老板的真实回答。**

5. **这个月发生过哪件小事？**  
   可以是一位客人、一台设备、一次备料调整或一次出餐变化，但必须讲清时间、人物、动作和结果。  
   **待确认：一件完整经过。**

6. **顾客为什么选这里而不是别家？**  
   要找顾客说过的话，不接受“因为我们正宗”“因为价格实惠”这种老板判断。  
   **待确认：至少一句顾客原话。**

7. **老板亲手做哪一步，别人做出来不一样？**  
   我推测可能是炒料、看火候、食材处理或烧烤火力判断，但不能替老板决定。  
   **待确认：具体动作、判断标准，以及别人容易做错的地方。**

# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

这是典型的**本地晚餐、夜间餐饮生意**：顾客不是提前很久规划，而是在下班前、接完孩子后、朋友约饭时，临时决定“今晚去哪吃”。因此，短视频的任务不是把所有菜都讲明白，而是让南乐本地人在这个时刻能想起这家店。

餐饮利润通常不靠一项低门槛产品单独支撑，而是靠一桌人的完整点单结构：有人因一元火锅愿意第一次进来，但是否形成有效消费，要看顾客会不会继续点川味串串火锅、川味烧烤、川菜及店内其他真实售卖品。  
所以，一元火锅适合做“降低第一次进店顾虑”的入口，不能长期拍成“只要便宜就值得来”的价格广告。否则会吸引大量只问价格、不形成复购的人。

这行真正卡获客成本的地方有两个：

1. **顾客刷到后记不住。**  
   同城餐饮号大多是菜品特写、门头、团购字幕、老板招呼，画面热闹但没有记忆锚点。用户晚上要吃饭时，想不起是哪一家。

2. **第一次到店前有小顾虑。**  
   顾客会想：一元火锅怎么点？辣不辣？除了串串还有什么？带孩子或朋友去能不能吃？这些问题没人提前讲清，就容易停在“刷到过”而不是“去一次”。

我推测，这家店的高频消费时段是晚餐和夜间；下午四点出摊前后的备料、开灶、第一轮出餐，是最适合稳定生产内容的时间线。午间是否经营、是否有外卖、是否存在高峰排队，均待确认，不能提前写成卖点。

同行常犯的错，是把“菜多、价格低、老板忙”当成内容本身。顾客看到这些，只会觉得又是一家餐饮店。这个号真正该占的位置是：**成都厨师每天四点在南乐开灶，把本地人的一顿川味晚饭做出来。**

**一句话定位：成都厨师四点开灶做川味串串火锅、川味烧烤、川菜，管南乐晚饭。**

## 变现全景

### **现在能卖什么**

1. **川味串串火锅**  
   适合下班晚饭、朋友小聚、多人围桌吃饭。画面上最好拍“拿串—下锅—出锅”的完整过程，减少第一次尝试者“不知道怎么点”的顾虑。

2. **川味烧烤**  
   适合晚间加餐、朋友聊天、想吃点有烟火气的顾客。它不能只拍成品盘子，要拍烤炉、翻烤、刷料、出炉等动作，让“现烤”成为能看见的理由。

3. **川菜**  
   适合家庭晚饭、带孩子、招待亲友，以及不想只吃串串或烧烤的人。它承担的是“多人一桌吃什么都能接住”的消费场景，不应被短视频忽略。

4. **一元火锅首次尝试入口**  
   这不是独立的长期主角，而是降低首次进店门槛的机制。它必须讲清真实规则：哪些品类适用、怎么点、是否有最低消费或搭配要求，均待店内确认后再拍。

### **各自的客单价与毛利大致区间**

门店没有提供实际菜单、进货成本、人工和房租数据，**不能替店里编客单价或毛利率数字**。目前只能先按经营结构判断：

- **川味串串火锅**：通常靠多人点单、串品数量和搭配消费形成单桌收入；
- **川味烧烤**：通常依赖加点、晚间续单和多人分享；
- **川菜**：通常承担桌餐中的补充点单，提高一桌人“坐下来吃正餐”的完整度；
- **一元火锅**：承担首次到店转化，不宜单独作为利润判断依据。

**待确认，优先补三项：**  
1. 顾客一桌实际点单区间；  
2. 一元火锅的真实点单规则；  
3. 串串、烧烤、川菜里复点率较高的具体品项。  

没有这三项，后续团购、套餐、价格表达都不能定。

### **决策难度**

整体属于**低到中等决策**：

- 看完视频就可能想去，但通常不会立刻付款；
- 顾客会先看主页确认位置、营业时间、品类和评论；
- 再等到“今天晚上吃什么”的具体时刻，和同事、家人一起决定；
- 首次进店门槛不高，但复购取决于实际口味、出餐体验和是否方便点单。

因此，账号不能只做促销，也不能只做后厨纪录片。要同时完成“让人想起你”和“让人敢进来”的两件事。

## 主推产品

**主推：一元火锅的首次到店体验。**

这不是把川味串串火锅、川味烧烤、川菜分出高低，也不是把其中任何一个降成配角；它只是现阶段最适合做**首次转化入口**的表达方式。

选择它有三个原因：

1. **信任门槛最低。**  
   新号没有老顾客评论、案例积累和稳定认知时，陌生人最怕的不是“不知道这家有没有菜”，而是“我去了会不会点不明白、花得不值”。低门槛机制更容易让人愿意第一次到店。

2. **能自然带出三类品类。**  
   顾客进店后，川味串串火锅、川味烧烤、川菜需要轮流接住不同人的需求。短视频不能只举价格牌，而要拍清楚“第一次怎么点、同行的人还能吃什么”。

3. **生产成本低，拍摄稳定。**  
   每天下午四点开灶后，就能拍备料、拿串、下锅、烤制、出川菜等真实动作，不依赖演员、复杂剧情或虚构顾客反馈。

明确不做：  
- 不把“一元”拍成全账号唯一记忆点；  
- 不承诺“花很少的钱就能吃得怎样”；  
- 不在未确认规则前，用模糊话术吸引顾客到店后再解释。

## 成交路径

### 1. 第一次接触看到什么

顾客先刷到的，应是“成都厨师下午四点开灶”的现场，而不是价格海报。

例如：  
- 空锅点火；  
- 手上正在穿的串；  
- 烤炉上的翻烤动作；  
- 一道川菜刚下锅的瞬间；  
- 厨师说一句真实判断：“这一步要是急了，晚上这一锅味道就不对。”

**这一环节会流失的人：**  
只想看纯搞笑、与吃饭无关内容的泛流量。  
**为什么允许流失：**  
本地餐饮号不需要讨好所有人，先留下会在南乐吃晚饭的人。

### 2. 靠什么产生兴趣

兴趣不只靠“便宜”，而是靠三层信息同时建立：

- **身份反差**：成都厨师来到南乐掌勺；
- **场景共鸣**：下班、接孩子、朋友约饭时，晚饭已经有人开始准备；
- **降低顾虑**：第一次来的人，知道川味串串火锅、川味烧烤、川菜分别怎么选。

**这一环节会流失的人：**  
对川味、晚饭场景完全无需求的人。  
**为什么会流失：**  
这是正常筛选，强留泛人群只会让账号播放和到店脱节。

### 3. 在哪里沉淀

沉淀主阵地是**主页 + 到店前私信或评论问答**，不建议起号期把路径拉得太长。

主页必须让顾客一眼确认四件事：

- 这是成都厨师本人掌勺；
- 卖川味串串火锅、川味烧烤、川菜；
- 下午四点开灶；
- 地址和营业信息以店内真实情况为准。

评论区和私信只回答真实规则，例如：  
“第一次来怎么点？”  
“带孩子能吃什么？”  
“烧烤和川菜有没有？”  
“一元火锅具体怎么算？”

**这一环节会流失的人：**  
问完规则仍觉得不适合自己的人。  
**为什么会流失：**  
提前讲清规则，比顾客到店后产生误解更重要。

### 4. 临门一脚是什么

临门一脚不是催单，而是解决“今晚去不去”的最后一个问题：

- 下班后想吃点热乎的；
- 朋友约饭不想只吃一种；
- 接完孩子不想回家再做饭；
- 第一次来不知道怎么点。

最合适的行动是：  
**“下午四点后，想吃川味晚饭就到店。”**

**这一环节会流失的人：**  
距离远、时间不合适、口味偏好不匹配的人。  
**为什么会流失：**  
餐饮到店有天然地域和时段限制，不能靠短视频承诺覆盖所有人。

## 信任证据清单

以下证据必须拍成画面，不能只写在字幕里。

| 可拍证据 | 证明什么 | 当前状态 / 怎么攒 |
|---|---|---|
| 厨师本人下午四点开始备料、开灶 | 真实、本人掌勺 | 已有硬事实，可固定拍 |
| 川味串串火锅从备料到下锅的一个完整环节 | 手艺、真实出品 | 可立即拍，但先选一个固定动作 |
| 川味烧烤的翻烤、刷料、出炉过程 | 现做过程、制作能力 | 可立即拍，避免只拍成品 |
| 川菜下锅、翻炒、出餐的关键动作 | 厨师能力、品类真实存在 | 可立即拍，每周至少保留一个川菜主角 |
| 新顾客第一次点单时最常问的问题 | 降低首次消费顾虑 | 待确认：先记录连续一周真实提问 |
| 一元火锅的真实点单规则 | 透明、实在不坑 | 待确认：必须先由老板逐条确认 |
| 顾客吃完后的真实反馈 | 结果、口碑 | 待积累；须经顾客同意，不摆拍、不代写原话 |
| 一位老客第一次来与再次来的真实原因 | 复购理由 | 待老板提供具体顾客和原话 |

优先级上，先攒“本人掌勺、三类品类真实出餐、点单规则”三类证据。  
顾客反馈和老客故事是后续加分项，不能在没有真实素材时硬拍。

## 变现型内容怎么排

### **变现型内容占比建议：30%**

起号期不建议超过这个比例。

原因是账号现在粉丝少、陌生人对厨师和门店都没建立认识。变现内容太密，会让主页看起来像连续广告；完全不做变现，又会让刷到的人不知道该怎么进店。  
30%的作用，是每发出约三条流量或人设内容，就安排一条把真实点单、真实出餐、真实场景说清楚的内容。

变现型内容只承担一件事：**让顾客更容易做出第一次到店决定。**

### 方向一：第一次来，一元火锅到底怎么点

- **成交路径**：解决“看见过，但不敢进店”的阶段。  
- **成交理由**：低门槛、规则清楚、实在不坑。  
- **先给的价值**：让第一次来的顾客看懂真实点单流程，减少到店尴尬。  
- **四大脚本**：晒过程·火车节  
  - 钩子：顾客第一次来，最常卡在“这个怎么点”；  
  - 过程：菜单、拿串、下锅或搭配其他品类；  
  - 结果：说明适合


## 输出要求

行业建议只管「这个阶段怎么打」，不重复定位。账号是谁（账号定位）、长期拍什么（内容定位）、靠什么成交（商业定位）已经定好，这里只引用它们的原名。按下面的结构输出 Markdown，每一节都落到这个账号和这个阶段上：

1. **本阶段判断**：这个阶段和目的下，现状和目标之间差在哪里，依据是档案和作品数据。数据不够就直说不够。
2. **本阶段重心方向**：给 2–3 个建议方向，优先引用内容定位里已有的系列原名。每个写清：这一阶段它负责哪个目的（流量、人设、变现）、占本阶段的比例、为什么选它（对准哪个真实需求，依据档案的哪条事实）。这是建议，用户自己选定的方向优先。
3. **每类目的的结尾动作**：流量、人设、变现各一个结尾动作，每类只留一个。变现型的动作要对应商业定位里的哪一步，写出原步骤名。
4. **本阶段暂停什么**：2–3 条，每条写依据（禁忌、档案，或内容定位里的排除项）。
5. **30 天执行规则**：3 条，只约束选题和脚本怎么做（例如「每条都要在前 5 秒说出位置」），不重述定位。
6. **复诊条件**：出现哪些迹象就该换阶段，换的时候重心怎么变。只写可以观察的迹象（例如「连续几条都有陌生人在评论区问地址」），用这个号自己过去的数据比；**不写任何具体数字**（播放量、新客人数、连续条数都不写）。

## 硬约束

- 药方是建议，不是命令。用户选定的方向优先：用户的方向不在内容定位里，就照用户的方向给建议，并说明它和内容定位、本阶段重心的差距，不阻止、不改写。
- 不替用户新增或改写内容定位。如果本阶段反复需要内容定位里没有的方向，只写「建议把它加进内容定位」，由用户决定。
- 拍小票、结账、价格画面时，金额一律用【待确认】或「金额打码」，档案里没有的数字不写。
- 不重述账号定位（这个号是谁、说给谁、凭什么信）、内容定位（长期拍什么）、商业定位（靠什么赚钱）的内容，只引用原名。
- 内容定位已有，第 2 节优先引用它的原系列名。
- 商业定位已有，第 3 节的变现动作写出原步骤名。
- 不编造任何数字、案例、客户故事、效果承诺。缺的事实用【待确认】标出
- 价格、价位、人均、营业时间、地址、作息、门店活动，只有档案或素材里写了才能用。档案里没有的，写成「价格摆在明面」这类做法即可，具体数字用【待确认】占位，不要替它定价
- 阈值类数字（完播率、播放量、咨询人数、转化率）一律不给具体合格线，例如「完播低于 X% 就换」。改成和这个号自己过去的数据比较；没有历史数据就写「待建立」
- 档案里写着「未填」「待补充」或留空的项，不当作事实使用，也不凭行业印象补成具体值；推断出来的内容要标明是推断
- 与账号档案的事实冲突时以档案为准
- 禁忌里写的不能说、不能拍，方案里一律不出现
- 不输出寒暄和过程说明，只输出方案正文
