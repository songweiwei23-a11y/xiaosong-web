# 🎯 账号定位方案

## 📌 核心结论（先看这 8 条）

1. **这是什么号**：本地餐饮号；成都厨师做川味三品类  
2. **给谁看**：下班赶晚饭的新锐白领和宝妈  
3. **人设标签**：下午四点开灶的成都厨师  
4. **主打内容**：流量45%人设25%变现30%，过程主打  
5. **怎么赚钱**：抖音种草→到店点串串、烧烤或川菜  
6. **第一条拍什么**：成都厨师在南乐下午四点开灶  
7. **最该避开的坑**：把一元火锅拍成单纯低价广告  
8. **多久能看出跑没跑通**：连续发完20—30条后复盘

## 🔍 先说这一行

- **归口**：A类本地实体店中的**餐饮食品**，主业态是晚餐、夜间消费场景下的川味餐饮。川味串串火锅、川味烧烤、川菜是三条并列产品线，不应只把账号做成“一元火锅号”。

- **这行的钱怎么赚**：  
  餐饮的收入不只看一桌点了多少，更看“今天有没有让人进店”和“下次还会不会回来”。一元火锅适合降低第一次尝试的门槛，但不能承担全部盈利任务；真正决定一桌消费结构的，是顾客是否继续点串串、烧烤、川菜以及饮品等。  
  对这家店来说，短视频的核心任务不是讲复杂菜品知识，而是让南乐本地人先形成一个认知：**下午四点以后，想吃川味串串火锅、川味烧烤、川菜，可以想到这位成都来的厨师。**

- **客人的决策链路**：  
  这是低到中等决策餐饮，不像装修需要反复比较，也不是刷到就必然到店。多数人会经历：  
  刷到视频 → 记住“一元火锅+成都厨师” → 和同事、家人讨论晚上吃什么 → 看距离、营业时间、评论和菜品画面 → 到店尝试。  
  决策通常集中在下班前、接孩子后、周末聚餐前，因此内容必须把“今天晚上吃什么”的场景拍出来，而不是只拍后厨。

- **时间规律**：  
  下午四点出摊是天然内容节点：备菜、穿串、炒料、点火、第一桌客人到店，都能成为固定素材。  
  推测晚餐和夜间是重点时段；周末、节假日、朋友聚餐、接待亲友时，串串火锅、烧烤和川菜更容易被想起。是否存在午间经营、外卖、高峰排队等情况，**待确认**，不能提前写成事实。

- **这行老板普遍会犯的错**：  
  最常见的自嗨是反复拍“菜摆得很满”“价格很便宜”“老板很忙”，以为顾客自然会来。问题是，陌生人刷到后仍不知道：这家到底适合谁、什么时候去、为什么值得专门去一趟。  
  这个账号目前也有这个风险：如果只围绕“一元火锅”喊低门槛，容易吸来只问价格的人，却没把川味串串火锅、川味烧烤、川菜的完整消费理由讲清。

- **同行现在都在拍什么**：  
  同城餐饮号常拍门头、菜品转盘、老板招呼、团购口播和顾客吃饭镜头。大多效果有限，原因不是画面不够热闹，而是内容缺少一个可复述的人和固定事件。  
  这家店的空档在于：**不是泛泛拍一家川味店，而是持续拍“成都厨师每天四点在南乐开灶，把一顿川味晚饭做出来”的现场。** 厨师身份、固定时间和真实烹饪动作，才是别人不容易复制的内容资产。

## 🗣 我会先问老板的几个问题

- **问题**：最近一次有顾客吃完觉得不满意，具体是因为什么？你当时说了什么、做了什么？  
  - **我的推测**：餐饮店最容易留下信任的，不是“从没出过问题”，而是出现口味、出餐、等位等情况时，老板有没有当场处理。这个事件能拍出服务边界，也能避免后面内容只剩宣传。  
  - 待老板确认。

- **问题**：顾客进店最常问的一句话是什么？你通常怎么回答？  
  - **我的推测**：顾客大概率会问“一元火锅具体怎么点”“辣不辣”“几个人吃合适”“除了串串还有什么”。依据是“一元火锅”会吸引尝鲜者，但具体规则和口味决定他会不会坐下。  
  - 待老板确认。

- **问题**：有没有一位老客，第一次为什么来、第二次为什么又来？请说出他原话。  
  - **我的推测**：第一次可能由价格或短视频吸引，第二次更可能由口味、某一道菜、老板做法或就餐氛围留下。真正的差异化要以老客第二次回来的理由为准，而不是老板自己认为“配方正宗”就足够。  
  - 待老板确认。

- **问题**：你亲手做的哪一步，别人接手后味道最容易不一样？请从备料、炒料、烤制或出菜里选一个动作讲清。  
  - **我的推测**：成都厨师做川菜9年，真正能支撑人设的不是“正宗”这个词，而是某一步可见、可反复拍、能解释口味差异的手艺。  
  - 待老板确认。

- **问题**：有没有明确不卖、不做的东西？这背后发生过什么具体事？  
  - **我的推测**：如果老板确实有不妥协的食材、做法或出餐边界，这会是人设内容的好素材；如果没有，也不要硬编“原则”。  
  - 待老板确认。

- **问题**：这个月店里发生过哪件小事，你到现在还记得？  
  - **我的推测**：可能是一桌客人对辣度的反应、一位顾客点单时的犹豫、一次备料失误后的调整，或者第一桌客人的到来。这类小事比“生意很好”更有画面，也更适合做真实内容。  
  - 待老板确认。

## 一句话定位

**成都厨师做川味串串火锅、川味烧烤、川菜，替南乐人解决晚饭。**

这句话不把账号说成泛泛的“川味美食分享”，而是把身份、地域、三项品类和具体价值放在一起：观众刷到时能立刻判断，自己下班、带娃、朋友聚餐时是否需要关注。

## 六维地基

### 1. 人设定位

- **原料在哪**：  
  真材料有三句：  
  1. “成都来的川菜厨师”；  
  2. “做川菜9年”；  
  3. “每天下午4点出摊”。  

  “正宗川味配方”是卖点原料，不是人设；“专业”“认真”“有烟火气”这类词，如果没有动作和事件支撑，也只是形容词。  
  这个号应该把“厨师”翻译成观众看得见的行为：下午四点开始备料、穿串、炒料、烤制、出菜；把“成都来”翻译成他对川味做法的坚持和具体判断，而不是喊口号。

- **人设标签句**：  
  **下午四点开灶的成都厨师**

- **用了哪个入口**：  
  **特殊经历 + 职业身份**。  
  成都来南乐半年、做川菜9年，不是凭空设计的反差，而是现成的、能持续拍下去的职业经历。

- **验证**：  
  这个人设能立住，前提是每周都能拍到真实的“四点开灶”和厨师实际参与的关键步骤。  
  他不是只在镜头前说“我是成都厨师”，而是要让观众反复看见：他在哪里做、做哪一步、如何判断火候或味道。只要本人稳定掌勺，这个标签就可验证、可长期生产。  
  如果实际日常不由本人掌勺，或下午四点并非稳定开灶时间，这个人设就需要调整，不能硬立。

- **在同类账号里的位置**：  
  同城餐饮同行常见人设是“热情老板”“实惠老板”“探店口播老板”，内容容易落到价格和菜品展示。  
  这个号的差别不该是“我更正宗”这种难验证的话，而是：**固定时间、固定身份、固定现场的成都厨师开灶记录。**  
  别人拍“今天有什么活动”，他拍“今天四点，这锅底料是怎么从空锅变成晚饭的”。

- **证据链**：  
  1. **四点开灶过程**：固定记录备菜、炒料、串签、烤制中的一个环节；  
  2. **厨师判断**：为什么这一步先放、什么时候看状态、不同食材如何处理；  
  3. **真实顾客场景**：顾客问辣度、点单犹豫、第一次尝试后的反馈，前提是获得对方同意；  
  4. **成都与南乐的味觉交流**：只讲自己的做法和观察，不贬低本地口味或同行。

- **边界**：  
  不说“全南乐最正宗”“谁家都比不上”；不为了立人设编辛苦经历；不拍假装很忙、假装顾客爆满的画面；不把同行写成反面角色。  
  人设一旦只剩“成都来的”而没有持续的手艺现场，观众很快就会忘记。

### 2. 用户定位

- **一句话画像**：  
  **下班前还在群里问“晚上吃啥”的南乐新锐白领，和接完孩子、想带家人吃一顿热乎饭的宝妈。**

- **主攻人群**：  
  1. **新锐白领**：下班后的晚餐、同事小聚、朋友见面是高频场景；他们需要的是不用研究太久、能坐下来吃、价格门槛不高的选择。  
  2. **精致妈妈**：接孩子后、周末带家人、招待亲友时，需要一个能兼顾口味选择和就餐便利的晚饭去处。  

  选择这两类，是因为他们和“下午四点开灶—晚餐时段到店”的消费链路最贴合。  
  **暂不主攻银发族和小镇中老年**，不是他们不能消费，而是他们更依赖熟人推荐和线下口碑，短视频起号阶段不宜把第一批内容做得过于宽泛。

- **为什么不服务另一批**：  
  不优先追逐只想找最低价、没有明确就餐计划的泛流量；也不承诺满足所有重度川味爱好者的个人口味。  
  更不服务“刷到一条视频就要求全店菜品、价格、体验完全符合预期”的人群——餐饮体验有个人口味差异，账号不能靠夸张承诺接客。

- **他们心里真正想的**：  
  白领心里可能是：“别让我下班还要研究半天，找个能坐下来好好吃的地方。”  
  宝妈心里可能是：“今天不想做饭，但也不想随便对付。”  
  这两个念头都不是“我要看厨师教学”，所以视频要从他们的晚饭场景切入，再让厨师手艺成为理由。

- **决策链路**：  
  他们通常会先刷到一条有画面感的内容，再进主页确认：在哪里、什么时候开、主要吃什么、味道大概如何。随后可能把视频发给同事、家人，等到临近晚餐时再决定。  
  这意味着账号不能只靠一条促销视频成交，而要先连续积累“厨师本人、真实出餐、三类品类、就餐场景”四类证据。

- **什么时刻会想起你**：  
  - 下午下班前，群里开始讨论晚饭；  
  - 接完孩子后，不想再回家做饭；  
  - 周五下班、周末见朋友；  
  - 家里来了亲友，想找一桌能吃串串、烧烤、川菜的地方。  

- **他们在平台上可能会搜**：  
  “南乐串串火锅”“南乐烧烤”“南乐川菜”“南乐晚上吃什么”“南乐聚餐”“南乐一元火锅”。  
  其中具体搜索词是否符合本地习惯，待发布后根据抖音搜索词和评论进一步确认。

### 3. 内容定位

- **长期提供什么价值**：  
  **替南乐人把每晚吃什么，拍成看得见的川味现场。**

- **内容方向**：  
  选择**多元四类打底 + 一个固定王牌栏目**。  
  原因是新号没有验证过的数据，直接赌一个复杂单一主题风险高；但纯四类内容又容易松散，所以用“下午四点开灶”做统一栏目，把知识、故事、过程和观点都收进同一个真实场景。  
  不选择纯单一主题，是因为“每天开灶”虽稳定，但仅靠一个动作连续拍很容易重复；需要串串火锅、烧烤、川菜轮流提供新画面和新事件。

- **王牌栏目**：  
  **《下午四点，成都厨师在南乐开灶》**  
  每集只拍一个真实任务：炒一锅料、备一类串、烤一份食材、出一道川菜，或处理当天发生的一件小事。

#### 当前阶段配比

- **作用配比：流量型45% / 人设型25% / 变现型30%**  
  这是起号期合理的结构：流量型是最大块，负责让陌生人先认识“成都厨师+川味晚饭”这个符号；人设型不能太少，否则账号只剩菜品；变现型保留30%，从起步阶段就建立到店理由，但不把主页做成广告墙。

- **每一块用什么形式做**：  
  - **流量型45%**：以晒过程、轻知识、地域差异为主，少量段子或一人分饰多角。重点拍“成都厨师在南乐做晚饭”带来的反差、晚饭共鸣、锅气和现场感。  
  - **人设型25%**：以真实故事、职业观点、开灶日常为主。重点不是卖苦，而是让人记住这位厨师为什么从成都来到南乐、做菜时坚持什么。缺少真实事件的部分，先不拍。  
  - **变现型30%**：以晒过程和教知识为主。每条只证明一个成交理由：比如一元火锅的低门槛、厨师本人掌勺的手艺、三类品类能覆盖不同晚饭场景。画面必须有过程，不靠空口夸味道。

- **题材配比：主赛道75% / 目标人群兴趣25%**  
  - 主赛道75%中，**川味串串火锅25%、川味烧烤25%、川菜25%**，三个品类轮流成为单条主角，保持并列，不互相降级。  
  - 目标人群兴趣25%围绕“下班晚饭、带娃吃饭、朋友聚餐、周末解压、南乐本地生活”展开。  
  这样做不是偏离餐饮，而是先让观众觉得“这说的是我今晚的处境”，再接住这三类产品。

- **主力形式**：  
  档案没有提供“数据最好的内容类型”，因此目前不能把某种形式说成已验证主力。  
  **暂定以晒过程为主力形式，连续测试20—30条。** 原因是现有硬资源最明确：本人掌勺、下午四点出摊、三类产品都具备制作过程；它比强口播、剧情表演更容易稳定产出。  
  如果后续数据显示知识口播或地域话题的完播、关注明显更高，再调整主力，但不能靠感觉替换。

- **用户路径怎么走**：  
  - **刷到**：流量型内容，用晚饭场景、地域差异、反差动作让陌生人停下来；  
  - **记住**：人设型内容，反复强化“下午四点开灶的成都厨师”；  
  - **信**：变现型内容，让观众看见备料、烹饪、出餐以及三类品类各自的存在；  
  - **联系或到店**：主页明确位置、营业时间和主营品类，变现型视频只引导一次到店。

#### 三种视频各怎么拍

**流量型：不讲卖点，只让陌生人停下来**

- **四大脚本**：  
  方向：地域差异 + 下班晚饭共鸣。  
  结构：教知识·拆解型——“很多人以为川味只靠辣”→拍一口锅底、一把食材、一个烹饪动作→厨师讲自己观察到的差异→提问互动。  
  结尾行动指令：**“你们晚饭更想吃串串、烧烤还是川菜？”**

- **起号36计**：  
  **第31计·南北/地域差异：**同样是准备晚饭，成都厨师先做的步骤，与南乐顾客常问的口味问题形成对照→讲一个具体差异→请评论区说本地习惯。  
  这条的事件是“同一顿晚饭的两种期待”，不是空讲地域优劣。

**人设型：不推菜品，只让人记住厨师**

- **四大脚本**：  
  方向：职业经历。  
  结构：讲故事·小有成就型——“来南乐半年，最怕的不是没人认识我”→讲一个真实阻碍→如何从每天四点开灶开始适应→落到做菜的人对一顿晚饭的理解。  
  前提：阻碍和转机必须由老板提供真实事件。  
  结尾行动指令：**“想看我四点开灶，就关注。”**

- **起号36计**：  
  **第7计·一句话设定故事感：**普通动作“下午四点点火”+真实设定“一个成都厨师来南乐半年”→让观众等待这锅晚饭会迎来谁。  
  只拍真实日常，不补编感人情节。

**变现型：让本地人产生到店理由**

- **四大脚本**：  
  方向：一元火锅如何降低首次尝试门槛。  
  结构：晒过程·火车节——顾客第一次问“怎么点”→厨师按真实点单规则说明→拍串串火锅出锅或搭配烧烤、川菜的实际画面→落到适合什么就餐场景。  
  成交理由：**一元火锅低门槛**，但规则、品类和价格细节必须以店内真实情况为准。  
  结尾行动指令：**“想吃川味晚饭，下午四点后到店。”**

- **起号36计**：  
  **第10计·情境还原：**还原一位新顾客第一次点单→顾客问一元火锅怎么吃→厨师现场说明并出餐→让旁观者看懂适用场景。

## ⚡ 差异化：A + 变量B

### 1. 常规菜品展示 + 固定开灶时间

- **常规A**：同行拍一盘菜、一锅串串，加字幕“好吃不贵”。  
- **变量B**：情境类的**换场景**——把展示菜品换成“下午四点开灶到晚饭上桌”的真实时间线。  
- **A+B长什么样**：  
  《下午四点，今天先备的是串串火锅》：从空的备料台开始，拍食材处理、串签、下锅前的一步，不急着拍成品。  
  它服务白领和宝妈，因为他们看到的是“今晚晚饭正在被准备”，而不是又一条静态菜品广告。

### 2. 厨师讲口味 + 南北/地域差异

- **常规A**：厨师对镜头讲“川味要麻要辣”。  
- **变量B**：情境类的**南北差异**。  
- **A+B长什么样**：  
  《成都厨师来南乐半年，顾客点川菜最常问我的一句话》：先抛真实问题，再通过一道正在做的川菜讲自己的处理方式，最后问本地观众更习惯哪种口味。  
  它服务目标用户的身份确认和互动，而不是用“成都”压过本地饮食习惯。

### 3. 一元火锅介绍 + 情境还原

- **常规A**：举着价目牌讲一元火锅。  
- **变量B**：人物/情境类的**情境还原**。  
- **A+B长什么样**：  
  还原新顾客第一次问“怎么点”的真实场景：镜头拍菜单、拿串、下锅、出锅；老板只解释真实规则。  
  它服务第一次想尝试的人，帮他降低“不知道怎么点、怕尴尬”的门槛，不是单纯靠低价吸引围观。

## ⚠️ 这个号最大的风险

1. **“一元火锅”压过了完整品类。**  
   如果账号反复只拍价格，观众会把店理解成低价尝鲜点，川味串串火锅、川味烧烤、川菜的消费价值接不住。解决方式不是少拍一元火锅，而是让三类品类在内容中轮流当主角。
