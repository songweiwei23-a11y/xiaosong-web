# 1. 本阶段判断

这是**起号期的大流量任务**，当前最重要的不是证明卖货能力，而是先确认：哪些“大码女生的真实处境”，能让县城本地陌生人停下来、评论并关注。

目前和目标之间有三层差距：

- **缺少数据依据**：账号刚开始发，还没有稳定播放、完播、评论或关注数据，暂时无法判断哪种选题、表达方式和试穿形式最有效。
- **缺少本地识别信号**：目标是先让同城的人看到，但现有内容还没有经过数据验证，无法确认观众是否来自县城及周边。
- **缺少内容样本对照**：已有方向包含穿搭教学、试衣过程和大码女生的穿衣烦恼，但目前不能确定是“共鸣情境”还是“真实试穿”更能带来陌生人互动。

因此，本阶段的药方是：**先用真实的大码穿衣处境拿流量，再用阿梅本人和门店试穿现场，验证用户是否愿意进一步了解。**

---

# 2. 本阶段重心方向

建议沿用《内容定位方案》中的作用配比：**流量型45% / 人设型25% / 变现型30%**。本阶段优先看流量型是否能让本地陌生人产生身份确认，再观察人设和试穿内容能不能承接信任。

## 方向一：系列《试衣间门口的那一句》

- **负责目的**：流量
- **本阶段比例**：约45%
- **为什么选它**：  
  直接对准“大码女生进服装店前，不敢问尺码、怕尴尬、怕没有合适衣服”的真实需求。档案明确提到，很多大码女生在其他店买不到合身衣服；内容定位也已经确定，这个系列专门拍“进店前不敢问的话”。
- **怎么打**：  
  用一人分饰多角或轻情境还原，拍一句没说出口的话，例如：
  - “有没有我能穿的？”
  - “这个最大到多少码？”
  - “我试一下会不会不合适？”
- **脚本重点**：  
  开头直接进入门店或试衣间门口的场景，不先介绍阿梅、不先展示衣服；中间还原犹豫，结尾留下评论问题。
- **判断重点**：  
  看陌生人是否在评论区说“我也遇到过”“不敢进店”“问过类似的话”，以及评论者是否出现本地语境。

## 方向二：真实试穿过程

- **负责目的**：变现，同时承担信任建立
- **本阶段比例**：约30%
- **为什么选它**：  
  商业定位已经确定，当前最硬的成交理由是“50码以上有可试穿款”。档案也明确有连衣裙、外套、裤装和试衣间。单拍衣架不能证明顾客能不能穿，必须让观众看到拿尺码、进试衣间、上身判断的过程。
- **怎么打**：  
  每条只围绕一个品类和一个试穿问题：
  - 连衣裙：看腰腹、肩背、长度；
  - 外套：看肩背、抬手、活动空间；
  - 裤装：看腰、臀、腿部活动。
- **脚本重点**：  
  不把每件衣服都说成适合；适合就说适合，不适合就说明卡在哪里。涉及具体款式时，明确“这条视频只代表当前实际可试的款”，避免让观众误解成所有款都有50码以上。
- **判断重点**：  
  看评论是否开始出现“这个码能不能试”“哪类裤装有可试的”“怎么到店”等具体问题。没有这些反馈时，不急着增加促销表达。

## 方向三：阿梅的职业经历与门店观点

- **负责目的**：人设
- **本阶段比例**：约25%
- **为什么选它**：  
  人设事实卡确认了阿梅是老板本人，做大码女装6年，本地开店3年。内容定位也已经确定，人设型内容要让用户记住“给大码女生留试衣间的阿梅”。
- **怎么打**：  
  从真实职业场景切入，不空讲“我很懂大码女生”，而是拍：
  - 阿梅整理试衣间时讲一个确认真实发生的片段；
  - 阿梅讲自己为什么不隔着镜头保证“你肯定能穿”；
  - 阿梅说明试衣时自己通常先看哪些地方。
- **脚本重点**：  
  只使用阿梅确认过的真实经历。顾客原话、顾客故事和具体事件目前没有充分资料，未确认前用【待确认】占位，不把推测写成事实。
- **判断重点**：  
  看评论里是否开始直接称呼“阿梅”、询问阿梅在不在店、表达对她判断方式的认可。若只有泛泛点赞，没有人物记忆，说明人设内容还没有落到具体行为上。

# 3. 每类目的的结尾动作

| 视频目的 | 只保留一个结尾动作 | 适用方式 |
|---|---|---|
| 流量型 | **评论区说一句** | 让有相同尺码经历的人留下自己的情况，不加到店、私信或购买引导 |
| 人设型 | **关注阿梅** | 让用户继续看阿梅的真实门店经历，不在结尾顺带卖衣服 |
| 变现型 | **到店找阿梅试穿** | 对应《商业定位方案》的原步骤：**“兴趣 → 到店前确认”**，把观众从看到试穿过程推进到实际到店 |

每条视频只使用其中一个动作，不在同一条里同时说“关注、评论、私信、到店”。

# 4. 本阶段暂停什么

## 1. 暂停只拍挂版新品

- **依据**：账号定位方案已经指出，最该避开的坑是“只拍挂版新品，没人愿意看完”。
- **原因**：挂在衣架上的衣服只能证明店里有货，不能回答大码女生最关心的“我能不能穿、穿上哪里合适”。
- **替代方式**：至少拍出一个真实动作：拿尺码、进试衣间、抬手、坐下、看长度或判断腰臀位置。

## 2. 暂停没有真实素材支撑的顾客故事

- **依据**：内容定位已经明确，顾客故事需要先征得同意；当前前采中顾客原话、老客复购故事仍是待确认。
- **原因**：起号期最需要建立信任，编造顾客经历会让人设和门店可信度一起变弱。
- **替代方式**：先拍阿梅本人、试衣间、货品和已经确认的职业事实；真实顾客事件出现后再加入故事型内容。

## 3. 暂停把价格或促销当主要流量入口

- **依据**：商业定位没有提供价格、折扣或低价优势；内容定位也明确不把“特价清仓”当主推路线。
- **原因**：当前目标是让同城陌生人先产生共鸣，不是用价格吸引一批只等折扣的人。
- **替代方式**：拍“有没有合适尺码”“试穿是否尴尬”“这类版型该看哪里”，价格画面如确有需要，金额使用【待确认】或金额打码。

# 5. 30 天执行规则

## 规则一：每条开头先说清“人群＋处境”

开头不要先说“今天上新”或“这是一条连衣裙”，而要先让目标观众认出自己，例如：

- “大码女生进店，最难开口的不是多少钱。”
- “买裤子总卡在腰和腿之间，先别急着看颜色。”
- “换季想买外套，抬手这一动作一定要试。”

前几秒只完成一件事：让观众知道这条内容和自己的穿衣处境有关。

## 规则二：一条视频只解决一个问题

每条只选一个问题、一个品类或一个情绪点：

- 只讲一次“进店不敢问尺码”；
- 只拍一条裤装的试穿判断；
- 只讲阿梅一次确认过的职业经历。

不要在一条视频里同时讲连衣裙、外套、裤装，也不要同时安排评论、关注和到店。

## 规则三：画面必须出现能验证内容的现场动作

选题和脚本不能停在口播。每条至少安排一个可核验动作：

- 流量型：站在门口、试衣间前、一人分饰两角；
- 人设型：阿梅整理试衣间、拿回一件不建议直接推荐的衣服；
- 变现型：展示实际可试尺码、拿衣服、上身活动、给出适合或不适合的判断。

没有真实试穿者授权时，使用阿梅本人或只拍衣服、手部和试衣间局部，不编顾客反应。

# 6. 复诊条件

出现以下迹象时，可以考虑从起号期进入下一阶段：

- 近期多条内容都有陌生人在评论区描述自己的尺码困扰，或主动问“哪里能试”“店在哪”“有没有某类衣服”；
- 评论者开始直接称呼阿梅，询问她是否在店里，说明人设已经被记住；
- 试穿内容下出现具体的连衣裙、外套、裤装尺码问题，而不只是泛泛夸好看，说明观众开始把内容和实际需求连接起来；
- 同城观众的互动来源逐渐稳定，且比账号早期的本地互动表现更好；
- 平台数据能够分辨出哪类开头、哪种试穿动作和哪类生活场景更容易带来陌生人停留与关注。当前没有历史数据，这部分先标记为**待建立**。

进入下一阶段后，重心不再只是测试“什么能让人停下来”，而是：

- 适当提高真实试穿和具体尺码判断的比重；
- 保留《试衣间门口的那一句》，但从泛共鸣转向更具体的到店前问题；
- 增加阿梅的真实职业经历和已确认的顾客案例；
- 让流量内容负责吸引，变现内容负责承接，不再平均测试所有方向。
