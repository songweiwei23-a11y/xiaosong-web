# 🚀 起号方案

## 📌 先说结论

- **建议主攻：36计·第9计 一人分饰多角。**  
  阿梅本人能同时演“站在门口想问尺码的人”和“准备离开的人”，不需要顾客出镜，不需要店员配合。门店的衣架、尺码牌、试衣间帘子就是现成场景。它正好打开王牌栏目 **《试衣间门口的那一句》**：把大码女生不愿说出口的犹豫拍出来，先让县城本地25—40岁女性觉得“这说的就是我”。

- **备选：**
  1. **36计·第32计 换个视角**：第9计连续发满5条后，前3秒流失仍明显时切入。用“站在试衣间外等答案的人”视角，减少正面对口播的重复感。
  2. **36计·第10计 情境还原**：当评论、私信开始出现“有没有我能试的码”“裤子怎么选”时切入。它负责承接《先试，再决定》，把“50码以上有可试穿款”拍成看得见的现场证据。
  3. **36计·第15计 正确做法VS错误做法**：第10计发3条后，用户仍只看热闹、不问试穿时切入。用“只看挂版”与“先确认可试尺码”的对比，补足用户到店前的判断方法。

- **明确不做：**
  1. **街头采访**：当前确认资源只有阿梅和门店，没有街采人员、路人授权和收音条件。硬拍会拖慢更新，还会让内容偏离“试衣间、试穿、尺码”这个核心场。
  2. **对比改造**：当前没有确认的顾客出镜素材，也不能为了反差让人扮演顾客。大码女装更适合拍真实尺码与真实试穿判断，不拍夸张变装。

- **多久能看出跑没跑通：**  
  用前20条作为第一轮判断。主攻打法连续测试5条，备选打法各测试3—5条；零粉到一千粉、非关注播放逐渐稳定，是起号阶段的重要里程碑。  
  但不只看粉丝数：评论里是否出现“我也怕问尺码”“店里有能试的吗”，主页访问后是否有本地用户来问试穿，同样决定这条路是否跑通。

## 🧮 起号期内容配比

### 起号期：到一千粉、流量稳定之前

| 作用 | 占比 | 为什么适合阿梅大码女装店 |
|---|---:|---|
| 流量型 | 45% | 新号先抓住“进店不敢问尺码”“怕没有能试的码”这类强人群共鸣，让本地陌生用户先停下来。 |
| 人设型 | 25% | 阿梅做大码女装6年，是稳定可信的人设事实；但没有确认的顾客故事不能硬拍，因此只占四分之一。 |
| 变现型 | 30% | “50码以上有可试穿款”必须从第一批内容就反复被看见，用户才会知道店里能解决什么问题。 |

### 每一种怎么拍

#### 1. 流量型：45%

- **出发点**：  
  围绕“人”——大码女生进店前的尺码犹豫；场景固定在衣架区、尺码牌前、试衣间门口。  
  爆款元素押 **人群 + 反差**：衣服挂在眼前，但人先把手收回去；想买衣服，最难问的却不是价格。

- **形式**：  
  主用 **36计·第9计 一人分饰多角**，补用 **36计·第32计 换个视角**。

- **脚本结构**：  
  顾客角色的犹豫 → 另一个角色的退缩回应 → 阿梅本人说出真实处境 → 评论互动。

- **结尾行动指令**：  
  **“有过这种经历的，评论区说一句。”**

#### 2. 人设型：25%

- **出发点**：  
  只讲阿梅本人做大码女装6年的职业经历，不把未确认的顾客经历写成故事。让用户记住：这是一个长期在门店里看尺码、看试穿、看顾客犹豫的老板。

- **形式**：  
  用 **讲故事·平凡英雄型**。  
  目前只拍已经确认的事实：阿梅做大码女装6年、本地开店3年、店内有试衣间、主卖大码连衣裙、大码外套和大码裤装。

- **脚本结构**：  
  普通日常动作 → 做大码女装6年的职业事实 → 一个真实可见的门店细节 → 关注。

- **结尾行动指令**：  
  **“想看阿梅讲门店里的真事，就关注。”**

- **待确认后再加的素材：**  
  阿梅最近一次因为尺码、版型或试穿感受而没有马上推荐某件衣服的真实事件。确认事件后，再拍更完整的人设故事。

#### 3. 变现型：30%

- **出发点**：  
  围绕“人、货、场”：本地需要试大码女装的女性、门店实际在售的连衣裙/外套/裤装、试衣间和尺码区。  
  每条只证明一个成交理由：**50码以上有可试穿款。**

- **形式**：  
  主用 **36计·第10计 情境还原 + 晒过程·火车节**；  
  用户开始问具体判断方法后，用 **36计·第15计 正确做法VS错误做法 + 教知识·解题型**。

- **脚本结构**：  
  顾客需求 → 确认当次实际可试尺码 → 试穿前看一个位置 → 如实说出本次货品的结论。

- **结尾行动指令**：  
  **“想现场试穿的，到店找阿梅。”**

### 过线之后怎么变

过了一千粉、非关注播放较稳定后，内容从“先让人刷到”转为“让人更信、让人来试”：

- 流量型降到 **35%**
- 人设型升到 **30%**
- 变现型升到 **35%**

原因很直接：前期先用《试衣间门口的那一句》筛出尺码困扰人群；后期要补阿梅的职业判断，也要提高《先试，再决定》的实际试穿证据密度。

### 和已定内容定位怎么对上

- **主力形式对上**：主攻第9计，直接服务《试衣间门口的那一句》；第10计服务《先试，再决定》。
- **主系列对上**：前10条以“没问出口的话”为主，穿插真实试穿；第11条开始提高试穿过程比例。
- **核心卖点对上**：变现内容不空说“尺码多”，直接拍尺码牌、实际拿货、试衣间和当次可试结果。

## 🎯 主攻打法：36计·第9计 一人分饰多角

### 为什么是阿梅能拍的

1. **出镜条件够用**：已确认由店主阿梅本人出镜，一人就能完成两个角色，不依赖顾客和店员。
2. **拍摄场景现成**：县城商业街门店、衣架、尺码牌、试衣间都是真实内容场，不需要搭景。
3. **素材每天都能换**：连衣裙、外套、裤装轮换；上班、带娃、换季、聚会等场景轮换，不会只剩“换一件衣服”。
4. **表达门槛低**：每条只围绕一句“没问出口的话”，不是长篇口播。阿梅先记住两三句台词，再分别拍两个角色。
5. **符合起号任务**：它不急着卖货，先抓“大码女生问尺码时的尴尬和犹豫”，更适合陌生人刷到后的身份确认。

### 结构公式

**角色A想问尺码 → 角色B替自己打退堂鼓 → 阿梅本人说出共同处境 → 评论互动**

套到阿梅店里：

> 【顾客角色，站在衣架前】“这件有我能试的吗？”  
> 【退缩角色，把手从衣架收回来】“算了，我再看看。”  
> 【阿梅本人站在试衣间门口】“很多人走出去，不是没看中，是不想再问第二次。”  
> 【结尾】“有过这种经历的，评论区说一句。”

### 配什么脚本讲

- **搭配结构：聊观点·论证型**
- **第9计负责的内容**：让片子里发生“想问—退缩—离开”的小冲突。
- **聊观点·论证型补上的内容**：让阿梅最后那一句不是单纯演段子，而是落在她做大码女装6年见过的真实人群处境上。
- **不补成交理由**：主攻内容是流量型，不讲“店里有什么码”，不引导到店，不把共鸣片拍成广告。

### 前3条具体拍什么

#### 第1条  
**《大码女生进店，最难问出口的那句话》**（人群）

- **首帧**：阿梅站在衣架前，手碰到一条大码连衣裙又收回来。
- **角色A**：拿着衣服，小声问：“这件有我能试的吗？”
- **角色B**：停两秒，把衣服挂回去：“算了，我再看看。”
- **本人收尾**：阿梅站在试衣间帘子旁：“很多人进店先看衣架，不是不喜欢，是怕问完以后更尴尬。”
- **停下来的原因**：第一句直接点中大码女生最熟悉、也最少被直接说出来的时刻。
- **结尾**：  
  **“有过这种经历的，评论区说一句。”**

#### 第2条  
**《上班要穿裤子时，我最怕先听到这句》**（人群）

- **首帧**：裤装区近景，阿梅拿起一条裤子，对镜头停半秒。
- **角色A**：穿通勤外套，问：“这条裤子有大一点的吗？”
- **角色B**：还没等回答，自己接话：“没事，我就随便看看。”
- **本人收尾**：阿梅站在镜前：“上班穿裤子的人，怕的不是款式少，是看中一条以后，不知道自己有没有机会试。”
- **停下来的原因**：把“上班穿裤子”这个具体场景，和“尺码犹豫”放在同一秒里。
- **结尾**：  
  **“你上次问尺码，是怎么开口的？”**

#### 第3条  
**《换季买外套，很多人先把手从衣架上收回来》**（反差）

- **首帧**：阿梅伸手拿外套，手停在衣架前。
- **角色A**：看着外套说：“这件我还挺喜欢的。”
- **角色B**：立刻接一句：“喜欢也没用，先别问了。”
- **本人收尾**：阿梅拉开试衣间帘子：“有时候人不是没想买，是已经习惯了先替自己说‘算了’。”
- **停下来的原因**：从“喜欢”到“算了”的反差，让用户快速代入。
- **结尾**：  
  **“这句话你对自己说过吗？”**

### 边界

1. **不把情境演绎伪装成真实顾客对话**：首帧字幕固定标注“门店常见场景演绎”。
2. **不攻击同行或店员**：矛盾只放在用户自己的犹豫里，不写“别人不愿意拿尺码”“店员态度不好”。
3. **不在流量视频里承诺全部货品都有大码可试**：这类内容不讲库存，不把人群共鸣和货品承诺混在一起。
4. **不连续拍同一句“没有码”**：每条必须换一个生活场景：上班、换季、聚会、带娃、走亲友。
5. **不把身材当笑点**：笑点只能来自“想问又退缩”的日常心理，不能来自体型。

## 🔄 备选打法

### 备选一：36计·第32计 换个视角

- **什么情况下切过去**：  
  第9计连发5条后，评论有共鸣，但前3秒流失明显；说明“对话内容”成立，“正面演戏画面”开始重复。

- **为什么阿梅能拍**：  
  不需要增加人员。阿梅把手机放在“顾客站的位置”，镜头只拍衣架、尺码牌、阿梅拿货的手、试衣间帘子，门店就是现成场景。

- **怎么套到这个号上**：  
  从“站在试衣间外等答案的人”视角拍。镜头先看尺码牌，再看阿梅走向衣架，最后停在试衣间帘子前。

- **配的四大脚本结构**：  
  **晒过程·事件体验**

- **它补上的是什么**：  
  补沉浸感。第9计靠角色对话制造代入，第32计让观众直接站到“等答案的人”那个位置。

- **第一条拍什么**：  
  **《站在试衣间外的人，最怕听见哪句话？》**（人群）  
  镜头从试衣间外往衣架区拍，阿梅拿起尺码牌，再走向镜头。字幕只写：“我不是怕试，我是怕根本没有能试的。”

### 备选二：36计·第10计 情境还原

- **什么情况下切过去**：  
  评论或私信开始出现“店里有我能试的吗”“大码裤子怎么选”；说明用户已从共鸣进入具体需求。

- **为什么阿梅能拍**：  
  阿梅是老板本人，门店有试衣间，店内实际卖大码连衣裙、大码外套和大码裤装；她只需要拍当天确认有可试尺码的货，不需要额外演员。

- **怎么套到这个号上**：  
  “来找一条上班能穿的裤装”这个需求出现后，阿梅先确认需求，再去裤装区拿当次实际可试的尺码，最后在镜前验证裤腿、臀腿活动或坐下时的感受。结论只说这一次货品，不扩大到全店。

- **配的四大脚本结构**：  
  **晒过程·火车节**

- **它补上的是什么**：  
  补成交理由。用户能看到“50码以上有可试穿款”不是口头承诺，而是尺码牌、拿货、试衣间都在现场发生。

- **第一条拍什么**：  
  **《这条大码裤装，先看有没有能试的码》**（反差）  
  首帧拍尺码牌；阿梅说：“裤子挂着好不好看先放一边，先确认今天有没有能试的。”随后拍实际拿出的可试款与试衣间门口。

### 备选三：36计·第15计 正确做法VS错误做法

- **什么情况下切过去**：  
  第10计已发3条，播放和完播正常，但到店询问仍少；说明用户看到了货，却没建立“为什么我必须去现场试”的认知。

- **为什么阿梅能拍**：  
  一个人、一排衣架、一间试衣间就能完成。错误示范和正确示范由阿梅先后拍摄，不用顾客配合。

- **怎么套到这个号上**：  
  错误做法：只看挂版、只看花色，就判断能不能穿。  
  正确做法：先问当次有没有可试尺码，再进试衣间确认一个最在意的位置。  
  对比的是判断路径，不贬低其他门店，也不把同一件衣服换种穿法当对比。

- **配的四大脚本结构**：  
  **教知识·解题型**

- **它补上的是什么**：  
  补用户行动理由：到店不是为了“随便逛一逛”，而是为了实际确认尺码和版型。

- **第一条拍什么**：  
  **《别只看挂版，大码外套先确认这一件事》**（反差）  
  左边画面：阿梅看一眼挂版就点头。  
  右边画面：阿梅拿起尺码牌，确认当次是否有实际可试款，再到试衣间前举起外套。  
  收尾：“挂版只能看款，试穿才能看这件衣服到底合不合身。”

## 🧪 怎么测

### 一次只改一个核心变量

第一轮只测 **开头形式**，其他条件保持一致：

- 同一类场景：都拍“问尺码时的犹豫”
- 同一位出镜人：阿梅
- 同一地点：衣架区或试衣间门口
- 同一时长：控制在同一时长区间
- 只改变：  
  **第9计的双角色对话**，或 **第32计的第一视角**

第二轮再测 **场景变量**：

- 上班裤装
- 换季外套
- 聚会连衣裙
- 带娃活动

第三轮才进入 **货品试穿验证**：

- 当天有可试尺码的大码裤装
- 当天有可试尺码的大码外套
- 当天有可试尺码的大码连衣裙

### 每计测几条、看什么指标

| 打法 | 最少测试量 | 主要看什么 |
|---|---:|---|
| 第9计 一人分饰多角 | 5条 | 非关注播放、前3秒流失、评论里的身份确认 |
| 第32计 换个视角 | 3条 | 前3秒留存、完播、评论是否更愿意讲自己的经历 |
| 第10计 情境还原 | 3—5条 | 主页访问、私信或到店询问、是否出现“有没有能试的码” |
| 第15计 正确做法VS错误做法 | 3条 | 收藏、主页访问、用户是否开始问具体试穿问题 |

### 什么信号算“这计行”

- **第9计行**：评论出现“我也是”“我就不敢问”“每次都说随便看看”；同类视频连续几条都能拿到陌生人播放。
- **第32计行**：前3秒留存比第9计更稳，且用户能从字幕和画面立刻看懂“这是在等尺码答案”。
- **第10计行**：用户从共鸣评论转向真实需求，开始问“店在哪”“有什么能试”“裤子有没有大码”。
- **第15计行**：用户开始收藏、转发给同样有尺码困扰的人，或评论说“原来要先看这个”。

### 什么信号算“换掉”

- 同一种打法发满最低测试量，首帧、台词、场景都已轮换，仍没有目标用户停留和评论，就换打法。
- 播放有了，评论却都是与尺码无关的泛互动，说明吸引来的人不准，标题收窄到“大码女生”“上班裤装”“试衣间”等具体场景。
- 变现视频有人看、没人问，说明证据不够：下一条增加尺码牌、实际拿货、试衣间门口三个镜头，不增加促销口播。

## 📅 30天节奏

以下按**每周2次集中拍摄、每周发布5条、30天完成20条**排产。每次拍摄只在门店完成：一次拍流量情境，一次拍试穿过程和素材补录。

### 第1—7天：先把“尺码犹豫”拍准

  - 拍5条第9计一人分饰多角。
  - 主题依次为：进店问尺码、上班裤装、换季外套、连衣裙、带娃逛街。
  - 补拍门店空镜：门头、衣架、尺码牌、试衣间帘子、镜子。

- **交付物**

  - 可复用门店素材库1组。
  - 评论关键词记录表1份。

## 📊 跑不通先查哪里

### 1. 现象：有曝光，但前3秒流失快

- **先怀疑**：  
  首帧只是衣架或阿梅站着说话，观众看不懂这条要讲什么。

- **下一步实验**：  
  把冲突放到第一秒：  
  “这件有我能试的吗？”  
  或者直接拍“手伸向衣架又收回来”的动作。  
  同一主题连拍5个不同开头，只换第一句话和首帧动作。

---

### 2. 现象：评论很多“我也是”，但没人问店里有没有能试的码

- **先怀疑**：  
  账号只拍到了情绪，没有让用户看见门店的试穿证据。

- **下一步实验**：  
  在连续两条流量内容后，固定插入一条《先试，再决定》。  
  每条变现内容必须出现：  
  **尺码牌近景 → 阿梅拿出实际可试款 → 试衣间门口。**

---

### 3. 现象：变现视频有人看，主页访问和到店询问少

- **先怀疑**：  
  视频只拍“衣服挂着”，没有讲清本次货品能不能试、该看哪里；或者结尾指令不明确。

- **下一步实验**：  
  用第10计重拍一条，只讲一件事：  
  “这条裤装，当天有没有可试尺码。”  
  结尾只说：  
  **“想现场试穿的，到店找阿梅。”**  
  不叠加私信、关注、评论等其他指令。
