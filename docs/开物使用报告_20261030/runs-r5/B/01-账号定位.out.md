# 🎯 账号定位方案

## 📌 核心结论（先看这 8 条）

1. **这是什么号**：县城实体店｜阿梅的大码女装试穿号  
2. **给谁看**：买衣服常卡在尺码的本地女性  
3. **人设标签**：给大码女生留试衣间的阿梅  
4. **主打内容**：流量45/人设25/变现30，主拍试穿过程  
5. **怎么赚钱**：刷到内容→到店试穿→选购大码女装  
6. **第一条拍什么**：大码女生最怕进店听到的话  
7. **最该避开的坑**：只拍挂版新品，没人愿意看完  
8. **多久能看出跑没跑通**：连续发满20条后看数据

## 🔍 先说这一行

- **归口**：本地实体店，属于 **B 服装鞋包类**；线上内容的任务不是全国发货，而是让县城及周边需要试穿大码女装的女性走进门店。

- **这行的钱怎么赚**：  
  大码女装店的核心不是靠“看一眼就下单”，而是靠**试穿后的合身感、搭配后的确定感、老客复购**。连衣裙、外套、裤装都属于需要上身判断的品类，顾客会看腰腹、臀腿、肩背、长度和活动是否舒服。  
  这行容易被库存卡住：尺码覆盖越宽，备货压力越大；款式进得太多，容易压货；只进“看着好看”的款，顾客试完不合适也留不住。因此账号不能只展示衣架上的货，得让人看见“这件衣服穿到什么身形上，哪里合适、哪里不适合”。

- **客人的决策链路**：  
  大部分顾客会先刷到视频，收藏或进主页看几条，再看看门店位置、有没有适合自己的尺码，最后到店试穿。她们通常不会只因一条视频立刻买，而是会先观察：  
  1）这家是不是真的有大码；  
  2）不是只拍瘦模特；  
  3）自己去店里会不会尴尬；  
  4）能不能实际试到。  
  所以账号要持续降低她的顾虑，而不是天天喊“上新”。

- **时间规律**：  
  服装消费会跟着换季、节假日、婚宴聚会、返工返校、天气骤变走。县城门店还会受到赶集日、周末、节前置装等影响。  
  内容上不必硬追热点，更适合围绕“换季不知道穿什么”“见人前想买一身”“裤子总卡腿”“想穿裙子又怕显肚子”等真实场景提前铺内容。

- **这行老板普遍会犯的错**：  
  最大的自嗨，是把“今天又到新款了”“这件显瘦”“这件高级”当成内容。老板看的是货，顾客在意的是：**我这个身材能不能穿、去试会不会难堪、穿完到底是什么样。**  
  阿梅目前的真实优势不是“款多”——档案没有这个依据；而是“50码以上可试穿”。这个优势若只写在简介里，等于没用，必须反复拍成看得见的现场。

- **同行现在都在拍什么**：  
  常见内容是挂版扫货、老板拿着衣服讲面料、瘦模特换装、音乐卡点。它们的问题是：观众看完只知道店里有衣服，不知道“我能不能穿”。  
  这个号的空档是：**让真正有尺码困扰的本地女性，看到一间愿意让她安心走进去试穿的店。**

## 🗣 我会先问老板的几个问题

- **问题**：最近一次顾客进店后没买，卡在哪一步？她当时说了什么？  
  - **我的推测**：她可能不是不喜欢款式，而是担心尺码、版型或试穿后的尴尬。依据是大码女装的购买门槛常出现在“能不能穿”和“穿上敢不敢看镜子”这一步。  
  - 待老板确认。

- **问题**：顾客进店最常问的一句话是什么？阿梅通常怎么回答？  
  - **我的推测**：高频问题可能是“有没有我能穿的”“最大到多少码”“这个肚子能遮住吗”。这决定视频开头该直接说哪句话，而不是自说自话。  
  - 待老板确认。

- **问题**：有没有一位老客，第一次为什么进来，后来又为什么回来？请讲清她买过哪类衣服、说过什么。  
  - **我的推测**：老客复购的原因，未必是“便宜”，可能是“记得我的尺码”“能直接试”“不怕进来被打量”。这才是顾客感受到的差异化。  
  - 待老板确认。

- **问题**：50码以上可试穿，具体是哪些款有、哪些款没有？遇到顾客需要更大或更小尺码时怎么处理？  
  - **我的推测**：这是账号最重要的信任证据，但必须说清边界。不能让观众误以为每一件都有50码以上。  
  - 待老板确认。

- **问题**：有没有明确不卖的货，或者不会推荐给顾客的情况？发生过什么？  
  - **我的推测**：如果阿梅会明确告诉顾客“这件不适合你”，这比说“我家都好看”更容易建立信任；但这件事必须有真实案例才能拍。  
  - 待老板确认。

- **问题**：店里最近发生过一件和“试衣”有关的小事吗？比如一位顾客试了很久、换了几条裤子、带朋友一起来。  
  - **我的推测**：门店最有价值的素材，往往不是新品，而是顾客从犹豫到愿意试穿的过程。  
  - 待老板确认。

## 一句话定位

**县城阿梅，替大码女生找能安心试穿的大码女装。**

## 六维地基

### 1. 人设定位

- **原料在哪**：  
  真正能做人设的材料只有三条：  
  1）阿梅本人是店主；  
  2）做大码女装6年；  
  3）门店里有50码以上可试穿款。  

  “专业、懂大码女生、服务好”都只是形容词，不能直接当人设。  
  这些形容词要翻成可拍行为，例如：顾客进店先问尺码，阿梅拿出可试穿的款；顾客试穿时，阿梅明确说这条裤子的腰、腿、臀部哪里合适，哪里不建议选。  
  但阿梅是否会这样服务，当前缺少真实素材，待确认后再写进文案。

- **人设标签句**：  
  **给大码女生留试衣间的阿梅。**

- **用了哪个入口**：  
  **痛点+职业**。  
  大码女生怕进店没尺码、怕试穿尴尬；阿梅做的是大码女装，并且店内有50码以上可试穿款。

- **验证**：  
  这个人设能立住，因为不是一句空承诺，而是可以持续被镜头证明：  
  - 店里真实有试衣间；  
  - 真实有50码以上可试穿款；  
  - 阿梅本人能连续出镜讲6年里反复遇到的尺码问题。  
  它也能拍超过十条：试连衣裙、试外套、试裤装，每类都能围绕“有没有尺码、上身哪里卡、试穿后怎么判断”展开。

- **在同类账号里的位置**：  
  同类账号常见人设是“穿搭老师型”“每日上新老板娘型”“身材焦虑安慰型”。  
  阿梅不需要硬装时尚导师，也不适合做夸张变装。她的位置应是：**一个把试穿这件事讲明白、留出空间让顾客自己判断的实体店老板。**  
  差别在于：别人先展示衣服，阿梅先承认顾客的尺码困扰，再用现场试穿给答案。

- **证据链**：  
  1）真实试衣过程：不同品类怎么上身、哪里需要看；  
  2）尺码问答：回答顾客常问的那一句；  
  3）阿梅的职业经历：做大码女装6年里反复碰到的真实场景；  
  4）门店现场：试衣间、尺码架、顾客到店前的准备动作。  

- **边界**：  
  不说“谁穿都显瘦”“一穿就变样”“这件能遮所有问题”；不拿顾客身材开玩笑；不把同行写成反面角色；不承诺每件衣服都有50码以上。  
  这类话一多，“让人安心试穿”的人设就会变成普通卖货话术。

### 2. 用户定位

- **一句话画像**：  
  **住在县城或周边、上班或带娃都要出门，想买条合身裙子或裤子，却常在店门口先问“我这个码有吗”的女性。**

- **主攻人群**：  
  **精致妈妈 + 新锐白领**。  
  精致妈妈有接送孩子、家庭聚会、走亲访友、参加活动等穿衣需求；新锐白领有上班、同事聚餐、约会、换季添衣的需求。两类人都需要“得体、舒服、能试到”的大码女装。  
  不主攻只追求潮流打卡、购买频率完全看短期热点的人群，因为这个号的优势是线下试穿与真实合身感，不是追逐快速更新的潮流款。

- **明确不服务谁**：  
  不把“只想让一件衣服解决所有身材焦虑”的人当核心客群；不承接只问线上最低价、没有到店或试穿意愿的泛围观用户。  
  原因不是拒绝卖货，而是当前门店最强的成交场景是到店试穿，账号要先把最可能成交的人接住。

- **她们心里真正想的**：  
  “我不是不想买好看的衣服，我是怕问完尺码以后，店员看我的眼神。”  
  这句话不一定会被她直接说出来，但会决定她是否走进门店。

- **决策链路**：  
  刷到阿梅讲尺码烦恼 → 发现这家店不是只拍瘦模特 → 看几条真实试穿和门店位置 → 收藏/转给朋友 → 某次需要买衣服时到店。  
  她会先潜水看一段时间，尤其要确认店里是否真能试、氛围是否让人放松。因此需要持续内容建立信任，不靠一条促销视频催成交。

- **什么时刻会想起你**：  
  换季衣柜里没衣服穿；临时要参加聚会或家宴；上班需要一条合适裤子；天气变冷想添外套；逛街试了几家都没有尺码后。

- **她在平台上搜什么**：  
  “县城大码女装”“附近大码女装店”“大码连衣裙试穿”“大码裤子哪里买”“大码外套实体店”“50码女装”。

### 3. 内容定位

- **长期提供什么价值**：  
  **让本地大码女生少一次进店前的犹豫。**

- **内容方向**：  
  选择 **多元四类打底 + 试穿过程做王牌栏目**。  
  原因是阿梅目前能稳定发生的真实事件，就是门店里的试衣、尺码沟通和换季选款；但档案没有足够的持续人物关系或固定挑战任务，暂时不适合硬做单一主题账号。  
  不选纯单一主题，是因为“每天一条大码试穿挑战”容易拍成重复换装，撑不起长期内容。

- **当前阶段配比**：  
  - **作用配比：流量型45% / 人设型25% / 变现型30%。**  
    账号仍在起号期，先用流量型内容让本地有相同困扰的人刷到；人设型让她知道出镜的是阿梅，不是普通挂货号；变现型则从第一周开始证明“确实有可试穿款”，但不能一上来全是广告。  

  - **形式配比**：  
    - 流量型：以短情景、观点、轻过程为主。拍“大码女生进店前会想什么”“试裤子最怕哪一步”，依靠人群共鸣和反差停住陌生人。  
    - 人设型：以真实职业故事、门店日常观点为主。阿梅讲做大码女装6年里反复听到的一句话，但只讲已确认的真实经历。  
    - 变现型：以试穿过程、尺码判断、单品对比为主。让“50码以上可试穿”出现在镜头里，而不是只在字幕里。  

  - **题材配比**：  
    **主赛道70%：大码连衣裙、大码外套、大码裤装及试穿场景；人群兴趣30%：上班、带娃、见亲友、换季、聚会等穿衣处境。**  
    原因是只讲衣服会变成货架号；只讲情绪又接不住到店。每个品类都要轮流出现，不能只拍连衣裙或只拍裤装。

- **主力形式**：  
  档案未提供“数据最好的内容类型”，新号也没有历史数据可验证。  
  **暂定主力形式为：真实试穿过程 + 阿梅口播解释。**  
  这是因为门店最硬的证据是“50码以上可试穿”，用挂版图、图文或纯配音都无法充分证明。后续必须根据完播、评论和到店询问验证，不把这个判断当成定论。

- **每类内容管哪一段路**：  
  - **刷到**：流量型负责。让没关注过的人先觉得“这不就是我吗”。  
  - **记住**：人设型负责。让她记住阿梅是做大码女装6年、门店有试衣间的人。  
  - **相信**：变现型负责。让她反复看到真实尺码、真实上身、真实试穿过程。  
  - **联系或到店**：变现型负责。用“到店试穿”承接，而不是逼她线上立刻下单。

- **三种视频各怎么拍**：

  **流量型**  
  - 四大脚本：用“聊观点·观点立场”。方向是“大码女生进服装店，真正怕的不是衣服不好看”。开头给具体场景，中间说一次真实感受或待确认的顾客原话，结尾只引导：**“有过这种经历的，评论区说一句。”**  
  - 起号36计：**第9计·一人分饰多角：**阿梅一人演“想进店试衣的女生”和“站在门口犹豫的自己”两句对话，最后回到“先问有没有尺码，已经很累了”。看点是人群共鸣，不讲店铺卖点。

  **人设型**  
  - 四大脚本：用“讲故事·职业经历”。方向是“做大码女装6年，我反复听到的一句话”。前提是这句话必须由阿梅确认真实发生过；结尾只引导：**“想看阿梅讲门店里的真事，就关注。”**  
  - 起号36计：**第7计·一句话设定故事感：**阿梅在整理试衣间，开场说“今天我又把这间试衣间收拾了一遍，因为有人进来前问了我一句……”随后讲真实事件，不加商品推销。

  **变现型**  
  - 四大脚本：用“晒过程·火车节”。方向是“一位顾客来找能试穿的裤装，阿梅怎么从拿尺码到试穿判断”。成交理由只讲一个：**50码以上有可试穿款。** 结尾只说：**“想现场试穿的，到店找阿梅。”**  
  - 起号36计：**第10计·情境还原：**真实任务是顾客来找裤装；阿梅按实际情况拿出可试穿尺码、说明上身要看哪里、顾客自行判断；结果是“适合/不适合”的真实结论。不能把不适合的款硬说成适合。

- **配比核验**：  
  1. **流量型是否匹配起号期：是。**45%是最大一块，符合新号先拿陌生人曝光的需要。  
  2. **主力形式是否有数据依据：否，待补。**暂无历史数据，先用最能证明门店优势的试穿过程测试。  
  3. **大流量内容是否占主力：是。**流量型占45%，且每条先设计人群共鸣、反差或具体场景。  
  4. **是否给人群兴趣留位置：是。**30%题材围绕上班、带娃、换季、聚会等生活处境。  
  5. **每个数字是否有原因：是。**起号期先扩触达，同时保留30%变现内容承接到店需求。

- **第一条该发什么**：  
  **题目：**《大码女生进服装店，最怕听到的不是“没货”》  
  **目的：流量型。**  
  **打法：第9计·一人分饰多角 + 共鸣观点。**  
  阿梅站在试衣间门口，一人演两句：  
  “这条有我能穿的吗？”  
  “你先看看别的吧。”  
  随后阿梅回到镜头前说：“很多人不是不想试，是问完这句话以后，就不想再进第二家店了。”  
  结尾只说：“有过这种经历的，评论区留个‘有’。”  
  这条不卖货、不讲尺码卖点，先把真正会需要这个店的人吸引过来。

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：真人出镜口播 + 试衣过程短视频。阿梅本人出镜，镜头固定在试衣间外、镜前和服装区；因为门店的核心证据是“能试穿”，不建议做纯图文或只拍挂版。  
- **产能**：待确认：缺少团队、拍摄时间与剪辑资源信息。若仅阿梅一人、一部手机，先以每周2—3条为上限，避免承诺高频后断更。  
- **在哪拍**：商业街门头、服装区、试衣间外、镜前。场景要真实，不用搭假背景。

### 5. 风格调性（只给结论，≤200字）

- **正向匹配**：选正向匹配。阿梅是实体店老板，镜头就在真实门店里，直接、松弛、能试穿，比精致棚拍更自洽。  
- **气质关键词**：直白、体面、松弛。  
- **会说的一句话**：“这条你先别急着拿，我给你找个能试的码。”  
- **不会说的一句话**：“穿上它，立刻让你换个人。”  
  前者符合门店试穿逻辑，后者夸大且容易制造身材焦虑。

### 6. 变现定位（只给结论，≤250字）

- **卖什么 + 客单价区间**：卖大码连衣裙、大码外套、大码裤装；客单价区间待确认，档案未提供。  
- **成交路径**：抖音刷到内容 → 看主页确认门店与试穿信息 → 私信/导航到店 → 试穿 → 选购。  
- **最缺的信任证据是什么**：真实展示哪些款有50码以上可试穿、实际试穿过程，以及门店位置和试衣间环境。  
- 完整的变现拆解请用「商业定位」板块。

## 🧠 记忆点设计
