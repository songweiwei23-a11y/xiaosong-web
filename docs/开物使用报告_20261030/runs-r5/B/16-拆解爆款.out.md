## 2. 出发点（2026-10-29）

### 人、货、场

- **核心围绕：人**
  - 是“大码姐妹”进店后的心理状态：先说“我穿不了”。
  - 本质解决的是“怕试、怕不合身、怕被否定”的问题。

- **货：辅助出现**
  - 原文提到“剪裁”“买再贵”，但没有具体到哪件衣服、哪类版型、什么尺码。
  - 因此货不是看点主体，而是解决客户问题的工具。

- **场：辅助出现**
  - “进店”“站到镜子前”构成了试衣场景。
  - 对阿梅账号可承接为门店试衣间，但原稿没有明确说该场景就是阿梅门店，不能直接认定。

### 三有判断

- **有用：符合**
  - 给出一个明确的选衣逻辑：别只看价格或尺码，要先看剪裁是否适合自己。
- **有共鸣：符合**
  - “我穿不了”是大码女性可能出现的高频自我否定表达。
- **有趣：不明显**
  - 原稿没有事件、挑战、反转过程或人物互动，主要靠痛点共鸣和认知反转留人。

### 八大爆款元素

- **人群：明显用到，设计在钩子**
  - “很多大码姐妹”直接圈定目标人群。
- **成本：明显用到，设计在结尾**
  - “买再贵也白搭”指向金钱成本和试错成本。
- **反差：轻度用到，设计在结构里**
  - 从“我穿不了”的低预期，转到“是剪裁在帮你”的新判断。
  - 但不属于“实际做对比或前后变化”，力度偏弱。
- 其余元素：**没有明显用到**。

> 【身材偏丰满女性】进店时先否定自己 → 不马上推衣服 → 用试穿和版型判断帮她找到方向 → 避免盲买后闲置。

- **场**：县城商业街门店、试衣间、镜子前试穿。
- **已确认卖点**：50码以上有可试穿款。

### 信息递进

原稿的信息推进是清晰的：

1. **先承认顾客害怕什么**：我穿不了。  
2. **再推翻常规卖货动作**：不急着推荐。  
3. **给出新的判断标准**：看剪裁是否在帮你。  
4. **提醒错误选择的代价**：买再贵也白搭。  

问题是第3步太抽象。“哪一个剪裁”“怎么帮你”没有展开，观众听完知道“要看剪裁”，却不知道该看什么。

---

### 情绪曲线

**情绪曲线：共鸣爆发型**

- **认同**：大码姐妹看到“我穿不了”，容易产生“她说的是我”。
- **更认同**：店主没有立刻推衣服，降低被推销的防备。
- **爆发点**：“买再贵也白搭”击中盲买、买回家不穿的经历。

原稿的情绪不是强烈起伏型，而是从低落的自我否定，转向“原来不是我不行，是我可能没选对”的轻度释放。

---

### 结尾行动

**原稿结尾：**  
> “站不对，买再贵也白搭。”

**判断：**

- 有一句能收束主题的结论。
- 但它不是完整的行动指令。
- 如果视频定位为变现型，建议只补一个动作，例如：
  - “想知道自己适合什么版型，来店里试穿。”
  - 或“把你最怕显的地方私信告诉我。”

二选一即可，不要同时要求关注、评论、私信、到店。

## 4. 能保留的创意与需要优化的问题

### 能保留的创意

1. **先说顾客的自我否定，而不是先展示衣服**  
   “我穿不了”比“今天上新一条裙子”更容易让目标客户停下来。

2. **反向销售的表达很适合门店账号**  
   “今天我不推荐衣服”不是拒绝卖货，而是先建立一个更可信的服务顺序：判断问题，再推荐产品。

3. **把问题从身材转向剪裁**  
   这会减轻目标顾客的羞耻感。内容不把顾客描述成“身材有问题”，而是讨论衣服是否合适，表达更友好。

4. **“买再贵也白搭”保留了成本感**  
   它能承接“买错后闲置”的经历，适合变现型内容里的损失提醒。

---

### 需要优化的问题

1. **“很多大码姐妹”属于泛化表达，建议换成可验证的真实观察**  
   原稿没有证据证明“很多”是阿梅门店里的真实情况。  
   可改为：
   - “有些姐妹一进试衣间就先说……”
   - 或使用阿梅真实接待时客户说过的话，但需先确认。

2. **“哪一个剪裁其实是在帮你”太虚，缺少可学的判断点**  
   需要补一个真实、可展示的判断点，例如：
   - 【换成你的真实情况：腰线位置】
   - 【换成你的真实情况：肩线是否卡住】
   - 【换成你的真实情况：裤腰和裆部活动空间】
   - 【换成你的真实情况：裙摆或外套下摆的线条】

3. **“站不对”表达不准确**  
   容易被理解成顾客站姿不对，而原意应是“版型选不对”或“衣服没试对”。  
   建议改成：
   - “版型没选对，买再贵也白搭。”
   - “没试到适合自己的版型，价格再高也穿不出去。”

4. **缺少阿梅账号的确认事实植入**  
   可自然补入：
   - “店里50码以上有可试穿款。”
   - “先到试衣间穿上看，再决定要不要带走。”
   
   这两点来自账号档案，可以用；不要补进货价、客流、销量、老客故事等未核实经营事实。

5. **没有明确行动指令，变现闭环不足**  
   建议结尾只留一个：
   - 到店试穿；或
   - 私信描述自己的穿衣烦恼。  

---

### 借鉴它的结构和手法后，阿梅大码女装店可以怎么拍

保留原稿的四段式：

> 客户顾虑 → 不急着卖 → 给一个具体判断点 → 提醒盲买成本并引导试穿

换成阿梅账号的确认事实：

- 人物：店主阿梅本人。
- 品类：大码连衣裙、大码外套、大码裤装。
- 场景：县城商业街门店、试衣间、镜子前。
- 差异化卖点：50码以上有可试穿款。
- 内容重点：不说空泛“显瘦”，改讲一个可看见的试穿判断动作。

## 5. 优化后的完整脚本

### 优化后的完整脚本

很多大码姐妹进店，第一句话就是：“我穿不了。”

但我一般不会马上给你拿一排衣服。  
先别急着看吊牌，也别急着问有没有你的码，先站到镜子前看一眼。

你穿衣服总觉得显壮、显肚子，很多时候不一定是你不能穿，可能只是这件衣服的版型，没有顺着你的身形走。

比如试大码连衣裙，别只看颜色。  
先看【换成你的真实情况：腰线位置怎么判断】。  
这个位置对了，整个人的线条会更顺；位置不对，再喜欢的花色，穿上也容易觉得别扭。

阿梅店里50码以上有可试穿款。  
别先给自己下结论，进试衣间穿上看，比对着尺码猜来猜去更实在。

**版型选对了，镜子会先告诉你。**
