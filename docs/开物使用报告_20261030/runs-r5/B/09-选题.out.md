 ## 选题1：第一次体验大码上班裤装的人，会先问“有我的码吗”吗？

**承接**：取自方向2“围绕上班买裤装，拍一句没问出口的话”，以及“一人分饰‘站在店门口犹豫的人’和‘准备开口又收回去的人’”。

**0️⃣ 视频目的**  
流量型——让有类似经历的大码女生停留，并在评论区说出自己的感受。

**视频任务**  
让观众代入买上班裤装时想问又收回去的瞬间，愿意评论自己的经历。

**🅰 打法**  
36计·第9计 一人分饰多角：阿梅分别扮演“站在门口的人”和“准备开口的人”，一边想问尺码，一边因为担心没有合适的而把话咽回去，最后回到阿梅本人视角收住。

**1️⃣ 爆款元素**  
人群——套用“第一次体验X的人”：第一次在实体店挑大码上班裤装的人，可能会先观察尺码牌和衣架，再决定要不要开口。

**2️⃣ 开篇钩子**  
“有些人进服装店，第一句话不是‘这条多少钱’，而是‘有我的码吗’——但这句话，最后也没问出口。”

**3️⃣ 内容方向及目的**

- **核心内容方向**：还原大码女生挑选上班裤装时，想问尺码却又收回去的心理过程。
- **核心问题与观众价值**：她们为什么不直接问？是怕没有合适的，还是怕得到让自己尴尬的回答？观众能从具体对话里看见自己的经历，并在评论区补充。
- **取材与内容推进**：
  1. 阿梅站在店门口，扮演准备进店的人，先看一眼裤装区。
  2. 切到另一个位置，扮演准备开口的人，低声说：“老板，这条有……”
  3. 停顿后把话改成：“我再看看。”
  4. 回到第一个角色，继续看衣架，但手没有拿衣服。
  5. 阿梅本人出镜，追问一句：“你买上班裤装时，最难开口的是哪句话？”
- **事实边界**：这是情境演绎，不写成真实顾客经历；不预设观众一定会怎么回答；不展示具体货品卖点或到店信息。
- **关键画面（3个）**：
  1. 手伸向裤装后又收回。
  2. 面对衣架欲言又止的侧脸或背影。
  3. 两个角色之间的短对话，保留阿梅现场口播。
- **场景设置**：店内裤装区，固定机位拍摄，利用换站位或换外套区分两个角色。

**4️⃣ 脚本结构**  
按36计的公式走：角色A想问尺码 → 角色B把“有我的码吗”咽回去 → 角色A继续假装只是看看 → 阿梅本人提出评论问题。

**5️⃣ 结尾行动指令**  
评论区说说，你买衣服时最难开口问哪句话？

**6️⃣ 执行要点**

- 准备一件上班场景常见的裤装作为画面道具，不需要讲价格和具体尺码。
- 一个人完成拍摄，用两个站位和不同外搭区分角色。
- 台词要留停顿，特别是“有我的码吗”前后的犹豫。
- 不拍未经同意的顾客正脸，不把演绎内容说成真实案例。
- 收声优先，店内嘈杂时靠近手机录制。

**1️⃣ 爆款元素**  
人群——套用“第一次体验X的人”：第一次独自进店挑大码外套的人，不知道该怎么描述自己的需求。

**2️⃣ 开篇钩子**  
“换季想买件外套，很多人真正想问的不是款式，而是这一句：‘有大一点的吗？’”

**3️⃣ 内容方向及目的**

- **核心内容方向**：还原换季挑外套时，顾客从想询问到放弃开口的短暂过程。
- **核心问题与观众价值**：观众能分辨自己犹豫的是尺码、版型，还是担心被注视；这比单纯展示外套更贴近她们进店前的真实状态。

  1. 角色A站在外套区，拿起一件外套看领口和袖口。
  2. 角色A准备询问：“这件有没有……”
  3. 角色B从旁边接话：“算了，我再看看。”
  4. 角色A把外套重新挂回去，视线转向其他衣架。
  5. 阿梅回到本人视角：“如果你也有过这种停顿，你当时最怕听到什么回答？”
- **事实边界**：角色对话为拍摄演绎，不代表真实顾客说过；不补充“很多人都这样”等未经核实的结论；不引导到店。
- **关键画面（3个）**：
  1. 手拿起外套后查看衣架尺码牌。
  2. 角色准备开口又停下。
  3. 外套重新挂回衣架，人物转身离开画面。
- **场景设置**：店内外套区，手机固定拍摄，两个角色通过站位和语气区分。

**4️⃣ 脚本结构**  
按36计的公式走：角色A提出挑外套的需求 → 角色B回应并打断提问 → 角色A把外套挂回去 → 阿梅本人抛出可评论的问题。

**5️⃣ 结尾行动指令**  
评论区说说，你买外套时最想问又没问出口的是哪句？

**6️⃣ 执行要点**

- 不需要安排顾客出镜，阿梅一人完成两个角色。
- 角色A动作慢一点，给“想问又停下”的停顿留出空间。
- 尺码牌只作为画面细节，不放大未经确认的数字。
- 尽量使用侧身、背影和手部特写，减少表演压力。
- 剪辑时保留“准备开口”的空白，不要用音乐盖住停顿。

## 选题3：第一次体验挑连衣裙的人，为什么会把“我能试吗”改成“我再看看”？

**承接**：取自方向2“围绕聚会想穿连衣裙的场景，拍一句没问出口的话”。

**0️⃣ 视频目的**  
流量型——让有过类似经历的女生产生代入感，并评论自己的试衣感受。

**视频任务**  
把“想试但不敢问”的瞬间拍具体，让目标观众愿意留下自己的经历。

**🅰 打法**  
36计·第9计 一人分饰多角：角色A负责挑选连衣裙，角色B负责说出她心里没说出口的担心，最后由阿梅本人提出开放式问题。

**1️⃣ 爆款元素**  
奇葩——套用“外行人绝对不知道的X”：外行人容易只看到顾客在挑衣服，却不一定看见她在衣架前反复做决定的过程。

**2️⃣ 开篇钩子**  
“想买一条聚会穿的连衣裙，最难问出口的，可能不是价格，而是：‘我能试吗？’”

**3️⃣ 内容方向及目的**

- **核心内容方向**：拍出顾客面对连衣裙时，想试穿却因为担心不合适而迟疑的过程。
- **核心问题与观众价值**：观众能进一步想清楚，自己不敢试，是怕尺寸不合、怕动作尴尬，还是怕试完只能离开。
- **取材与内容推进**：
  1. 角色A从连衣裙衣架上拿下一件，先看长度和袖口。
  2. 角色A走到试衣间附近，但没有马上进去。
  3. 角色B用内心口播说：“要是试了不合适呢？是不是还要解释？”
  4. 角色A把衣服抱在身前比一下，又放回衣架。
  5. 阿梅本人出镜：“你想试衣服的时候，最担心哪一步？”
- **事实边界**：不写成真实顾客试穿故事；不预设试穿结果；不出现“这件一定适合”等判断。
- **关键画面（3个）**：
  1. 手拿连衣裙在身前比量。
  2. 人走到试衣间帘子前又停下。
  3. 连衣裙被重新挂回衣架，留下一个短暂停顿。
- **场景设置**：店内连衣裙区与试衣间门口，尽量一镜一景完成。

**4️⃣ 脚本结构**  
按36计的公式走：角色A拿裙子 → 角色B说出没问出口的担心 → 角色A在试衣间门口停下 → 角色A把裙子挂回去 → 阿梅本人提出评论问题。

**5️⃣ 结尾行动指令**  
评论区说说，你想试衣服时最担心哪一步？

**6️⃣ 执行要点**

- 只用一件店内现有连衣裙作为道具，不介绍价格和尺码。
- 试衣间保持空置，拍帘子、门口和手部即可。
- 不需要真正试穿，避免把演绎过程误认为顾客案例。
- “我能试吗”与“我再看看”之间要留出明显停顿。
- 拍摄时确认试衣间内没有顾客及个人物品入镜。

## 选题4：外行人绝对不知道的试衣间门口犹豫动作

**0️⃣ 视频目的**  
流量型——用第一视角让观众代入“想试又不敢问”的瞬间，提升评论互动。

**视频任务**  
让观众从第一视角看见自己买衣服时的犹豫动作，并评论曾经卡在哪一步。

**1️⃣ 爆款元素**  
奇葩——套用“外行人绝对不知道的X”：外行人看到的是“拿起又放下”，第一视角呈现的是中间连续发生的犹豫。

**2️⃣ 开篇钩子**

**3️⃣ 内容方向及目的**

- **核心内容方向**：用顾客第一视角还原从看尺码牌、拿衣服到停在试衣间门口的连续动作。
- **核心问题与观众价值**：观众能看见自己平时没有说出口的判断过程：先确认衣服有没有可能合适，再决定是否拿进去试。

  2. 手伸向一件衣服，拿起后对着自己比一下。

- **关键画面（3个）**：
  1. 第一视角看尺码牌，保持停留。
  2. 衣服被拿起又挂回去。
  3. 镜头停在试衣间帘子前，手没有拉开帘子。
- **场景设置**：店内衣架到试衣间门口的一小段动线，不需要切换场景。

**4️⃣ 脚本结构**  
按36计的公式走：常规逛衣架 → 换成顾客第一视角 → 由尺码牌推进到衣服和试衣间帘子 → 在帘子前停住并留下问题。

**5️⃣ 结尾行动指令**  
评论区说说，你会停在看尺码牌、拿衣服，还是试衣间门口？

**6️⃣ 执行要点**

- 手机直接手持拍摄，镜头高度保持在自然视线附近。
- 尺码牌可以拍到动作，但不要刻意放大未确认的具体数字。
- 拍摄前确认动线内没有其他顾客正脸。
- 通过手部动作区分不同阶段，不需要演员。
- 环境声保留少量衣架声，口播靠近手机完成。

## 选题6：曾经先看显不显瘦，现在先看能不能自在活动

**承接**：取自方向4“常规动作是穿上衣服马上照镜子；反向动作是先坐下、抬手、走两步，再去看镜子里的整体状态”。

**0️⃣ 视频目的**  
流量型——用反向试衣动作制造停留，让观众评论自己试衣时最在意什么。

**视频任务**  
让观众重新代入试衣过程，讨论照镜子之前应该先观察哪些实际动作。

**🅰 打法**  
36计·第1计 反向操作：常规是穿上衣服马上照镜子 → 反向先坐下、抬手、走两步 → 再到镜子前看整体状态。

**1️⃣ 爆款元素**  
反差——套用“曾经 vs 现在”：把“曾经穿上就照镜子”和“现在先做动作再看镜子”放在同一件试衣流程里对比。

**2️⃣ 开篇钩子**  
“穿上衣服先别急着照镜子，先坐一下、抬抬手、走两步，再看你还想不想穿它。”

**3️⃣ 内容方向及目的**

- **核心内容方向**：把试衣顺序从“先看镜子”改成“先做日常动作”，观察衣服是否影响坐下、抬手和行走。
- **核心问题与观众价值**：观众能带走一个具体试衣判断顺序：先看活动状态，再看镜子里的整体效果。
- **取材与内容推进**：
  1. 先拍常规动作：穿好衣服，直接站到镜子前。
  2. 画面停住，阿梅口播：“但日常穿衣，不是只站在镜子前。”
  3. 切换到反向动作：坐下、抬手、走两步。
  4. 每个动作只观察一个问题：坐下是否方便、抬手是否受限、走动时长度是否需要留意。
  5. 最后再走到镜子前，问观众：“你试衣时最先看镜子，还是先看能不能活动？”
- **事实边界**：不评价某件衣服好坏，不承诺穿着效果；实际动作结果以当次试穿为准；画面中如果出现不适，只呈现“需要继续判断”，不下绝对结论。
- **关键画面（3个）**：
  1. 穿好衣服后直接照镜子的常规动作。
  2. 坐下、抬手、走两步的连续测试动作。
  3. 完成动作后再站到镜子前观察整体状态。
