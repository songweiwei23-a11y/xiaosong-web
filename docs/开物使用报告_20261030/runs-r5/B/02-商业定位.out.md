# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

这是 **A 本地实体店｜B 服装鞋包类** 生意，核心不是“刷到就线上下单”，而是把县城及周边有尺码困扰的女性，带到店里完成试穿和选购。

大码女装的利润不只取决于单件加价，更取决于库存周转：尺码覆盖越宽，压货风险越高；同一款进得不够深，顾客来了没码；款式进得太散，又容易卖不动。门店不能单靠低价获客，否则需要靠更高销量消化库存，而现有资料没有“低价”或“大量走货”的依据，不建议把价格战当路线。

这行更适合靠三件事赚钱：

1. **到店试穿提高成交率**  
   连衣裙要看腰腹、肩背和长度；外套要看活动空间与叠穿；裤装要看腰、臀、腿的活动感。顾客愿意进试衣间，才有后面的成交机会。

2. **一位顾客买多件，而不是只卖一件**  
   真实需求往往不是“买件衣服”，而是“上班缺裤子”“天气降温缺外套”“聚会想穿条裙子”。但是否能带出第二件，取决于顾客对尺码和试穿氛围是否放心，不能靠硬推。

3. **老客在换季和临时有场合时回来**  
   大码女装的复购，通常建立在“她知道这里有自己能试的码”上。阿梅要被记住的不是某一件爆款，而是“我不用先进门受一圈打量，能先试再决定”。

获客成本卡在一个心理门槛：很多顾客不是没需求，而是已经在别家问过“有没有我能穿的”，得到过模糊回应或直接放弃。短视频必须先替她降低“我进去会不会尴尬”的顾虑，再谈衣服。

旺季通常集中在换季、节前走亲访友、婚宴聚会、返工添置、天气突然变化时；淡时更不能只发“新品到了”，而要提前种下具体场景，例如“上班裤子总卡腿”“见亲友不知道穿哪条裙子”。  
**我推测，县城顾客的到店决策会较依赖熟人转述、看过几条视频后的信任和实际试穿；待确认：顾客主要来自商业街自然进店、老客介绍，还是抖音导航。**

**一句话定位：县城阿梅，用大码女装让女生先试再决定。**

## 变现全景

### **现在能卖什么**

现有资源下，可直接变现的不是虚构套餐，而是以下三类真实货品及其共同的到店试穿服务：

1. **大码连衣裙**  
   对应聚会、走亲访友、日常出门等需求；顾客决策重点是长度、腰腹和整体上身效果。

2. **大码外套**  
   对应换季、降温、上班通勤；决策重点是肩背活动空间、内搭后是否紧绷。

3. **大码裤装**  
   对应上班、带娃、日常出门；往往是顾客试穿意愿较强的一类，决策重点是腰、臀、腿部活动感。

4. **到店试穿与尺码判断**  
   这不是额外收费项目，而是当前最该被拍出来的成交方式：顾客到店，先试真实尺码，再决定是否购买。

### **各自的客单价与毛利大致区间**

档案未提供吊牌价、进货价、折扣方式与退换货政策，**不能替门店编客单和毛利数字**。尤其大码女装的利润会受采购渠道、尺码断码率、季节清货和门店租金影响，同一品类差异很大。

先补这三项，才能排出真正赚钱的货：

- 连衣裙、外套、裤装的常规成交价区间；
- 每类货的平均进货成本与滞销款比例；
- 顾客一次通常买一件，还是会连带买两件以上。

**我推测：裤装与外套的决策通常比普通上衣更谨慎，因为尺码和活动感更难靠挂版判断；待确认：店内哪类货试穿率最高、成交率最高。**

### **决策难度**

属于 **中等偏高决策**，不适合按“看完立刻拍单”设计。

原因是顾客要先确认三件事：  
- 有没有自己能穿的尺码；  
- 上身后哪里合适、哪里不合适；  
- 进店试穿是否自在。  

所以短视频的任务不是催单，而是把她带到“愿意进店试一次”。

## 主推产品

**主推的不是某一件单品，而是“50码以上可试穿的大码女装到店试穿”。**

连衣裙、大码外套、大码裤装必须轮流做主角，不能只推其中一类。原因是当前最硬的优势不是某个款式，而是“有真实可试穿的尺码”；如果把账号做成只卖裤装或只拍连衣裙，会把原本能到店的需求主动缩窄。

执行上，先按顾客出现频率测试三个品类：

- 有人因上班需求进店：拍大码裤装；
- 有人因换季添衣进店：拍大码外套；
- 有人因聚会、见亲友进店：拍大码连衣裙。

每条只讲一个品类、一个真实需求、一个可试穿款。这样顾客看得清，阿梅也拍得动。

**明确不做：**  
- 不把“特价清仓”当主推内容。现有资料没有低价优势依据，长期拍低价只会让顾客等折扣。  
- 不拿一件衣服换三种穿法当核心卖点。衣服没变，观众学到的是技巧，不是“为什么要来这家买”。  
- 不承诺所有款都有50码以上。必须拍哪类款，就说哪类款可试。

## 成交路径

### 1. 第一次接触看到什么

她先刷到的应是一个同一位试穿者的两件不同货品对比**  
   - 画面：同一个人、同一面镜子，先后试两条不同裤装或两件不同外套。  
   - 证明：产品差异、专业判断。  
   - 用途：证明衣服版型不同带来的差异。  
   - 前提：顾客授权；不愿出镜就只拍腰以下、手部和衣服局部。

4. **阿梅讲“这件不建议你拿”的真实判断**  
   - 画面：阿梅说明某件衣服在腰、臀、肩背或长度上的实际问题。  
   - 证明：真实、边界。  
   - 用途：顾客相信阿梅不是“每件都说好看”。  
   - 待确认：阿梅是否真实做过这类判断，需先收集一次真实事件。

5. **门头到试衣间的连续镜头**  
   - 画面：商业街门头 → 店内服装区 → 试衣间。  
   - 证明：实体门店真实存在。  
   - 用途：降低本地顾客找店成本。

6. **连衣裙、外套、裤装分别有可试穿款的现场展示**  
   - 画面：三个视频轮流拍，不要求同框。  
   - 证明：品类完整、库存真实。  
   - 用途：让不同需求的人都能在主页找到对应内容。  
   - 待确认：每类具体有哪些可试尺码。

7. **老客复购故事**  
   - 画面：老客授权后讲第一次来问什么、后来为什么还来；或阿梅复述顾客允许公开的原话。  
   - 证明：结果、复购。  
   - 待确认：缺少真实老客事件，不能现在编。

8. **阿梅做大码女装6年的职业经历**  
   - 画面：阿梅整理衣架或准备试穿款时，讲一件确认真实发生的事。  
   - 证明：长期经营。  
   - 注意：6年是经历背书，不等于可以夸大成“什么身材都能解决”。

## 变现型内容怎么排

### **变现型内容占比：30%**

起号期仍保持流量型为最大部分，变现型暂定30%，原因有两个：

- 账号需要先让本地有尺码困扰的人刷到，不能一上来满屏“到店试穿”；  
- 但大码女装属于需要试穿确认的品类，若没有足够过程证据，观众即使喜欢阿梅，也未必愿意进店。

建议每发10条内容，安排3条变现型；三类货品轮流出现：大码连衣裙1条、大码外套1条、大码裤装1条。不是按货量排，而是避免主页只留下单一品类印象。

### 方向1：一条裤子，到底先看哪里能不能穿

- **对应成交路径：**兴趣 → 到店前确认  
- **成交理由：**50码以上有可试穿款  
- **观众变化：**信任变化。她会知道这家不是只挂着衣服，而是能试。  
- **四大脚本：**晒过程·火车节  
  - 起因：“今天有人来找一条上班能穿的裤子，先不是看颜色。”  
  - 关键步骤：拿可试尺码 → 拍尺码牌 → 说清试穿时看腰、臀、腿部活动。  
  - 结果：这条适合或不适合，以实际试穿为准。  
- **36计：**第10计·情境还原：顾客来找裤装 → 阿梅按真实需求拿可试尺码 → 镜头旁观试穿判断 → 给出真实结论。  
- **结尾行动：**“想试这类裤装的，到店找阿梅。”  

### 方向2：不是所有大码连衣裙，都适合直接拿回家

- **对应成交路径：**主页观察 → 建立专业信任  
- **成交理由：**真实试穿、真实判断  
- **观众变化：**信任变化。她会知道阿梅不会把每件衣服都说成适合。  
- **四大脚本：**教知识·拆解型  
  - 反常识开场：“大码连衣裙，挂着好看不等于穿上就合适。”  
  - 中间：只讲当前两件不同连衣裙，上身时腰腹、肩背、长度分别有什么不同。  
  - 收束：先试，再决定。  
- **36计：**第15计·正确做法VS错误做法：只看挂版就带走 → 到店先试具体版型 → 说明适用条件。  
- **结尾行动：**“想试连衣裙的，到店找阿梅。”  

### 方向3：换季买外套，先别急着看颜色

- **对应成交路径：**第一次接触 → 到店试穿  
- **成交理由：**可试穿、门店现场  
- **观众变化：**行动变化与信任变化。她知道外套到店该怎么判断，也知道在哪里能试。  
- **四大脚本：**教知识·解题型  
  - 场景难题：外套看着宽松，上身一抬手就紧。  
  - 放大问题：肩背紧会影响通勤、抱孩子、开车等日常动作。  
  - 解决方式：试穿时做三个动作——抬手、侧身、坐下；只展示当前外套的实际表现。  
- **36计：**第26计·推荐建议：圈定“换季想添外套的大码女生” → 讲试穿时看哪几处 → 给出适用与不适用。  
- **结尾行动：**“想现场试外套的，到店找阿梅。”  

### 方向4：顾客进店先问“有没有我能试的码”，阿梅怎么接

- **对应成交路径：**消除尴尬 → 到店  
- **成交理由：**服务过程与可试穿款  
- **观众变化：**信任变化。她会看到进店后的第一步，不再只想象尴尬。  
- **四大脚本：**晒过程·过程展示  
  - 钩子：顾客最常问的一句原话。  
  - 过程：阿梅先问她想找连衣裙、外套还是裤装，再拿当前有可试尺码的款。  
  - 结果：顾客进入试衣间试，不强行展示购买。  
- **36计：**第17计·互联网嘴替/替网友做：从评论或顾客真实问题中选一句 → 阿梅现场按真实流程处理 → 给出到店前可先确认的信息。  
- **结尾行动：**“想先确认可试尺码，私信发你想试的品类。”  

**提醒：**变现内容不是“新款上架播报”。每条先回答顾客一个问题，再让她看见这家店如何解决。成交理由必须在画面里出现，不靠字幕喊“服务好”。

## 定价与节奏

### 起步阶段建议怎么定价

**不建议为了起号专门造一个低价引流款。**

原因是：  
- 现有资料没有价格优势和供货优势；  
- 大码女装尺码覆盖本身有库存成本，低价可能让顾客只盯折扣；  
- 这个店现在应先卖“可试穿的确定感”，而不是卖“全城低价”的印象。

更实际的起步动作是：

- 正常价格体系先不乱动；  
- 视频里不把价格当第一钩子；  
- 顾客到店后，按真实需求试连衣裙、外套、裤装；  
- 记录哪类需求最常出现、哪类货最容易试后成交。

### 什么时候可以调整价格

待确认门店目前定价体系后再决定。可以考虑调整价格的依据，不是“粉丝涨了”，而是：

1. 某类货连续出现缺码、断码；  
2. 顾客到店后对价格异议明显减少，但对版型和尺码认可更高；  
3. 单次成交从只买一件，变成稳定出现连带购买；  
4. 老客复购时明确反馈“这次还是来试这个品类”。

没有这些真实信号前，不建议贸然涨价，也不建议为了成交频繁降价。

## ⚠️ 风险

1. **“50码以上可试穿”说得太大，现场证明太少**  
   顾客最在意的是具体哪类款、当天有没有可试尺码。  
   **处理：**每条变现视频拍清本条是哪类货、当前可试什么，不把局部事实扩大成全店承诺。

2. **只拍上新，主页变成衣架目录**  
   观众看完只知道有货，不知道自己能不能穿、进店会经历什么。  
   **处理：**每条新品视频必须挂到一个真实需求上：上班裤装、换季外套、聚会连衣裙；并至少出现尺码牌、试衣间或上身判断中的一个。

3. **阿梅一人拍摄和守店，内容计划过重**  
   目前没有团队与剪辑资源信息，复杂剧情、多人采访、日更精剪都可能断更。  
   **处理：**先用一部手机完成“固定机位口播 + 尺码牌近景 + 试衣间外过程”三镜头模板；待确认拍摄时间后，再决定更新频率。
