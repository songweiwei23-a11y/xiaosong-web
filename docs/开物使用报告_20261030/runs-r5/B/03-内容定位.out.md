# 💎 内容定位方案

## 长期价值主张

**让县城大码女生，通过大码女装试穿，少一次进店前的犹豫。**

## 内容方向：多元四类还是单一主题

选择：**A 多元四类打底 + B 王牌栏目。**

- **为什么这样选**：阿梅手里有稳定、真实、能每天发生的素材——门店选款、拿尺码、试衣间、镜前判断。这些足够支撑“试穿过程”做王牌栏目；但目前没有已确认的顾客故事、固定人物关系或挑战素材，直接把全号押在单一剧情主题上，容易拍到后面只剩重复换装。
- **A 打底负责什么**：观点做共鸣，故事讲阿梅做大码女装6年的职业片段，晒过程证明店里能试，知识讲清楚不同货品该看哪里。
- **B 王牌栏目一句话**：**《试衣间门口的那一句》——把大码女生进店前不敢问的话，拍成一条条真实小情境。**
- **为什么不选纯单一主题**：纯做“每天试一件衣服”看似省事，实际变量只是换货，陌生人看两三条就知道后面内容，无法长期制造新的点击理由。

## 内容配比

### 作用配比

| 作用 | 占比 | 为什么 |
|---|---:|---|
| 流量型 | 45% | 起号期先让本地有尺码困扰的陌生人刷到。流量内容不卖货，专拍“站在店门口不敢问”“试裤子怕卡腿”等人群共鸣，先把真正会来试穿的人吸引进主页。 |
| 人设型 | 25% | 阿梅是老板本人，做大码女装6年，这个职业事实需要被持续看见；但现阶段真实人物故事不足，不能为了人设硬编，所以占比不能过高。 |
| 变现型 | 30% | 门店的核心证据是“50码以上有可试穿款”，必须从第一批内容开始展示，否则用户刷到共鸣内容后，仍不知道店里能不能解决她的问题。 |

**切换条件**：连续发满20条后，如果非关注播放和新增关注稳定、但私信或到店询问很少，变现型可从30%提高到35%；如果前段流失明显、陌生人播放不足，维持45%流量型，不急着加促销内容。

### 形式配比

| 形式 | 占比 | 负责哪种作用 | 为什么 |
|---|---:|---|---|
| 晒过程 | 35% | 变现型为主，少量流量型 | 真实试穿、拿尺码、看版型，是“50码以上可试穿”最直接的证据。新号没有历史数据，先集中测试这类最贴近门店优势的形式。 |
| 观点 | 25% | 流量型、人设型 | “大码女生怕的不是衣服不好看”等具体处境，容易触发身份确认；但必须结合阿梅本人见过的真实场景，不能空喊口号。 |
| 故事 | 20% | 人设型 | 用阿梅做大码女装6年里确认过的职业片段，让用户记住“这个店主是谁”。顾客故事需先征得同意，没有真实事件就不拍。 |
| 知识 | 15% | 变现型 | 讲连衣裙、外套、裤装试穿时该看哪些位置，帮助顾客到店前减少无效试穿；知识只讲门店能现场验证的内容。 |
| 段子 | 5% | 流量型 | 用一人分饰多角拍“想问尺码又不敢问”的小情境，降低口播门槛，也让账号不全是商品展示。比例低，避免拍成脱离门店的搞笑号。 |

### 题材配比

- **主赛道70%**：围绕**大码女装**展开，连衣裙、外套、裤装轮流出现。原因是用户最终要确认“我能不能试到、穿上是什么状态”。
- **目标人群兴趣30%**：围绕精致妈妈、新锐白领的真实穿衣处境展开，包括：
  1. 上班见人、通勤久坐；
  2. 带娃、接送、日常活动方便；
  3. 换季、聚会、走亲友前临时不知道穿什么。  
  这些话题不是另开生活号，而是给大码女装提供具体的使用场景。

### 配比核验

1. **流量型是否匹配起号期：是。**45%是最大板块，符合新号先获取陌生人曝光的任务。  
2. **主力形式是否有历史数据依据：否，但理由够硬。**暂无历史数据；先测试最能证明门店试穿优势的晒过程。  
3. **大流量内容是否占主力：是。**45%流量型内容都围绕人群困扰、门店场景和衣服展开。  
4. **是否给人群兴趣留位置：是。**30%题材连接上班、带娃、换季等现实场景。  
5. **每个数字是否有原因：是。**起号先扩曝光，同时保留30%变现内容承接到店试穿。

## 三种视频怎么拍

### 流量型

**拍什么方向：**
1. 大码女生进服装店前，最犹豫的那一句话。  
2. 连衣裙、外套、裤装里，哪些“看着能穿”但上身前仍让人担心的部位。

**四大脚本（薛老师）：**
- **聊观点·观点立场**：具体场景 → 阿梅的判断 → 为什么会这样 → 评论互动。  
  例如：站在试衣间门口说：“很多人进店先看衣架，不是不喜欢衣服，是怕问完尺码以后更尴尬。”
- **晒过程·轻过程**：先拍顾客常看的尺码牌、衣架和试衣间帘子，再由阿梅补一句“进店先问有没有能试的码，不丢人”。  
  标题可叠加**人群、反差**。

**示范：**  
《大码女生进服装店，最难开口的不是“多少钱”》（人群）  
阿梅一人演“想问尺码的顾客”和“站在门口犹豫的自己”，最后回到镜头前说出真实处境，不提门店卖点。

**起号36计（小黄）：**
- **第9计·一人分饰多角：角色A观点 ↔ 角色B回应 → 共鸣回收。**  
  阿梅分别演“我这个码有吗”和“算了，我再看看”，最后回到本人视角：很多人走出门，不是因为不想买，是不想再问第二次。
- **第32计·换个视角：常规事件 + 新POV → 新信息/情绪。**  
  镜头从“站在试衣间外等答案的人”视角拍：先看尺码牌，再看阿梅拿衣服，最后停在试衣间帘子前，强调等待答案时的忐忑。

**示范：**  
《站在试衣间外的人，最怕听见哪句话？》（人群）  
用第一视角拍阿梅拿尺码、挂衣服、拉开试衣间帘子的过程，结尾不卖货，只留一句提问。

**结尾行动指令：**  
**“有过这种经历的，评论区说一句。”**

### 人设型

**拍什么方向：**
1. 阿梅做大码女装6年里，反复遇到的尺码沟通场景。  
2. 阿梅对“衣服适不适合”的真实边界：不确定的款，就让顾客先试再决定。

**四大脚本（薛老师）：**
- **讲故事·职业经历**：一个真实场景 → 阿梅当时怎么做 → 她为什么这么判断 → 留下的感受。  
  这类素材必须先由阿梅确认，不能把推测写成顾客原话。
- **聊观点·观点立场**：亲身经历 → 我的判断 → 一次具体细节 → 关注。  
  例如：“做大码女装6年，我不太愿意隔着镜头替人保证合不合身，因为每个人在意的位置不一样。”

**示范：**  
《做大码女装6年，我不太敢隔着镜头说“你肯定能穿”》（反差）  
阿梅站在试衣间外，讲清“为什么先试再决定”是她的原则，不讲价格、不引导到店。

**起号36计（小黄）：**
- **第7计·一句话设定故事感：普通动作 + 目标/困境 → 故事期待。**  
  阿梅整理试衣间，开头说：“这件衣服我没有马上递出去，因为我先看了一眼尺码。”
- **第37计·赠送：身份反差：身份预期A → 行为B → 情绪结果。**  
  “服装店老板应该先夸衣服”是预期，阿梅做的是先提醒顾客试哪里、哪里不确定，落在“别急着买，先看合不合身”。

**示范：**  
《服装店老板最该说的，可能不是“这件好看”》（反差）  
阿梅把一件衣服挂回去，讲一个待确认的真实判断场景；确认前用【换成真实事件】占位。

**结尾行动指令：**  
**“想看阿梅讲门店里的真事，就关注。”**

### 变现型

**拍什么方向：**
1. 一件大码连衣裙、外套或裤装，现场有没有50码以上可试穿款。  
2. 顾客到店后，阿梅怎么根据真实尺码需求拿出能试的货，而不是只拍挂版。

**四大脚本（薛老师）：**
- **晒过程·火车节**：顾客需求 → 拿实际可试尺码 → 试衣前看哪里 → 结果。  
  每条只突出一个成交理由：**50码以上有可试穿款。**
- **教知识·解题型**：具体场景难题 → 为什么不能只看挂版 → 试穿时看腰腹、肩背或臀腿 → 到店验证。  
  不说“谁都能穿”，只说这一类货适合现场判断什么。

**示范：**  
《这条大码裤装，有没有50码以上能试的？》（反差）  
先拍尺码牌，再拍阿梅从裤装区拿出实际可试款，镜前只展示裤型和活动细节；结论按真实试穿结果说。

**起号36计（小黄）：**
- **第10计·情境还原：真实任务 → 对话/纠错 → 旁观学习 → 结果。**  
  任务是“来找一条上班能穿的裤装”；阿梅先问实际需求，再拿有可试尺码的款，最后说清这次能否试。
- **第15计·正确做法VS错误做法：错误示范 → 后果 → 正确示范 → 适用条件。**  
  错误做法是只看挂版就判断；正确做法是看实际尺码、上身活动和长度。两边比较的是不同裤装，不是同一条裤子换穿法。

**示范：**  
《别只看挂版，这件大码外套先看有没有能试的码》（反差）  
阿梅先拍衣架上的外套，再拿出本次实际可试的尺码，明确说明“这条视频只代表这一批货”。

**结尾行动指令：**  
**“想现场试穿的，到店找阿梅。”**

## 内容系列（2个）

### 系列一：《试衣间门口的那一句》

**一句话讲清：**阿梅一人还原大码女生进店前最常出现的犹豫瞬间。

- **出发点**：站在精致妈妈、新锐白领的“尺码焦虑”处境；围绕**人**；满足“有共鸣”；主用**人群、反差**，放在标题和开头对话里。
- **定量 / 变量**：  
  定量：试衣间门口、一人分饰两角、一句没问出口的话。  
  变量：不同的真实处境——上班裤装、换季外套、聚会连衣裙、逛街试衣等。
- **用哪套打法**：36计系列，**第9计·一人分饰多角**。
- **目的和结构**：流量型；“顾客角色提问/退缩 → 阿梅角色回应 → 本人一句共鸣收尾”。  
  结尾行动指令：**评论。**
- **让观众发生哪种变化**：身份确认。
- **变量自检**：变量是：不同穿衣处境和不同没问出口的问题。  
  看点不是试穿、挑选或穿搭技巧，而是“这句话我也说过”的人群共鸣。

**前10集标题：**
1. 《大码女生进店，最难问出口的那句话》（人群）  
2. 《不是怕衣服不好看，是怕没有能试的码》（反差）  
3. 《上班要穿裤子时，我最怕先听到这句》（人群）  
4. 《逛了几家店后，为什么有人不想再问尺码》（反差）  
5. 《想穿连衣裙的人，站在门口会先看什么》（人群）  
6. 《换季买外套，很多人先把手从衣架上收回来》（反差）  
7. 《带娃逛街时，我为什么不想反复试衣服》（人群）  
8. 《一件裤子挂得再好看，也替不了一句“能试吗”》（反差）  
9. 《聚会前想买件衣服，最怕店员先问什么》（人群）  
10. 《有些人不是不买衣服，是不想再经历一次尴尬》（反差）

**立项检验：**
- 一句话能讲清：围绕“没问出口的话”拍，定位明确。
- 追看理由：每集换一个生活处境，观众会等“这次是不是我遇到过的那句话”。
- 30集可持续：上班、带娃、换季、聚会、走亲友等场景可持续扩展。
- 真实性：对话是情境演绎，开头标注“门店常见场景”；不伪装成真实顾客。
- 与变现联系：先筛出有尺码困扰的人，后续试穿过程自然承接。
- 元素与句式：前10集交替使用人群、反差，不连续重复同一种句式超过3次。

- **定量 / 变量**：  
  定量：尺码牌近景 → 阿梅拿实际可试款 → 镜前验证一个部位 → 真实结论。  
  变量：每集换一件实际在售、且确认有可试尺码的大码连衣裙、大码外套或大码裤装。
- **用哪套打法**：四大脚本系列，**晒过程·火车节**。

  结尾行动指令：**到店。**
- **让观众发生哪种变化**：信任。
- **变量自检**：变量是：不同的大码女装货品和不同试穿需求。  
  看点不是同一件衣服换穿法，而是不同货品的实际尺码与版型差异。

**前10集标题：**
1. 《这条大码裤装，先看有没有能试的码》（反差）  
2. 《上班穿的大码裤子，到店前要确认哪一件事》（人群）

**立项检验：**
- 一句话能讲清：每集验证一件货是否适合现场试穿。
- 追看理由：用户会等自己的需求对应哪一类货、店里这次是否有可试尺码。
- 30集可持续：连衣裙、外套、裤装按货品和真实需求轮换；前提是每条都先确认库存和可试尺码。
- 真实性：只拍实际在售货品，不把“部分有”说成“全部有”。
- 与变现联系：成交理由“50码以上有可试穿款”在尺码牌、拿货和试穿现场都可见。
- 元素与句式：前10集使用反差、人群、成本三种元素，句式交替，不重复成上新播报。

## 选题来源

### 1. 知识储备

- **长期来源**：连衣裙、外套、裤装试穿时最需要现场确认的位置。  
  例：《大码裤装试穿，先别急着看显不显瘦，先看能不能坐下。》
- **长期来源**：顾客进店前常有的尺码误区。  
  例：《尺码牌不是答案，到店试穿还要看哪两处？》

### 2. 经历与故事

- **长期来源**：阿梅做大码女装6年中反复听到的话。  
  例：《【待确认原话】做大码女装这些年，我最常听到的一句。》
- **长期来源**：顾客从犹豫到愿意试的真实小事。  
  例：《【待确认真实事件】她在试衣间外站了一会儿，后来试了哪件？》

### 3. 热门话题与观点

- **长期来源**：换季、上班、带娃、见亲友前的穿衣难题。  
  例：《换季时，大码女生衣柜里最容易缺的不是衣服。》
- **长期来源**：大码女性在购物时的身份共鸣。  
  例：《问尺码这件事，为什么有人要在店门口想很久？》

### 4. 实操记录

- **长期来源**：当天实际有可试尺码的货品。  
  例：《今天这条裤装，50码以上哪些尺码能现场试？》
- **长期来源**：门店真实准备动作。  
  例：《阿梅开店前先整理的，不只是衣架，是试衣间。》

### 前采优先补问

1. **最近一次顾客没买，是卡在尺码、版型还是试穿后的感受？她当时说的原话是什么？**  
   我推测，高频卡点在“怕没有自己能穿的码”，待确认后决定流量视频的开头台词。

2. **最近一位回来复购的顾客，第一次买了什么，第二次为什么又来？**  
   我推测，原因可能是记得她的尺码或愿意让她慢慢试，但必须听到顾客原话才可拍。

3. **哪些连衣裙、外套、裤装实际有50码以上可试穿，哪些没有？**  
   这是变现内容最先要补的边界，防止视频承诺大于现场事实。

4. **阿梅最近一次明确说“这件先别拿”的真实场景是什么？**  
   这件事能拍人设型内容；没有真实案例，就不写“阿梅会劝顾客不买”。

### 九宫格示例

- 行业关键词：**大码连衣裙 / 大码外套 / 大码裤装**
- 人群关心关键词：**上班 / 带娃 / 换季**
- 连出选题：
  1. 《上班见人前，大码连衣裙先试哪一处？》
  2. 《带娃活动多，大码外套为什么要先活动手臂？》
  3. 《换季买大码裤装，到店先确认有没有能试的码。》

## 前 30 条节奏

### 第1-10条

- **目标**：先测试“尺码困扰”能否把本地目标人群停住。
- **做哪个系列**：主推《试衣间门口的那一句》。
- **加什么**：穿插2条《先试，再决定》，让用户知道阿梅不是只讲情绪，店里确实有试穿场景。
- **主要形式**：以**第9计·一人分饰多角**、**第32计·换个视角**为主；辅以观点立场。
- **验收标准**：看非关注播放占比、前3秒流失、评论里是否出现“我也这样”“我最怕问尺码”等身份确认反馈。

### 第11-20条

- **目标**：保留跑得动的共鸣开头，开始补足货品和试穿证据。
- **做哪个系列**：流量系列继续发；《先试，再决定》增加到每3条至少1条。
- **加什么**：连衣裙、外套、裤装各至少出现一次，避免账号被误认成只卖某一类货。
- **主要形式**：**晒过程·火车节**、**第10计·情境还原**、**第15计·正确做法VS错误做法**。
- **验收标准**：看主页访问、私信中是否出现“有没有我能试的码”“店在哪里”，以及变现视频是否比纯挂版内容有更高完播。

### 第21-30条

- **目标**：确认“共鸣吸引人—试穿建立信任—到店承接”的链路是否成立。
- **做哪个系列**：保留数据更好的流量情境；变现系列按实际库存与换季需求轮换货品。
- **加什么**：加入已确认的阿梅职业故事；未确认的顾客故事继续不碰。
- **主要形式**：流量端继续用**第9计·一人分饰多角**；人设端用讲故事·职业经历；变现端持续用晒过程·火车节。
- **验收标准**：看咨询、导航或到店反馈；如果用户只评论不问试穿，说明变现证据不足，要增加尺码牌、试衣间和实际货品镜头。

## ⚠️ 不要做什么

1. **不要只拍衣架扫货和“今天上新”。**  
   这类内容只能让人知道店里有货，不能回答大码女生最关心的“我能不能穿、能不能试”。

2. **不要长期拍同一件衣服换几种穿法。**  
   变化来自技巧，不来自大码女装本身；用户学完搭配方法，反而不知道为什么要到店试这件货。

3. **不要硬拍顾客变装、夸张前后反差。**  
   大码服装购买需要真实试穿判断，夸张剪辑容易放大身材焦虑，也会让“先试，再决定”的定位失去可信度。
