## 第1步：脚本策略卡

- **核心问题**：大码女生挑外套时，想判断上身是否显胖，不能只站在镜子前看，还要把坐下、抬手、走路这些日常动作试出来。  
- **用户目的**：流量型，引发大码女生对“试外套先看什么”的共鸣与评论。  
- **目标人群**：县城本地的宝妈、上班族大码女生。  
- **所选形式**：对比型公式。A方案是“穿上直接照镜子”，B方案是“先活动、再照镜子”，用同一件外套、同一人、同一空间完成对比。  
- **材料递进**：站着照镜子 → 坐下、抬手、走路时继续观察 → 回到镜子前看整体。  
- **事实边界**：只展示试衣动作和观察问题，不承诺显瘦效果，不评价某件外套一定适合谁。  
- **出发点**：围绕“人”——大码女生试外套时的真实判断过程｜三有：有用处、有共鸣｜爆款元素：反差，设计在“只站着看”与“先活动再看”的试衣顺序对比中。

最后回到镜子前，看整体和你在意的位置。

评论区说说，你试外套先照镜子，还是先动一动？

## 第3步：完整分镜脚本

### 【镜头1】0-8秒｜开场钩子

- **画面**：阿梅穿着一件外套，站在镜子前。先拍镜中半身，再切近景拍阿梅看镜子的动作。  
- **台词**：  
  “大码女生挑外套，想看上身显不显胖，别只站着盯镜子：一种试法只看站着，一种先活动再看，差别在哪？”  
- **拍摄/收音要点**：  
  - 手机固定，镜头以胸口以上近景为主。  
  - “只看站着”“先活动再看”要重读。  
  - 镜面避免拍进其他顾客或工作人员。  

### 【镜头2】8-14秒｜A方案铺垫

- **画面**：全身中景。阿梅拉好外套拉链，站直，正面看镜子，再侧身看镜子。  
- **台词**：  
  “日常穿外套，不是一直站在镜子前。”  
- **拍摄/收音要点**：  
  - 动作放慢，不要急着切镜头。  
  - 保留拉链和衣料轻微摩擦声。  
- **情绪推进**：平稳铺垫。  

### 【镜头3】14-25秒｜A方案：只站着看

- **画面**：镜前中景，依次拍正面、侧面、整理衣角的手部特写。  
- **台词**：  
  “第一种试法：拉好拉链，站直，看正面和侧面，就觉得差不多了。”  
- **拍摄/收音要点**：  
  - “站直、正面、侧面”每说到一个动作，就对应一个画面。  
  - 不用夸张表情，重点是试衣流程。  

### 【镜头4】25-37秒｜差异出现：坐下和抬手

- **画面**：  
  1. 阿梅坐到稳固椅子上，拍腰腹和衣摆位置。  
  2. 起身抬手取高处衣架上的外套，拍肩背和袖口活动。  
- **台词**：  
  “可一坐下，衣摆会不会堆着？一抬手，肩背会不会卡着？”  
- **拍摄/收音要点**：  
  - 坐下前确认椅子稳固、周围没有杂物。  
  - 这里连续两个问题，语速略放慢，让观众跟着看。  
- **波点**：💡从“站着看”转到“实际活动中看”。  

### 【镜头5】37-45秒｜差异继续：走路

- **画面**：阿梅从镜子前自然走向衣架，再转身走回来；补一个手部整理衣角的近景。  
- **台词**：  
  “走起来，会不会总想拉衣角？这些，站着看不出来。”  
- **拍摄/收音要点**：  
  - 走路幅度保持日常状态，不做夸张拉扯。  
  - “站着看不出来”停顿半秒，留给画面。  
- **波点**：⚡把开头“只照镜子”的问题落到具体动作上。  

### 【镜头6】45-52秒｜B方案：正确试衣顺序

- **画面**：快切三个动作，但每个动作都完整可看清：坐下、抬手、走两步。  
- **台词**：  
  “第二种试法：先坐一下，看看腰腹和衣摆；再抬手，看看肩背；再走两步，留意会不会反复整理。”  
- **拍摄/收音要点**：  
  - 每个动作配一行字幕：坐一下／抬抬手／走两步。  
  - 镜头以中景为主，手部细节可补特写。  

### 【镜头7】52-60秒｜回到镜前＋评论引导

- **画面**：阿梅完成动作后回到镜子前，正面站定，再转向镜头口播。  
- **台词**：  
  “最后回到镜子前，看整体和你在意的位置。想挑一件穿着顺眼的外套，先看活动，再看镜子。评论区说说，你试外套先照镜子，还是先动一动？”  
- **拍摄/收音要点**：  
  - 前半句看镜子，后半句看镜头。  
  - 最后一句语气放轻，停在镜头前即可。  
  - 结尾字幕：**“先活动，再看镜子。”**

## 第4步：执行与优化建议

1. **服装准备**：选一件店内可正常试穿的外套即可，全片保持同一件，避免观众把差异理解成换了衣服。  
2. **场地准备**：镜子、稳固椅子、可走动的小段通道即可；拍摄前整理地面和衣架。  
3. **镜头重点**：不要只拍脸，多拍衣摆、肩背、袖口和走动时的整体画面，让“先活动再看”看得见。  
4. **字幕重点**：  
   - 只站着看  
   - 坐一下  
   - 抬抬手  
   - 走两步  
   - 再看镜子  
5. **剪辑节奏**：前半段镜头稍稳，突出“站着看”；后半段跟随坐、抬手、走路三个动作推进，形成节奏变化。  
6. **可延续评论选题**：从评论里收集“试外套时最在意的位置”，后续再拍对应的试衣观察内容。

## 🎬 分镜方法论（按当前形式选用，用户明确拍法优先）

### 景别不是随便选的，每一种都有它的活儿

| 景别 | 它在替你说什么 | 什么时候用 | 滥用会怎样 |
|---|---|---|---|
| 远景 📷 | 交代这是哪儿、什么氛围 | 开场建立场景、结尾留白收束 | 没有新信息时会拖沓；观察比较需要的环境信息应保留 |
| 全景 🎥 | 人和环境的关系、完整动作 | 展示全身动作、人物进出场 | 竖屏里人物太小，细节全丢，不能当主力 |
| 中景 📹 | 承载信息，最接近日常对话的距离 | 口播主体、讲解、访谈 | 全片都是中景 = 没有情绪起伏，像念稿 |
| 近景 📸 | 表情和态度，让观众读到人 | 情绪转折、强调观点、建立信任 | 连续超过 3 个会让人喘不过气 |
| 特写 🔍 | 感叹号：这个细节值得看清 | 关键物件、微表情、证据细节 | 避免没有信息的重复特写；演示细节等内容可以按需要多用 |

**适配原则**：
- 同一景别持续时检查是否有新信息；访谈可保留稳定机位，不为了数量换景别
- 相邻两个镜头的景别不要只差一档还拍同一主体（中景接近景拍同一个人），
  剪出来像跳帧；要么差两档，要么换角度
- 有需要看清的细节才设计特写，不强制每条都有特写

### 景别节奏：跟着内容与信息走

先判断当前内容是采访、真实记录、口播、演示还是剧情，再选择镜头语言，不把快切、特写和情绪高潮当作所有内容的标准。
- **开场（0-3秒）**：需要交代门店、街道与比较环境时可以用全景或远景；需要看清动作或表情时用近景、特写。一个持续有信息的镜头也可以抓住观众，不规定镜头数量。
- **展开段**：镜头提供台词之外的证据；采访保留完整问题、回答与必要停顿，不用快切制造不存在的情绪。
- **重要段落**：只有真实细节、变化或情绪需要强调时才用特写和节奏变化；没有高潮就不制造高潮。
- **收尾**：跟随原稿收束，不另加励志结论、成交或反转。
**镜头时长**：按台词、动作和信息所需时间分配。快节奏短片可以参考2-4秒切镜；访谈、持续演示、观察记录允许更长的镜头，不强制前3秒切两镜或6秒内切镜。说明长镜头保留了哪些信息，别为满足数字拆坏问答。

### 运镜：每一个运动都要有理由

| 运镜 | 它制造什么感觉 | 适合放在哪 |
|---|---|---|
| 固定 | 稳定、可信、便于读信息 | 口播、讲解、需要看清字幕的地方 |
| 推镜 | 注意力收拢，情绪递进、压迫感 | 讲到关键点、抛出结论前 |
| 拉镜 | 揭示更大的真相、释然、收束 | 反转揭晓、结尾 |
| 摇镜 | 展示空间关系、罗列 | 展示店面、一排东西 |
| 移镜/跟随 | 代入感，观众"跟着走" | 探店进门、走动中的讲述 |

**手机单人拍摄的现实约束（必须遵守）**：
- 没有稳定器时运动镜头很难稳。**运动镜头占比不超过总镜头数的 1/3**，
  其余用固定镜头 + 剪辑节奏来制造动感——这是低成本拍摄的正解
- 推拉优先用「走近/走远」而不是变焦，手机数码变焦会糊
- 一个人拍，不要出现需要两台机器同时工作的镜头
- 每个运动镜头前后各留 1 秒静止，剪辑时才有干净的出入点

### 画面不要复述台词

这是新手分镜最常见、也最致命的问题：台词说"我们的牛肉很新鲜"，
画面就拍一块牛肉。观众同时用眼睛和耳朵接收到同一条信息，
等于有一半带宽被浪费了。

画面应该做三件事之一：
1. **佐证**——台词说"老板每天五点去市场"，画面拍凌晨的市场和挂着水珠的箱子
2. **补充**——台词讲道理，画面给具体场景，让抽象的话落地
3. **反差**——台词说"看起来很简单"，画面拍手忙脚乱的失败现场，制造张力

每个镜头的「画面内容」栏，都要能回答：**这一格画面提供了台词没说的什么信息？**
答不上来的，这个镜头就是废镜头，该删或该换。

### 镜头之间靠什么接上

给出分镜时要顺带想清楚剪辑点，否则拍回来接不上：
- **动作接动作**：上一个镜头手伸出去，下一个镜头手已经碰到——动作连贯，切口隐形
- **视线引导**：人物看向画外，下一个镜头就是他看的东西
- **同形状匹配**：圆形的锅接圆形的盘子，视觉上顺滑
- **声音先入**：下一个镜头的声音提前 0.5 秒进来，是最自然的过渡

**轴线（180度法则）**：同一场戏里，机位要待在主体连线的同一侧。
跨到另一侧，观众会觉得人物突然"调了个头"，方向感瞬间混乱。
一个人的口播不涉及轴线，但只要出现两个人或"人看物"的关系，就必须守住。

## 🎯 本类内容的特殊要求

**产品类的分镜重点**：
- 开箱/揭示的瞬间必须是特写 + 略慢速，这是唯一的"哇"点
- 产品的质感靠光走：侧光打出纹理，分镜里要标明光位
- 功能演示要"before / after"成对出现，观众信的是对比不是形容词
- 手持产品的镜头，手要干净、动作要慢，快了显廉价
- 尺寸和质感要有参照物：放在手里、桌上或跟常见物品同框，单拍产品观众感受不到大小

## 🖼 画幅与影调

- **抖音**：竖屏 9:16。主体放在画面中上部——底部约 1/5 会被文案和按钮遮住，重要信息不要放那里
- **明亮**：顺光或大面积柔光、高饱和、白平衡偏冷一点点；镜头切换可以更快

任何创作都必须符合现实的生活逻辑，有说服力才行。创作的来源只能是现实中真实存在、大多数人认可的事，不凭空编造。下面三类说法一律不写（括号里的例子只说明是什么类型，不是清单，类似的说法同样不写）：
- 太离谱：一件事改变整体、判若两人、几天就见效的保证（比如「收腰就能换风格」「换个头像粉丝就翻倍」「同一件外套两种人」「换个招牌字体，营业额就翻一番」）
- 太简单：一招搞定、一句话让客户当场签单、躺着就能赚（比如「一句话让客户当场下单」「躺着月入过万」）
- 太不科学：违背常识或没有依据的因果（比如「喝某种水就能瘦」「敷一下就能消炎」）
一件事能带来的变化，要有它真实的条件、过程和代价。反差和看点要来自生活或镜头里看得见的具体变量，不靠硬切换人设、身份或结果。拿不准能不能成立，就写清楚前提和做法，不替事实下结论。一个小细节（一种做法、一个动作、一句话、一处调整）只能改变它直接作用的那一处，不能写成它让整件东西、整个人或整家店都变了。结论的范围也要和证据一样大：一次现场的反应只说明这一次，不能推成普遍的道理（比如一位客户换了靠垫说舒服，就说挑沙发都要试靠垫）。
主角是这个号卖的东西（这条管变现型，以及任何要做对比、前后变化的内容）：观众看完要觉得「是这家的东西（或手艺）让人变好看、变好用、变好吃」，而不是学会一个技巧就不用来买了。
- 流量型也遵守对比变量规则：不是每条都要对比，但只要做反差、对比或前后变化，变的是卖的东西，人、场和动作保持一致；不为了满足规则把每条都拍成商品对比。流量型仍以用户感兴趣的看点为主，不硬推卖点
- 要做对比、反差、前后变化，变的那一样必须是这个号在卖的东西，其他条件不变：同一个人（同一个空间、同一桌人）先后用两样东西——这家卖的，和普通的、旧的或常见的——前后差别看得见，才证明是东西好。例：同一个人先后穿两套衣服，前后两种风格；同一个客厅换两张沙发；同一个人戴两副镜框
- 不做「同一件东西换个穿法、搭法、摆法、用法、吃法」的对比：卖的东西没变，差别只能归功于技巧，证明不了东西好，也给不出来买的理由
- 卖的就是手艺或服务的（剪发、验光、装修设计、厨师的做法），手艺本身就是货：同一个人剪前剪后、同一份食材我们的做法和普通做法，这类对比成立
- 穿法、搭法、用法这类技巧只能顺带一句，不能当一个方向或一条内容的看点；人设型可以以人为主角，但做对比时仍遵守上面的变量规则
- **镜头围绕出发点和元素**：脚本里写明的爆款元素设计在哪一段，那一段的镜头就要把它拍出来（元素的具体画面，比如一件外套、一张沙发、一锅串，镜头里看得见）；第一秒画面用元素的句式对应的画面；人、货、场里说好的那一个要在镜头里出现。脚本没写元素的，镜头按脚本写的出发点来，不另加
每一栏的要求：
- **景别**：中文 + emoji（远景📷 / 全景🎥 / 中景📹 / 近景📸 / 特写🔍）
- **运镜**：固定 / 推镜 / 拉镜 / 摇镜 / 移镜 / 跟随
- **画面内容**：具体到「谁在哪做什么、镜头对着什么」，
  且必须提供台词之外的信息（见上文「画面不要复述台词」）
- **台词/旁白**：从原脚本里摘的原句，不要改写；没有台词写「无」
- **时长**：数字 + s，如 3s
- **拍摄要点**：这一个镜头拍的时候最容易失败的地方，一句话说清
