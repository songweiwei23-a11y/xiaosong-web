### 1. 一句话定位
阿梅大码女装店，让本地女生先试再决定。

### 2. 人设与口吻
- **我是谁**：店主阿梅，做大码女装6年，店开在县城商业街。  
- **说话什么调**：像在店里接待熟客；多说“先看”“能不能试”“这次这类款”，不用“显瘦神器”“闭眼入”。  
- **会说的一句话**：“这件先看有没有能试的码，再进试衣间看看。”  
- **不会说的一句话**：“这件谁穿都显瘦，拿走肯定好看。”  

### 3. 说给谁听
- **画像**：住在县城或周边、要上班或带娃，进服装店前会先问“有我能穿的吗”的25—40岁女性。  
- **他最怕什么**：①问完尺码被敷衍；②进店后没有能试的码；③衣服挂着好看，上身腰腹、臀腿、肩背不合适。  
- **他最想要什么**：①到店能试到的尺码；②裤装、外套、连衣裙上身后的真实状态；③不用尴尬、能自己决定买不买的试衣过程。  
- **他会搜什么词**：县城大码女装、附近大码女装店、大码裤子哪里买、大码连衣裙试穿、50码女装、大码外套实体店。  

### 4. 内容方向
- **三种视频的配比**：流量型45%（尺码困扰、小情景共鸣）+ 人设型25%（阿梅做大码女装6年的真实职业片段）+ 变现型30%（实际可试尺码、试穿过程、版型判断）。  
- **各自的结尾指令**：流量型：“有过这种经历的，评论区说一句。”；人设型：“想看阿梅讲门店里的真事，就关注。”；变现型：“想现场试穿的，到店找阿梅。”  
- **两套打法各用什么**：四大脚本主打聊观点·观点立场、讲故事·职业经历、晒过程·火车节、教知识·解题型；起号36计主打第9计·一人分饰多角、第10计·情境还原、第15计·正确做法VS错误做法、第32计·换个视角。  
- **能长期挖的选题来源**：①试衣间门口没问出口的话，如“不是怕衣服不好看，是怕没有能试的码”；②当天真实可试的货，如“这批裤装哪些尺码能现场试”；③上班、带娃、换季、聚会场景，如“上班裤子先试哪里”；④连衣裙、外套、裤装的实际判断，如“外套抬手时要看哪里”；⑤【待确认：顾客真实原话】先问最近一次顾客进店时问了什么。  
- **明确不做的方向**：①只扫衣架、报上新，观众看不出自己能不能穿；②同一件衣服换几种搭法，变化来自技巧，不是货品；③夸张变装和身材前后反差，容易制造焦虑，也证明不了试穿价值。  

### 5. 凭什么信你
- **核心卖点**：①店主阿梅做大码女装6年；②门店在县城商业街，有试衣间；③部分款有50码以上可试穿，拍哪类货就说清哪类货。  
- **可以拍成画面的证据**：门头；试衣间帘子；尺码牌近景；阿梅从衣架拿实际可试款；镜前拍腰腹、肩背、臀腿或长度；连衣裙、外套、裤装轮流出镜。  

### 6. 怎么拍
- **呈现形式**：真人口播＋试衣过程＋一人分饰小情景；试衣间和尺码牌比挂版更能证明“能试”。  
- **真实条件**：阿梅本人、一部手机、商业街门头/服装区/试衣间/镜前；暂按每周2—3条执行，【待确认：是否有人帮拍、剪辑时间】。  
- **视觉调性**：用店内自然光或正面补光，暖白色画面，手机固定拍稳；少滤镜，尺码牌和衣服颜色要拍清。  

### 7. 记忆点
- **场景**：每条变现视频从试衣间门口开始，阿梅拉开帘子或挂回衣服后开讲。  
- **道具**：涉及试穿时固定拍一秒尺码牌和拿衣服的手。  
- **语言**：“先试，再决定。”只放在试穿验证类视频结尾；**待验证：**评论区是否形成自然记忆。  

### 8. 绝对不能说
- 不说“谁穿都显瘦”“一穿就像换个人”“遮住所有问题”。  
- 不说“全店都有50码以上”“每件都能试”；只说当条视频里的实际货品和尺码。  
- 不拿顾客身材开玩笑，不拍顾客隐私；顾客出镜必须先同意。  
- 不编顾客原话、复购故事、阿梅劝顾客不买的经历；没有素材就标【待确认】。  
- 不承诺效果，不用“最”“第一”“绝对”“保证”等绝对化说法。  
- 不贬低同行，不把别家店写成反面角色。
