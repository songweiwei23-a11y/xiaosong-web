# 🚀 起号方案

## 📌 先说结论

- **建议主攻：36计·第36计 冷知识。**  
  主攻《下午4点，成都厨师开火了》。这家店每天固定下午4点出摊，成都厨师本人掌勺，串串火锅、烧烤、川菜都有真实制作动作。冷知识不靠顾客配合、不靠剧情演员，镜头跟着“一个动作 + 一个问题 + 一个结果”走，最适合新号连续拍出20—30条。

- **备选：**
  1. **36计·第31计 南北/地域差异**：当“成都来的厨师”身份被评论区频繁提起，且厨师能讲清楚一件真实的口味或点单差异时切入。
  2. **36计·第10计 情境还原**：当评论区开始问“一元怎么点”“怕辣怎么选”“两个人怎么吃”时，用来承接到店。
  3. **36计·第7计 一句话设定故事感**：当补齐真实顾客反馈、出摊经历后再启用，用来建立“成都厨师”这个人的记忆点。

- **明确不做：**
  1. **36计·第35计 街头采访**：现在没有稳定的采访条件，也不能让店员假装顾客；街采素材不稳定，会打乱下午4点备菜和出摊节奏。
  2. **36计·第30计 角色扮演**：需要多人配合、台词和表演。目前账号最值钱的是厨师本人掌勺的真实现场，不需要用剧情把真实感冲淡。

- **多久能看出跑没跑通：**  
  每种打法连续测 **3—5条**，20条左右看出主力方向；到“零粉—一千粉、非关注播放逐步稳定、本地评论和主页访问持续出现”这条线，再判断账号进入下一阶段。  
  不用一条视频定生死：先看同类视频里，哪一种开场更容易让陌生人停下来，哪一种内容更容易引来南乐本地人提问。

## 🧮 起号期内容配比

### 起号期配比：流量型45% / 人设型25% / 变现型30%

这个比例直接沿用已定定位，适合这个号的原因是：

- **流量型45%**：新号先让南乐本地陌生人认识“下午4点出摊的成都川菜厨师”。主力拍锅、火、食材、烧烤上炉、川菜下锅这些看得见的现场。
- **人设型25%**：成都人、做川菜9年、来南乐半年，是有辨识度的人设事实；但目前缺少足够的真实故事，不能一上来硬拍太多故事。
- **变现型30%**：一元火锅是到店入口，串串火锅、烧烤、川菜都需要解释“第一次来怎么点”；但不能连续拍成菜单广告。

### 每一种怎么拍

| 目的 | 先定出发点 | 用什么形式 | 脚本结构 | 结尾行动指令 |
|---|---|---|---|---|
| 流量型45% | **人**：成都厨师；**货**：串串火锅、烧烤、川菜；**场**：下午4点开火。爆款元素用**反差 / 人群 / 成本**。 | **36计·第36计 冷知识** | 反常识问题 → 厨师现场动作 → 解释这一步影响什么 → 评论互动 | **评论** |
| 人设型25% | 让人记住：成都来、做川菜9年、来南乐半年后的真实判断。 | **36计·第7计 一句话设定故事感** + 聊观点·观点立场 | 一件真实小事 → 我的判断 → 手上正在做的动作 → 关注 | **关注** |
| 变现型30% | **人**：第一次吃川味的白领、宝妈；**货**：一元火锅、串串、烧烤、川菜；**场**：真实点单和出餐。成交理由突出：**低门槛、选择清楚**。 | **36计·第10计 情境还原** + 晒过程·火车节模型 | 顾客高频问题 → 厨师问清需求 → 点单/出餐过程 → 到店 | **到店** |

### 和已定内容定位怎么对上

- **主力形式一致**：以晒过程为底，冷知识负责把过程拍得更有停留点。
- **主力系列一致**：主攻《下午4点，成都厨师开火了》。
- **三品类都能出现**：川味串串火锅、川味烧烤、川菜轮换拍，不会拍成只卖一元火锅的价格号。
- **固定人设一致**：每条都让观众看到“下午4点、成都厨师、本人掌勺”中的至少两个信息。

### 过线之后怎么变

当账号过了“一千粉、流量开始稳定”的阶段，调整为：

- **流量型40%**
- **人设型25%**
- **变现型35%**

此时加密《第一次来，怎么点才明白》，把已经验证过的“怕辣怎么选、两个人怎么点、带家人怎么选川菜”等问题拍透。  
人设型仍只用真实事件，不补编顾客故事。

## 🎯 主攻打法：36计·第36计 冷知识

### 为什么是你能拍的

这计只吃现有资源，不需要额外搭建剧情。

1. **有固定拍摄场景**：每天下午4点出摊，炉台、备菜、烧烤上炉、川菜下锅都是天然画面。
2. **有稳定出镜人**：本人就是掌勺厨师，不需要找演员，不存在“今天谁出镜”的问题。
3. **有可持续货品**：串串火锅、烧烤、川菜三个品类，每个品类都能拆出食材处理、火候、下锅、上炉、出餐等不同动作。
4. **有明确身份差异**：成都人、做川菜9年、来南乐半年，讲的是自己手上正在做的事，不是空口讲“正宗”。
5. **最低拍摄条件明确**：一部手机、一支支架或固定机位即可完成；如现场暂时无人辅助拍摄，就先拍手部、锅底、食材、出餐，再录后配口播。  
   **待确认：店里是否有能在下午4点固定帮忙拍10分钟的人。** 有人拍时，再增加厨师半身和开火全景。

### 结构公式

**36计·第36计 冷知识：反常识结论 → 现场证据 → 原理 → 应用**

套到这个号上：

> “很多人第一次吃川味，只先问辣不辣。”  
> ↓  
> 下午4点，拍厨师处理一份真实食材、开火或上炉的动作。  
> ↓  
> 厨师说清：这一步实际影响的是香味、口感、下锅时间或辣度选择中的哪一项。  
> ↓  
> 结尾问观众：你吃川味先在意辣，还是先在意香？

**一条只讲一个动作。**  
不要一条里又讲锅底、又讲穿串、又讲烧烤、又讲川菜；一个动作讲明白，观众才知道这条在说什么。

### 配什么脚本讲

配 **教知识·拆解型**。

- **冷知识**负责让片子发生一件事：厨师在下午4点做一个观众不太注意的动作。
- **教知识·拆解型**负责把话讲清楚：误区 → 动作证明 → 原因 → 观众下次怎么判断。

它补上的不是硬卖点，而是**专业可信度**。  
流量型不讲“一元火锅多划算”、不引导到店；先让陌生人觉得“这个成都厨师讲得明白，而且手上真在做”。

### 前3条具体拍什么

#### 1.《第一次吃川味，别只先问辣不辣》（反差）

**为什么会停下：** 大多数人吃川味先问辣不辣，这句话直接打破熟悉习惯。

**拍摄要点：**
- 首帧：锅、食材、厨师手部动作同时入镜。
- 厨师第一句：“第一次吃川味，别只先问辣不辣。”
- 镜头拍一个真实动作：【换成当天真实动作：处理食材 / 开锅前准备 / 烧烤上炉前处理】。
- 厨师解释：“辣只是其中一部分，像这一步，主要影响的是【换成真实结果】。”
- 最后拍下锅、上炉或出餐的画面。

**结尾：**  
“你吃川味，先在意辣还是香？评论区说说。”

---

#### 2.《下午4点，成都厨师开火前先做什么？》（人群）

**为什么会停下：** 下班前正是白领和宝妈想晚饭吃什么的时间，“开火前先做什么”有明确等待结果。

**拍摄要点：**
- 首帧直接拍下午4点开火，不拍门头长铺垫。
- 字幕：`下午4点，成都厨师开火了`
- 镜头跟拍厨师先做的第一件真实工作。
- 厨师只解释这一步，不扩展成一堂川菜课。
- 结尾用锅里变化、烤炉声音或成品近景兑现开头问题。

**结尾：**  
“明天4点，你想看串串、烧烤还是川菜？”

---

#### 3.《川味烧烤上炉前，这一步别只看辣椒》（反差）

**为什么会停下：** 观众以为川味烧烤的重点是辣椒，镜头却先拍上炉前的真实处理动作，形成反差。

**拍摄要点：**
- 首帧拍食材准备上炉，厨师手停在关键动作上。
- 开场：“川味烧烤上炉前，别只看辣椒。”
- 拍清一个真实步骤：【换成当天真实步骤】。
- 厨师解释这个步骤与【换成真实结果：口感 / 香味 / 火候】的关系。
- 最后给上炉后的声音和局部成品镜头，不做夸张试吃表演。

**结尾：**  
“你吃烧烤，最先看肉还是先看辣椒？”

### 边界

- 不把未经验证的制作细节说成固定规律。厨师当天做什么，就讲什么；没有真实依据就不拍。
- 不讲“只有成都才这样”“别人都不会做”这类无法证明的话。
- 不把“正宗”挂在嘴上，镜头里的动作、火候和出餐就是依据。
- 不拍顾客夸赞、顾客试吃反应，除非顾客本人明确同意且内容真实。
- 不在流量视频里塞“一元火锅”“到店”“私信”等成交引导。

## 🔄 备选打法（3计）

### 备选一：36计·第31计 南北/地域差异

**什么情况下切过去：**  
连续3条冷知识视频里，评论区持续出现“南乐这边吃辣吗”“成都和这边有什么不一样”“辣度能不能选”这类问题时切入。

**为什么能拍：**  
厨师本人是成都人，来南乐半年，身份事实天然具备地域入口；拍摄仍发生在炉台和出餐现场，不需要外出街访。

**怎么套到这个号上：**  
成都厨师讲一件自己在南乐真实观察到的点单或口味差异，再拍同一类菜品如何按真实需求处理。

**结构公式：**  
同一吃饭问题 → 成都做法/南乐顾客常问的问题 → 厨师解释自己的处理方式 → 评论交流。

**配的四大脚本：**  
教知识·拆解型。  
它补的是“地域话题的解释”，避免只拍成都和南乐谁对谁错。

**先拍哪一条：**  
《来南乐半年后，我发现大家吃川味先问这个》（人群）  
前提：**待确认：厨师必须给出一个真实高频问题，不能凭空写“本地人都怎样”。**

---

### 备选二：36计·第10计 情境还原

**什么情况下切过去：**  
评论区、私信或现场接待里开始反复出现“一元怎么点”“辣不辣”“两个人怎么选”的真实问题时切入。

**为什么能拍：**  
店里有真实点单、出餐、上桌流程；主角是这家卖的串串火锅、烧烤和川菜，手艺和货都能被镜头拍到。

**怎么套到这个号上：**  
复述一个真实高频问题 → 厨师先问清需求 → 拍点单和出餐 → 让观众知道下次到店该怎么问。

**结构公式：**  
真实任务 → 对话/纠错 → 厨师处理 → 出餐结果。

**配的四大脚本：**  
晒过程·火车节模型。  
它补的是**成交理由**：一元火锅低门槛、串串烧烤川菜选择清楚。

**先拍哪一条：**  
《第一次来吃一元火锅，先问清这一句》（成本）  
其中“这一句”必须替换成店里真实存在的点单规则；规则未确认前不发布。

---

### 备选三：36计·第7计 一句话设定故事感

**什么情况下切过去：**  
前采补齐至少3件真实小事后切入，例如：一次顾客反馈、一次口味沟通、一次下午4点出摊时的真实判断。

**为什么能拍：**  
厨师每天都有固定工作动作，可以用真实备菜、开火、炒制做画面；但故事必须来自本人经历，不能安排顾客演戏。

**怎么套到这个号上：**  
一个普通的开火动作 + 一句真实背景 → 讲清一件具体发生过的事 → 落到厨师的真实判断。

**结构公式：**  
普通动作 + 真实事件设定 → 事件经过 → 厨师判断 → 关注。

**配的四大脚本：**  
聊观点·观点立场，或讲故事·平凡英雄型。  
它补的是“人为什么值得被记住”，不承担成交任务。

**先拍哪一条：**  
《来南乐半年后，有句话让我不再只讲“正宗”》（反差）  
前提：**待确认：顾客当时说了什么、厨师怎么回应、这件事发生在什么真实场景。**

## 🧪 怎么测

### 一次只改一个核心变量

主攻冷知识阶段，先固定：

- 固定：下午4点、厨师本人、真实操作、20—35秒左右的短节奏。
- 只轮换：**开场问题**。

先测三种开场：

1. **反差型**：`别只看辣不辣。`
2. **结果期待型**：`开火前他先做什么？`
3. **人群型**：`下班想吃川味的人，先看这一步。`

不要同一条里同时改标题、开场、拍摄角度、时长和背景音乐，不然无法判断到底什么有效。

### 每计测几条、看什么指标

| 打法 | 最少测试量 | 主要看什么 |
|---|---:|---|
| 第36计 冷知识 | 5条 | 非关注播放、前段停留、完播、本地评论 |
| 第31计 南北/地域差异 | 3条 | 评论互动、南乐本地用户出现频率、主页访问 |
| 第10计 情境还原 | 3条 | “怎么点”“地址在哪”“几点出摊”等有效提问、到店反馈 |
| 第7计 一句话设定故事感 | 3条 | 关注、主页访问、评论是否在讨论厨师本人 |

### 什么信号算“这计行”

- 同一批视频里，某种开场连续出现更高的前段停留。
- 评论开始出现具体问题，而不只是“看着不错”。
- 本地用户开始问地点、下午几点出摊、辣度、点单方式。
- 冷知识视频里，有人开始复述厨师讲过的判断，例如“原来不只是看辣不辣”。

### 什么信号算“换掉”

- 连续5条同类内容，开头都无法让人看懂“这条到底讲什么”。
- 评论长期只围绕画面，没有人问制作、口味、品类或到店问题。
- 厨师讲不清某个知识点，现场也没有动作能证明，就立即换成另一个真实动作。
- 地域差异内容如果引发误解、争论，或厨师拿不出真实观察，就回到冷知识主线。

## 📅 30天节奏

**执行节奏按“每周集中拍2次”安排。**  
每次围绕下午4点出摊，集中拍摄2—3条；一条完整拍、一条只换开场、一条补充变现或人设素材。  
**待确认：如店里无人可固定拍摄，就以手机支架固定机位为主，厨师只补录口播。**

### 第1—7天：先把主栏目拍出来

**任务：**
- 固定《下午4点，成都厨师开火了》的首帧：炉台、火、手部动作。
- 连拍3条冷知识，三个品类各出一条：串串火锅、烧烤、川菜。
- 录下厨师真实说法，整理成“食材动作—影响结果—顾客能听懂的话”。

**交付物：**
- 冷知识成片3条。
- 真实动作素材库1份。
- 可持续使用的开场句6条。

---

### 第8—14天：测开场，不换主线

**任务：**
- 再拍2条冷知识，只换开场方式。
- 拍1条情境还原，内容只选一个已确认的高频点单问题。
- 记录评论里关于辣度、价格、点单、出摊时间的原话。

**交付物：**
- 冷知识2条。
- 情境还原1条。
- 评论问题清单1份。

---

### 第15—21天：筛出更能留人的品类

**任务：**
- 根据前5条数据，保留前段停留更好的开场。
- 用表现更好的品类继续拍3条冷知识。
- 如果已拿到真实事件，拍1条一句话设定故事感；没有真实事件就不拍人设故事，继续补过程素材。

**交付物：**
- 冷知识3条。
- 人设素材或真实事件记录1份。
- “串串 / 烧烤 / 川菜”三品类表现对比表。

---

### 第22—30天：把有效内容接到到店问题

**任务：**
- 保留数据更好的冷知识结构，拍1—2条。
- 加密情境还原，拍2条“第一次来怎么点才明白”。
- 只要顾客现场提出真实问题，就当场记录问题，不强行拍顾客脸。

**交付物：**
- 冷知识1—2条。
- 情境还原2条。
- 下月主推选题池20条：按串串、烧烤、川菜和真实顾客问题分类。
