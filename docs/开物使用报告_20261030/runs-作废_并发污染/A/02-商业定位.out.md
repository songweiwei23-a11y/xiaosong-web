# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

这是 **A 类本地实体店里的餐饮食品生意**，成交发生在南乐本地的真实到店场景。餐饮不是“拍到嘴馋就结束”，而是让顾客在想吃饭的那一刻，能看懂：吃什么、辣不辣、怎么点、价格怎么算、去哪找。

**钱主要从两处来：单桌消费和复购。**  
川味串串火锅、川味烧烤、川菜分别对应不同吃饭需求：有人临时约饭想吃串串，有人晚上想吃烧烤，有人带家人更需要一桌川菜。三类都要持续出现在账号里，原因不是“菜单丰富”这么简单，而是它们共同覆盖了顾客不同的到店理由。只拍一元火锅，容易把顾客认知锁死在“低价”；只拍厨师手艺，又会让人不知道店里具体卖什么。

**毛利不是看一个“一元”决定的。**  
餐饮利润通常由单桌点单结构决定：低门槛产品负责让顾客愿意进来，高频点单的菜品、烧烤、饮品等共同构成一桌收入；同时还要扣掉食材、调料、损耗、人工、摊位或房租、燃料等成本。  
所以，一元火锅可以是引流入口，但不能在视频里只留下“一元”两个字。顾客若到店后才发现计价范围、适用品项或其他收费没讲清，期待落差会直接伤害复购。

**我推测，这家店的决策链路属于“短决策为主、家庭和聚餐会拉长”的类型。**  
下班临时约饭的人，刷到当晚可能就会来；带家人、约同事或朋友的人，则常会先问位置、辣度、价格规则、有没有适合同行人的菜。账号不能只负责“看着香”，还要在主页和变现内容里负责“看得懂”。

**时段上，已知每天下午4点出摊，这就是目前最稳定的经营节奏。**  
不建议现在就拍“全天忙到飞起”之类的内容，因为没有真实客流数据支撑。先连续记录出摊前、刚出摊、晚饭前、晚饭高峰四段：哪段最方便拍、哪段评论和咨询多、哪段真实到店多，再确定拍摄和发布时间。

**这类店最常见的自嗨有三个：**

1. **只拍成品特写。** 观众看完知道“有一盘菜”，但不知道为什么要来这家吃。  
2. **反复讲实惠。** “便宜”不能替代计价规则，尤其一元火锅更要把适用范围讲清。  
3. **一直拍厨师炒菜。** 厨师动作能建立手艺信任，但如果没有对应到“顾客这一顿怎么吃”，视频容易吸来围观做菜的人，接不住到店客。

**同行常拍出餐、菜品、环境和价格牌，很多内容效果一般，不是画面不够香，而是缺一个具体问题。**  
本号该抢的空档是：**成都来的川菜厨师，在南乐真实掌勺，直接回答本地人吃川味时真正会犹豫的问题。**  
例如“这道川菜辣到什么程度”“一元火锅具体怎么点”“带孩子或不太能吃辣的人这一桌怎么选”。这些问题比“今天又做了什么菜”更贴近到店决策。

**一句话定位：**  
**成都厨师掌勺，南乐川味串串火锅、川味烧烤、川菜做给你。**

这句话的价值不在于喊“正宗”，而在于承诺三件可被镜头验证的事：本人掌勺、三类餐食都在做、顾客能看见实际制作。

## 变现全景

### **现在能卖什么**

1. **川味串串火锅**  
   已知一元火锅是门店核心卖点，可作为顾客第一次尝试的低门槛入口。  
   但“1元具体对应什么、哪些品项适用、其他项目如何计价”待确认后才能公开讲。

2. **川味烧烤**  
   适合晚间临时约饭、下班放松、朋友聚餐等场景。它不是串串火锅的附带内容，而是独立的到店理由，应单独拍备料、烤制和出品。

3. **川菜**  
   更适合“坐下来吃一顿”的需求，例如家庭晚饭、多人聚餐或想吃热菜的人。视频重点不是展示复杂做法，而是让顾客知道这道菜适合什么场景、辣度如何、谁能吃。

4. **组合型到店消费**  
   不是现在就推出“套餐”或编价格，而是让顾客自然形成“串串火锅＋烧烤／川菜”的点单认知。是否已有真实组合点单习惯，待确认菜单和顾客订单后再决定是否做明确推荐。

### **各自的客单价与毛利大致区间**

目前不能给出真实客单价和毛利区间，原因是缺少以下关键数据：

- 川味串串火锅的一元具体计价单位与适用品项；
- 川味烧烤、川菜的菜单售价；
- 三类产品食材成本、调料成本和损耗；
- 一桌顾客实际点单结构；
- 饮品是否销售、是否构成单桌利润；
- 房租、人工、燃料等固定成本。

**先补一张近7天的真实订单表。**  
至少记录：每桌点了什么、消费总额、串串火锅/烧烤/川菜各占多少、是否复购。没有这张表，“主推什么最赚钱”“一元火锅会不会拖低利润”都只能猜。

### **决策难度**

- **川味串串火锅：低到中决策。**  
  “一元”降低尝试门槛，但顾客仍会问计价和辣度。规则清楚，决策就短；规则模糊，顾客就会犹豫。

- **川味烧烤：低决策。**  
  对下班聚餐和临时约饭的人来说，关键是看着想不想吃、位置远不远、价格是否清楚。

- **川菜：中决策。**  
  家庭或多人吃饭时，会考虑口味、菜量、同行人的接受程度。因此川菜内容要补足“这一顿怎么点”的信息，而不只拍翻锅。

## 主推产品

**主推入口：一元火锅。**  
这里的“主推”是账号获客入口，不代表川味烧烤和川菜被降成配角。账号整体仍然要并列经营**川味串串火锅、川味烧烤、川菜**三类内容。

选择一元火锅做入口，有三个原因：

1. **信任门槛相对低。**  
   新客第一次刷到陌生店，通常不愿意直接为一桌未知口味做高决策；低门槛入口更容易让人愿意进一步问。

2. **传播记忆点明确。**  
   “一元火锅”比“有火锅”更容易被记住，但前提是把规则讲完整，不能靠模糊低价吊人胃口。

3. **生产上拍得出来。**  
   老板本人每天出摊、掌勺，可以持续拍食材、串签、锅底、出品和顾客常问问题，不需要找演员或搭建复杂剧情。

**不建议现阶段把“成都厨师做川菜9年”单独当主推产品。**  
这是信任背书，不是顾客点单时购买的东西。它应该出现在过程里，证明“为什么这个人值得看”，不能替代对川味串串火锅、川味烧烤、川菜的实际展示。

## 成交路径

### 1. 第一次接触看到什么

顾客先刷到的应是一个能立刻看懂的吃饭问题，而不是店铺自我介绍。

例如：

- 成都厨师在南乐做这道川菜，问“你们能接受多辣？”
- 一元火锅到底是一元什么？
- 下班两个人吃串串、烧烤还是点川菜，怎么选？
- 同样是晚饭，一桌人有人能吃辣、有人不能吃辣，怎么点更稳？

**这一环节会流失的人：** 不在南乐、不关心吃饭、对川味无兴趣的人。  
这是正常流失，不需要硬留；本地餐饮账号最怕为了泛流量拍无关内容，最后有播放却没有到店。

### 2. 靠什么产生兴趣

靠三类兴趣，不靠重复喊口号：

- **身份兴趣：** 成都来的川菜厨师本人掌勺；
- **场景兴趣：** 下班、约朋友、带家人吃饭时怎么选；
- **食物兴趣：** 串串下锅、烧烤上炉、川菜出锅等真实制作画面。

**这一环节会流失的人：** 只想看做菜、但没有到店可能的人。  
解决方式不是停止拍过程，而是在主页和后续变现内容中逐步补齐“店在哪、怎么计价、适不适合我”。

### 3. 在哪里沉淀

**优先沉淀在抖音主页，再引导到店。**

主页要承担三个任务：

- 让人一眼知道卖的是**川味串串火锅、川味烧烤、川菜**；
- 让人知道出镜的是成都来的川菜厨师；
- 已核实后放清楚地址、营业情况、一元火锅规则或咨询方式。

现阶段不建议急着把私信当主要成交场。  
原因是餐饮客单通常不高，所有人都私信问一遍地址和价格，会消耗老板出摊时间。能公开说清的信息，优先放主页、置顶视频和评论区；只有复杂问题再进私信。

**这一环节会流失的人：** 想来但找不到位置、看不懂计价、担心辣度的人。  
这不是内容不够香，而是承接信息缺失。

### 4. 临门一脚是什么

**临门一脚是“把这一顿吃饭的不确定性降下来”。**

具体不是催顾客“快来”，而是让他确认：

- 今天是否正常出摊；
- 店在哪；
- 一元火锅对应什么；
- 川味烧烤和川菜是否有自己想吃的；
- 自己和同行的人能否接受辣度。

对临时吃饭的人，临门一脚通常是看到真实出品和位置；  
对家庭、朋友聚餐的人，临门一脚通常是价格规则和口味选择是否清楚。

**变现视频结尾只留一个动作：到店。**  
例如：  
“位置和当天出摊情况看主页，想吃这口再过来。”  
前提是地址和营业信息已经核对无误。

## 信任证据清单

下面的证据都必须拍得到、核实得了，不用“正宗”“专业”这种空词。

1. **本人从备料到出品的连续动作**  
   - 证明：真实、专业  
   - 拍法：固定一个机位，拍切配、下锅、调味、出品中的关键段，不只拍成品。  
   - 为什么重要：顾客能看到“成都厨师本人掌勺”不是挂在简介里的身份。

2. **下午4点实际出摊的准备现场**  
   - 证明：真实、稳定经营  
   - 拍法：当天食材、串签、炉具或工作台的准备过程，以真实发生为准。  
   - 为什么重要：比空口说“每天营业”更有说服力。  
   - 注意：不要为了拍视频重复摆动作。

3. **一元火锅的实际计价展示**  
   - 证明：价格透明、实在不坑  
   - 拍法：确认规则后，对着实际品项说明“一元对应什么、怎么计算、哪些不适用”。  
   - 待确认：完整菜单、收费方式、是否存在时段或品项限制。  
   - 这是当前最缺的一条信任证据。

4. **川味串串火锅的真实出品**  
   - 证明：货真、出品稳定  
   - 拍法：食材入锅、锅中状态、实际端出，不用滤镜堆“高级感”。  
   - 为什么重要：顾客先判断的是“这一顿我想不想吃”。

5. **川味烧烤的关键烤制过程**  
   - 证明：手艺、现场制作  
   - 拍法：选一个实际售卖品项，拍上炉、翻面、出炉，不需要把全部烧烤拍成流水账。  
   - 待确认：最常被点的品项是什么，别凭空挑招牌。

6. **川菜的辣度与适用人群说明**  
   - 证明：懂顾客、能降低点单风险  
   - 拍法：厨师边做边说“这道菜今天的辣度是【按实际填写】；不能吃辣的人可以怎么选”。  
   - 为什么重要：宝妈、家庭聚餐和多人同行的顾客，往往先担心“有人吃不了”。

7. **真实顾客问答或真实回头客反馈**  
   - 证明：结果、口碑  
   - 拍法：只能在顾客同意后拍；也可以不拍人，只记录经同意的真实原话。  
   - 待确认：先问一位回头客，“第一次为什么来，后来为什么又来？”  
   - 禁止把一位顾客的反馈说成“大家都这么认为”。

8. **老板明确的经营边界**  
   - 证明：人品、稳定性  
   - 拍法：先前采，不先编。比如问老板有没有一次明确不卖、不做或不妥协的真实情况。  
   - 待确认：必须补到具体事件、当时原话和处理结果，不能拍“我做生意有原则”的空口播。

### 先补的前采问题

这几条不问“你有什么优势”，只问能拍成真实内容的事：

- 最近一次顾客对辣度、计价或出品有疑问，顾客原话是什么？你当时怎么解释、最后怎么处理？
- 有没有一位回头客，第一次为什么来、第二次为什么回来？他亲口说过什么？
- 顾客走到摊前最常问的一句话是什么？你通常怎么答？请举最近一次。
- 这个月发生过哪件和食材、备餐、设备、客人有关的小事？从开始到结束怎么处理？
- 你做川菜9年里，有哪一次做菜经历让你现在仍坚持某个做法？当时发生了什么？
- 一元火锅到底包含什么、不包含什么、怎么计价？请直接拿菜单逐项核对。
- 川味串串火锅、川味烧烤、川菜里，各自最常被顾客点的是什么？没有订单记录就先连续记7天。

## 变现型内容怎么排

### **变现型内容占比：起号期建议20%**

原因不是变现不重要，而是这个账号现在粉丝量低、陌生人对店和厨师还不熟。主页一开始连续发价格、地址、促销，容易让用户划走；但完全不发变现内容，又会导致看完不知道怎么来。

建议先按 **流量型60%／人设型20%／变现型20%** 测试。  
每发5条内容，安排1条变现型；连续测试20—30条后，再看真实咨询、主页访问、到店反馈决定是否增加。

三类经营品类在变现内容中的位置也要均衡测试：

- **川味串串火锅：** 重点讲一元火锅规则和实际出品；
- **川味烧烤：** 重点讲现场烤制和适合什么吃饭场景；
- **川菜：** 重点讲辣度、菜品特点和一桌人如何选择。

### 方向一：一元火锅到底怎么点

- **成交路径：** 解决顾客从“有兴趣”到“愿意来”的计价疑问。  
- **成交理由：** 实在不坑、价格清楚。  
- **先给的价值：** 让顾客看懂一元具体对应什么，避免到店前猜价格。  
- **四大脚本：** 教知识·推荐型  
  - 圈定人群：“第一次来、想先把价格算明白的人。”  
  - 展示实际品项和规则；  
  - 讲清适用与不适用；  
  - 不做模糊承诺。  
- **36计：** 第26计·推荐建议：  
  **事件是**厨师拿着当天真实可选品项，逐项说明一元火锅的适用范围、计价单位和其他收费，不靠一句“便宜”带过。  
- **结尾行动：** 私信。  
  仅在规则复杂、主页无法放全时使用：“想先问清楚怎么点，私信发你当天规则。”  
- **前提：** 菜单与收费方式必须老板逐项确认后再拍。

### 方向二：一份川味烧烤从上炉到端出

- **成交路径：** 让刷到的人从“看着不错”进入“我愿意去试试”。  
- **成交理由：** 本人掌勺、现场制作。  
- **先给的价值：** 顾客能看见食物是怎么从备料到出炉，不用靠形容词猜。  
- **四大脚本：** 晒过程·火车节  
  - 钩子：今天这份烧烤，先看它下炉前这一步；  
  - 关键步骤：实际处理、上炉、翻烤；  
  - 结果：出炉端盘。  
- **36计：** 第10计·情境还原：  
  **事件是**还原一位顾客点这份实际烧烤时，后厨如何从接单、烤制到出品；如果没有真实顾客订单，就只拍真实备餐和出品，不编对话。  
- **结尾行动：** 到店。  
  地址和当天出摊信息确认后，统一放主页。

### 方向三：家里有人不能吃太辣，这桌川菜怎么点

- **成交路径：** 降低家庭顾客、多人同行顾客的口味顾虑。  
- **成交理由：** 选择清楚、厨师专业判断。  
- **先给的价值：** 不教观众回家做菜，而是帮助他到店前判断这一顿是否适合自己。  
- **四大脚本：** 教知识·解题型  
  - 场景难题：一桌人有人想吃川味、有人怕辣；  
  - 放大困扰：点错菜，一桌人都吃得不自在；  
  - 解决方式：按实际菜单说明可选菜品和辣度；  
  - 最后说明适用范围。  
- **36计：** 第15计·正确做法VS错误做法：  
  **事件是**同一桌多人吃饭时，先展示“只按一个人能吃辣程度点菜”的不合适结果，再展示按实际辣度需求搭配川菜的做法。  
  这里的“错误”是点单方式，不是贬低顾客或同行。  
- **结尾行动：** 到店。

### 方向四：成都厨师今天做的这道川味串串火锅，适合谁吃

- **成交路径：** 从看食物，进入判断“这是不是我今晚想吃的”。  
- **成交理由：** 本人掌勺、实际出品。  
- **先给的价值：** 帮顾客按真实需求判断，不把所有人都往店里拉。  
- **四大脚本：** 晒过程·过程展示  
  - 选一类当天实际售卖的串串；  
  - 拍入锅、成熟、端出；  
  - 明确说适合哪种口味偏好，不适合谁。  
- **36计：** 第26计·推荐建议：  
  **事件是**厨师在真实制作过程中，按“能吃辣／想尝川味／第一次来”的不同情况，推荐当天实际有售的串串选择。  
- **结尾行动：** 到店。

### 变现内容的明确边界

- 不拍“全场都一元”“来晚就没了”等未经确认的信息；
- 不拿同行当反面例子；
- 不做夸张食物对比，不说“吃过就忘不了”；
- 不让一条视频同时出现“私信、评论、关注、到店”四个指令；
- 不把“成都厨师”当成不用展示过程的免检标签。

### 30天变现实验

**第1周：把承接补齐。**  
核对菜单、地址、出摊时间、一元火锅规则；完成头像、简介、主页置顶的基础信息。这个阶段不急着卖，先避免顾客刷到后找不到地方、问不清价格。

**第2周：测试三类餐食的到店兴趣。**  
围绕川味串串火锅、川味烧烤、川菜，各发至少1条变现型过程内容。目的不是比播放，而是看哪类内容带来更多主页访问、询价、到店反馈。

**第3周：拍顾客最常问的问题。**  
从真实评论、私信、现场问答里选问题拍，不预设“大家最关心什么”。如果多数人问辣度，就做辣度；如果多数人问一元规则，就做规则。

**第4周：留下能承接成交的3条置顶。**  
置顶不是选播放最高的，而是选：  
1）能认出厨师是谁的；  
2）能看懂三类餐食实际出品的；  
3）能看懂价格和到店信息的。

## 定价与节奏

### 起步阶段怎么定价

**不建议为了抖音额外编一个“网络专享低价”。**  
原因是餐饮最怕线上承诺和线下体验不一致。已有的一元火锅已经是低门槛入口，当前更该做的是把规则讲清楚，而不是再叠一层不确定优惠。

如果后续确实要做抖音引流，建议只在以下信息明确后再定：

- 引流品具体是什么；
- 是否限时、限量、限品项；
- 正常价格与活动价格如何区分；
- 活动是否会影响出品和现场接待；
- 顾客到店后能否一眼看懂规则。

**起步阶段最该“定”的不是低价，而是统一说法。**  
线上视频、主页、现场菜单、老板口头解释必须一致。顾客问“一元火锅怎么算”，每次听到的答案都应该一样。

### 什么时候可以涨价

现阶段不建议先讨论涨价，因为没有现有价格、成本和订单结构。  
能讨论涨价至少要满足以下依据：

1. 连续一段时间记录到真实食材、调料、人工或能源成本变化；
2. 菜单中哪些品项利润不足，已经有账目证明；
3. 顾客对价格规则的疑问不多，说明价格透明度已经建立；
4. 调价前后能清楚说明变化，不让老顾客到店才发现。

**涨价不是账号运营动作，而是经营数据动作。**  
短视频能做的是提前把实际食材、制作和规则拍清楚，降低顾客对价格变化的陌生感；不能替没有依据的涨价找话术。

## ⚠️ 风险

1. **一元火锅规则不清，吸引来的可能是误解，不是顾客。**  
   这是当前最大风险。视频里只强调“一元”，却不讲具体计价，评论和到店都会反复问；一旦线下理解不同，低门槛入口会变成信任损耗。  
   **先做什么：** 菜单逐项核对，拍一条完整规则视频，并把核心规则放主页或置顶评论。

2. **三个品类拍得像三家店，账号认知会散。**  
   川味串串火锅、川味烧烤、川菜必须轮流出现，但不能各拍各的、没有统一人物。  
   **解决方式：** 所有内容都围绕“成都厨师本人掌勺、下午4点出摊、南乐真实制作现场”展开；品类可以切换，人物和场景锚点不换。

3. **把制作过程拍成流水账，播放和到店都接不住。**  
   一直拍切菜、翻锅、烤串，观众会看两秒就划走，因为不知道这条和自己有什么关系。  
   **解决方式：** 每条先定一个顾客问题：辣度、点法、价格、下班吃什么、家庭一桌怎么选。过程只是回答问题的证据。

### 跑不通时怎么查

- **有播放、没人点主页：** 首先查视频只满足了“好看”，没有让观众知道这是南乐本地、卖什么。下一条把“成都厨师在南乐掌勺”和实际品类前置。  
- **有人点主页、没人问也没人来：** 查主页是否缺地址、出摊时间、计价规则；这不是多发视频能解决的。  
- **一直有人问一元火锅、但问完不来：** 查规则是否复杂、表达是否含糊、顾客是否误以为全部产品都一元。把完整计价说明做成置顶。  
- **川味内容播放可以、家庭客顾虑多：** 不要硬说“不辣”，应按真实菜单补拍辣度、可选菜和适用人群。  
- **烧烤、串串、川菜里某一类询问明显更多：** 先增加这一类的测试频率，但不能把另两类从账号里拿掉；要继续观察它是否真的带来到店，而不只是看播放。
