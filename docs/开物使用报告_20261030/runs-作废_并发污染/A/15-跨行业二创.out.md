原片的机制是：**先给一个具体的工作场景，再用“这个环节会影响成品”制造好奇，最后带观众看过程**。它的目的偏**变现型**：通过老板亲自挑料，给观众一个相信成品的理由。

跨行业可以借的是“场景动作→厨师的判断→带看过程→回答为什么重要”的顺序。原片围绕**人和食材**，主打“有用”，用的是“老板亲自参与”的**人群看点**；换到这家店，就拍成都来的川菜厨师在摊位上做事。原文没有说明具体镜头，下面的拍法是根据文案推测出的**纪实带看形式**，不是声称原片一定这么拍。

### 方案 1：出摊前，一元火锅先准备什么

**一句话**：原片的「老板去挑牛肉」→ 你店里的「厨师出摊前准备一元火锅」。

**借了**：用具体动作开场，再带观众看关键准备环节。  
**换成自己的**：地点换成南乐摊位，主角换成掌勺的成都厨师，事件换成一元火锅出摊准备。成交理由聚焦**专业强**，通过真实操作展示。

#### 迁移对照

| 层 | 原片 | 你的版本 |

| 开篇 | 时间＋地点＋老板正在做的动作 | 下午出摊前＋摊位＋厨师正在准备火锅 |

| 呈现形式 | 文案呈现为旁观者带看，具体镜头未知 | 手机固定在摊位，厨师本人出镜操作，后期配旁白 |
| 事件/主角 | 老板为一锅汤挑牛肉 | 成都来的川菜厨师为一元火锅出摊做准备 |

#### 开头（前 3 秒）

**第一句话**：“下午出摊前，南乐这个摊位上，厨师正忙着准备一元火锅。”

**画面**：手机固定拍摊位，厨师把当天实际要用的火锅用品摆到操作台上。

#### 口播要点

- **开场动作**：交代每天下午4点出摊，镜头跟着厨师准备当天的一元火锅。
- **说清原因**：选一个真实准备环节，说清它会影响火锅的什么；具体说法用【换成你的：出摊前实际会检查或调整的一件事，以及原因】。

- **结果与行动**：展示准备好的摊位；想了解一元火锅的朋友，**私信问我**。

#### 注意

原片依靠早起采购和挑料撑起故事；这个方案不必假设厨师去采购，直接拍出摊前真实发生的准备。台词、地点、动作和事件都换成自己店里的，不照搬原片；准备环节要先和厨师核实。
