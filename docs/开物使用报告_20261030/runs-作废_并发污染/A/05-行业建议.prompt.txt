## 内容方向：多元四类还是单一主题

**选 A 打底 + B 王牌栏目。**

- **A 多元四类打底**：晒过程为主，补知识、故事、观点。原因是店里同时卖**川味串串火锅、川味烧烤、川菜**，三个品类都需要在一批内容中持续出现；只做一个品类，主页容易被误解成单品店。
- **B 王牌栏目**：**《下午4点，成都厨师开火了》**。每天4点出摊是现成、稳定、可重复拍到的现场，能把“成都来的川菜厨师”变成观众看得见的工作状态。

**为什么不选纯单一主题：**  
目前能被持续验证的固定事件只有“下午4点出摊、本人掌勺”，还不足以支撑一个只围绕挑战、顾客故事或剧情展开的强主题账号。硬做单一主题，后面容易出现重复摆菜、重复开火，内容会空。

**为什么不做纯多元四类：**  
纯多元容易拍成“今天串串、明天烧烤、后天炒菜”，观众记不住是谁在做。王牌栏目固定“4点、厨师、开火”三个信息，负责把内容串起来。

## 三种视频怎么拍

### 一、流量型

**拍什么方向：**

1. **成都和南乐吃川味时，大家最容易误解的一件事。**  
   例如辣度、食材处理、串串和烧烤的口感差异。让观众产生“原来如此”的认知变化。

2. **下午下班前，看成都厨师怎样把一口锅准备起来。**  
   不推到店，只让陌生人看见4点出摊现场的节奏、声音和动作。

**四大脚本（薛老师）：教知识·拆解型**

- 骨架：反常识开篇 → 现场动作证明 → 解释原因 → 留一个讨论问题。
- 套到账号上：拍一份川味串串火锅食材的处理动作，厨师讲“这一刀、这一泡、这一锅分别影响什么”，最后问大家平时更在意辣还是香。
- 可叠加爆款元素：**反差、人群、成本。**

**示范标题：**  
《第一次吃川味串串火锅，别只盯着辣不辣》  
**怎么拍：** 手部近景处理食材开场，成都厨师用一句话解释“辣只是味道的一部分”，再拍下锅变化，结尾让观众评论自己能接受什么辣度。

**起号36计（小黄）：第36计·冷知识**  
反常识结论 → 食材或操作证据 → 原理 → 应用。  
事件是：观众以为川味串串火锅“辣就够了”，厨师现场处理一份食材，说明辣度之外，哪一步会影响入口后的味道。

**示范标题：**  
《川味烧烤上炉前，为什么还要多做这一步？》  
**怎么拍：** 先拍食材上炉前的关键动作，再拍火候变化，最后由厨师解释这一步影响的是哪一口口感，不出现到店引导。

**结尾行动指令：**  
**评论区说说，你下班最想看串串、烧烤还是川菜。**

# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

这是一个典型的**本地晚餐型餐饮生意**：顾客不需要提前很久决策，但会在“今晚吃什么、几个人吃、口味能不能接受、第一次会不会花冤枉钱”这几个问题上犹豫。

它不是靠一条视频卖出一桌饭，而是靠视频在顾客脑中提前占一个位置：下班、聚餐、家庭晚饭时，能想起“南乐有个成都厨师，下午4点出摊，能吃川味串串火锅、川味烧烤、川菜”。

### 这门生意主要靠什么赚钱

我推测，门店收入不是靠“一元”本身赚钱，而是靠顾客进店后的**组合消费**：

- 川味串串火锅负责降低第一次尝试门槛；
- 川味烧烤承接下班、朋友相聚、晚间加餐场景；
- 川菜承接多人吃饭、家庭晚餐和“想正经吃顿饭”的需求。

所以，真正要看的不是“有多少人冲着一元来”，而是：

1. 顾客第一次进店后，会不会继续点其他品类；
2. 一桌人是否能从串串延展到烧烤、川菜；
3. 顾客吃完是否愿意下次再来，而不是只问一遍价格；
4. 三个品类各自在什么场景下最容易被点。

**获客成本最容易卡在两头：**  
前端，短视频只讲“一元”，吸来的可能是只关心低价的人；后端，顾客到店后不知道怎么点、不理解规则，第一次体验没被接住。

### 决策周期与时段规律

这类消费的决策链路短，但不是“刷到马上到店”。

常见路径是：

> 下午刷到备菜或开火现场 → 记住店和川味特色 → 下班、周末、朋友约饭时想起 → 看主页确认位置和出摊时间 → 到店。

已知每天下午4点出摊，因此内容的有效时间应靠近晚饭决策时段。  
具体高峰、收摊时间、工作日与周末差异，档案未提供，**待确认**。这会直接影响发布时间和“到店提醒”该怎么写。

### 淡旺季与餐饮常见问题

我推测，川味串串火锅和川味烧烤更容易受天气、夜间消费和朋友聚餐影响；川菜更能承接正餐需求。具体哪类是门店稳定出单品类，不能凭感觉判断，要看真实点单和营业数据。

这类门店最常见的内容误区有三个：

1. **只拍一桌菜。**  
   观众看完只知道“有菜”，不知道自己该什么时候来、来了怎么点。

2. **只拍低价字幕。**  
   顾客会问价格，却不一定会记住川味、厨师和现场体验。

3. **三个品类一条全塞。**  
   视频会变成菜单翻页，顾客看完没有记忆点。

接手后我会明确不做两类内容：  
- 不做纯菜单轮播；  
- 不做“全场都便宜”“谁来都满意”这种没有证据的承诺。  

因为它们既不能建立信任，也接不住到店。

### 一句话定位

**成都厨师做川味串串火锅、川味烧烤、川菜，教你点明白。**

这句话把三个经营品类完整保留；“教你点明白”不是泛泛说好吃，而是直接回应新客最常见的决策问题：第一次来怎么开始、几个人怎么选、想吃川味时怎么搭配。

### 各自的客单价与毛利大致区间

门店没有提供菜单、食材成本、桌均消费和三类产品的实际销售占比，**不能替门店编具体客单价和毛利率**。

目前必须补齐四项数据，才能做真实定价判断：

1. 单人、双人、多人实际消费区间；
2. 川味串串火锅、川味烧烤、川菜各自的销售占比；
3. 各品类食材成本、损耗和人工占比；
4. 一元火锅规则下，顾客通常还会搭配点什么。

在没有数据前，只能先做商业判断：

- **川味串串火锅**：决策门槛低，但不能只看单串一元，要看整桌的实际组合消费；
- **川味烧烤**：通常更适合作为晚间消费和多人加点品类；
- **川菜**：更接近正餐结构，是否能承担更高消费，要看菜品、分量和顾客点单习惯。

### 决策难度

- **川味串串火锅：低决策。**  
  顾客先愿意试，关键是规则讲清楚、现场看起来有食欲、到店路径明确。

- **川味烧烤：中低决策。**  
  顾客会看食材、火候、出餐速度和是否适合聚餐。

- **川菜：中决策。**  
  顾客更在意人数、口味、分量、搭配和是否适合一起吃饭。

---

## 主推产品

### 主推：川味串串火锅中的“一元火锅”首次尝试入口

主推它，不是因为它一定利润最高，而是因为它最容易突破新客的第一层防线。

一个没来过的新顾客，对“正宗川味”未必能立刻判断，但对“能不能先低门槛试一下、规则清不清楚、会不会点错”感受非常直接。一元火锅能承担“第一次进店”的任务。

但要明确：**一元火锅是入口，不是账号唯一主角。**

原因有两个：

1. 如果账号长期只讲一元，顾客会把店理解成低价串串店，川味烧烤和川菜会被忽略；
2. 真正决定复购的，不会只是价格，还包括味型、选择、现场体验和是否方便。

因此，商业路径应是：

> 一元火锅降低第一次到店门槛  
> → 川味串串火锅让顾客继续点  
> → 川味烧烤、川菜承接不同用餐场景  
> → 靠真实体验形成复购。

## 成交路径

### 1. 第一次接触：先看到“一个有看点的现场”

顾客第一次不该先看到促销口播，而应该先看到：

- 下午4点开火、备菜、出摊；
- 成都川菜厨师正在处理一份食材；
- 串串下锅、烧烤上炉、川菜出锅中的一个关键瞬间；
- 一个新客最容易问的问题，例如“第一次来怎么点”。

**这一步流失的人：**  
对本地吃饭没有需求、只刷泛美食内容的人。

**为什么仍然要做：**  
新号起步必须先让陌生人停下来。没有本地以外的曝光不一定是坏事，但画面首先要能让陌生人看懂。

### 2. 产生兴趣：让顾客觉得“我去不会没头绪”

兴趣不只来自“看起来好吃”，还来自不确定感被消除。

顾客要在视频里得到其中一个答案：

- 一元火锅具体怎么开始点；
- 不太能吃辣的人怎么选；
- 下班两个人、朋友聚餐、家庭吃饭，各自可以看什么品类；
- 川味串串火锅、川味烧烤、川菜分别适合什么场景。

**这一步流失的人：**  
只喜欢看画面、但对到店没有行动意愿的人。

**为什么：**  
餐饮顾客不是缺菜单，而是缺“这家是否适合我今天”的判断。

### 3. 沉淀：主页承担“确认店铺”的任务

顾客从视频点进主页后，必须在几秒内确认四件事：

1. 这是南乐本地店；
2. 出镜的是成都来的川菜厨师；
3. 店里有川味串串火锅、川味烧烤、川菜；
4. 每天下午4点出摊，具体位置在哪里。

目前地址未提供，**待确认后补在主页简介、背景图和置顶视频里**。

**这一步流失的人：**  
找不到位置、看不懂卖什么、看不懂一元火锅规则的人。

**为什么：**  
视频负责勾起兴趣，主页负责降低行动成本。主页信息不完整，再好的视频也会漏人。

### 4. 临门一脚：到店前减少最后一个犹豫

临门一脚不是喊“快来”，而是拍清楚：

- 一元火锅真实怎么点；
- 川味串串火锅、川味烧烤、川菜分别有哪些适合的选择；
- 顾客从进店、询问、下单到上桌的大致过程；
- 下午4点后什么时间能来吃，是否需要等位或提前联系。

**这一步流失的人：**  
想来但怕规则复杂、怕口味不适合、怕到店不知道怎么点的人。

**为什么：**  
本地餐饮成交的最后障碍，通常不是“没看见”，而是“怕麻烦、怕踩空、怕第一次吃不好”。

## 信任证据清单

以下证据不是口号，都必须拍成真实画面。没有的先攒，不允许摆拍成顾客反馈。

| 可拍证据 | 证明什么 | 当前状态与攒法 |
|---|---|---|
| 下午4点备菜、开火、出摊的固定现场 | 真实、稳定经营 | 已有事实，可直接连续拍 |
| 厨师亲手处理食材、调味、掌握火候 | 专业能力 | 已有事实，但要拍具体动作，不能只拍人站在锅前 |
| 一元火锅的真实点单规则 | 透明、实在不坑 | 规则细节待确认，确认后拍“顾客怎么问、老板怎么答” |
| 川味串串火锅出锅全过程 | 产品真实、现场感 | 可拍，重点拍一个品类，不做混剪菜单 |
| 川味烧烤从处理到上炉的关键动作 | 手艺、出餐过程 | 可拍，需确认最有代表性的品项 |
| 川菜从备料到出锅的一道完整流程 | 川菜能力、正餐承接 | 可拍，需先确认哪道菜最稳定、最好拍 |
| 顾客关于辣度、点单、复购的真实原话 | 顾客感受、结果 | 当前缺失；请老板记录原话并征得拍摄同意 |
| 顾客第一次来与再次来的真实经历 | 复购理由 | 当前缺失；前采先找一位真实老客，问清两次来的原因 |

接手后的第一项前采，不是问“你家哪里好”，而是问老板：

- 顾客进店最常问的一句话是什么？
- 最近一次顾客觉得口味不合适，老板怎么处理？
- 哪位老客第二次回来时说过什么？
- 哪一步必须由老板亲手判断？
- 一元火锅最容易被误解的规则是什么？

这些回答才是后续变现内容的原料。

## 变现型内容怎么排

### 占比建议：30%

起号期仍要以流量内容为主，变现型先占30%，不建议更高。




## 输出要求

行业建议只管「这个阶段怎么打」，不重复定位。账号是谁（账号定位）、长期拍什么（内容定位）、靠什么成交（商业定位）已经定好，这里只引用它们的原名。按下面的结构输出 Markdown，每一节都落到这个账号和这个阶段上：

1. **本阶段判断**：这个阶段和目的下，现状和目标之间差在哪里，依据是档案和作品数据。数据不够就直说不够。
2. **本阶段重心方向**：给 2–3 个建议方向，优先引用内容定位里已有的系列原名。每个写清：这一阶段它负责哪个目的（流量、人设、变现）、占本阶段的比例、为什么选它（对准哪个真实需求，依据档案的哪条事实）。这是建议，用户自己选定的方向优先。
3. **每类目的的结尾动作**：流量、人设、变现各一个结尾动作，每类只留一个。变现型的动作要对应商业定位里的哪一步，写出原步骤名。
4. **本阶段暂停什么**：2–3 条，每条写依据（禁忌、档案，或内容定位里的排除项）。
5. **30 天执行规则**：3 条，只约束选题和脚本怎么做（例如「每条都要在前 5 秒说出位置」），不重述定位。
6. **复诊条件**：出现哪些迹象就该换阶段，换的时候重心怎么变。只写可以观察的迹象（例如「连续几条都有陌生人在评论区问地址」），用这个号自己过去的数据比；**不写任何具体数字**（播放量、新客人数、连续条数都不写）。

## 硬约束

- 药方是建议，不是命令。用户选定的方向优先：用户的方向不在内容定位里，就照用户的方向给建议，并说明它和内容定位、本阶段重心的差距，不阻止、不改写。
- 不替用户新增或改写内容定位。如果本阶段反复需要内容定位里没有的方向，只写「建议把它加进内容定位」，由用户决定。
- 拍小票、结账、价格画面时，金额一律用【待确认】或「金额打码」，档案里没有的数字不写。
- 不重述账号定位（这个号是谁、说给谁、凭什么信）、内容定位（长期拍什么）、商业定位（靠什么赚钱）的内容，只引用原名。
- 内容定位已有，第 2 节优先引用它的原系列名。
- 商业定位已有，第 3 节的变现动作写出原步骤名。
- 不编造任何数字、案例、客户故事、效果承诺。缺的事实用【待确认】标出
- 价格、价位、人均、营业时间、地址、作息、门店活动，只有档案或素材里写了才能用。档案里没有的，写成「价格摆在明面」这类做法即可，具体数字用【待确认】占位，不要替它定价
- 阈值类数字（完播率、播放量、咨询人数、转化率）一律不给具体合格线，例如「完播低于 X% 就换」。改成和这个号自己过去的数据比较；没有历史数据就写「待建立」
- 档案里写着「未填」「待补充」或留空的项，不当作事实使用，也不凭行业印象补成具体值；推断出来的内容要标明是推断
- 与账号档案的事实冲突时以档案为准
- 禁忌里写的不能说、不能拍，方案里一律不出现
- 不输出寒暄和过程说明，只输出方案正文
