# 💎 内容定位方案

## 长期价值主张

**带你看懂川味串串火锅、川味烧烤、川菜怎么做怎么吃。**

---

## 内容方向：多元四类还是单一主题

**选 A 打底 + B 王牌栏目。**

- **A 多元四类打底**：晒过程为主，补知识、故事、观点。原因是店里同时卖**川味串串火锅、川味烧烤、川菜**，三个品类都需要在一批内容中持续出现；只做一个品类，主页容易被误解成单品店。
- **B 王牌栏目**：**《下午4点，成都厨师开火了》**。每天4点出摊是现成、稳定、可重复拍到的现场，能把“成都来的川菜厨师”变成观众看得见的工作状态。

**为什么不选纯单一主题：**  
目前能被持续验证的固定事件只有“下午4点出摊、本人掌勺”，还不足以支撑一个只围绕挑战、顾客故事或剧情展开的强主题账号。硬做单一主题，后面容易出现重复摆菜、重复开火，内容会空。

**为什么不做纯多元四类：**  
纯多元容易拍成“今天串串、明天烧烤、后天炒菜”，观众记不住是谁在做。王牌栏目固定“4点、厨师、开火”三个信息，负责把内容串起来。

## 内容配比

### 作用配比

| 作用 | 占比 | 为什么 |
|---|---:|---|
| 流量型 | 45% | 起号期需要先让南乐本地陌生人刷到、停下来。川味制作、地域口味差异、下班吃什么，覆盖面比单纯介绍菜单更大。 |
| 人设型 | 25% | 成都厨师、做川菜9年、来南乐半年，这些事实需要反复被看见；但真实故事素材目前不足，不能硬占太多。 |
| 变现型 | 30% | 一元火锅是低门槛入口，川味串串火锅、川味烧烤、川菜都需要拍清楚“第一次来怎么选、怎么点、什么时候来”。但新号不能连续硬推。 |

**什么数据出现时切换：**  
连续20—30条后，如果流量型内容已经能稳定带来非关注播放、评论和主页访问，而“地址在哪”“一元怎么点”“辣不辣”等到店问题明显增加，可把流量型逐步降到40%，变现型提到35%；如果播放有但主页访问和本地评论少，先不加变现，继续优化流量入口是否足够本地化。

### 形式配比

| 形式 | 占比 | 负责哪种作用 | 为什么 |
|---|---:|---|---|
| 晒过程 | 45% | 流量型、变现型 | 当前没有已验证的数据型内容，先以最匹配现场资源的形式起步。备菜、穿串、上炉、炒制、出摊都是真实动作，三个品类都能拍，也最能证明“本人掌勺”。 |
| 知识 | 25% | 流量型、变现型 | 不讲大而空的川菜课，只讲顾客能听懂的一个判断：辣度、食材处理、火候、不同吃法。让观众产生认知变化。 |
| 故事 | 20% | 人设型、变现型 | 用真实职业经历、真实顾客反馈和真实出摊小事，让人记住厨师本人。前提是前采拿到具体事件，拿不到就不拍。 |
| 观点 | 10% | 人设型 | 用于表达这位成都厨师对川味、口味、出餐的真实判断；不能脱离9年做川菜的经历做空泛输出。 |
| 段子 | 0% | 暂不安排 | 目前没有多人表演、稳定演员和剧情拍摄条件，强做会拉低真实感，也挤占出摊现场的拍摄时间。 |

### 题材配比

- **主赛道题材：75%**  
  围绕**川味串串火锅、川味烧烤、川菜**轮换拍：备菜、制作、出餐、点单、口味判断、下午4点出摊。

- **目标人群兴趣题材：25%**  
  不是拍无关日常，而是从白领和宝妈真实会关心的吃饭问题切入：
  1. 下班前“今晚吃什么”；
  2. 家庭晚饭、朋友聚餐怎么点更清楚；
  3. 第一次吃川味，担心辣度、选择和价格规则。

### 配比核验

1. **流量型是不是和账号阶段匹配：是。**  
   45%是最大块，符合0—1000粉阶段先获取陌生人反馈的需求。

2. **主力形式是不是已验证类型：否，但理由成立。**  
   档案没有历史数据；晒过程不是“已经跑通”，而是基于每日4点出摊、本人掌勺、三品类都有制作现场的工作假设。

3. **大流量内容是否有明确出发点：是。**  
   人是成都厨师，货是川味制作，场是下午4点开火；每条流量内容必须叠加人群、反差、成本或地域差异中的一个看点。

4. **题材有没有给目标人群兴趣留位置：是。**  
   下班吃饭、家庭点单、第一次尝试川味，都是白领和宝妈会遇到的具体场景。

5. **每个数字能否解释：是。**  
   45/25/30采用已定作用配比；形式配比依据真实素材量和拍摄条件，不假装已有数据验证。

## 三种视频怎么拍

### 一、流量型

**拍什么方向：**

1. **成都和南乐吃川味时，大家最容易误解的一件事。**  
   例如辣度、食材处理、串串和烧烤的口感差异。让观众产生“原来如此”的认知变化。

2. **下午下班前，看成都厨师怎样把一口锅准备起来。**  
   不推到店，只让陌生人看见4点出摊现场的节奏、声音和动作。

**四大脚本（薛老师）：教知识·拆解型**

- 骨架：反常识开篇 → 现场动作证明 → 解释原因 → 留一个讨论问题。
- 套到账号上：拍一份川味串串火锅食材的处理动作，厨师讲“这一刀、这一泡、这一锅分别影响什么”，最后问大家平时更在意辣还是香。
- 可叠加爆款元素：**反差、人群、成本。**

**示范标题：**  
《第一次吃川味串串火锅，别只盯着辣不辣》  
**怎么拍：** 手部近景处理食材开场，成都厨师用一句话解释“辣只是味道的一部分”，再拍下锅变化，结尾让观众评论自己能接受什么辣度。

**起号36计（小黄）：第36计·冷知识**  
反常识结论 → 食材或操作证据 → 原理 → 应用。  
事件是：观众以为川味串串火锅“辣就够了”，厨师现场处理一份食材，说明辣度之外，哪一步会影响入口后的味道。

**示范标题：**  
《川味烧烤上炉前，为什么还要多做这一步？》  
**怎么拍：** 先拍食材上炉前的关键动作，再拍火候变化，最后由厨师解释这一步影响的是哪一口口感，不出现到店引导。

**结尾行动指令：**  
**评论区说说，你下班最想看串串、烧烤还是川菜。**

---

### 二、人设型

**拍什么方向：**

1. **做川菜9年后，这位成都厨师形成的一个工作判断。**  
   例如：面对辣度、出锅、食材状态时，他为什么不按“随便来”的方式处理。必须以真实现场为证据。

2. **来南乐半年后，一次真实反馈怎样改变了他的表达方式。**  
   待确认：需要老板提供顾客当时说的话、自己怎么回应、最后怎么处理。

**四大脚本（薛老师）：聊观点·观点立场**

- 骨架：亲身经历 → 我的判断 → 为什么这么看 → 邀请观众看主页。
- 套到账号上：从一次真实的顾客口味反馈开始，讲“我不认为川味只能靠辣让人记住”，再用自己的制作习惯解释原因。
- 可叠加爆款元素：**反差、人群。**

**示范标题：**  
《做川菜9年，我不认为川味只靠辣》  
**怎么拍：** 厨师在4点备菜时说出真实判断，镜头跟着手上动作走，不摆拍顾客反馈。

**起号36计（小黄）：第7计·一句话设定故事感**  
普通动作 + 目标/困境/关系设定 → 故事期待。  
事件是：下午4点，厨师正在准备川菜，旁白抛出一件真实发生过的事：“来南乐半年后，有位顾客问我的一句话，让我重新想了想怎么讲川味。”随后讲清事件经过。

**示范标题：**  
《来南乐半年后，有句话让我不再只讲“正宗”》  
**怎么拍：** 先拍开火和备料，后续必须替换为老板真实经历；没有这件事就不拍这条。

**结尾行动指令：**  
**关注，看这个成都厨师每天4点怎么开火。**

---

### 三、变现型

**拍什么方向：**

1. **第一次来，川味串串火锅怎么开始点。**  
   成交理由是**低门槛**：一元火锅不是一句价格口号，而是让顾客看懂怎么尝试。

2. **下班聚餐或家庭晚饭，川味烧烤和川菜怎么选。**  
   成交理由是**选择清楚**：不是说“什么都好吃”，而是把不同场景对应的品类讲明白。

**四大脚本（薛老师）：晒过程·火车节模型**

- 骨架：顾客的真实问题 → 厨师现场处理 → 出餐结果。
- 套到账号上：从“第一次来不知道怎么点”开始，拍老板怎样介绍一元火锅规则、怎样按顾客真实需求推荐川味串串火锅、川味烧烤或川菜。
- 可叠加爆款元素：**成本、人群。**

**示范标题：**  
《第一次来吃一元火锅，先把这件事问清楚》  
**怎么拍：** 只拍真实顾客问题或由厨师复述高频原话，现场展示怎么点、怎么下锅，最后拍出餐。

**起号36计（小黄）：第10计·情境还原**  
真实任务 → 对话/纠错 → 旁观学习 → 结果。  
事件是：顾客第一次点川味串串火锅，问一元怎么计算、辣度怎么选；厨师按真实回答讲清楚，镜头记录点单到上桌。

**示范标题：**  
《下班两个人吃川味烧烤，厨师会先问哪一句？》  
**怎么拍：** 不替顾客设计台词，先由厨师说出真实接待中会确认的需求，再展示对应出餐过程。

**结尾行动指令：**  
**想试试的，下午4点后直接到店问。**

## 内容系列（3 个）

### 1. 《下午4点，成都厨师开火了》

**一句话讲清：** 每天下午4点，拍一件决定川味口感的小事。

- **出发点：**  
  面向下班前刷短视频的新锐白领和想安排晚饭的精致妈妈；围绕“场”——固定的4点出摊现场；满足“有兴趣”，让人想看锅什么时候开、食材怎么变；爆款元素主要用**反差、成本、人群**，放在标题和开场问题里。

- **定量 / 变量：**  
  定量是“4点开火 + 一个具体问题 + 一个现场动作”；变量是每集的品类、食材和问题。  
  **变量是：川味串串火锅、川味烧烤、川菜中的不同食材或制作任务。**  
  **看点是不是一个试穿、挑选、穿搭技巧：不是。** 每集都有一个制作结果或认知结果。

- **用哪套打法：**  
  36计系列，**第36计·冷知识**。

- **目的和结构：**  
  主目的为流量型。结构是反常识结论 → 现场证据 → 厨师解释 → 评论互动。

- **让观众发生哪种变化：**  
  **认知变化。**

- **前10集标题：**
  1. 《下午4点，川味串串火锅为什么不是先下锅？》（反差）
  2. 《川味烧烤上炉前，成都厨师先看哪里？》（人群）
  3. 《一元火锅里的串，什么情况不适合久煮？》（成本）
  4. 《川菜下锅前多等一会儿，差别在哪？》（反差）
  5. 《下班想吃串串的人，最容易忽略哪一步？》（人群）
  6. 《川味烧烤的香，不只是靠辣椒》（反差）
  7. 《下午4点这锅底，先准备的不是你以为的东西》（反差）
  8. 《第一次吃川菜，为什么别急着只看辣？》（人群）
  9. 《串串火锅煮久了，到底少了什么？》（成本）
  10. 《成都厨师出摊前，为什么总要先做这一件事？》（人群）

- **立项检验：**  
  一句话能讲清，观众会追看下一次“4点又做了什么”；三个品类、不同食材、不同问题能支撑30集以上；每天真实发生，不需要演；流量内容不推销，但持续强化“南乐、成都厨师、4点出摊”的记忆，为后续到店内容铺路。前10集覆盖反差、人群、成本三种元素，句式没有连续重复超过3次。

### 2. 《成都厨师的出摊规矩》

**一句话讲清：** 用真实经历讲清，这位厨师为什么坚持某个做法。

- **出发点：**  
  面向会因为“人真实、做事有边界”而关注的本地消费者；围绕“人”——成都来的川菜厨师；满足“有共鸣”，让人看到职业里真实的坚持和调整；爆款元素主要用**反差、人群**，放在标题的经历冲突里。

- **定量 / 变量：**  
  定量是“一个真实事件 + 一个厨师判断 + 一个现场动作”；变量是不同事件、不同顾客问题、不同品类。  
  **变量是：真实发生的顾客反馈、制作判断或出摊事件。**  
  **看点是不是一个试穿、挑选、穿搭技巧：不是。** 看的是人如何面对一件真实的事。

- **用哪套打法：**  
  四大脚本系列，**聊观点·观点立场** 或 **讲故事·平凡英雄型**。

- **目的和结构：**  
  主目的为人设型。结构是亲身经历 → 判断 → 现场细节 → 关注。

- **让观众发生哪种变化：**  
  **信任变化。**

- **前10集标题：**
  1. 《做川菜9年后，我不再只说“辣一点”》（反差）
  2. 《来南乐半年，我第一次被问住的是这句话》（人群）
  3. 《这份川菜，我为什么宁愿多等一会儿再出锅？》（反差）
  4. 《顾客问“能不能不辣”，我会先问清什么？》（人群）
  5. 《下午4点出摊前，这一步我不会省》（反差）
  6. 《一元火锅被问得最多的一次，后来我怎么回答》（成本）
  7. 《做川味烧烤时，有个要求我得先讲明白》（人群）
  8. 《一位顾客的话，让我重新想怎么介绍川味》（反差）
  9. 《来南乐后，我发现大家点川菜时最在意这个》（人群）
  10. 《做川菜这么多年，我最怕顾客只记住价格》（成本）

- **立项检验：**  
  这套系列必须先完成前采才能启动：至少收集10件真实事件、10句顾客原话或10次现场判断。现在的标题是拍摄方向，不是已发生事实。追看理由在于观众想知道“这位成都厨师下一次会怎么判断”；真实事件、顾客反馈和三品类都能提供30集变量；与变现的连接是先建立“这个人做事有依据”的信任，但系列内不推到店。元素覆盖反差、人群、成本，句式有变化。

### 3. 《第一次来，怎么点才明白》

**一句话讲清：** 把第一次到店会问的问题，在真实出餐现场讲清。

- **出发点：**  
  面向第一次尝试川味的白领、宝妈和朋友聚餐人群；围绕“货”——川味串串火锅、川味烧烤、川菜；满足“有用”，降低顾客第一次点单的不确定；爆款元素主要用**成本、人群、反差**，放在“第一次来”“怎么点”“别误会”的开场里。

- **定量 / 变量：**  
  定量是“一个真实高频问题 + 现场演示 + 一份出餐结果”；变量是顾客需求、点单场景和对应品类。  
  **变量是：串串火锅、烧烤、川菜的不同点单需求与真实顾客问题。**  
  **看点是不是一个试穿、挑选、穿搭技巧：不是。** 每集解决一个到店前的具体疑问。

- **用哪套打法：**  
  36计系列，**第10计·情境还原**。

- **目的和结构：**  
  主目的为变现型。结构是真实任务 → 问答或纠错 → 厨师处理 → 出餐 → 到店。

- **让观众发生哪种变化：**  
  **行动变化。**

- **前10集标题：**
  1. 《第一次来吃一元火锅，先问清这一句》（成本）
  2. 《下班两个人吃川味串串火锅，怎么开始点？》（人群）
  3. 《带家人吃川菜，点菜前先说清这个》（人群）
  4. 《想吃川味烧烤，又怕辣，现场怎么问？》（反差）
  5. 《一元火锅不是只看价格，第一次来这样问更明白》（成本）
  6. 《朋友聚餐想吃川味，串串和烧烤怎么选？》（人群）
  7. 《第一次点川菜，哪些需求要提前告诉厨师？》（人群）
  8. 《川味串串火锅下单前，别把这个问题留到上桌后》（反差）
  9. 《想吃烧烤又想吃川菜，先看你是哪种聚餐》（人群）
  10. 《下午4点后到店，第一次来可以怎么问？》（成本）

- **立项检验：**  
  一句话清楚，观众会追看下一个“我自己的场景怎么点”；变量来自真实高频问法，能持续拍30集；必须录真实顾客问法或由老板基于真实接待复述，不能找人假装随机顾客；与变现直接相连，解决顾客到店前的不确定。元素覆盖成本、人群、反差，标题句式未连续重复超过3次。

### 第1—10条

  看非关注播放、前段停留、评论里是否有人开始问“这是哪儿”“几点出摊”“一元怎么点”；第一阶段不只看播放高低，要看哪类开头能带来本地问题。

### 第11—20条

- **目标：** 找到最容易被看完的品类和问题，并开始让观众记住厨师本人。
- **做哪个系列：**  
  继续测试《下午4点，成都厨师开火了》；启动已完成真实素材采集的《成都厨师的出摊规矩》。

- **主要用哪套形式：**  
  流量继续用第36计·冷知识，也可测试**第31计·南北/地域差异**；人设以讲故事、观点立场为主；变现继续用火车节模型和第10计·情境还原。
- **验收标准：**  
  看哪些品类能带来更高完播、哪些问题评论最多、主页访问是否增加；变现型重点记录到店顾客是否提到视频内容。

### 第21—30条

- **目标：** 用有效栏目稳定生产，把“看热闹”推进到“知道怎么来、怎么点”。

  保留数据更好的流量栏目；加密《第一次来，怎么点才明白》；只保留真实度高的人设故事。

  看主页访问到咨询、到店问法、复看和本地评论的变化；如果变现型播放不高但带来真实到店询问，仍可保留，不要只按播放淘汰。

## ⚠️ 不要做什么

1. **不要把账号拍成只讲“一元”的价格号。**  
   一元火锅是第一次尝试的入口，不是全部价值。长期只拍价格，容易吸引只问规则、不关心川味串串火锅、川味烧烤、川菜的人。

2. **不要每条视频把串串、烧烤、川菜全部塞进去。**  
   单条信息过多，观众记不住重点；正确做法是按品类轮换，但固定由“成都厨师下午4点出摊”串联。

3. **不要硬拍顾客采访、假装随机反应或编厨师故事。**  
   这个号真正能建立信任的，是厨房、炉台、备菜和真实问答。没有真实顾客原话，就先拍厨师手上的动作，不用剧情填空。
