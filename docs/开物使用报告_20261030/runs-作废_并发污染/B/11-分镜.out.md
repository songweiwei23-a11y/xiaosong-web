- 景别分布：特写 **2 个** / 近景 **4 个** / 中景 **5 个** / 全景 **4 个** / 远景 **0 个**

### 4. 🧰 拍摄清单

- **必备**：手机；手机支架，或能稳固托住手机的台面；可用于坐下演示的座椅。
- **加分项**：领夹麦可减少门店环境声；补光灯可在自然光不足时补亮面部。没有设备时，靠窗拍摄，并在安静时另录配音。
- **道具与场地**：店内外套、试衣镜、试衣间、衣架；包为建议道具，也可用低处衣架替代并同步删去对应台词。外套在整条片中保持同一件。
- **画幅与光线**：手机竖拍；人物和字幕避开屏幕底部遮挡区域。优先利用窗边柔和自然光，衣服局部镜头可让光从侧面进入。

### 5. ⚠️ 这条片子最容易翻车的 3 个地方

- **【风险】**站姿和活动画面切得太快，看不出外套怎么随动作变化 → **【怎么避】**先完整拍下坐下、抬手、弯腰，再剪掉动作前后的等待，别切掉动作本身。
- **【风险】**镜前拍摄时手机入镜，或者镜头只拍到脸，看不到外套 → **【怎么避】**开拍前让阿梅站到标记位置检查画面，把手机放在镜子侧前方，同时确认肩、腰和动作范围可见。
- **【风险】**抬手或弯腰时刻意拉扯，观众误以为这件外套一定紧或一定舒服 → **【怎么避】**按日常速度自然做动作，只提出观察问题；不加“适合所有人”等结论字幕。
