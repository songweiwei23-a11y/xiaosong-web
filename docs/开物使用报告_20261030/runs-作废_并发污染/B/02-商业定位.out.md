# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

大码女装不是单纯“卖一件衣服”的生意，核心难点在于**尺码库存和试穿信任**。

普通女装可以靠挂版、模特图、低价上新吸引人；但大码顾客买之前通常要多确认几件事：有没有自己的码、上身会不会卡肩背或腰腹、坐下和抬手是否舒服、试衣时会不会尴尬。她愿意到店，往往不是因为刷到了一件“显瘦新款”，而是先确认“我去了不会白跑”。

这行的毛利通常来自零售差价，但真正影响利润的不是一件卖得多贵，而是库存周转：同一款要覆盖更多尺码，断码会丢成交，积压又会占资金。  
**我推测：阿梅店里最需要优先解决的不是曝光量，而是让本地顾客刷到后愿意进试衣间。待确认：各尺码段的断码和积压情况。**

大码女装的成交属于**中低决策、线下确认型消费**：  
- 临时有聚会、换季、上班要见人，顾客会很快产生需求；  
- 但她通常不会看完一条视频就付款，还会先看主页、问尺码、看试穿，再决定是否到店；  
- 到店后，真正影响成交的是“试到合身款”的数量和体验，而不是阿梅讲了多少穿搭术语。

旺季通常集中在换季、节前聚会、返工返校、天气突然转冷或转热前后；日常高频需求则来自下班逛街、接孩子路过商业街、临时要参加饭局或家庭聚会。

同行最容易犯的错，是把短视频拍成“衣架上新通知”：一排衣服加几句“新款、百搭、显瘦”。这种内容看着像在卖货，但顾客仍不知道自己能不能穿。阿梅要做的不是和同行比谁上新快，而是反复让观众看到：**大码女装在这里能试，试完能判断。**

**一句话定位：做了6年大码女装的阿梅，先替县城女生试合身款。**

## 变现全景

### **现在能卖什么**

1. **大码连衣裙**  
   对应聚会、节假日、见亲友、日常通勤等需求。画面上最适合做试穿前后对比，容易让顾客判断版型。

2. **大码外套**  
   对应换季、降温、通勤和出门场景。顾客尤其会在意肩背活动、袖口、叠穿空间和长度。

3. **大码裤装**  
   对应上班、接送孩子、久坐、日常活动等高频需求。顾客重点看腰腹、臀腿、坐下和走动时的状态。

4. **到店试穿后的成套选购**  
   不是额外虚构一项服务，而是把现有的试衣间资源变成成交环节：顾客进店后，不只试一件，而是在连衣裙、外套、裤装里找到适合自己当下场景的款。

### **各自的客单价与毛利大致区间**

客单价、进货成本、折扣空间均未提供，不能编具体金额。  
从服装零售逻辑看，毛利通常受进货渠道、尺码完整度、季末清货和本地竞争影响较大，不能只按吊牌价判断。

**待确认三项后，才能定真实价格带：**  
1. 连衣裙、外套、裤装目前的主销价；  
2. 各品类平均进货成本；  
3. 顾客通常是一件成交，还是会连带买两件以上。

### **决策难度**

- **大码连衣裙：中低决策。** 有具体场景时下单更快，但上身版型必须确认。  
- **大码外套：中决策。** 季节性强，价格通常更高，顾客会比较面料、厚度、活动空间和搭配范围。  
- **大码裤装：中决策。** 复购潜力较高，但腰腹、臀腿和裤长是否合适，必须靠试穿建立信任。  
- **到店成套选购：中决策。** 不是顾客一开始就想买一套，而是试到一件合适后，才愿意继续试第二件、第三件。

## 主推产品

主推的不是某一件最贵的货，而是：**“到店试穿后选购的大码女装”，连衣裙、大码外套、大码裤装按季节轮流承接。**

原因有三个：

1. **它最符合阿梅现有资源。** 店里已有试衣间，且50码以上有可试穿款；这是顾客在线上买衣服得不到的确认过程。  
2. **它先跨过最大信任门槛。** 大码顾客最怕白跑、没码、上身不合适。先让她进店试，后面的单件成交和连带购买才有机会发生。  
3. **它不依赖阿梅硬讲专业术语。** 现在未确认阿梅是否擅长长口播和复杂搭配教学，先用真实试穿过程建立信任，生产成本更低，也更可持续。

明确不建议把“低价清仓款”当成起号主推。原因不是不能卖，而是阿梅当前最硬的优势是“能试到”，不是“全城最低价”。一开始靠低价吸来的人，会把账号带向价格比较，后续很难回到试穿价值。

## 成交路径

### 1. 第一次接触：刷到“大码女生的真实进店顾虑”

顾客先看到的，不该是衣架，而是她熟悉的一句话：  
“有我能穿的吗？”  
“最大到多少码？”  
“这件我穿会不会紧？”

这一步的任务是圈中真正需要大码女装的人，靠的是**身份确认**。她会觉得“这说的不就是我”。

**这里会流失的人：**  
只看潮流穿搭、追求全国低价、与大码需求无关的泛观众。  
**为什么可以流失：**  
阿梅是县城门店，目标不是吸所有女装流量，而是让本地需要试穿的人留下来。

### 2. 产生兴趣：看到真实上身，而不是只看挂版

顾客会继续看：同一位出镜人试不同版型的大码连衣裙、大码外套或大码裤装，镜头保留侧身、坐下、抬手、走动等动作。

这一步的任务是从“我也有这个烦恼”变成“这家店可能真有我能试的衣服”，靠的是**真实试穿证据**。

**这里会流失的人：**  
只想看快速换装、只要低价信息、没有到店条件的人。  
**为什么会流失：**  
她们没有进入线下试穿链路的意愿，不是当前变现的核心人群。

### 3. 沉淀：主页、私信与到店前确认

主页置顶内容要解决三个问题：  
- 阿梅是谁；  
- 店里卖什么大码女装；  
- 50码以上是否有可试穿款、怎么到店试。

私信不需要聊很长，先做一个固定回复：  
“你平时穿什么尺码？想找连衣裙、外套还是裤装？方便的话到店先试，上身合适再选。”

**这里会流失的人：**  
只问价格、不说需求，也不愿到店的人。  
**为什么会流失：**  
大码女装的核心问题是版型和上身，不是只靠聊天就能替她判断。

### 4. 临门一脚：进试衣间，试到一件合身的货

真正让顾客付款的，不是“阿梅说这件好看”，而是顾客自己穿上后，能完成她原本想做的动作：抬手、坐下、走路、侧身看腰腹和肩背。

临门一脚应是阿梅的现场引导：  
“你先别急着拿，去试衣间活动两下，舒服再留。”

**这里会流失的人：**  
试穿后发现尺码、版型或预算不合适的人。  
**为什么会流失：**  
这属于正常筛选，不能靠强推成交。记录这些没成交原因，反而能帮助后续选款和拍内容。

## 信任证据清单

1. **尺码牌特写 + 衣架区镜头**  
   - 证明：真实、可试穿  
   - 已有基础：50码以上有可试穿款。  
   - 拍法：顾客问尺码时，先拍阿梅从尺码牌开始找，而不是只口头回答。

2. **试衣间门口的进出过程**  
   - 证明：真实、服务过程  
   - 已有基础：门店有试衣间。  
   - 拍法：拍拿衣服、进试衣间、出来调整衣领或袖口的过程；顾客不愿出镜时，只拍背影、手部或阿梅配音。

3. **同一人试两件不同版型的衣服**  
   - 证明：专业判断、结果  
   - 拍法：同一个人、同一面镜子、同样的抬手和侧身动作，只换大码连衣裙、大码外套或大码裤装。  
   - 注意：不拍同一件衣服换穿法的对比，避免把成交理由变成技巧。

4. **阿梅回答真实高频问题的原声**  
   - 证明：真实、专业  
   - 待确认：顾客进店最常问的一句话及阿梅原本的回答。  
   - 攒法：连续一周记录顾客问句，选重复最多的三句拍成固定栏目。

5. **顾客授权后的试穿反馈**  
   - 证明：结果、真实  
   - 待确认：是否有顾客愿意出镜或录音。  
   - 攒法：不要求夸奖，只记录真实判断，例如“这件肩膀不会卡”“这条坐下不勒”。

6. **阿梅的选款与淘汰过程**  
   - 证明：专业、边界  
   - 待确认：店里是否确实有因版型不稳定、尺码偏差大而不再进的款。  
   - 只有存在真实事件才能拍，不能为了立人设编“什么货都不卖”。

7. **老客再次进店的原因**  
   - 证明：复购、结果  
   - 待确认：找一位真实老客，问清第一次和第二次来的具体原因。  
   - 拍法：重点不是拍成交金额，而是拍她当初卡在哪里、这次为什么直接来试。

8. **门店入口到试衣间的完整动线**  
   - 证明：便利性、真实  
   - 拍法：从商业街门口走进店，经过衣架到试衣间，告诉顾客“不是网上看图，是到了能直接试”。  
   - 这条尤其适合做置顶，不需要顾客出镜。

## 变现型内容怎么排

### **占比建议：25%**

起号期不建议把变现内容做得太多。这个号当前仍需要靠流量型内容让县城大码女生先刷到、先认出自己；但每4条里至少要有1条变现内容，持续证明“不是普通挂版女装店”。

这25%的内容全部围绕一个成交理由：  
**50码以上有可试穿款。**

变现内容不是硬广。每条先帮顾客解决一个具体判断，再让她知道可以到店试。

### 方向一：顾客问“有我能穿的吗”，阿梅怎么找款

- **对应成交路径：** 从私信/主页观看，走向到店前确认。  
- **观众变化：** 信任变化——她知道这里不是空口说有大码，而是有具体找码和试穿过程。  
- **成交理由：** 50码以上有可试穿款。  
- **四大脚本：** 晒过程·火车节  
  - 起因：顾客问“有我能穿的吗？”  
  - 过程：阿梅看需求、找尺码、拿两件不同版型的衣服。  
  - 结果：顾客进试衣间，展示其中一件的真实上身状态。  
- **36计拍法：第10计·情境还原：**  
  用真实顾客授权拍，或由阿梅自己还原真实高频问答；从“有我能穿的吗”开始，到找衣服、进试衣间、上身判断结束。  
- **结尾行动：** 到店。  
  “想试大码女装，来店里先试再选。”

---

### 方向二：同一人试两条不同版型的大码裤装

- **对应成交路径：** 从“感兴趣”走向“我愿意来试”。  
- **观众变化：** 行动变化 + 信任变化——她知道该看什么，也知道店里可以现场确认。  
- **成交理由：** 可试穿、版型可判断。  
- **四大脚本：** 教知识·解题型  
  - 场景难题：上班坐一天，裤腰和臀腿总是不舒服。  
  - 放大问题：挂着看不出腰腹和活动空间。  
  - 过程：同一人试两条不同大码裤装，做坐下、走动、侧身动作。  
  - 结论：分别说清适合什么情况，不说“谁穿都行”。  
- **36计拍法：第19计·对比改造：**  
  同一个人、同一试衣间，只换两条店内大码裤装；镜头统一做坐下、站起、侧身三个动作，差异落在裤装版型本身。  
- **结尾行动：** 到店。  
  “裤子还是上身试，合不合适一动就知道。”

---

### 方向三：换季外套，别只看镜子里站着的样子

- **对应成交路径：** 从刷到视频走向试穿前判断。  
- **观众变化：** 认知变化——顾客知道试外套要看肩背、袖口和叠穿空间。  
- **成交理由：** 大码外套可试穿。  
- **四大脚本：** 教知识·拆解型  
  - 开头：外套站着看合身，不代表抬手也舒服。  
  - 中间：演示抬手、抱孩子、坐下三种动作。  
  - 结尾：说明这不是让顾客学搭配，而是提醒她到店试时要动一动。  
- **36计拍法：第17计·互联网嘴替/替网友做：**  
  从真实评论或私信选一句问题：“大码外套抬手会不会紧？”阿梅拿一件店内大码外套试动作，展示实际状态和适用条件。  
- **结尾行动：** 私信。  
  “想找外套的，私信说下平时尺码和要穿的场景。”

---

### 方向四：一位老客为什么第二次直接来店里试

- **对应成交路径：** 从观望走向到店和复购。  
- **观众变化：** 信任变化——观众看见别人如何从“怕没码”变成“愿意再来”。  
- **成交理由：** 真实试穿体验。  
- **前提：** 必须先完成老客前采，确认真实经历和授权；没有真实案例不拍。  
- **四大脚本：** 讲故事·成功案例  
  - 困境：她第一次买大码女装时卡在哪。  
  - 阿梅做了什么：提供了哪些试穿选择。  
  - 顾客自己的选择：她试了什么、怎么判断。  
  - 结果：第二次为什么还愿意回来。  
- **36计拍法：第26计·推荐建议：**  
  用老客真实需求做开头，阿梅按“她这次要去哪里穿”推荐连衣裙、外套或裤装中的一类，并说清适用与不适用。  
- **结尾行动：** 到店。  
  “不确定自己适合哪类，来店里试过再定。”

## 定价与节奏

### **起步阶段建议怎么定价**

目前不建议为了短视频专门造一个低价引流款。原因是价格、库存、进货成本和当地竞争情况均未确认，贸然定低价，可能吸引只比价的人，也可能压缩本就受尺码库存影响的利润。

起步期更适合做的是：  
- 正常卖现有大码连衣裙、大码外套、大码裤装；  
- 短视频不先打价格战，先打“到店能试”；  
- 顾客到店后，根据她的具体场景推荐试穿，而不是一上来推最高价款。

### **什么时候可以调整价格**

不是“视频有播放就涨价”，而是满足以下真实依据后再评估：

1. 某类大码女装持续出现断码、顾客到店后找不到适合尺码；  
2. 顾客对某类版型反复询问、试穿率高、成交稳定；  
3. 同一款或同一类货不靠降价也能完成正常周转；  
4. 已记录到明确的复购和连带购买情况。

待确认每月进货、售卖、断码和积压记录后，再决定是补货、调价，还是减少某类版型。没有这些数据，不建议凭感觉涨价或降价。

## ⚠️ 风险

### 1. 只把“50码以上可试穿”写在字幕里

这是当前最大的风险。  
如果画面里一直是挂版、模特图和阿梅报款，顾客依然不知道自己能不能试到。每周至少要有一条内容出现尺码牌、试衣间和上身动作，让卖点变成看得见的证据。

### 2. 为了拍视频，让顾客做不真实的夸张反馈

不能让顾客配合说“穿上立刻变了”“这家比别家都好”之类的话。大码顾客对夸张承诺很敏感，一旦觉得内容在演，反而更不敢进店。真实反馈哪怕只是“这件肩膀活动方便”，也比空泛夸奖可信。

### 3. 把账号拍成穿搭技巧号，顾客学完却不来店里

阿梅可以讲一点试穿判断，例如裤腰、肩背、坐下时怎么看；但技巧不能成为主角。主角必须是店内的大码连衣裙、大码外套、大码裤装，以及顾客到店能完成的试穿过程。否则账号有播放，门店却接不住。
