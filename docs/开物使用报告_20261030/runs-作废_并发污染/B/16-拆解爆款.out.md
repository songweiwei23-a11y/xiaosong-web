## 2. 出发点（2026-10-29）

### 原文围绕什么：**人 + 货**

- **人**：大码女生进店时常说“我穿不了”，这是明确的人群痛点。
- **货**：原文的关键货品信息不是某一条裙子，而是“剪裁”是否适合。
- **场**：有“进店”“站到镜子前”的轻度场景，但场不是主要看点。

### 符合“三有”中的哪一条

- **有用**：告诉用户，挑衣服不只是看贵不贵、好不好看，而要先判断剪裁是否适合。
- **有共鸣**：用“大码姐妹”“我穿不了”直接击中目标顾客的常见心理。

### 八大爆款元素

- **人群**：设计在开头。  
  依据：“很多大码姐妹进店第一句话就是「我穿不了」。”

- **成本**：设计在结尾。  
  依据：“站不对，买再贵也白搭。”  
  这里的成本是金钱成本，也隐含“买回去穿不出去”的时间和面子成本。

- **没有明显用到**：头牌、怀旧、反差、最差、荷尔蒙、奇葩。  
  原稿没有实际展示不同货品的前后变化，因此不能判为“反差”。

### 二创可复刻的出发点

> 先点名“有需求但总觉得自己不适合”的目标人群，再提出一个反常规动作：**不急着卖货，先帮顾客判断适配。**最后用“买错会闲置”的成本提醒，承接试穿、咨询或选款服务。

## 3. 开篇钩子、脚本结构、信息递进、情绪和结尾行动

### 3.1 开篇钩子

**原文：**  
> “很多大码姐妹进店第一句话就是「我穿不了」。”

**用到的拆解知识：**

- 开篇 36 计：**圈定人群**
- 开篇 36 计：**直击痛点**
- 八大爆款元素：**人群**
- 情绪曲线：**共鸣爆发型**的起点

**为什么有效：**

1. “大码姐妹”先把人点出来，目标用户会马上判断“这条是不是在说我”。
2. “我穿不了”不是泛泛地说“穿衣烦恼”，而是顾客可能真的会说出口的一句话。
3. 这句话带有自我否定，天然给后文留下一个要解决的问题：到底是真的穿不了，还是没有找对适合的剪裁？

**六大钩子判断：**

- 原稿**没有明显用到**金钱、盲盒、对抗、送温暖、荷尔蒙。
- 可弱归入“验证解密”：后文承诺通过镜子和剪裁判断“什么适合你”，但原句没有直接提出验证问题，因此不宜强判为核心钩子。

### 3.3 信息递进

原稿的信息推进是清楚的：

1. **顾客的问题**：我穿不了。
2. **店主的不同做法**：不急着推荐衣服。
3. **店主的专业判断**：先看剪裁是否帮助你。
4. **不这样做的代价**：买再贵也白搭。

这个递进的优势是：它不是直接夸“我家衣服好”，而是先重新定义顾客的选择标准——不是先看价格，而是先看是否适合自己。

### 3.4 情绪曲线

原稿更接近：**共鸣爆发型**

- **认同**：很多大码女生都说“我穿不了”。
- **更认同**：原来店主也听过这句话，而且不急着推衣服。
- **爆发 / 收束**：“买再贵也白搭。”一句话把“不会选”带来的损失说透。

原稿没有盲盒、明确反转、故事人物关系，因此不属于盲盒型、反转型或情感渗透型。

### 3.5 结尾行动

**原稿结尾：**  
> “站不对，买再贵也白搭。”

这是一个能收住观点的结尾句，但它**没有行动指令**。

对于变现型内容，建议补一个动作：到店试穿、私信咨询、留资三选一。结合账号有实体门店和试衣间，最自然的是：

> “拿不准的，来店里试完再选。”

这样既不硬卖，也能承接“50码以上可试穿款”的真实卖点。

## 4. 能保留的创意与需要优化的问题

### 能保留的创意

1. **保留“我穿不了”这句真实痛点。**  
   它比“不会穿搭”“身材焦虑”更具体，也更像真实顾客语言。

2. **保留“今天我不推荐衣服”的反常规表达。**  
   这句话能让用户停一下：一个卖衣服的人，为什么先不推荐衣服？

3. **保留“剪裁在帮你”的拟人表达。**  
   “哪个剪裁其实是在帮你”比“要选合适的版型”更有画面，也不显得生硬。

4. **保留“买再贵也白搭”的成本收束。**  
   它不靠低价促销，而是让用户意识到：买错才是真浪费。

### 需要优化的问题

1. **“站不对”表达有歧义。**  
   用户可能会理解成“站姿不对”，而前文实际想说的更像是“选错剪裁、选错版型”。  
   建议改成：  
   - “剪裁没选对，买再贵也可能穿不出去。”  
   - “不是你穿不了，是这件衣服没选对。”  

2. **核心知识点太虚。**  
   原稿说“哪一个剪裁在帮你”，但没有说具体看什么。  
   可以补1—2个真实判断维度，但必须由阿梅确认，例如：  
   - 【换成你的真实判断标准：肩线、腰线、裙摆、长度、面料垂感等】  
   未确认前不能写成经营事实。

3. **缺少阿梅本人的身份背书。**  
   档案已确认：阿梅做大码女装6年、本地开店3年。  
   可用一句轻量植入增加可信度：  
   > “做大码女装这些年，我听得最多的就是这句。”  
   若要出现“6年”，可以写；但不要扩写成“服务过多少人”等未核实经历。

4. **没有承接门店卖点。**  
   账号的真实卖点是“50码以上可试穿款”，原稿没有接住。  
   可在结尾自然加入：  
   > “50码以上想先试的，来店里慢慢试。”  
   这属于档案已确认事实，可以使用。

5. **缺少单一行动指令。**  
   原稿止于观点，适合做流量或人设片段；若要服务门店成交，结尾要明确引导“到店试穿”或“私信咨询”其中一个。
