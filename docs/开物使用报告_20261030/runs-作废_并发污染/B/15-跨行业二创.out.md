原片的核心机制是：**先接住目标顾客“我不行”的自我否定，再用一个反常规动作打断她，最后把“怎么选”落到看得见、能马上试的动作上。**  
但这条原片本身和阿梅店同属大码女装，内容太接近，直接换词风险很高。下面只借它的开篇句式、段落功能和“镜子前讲解+试穿动作”的形式，事件全部换成阿梅店里真实能发生的事。

### 方案 1：先别说穿不上，先进试衣间

**一句话**：原片的「先站到镜子前看剪裁」→ 你店里的「先把50码以上可试穿的款拿进试衣间，试过再说穿不穿得上」

**借了**：先说顾客常见退缩句 → 反常规回应 → 用镜子和试穿给答案的结构；店内镜子前口播、边讲边演示的形式。  
**换成自己的**：阿梅在县城商业街门店的试衣间外，拿店内50码以上可试穿款，回应大码女生“我穿不了”的顾虑。

#### 迁移对照

| 层 | 原片 | 你的版本 |
|---|---|---|
| 开篇 | 顾客进店先说“我穿不了” | 大码女生走到衣架前先说“别拿了，我试不上” |
| 结构 | 不先推荐衣服 → 先看镜子和剪裁 → 解释站不对买贵也没用 | 不急着隔空说能不能穿 → 先拿可试穿款进试衣间 → 试过再判断合不合身 |
| 呈现形式 | 店内镜子前，老板口播讲解 | 阿梅站在试衣间外/全身镜前，手拿衣服，镜头跟着走进试衣间 |
| 事件/主角 | 店员帮助大码顾客建立穿衣判断 | 阿梅帮助来到店里的50码以上顾客，先从“敢试”开始找衣服 |

#### 开头（前 3 秒）

**第一句话**：  
“不少穿50码以上的姐妹，刚走到衣架前就说：‘阿梅，别拿了，我肯定试不上。’”

**画面**：  
阿梅站在门店衣架旁，手里刚拿起一件店内可试穿款；说到“别拿了”时，把衣服先放回衣架，再转身朝试衣间走。

#### 口播要点

- **【顾客困境】**  
  “这句话我在店里听得不少。不是她不想穿得好看，是之前进店问了半天，最后一句‘没有合适的’，人就不想再试了。”

- **【反常规动作】**  
  “所以来我这儿，先别急着问‘我能不能穿’，也别隔着衣架给自己下结论。咱们先拿能试的，进试衣间。”

- **【试衣过程】**  
  镜头拍阿梅拿出店内50码以上可试穿的大码连衣裙、大码外套或大码裤装。  
  “连衣裙、外套、裤装，先挑你今天最想试的一类。穿上以后，看看肩膀、腰那里，还有坐下来的感觉。”

- **【情绪转折】**  
  “衣服挂在衣架上，只是一块布。穿到自己身上，才知道它是不是你的。”

- **【结果与转化】**  
  “县城商业街这家店，50码以上有可试穿款。别在门口先把自己劝退，进来试一件再走。”

- **行动指令**：  
  “想试的姐妹，直接来店里。”

#### 注意

- 不要找顾客演“自卑、被拒绝”的夸张剧情，阿梅自己口播、拿衣服走向试衣间就能拍；如有真实顾客试衣，必须先征得同意，且不拍正脸也可以。  
- 这条不是搬运：原片讲“镜子前判断剪裁”，这条讲的是阿梅店里“50码以上可试穿、先进试衣间”的实际服务场景；台词、衣服、人物、地点都是自己的。

### 方案 2：别先问显不显瘦，先问能不能试

**一句话**：原片的「不先推荐衣服，先让顾客做一个动作」→ 你店里的「不先回答显不显瘦，先让顾客把想试的款穿上」

**借了**：顾客提问 → 老板不按常规回答 → 给出新的判断顺序 → 点出错误代价的结构；镜子前一问一答式口播。  
**换成自己的**：阿梅用“能不能试”代替“显不显瘦”作为第一步，突出店里50码以上可试穿的特点。

#### 迁移对照

| 层 | 原片 | 你的版本 |
|---|---|---|
| 开篇 | 顾客先说自己穿不了 | 顾客先问“这件显不显瘦” |
| 结构 | 不先推荐 → 先做判断动作 → 解释判断错的后果 | 不先承诺效果 → 先进入试衣环节 → 解释不试就下单容易不合适 |
| 呈现形式 | 镜子前直接讲，边说边指向穿搭细节 | 阿梅面对镜头模拟顾客提问，再把衣服拿到试衣间门口 |
| 事件/主角 | 顾客通过镜子找到适合自己的剪裁 | 阿梅让大码女生先把衣服试上，再判断连衣裙、外套或裤装是否适合 |

#### 开头（前 3 秒）

**第一句话**：  
“很多大码姐妹进店先问：‘阿梅，这件显不显瘦？’我一般不马上回答。”

**画面**：  
阿梅站在全身镜旁，对镜头举起一件店内可试穿的大码女装；说“我一般不马上回答”时，轻轻把衣服往试衣间方向一带。

#### 口播要点

- **【抛出反常规】**  
  “因为一件衣服显不显，不是我站在这儿嘴上说了算，是你穿上以后，看镜子里的自己怎么感觉。”

- **【解释顾客的真实难处】**  
  “很多姐妹不是不会挑，是外面想试的码不一定有。没试过，就只能拿着衣服在手里猜。”

- **【阿梅的做法】**  
  “来店里先挑一类：想穿裙子，就试大码连衣裙；天凉想搭一件，就试大码外套；平时上班、接娃方便，就从大码裤装里试。”

- **【镜前判断动作】**  
  “站起来看看，侧身看看，再坐一下、走两步。别只看衣架上的样子，试衣间里那几分钟才算数。”

- **【结果前置】**  
  “衣服合不合适，不用靠猜。50码以上有可试穿款，穿上再决定要不要。”

- **行动指令**：  
  “想试哪一类，直接到店里来试。”

#### 注意

- “显瘦”不要说成保证效果，不要出现“穿上立刻瘦十斤”这类夸张表达。重点是：阿梅提供试穿，让顾客自己判断。  
- 不需要模特，也不需要拍到顾客身体。阿梅可用衣架、试衣间门口、全身镜完成整条内容。  
- 这条不是搬运：原片的核心动作是“看剪裁”，此版本的核心动作是“先试、再判断”，并且落点是阿梅店里的连衣裙、外套、裤装与试衣间。

### 方案 3：别在衣架前给自己下结论

**一句话**：原片的「顾客站错位置，买再贵也白搭」→ 你店里的「顾客站在衣架前先否定自己，再多看几件也没用」

**借了**：先呈现常见顾客行为 → 老板提出反转判断 → 用一个现场动作证明 → 结尾回到顾客顾虑的结构；店内第一视角口播、镜头跟拍的形式。  
**换成自己的**：阿梅从门店衣架前出发，带观众走到试衣间，讲“大码女生别在还没试的时候就先否定自己”。

#### 迁移对照

| 层 | 原片 | 你的版本 |
|---|---|---|
| 开篇 | 顾客一进店就认定自己穿不了 | 顾客还站在衣架前，就先认定自己不适合任何一件 |
| 结构 | 先指出错误起点 → 提供新动作 → 说明错误代价 | 先指出“衣架前下结论” → 带去试衣间 → 说明不试就一直找不到合适衣服 |
| 呈现形式 | 镜子前的讲解式展示 | 第一视角跟拍阿梅穿过衣架区、走到试衣间，边走边说 |
| 事件/主角 | 顾客通过站位/镜子重新认识穿衣选择 | 阿梅带50码以上顾客从“我不能穿”走到“我先试试” |

#### 开头（前 3 秒）

**第一句话**：  
“大码姐妹最容易做的一件事，就是还没进试衣间，先在衣架前把自己否定了。”

**画面**：  
手机从衣架间穿过，镜头跟着阿梅的手划过大码连衣裙、大码外套、大码裤装，最后停在试衣间门口。

#### 口播要点

- **【常见场景】**  
  “看见裙子，说‘我穿不了’；看见外套，说‘我胳膊粗’；看到裤装，又说‘算了，肯定卡腿’。”

- **【阿梅的判断】**  
  “但衣架不会告诉你合不合身。你站在外面看半天，最后只会越来越不想试。”

- **【带入真实门店动作】**  
  “我做大码女装6年，在本地开店3年，最希望姐妹们进店先做一件事：选一件你平时最不敢拿的，进试衣间。”

- **【过程展示】**  
  阿梅拿起店内50码以上可试穿款。  
  “不用一次拿很多，先从一件开始。穿上，照镜子，走两步。觉得哪里不舒服，就换下一件。”

- **【情绪收束】**  
  “合身不是等来的，是试出来的。你不是不能穿，你只是还没试到那件。”

- **行动指令**：  
  “在县城商业街的姐妹，来店里试试再说。”

#### 注意

- “你不是不能穿”是情绪鼓励，不要延伸成“所有人都能穿得一样好看”的绝对承诺。  
- 这条最好用一镜到底或少剪辑跟拍，靠“从衣架走到试衣间”的动线自然推进；只需阿梅、一部手机、店内衣架和试衣间。  
- 这条不是搬运：原片以“剪裁和镜子”为核心，这条以“衣架前否定自己—走进试衣间试穿”为核心；阿梅的6年从业经验、本地门店、可试穿款都是账号自身信息。

### 我推荐先拍哪个

**先拍方案 3《别在衣架前给自己下结论》。**

原因有三个：  
1. **最贴阿梅的真实顾客场景**：很多大码女生的难处不是不会买，而是还没试就先放弃。  
2. **最好拍**：从衣架走到试衣间，一部手机跟拍就能完成，不用找顾客配合。  
3. **卖点露得自然**：不硬讲“50码以上可试穿”，但观众能从阿梅拿衣服、走试衣间的过程里看到这件事。
