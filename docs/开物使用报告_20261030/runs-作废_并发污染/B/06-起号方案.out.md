# 🚀 起号方案

## 📌 先说结论

- **建议主攻：36计·第1计 反向操作。**  
  阿梅最稳定的真实场景，就是门店衣架、不同版型的大码女装、试衣间和拿码动作。大码女生进店通常先问“显不显瘦”“最大到多少”，阿梅反过来先问“哪里最怕勒”，这个反差能直接圈中目标人群，也正好打进王牌栏目《先试再选：大码女生进店先解决哪里不舒服》。

- **备选：**
  1. **36计·第9计 一人分饰多角**：主攻内容的开头停留弱时切入，用阿梅一人演出“怕问尺码”的顾客和“先问哪里勒”的店主，强化冲突。
  2. **36计·第10计 情境还原**：评论和主页访问开始上升、有人问尺码和门店位置时切入，把“50码以上有可试穿款”拍成到店前的真实证据。
  3. **36计·第19计 对比改造**：有稳定试穿者、能持续拍到同人同场试两件不同版型衣服时切入，专门承担变现型内容。

- **明确不做：**
  1. **36计·第35计 街头采访**：需要陌生人出镜授权、现场组织和稳定收音；当前已确认资源只有阿梅、门店、衣架和试衣间，硬拍会拖慢更新。
  2. **36计·第16计 整蛊**：大码女生本就容易在试衣问题上尴尬，任何误导式情节都会和“先试再选、体面试穿”的账号定位冲突。

- **多久能看出跑没跑通：**  
  主攻打法至少连续测 **5条**，备选打法各测 **3条**。前30天不拿单条播放定生死，重点看目标评论是否出现“腰勒”“胳膊紧”“有没有能试的码”等真实需求。  
  起号阶段的参考线是：**零粉到一千粉，并且流量逐步稳定。** 过线前不频繁换赛道，只围绕“先试再选”把同一种看点拍透。

## 🧮 起号期内容配比

### 起号期：流量型45% / 人设型25% / 变现型30%

这个比例适合阿梅大码女装店：

- **流量型45%**：先让县城里“买不到合身衣服”的大码女生刷到阿梅。主打身份确认和真实烦恼，不在流量视频里硬推门店。
- **人设型25%**：让观众记住阿梅不是只报尺码的店主，而是会先问“哪里勒”的人。
- **变现型30%**：从第一周开始拍试衣间、拿码、活动测试，让“50码以上可试穿”成为看得见的事实。

起号期不把四类形式平均摊开。所有内容都围绕同一主线：**先试再选。**

| 视频目的 | 出发点 | 主要形式 | 脚本结构 | 结尾行动指令 |
|---|---|---|---|---|
| 流量型45% | **人**：大码女生不敢问出口的穿衣不舒服；爆款元素：**人群、反差** | 36计·第1计 反向操作；观点型短口播 | 常规提问“显不显瘦”→ 阿梅反问“哪里勒”→ 拿出对应版型 → 评论互动 | **“你买衣服最怕哪里勒，评论区说说。”** |
| 人设型25% | **人**：阿梅做大码女装6年、在本地开店3年形成的真实判断 | 观点立场；36计·第7计 一句话设定故事感 | 真实营业片段/真实经历 → 阿梅的判断 → 一个具体细节 → 关注 | **“关注阿梅，看看店里每天真实发生的事。”** |
| 变现型30% | **人、货、场**：顾客试衣不舒服；不同版型大码女装；试衣间；成交理由：**50码以上有可试穿款** | 晒过程·火车节；36计·第10计 情境还原；第19计 对比改造 | 顾虑 → 拿两件不同版型衣服 → 做相同动作 → 说明适用情况 → 到店试 | **“想试大码女装，直接到店试。”** |

### 过线之后怎么调

当“有没有我的码”“店在哪里”“能不能试”等询问开始稳定出现，同时流量型的非关注播放没有持续下滑，调整为：

- **流量型40%**
- **人设型25%**
- **变现型35%**

增加的5%变现内容，继续投到《同一间试衣间，换两件大码女装》，不改成衣架扫镜或单纯上新。

### 和已定内容定位怎么对上

- **主力形式**：晒过程负责证明门店真实有试衣间、有可试款；反向观点负责拉新。
- **主力系列**：先跑《先问哪里勒》，再放大《同一间试衣间，换两件大码女装》。
- **阿梅的人设**：不是“教人遮肉”的店主，而是先问顾客哪里不舒服、再拿版型的人。

## 🎯 主攻打法：36计·第1计 反向操作

### 为什么是阿梅能拍的

1. **出镜人明确**：阿梅本人就是店主，不依赖店员、顾客或外部演员。
2. **场景明确**：县城商业街门店里有衣架、不同品类大码女装和试衣间，拍摄地点固定。
3. **货品明确**：大码连衣裙、大码外套、大码裤装都能成为“反向提问”后的真实拿货对象。
4. **动作真实**：从衣架拿衣服、看版型、递进试衣间，都是日常营业动作，不需要设计复杂剧情。
5. **表达门槛低**：阿梅每条只说一句核心判断：“别先问显不显瘦，先告诉我哪里最怕勒。”

> **待确认：设备和拍摄协助人数未提供。**  
> 起号前30天不把店员或顾客出镜算进产能，全部按“阿梅本人出镜 + 固定机位拍门店真实动作”设计。

### 结构公式

**常规A → 反向B → 真实动作/结果**

套到阿梅账号：

> 大码女生进店先问“显不显瘦 / 最大到多少”  
> → 阿梅不先回答尺码，先问“你是腰怕勒、胳膊怕紧，还是坐下不舒服”  
> → 阿梅从衣架拿出对应版型的大码裤装、外套或连衣裙  
> → 结尾问观众：“你买衣服最怕哪里勒？”

### 配什么脚本讲

搭配：**观点型短口播——常见场景 → 明确判断 → 具体部位 → 评论。**

- **36计·第1计 反向操作**负责“片子里发生什么”：先问显瘦，反过来问哪里勒。
- **观点型短口播**负责“为什么这样问”：让观众明白，能穿进去不等于活动舒服。

主攻内容是流量型，不讲“50码以上可试穿”的成交理由，不引导到店，不推某一件衣服。

### 前3条具体拍什么

#### 1.《大码女生买裤子，别先问显不显瘦，先问坐下哪里勒》（人群）

- **第一句钩子：**  
  “大码女生买裤子，别先问显不显瘦，先问你坐下时哪里勒。”
- **拍摄要点：**  
  阿梅站在裤装衣架前，手里拿两条不同版型的大码裤装；说到“坐下”时，镜头切试衣间门帘、凳子和裤装细节；最后回到阿梅正脸。
- **停下来的原因：**  
  “坐下哪里勒”是上班久坐、接送孩子、聚餐吃饭都会遇到的具体烦恼。

#### 2.《“这件最大到多少？”阿梅为什么不先回答这个》（反差）

- **第一句钩子：**  
  “有人一进门就问最大到多少，但我会先问她一句：你最怕哪里紧？”
- **拍摄要点：**  
  阿梅站在试衣间门口，先看镜头，再指向外套衣架；分别拍肩背、胳膊位置和衣服的活动空间，不报未确认的具体尺码。
- **停下来的原因：**  
  观众预期店主先报尺码，阿梅却先问身体感受，形成反差。

#### 3.《带孩子总要弯腰，试衣服别只站着照镜子》（人群）

- **第一句钩子：**  
  “带孩子总要弯腰的人，试衣服别只站着照镜子。”
- **拍摄要点：**  
  阿梅拿一件大码连衣裙，在试衣间外示范“站着看”和“弯腰活动”是两回事；镜头只拍阿梅和衣服，不拍顾客。
- **停下来的原因：**  
  直接打中宝妈的生活动作，不用泛泛讲“显瘦”“遮肉”。

### 边界

- 不问顾客体重，不拿身材问题开玩笑。
- 不用“胖”“藏肉”“秒瘦”一类标签。
- 不把一件衣服说成适合所有人。
- 不把“能穿进去”说成“穿着舒服”；舒服与否必须通过试穿和活动动作判断。
- 流量型视频不说“店里50码以上可试”“来店里买”，避免流量和成交混在一条里。

## 🔄 备选打法

### 1. 36计·第9计 一人分饰多角

**什么情况下切过去：**  
连续3条反向操作内容前3秒流失明显，观众没有停在“哪里勒”这个问题上时，切入一人分饰多角，把场景冲突演出来。

**为什么阿梅能拍：**  
阿梅本人完成两个角色，不需要店员或顾客配合；场景只用衣架和试衣间门口。

**怎么套到账号：**

> 角色A：站在衣架前犹豫的顾客，“这件还有没有再大一点的？”  
> ↔ 角色B：阿梅，“先别急着问最大码，你是腰怕勒还是胳膊怕紧？”  
> → 切真实拿货动作  
> → 评论区提问。

**配的四大脚本结构：**  
**轻情景观点——痛点场景 → 反向回答 → 真实动作 → 评论。**

它补的是开头冲突，不补成交理由；主目的仍是流量型。

---

### 2. 36计·第10计 情境还原

**什么情况下切过去：**  
主页访问增加，评论区开始出现“有没有我的码”“店在哪”“能试吗”时切入，用真实过程承接到店需求。

**为什么阿梅能拍：**  
门店有试衣间，阿梅每天都在衣架前拿码、递衣服；不拍真实顾客时，由阿梅明确标注“还原常见咨询”。

**怎么套到账号：**

> “有没有我能试的码？”  
> → 阿梅不先报尺码，先问“你最怕哪里勒？”  
> → 根据回答拿出一件大码外套或裤装  
> → 试衣间外说明要做哪几个活动动作  
> → 落到到店试穿。

**配的四大脚本结构：**  
**晒过程·火车节——顾虑 → 拿码 → 试穿动作 → 结果。**

它补的是成交理由：**50码以上有可试穿款。**

---

### 3. 36计·第19计 对比改造

**什么情况下切过去：**  
有稳定、愿意出镜的试穿者，或阿梅本人能稳定试穿两件不同版型衣服时切入；每次对比都要保证同一个人、同一个试衣间、同一组活动动作。

**为什么阿梅能拍：**  
店里同时卖大码连衣裙、大码外套和大码裤装，货品变量充足；试衣间是固定场地，画面可重复。

**怎么套到账号：**

> 同一个人、同一试衣间  
> → 先试两条不同版型大码裤装  
> → 都做坐下、抬腿、走路动作  
> → 阿梅说清哪一条更适合久坐、哪一条活动空间更宽  
> → 到店试穿。

**配的四大脚本结构：**  
**晒过程·火车节 + 对比型过程展示。**

它补的是变现证据：不是阿梅口头说“有大码”，而是观众能看到同一个人在两件货上的活动差别。

## 🧪 怎么测

### 一次只改一个变量

主攻打法前5条，只改以下一个变量：

- **第1-2条**：同样是裤装，只换开头问法。
- **第3-4条**：同样是“哪里勒”，只换品类，从裤装换到外套。
- **第5条**：保留表现最好的开头和品类，只换生活场景，从通勤换到带娃或聚餐。

不要同一条里同时换品类、换开头、换拍法、换结尾。

### 每计测几条、看什么指标

| 打法 | 至少测试 | 重点看什么 |
|---|---:|---|
| 第1计 反向操作 | 5条 | 非关注播放、前3秒停留、完播、评论是否出现具体穿衣烦恼 |
| 第9计 一人分饰多角 | 3条 | 前3秒停留、完播、评论是否复述视频里的问题 |
| 第10计 情境还原 | 3条 | 主页访问、尺码询问、门店位置询问、到店试穿反馈 |
| 第19计 对比改造 | 3条 | 完播、主页访问、评论是否问“我这种情况该试哪类” |

### 什么信号算“这计行”

- **第1计行：**  
  评论区开始出现“我就是腰那里勒”“我怕胳膊紧”“坐下总卡腿”这类具体反馈，且同类题材连续几条都有陌生人观看。

- **第9计行：**  
  观众愿意在评论里接角色的话，例如“我每次都不敢问有没有更大的”。

- **第10计行：**  
  评论和私信开始出现“店在哪”“能试吗”“外套有没有我的码”等到店意向。

- **第19计行：**  
  观众不是只夸衣服，而是能说出自己要解决的问题，例如“久坐该看裤腰还是腿围”。

### 什么信号算“换掉”

- 连续完成规定样本后，目标评论始终没有出现；
- 播放有了，但评论都是泛穿搭观众，没有本地大码女性的需求表达；
- 阿梅拍起来费劲、需要反复背台词，导致无法稳定更新；
- 试衣对比画面看不出货品差别，只剩“换一件衣服”时，停止第19计，先补拍活动动作和版型细节。

## 📅 30天节奏

> **产能前提：团队人数和设备尚未确认。前30天按不依赖店员、顾客出镜的最低产能执行：每周集中拍2次，每次完成3条素材；每周发布3条。**  
> 若实际只能每周拍1次，就优先保证主攻第1计不断更，备选打法顺延，不压缩拍摄质量。

### 第1周：打清“这是给谁看的”

**任务：**

- 连拍3条第1计·反向操作。
- 题材只选大码裤装和“坐下、抬腿、腰勒”。
- 固定一句栏目开场：“你先别急着看颜色，告诉我哪里最怕勒。”

**交付物：**

- 3条《先问哪里勒》视频；
- 1份评论关键词记录：腰、臀腿、胳膊、肩背、长度等。

### 第2周：测试开头冲突

**任务：**

- 拍2条第1计·反向操作，换外套和连衣裙；
- 拍1条第9计·一人分饰多角；
- 不改结尾，继续只引导评论。

**交付物：**

- 3条视频；
- 对比表：哪种开头的前3秒停留更稳，哪种问题评论更多。

### 第3周：把试穿证据拍出来

**任务：**

- 拍2条第10计·情境还原；
- 拍1条第19计·对比改造；
- 变现内容只围绕一个成交理由：**50码以上有可试穿款。**

**交付物：**

- 3条试衣间内容；
- 记录主页访问、门店位置询问、尺码询问。

### 第4周：留下有效模式

**任务：**

- 复拍本月评论最多的一类穿衣烦恼；
- 保留1条流量型、1条变现型；
- 人设型只拍已确认的事实：  
  **“做大码女装第6年，我现在先问顾客哪里不舒服。”**
- 没有真实顾客事件，不拍顾客故事。

**交付物：**

- 3条视频；
- 1份复盘：留下1个流量开头、1个变现过程、1个高频评论问题；
- 下月选题池至少12条，继续围绕裤装、外套、连衣裙轮换。

## 📊 跑不通先查哪里

| 现象 | 先怀疑什么 | 下一步做什么实验 |
|---|---|---|
| 曝光少 | 标题太像门店广告，陌生人看不懂“这条和我有什么关系” | 把开头改成具体生活动作，例如“坐下”“抬手”“弯腰”，连续拍3条同类问题 |
| 有曝光但前段流失 | 首句没有反差，阿梅一上来就在解释 | 第一秒先丢出反向判断：“别先问显不显瘦，先问哪里勒。” 再接解释 |
| 点赞有了，但没有主页访问和试穿询问 | 视频只讲烦恼，没有拍到衣架、拿码、试衣间这些真实证据 | 增加第10计·情境还原，拍“问哪里勒—拿什么版型—怎么试”的完整过程 |

阿梅这个号起步最重要的不是拍出多少“好看穿搭”，而是先让本地大码女生刷到时确认一件事：

**这里不会只问你穿多大，阿梅会先问你哪里不舒服。**
