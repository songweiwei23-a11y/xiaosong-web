# 🎯 账号定位方案

## 📌 核心结论（先看这 8 条）

1. **这是什么号**：A类实体店｜县城大码女装试穿号  
2. **给谁看**：县城想穿得合身的宝妈和上班族  
3. **人设标签**：做了6年大码女装的阿梅  
4. **主打内容**：流量60%｜试穿过程为主  
5. **怎么赚钱**：刷到内容→到店试穿→选购大码女装  
6. **第一条拍什么**：大码女生进店前最常问的一句  
7. **最该避开的坑**：只拍挂版新款，没人知道适不适合自己  
8. **多久能看出跑没跑通**：连续发18条后看咨询与到店反馈

## 🔍 先说这一行

- **归口**：A类本地实体店中的**服装鞋包类**，主业是大码女装，不是泛穿搭博主。  
  原因是收入依赖顾客到店试穿、选购和复购，短视频要解决的是“附近哪里有我能穿、能试、穿上合适的衣服”，不是靠全国泛流量接广告。

- **这行的钱怎么赚**：  
  大码女装的收入来自单件销售、成套购买、换季补货和老客复购。它不是单纯拼低价的生意，真正卡利润的是库存：尺码段更长、同一款要备更多尺码，某些尺码一旦断货或积压，都会影响周转。  
  所以账号不能只拍“今天上新了”，而要拍清楚：**这件衣服适合什么身形、店里有没有能试的尺码、试出来是什么状态。**

- **客人的决策链路**：  
  这是“线上先确认、线下再决定”的中短决策生意。顾客刷到后通常先看款式，再确认有没有适合自己的尺码，然后才会到店试。  
  大码女装比普通女装多一道门槛：她不只担心好不好看，还担心“我去了会不会还是没有码”“试了会不会尴尬”。因此，试衣间、试穿过程、尺码覆盖，是比空口说款式更多的信任证据。

- **时间规律**：  
  行业判断：换季、节前、婚礼宴请、返工开学、天气突然转冷或转热，都是顾客更容易集中买衣服的节点；日常则常发生在下班后、周末逛街、临时要参加聚会之前。  
  账号内容不用追所有节日热点，但换季前后应提前拍“外套怎么选”“连衣裙试穿”“裤装尺码实测”等真实门店内容。

- **这行老板普遍会犯的错**：  
  最常见的自嗨点是：对着衣架拍一排衣服，配一句“新款到了，显瘦百搭”。  
  这类内容的问题是，顾客看不出“和我有什么关系”。大码顾客需要的是可判断的信息：面料会不会贴身、腰腹位置怎样、袖口和肩背活动是否舒服、店里能否试到对应尺码。  
  阿梅目前最大的潜在风险也是这个：如果只把账号做成新款展示，观众只会把它当普通服装店橱窗。

- **同行现在都在拍什么**：  
  同城女装账号常拍上新、挂版、快速换装、店内走秀、价格字幕。大多没效果，不是因为衣服不能拍，而是因为内容没有回答顾客最在意的那句：**“我这样的身形，去了到底有没有得试、穿上是什么样？”**  
  空档就在“真实试穿证据”和“替大码女生把尴尬问题问出来”。

## 🗣 我会先问老板的几个问题

- **问题**：最近一次顾客试了很多件却没买，最后卡在哪一件事？  
  - **我的推测**：大概率不是单纯嫌款式，而是尺码、版型、腰腹或肩背活动度不合适。因为大码顾客进店前已经经历过“很多店没有合适尺码”的筛选。  
  - 待老板确认

- **问题**：顾客进店最常问的第一句话是什么？阿梅通常怎么回答？  
  - **我的推测**：高频问题可能是“有我能穿的吗”“最大到多少码”“这件会不会紧”。这不是普通咨询，是后续内容最值得反复拍的真实语言。  
  - 待老板确认

- **问题**：有没有一位老客，第一次来时因为什么进店，后来为什么又回来？  
  - **我的推测**：她再次回来，未必只是因为款式，而可能是第一次在店里真正试到合身衣服，减少了反复跑店和退换的麻烦。顾客感受到的“有得试”，往往比老板以为的“款多”更有价值。  
  - 待老板确认

- **问题**：店里有没有明确不卖的货？是因为什么真实事件决定的？  
  - **我的推测**：阿梅可能会淘汰尺码标得大、实际版型偏小，或试穿反馈不稳定的款。这个边界一旦真实存在，可以成为人设内容，不要硬编“什么货都不卖”。  
  - 待老板确认

- **问题**：阿梅亲手参与最多的是哪一步：挑款、看尺码、帮试衣、搭配还是售后？  
  - **我的推测**：如果她长期在试衣间外看顾客上身反馈，那么她最有价值的不是讲潮流术语，而是积累了“哪类版型容易卡在哪”的现场判断。  
  - 待老板确认

- **问题**：顾客说过哪一句原话，能说明她为什么不去别家？  
  - **我的推测**：真正的差异化，可能不是“衣服多”，而是“终于不用进店先问有没有我的码”“能直接进试衣间试”。这必须用顾客原话确认，不能由老板替顾客下结论。  
  - 待老板确认

## 一句话定位

**做了6年大码女装的阿梅，替县城女生先把合身衣服试出来。**

---

## 六维地基

### 1. 人设定位

- **原料在哪**：  
  真材料有三句：  
  1）“店主阿梅本人出镜”；  
  2）“做大码女装6年”；  
  3）“很多大码女生在别的店买不到合身的衣服”。  

  这些能支撑的不是“专业、贴心”这种空词，而是具体行为：阿梅站在店里，围绕顾客的尺码、上身效果和试穿反馈说话。  
  “专业”要翻译成：**拿同一类衣服讲清楚什么地方能试、什么地方要看上身。**

- **人设标签句**：  
  **做了6年大码女装的阿梅**

- **用了哪个入口**：  
  **特殊经历 + 痛点职业。**  
  她不是泛时尚博主，而是连续做了6年大码女装、面对过“买不到合身衣服”这个高频痛点的店主。

- **验证**：  
  这个人设立得住，因为“6年做大码女装”是已确认的事实，门店有试衣间、“50码以上可试穿”也能持续提供拍摄现场。  
  但“她很会搭配”“她特别懂身材”目前没有直接证据，不能先写进人设。要靠后续真实试穿、顾客提问和选款过程慢慢证明。

- **在同类账号里的位置**：  
  同行常见人设是“上新播报员”“快速换装模特”“穿搭老师”。  
  阿梅要占的位置是：**不急着教你变成谁，而是先让你在县城有衣服能试。**  
  差别不在夸张话术，而在她有本地门店、试衣间和大码试穿条件，这些是线上换装账号很难长期给出的现场证据。

- **证据链**：  
  1. 阿梅整理不同尺码衣服的真实工作过程；  
  2. 回答“有我能穿的吗”等高频问题；  
  3. 同一位真人试穿不同款大码连衣裙、大码外套或大码裤装；  
  4. 顾客授权后，记录从进店询问到试衣间试穿的过程。  

- **边界**：  
  不要说“穿上立刻显瘦”“谁穿都好看”“一件解决身材焦虑”。  
  不要拿顾客身材开玩笑，也不要把“能穿”说成“应该遮住自己”。阿梅一旦用夸张承诺或身材评判博眼球，“替顾客解决试穿难”的可信度就会下降。

---

### 2. 用户定位

- **一句话画像**：  
  县城里下班后想逛街、临时要参加聚会或接送孩子路过商业街，进普通女装店前总要先问“有我能穿的吗”的宝妈和上班族。

- **为什么是她们，不是另一批**：  
  主攻**精致妈妈 + 新锐白领**。  
  精致妈妈会遇到接送孩子、家庭聚会、节日见亲友等场景，需要一件穿得体面、活动方便的衣服；新锐白领更常有通勤、聚餐、临时见人等即时需求，愿意先在线上看试穿，再到店确认。  

  不把Z世代潮流打卡客作为核心，因为这个号当前最硬的资源不是潮流造型能力，而是本地大码试穿；也不服务只想线上比全网低价、不准备到店试的人，因为店铺的优势在现场试穿，不在全国价格竞争。

- **她们心里真正在想什么**：  
  “我不是不想买衣服，我是不想每次进店都先问一遍有没有我的码。”  
  “网上看着都行，可我怕到了店里还是试不上。”  
  这两句比“我想显瘦”更接近真实需求：她们首先要的是被正常服务和能做选择。

- **决策链路**：  
  刷到阿梅试穿内容 → 看见店里确实有大码女装和试衣间 → 观察几条是否一直在拍真实上身 → 私信问尺码或款式 → 路过商业街到店试穿 → 买到合适的，再成为老客。  
  她们通常不会刷到一条就下单，会先潜水看账号是否持续、是否真的有可试穿的款。因此前期要持续堆“现场证据”，不是急着每条都催到店。

- **什么时刻会想起你**：  
  下班后要参加饭局、天气突然变冷要买外套、换季整理衣柜、节前走亲戚、临时有聚会又不想穿旧衣服时。

- **她会搜什么**：  
  “县城大码女装”  
  “附近大码女装店”  
  “大码连衣裙试穿”  
  “大码外套哪里能试”  
  “大码裤装实体店”

### 3. 内容定位

- **长期提供什么价值**：  
  **让县城大码女生知道哪里有衣服能试。**

- **内容方向**：  
  选**多元四类打底 + 一个试穿过程王牌栏目**。  
  原因是阿梅目前能稳定发生的真实事件，是店里上新、顾客询问、试衣和选款；这些足够支撑知识、过程、观点和故事四类内容。  
  不选纯单一主题号，因为现阶段没有确认到可长期重复、每周都有强冲突的固定任务；强行只拍一种“每日试穿挑战”，容易变成重复换衣服。

- **当前阶段配比**：  
  账号处于0—1000粉起号期，采用：  
  - **流量型60%**：先让本地陌生人停下来，解决新号没有初始分发和认知的问题。  
    - 形式：共鸣观点、轻量情景还原、真实过程。  
    - 题材：大码女生进店前的顾虑、县城逛衣服的真实场景、试衣间视角。  
    - 必须用到的人群爆款元素：大码女生这一明确人群；不能只讲服装术语。  

  - **人设型15%**：让人知道阿梅不是只会报款的店主。  
    - 形式：真实职业经历、门店小事、阿梅的边界观点。  
    - 前提：只用确认过的真实故事，例如做大码女装6年的经历，未确认的经历不拍。  

  - **变现型25%**：从第一周开始建立到店理由，但不能多到像广告号。  
    - 形式：试穿过程、尺码咨询回答、同一人换不同款的对比。  
    - 成交理由：**50码以上有可试穿款。** 画面要拍到衣架尺码、顾客进试衣间、上身反馈，而不是只在字幕里写。  

  **题材配比**：  
  - 主赛道75%：大码女装，包括大码连衣裙、大码外套、大码裤装轮流出现；  
  - 目标人群兴趣25%：上班、接孩子、聚会、换季等真实穿衣场景。  
  这样不把账号拍成只讲衣服参数的行业号，也不脱离卖大码女装这件事。

- **主力形式**：  
  当前没有“数据最好的内容类型”，因为账号仍在起号期。  
  所以先把**视频配音Vlog式试穿过程**作为主力测试形式：门店、试衣间、衣架、阿梅本人都是真实资源，表达门槛低于长口播，也比纯挂版更有信任证据。  
  前18条里先集中测试这一种，再根据完播、主页访问、私信和到店反馈决定是否加重口播。

- **每类内容管哪一段路**：  
  - 刷到：流量型用“有我能穿的吗”这类高共鸣问题，让陌生人停下；  
  - 记住：人设型让人知道店主是做了6年大码女装的阿梅；  
  - 信：变现型反复让观众看到有试衣间、有真实试穿、有50码以上可试穿款；  
  - 联系：变现型结尾只引导一次到店试穿或私信问码。

- **三种视频各怎么拍**

  **流量型**  
  - 四大脚本：观点型。方向是“大码女生逛衣服真正怕的是什么”；结构为亲身观察→明确判断→门店场景验证→评论提问。  
    结尾行动指令：**“你进店最先问哪一句？评论区告诉我。”**  
  - 起号36计：**第32计·换个视角：**从试衣间门口视角拍阿梅听到的高频问句——顾客进门先问“有我能穿的吗”，阿梅拿衣服、带去看尺码，落在“很多人进店前先在心里问过这句”。  
    这是人群共鸣，不讲卖点、不引导到店。

  **人设型**  
  - 四大脚本：讲故事型。方向是“阿梅为什么一直做大码女装”；结构为做了6年→最常遇到的真实难题→她持续留在这个品类的原因→一句真实感悟。  
    结尾行动指令：**“关注阿梅，带你看真实试穿。”**  
  - 起号36计：**第7计·一句话设定故事感：**阿梅在整理大码女装时说：“做了6年，我听得最多的不是这件多少钱，是有我能穿的吗。”随后拍她整理大码连衣裙、大码外套和大码裤装的工作现场。  
    不能补编她的创业苦难或顾客故事。

  **变现型**  
  - 四大脚本：晒过程·火车节。方向是“一位顾客要找能试穿的大码外套”；结构为进店需求→阿梅找对应尺码→进试衣间→上身结果。  
    结尾行动指令：**“想试大码女装，来店里先试再选。”**  
  - 起号36计：**第19计·对比改造：**同一位真实出镜人，在同一试衣间先后试两件不同版型的大码连衣裙或大码外套，只换衣服、不换人和场景，拍她活动肩背、坐下和侧身的差异，再说明各自适合的情况。  
    这是证明衣服版型，不是拿同一件衣服换穿法。

- **配比核验**：  
  1. **流量型与阶段匹配：是。** 新号流量型60%，是最大模块。  
  2. **主力形式有依据：是。** 暂无历史数据，先用门店最容易稳定生产的试穿过程测试。  
  3. **大流量内容占主力：是。** 60%围绕大码女生、人群共鸣、真实门店场景设计。  
  4. **给人群兴趣留了空间：是。** 25%题材连接通勤、接孩子、聚会、换季。  
  5. **每个数字有原因：是。** 起号先扩触达，变现内容保留信任证据，人设内容暂不硬编。  

- **第一条该发什么**：  
  **标题方向：《大码女生进店前，最常先问的一句话》**  
  目的：**流量型。**  
  用法：**第32计·换个视角**。  
  拍法：镜头从试衣间门口或衣架旁开始，阿梅拿起一件大码女装，说：“很多女生进店，第一句不是问多少钱，是问：有我能穿的吗？”接着拍她走向尺码区、整理衣架，最后停在一句：“你进店最先问哪一句？”  
  为什么先拍它：它不急着卖货，但直接圈中目标人群，阿梅一个人、一部手机、在店里就能完成，也能测试账号能否吸到真正的大码女生。

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：视频配音Vlog + 少量近景口播。门店和试衣间是最有说服力的场，不建议纯白墙讲穿搭。  
- **产能**：待确认：缺阿梅每周可出镜时间、是否有人协助拍摄。未确认前按每周3条设计，一次拍完3—4条素材。  
- **在哪拍**：衣架区、试衣间门口、镜子前、门店入口。多用中景和近景，拍衣服上身、活动动作和阿梅回答问题的瞬间。

### 5. 风格调性（只给结论，≤200字）

- **正向匹配**：县城实体店就该拍得像真实门店，不做精修时尚大片。真实试穿比过度滤镜更自洽。  
- **气质关键词**：直接、松弛、尊重。  
- **会说的一句话**：“你先试，上身舒服不舒服，比挂着好不好看更重要。”  
- **不会说的一句话**：“这件谁穿都显瘦，闭眼拿。”  

### 6. 变现定位（只给结论，≤250字）

- **卖什么**：大码连衣裙、大码外套、大码裤装；客单价区间待确认。  
- **成交路径**：抖音刷到试穿内容 → 私信问尺码/到店 → 进试衣间试穿 → 选购 → 老客复购。  
- **最缺的信任证据**：不是更多“显瘦”形容词，而是持续证明50码以上有可试穿款，以及真实上身后的活动和版型状态。  
- 完整的变现拆解请用「商业定位」板块。

## 🧠 记忆点设计

## ⚡ 差异化：A + 变量B

### 1. 挂版上新 + 试衣间视角

- **常规A**：同行对着衣架快速拍新款，字幕写“新款到了”。

### 2. 快速换装 + 对比改造

- **常规A**：同一个人连换多套衣服，追求节奏快。  
- **变量B**：行为类的**对比改造**。  
- **A+B长什么样**：同一人、同一试衣间，只换两件不同版型的大码外套，保留侧身、抬手、坐下等同样动作，让观众看见衣服本身带来的差异。  
- **为什么不是自嗨**：不拿同一件衣服换穿法做假对比，顾客能直接判断自己更可能适合哪类版型。

### 3. 穿搭口播 + 替网友做

- **常规A**：店主对镜头讲“梨形身材怎么穿”“微胖怎么搭”。  
- **变量B**：行为类的**互联网嘴替/替网友做**。

- **为什么不是自嗨**：问题来自顾客真实顾虑，回答落到店内能试的大码裤装上。
