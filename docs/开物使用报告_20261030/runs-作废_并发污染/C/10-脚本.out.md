### 第1步：脚本策略卡
- **核心问题**：挑布艺沙发时，怎样避免只看颜色、坐一下就决定。
- **用户目的**：变现型；引导准备置家的用户到店完成真实试坐。
- **目标人群**：县城新婚家庭、换房业主。
- **所选形式**：**对比型 + 36计·第15计 正确做法VS错误做法**。先拍“坐一下就走”的遗漏，再用完整试坐动作给出可执行判断。
- **材料递进**：颜色第一眼 → 错误试坐遗漏 → 四步试坐 → 不同家庭使用习惯 → 到店行动。
- **事实边界**：只说现场能观察到的坐姿、靠背、扶手与活动空间；不承诺舒适度、耐用性或适配所有家庭。

### 第2步：纯文字文案
布艺沙发坐一下就准备定，可能只看到了颜色，还没看清自己坐着合不合适。  

很多人试坐就两步：坐下，看一眼颜色，起身。  

这样看不到的，是你平时会不会靠着坐、起身顺不顺手，还有沙发前面和侧边能不能走人。  

别急着定，换成这套试法。  

第一，按你在家最常用的姿势坐下。  

第二，往后靠一靠，看腰背落在哪儿。  

第三，起身一次，看看扶手用不用得上。  

第四，站到沙发前面和侧边，看看家里留出的活动位置。  

再想清楚，家里是谁坐得最多。有人习惯并排聊天，有人经常靠着休息，也有人起身时更需要扶手。  

不要替家里人凭第一眼做决定，能一起试，就一起试。  

这就是坐一下和坐明白的差别：颜色是第一眼，合不合适得靠动作。  

准备选布艺沙发的，到店把你平时的坐法试一遍。  

### 第3步：完整分镜脚本
【镜头1】0-8秒  
- **画面**：固定近景。老周坐到布艺沙发上，手摸一下靠垫或看向颜色，随即起身。  
- **台词**：布艺沙发坐一下就准备定，可能只看到了颜色，还没看清自己坐着合不合适。  
- **拍摄/收音要点**：开头动作要连贯，字幕突出“坐一下”“看颜色”。  
- **波点**：⚡反差——“坐一下”和“坐明白”不是一回事。

【镜头2】8-17秒  
- **画面**：中景，重复“坐下—看一眼—起身”的短动作；切一个沙发颜色或靠垫局部。  
- **台词**：很多人试坐就两步：坐下，看一眼颜色，起身。  
- **拍摄/收音要点**：动作稍快，表现“只看第一眼”的过程，不配顾客反应。

【镜头3】17-25秒  
- **画面**：侧拍老周坐在沙发上；补拍靠背、扶手、沙发前方与侧方空位。  
- **台词**：这样看不到的，是你平时会不会靠着坐、起身顺不顺手，还有沙发前面和侧边能不能走人。  
- **拍摄/收音要点**：画面跟着台词逐一切换：靠背→起身→前侧活动空间。  
- **波点**：😓共鸣——原来漏看的不是颜色，而是日常动作。

【镜头4】25-29秒  
- **画面**：老周回到沙发前，手掌向下示意“先别急”。  
- **台词**：别急着定，换成这套试法。  
- **拍摄/收音要点**：此处停半拍后进入步骤，音乐节奏稍提。

【镜头5】29-35秒  
- **画面**：全身侧拍，老周按自然姿势坐下。  
- **台词**：第一，按你在家最常用的姿势坐下。  
- **拍摄/收音要点**：不刻意摆姿势，保留完整坐下动作。

【镜头6】35-40秒  
- **画面**：近景拍后背靠向靠背；镜头带到腰背接触的位置。  
- **台词**：第二，往后靠一靠，看腰背落在哪儿。  
- **拍摄/收音要点**：手机手持缓慢推进，避免只拍脸。

【镜头7】40-45秒  
- **画面**：中景，老周从沙发起身，手自然接触或不接触扶手。  
- **台词**：第三，起身一次，看看扶手用不用得上。  
- **拍摄/收音要点**：完整记录起身过程，不快切。

【镜头8】45-49秒  
- **画面**：广一点的侧拍。老周站到沙发前方、侧边各走一步，镜头展示可见空间。  
- **台词**：第四，站到沙发前面和侧边，看看家里留出的活动位置。  
- **拍摄/收音要点**：不标具体尺寸；用人走动呈现空间关系。

【镜头9】49-55秒  
- **画面**：老周坐回沙发，镜头交替拍并排座位、靠背、扶手。  
- **台词**：再想清楚，家里是谁坐得最多。有人习惯并排聊天，有人经常靠着休息，也有人起身时更需要扶手。  
- **拍摄/收音要点**：字幕分段出现“并排聊天”“靠着休息”“起身扶手”。  
- **波点**：💡顿悟——先确认使用的人，再判断这张沙发。

【镜头10】55-60秒  
- **画面**：老周站在沙发旁，最后切回“坐下—靠一靠—起身”的连续动作回放。  
- **台词**：不要替家里人凭第一眼做决定，能一起试，就一起试。  
- **台词**：这就是坐一下和坐明白的差别：颜色是第一眼，合不合适得靠动作。  
- **台词**：准备选布艺沙发的，到店把你平时的坐法试一遍。  
- **拍摄/收音要点**：最后一句正对镜头说；结尾只保留“到店试坐”的行动指令。

### 第4步：执行与优化建议
- 一套布艺沙发即可完成，固定机位拍全身动作，再补靠背、扶手和活动空间特写。
- 拍摄前清出沙发前方、侧边可走动的位置，避免杂物遮挡“活动空间”这个关键证据。
- 老周口播时以正常语速说，重点重读“坐一下”“坐明白”“靠动作”。
- 现场如有家人愿意出镜，可只拍背影或手部，补充“能一起试，就一起试”；无人出镜也不影响脚本成立。
