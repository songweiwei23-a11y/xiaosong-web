# 🎯 账号定位方案

## 📌 核心结论（先看这 8 条）

1. **这是什么号**：本地家居实体店号，讲清实木家具、布艺沙发怎么选  
2. **给谁看**：正在布置婚房或换房、要在县城买家具的家庭  
3. **人设标签**：做家具12年的本地木工店老板  
4. **主打内容**：流量50% / 人设20% / 变现30%；主力先测木料辨认和选购知识  
5. **怎么赚钱**：抖音内容触达本地家庭 → 私信或到店看实木家具、布艺沙发  
6. **第一条拍什么**：老周在工坊现场展示一块木料，讲清怎么辨认  
7. **最该避开的坑**：只讲木料知识，却不让观众看见店里卖的家具  
8. **多久能看出跑没跑通**：先连续测试20条，再看非粉播放、完播、主页访问和到店咨询

## 🔍 先说这一行

**归口：D类家居家电，以家具零售为主。**这类生意通常不是刷到视频就立刻成交：家具金额和使用周期往往让顾客需要看实物、比较款式与价格，并和家人商量。这里是行业推测，具体客单、成交周期和利润结构需要老板补充，不能当作本店已确认事实。

**钱怎么赚：**家具店通常靠单笔销售贡献收入，购买频率较低，复购不是主要成交来源；获客成本容易卡在“顾客看过、问过，却没到店或没决定”。对这个账号，视频的作用不是承诺成交，而是让本地顾客愿意进一步看实物。实际毛利和客单价待确认，不能凭行业印象给数字。

**决策链路：**更可能是刷到视频、记住店或老板、转给家人讨论、到店看款和材料，再决定是否购买。具体要几天或几周，取决于顾客装修进度、预算和家庭意见，现阶段没有依据给出固定天数。

**时间规律：**婚房、换房和装修节点可能带来集中需求；节假日也可能影响进店，但本店的淡旺季和客流时段没有资料支持。先问清过去一年哪些月份进店咨询明显变化，再决定是否围绕节点做内容。

**老板普遍容易犯的错：**把“我懂木料、我有工坊”当成观众天然关心的内容。观众真正想知道的是：这些信息能不能帮他判断家具、减少买错的风险。档案已有“客人常问沙发怎么挑不踩坑”，说明内容应从具体购买疑问切入，再展示对应产品或现场判断。

**同行常见内容与空档：**行业账号常见门店巡店、产品展示、价格介绍和选购知识。单纯拍货容易像广告，纯口播知识又可能让观众看完只学到方法、想不起店铺。这个号可利用真实工坊和木料可现场看的条件，把“讲判断”与“展示实物”连起来；但具体竞品内容需完成同城账号调研后再下结论，目前不能断言本地同行都在拍什么。

## 🗣 我会先问老板的几个问题

- **问题**：最近一次顾客觉得家具或沙发不合适是什么时候？他当时怎么说，老周怎么处理，最后结果是什么？
  - **我的推测**：家具是高决策商品，顾客可能会在尺寸、颜色、坐感、材料或预期上提出疑问。具体问题及处理过程必须以真实事件为准。
  - 待老板确认

- **问题**：有没有明确不接的单、不做的改动或不卖的货？是哪一次经历让你定下这个边界？
  - **我的推测**：自家有工坊，可能会遇到顾客提出定制或改动要求；是否承接、边界在哪里，不能替老板设定。
  - 待老板确认

- **问题**：哪位老客后来又回来买过？第一次为什么来，第二次为什么回来？请讲具体商品和当时发生的事。
  - **我的推测**：家具购买周期较长，若有回购或介绍亲友的顾客，关键原因可能是体验、款式、服务或关系中的某一项，需要顾客实际反馈验证。
  - 待老板确认

- **问题**：顾客进店最常问的一句话是什么？老周通常怎么回答？能不能举一次真实对话？
  - **我的推测**：档案提到顾客常问“沙发怎么挑不踩坑”，但这是否是进店频率最高的问题、老周实际怎么回答，仍需核实。
  - 待老板确认

- **问题**：店里这个月发生过哪件具体小事？可以是一位顾客、一件家具、一次木料查看或工坊里一个步骤，请按经过讲一遍。
  - **我的推测**：工坊日常更容易提供真实过程素材，但要先确认哪些步骤能拍、哪些属于常规操作，不能把普通过程包装成特殊成果。
  - 待老板确认

- **问题**：有没有顾客明确说过“为什么选这里，而不是别家”？请尽量还原顾客原话。
  - **我的推测**：老板认为“自家工坊、木料可现场看”是卖点，但顾客是否也把它当作选择理由，必须问顾客感受或回忆真实原话。真正的差异化要以顾客感受到的为准。
  - 待老板确认

## 一句话定位

**做家具12年的本地老板，带你看实木家具和布艺沙发，选购先看实物再决定。**

（30字以内；定位理由是老周有行业经历，且“木料可现场看”能变成画面证据。布艺沙发的具体差异尚未确认，先不替它编卖点。）

## 六维地基

### 1. 人设定位

- **原料在哪**：可作为人设真材料的是“老板老周”“做家具12年”“本地人”“自家有木工工坊”“木料可现场看”。这些是身份、经历和可拍的场景，不是性格结论。档案没有“脾气直”“特别实在”之类描述，不能擅自加。
- **形容词怎么翻译成行为**：如果想表达“懂家具”，就拍老周在真实木料或家具前回答顾客问题；如果想表达“愿意让顾客看材料”，就拍顾客实际看料的过程。没有拍到行为前，不把“专业、靠谱”写成人设结论。
- **人设标签句**：做家具12年的本地木工店老板。
- **用了哪个入口**：特殊经历 + 职业身份。验证问题是：能不能持续拿出行业判断和工坊现场？目前有12年从业经历、自家工坊及木料可现场看的事实作为起点；具体制作环节和老周亲手负责的步骤，还要前采确认。
- **在同类账号里的位置**：常见方向是老板口播讲选购、门店展示家具。老周可把选购回答带到木料和工坊现场，不只讲结论。但这是否构成本地差异，仍需同城竞品调研；不能仅凭档案断言同行没有工坊。
- **证据链**：
  1. 老周现场辨认木料，回答顾客真实问题。
  2. 展示工坊里的真实制作或检查步骤，拍前确认每一步实际由谁完成。
  3. 讲顾客挑布艺沙发时常问的问题，结合店内真实款式演示判断。
  4. 用顾客真实反馈和事件补充“为什么选这里”，取得顾客同意后再拍。
- **边界**：不说“全县最好”“绝对不踩坑”等无法证明的绝对化话；不编顾客评价、订单结果、材料来源和制作工艺；不把木料现场可看扩大成“买了就不会买错”。

### 2. 用户定位

- **一句话画像**：正在准备婚房，或刚换房开始挑家具，想在县城本地看实物、又担心买错实木家具或布艺沙发的家庭。
- **为什么是他们、不是另一批**：这两类人正处在家具购买决策里，与门店的实木家具、布艺沙发直接相关，也更可能愿意到店看货。暂不把泛家居爱好者、只看装修灵感的人当主攻人群；他们可能看内容，却未必处于购买场景。八类人群词根中，优先测试“精致妈妈”和“小镇中老年”之外的家庭决策者并不妥当；因此建议主攻**精致妈妈**，其次是**小镇青年中的新婚家庭**。这是基于购买场景的判断，具体来客画像待门店确认。
- **他们心里真正在想什么**：可能是“照片看着差不多，我怎么知道这件家具适不适合我家？”以及“家里人意见不一样，买回去不合适怎么办？”这是推测，要通过进店对话验证。
- **决策链路**：刷到一条具体选购内容 → 记住老周或门店 → 看主页其他内容确认是否真在卖相关商品 → 转给家人商量 → 私信或到店看实物、问价格和尺寸 → 决定是否购买。家具购买决策通常需要多轮比较，但这家店具体要多久待确认。
- **什么时刻会想起你**：开始量新房尺寸、婚房准备置办家具、旧沙发需要更换、家人讨论家具材质和款式时。
- **他在平台上搜什么**：县城实木家具、实木餐桌椅怎么选、布艺沙发怎么挑、沙发怎么挑不踩坑、家具店实木家具。县城具体地名和店名要补齐后再用于昵称和搜索词。

### 3. 内容定位

- **长期提供什么价值**：让本地家庭看懂实木家具与布艺沙发的选购问题，并看到真实商品和工坊现场。
- **内容方向**：选“多元四类打底 + 工坊现场作为稳定栏目”，暂不做单一主题。原因是目前已有常识、木料辨认、工坊过程三个方向，但没有确认老周能否持续完成一个固定任务，也没有真实事件素材库支撑单一主题长期更新。待拍出样片、确认工坊可拍流程后，再判断是否升级为单一主题。
- **当前阶段配比：流量型50% / 人设型20% / 变现型30%。**
  - **作用配比依据**：账号处于0—1000粉起号期，没有已验证的高表现内容，所以流量型最大，先争取陌生本地用户停留；人设型用真实职业和现场增加记忆；变现型从一开始保留，但避免账号一开场全是商品介绍。
  - **流量型形式**：以知识和现场演示为主，但必须把“成本、人群、反差、冷知识”等爆款元素具体设计进内容。比如同一块木料的外观与切面特征作为视觉看点，或围绕新婚家庭的选购疑问开场。不能只把行业知识讲细，就称为大流量。
  - **人设型形式**：真实职业经历、工坊日常、老周对顾客问题的处理和经营边界。当前没有具体故事，先采集真实事件，不编“创业逆袭”。
  - **变现型形式**：晒过程和教知识结合，围绕一个真实成交理由，例如“木料可现场看”，画面要实际拍到材料和观看过程；布艺沙发则围绕真实款式、坐感或顾客常问展开，待确认可证明的卖点。
  - **题材配比**：主赛道家居家具选购约70%，目标人群兴趣约30%。主赛道包含实木家具、布艺沙发，比例轮换安排，两个品类都要持续出现；人群兴趣可围绕婚房布置、换房时如何量尺寸、家人意见不一致等场景。比例是起号测试起点，不代表已验证最优。
- **主力形式**：档案没有“数据最好的内容类型”，不能称某一种已被验证。起步先以“选购知识 + 现场演示”为测试主力，因为已有选家具常识、木料辨认和顾客沙发问题这三类素材依据；连续测试后再按数据调整。
- **每类内容管哪一段路**：
  - **流量型：刷到。**用陌生人听得懂的家具问题、现场演示和可见的木料细节吸引停留。
  - **人设型：记住。**让观众记住老周是做家具12年的本地老板，内容靠真实行为而不是形容词。
  - **变现型：信、联系。**让观众看到店里确实有实木家具、布艺沙发，以及能现场看木料，再引导到店了解。
- **三种视频各怎么拍：**
  - **流量型**
    - 四大脚本：教知识·拆解型，用“一个常见选购误区 → 现场展示对应木料或家具细节 → 说明判断边界”；结尾引导评论：“你挑家具最纠结哪一点？”
    - 起号36计：**第36计·冷知识**：老周拿起店内真实木料，提出一个经确认的反常识判断，再展示能支持该判断的特征，说明适用范围，最后问观众是否见过这种材料。结论须由老周确认，不能为了反常识编知识。
  - **人设型**
    - 四大脚本：观点立场，用老周一段真实经历 → 形成的判断 → 为什么这么看；素材未采到前不写具体故事。结尾：“关注老周，看看家具店里每天发生什么。”
    - 起号36计：**第7计·一句话设定故事感**：老周在工坊做一项真实日常工作，开头用一句话交代当天的实际目标或遇到的问题，记录过程和结果；结尾引导看主页。目标必须来自当天真实任务，不摆拍成突发事件。
  - **变现型**
    - 四大脚本：晒过程·火车节，拍顾客或老周实际查看木料的起因 → 查看过程 → 能确认的结果；结尾：“想现场看木料，可以到店看看。”
    - 起号36计：**第10计·情境还原**：还原一次真实顾客选购过程，用顾客真实问题开场，老周现场展示对应家具或材料，解释判断依据，最后拍到顾客实际看见的结果。顾客须同意出镜；没有真实顾客时，改拍老周演示真实步骤，并明确是演示，不冒充真实成交。
- **配比核验**：
  1. **是**：起号期流量型为最大块，符合先获得陌生触达和正反馈的阶段任务。
  2. **否（暂不可验证）**：档案没提供数据最好的内容类型；先测试“知识+现场演示”，不把它冒称为已验证主力。
  3. **是**：流量型占50%，但每条还需落实人货场、三有和爆款元素，不能只讲窄行业知识。
  4. **是**：约30%留给婚房、换房等目标家庭的生活场景，不让内容只对木工或家具从业者有用。
  5. **是**：50/20/30是起号阶段的测试比例：流量拓新、人设建立记忆、变现证明商品与现场；没有历史数据，后续需按实际表现修正。
- **第一条该发什么**：拍流量型，用四大脚本·教知识拆解结构。老周在工坊拿一块真实木料，开头说：“挑实木家具，先别只看表面颜色，先看这块料的具体特征。”随后展示木料可见部位，讲一个经老周确认、适用范围明确的辨认点；结尾问：“你买家具时最想先看哪一点？”  
  **为什么先发它**：从选家具的真实疑问切入，现场也有可拍材料，陌生观众不需要先认识老周就能看懂。拍前必须由老板核实判断内容，避免把单一特征说成普遍结论。
- **主打内容、栏目和第一条的边界**：可以一条拍实木家具、一条拍布艺沙发，不要求同框；但内容配比要持续轮换两个品类。对比内容只在同一空间、条件尽量一致时更换商品对比，例如同一客厅更换两张实际在售沙发；不能用同一张沙发换摆法来证明产品变好。

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：以现场口播加过程镜头为主；老周可一人完成口播，木料、工坊和店内家具提供画面证据。
- **产能**：建议先按每周2—3条试运行。团队人数、拍摄时间和剪辑资源未提供，这是起步估算；先确认老周每周能固定留出的拍摄时段，再承诺产量。
- **在哪拍**：木料查看在工坊拍；实木家具和布艺沙发的选购演示在对应商品旁拍。避免长期用无关白墙背景。

### 5. 风格调性（只给结论，≤200字）

- **正向匹配**：本地木工店老板在真实工坊、店内家具旁讲选购，身份、场景和话题一致。
- **气质关键词**：清楚、朴实、克制。
- **会说的一句话**：“这块料先看这里，能判断到哪一步，我给你讲到哪一步。”
- **不会说的一句话**：“买家具照我说的选，保证不踩坑。”前者能按现场证据说明边界，后者作出无法保证的承诺。

### 6. 变现定位（只给结论，≤250字）

- **卖什么 + 客单价区间**：实木家具、布艺沙发；客单价区间待确认，需先补充各品类常见成交价和价格范围。
- **成交路径**：抖音视频 → 主页了解门店 → 私信或到店看实木家具、布艺沙发 → 现场沟通购买
- **最缺的信任证据是什么**：木料可现场看的实际流程、商品实物细节，以及顾客为何选择门店的真实反馈。
- 完整的变现拆解请用「商业定位」板块。

## 🧠 记忆点设计

以下建议先测试，不强行固定；最终看评论区是否有人主动提到：

1. **场景道具（待验证）**：老周讲木料时，固定在工坊工作台旁，手里拿实际要讲的木料。每次重复“拿料—展示特征—说明判断边界”，和“木料可现场看”的定位直接相关。
2. **动作（待验证）**：开头先把木料或家具细节放到镜头前，再切到老周讲解。这个动作每条都可重复，但不能让动作本身替代内容看点。
3. **语言（待验证）**：尝试用“先看实物，再听我说”作为固定表达。只在符合当条内容时使用，不要硬塞；如果评论区无人记住，就换掉。

## ⚡ 差异化：A + 变量B

## ✅ 自洽检验

1. **遮住字幕，还能看出账号气质吗？**现在未验证。工坊、老周和实物能提供视觉线索；若镜头长期只拍脸和字幕，就看不出家具店属性。补救：每条至少拍到工坊、木料或店内对应商品。
2. **只听声音，还能判断人物性格吗？**目前没有老周真实口播样本，不能判定。建议先用平常说话的语速回答顾客问题，不先设计夸张口号；拍后听一遍，确认像日常交流而非念广告。
3. **头像、简介、单条视频放一起，会不会像三个不同账号？**方案方向上自洽，但尚未实拍验证。头像用老周与店内场景，简介写清实木家具、布艺沙发，视频也按两个品类轮换；若实际视频只讲木料、不出现商品，会造成定位与内容不一致。

## ⚠️ 这个号最大的风险

1. **内容容易变成木料知识号，而不是家具店账号。**观众可能学到一个辨认方法，却没有看到实木家具、布艺沙发，也不知道门店能提供什么。每条知识内容都要回到对应的实际商品或工坊过程，但流量型内容不能硬推销。
2. **“自家工坊、木料可现场看”目前只是条件，不等于已证实的差异化。**如果顾客并不在意、现场也没有可展示的材料判断过程，就难以持续形成信任。下一步先问真实顾客为何选择这里，并拍一段能证明“现场怎么看”的过程；在顾客反馈和竞品调研出来前，不把它夸大成独家优势。
