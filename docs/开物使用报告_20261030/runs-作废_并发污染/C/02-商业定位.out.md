# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

家具零售卖的不是“看一眼就下单”的货，而是一个家庭要用很多年的耐用品。顾客通常会先看款式和尺寸，再问材质、坐感、价格、送装和售后，最后还要回家和家人商量。**这门生意主要靠单笔客单贡献，不靠高频复购**；真正有价值的是一次成交后，顾客愿不愿意介绍亲友。

这行的获客成本，容易卡在两个地方：

1. **刷到视频的人不在装修节点。**他觉得内容有用，但暂时不买，过几天就忘了店。
2. **到店的人只看不决策。**家具需要对比，顾客会担心尺寸不合适、材料看不懂、沙发坐久了不舒服，于是“再看看”就流失了。

县城家具店的成交并不只拼低价。顾客往往会问熟人、看门店是否开得久、老板说话是否讲得明白。老周“做家具12年、本地人、自家有木工工坊、木料可现场看”，有机会降低顾客对实木家具的材料疑虑；但这只是现有条件，不能直接等同于“顾客一定因此买单”。要靠真实看料过程、商品细节和顾客反馈去证明。

淡旺季我推测会和**交房、装修进度、婚房布置、换房搬家、节假日回乡团聚**有关；但本店具体旺月、淡月、客流高峰时段待确认。接手后先翻近一年的进店记录或老板回忆，确认哪些月份咨询明显集中，再安排节点内容，不能只按行业印象排期。

同行常见的拍法是拍一排家具、报价格、镜头扫一遍门店。这类内容的问题是：顾客看完只知道“这里有家具”，却不知道“我为什么要专门来这里看”。另一类是只讲木料知识，问题是流量可能来了，店里的实木家具和布艺沙发却没被记住。

**这个号不做纯产品画册，也不做脱离商品的木料知识号。**内容应该让顾客看到：老周讲的判断，最后落在店内真实的实木家具或布艺沙发上。

**一句话定位：老周带你看实木家具、布艺沙发，先看木料再决定。**

## 变现全景

### 现在能卖什么

1. **实木餐桌椅**  
   是当前最适合做“看木料—看结构—看成品”内容闭环的品类。工坊、木料和成品之间有明确画面关系，适合把顾客的材料疑问带到店里解决。

2. **其他实木家具**  
   档案只确认在卖“实木家具”，没有确认具体细分款式，不能擅自扩写成床、柜、茶几等。后续需要老板列出店内常卖款、可拍款和利润相对稳定的款。

3. **布艺沙发**  
   顾客已明确常问“沙发怎么挑不踩坑”，说明它有真实内容入口。布艺沙发不能只拍颜色和外观，重点应放在顾客实际会关心的尺寸、坐感、面料触感、拆洗方式及与家庭使用场景的关系；具体可讲到什么程度，要由店内真实商品参数确认。

4. **到店选购咨询与搭配建议**  
   这不是单独收费项目，而是推动家具成交的服务环节。视频先解决一个判断问题，顾客再到店结合自家尺寸、家庭成员和预算看实物。

### 各自的客单价与毛利大致区间

目前不能给这家店编客单价和毛利率。家具的价格差会受木材种类、规格、工艺、款式、进货或自制比例、配送安装成本影响很大；县城同类店的实际成交，也会受本地消费能力影响。

**待确认的三项信息：**

- 实木餐桌椅常见成交价区间；
- 布艺沙发常见成交价区间；
- 每个品类卖得最多的前三个款式，以及大致毛利空间。

没有这三项，不建议在短视频里大量拍“价格优势”或做低价承诺。起号期先卖“愿意到店看实物”的机会，再根据实际价格带设计内容。

### 决策难度

| 产品 | 决策难度 | 为什么 |
|---|---|---|
| 实木餐桌椅 | 高决策 | 顾客会看材料、尺寸、风格和耐用性，通常还需要和家人商量。 |
| 实木家具 | 高决策 | 使用周期长、占用空间大，顾客需要到店确认实物。 |
| 布艺沙发 | 高决策 | 顾客不仅看颜色，还会在意坐感、大小、面料、家庭成员使用情况。 |
| 到店选购咨询 | 低门槛、高价值 | 顾客不一定马上买，但“先来看看、坐一坐、看材料”比直接下单更容易迈出第一步。 |

## 主推产品

**商业主推建议：实木餐桌椅。**

不是因为它一定最贵，而是它最适合当前账号已有资源：老周有工坊、有木料可看、有“做家具12年”的经历，餐桌椅可以把“木料”这个信任点拍得具体——从工坊里的料，到店里的成品，顾客能看懂两者的关系。

主推实木餐桌椅的目的，是先把顾客带到店里看料、看工坊、看实物；**不代表布艺沙发被降成配角。**账号内容仍要持续轮换：

- 实木家具：承担“材料判断、工坊现场、结构细节”的信任建立；
- 布艺沙发：承担“家庭使用场景、坐感与挑选问题”的咨询转化。

我建议首月变现内容中，实木家具与布艺沙发按接近 **1:1** 轮换测试。因为目前只有“木料可现场看”被确认是实木家具的证据，布艺沙发的真实优势还没有采到，不能一上来替它编卖点。

## 成交路径

### 1. 第一次接触看到什么

顾客刷到的第一条，不该是“本店家具优惠”，而应是一个他正在纠结的具体问题。

例如：

- “挑实木餐桌，别只盯着表面颜色，先看这个位置。”
- “婚房挑沙发，先把家里这个尺寸量明白。”
- “一张餐桌摆进家里之前，很多人漏看了这一处。”

这一步的任务是让陌生人停下来，完成的是**认知变化或身份确认**：正在装修、准备结婚、打算换家具的人，会觉得“这正是我在纠结的事”。

**会流失的人：**暂时没有装修、换房、婚房需求的人。  
**为什么会流失：**家具不是高频消费，不可能靠一条视频让所有本地人都成为客户。这个流失正常，不要为了扩大播放去拍和家具无关的泛内容。

### 2. 靠什么产生兴趣

顾客产生兴趣，不是因为老周说“质量好”，而是他看到了可验证的判断过程：

- 实木家具：木料、切面、结构、成品细节之间的关系；
- 布艺沙发：顾客实际会坐、会摸、会量的部位；
- 工坊：不是拍机器转一圈，而是拍“这块料怎么看、这一步检查什么、和最后成品有什么关系”。

这一步要让顾客从“我刷到一条知识”变成“这个老板讲得清楚，而且店里真有实物能看”。

**会流失的人：**只想看低价、不愿意比较材料与实物的人。  
**为什么会流失：**账号不适合承诺全城低价，也没有价格优势依据。与其把内容做成低价引流，不如筛出愿意认真挑家具的人。

### 3. 在哪里沉淀

核心沉淀地是：**主页 → 私信 → 到店。**

主页至少要让顾客快速确认三件事：

1. 老周是谁：做家具12年的本地老板；
2. 店里卖什么：实木家具、布艺沙发；
3. 为什么值得到店：可以现场看木料、看实物、问选购问题。

私信不建议急着报一个模糊价格。先问清顾客处于什么节点：

- 新房还是旧房换新；
- 想看实木家具还是布艺沙发；
- 家里大致空间尺寸；
- 什么时候方便到店。

这不是为了把顾客“筛掉”，而是让到店沟通从“随便看看”变成“带着问题来看”。

**会流失的人：**只问一句“多少钱”，不愿提供任何需求信息的人。  
**为什么会流失：**家具价格必须对应具体款式、规格和材质。只报一个数字，容易吸引价格比较型咨询，也容易造成顾客预期不一致。

### 4. 临门一脚是什么

临门一脚不是催单，而是让顾客在同一个现场完成关键确认：

- 看实木家具时，确认木料、尺寸、结构、桌椅搭配；
- 看布艺沙发时，确认实际坐感、尺寸、面料和家庭使用需求；
- 顾客有家人一起决策时，尽量让关键决策人同步到店或视频连线确认。

真正推动成交的，是“我看过实物，知道它放在我家大概是什么样，也知道自己为什么选它”，不是一句限时话术。

**会流失的人：**装修尚未推进、家人意见没有统一、预算未确定的人。  
**为什么会流失：**这是家具高决策的正常过程。对这类人不要反复硬推，应该让他们先关注主页，等装修进度推进后再回来。

## 信任证据清单

| 可拍证据 | 证明什么 | 当前状态与怎么拍 |
|---|---|---|
| 1. 老周在工坊拿真实木料讲一个可见特征 | 专业、真实 | 已有条件。每次只讲一个经老周确认的判断点，并说清“能判断到哪一步”。 |
| 2. 木料与店内对应实木家具同框 | 真实、产品关联 | 已有条件。工坊拍料后切到店内成品，避免讲完木料就断掉。 |
| 3. 餐桌椅的边角、连接处、桌面细节 | 产品细节、专业判断 | 待确认哪些部位适合拍、哪些说法有依据。不能拿单一细节推成全部质量结论。 |
| 4. 顾客到店实际看木料的过程 | 真实、服务过程 | 待积累。顾客同意出镜后再拍；不方便出镜可只拍手部和对话重点。 |
| 5. 顾客试坐布艺沙发、量尺寸、看面料 | 产品体验、真实 | 待确认。要拍真实选购行为，不摆拍成“顾客马上决定购买”。 |
| 6. 老周回答“沙发怎么挑不踩坑”的真实对话 | 专业、沟通能力 | 有问题入口，缺真实回答。前采先录下老周平时怎么说，再整理成短视频。 |
| 7. 工坊真实制作或检查步骤 | 生产能力、真实 | 待确认老周亲手负责哪一步、哪些流程能公开拍。不能把普通流程包装成特殊工艺。 |
| 8. 顾客为什么选择这里的一句原话 | 结果、口碑 | 目前缺失。先问一位已成交顾客：“你最后为什么决定在这里买？”只用对方原话，不改成夸张好评。 |

**首要补证据动作：**拍一条“到店怎么看木料”的真实流程。因为“木料可现场看”是现阶段最明确的卖点，但如果镜头里始终只有老周拿木头讲知识，顾客看不到“自己到店后会怎么被服务”，这个卖点就没有落地。

## 变现型内容怎么排

### 变现型内容占比建议：30%

这是起号期合适的小头，不宜更高。

原因是账号现在粉丝量低，如果一开始连续拍产品介绍和到店引导，平台和观众都会更容易把它识别成广告；但家具又是高决策商品，完全不发变现内容也不行，主页会缺少“店里到底卖什么、到店能看什么”的承接。

建议按每周2—3条的试运行产能，先保证其中至少有1条是变现型；其他内容由流量型承担陌生触达、人设型承担对老周的记忆。实木家具、布艺沙发在一个月内都要有对应变现内容。

### 方向一：到店看木料，到底看什么

- **成交路径位置：**从主页或私信进入到店前，降低第一次到店的陌生感。
- **对应成交理由：**木料可现场看。
- **观众变化：**从“只听老板说材质”变成“我知道到店可以看什么”。
- **四大脚本：**晒过程·火车节  
  起因：顾客问“到店看木料到底看什么？”  
  过程：老周拿出真实木料，按实际流程展示顾客能看的部位。  
  结果：切到对应实木家具，说明“看料只是第一步，最后还要看成品和尺寸。”
- **36计拍法：**第10计·情境还原：还原顾客进店想看木料的真实任务，老周带着看一块料、一个细节、一件成品；没有顾客出镜时，要明确是“到店看料演示”。
- **结尾行动：**到店。  
  “想看木料，带上你家尺寸，到店我给你对着实物看。”
- **为什么能做：**工坊和木料是已确认资源，不需要编案例，也不依赖复杂拍摄。

### 方向二：婚房挑餐桌，先确认家里哪两个尺寸

- **成交路径位置：**顾客有需求、但还没确定款式的阶段。
- **对应成交理由：**专业判断。  
  这里不承诺“量完就能选对”，而是帮助顾客减少到店后信息不完整的问题。
- **观众变化：**从“先去店里随便看”变成“先把尺寸准备好再看”。
- **四大脚本：**教知识·解题型  
  难题：婚房要买餐桌，但不知道多大合适。  
  风险：只看门店效果，搬回家可能显得拥挤或空。  
  解决：到店前准备餐区长度、宽度，以及日常几个人用。  
  收束：带着这三个信息看实物更有效率。
- **36计拍法：**第15计·正确做法VS错误做法：错误做法是只拍一张户型图就问“这桌子能不能放”；正确做法是补齐实际可用尺寸和用餐人数，再到店对照实木餐桌椅。  
- **结尾行动：**私信。  
  “不确定餐区尺寸怎么量，私信发户型和尺寸，我先帮你看该带哪些信息到店。”
- **为什么能做：**内容的主角仍是实木餐桌椅，不把“量尺寸技巧”拍成脱离商品的纯教程。

### 方向三：挑布艺沙发，先试这三个位置

- **成交路径位置：**顾客已经想买布艺沙发、正在比较款式的阶段。
- **对应成交理由：**真实商品体验。  
  不是说某一张沙发适合所有人，而是让顾客到店有明确试坐动作。
- **观众变化：**从“只看颜色和照片”变成“知道自己要到店确认坐感和尺寸”。
- **四大脚本：**教知识·推荐型  
  圈定人群：正在布置婚房、准备换沙发的家庭。  
  推荐理由：先看家里空间，再坐靠背和坐垫，再确认面料和家庭使用情况。  
  适用边界：不同身高、习惯、户型，感受会不同，最终以到店体验为准。
- **36计拍法：**第26计·推荐建议：老周在一张店内真实布艺沙发旁，按“空间—坐感—面料”三个顺序讲顾客到店的查看步骤，并说明哪些情况适合、哪些情况需要再比较。
- **结尾行动：**到店。  
  “挑布艺沙发别只看照片，到店坐一会儿，再决定。”
- **为什么能做：**档案已经确认顾客常问沙发怎么挑，这是从真实问题出发，不是硬造选题。

### 方向四：同一个客厅，换两张不同尺寸的布艺沙发会怎样

- **成交路径位置：**解决顾客“怕买大、怕买小”的临门犹豫。
- **对应成交理由：**选择更匹配，而非单纯款式多。  
  “选择多”是否成立尚未确认，因此这里只证明“不同尺寸带来的空间差异”，不宣称店里款式丰富。
- **观众变化：**从“看单张沙发”变成“把沙发放回自己的空间判断”。
- **四大脚本：**晒过程·过程展示  
  保持同一个客厅、同一个机位，只替换两张店内真实在售、尺寸不同的布艺沙发；拍出过道、茶几距离、坐下后的空间感，再由老周解释适用条件。
- **36计拍法：**第19计·对比改造：同一空间原有沙发 → 换成尺寸不同的店内沙发 → 展示空间变化 → 复盘什么户型更适合哪种尺寸。  
- **结尾行动：**私信。  
  “你家客厅大概多宽，私信告诉我，我先提醒你到店该重点试哪种尺寸。”
- **为什么能做：**对比中变的是店里卖的布艺沙发，空间、机位和拍摄条件保持一致，观众能看懂差别来自产品尺寸，而不是换了摆法。

**提醒：**变现内容先解决一个具体问题，再给行动入口。不要拍成“这款很好、来店里买”，那种内容只是在报货，缺少顾客愿意行动的理由。

## 定价与节奏

### 起步阶段建议怎么定价

现阶段**不建议为了短视频单独做无法验证的低价引流款**。原因有两个：

1. 家具是高决策商品，顾客被低价吸引进来后，如果实际可选款、材质或规格与预期不同，反而会增加沟通成本；
2. 店内实际价格带、毛利、可承受优惠空间尚未确认，不能替老板承诺。

更可行的起步动作是做“低门槛到店动作”，而不是压低产品价格：

- 带尺寸到店看实木家具；
- 到店看木料与对应成品；
- 到店试坐布艺沙发；
- 私信先确认需要准备哪些尺寸和信息。

这类动作不靠虚构优惠，也符合家具购买逻辑。

### 什么时候可以涨价、涨价的依据是什么

目前没有本店价格资料，不能直接建议涨价。能考虑调整价格或减少优惠的前提，至少要同时满足：

1. 某些款式持续被顾客主动询问，且到店后成交率相对稳定；
2. 顾客选择理由不只剩“便宜”，而是能说出材料、实物、服务或款式匹配等具体原因；
3. 毛利、配送安装成本、售后成本已经被老板算清；
4. 同类产品的价格比较和顾客异议已经有记录。

涨价不是“视频有播放就涨”，而是供需、成交和成本都能支撑时再调。视频只能帮店里获得更多有效咨询，不能替代经营核算。

## ⚠️ 风险

### 1. 木料内容有播放，家具咨询却没有增长

这是这个号最可能发生的问题。原因是木料辨认对一部分人有新鲜感，但如果每条都停在工坊，观众会把账号当成木工知识号，不会主动联想到要买实木家具或布艺沙发。

**应对：**每条讲木料的内容，至少在中段或结尾切回一件店内实木家具；但流量型内容只做内容关联，不硬塞到店话术。变现型内容才明确引导到店看料。

### 2. 布艺沙发内容讲得太泛，观众觉得哪里都能看

“沙发怎么挑”是大题目，讲“看面料、看坐感、看尺寸”谁都能说。如果没有店内真实商品、真实试坐和真实顾客问题，内容很容易变成泛家居口播。

**应对：**先采集老周真实回答的原话，并确定店内能拍的沙发细节。每条只解决一个问题，例如“家里有孩子时先确认哪种使用情况”，不要一条视频讲完所有沙发知识。

### 3. 一开始就把每条视频都拍成成交视频

起号期如果连续报产品、讲优惠、引导私信，账号容易缺少陌生人愿意停留的理由，播放和主页访问都可能起不来。

**应对：**维持流量型50% / 人设型20% / 变现型30%的测试结构。先连续测试20条，再看哪类内容带来的主页访问、私信、到店咨询更多；不是单看播放量高低。  
如果“播放高、主页访问低”，下次加强老周、工坊、实木家具和布艺沙发的视觉承接；如果“咨询多、到店少”，就检查私信回复是否只报价格、有没有把顾客带到具体到店动作上。
