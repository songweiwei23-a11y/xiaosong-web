## 🧭 写作底线（每条都要遵守）

- **优先级**：事实与安全边界（人设事实卡、禁忌、平台规则） > 用户这次的明确要求 > 这条内容的创作目的 > 模板和标准。用户的明确要求哪怕只有一句（「只换开头」「别提价格」），也排在模板前面。
- 价格、百分比、销量、年限、分店数、获奖、顾客经历——资料里没有的一律不写；需要具体感时，用不带数字的说法（「90% 的人」不行，「不少人」可以；「人均 68 元」不行，「价格很亲民」可以）。顾客经历包括「吃完了跟我说」「老客隔三差五来」「很多人都说」这类反馈和复购结果；个人经历包括「我之前在别的店做过」「我以前在……干过」这类过去的经历，资料里没有都不能写。
- 可以写虚构的示例帮助理解，但必须标【示例】，不能写成「有位顾客说……」这种真实见证。
- 送什么、包什么、保证什么、打几折——老板没说过的经营承诺不能替他答应，包括「不好吃不要钱」「不满意全额退」这类口头保证。
- 真想写一个具体数字又没有资料，用【待确认：xx】占位，让用户自己填。
- 不要写「自检通过」「无编造」「数据真实」这类自我认证，系统会单独核对。

**【目的】**：流量型——用两种县城家庭的真实用餐场景，引出餐桌摆放不能只看款式。

### 1️⃣ 爆款元素
**反差**：新婚家庭 vs 换房家庭。

### 2️⃣ 开篇钩子
“同一张餐桌，刚结婚的小两口和换房家庭，留的位置可能完全不一样。”

### 3️⃣ 内容方向及目的

- **核心内容方向**：用门店餐桌椅模拟两种县城家庭的日常场景，观察餐桌摆放对通道和坐席使用的影响。
- **核心问题与观众价值**：观众要弄明白，买餐桌前为什么不能只看桌面大小和外观，还要先想清楚平时谁吃饭、父母来时怎么坐、椅子能不能顺利拉开。
- **取材与内容推进**：
  1. 在店内摆出一张餐桌和几把椅子。
  2. 第一组模拟“平时家里人少、偶尔父母来吃饭”的场景。
  3. 观察椅子拉开后，旁边的人能不能通过；记录哪些位置容易挡住。
  4. 第二组模拟“新婚置家后，亲友来坐得更多”的场景。
  5. 增加座位使用和进出动作，但不虚构具体人数。
  6. 老周分别说两种场景需要先确认什么，最后让观众代入自己的家庭。
- **事实边界**：两种家庭场景来自原方向设定，是拍摄模拟，不代表真实顾客案例。不得补充具体户型、人数和尺寸；现场只展示椅子拉动、人员通行等可见现象。
- **关键画面**：
  1. 餐桌与椅子摆放的俯拍或侧拍。
  2. 椅子拉开后，老周从旁边通过的动作。
  3. 两种生活场景下，桌边位置和通道变化的对比。
- **场景设置**：门店餐桌椅展示区，一张桌子完成两种摆放，不安排顾客或演员。

- **场景难题**：很多人先看餐桌款式，买回去才发现椅子拉不开、旁边不好走。
- **放大危机**：当餐桌放在日常吃饭和待客都要用的位置，桌边留得不合适，每次起身、坐下、端菜都可能互相挡。
- **低行动成本解决**：买之前先在现场模拟“坐下、拉椅子、从旁边通过”三个动作。
- **具体操作**：
  1. 先确定平时主要坐哪几个位置。
  2. 把椅子完整拉开。
  3. 由一个人从桌边通行。
  4. 再模拟父母或亲友来坐的场景。
  5. 记录需要回家核对的空间信息。

### 5️⃣ 结尾行动指令
“你家吃饭更像哪一种？评论区说说。”

### 6️⃣ 执行要点
提前准备纸胶带或纸张，在地面简单标出桌椅位置即可。不要使用未确认的统一尺寸标准。镜头重点拍动作和空间关系，不拍顾客正脸，不把模拟场景说成真实家庭案例。

**【目的】**：流量型——从普通家庭都会遇到的沙发选择问题切入，让陌生观众带走一个试坐观察点。

**奇葩**：内行人的神奇操作。

  3. 模拟家里有孩子，观察活动空间和起身动作。

- **事实边界**：三个家庭场景是拍摄模拟，不是顾客案例；只讲现场能观察的坐姿、动作和空间关系，不延伸到面料耐污、耐用等未经确认的性能。

  2. 三种场景下坐下、靠背、起身的动作。
  3. 拍扶手、靠背和沙发前方活动空间的局部。
- **场景设置**：门店布艺沙发区，两套沙发之间完成对照，不需要外出。

**教知识·冷知识结构**：

- **证据与例子**：分别模拟两口之家、有孩子、父母偶尔来住三种情况。
- **原理说明**：不同使用者的坐姿、起身方式和活动空间不同，现场试坐才能看出差异。
- **应用方法**：到店后至少完成“坐下、靠一靠、起身、看活动空间”四个动作。
- **一句话收住**：颜色决定第一眼，坐着是否合适要靠现场验证。

### 5️⃣ 结尾行动指令
“你家沙发主要是谁坐？评论区告诉我。”

### 6️⃣ 执行要点

## 选题4：这块料今天先不往下做

**承接**：取自方向4“这块料今天先不往下做”，以及“老周拿起一块正在处理的木料，说清这块料今天先不往下做”。

**【方向】**：这块料今天先不往下做  
**【目的】**：人设型——通过一次真实的工坊判断，让观众记住老周做事时会先检查、再决定是否继续。  
**【结尾动作】**：关注  
**【成交步骤】**：—

### 🅰 打法
**36计·第7计 一句话设定故事感**：普通动作“拿起一块木料”+明确设定“今天先不往下做” → 跟拍检查和比对 → 由老周说出这次暂停加工的真实原因。

### 1️⃣ 爆款元素
**奇葩**：内行人的神奇操作——木料已经开始处理，却先停下来检查。

### 2️⃣ 开篇钩子
“这块料今天先不往下做，我先把这几个地方看清楚。”

### 3️⃣ 内容方向及目的

- **核心内容方向**：记录工坊当天真实发生的一次选料、检查、暂停加工或调整顺序。
- **核心问题与观众价值**：观众要看到，老周在继续加工前会检查什么；这比直接说“我做家具12年”更能让人认识他的做事方式。
- **取材与内容推进**：
  1. 只有当天工坊确实出现需要暂停或调整的木料时才拍。
  2. 老周拿起木料，先说暂停加工。
  3. 镜头跟着拍他检查的具体位置，例如表面、切面、边角或与其他部件的比对。
  4. 由编导或老周补问：“你刚才先看的是哪里？”“如果继续往下做，下一步会受到什么影响？”
  5. 拍他把木料暂时放下、调整顺序或更换处理方式的动作。
  6. 结尾只回到这次判断，不上升成所有木料都必须这样处理。
- **事实边界**：老周做家具12年、自家有木工工坊是已知事实；具体暂停原因、木料状况和处理结果必须现场获得。当天没有合适判断时不拍，不用摆拍制造冲突。
- **关键画面**：
  1. 老周拿起木料并说“今天先不往下做”。
  2. 手部检查、比对和标记动作。
  3. 木料被暂时放下或工序调整后的现场状态；原因保留现场原话。
- **场景设置**：自家木工工坊当天正在进行的工作区域，单人手机记录，不安排顾客出镜。

### 4️⃣ 脚本结构
**讲故事·平凡英雄型**：

- **普通人**：老周在工坊处理一块木料。
- **不普通的小事**：没有急着继续，而是先暂停检查。
- **细节验证**：拍他看哪里、比对什么、为什么先放下。
- **感悟收束**：由老周用自己的话说，这次判断让他以后遇到类似情况会先确认什么。
- **剪辑重点**：保留停顿、检查和决定的过程，不把结果提前说死。

### 5️⃣ 结尾行动指令
“想继续看老周在工坊里的真实判断，关注我。”

### 6️⃣ 执行要点
这条必须等真实素材，不提前选一块木料安排表演。手机靠近拍手部动作，环境噪音较大时，检查过程可以补录旁白，但补录内容必须与现场实际一致。涉及木料问题的专业判断，以老周现场确认的说法为准。

- **取材与内容推进**：
  1. 明确字幕：“常见咨询情境演示”，不伪装成真实顾客。
  2. 老周先模拟“只想看款式”的咨询开场。
  3. 再让老周提出三个问题：“餐桌准备放在哪里？”“旁边有哪些固定物品？”“椅子拉开后，谁需要从旁边通过？”
  4. 用纸笔画出简单摆放示意，纸上只写现场已有信息，不补具体尺寸。
  5. 在店内餐桌椅旁演示椅子拉开、人员通行、桌边活动等动作。
  6. 结尾给出到店准备清单：拍摆放位置、记录已有尺寸、说清平时谁使用。
- **事实边界**：没有真实顾客授权，因此只能拍老周自演的常见咨询情境；不写具体户型、尺寸、价格或节省金额；现场尺寸如果要出现，必须使用真实测量结果或保留“待确认”。
- **关键画面**：
  1. 老周先拿款式册或看餐桌，再停下来询问摆放位置。
  2. 纸笔记录家庭空间信息。
  3. 椅子拉开、人员通行和桌边活动的现场演示。
- **场景设置**：门店实木餐桌椅区域，纸笔和手机即可完成，不需要顾客或演员。

### 4️⃣ 脚本结构
**教知识·解题型**：

- **场景难题**：只带“我想看某种款式”到店，往往无法判断餐桌放回家后是否方便使用。
- **放大危机**：桌子摆得下，不代表椅子能顺利拉开；看起来合适，也不代表家人进出方便。
- **低成本解决**：到店前先把家里的摆放位置、已有尺寸和通道情况记录下来。
- **具体步骤**：
  1. 拍下准备摆放餐桌的位置。
  2. 记录旁边固定柜体、墙面或通道。
  3. 测量能够实际测量的空间，工具测出的数字再记录。
  4. 到店后先说清平时谁使用、是否经常待客。
  5. 现场把椅子拉开并模拟通行，再看款式。

### 5️⃣ 结尾行动指令
“准备买餐桌的，带着家里的摆放信息到店里再看。”

### 6️⃣ 执行要点
拍摄时必须标注“常见咨询情境演示”。手机一台、纸笔和店内餐桌椅即可。若需要展示尺寸，使用卷尺等合适工具实测；不要用手机大小代替测量，也不要给出统一预留厘米数。收声重点录清老周的提问和操作步骤。

### 7️⃣ 成交理由
- **体现的理由**：专业强——先问家庭空间，再让用户现场验证。
- **转化路径**：观看→准备尺寸→到店试摆

## 选题6：布艺沙发试坐，坐一下和坐明白不一样

**承接**：取自方向6“布艺沙发试坐，坐一下和坐明白不一样”，以及“进店坐一下、看一眼颜色就准备定”的错误示范和“坐一会儿、靠一靠、起身看看活动空间”的正确过程。

**【方向】**：布艺沙发试坐，坐一下和坐明白不一样  
**【目的】**：变现型——把用户从“看颜色”引导到店内完整试坐，用现场体验承接咨询。  
**【结尾动作】**：到店  
**【成交步骤】**：到店  
**【成交理由】**：专业强

### 🅰 打法
**36计·第15计 正确做法VS错误做法**：错误示范“坐一下、看一眼颜色就决定” → 展示可能遗漏的观察点 → 正确示范“坐一会儿、靠一靠、起身、看活动空间” → 说明不同家庭要结合真实使用习惯确认。

### 1️⃣ 爆款元素
**最差**：反人类设计的布艺沙发——不预设某款有问题，而是现场演示哪些情况需要进一步确认。

### 2️⃣ 开篇钩子
“布艺沙发坐一下就准备定，可能只看到了颜色，还没看清自己坐着合不合适。”

### 3️⃣ 内容方向及目的

- **核心内容方向**：用一套错误示范和一套正确试坐流程，拍清楚到店试沙发时应该完成哪些动作。
- **核心问题与观众价值**：观众要弄明白，试坐不是坐下拍一张照片就结束，而是要根据家里谁坐、怎么坐、活动空间如何来确认。
- **取材与内容推进**：
  1. 先由老周完成错误示范：坐下、看一眼颜色、马上起身。
  2. 字幕标注“只看颜色和第一感觉”。
  3. 重新坐下，按照正确流程完成：坐一会儿、靠一靠、起身、观察前方和侧方活动空间。
  4. 老周分别提出观察问题：“平时坐的人是喜欢靠着，还是经常坐着聊天？”“起身时是否需要借扶手？”“沙发前方是否还有走动空间？”
  5. 用新婚两口之家、家里有孩子、父母偶尔来住三个场景说明试坐重点不同。
  6. 结尾将行动落到店内体验：到店后把自己的使用习惯说清楚，再完成试坐。
- **事实边界**：错误示范是拍摄设计，不是真实顾客；不说某款沙发一定不适合某类人，也不承诺面料耐污、耐用或长期效果；试坐结论以现场动作和使用者反馈为准。
- **关键画面**：
  1. 老周坐下看颜色后立即起身的错误示范。
  2. 坐一会儿、靠一靠、起身的连续动作。
  3. 拍沙发扶手、靠背和前方活动空间，保留老周现场说明。
- **场景设置**：门店布艺沙发区，一套沙发完成完整流程，不需要真实顾客出镜。

### 4️⃣ 脚本结构
**教知识·正确做法VS错误做法**：

- **错误示范**：坐下，看颜色，拍一眼，直接准备决定。
- **指出遗漏**：没有确认坐姿、靠背、扶手和起身动作，也没有看沙发周围是否方便活动。
- **正确示范**：
  1. 按平时习惯坐下。
  2. 靠一靠，观察腰背和靠背的接触位置。
  3. 起身，确认是否顺手。
  4. 看前方和侧方活动空间。
  5. 结合家里主要使用者，再做判断。
- **原理与适用条件**：沙发是长期使用的家具，试坐要尽量接近日常动作；不同家庭的使用习惯不同，现场体验不能被一个颜色或一个动作替代。

### 5️⃣ 结尾行动指令
“准备选布艺沙发的，到店里把平时的坐法试一遍。”

### 6️⃣ 执行要点
只用手机、店内沙发完成拍摄。错误示范和正确示范用固定机位拍全身，再补拍扶手、靠背和活动空间特写。不要把演示中的错误动作说成真实顾客经历；字幕避免使用“保证适合”“一定舒服”等绝对表达。

### 7️⃣ 成交理由
- **体现的理由**：专业强——用实际试坐动作帮助用户判断。
- **转化路径**：观看→说明需求→到店试坐

- 顿悟波点：💡

**目的**：总结AB差异的根本原因

**必须包含**：
- "这就是为什么..."
- 揭示本质原因/底层逻辑
- 金句总结
- 情绪高潮：⚡

**必须包含**：
- 金句
- CTA行动指令

## 内容质量要求
- 先落实用户想拍的那条内容，不用“创新”另起节目。主问题要具体，段落之间有信息递进，关键细节来自材料或标为待核实。
- 若是比较观察，说明比较谁、哪两个阶段、每个对象使用的共同问题，以及如何保留不同回答；没有数据时不预设变化或原因。
- 若是尚未完成的采访，写主持人主问、至少两条可根据回答继续追问的问题、可拍证据、记录和剪辑顺序。受访者未知回答只写“按现场真实回答”，不编对白、采访结论、人数、经营变化或情绪。
- 流量脚本先定出发点再设计结构：站在哪类用户、围绕人货场其中一个、符合三有之一，再用爆款元素（选题或方向里写明的那个，没有就从八大元素里挑一个能落到这个人货场上的）设计整个结构：开场第一句用元素的句式说出看点，中段推进落在元素的具体事上，不只在标题里提一句。脚本结构（四大脚本、36 计）只是把它拍出来的形式
- 效果最佳优先：开头用一个清楚而有吸引力的切口，让人想看下去；中段要有信息递进或情绪起伏，结尾收在最精彩的一点上，不是流水账。起伏和反差只能来自材料里真实存在的变量（比如换上的那样东西、一句真实的回应）；要证明东西好，变的就是这家卖的东西，不是穿法、用法这类技巧。不能把一个小改动放大成整个人或整件事的转变。不为凑波点、金句硬加反转，也不改变原意。结尾按这条视频的目的给一个行动指令（流量型：关注或评论；人设型：关注或看主页；变现型：私信、到店、留资选一个）；只有用户明确说不要结尾指令时才不加。
- 人物的反应、对白和动作只写材料里有的；材料没写的反应（犹豫、没急着定、皱眉、惊讶）不补，画面只写镜头拍得到的动作。小改动只说它改了画面上的哪一处（领口、袖口、靠垫的位置），不推到人的气质、状态或整个人。
- 任何创作都必须符合现实的生活逻辑，有说服力才行。创作的来源只能是现实中真实存在、大多数人认可的事，不凭空编造。下面三类说法一律不写（括号里的例子只说明是什么类型，不是清单，类似的说法同样不写）：
- 太离谱：一件事改变整体、判若两人、几天就见效的保证（比如「收腰就能换风格」「换个头像粉丝就翻倍」「同一件外套两种人」「换个招牌字体，营业额就翻一番」）
- 太简单：一招搞定、一句话让客户当场签单、躺着就能赚（比如「一句话让客户当场下单」「躺着月入过万」）
- 太不科学：违背常识或没有依据的因果（比如「喝某种水就能瘦」「敷一下就能消炎」）
一件事能带来的变化，要有它真实的条件、过程和代价。反差和看点要来自生活或镜头里看得见的具体变量，不靠硬切换人设、身份或结果。拿不准能不能成立，就写清楚前提和做法，不替事实下结论。一个小细节（一种做法、一个动作、一句话、一处调整）只能改变它直接作用的那一处，不能写成它让整件东西、整个人或整家店都变了。结论的范围也要和证据一样大：一次现场的反应只说明这一次，不能推成普遍的道理（比如一位客户换了靠垫说舒服，就说挑沙发都要试靠垫）。
- 主角是这个号卖的东西（这条管变现型，以及任何要做对比、前后变化的内容）：观众看完要觉得「是这家的东西（或手艺）让人变好看、变好用、变好吃」，而不是学会一个技巧就不用来买了。
- 流量型也遵守对比变量规则：不是每条都要对比，但只要做反差、对比或前后变化，变的是卖的东西，人、场和动作保持一致；不为了满足规则把每条都拍成商品对比。流量型仍以用户感兴趣的看点为主，不硬推卖点
- 要做对比、反差、前后变化，变的那一样必须是这个号在卖的东西，其他条件不变：同一个人（同一个空间、同一桌人）先后用两样东西——这家卖的，和普通的、旧的或常见的——前后差别看得见，才证明是东西好。例：同一个人先后穿两套衣服，前后两种风格；同一个客厅换两张沙发；同一个人戴两副镜框
- 不做「同一件东西换个穿法、搭法、摆法、用法、吃法」的对比：卖的东西没变，差别只能归功于技巧，证明不了东西好，也给不出来买的理由
- 卖的就是手艺或服务的（剪发、验光、装修设计、厨师的做法），手艺本身就是货：同一个人剪前剪后、同一份食材我们的做法和普通做法，这类对比成立
- 穿法、搭法、用法这类技巧只能顺带一句，不能当一个方向或一条内容的看点；人设型可以以人为主角，但做对比时仍遵守上面的变量规则
- 数值标准（尺寸、坐深、厘米、区间、比例、时长标准）只能用原始材料或档案里有的；没有依据就写成【待测量】或改成问题，不许用「行业常识」「通用标准」「一般来说」来写具体数字。
- 已确定的开头与用户锁定原句逐字保留；没有用户资料支持的事件不能写成“我已经问了/走访了”。不要预写老板回答。
