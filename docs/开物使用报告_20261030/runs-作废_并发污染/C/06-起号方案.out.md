# 🚀 起号方案

## 📌 先说结论

- **建议主攻：第1计·反向操作。**它能把已定的王牌栏目《一块料到一件家具》直接拍出来：先掠过成品，再把镜头带进自家木工工坊看木料和制作节点。主要看点是“家具店不先拍成品，先带你看它从哪儿来”，不需要编顾客故事，也不用多人配合。
- **备选：**
  1. **第36计·冷知识**：第1计的开头和工坊画面有人停留，但用户对“看木料”还缺具体认知时切换；每条讲清一个真实可见的木料或制作细节。
  2. **第10计·情境还原**：收到真实的家具选购问题时切换；老周自己演示如何确认需求，不假装有顾客在场。
  3. **第15计·正确做法VS错误做法**：某个判断标准已由老周确认、能在现场演示时切换；不做未经证实的材料结论。
- **明确不做：**
  1. **第35计·街头采访**：档案没有采访搭档和外拍安排，无法确认能稳定拍到真实受访者。
  2. **第30计·角色扮演**：没有已确认的搭档，也不能让店员扮顾客；多人剧情会增加执行成本，还容易把真实经营现场拍成虚构剧情。
- **多久能看出跑没跑通：**先按既定比例发布，观察“零粉到一千粉、流量稳定”这条参考线。以连续作品的非关注播放、完播、主页访问和有效咨询一起判断，不凭一两条视频下结论；具体多久不能预先保证。

> **执行前提：**已确认老周本人、自家木工工坊和门店。团队人数、拍摄设备、每周可拍时段没有提供；以下按“老周一人、一部手机可完成”设计，不把店员、顾客或额外设备当作必要条件。

## 🧮 起号期内容配比

### 起号期：流量型45% / 人设型25% / 变现型30%

按已定比例执行，不另行调整。家具是长决策商品，起号阶段要有陌生人能看懂的工坊画面，也要让用户认识老周，并从第一周开始留出空间说明实木家具和布艺沙发怎么选。

- **流量型45%：人货场 + 爆款元素。**  
  出发点：县城家庭买家具，通常先看到展厅里的成品；老周把镜头从成品转进工坊，呈现一块木料到家具之间真实存在的制作过程。  
  爆款元素：**反差**。  
  形式：第1计·反向操作，配“晒过程·火车节”的“起因—关键节点—成品回看”。  
  结尾只用一个行动指令：**评论“你买家具先看款式还是先问材质？”**

- **人设型25%：真实经历 + 老周的具体做法。**  
  出发点：让人记住做家具12年的本地老板老周，不靠形容词，不把年限说成结论。  
  形式：四大脚本“聊观点·观点立场”或“讲故事·平凡英雄型”，只拍真实发生过的工坊判断、咨询或沟通。  
  **待确认：**目前没有具体事件可用。先问老周：“最近一次你提醒顾客先别急着选家具，是在什么情况下？你当时具体看见了什么、做了什么？”没有真实事件前，不拍成既成事实。  
  结尾只用一个行动指令：**关注老周，看工坊里真实发生的事。**

- **变现型30%：人货场 + 一个真实成交理由。**  
  出发点：用户有实木家具或布艺沙发的选购问题；让他看见“自家有木工工坊、木料可现场看”，或看见老周如何回应“沙发怎么挑不踩坑”。  
  成交理由：实木家具对应“自家工坊、木料可现场看”；布艺沙发对应“能回应顾客常问的挑选问题”。具体面料标准、沙发性能等没有提供，不能先替老周下结论。  
  形式：实木家具用“晒过程·火车节”；布艺沙发用“教知识·解题型”，先呈现老周实际确认的使用需求，再拍真实试坐或看面料过程。  
  结尾只用一个行动指令：**带上家里尺寸，到店看料试坐。**

### 过线之后

达到“零粉到一千粉、流量稳定”这条参考线后，再逐步增加有真实事件支撑的故事和观点内容；继续保留实木家具与布艺沙发的变现内容。比例调整不预设具体数字，先依据非关注播放、主页访问、咨询和到店来源复盘。起号期内，仍以工坊过程作为稳定视觉入口，避免账号变成只拍木料或只答沙发问题。

### 和已定内容定位怎么对上

主攻打法落在《一块料到一件家具》：工坊过程既是老周稳定能拍到的现场，也是实木家具内容的视觉入口。布艺沙发不从账号内容里消失，按既定配比持续回答真实的试坐、面料和家庭使用问题；没有具体素材或判断标准时，先向老周核实，不用猜测补齐。

## 🎯 主攻打法：第1计·反向操作

### 为什么是你能拍的

- 老周是家具店老板本人，能在自家木工工坊出镜，不需要临时找演员。
- 档案确认店里卖实木家具，且木料可以现场看；“从成品转进工坊看木料”有真实地点和物件支撑。
- 不需要顾客出镜，也不需要多人配合；手机固定拍摄、老周边走边讲即可。设备情况未提供，先按手机拍摄安排，不假设已有灯光或摄影器材。
- 主看点不是“木料一定更好”，而是工坊里的木料和成品之间有可拍的前后过程。是否同一块木料对应某件成品，必须先核实；不能对应时，不用“从这块料做成这张桌子”的说法。

### 结构公式

**常规A（先看展厅成品）→ 反向B（转身进入自家工坊看木料或制作节点）→ 回到成品或停在真实工序，收住一个明确问题。**

### 配什么脚本讲

**第1计·反向操作 + 晒过程·火车节。**

这一计负责片子里发生什么：先从成品切入，再反向带到工坊现场。四大脚本负责讲清楚过程：交代“今天拍的是什么”→拍木料或制作节点→回到对应成品（确认对应关系后再说）→留一个问题给观众。

这样补上的不是未经证实的木料优劣结论，而是让观众看见自家工坊和木料现场。若该条作为流量型发布，不讲卖点、不引导到店；成交理由留给变现型内容讲。

### 前3条具体拍什么

1. **《家具店老板，为什么不先带你逛展厅？》（反差）**  
   拍摄要点：先给展厅成品一个短镜头；老周转身走进自家工坊，说：“今天先不逛成品，我带你看工坊里这块木料。”接着拍木料近景和老周指认的真实细节。结尾问：“你买家具先看款式，还是先问材质？”  
   **停留点：**家具店老板先不讲成品，反而把镜头带进工坊。

2. **《一张实木餐桌，进漆房前长什么样？》（反差）**  
   拍摄要点：先确认能否拍到同一张桌子进漆前的真实状态；能拍到，就拍未上漆状态、制作节点和同一张成品。不能确认同一件对应关系，就改成展示“工坊里一张桌子的当前制作节点”，不做前后对比。  
   **停留点：**观众能看到餐桌在成为成品前的真实样子。

3. **《新房餐桌进场前，工坊里先发生了什么？》（人群）**  
   拍摄要点：用餐桌的真实制作或检查节点开场，画面跟着老周的手部动作走；旁白只讲当天实际拍到的步骤，不添加没有核实的工序。结尾问：“你家选餐桌时，最先想确认什么？”  
   **停留点：**把“新房要买餐桌”这个具体家庭场景，接到工坊真实过程上。

### 边界

- 不把不同木料说成同一件家具的前后状态；做前后呈现必须确认是同一件成品、对应同一块料。
- 不因为画面反差就下“木料更好”“成品更耐用”之类结论，除非有可核实依据。
- 不安排假顾客、假咨询或假的现场反应。
- 不把展厅或工坊的拍摄过程包装成“所有家具店都怎样”。只讲老周当天拍到的事实。

## 🔄 备选打法（3计）

### 备选一：第36计·冷知识

- **什么情况下切过去：**第1计已经能稳定拍出工坊画面，但观众看完仍不知道“这块木料具体能看什么”时，切到单条知识解释。
- **怎么套：**每条只拿一块真实木料或一个真实制作节点，让老周指出一个经确认、能在镜头里看见的细节。
- **配哪个四大脚本结构：**教知识·拆解型——先提一个容易忽略的问题，再展示细节和说明判断范围，最后说到店看料时可以问什么。  
  **待确认：**具体木料辨认标准，先问老周：“顾客站在木料前最常问什么？你会指着哪里解释？这个判断有哪些条件？”

### 备选二：第10计·情境还原

- **什么情况下切过去：**顾客常问的具体问题积累到足以回答，或出现可公开拍摄的真实咨询时切换。未获授权，不拍顾客、不暗示是真实顾客在场。
- **怎么套：**老周自己展示一种“常见咨询情境”，明确说明是情境演示；围绕尺寸、家庭使用需求或沙发挑选问题，拍老周实际会问什么、怎么检查。
- **配哪个四大脚本结构：**教知识·解题型——具体问题→先确认条件→展示确认过程→给出适用范围。  
  **待确认：**布艺沙发的面料、坐感判断标准；先问老周：“顾客问沙发怎么挑不踩坑时，你通常会先确认哪三件事？每一项怎么现场看或试？”

### 备选三：第15计·正确做法VS错误做法

- **什么情况下切过去：**老周能给出一项明确、可重复演示的检查方法，并确认它适用的条件时切换。
- **怎么套：**同一个人、同一个空间、同一件商品，先演示一个容易漏掉的检查动作，再按老周确认的方式演示；不把未经证实的做法说成“错”。
- **配哪个四大脚本结构：**教知识·拆解型——提出误区→现场示范→解释适用条件→给观众一个可执行的检查动作。  
  **待确认：**先问老周：“顾客挑实木餐桌或布艺沙发时，有哪一步经常漏掉？你能用店里的商品现场示范吗？”

## 🧪 怎么测

- **一次只改一个核心变量：**第一轮固定第1计·反向操作、固定工坊拍摄方式和结尾评论指令，只测试“开头第一镜头／第一句话”。不要同时改题材、时长和剪辑节奏。
- **每计测几条：**每种打法至少测3条；样本不足时只判断单条执行，不判定打法无效。总体继续按45% / 25% / 30%配比，不为了测试一计而连续发同一种目的。
- **看什么指标：**
  - 流量内容：非关注用户播放占比、前段流失、完播、分享、新粉。
  - 人设内容：主页访问、关注、评论里是否有人回应老周本人。
  - 变现内容：是否出现本地用户的家具问题、私信或到店咨询，以及用户是否提到视频来源。
- **什么信号算这计行：**相同主题连续测试后，非关注用户愿意停留，且主页访问、关注或评论里出现与木料、工坊、家庭选家具相关的反馈；不能只凭某一条播放高就判定有效。
- **什么信号算换掉：**连续测试出现曝光有但前段流失明显，先重写开头；前段留得住但完播差，删掉重复说明、提前回到成品或制作节点；有播放但主页访问低，强化《一块料到一件家具》的系列承诺。完成这些单变量修正后，仍无改善，再切到冷知识或情境还原测试。

## 📅 30天节奏

每周可拍次数没有提供，下面先按**每周两次集中拍摄、每周发布3条**做最低限度排期；这是执行假设，不代表已知团队产能。老周一人用手机拍摄，不安排顾客必须出镜。每周按约2条流量型、1条人设型或变现型轮换，使一个月大体贴近45% / 25% / 30%，月底按比例核对，不为凑数编故事。

| 阶段 | 任务 | 交付物 |
|---|---|---|
| 第1周 | 在工坊集中拍第1计素材；发出首批测试内容；同时向老周核实一条真实经历和布艺沙发判断标准 | 3条成片；1份待核实问题答案；首轮数据记录 |
| 第2周 | 延续第1计，只改开头变量；把实木家具和布艺沙发内容交替安排 | 3条成片；开头版本记录；评论问题清单 |
| 第3周 | 若有已核实的木料判断，测第36计；若出现真实咨询或授权素材，测第10计；没有素材就不硬拍 | 3条成片；备选打法至少一轮测试；本地咨询来源记录 |
| 第4周 | 根据数据保留有效系列；对流失点做单变量修正；核对两类产品是否都有持续出现 | 3条成片；月度复盘；下阶段保留的2个有效模式 |

如果实际只能每周拍一次，就把当周素材集中拍完、按实际产能减少发布量；不以牺牲真实记录或硬编事件来补条数。

## 📊 跑不通先查哪里

| 现象 | 先怀疑什么 | 下一步做什么实验 |
|---|---|---|
| 工坊视频曝光少 | 开头只对家具从业者有意义，普通家庭用户没听懂看点 | 保持第1计不变，把第一句话改成新房、换房家庭能听懂的问题；连续测3条 |
| 开头有人停，但完播差 | 进工坊后只是连续拍木料，没有说明观众接下来要看什么 | 固定主题，只调整中段：先交代这次要看的一个真实制作节点，再拍过程，最后回到对应成品 |
| 播放有，主页访问或本地咨询少 | 工坊画面成了纯观赏内容，实木家具和布艺沙发的内容关联不足 | 保持工坊流量内容不加销售引导；另发变现内容，分别拍“木料可现场看”和“沙发挑选问题”，记录用户是否提到视频来源 |

**最后的执行边界：**主攻先拍第1计，不把37计逐个试一遍。老周的真实故事、木料判断、沙发面料标准，当前资料都不足以替他写成具体事实；先用上面的问题向老周核实，再决定对应的人设或知识内容是否开拍。
