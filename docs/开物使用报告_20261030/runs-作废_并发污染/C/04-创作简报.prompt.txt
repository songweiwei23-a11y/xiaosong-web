## 🔍 先说这一行

- **归口**：本地实体店，属于 **D 家居家电类**，主业是家具零售，兼有自家工坊的生产与展示能力。  
  这不是纯装修号，也不是全国发货的电商号。账号的核心任务不是讲泛家装知识，而是让县城本地准备置家的人，愿意来店里看实物、看木料、试坐布艺沙发。

- **这行的钱怎么赚**：  
  家具不是靠低频冲动消费赚钱，而是靠一笔相对集中的“大件决策”成交。实木家具的成交，通常取决于材质是否看得懂、尺寸是否合适、做工是否让人放心；布艺沙发则更容易卡在面料、坐感、清洁维护、家庭成员使用习惯。  
  真正的成本不只在货本身，还包括门店陈列、库存占用、配送安装、售后沟通。获客最难的地方在于：用户刷到视频时往往还没准备买，但等他真要买时，可能只记得当时哪个老板讲得明白、东西看得见。

- **客人的决策链路**：  
  这不是看完视频当天就下单的行业。大多数人会经历：准备装修或搬家 → 量尺寸 → 网上看款 → 问家人 → 到几家店比较 → 看材质、试坐、问价格 → 回家再商量。  
  决策时间通常是数天到数周，遇到装修进度、婚期、搬家日期等节点才会明显加速。所以账号不能只等“今天就买”的客户，要提前在本地用户心里占一个位置。

- **时间规律**：  
  我推测，春秋装修与婚嫁置家阶段、节假日前后、交房集中期，都是家具咨询更密集的时候；日常则常见于周末和晚饭后，夫妻或家庭成员有时间一起刷视频、讨论家里要添什么。  
  **待确认**：本地交房高峰、婚嫁旺季、门店周末到店规律，需要老周用实际接待记录补充。

- **这行老板普遍会犯的错**：  
  最常见的自嗨，是拍一整排家具、配上“质量好、价格实在、款式多”。问题是县城家具店都能这么说，用户看完仍不知道：这张桌子为什么值得看、这套沙发适不适合自己家、老板能不能把话讲明白。  
  这家店目前有一个没被充分利用的优势：**自家工坊和木料现场可看**。如果只拍成品陈列，这个优势等于没拍。

- **同行现在都在拍什么**：  
  同行常拍门店全景、家具合集、到货视频、促销字幕、报价口播。大多数没效果，不是家具不够多，而是视频前几秒没有给用户一个“我为什么要看下去”的问题。  
  这个号的空档在于：不把家具当静态商品拍，而是把“木料、制作、试坐、家庭选择”拍成看得懂的现场过程。

## 🗣 我会先问老板的几个问题

- **问题**：最近一次顾客对家具不满意，具体是因为什么？当时顾客说了哪句话，店里怎么处理？  
  - **我的推测**：家具大件售后常见于尺寸理解偏差、颜色与现场光线不同、送装过程磕碰、坐感与预期不同。这个问题能找到老周真实的处理方式，而不是只说“售后很好”。  
  - 待老板确认。

- **问题**：店里有没有明确不卖、不接、不建议顾客买的货？是发生过哪件事后定下来的？  
  - **我的推测**：老周做了12年家具，应该有一些“我宁可少卖，也不建议你这样买”的边界，例如尺寸不合适、家庭使用场景不匹配、预算与需求明显冲突。这个边界比“专业”更能立人设。  
  - 待老板确认。

- **问题**：最近一位回头客是谁？他第一次买了什么，后来为什么又回来？  
  - **我的推测**：回头客不一定是再次购买，也可能是带亲戚朋友到店。要问清他回来时说的原话，才能知道顾客真正认可的是木料、坐感、服务过程，还是老周讲得明白。  
  - 待老板确认。

- **问题**：顾客进店问得最多的一句话是什么？老周通常怎么回答？  
  - **我的推测**：实木家具大概率会问“这是什么木头”“会不会开裂”；布艺沙发大概率会问“耐不耐脏”“坐久了会不会塌”。这些高频问答就是最稳定的变现内容素材。  
  - 待老板确认。

- **问题**：这个月店里发生过什么小事？一位顾客、一块木料、一台机器、一次送货，完整经过是什么？  
  - **我的推测**：工坊每天都有切料、打磨、组装、搬运、选料等真实过程。账号不缺素材，缺的是把一件小事讲成“用户看完有收获”的角度。  
  - 待老板确认。

- **问题**：真正的差异化是什么——顾客为什么选这里，而不是别家？请说顾客的原话。  
  - **我的推测**：老板以为的差异化可能是“自家工坊”；顾客感受到的可能是“能看到木料，买得心里有数”“沙发能坐能试，不是只看图片”。必须以顾客原话为准，否则内容容易自说自话。  
  - 待老板确认。

## 六维地基

### 1. 人设定位

- **原料在哪**：  
  真材料是：“老板老周”“做家具12年”“本地人”“自家有木工工坊”“现场看木料”。  
  这些不是“专业、靠谱”一类的空词，而是能反复拍到的事实：老周能站在工坊里拿起木料讲，能在门店让顾客试坐布艺沙发，能把一件家具从原料到成品的过程摊开讲。  
  “专业”翻译成行为，不是说“我很懂家具”，而是“这块木料在这，桌子做到哪一步，客人能看见”。

- **人设标签句**：  
  **在工坊里讲家具的老周**

- **用了哪个入口**：  
  **特殊经历 + 痛点+职业**。  
  12年家具从业经历，是持续可讲的职业积累；“买大件怕看不懂、怕买错”是本地家庭的真实痛点。

- **验证**：  
  这个人设立得住，因为老周不是靠一次性故事撑着，而是每天都有工坊、木料、家具制作和顾客咨询作为证据。  
  验证动作很简单：镜头里能不能反复出现“老周拿起一块料、站在工坊、讲清一个选择”。能持续出现，标签才不是硬贴。

- **在同类账号里的位置**：  
  同城家具账号常见人设是“老板报价型”“门店导购型”“促销主播型”。  
  老周不抢“喊价格”的位置，抢的是“让我先看明白再决定”的位置。差异不在话术，而在于有工坊、有木料可拍，能把静态家具拍成真实过程。

- **证据链**：  
  1. 工坊里的一块木料如何进入制作流程；  
  2. 老周现场回答顾客常问问题；  
  3. 同一空间试摆不同尺寸家具时，尺寸差异如何影响使用；  
  4. 布艺沙发让真实到店顾客试坐后的反馈。  
  第3、4项必须基于真实顾客和真实现场，不安排摆拍评价。

- **边界**：  
  不说“全县最便宜”“什么木头都一样”“买了就不会出问题”这类绝对话。  
  不贬低同行，不拍“别人不行、我家才行”的对立戏。老周的人设应是讲清选择条件，而不是替用户下武断结论。

### 2. 用户定位

- **一句话画像**：  
  **正在装修、准备结婚或刚换房的县城家庭，家里人都要参与挑家具，最怕花一笔钱买回去尺寸不合、材质看不懂、沙发坐着不舒服。**

- **主攻人群**：  
  **小镇青年 + 精致妈妈。**  
  小镇青年正处在结婚置家、买房搬家阶段，对餐桌、沙发等大件有刚性需求；精致妈妈更关注一家人的日常使用、安全感、清洁维护和空间是否好打理。  
  这两类人能覆盖“新婚置家”和“换房家庭”两个真实需求场景。

- **为什么不是另一批**：  
  不优先服务纯探店打卡的Z世代，也不把银发族当内容主攻对象。不是他们不买家具，而是账号起步阶段要先抓决策更集中、使用场景更明确、愿意到店细看的家庭客户。  
  也不服务“只想网上问个最低价、不愿量尺寸、不愿到店看实物”的人群。家具是高决策商品，靠一条视频远程解决所有问题不现实。

- **他们心里真正在想什么**：  
  “我不是不会看家具，我是怕我现在觉得好看，搬回家才发现不合适。”  
  “卖家具的人都会说好，我就想知道这东西放到我家、给我家人用，到底行不行。”

- **决策链路**：  
  刷到老周的工坊或问答视频 → 关注、翻主页看他是否持续讲得明白 → 装修或换房节点临近时想起账号 → 带着尺寸和预算到店 → 看木料、看实物、试坐布艺沙发 → 回家与家人商量 → 成交。  
  所以内容不能只做一次性促销，必须让用户多次刷到同一个可信的人和现场。

- **什么时刻会想起你**：  
  交房后量完尺寸、婚期临近、旧沙发坐感变差、父母要来住、准备搬新家、周末和家人逛家具店前。

- **他在平台上搜什么**：  
  “县城实木餐桌怎么选”  
  “布艺沙发怎么选不踩坑”  
  “附近家具店”  
  “实木家具看什么”  
  “沙发面料怎么选”  
  “新房家具尺寸怎么留”

### 3. 内容定位

- **长期提供什么价值**：  
  **让本地家庭把实木家具、布艺沙发看明白再买。**

- **内容方向**：  
  采用 **多元四类打底 + 工坊看料做王牌栏目**。  
  不做完全单一主题，因为家具购买决策不只看木料，还涉及尺寸、坐感、家庭使用场景和老板是否可信；但“工坊看料”必须成为稳定栏目，避免内容散成普通家具店日常。

- **为什么不选纯单一主题**：  
  只围绕“木料辨认”拍，容易吸引对木材感兴趣的人，却不一定覆盖准备买布艺沙发的家庭；只拍“工坊制作”，也会忽略顾客最常问的沙发问题。  
  所以用工坊建立辨识度，用知识、过程、真实问答覆盖两个经营品类。

#### 当前阶段配比

- **作用配比：流量型45% / 人设型25% / 变现型30%**  
  这是起号期更适合的比例。账号目前粉丝少，首先要让陌生本地用户刷到并停下；但家具决策长，不能只追播放，必须从一开始就有变现内容，让用户知道到店后能获得什么。  
  人设型保留25%，因为家具属于低频高客单决策，用户会先判断“这个老板值不值得信”。

- **流量型45%：以过程型、反常识知识型为主**  
  拍木料、工坊机器、家具制作中的可见反差，以及“买家具前很多人先看错了什么”。  
  流量内容只负责让陌生人停下，不讲促销、不强调卖点、不催到店。  
  - 实木家具位置：木料未上漆、制作过程、尺寸与空间的可见差异。  
  - 布艺沙发位置：同一家庭使用场景下，用户常见误区和真实试坐问题。

- **人设型25%：以真实故事、观点型内容为主**  
  拍老周做家具12年里形成的判断和边界，但只能讲真实发生过的事。  
  例如【待确认真实事件后拍】：为什么有些钱老周不建议顾客花、一次顾客回头带亲友来的经过、他在工坊里坚持亲手看的一步。  
  不把“12年”当口号，要拍成一件件具体行为。

- **变现型30%：以晒过程、解题知识型为主**  
  变现内容每条只讲一个成交理由。现阶段已确认可用的成交理由是：**自家工坊、木料可现场看**。  
  - 实木家具位置：带顾客看木料、看制作节点、看尺寸匹配。  
  - 布艺沙发位置：围绕“沙发怎么挑不踩坑”，拍真实试坐、面料触感、家庭使用需求确认；具体判断标准需在前采后补全，不能凭空说某种面料一定更耐用。

- **题材配比：主赛道75% / 目标人群兴趣25%**  
  75%围绕家具购买、实木餐桌椅、布艺沙发、工坊过程；25%围绕新婚置家、搬家、父母来住、孩子活动空间等家庭生活场景。  
  原因是只讲家具知识容易变成行内内容，而家庭置家话题更容易让本地用户代入。

- **主力形式**：  
  档案没有“历史数据最好的内容类型”，不能假装已经验证。  
  起步阶段建议暂定 **视频配音Vlog式晒过程** 为主力形式，原因不是它一定数据最高，而是自家工坊是现成场景，老周不需要靠复杂口播撑住前几秒。连续测试后，再根据完播、评论和主页访问决定是否强化“木料辨认”或“沙发问答”。

#### 每类内容管哪一段路

- **刷到**：流量型。用工坊现场、反向操作、反常识问题，让陌生用户停下来。  
- **记住**：人设型。让用户知道这不是普通导购，而是“在工坊里讲家具的老周”。  
- **信**：变现型。让用户看到木料、工坊、试坐和判断过程，而不是只听口头承诺。  
- **联系**：变现型。用户带着尺寸、需求和预算到店，现场看料、看实物、试坐后再谈选择。

#### 三种视频各怎么拍

**流量型**

- **四大脚本**：  
  方向：买实木餐桌时，很多人先看颜色，老周先给看未上漆木料。  
  结构：教知识·拆解型——反常识开篇 → 看木料的现场动作 → 为什么成品颜色不能代替看料 → 留问题。  
  结尾行动指令：**评论区说说，你买家具先看款式还是先问材质？**

- **起号36计**：  
  **第1计·反向操作：** 常规拍成品家具 → 老周先把镜头带进工坊看木料 → 展示从原料到成品的变化。  
  事件核心是“家具店不先拍家具成品”，不是硬塞促销。

**人设型**

- **四大脚本**：  
  方向：老周做家具后形成的一条真实边界。  
  结构：聊观点·观点立场——真实经历 → 老周的判断 → 当时为什么这么做 → 关注。  
  待确认：必须先拿到一件真实事件，不能编“拒绝顾客”的故事。  
  结尾行动指令：**关注我，慢慢讲家具店里的真事。**

- **起号36计**：  
  **第7计·一句话设定故事感：** 老周在工坊检查一块木料 + “这块料今天不进客户家，原因我得跟他讲明白。”  
  之后讲真实缘由和沟通结果。没有真实事件，不拍。

**变现型**

- **四大脚本**：  
  方向：顾客问“实木餐桌怎么选”，老周带他从木料看到成品；或顾客问“布艺沙发怎么挑”，现场确认家庭使用需求后试坐。  
  结构：晒过程·火车节——顾客带着问题进店 → 看关键步骤 → 得到适配建议。  
  结尾行动指令：**带上家里尺寸，到店看料试坐。**

- **起号36计**：  
  **第10计·情境还原：** 顾客要选餐桌或布艺沙发 → 老周现场问清空间和使用人数/习惯 → 纠正不适配的选择 → 让旁观用户看懂判断过程。  
  成交理由落在“木料现场可看、工坊过程可见”，不夸大为“看了就不会买错”。

#### 配比核验

1. **流量型是否匹配账号阶段：是。** 起号期流量型45%为最大块，符合0-1000粉需要先拿陌生曝光的现实。  
2. **主力形式是否为已验证数据类型：否，待验证。** 档案没有历史数据；先用工坊过程做低成本样片测试，不把推测当结论。  
3. **大流量是否占主力：是。** 流量型45%，且围绕工坊、木料、家具使用场景设计看点。  
4. **是否给目标人群兴趣留出内容：是。** 25%题材进入新婚置家、换房、家庭生活场景。  
5. **每个数字是否有依据：是。** 作用配比按已定方案执行；形式按现有工坊资源、长决策链路和两个品类的不同问题拆分。

#### 第一条该发什么

- **选题**：《家具店老板，为什么不先拍成品，先拍一块木料？》  
- **目的**：流量型。  
- **打法**：起号36计·**第1计 反向操作**。  
- **事件**：镜头先对准门店里一张成品餐桌，老周把镜头转向工坊里未上漆的木料：“大多数人进家具店先看款式，我先带你看它从哪来的。”随后拍切面、纹理、制作现场，最后回到成品桌。  
- **为什么首发它**：这条不要求老周长篇口播，工坊画面本身就有可看性；也能在第一条就让用户知道，这家店和只拍展厅的家具店不一样。  
- **结尾**：**你买家具，会先看成品还是先问木料？**

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：视频配音Vlog为主，辅以老周近景口播。工坊有天然过程画面，先用手、木料、机器、成品承接注意力，再由老周讲一句判断，比全程站在展厅口播更自然。

- **在哪拍**：工坊拍木料和制作；门店拍实木家具与布艺沙发试坐；避免长期对白墙或只拍整齐陈列。

### 5. 风格调性（只给结论，≤200字）

- **正向匹配**：选择正向匹配。老周、工坊、木料、门店应统一成“县城本地、实在、看得见”的气质，不做浮夸剧情反差。  
- **气质关键词**：朴实、明白、现场感。  
- **会说的一句话**：“这套好不好，别急着听我说，先看它用在你家哪儿。”  
- **不会说的一句话**：“这款谁买谁赚，错过就没了。”  
原因是家具购买需要缓慢建立信任，催促和夸张会破坏老周“讲明白”的位置。

### 6. 变现定位（只给结论，≤250字）

- **卖什么 + 客单价区间**：实木家具、布艺沙发；客单价区间待确认，不能凭行业印象编写。  
- **成交路径**：抖音本地内容触达 → 用户看主页建立认知 → 私信/到店咨询 → 现场看木料、看实物、试坐 → 家庭商量 → 成交。  
- **最缺的信任证据**：顾客为什么认可“现场看料”和“自家工坊”，以及布艺沙发从需求确认到试坐选择的真实过程。

## 🧠 记忆点设计

   重复方式：每条与实木家具相关的视频，开头三秒让木料先入镜。

2. **场景：工坊门口或工作台前开场**【待验证】  
   不必每条都在同一机位，但要保留木工台、木料堆、工具声等真实背景。  
   原因：这是店里最难被同行复制的视觉资产，也是“自家工坊”最直接的证据。

3. **语言：固定一句“先别急着挑款，先看这一步”**【待验证】  
   适用于实木家具和布艺沙发的讲解开头，表达的是“先理解，再选择”的账号立场。  
   后续看评论区是否有人主动复述；没人提，就不强行保留。

## ⚡ 差异化：A + 变量B

### 1. 展厅家具合集 + 工坊换场景

- **常规A**：同行拍展厅全景、家具成套展示、字幕标价。  
- **变量B**：情境类的“换场景”。从成品展厅切进工坊原料区。  
- **A+B长什么样**：  
  先拍餐桌成品，再切到同类木料的工坊画面，老周讲“这张桌子先不说好不好看，先看它从哪一步开始。”  
  服务目标用户的原因：用户买大件想知道“看起来差不多，到底差在哪”，工坊能提供可见证据。

### 2. 沙发口播讲知识 + 情境还原

- **常规A**：导购站在沙发前讲“面料好、坐感舒服”。  
- **变量B**：行为类的“情境还原”。  
- **A+B长什么样**：  
  还原真实顾客进店场景：一家人坐沙发，老周先问“家里谁坐得最多、有没有孩子、平时会不会在沙发上吃东西”，再根据真实回答带着试坐。  
  服务目标用户的原因：用户不是只想听参数，而是想知道“我家这种情况该怎么选”。  
  前提：必须是顾客同意拍摄，或由老周和店员明确演示“常见咨询情境”，不能伪装成真实顾客。

### 3. 家具避坑口播 + 反向操作

- **常规A**：上来讲“三个家具避坑点”。  
- **变量B**：行为类的“反向操作”。  
- **A+B长什么样**：  
  别人带用户先看成品颜色和款式，老周先让镜头看木料、桌腿连接、坐垫支撑等可拍细节，再回到成品。  
  服务目标用户的原因：降低“我完全不懂家具”的焦虑，也避免纯术语口播让用户划走。

## ⚠️ 这个号最大的风险

1. **把工坊当背景，不把工坊拍成证据。**  
   自家工坊是核心资源，但如果只是远景扫一下，用户仍然不知道它和自己买家具有什么关系。每次进工坊都要回答一个用户问题：这一步影响什么、用户到店能看什么、为什么要看。

2. **布艺沙发内容被实木家具压住。**  
   木料和工坊画面天然更好拍，实木家具容易成为主角；但店里同时卖布艺沙发，必须稳定补足“试坐、面料、家庭使用场景”的内容。否则用户会误以为这只是卖木桌木椅的账号。

# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

家具店卖的不是一件“看着不错”的货，而是一笔家庭大件决策。实木家具和布艺沙发都存在同一个特点：顾客在线上先形成印象，真正成交多数发生在到店看实物、带着家人讨论之后。

这行主要靠**单笔客单**，不是靠高频复购。一个新婚家庭、换房业主，可能一次把餐桌椅、沙发等大件一起看完；但买完后短期内通常不会重复购买。因此，获客成本卡在两件事上：

1. **用户还没到购买节点时，先记住你。**  
   家具决策常常跟着交房、装修、婚期、搬家走。等顾客真要买时，刷到过、讲得明白、能看到实物的店，更容易进入他的备选名单。

2. **到店后消除“怕买错”的顾虑。**  
   实木家具，顾客会看材质、做工、尺寸是否适配；布艺沙发，顾客会关心坐感、面料、日常使用习惯。门店如果只讲“款式多、价格实在”，顾客还是会继续去下一家比较。

我推测，县城家具消费的咨询高峰通常会跟着春秋装修、交房、婚嫁置家、节假日前后的家庭聚集需求出现；到店沟通更容易集中在周末和晚饭后。**待确认：本地交房时间、门店周末客流和婚嫁旺季。**

同行最常见的自嗨，是拍一排家具、加价格字幕、说“质量好”。这类视频没效果，不是货不够，而是用户没有得到一个明确答案：**这张桌子放我家行不行？这套沙发适不适合我家人用？我进店能看到什么？**

老周这家店真正能拉开差别的，不是“有家具”，而是有两个可拍、可验证的现场：  
- 实木家具能进工坊看木料；  
- 布艺沙发能到店真实试坐、按家庭使用场景沟通。  

**一句话定位：县城老周带你看实木家具、布艺沙发，买前看料试坐。**

## 变现全景

### **现在能卖什么**

1. **实木家具**  
   重点可落在实木餐桌椅等家庭高频使用家具。顾客需要看到木料、结构、尺寸和成品之间的关系。

2. **布艺沙发**  
   顾客购买时，更需要结合家庭成员、使用频率、空间大小和日常习惯来试坐、判断。

3. **到店选购服务**  
   这不是单独收费项目，而是促进成交的过程服务：顾客带尺寸到店，老周带着看木料、看实物、试坐布艺沙发，再讨论适配条件。

### **各自的客单价与毛利大致区间**

目前不能给出具体客单价和毛利数字。档案没有提供进货成本、工坊生产成本、配送安装成本、售价区间，也不能凭行业印象替门店编数据。

但经营上可以先按两类账来算：

- **实木家具**：材料成本 + 工坊人工 + 油漆/五金等辅料 + 门店陈列 + 配送安装 + 售后预留。  
  自家工坊的价值不只是生产，而是让顾客在成交前能看见一部分成本和制作过程，降低“看不懂材质”的顾虑。

- **布艺沙发**：采购或生产成本 + 门店样品占用 + 配送安装 + 面料、坐感与尺寸沟通带来的售后风险。  
  布艺沙发的利润不能只看标价，要把顾客因“没试坐、没量尺寸、没说清使用场景”产生的沟通成本算进去。

**待确认：**  
- 实木家具的主销价格带、单笔平均成交额；  
- 布艺沙发的主销价格带、单笔平均成交额；  
- 配送安装由谁承担、单笔平均成本；  
- 哪个品类目前成交更稳定、退换沟通更少。

### **决策难度**

两类产品都属于**高决策产品**。

- 实木家具：需要看材质、尺寸、工艺，往往还要和装修风格、家庭成员意见一起比较。  
- 布艺沙发：需要试坐、看空间比例、确认使用习惯，通常不是刷到一条视频就立即成交。

所以短视频的任务不是“让人立刻下单”，而是让本地准备置家的用户，在需要看家具时愿意先想到老周这家店。

## 主推产品

### **主推：实木餐桌椅所在的实木家具线**

原因不是它一定更贵，而是它最适合账号起号阶段建立信任。

1. **自家工坊的优势，能先在实木家具上拍透。**  
   木料、切面、纹理、加工、连接结构、成品，这是一条完整的可视化链路。用户能看见，视频就不只是在嘴上说“材质好”。

2. **实木家具能承担账号的“第一记忆”。**  
   老周拿着木料，在工坊里讲一张餐桌从哪里开始，这个画面比展厅扫一圈更容易被记住。

3. **实木家具能把用户带进店，再承接布艺沙发。**  
   顾客进店看实木家具时，本来就会同步看客厅、餐厅的大件搭配；但内容上不强行把两个品类塞进一条视频，而是通过主页和门店动线承接。

### **明确不做**

- 不把“全店低价家具合集”作为主推内容。  
  原因是低价字幕带来的大多是纯比价咨询，用户只问价格、不愿看料、不愿到店，容易消耗接待时间。

- 不把布艺沙发拍成“哪种面料一定耐脏、哪种沙发一定不塌”。  
  目前没有对应产品参数和真实售后数据，不能替门店下绝对结论。先拍真实试坐和需求确认，再逐步沉淀可说的判断标准。

## 成交路径

### 1. 第一次接触看到什么

用户第一次刷到的，不应该是门店全景和促销海报，而是一个具体问题或现场画面：

- 老周把一块未上漆木料放到镜头前；
- 工坊里一张桌子正在制作；
- 顾客进店选布艺沙发前，先被问“家里谁坐得最多”；
- 同一个空间里，展示不同尺寸家具带来的占用差异。

**这一步会流失的人：**  
只是随手刷视频、没有家具需求、只想看娱乐内容的人。  
这是正常流失，不需要硬留。账号要的是未来有置家需求的本地家庭，而不是所有人。

### 2. 靠什么产生兴趣

靠的不是“便宜”，而是让顾客产生一个具体念头：

- “原来实木家具不是只看成品颜色。”  
- “我家这种情况，选沙发前还真得先想清楚谁用、怎么用。”  
- “这老板不是只让我买，他会先问我家实际情况。”

这里对应的是**认知变化 + 信任变化**。用户开始愿意翻主页，不一定马上咨询，但会把老周放进“以后看家具可以去看看”的名单。

**这一步会流失的人：**  
只想网上拿最低价、不给尺寸、不愿到店看实物的人。  
家具大件不适合把全部判断压在一段私信里，接待时要提前筛选。

### 3. 在哪里沉淀

沉淀重点放在：**抖音主页 + 到店。**

主页要完成三个回答：

1. 老周是谁：做家具12年、在工坊里讲家具；  
2. 店里卖什么：实木家具、布艺沙发；  
3. 到店能得到什么：看木料、看实物、试坐后再做选择。

私信可以作为预约和初步沟通入口，但不建议把私信做成远程报价台。更适合引导用户先准备：

- 家里尺寸；  
- 需要放家具的区域照片；  
- 家里使用人数；  
- 对实木家具或布艺沙发更优先的需求。

**这一步会流失的人：**  
主页内容混乱、看不出卖什么的用户；以及咨询后迟迟没有明确需求的人。  
解决办法不是催单，而是把“带尺寸到店看料试坐”说清楚。

### 4. 临门一脚是什么

临门一脚不是一句“今天下单有优惠”，而是让家庭决策真正落地：

- 实木家具：顾客现场看木料、看成品、确认尺寸是否适合；  
- 布艺沙发：顾客本人及主要使用者到店试坐，确认空间和使用需求；  
- 家庭成员意见不一致时，建议把尺寸、照片和需要比较的问题带回家商量，再约下一次到店。

**这一步会流失的人：**  
尺寸不清楚、家庭意见没统一、预算与需求不匹配的顾客。  
这些不是靠强推能解决的。老周要做的是把“不适合的原因”讲明白，减少买回去后再后悔的情况。

| 实木餐桌椅的连接、边角、桌腿等细节 | 专业、做工判断 | 待现场确认 | 勘察时找到最适合近拍的结构细节，由老周讲一个判断点 |
| 顾客带尺寸到店选家具的过程 | 专业、需求匹配 | 待积累 | 顾客同意后拍；不方便出镜时，只拍尺寸纸、家具和老周讲解 |
| 布艺沙发真实试坐过程 | 真实、产品体验 | 已具备场地，素材待积累 | 拍不同坐姿、家庭成员试坐、老周问需求的过程；不编顾客反馈 |
| 顾客常问“沙发怎么挑”的真实问答 | 专业、沟通能力 | 已确认高频问题 | 先录老周自然回答，整理出真实说法后再拍 |
| 配送安装或到货检查过程 | 服务、结果 | 待确认是否可拍 | 先确认配送是否自做、能否拍摄、客户是否同意 |
| 回头客或转介绍的真实原话 | 结果、口碑 | 待确认 | 前采时找出一位真实顾客，获得授权后记录原话；没有就不拍 |

当前最缺的不是“更多产品视频”，而是两类证据：

1. **顾客为什么愿意相信现场看料。**  
   需要真实顾客说出感受，而不是老周替顾客总结。

2. **布艺沙发怎么从需求到试坐做选择。**  
   目前只知道顾客常问“怎么挑不踩坑”，还不知道老周具体会问什么、怎么排除不适合的选择。必须先录一段真实接待过程。

## 变现型内容怎么排

### **变现型内容占比：30%**

这个比例与已确定的账号地基一致。

起号期流量型内容要占最大块，先让本地陌生用户刷到；但家具是长决策商品，变现内容不能等涨粉以后再拍。30%的变现内容，能让用户从一开始就知道：老周不是只拍工坊，而是能带着看实木家具、试坐布艺沙发、解决置家时的实际选择问题。

建议前12条样片中，安排约4条变现型内容：  
- 2条实木家具；  
- 2条布艺沙发。  

这样不会让实木家具压住布艺沙发，也不会让主页看起来像纯工坊号。

### 方向一：顾客带尺寸来选实木餐桌椅

- **对应成交路径**：到店咨询 → 确认尺寸 → 看木料和实物 → 缩小选择范围。  
- **成交理由**：木料可现场看。  
- **先给的价值**：让用户知道，买餐桌前只看款式不够，尺寸和摆放空间要先确认。  
- **画面重点**：尺寸记录、门店实物、工坊木料、老周对应讲解。  
- **不做什么**：不演“顾客一进店就立刻买下”，真实咨询可能要回家商量。

**四大脚本拍法：晒过程·火车节**  
顾客带着尺寸进店 → 老周确认摆放区域和使用人数 → 看餐桌尺寸与实物 → 带到工坊看木料 → 给出适配范围。  

**起号36计拍法：第10计·情境还原**  
事件是：顾客先看中一张餐桌，老周没有马上推荐，而是先问空间尺寸和使用人数，再带他看木料、看实物，说明为什么有些尺寸不适合直接定。  

**结尾行动：到店**  
“带上家里尺寸，到店看料再选餐桌。”

---

### 方向二：布艺沙发怎么按家庭情况试坐

- **对应成交路径**：产生兴趣 → 到店试坐 → 家庭共同决策。  
- **成交理由**：实物可看、可试坐，按使用场景沟通。  
- **先给的价值**：让用户明白，挑沙发先问“谁用、怎么用”，比只问颜色更靠前。  
- **画面重点**：老周提出真实问题、顾客试坐、沙发细节、空间比例。  
- **待确认**：老周真实的问诊顺序、店内不同沙发对应的具体适配条件。

**四大脚本拍法：教知识·解题型**  
场景难题：“家里要买沙发，光看颜色总怕搬回去不对。” → 放大问题：家里人坐得最多、日常习惯不同 → 现场先问需求再试坐 → 总结到店前要准备的X项信息。  

**起号36计拍法：第15计·正确做法VS错误做法**  
事件是：先演示只看外观、没有试坐就决定的常见做法；再演示到店先说家庭使用习惯、让主要使用者试坐、再看空间的流程。  
注意：这里只对比选择流程，不承诺哪种沙发一定适合所有家庭。

**结尾行动：到店**  
“想选布艺沙发，带家里人来试坐。”

---

### 方向三：一块木料最后会变成什么

- **对应成交路径**：第一次产生信任 → 翻主页 → 到店看料。  
- **成交理由**：自家工坊、木料现场可看。  
- **先给的价值**：把“实木家具看什么”从抽象词，变成用户看得到的原料和制作节点。  
- **画面重点**：同一块木料、工坊动作、半成品、成品餐桌椅。  
- **注意**：只讲老周确认无误的材质和制作事实；不把未确认的木材特性说成结论。

**四大脚本拍法：教知识·拆解型**  
反常识开篇：“看实木餐桌，别只盯着上完漆的颜色。” → 拿出同类未上漆木料 → 展示它进入制作的一个节点 → 回到成品，说清到店能看什么。  

**起号36计拍法：第22计·行业避坑**  
事件是：用户只按成品颜色判断餐桌 → 老周把镜头带进工坊，拿出对应木料 → 提醒“颜色只是最后看到的一层，先看料和做工更有依据” → 告诉用户到店可看哪些位置。  
表达上不攻击同行，只讲用户自己怎么判断。

**结尾行动：到店**  
“想看实木家具，来店里先看料。”

---

### 方向四：顾客问“沙发怎么挑不踩坑”，老周先问哪几句

- **对应成交路径**：私信或评论咨询 → 到店试坐 → 缩小选择范围。  
- **成交理由**：老周能把需求问清，再让顾客看实物、试坐。  
- **先给的价值**：用户到店前先整理自己的需求，减少“看了一圈还是不知道选哪个”的情况。  
- **待确认**：这X个问题必须来自老周真实接待过程，不能由编导替他编成标准答案。

**四大脚本拍法：教知识·案例引入**  
用真实咨询开场：“顾客问我沙发怎么挑，我没有先说哪款好。” → 老周问出真实的X个问题 → 解释每个问题影响什么 → 现场试坐和看实物。  

**起号36计拍法：第17计·互联网嘴替/替网友做**  
事件是：从评论区或私信选一个真实问题“家里准备换布艺沙发，该先看什么” → 老周在店里按真实接待步骤演示 → 告诉用户到店时带什么信息。  

**结尾行动：私信**  
“拿不准家里怎么选，先把尺寸私信给我。”

### **执行提醒**

变现内容不是“今天特价、快来购买”的硬广。每条都先完成一个用户价值：

- 看懂一块木料；  
- 知道餐桌先量什么；  
- 明白沙发为什么要试坐；  
- 学会到店前先准备哪些信息。  

然后再把行动收在一个明确入口：**到店或私信，二选一。**

## 定价与节奏

### **起步阶段怎么定价**

现阶段不建议为了短视频起号，仓促推出“超低价引流款”。

原因有三个：

1. 家具是高决策产品，极低价格容易吸引只问价、不愿到店比较需求的流量；  
2. 实木家具和布艺沙发都涉及配送、安装、售后，低价如果没算清成本，订单越多风险越大；  
3. 老周账号的差异不是“全县最低价”，而是“让顾客到店看料试坐后再决定”。

更适合的起步动作是：

- **价格透明但不靠价格做钩子。**  
  对于已经到店、需求明确的顾客，报价要把产品、配送安装和售后范围说清楚。

- **把“到店看料试坐”作为引流动作，而非降价。**  
  视频引导用户带尺寸到店，先提升有效到店率，再看具体成交情况。

- **先做12条同标准样片，再看咨询质量。**  
  重点记录：咨询里有多少人带尺寸、有多少人问实木家具、有多少人问布艺沙发、有多少人实际到店。先知道哪类内容带来有效顾客，再考虑是否做某个具体产品的活动。

### **什么时候可以调整价格**

不能因为一条视频播放高就涨价，也不能因为当天没人咨询就降价。

可以考虑调整价格或套餐表达的依据，应来自真实经营记录：

1. 某类实木家具或布艺沙发连续出现需求，但现有报价经常被顾客认为“看不明白”；  
2. 配送安装、材料、人工等成本发生持续变化；  
3. 到店咨询中，顾客对某一类产品的需求明显集中，且成交率稳定；  
4. 售后记录显示，某些低价选择带来的沟通和维护成本过高。

**待确认：**门店当前是否统一报价、是否存在套餐、是否有配送安装收费标准。没有这些信息前，不建议设计“满减”“限时价”等活动。

## ⚠️ 风险

### 1. 只靠工坊拍实木家具，布艺沙发被边缘化

工坊、木料、机器的画面更有视觉吸引力，实木家具容易越拍越多；但店里同时卖布艺沙发，如果沙发内容长期缺失，用户会误以为这是一家只卖木桌木椅的店。

**规避动作：**前12条里固定至少4条变现内容，其中2条专门围绕布艺沙发试坐和家庭使用场景。

### 2. 把“现场看料”说成万能保证

看木料能增加透明度，但不能被说成“看了就一定不会买错”。家具最终是否合适，还受尺寸、摆放、家庭使用习惯和预算影响。

**规避动作：**每次讲木料，都同时说清它只解决什么问题；比如“这一步帮助你看材质，不替代量尺寸和现场试坐。”

### 3. 私信很多，但到店和成交少

家具短视频容易吸来大量“多少钱”“能不能发图”的泛咨询。如果主页没有明确告诉用户卖什么、怎么到店、到店前带什么，接待会被无效问价占满。

**规避动作：**主页和视频结尾统一一个动作：实木家具引导“带尺寸到店看料”，布艺沙发引导“带家里人到店试坐”；私信只做初步筛选，不替代现场成交。

# 💎 内容定位方案

## 长期价值主张
**让县城家庭把实木家具、布艺沙发看明白再买。**

## 内容方向：多元四类还是单一主题
**选：A 多元四类打底 + B 王牌栏目。**

- **A打底**：家具是长决策商品，用户不只关心木料，还会问尺寸、坐感、面料、清洁、家庭成员使用习惯。只拍工坊，布艺沙发会被忽略；只拍沙发问答，又浪费了工坊这个现场资源。
- **B王牌栏目**：做《老周带你看一件家具从料到家》。工坊里的木料、制作节点、成品家具，是老周每天真实能拍到的素材，也能自然连到实木家具的成交。
- **为什么不纯做单一主题**：单一主题要求稳定发生同一种有看点的事件。当前已确认工坊过程稳定，但布艺沙发的真实顾客试坐、面料问题、家庭使用场景还没有素材库支撑，暂时不能把全号押在一个栏目上。
- **为什么不完全多元散发**：新号如果今天拍木料、明天拍促销、后天拍无关日常，用户记不住。必须用“工坊看料”做稳定视觉入口。

## 内容配比

### 作用配比

| 作用 | 占比 | 为什么 |
|---|---:|---|
| 流量型 | 45% | 起号期需要先让本地陌生用户刷到。工坊、木料、家具大件进入家庭前后的反差，具备停留点；流量内容不推销，只负责让人认识老周。 |
| 人设型 | 25% | 家具不是看完就买，用户会先判断老板是不是讲得明白、有没有边界。老周做家具12年、本地人、在工坊出镜，是建立信任的真实基础。 |
| 变现型 | 30% | 不能等有流量才讲产品。实木家具要让用户看见木料和工坊，布艺沙发要让用户看见试坐与需求确认，用户才会愿意带尺寸到店。 |

**切换条件：**先按45%/25%/30%发满12条同标准样片。若连续出现工坊流量内容能带来稳定非关注播放、主页访问，且私信或到店咨询开始出现“看了视频来问”的来源，再把流量型调至40%、变现型调至35%。如果流量内容有播放但主页访问低，不加变现比例，先重做开头和系列承诺。

### 形式配比

| 形式 | 占比 | 负责哪种作用 | 为什么 |
|---|---:|---|---|
| 晒过程 | 40% | 流量型、变现型 | 工坊是现成现场。木料、切料、打磨、组装、试坐比展厅扫一圈更有画面，也能让“自家工坊”变成看得见的证据。 |
| 知识 | 30% | 流量型、变现型 | 用户已有明确问题：实木家具怎么看、布艺沙发怎么挑不踩坑。知识内容要落到一块料、一处连接、一次试坐，不做空泛清单。 |
| 故事 | 20% | 人设型、变现型 | 只讲老周真实经历、真实顾客咨询和真实工坊小事。家具大件需要长期信任，但当前缺具体故事素材，先留20%，不能硬编。 |
| 观点 | 10% | 人设型 | 用来讲老周的选择边界，例如什么情况他会提醒顾客先别急着选。必须先拿到真实事件，不能把“12年经验”说成口号。 |
| 段子 | 0% | 不作为固定形式 | 当前未确认老周是否擅长表演，也没有多人剧情资源。起号阶段不拍粗糙情景剧，避免为了热闹把账号做成泛娱乐。 |

**主力形式判断：**档案没有历史数据，不能说哪种形式已经验证有效。先以“配音Vlog式晒过程”作为测试主力，不是因为它数据一定更高，而是工坊每天都能拍、老周口播压力低、画面能直接证明经营现场。

### 题材配比
- **主赛道75%**：实木家具45%，布艺沙发30%。  
  实木家具承担工坊、木料、制作过程；布艺沙发承担试坐、家庭需求、面料与日常使用问题，不能长期缺席。
- **目标人群兴趣25%**：  
  1. 新婚置家：餐桌怎么容纳一家人、客厅怎么留活动空间；  
  2. 换房搬家：旧家具何时该换、尺寸怎么提前量；  
  3. 家庭生活：孩子活动、父母来住、日常清洁与耐用需求。  

原因是用户买的不是一张桌子或一套沙发，而是新家里一家人怎么坐、怎么吃饭、怎么待客。

### 配比核验
1. **流量型和阶段匹配：是。**45%是最大块，符合0-1000粉阶段先拿陌生曝光的需要。  
2. **主力形式是已验证类型：否，但有硬理由。**没有历史数据，只能先用工坊过程做低成本测试。  
3. **大流量内容是否占主力：是。**围绕木料、工坊、家庭置家场景设计人货场和反差。  
4. **是否给目标人群兴趣留出位置：是。**25%进入新婚、换房、家庭生活场景。  
5. **每个数字是否有依据：是。**作用比例按既定方案；形式比例按可拍资源和家具长决策链路安排。

## 三种视频怎么拍

### 一、流量型
**拍什么方向**
1. 家具店不先拍成品，先拍一块未上漆木料；  
2. 新房看着够大，餐桌或沙发一进场，活动空间为什么会变。

**四大脚本（薛老师）**
- **教知识·拆解型**：反常识开篇“看餐桌别急着看颜色”→拍木料切面、纹理、制作现场→说明成品颜色不能替代看料→抛问题。  
  示范：《买实木餐桌，为什么我先让你看没上漆的料？》  
  一句话怎么拍：成品餐桌开场，镜头立刻转进工坊，老周拿起木料讲“它进漆房以前长这样”。
- **晒过程·任务挑战型**：任务是“把一张桌子从木料拍到能摆进家里”→选料、加工、成品三个关键节点→回到成品。  
  可叠加元素：**反差、成本**。

**起号36计（小黄）**
- **第1计·反向操作：**同行常规先拍展厅成品→老周反过来先带镜头进工坊看木料→回到同类成品，让用户看到变化。  
  示范：《家具店老板，为什么不先带你逛展厅？》  
  一句话怎么拍：先扫过展厅一秒，老周转身推开工坊门：“这张桌子先不急着看，先看它从哪儿来。”
- **第36计·冷知识：**反常识结论“成品颜色看不出木料原本的样子”→拿未上漆料和成品对应展示→说明用户到店该看什么。  
  示范：《一张实木桌子上漆前，原来是这个样子》  
  一句话怎么拍：用同一块料和对应成品做前后镜头，不评价优劣，只让用户看见差异。

**结尾行动指令：**评论区说说，你买家具先看款式还是先问材质？

### 二、人设型
**拍什么方向**
1. 老周做家具12年后形成的真实判断：什么情况不建议客户急着买；  
2. 工坊里一块料、一次返工、一次沟通，让用户看见老周如何做选择。

**四大脚本（薛老师）**
- **聊观点·观点立场：**真实经历→“我不建议你急着定”→当时看见了什么、为什么这样判断→收住观点。  
  示范：《做家具12年，我不建议没量尺寸就先定餐桌》  
  一句话怎么拍：老周站在工坊工作台前，用一件真实咨询事件讲“客户带来的尺寸和餐桌需求为什么对不上”。  
  **待确认：必须补到真实事件才能拍。**
- **讲故事·平凡英雄型：**普通工坊一天→发生一件需要老周判断的小事→具体动作验证→一句感悟。  
  可叠加元素：**人群、反差**。

**起号36计（小黄）**
- **第7计·一句话设定故事感：**老周检查一块木料→一句真实困境“这块料今天先不往下做”→解释判断依据与处理结果。  
  示范：《这块料今天先停下，不是因为做不出来》  
  一句话怎么拍：只拍真实发生的停工、检查、沟通，不安排顾客反应。
- **第4计·借物喻人：**一块木料从粗糙到成型→老周讲自己做家具这些年形成的一个判断→落到“先看明白，再决定”。  
  示范：《一块木料没处理前，别急着下结论》  
  一句话怎么拍：边打磨边讲一个真实职业感悟，不出现促销信息。

**结尾行动指令：**关注老周，慢慢讲工坊里真实发生的事。

### 三、变现型
**拍什么方向**
1. 顾客带着户型尺寸来选实木餐桌椅，老周带他从尺寸、木料到成品逐步看；  
2. 顾客问“布艺沙发怎么挑不踩坑”，老周先确认谁坐、怎么用、是否有孩子，再安排试坐。

**四大脚本（薛老师）**
- **晒过程·火车节：**顾客带问题进店→量尺寸、看木料、看成品→给出适配范围。  
  示范：《带着家里尺寸来，餐桌别先挑款式》  
  一句话怎么拍：真实顾客同意拍摄时，记录老周先看尺寸再带看桌子的过程；无授权则用店员演示“常见咨询情境”。
- **教知识·解题型：**家庭难题“沙发好看但怕不耐用”→说明只看外观的风险→问使用人数、孩子、清洁习惯→试坐与面料确认。  
  示范：《家里有孩子，布艺沙发进店先问这件事》  
  一句话怎么拍：镜头跟着老周完成“问需求—试坐—确认”的真实流程。  
  **待确认：具体面料判断标准需由老周补充。**

**起号36计（小黄）**
- **第10计·情境还原：**顾客想选餐桌或布艺沙发→老周问空间和使用习惯→纠正不适配的选法→旁观用户看懂判断逻辑。  
  示范：《两口之家选餐桌，老周先问的不是预算》  
  一句话怎么拍：用真实咨询或明确标注的常见情境演示，不能伪装成随机顾客。
- **第15计·正确做法VS错误做法：**先演示只看款式的选择方式→说明可能忽略的尺寸或使用问题→展示到店如何看木料、怎么试坐→讲适用条件。  
  示范：《布艺沙发别只坐一下，试坐要看这一步》  
  一句话怎么拍：同一个人、同一套沙发，分别做短暂试坐和按家庭习惯试坐的演示，不夸大一次试坐的结论。

**结尾行动指令：**带上家里尺寸，到店看料试坐。

## 内容系列（3个）

### 系列一：《一块料到一件家具》
**一句话讲清：**老周用一块真实木料，带你看它怎么变成家里的实木家具。

- **出发点：**站在准备新婚置家、换房添家具的小镇青年和精致妈妈；围绕“货”——木料与实木家具；满足“有兴趣”和“有用”；以**反差**放在开场和结构里：粗糙木料与成品家具前后对应。
- **定量 / 变量：**定量是“原料开场—工坊节点—成品回看”；变量是每集换一件真实家具或一个制作节点。
- **用哪套打法：**36计系列，**第1计·反向操作**。
- **目的和结构：**流量型；常规先拍展厅成品→反过来先进工坊看料→回到成品。结尾统一评论。
- **观众变化：**认知变化。
- **变量自检：**变量是：不同实木家具、不同木料或不同工坊节点。看点不是挑选技巧，而是用户平时看不到的“货从哪里来、怎么变成成品”。
- **前10集标题：**  
  1.《一张实木餐桌，进漆房前长什么样？》（反差）  
  2.《椅子还没装起来前，先看这一堆木料》（反差）  
  3.《展厅里的实木桌，工坊里从这一步开始》（反差）  
  4.《同样是一块木料，为什么先看切面再看颜色？》（反差）  
  5.《餐椅做出来以前，靠背先经过哪一步？》（人群）  
  6.《木工工坊今天做的，不是摆件，是一家人的餐桌》（人群）  
  7.《新房餐桌进场前，工坊里先发生了什么？》（人群）  
  8.《一块没上漆的木料，和成品桌差得有多远？》（反差）  
  9.《老周今天拿的这块料，后来会放进谁家的餐厅？》（人群）  
  10.《家具店不先拍展厅，先拍工坊里的这块料》（反差）
- **立项检验：**一句话能讲清；用户想追看下一集，是想知道下一块料会变成什么家具；实木餐桌椅、柜类及制作节点可持续扩展；全部在自家工坊真实记录；看过程的人正是未来会到店看实木家具的人。前10集使用了反差、人群两类元素，后续补成本类题材，例如“做一件家具要经过哪些看得见的步骤”，避免长期同一句式。

### 系列二：《沙发坐进去以前》
**一句话讲清：**每集还原一个真实家庭选布艺沙发时会遇到的问题。

- **出发点：**站在换房家庭、精致妈妈；围绕“人”——不同家庭成员的使用需求；满足“有用”；以**人群**放在标题和开场，先圈定“有孩子”“父母同住”“常待客”等场景。
- **定量 / 变量：**定量是“家庭情况—老周提问—试坐或看面料—适配建议”；变量是每集换一个真实家庭需求。
- **用哪套打法：**四大脚本系列，固定为“教知识·解题型”；可叠加**第10计·情境还原**。
- **目的和结构：**变现型；难题→容易忽略的条件→现场确认→试坐建议。结尾统一到店。
- **观众变化：**信任变化。
- **变量自检：**变量是：不同家庭成员、不同客厅需求、不同布艺沙发。看点不是教用户换摆法，而是让用户看见卖家具的人怎么确认“这套适不适合你家”。
- **前10集标题：**  
  1.《家里有孩子，选布艺沙发先别只看颜色》（人群）  
  2.《父母偶尔来住，沙发试坐不能只坐X秒》（人群）  
  3.《两口之家选布艺沙发，客厅空间先看哪儿？》（人群）  
  4.《经常在沙发上吃东西，进店先问面料还是坐感？》（人群）  
  5.《客厅不大，布艺沙发别一眼只看“大气”》（反差）  
  6.《家里常来客人，沙发座位怎么留才够用？》（人群）  
  7.《布艺沙发试坐时，老周为什么让你靠一会儿？》（反差）  
  8.《同样是布艺沙发，家里有宠物先确认什么？》（人群）  
  9.《新婚置家选沙发，别把“好看”当成唯一条件》（反差）  
  10.《换房买沙发前，先把一家人的使用习惯说清》（人群）
- **立项检验：**一句话讲清；不同家庭都会想知道“我家这种情况怎么选”；变量能覆盖家庭结构、空间、使用习惯与不同布艺沙发，足够延展；顾客授权后拍真实过程，未授权则明确标注“常见咨询情境”；内容自然承接布艺沙发到店试坐。前10集有人群、反差两类元素，后续可加入成本类问题，如“预算有限先保留哪项需求”，但不能替用户虚构价格。

### 系列三：《老周今天先不急着卖》
**一句话讲清：**老周用当天真实发生的一次判断，讲清买家具前为什么要先把条件问明白。

- **出发点：**站在怕买错大件、又担心导购只催成交的本地家庭；围绕“人”——老周的职业判断；满足“有共鸣”；以**反差**放在标题：家具店老板不先推荐，而是先提醒一个条件。
- **定量 / 变量：**定量是“当天真实问题—老周怎么判断—做了什么—结果”；变量是每集换一个真实咨询、木料检查或家具匹配问题。
- **用哪套打法：**四大脚本系列，固定为“聊观点·观点立场”或“讲故事·平凡英雄型”。
- **目的和结构：**人设型；真实事件→老周判断→具体动作→感悟。结尾统一关注。
- **观众变化：**情绪变化。
- **变量自检：**变量是：不同真实咨询事件、不同顾客需求或不同工坊判断。看点不是挑选技巧，而是一个家具老板在具体事情里的边界和做法。
- **前10集标题：**  
  1.《今天这张餐桌，老周没让顾客立刻定》（反差）  
  2.《这块料先停下来，老周要再看一眼》（反差）  
  3.《顾客问能不能直接送，老周先问了家里哪儿》（人群）  
  4.《今天有人想先定沙发，老周让他回去量个尺寸》（反差）  
  5.《餐桌选得快，老周反而多问了一句》（人群）  
  6.《工坊里这一步慢一点，后面少一份麻烦》（反差）  
  7.《今天这套布艺沙发，老周先没急着推荐》（人群）  
  8.《顾客带来一张户型图，老周先看的不是款式》（反差）  
  9.《一件家具能不能进家门，工坊里先过这一关》（人群）  
  10.《做家具12年，老周现在更愿意先把话说清》（反差）
- **立项检验：**一句话成立；追看理由来自“今天又发生了什么真实判断”；只要工坊、门店每天有咨询和制作，就有持续变量；没有真实事件时宁可停更，不拿演绎冒充事实；系列不卖货，但会给“老周讲明白”的人设增加信任。前10集使用反差、人群两类元素，后续补成本话题；同一句式不连续使用超过3集。

### 第1-10条：先让用户认出“工坊里的老周”
- **目标：**测试陌生用户是否愿意停在工坊和木料画面上。

### 第11-20条：验证两个品类能否同时被记住
- **目标：**避免账号被误认成只卖木料或只卖餐桌椅。

### 第21-30条：保留有效变量，补足人设信任
- **目标：**从“有工坊的家具店”升级为“会把选择讲清的老周”。  
- **重点系列：**保留前20条数据更好的两个系列；人设型只拍已确认的真实事件。  
- **主要形式：**晒过程仍是主力；补“观点立场”“平凡英雄型”故事；变现内容继续用情境还原和正确做法VS错误做法。  
- **验收标准：**看关注、主页访问、咨询、到店来源记录。若评论只夸画面却没有本地咨询，说明工坊拍成了观赏内容，要增加“尺寸—试坐—到店看料”的承接。

## ⚠️ 不要做什么

1. **不要只拍满店家具和价格字幕。**  
   用户看完只会知道店里有货，不会知道自己为什么要来这家。工坊、木料、试坐必须成为内容证据。

2. **不要把实木家具讲成唯一主角。**  
   木料画面更容易拍，但店里同样卖布艺沙发。连续多条只拍木料，会让有沙发需求的人直接划走。

3. **不要拍夸张家庭剧情或假装随机顾客。**  
   老周的人设靠本地、工坊和真实判断建立；顾客咨询可以演示，但必须明确是“常见咨询情境”，不能拿摆拍当真实记录。

- 你认为明显不合适的，在核验里用一两句话提建议，正文仍按这个数写；和定位、简报里原来写的配比不一样时，以这里为准
- 简报「内容方向」里的**三种视频的配比**照这个数写，不照上面定位里的抄（定位可能是按旧配比写的）

## 📤 输出格式

严格按下面的小节标题和顺序输出，**标题一个字都不要改**——
各板块靠标题把简报切开，改了就读不到了。

### 1. 一句话定位
不超过30字。[身份]+[特点]+[价值]，要能让陌生人立刻知道这个号是干什么的。

### 2. 人设与口吻
分四行写，每行都要能直接指导写文案：
- **我是谁**：一句能被观众复述的人设标签。身份称呼只用人设事实卡「出镜人是谁」「和店的关系」里写的原词；卡里没写就不起称呼、不编身份，也不把别的行业或别的人的称呼套过来
- **说话什么调**：具体到语气词和句式习惯，不要写"亲切专业"这种
- **会说的一句话**：举一个真实例子
- **不会说的一句话**：举一个真实例子（这条比上一条更有用）

### 3. 说给谁听
分四行：
- **画像**：一句话，要具体到能想起某个真实的人
- **他最怕什么**：3条，每条都能直接拍成内容
- **他最想要什么**：3条
- **他会搜什么词**：写出他真会打出来的那几个词

### 4. 内容方向
分五行：
- **三种视频的配比**：照定位里定的抄，写成"流量型X%（主打什么）+ 人设型X%（主打什么）+ 变现型X%（主打什么）"——配比说的是目的，不是脚本类型
- **各自的结尾指令**：流量型要什么、人设型要什么、变现型要什么，每种只一个
- **两套打法各用什么**：四大脚本主打哪几种结构；起号36计主打哪几计（写计名，照定位里挑的来）
- **能长期挖的选题来源**：4-5个，每个举一个具体例子
- **明确不做的方向**：3条，说明为什么不做

### 5. 凭什么信你
分两行：
- **核心卖点**：2-3条，每条一句话
- **可以拍成画面的证据**：4-6条，必须是能真实拍到的东西，不是形容词

### 6. 怎么拍
分三行：
- **呈现形式**：口播/探店/Vlog/情景剧等，一句话说明为什么是它
- **真实条件**：设备、场地、一个人还是有帮手、一周能出几条
- **视觉调性**：光线、色彩、镜头稳不稳，一句话

### 7. 记忆点
2-3条。语言/动作/道具/服装/场景声音里挑，每条说明怎么重复。标明哪些还待验证。

### 8. 绝对不能说
逐条列出。包含账号自己的禁忌和通用红线（绝对化用语、承诺疗效等）。

## ✍️ 写作要求

- **每句都是指令**：能直接拿去指导写文案、起标题、排镜头。不要写"要注重…"这类空话
- **具体到能执行**：不要形容词，要具体的词、句、动作、画面
- **忠于定位**：结论必须来自上面那份定位，不要自己另起一套（事实性的年限、经历以账号档案为准）
- 人和事只写真的：人设里要让人记住的那个人、那件事，只用档案写的或前采里说的；不让店员或别人扮演顾客，不替老板编性格、经历、顾客原话。没有的，写「待确认：缺哪一条」，并给出先要问的那个具体事件。
- 任何创作都必须符合现实的生活逻辑，有说服力才行。创作的来源只能是现实中真实存在、大多数人认可的事，不凭空编造。下面三类说法一律不写（括号里的例子只说明是什么类型，不是清单，类似的说法同样不写）：
- 太离谱：一件事改变整体、判若两人、几天就见效的保证（比如「收腰就能换风格」「换个头像粉丝就翻倍」「同一件外套两种人」「换个招牌字体，营业额就翻一番」）
- 太简单：一招搞定、一句话让客户当场签单、躺着就能赚（比如「一句话让客户当场下单」「躺着月入过万」）
- 太不科学：违背常识或没有依据的因果（比如「喝某种水就能瘦」「敷一下就能消炎」）
一件事能带来的变化，要有它真实的条件、过程和代价。反差和看点要来自生活或镜头里看得见的具体变量，不靠硬切换人设、身份或结果。拿不准能不能成立，就写清楚前提和做法，不替事实下结论。一个小细节（一种做法、一个动作、一句话、一处调整）只能改变它直接作用的那一处，不能写成它让整件东西、整个人或整家店都变了。结论的范围也要和证据一样大：一次现场的反应只说明这一次，不能推成普遍的道理（比如一位客户换了靠垫说舒服，就说挑沙发都要试靠垫）。
- 主角是这个号卖的东西（这条管变现型，以及任何要做对比、前后变化的内容）：观众看完要觉得「是这家的东西（或手艺）让人变好看、变好用、变好吃」，而不是学会一个技巧就不用来买了。
- 流量型也遵守对比变量规则：不是每条都要对比，但只要做反差、对比或前后变化，变的是卖的东西，人、场和动作保持一致；不为了满足规则把每条都拍成商品对比。流量型仍以用户感兴趣的看点为主，不硬推卖点
- 要做对比、反差、前后变化，变的那一样必须是这个号在卖的东西，其他条件不变：同一个人（同一个空间、同一桌人）先后用两样东西——这家卖的，和普通的、旧的或常见的——前后差别看得见，才证明是东西好。例：同一个人先后穿两套衣服，前后两种风格；同一个客厅换两张沙发；同一个人戴两副镜框
- 不做「同一件东西换个穿法、搭法、摆法、用法、吃法」的对比：卖的东西没变，差别只能归功于技巧，证明不了东西好，也给不出来买的理由
- 卖的就是手艺或服务的（剪发、验光、装修设计、厨师的做法），手艺本身就是货：同一个人剪前剪后、同一份食材我们的做法和普通做法，这类对比成立
- 穿法、搭法、用法这类技巧只能顺带一句，不能当一个方向或一条内容的看点；人设型可以以人为主角，但做对比时仍遵守上面的变量规则
- **不编事实**：档案和定位里没有的数字、客单价、客群比例、案例、客户故事、效果承诺，一律不写；需要它的地方写【待确认】并注明缺哪一项
- **全篇控制在 1500 字以内**：这是要塞进每一次生成的，长了就是给所有板块加负担
- 不要写前言、不要复述定位、不要解释你在做什么，直接从"### 1. 一句话定位"开始
