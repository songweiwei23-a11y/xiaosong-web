## 1. 原主题、核心方向、目标人群和视频目的

- **原主题**：买沙发时，如何从木料判断沙发是否可能更耐用。主题和核心方向均由原文直接给出。  
- **目标人群**：准备买沙发、担心坐塌的人；这是根据“买沙发”“坐三个月就塌”推断。  
- **视频目的**：**变现型**。原文用“木料”“撑得住”建立专业判断，承接家具店的材料透明卖点；但原稿没有明确行动指令。  

## 2. 出发点（2026-10-29）

原文围绕的是**货**：一块决定承重表现的木料；符合“三有”里的**有用**，让用户学会看一个以前看不到的判断点。用了八大爆款元素中的**最差**和**成本**，都设计在钩子里：“坐三个月就塌”对应最差结果、金钱和搬换成本。  

## 3. 开篇钩子、脚本结构、信息递进、情绪和结尾行动

- **开篇钩子**：“最怕的不是贵，是买回家坐三个月就塌”，用到开篇36计的**损失厌恶、焦虑/危机、警告避坑**，六大钩子中的**验证解密**，以及八大爆款元素的**最差、成本**。  
- **脚本结构**：归为**教知识·解题型**：痛点“坐三个月就塌”→反认知“今天不卖沙发”→证据“把一块木头拿到镜头前”→承诺解释“为什么这块木料撑得住”。  
- **信息递进与情绪**：属于**盲盒型**，从担心坐塌，到好奇老板为什么不卖货，再到等待木料判断依据；“纹路”只是一个线索，判断标准还没说出来。  
- **结尾行动**：原文停在“我告诉你”，没有完成知识兑现，也没有咨询、到店或预约动作，变现链路断在中段。  

## 4. 能保留的创意与需要优化的问题

- **可保留**：用“坐塌”代替泛泛说“质量不好”，风险具体；“今天不卖沙发”制造反常识；把木料拿出来，契合老周自家工坊、木料可现场看的已确认事实。  
- **需要优化**：不能仅凭“纹路”就下结论，需补充【木材种类、含水率、框架结构、连接方式】等真实可核验依据；“撑得住”应改成有条件的判断，避免把材料单点说成唯一决定因素。  
- **待核实**：原稿没有说明木头的种类、木料是否用于该沙发框架、具体工艺及实际承重表现，这些不能直接当成门店经营事实。  

### 优化后的完整脚本

买沙发最怕的，不是贵。  
是刚搬回家觉得挺软，坐几个月，常坐的位置先陷下去，起身的时候还得扶一下扶手。

今天我先不讲哪款沙发好看。  
我是老周，做家具12年，自家有木工工坊。咱们先看一块木料。

很多人看沙发，只试坐两分钟。  
坐着软不软是一回事，里面的框架材料和做法，才关系到后面会不会越坐越没支撑。

你看木料，别只看纹路漂不漂亮。  
要问清楚这是什么木材、用在沙发哪个位置；再看框架怎么连接，有没有把受力的位置做扎实。

一块木料不能替整张沙发打包票。  
但买之前肯把里面问明白，能少花很多冤枉钱。

想现场看木料、看沙发里面怎么做的，来店里找老周。
