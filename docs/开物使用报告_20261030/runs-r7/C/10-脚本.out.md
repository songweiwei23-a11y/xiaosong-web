## 第1步：脚本策略卡

- **核心问题**：换房挑沙发，先看外观，还是先把“谁来坐、怎么坐、周边怎么活动”想清楚？
- **用户目的**：流量型，引发换房业主评论“家里谁坐沙发最多”。
- **目标人群**：县城本地准备换房、布置客厅的新婚家庭和业主。
- **所选形式**：对比型观察。  
  - A端：先看颜色、款式和摆出来的样子。  
  - B端：先按家里的实际使用场景试坐、换位置、走动。  
  A端不是“错误”，而是容易漏掉后续使用问题；B端是补充观察顺序。
- **材料递进**：沙发外观近景 → 老周模拟下班回家坐法 → 换位置模拟家人使用 → 站起走动看周边空间 → 回到“谁坐得最多”的评论问题。
- **事实边界**：所有坐法均为现场演示，不代表真实顾客案例，也不替观众判断哪种沙发适合所有家庭；不讲尺寸、性能、价格或保证。
- **出发点**：围绕“人”——换房后使用沙发的人｜三有：有用处、有关联感｜爆款元素：人群，开场直接圈定“第一次给换房后的客厅挑沙发的人”，中段用不同使用场景推进。

## 第2步：纯文字文案

第一次给换房后的客厅挑沙发，先想好家里平时是谁坐得最多。  

不少人挑沙发，先看颜色、款式，坐一下就准备选。  

好看要看，但只看摆出来的样子，回家才发现：你喜欢靠着坐，家里人来时要留位置，客厅还得能活动。  

这些问题，店里一眼看不全。  

换个顺序：先像下班回家那样靠着坐；再换个位置，想想家里人平时怎么坐。  

最后站起来走一圈，看看沙发周边要留给谁，再看看起身走动顺不顺。  

别只盯着正面拍出来的样子，把家里会发生的事先过一遍。  

同一张沙发，摆在店里是一种样子，放进不同的客厅，问题不一样。  

先看谁在用，再看它好不好看。  

沙发每天都要坐。  

评论：你家沙发平时谁坐得最多？

## 第3步：完整分镜脚本

### 【镜头1】0-8秒｜开场钩子
- **画面**：老周站在布艺沙发旁，先拍沙发整体，再推近到老周胸口以上近景。老周手指沙发座位。
- **台词**：  
  第一次给换房后的客厅挑沙发，先想好家里平时是谁坐得最多。
- **情绪/节奏**：语速平稳，“谁坐得最多”稍停顿，留出观众代入空间。
- **拍摄/收音要点**：手机竖拍，镜头从沙发整体推向人物；收音靠近老周，避免门店环境声盖住口播。

### 【镜头2】8-17秒｜A端：先看摆出来的样子
- **画面**：镜头扫过沙发颜色、靠垫、整体款式；老周站在旁边，用手示意沙发正面。
- **台词**：  
  不少人挑沙发，先看颜色、款式，坐一下就准备选。  
  好看要看，但只看摆出来的样子，回家才发现：你喜欢靠着坐，家里人来时要留位置，客厅还得能活动。
- **情绪/节奏**：前半段自然描述；说到“回家才发现”时放慢一点，形成第一个波点。
- **画面字幕**：  
  先看外观  
  颜色 / 款式 / 摆出来的样子

### 【镜头3】17-25秒｜A端的不足
- **画面**：老周坐到沙发上，停留片刻；镜头拍侧面，不需要表演表情或反应。
- **台词**：  
  这些问题，店里一眼看不全。
- **情绪/节奏**：短句压低语速，给后面的“换顺序”留转折。
- **拍摄/收音要点**：侧面中景，保留老周坐下的完整动作。

### 【镜头4】25-35秒｜B端：模拟下班回家
- **画面**：老周坐下后向后靠，手臂自然放在扶手或靠垫附近；镜头从中景切近景，拍清楚“坐下、靠着坐”的动作。
- **台词**：  
  换个顺序：先像下班回家那样靠着坐；再换个位置，想想家里人平时怎么坐。
- **情绪/节奏**：语速比前段更利落，“换个顺序”重读，形成第二个波点。
- **画面字幕**：  
  先想怎么坐  
  下班回家怎么坐？  
  家里人平时怎么坐？

### 【镜头5】35-45秒｜B端：从沙发站起来，看客厅活动
- **画面**：老周从沙发起身，沿沙发前方走几步；镜头后退或横移，拍到沙发与周边可见空间。
- **台词**：  
  最后站起来走一圈，看看沙发周边要留给谁，再看看起身走动顺不顺。  
  别只盯着正面拍出来的样子，把家里会发生的事先过一遍。
- **情绪/节奏**：动作和台词同步，最后一句稍放慢，强调“家里会发生的事”。
- **拍摄/收音要点**：手持横移即可，不要跑动；画面重点是“从坐到起身再走动”的连续动作。

### 【镜头6】45-52秒｜差异揭示
- **画面**：同一张沙发，剪入两个画面：  
  画面一是正面整体陈列；  
  画面二是老周坐下、换位置、起身后的广角画面。  
- **台词**：  
  同一张沙发，摆在店里是一种样子，放进不同的客厅，问题不一样。
- **情绪/节奏**：语速放稳，作为总结句落下。
- **画面字幕**：  
  先看外观  
  再想家里怎么用

### 【镜头7】52-60秒｜结尾行动指令
- **画面**：老周站在沙发旁，正对镜头；最后镜头停在沙发座位和靠背的近景。
- **台词**：  
  先看谁在用，再看它好不好看。  
  沙发每天都要坐。  
  评论：你家沙发平时谁坐得最多？
- **情绪/节奏**：前两句说得干脆，最后一句语气放松，像和观众聊天。
- **拍摄/收音要点**：结尾不加到店、私信等引导；画面保持干净，不拍顾客正脸。

## 第4步：执行与优化建议

1. **拍摄前先整理沙发周边**  
   留出老周“坐下—换位置—起身—走动”的路径，避免镜头里出现杂物，也确保动作安全。

2. **一部手机就能完成**  
   - 沙发整体：中景或全景。  
   - 坐下、靠背、换位置：侧面中景和近景。  
   - 起身走动：稍远一点的全景或横移镜头。  
   不需要演员，老周一人完成演示即可。

3. **对比画面保持同一张沙发**  
   A端和B端都围绕同一张布艺沙发展开，差别只在观察顺序：  
   - A端看正面陈列；  
   - B端看实际坐法和周边活动。  
   这样观众更容易看懂主题，没有额外变量干扰。

4. **剪辑时保留动作声**  
   老周坐下、起身、脚步移动时，可保留少量现场声音。背景音乐音量压低，避免盖过“谁坐得最多”这个核心问题。

5. **封面文案可用**  
   **换房挑沙发，先想谁坐得最多**
