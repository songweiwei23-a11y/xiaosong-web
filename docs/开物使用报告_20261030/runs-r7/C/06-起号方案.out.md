# 🚀 起号方案

## 📌 先说结论

- **建议主攻：36计·第32计 换个视角。** 老周有自家木工工坊，木料、工作台、餐桌制作过程都是真实场景；用“顾客站在工坊里看一张桌子”的视角拍，最贴合王牌栏目《老周在工坊替你先看一眼》。
- **备选：第36计 冷知识、第15计 正确做法VS错误做法、第10计 情境还原。** 主攻连续发完一组仍留不住陌生人时，按数据切换。
- **明确不做：街头采访、多人剧情。** 团队人数和搭档资源未确认，靠路人和演员撑内容，拍摄不稳定，还容易显得不真实。
- **多久能看出跑没跑通：** 每计连续测3—5条；零粉到一千粉、非关注播放和流量逐渐稳定，说明主攻方向跑通。未过线前不频繁换赛道，只改开头和同一计里的看点。

## 🧮 起号期内容配比

- **流量型45%：** 围绕“新婚、换房家庭怎么买餐桌椅和沙发”展开，主打人群、反差、成本元素；用第32计·换个视角、第36计·冷知识，配**晒过程·过程展示**；结尾只留“评论区说说”。
- **人设型25%：** 拍老周做家具12年、遇到尺寸和木料问题时怎么判断；用第7计·一句话设定故事感，配**讲故事·平凡英雄型**；结尾只留“关注”。
- **变现型30%：** 围绕实木家具、布艺沙发和门店场景，突出“自家工坊、木料现场看、沙发现场试坐”；用第15计·正确做法VS错误做法、第10计·情境还原，配**教知识·解题型**；结尾只留“到店找老周”。

过一千粉且流量稳定后，**变现型往上加一档**，补足到店看木料、试坐沙发、量尺寸的真实过程；人设型保留职业判断内容。  
这套配比对齐既定定位：流量主力喂给《老周在工坊替你先看一眼》，变现内容稳定喂给《布艺沙发到店试坐课》；形式上以晒过程和知识为主，故事、观点辅助。

## 🎯 主攻打法：36计·第32计 换个视角

- **为什么是你能拍的：** 老周本人做家具12年，有自家木工工坊，木料和制作现场每天都能拍；不需要顾客出镜，不需要店员演戏。团队和设备待确认：先用固定机位拍老周的手、木料、卷尺和工作台，缺稳定支架就先补一只。
- **结构公式：** 顾客平时看到成品餐桌 → 镜头跟着一块木料走进工坊 → 老周做一个真实检查动作 → 解释“这一步和你家餐桌有什么关系” → 留下一个家庭使用问题。
- **配什么脚本讲：** 第32计管“顾客进入工坊”的事件走向，配**晒过程·过程展示**。它补上过程解释，避免拍成只给同行看的加工流水账；流量内容不讲门店卖点、不引导到店。
- **最强看点：** 顾客看到的是一张餐桌，工坊先面对的是一块还没做成桌子的木料，这个视角反差能让正在买家具的人停下来看“原来前面还有这一步”。

**前3条具体拍什么：**

1. **《顾客看到餐桌，工坊先看的却是这块木料》**（反差）  
   拍摄要点：木料放在工作台上，镜头先拍成品餐桌一角，再切老周查看木料的动作；只讲一个观察点，结尾问“你家买餐桌先看样式还是先量位置？”

2. **《新房餐厅不大，餐桌进工坊前先问这一句》**（人群）  
   拍摄要点：老周拿卷尺站在待做餐桌旁，镜头拍桌边、椅子和通道的关系；话术落在“椅子拉开后，家里还能不能正常走路”。

3. **《同样叫实木餐桌，工坊先看的不是颜色》**（反差）  
   拍摄要点：两块木料放在同一张工作台，老周指向实际要看的位置，再回到成品桌面；不下“哪块一定更好”的结论，只说顾客到店该问什么。

- **边界：** 不讲无法现场证明的木料结论；不拍复杂术语堆砌；不把工坊加工动作硬说成所有家庭都适用的购买标准；没有真实顾客订单时，只拍日常检查，不伪造顾客咨询现场。

## 🔄 备选打法（2—3计）

### 36计·第36计 冷知识
- **什么时候切：** 第32计有播放但前3秒流失明显，说明“跟拍木料进工坊”的悬念不够，切成一句反常识结论先拦人。  
- **为什么能拍：** 餐桌、卷尺、椅子、木料都在现场，老周能用实物讲清“餐桌不是越大越好”这类家庭决策问题。  
- **怎么套：** “看着大气的餐桌，不一定适合小餐厅”→现场比划椅子拉开后的空间→说明原因→评论提问；配**教知识·解题型**。

### 36计·第15计 正确做法VS错误做法
- **什么时候切：** 布艺沙发内容评论多、但用户不知道怎么行动时，切到清晰的动作对比。  
- **为什么能拍：** 门店有布艺沙发，老周本人能演示站着看外观和实际试坐的差别，不用搭档、不用虚构顾客。  
- **怎么套：** 只看颜色和靠包→漏掉坐感、面料和家庭使用需求→试坐、按坐垫、摸面料、确认谁使用→到店；配**教知识·解题型**。

### 36计·第10计 情境还原
- **什么时候切：** 用户开始问“到店到底该怎么看”，且需要把“现场看木料”拍成具体服务时切入。  
- **为什么能拍：** 工坊、木料区、门店实物都是真实场景；顾客未授权时，老周复述常见流程，不拍成真实成交。  
- **怎么套：** “进店挑实木餐桌，第一步别急着选颜色”→老周带看木料和成品→确认家庭使用场景→到店；配**晒过程·过程展示**。

## 🧪 怎么测

- **一次只改一个变量：** 同一主题先固定场景和时长，只换开头；例如都讲餐桌通道，分别测“反差开头”和“人群开头”。
- **每计测3—5条：** 流量型看非关注播放、前段留存、完播、新粉；人设型看主页访问和关注；变现型看到店咨询和顾客是否提到短视频。
- **什么信号算行：** 同一计连续作品的非关注播放和完播不再明显下滑，评论开始出现尺寸、木料、试坐等真实问题，就继续做系列；连续测完仍前段流失，就换开头元素；有播放却没有目标用户互动，就换到备选计。

- **第4周：** 上第15计和第10计，拍试坐、看料、量尺寸的到店判断过程；交付物：下月系列排期、到店询问记录。

## 📊 跑不通先查哪里

- **现象：有曝光，但前段流失快。**  
  先怀疑第一句太像木工工艺课；下一条把“新房餐厅不大”“家里有孩子”这类家庭场景放到第一句。

- **现象：点赞有，收藏和评论少。**  
  先怀疑只拍过程、没讲用户能带走什么；下一条在结尾补一个明确动作，例如“量尺寸别漏掉椅子拉开的距离”。

- **现象：主页有人看，到店询问少。**  
  先怀疑用户只记住工坊，没看懂到店能做什么；下一条切第10计，完整拍老周带看木料或试坐沙发的真实顺序。
