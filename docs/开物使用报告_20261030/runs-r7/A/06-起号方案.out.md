# 🚀 起号方案

## 📌 先说结论

- **建议主攻：第32计·换个视角。**「下午四点开工」是已确认、能反复拍的真实场景；从一把串、一道菜或一炉烧烤的视角，拍它从备料到出品，最贴合已定王牌栏目，也不需要演员或顾客出镜。
- **备选：第31计·南北/地域差异、第15计·正确做法VS错误做法、第7计·一句话设定故事感。**只有拿到真实差异、真实操作依据或厨师亲历的具体小事，才切换。
- **明确不做：街头采访、多人剧情。**团队人数、设备和可用搭档都未确认，不能把这些当成现成资源；先不设计需要陌生人或演员配合的内容。
- **多久能看出跑没跑通：**以零粉到一千粉、发布视频流量稳定作为参考线；单条表现不下结论。拍摄频次未确认，按每周实际能完成的素材量执行，不承诺固定条数。

## 🧮 起号期内容配比

- **流量型45%：**围绕下午四点的真实备餐现场，用“成都厨师在南乐备晚饭”的场景和反差吸引陌生本地用户；主力用第32计·换个视角，结尾引导评论。
- **人设型25%：**围绕成都人、做川菜9年、来南乐半年这些已确认事实；用第7计·一句话设定故事感，讲具体经历前先问本人，结尾引导关注。
- **变现型30%：**围绕川味串串火锅、川味烧烤、川菜，突出“成都来的川菜厨师本人掌勺”这一已确认理由；用晒过程·火车节，拍真实备餐到出品，结尾引导到店。
- **过线之后：**补真实职业故事和顾客高频点单问题；若关注偏低，人设型往上加一档，若真实到店问询多但用户不清楚怎么点，变现型往上加一档。
- **和定位对齐：**主力仍是晒过程，主系列仍是《下午四点，成都厨师开始备晚饭》；串串火锅、烧烤、川菜轮流入镜，不把账号拍成只讲一元火锅。

## 🎯 主攻打法：第32计·换个视角

- **为什么是你能拍的：**确定资源只有掌勺的成都厨师、门店和每天出摊前的备餐时段；不用顾客、店员或演员配合。团队与设备未确认，因此按单人、手机、现场实拍设计，不依赖额外灯光或复杂调度。
- **结构公式：**常规备餐事件＋新POV → 新信息/情绪。落到本号就是：选当天真实在备的一样货 → 从它所在的备料台、锅边或炉边跟拍 → 拍到实际出品，呈现一顿晚饭从下午四点开始的过程。
- **配什么脚本讲：**第32计管镜头跟随对象；配「晒过程·过程展示」，补足真实过程和成品呈现。流量型不讲价格、不推到店；变现型另拍，并明确一个真实成交理由。
- **前3条具体拍什么：**
  1. 《这把串，从下午四点开始等今晚这一锅》（反差）  
     拍这把串当天真实的备料动作，再跟到下锅；最后用成品兑现“它今晚会变成什么”。
  2. 《成都厨师备烧烤，点火前这炉先拍什么》（反差）  
     只拍当天真实准备的烧烤食材、炉具和起炉过程；不宣称某一步是独家做法。
  3. 《这道川菜出锅前，下午四点先做哪一步》（人群）  
     选当天真实要做的一道川菜，拍实际准备、炒制和出锅；不补菜单、分量或价格信息。
- **边界：**不把一把串拟造成会说话或有真实经历的角色；不拿未确认的成都与南乐做法差异当事实；不摆拍顾客反应，不用虚构的前后效果。

## 🔄 备选打法

- **第31计·南北/地域差异：**当厨师提供一件亲历、可拍的成都与南乐饮食习惯差异时切换；拍同一项备餐任务和两种真实做法，配「聊观点·论证型」。差异未确认前不拍结论型标题。
- **第15计·正确做法VS错误做法：**当厨师确认某项食材处理方式及其实际影响后切换；同一厨师、同一场景，演示错误示范与正确示范，再说明适用条件，配「教知识·解题型」。只对比厨师手艺，不评价同行。
- **第7计·一句话设定故事感：**当厨师能提供一件来南乐半年间真实发生的具体小事时切换；用“成都来的川菜厨师，下午四点开始备今晚的菜”带出真实经历，配「讲故事·平凡英雄型」。待确认：请问“来南乐后，哪一次做菜或备餐让你记得最清楚？当时发生了什么？”

## 🧪 怎么测

- 同一计至少拍3条；一次只改一个变量，先固定拍摄对象与剪辑节奏，只换开头或当集品类。
- 看非关注播放、前三秒停留、完播、分享、新粉和本地评论；同时记录评论是否提到厨师、备餐或具体品类。
- 同一计连续3条前段流失或完播偏弱，先重做开头、缩短重复过程；看点仍无法兑现，再换计，不凭单条否定。

## 📅 30天节奏

- **第1周：**拍第32计样片；交付3条素材及开头、完播、评论记录。实际产能未确认，按每周可完成的拍摄量排，不为凑条数虚拍。
- **第2周：**固定一个变量测试第32计；交付复盘，确认串串、烧烤、川菜哪类现场最容易拍清楚。
- **第3周：**保留有效拍法；补一条人设内容，先采集厨师亲历事件，不编经历。
- **第4周：**按数据调整开头或品类；交付月度复盘，判断是否继续主攻第32计、是否启动备选。

## 📊 跑不通先查哪里

- **曝光少：**先怀疑开头太像普通备菜记录；下一条把“下午四点、成都厨师、今晚要备什么”放进首句和首帧，只改开头。
- **有人看但完播差：**先怀疑过程重复或结果出现太晚；删掉重复动作，把出品结果提前作为期待，再用过程兑现。
- **播放有但关注少：**先怀疑系列记忆点不足；固定《下午四点，成都厨师开始备晚饭》的栏目名，并轮换串串火锅、烧烤、川菜，不把三类缩成单一低价标签。
