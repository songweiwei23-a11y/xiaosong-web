  大码女装不是纯靠一次高客单赚钱，更依赖“买到合身后的复购”和老客转介绍。普通女装顾客可以线上看图下单，但大码女生常常卡在腰、胯、肩、袖口、长度这些实际问题上；只要第一次试到合身，后续换季、上班、聚会、接送孩子，都可能再回来。  
  这家店真正该放大的，不是“衣服多”，而是“**50码以上有可试穿款**”。这能降低顾客最担心的试错成本。

- **客人的决策链路**：  
  这类顾客通常不会刷到一条视频就立刻买。她会先看：这家尺码是不是真的够大、上身会不会勒、版型会不会显臃肿、老板会不会让人尴尬；然后可能翻主页看几条不同身形的试穿，再选时间到店。  
  决策不算特别长，但信任要提前铺。视频的作用不是替代试穿，而是让她愿意走进试衣间。

- **时间规律**：  
  春秋换季、春节前、节假日前、开学前、婚礼宴请前，通常是“需要一套得体衣服”的集中时刻；县城门店的到店高峰往往在下班后、周末和赶集/商业街人流较多的时段。

- **这行老板普遍会犯的错**：  
  第一，把衣架上挂满的货当成内容，以为“拍得多”就有人来。顾客看完只记住一排衣服，没记住自己能不能穿。

- **这个客户有没有中招**：  
  现有方向里有“穿搭教学”，需要收一收。不是不拍穿搭，而是不能把“搭配技巧”当主角；主角必须是店里真实可试穿的大码连衣裙、大码外套、大码裤装，以及换货后能看见的版型差异。

- **同行现在都在拍什么**：  
  大多数服装店账号在拍“新款到店、货号、价格、上身展示、今天穿哪套”。这类内容的问题是：没有圈定谁该看，也没有解释为什么要来这家店试。

## 六维地基

### 1. 人设定位

- **原料在哪**：  
  真材料是：“店主阿梅本人出镜”“做大码女装6年”“在本地开店3年”“50码以上可试穿”“很多大码女生在别的店买不到合身衣服”。  
  这些是事实，不是人设。  
  “专业、懂大码、对顾客好”这类词不能直接拿来做人设；要翻译成行为，才有用。这里可被验证的行为是：阿梅长期站在试衣间和货架之间，帮顾客确认“这件到底能不能穿、哪里不舒服、要不要换一件”。

- **人设标签句**：  
  **帮大码女生现场试衣的阿梅**

- **用了哪个入口**：  
  **痛点+职业**。  
  大码女生最怕的不是“不会搭配”，而是进了店却没有自己能试的码；阿梅的职业正好能解决这件高频小事。

- **验证**：  
  这个人设能立住，因为“6年做大码女装”“50码以上可试穿”都可以持续用真实试衣过程证明。  
  后续每一条不是靠喊“我懂大码”，而是靠镜头里真实出现：拿尺码、看肩背、看腰腹、看裙长、替顾客换款。只要门店日常有顾客试穿，就有持续素材。

- **在同类账号里的位置**：  
  同行常见人设是“穿搭博主型”“新款推荐型”“老板娘展示型”。问题是很多账号拍的是“我觉得这件好看”。  
  阿梅的差别应是“**不替顾客做梦，先替顾客试清楚**”。她不需要装成时尚导师，而是成为县城大码女生到店前愿意先看的试衣参考。

- **证据链**：  
  1. 顾客常问尺码问题的情境还原；  
  2. 同一位试穿者换不同店内款式的真实过程；  
  3. 阿梅讲一件货为什么留下、为什么不再补；  
  4. 老客再次进店时的真实回访故事。  

- **边界**：  
  不说“穿上立刻显瘦”“谁穿都好看”“保证合身”这类过度承诺。  
  不评价顾客身材，不拿“大码”开玩笑，也不把“胖”拍成负面标签。阿梅的表达要始终落在“试穿、合身、舒服、场景需要”上。

### 2. 用户定位

- **一句话画像**：  
  **住在县城、下班要接孩子或周末要见人，衣柜里有衣服却常因尺码不合适不想出门试衣的女性。**

- **主攻人群**：  
  **精致妈妈**与**新锐白领**。  
  精致妈妈要兼顾接送孩子、家庭聚会、走亲访友，穿衣不只想宽松，还希望得体；新锐白领有通勤、聚餐、同事见面等场景，想穿得利落但不愿反复线上退换。  
  她们共同的决策点是：先确认尺码和上身效果，再决定到店。

- **为什么不是另一批**：  
  不主攻只追热点、只想买极低价快时尚的泛年轻用户。她们对“现场试穿”的需求没那么强，容易只问价不进店。  
  也不把银发族作为账号主攻对象：并不是不能服务，而是账号的人设、镜头语言和商品展示先要围绕25—40岁女性建立清晰认知，起号期不能一开始什么人都想接。

- **她们心里真正在想什么**：  
  “我不是不想穿得好看，我是怕又进一家店，店员说有大码，结果拿出来还是穿不上。”  
  这句话不一定会直接说出口，但决定了她会不会愿意进门。

- **决策链路**：  
  刷到阿梅试衣视频 → 看评论和主页确认是否真的有大码可试 → 收藏或记住门店位置 → 路过商业街、换季、聚会前需要衣服时到店 → 在试衣间完成真实判断。  
  她通常会先观察，不会因为一条视频立刻买；因此主页前几条必须让她迅速看到不同品类和真实试穿场景。

- **什么时刻会想起阿梅**：  
  下周要参加婚礼或聚餐；换季发现去年衣服不合适；单位临时通知活动；接孩子时发现自己总穿同一套；周末逛商业街但不想再空手回家。  
  内容标题和开头要抓这些具体时刻，而不是泛泛说“微胖女生穿搭”。

- **她在平台上搜什么**：  
  “县城大码女装”“大码连衣裙试穿”“大码外套怎么选”“大码裤子实体店”“附近大码女装店”“50码女装”。

### 3. 内容定位

- **长期提供什么价值**：  
  **让县城大码女生到店前先看懂自己能试什么。**

- **内容方向**：  
  选择**A多元四类打底 + 一个单一主题王牌栏目**。  
  原因是新号还没有验证哪种表达最能吸引本地用户，不能一开始把全部内容押在单一玩法上；但门店每天有稳定试衣素材，适合用一个固定栏目建立记忆。  
  王牌栏目建议：**《这位姐姐能试哪一套》**。前提是每位出镜顾客都明确同意拍摄；若顾客不愿出镜，就只拍阿梅拿衣服、试衣间门口和衣服细节，不硬拍人。

- **当前阶段配比**：  
  - **作用配比**：流量型45% / 人设型25% / 变现型30%。  
    这是起号期合理的结构：先靠流量型内容让本地陌生人刷到，再用人设型内容消除“又是一家只卖货的店”的距离感，最后用变现型内容承接到店试穿。  
  - **流量型形式**：以共鸣观点、反差试穿、轻情境短视频为主，辅助冷知识式的尺码认知内容。原因是陌生用户首先会停在“这说的不就是我”的场景上。  
  - **人设型形式**：以真实职业故事、阿梅的判断和边界观点为主。原因是阿梅本人是这家店最稳定的信任入口。  
  - **变现型形式**：以晒过程、试穿对比、解题型知识为主。原因是“50码以上可试穿”必须通过实际过程让人看到，空口说没有力度。  
  - **题材安排**：大码女装是绝对主赛道；目标人群关心的通勤、带娃、走亲访友、聚会等生活场景占一部分。生活场景负责圈人，真实试穿负责承接到店。

- **主力形式**：  
  档案没有提供“数据最好的内容类型”，因为账号仍在起号期，**暂不能断定已有主力形式**。  
  第一阶段先集中测试“真实试衣过程”——这是现有资源里最容易持续产出、最能证明50码可试穿、也最接近成交的一种形式。连续测试后，再根据非关注播放、评论里的尺码提问、到店咨询判断是否继续作为主力。

- **每类内容管哪一段路**：  
  - **刷到**：流量型内容，用“大码女生不敢进店”“明明标大码却穿不上”等可共鸣的场景，让陌生人停住。  
  - **记住**：人设型内容，让观众知道阿梅不是只会报货号，而是做了6年大码女装、长期在试衣间解决实际问题的人。  
  - **信**：变现型内容，用真实试穿和不同货品的版型差异，让观众确认这里真的能试到。  
  - **联系/到店**：变现型结尾只引导一次到店试穿，不把关注、私信、下单全塞进去。

- **流量型怎么拍**：  
  - **四大脚本**：方向是“大码女生逛店时最怕听到的一句话”；用**聊观点·争议开篇**或**教知识·拆解型**，从“吊牌码数不等于上身空间”切入。结尾只用：**“你也遇到过这种情况吗？评论区说说。”**  
  - **起号36计**：**第1计·反向操作：**常规是先问“你穿多少码”，反向是阿梅先说“别急着报码，先看这三个位置”，再展示肩、腰、胯的实际判断过程和顾客常见反应。产品只作为画面里的货，不讲到店成交。

- **人设型怎么拍**：  
  - **四大脚本**：方向是“阿梅为什么只做大码女装”；用**讲故事·职业经历型**，前提是补齐真实起因和转折。结尾只用：**“想看阿梅每天在店里遇到的事，就关注。”**  
  - **起号36计**：**第7计·一句话设定故事感：**阿梅整理一排大码外套，开头一句“今天这位姐姐进门前，在门口站了很久”；后续必须是当天真实发生、顾客同意使用的故事，不能摆拍。

- **变现型怎么拍**：  
  - **四大脚本**：方向是“50码以上能不能试到合身的连衣裙/外套/裤装”；用**晒过程·火车节模型**：顾客担心穿不上 → 阿梅拿出同类不同版型的店内款 → 展示试穿后的实际差异 → 到店试穿。结尾只用：**“想试50码以上的，到店直接找阿梅。”**  
  - **起号36计**：**第19计·对比改造：**同一位试穿者、同一面镜子、同一场景，前后换两件不同的店内大码女装，重点呈现肩背、腰腹、裤长或裙长的可见差异，再由阿梅说清适用身形。不能拍同一件衣服换几个穿法。

- **配比核验**：  
  1. **流量型是否匹配账号阶段：是。** 起号期流量型最大，符合先拿陌生人曝光的任务。  
  2. **主力形式是否来自已验证数据：否，但有原因。** 账号未提供历史爆款数据，只能先以最接近真实门店优势的试衣过程做首轮测试。  
  3. **大流量内容是否占主力：是。** 流量型占45%，且每条必须围绕真实人、货、场设计看点。  
  4. **题材是否有人群兴趣部分：是。** 通勤、带娃、聚会、走亲访友等场景承担圈人作用。  
  5. **百分数是否只来自配比块：是。** 仅使用流量45% / 人设25% / 变现30%，其余均用主次描述。

- **第一条该发什么**：  
  **题目：**《50码以上，在县城到底能不能进店试穿？》  
  **目的：变现型。**  
  **打法：四大脚本“晒过程·火车节” + 第19计“对比改造”。**  
  事件要真实：阿梅从店内拿出一件大码连衣裙或大码外套，由一位真实愿意出镜、尺码符合的试穿者，在同一试衣镜前换两件不同版型的店内货；镜头只说清“这一件卡在哪里、另一件多出的空间在哪里”。  
  为什么第一条拍它：它一次性把“阿梅是谁、卖什么、为什么值得到店”讲清，但主目的只放在“到店试穿”。不需要制造夸张结果，真实的上身差异就够。

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：真人出镜短视频 + 试衣过程配音Vlog。阿梅不需要站在白墙前讲时尚理论，门店试衣间、货架和镜子就是最有说服力的现场。

## ⚡ 差异化：A + 变量B

### 1. 货架展示 + 情境还原

1. **常规A**：同行拍“新款到了，给大家看一圈”，镜头扫货架、报尺码。  
2. **变量B**：选择“情境还原”。因为目标用户在意的不是新款数量，而是她进店后会不会又遇到“没码”的尴尬。  
3. **A+B 长什么样**：  
   阿梅站在门口，模拟但不捏造一段高频真实对话：  
   “姐，最大多少码？”  
   阿梅不直接报数，带到货架前说：“这边50码以上能试，先别急着看款，咱们先找你肩和腰能活动开的。”  
   后面接真实可试的店内货。  
   它服务的是“怕白跑一趟”的顾客，不是为了拍段子。

### 2. 试穿展示 + 对比改造

1. **常规A**：同一件衣服换角度拍，配“显瘦、遮肉”的字幕。  
2. **变量B**：选择“对比改造”。对比变量只能是店里卖的不同衣服，人物、镜子、拍摄位置保持一致。  
3. **A+B 长什么样**：  
   同一试穿者先穿一件肩背或腰腹不适合她的普通版型，再换一件店内大码连衣裙/大码外套/大码裤装；阿梅只讲镜头里看得见的差异，例如“这一件抬手时肩背紧，那一件这里留出了活动空间”。  
   这能让目标用户判断自己为什么需要试穿，不把功劳归到搭配技巧上。

### 3. 新款推荐 + 换个视角

1. **常规A**：老板站在货架前说“今天推荐三套”。  
2. **变量B**：选择“换个视角”，从“陪朋友逛店的人”视角切入。  
3. **A+B 长什么样**：  
   镜头先拍一位顾客陪朋友进店、自己站在旁边不看衣服；转到阿梅拿出一条大码裤装说：“她本来只是陪来的，后来问我，这条腰这里会不会勒。”  
   必须是真实发生、顾客同意拍摄的事件。它服务的是那些“不敢主动试衣”的人，让她们先降低心理压力。

# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

这是 **A 本地实体店｜B 服装鞋包类** 生意，核心不是“刷到就线上下单”，而是把县城及周边有尺码困扰的女性，带到店里完成试穿和选购。

大码女装的利润不只取决于单件加价，更取决于库存周转：尺码覆盖越宽，压货风险越高；同一款进得不够深，顾客来了没码；款式进得太散，又容易卖不动。门店不能单靠低价获客，否则需要靠更高销量消化库存，而现有资料没有“低价”或“大量走货”的依据，不建议把价格战当路线。

这行更适合靠三件事赚钱：

1. **到店试穿提高成交率**  
   连衣裙要看腰腹、肩背和长度；外套要看活动空间与叠穿；裤装要看腰、臀、腿的活动感。顾客愿意进试衣间，才有后面的成交机会。

2. **一位顾客买多件，而不是只卖一件**  
   真实需求往往不是“买件衣服”，而是“上班缺裤子”“天气降温缺外套”“聚会想穿条裙子”。但是否能带出第二件，取决于顾客对尺码和试穿氛围是否放心，不能靠硬推。

3. **老客在换季和临时有场合时回来**  
   大码女装的复购，通常建立在“她知道这里有自己能试的码”上。阿梅要被记住的不是某一件爆款，而是“我不用先进门受一圈打量，能先试再决定”。

获客成本卡在一个心理门槛：很多顾客不是没需求，而是已经在别家问过“有没有我能穿的”，得到过模糊回应或直接放弃。短视频必须先替她降低“我进去会不会尴尬”的顾虑，再谈衣服。

旺季通常集中在换季、节前走亲访友、婚宴聚会、返工添置、天气突然变化时；淡时更不能只发“新品到了”，而要提前种下具体场景，例如“上班裤子总卡腿”“见亲友不知道穿哪条裙子”。  
**我推测，县城顾客的到店决策会较依赖熟人转述、看过几条视频后的信任和实际试穿；待确认：顾客主要来自商业街自然进店、老客介绍，还是抖音导航。**

**一句话定位：县城阿梅，用大码女装让女生先试再决定。**

## 变现全景

### **现在能卖什么**

现有资源下，可直接变现的不是虚构套餐，而是以下三类真实货品及其共同的到店试穿服务：

1. **大码连衣裙**  
   对应聚会、走亲访友、日常出门等需求；顾客决策重点是长度、腰腹和整体上身效果。

2. **大码外套**  
   对应换季、降温、上班通勤；决策重点是肩背活动空间、内搭后是否紧绷。

3. **大码裤装**  
   对应上班、带娃、日常出门；往往是顾客试穿意愿较强的一类，决策重点是腰、臀、腿部活动感。

4. **到店试穿与尺码判断**  
   这不是额外收费项目，而是当前最该被拍出来的成交方式：顾客到店，先试真实尺码，再决定是否购买。

### **各自的客单价与毛利大致区间**

档案未提供吊牌价、进货价、折扣方式与退换货政策，**不能替门店编客单和毛利数字**。尤其大码女装的利润会受采购渠道、尺码断码率、季节清货和门店租金影响，同一品类差异很大。

先补这三项，才能排出真正赚钱的货：

- 连衣裙、外套、裤装的常规成交价区间；
- 每类货的平均进货成本与滞销款比例；
- 顾客一次通常买一件，还是会连带买两件以上。

**我推测：裤装与外套的决策通常比普通上衣更谨慎，因为尺码和活动感更难靠挂版判断；待确认：店内哪类货试穿率最高、成交率最高。**

### **决策难度**

属于 **中等偏高决策**，不适合按“看完立刻拍单”设计。

原因是顾客要先确认三件事：  
- 有没有自己能穿的尺码；  
- 上身后哪里合适、哪里不合适；  
- 进店试穿是否自在。  

所以短视频的任务不是催单，而是把她带到“愿意进店试一次”。

## 主推产品

**主推的不是某一件单品，而是“50码以上可试穿的大码女装到店试穿”。**

连衣裙、大码外套、大码裤装必须轮流做主角，不能只推其中一类。原因是当前最硬的优势不是某个款式，而是“有真实可试穿的尺码”；如果把账号做成只卖裤装或只拍连衣裙，会把原本能到店的需求主动缩窄。

执行上，先按顾客出现频率测试三个品类：

- 有人因上班需求进店：拍大码裤装；
- 有人因换季添衣进店：拍大码外套；
- 有人因聚会、见亲友进店：拍大码连衣裙。

每条只讲一个品类、一个真实需求、一个可试穿款。这样顾客看得清，阿梅也拍得动。

**明确不做：**  
- 不把“特价清仓”当主推内容。现有资料没有低价优势依据，长期拍低价只会让顾客等折扣。  
- 不拿一件衣服换三种穿法当核心卖点。衣服没变，观众学到的是技巧，不是“为什么要来这家买”。  
- 不承诺所有款都有50码以上。必须拍哪类款，就说哪类款可试。

## 变现型内容怎么排

### **变现型内容占比：30%**

起号期仍保持流量型为最大部分，变现型暂定30%，原因有两个：

- 账号需要先让本地有尺码困扰的人刷到，不能一上来满屏“到店试穿”；  
- 但大码女装属于需要试穿确认的品类，若没有足够过程证据，观众即使喜欢阿梅，也未必愿意进店。

建议每发10条内容，安排3条变现型；三类货品轮流出现：大码连衣裙1条、大码外套1条、大码裤装1条。不是按货量排，而是避免主页只留下单一品类印象。

### 方向1：一条裤子，到底先看哪里能不能穿

- **对应成交路径：**兴趣 → 到店前确认  
- **成交理由：**50码以上有可试穿款  
- **观众变化：**信任变化。她会知道这家不是只挂着衣服，而是能试。  
- **四大脚本：**晒过程·火车节  
  - 起因：“今天有人来找一条上班能穿的裤子，先不是看颜色。”  
  - 关键步骤：拿可试尺码 → 拍尺码牌 → 说清试穿时看腰、臀、腿部活动。  
  - 结果：这条适合或不适合，以实际试穿为准。  
- **36计：**第10计·情境还原：顾客来找裤装 → 阿梅按真实需求拿可试尺码 → 镜头旁观试穿判断 → 给出真实结论。  
- **结尾行动：**“想试这类裤装的，到店找阿梅。”  

### 方向2：不是所有大码连衣裙，都适合直接拿回家

- **对应成交路径：**主页观察 → 建立专业信任  
- **成交理由：**真实试穿、真实判断  
- **观众变化：**信任变化。她会知道阿梅不会把每件衣服都说成适合。  
- **四大脚本：**教知识·拆解型  
  - 反常识开场：“大码连衣裙，挂着好看不等于穿上就合适。”  
  - 中间：只讲当前两件不同连衣裙，上身时腰腹、肩背、长度分别有什么不同。  
  - 收束：先试，再决定。  
- **36计：**第15计·正确做法VS错误做法：只看挂版就带走 → 到店先试具体版型 → 说明适用条件。  
- **结尾行动：**“想试连衣裙的，到店找阿梅。”  

### 方向3：换季买外套，先别急着看颜色

- **对应成交路径：**第一次接触 → 到店试穿

- **对应成交路径：**消除尴尬 → 到店

- **观众变化：**信任变化。她会看到进店后的第一步，不再只想象尴尬。

## 定价与节奏

### 起步阶段建议怎么定价

**不建议为了起号专门造一个低价引流款。**

原因是：  
- 现有资料没有价格优势和供货优势；  
- 大码女装尺码覆盖本身有库存成本，低价可能让顾客只盯折扣；  
- 这个店现在应先卖“可试穿的确定感”，而不是卖“全城低价”的印象。

更实际的起步动作是：

- 正常价格体系先不乱动；  
- 视频里不把价格当第一钩子；  
- 顾客到店后，按真实需求试连衣裙、外套、裤装；  
- 记录哪类需求最常出现、哪类货最容易试后成交。

### 什么时候可以调整价格

待确认门店目前定价体系后再决定。可以考虑调整价格的依据，不是“粉丝涨了”，而是：

1. 某类货连续出现缺码、断码；  
2. 顾客到店后对价格异议明显减少，但对版型和尺码认可更高；  
3. 单次成交从只买一件，变成稳定出现连带购买；  
4. 老客复购时明确反馈“这次还是来试这个品类”。

没有这些真实信号前，不建议贸然涨价，也不建议为了成交频繁降价。

## ⚠️ 风险

1. **“50码以上可试穿”说得太大，现场证明太少**  
   顾客最在意的是具体哪类款、当天有没有可试尺码。

   观众看完只知道有货，不知道自己能不能穿、进店会经历什么。

## ✍️ 写作要求

- **每句都是指令**：能直接拿去指导写文案、起标题、排镜头。不要写"要注重…"这类空话
- **具体到能执行**：不要形容词，要具体的词、句、动作、画面
- **忠于定位**：结论必须来自上面那份定位，不要自己另起一套（事实性的年限、经历以账号档案为准）
- 人和事只写真的：人设里要让人记住的那个人、那件事，只用档案写的或前采里说的；不让店员或别人扮演顾客，不替老板编性格、经历、顾客原话。没有的，写「待确认：缺哪一条」，并给出先要问的那个具体事件。
- 任何创作都必须符合现实的生活逻辑，有说服力才行。创作的来源只能是现实中真实存在、大多数人认可的事，不凭空编造。下面三类说法一律不写（括号里的例子只说明是什么类型，不是清单，类似的说法同样不写）：
- 太离谱：一件事改变整体、判若两人、几天就见效的保证（比如「收腰就能换风格」「换个头像粉丝就翻倍」「同一件外套两种人」「换个招牌字体，营业额就翻一番」）
- 太简单：一招搞定、一句话让客户当场签单、躺着就能赚（比如「一句话让客户当场下单」「躺着月入过万」）
- 太不科学：违背常识或没有依据的因果（比如「喝某种水就能瘦」「敷一下就能消炎」）
一件事能带来的变化，要有它真实的条件、过程和代价。反差和看点要来自生活或镜头里看得见的具体变量，不靠硬切换人设、身份或结果。拿不准能不能成立，就写清楚前提和做法，不替事实下结论。一个小细节（一种做法、一个动作、一句话、一处调整）只能改变它直接作用的那一处，不能写成它让整件东西、整个人或整家店都变了。结论的范围也要和证据一样大：一次现场的反应只说明这一次，不能推成普遍的道理（比如一位客户换了靠垫说舒服，就说挑沙发都要试靠垫）。
- 主角是这个号卖的东西（这条管变现型，以及任何要做对比、前后变化的内容）：观众看完要觉得「是这家的东西（或手艺）让人变好看、变好用、变好吃」，而不是学会一个技巧就不用来买了。
- 流量型也遵守对比变量规则：不是每条都要对比，但只要做反差、对比或前后变化，变的是卖的东西，人、场和动作保持一致；不为了满足规则把每条都拍成商品对比。流量型仍以用户感兴趣的看点为主，不硬推卖点
- 要做对比、反差、前后变化，变的那一样必须是这个号在卖的东西，其他条件不变：同一个人（同一个空间、同一桌人）先后用两样东西——这家卖的，和普通的、旧的或常见的——前后差别看得见，才证明是东西好。例：同一个人先后穿两套衣服，前后两种风格；同一个客厅换两张沙发；同一个人戴两副镜框
- 不做「同一件东西换个穿法、搭法、摆法、用法、吃法」的对比：卖的东西没变，差别只能归功于技巧，证明不了东西好，也给不出来买的理由
- 卖的就是手艺或服务的（剪发、验光、装修设计、厨师的做法），手艺本身就是货：同一个人剪前剪后、同一份食材我们的做法和普通做法，这类对比成立
- 穿法、搭法、用法这类技巧只能顺带一句，不能当一个方向或一条内容的看点；人设型可以以人为主角，但做对比时仍遵守上面的变量规则
- **不编事实**：档案和定位里没有的数字、客单价、客群比例、案例、客户故事、效果承诺，一律不写；需要它的地方写【待确认】并注明缺哪一项
