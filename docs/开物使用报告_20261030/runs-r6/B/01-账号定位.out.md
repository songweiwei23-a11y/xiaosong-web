## 🔍 先说这一行

- **归口**：本地实体店，12类中的**B服装鞋包类**，主赛道是大码女装，兼具“时尚穿搭”和“本地到店试穿”属性。

- **这行的钱怎么赚**：  
  大码女装不是纯靠一次高客单赚钱，更依赖“买到合身后的复购”和老客转介绍。普通女装顾客可以线上看图下单，但大码女生常常卡在腰、胯、肩、袖口、长度这些实际问题上；只要第一次试到合身，后续换季、上班、聚会、接送孩子，都可能再回来。  
  这家店真正该放大的，不是“衣服多”，而是“**50码以上有可试穿款**”。这能降低顾客最担心的试错成本。

- **客人的决策链路**：  
  这类顾客通常不会刷到一条视频就立刻买。她会先看：这家尺码是不是真的够大、上身会不会勒、版型会不会显臃肿、老板会不会让人尴尬；然后可能翻主页看几条不同身形的试穿，再选时间到店。  
  决策不算特别长，但信任要提前铺。视频的作用不是替代试穿，而是让她愿意走进试衣间。

- **时间规律**：  
  春秋换季、春节前、节假日前、开学前、婚礼宴请前，通常是“需要一套得体衣服”的集中时刻；县城门店的到店高峰往往在下班后、周末和赶集/商业街人流较多的时段。  
  具体旺淡季、门店营业高峰仍需阿梅确认，不能直接按行业经验当事实。

- **这行老板普遍会犯的错**：  
  第一，把衣架上挂满的货当成内容，以为“拍得多”就有人来。顾客看完只记住一排衣服，没记住自己能不能穿。  
  第二，拿偏瘦模特展示大码衣服。大码顾客最想知道的是“和我差不多的人穿上是什么样”，不是看一件裙子挂着多好看。  
  第三，反复教“显瘦技巧”。技巧可以顺带说，但如果内容核心变成“同一件衣服换个穿法就不一样”，观众学完技巧未必需要进店试穿，卖点反而被削弱。

- **这个客户有没有中招**：  
  现有方向里有“穿搭教学”，需要收一收。不是不拍穿搭，而是不能把“搭配技巧”当主角；主角必须是店里真实可试穿的大码连衣裙、大码外套、大码裤装，以及换货后能看见的版型差异。

- **同行现在都在拍什么**：  
  大多数服装店账号在拍“新款到店、货号、价格、上身展示、今天穿哪套”。这类内容的问题是：没有圈定谁该看，也没有解释为什么要来这家店试。  
  这个号的空档是：不拍“谁都能穿的女装”，专拍“很多大码女生在别处试不到、这里能现场试”的真实场景。县城本地用户看完能立刻判断：这是不是为我准备的店。

## 🗣 我会先问老板的几个问题

- **问题**：最近一次顾客试穿后不满意是什么情况？她当时哪件衣服不舒服，阿梅怎么处理、说了什么？  
  - **我的推测**：大码顾客的不满意通常不只是“款式不好看”，更可能是腰腹卡、肩背紧、裤长不合适，或者怕显壮不敢走出试衣间。这个事件最能拍出阿梅如何帮顾客判断，而不是只会说“这件显瘦”。  
  - 待老板确认。

- **问题**：有没有明确不卖的款？是哪一次进货或顾客试穿后，让你决定以后不再拿这种货？  
  - **我的推测**：阿梅做了6年，应该遇到过“尺码标得大，但实际版型不够”的货。若真实存在，这能变成账号的边界：不是只看吊牌尺码，而是看上身空间和实际版型。  
  - 待老板确认。

- **问题**：哪位老客第二次回来时，说过哪一句话？她第一次为什么来，后来又为什么回来？  
  - **我的推测**：老客回来的理由，可能不是“衣服便宜”，而是“上次那件穿着不勒”“你知道我哪里难买”“不用每次解释自己的身形”。这才是顾客感受到的差异化。  
  - 待老板确认。

- **问题**：顾客一进门最常问的一句话是什么？阿梅平时怎么答？  
  - **我的推测**：高频原话可能是“有没有我能穿的”“最大到多少码”“我肚子这里能穿吗”。这类问题就是短视频最天然的开头，不需要硬编痛点。  
  - 待老板确认。

- **问题**：这个月店里发生过哪件小事？从顾客进店、试穿、犹豫到离开，按顺序讲清楚。  
  - **我的推测**：商业街门店每天都有“顾客先在门口看、后来进来试”“陪朋友来却自己试了”“怕穿不下却试到合身”等小事件。只要是真实发生，就比硬拍剧情有说服力。  
  - 待老板确认。

- **问题**：顾客为什么会选这里，而不是别家？请给一句顾客原话。  
  - **我的推测**：阿梅以为的优势可能是“款式多”，顾客真正感受到的可能是“我不用担心来了没码”“试衣间里有人能给我判断”“这里不会让我因为尺码尴尬”。这两者必须分开确认。  
  - 待老板确认。

## 一句话定位

**阿梅在县城，替大码女生现场试到合身的大码女装。**

## 六维地基

### 1. 人设定位

- **原料在哪**：  
  真材料是：“店主阿梅本人出镜”“做大码女装6年”“在本地开店3年”“50码以上可试穿”“很多大码女生在别的店买不到合身衣服”。  
  这些是事实，不是人设。  
  “专业、懂大码、对顾客好”这类词不能直接拿来做人设；要翻译成行为，才有用。这里可被验证的行为是：阿梅长期站在试衣间和货架之间，帮顾客确认“这件到底能不能穿、哪里不舒服、要不要换一件”。

- **人设标签句**：  
  **帮大码女生现场试衣的阿梅**

- **用了哪个入口**：  
  **痛点+职业**。  
  大码女生最怕的不是“不会搭配”，而是进了店却没有自己能试的码；阿梅的职业正好能解决这件高频小事。

- **验证**：  
  这个人设能立住，因为“6年做大码女装”“50码以上可试穿”都可以持续用真实试衣过程证明。  
  后续每一条不是靠喊“我懂大码”，而是靠镜头里真实出现：拿尺码、看肩背、看腰腹、看裙长、替顾客换款。只要门店日常有顾客试穿，就有持续素材。

- **在同类账号里的位置**：  
  同行常见人设是“穿搭博主型”“新款推荐型”“老板娘展示型”。问题是很多账号拍的是“我觉得这件好看”。  
  阿梅的差别应是“**不替顾客做梦，先替顾客试清楚**”。她不需要装成时尚导师，而是成为县城大码女生到店前愿意先看的试衣参考。

- **证据链**：  
  1. 顾客常问尺码问题的情境还原；  
  2. 同一位试穿者换不同店内款式的真实过程；  
  3. 阿梅讲一件货为什么留下、为什么不再补；  
  4. 老客再次进店时的真实回访故事。  

- **边界**：  
  不说“穿上立刻显瘦”“谁穿都好看”“保证合身”这类过度承诺。  
  不评价顾客身材，不拿“大码”开玩笑，也不把“胖”拍成负面标签。阿梅的表达要始终落在“试穿、合身、舒服、场景需要”上。

### 2. 用户定位

- **一句话画像**：  
  **住在县城、下班要接孩子或周末要见人，衣柜里有衣服却常因尺码不合适不想出门试衣的女性。**

- **主攻人群**：  
  **精致妈妈**与**新锐白领**。  
  精致妈妈要兼顾接送孩子、家庭聚会、走亲访友，穿衣不只想宽松，还希望得体；新锐白领有通勤、聚餐、同事见面等场景，想穿得利落但不愿反复线上退换。  
  她们共同的决策点是：先确认尺码和上身效果，再决定到店。

- **为什么不是另一批**：  
  不主攻只追热点、只想买极低价快时尚的泛年轻用户。她们对“现场试穿”的需求没那么强，容易只问价不进店。  
  也不把银发族作为账号主攻对象：并不是不能服务，而是账号的人设、镜头语言和商品展示先要围绕25—40岁女性建立清晰认知，起号期不能一开始什么人都想接。

- **她们心里真正在想什么**：  
  “我不是不想穿得好看，我是怕又进一家店，店员说有大码，结果拿出来还是穿不上。”  
  这句话不一定会直接说出口，但决定了她会不会愿意进门。

- **决策链路**：  
  刷到阿梅试衣视频 → 看评论和主页确认是否真的有大码可试 → 收藏或记住门店位置 → 路过商业街、换季、聚会前需要衣服时到店 → 在试衣间完成真实判断。  
  她通常会先观察，不会因为一条视频立刻买；因此主页前几条必须让她迅速看到不同品类和真实试穿场景。

- **什么时刻会想起阿梅**：  
  下周要参加婚礼或聚餐；换季发现去年衣服不合适；单位临时通知活动；接孩子时发现自己总穿同一套；周末逛商业街但不想再空手回家。  
  内容标题和开头要抓这些具体时刻，而不是泛泛说“微胖女生穿搭”。

- **她在平台上搜什么**：  
  “县城大码女装”“大码连衣裙试穿”“大码外套怎么选”“大码裤子实体店”“附近大码女装店”“50码女装”。

### 3. 内容定位

- **长期提供什么价值**：  
  **让县城大码女生到店前先看懂自己能试什么。**

- **内容方向**：  
  选择**A多元四类打底 + 一个单一主题王牌栏目**。  
  原因是新号还没有验证哪种表达最能吸引本地用户，不能一开始把全部内容押在单一玩法上；但门店每天有稳定试衣素材，适合用一个固定栏目建立记忆。  
  王牌栏目建议：**《这位姐姐能试哪一套》**。前提是每位出镜顾客都明确同意拍摄；若顾客不愿出镜，就只拍阿梅拿衣服、试衣间门口和衣服细节，不硬拍人。

- **当前阶段配比**：  
  - **作用配比**：流量型45% / 人设型25% / 变现型30%。  
    这是起号期合理的结构：先靠流量型内容让本地陌生人刷到，再用人设型内容消除“又是一家只卖货的店”的距离感，最后用变现型内容承接到店试穿。  
  - **流量型形式**：以共鸣观点、反差试穿、轻情境短视频为主，辅助冷知识式的尺码认知内容。原因是陌生用户首先会停在“这说的不就是我”的场景上。  
  - **人设型形式**：以真实职业故事、阿梅的判断和边界观点为主。原因是阿梅本人是这家店最稳定的信任入口。  
  - **变现型形式**：以晒过程、试穿对比、解题型知识为主。原因是“50码以上可试穿”必须通过实际过程让人看到，空口说没有力度。  
  - **题材安排**：大码女装是绝对主赛道；目标人群关心的通勤、带娃、走亲访友、聚会等生活场景占一部分。生活场景负责圈人，真实试穿负责承接到店。

- **主力形式**：  
  档案没有提供“数据最好的内容类型”，因为账号仍在起号期，**暂不能断定已有主力形式**。  
  第一阶段先集中测试“真实试衣过程”——这是现有资源里最容易持续产出、最能证明50码可试穿、也最接近成交的一种形式。连续测试后，再根据非关注播放、评论里的尺码提问、到店咨询判断是否继续作为主力。

- **每类内容管哪一段路**：  
  - **刷到**：流量型内容，用“大码女生不敢进店”“明明标大码却穿不上”等可共鸣的场景，让陌生人停住。  
  - **记住**：人设型内容，让观众知道阿梅不是只会报货号，而是做了6年大码女装、长期在试衣间解决实际问题的人。  
  - **信**：变现型内容，用真实试穿和不同货品的版型差异，让观众确认这里真的能试到。  
  - **联系/到店**：变现型结尾只引导一次到店试穿，不把关注、私信、下单全塞进去。

- **流量型怎么拍**：  
  - **四大脚本**：方向是“大码女生逛店时最怕听到的一句话”；用**聊观点·争议开篇**或**教知识·拆解型**，从“吊牌码数不等于上身空间”切入。结尾只用：**“你也遇到过这种情况吗？评论区说说。”**  
  - **起号36计**：**第1计·反向操作：**常规是先问“你穿多少码”，反向是阿梅先说“别急着报码，先看这三个位置”，再展示肩、腰、胯的实际判断过程和顾客常见反应。产品只作为画面里的货，不讲到店成交。

- **人设型怎么拍**：  
  - **四大脚本**：方向是“阿梅为什么只做大码女装”；用**讲故事·职业经历型**，前提是补齐真实起因和转折。结尾只用：**“想看阿梅每天在店里遇到的事，就关注。”**  
  - **起号36计**：**第7计·一句话设定故事感：**阿梅整理一排大码外套，开头一句“今天这位姐姐进门前，在门口站了很久”；后续必须是当天真实发生、顾客同意使用的故事，不能摆拍。

- **变现型怎么拍**：  
  - **四大脚本**：方向是“50码以上能不能试到合身的连衣裙/外套/裤装”；用**晒过程·火车节模型**：顾客担心穿不上 → 阿梅拿出同类不同版型的店内款 → 展示试穿后的实际差异 → 到店试穿。结尾只用：**“想试50码以上的，到店直接找阿梅。”**  
  - **起号36计**：**第19计·对比改造：**同一位试穿者、同一面镜子、同一场景，前后换两件不同的店内大码女装，重点呈现肩背、腰腹、裤长或裙长的可见差异，再由阿梅说清适用身形。不能拍同一件衣服换几个穿法。

- **配比核验**：  
  1. **流量型是否匹配账号阶段：是。** 起号期流量型最大，符合先拿陌生人曝光的任务。  
  2. **主力形式是否来自已验证数据：否，但有原因。** 账号未提供历史爆款数据，只能先以最接近真实门店优势的试衣过程做首轮测试。  
  3. **大流量内容是否占主力：是。** 流量型占45%，且每条必须围绕真实人、货、场设计看点。  
  4. **题材是否有人群兴趣部分：是。** 通勤、带娃、聚会、走亲访友等场景承担圈人作用。  
  5. **百分数是否只来自配比块：是。** 仅使用流量45% / 人设25% / 变现30%，其余均用主次描述。

- **第一条该发什么**：  
  **题目：**《50码以上，在县城到底能不能进店试穿？》  
  **目的：变现型。**  
  **打法：四大脚本“晒过程·火车节” + 第19计“对比改造”。**  
  事件要真实：阿梅从店内拿出一件大码连衣裙或大码外套，由一位真实愿意出镜、尺码符合的试穿者，在同一试衣镜前换两件不同版型的店内货；镜头只说清“这一件卡在哪里、另一件多出的空间在哪里”。  
  为什么第一条拍它：它一次性把“阿梅是谁、卖什么、为什么值得到店”讲清，但主目的只放在“到店试穿”。不需要制造夸张结果，真实的上身差异就够。

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：真人出镜短视频 + 试衣过程配音Vlog。阿梅不需要站在白墙前讲时尚理论，门店试衣间、货架和镜子就是最有说服力的现场。  
- **产能**：待确认：缺少团队人数、阿梅每天可拍时间、是否有固定拍摄协助。未确认前，不承诺每周固定条数。  
- **在哪拍**：门头、挂满不同尺码的货架、试衣间门口、镜前上身区域。避免只拍素背景口播，现场比空讲更可信。

### 5. 风格调性（只给结论，≤200字）

- **正向匹配**：选正向匹配。大码女装店要让人先感到“可进、可试、可问”，不适合靠夸张反差博眼球。  
- **气质关键词**：利落、直白、松弛。  
- **会说的一句话**：  
  “别先看吊牌，先看这件衣服肩膀和腰这里有没有余量。”  
- **不会说的一句话**：  
  “这件谁穿都显瘦，闭眼拿。”  

### 6. 变现定位（只给结论，≤250字）

- **卖什么 + 客单价区间**：大码女装，包括大码连衣裙、大码外套、大码裤装；客单价区间**待确认：需补充门店主销价格带**。

## ⚡ 差异化：A + 变量B

### 1. 货架展示 + 情境还原

1. **常规A**：同行拍“新款到了，给大家看一圈”，镜头扫货架、报尺码。  
2. **变量B**：选择“情境还原”。因为目标用户在意的不是新款数量，而是她进店后会不会又遇到“没码”的尴尬。  
3. **A+B 长什么样**：  
   阿梅站在门口，模拟但不捏造一段高频真实对话：  
   “姐，最大多少码？”  
   阿梅不直接报数，带到货架前说：“这边50码以上能试，先别急着看款，咱们先找你肩和腰能活动开的。”  
   后面接真实可试的店内货。  
   它服务的是“怕白跑一趟”的顾客，不是为了拍段子。

### 2. 试穿展示 + 对比改造

1. **常规A**：同一件衣服换角度拍，配“显瘦、遮肉”的字幕。  
2. **变量B**：选择“对比改造”。对比变量只能是店里卖的不同衣服，人物、镜子、拍摄位置保持一致。  
3. **A+B 长什么样**：  
   同一试穿者先穿一件肩背或腰腹不适合她的普通版型，再换一件店内大码连衣裙/大码外套/大码裤装；阿梅只讲镜头里看得见的差异，例如“这一件抬手时肩背紧，那一件这里留出了活动空间”。  
   这能让目标用户判断自己为什么需要试穿，不把功劳归到搭配技巧上。

### 3. 新款推荐 + 换个视角

1. **常规A**：老板站在货架前说“今天推荐三套”。  
2. **变量B**：选择“换个视角”，从“陪朋友逛店的人”视角切入。  
3. **A+B 长什么样**：  
   镜头先拍一位顾客陪朋友进店、自己站在旁边不看衣服；转到阿梅拿出一条大码裤装说：“她本来只是陪来的，后来问我，这条腰这里会不会勒。”  
   必须是真实发生、顾客同意拍摄的事件。它服务的是那些“不敢主动试衣”的人，让她们先降低心理压力。
