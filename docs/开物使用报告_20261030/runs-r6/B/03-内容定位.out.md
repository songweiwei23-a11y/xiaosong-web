# 💎 内容定位方案

## 长期价值主张

让县城大码女生看懂大码女装能怎么试。

## 内容方向：多元四类还是单一主题

**选择：A 多元四类打底 + B 王牌栏目。**

- **主题**：《这位姐姐能试哪一套》——围绕真实试衣需求，记录一位试穿者试不同店内款式，呈现实际结果。
- **为什么这样选**：门店、衣服和试衣间是现成场景；大码女装的连衣裙、外套、裤装也能轮流入镜。试衣过程直接连接到店决策，适合作为持续测试的主形式。知识、观点和故事作为补充，让主页不只是重复换衣服。
- **为什么不只做单一主题**：愿意出镜的顾客、拍摄协助和阿梅的拍摄时间都待确认。若每条都依赖真实顾客出镜，产能目前无法保证；而且已有事实不足以支撑持续讲顾客故事。
- **为什么不只做多元四类**：新号需要一个清楚的记忆点。固定“一个真实需求→试店内款→看实际结果”，比今天讲知识、明天随意拍货更容易让人记住账号做什么。

**执行前提**：顾客出镜、声音和故事都需事先征得同意；尺码、上身结果按实际呈现。不愿出镜时可由阿梅本人试穿，但仅限实际合适的款；不能试穿时先拍衣物细节，不把它包装成上身验证。

## 内容配比

### 作用配比

| 作用 | 占比 | 为什么 |
|---|---:|---|
| 流量型 | 45% | 起号期先让陌生人看到。用大码女性逛街、通勤、聚会前找衣服的具体处境做入口，货和门店是画面背景，不讲卖点、不引导到店。 |
| 人设型 | 25% | 阿梅本人长期出镜，观众需要记住她这个人。用真实工作中的选择、经历和表达建立熟悉感，而不是反复报从业年限。 |
| 变现型 | 30% | 门店需要到店试穿，不能只有共鸣。用真实可试的货和结果，回答“值不值得来试”；每条突出一个有依据的理由。 |

**调整观察：**流量内容的非关注播放、完播和相关评论持续偏弱，就先换开篇和看点；若仍弱，流量选题测试往上加一档。主页访问、关注和对阿梅本人的讨论偏弱时，人设内容往上加一档；有播放却少尺码咨询、到店反馈时，变现过程往上加一档，同时把缺证据的内容往下收一档。是否调整作用配比，先看连续内容表现，不凭单条决定。

### 形式配比

| 形式 | 主次 | 负责哪种作用 | 为什么 |
|---|---|---|---|
| 晒过程 | 主力测试 | 流量型、变现型；真实工作过程也可服务人设 | 试衣间和货是现有资源，过程既能承载衣服差异，也能让“可试穿”被看到。**待确认：档案没有数据最好的内容类型**，所以这是起步假设，不是已验证结论。 |
| 观点 | 辅助 | 流量型、人设型 | 大码女性的逛街处境容易形成共鸣；人设观点则要连着阿梅真实做过的事，不能只喊态度。 |
| 知识 | 辅助 | 流量型、变现型 | 可以解释尺码和实际版型的区别，但要结合实物，不能把穿法技巧拍成主角。 |
| 故事 | 少量 | 人设型；真实顾客案例可用于变现 | 故事能让人记住阿梅，但目前缺具体事件。先前采、再拍，不补造转折和顾客原话。 |
| 段子 | 暂不安排 | — | 未确认阿梅的表演意愿和拍摄协助；多人剧情成本高，也容易把大码身材变成笑点。 |

### 题材配比

- **主赛道占大头**：围绕**大码女装**，轮流拍大码连衣裙、大码外套、大码裤装。每条聚焦一个品类或一个真实需求，不必同框；三类在内容中都有位置，也不预设哪类更重要。
- **目标人群兴趣占一部分**：主攻“精致妈妈”和“新锐白领”。话题选接送孩子与家庭聚会、通勤和下班后的安排、朋友聚餐或参加活动前的准备。它们能提供逛街需求的具体时刻，又不会把账号带成泛生活号。
- **为什么是她们**：档案已有宝妈和上班族两个方向，她们的生活场景能与试衣连接。其他人群当然可以进店，但起号先不为追泛流量转向与大码试衣无关的潮流话题。

### 配比核验

1. **是**：流量型是最大一块，符合起号阶段先拓展陌生人触达的任务。
2. **否，但有依据**：档案没有已验证的数据最佳形式；晒过程是基于门店资源与试穿决策做的首轮测试，后续用数据核实。
3. **是**：流量型为主，每条先定人货场、三有和可拍的爆款元素，再选结构；不把卖点内容算成大流量。
4. **是**：给通勤、带娃和聚会等人群兴趣留了位置，但仍与大码女性的实际生活相连。
5. **是**：百分数只使用既定作用配比；形式、题材和调整条件均用主次或增减方向表达。

## 三种视频怎么拍

### 一、流量型：先让陌生人说“我也遇到过”

**两个方向**

1. **逛街处境**：大码女生看到喜欢的衣服，先看能不能试，而不是先讨论搭配。主要带来**身份确认**；三有中占“有共鸣”，爆款元素用**人群**。
2. **同人同镜换货**：同一试穿者在同一镜前，试两件不同的大码女装，观察版型的可见差异。主要带来**认知变化**；三有中占“有用”，元素用**反差**。实际没有明显差异也照实说，不引导到店。

**四大脚本（薛老师）｜晒过程·任务挑战型**

骨架：提出一个日常试衣问题 → 同一人试不同的衣服 → 记录实际差别或没有差别 → 收住判断。标题可叠**反差**。

- 示范标题：《同一个人试两件外套，肩背活动有什么不同？》
- 怎么拍：固定镜头，由同一位已同意拍摄的试穿者分别穿两件外套，做相同抬手动作，只描述画面中实际能看到的差别。

**起号36计（小黄）｜第32计·换个视角**

公式落地：常见逛店事件 → 从大码女生看衣架的视角出发 → 看到她先关注的衣服信息 → 留下一个交流问题。

- 示范标题：《大码女生逛街，目光会先落在哪儿？》
- 怎么拍：用第一视角拍靠近衣架、查看衣服，再由阿梅提出问题；这是生活情境表达，不冒充真实顾客采访。

**共用结尾行动指令**：评论说说，你逛衣服时先看什么？

### 二、人设型：记住在店里做事的阿梅

**两个方向**

1. **真实职业经历**：阿梅做大码女装过程中，哪一次试衣经历让她改变了判断方式。主要带来**信任变化**；事件待前采。
2. **工作中的边界**：遇到衣服不适合顾客时，阿梅实际如何说、如何处理。主要带来**信任变化**；必须有真实事件，不写成“阿梅一定会这样”。

**四大脚本（薛老师）｜聊观点·观点立场**

骨架：一件亲身经历 → 阿梅当时的判断 → 为什么这样判断 → 留下她现在的做法。标题可叠**人群**。

- 示范标题模板：《做大码女装时，阿梅记住了【真实的一次试衣经历】》
- 怎么拍：阿梅在店里边整理衣服边讲清事件经过和自己当时的选择；发布前将括号替换为已核实经历。

**起号36计（小黄）｜第7计·一句话设定故事感**

公式落地：整理衣服的普通动作 + 阿梅当天要解决的真实工作任务 → 记录她怎么处理 → 交代实际结果。

- 示范标题模板：《阿梅整理衣架时，想起【真实发生的一件事】》
- 怎么拍：固定手机拍阿梅整理衣服，配她本人对真实事件的复述；没有具体事件就不发布此题。

**共用结尾行动指令**：关注阿梅，看她在店里的日常。

### 三、变现型：把“可试”拍成证据

**两个方向**

1. **50码以上能试什么**：围绕已确认的“50码以上有可试穿款”，拍货、尺码标识和实际试穿结果。主要带来**信任变化**；每条只说清本次拍到的款，不推成所有衣服都有。
2. **同一需求试不同店内款**：比如需要大码裤装的顾客，试两条店内裤子，看腰部或长度的实际情况。主要带来**信任变化**；不保证两条都合适。

**四大脚本（薛老师）｜晒过程·火车节**

骨架：提出“这次能试什么” → 展示店内实际款和试穿过程 → 说明这一次的结果 → 引导到店。成交理由是**50码以上有可试穿款**。

- 示范标题：《50码以上，店里能试到什么样的连衣裙？》
- 怎么拍：阿梅拿出实际符合条件的连衣裙，拍尺码标识和经同意的试穿过程；是否合身由试穿者实际反馈。

**起号36计（小黄）｜第19计·对比改造**

公式落地：试穿者当前需求 → 同一人、同一镜前试两件不同店内货 → 记录真实差异 → 复盘哪件哪里更适合或都不适合。

- 示范标题：《同一位姐姐试两条大码裤装，腰部差别看得见吗？》
- 怎么拍：固定人、镜头和动作，只换裤子，保留试穿者对腰部感受的真实反馈。

**共用结尾行动指令**：到县城商业街门店找阿梅试穿。

## 内容系列（2 个）

### 系列一：《这位姐姐能试哪一套》

**一句话**：围绕一位试穿者的真实需求，试店内不同大码女装，记录这次试衣的实际结果。

- **出发点**：给需要买衣服、又在意实际尺码和上身感受的大码女性看；围绕**货**；符合“有用”——能看到真实款式和试穿结果；爆款元素以**人群、反差、成本**为主，落在标题和试衣任务上。成本指找衣服、反复试衣的时间或精力，不虚构金额。
- **定量**：一次真实需求 → 看店内可试款 → 试穿 → 交代结果。
- **变量**：试穿者、她提出的问题、实际试的店内货。
- **打法**：四大脚本系列，固定用**晒过程·火车节**。
- **目的和结构**：变现型；每集突出“有可试穿款”这一理由，只在符合条件时说明50码以上；结尾统一引导**到店试穿**。
- **观众变化**：信任变化。
- **变量自检**：变量是**人、真实需求和货**。看点是不是一个试穿、挑选、穿搭技巧：**不是**；看点是这次需求能试到什么、实际结果如何。
- **前10集标题**：

1. 《想试大码连衣裙，这位姐姐能试到哪一件？》（人群）
2. 《同一位姐姐试两条裤装，腰部感受有差别吗？》（反差）
3. 《通勤要穿的大码外套，试过后肩背能活动开吗？》（人群）
4. 《担心白跑一趟：这次到店能试到什么码？》（成本）
5. 《一件裙子不合适，再试另一件结果如何？》（反差）
6. 《带娃出门想穿条裤子，这次试到了什么？》（人群）
7. 《不想反复跑店找裤装，先看这次的真实试穿》（成本）
8. 《参加聚餐前试连衣裙，裙长合不合适？》（人群）
9. 《同一面镜子前换两件外套，肩部差在哪？》（反差）
10. 《找可试穿的大码裙装，现场需要试几件？》（成本）

**立项检验**

- **一句话能讲清**：每集解决一位真实试穿者的一个需求，结果可以是合适、暂时没找到，或需要继续试。
- **追看理由**：下一位试穿者的需求和实际货不同，结果不能预先断定。
- **持续性**：可由真实需求、不同试穿者和连衣裙、外套、裤装扩展至30集；但能否实际持续，取决于授权顾客和可拍货源，待门店勘察确认。
- **真实性**：标题涉及的具体需求和结果必须当天真实存在；若没有合适试穿者，该集暂缓，不找人假扮顾客。
- **与变现的联系**：看这类内容的人正在判断能否找到可试的衣服，与到店试穿直接相关。
- **元素和句式**：前10集用了人群、反差、成本；标题分别从人物需求、对比、问题和时间成本切入，没有连续重复同一句式。

**一句话**：从逛街、找衣服的具体处境出发，让大码女性看到熟悉的问题，也看到实际衣服带来的不同结果。

- **出发点**：给平时通勤、带娃或参加聚会，需要找合适衣服的大码女性看；围绕**人**；符合“有共鸣”；以**人群、反差、成本**设计标题和事件看点，不讲门店卖点。
- **定量**：**36计·第32计 换个视角**——从大码女性的视角进入一次找衣服事件 → 展示眼前的衣服和实际情况 → 提出一个交流问题。
- **变量**：人物所面临的真实话题、找衣任务、涉及的不同衣服。需要换货对比时，保持同一人、同一场和动作，只换衣服。
- **目的和结构**：流量型；按“熟悉事件→新视角→新信息→交流”展开；结尾统一请观众**评论**。
- **观众变化**：身份确认。
- **变量自检**：变量是**人群处境、话题和任务**。看点是不是一个试穿、挑选、穿搭技巧：**不是**；每集呈现一个具体处境或实际结果，不只抛选择题。
- **前10集标题**：

1. 《大码女生逛衣服，看到喜欢的款会先想什么？》（人群）
2. 《同一件尺码标识，看过之后还要试吗？》（成本）

4. 《上班要穿的衣服，大码女生逛街时会留意什么？》（人群）
5. 《为了找条合适的裤子，试衣时哪些时间省不掉？》（成本）
6. 《同一人试两条裤装，长度差别能看出来吗？》（反差）
7. 《聚会前找连衣裙，大码女生会从哪件开始试？》（人群）
8. 《衣架上看着相近的两条裙，上身会有差别吗？》（反差）
9. 《带娃出门前想找件外套，逛街时会考虑什么？》（人群）
10. 《不想白跑找衣服，出门前想先确认什么？》（成本）

**立项检验**

- **一句话能讲清**：从大码女性自己的视角，看一次找衣服的实际处境。
- **追看理由**：每集换一个任务或具体问题；观众能继续看不同衣服和处境下实际出现的信息，而不只是听一句观点。
- **持续性**：可从不同人物、真实问题和三类店内货扩展至30集；如果问题开始重复，就暂停，不靠换机位凑集数。
- **真实性**：第一视角可明确作为情境表达；涉及顾客原话或试穿反馈时必须来自真实授权素材。
- **与变现的联系**：吸引的是对大码女装有需求的人，为主页其他试穿内容带来相关观众；本系列自身不讲卖点、不引导到店。
- **元素和句式**：前10集覆盖人群、反差、成本；分别用逛街问题、试衣任务和货品差异切入，句式有变化。

## 选题来源

| 来源 | 长期怎么挖 | 例子 |
|---|---|---|
| 知识储备 | 收集阿梅实际看货、试货时会关注的问题；不把未验证经验讲成通用结论 | 《同样标大码，两件外套的肩部空间会一样吗？》——用实际衣服展示，结果以现场为准。 |
| 经历与故事 | 访谈阿梅做大码女装以来记得的事件，记录当时的动作和原话 | 《阿梅记得的一次试衣：顾客提出了什么问题？》——具体事件待确认。 |
| 热门话题与观点 | 从评论区反复出现的问题、经核实的同类公开选题找角度；当前未做竞品调研，不假称已有热门案例 | 《买衣服时，吊牌尺码能代替试穿吗？》 |
| 实操记录 | 记录真实整理货品、顾客授权试衣、试后反馈 | 《一位顾客试两条裤装后，实际留下了什么反馈？》——仅真实发生时拍。 |

**前采先补这些事件，拿到答案后再写人设和案例：**

1. 最近一次顾客试衣不满意，是哪件、哪里不合适？阿梅当时说了什么、做了什么？  
   **推测，待确认**：问题可能出在肩背、腰腹或长度；不能提前认定。
2. 有没有决定不再卖的某件货？是哪一次具体试穿或进货经历让她做出决定？  
   **推测，待确认**：可能涉及标识尺码与实际版型的差异。
3. 哪位老客回来过？第一次为什么来，后来又因为什么回来？能否经同意引用她的话？  
   **推测，待确认**：再次到店可能与上次试衣体验有关，具体原因要问顾客。
4. 顾客进门常问哪句话？阿梅原话怎么回答？  
   **推测，待确认**：可能先问有没有自己能试的尺码。
5. 这个月店里发生过哪件小事？从谁进店、提出什么需求，到最后怎样结束，按顺序讲一次。  
   **推测，待确认**：一次没有找到合适衣服的过程也可能有内容价值。
6. 有没有顾客亲口说过为什么选这里？原话是什么？  
   **推测，待确认**：顾客感受到的理由，可能与阿梅认为的卖点不同。
7. 最近一次试衣中，阿梅亲手做了哪一步？请讲清动作和结果。  
   **推测，待确认**：她可能会关注肩背或腰部活动空间；不能预设这是别人做不到的事。

## 前 30 条节奏

**总原则**：前期集中测试晒过程，但不把30条都拍成同一种售货内容。作用仍按既定配比安排；同一形式可以分别承担流量、人设或变现，单条只设一个目的。具体拍摄频率待确认团队、时间和顾客授权情况。

### 第 1—10 条：先验证“有人愿意看什么”

- **目标**：让陌生人快速看懂账号与大码女性的关系，同时验证试衣画面能否留住人。
- **系列与形式**：以《这位姐姐能试哪一套》和《大码女生逛衣服时》交替测试；主要用**晒过程·火车节**和**第32计·换个视角**。流量内容先设计人群或反差，再拍事件。
- **增加**：穿插阿梅本人真实工作片段；不够真实的故事先不讲。
- **验收**：看非关注用户播放、开头流失、完播，以及评论是否围绕尺码、试衣处境展开；同时记录是否出现实际尺码咨询。没有历史基线时，先比较本批不同选题和开篇，不设虚构达标线。

### 第 11—20 条：验证哪种问题值得反复拍

- **目标**：找出观众更愿意看连衣裙、外套、裤装中的哪些具体问题，而不是只比较哪件货播放高。
- **系列与形式**：继续两条系列；主要用**晒过程·火车节**，有真实同人换货条件时测试**第19计·对比改造**。
- **增加**：前采确认后，加入**观点立场**或**第7计·一句话设定故事感**的人设内容；没有事件就继续拍真实工作，不编故事。
- **验收**：看同类问题能否重复获得相关评论、主页访问和咨询；记录咨询涉及的尺码和品类。连续发满20条后，结合门店实际询问到店来源，看有没有可确认的试穿反馈，而不把播放等同到店。

### 第 21—30 条：保留有效变量，补足信任链

- **目标**：保留能持续吸引相关观众的试衣问题，改善“看了却不敢来试”的信息缺口。
- **系列与形式**：继续有效的主系列；流量用**第32计·换个视角**或任务挑战，变现用**晒过程·火车节**与**第19计·对比改造**，人设用已核实的经历和观点。
- **增加**：针对真实咨询补拍对应品类、实际尺码和试穿结果；如果缺合适试穿者，不承诺现场效果。
- **验收**：对照前两阶段，看非关注播放、相关评论、主页访问、试穿咨询和可核实到店反馈是否有改善；若只有播放没有咨询，检查是否缺货品与试穿证据；若有咨询但没有到店反馈，先问清顾客卡在尺码、位置还是时间，不能直接断定原因。

## ⚠️ 不要做什么

1. **不做纯穿法教学和同一件衣服换搭法的前后对比。** 这会把看点落在技巧上，观众看不到店里不同衣服的实际差别，也偏离“现场试衣”的定位。
2. **不拍把大码身材当笑点的段子，也不追与目标人群无关的泛热点。** 即使获得围观，也可能让真正需要试衣的人不愿进入主页。
3. **不编顾客故事、不假装随机采访，也不保证每个人都能试到合身款。** 目前真实故事和试穿授权尚未补齐；拍不到就暂缓，保留不合适或暂未找到的真实结果，比制造满意反馈更可信。
