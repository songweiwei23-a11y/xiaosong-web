## 📌 先说结论

- **建议主攻：36计·第32计 换个视角。**  
  阿梅大码女装店起号期先拍“大码女生找衣服时到底在看什么”。这条线不靠阿梅讲大道理，不靠顾客配合演剧情，手机对着衣架、吊牌、试衣间门口和手部动作就能开拍。它直接承接已定系列《大码女生逛衣服时》，让陌生大码女性先产生“这就是我逛街会遇到的事”的身份确认。

- **备选：**
  1. **36计·第19计 对比改造**：出现真实、授权的试穿者，且同一人能试两件不同店内货时切入。  
  2. **36计·第10计 情境还原**：顾客进店提出明确需求，阿梅现场找款、试穿、沟通的真实过程完整时切入。  
  3. **36计·第7计 一句话设定故事感**：前采拿到阿梅亲历的具体试衣事件后切入，用于补人设内容。

- **明确不做：**
  1. **第35计 街头采访**：需要在商业街反复找路人、征得出镜同意、完成追问。当前没有确认拍摄协助和路人授权机制，拍摄成本高，且容易偏离门店试衣定位。  
  2. **第30计 角色扮演**：需要多人角色、对话和表演配合。大码女性的穿衣烦恼不该被演成笑点，当前也没有确认阿梅的表演意愿和搭档资源。

- **多久能看出跑没跑通：**  
  第32计先连续测 **3—5条**，看它是否能稳定带来非关注播放、围绕“尺码、试衣、白跑一趟”的评论，以及相关主页访问。  
  起号阶段的阶段性目标仍是：**从零粉走到一千粉，且作品流量逐步稳定。** 但不把一千粉当成唯一结论；目标人群是否进主页、是否询问尺码和试穿，同样决定这条路值不值得继续跑。

## 🧮 起号期内容配比

起号期到“一千粉、流量稳定”之前，按已定定位执行：

- **流量型 45%**
- **人设型 25%**
- **变现型 30%**

这个比例适合阿梅：新号先靠大码女性熟悉的逛街处境打开陌生人触达；阿梅本人再用真实工作选择建立信任；最后把“50码以上有可试穿款”拍成到店前能看见的证据。

### 1. 流量型：先让大码女生停下来

- **出发点：**  
  - 人：县城里通勤、带娃、聚会前要找衣服的大码女性。  
  - 货：大码连衣裙、大码外套、大码裤装。  
  - 场：商业街门店的衣架、试衣间、镜子前。  
  - 三有：主打“有共鸣”。  
  - 爆款元素：主用**人群、成本、反差**。成本不是金额，而是“跑一趟店、反复试衣、喜欢了却不能试”的时间和精力。

- **主形式：**  
  **36计·第32计 换个视角 + 晒过程·挑战型。**

- **脚本结构：**  
  熟悉的找衣服事件 → 从大码女生的视角看衣架或试衣间 → 给出一个当下看得见的信息 → 留一个具体问题。

- **结尾行动指令：**  
  **评论说说，你找衣服时最先确认什么？**

- **边界：**  
  流量内容不说“店里50码以上都能试”、不报货品卖点、不引导到店。衣服只作为事件里的货出现，不把流量片拍成广告片。

### 2. 人设型：让人记住阿梅怎么做事

- **出发点：**  
  主角是店主阿梅：做大码女装6年、在本地开店3年。人设内容不反复报年限，而是拍她在真实工作里做过的选择。

- **主形式：**  
  **36计·第7计 一句话设定故事感 + 讲故事·平凡英雄型。**

- **脚本结构：**  
  阿梅正在做的一件普通工作 → 一句真实背景交代她当天面对的事 → 她怎么处理 → 这件事留下的判断。

- **结尾行动指令：**  
  **关注阿梅，看她在店里的日常。**

- **前提：**  
  待确认：缺阿梅亲历的完整事件。先问清一件事：  
  **“最近一次顾客试衣不满意时，顾客试的是哪类衣服、哪里不合适、你当时说了什么、最后怎么结束？”**  
  没有这个完整事件，不发人设故事，不用“很多顾客都说”代替事实。

### 3. 变现型：让“能试”成为看得见的理由

- **出发点：**  
  - 人：正在找大码连衣裙、外套或裤装，担心白跑一趟的人。  
  - 货：当天店内实际可试的大码女装。  
  - 场：门店衣架、尺码标识、试衣间、镜子前。  
  - 成交理由：**50码以上有可试穿款。**

- **主形式：**  
  **36计·第19计 对比改造 + 晒过程·火车节。**

- **脚本结构：**  
  这次试衣需求是什么 → 同一位试穿者试两件店内货 → 固定镜头记录腰部、长度、肩背活动等现场画面 → 说清这一次哪件更贴近她的需求，或两件都暂时不合适。

- **结尾行动指令：**  
  **到县城商业街门店找阿梅试穿。**

- **边界：**  
  只说当天拍到的款，不把一条视频拍成“所有人都能试到”。试穿者没有找到合适款，就如实拍“这次没有留下合适的”，这比硬凑满意结果更有说服力。

### 过线之后怎么调

当流量开始稳定、主页已经让人看懂“这是一个拍大码试衣的账号”后：

- **人设型往上加一档**：补阿梅真实经历、工作判断和待人方式。
- **变现型往上加一档**：围绕真实咨询补拍裤装、外套、连衣裙的可试信息。
- **流量型往下收一档**：保留表现稳定的“逛衣服处境”选题，不再盲目扩泛话题。

### 和已定内容定位怎么对上

主攻第32计，直接喂给系列二《大码女生逛衣服时》；  
备选第19计和第10计，直接支撑系列一《这位姐姐能试哪一套》；  
第7计负责补阿梅本人的真实工作故事。

主力形式仍是**晒过程**：衣架、衣服、试衣间和镜子都是现成画面。第32计只改变叙事视角，不另起一套内容方向。

## 🎯 主攻打法：36计·第32计 换个视角

### 为什么是阿梅能拍的

1. **人是现成的。** 阿梅本人就是固定出镜人，不需要找演员，不让店员扮顾客。  
2. **场是现成的。** 县城商业街门店、衣架、试衣间、镜子前，都能成为“大码女生找衣服”的真实场景。  
3. **货是现成的。** 连衣裙、外套、裤装轮流入镜，一条只拍一个找衣服的处境。  
4. **不依赖顾客出镜。** 起号前几条先拍阿梅的第一视角、手部动作和衣服细节；涉及顾客原话、试穿反馈和正脸时，再单独取得授权。  
5. **对设备要求低。** 一台手机、一只固定支架就能拍。  
   **待确认：目前未确认门店是否有稳定手机支架。开拍前先补齐固定支架，避免镜头晃动。**

### 结构公式

**常见逛店事件 → 从大码女生视角进入 → 看到一个真实信息或处境 → 留下交流问题。**

套到阿梅账号：

> 镜头从门店外或衣架前推进 → 字幕抛出“大码女生找衣服时”的具体烦恼 → 手翻过衣架、看吊牌、走向试衣间 → 阿梅用一句话点出当下动作的原因 → 结尾问观众自己的习惯。

这里的“大码女生视角”必须明确是**情境表达**，不冒充某位真实顾客，不把阿梅的判断说成所有人的想法。

### 配什么脚本讲

配 **晒过程·挑战型**。

- **第32计负责事件：** 让镜头从“大码女生找衣服”的视角进入门店。  
- **晒过程·挑战型负责叙述：** 给这次逛衣服设一个小任务，例如“今天只确认一件事：这条裤子能不能先试”。  
- **它补上的内容：** 第32计解决代入感，晒过程解决过程感。观众不是只听阿梅讲“尺码重要”，而是看见从衣架到试衣间前的真实选择。

### 前3条具体拍什么

#### 1.《大码女生逛衣服，最怕先喜欢再发现不能试》（人群）

**为什么会让人停下：** 很多大码女生看到喜欢的衣服时，先确认的不是颜色，而是自己能不能试。

**拍摄要点：**
- 首帧：手机从衣架外推进，手停在一件衣服前。
- 字幕：`看到喜欢的款，先别急着看颜色。`
- 中段：镜头拍手翻看衣架、拿起衣服、走到试衣间门口。
- 阿梅口播：  
  “找衣服最怕的，不是没喜欢的，是拿起来以后才发现，这次没法试。大码女生逛店，很多时候先问的就是：这件我能试吗？”
- 结尾：  
  “你找衣服时，第一句会问什么？评论区说说。”

**拍摄边界：** 不拍成“我们店都能试”，不出现到店引导。

---

#### 2.《不想白跑找大码裤装，进店前最想确认哪件事？》（成本）

**为什么会让人停下：** “白跑一趟”是找衣服时最真实的时间成本，比空讲裤装版型更容易让人代入。

**拍摄要点：**
- 首帧：两排裤装衣架，阿梅的手停在一排裤装前。
- 字幕：`找裤子最怕的，不是挑花眼。`
- 中段：拍裤装吊牌、挂杆、试衣间门口，不评价哪条更好。
- 阿梅口播：  
  “有些人进店先看裤子，不是因为裤子最难挑，是不想翻了半天，最后还是没找到能试的。你进一家店之前，最想先确认什么？”
- 结尾：  
  “评论告诉我，你最怕白跑哪一步。”

**拍摄边界：** 不讲“哪条显瘦”“一穿就好看”等没有现场证据的结论。

---

#### 3.《聚会前找连衣裙，大码女生会先走向衣架还是试衣间？》（人群）

**为什么会让人停下：** 聚会前找衣服是25—40岁宝妈和上班族都能理解的具体时刻，画面里有明确任务。

**拍摄要点：**
- 首帧：镜头从试衣间门口转向连衣裙衣架。
- 字幕：`聚会前找裙子，最怕时间不够。`
- 中段：阿梅从衣架抽出两件不同款式的连衣裙，只拍款式和吊牌，不安排上身对比。
- 阿梅口播：  
  “聚会前找裙子，很多人不是先想搭什么，而是先想：我今天有没有时间一件件试。你会先看衣架，还是先问能不能试？”
- 结尾：  
  “评论区选一个：先看衣架，还是先问试穿？”

**拍摄边界：** 不用“聚会必备”“显气质”等泛形容词，不把一件裙子写成解决整场聚会的问题。

### 边界

- 不把阿梅的视角说成顾客原话。  
- 不把“情境表达”拍成假采访。  
- 不用大码身材制造尴尬、反差或笑点。  
- 不为了做反差，拿同一件衣服换穿法、换搭法。  
- 画面里没有真实差别，就不强行下“这件更适合”的结论。  
- 顾客出镜前先取得正脸、声音、试衣画面的授权。

## 🔄 备选打法

### 36计·第19计 对比改造

**切入条件：** 有一位真实、已授权的试穿者；她有明确需求；当天能试两件不同店内货；两件衣服的实际结果看得出来。  

**怎么套到阿梅账号：** 同一位姐姐、同一面镜子、同一组动作，只换店内两条裤装或两件外套，记录腰部、长度、抬手活动等现场状态。主角始终是店里卖的两件衣服，不拍同一件衣服换搭配。  

**配的结构：** **晒过程·火车节。**  
起因是“她今天要找什么” → 试第一件 → 试第二件 → 交代这一次的结果 → 到店试穿。  

**切走主攻的信号：** 第32计能带来播放，却长期没有人关心具体衣服和试穿；而同人同镜的对比内容连续出现尺码、裤长、肩背活动等相关提问时，第19计往上加一档。

---

### 36计·第10计 情境还原

**切入条件：** 门店当天发生完整、真实的接待过程：顾客提出需求，阿梅找出实际款，试衣有明确结果。  

**怎么套到阿梅账号：** 从顾客进店问“有没有能试的”开始，阿梅拿出当天实际可试的货，保留试衣过程和真实结果。顾客不愿露脸时，只拍手部、背影、衣服和阿梅的操作，不补顾客台词。  

**配的结构：** **晒过程·过程展示。**  
真实需求 → 拿货与确认 → 试衣过程 → 结果。  

**切走主攻的信号：** 顾客授权稳定、门店每天都有可拍试衣过程，而第32计的情境镜头开始重复时，第10计接替部分流量内容，同时承担变现内容。

---

### 36计·第7计 一句话设定故事感

**切入条件：** 前采拿到阿梅亲历的一件完整事件，包含时间、人物需求、阿梅的动作和实际结果。  

**怎么套到阿梅账号：** 阿梅整理衣架时，说起一次真实试衣经历；镜头拍她整理货、停下想起当时那件衣服，再讲清她为什么做出那个判断。  

**配的结构：** **讲故事·平凡英雄型。**  
普通工作 → 一件具体小事 → 阿梅做了什么 → 她留下的判断。  

**待确认：** 缺“哪一次试衣经历改变了阿梅的判断”。先问清事件，再写标题和口播；没有事件，不拍。

## 🧪 怎么测

### 一次只改一个变量

主攻第32计时，固定以下内容：

- 场景固定在门店衣架、试衣间、镜子前。
- 主角固定为“大码女生找衣服的一个处境”。
- 结尾固定为评论互动。
- 视频时长和字幕风格保持接近。

每一轮只改一个核心变量：

1. **第一轮改开篇：**  
   “最怕先喜欢再发现不能试”  
   对比  
   “不想白跑一趟，进店前先问这句”。

2. **第二轮改任务：**  
   连衣裙找衣任务  
   对比  
   大码裤装找衣任务。

3. **第三轮改爆款元素：**  
   人群共鸣  
   对比  
   白跑一趟的时间成本。

### 每计测几条、看什么指标

- **每一计连续测3—5条。**
- **第32计看：** 非关注播放、前段流失、完播、评论是否围绕真实试衣处境、相关主页访问。
- **第19计看：** 尺码咨询、对具体款式的提问、到店试穿反馈。
- **第10计看：** 过程完播、评论里是否有人追问“还有没有能试的”、实际到店来源。
- **第7计看：** 主页访问、关注、评论是否开始记住阿梅这个人和她做事的方式。

### 什么信号算“这计行”

**第32计跑通的信号：**
- 连续内容都有非关注触达；
- 评论开始出现“我也是先问能不能试”“找裤子最怕白跑”等具体共鸣；
- 不同品类都有人愿意讨论；
- 主页访问里出现对试衣、尺码、门店位置的相关兴趣。

**换掉的信号：**
- 连发3—5条后，开头已经重写过，仍没有非关注触达；
- 评论只剩熟人互动，目标人群不讨论试衣问题；
- 观众看完不知道账号拍的是大码女装还是泛逛街日常；
- 同样场景下，第19计或第10计的相关咨询明显更集中。

换掉不是全盘放弃“试衣”方向，而是把主力从“情境共鸣”切到“真实试穿过程”。
