# 🚀 起号方案

## 📌 先说结论

- **建议主攻：第32计·换个视角。**把镜头放在“这把串的一天”上，从下午四点的真实备料开始，跟到它进入锅里或上桌。它不用顾客出镜、不需要搭档演戏，直接利用已经确认的稳定现场；也能轮流拍川味串串火锅、川味烧烤、川菜，不会让账号只剩“一元火锅”。
- **备选：第31计·南北/地域差异、第7计·一句话设定故事感、第17计·互联网嘴替/替网友做。**等有相应的真实素材或条件再切，具体触发条件见后文。
- **明确不做：第8计·加入人物关系、第35计·街头采访。**目前没有确认店员、顾客或搭档能稳定出镜；硬做就得临时找人配合，容易出现表演感，也超出目前已知资源。
- **多久能看出跑没跑通：**按“零粉到一千粉、流量稳定”这条参考线判断，不用一两条视频就给打法判死刑。先对主攻打法做一组连续测试；样本至少达到三至五条，再看非关注播放、开头留存、完播、分享、新粉和本地评论。粉丝数到了不等于自然过线，流量还要相对稳定，且关注者要和南乐晚饭场景有关。

**拍摄资源边界：**档案确认出镜人是掌勺的成都厨师，店内每天有下午四点出摊这个固定现场；没有确认团队人数、手机型号、收音设备、门店可拍区域。以下全部按“厨师本人、一部手机、店内真实工作现场”的最低配置设计，不要求额外演员或专门设备。开拍前只确认两件事：手机能稳定收音、拍摄不妨碍备餐。若由代运营人员掌机，采用手持跟拍；若现场只有厨师一人，手机固定在安全位置，拍完一个动作再换位置，不边操作边手持拍摄。

## 🧮 起号期内容配比

起号期按已定作用配比执行：**流量型 45% / 人设型 25% / 变现型 30%。**

流量型仍是最大项，负责让南乐陌生用户停下来认识“下午四点开工的成都厨师”；人设型让用户记住掌勺的人，而不是只记住低价；变现型从起号期就保留，展示三类菜品的真实过程和到店理由。这个配比与账号已定的王牌栏目《下午四点，今晚先备哪一口》、以及“晒过程为主”的定位一致，不另起一套定位。

### 流量型：人货场 + 爆款元素，再选拍法

- **出发点：**下午四点，成都来的川菜厨师在南乐真实备晚饭；货是当天确实在准备的串串、烧烤或川菜；场是出摊前的工作现场。看点押在“同一把食材从备料台走到成品”的过程上，叠加**人群、反差**：多数人还没开始想晚饭，厨师已经在备餐。
- **形式：**主力用第32计·换个视角，配合**晒过程·火车节**：起因（下午四点开始备这一口）→关键步骤→成品。动作必须是真实当日流程，不为拍摄改流程。
- **结尾行动指令：**“你们家晚饭一般先准备什么？评论区说说。”
- **不带价格优惠和到店引导。**这类视频让食物作为画面里的货出现，重点是现场和过程，不讲成交理由。

### 人设型：真实职业经历 + 真实行为

- **出发点：**让用户记住这个人：成都人、做川菜九年、来南乐半年、本人掌勺。这些是已确认事实。选一个真实开工动作，拍他本人怎么做，不替他加性格评价或编一段“坚持的原因”。
- **形式：**先用工作现场建立人物和时间，再讲经核实的职业经历。配**讲故事·小有成就型**之前，必须补齐真实的阻碍与转机；未补齐时不硬套这个故事结构，先拍真实职业经历的短记录，并标注“未归入注册表”。
- **结尾行动指令：**“关注我，看我每天四点怎么准备晚饭。”

### 变现型：人货场 + 一个有依据的成交理由

- **出发点：**明确呈现店里卖川味串串火锅、川味烧烤、川菜；每条聚焦一个实际品类或真实点单需求。当前能直接使用的成交理由是“成都来的川菜厨师本人掌勺”和“一元火锅低门槛”，但一条只讲一个，不把三个品类和所有卖点挤在一起。
- **形式：**配**晒过程·火车节**：真实备餐需求→关键操作→成品→到店。顾客需求、菜单、价格、分量和适合人数均以店内确认的信息为准，不替店里编套餐或点单方案。
- **结尾行动指令：**“今晚想吃川味，直接到店找我。”

### 过线之后怎么调

零粉到一千粉且流量稳定后，继续保留《下午四点，今晚先备哪一口》，逐步补足真实职业故事、顾客常问的点单问题和三类菜品的到店过程。若主页访问和关注偏低，人设型往上加一档；若评论、私信或到店询问增加，但用户仍不清楚怎么点，变现型往上加一档。若三类菜品曝光失衡，就把镜头往下收一档表现过多的品类，让串串火锅、烧烤、川菜都持续出现。

## 🎯 主攻打法：第32计·换个视角

### 为什么是你能拍的

1. **人物条件已确认：**出镜人就是掌勺的成都厨师，不需要安排顾客或员工扮演角色。
2. **现场条件已确认：**每天出摊前有备餐场景，下午四点可以自然开拍；不需要为视频制造一次假操作。
3. **内容货品已确认：**川味串串火锅、川味烧烤、川菜都在卖，可以轮换拍，不会把账号锁死在“一元火锅”。
4. **制作条件按最低配置设计：**手机固定或由一人掌机，拍手部、食材、锅和成品即可。设备型号和团队人数没有确认，所以不写“专业灯光”“多人机位”作为必要条件。
5. **符合账号主系列：**镜头跟着食材走，天然服务《下午四点，今晚先备哪一口》，也让观众看见“下午四点开始备晚饭”这个账号记忆点。

**这计唯一的看点：**观众看到的不是静态菜单，而是同一把串从下午四点的备料现场，走到锅里的真实过程。它把“晚饭什么时候开始准备”变成一个看得见的答案。

### 结构公式

**常规事件：**下午四点备餐  
→ **换个视角：**跟着一把串、一道菜或一份烧烤走  
→ **新信息：**展示它经过的真实操作环节  
→ **结果：**拍到当天实际完成的成品或出餐状态  
→ **评论：**问观众今晚更想看哪一类晚饭过程。

“换个视角”落在事件上：镜头叙事主体从厨师的口播，换成一把真实在处理的食材；不做拟人台词，不假装食材有想法，也不把正常备餐剪成虚构挑战。

### 配什么脚本讲

- **计负责事件怎么走：**第32计·换个视角，跟着一份真实食材经过当天实际流程。
- **话怎么讲：**配**晒过程·火车节**，用“起因—关键步骤—结果”讲清楚。开头交代下午四点和当天要准备的品类，中段只讲画面里能看见的实际动作，结尾展示当天真实成品。
- **补上的内容：**补足王牌栏目的固定记忆点和稳定过程素材。主攻的流量视频不讲优惠、不引导到店；店内手艺证据留给变现型内容单独讲，避免一条片同时抢流量和成交两个目的。

### 前 3 条具体拍什么

**第1条：《下午四点，成都厨师先准备的一把串，后来进了哪一锅？》（反差）**

- 开头先拍下午四点的真实现场，再给一把当天确实要处理的串。
- 手机固定在安全位置，先拍手部和食材，再拍实际处理步骤，最后拍它进入锅里的画面。
- 旁白只说当天实际做了什么，不写“最先备的”“每天都这样”之类未经核实的结论。若当天流程不是先做这一把，就据实调整标题，不能为标题倒置流程。
- 看点一句话：下午四点的备料现场和晚饭成品连在一起，观众能看见一把串如何进入当天的晚饭。

**第2条：《南乐下班前，成都厨师正在给今晚备哪一口？》（人群）**

- 按当天真实工作，从串串火锅、烧烤、川菜中选正在准备的那一类，标题同步换成实际品类，不三类全塞进一条。
- 先拍备料台，再跟拍一个完整、真实的操作环节，最后落到当天确实完成的状态。
- 不补写下班时间、不假装顾客催单。
- 看点一句话：用下班前的晚饭场景，把观众带进正在发生的备餐现场。

**第3条：《同一把食材，从下午四点的备料台走到今晚的桌上》（反差）**

- 只选当天能拍完整的一种产品，画面按实际流程衔接。
- 若能拍到出餐就以真实出餐为结尾；若拍不到顾客桌面，就以当天完成的成品为结尾，不虚构顾客用餐。
- 看点一句话：同一份货物前后连贯出现，观众能看懂这段过程如何收尾。
- 这里的“反差”来自时间阶段与画面状态变化，不夸成品质差异，也不拿普通做法或其他店作对照。

### 边界

- 不拍假顾客反应、假排队、假评论，不让员工演顾客。
- 不把“成都口味”和“南乐口味”写成对立或评判；地域差异必须有实际例子支撑。
- 不说某个动作“保证更好吃”，除非能用明确、可核实的事实解释其作用。
- 一条视频只讲一个主要品类，不为了填栏目强行让串串、烧烤、川菜同时入镜。
- 拍摄不得影响备餐安全；手机不放在火源、食材操作面或顾客通行的位置。

## 🔄 备选打法

### 第31计·南北/地域差异

**什么时候切过去：**厨师能说出一件亲身经历过、可在画面里讲清的地域饮食差异，并能确认不是以偏概全时再拍。在此之前，不能凭“成都厨师来到南乐”直接推断两地习惯不同。

**为什么是你能拍的：**成都籍贯和在南乐经营的经历已经确认，人物与地点真实存在；拍摄仍可由厨师本人在工作现场完成，不依赖街访或演员。

**怎么套、配什么结构：**同一项真实备餐任务→厨师讲自己在成都形成的做法→展示在店内实际采用的做法→把差异范围说清楚。配**教知识·解题型**，但前提是问题和解释经过厨师本人确认。流量版只做地域交流，结尾问“你们那边会怎么做？”；不拿差异当成“谁更正宗”的评判。

### 第7计·一句话设定故事感

**什么时候切过去：**补到一个真实的职业经历或来南乐后的具体工作事件，有时间、动作和结果，且厨师能讲清楚前因后果时再切。现有资料只能确认籍贯、年限、来南乐时间和下午四点出摊，不能据此补写艰难创业、顾客感动或重大转折。

**为什么是你能拍的：**主角本人就是厨师，日常备餐动作已确认；只要故事是真实发生的，一部手机即可拍动作和本人讲述，不需要其他人表演。

**怎么套、配什么结构：**用一句已核实的背景交代“今天这个动作为什么对他有意义”，随后拍真实动作和结果。配**讲故事·平凡英雄型**仅在确有一件具体小事时使用；若只有职业背景、没有事件，就不强行套故事结构，继续用晒过程。

### 第17计·互联网嘴替/替网友做

**什么时候切过去：**账号收到一条真实、可复述的点单问题，且店里确认能用现有菜单和实际备餐回答时再切；没有真实评论，不模拟网友留言。

**为什么是你能拍的：**掌勺厨师能在自己的工作现场直接处理真实问题；不要求顾客出镜，手机拍问题字幕、实际准备过程和真实结果即可。

**怎么套、配什么结构：**展示真实问题→厨师按店内实际菜单准备对应内容→拍关键过程→说明适用条件和已确认信息。配**晒过程·火车节**。若问题涉及价格、分量或人数，先向店内核实再上字幕；没核实就不写。

## 🧪 怎么测

### 一次只改一个变量

主攻打法的事件、食材跟拍方式和结尾类型先固定。第一轮只改**开头第一句话或首帧画面**，不同时改标题、人群、时长、字幕和剪辑节奏。比如一条从下午四点的现场开场，下一条从一把串的近景开场；正文仍按当天真实流程拍。

### 每计测几条、看什么

- **主攻第32计：**先测三至五条，串串火锅、烧烤、川菜轮流进入；逐条记录非关注用户播放占比、前三秒停留、完播、分享、新粉和本地评论。
- **备选第31计：**有真实地域素材后再测三至五条。除了流量指标，检查评论是否围绕具体吃法交流，而不是把未经证实的地域判断当事实传播。
- **备选第7计：**补齐真实事件后再测三至五条，重点看主页访问、关注和评论里是否出现对厨师本人职业经历的回应。
- **备选第17计：**有真实问题后再测三至五条，重点看评论是否继续提出点单问题、是否出现有效到店咨询；不能把模拟评论造成的互动当成结果。

### 什么信号算“这计行”，什么信号算“换掉”

- **算行：**至少一组连续作品的非关注播放和完播表现相对稳定，有本地用户看完后讨论晚饭、品类或具体备料过程；出现用户主动问“今晚做什么”“这是什么菜”之类与账号主题相连的反馈。单条高播放不够。
- **先改开头，不急着换计：**曝光有了，但前三秒明显流失；或者画面看得懂，第一句话没说清“下午四点、成都厨师、晚饭”之间的关系。
- **考虑换掉：**同一打法按单变量测试，完成至少三至五条后，仍持续出现前段流失、完播弱、评论与本地晚饭无关；复核拍摄后确认不是首帧、收音或流程断裂问题，再切到有真实素材支撑的备选打法。
- **同时看受众质量：**播放量高但新粉和本地互动弱，不算真正跑通。若用户只记住一元火锅、对烧烤和川菜没有认知，就减少重复价格入口，补拍其他品类的真实过程。

## 📅 30 天节奏

发布频次不预设：档案没有确认团队人数和每周可拍时间，不把计划写成每天一条。以每次实际开工、每次完成一条为单位；拍摄要在真实备餐过程中完成，剪辑和发布按团队确认的产能安排。

### 第1周：把主攻拍法做成可执行模板

- **任务：**核实可拍区域、手机固定方式、收音条件和备餐流程；选一份当天确实要做的食材，拍一条从下午四点现场到真实结果的样片。
- **交付物：**一份手机机位清单、一条主攻样片、一份真实动作顺序记录。
- **代表标题：**《下午四点，成都厨师先准备的一把串，后来进了哪一锅？》

### 第2周：连续测试主攻，不改核心事件

- **任务：**围绕同一个“跟着食材走”结构拍三至五条；内容随当天真实食材变化，但不把改变食材误当成改变方法。每条只改一个开头变量。
- **交付物：**三至五条发布作品、逐条数据记录、有效评论摘录。
- **代表标题：**《南乐下班前，成都厨师正在给今晚备哪一口？》

### 第3周：让三类产品都进入主力镜头

- **任务：**轮流拍川味串串火锅、川味烧烤、川菜。某类当天没有真实备餐就不硬拍；先完成已有现场，再决定下一次拍摄内容。
- **交付物：**三类产品的真实过程素材各一组；完成后按前两周数据找出开头留存较好的表达。
- **代表标题：**《同一把食材，从下午四点的备料台走到今晚的桌上》

### 第4周：主攻复测，补一条有依据的内容

- **任务：**继续用数据表现较好的开头拍主攻系列；若收到真实点单问题，核实后拍一条变现型视频；若取得真实地域经历或职业事件，再安排相应备选。没有素材就不为凑数拍故事。
- **交付物：**主攻复测作品、一个真实问题或职业事件素材卡、三十天复盘结论。
- **代表标题：**《今晚想吃川味，厨师从下午四点开始准备什么？》  
  该标题仅在当天确实开始准备相应菜品时使用；否则按当天实际品类改写。

三十天结束不以“发满多少条”作为唯一结论，而是看主攻打法是否出现连续可复现的本地反馈。若拍摄产能不足，先保住真实、连贯的主攻作品，不用补拍假剧情或虚构顾客故事。
