## 📊 节奏自检

- 景别分布：特写 4 个 / 近景 4 个 / 中景 3 个 / 全景 4 个 / 远景 1 个
- 特写占比：25%（用于呈现坐垫、扶手、坐下视角等具体观察动作，不替代口播讲解）
- 运动镜头占比：6%（仅镜头13为摇镜，手机无稳定器也能完成）
- 最长镜头：5s（保留结尾完整总结和评论引导，避免行动指令被切碎）
- 开场 3 秒内镜头数：1 个
- 总时长：60s
- 是否存在同一景别连续超过 3 个：否

> **删减/压缩建议：无。** 当前执行口播以第2步“纯文字文案”为准，配合坐下、换位、起身和观察空间的动作，可以落在60秒内；不要把文档中的策略卡、分镜说明和执行建议念进视频。

## 🧰 拍摄清单

- **必备**：手机 + 手机三脚架或桌面支架 + 干净纸巾（拍前擦镜头）+ 一张可正常坐下和起身的布艺沙发。
- **加分项**：领夹麦（减少门店环境声对口播的影响）；补光灯（放在老周斜前方，让脸部和布艺纹理更清楚）；第二个手机支架（方便固定低机位视角）。
- **道具与场地**：整理好的布艺沙发区域、沙发周边实际通道、无遮挡的地面；拍摄前移开画面内杂物，保留沙发周边真实空间关系。

## ⚠️ 这条片子最容易翻车的 3 个地方

1. 【“换个视角”只剩换机位】观众只看到不同角度的沙发，看不到为什么要换视角 →【怎么避】镜头6和镜头9必须拍成坐下者的第一人称画面，镜头12到14必须拍出起身后观察沙发周边空间的过程。

2. 【坐下、换位动作被剪碎】老周刚坐下就切走，观众看不清“自然换位置、靠一靠”的观察动作 →【怎么避】镜头7、10、11分别完整录下坐下、换位置、靠向靠背，每个动作完成后停稳再切镜。
