## 1. 原主题、核心方向、目标人群和视频目的

- **原主题**：买沙发时，不只看价格和外观，要看内部木料能否支撑使用；这是材料直接给出的。  
- **核心方向**：用一块木头讲沙发耐用性，属于「选家具的常识、木料辨认」方向；与账号档案一致。  
- **目标人群**：已给出的是县城本地28—45岁、新婚家庭和换房业主；原稿中的“买沙发的人”是进一步圈定。  
- **主目的：变现型**。理由是原稿把“木料”作为选择依据，服务于卖沙发和建立购买信任，而非单纯追求讨论或展示老板经历。材料品类、经营做法与档案一致，但无法仅凭文字确认原稿作者。  

## 2. 出发点（2026-10-29）

原文围绕**货**展开：从“沙发会不会塌”的使用风险，转到“木料纹路”这个可展示的选购依据。它符合“三有”中的**有用**，用了八大爆款元素里的**最差**和**成本**：把“坐三个月就塌”设计在钩子里，放大买错后的损失；“一块木头”则是结构里的实体证据。  

## 3. 开篇钩子、脚本结构、信息递进、情绪和结尾行动

- **开篇钩子**：“买沙发最怕的不是贵，是买回家坐三个月就塌。”用了开篇36计的**损失厌恶**，也对应八大爆款元素的**最差、成本**；六大钩子可归为**验证解密**的前置问题。  
- **脚本结构**：最接近注册表中的**教知识·解题型**：购买风险→换一个判断视角→承诺解释判断依据。但原稿只有问题和承诺，缺少真正的“具体操作步骤”，结构尚未走完。  
- **信息递进**：先用“贵”与“塌”形成对比，再用“今天不卖沙发”制造反认知，最后拿出“木头、纹路”承接验证；其中“我今天不卖沙发”可借鉴**36计·第1计 反向操作**的表达机制。  
- **情绪和结尾行动**：情绪接近**共鸣爆发型**：怕买错→发现原来该看木料→等待答案。原稿没有行动指令，也没有兑现“为什么撑得住”的完整解释；“撑得住”涉及具体材料、结构和工艺，当前属于待核实经营事实。  

## 4. 能保留的创意与需要优化的问题

**可保留：**“不先卖成品，先拿材料说话”的反向表达很适合老周；账号有自家木工工坊、木料可现场看的事实支撑，能把抽象的“耐用”变成客户眼前可看的东西。  

**需要优化：**第一，“坐三个月就塌”容易显得绝对，改成“坐一阵子发现松、晃、塌”更稳妥；第二，不能只让客户看纹路，要补足“看哪里、为什么看、怎么看”的步骤；第三，结尾应加一个到店动作。木料品种、沙发框架具体做法、承重效果均未核实，不应写成既定事实。
