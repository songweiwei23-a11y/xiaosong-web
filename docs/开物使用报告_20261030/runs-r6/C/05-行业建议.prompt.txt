- **归口**：本地实体店，属于 **D 家居家电类**，其中以家具零售为主，兼具本地服务属性。顾客买的不只是桌椅或沙发，也是在为“能不能放进我家、耐不耐用、出了问题找不找得到人”做决策。

- **这行的钱怎么赚**：  
  家具是低频、高决策商品，收入主要来自单次成套购买，而不是像餐饮一样靠高频复购。实木餐桌椅和布艺沙发通常会带动客厅、餐厅整体搭配需求，但档案未提供客单、品类利润和成交结构，**待确认：哪一类产品更常被顾客作为首单购买**。  
  获客最卡的不是“让人知道店存在”，而是让顾客在比较几家后，愿意专程进店坐一坐、摸一摸、看一眼材料。线上内容的任务，是先把“这家能现场看木料”变成顾客到店的理由。

- **客人的决策链路**：  
  这不是刷到视频就立刻下单的品类。新婚家庭往往要等装修进度、和家人商量尺寸及预算；换房业主通常会先看风格，再比较材质、坐感、尺寸和价格。  
  所以视频不能只追求“看着高级”，还要提前回答顾客到店前最常问的事：餐桌怎么选、木料怎么看、布艺沙发怎么试坐。短视频负责降低第一次进店的心理门槛，到店现场负责完成比较和成交。

- **时间规律**：  
  家具需求常跟装修交房、搬家、结婚、节假日家庭聚会前的置换有关。周末和节假日前，顾客更容易带着家人一起看；工作日则更适合拍工坊加工、到货检查、木料挑选等过程。  
  具体旺淡季受当地交房节奏、婚嫁习惯影响较大，**待确认：本地哪几个月进店看家具的人明显更多**，之后再把内容主题跟着节点走。

### 2. 用户定位

- **一句话画像**：  
  **正在装修收尾或准备换房，家里人反复问“餐桌放不放得下、沙发坐久了舒不舒服”，已经刷了不少家具视频，却还没敢直接下决定的县城家庭决策者。**

- **主攻人群**：  
  **精致妈妈 + 资深中产。**  
  精致妈妈通常要兼顾孩子活动、清洁维护、老人来家里坐、日常使用；她不是只问好不好看，更关心放进家后是不是省心。  
  资深中产更在意接待亲友时的体面、材料是否看得明白、门店是否找得到人。家具属于长期使用品，他们未必只追最低价，更怕买错后天天看着不舒服。

- **为什么是他们、不是另一批**：  
  内容不优先服务只想看“最低多少钱”、不愿意到店看材料和试坐的人；也不优先服务还没进入装修或换房阶段、纯粹围观家具的人。  
  这不是拒绝成交，而是账号有限的内容资源，要优先服务真正会进入比较、到店、决策链路的人。

- **他们心里真正在想什么**：  
  “网上看着都差不多，买回家才发现尺寸不对、坐着不舒服、材料也说不清，到时候找谁？”  
  这句话决定内容不能只讲审美，还要把“看得见、问得明、能到店”的安全感做出来。

- **决策链路**：  
  刷到老周的过程内容或家具判断内容 → 记住“这家能现场看木料” → 连续观察几条餐桌、沙发相关内容 → 收藏或转给家人商量 → 到店看料、量尺寸、试坐 → 再决定购买。

### 3. 内容定位

- **长期提供什么价值**：  
  **让县城家庭看懂家具，再放心到店决定。**

- **内容方向**：  
  选择 **多元四类打底 + 工坊过程做王牌栏目**。  
  原因是老周有持续发生的工坊场景，但档案尚未证明每天都有足够强的单一任务或人物事件，直接把全号押成单一主题，容易拍成重复的加工流水账。先用知识、过程、故事、观点建立内容面，再从工坊过程里筛出能长期连载的栏目。

- **当前阶段配比**：  
  - **作用配比**：流量型45% / 人设型25% / 变现型30%。  
    这是起号期适合的结构：流量型最大，先解决陌生人看不见的问题；人设型让“老周”不只是一个卖家具的人；变现型从一开始就放入，但不让主页像连续广告。  
  - **流量型怎么做**：主用反常识知识、工坊反差过程、县城家庭共鸣话题。重点不是推“我家木料能看”，而是让陌生人停下来，例如“餐桌看着厚，不代表适合小户型”“一张桌子进工坊前先要过哪几关”。形式以短知识、过程、少量一人分饰多角为主。  
  - **人设型怎么做**：主用真实职业故事、老周的工作判断、工坊日常。重点让观众看见他怎么做事，而不是让他对镜头自夸。形式以故事、过程和基于真实经历的观点为主。  
  - **变现型怎么做**：主用现场看料、试坐判断、产品对比分析、顾客常问问题。实木家具重点突出“木料可现场看”，布艺沙发重点围绕“怎么挑不踩坑”的真实需求展开。形式以教知识、晒过程为主。  
  - **题材安排**：主赛道是实木家具、布艺沙发及工坊过程；目标人群兴趣占一部分，围绕新房入住、换房、家庭聚餐、接待父母、孩子活动空间等真实生活场景展开。

- **主力形式**：  
  档案没有提供“数据最好的内容类型”，不能假装已经验证。现阶段暂定 **工坊过程+现场判断** 为主力测试形式，因为这是这家店最难被同行复制的真实素材源。  
  如果连续测试后，观众只看加工、不问产品和到店，则把知识型“选餐桌、挑沙发”的位置往上加一档；如果知识内容收藏多但主页访问弱，则增加老周出镜和工坊判断，让内容回到人和现场。

- **每类内容管哪一段路**：  
  - **刷到**：流量型用反差、冷知识、家庭场景让陌生人停下。  
  - **记住**：人设型反复让老周在工坊做真实判断，形成“在工坊里讲家具”的记忆。  
  - **信**：变现型让顾客看到木料、产品、试坐和判断依据。  
  - **联系**：变现型明确引导到店看料、试坐，完成从线上到线下的动作。

- **三种视频各怎么拍**：

  **流量型**  
  - 四大脚本：方向是“新房家庭挑家具时最容易误判的地方”；用**教知识·拆解型**，以反常识结论开头，再现场拿一张餐桌或一块木料讲明白。结尾只用：**“你家餐桌最纠结哪一点，评论区说说。”**  
  - 起号36计：**第36计·冷知识：**“看起来很厚的餐桌，不一定适合你家”→老周拿现场桌板做例子→解释尺寸与空间的关系→问观众家里餐厅多大。产品只做画面道具，不讲购买理由。

  **人设型**  
  - 四大脚本：方向是“老周做家具时坚持亲自看的一个环节”；用**讲故事·平凡英雄型**，普通一天开场→一个具体订单里的检查动作→为什么他会停下来确认→落到做家具12年的真实感悟。结尾只用：**“想看工坊里真实干活，就关注老周。”**  
  - 起号36计：**第7计·一句话设定故事感：**老周拿着一块准备加工的木料说：“这块料今天不进机器，先等客户来看一眼。”→带出真实原因与后续处理。前提是该事件真实发生。

# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

这家店属于本地实体店里的 **D家居家电类**，实际经营逻辑不是“把家具摆出来等人买”，而是通过一次家庭大件消费完成成交。

家具的利润通常集中在单次成交，而不是高频复购。实木家具、布艺沙发都属于低频、高决策品类，顾客不会因为刷到一条视频就立刻付款，通常要经历看图、问家人、比尺寸、比价格、到店摸料、试坐，最后才决定。

这意味着获客成本不只是一笔广告费，还包括：

- 顾客反复咨询却没有到店；
- 到店后只比较价格；
- 看了很多内容，却没有形成“为什么到你店里看”的理由；
- 老板花时间接待，但顾客最后仍然去别家比较。

这家店目前最有价值的资源不是“店里有家具”，而是 **自家有木工工坊，顾客可以现场看木料**。普通展厅只能展示成品，老周可以把顾客的判断提前到木料和制作过程上。这能解决家具行业最难的一步：顾客不知道该相信什么。

### 毛利结构判断

我推测，实木家具的毛利空间主要受木料成本、加工工时、损耗、运输和展厅成本影响；布艺沙发则更多受面料、填充、框架、采购渠道和售后成本影响。两类产品的实际毛利不能只按售价判断，必须先补一张成本表。

**待确认：**

- 实木餐桌椅的进料成本、加工成本、运输成本；
- 布艺沙发的采购价、运输和售后成本；
- 是否存在定制、改尺寸、改颜色等额外工艺；
- 顾客从看货到成交平均需要几次沟通；
- 退换、维修和售后成本由谁承担。

在没有这些数据前，不给具体毛利百分比。可以先用这个公式核算：

> 单笔毛利 = 成交价 - 木料或采购成本 - 加工成本 - 运输安装成本 - 售后预留

真正需要追踪的不是“哪件家具卖得贵”，而是“哪类产品从抖音咨询到成交的时间更短、解释成本更低、售后争议更少”。

### 客人的决策周期

我推测，这个账号的顾客决策周期通常不会短于一次到店沟通，尤其是新婚家庭和换房业主。原因是家具要同时满足几个人：

- 一个人看外观；
- 另一个人看价格；
- 家里长辈可能看材质；
- 使用者会关心坐感、尺寸和清洁；
- 最后还要确认能不能放进家里。

所以视频不能只展示“好看”，要提前回答“我为什么要到店看”“到店应该看什么”“我怎么带家人判断”。

### 淡旺季与时段

家具需求通常跟装修进度、交房、搬家、结婚和家庭团聚有关。周末、下班后更适合到店，节假日前后更容易出现集中看家具的需求。

但不能只在节假日拍促销。淡季更应该拍木料、工坊、试坐、尺寸判断和顾客常问的问题，把信任提前建立起来。等顾客真正进入购买节点时，老周才有机会被想起来。

### 这行老板最容易犯的错

最常见的自嗨不是不会拍，而是拍错了重点：

- 拍“店里有很多款”，但顾客不知道该怎么选；
- 拍“今天又到货”，但顾客不知道和自己有什么关系；
- 反复说“质量好”，却不让顾客看到材料和制作过程；
- 只拍价格，吸引来只比低价的人；
- 工坊只是背景，老周没有把木料、加工和成品连接起来。

这个账号要明确不做“线上产品目录”。每一条视频都要让观众看见一个判断依据，或者看见老周正在做的一件真实工作。

### 一句话定位

**县城老周现场看料，买实木家具、布艺沙发少走弯路**

这句话同时包含了：

- 身份：县城老周；
- 特点：现场看料；
- 两个经营品类：实木家具、布艺沙发；
- 价值：帮助顾客少走弯路。

别人也能说“家具质量好”，但未必能让顾客进自家木工工坊看木料，这是这个账号的独有承诺。

- **内容价值：**通过真实试坐和家庭场景，降低顾客“买回家不合适”的担心。

#### 3. 到店选购判断服务

不是额外包装出来的咨询产品，而是成交过程中的服务价值，包括：

- 看木料；
- 判断餐桌尺寸；
- 试坐布艺沙发；
- 根据家庭使用情况提出选购建议。

目前没有证据表明这项服务单独收费，因此不能把它写成独立收费项目。它的作用是提高到店后的成交率和信任感。

#### 4. 工坊现场看料体验

目前更适合作为到店成交的信任环节，而不是单独收费产品。它能让顾客看到家具不是只从展厅成品开始，而是可以追溯到木料和制作过程。

**注意：**不能承诺“所有产品都能现场看完整制作过程”，除非老板确认具体哪些产品、哪些木料可以展示。

## 主推产品

### 主推成交场景：实木餐桌椅现场看料

这里的“主推”指第一阶段优先跑通的成交场景，不代表降低布艺沙发的经营位置。实木家具和布艺沙发仍然要在内容配比中分别出现。

选择实木餐桌椅作为第一阶段的主推成交场景，理由有三个：

1. **最能使用现有差异化资源。**  
   自家有木工工坊，现场看木料不是口号，而是可以直接拍出来的内容。

2. **更容易形成记忆点。**  
   “带你进工坊看料的老周”比“展厅里介绍家具的老板”更容易被记住。

3. **更适合建立专业信任。**  
   顾客买实木餐桌时，通常会问木料、纹理、尺寸、结构和制作过程，这些问题都能转化成视频主题。

布艺沙发不做配角。它需要单独建立“怎么试坐、怎么结合家庭使用来判断”的内容线。后续两类产品都要有各自的变现视频，不能让账号只剩木工坊。

## 成交路径

### 1. 第一次接触：先看到具体动作，不先看到广告

第一条接触内容建议从这些画面开始：

- 老周从工坊拿起一块真实木料；
- 木料纹理和加工位置的近景；
- 木工工具和打磨声音；
- 老周坐到布艺沙发上，演示真实坐姿；
- 从门店走进工坊的连续镜头。

开头不要先说“我们店有很多家具”，而是先让观众看到一个具体问题：

> “买实木餐桌，别先看摆出来的样子，先看这块料。”

或者：

> “买布艺沙发，坐一下就走，很多人其实没试到自己每天会坐的位置。”

**这一环节会流失的人：**只想看低价和促销的人。  
这是必要流失，因为只靠价格吸引来的观众，后面更容易反复比价，不能形成稳定成交。

### 2. 产生兴趣：让顾客带走一个判断方法

兴趣不能靠“这张桌子真漂亮”，而要靠一个清楚的问题：

- 这块木料最后会做成什么；
- 餐桌选尺寸时，家里几个人使用；
- 沙发试坐时要注意哪个位置；
- 工坊里的木料和成品之间有什么关系；
- 到店看家具，应该先看材料还是先看外观。

每条视频只解决一个小问题。信息太多，顾客记不住；只展示成品，又无法证明老周为什么值得信任。

### 3. 沉淀：主页先承担“确认真实”的作用

家具顾客不会只看一条视频就到店。主页至少要让他确认三件事：

1. 老周确实是老板本人；
2. 店里确实卖实木家具、布艺沙发；
3. 确实有自家木工工坊，可以现场看料。

主页内容建议形成三条固定证据线：

- **工坊线：**木料、加工、打磨、成品；
- **家具判断线：**实木餐桌椅怎么观察、布艺沙发怎么试坐；
- **老周线：**做家具12年的真实工作片段和现场回答。

私信不要只回复“在的”“欢迎到店”。至少先问三个必要信息：

- 看的是实木餐桌椅，还是布艺沙发；
- 家里大概是什么使用场景；
- 是否已经有尺寸或户型信息。

**这一环节会流失的人：**不愿意提供基本使用信息、只要求立刻报最低价的人。  
这不是拒绝顾客，而是避免把高决策产品变成无条件比价。

### 4. 临门一脚：到店看料、试坐

临门一脚不要同时说“私信、电话、加微信、到店、关注”。每条变现视频只保留一个动作：

> **“带着家里的尺寸，到店看料、试坐。”**

实木家具的视频重点是让顾客带着问题到店看木料；布艺沙发的视频重点是让顾客带着家庭使用情况到店试坐。

到店后的动作顺序建议固定：

1. 先问家庭使用人数和房间尺寸；
2. 再看对应品类；
3. 实木家具看木料、纹理、结构和成品；
4. 布艺沙发按日常坐姿试坐；
5. 最后再谈款式和价格。

这样做不是为了拖延报价，而是先把顾客的判断依据建立起来，减少“只看一眼价格就走”的情况。

## 信任证据清单

### 1. 老周本人在工坊里拿木料

- **画面：**老周拿起当天正在使用的一块木料，说明它会用于哪一步。
- **证明能力：**真实、专业。
- **注意：**木料具体名称、等级、性能没有资料时不能自行补充，要由老板确认。

### 2. 木料到成品的连续过程

- **画面：**同一块或同一批材料，拍木料、加工中、半成品、成品局部。
- **证明能力：**生产过程真实。
- **要求：**不能把不同材料剪成一条“像是同一张桌子”的假过程。

### 3. 老周现场回答顾客问题

- **画面：**顾客提问，老周在木料或家具旁回答。
- **证明能力：**专业判断和沟通能力。
- **要求：**顾客是否露脸、是否录音，要提前征得同意


## 输出要求

行业建议只管「这个阶段怎么打」，不重复定位。账号是谁（账号定位）、长期拍什么（内容定位）、靠什么成交（商业定位）已经定好，这里只引用它们的原名。按下面的结构输出 Markdown，每一节都落到这个账号和这个阶段上：

1. **本阶段判断**：这个阶段和目的下，现状和目标之间差在哪里，依据是档案和作品数据。数据不够就直说不够。
2. **本阶段重心方向**：给 2–3 个建议方向，优先引用内容定位里已有的系列原名。每个写清：这一阶段它负责哪个目的（流量、人设、变现）、在本阶段是主力还是辅助（只写主次，不写百分数）、为什么选它（对准哪个真实需求，依据档案的哪条事实）。这是建议，用户自己选定的方向优先。
3. **每类目的的结尾动作**：流量、人设、变现各一个结尾动作，每类只留一个。变现型的动作要对应商业定位里的哪一步，写出原步骤名。
4. **本阶段暂停什么**：2–3 条，每条写依据（禁忌、档案，或内容定位里的排除项）。
5. **30 天执行规则**：3 条，只约束选题和脚本怎么做（例如「每条都要在前 5 秒说出位置」），不重述定位。
6. **复诊条件**：出现哪些迹象就该换阶段，换的时候重心怎么变。只写可以观察的迹象（例如「连续几条都有陌生人在评论区问地址」），用这个号自己过去的数据比；**不写任何具体数字**（播放量、新客人数、连续条数都不写）。

## 硬约束

- 药方是建议，不是命令。用户选定的方向优先：用户的方向不在内容定位里，就照用户的方向给建议，并说明它和内容定位、本阶段重心的差距，不阻止、不改写。
- 不替用户新增或改写内容定位。如果本阶段反复需要内容定位里没有的方向，只写「建议把它加进内容定位」，由用户决定。
- 拍小票、结账、价格画面时，金额一律用【待确认】或「金额打码」，档案里没有的数字不写。
- 不重述账号定位（这个号是谁、说给谁、凭什么信）、内容定位（长期拍什么）、商业定位（靠什么赚钱）的内容，只引用原名。
- 内容定位已有，第 2 节优先引用它的原系列名。
- 商业定位已有，第 3 节的变现动作写出原步骤名。
- 不编造任何数字、案例、客户故事、效果承诺。缺的事实用【待确认】标出
- 百分数只能照抄「已做过的内容定位」里的作用配比（流量 / 人设 / 变现）；内容定位里没有的，一律不写百分数，只写主次词（主力、辅助、少量）
- 价格、价位、人均、营业时间、地址、作息、门店活动，只有档案或素材里写了才能用。档案里没有的，写成「价格摆在明面」这类做法即可，具体数字用【待确认】占位，不要替它定价
- 阈值类数字（完播率、播放量、咨询人数、转化率）一律不给具体合格线，例如「完播低于 X% 就换」。改成和这个号自己过去的数据比较；没有历史数据就写「待建立」
- 档案里写着「未填」「待补充」或留空的项，不当作事实使用，也不凭行业印象补成具体值；推断出来的内容要标明是推断
- 与账号档案的事实冲突时以档案为准
- 禁忌里写的不能说、不能拍，方案里一律不出现
- 不输出寒暄和过程说明，只输出方案正文
