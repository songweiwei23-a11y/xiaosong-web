# 🚀 起号方案

## 📌 先说结论

- **建议主攻：第32计·换个视角。**  
  用《老周在工坊替你先看一眼》做起号主栏目：顾客平时只看到餐桌、椅子等成品，镜头跟着老周从木料区走进工坊，拍“成品出现前，老周先确认什么”。  
  这计最贴合老周现有资源：他本人就在店里，自家有木工工坊，有实木餐桌椅和木料可持续拍；不依赖顾客出镜，不依赖多人表演，也不需要编订单故事。它既能让陌生用户看见工坊，又能把工坊动作翻译成新房家庭听得懂的家具问题。

- **备选：第36计·冷知识、第15计·正确做法VS错误做法、第7计·一句话设定故事感。**  
  当“换个视角”连续拍到第3—5条，前段停留和完播仍然偏弱，切到第36计·冷知识，用“餐桌不是越大越好”“沙发不是只看颜色”这种反常识结论拉住陌生人；当评论开始集中问“沙发怎么挑”“到店看什么”，切到第15计·正确做法VS错误做法，承接布艺沙发变现内容；当主页访问有、关注偏少，切到第7计·一句话设定故事感，让用户记住“在工坊里做判断的老周”。

- **明确不做：第35计·街头采访。**  
  县城家具店的目标用户是新婚家庭、换房业主，不需要为了热闹在街上随机问人。街访需要稳定出镜对象、现场收音和临场剪辑，且回答很容易偏离家具决策，拍出来热闹但接不回实木家具和布艺沙发。

- **明确不做：第30计·角色扮演。**  
  当前没有确认老周擅长表演，也没有确认有搭档。让店员扮顾客、把模拟咨询拍成真实咨询，会削弱家具这种高决策生意最需要的信任。账号前期先让用户看到真实木料、真实工坊和真实判断。

- **多久能看出跑没跑通：**  
  先围绕第32计·换个视角连续拍3—5条，再与第36计·冷知识各做一组对照。首月不拿单条播放量下结论，重点看非关注播放、前段流失、完播、新粉和评论里的真实家具问题。  
  起号参考线是：**从零粉到一千粉，并且作品流量开始稳定。** 但这不是唯一判断标准；本号还要看县城本地用户是否开始问尺寸、木料、试坐和到店看料。达到这条线前，主栏目不频繁换；过了这条线，再补强人设和变现承接。

## 🧮 起号期内容配比

### 起号期：流量型45% / 人设型25% / 变现型30%

这个配比直接沿用已定内容定位。

- **流量型45%**是起号主力。家具是低频高决策品，新号先要让装修收尾、换房、新婚家庭刷到老周。流量内容不讲门店卖点，不报价格，不引导到店，只解决一个大众听得懂的问题：餐桌为什么不能只看大小、木料为什么不能只看颜色、沙发为什么不能只看外观。

- **人设型25%**负责让用户记住老周。家具决策周期长，用户不是刷到一条就进店，而是在反复比较中判断：这个老板说话是否清楚，遇到尺寸和使用问题时会不会先确认。人设内容不卖产品，只拍老周在工坊里做判断、暂缓动作、复核问题的真实职业日常。

- **变现型30%**从第一周就稳定出现，但每条只讲一个到店判断动作。实木家具的成交理由是“自家工坊，木料可现场看”；布艺沙发的成交理由是“到店能实际试坐、摸面料、确认家庭使用需求”。变现内容不做电子画册，而是把顾客到店后真正能做什么拍出来。

### 每一种怎么拍

#### 1. 流量型：主推工坊视角

- **出发点：**  
  人是做家具12年的本地老板老周；货是实木餐桌椅、木料；场是自家木工工坊。  
  爆款元素主用**反差**和**人群**：顾客看到成品，工坊先看木料；新房家庭想要“大气”，实际还要先看餐厅空间。

- **主用形式：第32计·换个视角 + 晒过程·过程展示。**  
  结构：**顾客常见视角里的成品家具 → 镜头切进工坊里的真实判断动作 → 老周用家庭语言解释这一步和谁有关 → 留一个具体问题。**

- **结尾行动指令：**  
  “你家挑家具最纠结尺寸、材质还是坐感？评论区说说。”

流量型视频里，木料和家具只作为内容主体出现，不讲“我们家更好”，不带“到店找我”。用户先因为一个自己家的问题停下，再逐步记住老周在工坊里讲家具。

#### 2. 人设型：拍老周的判断边界

- **出发点：**  
  人设不是“老周专业、老周靠谱”这种形容词，而是拍他真实做了什么。已知真实事实是：老周做家具12年、本地人、老板本人出镜、自家有木工工坊。  
  人设重点立住一句话：**老周不急着把家具做出来，先把它放进谁家、怎么用问明白。**

- **主用形式：第7计·一句话设定故事感 + 讲故事·平凡英雄型。**  
  结构：**一个普通工坊动作 → 一句真实背景设定 → 老周停下来确认什么 → 这个确认和他做家具12年的判断有什么关系。**

- **结尾行动指令：**  
  “想看老周在工坊里怎么做判断，就关注。”

人设内容必须基于真实事件。  
待确认素材：老周最近一次“暂缓加工、复核尺寸、让顾客先确认使用需求”的具体事件。先问清三件事：当时做的是什么家具、发现了什么需要确认的点、最后确认了什么。没有这三件事，就不拍成故事，只拍普通职业日常。

#### 3. 变现型：让用户看见到店后能判断什么

- **出发点：**  
  人是新婚家庭、换房业主；货是实木餐桌椅、布艺沙发；场是门店沙发区、木料区、工坊。  
  成交理由只用已有事实：**自家工坊、木料可现场看、布艺沙发能现场试坐。**

- **主用形式：第15计·正确做法VS错误做法 + 教知识·解题型。**  
  结构：**只站着看外观的常见做法 → 漏掉的家庭使用问题 → 老周现场演示正确判断顺序 → 说清什么家庭要重点看什么。**

- **结尾行动指令：**  
  “想现场看木料、试坐沙发，直接到店找老周。”

变现内容里，主角始终是实木家具和布艺沙发本身。拍沙发时，演示的是试坐、按坐垫、摸面料、确认谁使用；拍餐桌时，演示的是看木料、看实物、确认空间。不能把重点拍成“换个摆法就显大”“改个坐姿就舒服”，那样用户学会技巧后，不需要到店看产品。

### 过线之后怎么调

当账号跨过零粉到一千粉、作品流量开始稳定这条线后：

- 流量型仍然保持主力，但从单个反差问题扩展到“新房收尾”“换房家庭”“接待父母”等更完整的生活场景。
- 人设型往上加一档，增加老周的真实职业经历、工坊判断和真实顾客沟通细节。
- 变现型往上加一档，增加到店看木料、试坐布艺沙发、量尺寸的真实过程，但仍然一条只放一个成交理由。

### 和已定内容定位怎么对上

主攻第32计·换个视角，正好服务王牌栏目**《老周在工坊替你先看一眼》**。  
主力形式仍然是晒过程和知识：工坊提供真实过程，老周负责把动作解释成用户关心的尺寸、材质、坐感和家庭使用问题。布艺沙发则由第15计·正确做法VS错误做法承接，保证两个经营品类都持续出现，不把账号做成只拍木料的同行号。

## 🎯 主攻打法：第32计·换个视角

### 为什么是老周能拍的

1. **有真实场。**  
   老周有自家木工工坊，木料、工作台、待做餐桌椅就是天然画面，不用搭景，不用找外拍地点。

2. **有真实货。**  
   实木餐桌椅从木料到成品，本身就具备“顾客看见的”和“工坊先确认的”两层视角。镜头跟着木料走，画面有动作，不会变成站在店里空讲知识。

3. **有真实人。**  
   老周是老板本人，做家具12年。他不需要表演顾客，只要做平时真实会做的检查、量尺、确认动作，就能把“老板在工坊里干什么”拍出来。

4. **不依赖未确认资源。**  
   档案没有确认团队人数、专业设备和出镜搭档，这套打法不把多人拍摄作为前提。每条都按“老周本人出镜、固定机位拍动作、补拍手部和木料细节”的方式设计。  
   待确认：店内是否已有稳定手机支架和收音设备。没有时，先用安静工坊时段拍同期声，字幕补足关键信息。

### 结构公式

**第32计·换个视角：常规事件 + 新POV → 新信息/情绪。**

套到账号上：

**顾客看到一张餐桌成品 → 镜头从木料区跟着老周走到工作台 → 老周完成一个真实检查或确认动作 → 说清“这一步影响的不是工坊好不好看，而是这张桌子进家后和谁、怎么用有关” → 评论区提问。**

这一计的核心不是换机位，而是换叙事主体：  
顾客的视角是“这张桌子好不好看”；工坊的视角是“做它之前，先要确认哪件和家庭有关的事”。

### 配什么脚本讲

配**晒过程·过程展示**。

- **第32计·换个视角**负责片子里发生什么：从成品背后，带用户进入木料和工坊的真实动作。
- **晒过程·过程展示**负责把话讲清楚：不把加工拍成流水账，而是只挑一个动作讲透，例如量空间、看木料、确认边角使用场景。
- 它补上的是**信息密度和真实性**。工坊动作真实发生，老周不用背大段术语；用户看到动作，再听一句家庭语言解释，容易明白“这和我家有什么关系”。

主攻阶段不把成交理由塞进这类流量片。视频只让用户记住：老周不是在展示机器，而是在替普通家庭先看一道家具判断。

### 前3条具体拍什么

#### 第1条  
**标题：《顾客看到的是餐桌，老周进工坊先看的却是这块木料》**（反差）

- **最强看点：** 一张看起来已经很完整的餐桌，前面真正决定它从哪里开始，普通顾客平时看不到。
- **拍摄要点：**  
  首帧放成品餐桌，镜头立刻切到老周手里的一块待用木料。  
  老周从木料区走到工作台，做当天真实的第一项检查动作；镜头拍手部、木料纹理、工作台，不拍空镜头堆砌。  
  口播只讲一句：“顾客来店里先看桌子，我们进工坊，先从这块料开始看。”  
  再补一句真实解释：“因为桌子做出来以后，是每天吃饭、拉椅子、擦桌面的人在用，不是只摆着看。”
- **结尾：**  
  “你家买餐桌，第一眼先看样式还是先看材质？评论区说说。”

#### 第2条  
**标题：《新房餐厅不大，餐桌开工前为什么先拿卷尺？》**（人群）

- **最强看点：** 很多人以为餐桌只要能摆进去就行，老周先量的是坐下以后还能不能走路。
- **拍摄要点：**  
  首帧是卷尺拉开，旁边放一张餐桌和椅子。  
  老周演示真实的量尺逻辑：桌边、椅子拉开的位置、通道位置依次拍清，不下固定尺寸结论，不编“标准距离”。  
  口播：“餐桌能放下，不等于一家人坐下以后还有路走。开工前先问清餐厅怎么用，比先挑桌面颜色更重要。”
- **结尾：**  
  “你家餐厅最怕不够放桌子，还是不够走路？评论区说说。”

#### 第3条  
**标题：《家里常来人吃饭，餐桌开工前老周先把哪件事问清？》**（人群）

- **最强看点：** 同一张餐桌，不同家庭用法不同；“常来人吃饭”会直接改变老周要确认的问题。
- **拍摄要点：**  
  老周站在待做餐桌旁，先问镜头一句：“你家平时是几个人吃饭，来亲戚时怎么坐？”  
  随后拍他把椅子拉开、摆出日常使用位置的动作。  
  文案只讲“先确认日常人数和来客场景”，不承诺一张桌子解决所有聚餐问题，不给未核实的尺寸方案。
- **结尾：**  
  “你家餐桌最常坐几个人？评论区说说。”

### 边界

- 不把工坊拍成纯机器运转合集。每条必须落到一个家庭问题：尺寸、使用人数、日常活动、边角、餐椅拉开后的通道。
- 不把木料专业术语堆给用户。老周每条只讲一个普通家庭听得懂的判断，不讲成同行教学。
- 不用“最耐用”“绝不会开裂”“一张桌子用很多年”这类无法由当前资料证实的话。
- 不为了反差而把普通产品说差，也不把同行、顾客写成反面角色。
- 不拍未经顾客同意的脸、聊天记录、家庭地址和订单信息。

## 🔄 备选打法

### 第36计·冷知识

**切换条件：** 第32计·换个视角有画面但前段流失明显，用户看见木料和工坊却没立刻明白“和我有什么关系”时，切到第36计·冷知识。  
**为什么老周能拍：** 老周有实木餐桌椅、木料和布艺沙发实物，反常识结论能当场拿产品、卷尺、椅子和试坐动作证明，不需要空口说观点。  
**怎么套：** “餐桌看着大气，不等于适合小餐厅”→拍椅子拉开后的通道→讲空间和日常走动的关系→问观众家里最纠结什么。  
**配的四大脚本：教知识·解题型。** 它补的是陌生用户的理解门槛：先用反常识结论把人留下，再用现场动作讲清问题。

### 第15计·正确做法VS错误做法

**切换条件：** 评论区开始出现“布艺沙发怎么挑”“有孩子怎么选”“坐着舒服怎么看”这类具体问题，或者主页访问不少、到店咨询偏少时，切到第15计·正确做法VS错误做法。  
**为什么老周能拍：** 门店有布艺沙发实物，老周能在同一张沙发上完成站着看、坐下试、按坐垫、摸面料、问家庭需求等真实动作，不需要顾客配合。  
**怎么套：** “只站着看颜色”→漏掉谁坐、坐多久、怎么打理的问题→老周演示试坐与确认顺序→说清适用条件。  
**配的四大脚本：教知识·解题型。** 它补的是变现承接，把“怎么挑不踩坑”的常见提问变成一套到店能做的检查顺序。结尾只落“直接到店找老周”。

### 第7计·一句话设定故事感

**切换条件：** 工坊内容有观看、主页访问有增长，但关注偏弱，用户只记得“看了家具知识”，没记住“老周是谁”时，切到第7计·一句话设定故事感。  
**为什么老周能拍：** 老周每天就在工坊，普通动作本身真实：停下检查、量尺寸、整理木料、确认待做餐桌。只需一句真实背景，就能让动作有故事，不需要编顾客冲突。  
**怎么套：** “这块料今天先不进机器，因为有一件和客户家里有关的事还没确认。”→拍老周真实确认动作→说明确认的内容→回到“先适合家，再谈样式”。  
**配的四大脚本：讲故事·平凡英雄型。** 它补的是人设记忆点，让用户看到老周做家具时的边界感。  
待确认：用于该系列的真实事件，要先补齐“什么家具、什么问题、老周确认了什么”。

## 🧪 怎么测

### 一次只改一个核心变量

主攻第32计·换个视角时，第一轮只测**开头承诺**，不同时换标题、拍法、时长和口播内容。

同一个工坊动作，分别测试：

- 开头A：先给反差——“顾客看到的是桌子，工坊先看的是这块料。”
- 开头B：先给人群——“新房餐厅不大，这张桌子开工前先要确认一件事。”
- 开头C：先给问题——“餐桌能摆进去，为什么坐下以后还是别扭？”

后半段保持同一个真实动作和同一个结尾问题，才能看出到底是哪种开头把目标用户留下。

### 每计测几条、看什么指标

- 每种打法连续测**3—5条**，不要因为一条数据波动就彻底否定。
- **第32计·换个视角**看：非关注播放、前段流失、完播、新粉、评论中是否出现尺寸和木料问题。
- **第36计·冷知识**看：前段停留、评论互动、分享，以及评论是不是目标人群在问家具问题。
- **第15计·正确做法VS错误做法**看：主页访问、评论咨询、私信、到店时是否有人提到短视频。
- **第7计·一句话设定故事感**看：主页访问、关注转化、评论中是否有人开始提“老周”“工坊”“讲得明白”。

### 什么信号算“这计行”

- 非关注用户能稳定进入；
- 前段不出现明显大幅流失；
- 评论从“这是什么木头”逐渐变成“我家餐厅不大怎么选”“有孩子沙发怎么试坐”；
- 用户开始关注后继续看系列，而不是只看单条；
- 变现内容发布后，开始出现真实到店询问，而不是只问价格。

### 什么信号算“换掉”

- 连续3—5条都只有工坊画面，评论却没有家庭家具问题，说明工坊动作没有翻译给普通用户，主攻内容切到第36计·冷知识。
- 前段停留不错、完播持续弱，说明镜头在重复加工过程，删掉重复动作，把结果或问题提前。
- 流量型能带播放却不涨关注，说明栏目承诺不清，补第7计·一句话设定故事感。
- 布艺沙发内容有人看却没人询问到店，说明画面只拍产品，没有拍“进店后怎么试坐、怎么判断”，改用第15计·正确做法VS错误做法。

## 📅 30天节奏

拍摄频次以老周能长期稳定承担的节奏固定，不为了日更透支工坊工作。首月采用“集中拍真实动作、拆成多条发布”的方式：一次拍摄先完成同一类工坊动作的多个镜头，再按不同开头拆成单条内容。

### 第1周：把主栏目拍出来

**任务：**  
建立《老周在工坊替你先看一眼》的固定拍法：成品首帧、木料或工作台细节、老周动作、家庭语言解释、评论问题。  
现场盘点木料区、工作台、待做餐桌椅、卷尺、沙发试坐区，确定哪些位置光线和收音稳定。

**交付物：**  
- 主栏目固定片头句和固定字幕格式；  
- 第32计·换个视角样片3条；  
- 一张工坊镜头清单：木料、手部、卷尺、桌边、椅子拉开、成品局部。

**代表标题：**  
- 《顾客看到的是餐桌，老周进工坊先看的却是这块木料》  
- 《新房餐厅不大，餐桌开工前为什么先拿卷尺？》  
- 《一把椅子坐得稳不稳，工坊先看哪里？》

### 第2周：只测试开头，不乱换方向

**任务：**  
继续拍第32计·换个视角，围绕餐桌、餐椅、木料各拍一个真实动作；同一类动作只改开头承诺，验证反差、人群、问题三种入口。  
同时拍一条布艺沙发素材备用：试坐、按坐垫、摸面料、确认家庭谁使用。

**交付物：**  
- 第32计·换个视角3—5条；  
- 一份逐条记录表：开头类型、前段流失、完播、评论问题；  
- 布艺沙发原始素材包。

**代表标题：**  
- 《餐桌进工坊前，老周先确认的不是颜色》  
- 《家里有孩子，做实木餐桌前会多问一个问题》  
- 《布艺沙发到店先别急着看颜色》

### 第3周：保留有效入口，补一条人设和变现

**任务：**  
保留前两周数据更好的开头，不再同时测试多个大方向。  
补一条第7计·一句话设定故事感，拍老周真实的普通工作动作；补一条第15计·正确做法VS错误做法，拍布艺沙发试坐判断。

**交付物：**  
- 一组统一开头风格的工坊系列；  
- 人设型样片1条；  
- 布艺沙发变现型样片1条；  
- 待确认事件清单：最近一次真实复核尺寸或确认使用需求的事件。

**代表标题：**  
- 《这块木料今天先不进机器，因为有件事还没确认》  
- 《家里有孩子，布艺沙发到店先别急着看颜色》  
- 《做家具12年，老周不建议没量尺寸就先订餐桌》

### 第4周：形成首个稳定组合

**任务：**  
把跑得更好的主攻打法做成连续系列，固定“工坊视角+一个家庭问题”的内容结构。  
检查主页：昵称、简介和置顶内容是否让用户一眼知道老周卖实木家具、布艺沙发，能到店看木料、试坐沙发。  
收集评论区出现频率高的问题，作为下月选题池。

**交付物：**  
- 一组连续发布的主栏目内容；  
- 一条布艺沙发变现内容；  
- 一条真实职业日常人设内容；  
- 下月选题池，按“餐桌尺寸、木料判断、布艺试坐、家庭使用场景”分类。

## 📊 跑不通先查哪里

| 现象 | 先怀疑什么 | 下一步做什么实验 |
|---|---|---|
| 有曝光，但用户前几秒就划走 | 首帧先拍了机器、木料或门店，普通家庭不知道这和自己有什么关系 | 同一个工坊动作重拍3个开头：先给“新房餐厅不大”、先给“家里常来人吃饭”、先给“餐桌能放下却不好用” |
| 有人点赞，但完播偏弱 | 中段变成连续加工画面，动作重复，没有持续回答顾客问题 | 一条只留一个判断动作；把“这一步影响谁、怎么用”提前说；删掉无关加工镜头 |
| 播放有了，关注和到店询问偏少 | 用户只学到零散知识，没记住老周，也没看见到店后能做什么 | 每周固定补一条第7计·一句话设定故事感和一条第15计·正确做法VS错误做法；主页置顶“工坊看木料”和“沙发试坐”两类代表内容 |

这套起号打法的核心不是把工坊拍得多热闹，而是让县城里准备结婚、换房、装修收尾的人每次刷到老周，都多解决一个真实问题：**家具进家以前，先该看什么。**
