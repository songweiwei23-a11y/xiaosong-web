# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

这是 **A类本地实体店｜B类服装鞋包** 生意，成交不只靠“衣服挂出来好不好看”，而是靠顾客进店后能不能真正试到、穿得舒服、看清效果。

大码女装的利润通常来自单件服装差价和试穿后的连带购买：顾客本来为一条裙子进店，试穿过程中如果发现外套、裤装也合身，才可能一起带走。真正拉开差距的不是低价，而是减少顾客反复进店、反复试错的时间成本。

这类店的获客成本，卡在两个地方：

1. **线上不相信。** 很多视频只拍衣架、模特或修图图，顾客看不出自己能否穿。  
2. **线下不敢进。** 大码女生最怕的不是款式少，而是进店后被告知“没有合适的码”。她宁愿不进，也不愿再经历一次落空。

所以，阿梅店最该卖的不是“显瘦穿搭技巧”，而是一个可验证的结果：**到县城商业街这家店，50码以上有衣服可以试。**

顾客决策不会只靠一条视频完成。她通常会先刷到内容、翻主页确认有没有和自己接近的试穿参考、看店铺位置，再等下班、周末、换季或参加聚餐前到店。决策周期不算长，但需要反复建立“我去不会白跑”的确定性。

季节上，连衣裙在春夏更容易成为进店入口；外套在秋冬和节前需求更集中；裤装是四季稳定需求。内容上必须轮换展示，不能长期只发连衣裙，否则顾客会默认店里只有裙子可试。

**我推测同行最容易犯的错**，是把账号做成“每日上新相册”：一排衣服、几个颜色、配上“新款到店”。这类内容对已经认识店的人有用，但对陌生大码顾客没有回答最关键的问题——“我能穿吗？”阿梅要拍的是尺码、试衣间、上身后的活动空间和真实选择过程。

**一句话定位：**  
**阿梅做大码女装，帮本地女生少跑空店。**

## 变现全景

### **现在能卖什么**

1. **大码连衣裙**  
   春夏、聚餐、走亲访友、参加活动前的需求更集中，适合做“先刷到、再到店试”的入口款。

2. **大码外套**  
   换季和秋冬需求更明显，顾客通常更在意肩背、手臂、胸围和叠穿后的活动空间，适合用试穿过程建立信任。

3. **大码裤装**  
   四季需求稳定，且顾客对腰、胯、腿围和裤长的顾虑更具体。裤装不是只展示版型就能成交，试穿证据比挂版更重要。

4. **到店试穿服务**  
   这不是额外收费项目，但它是最关键的成交服务。短视频先让顾客在线上筛一遍，到店再完成尺码和版型确认，降低她“逛半天没收获”的顾虑。

### **各自的客单价与毛利大致区间**

档案未提供进货成本、零售价、折扣规则和连带购买数据，**不能编具体客单价和毛利率**。

待确认的优先信息：

- 连衣裙、外套、裤装目前的零售价区间；
- 每类货的大致进货成本；
- 顾客一次到店通常试几件、成交几件；
- 是否存在换季清货、会员折扣或搭配优惠。

拿到这四项后，才能判断哪类货适合做引流入口、哪类货适合承担利润，而不是凭“外套单价高”就把外套定为主推。

### **决策难度**

- **线上直接下单：偏高决策。** 顾客看不到真实上身、担心尺码不准，尤其裤装和外套更难线上盲买。  
- **短视频种草后到店试穿：中等决策。** 店铺有试衣间、50码以上可试穿，这会显著降低顾客顾虑。  
- **到店后成交：中低决策。** 前提是顾客能试到合身款，并且店内有不同版型可比较。

## 主推产品

### **主推：大码裤装的到店试穿**

不是因为裤装一定最贵，而是因为它最能验证阿梅店的核心价值：**顾客在别处最容易卡在“腰胯不合、裤长不对、坐下勒不勒”，而这些问题只有上身试才说得清。**

连衣裙的视觉吸引力更强，可以承担短视频里的“把人吸引进来”；但裤装是四季高频需求，也最容易让顾客产生“我得去试一下”的行动。

主推逻辑是：

- **信任门槛高：** 裤装尺码和版型顾虑更具体，顾客不能只看挂版下决定。  
- **到店价值高：** 同一位顾客试不同裤型，能直观看到腰胯、腿部、裤长的差异。  
- **生产能力匹配：** 阿梅现有资源就是门店、衣架、试衣间和本人，无需复杂布景或多人演员。  
- **连带空间更自然：** 顾客试裤装时，可能顺带试搭配的外套或连衣裙，但视频里不硬推，成交发生在店内真实试穿之后。

**明确不做：** 不把“显瘦口诀”当主推内容，也不做“同一条裤子换三种穿法”的前后对比。因为货没变，差异会被归到穿搭技巧上，观众学会技巧后未必需要到店买衣服。

## 成交路径

### 1. 第一次接触：先看到“这说的不就是我”

顾客刷到的第一类内容，应是大码女生熟悉的真实场景，例如：

- 路过女装店却不敢进去；
- 想买裤子，却担心腰胯卡住；
- 看见好看的外套，却先问“最大到多少码”；
- 参加聚餐前想买连衣裙，但不想跑几家店都试不到。

**这一步靠身份确认产生停留。**  
不是急着展示衣服价格，也不是开场就说“我们店有大码”，而是先让她承认：“对，我逛街就是这样。”

**为什么会流失：** 账号本来就不该服务所有女性，先把“需要试大码女装的本地顾客”筛出来，后面的到店成本更低。

- 连衣裙、外套、裤装的真实衣架区；
- 试衣间入口；
- 阿梅拿两件不同版型衣服做判断；
- 顾客或阿梅本人在镜前展示活动空间、腰胯位置、袖口和长度。

**这一步的核心不是“穿上多惊艳”，而是“原来我真能试”。**

**会流失的人：** 只想网购、不愿到店的人；店内暂时没有对应尺码和风格的人。  
**为什么会流失：** 不能靠视频承诺所有需求都能满足。遇到缺码或不适合的版型，应在私信和到店环节提前说清，避免顾客白跑。

---

### 3. 在哪里沉淀：主页确认 + 到店前问尺码

这个账号不建议一开始就把成交全压在私信，更不建议急着把顾客导去其他平台。起号期最现实的沉淀路径是：

**视频 → 主页置顶 → 看店铺信息 → 到商业街进店试穿。**

主页至少要承接三个问题：

1. 店里卖什么：大码连衣裙、大码外套、大码裤装；  
2. 最大的差异是什么：50码以上可试穿；  
3. 到哪里找：县城商业街。

置顶视频要让顾客在进店前完成基础判断：

- 《50码以上到店能试什么》  
- 《第一次来阿梅店，先怎么问尺码》  
- 《一位顾客试裤装时，阿梅会先看哪里》

**会流失的人：** 主页翻完仍然看不到真实试穿、看不出门店在哪里、担心自己去没有码的人。  
**为什么会流失：** 她还没有获得“到店值得”的确定性。解决办法不是重复喊“欢迎来店”，而是补不同身形、不同需求下的真实试穿素材。

---

### 4. 临门一脚：到店试穿，不是线上催单

最后一步应是顾客走进店、说出需求、试到合适版型，再决定带走哪件。

阿梅在店内要把动作固定下来：

1. 先问顾客今天要解决什么场景：上班、接孩子、聚餐、换季；  
2. 再问她最介意哪里：腰胯、手臂、长度或穿着是否舒服；  
3. 拿两件不同版型给她试，而不是只递一件；  
4. 试完后说明差别来自哪里；  
5. 顾客自己决定，不用“这件你必须拿”式催单。

**会流失的人：** 本次没有合适尺码、预算不匹配、暂时只是看看的人。  
**为什么会流失：** 服装试穿本来就有不成交的情况。阿梅要留下的是“这次没买，但下次需要会再来”的信任，而不是一次性成交压力。

## 信任证据清单

以下证据必须拍成画面，不能只写在字幕里。

1. **50码以上尺码牌挂在衣架上**  
   - 证明：真实、货品匹配。  
   - 拍法：开头先拍阿梅从衣架拉出对应尺码，再进入试穿过程。  
   - 作用：让顾客第一秒确认“不是普通女装店顺带卖几件大码”。

2. **连衣裙、外套、裤装三个区域轮流实拍**  
   - 证明：选择基础、真实库存结构。  
   - 拍法：一条视频只主拍一个品类，但一周内轮流出现。  
   - 作用：证明店里不是只有单一品类有大码。

3. **试衣间入口和镜前试穿过程**  
   - 证明：到店服务真实存在。  
   - 拍法：先拍顾客进试衣间前拿到的两件衣服，再拍镜前结果；未经允许不拍顾客正脸。  
   - 作用：降低“我去了能不能试”的心理门槛。

4. **阿梅明确说“不建议先试这件”的判断**  
   - 证明：专业判断、真实。  
   - 拍法：必须来自真实发生的服务场景，例如“这件袖口空间小，你先试另一件”。  
   - 作用：让顾客知道阿梅不是只想把每件衣服卖出去。  
   - 待确认：阿梅是否确实有这类判断能力和真实案例。

5. **同一人、同一镜前，换两件不同版型的大码裤装或外套**  
   - 证明：结果、产品差异。  
   - 拍法：人、场、镜头位置不变，只换衣服；展示腰胯、袖口、长度或活动空间的可见差异。  
   - 作用：证明差别来自商品本身，而不是换姿势或换拍法。

6. **顾客进门时的一句真实提问**  
   - 证明：真实需求。  
   - 拍法：顾客不愿出镜时，可由阿梅复述当天真实问题，例如“她刚刚问，裤子最大到多少码”。  
   - 作用：视频开头更贴近目标顾客。  
   - 待确认：收集顾客原话，不能自己编。

7. **顾客回访或再次到店的真实故事*


## 输出要求

行业建议只管「这个阶段怎么打」，不重复定位。账号是谁（账号定位）、长期拍什么（内容定位）、靠什么成交（商业定位）已经定好，这里只引用它们的原名。按下面的结构输出 Markdown，每一节都落到这个账号和这个阶段上：

1. **本阶段判断**：这个阶段和目的下，现状和目标之间差在哪里，依据是档案和作品数据。数据不够就直说不够。
2. **本阶段重心方向**：给 2–3 个建议方向，优先引用内容定位里已有的系列原名。每个写清：这一阶段它负责哪个目的（流量、人设、变现）、占本阶段的比例、为什么选它（对准哪个真实需求，依据档案的哪条事实）。这是建议，用户自己选定的方向优先。
3. **每类目的的结尾动作**：流量、人设、变现各一个结尾动作，每类只留一个。变现型的动作要对应商业定位里的哪一步，写出原步骤名。
4. **本阶段暂停什么**：2–3 条，每条写依据（禁忌、档案，或内容定位里的排除项）。
5. **30 天执行规则**：3 条，只约束选题和脚本怎么做（例如「每条都要在前 5 秒说出位置」），不重述定位。
6. **复诊条件**：出现哪些迹象就该换阶段，换的时候重心怎么变。只写可以观察的迹象（例如「连续几条都有陌生人在评论区问地址」），用这个号自己过去的数据比；**不写任何具体数字**（播放量、新客人数、连续条数都不写）。

## 硬约束

- 药方是建议，不是命令。用户选定的方向优先：用户的方向不在内容定位里，就照用户的方向给建议，并说明它和内容定位、本阶段重心的差距，不阻止、不改写。
- 不替用户新增或改写内容定位。如果本阶段反复需要内容定位里没有的方向，只写「建议把它加进内容定位」，由用户决定。
- 拍小票、结账、价格画面时，金额一律用【待确认】或「金额打码」，档案里没有的数字不写。
- 不重述账号定位（这个号是谁、说给谁、凭什么信）、内容定位（长期拍什么）、商业定位（靠什么赚钱）的内容，只引用原名。
- 内容定位已有，第 2 节优先引用它的原系列名。
- 商业定位已有，第 3 节的变现动作写出原步骤名。
- 不编造任何数字、案例、客户故事、效果承诺。缺的事实用【待确认】标出
- 价格、价位、人均、营业时间、地址、作息、门店活动，只有档案或素材里写了才能用。档案里没有的，写成「价格摆在明面」这类做法即可，具体数字用【待确认】占位，不要替它定价
- 阈值类数字（完播率、播放量、咨询人数、转化率）一律不给具体合格线，例如「完播低于 X% 就换」。改成和这个号自己过去的数据比较；没有历史数据就写「待建立」
- 档案里写着「未填」「待补充」或留空的项，不当作事实使用，也不凭行业印象补成具体值；推断出来的内容要标明是推断
- 与账号档案的事实冲突时以档案为准
- 禁忌里写的不能说、不能拍，方案里一律不出现
- 不输出寒暄和过程说明，只输出方案正文
