原片的核心机制是：**先接住顾客“我不行”的自我判断，再用“先别买、先验证”的反常规动作，把卖衣服变成帮她找到能穿的选择。**它能跨行业借，是因为借的不是某件衣服或原话，而是“顾客卡点→老板不急着卖→现场验证→给出结果”的转化结构。

### 方案 1：先别说穿不了，先去试衣间
**一句话**：原片“先站到镜子前看剪裁” → 你店里“先拿50码以上进试衣间试一试”

**借了**：顾客先否定自己→老板不急着推荐→现场验证→点出“盲买不如先试”的结构；店内镜子前口播形式。  
**换成自己的**：阿梅在县城商业街门店里，拿着大码连衣裙、大码外套或大码裤装，带顾客去试衣间试穿50码以上可试穿款。

#### 迁移对照
| 层 | 原片 | 你的版本 |
|---|---|---|
| 开篇 | 顾客进店先说“我穿不了” | 大码女生进店先问“有我能试的吗？” |
| 结构 | 不急着推荐衣服→先站镜子前看剪裁→说明站不对买贵也白搭 | 不急着把衣服塞给顾客→先拿可试穿的大码款进试衣间→说明没试过，别急着给自己下结论 |
| 呈现形式 | 店主在镜子前口播，边说边展示衣服 | 阿梅站在试衣间外/镜子前口播，手里拿一件大码连衣裙或外套，穿插拿衣服、推开试衣间门帘的画面 |
| 事件/主角 | 店主帮助大码顾客重新判断适合自己的剪裁 | 阿梅帮助担心买不到合身衣服的大码女生，先找到能实际试穿的款 |

#### 开头（前 3 秒）
**口播**：“很多大码姐妹进店先问：‘有我能试的吗？’今天我先不急着给你推荐，咱先进试衣间试一件再说。”  

**画面**：阿梅站在试衣间门口，手里拿着一件大码连衣裙；镜头先拍衣架上的大码款，再切阿梅把衣服递向试衣间。

#### 口播要点
- **【顾客卡点】**：很多大码女生不是不想穿得好看，是去过几家店，看到尺码就不敢问了。  
- **【反常规动作】**：到阿梅店里，先别急着问哪件显瘦、哪件最好看，先挑一件能进试衣间的50码以上款。  
- **【现场验证】**：连衣裙、外套、裤装，挂在衣架上看不出合不合适，穿上抬抬手、坐一坐、走两步，心里才有数。  
- **【结果落点】**：别站在衣架前就给自己下结论，衣服合不合身，得进试衣间才知道。  
- **【行动指令】**：县城附近想试50码以上大码女装的，来店里试穿。  

#### 注意
- 不要承诺“显瘦”“谁穿都好看”这类无法验证的话；重点拍“可试穿”和真实试衣过程。  
- 不需要找模特，阿梅本人对镜口播即可；顾客画面需征得同意，不方便出镜就只拍手部、衣服和试衣间门帘。  
- **这条不是搬运**：原片讲“镜子前判断剪裁”，这条讲的是阿梅店里“50码以上先实际试穿”；台词、衣服、场景和事件都来自自己的门店。

### 方案 2：别一上来问显不显瘦，先看你能不能试
**一句话**：原片“先看哪个剪裁在帮你” → 你店里“先看有没有能让你进试衣间试的尺码”

**借了**：先打断顾客惯性问题，再把注意力从“买哪件”转到“先验证是否合身”的结构；镜子前直接对话式口播。  
**换成自己的**：阿梅以“先有得试，再谈搭配”为观点，突出店里50码以上可试穿的大码连衣裙、外套、裤装。

#### 迁移对照
| 层 | 原片 | 你的版本 |
|---|---|---|
| 开篇 | 顾客默认自己穿不了 | 顾客一进店就问“这件显不显瘦？” |
| 结构 | 不推荐衣服→先看剪裁→提醒错误判断的代价 | 不先回答显不显瘦→先解决有没有尺码能试→提醒网图和衣架都替代不了试穿 |
| 呈现形式 | 镜子前口播+衣服展示 | 阿梅站在全身镜旁口播+从衣架上抽出不同品类的大码款 |
| 事件/主角 | 店主引导顾客调整挑衣思路 | 阿梅引导大码女生从“先问效果”变成“先试合身” |

#### 开头（前 3 秒）
**口播**：“很多大码姐妹进店先问：‘这件显不显瘦？’我一般不马上回答，先问你一句：这件你能不能进试衣间试？”  

**画面**：阿梅站在镜子旁，一只手拿着大码外套，另一只手指向试衣间；字幕突出“先试，再谈搭配”。

#### 口播要点
- **【常见场景】**：衣服挂在架子上，谁都能觉得好看；真正难的是，自己有没有合适尺码可以上身试。  
- **【阿梅的做法】**：在店里先从50码以上可试穿款里选，不管是连衣裙、外套还是裤装，先找到能穿进去、活动舒服的那件。  
- **【细节证据】**：试穿时不只看镜子里的正面，也看看肩膀、腰腹、坐下和抬手时舒不舒服。  
- **【转折】**：很多人不是不会挑衣服，是以前没有机会好好试一件合身的。  
- **【行动指令】**：想试50码以上大码女装，直接到县城商业街店里来。  

#### 注意
- “显不显瘦”是高频需求，但别把它说成唯一标准，避免强化身材焦虑；把重点放在“合身、能活动、自己穿着自在”。  
- 可以只拍阿梅一个人：衣架近景→阿梅口播→试衣间门口→镜子里衣服细节，不依赖顾客配合。  
- **这条不是搬运**：原片的重点是“剪裁”，这条的重点是“先有大码可试穿，再判断合不合适”；从衣服品类到门店动作都换成阿梅店里的真实内容。

### 方案 3：衣架前别急着走，先拿一件进去
**一句话**：原片“站不对，买再贵也白搭” → 你店里“没试就走，可能刚好错过能穿的那件”

**借了**：先呈现顾客的退缩动作→老板给一个简单动作→用一句有反差的结论收住；门店实景、近距离口播的拍法。  
**换成自己的**：阿梅在大码女装衣架和试衣间之间，拍“看一眼就走”与“拿进试衣间试一件”的对比。

#### 迁移对照
| 层 | 原片 | 你的版本 |
|---|---|---|
| 开篇 | “我穿不了”的自我否定 | 看见衣架、问完尺码就准备走 |
| 结构 | 不卖衣服→先做一个判断动作→说明错误判断的后果 | 不追着推荐→请顾客先拿一件进试衣间→说明不试就容易错过 |
| 呈现形式 | 镜子前直接口播 | 衣架旁开场，跟拍阿梅拿衣服走到试衣间，再回到镜子前口播 |
| 事件/主角 | 大码顾客在镜子前判断剪裁 | 阿梅遇到担心没有合适尺码的大码女生，邀请她先试一件50码以上款 |

#### 开头（前 3 秒）
**口播**：“很多大码姐妹问完一句‘有50码以上的吗’，看一眼衣架就准备走。今天我不追着让你买，你先拿一件进试衣间。”  

**画面**：先拍一排大码女装衣架；阿梅从中取下一件大码裤装或外套，转身走向试衣间。镜头跟拍两步即可。

#### 口播要点
- **【退缩场景】**：很多女生以前买不到合身衣服，进店时会先替自己判定“估计又没有”。  
- **【阿梅的动作】**：阿梅不急着讲款式，先从50码以上可试穿款里拿一件，让她进试衣间。  
- **【过程画面】**：衣架取衣、递衣服、试衣间门帘、镜子前看上身效果，四个画面就能把过程拍清楚。  
- **【核心观点】**：不是每件衣服都适合每个人，但不试就走，也可能把适合自己的那件留在了衣架上。  
- **【行动指令】**：县城商业街附近的大码姐妹，想试穿就到店里来。  

#### 注意
- 结尾不要说“保证有你能穿的”，档案只确认“50码以上可试穿”，不替店里作无法确认的承诺。  
- 顾客不出镜也能拍：用阿梅模拟“取衣—递衣—试衣间—镜子”的动线，或者拍顾客背影、手部。  
- **这条不是搬运**：原片是“镜前看剪裁”，这条是“衣架前别急着离开、到试衣间验证”；人物、动线、服装品类和门店场景全部是阿梅自己的。
