# 🚀 起号方案

## 📌 先说结论

- **建议主攻：36计·第1计 反向操作。**  
  这个号不从“新款上身”开始拍，而是反过来，先拍大码女生进店前最在意的东西：**尺码牌、试衣间、衣架里的大码款**。  
  它最贴合已定定位里的流量入口——“怕店里没码、不敢进店、想先确认能不能试”，同时不依赖顾客露脸，也不靠阿梅长篇口播。

- **备选：**
  1. **36计·第29计 吐槽奇葩现象**：当“怕没码”的共鸣内容前段停留不错、但评论不多时切入，用阿梅真实观察的逛店尴尬场景带评论。
  2. **36计·第10计 情境还原**：当主页访问、尺码咨询开始增加时切入，把“有大码”拍成“现场能试”的证据，承接到店。
  3. **36计·第15计 正确做法VS错误做法**：当有真实试穿顾客、且店内能拿出两件版型差异明确的同品类衣服时切入，拍同一人换两件货后的可见差别。

- **明确不做：**
  1. **36计·第35计 街头采访。** 县城商业街需要陌生人配合，还涉及路人肖像和收音；阿梅一个人守店时无法稳定执行，容易拍两条就停。
  2. **36计·第8计 加入人物关系。** 现在没有已确认、愿意长期出镜的顾客或家人素材，硬做关系故事会脱离真实门店日常。

- **多久能看出跑没跑通：**  
  主攻的第1计连续测 **5条**，再与第29计连续测 **3条**对照；前 **8条**先看非关注播放、前段停留和评论里的身份确认。  
  起号不以某一条爆不爆判断，而是看零粉到一千粉前，是否逐渐出现稳定的非关注播放、主页访问，以及“有大码吗”“能试吗”“店在哪”等有效互动。达到**零粉到一千粉、流量逐渐稳定**，再进入下一阶段。

## 🧮 起号期内容配比

### 起号期：到一千粉、流量稳定之前

| 类型 | 占比 | 这阶段具体怎么拍 |
|---|---:|---|
| 流量型 | 60% | 主力使用**36计·第1计 反向操作**，围绕“怕没有码、不敢进店、先看尺码牌”的真实心理拍。 |
| 人设型 | 15% | 阿梅只讲自己做大码女装6年、开店3年形成的真实职业判断，不编顾客故事。 |
| 变现型 | 25% | 用真实试衣过程证明：店里有50码以上可试穿款、店里有试衣间。 |

这和已定内容定位一致：  
- 主力仍是**晒过程、店内真实场景、试衣间和尺码牌**；  
- 主力系列仍是《大码女生逛街时没说出口的话》；  
- 第11条后逐步加重《阿梅今天给谁找尺码》《同一个人，换一件大码女装会差在哪》。

### 每一种怎么拍

#### 1）流量型：先让本地大码女生认出“这说的就是我”

- **出发点：**  
  - 人：25—40岁的宝妈、上班族大码女生；  
  - 货：大码连衣裙、大码外套、大码裤装只作为现场画面出现；  
  - 场：县城商业街女装店门口、尺码牌、试衣间；  
  - 爆款元素：**人群、反差、奇葩**；  
  - 三有：主打**有共鸣**。

- **用的形式：**  
  **36计·第1计 反向操作** + **聊观点·观点立场**

- **脚本结构：**  
  常规女装视频先拍新款上身  
  → 阿梅反过来，先拍尺码牌和试衣间  
  → 说出一个大码女生逛店时的真实顾虑  
  → 回到衣架区  
  → 评论区提问。

- **结尾行动指令：**  
  **“你逛街最怕听到哪句话？评论区说说。”**

> 流量型不说“来店里试”、不报卖点、不引导成交。

---

#### 2）人设型：让人记住阿梅是怎样做事的人

- **出发点：**  
  阿梅本人做大码女装6年、在本地开店3年。人设不靠“专业、靠谱”这种形容词，而靠她在试衣间外做判断的具体行为。

- **用的形式：**  
  **聊观点·观点立场**

- **脚本结构：**  
  阿梅在店里遇到的真实场景  
  → 她的职业判断  
  → 为什么不急着把某件衣服递进试衣间  
  → 留下她的边界。

- **第一批只拍这类真实内容：**  
  《做大码女装6年后，我越来越少说“这件你肯定能穿”》  
  前提：阿梅确认这就是她真实会说、真实会做的判断。

- **结尾行动指令：**  
  **“关注阿梅，陪你慢慢把合身这件事找明白。”**

> 待确认：阿梅真实遇到过哪一次“有尺码但不建议顾客试”的情况。先确认事件，再拍故事；没确认前不拍顾客案例。

---

#### 3）变现型：证明“这里不是挂着大码，而是能现场试”

- **出发点：**  
  - 人：担心腰能穿、胯不舒服，或者担心肩背、手臂活动受限的大码女生；  
  - 货：店内真实的大码连衣裙、大码外套、大码裤装；  
  - 场：衣架区、试衣间、镜前；  
  - 成交理由：**50码以上有可试穿款**。

- **用的形式：**  
  **36计·第10计 情境还原** + **晒过程·火车节**

- **脚本结构：**  
  顾客真实需求  
  → 阿梅找对应尺码和版型  
  → 试衣间试穿  
  → 镜前只讲一个看得见的判断  
  → 到店试穿。

- **结尾行动指令：**  
  **“来店里试穿。”**

> 一条只证明一个需求，例如“坐下时腰胯有没有空间”，不要一条里同时讲显瘦、颜色、搭配、面料和价格。

---

### 过线之后怎么调整

达到一千粉且流量开始稳定后，调整为：

| 类型 | 占比 | 增加什么 |
|---|---:|---|
| 流量型 | 50% | 保留“怕没码、不敢进店”的身份共鸣内容，持续拉新。 |
| 人设型 | 15% | 补阿梅真实的选货边界、真实职业判断、经确认的顾客互动。 |
| 变现型 | 35% | 增加连衣裙、外套、裤装的试穿证据和版型对比。 |

## 🎯 主攻打法：36计·第1计 反向操作

### 为什么这是阿梅能拍的

1. **出镜人明确。**  
   阿梅老板本人出镜，不需要另找主播、模特或店员配合。

2. **场景现成。**  
   门店就在县城商业街，有衣架、尺码牌、试衣间，这些正好是内容里的核心画面。

3. **不依赖顾客出镜。**  
   起号前期最不稳定的资源就是顾客配合；第1计只拍阿梅、衣架、试衣间和尺码牌，也能完成。

4. **不靠复杂表演。**  
   阿梅只需要做门店里每天都在做的动作：拉衣架、拿尺码、推开试衣间门、站在镜前说一句观察。

5. **和定位一致。**  
   已定定位不是“教大码女生怎么搭”，而是让她们在线上先看见：这里有没有能真实试穿的大码女装。  
   第1计把“先看尺码、再看衣服”拍出来，正好把这个认知钉住。

### 结构公式

**常规女装视频先展示新款**  
→ **阿梅反过来，第一秒先展示尺码牌或试衣间**  
→ **说出大码女生真实担心的那句话**  
→ **镜头再回到衣架上的大码连衣裙、外套或裤装**  
→ **评论提问。**

### 配什么脚本讲

- **36计·第1计 反向操作**负责事件：  
  先拍尺码和试衣间，而不是先拍衣服。

- **聊观点·观点立场**负责表达：  
  真实场景 → 阿梅判断 → 为什么这样判断 → 评论互动。

- **补上的东西：**  
  第1计有画面反差，观点结构把“为什么先拍尺码”说清楚。这样不是单纯拍衣架，也不是硬讲卖点。

### 前3条具体拍什么

#### 第1条  
**《大码女生进女装店，第一眼不是看新款》**（人群）

- **最强看点：** 开头不拍衣服，直接拍“50码以上”的尺码牌和试衣间门。
- **拍摄要点：**
  1. 首帧：阿梅手里拿着尺码牌，镜头能看到“50码以上”对应的真实尺码信息；
  2. 第二镜：推开试衣间门；
  3. 阿梅站在衣架前说：“很多人进门先看的不是新款，是这里有没有自己能试的码。”
  4. 镜头扫过大码连衣裙、外套、裤装衣架；
  5. 结尾：“你逛街最怕听到哪句话？评论区说说。”

- **为什么会让人停下：**  
  大多数女装视频先展示衣服，这条先给出“有没有我能试的码”这个更靠前的现实问题。

---

#### 第2条  
**《衣服挂着很好看，为什么有人还是不敢拿下来》**（反差）

- **最强看点：** 衣服就在面前，却因为不确定尺码而不敢伸手拿。
- **拍摄要点：**
  1. 首帧：阿梅手停在一排衣服前，没有立刻拿下来；
  2. 阿梅说：“有些人不是不喜欢，是怕拿下来一问，又没有自己的码。”
  3. 镜头切尺码牌、衣架、试衣间；
  4. 阿梅把衣服挂回去，再拿起一件大码款；
  5. 结尾：“你有没有过这种时候？评论区说说。”

- **为什么会让人停下：**  
  “喜欢却不敢拿”是大码女生逛街时常见的矛盾动作，画面和情绪是反着走的。

---

#### 第3条  
**《路过商业街时，大码女生最怕问的不是价格》**（人群）

- **最强看点：** 先把“怕问尺码”的心理说出来，打开县城商业街逛店的共同记忆。
- **拍摄要点：**
  1. 首帧：从店门口往里拍，能看到衣架和试衣间；
  2. 阿梅从门口走到尺码区，说：“路过女装店，很多人最怕问的不是多少钱，是有没有我的码。”
  3. 镜头切到阿梅翻看尺码牌；
  4. 镜头停在试衣间门口；
  5. 结尾：“你进店前会先看什么？评论区说说。”

- **为什么会让人停下：**  
  目标用户对“商业街路过女装店”有真实生活经验，不需要知道阿梅是谁，也能马上代入。

### 边界

1. **不把顾客身材当镜头笑点。**  
   不拍夸张身材反差，不说“谁穿都显瘦”“遮肉神器”。

2. **不把没有发生过的顾客心理说成具体事实。**  
   可以说“很多人会担心没有自己的码”，不能编“昨天有位顾客在门口站了很久”。

3. **流量型不推店。**  
   这3条不说地址、不说到店、不说“50码以上都能试”，尺码牌和试衣间只作为场景证据出现。

4. **首屏只放一个问题。**  
   一条只讲“怕没码”或“怕试衣尴尬”，不要同时塞进价格、显瘦、质量、颜色等内容。

## 🔄 备选打法

### 备选一：36计·第29计 吐槽奇葩现象

- **什么情况下切过去：**  
  第1计的前段停留不错，但评论区没有出现“我也是”“我就怕这个”等身份互动时，切这一计。

- **怎么套到这个号：**  
  阿梅拍大码女生逛店时的一个真实尴尬循环：  
  **想买衣服 → 站在门口看尺码 → 不敢问 → 假装随便看看 → 走开。**

- **配的四大脚本：**  
  **聊观点·观点立场。**

- **第一条拍什么：**  
  《明明想买衣服，却在门口绕了一圈又走了》（奇葩）  
  阿梅站在门口、看衣架、看尺码牌、转身回店内；最后说：“不是挑，是怕问完没有。”

- **它补什么：**  
  补评论区情绪。第1计偏“反向视觉”，第29计更容易让目标用户说出自己的经历。

---

### 备选二：36计·第10计 情境还原

- **什么情况下切过去：**  
  评论、私信或主页访问开始出现“有没有大码”“能不能试”“店在哪里”时切入。

- **怎么套到这个号：**  
  顾客真实说出一个需求  
  → 阿梅在衣架区找货  
  → 顾客进试衣间  
  → 镜前确认一处需求是否满足。  

  顾客不愿露脸时，只拍手部、背影、衣服和镜前局部；需求必须是当天真实发生的。

- **配的四大脚本：**  
  **晒过程·火车节。**

- **第一条拍什么：**  
  《她先问：50码以上真的能试吗？》（人群）  
  前提：顾客当天确实这样问过，并同意拍摄；没有真实原话，不使用这个标题。

- **它补什么：**  
  补变现证据，让观众看到“店里有大码”不是一句口播，而是有真实试衣间和现场试穿过程。

---

### 备选三：36计·第15计 正确做法VS错误做法

- **什么情况下切过去：**  
  店里同类货品中，确实有两件版型不同的大码连衣裙、外套或裤装；且有试穿者同意对比拍摄时切入。

- **怎么套到这个号：**  
  同一个人、同一面镜子、同一需求  
  → 先试不适合她本次需求的一件  
  → 阿梅说清楚卡在哪里  
  → 换另一件店内货品  
  → 只说这次需求下哪件更合适。

- **配的四大脚本：**  
  **教知识·拆解型。**

- **第一条拍什么：**  
  《同一个人试两条大码裤装，腰胯空间差在哪》（反差）

- **它补什么：**  
  补“为什么要到店试”的理由。变化来自两件不同货品，不来自同一件衣服换穿法。

## 🧪 怎么测

### 一次只改一个变量

主攻第1计的前5条，固定以下内容：

- 固定场景：门店尺码区、试衣间门口；
- 固定人物：阿梅本人；
- 固定时长：控制在同一长度区间；
- 固定结尾：评论区提问；
- 固定核心问题：怕没有合适尺码。

**只改开头第一句和首帧动作。**  
例如第一条先拍尺码牌，第二条先拍试衣间门，第三条先拍门口往店内的视角。

### 每计测几条、看什么

| 打法 | 至少测几条 | 核心指标 |
|---|---:|---|
| 第1计 反向操作 | 5条 | 非关注播放、前段停留、评论里的身份确认 |
| 第29计 吐槽奇葩现象 | 3条 | 评论量、评论是否出现真实逛店经历 |
| 第10计 情境还原 | 3条 | 主页访问、私信中是否问尺码/地址/试穿 |
| 第15计 正确做法VS错误做法 | 3条 | 主页访问、到店询问、完播情况 |

### 什么信号算这计行

- **第1计行：**  
  连续多条都有非关注播放，评论开始出现“我就怕没有码”“我也是先看尺码”“不敢问”等具体身份表达。

- **第29计行：**  
  观众不只点赞，而是开始讲自己逛女装店时的实际经历。

- **第10计行：**  
  主页访问、私信、到店询问开始围绕“尺码”“试穿”“位置”出现。

- **第15计行：**  
  观众会问“这种情况该选哪种”“店里有没有类似的”，而不是只评价衣服颜色。

### 什么信号算换掉

- 连续测完规定条数，首屏内容仍让人看不懂“这是给谁看的”；  
- 播放有一点，但评论全是泛互动，目标人群不出现；  
- 变现内容发出后，主页访问和尺码相关咨询没有变化。  

出现这些情况，不急着换赛道，先换开头的人群入口：  
从“怕没有码”换成“下班聚餐”“接孩子活动多”“换季旧裤子不舒服”等真实生活场景。
