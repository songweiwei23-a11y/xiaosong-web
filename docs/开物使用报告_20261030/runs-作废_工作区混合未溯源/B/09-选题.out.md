- 拍前先征得顾客同意；顾客不愿入镜就改拍阿梅整理裤装与讲解判断点。  
- 不能为了对比故意拿明显不合适的尺码给顾客试。  
- 手机竖屏固定拍镜前全身动作，补拍裤腰、胯部近景。  
- 收声以阿梅的提问和顾客现场原话为主，顾客声音不愿公开时可后期静音并打字幕。  

**7️⃣ 成交理由**  
- **体现的理由**：50码以上可试穿、专业强  
- **转化路径**：看判断→到店试裤装

## 选题6：大码外套一抬手就不自在？试衣间里先做这个动作

【方向】方向4：同一个人换两件，差别在哪  
【目的】变现型  
【结尾动作】到店  
【成交步骤】到店试穿  

**承接**：取自原文“先拍一件肩背活动受限的版型，再换另一件进行抬手、坐下、转身等动作”以及“重点是适用条件，不说‘谁穿都显瘦’”。

**0️⃣ 视频目的**  
变现型。通过同一个人、同一镜前位置、两件不同版型外套的抬手对比，证明现场试穿能看出挂着看不出来的活动感受。

**🅰 打法**  
36计·第15计 正确做法VS错误做法：  
只看“能不能穿上” → 抬手后发现肩背受限或袖口不自在 → 换另一件外套再抬手、转身验证 → 说明不同需求该看哪里。

**1️⃣ 爆款元素**  
荷尔蒙｜套用句式：**一秒下头的X**  
应用：用“穿上能站着，抬手却不自在”的反差作为开头，但不评价身材，只讨论衣服活动状态。

**2️⃣ 开篇钩子**  
“大码外套穿上能站着，不代表一抬手也舒服，试衣间先做这个动作。”

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：让同一位试穿者对比两件不同版型的外套，重点验证抬手时肩背、袖口和整体活动空间的差别。  
- **核心问题与观众价值**：大码女生试外套时，不能只对着镜子看正面，还要知道抬手、转身这些日常动作能帮助判断什么。看完能带走一个可执行动作。  
- **取材与内容推进**：  
  1. 选两件现货外套，确保版型差异真实存在；  
  2. 同一人站在同一镜前位置，先试第一件；  
  3. 完成抬手、向前伸手、侧身三个动作；  
  4. 换第二件，重复完全相同的动作；  
  5. 阿梅只讲镜头能看到的状态，例如“这次要看的是抬手后肩背有没有被拉住”，不做“显瘦”“谁都适合”等承诺。  
- **事实边界**：两件外套必须是门店真实现货；对比结果以现场画面为准。若没有顾客出镜，可由阿梅本人试穿演示，但不把演示写成顾客案例。  
- **关键画面（3个）**：  
  1. 同一镜前位置，第一件外套抬手动作；  
  2. 同一人换第二件，重复抬手动作；  
  3. 阿梅手指肩背、袖口位置，讲明本次该观察哪里。  
- **场景设置**：店内试衣间镜前，固定机位，同一光线、同一距离拍摄。

**4️⃣ 脚本结构**  
**教知识·拆解型：反常识开篇 → 讲清原理 → 操作示范 → 到店行动**  
- **反常识开篇**：外套能穿上，不等于活动起来就自在。  
- **讲清原理**：抬手时更容易看出肩背有没有被拉住、袖口是否卡住。  
- **操作示范**：同一个人、两件外套，重复抬手、向前伸手、侧身。  
- **适用条件**：需要日常通勤、带孩子活动或经常抬手做事时，更要做这个动作。  
- **行动收尾**：到店试穿时，阿梅可以按这个动作帮你一起比较。  

**5️⃣ 结尾行动指令**  
“想试外套活动起来自不自在，来店里抬手试一试。”

**6️⃣ 执行要点**  
- 拍摄前先把两件外套挂在镜前，方便开头直接形成对比。  
- 全程固定机位，确保两次动作可直接拼接对照。  
- 用手机后置镜头拍，画面包含上半身、手臂和镜中侧面。  
- 试穿者不愿露脸时，镜头从肩部以下拍，或拍镜中局部。  
- 不用夸张“错误款”“正确款”的说法，改为“这次需求下更需要比较哪一种状态”。  

**7️⃣ 成交理由**  
- **体现的理由**：50码以上可试穿、专业强  
- **转化路径**：看对比→到店试外套
