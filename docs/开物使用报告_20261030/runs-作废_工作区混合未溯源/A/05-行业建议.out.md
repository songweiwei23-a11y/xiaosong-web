 # 1. 本阶段判断

**判断：现在是建立本地内容基线的阶段，不是优化成熟爆款的阶段。**

- **目标与现状的差距**：目标是让南乐本地陌生人先看见、愿意关注或评论；但账号刚开始发布，还没有稳定作品数据，暂时无法判断哪种开头、哪种品类、哪种拍法最容易带来本地停留。
- **现阶段已有的可拍素材**：下午4点出摊、成都来的川菜厨师、做川菜9年、来南乐半年，以及川味串串火锅、川味烧烤、川菜的真实制作过程。这些都是可以重复验证的现场事实。
- **目前缺少的证据**：还不知道本地人更容易被哪类内容吸引，也不知道评论、主页访问和到店询问是否来自某个固定栏目；顾客原话、真实点单习惯、一元火锅具体规则等也还待确认。
- **本阶段重点**：先让内容可持续、可比较。每条视频只验证一个看点，不急着根据单条表现下结论，也不把没有数据当成内容方向已经失败。

# 2. 本阶段重心方向

建议先沿用内容定位里的 **「A 多元四类打底 + B 王牌栏目」**，按已确定的作用配比执行。

### 方向一：`《下午4点，开火》`里的「晒过程」

- **负责目的**：流量型，占本阶段约60%。
- **对准的真实需求**：南乐人在晚饭前想知道“今晚吃什么”，先通过真实出摊过程产生兴趣，而不是先看菜单和宣传。
- **为什么选它**：下午4点出摊是每天都会发生的固定场景；出镜人是成都来的川菜厨师，做川菜9年，来南乐半年，备料、开火、制作都有真实画面。
- **建议拍法**：优先使用内容定位里已有的「第31计·南北/地域差异」和「第32计·换个视角」，每条只拍一个过程变量，例如一段备料、一种制作顺序或一个锅边视角。
- **阶段判断标准**：先看南乐本地评论、关注和主页访问是否比其他试法更集中，不先看泛美食播放。

### 方向二：`「A 多元四类打底 + B 王牌栏目」`中的「故事」与「观点」

- **负责目的**：人设型，占本阶段约15%。
- **对准的真实需求**：陌生人看过几次后，需要知道镜头前这个厨师每天在做什么、为什么这样做，才可能记住这个人。
- **为什么选它**：成都籍贯、9年川菜经历、来南乐半年、每天下午4点出摊，都是已经确认的事实，可以支撑职业经历和出摊观点。
- **建议拍法**：先讲真实工作节奏、当天遇到的实际问题和厨师自己的判断；顾客故事、回头客原因、口味调整经过等，等拿到原话或现场证据后再使用。
- **阶段判断标准**：看评论里是否开始提到厨师本人、下午4点开摊或某个固定工作动作，而不只是泛泛评价食物。

### 方向三：`「A 多元四类打底 + B 王牌栏目」`中的「知识」与「情境还原」

- **负责目的**：变现型，占本阶段约25%。
- **对准的真实需求**：第一次接触时，用户可能想知道怎么点、辣度如何选择、三个品类分别适合什么吃饭场景。
- **为什么选它**：账号同时经营川味串串火锅、川味烧烤、川菜，且前采已经把“怎么点、辣不辣、等多久”等问题列为优先验证的问题。
- **建议拍法**：优先使用「教知识·解题型」和「第10计·情境还原」，但只能使用已经确认的菜单、点单规则和营业信息；没有确认的内容标为【待确认】。
- **阶段判断标准**：看是否出现真实的地址、营业时段、点单方式、辣度等询问，再决定哪类问题值得继续拍。

# 4. 本阶段暂停什么

1. **建议暂停把视频连续做成菜单展示、低价口播或硬广合集，也不要只围绕一元火锅反复拍。**  
   依据：内容定位已经明确要避免“菜单和硬广合集”，三个经营品类需要轮换；一元火锅的具体规则也还待确认。

2. **建议暂停使用没有原话或记录支撑的顾客故事、回头客结果、口味调整经过和具体点单承诺。**  
   依据：内容定位中这些素材都标注为启动前需要补充，当前档案没有对应事实，不能用推测替代。

3. **建议暂停把挑战、段子或多人情景剧作为固定主线。**  
   依据：内容定位已将段子暂列为不固定使用的形式，拍摄人手和配合条件也未确认；当前更适合先利用真实出摊过程建立基线。

# 5. 30 天执行规则

1. **开头规则**  
   使用 `《下午4点，开火》` 时，前5秒必须出现当天真实的开火、备料或操作动作，并让“南乐”进入画面或台词；第一句直接进入事件，不用空泛自我介绍。具体地址未提供时不自行补写。

2. **单条目的规则**  
   每条脚本开头先写清“目的—看点—结尾动作”，一条只承担一个目的：流量型不塞到店引导，人设型不塞成交话术，变现型只解决一个具体问题。

3. **事实与轮换规则**  
   选题先确定当天拍哪个品类、哪一个动作、怎样收尾，三个品类轮换出现。价格、活动规则、顾客原话、点单金额等档案和素材没有提供的内容，统一写【待确认】；涉及小票、结账或价格画面时，金额用【待确认】或打码。

# 6. 复诊条件

先把作品按**目的、品类、开头方式、结尾动作**做好记录，所有判断只和这个账号此前的同类作品比较；当前没有历史基线，不能套用外部合格线。

出现以下迹象时，可以考虑从起号期进入下一阶段：

- **本地性开始成立**：陌生人评论或私信中主动提到南乐，并询问位置、营业时段、怎么点，或在评论区叫朋友一起看。
- **栏目开始可复用**：`《下午4点，开火》`或某种固定开头，相比账号其他试法，反复带来更好的完播、主页访问、关注或有效评论；观众开始主动提到厨师、开火时间或固定动作。
- **变现信号出现**：视频发布后出现真实的到店询问，顾客能够说出是从视频看到，且问题集中在某个具体品类或点单场景。
- **事实素材变丰富**：已经拿到真实顾客原话、点单记录、常见问题和具体操作证据，能够支撑不止一种故事或知识内容。

换阶段后，重心从“广泛测试”转为“放大已验证的开头和栏目”：流量型围绕表现最好的现场变量继续延展，人设型加入真实工作事件和职业判断，变现型围绕被问得最多的问题制作内容，并补强《商业定位》「成交路径—3.在哪里沉淀」和「4.临门一脚是什么」。

如果只有泛流量，没有本地互动、可复用栏目或真实到店询问，就先不换阶段，继续建立这个账号自己的数据基线。
