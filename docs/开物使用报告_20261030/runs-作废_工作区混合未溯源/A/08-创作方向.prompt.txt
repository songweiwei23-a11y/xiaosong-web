# 💎 内容定位方案

## 长期价值主张

**南乐晚饭前，看川味串串火锅、川味烧烤、川菜。**

它不承诺口味高低，只解决本地人下班、聚餐前“今晚吃什么、现场做得怎么样”的判断问题。

**启动前先补一轮真实素材：**  
目前能稳定成立的是“成都厨师、下午4点出摊、做川菜9年、来南乐半年”。顾客故事、口味调整、回头客理由都还没有证据，不能急着拍成固定人设故事。前采优先问：

1. 最近一次顾客问“辣不辣、怎么点、等多久”是什么场景？原话是什么？  
2. 最近一次顾客对口味或出餐有意见，当时怎么处理？做了什么？  
3. 找一位真实回头客：第一次为什么来，第二次点了什么？  
4. 三个品类里，顾客经常复点的是哪些具体菜品？要看真实点单记录或当日点单。  
5. 厨师做串串锅底、烧烤调味、川菜炒制时，各有哪一个必须本人盯的动作？现场完整拍一遍。  
6. 来南乐半年里，有没有哪一次顾客反馈，让他调整了辣度、份量或点菜建议？  
7. 店里这个月发生过什么真实小事：一次备料失误、一次临时加单、一次顾客提问，都可以成为人设素材。

## 内容方向：多元四类还是单一主题

**选：A 多元四类打底 + B 王牌栏目。**

- **A 多元四类**：以晒过程为主，补知识、故事、观点。原因是起号期没有历史爆款数据，不能假设某一种内容已经跑通；而门店每天真实发生的备料、开火、烧烤、炒菜、点单，足够支撑多角度测试。
- **B 王牌栏目**：`《下午4点，开火》`。  
  它不是单拍一元火锅，而是每天从下午4点出摊切入，轮换拍川味串串火锅、川味烧烤、川菜。

**为什么不直接做纯单一主题号：**  
现有真实素材能证明“下午4点开火”，但还不足以支撑“连续挑战”“随机采访顾客”“每天做一件大事件”这类高执行主题。硬做会变成重复拍锅、拍菜，后面没有变量。先用固定时间栏目建立记忆，再从评论、到店问询和真实顾客故事里筛出能单独扩大的主题。

|---|---:|---|

**切换配比的条件：**  
连续发满前18—30条后，如果流量型作品的本地评论、主页访问和新增关注稳定出现，且变现视频开始有“位置在哪”“几个人怎么点”“几点营业”等真实询问，可调为：流量型50%、人设型20%、变现型30%。  
如果本地播放有了但到店问题很少，不先加硬广，而是先补真实点单、出餐、顾客高频问题等变现证据。

### 形式配比

| 形式 | 占比 | 负责哪种作用 | 为什么 |
|---|---:|---|---|
| 晒过程 | 55% | 流量型、变现型 | 这是当前资源能稳定生产的形式。备料、开火、烤制、炒制、上桌都在真实工作中发生，镜头比坐着介绍菜单更可信。 |
| 知识 | 20% | 变现型、流量型 | 用于回答“串串、烧烤、川菜怎么点”“辣度怎么选”等真实问题。前提是菜单、点单规则经老板确认，不凭经验编建议。 |
| 故事 | 15% | 人设型 | 只讲成都厨师来南乐、下午4点出摊、职业选择及真实服务事件。顾客故事必须有当事人同意或用厨师第一视角复述。 |
| 观点 | 10% | 人设型 | 用“我为什么坚持先做这一步”“我不愿意把什么做法省掉”为方向，但必须等前采拿到真实边界和经历后再拍。 |
| 段子 | 0% | 暂不作为固定形式 | 现阶段人手、表演和调度条件未确认，不用粗糙情景剧硬追热闹。后续若店员能稳定配合，再测试一人分饰多角。 |

**主力形式选择依据：**  
档案没有提供已验证的数据表现，因此不能说某类内容“数据最好”。晒过程不是因为它天然流量高，而是因为它与厨师、操作区、下午4点出摊这些现有资源匹配，能先稳定拍出20条，再判断是否扩大知识或故事占比。

### 题材配比

- **主赛道75%**：川味串串火锅25%、川味烧烤25%、川菜25%。  
  三个品类按批次轮换，每个都拍“准备—制作—成品—点单场景”，不能长期只拍一元火锅。
- **目标人群兴趣25%**：  
  1. 下班前“今晚别纠结吃什么”；  
  2. 朋友临时聚餐怎么不尴尬地点菜；  
  3. 带家人吃饭时，辣度、菜品和选择是否清楚。  

这些兴趣题材不是脱离餐饮去聊生活，而是把食物放进白领、宝妈真实会发生的晚饭场景里。

### 配比核验

1. **流量型和账号阶段匹配：是。** 起号期流量型60%，是最大的内容块。  
2. **主力形式有历史数据支撑：否，但理由成立。** 没有历史数据，只能先用可持续、真实的晒过程测试。  
3. **大流量内容是否占主力：是。** 以厨师、食物、下午4点出摊现场为核心，并加入人群、反差、地域差异等看点。  
4. **是否有目标人群兴趣题材：是。** 下班、聚餐、家庭晚饭占25%，能接住白领和宝妈。  
5. **每个数字是否有依据：是。** 比例由起号期、本地餐饮短决策和可拍资源推导，不按成熟餐饮号套模板。

## 三种视频怎么拍

### 一、流量型

**拍什么方向**

1. **下午4点的出摊反差**：别人刚准备下班，厨师开始备今晚的川味餐食。拍真实时间节点和开火现场，不报价格。  
2. **成都做法与南乐习惯的交流**：同一种食材，成都厨师按自己的顺序处理，再问本地人习惯怎么吃。重点是交流，不评价哪一种更高级。

**四大脚本（薛老师）**

- **晒过程型：火车节模型**  
  钩子：下午4点，厨师先处理当天其中一种食材。  
  过程：备料、开火、制作、出锅。  
  结果：锅边、烤架或炒锅完成的热气画面。  
  标题可叠加：**人群 / 反差**。  

  **示范标题：**《别人下班前刷视频，他下午4点才开始备晚饭》  
  **一句话怎么拍：**前3秒拍手机时间和开火动作，镜头跟着厨师完成一段真实备料，最后收在锅里沸腾的原声。

- **教知识型：拆解型**  
  钩子：同一种食材，为什么下锅顺序不同，口感会不一样？  
  原理：只讲现场能拍到的一步，例如下锅时间、火候顺序。  
  示范：厨师现场演示。  
  收尾：问观众平时更习惯哪一种。  
  标题可叠加：**反差 / 人群**。

  **示范标题：**《南乐人吃这口，先下锅还是后下锅？》  
  **一句话怎么拍：**同一份食材拍两种真实处理顺序，厨师只说自己的做法和原因，不做优劣判断。

**起号36计（小黄）**

- **第31计·南北/地域差异：**  
  同一种食材 → 成都厨师的处理顺序 → 南乐人常见吃法或评论区回答 → 问大家家里怎么做。  

  **示范标题：**《成都厨师做这口，南乐朋友会先接受哪一步？》  
  **一句话怎么拍：**镜头只跟一份食材，从处理到下锅，结尾留一个本地口味问题。

- **第32计·换个视角：**  
  常规出摊 → 用“食材第一视角”或“锅边第一视角”拍厨师准备 → 看见平时顾客看不到的工作动作。  

  **示范标题：**《从锅边看，下午4点的第一把火是什么样》  
  **一句话怎么拍：**手机固定在安全位置，拍开火、下料、蒸汽起来的过程，配简短旁白。

**结尾行动指令：**  
**“南乐人下班最想先吃哪一口？评论区告诉我。”**

### 二、人设型

**拍什么方向**

1. **成都厨师来南乐半年的真实工作节奏**：不是讲“创业多难”，而是讲下午4点为什么必须开始准备。  
2. **厨师的边界和职业判断**：例如某一步为什么不省、某种顾客需求为什么要先解释。前提是前采有真实事件。

**四大脚本（薛老师）**

- **讲故事型：职业经历**  
  结果钩子：来南乐半年，下午4点已经成了固定节奏。  
  阻碍：真实的适应问题或当天发生的小状况。  
  转机：靠一个具体动作、一次沟通或一次调整解决。  
  感悟：落回“人到摊前，先把今晚这一口做好”。  

  **示范标题：**《来南乐半年后，我每天4点先做的不是开火》  
  **一句话怎么拍：**拍厨师到操作区先完成一件真实准备工作，再用配音交代这件事和当天出摊的关系。

- **观点型：观点立场**  
  亲身经历 → 我的判断 → 为什么这么做 → 留一个关注出口。  
  适合拍“我不认为辣就是川味全部”“我不愿意为了省时间跳过哪一步”，但只能等真实做法确认后使用。  

  **示范标题：**《做川菜9年，我不认为辣就是一桌菜的全部》  
  **一句话怎么拍：**厨师站在真实炒菜区，讲一道当天在做的菜，论据是自己的操作，不攻击其他做法。

**起号36计（小黄）**

- **第7计·一句话设定故事感：**  
  普通动作“下午4点整理食材” + 身份“成都来的川菜厨师” + 目标“赶在晚饭前开火” → 形成职业故事期待。  

  **示范标题：**《下午4点，成都厨师先把这件事做完才开火》  
  **一句话怎么拍：**一镜跟拍真实动作，配音只交代“我是谁、我在做什么、为什么现在必须做”。

- **第37计·赠送：身份反差：**  
  成都厨师的身份预期 → 在南乐摊位做细碎备料工作 → 开火后的结果。  
  反差来自“厨师也要亲手做基础准备”，不是硬凹落差。  

  **示范标题：**《做川菜9年的人，下午4点还在一根根处理它》  
  **一句话怎么拍：**近景拍手部处理食材，再切到掌勺动作，保留原声。

**结尾行动指令：**  
**“关注我，看下午4点的出摊日常。”**

### 三、变现型

**拍什么方向**

1. **第一次来怎么点**：围绕两人吃、朋友聚餐、带家人三个真实场景，解释川味串串火锅、川味烧烤、川菜怎么组合。  
2. **看得见的现做过程**：每条只证明一个成交理由，例如现做、点单方便、川味做法。具体菜品和规则必须按真实菜单拍。

**四大脚本（薛老师）**

- **教知识型：解题型**  
  场景难题：第一次来，面对三个品类不知道怎么选。  
  放大问题：乱点容易菜多、口味不合或等菜时不知道先吃什么。  
  解决：按人数、是否吃辣、想吃锅还是想吃菜给真实建议。  
  步骤：①先问人数；②问吃辣程度；③确定主菜；④补串串或烧烤；⑤确认当天可点菜品。  

  **示范标题：**《第一次来，川味串串火锅、川味烧烤、川菜怎么点？》  
  **一句话怎么拍：**用真实菜单和实物演示三种场景的点法，菜单未确认前不发布。

- **晒过程型：过程展示**  
  钩子：一桌点单后，先做哪一道。  
  关键步骤：备料、烤制或炒制、出锅。  
  结果：整桌上齐后的真实画面。  
  成交理由：看得见的现做过程，不用口头堆“正宗”。  

  **示范标题：**《这一桌的川菜，是从锅边这样一道道出来的》  
  **一句话怎么拍：**从接到真实点单开始，挑一道菜拍透，不虚构顾客反应。

**起号36计（小黄）**

- **第10计·情境还原：**  
  真实点单难题 → 顾客或店员提出“几个人怎么点” → 厨师按真实规则建议 → 上桌结果。  

  **示范标题：**《两个人来吃，串串、烧烤、川菜到底怎么选？》  
  **一句话怎么拍：**店员演示真实顾客会问的问题，厨师拿菜单逐项解释，结尾给出上桌画面。

  错误点法 → 可能出现的菜品重复或口味不适应 → 按人数和需求重新搭配 → 说明适用条件。  
  不能把顾客拍成“不会点”，而是拍“第一次来信息不够，怎么问更省心”。  

  **示范标题：**《第一次点川味餐，先别把三样都按同一种思路点》  
  **一句话怎么拍：**厨师用两份真实菜单演示“先问需求”和“直接乱点”的区别，重点讲选择逻辑。

**结尾行动指令：**  
**“想吃川味的，下午4点后到店看当天出摊。”**

## 内容系列（2-4 个）

### 系列一：《下午4点，开火》

**一句话讲清：**每天跟着成都厨师，从下午4点的第一把火，看见今晚其中一类川味餐食怎么开始。

- **出发点：**站在下班前刷视频的新锐白领和准备晚饭的精致妈妈；围绕“场”——下午4点真实出摊现场；满足“有兴趣”，因为别人准备下班、他开始准备晚饭形成时间反差；主用**人群、反差**，设计在标题和开篇时间画面。
- **定量 / 变量：**定量是“下午4点+开火前第一步+制作推进”；变量是当天拍川味串串火锅、川味烧烤或川菜，以及当天处理的真实食材。
- **用哪套打法：**36计系列，定量是**第32计·换个视角**，用锅边、烤架、炒锅边的视角进入出摊现场。
- **目的和结构：**流量型；晒过程“钩子—关键步骤—热气结果”；结尾统一评论。
- **让观众发生哪种变化：**身份确认——“这就是我下班前会刷到的晚饭现场。”
- **变量自检：**变量是：当天制作的品类与食材，不是换机位或换动作。看点不是挑选、搭配技巧，而是固定时间下真实发生的出摊过程。

### 系列二：《第一次来，怎么点》

**一句话讲清：**把真实顾客会问的点单问题，拆成一条条能看明白的到店建议。

- **出发点：**站在朋友聚餐、家庭晚饭场景里的新锐白领和精致妈妈；围绕“货”——川味串串火锅、川味烧烤、川菜的真实点单组合；满足“有用”，观众能提前减少点菜纠结；主用**人群、成本**，设计在标题的问题场景里。
- **定量 / 变量：**定量是“一个点单场景—三个确认问题—一份真实建议—上桌结果”；变量是人数、吃辣程度、聚餐目的和当天可点菜品。
- **用哪套打法：**四大脚本系列，定量是教知识型“解题型”结构。
- **目的和结构：**变现型；“点单难题—确认需求—真实建议—上桌结果”；结尾统一到店。
- **让观众发生哪种变化：**行动——知道到店前该问什么、怎么选。
- **变量自检：**变量是：不同用餐人群和真实点单任务，不是同一份菜换吃法。看点不是教顾客自己做菜，而是降低到店决策成本。

## 选题来源

### 1. 知识储备

- **长期来源：顾客高频提问。** 每天让店员记录顾客问得最多的三句话。  
  例：`第一次来，川味串串火锅、川味烧烤、川菜怎么选？`
- **长期来源：厨师手上能看见的步骤。** 只讲镜头能证明的火候、顺序、食材处理。  
  例：`这道川菜下锅前，为什么要先把这一步做完？`

### 2. 经历与故事

- **长期来源：成都厨师来南乐后的真实适应过程。** 例如第一次遇到本地顾客问辣度、第一次被问“这怎么点”。

- **长期来源：真实服务事件。** 顾客临时加菜、店员备料、当天出摊出现的小问题。  
  例：`下午4点刚开火，店里先来了一个临时点单。`  
  前提：事件真实，顾客画面需征得同意。

### 3. 热门话题与观点

- **长期来源：本地晚饭讨论。** 下班吃什么、聚餐怎么选、能不能吃辣。  
  例：`下班后吃火锅、烧烤还是炒菜，南乐人怎么选？`
- **长期来源：地域口味讨论。** 成都做法和南乐习惯的差异。  
  例：`同一口蘸料，成都厨师和南乐朋友会怎么调？`

### 4. 实操记录

- **长期来源：每日固定节点。** 下午4点备料、开火，晚饭前制作，高峰后收摊。  
  例：`下午4点，今天先备的是川味烧烤这一口。`
- **长期来源：三个品类轮换。** 每周至少各拍到一次川味串串火锅、川味烧烤、川菜。  
  例：`今天这一锅串串开火前，厨师先检查什么？`

## 前 30 条节奏

### 第1—10条：先让本地人认识“下午4点”

- **目标：**跑通固定时间场景，验证“成都厨师+下午4点开火”能否带来停留和本地评论。  
- **主做系列：**《下午4点，开火》7条；《成都厨师问南乐》3条。  
- **主要形式：**流量型晒过程。  
- **主要打法：**第32计·换个视角、第31计·南北/地域差异；少量用晒过程火车节模型。  
- **验收标准：**看非关注播放占比、前3秒停留、完播、本地评论中是否出现“在哪”“几点开”“南乐人怎么吃”等真实互动。  
- **不过关怎么改：**若前段流失高，不换赛道，先把首帧改成“手机时间+开火”“食材近景+滋啦声”，删掉铺垫口播。

### 第11—20条：补点单信任，不让账号像菜品相册

- **目标：**验证观众是否愿意从“看热闹”进入“想去吃”。  
- **主做系列：**《第一次来，怎么点》5条；《下午4点，开火》3条；真实人设内容2条。  
- **主要形式：**变现型教知识、晒过程；人设型职业故事。  
- **主要打法：**第10计·情境还原、第15计·正确做法VS错误做法；教知识解题型、晒过程展示型。  
- **验收标准：**看主页访问、菜单相关评论、位置和营业时间询问、到店顾客是否提到刷到视频。  
- **不过关怎么改：**若播放有但咨询少，检查视频有没有拍清菜单、食物、点单场景和上桌结果；不靠加大价格字幕解决。

### 第21—30条：留下有效变量，开始建立人物熟悉感

- **目标：**保留前20条里互动更好的变量，形成“下午4点”记忆，并补充真实厨师故事。  
- **主做系列：**表现较好的流量系列6条、点单系列3条、真实职业故事1条。  
- **主要形式：**仍以晒过程为主，加入少量观点和故事。  
- **主要打法：**第31计·南北/地域差异、第7计·一句话设定故事感；讲故事职业经历、观点立场。  
- **验收标准：**看评论是否有人主动提“下午4点”“成都厨师”，以及变现内容是否有稳定到店询问。  
- **不过关怎么改：**若人设内容完播低，先不讲长故事，改成“一个动作+一句真实判断”的短片；若三个品类曝光不均，下一批优先补拍出现频率低的品类。

## ⚠️ 不要做什么

1. **不要连续拍一元火锅价格字幕。**  
   一元火锅是低门槛入口，但连续强调会把账号拍成只靠低价吸引人的号，川味烧烤、川菜很难被认识，后续点单也容易只围绕价格。

2. **不要拍空镜头扫菜单、菜品堆满桌。**  
   顾客看不出这和自己今晚吃饭有什么关系。菜单该放在“几个人怎么点”“不吃辣怎么选”的真实问题里，不单独当内容。

3. **不要在没有真实素材时硬讲励志故事或顾客感动。**  
   目前没有可核实的回头客故事、口味调整事件和职业边界。假故事短期可能有情绪，长期会损伤“成都厨师下午4点真实出摊”的可信度。
