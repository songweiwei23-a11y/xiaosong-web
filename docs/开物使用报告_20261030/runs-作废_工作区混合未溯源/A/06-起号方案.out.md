# 🚀 起号方案

## 📌 先说结论

- **建议主攻：36计·第32计 换个视角。** 就围绕固定栏目《下午4点，开火》拍：成都来的川菜厨师，在南乐下午4点开始准备串串火锅、烧烤、川菜。它最符合现有真实素材，不靠顾客配合、不靠表演、不需要编故事。
- **备选：**
  - **36计·第31计 南北/地域差异**：评论区开始出现本地口味讨论后切入。
  - **36计·第10计 情境还原**：菜单、辣度规则、常见点单方式核对清楚后，用来承接到店。
  - **36计·第7计 一句话设定故事感**：拿到真实职业事件后，用来补人设。
- **明确不做：**
  - **第35计 街头采访**：需要路人出镜、现场沟通和收音，当前没有确认团队与配合条件，产能撑不住。
  - **第30计 角色扮演**：需要表演、多人调度或反复拍摄，容易把真实出摊现场拍成生硬剧情。
- **多久能看出跑没跑通：**先连续测试20—30条，核心看非关注播放、本地评论、主页访问和新增关注；阶段目标是从零粉做到一千粉，并出现连续作品流量相对稳定，而不是只靠一条偶然高播放。

## 🧮 起号期内容配比

### 到一千粉、流量稳定之前

- **流量型 70%**：主打“下午4点，成都厨师开始准备晚饭”的时间反差。  
  - **出发点**：人＝成都来的川菜厨师；货＝串串火锅、烧烤、川菜；场＝南乐下午4点的出摊现场。  
  - **爆款元素**：人群 + 反差。别人准备下班，他开始为晚饭开火。  
  - **形式**：第32计 换个视角 + 晒过程火车节。  
  - **结构**：手机时间 → 第一把火/第一步备料 → 一个关键动作 → 热气或出锅结果。  
  - **结尾**：`南乐人下班最想先吃哪一口？评论区告诉我。`

- **人设型 10%**：只拍已经证实的“成都人、做川菜9年、来南乐半年、下午4点出摊”。  
  - **出发点**：让人记住“每天先到操作区准备晚饭的成都厨师”，不讲空泛励志。  
  - **形式**：第7计 一句话设定故事感 + 讲故事型职业经历。  
  - **结构**：一个真实动作 → 为什么现在必须做 → 当天出摊的关系 → 一句职业判断。  
  - **结尾**：`关注我，看下午4点的出摊日常。`
  - **待确认：**厨师来南乐后真实遇到的一次口味、点单或备料事件；拿到后再扩大人设内容。

- **变现型 20%**：解决第一次到店“怎么点、辣不辣、三个品类怎么搭”的问题。  
  - **出发点**：人＝白领、宝妈的晚饭和聚餐场景；货＝串串火锅、烧烤、川菜；成交理由＝一元火锅低门槛、厨师现场制作、点单更清楚。  
  - **形式**：第10计 情境还原 + 教知识型解题型。  
  - **结构**：点单难题 → 先确认人数/辣度/主菜 → 给真实菜单建议 → 上桌结果。  
  - **结尾**：`想吃川味的，下午4点后到店看当天出摊。`
  - **发布前提：**菜单、辣度规则、当天可点菜品必须由门店确认，不能按经验编。

### 过线之后

- 当“下午4点”“成都厨师”开始被本地评论主动提起，调整为：**流量型50%、人设型20%、变现型30%。**
- 继续以《下午4点，开火》做主系列；把真实顾客问题沉淀成《第一次来，怎么点》；有真实事件后再补职业故事和观点。
- 这套配比和已定定位一致：仍以晒过程为主，三个品类轮换出现；只是起号前20—30条把流量型进一步集中，先跑出固定场景记忆。

## 🎯 主攻打法：36计·第32计 换个视角

- **为什么是你能拍的：**
  - 已经有固定、可重复的真实场景：**每天下午4点出摊**。
  - 出镜人就是掌勺本人，镜头跟着手、锅、烤架、炒锅走，不需要额外演员。
  - 三个品类都有可拍动作：串串下锅、烧烤上架、川菜起锅，能稳定轮换，不会只剩菜品展示。
  - 未确认团队和设备时，按保守执行：一部手机固定在安全位置，补拍手部近景和成品即可；不依赖复杂运镜。

- **结构公式：**  
  `下午4点真实时间 → 锅边/烤架/炒锅的新视角 → 成都厨师完成一个关键动作 → 热气、滋啦声或出锅画面 → 留下本地晚饭问题`

- **配什么脚本讲：**  
  配**晒过程型·火车节模型**。  
  - 第32计负责“从哪里看”：锅边、烤架边、炒锅边。  
  - 晒过程负责“发生什么”：开火前第一步、制作推进、热气结果。  
  - 它补的是持续性：不需要厨师长篇口播，也不把内容拍成菜单广告。

### 前3条具体拍什么

1. **《下午4点，今晚先开的是串串这口锅》**（反差）  
   - 首帧拍手机时间和开火动作；随后固定机位拍锅边第一步；最后收在锅里沸腾的原声。  
   - **为什么会停下：**别人临近下班，他刚开始为晚饭开第一把火。

2. **《下午4点，烧烤架第一声响起来了》**（人群）  
   - 先给烤架点火或食材落架的声音；镜头只跟一个真实烧烤步骤；结尾留成品近景。  
   - **为什么会停下：**下班前的“滋啦声”直接对应本地人今晚吃什么。

3. **《下午4点，川菜下锅前先过这一关》**（头牌）  
   - 近景拍厨师处理当天一道真实川菜的关键准备动作；只解释这一步和后续下锅的关系，不延伸成泛泛教学。  
   - **为什么会停下：**观众能看到平时坐在桌前看不到的掌勺动作。

- **边界：**
  - 不把镜头架在高温、油烟或会影响操作的位置，安全优先。
  - 不为了“视角新”摆拍食材、重复点火或制造假忙。
  - 流量片不报一元火锅价格、不引导到店；产品只作为画面里的货出现。
  - 不连续三条只拍同一种品类；串串火锅、烧烤、川菜必须轮换。

## 🔄 备选打法

### 36计·第31计 南北/地域差异

- **什么情况下切过去：**《下午4点，开火》连续发出后，评论区开始有人讨论“我们这边怎么吃”“这个口味能不能吃”，再切入。
- **怎么套到这个号上：**同一种真实食材，拍成都厨师的处理顺序，再问南乐本地习惯怎么吃。
- **配哪个结构：**教知识型·拆解型，讲清“我的做法是什么、这一步为什么这样做”，不评价谁更好。
- **首条方向：**《这份食材，成都厨师和南乐人谁先下锅？》

### 36计·第10计 情境还原

- **什么情况下切过去：**门店已核对菜单、辣度规则、常见点单方式，并且评论里开始出现“几个人怎么点”的真实问题。
- **怎么套到这个号上：**还原第一次来店的真实点单场景：两个人、朋友聚餐、带家人吃饭，分别怎么问、怎么选。
- **配哪个结构：**教知识型·解题型，补上变现型最需要的成交理由——点单清楚、现场制作、低门槛尝试。
- **首条方向：**《两个人来吃，串串、烧烤、川菜怎么选？》

### 36计·第7计 一句话设定故事感

- **什么情况下切过去：**前采拿到一件真实职业事件，例如一次备料失误、一次临时加单、一次顾客问辣度后的实际处理。
- **怎么套到这个号上：**普通动作“下午4点整理食材”加上真实任务“赶在晚饭前开火”，让观众看见厨师当天在完成什么。
- **配哪个结构：**讲故事型·职业经历，补上人物熟悉感，不带卖点。
- **首条方向：**《下午4点，成都厨师先把这件事做完才开火》

## 🧪 怎么测

- **一次只改一个变量：**主攻第32计时，先固定“下午4点+真实制作过程”，只轮换一个变量：首帧是时间、声音还是食材近景。
- **每计测几条：**
  - 第32计连续测**9条**，串串火锅、烧烤、川菜各至少出现一次。
  - 第31计测**3—5条**，只换食材和讨论问题，不换整体结构。
  - 第10计测**3—5条**，只换点单场景，不换“确认需求—给建议—上桌”的结构。
- **看什么指标：**
  - 流量型：非关注播放、本地评论、前3秒停留、完播、新增关注。
  - 变现型：主页访问、菜单相关评论、位置/营业时间询问、到店顾客是否主动提到视频。
  - 人设型：主页访问、关注、评论里是否有人记住“成都厨师”“下午4点”。
- **什么信号算这计行：**
  - 第32计：连续几条都有本地互动，评论开始出现“几点开”“在哪”“今晚吃什么”等具体问题。
  - 第31计：评论区出现真实地域吃法讨论，而不是只有“看着香”。
  - 第10计：有人直接问人数、辣度、菜品搭配或到店信息。
- **什么信号算换掉：**
  - 同一计完成3—5条、首帧只改一个变量后，仍持续前段流失且没有本地互动，就换开篇画面或切备选计；不急着否定“下午4点开火”这个定位。

## 📅 30天节奏

按未确认团队和设备的保守产能执行：**每周集中拍2次，每次顺手拍够2—3条素材；每周发布3条。**

| 阶段 | 任务 | 交付物 |
|---|---|---|
| 第1—7天 | 先拍《下午4点，开火》；固定真实出摊时间，测试时间首帧、滋啦声、食材近景三种开头 | 3条第32计样片；一份开篇留存记录 |
| 第8—14天 | 继续第32计，三个品类轮换；每天记录顾客高频提问 | 3条流量片；顾客问题清单 |
| 第15—21天 | 从高频问题里挑真实点单问题，开始拍第10计；保留第32计做主力 | 2条点单情境片；1条开火片；菜单核对表 |
| 第22—30天 | 根据评论选择一个地域差异题材；补1条真实职业事件的人设片 | 2条第31计；1条第7计；月底复盘表 |

## 📊 跑不通先查哪里

- **有曝光，但前3秒掉得快**  
  → 先怀疑首帧太像普通做菜视频，没有把“下午4点”和第一把火拍出来。  
  → 下一步：同一段备料分别测试“手机时间”“火焰/滋啦声”“食材极近景”三个首帧。

- **播放有了，本地评论很少**  
  → 先怀疑标题只讲菜，没有把南乐人的晚饭场景放进去。  
  → 下一步：标题改成下班、朋友聚餐、带家人吃饭的具体问题，结尾只留一个本地口味提问。

- **变现片播放不差，但没人问怎么到店**  
  → 先怀疑点单建议不够真实，菜单、辣度、上桌结果没有被拍清。  
  → 下一步：只拍一个真实场景，例如“两个人来吃怎么点”，把菜单、确认问题和上桌画面拍完整。
