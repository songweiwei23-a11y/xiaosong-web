# 🎯 账号定位方案

## 📌 核心结论（先看这 8 条）

1. **这是什么号**：本地餐饮号；成都厨师的南乐川味记录  
2. **给谁看**：下班想吃点热乎、聚餐怕踩雷的南乐人  
3. **人设标签**：下午4点出摊的成都川菜厨师  
4. **主打内容**：流量60%、人设15%、变现25%；先靠现场感起号  
5. **怎么赚钱**：刷到视频→看出摊过程→到店点川味餐食  
6. **第一条拍什么**：下午4点，一元火锅摊开张前的准备  
7. **最该避开的坑**：别把账号拍成菜单和硬广合集  
8. **多久能看出跑没跑通**：连续发满18条后，看本地互动和到店询问

## 🔍 先说这一行

- **归口**：A类餐饮食品，本质是“本地晚餐/夜宵消费”，川味串串火锅、川味烧烤、川菜共同构成菜单，不宜把账号拍成单一串串摊。
- **这行的钱怎么赚**：餐饮不是靠一次看视频就成交，而是靠“想吃时能想起你”带来到店；一元火锅负责降低第一次尝试门槛，川味串串火锅、川味烧烤、川菜共同承接多人聚餐、下班解压和家庭点菜需求。具体毛利、客单、复购率均**待确认**，不能替门店编。
- **客人的决策链路**：大多是短决策——下班前、朋友约饭时刷到，先看距离、画面、价格感和“看着想不想吃”，再决定要不要去；但首次到店后能否复购，取决于实际味道、出餐和服务，短视频不能替代线下体验。
- **时间规律**：下午4点出摊是天然内容节点；真正适合拍的是“开摊准备—晚饭前客流—夜间收摊”三段。周末、节假日、朋友聚会和下班时段更适合发“吃什么”的内容，但具体旺时段需结合门店实际确认。
- **这行常犯的错**：老板容易只拍“锅里冒泡、菜品摆满”，自己觉得丰富，陌生人却不知道为什么要专门来；这个号也有这个风险。要把“成都厨师做什么、南乐人什么时候会来吃”拍清楚。
- **同行现在都在拍什么**：常见是菜品特写、团购口播、顾客满座和低价字幕。大多没效果，不是画面不香，而是前3秒没有事件：观众看不出今天这口锅、这把串、这道川菜和自己有什么关系。空档在“下午4点真实出摊的成都厨师”这个连续发生的现场。

## 🗣 我会先问老板的几个问题

- **问题**：最近一次顾客说“味道不对”或“等久了”，当时发生了什么？你怎么处理、原话怎么说？
  - **我的推测**：一元火锅降低进店门槛，也会带来对分量、口味和等待时间的直接提问；这类现场最能判断顾客真正在意什么。
  - 待老板确认

- **问题**：顾客第一次来，通常是冲着一元火锅、川味口味，还是朋友带来？第二次来又点了什么？
  - **我的推测**：第一次可能被“一元火锅”吸引，复购未必只靠价格，可能落在某一款串、烧烤口味或川菜上；必须用真实回头客验证。
  - 待老板确认

- **问题**：顾客进店最常问的一句话是什么？你一般怎么回答？
  - **我的推测**：高频问题可能集中在“一元火锅怎么点”“辣不辣”“几个人怎么吃”；这些问题就是变现内容最直接的选题来源。
  - 待老板确认

- **问题**：你亲手做的哪一步，换别人做会不一样？请现场完整演一遍。
  - **我的推测**：差异化不该停在“正宗川味配方”这句话，而要落到看得见的动作、香料、火候或出锅顺序；没有画面证据，观众只会把它当广告词。
  - 待老板确认

- **问题**：你明确不做什么？比如不卖什么口味、不用什么做法、不接什么要求？是哪次事情让你定下这个边界？
  - **我的推测**：成都厨师来南乐半年，口味调整和本地接受度之间一定有真实取舍；这类边界能立人设，但必须是老板真实经历。
  - 待老板确认

- **问题**：顾客说过一句什么话，让你觉得“他选这里不是因为便宜”？
  - **我的推测**：真正的差异化可能是“这一口味道”“出摊后的热乎劲”“点菜方便”之一，不一定是老板认定的“正宗”。要以顾客原话为准。
  - 待老板确认

## 一句话定位

**成都厨师在南乐，用川味串串火锅、川味烧烤、川菜接住下班后的这一口热乎。**

这句不承诺“最正宗”，而是把身份、地域、三个经营品类和消费场景说清楚；“下午4点出摊”负责后续视频里的持续证明。

## 六维地基

### 1. 人设定位

- **原料在哪**：真材料是“成都来的川菜厨师”“做川菜9年”“来南乐半年”“每天下午4点出摊”。“正宗”“低门槛”是产品卖点，不是人设；“专业”这类词也不能直接当人设。
- **形容词翻译成行为**：不说“有烟火气”，改成“下午4点开始备料、开摊、掌勺”；不说“川味专业”，改成“成都人做川菜9年，镜头里把关键工序拍出来”。
- **人设标签句**：**下午4点出摊的成都川菜厨师**
- **用了哪个入口**：特殊经历 + 职业身份。
- **验证**：立得住。成都籍贯、9年川菜经验、来南乐半年、每天4点出摊，都能在店里反复拍到；它不是一次性噱头，而是每天都会发生的工作现场。
- **在同类账号里的位置**：同行多是“老板报团购”“菜品特写”“探店感镜头”；这个号不抢美食博主路线，而是让观众记住“一个从成都来、下午4点开干的厨师”。差异在人物和固定时间场景，不靠夸张口号。
- **证据链**：  
  1. 下午4点备料、出摊、掌勺的真实过程；  
  2. 川味串串火锅、川味烧烤、川菜轮流呈现的制作细节；  
  3. 顾客真实高频提问与厨师现场回答；  
  4. 待确认后，加入一位真实回头客或一次真实服务事件。  
- **边界**：不说“全南乐第一”“成都人做的就一定正宗”；不攻击本地同行；没有真实顾客原话，不编“顾客吃完感动”“排队爆满”。

### 2. 用户定位

- **一句话画像**：下班路上刷视频、临时约朋友吃饭，想找一口热乎川味，又不想为了点菜和价格纠结太久的南乐新锐白领；以及晚上要带家人吃饭、会先确认辣度和能点什么菜的精致妈妈。
- **为什么是他们、不是另一批**：先抓新锐白领和精致妈妈，因为他们的消费场景分别对应下班解压、朋友聚餐、家庭晚饭，和三个品类都能接上。暂不把“纯打卡的外地游客”当主攻人群——门店是本地消费，账号前期需要本地可到店的人，而不是泛美食围观。
- **他们心里真正在想什么**：新锐白领想的是“今天别再纠结吃什么了，最好看着就想去”；宝妈想的是“带家里人去，辣度、菜品和环境能不能提前看明白”。
- **决策链路**：刷到一条视频后不会立刻相信，需要先看几条：是否真在营业、厨师是否一直本人出镜、食物是否稳定、位置怎么找；随后可能收藏，等到下班或聚餐时再翻出来。对本地餐饮来说，持续露脸比单条硬广更重要。
- **什么时刻会想起你**：下午下班前不知道吃什么；朋友临时约饭；周末带孩子或接待家人；天气转凉想吃热乎的。
- **他在平台上搜什么**：`南乐火锅`、`南乐烧烤`、`南乐川菜`、`南乐晚上吃什么`、`南乐聚餐`、`南乐一元火锅`。

### 3. 内容定位

- **长期提供什么价值**：**让南乐人提前看见，今晚这口川味值不值得去吃。**
- **内容方向**：选**多元四类打底 + 一个固定现场栏目**。理由是门店每天都能拍出摊和制作，但目前没有证据证明能长期支撑高成本单一挑战；先用过程、知识、故事、观点测试，再把“下午4点出摊”做成固定栏目。
- **不选纯单一主题的原因**：若整个号只拍“一元火锅”，会压缩川味烧烤、川菜的存在，也容易把账号拍成价格号；三个品类同等重要，需通过轮换建立完整认知。

**当前阶段配比**

- **作用配比**：流量型60%、人设型15%、变现型25%。  
  起号期的首要任务是让南乐陌生用户刷到并记住，流量必须最大；但餐饮不能长期只涨围观，所以从第一周开始保留变现内容；人设占小头，先用真实出摊场景建立熟悉感，不急着讲大故事。

- **每块用什么形式**：  
  - 流量型60%：以晒过程、地域差异、冷知识式口播为主，靠“成都厨师在南乐下午4点出摊”“同一锅底不同吃法的画面差异”等人货场切入；不讲卖点，不引导到店。  
  - 人设型15%：以真实职业故事、出摊观点为主，只讲“我为什么这样做、今天遇到什么”，不把菜品当广告。  
  - 变现型25%：以晒过程、情境还原、教知识为主，分别让川味串串火锅、川味烧烤、川菜展示一个看得见的成交理由：配方、现做过程或点菜便利性，具体理由待前采验证后定。

- **题材分配**：主赛道“川味串串火锅、川味烧烤、川菜”占75%；目标人群兴趣题材占25%，主要是下班吃什么、朋友聚餐、带家人吃饭、南乐本地口味差异。三个经营品类按批次**各占约三分之一**，轮流出现，不把任何一个降成配角。

- **主力形式**：档案没有“数据最好的内容类型”，不能假装已有验证。起号前20条先以**真实晒过程**做主力形式：资源最匹配、可每天拍、最容易让陌生人确认“店是真的、厨师是真的、食物在做”；再根据本地完播、评论和到店询问决定是否加大口播知识或人物故事。

- **用户路径**：  
  - 刷到：流量型用出摊、地域差异、反常识画面让人停下；  
  - 记住：人设型重复“成都厨师、下午4点出摊”；  
  - 信：变现型拍清真实做法、点菜问题和食物结果；  
  - 联系/到店：变现型只给一次明确到店指令。

**三种视频各怎么拍**

- **流量型**  
  - 四大脚本：晒过程型——“下午4点，成都厨师在南乐开摊前先做哪一步”→过程推进→收在一口热锅的画面；结尾只说：**“你们下班最想吃哪一口？”**  
  - 起号36计：**第31计·南北/地域差异：**同一类食材，成都厨师按自己的川味顺序处理，再问南乐人平时更习惯哪种口味；重点是差异和讨论，不讲优惠、不引导到店。

- **人设型**  
  - 四大脚本：讲故事·职业经历——“来南乐半年的成都厨师，下午4点为什么必须到摊上”→讲真实工作选择→落在当天出摊动作；结尾只说：**“关注我，看我每天4点怎么开摊。”**  
  - 起号36计：**第7计·一句话设定故事感：**厨师整理食材时说“我来南乐半年，每天下午4点先把这件事做完再开火”→镜头跟到动作结果；只讲人，不推菜。

- **变现型**  
  - 四大脚本：教知识·解题型——“第一次来，川味串串火锅、川味烧烤、川菜怎么点才不容易纠结？”→按真实菜单给出选择逻辑→拍出上桌结果；结尾只说：**“想吃川味的，下午4点后到店看当天出摊。”**  
  - 起号36计：**第10计·情境还原：**还原一桌顾客不知道怎么点的真实场景→厨师按人数、吃辣程度和需求给建议→上桌；前提是顾客同意拍摄，或用店员真实演示，不能伪装成顾客。

**配比核验**

1. **流量型与阶段匹配：是。** 0—1000粉起号期，60%流量型是最大块。  
2. **主力形式有验证吗：否，待验证。** 档案未给历史数据，只能先选资源最匹配的晒过程做测试。  
3. **大流量内容够不够：是。** 60%围绕厨师、食物、下午4点出摊现场，并使用地域差异、反向观察等看点。  
4. **有无人群兴趣题材：是。** 25%围绕下班、聚餐、家庭晚饭这些本地生活场景。  
5. **每个数字有理由吗：是。** 数字由起号阶段、本地餐饮短决策和现有拍摄资源共同推导，不是套成熟账号比例。

**第一条该发什么**

- **选题**：`下午4点，成都厨师在南乐出摊前，先把哪一口川味准备好？`
- **目的**：流量型，只担“让陌生人认识这个现场”这一件事。
- **打法**：起号36计 **第31计·南北/地域差异**，用“成都做法”和“南乐人熟悉的吃法”形成讨论；画面只拍真实备料、开火、出摊，结尾问：**“南乐人吃串串，先拿什么？”**
- **为什么第一条拍它**：下午4点是每天重复发生的真场景，人物、时间、食物一次讲清；它比上来就报价格更像内容，也为后续三个品类轮换留下空间。

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：视频配音Vlog + 少量近景口播。一个人、一部手机即可拍，真实出摊过程比坐店讲知识更有说服力。  
- **产能**：待确认拍摄人手与老板可出镜时间；在未确认前，按每周稳定拍3条设计，不承诺高频日更。  
- **在哪拍**：备料台、出摊现场、火锅锅边、烧烤操作区、川菜出锅区；少拍空白墙和菜单海报。  

### 5. 风格调性（只给结论，≤200字）

- **正向匹配**：选正向匹配。成都厨师、摊位、热锅、烟火声本身就是可信场景，不需要硬演反差。  
- **气质关键词**：热乎、利落、实在。  
- **会说的一句话**：`下午4点开火，今晚这口热乎的先给你备上。`  
- **不会说的一句话**：`全南乐都在吃，错过就亏。`  
原因：前者有现场和动作，后者既空又像硬广。

### 6. 变现定位（只给结论，≤250字）

- **卖什么**：川味串串火锅、川味烧烤、川菜；客单价区间**待确认：需要门店真实菜单与常见点单金额**。  
- **成交路径**：抖音刷到本地视频 → 主页确认位置/营业时间 → 下午4点后到店 → 通过真实菜单完成点单。  
- **最缺的信任证据**：顾客为什么第二次还来、三个品类各自最常被点的真实理由，以及辣度、分量、点单方式等高频问题的现场答案。  
- 完整的变现拆解请用「商业定位」板块。  

## 🧠 记忆点设计

- **固定语言**：每条出摊视频以“下午4点，开火”开场。  
  - 怎么重复：只在当天真实开摊时说。  
  - 为什么有关：它把成都厨师和真实营业节奏绑在一起。  
  - **待验证**：观察评论是否有人主动提“4点开火”。

- **固定动作**：开火前由厨师完成一个真实、稳定的准备动作，例如掀锅盖、检查食材或点火。  
  - 怎么重复：每条过程片前3秒保留同类动作，但不要求一模一样。  
  - 为什么有关：让观众一眼知道“又到开摊时间了”。  
  - **待验证**：先拍5条，看哪个动作最容易被记住。

- **固定场景声音**：保留火锅沸腾、烧烤滋啦声、炒菜声中的一种原声。  
  - 怎么重复：不强压音乐，给原声1—2秒呼吸。  
  - 为什么有关：餐饮账号需要食物现场感，不靠空洞口播。  
  - **待验证**：看完播是否因原声提升，而不是强行固定音效。

## ⚡ 差异化：A + 变量B

### 1. 下午4点出摊现场 + 固定时间情境

- **常规A**：同行拍成品菜品特写，加价格字幕。
- **变量B**：情境类“换场景/固定时间入口”——每次从下午4点开摊切入。
- **A+B 长什么样**：不先拍成品，先拍成都厨师到操作区、备料、开火，再进入当天其中一个品类：川味串串火锅、川味烧烤或川菜。它服务下班前正在想“晚上吃什么”的本地人，而不是只满足老板展示菜品的欲望。

### 2. 常规川味制作 + 南北/地域差异

- **常规A**：厨师讲“我们家味道好、配方好”。
- **变量B**：情境类“南北差异”。
