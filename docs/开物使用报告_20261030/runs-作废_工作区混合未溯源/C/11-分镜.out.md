### 4. 🧰 拍摄清单

- **必备**
  - 手机
  - 手机支架或三脚架；没有时可用店内稳定柜台固定手机
  - 要试坐的布艺沙发样品
  - 可擦拭的手机镜头布
  - 受访店主的拍摄和发布同意

- **加分项**
  - 领夹麦：减少店内说话声、走动声对采访的影响
  - 小型补光灯：店内背光时补亮老周和受访者面部
  - 另一部手机：可选，用于拍侧面试坐细节；没有时全部用单手机固定机位完成

- **道具与场地**
  - 布艺沙发样品
  - 店内座位区
  - 自家家具店门店环境
  - 如存在不同样品，提前确认样品可试坐，并标记各自位置
  - 如需回答“能不能拆洗、怎么打理”，提前准备对应的真实产品说明或由现场人员确认

### 5. ⚠️ 这条片子最容易翻车的3个地方

1. **【风险】采访回答被剪成未经证实的经营趋势** →【怎么避】只保留受访店主对本店前后时段的具体回答，并保留“按现场真实情况回答”的原意，不使用“全县城都变了”等扩大表述。

2. **【风险】没有不同样品却硬剪成沙发对比** →【怎么避】拍前先确认是否有可比较的不同布艺沙发；没有就只拍现有样品的完整试坐，不补拍不存在的第二张。

3. **【风险】60秒内塞入全部原稿，导致采访和试坐动作都被切碎** →【怎么避】优先保留“主问题、一个具体回答、完整试坐动作、面料确认、到店行动”，删掉重复解释和没有证据的泛泛回答。
