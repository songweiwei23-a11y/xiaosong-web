## 第1步：脚本策略卡

- **核心问题**：第一次挑布艺沙发，除了看颜色、坐一下，还要怎么判断是否适合家里日常使用？
- **内容目的**：变现型，引导有需求的本地家庭到店看实物、试坐。
- **目标人群**：准备置办家具的新婚家庭、换房业主。
- **采用形式**：以**36计·第35计 街头采访**衔接沙发实物对比。先问店主前后时段的经营变化和座位使用情况，再由老周在样品前演示如何试坐、摸面料。对比的重点是不同沙发的实际体验，而不是预设哪张更好。
- **事实边界**：前后时段拍摄前统一确认；采访回答和现场试坐感受均以实际情况为准。若店内有可供比较的不同布艺沙发，再拍同人、同动作试坐；否则只展示现有样品，不虚构第二张。
- **素材缺口**：受访店主的回答、不同样品的实际体验，需要现场拍摄后确定。口播与受访原声合计控制在约60秒；下方条件追问按现场情况选用，剪辑时为真实回答留出时间。

## 第3步：完整分镜脚本

### 【镜头1】0—8秒｜开场钩子

- **画面**：沙发样品区。老周坐下后起身，再切到手摸坐面和靠背的近景。若有不同样品，可拍老周依次试坐的画面，不预设体验差异。
- **台词**：  
  “第一次挑布艺沙发，坐下觉得软就定，和认真坐过再选，差别在哪？”  
  “今天我准备问问店里的座位是怎么用的，再带你看看沙发该怎么试。”
- **情绪**：从熟悉的挑选动作切入，在“差别在哪”处稍停，留下问题。
- **拍摄/收音**：手机固定拍中景，补拍坐面、靠背近景；优先收清人声。

### 【镜头2】8—25秒｜采访与常见挑法 😓

- **画面**：经同意，在受访店主门口或公共座位区采访；不拍店名、收款码和未经同意的人脸。
- **主问台词**：  
  “跟【待确认的前后时段】比，您店里生意有什么变化？具体变在哪里？”
- **受访者**：按现场真实回答。
- **条件追问台词**：  
  “这个变化主要体现在来店的人、消费方式，还是忙的时段？”  
  “有没有一件可以分享的小事，让您这样判断？”
- **深入问题台词**：  
  “店里的座位平时主要是谁坐，什么时候用得多？”
- **受访者**：按现场真实回答；对方不确定或表示没有变化，也保留原意。
- **切回沙发样品，老周台词**：  
  “挑沙发时，要是只看颜色，坐一下就起身，坐面合不合适、靠背能不能贴住，可能还没感受清楚。”
- **拍摄/收音**：采访时手机靠近受访者；按回答情况选追问，成片保留与座位使用相关的原声，不把个人回答剪成整体生意趋势。

### 【镜头3】25—45秒｜完整试坐 💡

- **画面**：老周在布艺沙发上坐下、自然放脚、靠向靠背，再起身；手摸面料，拍坐面与靠背接触位置。
- **台词**：  
  “到家以后，沙发不是只给眼睛看的，还得想想平时谁坐、喜欢靠着还是坐直。”  
  “换个挑法：先坐进去，脚自然落地，感受坐面的位置，再靠上去，看看腰背有没有支撑。”  
  “起身也试一试，感受动作顺不顺；再摸摸面料，问清楚能不能拆洗、平时该怎么打理。”
- **情绪**：从“只坐一下”转到具体可执行的试坐动作，语速放稳，让观众看清动作。
- **拍摄/收音**：固定机位拍完整动作，再补坐面、靠背、面料近景。拆洗方式只提出问题，不预设样品可以拆洗。

### 【镜头4】45—52秒｜样品对比与差异揭示 ⚡

- **画面**：**如现场有不同布艺沙发样品**，保持同一个人、同样试坐动作，依次拍两张沙发的坐面和靠背状态；如没有，则继续拍现有样品，并保留对比建议。
- **台词**：  
  “如果现场有不同样品，就按同样的坐法挨个试，看看哪张更适合家里常坐的人。”  
  “这就是为什么挑沙发不能只凭一眼：颜色看得见，坐着合不合适，还得自己试。”
- **情绪**：落点不是宣布哪张更好，而是把选择权交回给实际使用的人。
- **拍摄/收音**：镜头角度尽量一致；不编造支撑效果或耐用性。

### 【镜头5】52—60秒｜收尾与行动

- **画面**：老周坐在样品上，手轻触面料后看向镜头。
- **台词**：  
  “沙发是给日子坐的。”  
  “准备挑布艺沙发的，到店坐一坐、摸一摸再决定。”
- **拍摄/收音**：收尾语速放慢，留出坐面与面料的画面。

## 第4步：执行与优化建议

- **拍前准备**：确认同一组前后时段、受访店主是否同意拍摄和发布，以及沙发样品能否试坐。采访可在不影响经营的情况下进行；对方不愿露脸时，可经同意拍手部或背影并录原声。
- **采访记录**：先录主问，再按回答选追问，最后问座位由谁使用、何时使用。记录对方判断所依据的具体事情，不预设变化及原因。
- **样品素材**：先拍现有沙发的完整试坐，再拍面料细节；若有不同样品，老周用相同动作分别试坐，实际感受现场记录。
- **剪辑顺序**：开头提出差别 → 采访保留相关真实回答 → 快速试坐的局限 → 完整试坐与实物观察 → 到店行动。受访原声加入后，优先删减重复串场和未使用的条件追问，避免超过60秒。

### 🎯 先判断这条视频的目的

已带入的用户目的、人群、主线优先，不从主题重新定目的；没有明确目的时才参考下列类型选择表达，混合目的完整保留：
- **流量型**（让从没关注过你的陌生人看到、停下来、看完、转发（大流量，非关注用户的播放））：第一秒的看点或噱头：反差、悬念、冷知识，或一个爆款元素的具体画面；大众一听就懂，不用行业黑话
- **人设型**（让人记住你、信你这个人（深度信任），也让消费者对你这个人产生兴趣、喜欢你：靠真实的经历、性格、人品、行为或某个举动）：一个具体的举动或"这个人就是这样"的瞬间——先让人想看这个人
- **变现型**（直接推动目标用户咨询、到店、下单）：直接点出目标客人的难题，把要突出的成交理由摆在前面（为什么选你）；精准比广重要，点进来的要是会买的人

## ⚙️ 本次要求
所有标题都承接同一具体主线、人群、立场与事实状态。尚未采访或观察时，用问题/计划式表达，不将假设写成已证实结论；不得为标题承诺的效果补编正文。
标题要有**具体的东西**（一件事、一个处境、一个数字或一个人，不一定是商品细节）加一个**反差、冲突或悬念**，观众刷到第一眼就知道这条说的是什么、为什么跟他有关。不用「XX，怎么…」「别只…」「你知道吗」「XX 的 N 个技巧」「原来…」这类万能模板。标题不超过 20 个字，只有一个主句，不用分号把几句话连成一串。标题里不留占位符（X、某某、几元、XX 这类）：要么写出真的数字和东西，要么换一个不需要填空的说法。标题要读起来像一句人话，不硬拼两个不相干的名词或比喻（「压箱底的裤子，像怕被评价的人」这种就不通）。写完先把标题通读一遍，读不顺、看不出在说什么的就重写。写法对照（只学写法，不照抄）：平：「装修选材料，别被忽悠」（只有话题，没有东西，也没有冲突）；好：「同一面墙，两种漆，三年后差在哪」（具体的东西、一个对比、一个悬念）
任何创作都必须符合现实的生活逻辑，有说服力才行。创作的来源只能是现实中真实存在、大多数人认可的事，不凭空编造。下面三类说法一律不写（括号里的例子只说明是什么类型，不是清单，类似的说法同样不写）：
- 太离谱：一件事改变整体、判若两人、几天就见效的保证（比如「收腰就能换风格」「换个头像粉丝就翻倍」「同一件外套两种人」「换个招牌字体，营业额就翻一番」）
- 太简单：一招搞定、一句话让客户当场签单、躺着就能赚（比如「一句话让客户当场下单」「躺着月入过万」）
- 太不科学：违背常识或没有依据的因果（比如「喝某种水就能瘦」「敷一下就能消炎」）
一件事能带来的变化，要有它真实的条件、过程和代价。反差和看点要来自生活或镜头里看得见的具体变量，不靠硬切换人设、身份或结果。拿不准能不能成立，就写清楚前提和做法，不替事实下结论。一个小细节（一种做法、一个动作、一句话、一处调整）只能改变它直接作用的那一处，不能写成它让整件东西、整个人或整家店都变了。结论的范围也要和证据一样大：一次现场的反应只说明这一次，不能推成普遍的道理（比如一位客户换了靠垫说舒服，就说挑沙发都要试靠垫）。
主角是这个号卖的东西（这条管变现型，以及任何要做对比、前后变化的内容）：观众看完要觉得「是这家的东西（或手艺）让人变好看、变好用、变好吃」，而不是学会一个技巧就不用来买了。
- 流量型也遵守对比变量规则：不是每条都要对比，但只要做反差、对比或前后变化，变的是卖的东西，人、场和动作保持一致；不为了满足规则把每条都拍成商品对比。流量型仍以用户感兴趣的看点为主，不硬推卖点
- 要做对比、反差、前后变化，变的那一样必须是这个号在卖的东西，其他条件不变：同一个人（同一个空间、同一桌人）先后用两样东西——这家卖的，和普通的、旧的或常见的——前后差别看得见，才证明是东西好。例：同一个人先后穿两套衣服，前后两种风格；同一个客厅换两张沙发；同一个人戴两副镜框
- 不做「同一件东西换个穿法、搭法、摆法、用法、吃法」的对比：卖的东西没变，差别只能归功于技巧，证明不了东西好，也给不出来买的理由
- 卖的就是手艺或服务的（剪发、验光、装修设计、厨师的做法），手艺本身就是货：同一个人剪前剪后、同一份食材我们的做法和普通做法，这类对比成立
- 穿法、搭法、用法这类技巧只能顺带一句，不能当一个方向或一条内容的看点；人设型可以以人为主角，但做对比时仍遵守上面的变量规则
- **标题围绕出发点和元素**：参考内容（选题或脚本）里写明的「爆款元素」就是这条标题要用的元素，用它的句式写，光看标题就认得出；标题也要落在人、货、场其中一个上（这条围绕的那个）。参考内容里没写元素的，标题就只按出发点写，不硬套句式

## 📐 公式拆解：数字+动作

**结构**：[具体数字] + [动作动词] + [可衡量的结果]
**为什么有效**：数字提供确定感，结果提供收益预期，两者都降低了「值不值得看」的判断成本
**达标示例**：3个动作，让你的视频完播率翻一倍
**不达标示例**：几个提升完播率的小技巧（数字模糊、结果不可衡量）

公式只管表达，不改变核心问题；材料不支持反转、原因或结果时，不虚构它们去套公式，说明取舍并给同主线可用表达。不要套用示例里的行业和数字。

## 🪝 钩子机制库（开篇 36 计）

标题和开头是同一门手艺。下面 36 张卡是钩子的底层机制，
**每个标题挑 1 张主卡**——堆钩子等于没钩子。

- **圈定人群**（相关性）：人群标签 + 痛点/欲望 + 继续观看理由
- **直接提问**（相关性）：问题 + 意外事实/冲突 + 答案承诺
- **自我否定**（认知缺口）：我本以为A，没想到B；本来不想说，但C
- **反认知**（认知缺口）：大众认为A → 我的结论非A/B → 证据预告
- **高价值展示**（价值与损失）：结果/经历/投入 + 要讲的方法 + 适用对象
- **直击痛点**（相关性）：想要X但怕Y/正在遭遇Z + 低门槛解法
- **损失厌恶**（价值与损失）：别人都告诉你A，却没人告诉你B；问题发生是因为缺少C
- **对比·对立·区别**（冲突与选择）：A和B怎么选/有什么区别/谁更X
- **头牌借势**（认知缺口）：头牌对象 + 相关问题 + 我的专业解释
- **警告避坑**（价值与损失）：千万别做X/必踩N坑 + 后果 + 规避承诺
- **焦虑/危机**（价值与损失）：再不A就B；转错C就是D；哪类人永远E
- **内幕揭秘**（认知缺口）：揭秘X内幕/内行不说的真相 + 具体机制
- **速成**（价值与损失）：N秒/分钟 + 学会/搞定 + 具体微任务
- **引发共鸣**（相关性）：共同处境/细节 + 被理解的判断 + 后续解释
- **极限数字**（价值与损失）：很少有人知道/只有少数人注意到 + 具体信息（不写具体百分比，除非有依据）
- **不同视角**（认知缺口）：X身份眼中的Y；A阶段与B阶段怎么看Y
- **“最”字极值**（价值与损失）：对象/场景 + 最 + 极值属性 + 标准
- **未来趋势与历史来源**（认知缺口）：时间节点 + 趋势/机会/历史脉络 + 依据
- **对赌对抗**（事件期待）：若达不到X就付出Y → 执行 → 结果
- **金钱相关**（价值与损失）：做X挣/花/亏/省多少钱 + 条件与拆账
- **盘点与推荐**（价值与损失）：目标人群 + N个对象 + 统一标准 + 推荐理由
- **跨界组合**（认知缺口）：赛道A × 赛道B → 新问题/解释
- **送惊喜**（事件期待）：瞒着/偷偷为X准备Y → 揭晓 → 真实反应
- **荷尔蒙/人物吸引**（视觉与感官）：魅力人物首帧 + 适度悬念 + 内容价值
- **盲盒**（事件期待）：预算/范围 + 随机机制 + 抽到什么做什么
- **奇葩猎奇**（事件期待）：行业/地区 + 奇葩对象 + 到底多奇葩
- **负面事件切入**（价值与损失）：负面动作/误解 → 原因与过程 → 反转/价值
- **直接说具体的事**（事件期待）：时间/地点/动作 + 一个具体发现 + 感受/联想
- **高情绪**（视觉与感官）：鲜明态度 + 表情/声音/动作 + 内容出口
- **强节奏**（视觉与感官）：强动作首帧 → 节拍剪辑 → 连续信息点 → 呼吸点
- **凑热闹**（视觉与感官）：热闹首帧 + 为什么聚集 + 核心事件
- **沉浸感**（视觉与感官）：清晰动作 + 近景细节 + 原声/节奏 + 完成反馈
- **反差感**（视觉与感官）：预期A + 画面B → 反差 → 能力/故事解释
- **特殊视角拍摄**（视觉与感官）：新POV首帧 + 事件展开 + 视角带来的发现

- **复古怀旧**（视觉与感官）：年代锚点 + 视听符号 + 个人记忆/今昔对照

## 📱 抖音的标题逻辑

- 推荐流场景：用户是被动刷到的，标题要在 1 秒内制造点击冲动
- 前 8 个字最重要——信息流里经常只显示这么多，钩子必须前置
- 善用数字、对比、反常识；疑问句比陈述句点击率高
- 长度 12-20 字为宜，太长会被截断

## 🚫 违规与风险词

- **禁用「揭秘」**：容易招同行举报，也容易被判定为夸大。改用：教你看懂、带你了解、对比分析
- **禁用「震惊」**：典型标题党用词，平台会降权。改用：用具体数字替代情绪词
- **禁用「第一/最好/最强」**：绝对化用语违反广告法，会被限流。改用：我用过最顺手的、我个人最推荐的
- **禁用「100%/彻底根治」**：绝对化承诺，有违规风险。改用：大多数情况下、我这几次都有效
- ⚠️ **卡名不是豁免**：钩子库里有「内幕揭秘」这张卡，指的是「用信息不对称制造价值感」这个机制，不是允许你在标题里写「揭秘」二字。机制照用，词要换——写成「干了十年装修，我只看这 3 个地方」，而不是「装修行业内幕大揭秘」。

## 📏 每个标题的自查项（不达标就重写，不要输出不达标的）

1. **前 8 个字是否已经有钩子**——信息流里经常只显示这么多
2. **有没有一个具体的锚点**——数字、时间、身份、场景，四者至少占一个
3. **是否避免了形容词堆砌**——「很棒」「超赞」「绝了」不算信息
4. **换个人能不能用**——如果这个标题套在任何视频上都成立，它就太空了
5. **是否命中风险词**
6. **钩子卡是真用上了，还是只贴了个名字**——机制要能在标题里看出来
7. **标题里的数字、结果、身份是否都有材料或档案支持**——没有就改成材料能证明的说法，或标注「待核实」，不写成既定事实

【承接已有内容的要求】
- 原始方案用于保留创作意图，当前版本是本轮操作对象；用户本轮明确修改的内容优先。不得用聊天记忆里的其他方案替换所选方案。

- 既有 AI 稿、公式示例、拍摄设想和聊天记忆不是已核实事实。只沿用用户已确认的信息；原稿与档案冲突时标注待核实，不自行决定。
- X串、XX元、待核实、示例、假设等占位或未确认信息不能补成具体数字或真实经历。缺少依据就保留「待核实」或换成不依赖该事实的表达，不夸大或编造事实。
- 价格、数量、时间、地点、身份、经营经历与效果承诺逐项核对来源。创作建议可以新增，但必须标明是建议，不写成已经发生的事实。

【本轮内容落实规则】
- 原始用户想法及本轮明确修改决定目的、主体、比较对象、时间范围和取材方式。已有 AI 稿只作待核对草稿，不能把其中示范情节、假定回答或推断当作新增真实素材。
- 先完成当前这条内容；深化来自具体问题、证据、动作及信息关系，不能因追求流量先换节目、等涨粉后再兑现本来的任务。方法库用于解决问题，不用于补造冲突、结果或情绪。
- 只使用已确认资源。建议的人员、设备、场地或服务须写为可选且说明替代；不凭空承诺免费服务、价格、优惠、效果，不设未经验证的完播率或成交率合格线。效果看用户自己的基线和真实数据。
- **说话人**：出镜人是谁，以人设事实卡的「出镜人是谁」「和店的关系」为准，没填就不编身份。出镜人本人的台词、口播、旁白只用「我」「我们」「你」，不用「他」「她」指他自己，也不用身份称呼指他自己（禁用称呼：「师傅」「主厨」「老板」这类）；身份决定他说什么，不念出来。受访者、顾客等其他人照实称呼。
【采访落地】每个切口先写同一个必问主问题，再写该切口深入的问题及至少两条条件追问。不要只问“生意怎么样”：追问具体变化、可分享的事例、判断依据。不要把关门时间、泛情绪、未来预期换成主问题。
- 不预设答案不同、有反转或老板沉默：如果不同，比较各自依据；如果一致，深入共同原因与例子；不知道也如实保留。店主的感受不能包装成营收统计或整座县城趋势。
- 无采访实录或用户明确尚未采访时，全部候选标题、开头、正文、封面及建议都按事前方案写，只说准备问什么或待验证的问题。禁止“我问了一圈/问过几家/每家答案不一样/他的话让我意外”等已完成报道语气，禁止预填老板台词、答复比例、经营结果。参考稿出现这些句子也必须改正。已有真实实录时才可据实保留。
- 纯文字文案只放已知主持人/旁白台词和实际提问，不放未知回答占位，也不写未经采访验证的总结；受访者的“按现场真实回答”只放采访执行稿或分镜中。
- 角色分清：出镜人是主持人，说「我」；受访者是顾客或店主，只说他/她自己的话，不由出镜人替他说，也不让出镜人用「你」去问自己。主持人问受访者时，「你」指受访者本人。
【比较口径锁定】先从原始用户想法确定两端是什么，在所有主问、追问、标题、正文与分镜里保持同一口径。前后对比不能偷偷变成同比、和往年比、与平时比；用户明确要这些比较时才使用。
- 原意只说“前后”未给日期时，具体日期和口径待核对，不擅自改换比较对象。各对象保持相同时间范围和维度，不能拿不同长度的总量直接比较。
- 若用户只说国庆前后，主问题示范：“跟国庆前的那段时间比，国庆后这几天您店里生意有什么变化？”具体日期拍前统一。追问示范：“具体是来客、每单消费、忙的时段哪一项变了？也可能没变，您实际是哪种？”“能说一件让您这样判断的具体事吗？”“您觉得原因是什么，有什么依据？”示范仅适用于这个原意；用户明确假期期间与节后，则按那两个时段问，不能套节前。
- 没有前期录像也可采访同一店主对两个时段的回忆，再记录当下可见现象并注明证据边界；不安排回到已过去的日期补拍，不编两次走访，不要求全天跟拍来替代短访谈。
