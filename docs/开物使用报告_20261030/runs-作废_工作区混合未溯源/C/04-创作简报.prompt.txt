## 🔍 先说这一行

- **归口**：本地实体店，属于 **D类家居家电**，主业是家具零售，工坊能力是支撑销售的信任场景，不是单独做木工教学号。

- **这行的钱怎么赚**：  
  家具不是高频复购生意，主要靠单次成交客单和熟人转介绍。实木餐桌椅、布艺沙发都属于“要放进家里很多年”的决策，顾客在意的不只是价格，而是看得见的材质、尺寸、坐感、是否适合自家空间。  
  获客难点不在“让人知道店在”，而在于顾客刷到视频后，愿不愿意把“要不要去看看”变成一次到店。县城家具店普遍门头多、款式相似，线上内容如果只拍陈列，用户分不清为什么要来这一家。

- **客人的决策链路**：  
  多数不是刷到就下单，而是“有结婚、交房、换房、父母搬家等需求”后，先刷短视频建立印象，再问家人、问熟人、到两三家店看款和比价，最后带着户型、预算和家人一起回来确认。  
  从产生需求到成交，通常是中长链路；具体周期待确认，取决于本地交房节奏、顾客是否已装修完，以及店内是否有现货或定制需求。

- **时间规律**：  
  家具需求通常跟着交房、装修进度、结婚、节假日返乡团聚走。周末和节假日更适合拍“家人一起试坐、量尺寸、选桌椅”的真实到店场景；工作日适合拍工坊、看料、打磨、上样等过程。  
  本地具体旺淡季待确认：需要先问清近一年哪几个月到店客流明显集中。

- **这行老板普遍会犯的错**：  
  常见自嗨点是：把一屋子家具从头拍到尾，配上“款式多、质量好、价格实在”。老板自己知道差别，顾客隔着手机看不出来。  
  老周目前有一个可用优势：**自家木工工坊、木料能现场看**。但如果只拍木头堆和机器，同样会变成“行业内部看得懂，普通顾客不知道和自己有什么关系”。内容必须翻译成顾客关心的话：这张桌子放家里，为什么要看这块料；沙发为什么要坐、按、看细节。

- **同行现在都在拍什么**：  
  同城家具号常见内容是家具走一圈、价格口播、工厂库存、喊促销、展示大展厅。这类内容没有明确的观看任务，用户滑过去后只记住“又一家卖家具的”。  
  这个号的空档应是：**让县城家庭以顾客视角进入工坊、现场看料、试坐、判断适不适合自家。** 不是讲深奥术语，而是解决“我进店到底该看什么”的不安。

## 🗣 我会先问老板的几个问题

- **问题**：最近一次顾客没有马上定下来，是卡在哪一步？当时顾客原话是什么，老周怎么回应的？
  - **我的推测**：可能卡在“实木材质看不懂”“家人意见不一致”“沙发坐着和图片不一样”中的一个。依据是家具决策通常需要多人共同确认，且档案已明确顾客常问沙发怎么挑。
  - 待老板确认。

- **问题**：顾客进店问“这是什么木头”时，老周会带他看哪一块、摸哪里、怎么解释？
  - **我的推测**：老周的差异不该停在“能看木料”，而在于他是否能把木料、做法和成品对应起来，让顾客明白自己看的是什么。
  - 待老板确认。

- **问题**：最近一位老客第二次回来，第一次买了什么，后来为什么又找回来？
  - **我的推测**：复购或转介绍很可能来自一次具体的交付体验、某件家具使用后的反馈，或者家人看见实物后认可，而不只是“价格合适”。
  - 待老板确认。

- **问题**：有没有明确不卖、不接的货或做法？是因为发生过哪件具体事？
  - **我的推测**：如果老周对材料、结构或售后有明确边界，这比说“质量好”更能立人设；但不能替他预设任何承诺。
  - 待老板确认。

- **问题**：这个月工坊里发生过哪件值得拍的小事？比如改了一处结构、挑出一块不合适的料、顾客带家人来试坐。
  - **我的推测**：工坊每天发生的具体动作，是账号比展厅号更有画面的素材来源。
  - 待老板确认。

- **问题**：请一位顾客原话回答：为什么选这里，而不是再去别家看看？
  - **我的推测**：顾客真正感受到的差异，可能是“能亲眼看料”“老板解释得明白”“坐过再选更放心”，不一定是老板以为的“自家工坊”本身。
  - 待老板确认。

## 六维地基

### 1. 人设定位

- **原料在哪**：  
  真材料是：“老板老周”“做家具12年”“本地人”“自家有木工工坊”“现场看木料”。  
  “专业、靠谱、实在”这类词如果没有行为支撑，只是形容词。这里要把它翻成可拍行为：老周不站在展厅里空讲，而是把顾客带到木料和工坊现场，对着一块料、一张桌子、一个结构讲清楚。

- **人设标签句**：  
  **带你进工坊看木料的老周**

- **用了哪个入口**：  
  **特殊经历 + 痛点+职业。**  
  12年做家具和自家工坊，是老周能持续提供细节的经历；“家具看不懂、怕买错”是顾客真实痛点。

- **验证**：  
  这个人设能立住，因为工坊、木料、制作过程都是真实存在且可反复拍摄的场景，不靠一次性故事。  
  验证方式不是口头说“我做了12年”，而是持续拍：一块料进工坊后会经历什么、餐桌结构怎么做、顾客为什么坐完沙发才决定。

- **在同类账号里的位置**：  
  同行多是“展厅销售型”——讲款式、价格、活动；也有“工厂库存型”——拍堆货和发货。  
  老周应站在“**本地家庭的家具翻译官**”位置：不替顾客做夸张承诺，只把他们进店时看不懂、问不出口的地方，带到现场看明白。

- **证据链**：  
  1. 工坊里一块料到成品的过程；  
  2. 同一空间里不同餐桌尺寸、椅子坐感的现场判断；  
  3. 顾客问沙发怎么挑时，老周用手按、坐、看细节的真实回答；  
  4. 老客户回店、带家人看家具的真实事件。  
  第4项必须有真实顾客授权后再拍。

- **边界**：  
  不说无法验证的材质结论，不踩同行，不承诺“一次买对很多年”。  
  不把“工坊”拍成炫耀身份的背景，而要让每次进工坊都回答一个顾客问题。否则人设会从“懂家具的人”变成“只会展示机器的人”。

### 2. 用户定位

- **一句话画像**：  
  **县城刚交房、准备结婚或换房的一家人，周末带着父母和伴侣逛家具店，手机里存了很多款式，却不知道实木和沙发到底该怎么选。**

- **主攻人群**：  
  **精致妈妈 + 资深中产。**  
  前者常是家庭空间和使用体验的重要决策者，关心材质、耐用、清洁和家人使用；后者更在意一家人坐下来是否舒服、摆进家里是否得体、选错后的麻烦。  
  这两类人比纯“看热闹”的年轻用户更接近家具成交。

- **为什么不是另一批人**：  
  不主攻只想看低价清单、只问一句价格就走的泛流量；也不把刚毕业、暂时没有置家需求的人当成交核心。  
  不是不能看，而是他们短期没有明确家具决策场景，账号起号期不能把内容全部围着他们转。

- **他们心里真正在想什么**：  
  “我不是不想买好点的，我是怕花了钱，过几个月才发现桌子不适合、沙发坐着累，还不知道问题出在哪。”

- **决策链路**：  
  刷到“看料/试坐/家庭选家具”内容 → 先关注或收藏 → 连续看几条确认老周不是只讲销售话术 → 带着户型、尺寸或家人到店 → 现场看料、试坐、看款 → 回家商量后再定。  
  所以不能指望一条视频成交，前期需要用连续的过程和判断内容铺信任。

- **什么时刻会想起你**：  
  交房后开始量尺寸时；装修进入硬装收尾时；婚期临近需要添置家具时；家里旧沙发塌陷、餐桌不够用时；亲戚朋友问“县城哪里能看家具”时。

- **他在平台上搜什么**：  
  “县城实木餐桌”“本地家具店”“布艺沙发怎么选”“沙发坐感”“实木餐桌看什么”“新房家具怎么买”。

### 3. 内容定位

- **长期提供什么价值**：  
  **让本地家庭把家具看明白，再带着问题进店。**

- **内容方向**：  
  选 **A多元四类打底 + 一个单一王牌栏目**。  
  原因是新号还没有验证哪种内容最能起量，不能一开始把全部产能压在单一主题；但工坊是稳定、真实、可连续发生的素材源，可以做成王牌栏目。  
  不直接做纯单一主题号，是因为“天天拍做家具”容易拍成流水账，沙发品类也会被边缘化。

- **王牌栏目**：  
  **《老周带你进工坊看家具》**  
  一集只解决一个具体问题：一块木料、一张餐桌的一个结构、一次沙发试坐、一位顾客的一个顾虑。实木家具和布艺沙发轮流出现，不强行同框。

- **当前阶段配比**：

  **作用配比：流量型55% / 人设型15% / 变现型30%。**  
  账号处于0—1000粉起号期，流量型必须是最大块，先让同城陌生用户认识“县城有个能带人看料的老周”；变现型保留30%，因为家具决策周期长，要尽早积累到店理由；人设型暂不做太多，真实故事素材目前不足，硬讲容易失真。

  **每一块用什么形式做：**  
  - 流量型：以“过程+反常识知识+轻观点”为主。拍木料、工坊、试坐这些天然有画面的内容，用大众能懂的问题做钩子。  
  - 人设型：以真实过程和职业经历为主，不硬煽情。比如老周为什么坚持带顾客看料，前提是先有真实事件。  
  - 变现型：以“教知识+晒过程”为主。实木餐桌椅拍看料、结构、尺寸判断；布艺沙发拍试坐、按压、面料和家庭使用场景。

  **题材配比：主赛道75% / 目标人群兴趣25%。**  
  75%围绕实木家具、布艺沙发、工坊与选购；25%围绕新房布置、家庭聚餐、父母来家、婚房置办等置家场景。  
  原因是家具号不能只讲家具术语，也要让准备成家的县城家庭觉得“这就是我最近在忙的事”。

- **主力形式**：  
  **暂定视频配音Vlog式过程展示。**  
  档案没有提供“数据最好的内容类型”，因此不能把任何形式说成已验证主力。暂定过程展示，是因为现有资源里工坊、木料、成品、试坐都可直接拍，老周不需要一开始靠长篇口播撑住。  
  待连续测试后，以完播、同城评论、私信和到店提及来源决定是否强化口播。

- **每类内容管哪一段路**：  
  - **刷到**：流量型用“工坊里看得见的反差、冷知识、家庭置家场景”让陌生人停下来。  
  - **记住**：人设型让用户记住老周是那个愿意把家具带到木料现场讲的人。  
  - **信**：变现型用看料、试坐、判断过程，证明他讲得清、店里看得到。  
  - **联系**：变现型明确引导“带尺寸到店看”，减少顾客第一次进店的心理门槛。

- **三种视频各怎么拍**：

  **流量型**  
  - 四大脚本：教知识·拆解型。方向是“家里餐桌到底该看桌面，还是先看下面？”开头给反常识问题，中间用现场结构做演示，结尾只引导评论：**“你家餐桌最先坏的是哪儿？”**  
  - 起号36计：**第36计·冷知识：反常识结论 → 证据/例子 → 原理 → 应用。** 事件是老周拿起一张实木餐桌，从桌面移到桌腿、连接处，告诉大家“很多人先摸桌面，真正影响日常稳定的是这里”，不报价、不推店。

  **人设型**  
  - 四大脚本：讲故事·观点立场。前提是有真实经历后拍：“为什么我愿意把顾客带进工坊看料？”讲一次具体顾客提问或选择过程，再说自己的判断。结尾只引导关注。  
  - 起号36计：**第7计·一句话设定故事感：普通动作 + 目标/困境/关系设定 → 故事期待。** 事件是“今天有一家人来看餐桌，老周先没带他们看成品，先带去了工坊”，后续用真实结果收住。

  **变现型**  
  - 四大脚本：教知识·解题型。方向是“家里有孩子、常在沙发上坐很久，进店试沙发先做哪几步？”按坐、靠、起身、看面料、问使用场景展开。结尾只说：**“带上你家尺寸，到店试坐。”**  
  - 起号36计：**第15计·正确做法VS错误做法：错误示范 → 后果 → 正确示范 → 原理/适用条件。** 事件是同一位体验者只坐一下就选沙发，与坐、靠、起身、看扶手高度后再判断的差异。成交理由是“可现场试坐、能结合需求判断”，不编材质和功能承诺。

- **配比核验**：  
  1. **是**：新号流量型55%，是最大块。  
  2. **待验证**：无历史数据，暂以过程展示为主力；连续测试后再定。  
  3. **是**：55%的流量内容都要求有人、货、场与明确看点，不能只讲术语。  
  4. **是**：25%题材连接新房、婚房、家庭聚餐等置家兴趣。  
  5. **是**：每个比例对应起号期、家具决策链长、工坊有过程素材这三个条件。

- **第一条该发什么**：  
  **选题：**《一张餐桌进店前，老周先带你看哪块木料？》  
  **目的：流量型。**  
  **打法：第36计·冷知识 + 教知识·拆解型。**  
  开场直接拍老周把手放在木料上：“买实木餐桌，别只在展厅摸桌面，先跟我进工坊看这块料。”  
  中间只讲“木料和成品的关系”，不报价、不讲促销、不引导到店。结尾只问：“你买家具会先进展厅，还是想先看工坊？”  
  它适合做开场，因为一秒就能看见“人、木料、工坊”三个独有元素，先让陌生人知道这个号和普通家具陈列号不一样。

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：视频配音Vlog为主，少量现场口播。工坊、木料、打磨和试坐比坐着讲更有说服力，老周只需在关键处出镜说一句判断。  
- **产能**：待确认团队、拍摄时长与老周可出镜时间，当前不能承诺固定周更数量。建议一次集中拍工坊素材，再拆成多条。  
- **在哪拍**：木工工坊拍实木家具；展厅和试坐区拍布艺沙发；门口或装车区只在有真实事件时拍。

### 5. 风格调性（只给结论，≤200字）

- **正向匹配**：选正向匹配。老周、工坊、木料、展厅应呈现县城本地家具老板的直接和真实，不做浮夸反差。  
- **气质关键词**：直白、看得见、接地气。  
- **会说的一句话**：“这张桌子好不好，别急着问价，先把下面这处看明白。”  
- **不会说的一句话**：“这款一上新就被抢空，今天不定就没了。”  

### 6. 变现定位（只给结论，≤250字）

- **卖什么 + 客单价区间**：实木家具、布艺沙发；客单价区间待确认。  
- **成交路径**：抖音内容种草 → 评论/私信问款 → 带户型尺寸到店 → 现场看木料、看款、试坐 → 成交。  
- **最缺的信任证据是什么**：真实顾客为什么愿意到店、现场如何看料和试坐、成交后的使用反馈；目前均待采集。  
- 完整的变现拆解请用「商业定位」板块。

## 🧠 记忆点设计

- **道具：固定拿一小块木料或桌腿连接件**  
  每次讲实木家具时，老周手里拿真实材料，不拿泛泛的指示棒。它直接对应“现场看木料”，让观众形成“这个人是拿实物说话”的印象。  
  **待验证**：看评论区是否自然出现“拿木头那个老板”等称呼。

- **动作：先敲、摸、翻，再开口解释**  
  每条实木内容开头保持“手先碰材料，嘴再解释”的节奏。动作不是噱头，而是把判断落在现场。  
  **待验证**：避免做成机械重复，若完播下降就保留动作、不强制放在每条首帧。

- **场景声音：保留短暂工坊原声**  
  木料落台、打磨、推料等原声可保留1—2秒，再进入配音。它让账号和纯展厅口播区分开。  
  **待验证**：现场噪音过大时不硬留，保证人声清楚优先。

## ⚡ 差异化：A + 变量B

### 1. 展厅讲款式 + 换场景

1. **常规A**：同行站在展厅里介绍“这张桌子是什么材质、这套沙发什么价格”。  
2. **变量B**：情境类的“换场景”。从展厅退回工坊，让同一件家具先有来处。  
3. **A+B长什么样**：拍一张餐桌时，先拍成品，再切到同类木料和制作环节，老周只回答一个问题：“顾客摸到的桌面，前面经过了什么？”  
   服务对象是对材质没有概念、又怕买错的家庭，不是为了展示机器。

### 2. 沙发讲卖点 + 正确VS错误

1. **常规A**：拍布艺沙发的颜色、款式和摆放效果。  
2. **变量B**：行为类的“正确做法VS错误做法”。  
3. **A+B长什么样**：同一位体验者先“坐一下就说行”，再完整试坐：坐深、靠背、起身、扶手高度。老周说清不同家庭该重点感受哪里。  
   服务的是正准备换沙发、但只会看颜色的人；不把“试坐技巧”拍成主角，主角仍是不同沙发带来的实际体验差异。

### 3. 工坊流水账 + 顾客视角

1. **常规A**：机器运转、师傅忙碌、成品摆满一屋。  
2. **变量B**：情境类的“换个视角”。  
3. **A+B长什么样**：镜头用“顾客进工坊”的第一视角走一遍：门口看到木料、老周指一处、再回到展厅看成品。字幕只保留顾客会问的问题：“这块料最后会变成哪张桌子？”  
   服务的是不懂行业但想亲眼确认的人，不拍空泛的“工坊实力展示”。

# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

县城家具店做的不是“看见就买”的生意，而是**一次置家、多方决策、到店确认**的生意。

实木家具和布艺沙发都属于中高决策品：顾客通常在交房、装修收尾、结婚、换房、旧家具不好用这些节点才会集中购买。一个人刷到视频后，很少当场下单，更常见的是先存视频、问家人、量尺寸、去几家店看款，再带着父母或伴侣一起回店确认。

这行主要靠**单次客单**，不是靠高频复购。顾客这次买餐桌椅、沙发，下一次可能隔很久；但一旦家里摆出来合适，熟人来家里坐过、看过，才可能产生转介绍。所以前端获客的关键不是把“店里有什么”拍得越全越好，而是降低顾客第一次进店的顾虑：  
**我看不懂木料怎么办？沙发坐着几分钟觉得行，搬回家会不会不适合？我家尺寸能不能放？**

从成本上看，家具店线上获客真正卡的不是拍摄成本，而是两件事：

1. **内容拍得像广告，用户不愿意停留。**  
   展厅扫一圈、家具摆一排、老板报价格，用户看完只知道“又一家卖家具的”，不会形成到店理由。

2. **视频有播放，但没有把人送到到店环节。**  
   家具成交必须看实物、试坐、量尺寸。视频只负责让顾客愿意带着问题来，不能替代现场决策。

我推测，本地需求高峰会跟着交房、装修收尾、婚期、节假日返乡团聚走；周末适合拍家庭到店试坐、看款、量尺寸，工作日更适合拍工坊、木料、制作和上样。  
**待确认：近一年哪几个月到店客流最集中、顾客通常从进店到成交要多久。**这两个答案会决定后续内容是在“提前种草”还是“临门促成交”上加码。

这家店不该卷“全店最低价”或“款式最多”，因为目前没有相关事实支撑，也不适合靠无法长期验证的口号成交。真正能建立信任的，是让顾客看到：**木料能进工坊看、实木家具看得见来处、布艺沙发能坐下来按需求选。**

**一句话定位：老周带你看实木家具、布艺沙发，进工坊把木料看明白再选。**

## 变现全景

### **现在能卖什么**

1. **实木家具**  
   包括实木餐桌椅及门店现有实木家具品类。  
   这是“工坊看料”最容易被顾客理解的承接品类：木料、制作过程、结构和成品之间能形成完整画面。

2. **布艺沙发**  
   顾客已有明确提问：“沙发怎么挑不踩坑”。  
   这说明它不是只能放在展厅里等人看的产品，而是可以围绕“试坐、靠背、起身、面料和家庭使用”做内容承接的品类。

3. **到店选款与尺寸沟通**  
   这不是独立收费服务，但它是成交链路中必须被包装出来的一步。  
   对顾客来说，“带着尺寸来店里看”比“直接来买家具”心理压力小得多；对门店来说，这一步能筛掉只看热闹的人，也能让真实需求更快进入选款。

4. **工坊看料体验**  
   同样不建议单独收费，它应该是实木家具成交中的信任环节。  
   工坊不是景点，价值在于顾客能把“我看不懂实木”变成“我知道自己在看什么”。

### **各自的客单价与毛利大致区间**

客单价、毛利率、现货与定制占比，档案均未提供，不能编数字。

但经营上可以先按两类决策来管理：

- **实木家具：中高决策、偏中长链路。**  
  顾客会看材质、尺寸、结构、摆放空间，也更容易把家人意见带进决策里。毛利不应只看单件，还要看餐桌椅、配套家具与整屋添置的连带可能。

- **布艺沙发：中高决策、偏体验型成交。**  
  顾客会先看外观，但最终是否成交往往卡在“坐感是否适合”“尺寸是否压空间”“家里老人、小孩是否好用”。沙发内容必须让顾客知道自己到店该试什么，而不是隔着手机猜软硬。

**待确认：**  
- 实木家具与布艺沙发的价格带；  
- 现货、预订、定制各占多少；  
- 两类产品里，哪一类成交周期更短；  
- 顾客最常犹豫的价格区间与原因。  

这些信息补齐后，才能决定哪个产品承担“引流到店”，哪个产品承担“主要利润”。

### **决策难度**

两类都是**高决策产品**，不适合把短视频当成直接下单页。

顾客看视频后的合理动作应是：  
**收藏/关注 → 私信问能不能看 → 带尺寸到店 → 看料或试坐 → 回家商量 → 成交。**

所以账号不能只追求播放，也不能急着每条都报价格。价格可以在私信和到店沟通中解决；视频更该先解决“我为什么要去老周这里看”的问题。

## 主推产品

**起号前30天，建议主推“实木餐桌椅的到店看料与选款”，同时保持布艺沙发稳定露出。**

这不是把布艺沙发降成配角，而是按当前资源排序：实木餐桌椅更容易用“自家木工工坊、现场看木料”建立账号第一层辨识度；用户刷到木料、制作、结构与成品对应关系时，能快速理解老周和普通展厅销售的区别。

但布艺沙发必须占到变现内容的固定位置，建议在每周内容中至少有一条围绕沙发试坐和家庭使用场景。原因很直接：店里卖布艺沙发，且顾客已明确常问“怎么挑不踩坑”。如果主页长期只出现木料和餐桌，顾客会把账号认成“只卖实木桌椅”，后续再补沙发会很被动。

**为什么不直接主推最贵的产品？**  
因为当前缺少具体价格、利润和成交数据。起号期先推最容易拍出信任证据、最能解释门店差异的产品，比先推最贵的产品更稳。等连续出现“问餐桌的人多，但到店后连带看沙发”的真实情况，再考虑把“新房整套置家”做成更高客单的承接方向。

## 成交路径

### 1. 第一次接触：刷到“顾客看不懂的家具问题”

顾客第一次刷到的，不应该是促销海报，而应该是一个和自己有关的场景：

- “买实木餐桌，别只摸桌面，先看下面这处。”
- “沙发不是坐一下就能定，家里常坐的人要试这几个动作。”
- “同样是餐桌，为什么有人摆回家后才发现过道不够走？”
- “这块工坊里的木料，最后会变成展厅里的哪张桌子？”

**这一步的目标：让本地有置家需求的人停下来。**

流失的人：暂时没有家具需求、只想看低价促销的人。  
这部分人流失是正常的，因为账号不是为了吸引所有人，而是为了吸引正在结婚、交房、换房、添置家具的人。

### 2. 产生兴趣：看见“老周讲得明白，而且有现场可看”

用户不是因为听到“做家具12年”就信任，而是因为连续看到老周把话落在实物上：

- 讲餐桌时，手里有木料、桌腿、连接处；
- 讲沙发时，有人真实坐、靠、起身、按面料；
- 讲工坊时，从木料回到对应成品，而不是只拍机器；
- 讲尺寸时，用真实空间或真实摆放距离演示，而不是空讲公式。

**这一步的目标：让用户从“看个热闹”变成“这个人能帮我把家具看明白”。**

流失的人：只想马上要报价、没有意愿理解自己需求的人。  
不需要为了留住这类人，把视频改成价格轰炸；高决策家具不能靠一条报价视频解决所有顾虑。

### 3. 沉淀：主页和私信把“刷视频”变成“带问题来店”

主页必须承担三个任务：

1. 让人一眼看懂：老周卖**实木家具、布艺沙发**；  
2. 让人知道区别：可以进工坊看木料；  
3. 让人知道下一步：带户型尺寸或家里需求到店看。

私信不建议一上来追问“什么时候来店”，而应先接住顾客的问题：

- 家里大概多大空间；
- 几个人常用；
- 目前是交房、装修收尾，还是准备换旧家具；
- 更想先看实木家具还是布艺沙发。

**这一步的目标：把泛浏览者筛成有明确场景的潜在到店客。**

流失的人：离本地太远、暂时不具备置家条件、只想线上比最低价的人。  
这是必要筛选。县城实体店最怕私信很多、有效到店很少，客服时间被无效咨询占满。

### 4. 临门一脚：到店看料、试坐、对尺寸

实木家具的临门一脚，不是反复强调“自家工坊”，而是让顾客亲眼看见：  
**这张成品对应什么木料、自己在意的部分该看哪里。**

布艺沙发的临门一脚，不是让顾客坐一秒钟，而是结合家庭实际使用方式试：

- 常坐的人身高和习惯；
- 是否经常久坐；
- 起身是否方便；
- 扶手、靠背和坐深是否适合；
- 沙发放进去后是否挤压动线。

**这一步的成交理由：现场看得见、坐得到、能结合需求判断。**

流失的人：尺寸不合适、家人意见尚未统一、预算与需求不匹配的人。  
这类人不应被硬推。应留下其真实顾虑，后续用对应内容和到店复看承接，而不是靠“今天不定就没了”制造压力。

## 信任证据清单

高决策家具的信任，不靠“质量好”“价格实在”这类形容词，要靠顾客能看见的动作和过程。

1. **一块木料到一张实木餐桌的对应过程**  
   - 证明：真实、工坊能力  
   - 画面：木料落台、加工局部、桌腿或连接处、最后切回展厅成品。  
   - 注意：只拍店里真实能拍到的环节，不补拍、不摆拍成当天制作。

2. **老周带顾客看木料时，真实讲哪一处**  
   - 证明：专业判断  
   - 画面：顾客提出问题，老周指向木料或成品对应部位。  
   - 待确认：顾客授权与真实问答素材。

3. **同一张餐桌的结构细节与日常使用关系**  
   - 证明：专业  
   - 画面：从桌面切到桌腿、连接处、底部支撑，不做无法验证的材质承诺。  
   - 价值：顾客能带走一个进店检查思路。

4. **布艺沙发完整试坐过程**  
   - 证明：产品体验、服务  
   - 画面：坐下、后靠、起身、手按面料、看扶手和靠背。  
   - 重点：拍“不同需求看不同位置”，不是宣称某种坐感适合所有人。

5. **顾客带尺寸到店后，如何对应实物看款**  
   - 证明：服务过程  
   - 画面：户型图或尺寸记录打码后出现，老周在展厅用对应家具讲摆放逻辑。  
   - 待确认：是否有真实顾客愿意出镜；没有就拍老周用店内真实空间演示，不伪造客户案例。

6. **家具进入展厅前后的检查动作**  
   - 证明：真实、门店日常  
   - 画面：搬运、擦拭、摆放、核对局部细节。  
   - 注意：只能拍实际存在的检查流程；目前是否有固定验货流程待确认。

7. **成交后的真实使用反馈或老客回访**  
   - 证明：结果、售后  
   - 画面：顾客授权后的家中实拍、回店反馈，或顾客一句真实原话。  
   - 待攒：先问最近一位回头客——第一次买了什么、后来为什么又回来、实际使用中最满意或最在意的是什么。

8. **老周明确“不建议这样选”的边界**  
   - 证明：专业、人设  
   - 画面：某个家庭需求与某张家具不匹配时，老周说明“这种情况别急着选这款”。  
   - 待确认：必须来自真实销售经历，先问老周有没有明确不接、不推荐的情况，以及发生过什么。

### 前采优先补的6个问题

1. 最近一次顾客没马上定，是卡在材质、尺寸、家人意见还是价格？顾客原话是什么？  
2. 顾客问“这是什么木头”时，老周通常会带他看哪一块、怎么解释？  
3. 最近一位老客第二次回来，第一次买了什么，第二次为什么又找回来？  
4. 顾客挑布艺沙发时最常问哪一句？老周通常让他先坐、先按，还是先看哪里？  
5. 店里有没有明确不建议顾客买的情况？是哪一次真实经历让老周形成这个判断？  
6. 最近一个月工坊里发生过哪件具体事：一块料被挑出来、一张桌子调整细节、顾客带家人来看料，完整经过是什么？

这些问题不是为了找“感人故事”，而是为了把后续内容从“我很懂家具”变成“这里发生过一件真实的事”。

## 变现型内容怎么排

### **变现型内容占比建议：30%**

起号期仍要以流量型内容为最大块，不能一上来就把主页拍成产品目录；但家具决策周期长，变现内容也不能等到账号做大后才发。

30%的作用是：让看过流量内容的人在主页里找到“我到店后能解决什么”。  
建议按每10条内容安排3条变现型：其中至少2条覆盖实木家具，至少1条覆盖布艺沙发；下一轮再反过来，提高沙发比重，保证两个品类持续轮流出现。

### 方向1：实木餐桌，进店先看哪里

- **成交路径位置**：第一次到店前的兴趣建立  
- **成交理由**：现场看木料，能把成品和材料对应起来  
- **观众变化**：从“我不知道怎么挑”变成“我到店至少知道先问什么、看什么”  
- **四大脚本**：教知识·解题型  
  - 场景难题：买实木餐桌只会摸桌面；  
  - 放大顾虑：桌面看着顺眼，不等于自己知道该看哪些部位；  
  - 现场解决：老周在工坊和展厅各指一个对应位置；  
  - 收住：不同家庭的需求不同，到店再结合尺寸看。  
- **36计拍法**：**第15计·正确做法VS错误做法：**先拍“只摸桌面就准备定”，再拍“看木料—看连接处—回到成品确认”的真实到店流程。  
- **结尾行动**：**到店**  
  - “准备买餐桌的，带上尺寸到店看料再看款。”

### 方向2：布艺沙发，别只坐一下就决定

- **成交路径位置**：顾客已在看款、准备比较时  
- **成交理由**：可现场试坐，能结合家庭使用需求判断  
- **观众变化**：从“看颜色和款式”变成“知道自己到店该试哪些动作”  
- **四大脚本**：晒过程·过程展示  
  - 钩子：有人坐一下就说“这个行”；  
  - 关键过程：坐深、后靠、起身、扶手、面料逐个试；  
  - 结果：不是每个人都适合同一张沙发，要按常坐的人和使用方式选。  
- **36计拍法**：**第10计·情境还原：**真实顾客进店看沙发，老周根据对方的家庭使用场景提醒试坐顺序，顾客自己感受差别。  
- **结尾行动**：**到店**  
  - “准备换沙发的，别只看图片，来店里把坐、靠、起身都试一遍。”

### 方向3：一块料最后做成哪张桌子

- **成交路径位置**：从刷视频到形成到店意愿  
- **成交理由**：自家工坊，木料可现场看  
- **观众变化**：从“工坊和我有什么关系”变成“原来我买的成品能回到材料现场看”  
- **四大脚本**：晒过程·火车节  
  - 起因：顾客想知道展厅里的餐桌从哪里来；  
  - 关键步骤：木料—加工局部—成品结构；  
  - 结果：顾客到店可以看料，再看相应成品。  
- **36计拍法**：**第32计·换个视角：**用顾客第一视角从工坊走到展厅，提出“这块料最后会变成哪张桌子”，最后切到成品。  
- **结尾行动**：**到店**  
  - “想先看材料再看成品的，到店我带你走这一圈。”

### 方向4：带着家里尺寸来，怎么避开“买回去才发现不合适”

- **成交路径位置**：临近到店与成交确认  
- **成交理由**：能结合真实空间和需求选款  
- **观众变化**：从“看上就买”变成“知道尺寸是到店前必须带的资料”  
- **四大脚本**：教知识·案例型  
  - 真实案例：必须来自顾客授权的真实到店场景；  
  - 拆解：顾客先提供哪些尺寸，老周怎么在展厅对应看款；  
  - 结果：减少因空间不匹配造成的反复比较。  
- **36计拍法**：**第17计·互联网嘴替/替网友做：**从评论区征集“家里这个尺寸怎么选”，挑一条真实问题，老周在店内拿现有家具演示如何判断。  
- **结尾行动**：**私信**  
  - “拿不准尺寸怎么记，私信发【尺寸】，我把到店前要量的地方发你。”  
  - 前提：门店必须准备好真实可用的尺寸记录清单；没有就不发这条。

**提醒：变现内容不是硬广。**  
每条先帮顾客减少一个不确定，再让顾客知道到店能继续解决。不要在一条里同时报价格、喊活动、讲工坊、讲沙发、让人私信；信息越多，顾客越难记住行动理由。

## 定价与节奏

### 起步阶段建议怎么定价

当前不建议为了短视频专门做“低价引流款”，原因有两个：

1. 门店真实价格带、毛利和供货能力未确认，贸然设计低价款可能压缩利润，也可能引来大量只比价、不成交的咨询。  
2. 家具是高决策品，真正需要的是到店看料、试坐、量尺寸，不是靠一个低价标签把人拉进来。

起步阶段更适合做的是**低门槛到店动作**，而不是低价：

- 带尺寸到店看款；
- 到店看木料与成品对应；
- 到店完整试坐布艺沙发；
- 私信领取“到店前要量哪些尺寸”的清单——前提是门店真的能提供并使用。

这类动作的作用，是让顾客先迈出第一步，不是虚构优惠。

### 什么时候可以涨价、涨价依据是什么

当前没有价格资料，不能建议具体涨幅。

如果后续要调价，依据不应是“视频播放高了”，而应至少满足其中几项真实变化：

- 某类产品到店咨询与成交更稳定；
- 顾客越来越多是带着“看了老周视频”来的；
- 工坊看料、试坐和尺寸沟通已经形成固定流程；
- 某类产品的交付、售后和复购反馈有足够证据；
- 顾客不再只问价格，而是开始主动问“我家这种情况适合哪种”。

### 前30天的执行节奏

- **第1—10条：先测停留点。**  
  重点拍木料、工坊、餐桌结构、沙发试坐。测试用户更愿意停在哪个问题上，不急着报活动。

- **第11—20条：补到店理由。**  
  把评论区和私信里反复出现的问题，拍成“到店前要看什么”的变现内容；同时保证实木家具、布艺沙发都持续出现。

- **第21—30条：判断哪条成交链路更顺。**  
  看是“看料内容”带来更多到店，还是“沙发试坐内容”带来更多咨询。只看播放量不够，要记录顾客进店时是否提到视频、问的是哪类产品、最终卡在哪一步。

如果连续发出12—18条后，播放有但没有本地咨询，优先检查主页简介、地域表达、到店动作是否明确；  
如果咨询多但到店少，优先检查私信有没有先接住顾客需求，而不是一上来只问“什么时候来”。

## ⚠️ 风险

1. **只拍工坊，布艺沙发被长期压住。**  
   工坊画面容易拍，但店里卖的不只有实木家具。解决办法不是强行把餐桌和沙发塞进同一条，而是内容排期里固定轮换：实木家具讲看料和结构，布艺沙发讲试坐和家庭使用。

2. **把“能看木料”拍成一句口号。**  
   顾客不需要反复听“我们有工坊”，而是需要知道“我去了能看什么、看完能帮我做什么判断”。每次进工坊必须对应一个具体问题，否则就是机器流水账。

3. **起号期过早促销，账号变成线上传单。**  
   促销信息可以在有真实活动时发，但不能成为主页主力。家具成交链路长，顾客还没相信你，就先被催着下单，只会继续去别家比价。

4. **为了做案例而摆拍顾客。**  
   顾客试坐、带尺寸、回访反馈都必须是真的，并获得授权。没有真实客户素材时，宁可拍老周用店内空间演示，也不要制造“客户刚买完很满意”的剧情。

5. **没有记录线索来源，最后无法判断内容有没有挣钱。**  
   从第一位到店顾客开始，就要问一句：“你是刷到哪条视频过来的？”不需要复杂表格，至少记录日期、看的内容、咨询品类、是否成交、没成交卡在哪里。没有这个记录，后续只能看播放量猜经营效果。

## 📤 输出格式

严格按下面的小节标题和顺序输出，**标题一个字都不要改**——
各板块靠标题把简报切开，改了就读不到了。

### 1. 一句话定位
不超过30字。[身份]+[特点]+[价值]，要能让陌生人立刻知道这个号是干什么的。

### 2. 人设与口吻
分四行写，每行都要能直接指导写文案：
- **我是谁**：一句能被观众复述的人设标签。身份称呼只用人设事实卡「出镜人是谁」「和店的关系」里写的原词；卡里没写就不起称呼、不编身份，也不把别的行业或别的人的称呼套过来
- **说话什么调**：具体到语气词和句式习惯，不要写"亲切专业"这种
- **会说的一句话**：举一个真实例子
- **不会说的一句话**：举一个真实例子（这条比上一条更有用）

### 3. 说给谁听
分四行：
- **画像**：一句话，要具体到能想起某个真实的人
- **他最怕什么**：3条，每条都能直接拍成内容
- **他最想要什么**：3条
- **他会搜什么词**：写出他真会打出来的那几个词

### 4. 内容方向
分五行：
- **三种视频的配比**：照定位里定的抄，写成"流量型X%（主打什么）+ 人设型X%（主打什么）+ 变现型X%（主打什么）"——配比说的是目的，不是脚本类型
- **各自的结尾指令**：流量型要什么、人设型要什么、变现型要什么，每种只一个
- **两套打法各用什么**：四大脚本主打哪几种结构；起号36计主打哪几计（写计名，照定位里挑的来）
- **能长期挖的选题来源**：4-5个，每个举一个具体例子
- **明确不做的方向**：3条，说明为什么不做

### 5. 凭什么信你
分两行：
- **核心卖点**：2-3条，每条一句话
- **可以拍成画面的证据**：4-6条，必须是能真实拍到的东西，不是形容词

### 6. 怎么拍
分三行：
- **呈现形式**：口播/探店/Vlog/情景剧等，一句话说明为什么是它
- **真实条件**：设备、场地、一个人还是有帮手、一周能出几条
- **视觉调性**：光线、色彩、镜头稳不稳，一句话

### 7. 记忆点
2-3条。语言/动作/道具/服装/场景声音里挑，每条说明怎么重复。标明哪些还待验证。

### 8. 绝对不能说
逐条列出。包含账号自己的禁忌和通用红线（绝对化用语、承诺疗效等）。

## ✍️ 写作要求

- **每句都是指令**：能直接拿去指导写文案、起标题、排镜头。不要写"要注重…"这类空话
- **具体到能执行**：不要形容词，要具体的词、句、动作、画面
- **忠于定位**：结论必须来自上面那份定位，不要自己另起一套（事实性的年限、经历以账号档案为准）
- 人和事只写真的：人设里要让人记住的那个人、那件事，只用档案写的或前采里说的；不让店员或别人扮演顾客，不替老板编性格、经历、顾客原话。没有的，写「待确认：缺哪一条」，并给出先要问的那个具体事件。
- 任何创作都必须符合现实的生活逻辑，有说服力才行。创作的来源只能是现实中真实存在、大多数人认可的事，不凭空编造。下面三类说法一律不写（括号里的例子只说明是什么类型，不是清单，类似的说法同样不写）：
- 太离谱：一件事改变整体、判若两人、几天就见效的保证（比如「收腰就能换风格」「换个头像粉丝就翻倍」「同一件外套两种人」「换个招牌字体，营业额就翻一番」）
- 太简单：一招搞定、一句话让客户当场签单、躺着就能赚（比如「一句话让客户当场下单」「躺着月入过万」）
- 太不科学：违背常识或没有依据的因果（比如「喝某种水就能瘦」「敷一下就能消炎」）
一件事能带来的变化，要有它真实的条件、过程和代价。反差和看点要来自生活或镜头里看得见的具体变量，不靠硬切换人设、身份或结果。拿不准能不能成立，就写清楚前提和做法，不替事实下结论。一个小细节（一种做法、一个动作、一句话、一处调整）只能改变它直接作用的那一处，不能写成它让整件东西、整个人或整家店都变了。结论的范围也要和证据一样大：一次现场的反应只说明这一次，不能推成普遍的道理（比如一位客户换了靠垫说舒服，就说挑沙发都要试靠垫）。
- 主角是这个号卖的东西（这条管变现型，以及任何要做对比、前后变化的内容）：观众看完要觉得「是这家的东西（或手艺）让人变好看、变好用、变好吃」，而不是学会一个技巧就不用来买了。
- 流量型也遵守对比变量规则：不是每条都要对比，但只要做反差、对比或前后变化，变的是卖的东西，人、场和动作保持一致；不为了满足规则把每条都拍成商品对比。流量型仍以用户感兴趣的看点为主，不硬推卖点
- 要做对比、反差、前后变化，变的那一样必须是这个号在卖的东西，其他条件不变：同一个人（同一个空间、同一桌人）先后用两样东西——这家卖的，和普通的、旧的或常见的——前后差别看得见，才证明是东西好。例：同一个人先后穿两套衣服，前后两种风格；同一个客厅换两张沙发；同一个人戴两副镜框
- 不做「同一件东西换个穿法、搭法、摆法、用法、吃法」的对比：卖的东西没变，差别只能归功于技巧，证明不了东西好，也给不出来买的理由
- 卖的就是手艺或服务的（剪发、验光、装修设计、厨师的做法），手艺本身就是货：同一个人剪前剪后、同一份食材我们的做法和普通做法，这类对比成立
- 穿法、搭法、用法这类技巧只能顺带一句，不能当一个方向或一条内容的看点；人设型可以以人为主角，但做对比时仍遵守上面的变量规则
- **不编事实**：档案和定位里没有的数字、客单价、客群比例、案例、客户故事、效果承诺，一律不写；需要它的地方写【待确认】并注明缺哪一项
- **全篇控制在 1500 字以内**：这是要塞进每一次生成的，长了就是给所有板块加负担
- 不要写前言、不要复述定位、不要解释你在做什么，直接从"### 1. 一句话定位"开始
