### 1. 一句话定位
老板老周带你进工坊看家具，选实木餐桌椅和布艺沙发。

### 2. 人设与口吻
- **我是谁**：带你进工坊看木料的老板老周。
- **说话什么调**：用县城唠嗑口吻，短句直说；先指实物，再解释，不堆家具参数。
- **会说的一句话**：“别只在展厅摸桌面，跟我进工坊看这块料。”
- **不会说的一句话**：“这款全网最低，今天不买就没有了。”

### 3. 说给谁听
- **画像**：县城里准备结婚、刚交房或换房，周末带家人看家具的28—45岁家庭。
- **他最怕什么**：怕实木看不懂、花钱买错；怕沙发只坐一下，搬回家才发现不舒服；怕家具尺寸不合，摆进家里影响动线。
- **他最想要什么**：看得懂木料和结构；现场试坐后再选沙发；带着家里尺寸把家具选稳。
- **他会搜什么词**：县城实木餐桌、布艺沙发怎么选、实木家具怎么看、沙发怎么挑不踩坑、本地家具店。

### 4. 内容方向
- **三种视频的配比**：流量型55%（工坊看料、家具冷知识）+ 人设型15%（老板老周的真实职业经历）+ 变现型30%（看料、试坐、尺寸沟通）。
- **各自的结尾指令**：流量型引导评论；人设型引导关注；变现型引导到店。
- **两套打法各用什么**：四大脚本主打教知识·拆解型、教知识·解题型、晒过程·过程展示、讲故事·观点立场；起号36计主打第36计·冷知识、第15计·正确做法VS错误做法、第7计·一句话设定故事感、第10计·情境还原、第32计·换个视角。
- **能长期挖的选题来源**：  
  1. 木料辨认：买实木餐桌，先看桌面还是连接处？  
  2. 工坊过程：这块木料最后会变成哪张桌子？  
  3. 沙发试坐：坐、靠、起身，进店分别试什么？  
  4. 家庭置家：带家里尺寸到店，先确认哪几个位置？  
  5. 顾客问题：客人常问“沙发怎么挑不踩坑”，逐条用真实动作回答。
- **明确不做的方向**：不拍全店扫一圈，因为用户记不住差异；不做纯家具参数说明书，因为普通顾客看不懂；不靠虚假顾客案例和强行促销，因为家具需要现场看料、试坐和家庭商量。

### 5. 凭什么信你
- **核心卖点**：自家有木工工坊，实木家具可现场看木料；实木餐桌椅和布艺沙发都能到店看款、试坐。
- **可以拍成画面的证据**：  
  1. 木料落台、翻面、局部细节和对应成品；  
  2. 老板老周指着桌腿、连接处讲解；  
  3. 顾客真实坐下、后靠、起身、按面料；  
  4. 带尺寸到店后，在展厅对应看款；  
  5. 工坊打磨、推料等真实原声；  
  6. 老客回店或使用反馈，需先取得授权。

### 6. 怎么拍
- **呈现形式**：视频配音Vlog为主，关键判断用现场口播；工坊和试坐比坐着讲更能让人看懂。
- **真实条件**：手机、支架、收音设备；工坊和展厅都可拍；是否有帮手、每周能出几条待确认，先问老周可出镜时间和团队人数。
- **视觉调性**：保留木料落台、打磨等短暂原声，画面以自然光和真实场景为主，镜头稳定但不追求过度摆拍。

### 7. 记忆点
1. **道具**：讲实木家具时固定拿一小块木料或桌腿连接件；是否形成“拿木头的老板”记忆点，待验证。
2. **动作**：先敲、摸、翻材料，再开口解释；完播下降时保留动作但不强制每条首帧。
3. **场景声音**：保留1—2秒工坊原声；噪音影响人声时，以听清讲解为先。

### 8. 绝对不能说
- 不说“全网最低、绝对不会坏、买了就不会错、所有家庭都适合”等绝对化话术。
- 不编造价格、客单价、利润、客户数量、成交案例、顾客原话和使用效果。
- 不把“做家具12年”扩写成未确认的获奖、传承、行业地位。
- 不承诺“一次买对很多年”，只展示真实材料、结构、试坐和选款过程。
- 不攻击同行，不比较未核实的材料、价格和质量。
- 不把工坊拍成纯机器流水账，不把沙发只拍成颜色和款式展示。
- 不让店员或他人冒充顾客，不摆拍顾客满意、回购或成交。
- 不使用“匠心、用心、精心、始终、秉承、致力于、倾力打造、深耕、沉淀、赋能、焕新”等营销腔。
