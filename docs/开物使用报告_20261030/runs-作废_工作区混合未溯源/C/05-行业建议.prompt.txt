  获客难点不在“让人知道店在”，而在于顾客刷到视频后，愿不愿意把“要不要去看看”变成一次到店。县城家具店普遍门头多、款式相似，线上内容如果只拍陈列，用户分不清为什么要来这一家。

### 1. 人设定位

- **人设标签句**：  
  **带你进工坊看木料的老周**

- **用了哪个入口**：  
  **特殊经历 + 痛点+职业。**  
  12年做家具和自家工坊，是老周能持续提供细节的经历；“家具看不懂、怕买错”是顾客真实痛点。

- **验证**：  
  这个人设能立住，因为工坊、木料、制作过程都是真实存在且可反复拍摄的场景，不靠一次性故事。

- **在同类账号里的位置**：  
  同行多是“展厅销售型”——讲款式、价格、活动；也有“工厂库存型”——拍堆货和发货。  
  老周应站在“**本地家庭的家具翻译官**”位置：不替顾客做夸张承诺，只把他们进店时看不懂、问不出口的地方，带到现场看明白。

- **证据链**：  
  1. 工坊里一块料到成品的过程；  
  2. 同一空间里不同餐桌尺寸、椅子坐感的现场判断；  
  3. 顾客问沙发怎么挑时，老周用手按、坐、看细节的真实回答；  
  4. 老客户回店、带家人看家具的真实事件。  
  第4项必须有真实顾客授权后再拍。

- **边界**：  
  不说无法验证的材质结论，不踩同行，不承诺“一次买对很多年”。  
  不把“工坊”拍成炫耀身份的背景，而要让每次进工坊都回答一个顾客问题。否则人设会从“懂家具的人”变成“只会展示机器的人”。

- **主攻人群**：  
  **精致妈妈 + 资深中产。**  
  前者常是家庭空间和使用体验的重要决策者，关心材质、耐用、清洁和家人使用；后者更在意一家人坐下来是否舒服、摆进家里是否得体、选错后的麻烦。  
  这两类人比纯“看热闹”的年轻用户更接近家具成交。

- **为什么不是另一批人**：  
  不主攻只想看低价清单、只问一句价格就走的泛流量；也不把刚毕业、暂时没有置家需求的人当成交核心。

- **长期提供什么价值**：  
  **让本地家庭把家具看明白，再带着问题进店。**

- **内容方向**：  
  选 **A多元四类打底 + 一个单一王牌栏目**。

- **当前阶段配比**：

  **作用配比：流量型55% / 人设型15% / 变现型30%。**  
  账号处于0—1000粉起号期，流量型必须是最大块，先让同城陌生用户认识“县城有个能带人看料的老周”；变现型保留30%，因为家具决策周期长，要尽早积累到店理由；人设型暂不做太多，真实故事素材目前不足，硬讲容易失真。

  - 流量型：以“过程+反常识知识+轻观点”为主。拍木料、工坊、试坐这些天然有画面的内容，用大众能懂的问题做钩子。

  **流量型**  
  - 四大脚本：教知识·拆解型。方向是“家里餐桌到底该看桌面，还是先看下面？”开头给反常识问题，中间用现场结构做演示，结尾只引导评论：**“你家餐桌最先坏的是哪儿？”**

  **人设型**  
  - 四大脚本：讲故事·观点立场。前提是有真实经历后拍：“为什么我愿意把顾客带进工坊看料？”讲一次具体顾客提问或选择过程，再说自己的判断。结尾只引导关注。

  **打法：第36计·冷知识 + 教知识·拆解型。**  
  开场直接拍老周把手放在木料上：“买实木餐桌，别只在展厅摸桌面，先跟我进工坊看这块料。”  
  中间只讲“木料和成品的关系”，不报价、不讲促销、不引导到店。结尾只问：“你买家具会先进展厅，还是想先看工坊？”  
  它适合做开场，因为一秒就能看见“人、木料、工坊”三个独有元素，先让陌生人知道这个号和普通家具陈列号不一样。

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：视频配音Vlog为主，少量现场口播。工坊、木料、打磨和试坐比坐着讲更有说服力，老周只需在关键处出镜说一句判断。  
- **产能**：待确认团队、拍摄时长与老周可出镜时间，当前不能承诺固

# 💰 商业定位方案

## 🔍 先说这一行的生意逻辑

县城家具店做的不是“看见就买”的生意，而是**一次置家、多方决策、到店确认**的生意。

实木家具和布艺沙发都属于中高决策品：顾客通常在交房、装修收尾、结婚、换房、旧家具不好用这些节点才会集中购买。一个人刷到视频后，很少当场下单，更常见的是先存视频、问家人、量尺寸、去几家店看款，再带着父母或伴侣一起回店确认。

这行主要靠**单次客单**，不是靠高频复购。顾客这次买餐桌椅、沙发，下一次可能隔很久；但一旦家里摆出来合适，熟人来家里坐过、看过，才可能产生转介绍。所以前端获客的关键不是把“店里有什么”拍得越全越好，而是降低顾客第一次进店的顾虑：  
**我看不懂木料怎么办？沙发坐着几分钟觉得行，搬回家会不会不适合？我家尺寸能不能放？**

从成本上看，家具店线上获客真正卡的不是拍摄成本，而是两件事：

1. **内容拍得像广告，用户不愿意停留。**  
   展厅扫一圈、家具摆一排、老板报价格，用户看完只知道“又一家卖家具的”，不会形成到店理由。

2. **视频有播放，但没有把人送到到店环节。**  
   家具成交必须看实物、试坐、量尺寸。视频只负责让顾客愿意带着问题来，不能替代现场决策。

我推测，本地需求高峰会跟着交房、装修收尾、婚期、节假日返乡团聚走；周末适合拍家庭到店试坐、看款、量尺寸，工作日更适合拍工坊、木料、制作和上样。  
**待确认：近一年哪几个月到店客流最集中、顾客通常从进店到成交要多久。**这两个答案会决定后续内容是在“提前种草”还是“临门促成交”上加码。

这家店不该卷“全店最低价”或“款式最多”，因为目前没有相关事实支撑，也不适合靠无法长期验证的口号成交。真正能建立信任的，是让顾客看到：**木料能进工坊看、实木家具看得见来处、布艺沙发能坐下来按需求选。**

**一句话定位：老周带你看实木家具、布艺沙发，进工坊把木料看明白再选。**

## 变现全景

### **现在能卖什么**

1. **实木家具**  
   包括实木餐桌椅及门店现有实木家具品类。  
   这是“工坊看料”最容易被顾客理解的承接品类：木料、制作过程、结构和成品之间能形成完整画面。

2. **布艺沙发**  
   顾客已有明确提问：“沙发怎么挑不踩坑”。  
   这说明它不是只能放在展厅里等人看的产品，而是可以围绕“试坐、靠背、起身、面料和家庭使用”做内容承接的品类。

3. **到店选款与尺寸沟通**  
   这不是独立收费服务，但它是成交链路中必须被包装出来的一步。  
   对顾客来说，“带着尺寸来店里看”比“直接来买家具”心理压力小得多；对门店来说，这一步能筛掉只看热闹的人，也能让真实需求更快进入选款。

4. **工坊看料体验**  
   同样不建议单独收费，它应该是实木家具成交中的信任环节。  
   工坊不是景点，价值在于顾客能把“我看不懂实木”变成“我知道自己在看什么”。

### **各自的客单价与毛利大致区间**

客单价、毛利率、现货与定制占比，档案均未提供，不能编数字。

但经营上可以先按两类决策来管理：

- **实木家具：中高决策、偏中长链路。**  
  顾客会看材质、尺寸、结构、摆放空间，也更容易把家人意见带进决策里。毛利不应只看单件，还要看餐桌椅、配套家具与整屋添置的连带可能。

- **布艺沙发：中高决策、偏体验型成交。**  
  顾客会先看外观，但最终是否成交往往卡在“坐感是否适合”“尺寸是否压空间”“家里老人、小孩是否好用”。沙发内容必须让顾客知道自己到店该试什么，而不是隔着手机猜软硬。

**待确认：**  
- 实木家具与布艺沙发的价格带；  
- 现货、预订、定制各占多少；  
- 两类产品里，哪一类成交周期更短；  
- 顾客最常犹豫的价格区间与原因。  

这些信息补齐后，才能决定哪个产品承担“引流到店”，哪个产品承担“主要利润”。

### **决策难度**

两类都是**高决策产品**，不适合把短视频当成直接下单页。

顾客看视频后的合理动作应是：  
**收藏/关注 → 私信问能不能看 → 带尺寸到店 → 看料或试坐 → 回家商量 → 成交。**

所以账号不能只追求播放，也不能急着每条都报价格。价格可以在私信和到店沟通中解决；视频更该先解决“我为什么要去老周这里看”的问题。

---

## 主推产品

**起号前30天，建议主推“实木餐桌椅的到店看料与选款”，同时保持布艺沙发稳定露出。**

这不是把布艺沙发降成配角，而是按当前资源排序：实木餐桌椅更容易用“自家木工工坊、现场看木料”建立账号第一层辨识度；用户刷到木料、制作、结构与成品对应关系时，能快速理解老周和普通展厅销售的区别。

但布艺沙发必须占到变现内容的固定位置，建议在每周内容中至少有一条围绕沙发试坐和家庭使用场景。原因很直接：店里卖布艺沙发，且顾客已明确常问“怎么挑不踩坑”。如果主页长期只出现木料和餐桌，顾客会把账号认成“只卖实木桌椅”，后续再补沙发会很被动。

**为什么不直接主推最贵的产品？**  
因为当前缺少具体价格、利润和成交数据。起号期先推最容易拍出信任证据、最能解释门店差异的产品，比先推最贵的产品更稳。等连续出现“问餐桌的人多，但到店后连带看沙发”的真实情况，再考虑把“新房整套置家”做成更高客单的承接方向。

## 成交路径

### 1. 第一次接触：刷到“顾客看不懂的家具问题”

顾客第一次刷到的，不应该是促销海报，而应该是一个和自己有关的场景：

- “买实木餐桌，别只摸桌面，先看下面这处。”
- “沙发不是坐一下就能定，家里常坐的人要试这几个动作。”
- “同样是餐桌，为什么有人摆回家后才发现过道不够走？”
- “这块工坊里的木料，最后会变成展厅里的哪张桌子？”

**这一步的目标：让本地有置家需求的人停下来。**

流失的人：暂时没有家具需求、只想看低价促销的人。  
这部分人流失是正常的，因为账号不是为了吸引所有人，而是为了吸引正在结婚、交房、换房、添置家具的人。

### 2. 产生兴趣：看见“老周讲得明白，而且有现场可看”

用户不是因为听到“做家具12年”就信任，而是因为连续看到老周把话落在实物上：

- 讲餐桌时，手里有木料、桌腿、连接处；
- 讲沙发时，有人真实坐、靠、起身、按面料；
- 讲工坊时，从木料回到对应成品，而不是只拍机器；
- 讲尺寸时，用真实空间或真实摆放距离演示，而不是空讲公式。

**这一步的目标：让用户从“看个热闹”变成“这个人能帮我把家具看明白”。**

流失的人：只想马上要报价、没有意愿理解自己需求的人。  
不需要为了留住这类人，把视频改成价格轰炸；高决策家具不能靠一条报价视频解决所有顾虑。

### 3. 沉淀：主页和私信把“刷视频”变成“带问题来店”

主页必须承担三个任务：

1. 让人一眼看懂：老周卖**实木家具、布艺沙发**；  
2. 让人知道区别：可以进工坊看木料；  
3. 让人知道下一步：带户型尺寸或家里需求到店看。

私信不建议一上来追问“什么时候来店”，而应先接住顾客的问题：

- 家里大概多大空间；
- 几个人常用；
- 目前是交房、装修收尾，还是准备换旧家具；
- 更想先看实木家具还是布艺沙发。

**这一步的目标：把泛浏览者筛成有明确场景的潜在到店客。**

流失的人：离本地太远、暂时不具备置家条件、只想线上比最低价的人。  
这是必要筛选。县城实体店最怕私信很多、有效到店很少，客服时间被无效咨询占满。

### 4. 临门一脚：到店看料、试坐、对尺寸

实木家具的临门一脚，不是反复强调“自家工坊”，而是让顾客亲眼看见：  
**这张成品对应什么木料、自己在意的部分该看哪里。**

布艺沙发的临门一脚，不是让顾客坐一秒钟，而是结合家庭实际使用方式试：

- 常坐的人身高和习惯；
- 是否经常久坐；
- 起身是否方便；
- 扶手、靠背和坐深是否适合；
- 沙发放进去后是否挤压动线。

**这一步的成交理由：现场看得见、坐得到、能结合需求判断。**

流失的人：尺寸不合适、家人意见尚未统一、预算与需求不匹配的人。  
这类人不应被硬推。应留下其真实顾虑，后续用对应内容和到店复看承接，而不是靠“今天不定就没了”制造压力。

---

## 信任证据清单

高决策家具的信任，不靠“质量好”“价格实在”这类形容词，要靠顾客能看见的动作和过程。

1. **一块木料到一张实木餐桌的对应过程**  
   - 证明：真实、工坊能力  
   - 画面：木料落台、加工局部、桌腿或连接处、最后切回展厅成品。  
   - 注意：只拍店里真实能拍到的环节，不补拍、不摆拍成当天制作。

2. **老周带顾客看木料时，真实讲哪一处**  
   - 证明：专业判断  
   - 画面：顾客提出问题，老周指向木料或成品对应部位。  
   - 待确认：顾客授权与真实问答素材。

3. **同一张餐桌的结构细节与日常使用关系**  
   - 证明：专业  
   - 画面：从桌面切到桌腿、连接处、底部支撑，不做无法验证的材质承诺。  
   - 价值：顾客能带走一个进店检查思路。

4. **布艺沙发完整试坐过程**  
   - 证明：产品体验、服务  
   - 画面：坐下、后靠、起身、手按面料、看扶手和靠背。  
   - 重点：拍“不同需求看不同位置”，不是宣称某种坐感适合所有人。

5. **顾客带尺寸到店后，如何对应实物看款**  
   - 证明：服务过程  
 


## 输出要求

行业建议只管「这个阶段怎么打」，不重复定位。账号是谁（账号定位）、长期拍什么（内容定位）、靠什么成交（商业定位）已经定好，这里只引用它们的原名。按下面的结构输出 Markdown，每一节都落到这个账号和这个阶段上：

1. **本阶段判断**：这个阶段和目的下，现状和目标之间差在哪里，依据是档案和作品数据。数据不够就直说不够。
2. **本阶段重心方向**：给 2–3 个建议方向，优先引用内容定位里已有的系列原名。每个写清：这一阶段它负责哪个目的（流量、人设、变现）、占本阶段的比例、为什么选它（对准哪个真实需求，依据档案的哪条事实）。这是建议，用户自己选定的方向优先。
3. **每类目的的结尾动作**：流量、人设、变现各一个结尾动作，每类只留一个。变现型的动作要对应商业定位里的哪一步，写出原步骤名。
4. **本阶段暂停什么**：2–3 条，每条写依据（禁忌、档案，或内容定位里的排除项）。
5. **30 天执行规则**：3 条，只约束选题和脚本怎么做（例如「每条都要在前 5 秒说出位置」），不重述定位。
6. **复诊条件**：出现哪些迹象就该换阶段，换的时候重心怎么变。只写可以观察的迹象（例如「连续几条都有陌生人在评论区问地址」），用这个号自己过去的数据比；**不写任何具体数字**（播放量、新客人数、连续条数都不写）。

## 硬约束

- 药方是建议，不是命令。用户选定的方向优先：用户的方向不在内容定位里，就照用户的方向给建议，并说明它和内容定位、本阶段重心的差距，不阻止、不改写。
- 不替用户新增或改写内容定位。如果本阶段反复需要内容定位里没有的方向，只写「建议把它加进内容定位」，由用户决定。
- 拍小票、结账、价格画面时，金额一律用【待确认】或「金额打码」，档案里没有的数字不写。
- 不重述账号定位（这个号是谁、说给谁、凭什么信）、内容定位（长期拍什么）、商业定位（靠什么赚钱）的内容，只引用原名。
- 内容定位还没有做。第 2 节写「【待内容定位】」，方向先按用户选定的来给建议，之后补做内容定位会更准；其余照常，但标为推断。
- 商业定位已有，第 3 节的变现动作写出原步骤名。
- 不编造任何数字、案例、客户故事、效果承诺。缺的事实用【待确认】标出
- 价格、价位、人均、营业时间、地址、作息、门店活动，只有档案或素材里写了才能用。档案里没有的，写成「价格摆在明面」这类做法即可，具体数字用【待确认】占位，不要替它定价
- 阈值类数字（完播率、播放量、咨询人数、转化率）一律不给具体合格线，例如「完播低于 X% 就换」。改成和这个号自己过去的数据比较；没有历史数据就写「待建立」
- 档案里写着「未填」「待补充」或留空的项，不当作事实使用，也不凭行业印象补成具体值；推断出来的内容要标明是推断
- 与账号档案的事实冲突时以档案为准
- 禁忌里写的不能说、不能拍，方案里一律不出现
- 不输出寒暄和过程说明，只输出方案正文
