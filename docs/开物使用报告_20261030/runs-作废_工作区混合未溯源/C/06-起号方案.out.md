# 🚀 起号方案

## 📌 先说结论

- **建议主攻：第36计 冷知识**
- **主系列：老周现场看木料**
- **主打内容：让县城里准备结婚、换房的人，看懂买实木家具时应该现场看什么**
- **选择原因：**
  1. 老周本人做家具12年，具备真实行业经验。
  2. 自家有木工工坊，木料、加工过程、家具制作都能在现场拍。
  3. 选木料、挑沙发本来就是目标用户关心的问题。
  4. 单人出镜、一部手机、门店和工坊即可完成，不依赖演员、街访和复杂设备。
  5. “反常识结论→现场证据→应用方法”的结构，能把现有的木料辨认、家具常识拍成连续栏目。

- **备选：**
  1. **第15计 正确做法VS错误做法**：当木料辨认类内容有画面，但冷知识播放不稳定时切换。
  2. **第10计 情境还原**：当店里出现真实顾客挑沙发、选餐桌的咨询场景时切换。
  3. **第22计 行业避坑**：当用户评论里频繁出现“怎么挑沙发”“怎么判断实木”这类具体问题时切换。

- **明确不做：**
  1. **第35计 街头采访**：档案没有提供拍摄人员、采访授权和稳定街访条件，容易变成一次性内容，无法连续拍20—30条。
  2. **第30计 角色扮演**：没有确认第二位出镜者，也不能让店员或他人临时扮演顾客；剧情成立依赖演员反应，不符合当前已知资源。

- **多久能看出跑没跑通：**
  - 第36计至少连续测 **5条**，不能只发一条就否定。
  - 以“零粉到一千粉、后续视频流量逐步稳定”为起号参考线。
  - 同时看目标用户质量：是否有县城本地、准备结婚、换房、买家具的人评论或进入主页。
  - 若连续5条都没有前段留存、目标用户互动和主页访问，切换到第15计；若有播放但咨询明显增加，则保留冷知识作为流量入口，另外补变现内容。

## 🧮 起号期内容配比

### 起号期：流量型70% / 人设型20% / 变现型10%

按每周发布5条计算：

- **流量型：3—4条**
- **人设型：1条**
- **变现型：每两周1条左右**

起号期先集中跑“木料与家具选择常识”这个主系列，不把实木家具、布艺沙发、老板故事、工坊展示拆成四个完全不同的账号方向。

### 1. 流量型：第36计 冷知识

- **出发点：**
  - 人：老周，做家具12年的本地老板
  - 货：实木餐桌椅、布艺沙发只作为现场物件出现
  - 场：县城门店、自家木工工坊
  - 爆款元素：**人群**
  - 目标人群：新婚家庭、准备换房的业主
  - 三有：重点做“有用”，让陌生人看完带走一个现场判断动作

- **脚本结构：**
  - 反常识结论
  - 老周拿木料或家具部件现场演示
  - 解释为什么不能只看表面
  - 给出买家具时能执行的检查动作
  - 结尾只引导关注

- **结尾行动指令：**
  - “关注老周，下一条继续现场看木料。”

### 2. 人设型：观点立场或平凡英雄

- **出发点：**
  - 只拍老周真实的职业经历、做家具12年的判断和本地经营细节。
  - 不能直接把“专业、靠谱、实在”当人设，要用真实事件证明。

- **目前缺少的事实：**
  - 老周做家具12年中，最难的一次经历是什么；
  - 有没有一次客户选择前后让他印象深刻；
  - 有没有一次他因为某个原因放弃或调整订单。

- **脚本结构：**
  - 真实事件切入
  - 老周当时怎么判断
  - 具体做了什么
  - 这件事让他形成什么职业习惯
  - 结尾引导关注或看主页，二选一

- **结尾行动指令：**
  - “关注老周，看看一个县城木工老板每天怎么做家具。”

> 人设内容正式拍摄前，先向老周确认一个具体事件。没有真实事件，不拍煽情故事。

### 3. 变现型：第10计 情境还原或晒过程·火车节

- **成交理由：自家工坊，木料可现场看**
- **出发点：**
  - 人：老周
  - 货：实木餐桌椅或布艺沙发
  - 场：门店与自家木工工坊
  - 看点：用户从“只看成品”走到“现场看木料和制作过程”
  - 这条内容明确推动到店，不再按纯流量视频处理。

- **脚本结构：**
  - 用户常见问题
  - 老周带着看实物或制作环节
  - 讲清现场能看什么
  - 展示从木料到家具的真实过程
  - 结尾只引导到店

- **结尾行动指令：**
  - “准备买实木家具的，到店里现场看木料。”

### 过线之后

达到“零粉到一千粉、流量相对稳定”后：

- 流量型调整为50%
- 人设型调整为20%
- 变现型调整为30%

补充三类内容：

1. 继续保留“老周现场看木料”作为固定流量栏目。
2. 增加老周真实职业经历，让用户记住这个人。
3. 增加“现场看木料”和“沙发挑选”的咨询型内容，突出自家工坊和现场查看条件。

### 与已有内容定位的对应关系

- **选家具的常识**：用第36计冷知识打开陌生用户。
- **木料辨认**：作为主系列核心内容。
- **工坊过程**：作为变现型和部分流量型的画面证据。
- **实木家具、布艺沙发**：分别进入木料判断、餐桌椅选择、沙发挑选三个内容分支，不另起账号方向。

## 🎯 主攻打法：第36计 冷知识

### 为什么是你能拍的

基于当前档案，已经确认的拍摄条件有：

- 出镜人是老板老周，不需要另找主持人。
- 老周做家具12年，有真实行业经验。
- 门店在县城，能拍目标用户熟悉的本地消费场景。
- 自家有木工工坊，能拍木料、加工、家具制作过程。
- 主卖实木餐桌椅和布艺沙发，内容不会脱离实际经营。
- 已有内容方向就是选家具常识、木料辨认、工坊过程。
- 团队人数和设备没有提供，因此方案按“老周单人、手机拍摄、固定机位加手持近景”执行，不安排多人剧情和复杂调度。

### 结构公式

**反常识结论 → 现场展示木料或家具部件 → 解释判断依据 → 用户买家具时的执行动作 → 关注**

套到这个账号上：

> “买实木家具，不能只听名称”  
> → 老周把相关木料、家具部件放到镜头前  
> → 现场指出用户应该看哪里、摸哪里、问什么  
> → 给出一个到店能执行的检查动作  
> → 引导关注下一条

每一条只讲一个判断点，不在一条视频里同时讲木料、沙发、价格、工艺和售后。

### 配什么脚本讲

**第36计 冷知识 + 教知识·拆解型**

- 第36计负责：让片子里出现一个反常识判断和现场演示。
- 教知识·拆解型负责：把判断依据讲清楚，避免只剩噱头。
- 补上的内容：
  - 冷知识补“陌生人为什么停下来”；
  - 拆解型补“观众看完能带走什么”。

不在流量型里讲“我们家更好”“欢迎到店”“木料可现场看”，这些属于成交理由，留给变现型内容。

### 前3条具体拍什么

#### 第1条

**标题：**  
《准备结婚买餐桌，别先看颜色，先让老板把这块木料翻过来》（人群）

**拍摄要点：**

- 开头直接拍老周把木料翻面，第一句话：
  - “准备结婚买餐桌，别先看颜色，先看木料背面。”
- 镜头切到木料近景。
- 老周只演示一个现场查看动作，并解释这个动作能看什么。
- 拍门店里的实木餐桌椅作为真实场景，不出现购买引导。
- 结尾：
  - “关注老周，下一条继续看家具现场怎么判断。”

**换掉条件：**

- 如果现场没有适合演示的木料或背面细节，不能硬拍；
- 改成“看木料横截面”或“看家具连接处”，但判断点必须先由老周确认真实成立。

#### 第2条

**标题：**  
《县城换房买沙发，别只坐十秒：老周现场看这一个位置》（人群）

**拍摄要点：**

- 开头拍老周坐下后马上起身，第一句话：
  - “换房买沙发，坐十秒就决定，时间太短。”
- 老周在同一张布艺沙发上完成一个明确的坐、起、按压动作。
- 只讲一个观察位置，例如靠背、坐垫或扶手；具体位置由老周现场确认。
- 不把一次体验写成“所有沙发都这样”，只说：
  - “看这张沙发时，我会先看这里。”
- 结尾：
  - “关注老周，下一条继续讲买沙发时怎么现场看。”

**换掉条件：**

- 如果店内只有静态展示，无法完成真实坐感演示，就不拍“坐十秒”；
- 改拍“布艺沙发现场看哪个接缝位置”，保持一个判断点。

#### 第3条

**标题：**  
《买实木餐桌，很多人先问价格，老周先带你看木料》（人群）

**拍摄要点：**

- 开头拍老周站在木料和成品餐桌之间：
  - “买实木餐桌，先问价格之前，我会先带你看木料。”
- 从木料近景切到餐桌局部。
- 老周只讲一个“木料—成品”的对应关系，不能把没有核实的材质、等级、价格说成事实。
- 画面一定要让观众看到木料和家具之间的关系。
- 不出现价格，不引导到店，因为本条是流量型。
- 结尾：
  - “关注老周，下一条把木料和成品放在一起看。”

**换掉条件：**

- 如果木料和成品无法对应展示，就不拍这个题；
- 改成工坊里一个真实加工步骤的冷知识，先由老周确认具体步骤和判断依据。

---

### 边界

第36计冷知识在这个账号上不能这样拍：

1. 不把未经确认的木材知识说成统一规律。
2. 不凭空编造木料价格、家具寿命、客户数量、销量或工坊产量。
3. 不用“所有实木都……”这类范围过大的结论。
4. 不把“现场看木料”变成流量视频里的广告口号。
5. 不把一次老周的现场判断扩大成行业普遍结论。
6. 不用没有依据的“最便宜、最耐用、绝对不会踩坑”等说法。
7. 每条只讲一个判断点，现场没有证据就不拍。

## 🔄 备选打法

### 备选一：第15计 正确做法VS错误做法

#### 什么情况下切过去

连续5条冷知识出现以下情况时切换：

- 前3秒留存明显弱；
- 用户评论说“听不懂”“看不出来”；
- 木料细节在手机画面里不够明显；
- 老周讲知识时表达不够顺，但现场演示很清楚。

#### 怎么套到这个号

把“买家具时只看表面”与“现场看具体位置”拍成同一场景下的两种做法。

- 同一张桌子
- 同一个门店位置
- 老周先演示错误查看方式
- 再演示正确查看方式
- 最后解释两者差别

#### 配哪个四大脚本结构

**第15计 正确做法VS错误做法 + 教知识·拆解型**

- 错误做法：只看颜色、只听名称、只坐一下。
- 后果：看完仍然不知道该判断什么。
- 正确做法：把木料或家具具体部位放到镜头前。
- 原理：只讲老周能够现场验证的一个点。

### 备选二：第10计 情境还原

#### 什么情况下切过去

店里出现真实顾客咨询，并且顾客同意拍摄；或者老周能提供一段真实咨询过程。

#### 怎么套到这个号

围绕“客人常问沙发怎么挑不踩坑”拍一次真实咨询：

- 顾客提出一个真实问题；
- 老周带着顾客看布艺沙发的一个部位；
- 顾客现场体验；
- 老周讲清这个判断动作适合什么情况；
- 不编顾客反应，不替顾客下购买结论。

#### 配哪个四大脚本结构

**第10计 情境还原 + 教知识·解题型**

- 场景难题：顾客不知道沙发怎么选。
- 放大问题：只看外观，现场无法判断坐感和细节。
- 解决动作：老周带着看一个具体位置。
- 结尾行动指令：到店现场看。

---

### 备选三：第22计 行业避坑

#### 什么情况下切过去

评论区持续出现以下问题：

- “怎么看实木？”
- “沙发怎么挑？”
- “只看外观行不行？”
- “买家具最容易忽略什么？”

#### 怎么套到这个号

不讲行业内幕，只讲消费者能现场识别的一个风险点：

- 点出一个常见误区；
- 展示用户容易忽略的部位；
- 说明现场应该看什么；
- 给出替代动作。

#### 配哪个四大脚本结构

**第22计 行业避坑 + 教知识·案例引入**

- 从真实用户问题开头；
- 老周拿门店实物演示；
- 讲清判断步骤；
- 最后落到用户买家具时能执行的动作。

这一计必须有真实依据。档案没有提供具体“坑”的案例，正式拍摄前先问老周：

> “客人买实木餐桌或布艺沙发时，最常忽略哪个位置？有没有一次你现场带客户看过后，客户改变了选择？”

没有真实答案，不拍具体案例。

## 🧪 怎么测

### 一次只改一个变量

前5条全部保持不变：

- 出镜人：老周
- 场景：门店或自家工坊
- 形式：第36计冷知识
- 时长：控制在同一档
- 结尾：统一引导关注
- 画面：手机固定机位加木料、家具近景

只改一个变量：

- 第1—2条改“第一句话”
- 第3—4条改“首帧画面”
- 第5条改“判断点的呈现方式”

不能同时换标题、场景、主题和结尾，否则无法判断问题来自哪里。

### 每计测几条

- 第36计：5条
- 第15计：5条
- 第10计：3条
- 第22计：3条

### 看什么指标

流量型重点看：

- 非关注用户播放占比
- 前3秒留存
- 完播率
- 分享
- 新增关注
- 本地目标用户评论和主页访问

人设型重点看：

- 主页访问
- 关注率
- 评论里是否有人提到老周本人
- 是否出现“就喜欢你这样讲”“想看看你店里怎么做”这类人物反馈

变现型重点看：

- 私信
- 到店咨询
- 用户是否主动询问实木家具、布艺沙发和工坊情况

### 什么信号算这计行

第36计跑通的信号：

- 连续至少3条出现稳定的前段留存；
- 不是只有同行或泛用户观看；
- 评论出现县城本地、结婚、换房、买家具相关问题；
- 有人因为某个判断点继续追问；
- 后续视频仍有相近表现，而不是只有单条偶然播放。

### 什么信号算换掉

- 连续5条首帧和开头都按规则执行，前段仍然持续流失；
- 木料近景在手机上看不清；
- 老周无法把判断依据讲成一个具体动作；
- 用户看完只点赞，不知道下一步看什么；
- 评论与目标人群无关。

出现以上信号，切到第15计，不继续盲目重复冷知识标题。

## 📅 30天节奏

以下按“单人拍摄、每周集中拍2次、每次完成3条素材”的执行前提安排。团队人数和设备档案未提供，不增加额外人员和设备。

### 第1周：确定拍摄标准

**任务：**

- 确认老周能现场演示的木料判断点；
- 确认布艺沙发能现场演示的选择点；
- 在门店和工坊各拍一次画面测试；
- 完成第36计前3条。

**交付物：**

- 3条发布视频；
- 10个可拍的木料、家具、沙发判断点；
- 1套固定开头和结尾话术。

### 第2周：集中跑第36计

**任务：**

- 再拍3—5条冷知识；
- 保持同一栏目名和同一出镜人；
- 每条只讲一个现场判断点；
- 记录每条视频的前3秒留存和评论问题。

**交付物：**

- 第36计累计5条以上；
- 评论问题清单；
- 判断出用户更关注木料、餐桌椅还是布艺沙发。

### 第3周：根据数据切换备选打法

**任务：**

- 第36计表现稳定：继续拍5条同系列内容。
- 第36计前段表现弱：切换第15计，拍5条正误对比。
- 出现真实顾客咨询且获得授权：补拍1条第10计情境还原。

**交付物：**

- 留下一个前段表现更稳定的形式；
- 完成一次“冷知识”和“正误对比”的单变量对照；
- 形成下周固定栏目标题。

### 第4周：保留有效模式，补人设和变现
