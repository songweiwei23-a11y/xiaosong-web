已同步腾讯云正式网站，Dify 主应用已发布版本 12。

| 免费 | 0 | 各功能原有一次性体验额度 | 10 次体验 | 3 次一次性体验 |

联网由 Tavily Search 检索，Claude Sonnet 4.6 基于结果和知识库生成回答。套餐每期一个月，联网次数独立计量，不累计。普通资料创作跳过搜索。限额用完后继续基于已有资料创作，不冒充已经查询最新资料。

## 真实服务验证

- 正式站一次联网查询成功，真实来源返回，余额从 150 减到 149。
- 正式站关闭联网，口播改写成功，余额保持 149。
- 关闭 Dify 公开网页后，正式站再次上传六种附件并提交识别，六项答案全部与测试文件相符，余额仍为 149；刷新后历史与附件保留。
- Dify 六附件同轮执行成功：图片红绿蓝、TXT 松果7319/预算24680、Word 梧桐5826、Excel 合计400、PPT CEDAR-9462、PDF MAPLE-8047。此轮 Tavily 节点执行次数为 0。
- 真实数据库并发 10 个预占请求，免费额度 3 次只允许 3 个；测试自身的预占全部释放，原余额恢复。客户端直接调用私有计量函数被拒绝。
- SQL 事务验证免费 3 次、付费 20/60/150 次、会员到期、重复提交与释放，测试后全部回滚。
- 85 个测试文件、1747 项测试通过，类型检查通过。正式构建通过，332 个部署文件逐个哈希一致，HTTP 200。

## 本轮处理的实际问题

1. Dify 文件设置中显示 6，发布接口仍返回 3。仅保存功能面板未将该数值同步到工作流草稿。设置 6 后触发工作流修改、等待自动保存，再发布版本 12，接口与六文件真实执行均通过。后续导入 DSL 后仍须以 `/parameters` 和同轮六附件执行验证，不能只看面板数字。
2. 余额查询曾因暂时连接失败显示错误，重新查询成功。页面增加“重试”，失败响应不缓存；查询失败时禁止授权付费搜索。服务端记录错误代码，避免依赖用户猜测问题。
3. Dify 的公开聊天页暴露 `web_search_enabled` 输入，可绕过网站会员额度。经用户同意已关闭 Web App；公开 URL 返回“404 应用不可用”，后端服务 API 保持开启，参数接口仍返回六附件。
4. 会员常见问题沿用“企业版”名称，已改为购买会员联系说明。

若搜索请求结果无法确认（例如上游断线），保留预占，避免再次授权导致超额；这部分会占用当期次数，必要时需核对上游记录处理。
