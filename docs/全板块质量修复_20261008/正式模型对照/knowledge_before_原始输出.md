# 📚 知识库查询结果

## 一、教知识型脚本 vs 晒过程型脚本

### 1️⃣ **教知识型脚本**

**适合内容**：
- **专业难题**（多为变现型）：帮用户解决决策困扰、操作难题
- **泛知识**（多为流量型）：让更多人长见识、打破认知

**核心结构方法**（知识库提供4种）：

**① 解题型**：场景难题 → 放大危机 → 低成本解决 → 操作步骤12345  
**② 推荐型**：美好愿景 → 圈定人群 → 引发好奇 → 推荐理由按简单→难→简单排  
**③ 拆解型**：反常识开篇 → 讲清原理 → 操作示范  
**④ 案例型**：真实案例 → 拆解方法 → 可复制步骤

---

### 2️⃣ **晒过程型脚本**

**适合内容**：
- **多为变现型**：展示服务过程、产品制作、技术细节，建立信任
- 具体包括：进货 → 成交 → 技术 → 售后等真实工作场景

**核心结构方法**（知识库提供4种）：

**① 火车节模型**：起因带钩子 → 关键步骤 → 结果  
**② 过程展示**：进货→成交→技术→售后，挑一段拍透  
**③ 测评型**：产品介绍 → 使用过程 → 真实反馈 → 推荐理由  
**④ 任务挑战型**：挑战规则 → 执行过程 → 结果揭晓

## 三、🪑 家具展厅实战举例（老板一人手机拍摄）

### 案例背景
- **老板金句**："先看家里门能不能开,再看柜子摆得好不好看。"
- **拍摄条件**：一人一机,演示柜门开合
- **避坑要求**：不编数据、不说绝对化用语、不拍顾客

---

### 📘 **教知识型示例·拆解型结构**

**【定位】流量型·泛知识**  
**【目的】让小白长见识,涨粉为主**  
**【结构】反常识开篇 → 讲清原理 → 操作示范**

---

#### 📹 脚本正文

**【开场钩子·3秒】**  
（镜头：手伸向柜门把手,停住）  
"定制柜子千万别光看好不好看——先看这扇门能不能开。"

---

**【中段·讲清原理】**  
（镜头：侧身站在柜子前,打开柜门到90度,镜头拉近特写门板与墙面距离）

"你看,这个柜子门板打开以后,离墙还有X厘米。"

（镜头：换个角度,手指指向柜体侧面）

"但如果柜子往墙那边再靠5公分,门就撞墙了——根本打不开。"

（镜头：正面对镜头）

"很多人去定制,只盯着柜子摆那儿好不好看,结果装完发现:  
卧室门一开,柜门就卡住;  
床头柜一放,抽屉拉不出来。"

---

**【操作示范】**  
（镜头：手拿手机,演示测量动作）

"其实你去定制之前,只要做一件事:  
拿手机拍张照片,把门、窗、插座、开关的位置全拍下来,  
发给设计师——他就知道柜子该怎么摆、门往哪边开。"

（镜头:手做"框"的手势）

"记住:柜子是死的,生活是活的。  
先看门能不能开,再看柜子摆得好不好看。"

---

**【结尾金句】**  
"好看不能当饭吃,能开门才是真本事。"

**【行动指令】**  
"关注我,下期教你怎么量尺寸不出错。"

---

### 📦 **晒过程型示例·火车节模型**

**【定位】变现型·展示专业**  
**【目的】让用户看到"这老板懂行",推动咨询到店**  
**【成交理由】专业强 + 实在不坑**  
**【结构】起因带钩子 → 关键步骤 → 结果**

---

#### 📹 脚本正文

**【开场钩子·起因】**  
（镜头:手推开一扇柜门,卡住了,再推,还是卡）

"今天一个客人发微信问我:  
'老板,我家柜子门怎么关不上了?'  
我一看照片——果然又是这个问题。"

---

**【关键步骤·过程展示】**  
（镜头:走到另一个柜子前,手指柜体侧面）

"你看,这个柜子我当时特意留了X厘米的距离。"

（镜头:打开柜门,流畅推拉,特写合页位置）

"因为这个门是往外开的,合页这里得有空间——  
墙面不平、地面不平,都会影响门能不能关严。"

（镜头:转身对镜头）

"很多人定柜子,设计师只管画图好看,  
结果装完发现:  
门开到一半就撞墙了;  
抽屉拉出来,人都进不去卧室。"

（镜头:蹲下,手指地面与柜体底部）

"我做了X年柜子,有个习惯:  
量完尺寸以后,我会蹲下来看地面——  
哪里高、哪里低、门往哪边开、床放哪个位置,  
我心里都有数。"

---

**【结果·兑现钩子】**  
（镜头:再次推拉柜门,顺滑无阻）

"所以我做的柜子,客人用了X年,门还是这么顺。"

（镜头:正面对镜头,语气平静但坚定）

"不是我手艺有多好,  
是我知道:柜子是给人用的,不是给人看的。"

---

**【结尾金句】**  
"先看家里门能不能开,再看柜子摆得好不好看——  
这是我X年总结出来的。"

**【行动指令】**  
"想定柜子的,主页有地址,来店里我帮你现场量。"

## 四、📋 两种脚本的核心差异对照表

| 维度 | 教知识型·拆解型 | 晒过程型·火车节模型 |
|------|----------------|---------------------|
| **主目的** | 流量型为主,让更多人看到、长见识 | 变现型为主,展示专业、推动转化 |
| **镜头重心** | 讲原理、教方法,镜头配合讲解 | 拍真实工作场景,手上动作为主 |
| **开场钩子** | 反常识结论（"千万别光看好不好看"） | 真实事件（"客人发微信问我"） |
| **中段内容** | 为什么→怎么做→可复制步骤 | 我怎么做的→为什么这样做→结果验证 |
| **结尾指令** | 关注/评论（涨粉为主） | 私信/到店（成交为主） |
| **成交理由** | 不体现成交理由（纯知识价值） | 必须落在成交理由上（专业强、实在不坑） |
| **适合阶段** | 起号初期、扩大流量池 | 有一定粉丝后、推动变现 |
