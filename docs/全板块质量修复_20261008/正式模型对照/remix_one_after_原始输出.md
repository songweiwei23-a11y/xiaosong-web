原片的**表达机制**：
1. **开头设置悬念**："别急着看招牌"制造与常规相反的动作，引发好奇
2. **用道具做演示**：餐具摆桌测试容量，把抽象的"点多了"变成可见的"摆不下"
3. **替用户做决策前置验证**：不是事后后悔，而是点菜前就能预判

可借的核心：**"买之前先试试能不能装下/合不合适"这个动作**——这正是家具行业客人最担心的问题（档案里写了"担心买回去挡门、尺寸不合适"），原片的机制天然适配。

### 方案 1：先别急着看款式，在展厅演示"家里能不能放"

**一句话**：原片"用餐具测试桌面能摆几道菜" → 你的"用展厅现有家具演示门能不能开、抽屉会不会挡"

**借了**：开头反常识指令 + 道具演示替代口头讲解 + 帮用户做决策前置验证  
**换成自己的**：场景从餐桌换到家具展厅，道具从餐具换到衣柜门/床头柜/沙发，演示对象从"摆不摆得下菜"换到"门开不开得了、过道够不够宽"

#### 迁移对照

| 层 | 原片 | 你的版本 |
|---|---|---|
| **事件/主角** | 餐厅服务员教客人点菜前先用餐具测试桌面容量 | 家具店老板在展厅现场演示：买衣柜前先量门、买床前先量过道 |
| **开篇** | "点菜前，先别急着看招牌" | "买家具前，先别急着看款式" |
| **结构** | ①反常识指令 → ②道具演示（餐具摆桌测试）→ ③结论（得吃得完） | ①反常识指令 → ②道具演示（展厅现场量门/拉抽屉）→ ③结论（得装得进） |
| **呈现形式** | 第一人称口播 + 手持道具演示 | 第一人称口播 + 手持卷尺/直接推拉展厅样柜演示 |

#### 开头（前 3 秒）

**台词**："买家具前，先别急着看款式。"（10字）

**画面**：老板站在展厅一排衣柜前，手指向身后的样柜，镜头从老板脸部快速摇到衣柜特写

#### 口播要点

**第一段（开篇 + 演示引入）**  
"买家具前，先别急着看款式。今天拿店里这个衣柜试一下：你家卧室门开多大、门把手到墙有多宽。"  
*【画面】：老板蹲下，用手比划门框宽度，再站起来推开展厅衣柜的门*

**第二段（演示动作）**  
"把柜门打开，看看会不会挡住门。再量一下床到柜子的距离，人能不能正常走过去。"  
*【画面】：老板推开衣柜门，再用手臂比划"一个人侧身通过"的宽度；切到床头柜抽屉拉开的特写*

**第三段（结论 + 行动指令）**  
"款式喜欢，也得装得进。来店里，我帮你现场比划一遍。"  
*【画面】：老板拍拍衣柜，镜头拉远露出展厅全景，左下角字幕显示"📍青禾家具·XX路XX号"*

#### 注意

**原片学不来的部分**：原片是餐厅服务员的职业身份自带可信度，这个方案绕开方式是**用展厅真实样柜做演示道具**——客人能看到的实物比口头讲解更有说服力。

**这条不是搬运**：
- **台词**：原片"两个人吃、桌上能摆多少盘"→你的"卧室门开多大、门把手到墙有多宽"
- **画面**：原片餐具摆桌→你的推拉衣柜门/比划过道宽度
- **事件**：原片是点菜场景→你的是买家具前量尺寸场景
- **主角**：原片餐厅服务员→你的家具店老板

### 执行建议

1. **开拍前准备**：挑展厅里门板最大的衣柜（推开后视觉冲击最明显），提前用手机测距功能量一下门板打开后到对面墙的距离，心里有数"正常卧室门宽80cm，柜门打开需要xx"——拍的时候不说具体数字,用手比划
2. **第一条先拍衣柜版本**：因为"门打不开"是客人最常担心的（档案里有），先解决这个痛点。拍完如果效果好,后续可以用同样结构拍床版本(量床到墙的距离)、沙发版本(量客厅进深)
3. **镜头分三段录**：
   - 第1段:老板正面口播开头那句,背景是展厅
   - 第2段:特写手部动作(推门/比划宽度),可以录2-3遍挑最顺的
   - 第3段:全景展示展厅环境+结尾口播
4. **结尾行动指令只给一个**:因为是流量型,不急着要到店,用"评论区说说你家遇到过哪些尺寸翻车"引互动即可;如果老板想引到店,就改成最后那句"来店里我帮你现场比划一遍"
