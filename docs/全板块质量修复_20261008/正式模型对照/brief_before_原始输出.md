### 1. 一句话定位

县城家具店老板，展厅实拍教你量尺寸、挑沙发床柜子，先教你量、再让你买

### 2. 人设与口吻

- **我是谁**：先教你量、再让你买的实在老板
- **说话什么调**：唠家常的口气，"你看这个""其实吧""我跟你说"开头，不说"E0级板材""静音滑轨"，说"这种板甲醛少""关柜门没声儿"
- **会说的一句话**："买家具之前，先看家里门能不能开，再看柜子摆得好不好看"
- **不会说的一句话**："全县最低价""保证X年不坏""某某家用假板材"

### 3. 说给谁听

- **画像**：第一次装修、在网上看了一堆图片还是想不出摆进自己家什么样、怕买回去尺寸不合适退货麻烦、想找个靠谱的人现场问清楚再买的25-45岁本地家庭主妇（带着老公一起来看）
- **他最怕什么**：买回去柜门打不开挡门了 / 网上看着好看实际尺寸不合适 / 老板为了卖货忽悠我交钱后就不管了
- **他最想要什么**：到店试坐看真柜子开关门 / 买之前知道该量哪几个地方 / 找个实在人现场教我别买错
- **他会搜什么词**：衣柜尺寸怎么量、沙发怎么挑、买家具注意什么、小户型家具、家具买回去不合适

### 4. 内容方向

- **三种视频的配比**：流量型50%（泛人群避坑知识30%+装修观点20%）+ 变现型40%（现场演示20%+专业判断20%）+ 人设型10%（老板经历故事）
- **各自的结尾指令**：流量型要关注 / 人设型要关注或看主页 / 变现型要到店或私信
- **两套打法各用什么**：四大脚本主打教知识·解题型、晒过程·火车节模型；起号36计主打第22计行业避坑、第15计正确VS错误做法、第10计情境还原、第24计懒人学习
- **能长期挖的选题来源**：客人常问的问题（这个柜子多大、床头柜要留多宽）/ 展厅里真实发生的场景（客人试坐、量尺寸）/ 老板原话（先看门能不能开）/ 四个品类各自的避坑点（沙发尺寸、床高度、衣柜内部格局、整体搭配）/ 装修人群的泛痛点（小户型显大、哪些钱不该省）
- **明确不做的方向**：纯产品展示配音乐（没人设等于电子画册）/ 价格战喊麦（和实在人设冲突）/ 诋毁同行内幕爆料（县城熟人社会会被反噬）

### 5. 凭什么信你

- **核心卖点**：展厅有真实样柜和沙发可以试坐开门拉抽屉 / 老板愿意现场讲解教你量尺寸 / 先教你避坑不急着推销
- **可以拍成画面的证据**：展厅实拍一排沙发床柜子 / 老板拿卷尺在展厅演示量墙到墙门到门的距离 / 老板打开柜门演示需要多少空间 / 产品细节特写（沙发缝线、床板厚度、衣柜封边）/ 客人试坐反应（待攒，需真实场景不摆拍）/ 送货安装现场（待攒，需征得客人同意）

### 6. 怎么拍

- **呈现形式**：口播+现场演示（展厅实拍），必须拍到真柜子真演示动作，光讲知识会被认为背话术
- **真实条件**：老板一个人、一部手机、在展厅拍、手机基础剪辑（剪映加字幕配音乐）、一周能出2-3条
- **视觉调性**：展厅自然光+一盏补光灯、不刻意布置、中景能看清人和家具、特写插入卷尺和细节、横移或缓推不要晃

### 7. 记忆点

- **老板拿卷尺的动作**：每条变现型内容都出现，拍特写卷尺上的数字和老板手指的位置
- **那句原话**："先看家里门能不能开，再看柜子摆得好不好看"——第一条用、后续定期重复
- **固定开篇句式**："买X之前，先量这个地方"——沙发、床、衣柜各品类都用这个句式开场

### 8. 绝对不能说

- 价格绝对化："全县最低价""全网最便宜""比某某便宜一半"
- 质量绝对化："保证X年不坏""百分百环保""永远不会坏"
- 诋毁同行："某某用假板材""某某坑人""别家都不行"
- 虚假承诺："包退包换包送货"（待确认真实服务范围后才能提）
- 夸大效果："买我家的肯定不会错""所有人都满意"
- 通用红线：摆拍顾客配合表演、编造客户案例、伪造好评截图、承诺未经核实的服务年限和经营时长
