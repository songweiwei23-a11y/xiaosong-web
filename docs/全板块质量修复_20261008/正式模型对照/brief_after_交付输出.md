# 📋 创作简报

### 1. 一句话定位

县城家具店老板，展厅现场教你量尺寸、挑沙发床柜子，先教你量、再让你买

### 2. 人设与口吻

- **我是谁**：先教你量、再让你买的实在老板
- **说话什么调**：大白话，不说"E0级板材""静音滑轨"，说"这种板甲醛少""关柜门没声儿"。每句话之间有呼吸感，像当面唠嗑，不赶不拖
- **会说的一句话**："先看家里门能不能开，再看柜子摆得好不好看"（老板原话）
- **不会说的一句话**：❌"全县最低价" ❌"某某家用假板材" ❌"保证十年不坏"

### 3. 说给谁听

- **画像**：第一次装修、网上看了一堆图片还是拿不定主意、怕买回去尺寸不合适要退货麻烦、想找个靠谱的人现场问清楚的25-45岁本地家庭（通常女主人做决策、带着老公一起来看）
- **他最怕什么**：①买回去柜门开不了、挡门 ②看图片想象不出摆进自己家什么样 ③退货拆掉重装，损失好几千
- **他最想要什么**：①到店试坐，看真柜子开门拉抽屉 ②买之前知道该量哪些地方 ③找个不忽悠、能给建议的老板
- **他会搜什么词**："衣柜尺寸怎么量""沙发怎么挑""买家具注意什么""小户型家具""家具买回去不合适"

### 4. 内容方向

- **三种视频的配比**：流量型50%（泛人群避坑知识30%+观点20%）+ 变现型40%（专业判断20%+现场演示20%）+ 人设型10%（老板经历故事）
- **各自的结尾指令**：流量型→关注（"后面还有床、沙发的，关注我别走丢"）；人设型→关注（"想找个靠谱的，就关注我"）；变现型→到店（"拿着尺寸来店里，我免费帮你量"）或私信
- **两套打法各用什么**：四大脚本主打教知识·解题型（场景难题→危机→解决→步骤12345）、晒过程·火车节/现场演示、讲故事·平凡英雄型；起号36计主打第22计行业避坑、第15计正确VS错误做法、第10计情境还原、第24计懒人学习
- **能长期挖的选题来源**：①每个品类的尺寸避坑（沙发挡门、床头柜位置、衣柜柜门开合、电视柜高度）②客人真实提问（"转角沙发能不能拆""床垫软硬怎么选"）③四季装修节点（春季刚需房、秋季改善房、孩子长大换家具）④对比演示（3000的沙发VS 8000的沙发区别在哪）
- **明确不做的方向**：①不拍纯产品展示+音乐（没人设，等于电子画册）②不打价格战内容（"全场X折""比某某便宜一半"，县城熟人社会不吃这套）③不拍欧式豪华风高大上调性（和县城25-45岁家庭真实需求距离太远）

### 5. 凭什么信你

- **核心卖点**：便利性（有真实展厅可以试坐、现场看开门拉抽屉）+ 服务好（老板愿意现场讲解、教你怎么量）+ 实在不坑（先教你避坑、不急着推销）
- **可以拍成画面的证据**：①展厅实拍：手机从门口推进去，一排沙发、床、衣柜 ②老板拿卷尺现场演示：量墙到墙、门到门、柜门打开需要多少空间 ③对比演示：用道具模拟"门在这里，柜子摆这里，门就打不开；往后挪20公分就没问题" ④产品细节特写：沙发缝线、床板厚度、衣柜封边，老板手指着说"这个地方用的是XX工艺" ⑤【待确认·需真实场景才能拍】客人试坐反应、送货安装现场、用了一段时间的客户回访

### 6. 怎么拍

- **呈现形式**：口播+现场演示（展厅实拍）——老板一个人一部手机，只能做口播；家具必须拍真实场景（展厅、真柜子、真演示动作），不能只录脸
- **真实条件**：手机、展厅、老板一个人、手机基础剪辑（剪映加字幕配音乐）、【待确认：一周能出几条】
- **视觉调性**：自然光+一盏补光灯，展厅真实状态不刻意布置，固定机位拍中景（能看清人和家具）+手持特写插入（卷尺、柜门、抽屉），缓慢推进或横移，不晃

### 7. 记忆点

- **卷尺**：每条变现型内容都出现，老板拿着量、边量边说数字——重复道具建立"这人真教你怎么量"的记忆
- **那句话**："先看家里门能不能开，再看柜子摆得好不好看"——老板原话，在多条视频开篇或结尾重复出现
- **【待确认】老板日常穿着**：衬衫/T恤+裤子（不穿西装太正式、不穿背心拖鞋太随意）——视觉统一

### 8. 绝对不能说

- ❌"全县最低价""全网最便宜""我们比XX家好"——诋毁同行、价格战，县城熟人社会会被举报或反噬
- ❌"保证X年不坏""百分百环保"——绝对化承诺，过度承诺会被打脸
- ❌"E0级板材""静音滑轨""人体工学"等专业术语——目标人群听不懂、也不会搜
- ❌"这款必须今天定""不买就没了"——制造虚假紧迫感
- ❌【待确认的价格、年限、服务承诺】不能替老板答应（比如"免费上门量尺寸""包送货安装"——档案未明确提供，不能当成已有服务写进内容）
