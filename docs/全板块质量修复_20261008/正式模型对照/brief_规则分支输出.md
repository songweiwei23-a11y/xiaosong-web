# 📘 创作简报 · 青禾家具店

### 1. 一句话定位
县城家具店老板，展厅现场教你量尺寸挑沙发床柜子，先教你别买错再说成交

### 2. 人设与口吻

- **我是谁**：先教你量、再让你买的实在老板
- **说话什么调**：大白话，不说"E0级板材""静音滑轨"，说"这种板甲醛少""关柜门没声儿"。句子短，像当面唠嗑，每句话之间有停顿
- **会说的一句话**："先看家里门能不能开，再看柜子摆得好不好看"（老板原话）
- **不会说的一句话**：❌"全县最低价" ❌"我们比XX家质量好" ❌"保证十年不坏"

### 3. 说给谁听

- **画像**：第一次装修、网上看了一堆图片还是拿不定主意、怕买回去尺寸不对退货麻烦的25-45岁本地家庭（女主人做决策）
- **他最怕什么**：①买回去柜门打不开、挡门；②网上图片好看但不知道摆进自己家什么样；③退货要拆掉重装，损失好几千
- **他最想要什么**：①到店试坐、看真柜子开门拉抽屉；②买之前知道该量哪些地方；③找个靠谱的人、别被忽悠
- **他会搜什么词**："衣柜尺寸怎么量""沙发怎么挑""买家具注意什么""小户型家具""家具买回去不合适"

### 4. 内容方向

- **三种视频的配比**：流量型50%（泛人群避坑知识30%+观点20%）+ 变现型40%（现场演示20%+专业判断20%）+ 人设型10%（老板经历故事）
- **各自的结尾指令**：流量型要关注（"后面还有床沙发的，关注别走丢"）；人设型要关注（"想找个靠谱的就关注"）；变现型要到店（"拿着尺寸来店里，我免费帮你量"）
- **两套打法各用什么**：四大脚本主打教知识·避坑型、教知识·解题型、晒过程·现场演示型；起号36计主打第22计行业避坑、第29计吐槽奇葩现象、第15计正确VS错误做法
- **能长期挖的选题来源**：①每个品类的尺寸测量（沙发量客厅宽度、床量床头柜位置、衣柜量门的距离）；②客人真实踩过的坑（展厅里遇到的案例）；③展厅里能演示的细节（开柜门、拉抽屉、按海绵）；④目标人群关心的装修话题（小户型怎么显大、哪些钱不该省）
- **明确不做的方向**：①只拍产品展示配音乐，没人说话（像电子画册，建立不了人设）；②价格战（"全场X折""比某某便宜一半"，县城熟人社会不吃这套）；③只讲材质好不讲使用场景（客人听不懂也记不住）

### 5. 凭什么信你

- **核心卖点**：①展厅有真实样柜和沙发可以现场试坐、开门拉抽屉；②老板现场教你量尺寸、判断自己家适合什么；③先给避坑知识、不急着推销
- **可以拍成画面的证据**：①展厅实拍（手机从门口推进去，一排沙发床柜子）；②老板拿卷尺现场量（演示门到柜子的距离、柜门打开需要多少空间）；③打开柜门、拉抽屉、按沙发海绵的特写；④【待积累】客人试坐的反应（需等真实客人来，征得同意后拍，不摆拍）；⑤【待积累】送货安装现场（需征得客人同意，不拍正脸）；⑥【待积累】客人用了一段时间的反馈照片

### 6. 怎么拍

- **呈现形式**：口播+现场演示（展厅实拍）。理由：老板一个人只能做口播；家具必须拍真实场景证明有展厅、有真货
- **真实条件**：手机拍摄，展厅场地，老板一人，手机基础剪辑（剪映加字幕），一周能出几条【待确认】
- **视觉调性**：展厅自然光+一盏补光灯，不刻意布置，中景为主（能看清人和家具），特写插入卷尺、柜门、抽屉，运镜缓慢推进或横移不要晃

### 7. 记忆点

- **老板那句原话**："先看家里门能不能开，再看柜子摆得好不好看"——每条涉及尺寸的视频都用这句做开篇或收尾
- **卷尺**：每次教量尺寸都拍到卷尺特写、老板手指着卷尺上的数字——重复出现建立"这人真教你量"的记忆
- **【待验证】展厅里的固定机位角度**：如果每次都在同一个柜子前、同一个角度开拍，观众会形成"又是这个熟悉的展厅"的记忆点

### 8. 绝对不能说

- ❌"全县最低价""全网最便宜""比XX家好"——价格战话术，容易被同行举报，也和"实在"人设冲突
- ❌"保证X年不坏""百分百环保""零甲醛"——绝对化承诺，平台违规且容易被打脸
- ❌诋毁同行"某某用假板材""某某坑人"——县城熟人社会，这么说会被认为没格局
- ❌【待确认】的价格、年限、服务承诺（如"免费上门量尺寸""开店X年"）——档案未提供的经营事实不能替老板答应
- ❌编造客户案例、摆拍客人反应——档案明确"不安排顾客配合表演"，只能拍真实发生的场景
- ❌编造尺寸标准、质量诊断——没有专业依据的数据（如"柜门必须留60公分""海绵密度低于X就是劣质"）不能为举例而造
