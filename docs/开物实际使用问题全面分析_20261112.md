#### 🟡 P1-UX-01: 大量页面缺少加载状态提示

**严重程度**: 中等  
**影响范围**: ~20 个页面  
**用户影响**: 用户不知道是在加载还是卡住了

**问题描述**：
- 32 个 dashboard 页面中，只有 5 个使用了明确的 `loading` 状态
- 很多页面只是 `if (loading) return null`，用户看到空白

**问题页面**：
```typescript
// app/dashboard/topic/page.tsx
// app/dashboard/script/page.tsx
// app/dashboard/creative-brief/page.tsx
// app/dashboard/positioning/page.tsx
// ... 约 15 个页面
```

**改进方案**：
```typescript
if (loading) {
  return (
    <div className="flex items-center justify-center min-h-[400px]">
      <LoadingRings size={48} />
      <p className="mt-3 text-sm text-muted-foreground">正在加载数据...</p>
    </div>
  );
}
```

**工作量**: 2-3 天

## 3. 内容质量问题

### 3.1 整体评分：75/100 ⚠️ 需改进

这是**最需要关注的领域**。根据 2026-10-30 的使用报告，发现了 6 个内容质量问题。

**问题清单**：

#### 🔴 P0-CONT-01: 配比数字编造

**严重程度**: 高（事实错误）  
**影响范围**: 账号定位、内容定位、起号方案、行业建议  
**用户影响**: AI 自己编造百分比数字

**问题示例**：
```
A 行业账号定位输出：「主赛道 75%、人群兴趣 25%」
但提示词中没有给出这些数字
```

**根本原因**：
- 配比块只在部分节点传入
- 定位类提示词没有明确禁止「自拟配比」

**整改状态**: ✅ **已完成**（见 `docs/开物使用报告_20261030/03-整改记录.md`）

**整改内容**：
```typescript
// lib/content-mix.ts - 加硬规则
"这里只给了作用配比的数；形式占比、题材占比、「什么数据出现时怎么调」不写百分数"
```

**验证结果**: 重跑后 0 处无出处的百分比

**严重程度**: 高（事实错误）

```sql
CREATE OR REPLACE FUNCTION cleanup_expired_reservations()
RETURNS void AS $$
BEGIN
  UPDATE creation_requests 
  SET status = 'released' 
  WHERE status = 'pending' AND expires_at <= now();
  
  UPDATE web_search_requests 
  SET status = 'released'
  WHERE status = 'reserved' AND created_at < now() - interval '2 hours';
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;
```
