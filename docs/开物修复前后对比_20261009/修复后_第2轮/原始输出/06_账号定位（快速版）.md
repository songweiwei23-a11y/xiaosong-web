# 🎯 账号定位方案

## 📌 核心结论（先看这 8 条）

1. **这是什么号**：A 类本地实体店（餐饮食品），南乐本地川味三大品类门店（川味串串火锅、川味烧烤、川菜），地摊烟火气 + 9年成都川菜厨师坐镇
2. **给谁看**：18-40岁本地年轻人和蓝领，下班想撸串、周末朋友聚会、想吃正宗川味又怕踩坑的那批人
3. **人设标签**：成都来的川菜师傅，在南乐摆地摊做正宗川味的外乡人
4. **主打内容**：流量型45% / 人设型25% / 变现型30%；主力形式是晒过程（起号快、适合餐饮），配观点引流量、故事立人设、知识建信任
5. **怎么赚钱**：看视频 → 刷到地摊烟火气/一元火锅/正宗川味 → 团购下单/评论区问地址 → 到店核销
6. **第一条拍什么**：晒过程·火车节（变现型），拍傍晚开摊准备食材的完整链路，落在"实在不坑"成交理由上，结尾给团购入口
7. **最该避开的坑**：别把三个品类合并成"川味馆"；别只拍成品不拍过程；别学同行硬凹"老板出镜讲故事"（你的优势是厨师的手艺和地摊的真实感）
8. **多久能看出跑没跑通**：连续发20-30条晒过程类内容，如果同城流量稳定、评论区持续有人问地址和价格，就算跑通；跑不通再补观点和故事做流量

下面是展开论证，想细看再往下翻。

## 一句话定位

**南乐地摊上的成都川菜师傅，一元火锅 + 川味烧烤 + 正宗川菜，摆摊给你吃真材实料。**

拆解：
- 身份：成都川菜师傅（外地人 + 手艺背书）
- 特点：地摊（烟火气、接地气、价格透明）+ 三大品类并列（川味串串火锅、川味烧烤、川菜）
- 价值：一元火锅低门槛 + 真材实料（对应客人怕被坑、要实在的痛点）

为什么不写"老板"：档案里出镜人是厨师不是老板，老板是本地人在幕后；厨师的手艺和外乡人身份才是差异化人设的核心。

### 1. 人设定位

#### 原料在哪

档案里的真材料：
- **「出镜人是成都来的川菜厨师,做川菜9年,来南乐发展才半年」** ← 这是最硬的人设原料：外乡人 + 手艺年限 + 刚来不久
- **「老板是南乐本地人,门店在片区内已具备相当知名度,『这条街我们自带流量』」** ← 本地口碑背书，但老板不出镜，这条是幕后支撑
- **「地摊式露天经营,冬季有帐篷覆盖全年可营业」** ← 场景标签，烟火气、真实感、价格透明的视觉证明
- **「一元火锅是门店名称核心卖点,低门槛引流概念,性价比极高」** ← 记忆点 + 成交理由

形容词部分（"真实、接地气、情感、亲切"）是风格描述，不是人设；要翻译成具体行为：
- "真实、接地气" → 地摊现场备菜、手上有油、围裙上有汤汁、食客坐塑料凳
- "情感、亲切" → 厨师和老顾客打招呼、记得谁爱吃辣、谁带孩子来

#### 人设标签句

**成都来的川菜师傅，在南乐摆地摊做正宗川味的外乡人。**

（17字，可复述；"外乡人"三个字自带故事感和信任门槛——他要在陌生城市靠手艺站稳，比本地人更要拿出真本事）

#### 用了哪个入口

**特殊经历 + 反差**：
- 特殊经历：9年成都川菜厨师，离开熟悉的地方来县城发展（可持续讲细节：为什么来、怎么适应、本地人怎么看他）
- 反差：川菜师傅（预期是饭店后厨）× 地摊（实际场景），手艺和环境的反差制造记忆点

#### 验证

- **能否持续讲细节？** 能。9年从业经历可以拆成：学徒时期、在成都哪家店干过、拿手菜、为什么离开、来南乐半年遇到的文化差异（口味、经营习惯）、本地老顾客的故事
- **线下是否也能保持？** 能。这不是人设包装，就是他本人的真实身份；地摊现场观众随时能来验证
- **反差是否逻辑自洽？** 自洽。地摊不是降低身份，而是"手艺好的人不需要包装"——用环境的朴素反衬手艺的硬核，符合"实在不坑"的成交理由

#### 在同类账号里的位置

同城餐饮账号常见人设：
- **老板出镜型**：讲创业故事、晒营业额、喊"欢迎来我店" → 问题：广告感重、同质化严重
- **美食博主型**：精修画面、摆盘、配乐 → 问题：和地摊气质不符，观众会觉得"拍得这么好肯定贵"
- **素人晒单型**：只拍成品、没人设 → 问题：记不住是谁家

**你的差异化**：
- **身份独特**：本地餐饮号大多是本地老板，你是外地手艺人（自带"为什么一个成都人跑来南乐摆摊"的故事钩子)
- **场景真实**：不回避地摊环境，反而把它当标签（塑料凳、大排档、烟火气 = 价格实在、不宰客）
- **手艺可验证**：9年川菜经验不是自吹，后续内容持续展示刀工、火候、配方细节

#### 证据链（接下来靠这 4 类内容持续证明人设）

1. **晒过程·备菜与操作**（变现型，每周2-3条）：早市选菜、手工串串、调料配比、炒料过程 → 证明"手艺真"和"用料实在"
2. **讲故事·外乡人经历**（人设型，每周1条）：为什么来南乐、刚来时不适应什么、第一个本地老顾客怎么认识的、本地人和成都人吃辣的差别 → 证明"这个人有故事、不是随便开个店"
3. **教知识·川味冷知识**（流量型兼变现型，每周1条）：正宗麻辣烫和串串火锅的区别、成都人怎么吃串串、一元火锅为什么能做到一元 → 证明"专业"和"正宗"
4. **聊观点·地摊 vs 饭店**（流量型，隔周1条）：为什么手艺好的师傅也摆地摊、地摊不等于不卫生、成都的地摊文化 → 破除偏见，强化"地摊 = 实在"的标签

#### 边界（什么话一说人设就崩）

结合档案禁忌和人设逻辑：
- **不说"揭秘同行"**：你是外地人,在本地立足靠的是手艺不是撕同行,说同行坏话会被本地餐饮圈孤立
- **不承诺"最正宗""成都第一"**：你是来谋生的手艺人不是来砸场子的,说"和成都一模一样"反而假；改说"我们成都那边是这么做的"
- **不喊"欢迎来我店"**：地摊的气质是"你爱来不来,东西在这儿摆着"；硬拉客反而掉价
- **不拍后厨乱象**（平台红线）：就算地摊也要拍干净操作台、戴手套串串、生熟分开

### 2. 用户定位

#### 一句话画像

**18-40岁本地年轻人和蓝领：下班路过想撸串、周末呼朋唤友、想吃正宗川味又怕网红店踩坑、看到"一元火锅"会好奇但担心"一元能有什么好东西"的那批人。**

为什么是他们：
- **年龄段对应消费场景**：学生党聚会、年轻白领下班解压、蓝领工人发工资犒劳自己 → 地摊的价格和氛围都契合
- **地域**：本地同城，地摊不做外卖配送,必须到店
- **口味偏好**：档案写了"川味烧烤、串串火锅"，这是年轻人和下沉市场最爱的品类；中老年更偏清淡不是主力
- **消费心理**：要有面子（朋友聚会不能太寒碜）、要实在（怕被宰）、要特色体验（地摊烟火气、一元火锅的新奇感）

#### 为什么是他们、不是另一批

**明确不服务的人群**：
- **追求环境和服务的精致中产**：地摊塑料凳、露天帐篷，他们不会来；强行迎合他们会丢掉真正爱地摊文化的客人
- **纯外地游客**：南乐是县城不是旅游城市，抖音同城流量95%是本地人；做外地流量是资源错配
- **只看价格、不在乎口味的极端低价人群**：一元火锅已经是低门槛，再往下卷就没利润；这批人也不是你手艺的目标受众

#### 他们心里真正在想什么

嘴上不会说、但决定他们来不来的那几句话：
- **"一元火锅是不是噱头,会不会到店各种加钱?"** ← 对低价的怀疑（被套路过）
- **"地摊干不干净,会不会拉肚子?"** ← 对环境的顾虑（虽然爱吃但怕出事）
- **"成都师傅是真的假的,还是随便挂个名头?"** ← 对正宗的怀疑（网红店翻车太多）
- **"这么便宜能好吃吗?是不是用料很差?"** ← 性价比焦虑（便宜 = 不好？）

#### 决策链路

**看到视频 → 停留（被烟火气/手艺细节吸引）→ 翻主页（看是不是天天发、是不是真店）→ 评论区观望（看别人怎么说）→ 收藏（"找时间去"）→ 下次路过/周末约朋友 → 到店/团购下单。**

关键特征：
- **决策周期短**：烧烤串串不是大决策，当天或一周内就会到店；不像装修、医美要观察几个月
- **依赖主页和评论区**：会翻主页看"是不是只发了两条就不更新了"（那种是假店或倒闭了）；评论区有本地人问地址、晒到店照片 = 信任证明
- **到店前不会私信**：这个价位和品类,观众不会提前问"有没有包间""能不能定制",直接来
- **团购是主要入口**：抖音本地餐饮70%靠团购核销,不是到店现付

**这决定内容要铺多长的信任**：
- 前20条重点铺"这是真店、天天营业、真材实料"的基础信任（晒过程为主）
- 不需要长篇大论讲情怀和理念（那是高客单产品的打法）；烧烤串串靠的是"看着就想吃"

#### 什么时刻会想起你

- **下班路上刷手机**：傍晚6-8点，抖音本地美食黄金推流时段,你的营业时间正好吻合 → 刷到视频 → "下班就去"
- **周五发工资/周末约局**："这周末去哪吃" → 想起收藏过的那条视频
- **天冷想吃火锅、天热想撸串**：季节性需求 → 搜"南乐火锅""南乐烧烤" → 你的视频出现
- **朋友推荐**："最近我吃了一家地摊,成都师傅开的" → 口碑传播

#### 他在平台上搜什么

真会打出来的词（按抖音搜索习惯）：
- 南乐 + 烧烤/串串/火锅/川菜
- 南乐 + 好吃的/必吃/地摊
- 一元火锅（如果这个概念打出去了）
- 成都 + 南乐（如果"成都师傅"标签立住了）

**所以标题、话题标签、简介里这些词要反复出现**：南乐、地摊、川味、烧烤、串串火锅、一元火锅、成都师傅。

### 3. 内容定位

#### 长期提供什么价值

**让本地年轻人找到一个价格实在、手艺正宗、有烟火气的撸串火锅去处。**

拆解：
- 认知价值：知道南乐有个成都师傅摆地摊、一元火锅不是噱头
- 情绪价值：地摊烟火气、朋友聚会的松弛感、"这才是生活"的共鸣
- 行动价值：具体地址、团购入口、什么时段人少

#### 内容方向

**多元四类（知识/故事/晒过程/观点都发）。**

理由：
- **你不具备单一主题的素材条件**：单一主题（如"探访30年老店""接受粉丝挑战探店"）需要源源不断的外部素材或高强度策划执行；你是固定门店,每天做的事重复,硬凹一个任务型主题会很快枯竭
- **多元四类更适合餐饮实体店起号**：前期用晒过程快速拿到同城流量（餐饮最吃这一套），再用故事和观点丰富人设、扩大覆盖面
- **但要有一个王牌栏目**：在多元四类的底子上,做一个固定系列当记忆点 → 建议是 **"成都师傅教你吃川味"系列**（每周1条,教知识型,落在"怎么吃最值、怎么点、成都人怎么吃"，既是流量入口也强化"正宗"标签）

#### 当前阶段配比

**作用配比：流量型 45% / 人设型 25% / 变现型 30%**

依据：
- **账号阶段**：0-1万粉、还没发过内容 = 新号起号期；这一阶段首要任务是拿到稳定的同城流量和正反馈 → 流量型必须是最大的一块
- **用户的目标**：档案里写了"让人长见识、让人有情绪、让人产生信任"三种变化都要 → 流量、人设、变现三条线都得有；同时勾了"到店消费、私域引流、直播打赏、线下服务"多种变现 → 不能只做纯流量,变现型从第一周就要铺
- **为什么是 45/25/30 而不是其他比例**：
  - 流量型占 45%：新号起步必须先让更多本地人刷到,同城曝光不够后面都白搭；但也不能占到 70-80%（那样涨的是泛粉,不精准）
  - 变现型占 30%：餐饮行业决策链路短,不需要像高客单服务那样铺 50% 的信任内容；但也不能低于 20%（太少了观众记不住你卖什么）
  - 人设型占 25%：外地手艺人的身份是核心差异化,必须持续讲故事强化这个标签；但故事类内容产出慢,占比不能太高

**形式配比（每种作用用什么形式做）**：

| 作用 | 占比 | 主力形式 | 辅助形式 | 为什么 |
|---|---|---|---|
| **流量型** | 45% | 观点型（20%）<br>泛知识型（15%）<br>晒过程·地摊日常（10%） | 起号36计打法 | 观点（地摊文化、川味 vs 本地口味）覆盖人群广；泛知识（"成都人怎么吃串串""一元火锅为什么能做到一元"）能传播；晒过程里挑有烟火气、有冲突的片段（如大雨天撑伞摆摊、顾客排队）也能拿流量 |
| **人设型** | 25% | 讲故事（20%）<br>晒过程·关系细节（5%） | | 讲外乡人经历（为什么来、怎么适应、老顾客故事）；晒和顾客、合伙人、同行的关系细节（记得谁爱吃辣、本地同行怎么看你） |
| **变现型** | 30% | 晒过程·火车节（20%）<br>教知识·推荐型（10%） | | 晒备菜、串串、炒料、出餐完整链路,落在成交理由上；教"怎么点最值""这几样必点""一元火锅怎么吃回本" |

**题材配比（主赛道 vs 目标人群兴趣）**：
- **主赛道 65%**：川味串串火锅、川味烧烤、川菜的制作、吃法、选材、手艺展示
- **目标人群兴趣 35%**：地摊文化、年轻人聚会、下班解压、性价比、本地生活、南乐 vs 成都的差异

为什么是 65/35：
- 餐饮账号必须让观众持续看到"吃的"，主赛道不能低于 60%（太少了观众不知道你是干嘛的）
- 但也不能 100% 只拍菜（那是菜谱号，不是实体店号）；35% 的人群兴趣内容用来扩大覆盖面、做流量入口

#### 主力形式

**晒过程（档案里"数据最好的内容类型"一栏写了"还没发过"，所以主力形式按行业规律和这个号的资源来定）。**

为什么是晒过程：
1. **餐饮行业验证过的最快起号方式**：美食赛道里,晒备菜、炒料、出餐过程的视频,完播率和互动率普遍高于成品展示和老板讲述
2. **你有真实的过程可拍**：地摊现场、手工串串、大锅炒料、烟火气十足的操作环境 → 这些画面自带吸引力,不需要高超的口播能力
3. **匹配你的资源**：2-3人小团队、手机拍摄、店铺场地 → 晒过程只需要一部手机固定机位或手持跟拍,不需要剪辑特效、不需要出镜人口才
4. **对应核心成交理由**：档案里"实在不坑、质量好、专业强"三个卖点,都要靠过程来证明（只拍成品观众看不出用料和手艺）

**不换的理由**：虽然档案里还没发过、没有数据验证,但这是餐饮赛道的铁律 —— 同城餐饮号不晒过程,等于自废武功。

#### 每类内容管哪一段路

把用户从「不认识你」到「找你」拆成四步：

| 阶段 | 用户状态 | 负责的内容类型 | 怎么做 |
|---|---|---|---|
| **刷到** | 在同城推荐流里第一次看到 | **流量型（观点、泛知识）** | 大众入口选题：地摊文化、川味冷知识、年轻人聚会、性价比 → 覆盖人群广,让更多本地人刷到 |
| **记住** | 看过几条,能复述出"那个XX" | **人设型（故事）+ 记忆点** | 讲外乡人故事、强化"成都师傅"标签；视觉上强化地摊场景（塑料凳、大排档、烟火气） |
| **信** | 相信是真店、手艺真、价格实在 | **变现型（晒过程、教知识）** | 持续晒备菜、炒料、串串过程 → 证明真材实料；教"怎么吃最值" → 证明不宰客 |
| **到店** | 决定这周末去、或路过进去 | **变现型结尾行动指令** | 团购链接、地址、营业时间；评论区有人晒到店照片 = 社交证明 |

#### 三种视频各怎么拍

**流量型视频（每周 3-4 条，占 45%）**

**四大脚本打法**：
- **方向**：地摊文化观点、川味泛知识、年轻人聚会共鸣
- **脚本结构**：
  - 聊观点·争议开篇：如"我不认为地摊就是low"（否定句开场）→ 三个论据（地摊价格透明、老板跑不了、烟火气是生活本身）→ 总结归纳（"真正low的是那些环境好、宰你没商量的店"）
  - 教知识·冷知识：如"成都人吃串串的三个规矩"（反常识结论）→ 证据/例子（必蘸干碟、论把不论根、火锅串串分得清）→ 原理（为什么这么吃）→ 应用（"下次来我摊上试试"）
- **结尾行动指令**：关注 或 评论("你们那边地摊都吃啥?评论区说说")

**起号36计打法**（从适合流量型的计里挑）：
- **第31计·南北/地域差异**：同一道菜成都做法 vs 南乐做法 → 差异反应（"南乐人觉得不够麻,成都人觉得南乐的太咸"）→ 原因/文化 → 交流("所以我现在炒料都备两个版本")
- **第36计·冷知识**：如"一元火锅为什么能做到一元"（反常识结论）→ 成本拆解、薄利多销的逻辑 → 应用("所以我们靠走量,不靠宰客")
- **第29计·吐槽奇葩现象**：如"为什么有些店把串串称完还要抹零"（具体现象）→ 顾客被坑场景 → 为什么荒谬（"几毛钱的事,丢的是回头客"）→ 建议("我们摊上从来抹零,你自己看着给")

**人设型视频（每周 2 条,占 25%）**

**四大脚本打法**：
- **方向**：成都师傅来南乐的经历、和本地老顾客的关系、手艺传承
- **脚本结构**：
  - 讲故事·苦难经历：如"来南乐第一个月,一天只卖了三串"（低谷）→ 挣扎(不知道是口味不对还是位置不对)→ 顿悟(一个老哥跟我说"你这个味儿正,就是南乐人还没吃惯")→ 逆袭(三个月后那个老哥带了一桌朋友来)
  - 讲故事·平凡英雄：如"有个小伙每周五必来,风雨无阻"（普通人）→ 一件不普通的小事(有次下大雨我都没摆摊,他专门打电话问我在不在)→ 细节验证(后来才知道他在外地打工,每周五回南乐第一件事就是来吃我这口)→ 感悟("所以我再累也得摆,因为有人在等")
- **结尾行动指令**：关注("想听更多故事,关注我")

**起号36计打法**：
- **第3计·以物换物**：如"今天有个大哥拿一瓶酒来换串"（提出交换）→ 协商(酒不值几个钱,但是他自己酿的)→ 体验(尝了一口,是苞谷酒)→ 挖掘人物(聊起来才知道他家三代都酿酒)→ 情感结果(最后串没收钱,酒也没要,交了个朋友)
- **第7计·一句话设定故事感**：如普通动作(炒料)+ 设定("这锅料是我师傅在成都教我的,来南乐半年了,每次炒都想起他老人家")→ 故事期待(观众会想知道你和师傅的故事)

**变现型视频（每周 2-3 条,占 30%）**

**四大脚本打法**：
- **方向**：备菜过程、手工串串、炒料、出餐；怎么点最值、一元火锅怎么吃
- **脚本结构**：
  - 晒过程·火车节：如"今天进了20斤毛肚"(起因,带钩子"20斤能卖完吗")→ 关键步骤(清洗、切片、摆盘,镜头特写刀工和厚度)→ 结果(晚上8点就卖完了,还有人没吃上) → 落在成交理由"质量好、实在不坑"
  - 教知识·推荐型：如"第一次来我摊,这三样必点"(美好愿景:吃回本)→ 圈定人群(第一次来的、想尝正宗川味的)→ 引发好奇(为什么是这三样)→ 推荐理由123(毛肚是每天现切、牛油是成都空运、蘸料是我自己炒的) → 适用与不适用(不吃辣的可以要微辣版)
- **结尾行动指令**：团购链接("点左下角团购,到店核销") 或 评论区问地址("评论区扣1发地址")

**起号36计打法**：
- **第10计·情境还原**：如拍接待一桌客人的完整过程(真实任务)→ 对话("第一次来吧?我教你怎么点")→ 纠错(客人想点某个搭配,师傅说"那个不划算,我建议你这么点")→ 旁观学习(观众看完知道怎么点了)→ 结果(客人最后吃撑了,说"下次还来")
- **第19计·对比改造**：如"把隔壁摊5块钱的调料升级成我们的版本"(改造前)→ 目标(更香更正宗)→ 关键步骤(加什么料、怎么炒)→ 改造后(对比试吃)→ 复盘("多花3块钱成本,但客人吃完会记住你")

#### 第一条该发什么

**晒过程·火车节（变现型），拍傍晚开摊准备食材的完整链路，落在"实在不坑"成交理由上。**

**为什么是它开场**：
1. **新号第一条必须快速建立"这是真店"的信任**：晒过程比讲故事、讲观点更能证明"我真的在这里、真的在营业"
2. **餐饮账号起号最快的方式**：同城推荐流里,晒备菜、炒料的视频完播率和互动率最高（观众爱看"幕后"）
3. **匹配你的核心优势**：地摊现场、手工操作、烟火气 → 第一条就把这些视觉标签打出去
4. **对应客人的核心顾虑**："价格这么便宜会不会偷工减料" → 第一条就拍清洗毛肚、手工串肉、大锅炒料,用过程打消顾虑

**具体怎么拍**（火车节结构）：
- **起因（带钩子,0-3秒）**："今天进了20斤牛肉,你们猜能串多少串？"（盲盒型钩子,制造期待）
- **关键步骤（3-40秒）**：
  - 镜头1：早市选牛肉,手机跟拍,老板和摊主对话("要新鲜的,今天现杀的")
  - 镜头2：店里清洗、切块,特写刀工
  - 镜头3：手工串肉,一串一串穿,不用旁白,环境音(串肉的声音、和搭档的对话)
  - 镜头4：摆好的串串,一排排码在盘子里
- **结果（40-50秒）**："一共串了X串(到时候数一下真实数量),今晚8点开摊,先到先得" → 落在"实在不坑"（让观众看到真材实料、手工现做）
- **结尾行动指令**："团购链接在左下角,到店核销"（只要一个指令）

**用的打法**：
- 四大脚本：晒过程·火车节
- 成交理由：实在不坑、质量好
- 目的：变现型
- 结尾指令：团购链接

## 🎯 方案核心逻辑总结（写给执行团队的话）

这个号的底层逻辑是：**用"成都师傅 × 地摊"的身份反差制造记忆点,用晒过程证明手艺和用料,用故事强化外乡人的信任感,用观点和泛知识扩大同城覆盖面。**

**三条主线并行**：
- **流量线（45%）**：观点和泛知识做大众入口,让更多本地年轻人刷到 → 解决"没人看"
- **人设线（25%）**：讲外乡人经历、和老顾客的关系,强化"成都师傅在南乐摆地摊"的标签 → 解决"记不住"
- **变现线（30%）**：晒备菜、炒料、串串过程,教怎么点最值,落在成交理由上 → 解决"不信、不来"

**前20-30条的核心任务**：用晒过程跑通同城流量,让本地人知道"南乐有个成都师傅摆地摊、一元火锅是真的、东西确实不错"；数据跑通的标志是：同城曝光稳定、评论区持续有人问地址和价格、团购订单开始出现。

1. 别学同行只拍成品摆盘（那是美食博主的打法,实体店要拍过程）
2. 别把三个品类（川味串串火锅、川味烧烤、川菜）合并成"川味馆"或只突出一个（档案里明确写了都在卖,定位里必须都体现）
