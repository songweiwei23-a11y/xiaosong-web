## 2. 📊 节奏自检

- **景别分布**：特写 5 个 / 近景 4 个 / 中景 8 个 / 全景 3 个 / 远景 0 个
- **特写占比**：25%（用于展示家具细节和真实质感，符合变现型需要证据的要求）
- **运动镜头占比**：30%（6个运动镜头：2个跟随、2个推镜、1个摇镜，有稳定器可实现）
- **最长镜头**：6s（镜号18，台词较长且需要手势配合说明剩余预算用途）
- **开场 3 秒内镜头数**：1 个（镜号1为4秒，展示评论区截图，一个镜头说清起因）
- **总时长**：72s（比目标52秒多20秒，因加入5个无台词的家具细节展示镜头，用于提供台词外的质感证据）
- **是否存在同一景别连续超过 3 个**：否（最多连续2个中景后就切换）

## 5. ⚠️ 这条片子最容易翻车的 3 个地方

### 【风险1】评论区截图拍不清楚，观众看不到评论内容
**→ 怎么避**：用另一部手机横屏拍当前手机屏幕，距离20-30厘米，确保评论文字占满画面至少1/2，拍完回放检查字体是否清晰。如果手机屏幕反光，关掉头顶灯或侧身避开光源

### 【风险2】家具细节镜头（拉抽屉、按床垫、开衣柜）拍糊了或没拍到重点
**→ 怎么避**：特写和推镜时手机离家具30-50厘米，对焦点手动点一下家具表面，等对焦框变绿再开始拍。动作要慢（拉抽屉、开柜门速度放慢一倍），给手机对焦时间。拍完立刻回放检查是否清晰

### 【风险3】总价算错或台词里的【待确认】项没填，拍完才发现
**→ 怎么避**：拍摄前一天列清单：6件家具每件真实价格、客厅总价、卧室总价、全部总价、剩余预算、剩余预算建议配什么。写在纸上或手机备忘录，拍口播镜头（批次5）时拿着这张纸，念台词前看一眼，确保数字准确。如果总价加起来不是整5万（比如4.8万或5.2万），就如实说"配下来4万8"或"配下来5万2"，不要硬凑整数
