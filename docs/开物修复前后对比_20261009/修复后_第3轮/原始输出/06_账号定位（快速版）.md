# 🎯 账号定位方案

## 📌 核心结论（先看这 8 条）

1. **这是什么号**：A类本地实体店（餐饮复合品类）｜南乐本地川味串串火锅+川味烧烤+川菜，地摊烟火气+9年成都川菜师傅正宗手艺
2. **给谁看**：18-35岁本地年轻人、白领、学生，晚上下班下课想吃夜宵、周末朋友聚餐、想发圈打卡的那批人
3. **人设标签**：成都来的川菜师傅，在南乐地摊上做正宗川味的外乡人
4. **主打内容**：流量45% / 人设25% / 变现30%，主力形式是晒过程（档案未发过视频，按餐饮起号通用打法）+ 观点聊地摊烟火气和川味文化
5. **怎么赚钱**：看视频 → 团购下单（一元火锅已上线）/评论区问 → 到店，烧烤待流量稳定后上线团购
6. **第一条拍什么**：晒过程·火车节——拍师傅现场穿串+调料手法特写+一桌客人的反应，落在"正宗川味配方"这个成交理由上
7. **最该避开的坑**：不要把3个品类合并成"川味馆"——每个都要单独露出；不要只拍火锅冷落烧烤和川菜；不要为了"专业感"穿厨师服端着讲，地摊号最怕的就是端着
8. **多久能看出跑没跑通**：连续发20-30条晒过程类内容，看本地推流是否稳定、评论区有没有人问地址和价格，有就是跑通了

## 一句话定位

**南乐本地川味串串火锅+川味烧烤+川菜，9年成都川菜师傅在地摊上做正宗川味。**

（30字以内，把3个品类、地域、核心人设、核心场景都说清楚了）

---

## 1. 人设定位

### 原料在哪

档案里真正的人设材料有这几句：
- 「成都来的川菜厨师，做川菜9年，来南乐发展才半年」——这是最硬的身份和时间锚点
- 「门店在片区内已具备相当知名度」「老板是南乐本地人」——本地资源+外来手艺的组合
- 「地摊式露天经营，冬季有帐篷覆盖」——场景是烟火气而非精致餐厅

那些"真实、接地气、情感、亲切朋友式"是形容词，不是人设——翻译成行为可能是：师傅会蹲在摊位前和客人边穿串边聊天，会记得老顾客爱吃辣还是微辣，会把调料配比当场展示而不是藏着掖着。

### 人设标签句

**成都来的川菜师傅，在南乐地摊上做正宗川味的外乡人。**

（19字，能被复述，既有手艺背书又有地域反差）

### 用了哪个入口

**身份反差 + 特殊经历**：
- 身份反差：9年成都川菜师傅（大众预期是高档餐厅或连锁品牌）× 南乐地摊（实际场景是露天、烟火气、接地气）
- 特殊经历：外地师傅来县城创业才半年，片区内已有知名度——这个"半年做出名"本身就是故事

### 验证

- **场景是否逻辑自洽？** 是。川菜师傅在地摊不是硬凹——档案明确写了「地摊式露天经营」，这是真实场景；"一元火锅"的低门槛定价也和地摊消费水平匹配
- **能否持续讲细节？** 能。9年川菜经验可以持续拆解：怎么调红油、怎么选辣椒、怎么炒料、成都和南乐客人口味差异、川菜里的冷门知识……素材源源不断
- **线下是否也能保持？** 能。这不是演出来的人设，就是他本人——客人到店看到的就是这个师傅在地摊上穿串、炒料、和客人聊天

### 在同类账号里的位置

同城餐饮号通常三种人设：
- **老板型**："我家开了X年""我家用料多实在"——人设是本地商家，卖信任和实在
- **探店型**：第三方视角"我今天去吃了××"——人设是替观众试吃的人
- **大厨型**：厨师服、不锈钢厨房、专业术语——人设是技术权威

你这个号的差异：**外来手艺人在本地地摊创业**——既有手艺（成都川菜9年），又有烟火气（地摊而非餐厅），还有时间锚点（来南乐才半年，正在被本地接纳的过程本身就是内容）。这个组合在本地餐饮号里是空位。

### 证据链

接下来靠这4类内容持续证明人设：

1. **晒过程（变现型）**：现场穿串、调料、炒菜的手法特写——证明"9年川菜师傅"不是说说，手上有活
2. **讲故事（人设型）**：从成都来南乐的决定、半年里怎么被本地客人接纳、第一次有客人说"你这个味儿正宗"的那一刻——证明外来手艺人的身份和这半年的真实经历
3. **教知识（变现型）**：川菜冷知识、怎么判断红油好不好、串串和火锅的区别、成都人怎么吃串串——证明专业和文化底蕴
4. **观点（流量型）**：地摊为什么是烟火气、为什么南乐需要正宗川味、"我不认为地摊就低端"——证明价值观和对这个行业的理解

### 边界

什么话一说人设就崩（结合档案禁忌）：
- ❌ 不能说"我在成都开过多少家店""我是XX酒店主厨出来的"（档案没写过的经历不能编）
- ❌ 不能说"欢迎大家来我店""我们是全南乐最好的"（档案明确禁止广告腔和绝对化用语）
- ❌ 不能诋毁同行："隔壁那家用的是勾兑料""南乐其他川菜馆都不正宗"（档案明确不能诋毁同行）
- ❌ 不能端着讲："我们秉承匠心""我们致力于打造"（地摊号最怕的就是端着，和场景不自洽）

## 2. 用户定位

### 一句话画像

**18-35岁南乐本地年轻人、白领、学生，晚上七八点下班下课肚子饿、周末想和朋友聚餐撸串、想找个有氛围能发圈的地方、预算不高但要吃得爽的那批人。**

（不是"25-40岁喜欢美食的人"——那是人口统计；这是具体场景里的具体人）

### 为什么是他们、不是另一批

**为什么是他们**：
- 地摊消费场景天然匹配年轻人：晚上出摊时段（下午到深夜）正好是这批人的活动时间
- 一元火锅+烧烤的价格带（人均50-200）正好是学生、白领、蓝领的日常聚餐预算
- 地摊烟火气+川味特色+能发圈打卡——满足小镇青年、Z世代的社交需求

**明确不服务谁**（你要排除的人群）：
- ❌ 家庭聚餐、接待长辈的资深中产——他们要的是包间、安静、体面，地摊场景不匹配
- ❌ 只认连锁品牌、怕不卫生的精致妈妈——地摊的"原生感"对她们是减分项
- ❌ 纯粹想省钱、对口味没要求的银发族——他们更认熟人口碑和年头久，外来师傅"才半年"在他们眼里是风险

### 他们心里真正在想什么

嘴上不会说、但决策时真正在想的那句话：

**"这个地方看着挺热闹，但我不知道好不好吃、会不会踩雷、值不值得专门跑一趟。"**

拆解一下：
- "看着挺热闹"——说明他们已经被地摊烟火气吸引了，但还在观望
- "不知道好不好吃"——需要口味证明：客人的反应、师傅的手法、调料的特写
- "会不会踩雷"——需要信任证明：老客出镜、师傅真实操作过程、"片区内已有知名度"这个事实
- "值不值得专门跑一趟"——需要给一个明确理由：正宗川味配方、一元火锅、地摊独特体验

档案里"客人最担心：怕质量有问题、分辨不出好坏、选择太多挑花眼"——翻译成人话就是上面那句。

### 决策链路

从刷到你到到店，中间会做什么：

1. **刷到第一条**：看场景（地摊）+ 听到"成都师傅""正宗川味"，停留3秒
2. **被钩子拉住**：看到穿串手法 / 客人表情 / 一桌子红油的视觉冲击，看完这一条
3. **点进主页**：翻前几条，确认不是一次性的、是真的在做
4. **关注 / 收藏**：心里种草了，但还没到"现在就去"
5. **再刷到2-3条**：每次都强化"这家正宗""氛围好""性价比高"
6. **评论区问 / 私信**：问地址、问团购、问"现在去有位吗"
7. **到店**：带朋友一起来，拍照发圈

**这决定了什么**：
- 内容要铺得够密：一周至少4条，让他在一周内能刷到2-3次
- 前5条要把"正宗川味配方""地摊烟火气""片区内已有知名度"这三个信任锚点全立住
- 每条结尾都要有明确指令：前3条只要关注和评论（积累信任），第4条开始引导团购和到店

### 什么时刻会想起你

**具体时刻**（不是"有需求的时候"）：
- 晚上七八点下班 / 下课，肚子饿了，不想回家做饭，想吃点热闹的
- 周五周六晚上，约了朋友聚餐，在选"去哪吃"
- 刷到一条地摊烟火气的视频，突然想吃烧烤 / 串串
- 工资刚发 / 心情好 / 想犒劳自己的时候
- 外地朋友来南乐，想带他们吃点本地有特色的

### 他在平台上搜什么

他真会打出来的那几个词：
- 南乐美食 / 南乐夜宵 / 南乐烧烤 / 南乐串串
- 南乐地摊 / 南乐哪里好吃 / 南乐聚餐
- 一元火锅（如果这个概念在本地传开了）
- 成都川菜 / 正宗川味（小概率，但高意向）

**这决定了什么**：每条视频的话题标签要覆盖「#南乐美食 #南乐夜宵 #地摊烧烤 #川味串串」，主页简介里要写清"南乐××路地摊"而不是只写店名。

## 3. 内容定位

### 长期提供什么价值

**让南乐年轻人知道哪里能吃到正宗川味+地摊烟火气体验。**

（25字以内，既有实际价值——"哪里能吃到"，又有情绪价值——"地摊烟火气体验"）

### 内容方向

**多元四类**（不选单一主题）。

**理由**：
- 档案显示"还没发过"——新号阶段，策划能力和素材积累都还在摸索期,先用多元四类快速试出哪种数据好，再集中火力
- 单一主题（如"接受粉丝挑战探店""以物换物"）需要持续的外部素材源和较强的策划执行能力,档案里团队是2-3人小团队、老板对短视频还有疑虑——现阶段跑不动
- 餐饮号的素材源是稳定的（每天都在穿串、炒菜、接待客人），但不是围绕一个任务反复发生——更适合从多个角度立住"成都师傅+地摊川味"这个人设

**阶段策略**：A打底（多元四类快速起号）+ 观察数据后补一个B当王牌栏目（如"每周教一个川菜冷知识"或"老客带新客挑战吃辣"系列），但要等前20-30条数据稳定后再定。

### 当前阶段配比

#### 作用配比：流量型 45% / 人设型 25% / 变现型 30%

**依据**：
1. **账号阶段**：0-1万粉、还没发过——属于起号期到过渡期之间。起号期只有一个任务：拿到稳定流量和正反馈,所以**流量型必须是最大的一块**（45%）
2. **用户目标**：档案里"想让观众发生的变化"勾了认知、情绪、信任三项——说明既要流量（认知+情绪）又要转化（信任）,不是纯流量号也不是纯广告号,所以变现型从第一周就要有（30%），但不能超过流量型
3. **变现方式**：到店消费+团购+私域——这些都需要本地精准流量，而不是全国泛粉,所以人设型（让人记住你、信你这个人）要占一定比例（25%），不能只追播放量

**为什么这个比例适合这个号**：
- 流量型45%——保证每周有2条能覆盖更广人群的内容（观点聊地摊文化 / 川味文化 / 南乐夜宵场景,或者起号36计里的流量打法），把本地年轻人尽可能多地吸引进来
- 人设型25%——每周1条讲师傅的故事（从成都来南乐、半年里的真实经历、和客人的关系），让看过的人记住"成都师傅在地摊做正宗川味"这个标签
- 变现型30%——每周1-2条晒过程 / 教知识,落在3个品类和成交理由上（正宗川味配方、性价比、地摊独特体验），直接推动团购和到店

#### 每一块用什么形式做

| 作用 | 占比 | 主力形式 | 为什么 |
|---|---|---|---|
| 流量型 | 45% | **观点型**（地摊文化、川味文化、南乐夜宵场景）+ 起号36计里的流量打法 | 餐饮号的行业干货（怎么挑辣椒、怎么调料）受众窄、流量上限低；观点聊"地摊为什么是烟火气""南乐夜宵该有什么样子"覆盖人群更广。起号36计（如「反向操作」「南北差异」「街头采访」）能快速拿流量且不依赖口才 |
| 人设型 | 25% | **讲故事型**（成都师傅来南乐的经历、和客人的关系、半年里的真实事件） | 故事最能让人记住一个人。"9年川菜师傅"是标签,"他为什么来南乐、第一次被客人认可是什么时刻"是故事——后者才能让人信你这个人 |
| 变现型 | 30% | **晒过程型**（穿串、调料、炒菜手法）+ 教知识型（川菜冷知识、怎么吃最值） | 餐饮变现靠两个：一是手艺（晒过程证明）,二是专业判断（教知识证明）。晒过程离变现最近——评论区直接问"在哪""怎么去" |

#### 题材：主赛道 60% / 目标人群兴趣 40%

- **主赛道60%**：川味串串火锅、川味烧烤、川菜——3个品类轮着拍,每周2-3条（穿串、烧烤现场、炒川菜的过程）
- **目标人群兴趣40%**：这批年轻人关心的"南乐夜宵场景""地摊文化""朋友聚餐氛围""怎么吃最值""发圈打卡"——每周1-2条（聊观点、讲故事、教知识都能切入）

**为什么是这个配比**：
- 主赛道60%是底线——3个品类每个都要露出,不能只拍火锅冷落烧烤和川菜
- 目标人群兴趣40%是流量型内容的主要来源——只讲自己行业的号,流量天花板就是行业里那点人；聊"地摊文化""南乐夜宵"能覆盖整个本地年轻人群体
- **用户要大流量时往40%那头靠**——档案里没写要大流量,所以暂定40%;如果后续要扩影响力,可以调到50%

### 主力形式

**晒过程型**（待验证）+ **观点型**（流量补充）。

**为什么**：
- 档案里"数据最好的内容类型"写的是"还没发过"——没有已验证的数据,只能按餐饮起号通用打法推
- **餐饮起号通用打法第一选择：晒过程**——门槛低（每天都在做的事,拿手机拍下来就行）、起号快（真实操作过程天然有吸引力）、离变现近（评论区直接问地址）
- **补充观点型**——晒过程能拿精准流量但覆盖面窄,观点型（聊地摊、聊川味、聊南乐夜宵）能扩大曝光,把更多本地年轻人拉进来

**验证路径**：
- 前20-30条以晒过程为主（每周3条晒过程 + 1条观点 + 1条故事）
- 看数据：晒过程如果完播高、评论多问地址,就继续加大比例;如果只有播放没互动,说明钩子不够强或者内容同质化,换角度（加入老客反应、加入师傅讲解、用起号36计重新设计事件）
- 观点型如果分享多、评论区有共鸣,就每周增加到2条;如果只有情绪没转化,就降到辅助位

**如果主力形式跑不通怎么办**：
- 晒过程跑不通（20条后播放稳定在500以下、评论区没人问地址）→ 换成「情境还原」（第10计:真实任务→对话/纠错→旁观学习→结果）——拍师傅和客人的真实对话、客人点单时的纠结和师傅的建议
- 观点型跑不通（播放高但关注少、评论区全是路人）→ 换成「街头采访」（第35计）——问本地年轻人"你觉得南乐夜宵缺什么""你最爱的地摊是哪家",把账号和本地场景强绑定

### 每类内容管哪一段路

把用户从「不认识你」到「找你」拆成4步：

| 阶段 | 用户状态 | 哪类内容负责 | 怎么做 |
|---|---|---|---|

### 第一条该发什么

**晒过程·火车节——拍师傅现场穿串+调料手法特写+一桌客人的反应,落在"正宗川味配方"这个成交理由上。**

**为什么是它开场**：
1. **验证主力形式**：第一条就测试晒过程能不能跑通——看完播、看评论区有没有人问地址
2. **快速建立信任锚点**：第一条就要让本地年轻人看到"这是真师傅、手上有活、味儿正宗"
3. **3个品类先露一个**：第一条拍串串(穿串过程视觉冲击强),第二条拍烧烤,第三条拍川菜——前3条把3个品类全露出
4. **门槛低、容错高**：晒过程不依赖口才和剪辑技巧,一部手机、现场拍就行;第一条做不到完美,但能快速拿到第一个反馈

**它担什么目的**：变现型——直接推动团购和到店。

**用的哪套打法**：
- **四大脚本**：晒过程·火车节
  - 起因(带钩子):"今天来了一桌客人,点了X串菜"(开篇3秒出画面:一桌空盘子 or 师傅拿起一把签子)

  - 结果:客人夹起第一串、表情变化、说"这味儿正" or 师傅旁白"这就是正宗成都味儿"
- **起号36计**：未用计(第一条先测试最基础的晒过程能不能跑通,不叠加复杂玩法)
