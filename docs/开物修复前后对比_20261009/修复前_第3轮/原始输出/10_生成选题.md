# 📊 流量型选题方案

## 选题1：国庆那几天这套新中式沙发三拨人同时在看，现在你能坐下来慢慢试软硬

**承接**：这条取自带来内容里的"国庆那几天这套沙发三拨人同时在看,现在你能坐下来慢慢试软硬"这一具体场景

**0️⃣ 视频目的**  
流量型——用国庆挤与现在空的强烈视觉反差，让装修到选家具阶段、不想被催着下单的人看到"现在来正好"这个信息

**🅰 打法**  
36计·第31计 **地域差异**（这里改为时间差异）：国庆人挤人试沙发 → 现在一个人慢慢坐 → 能掀坐垫看填充、能问清楚每个细节 → 评论区问"你们那边节后也这样吗"

**1️⃣ 爆款元素**  
- **反差**：国庆三拨人同时看 VS 现在就你一个人，视觉冲击强
- **成本**（时间成本）：强调"现在能坐下来慢慢试"= 省了被催、挤不动的时间成本

**2️⃣ 开篇钩子**  
"国庆那几天这套沙发三拨人同时在看，现在正好，你能坐下来慢慢试软硬。"

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：用一套新中式沙发做对比点，展示国庆人挤人VS现在一个人能慢慢试的真实反差
- **核心问题与观众价值**：节后冷清是不是意味着店不行？不是，现在来能坐下来试、能问清楚工艺，不用被催着下单——解决"想好好挑但怕人多被催"的顾客痛点
- **取材与内容推进**：
  1. 开场站在新中式沙发区空荡荡的走道里，镜头能拍到远处空间和这套沙发
  2. 回忆国庆场景：用口播描述"那几天三拨人同时在看，你想坐下试都得等"
  3. 现在动作：走到沙发前坐下，掀开坐垫展示填充（高密度海绵/羽绒），讲解框架（实木/松木），手摸扶手讲工艺
  4. 强调"现在就你一个人，能坐多久坐多久，每个细节我都能给你讲清楚"
- **事实边界**：国庆人多是真实场景（用口播回忆），现在空荡荡需现场拍摄；掀坐垫、讲填充是真实操作，不编造材质参数
- **关键画面（3个）**：
  1. 开场空镜：6000平店里新中式区空荡荡，远处能看到家具和走道，你站在画面里显得空间很大
  2. 坐下试沙发：你坐到沙发上，掀开坐垫露出填充层，手指按压展示回弹
  3. 近景特写：手摸扶手的榫卯结构或实木纹理，配合口播"这些细节人多的时候根本没时间看"
- **场景设置**：店内新中式沙发区，选一套卖得好、工艺能讲的款，工作日下午客流少时拍摄

**4️⃣ 脚本结构**  
按36计公式走，话术配合**晒过程·过程展示**：  
- 空间对比（国庆挤 VS 现在空）→ 现在能做的动作（坐下、掀坐垫、摸细节）→ 强调"能坐多久坐多久，每个细节都能讲清楚"→ 评论区互动

**5️⃣ 结尾行动指令**  
"你们那边节后家具城也是这样吗？评论区说说。"（要评论）

**6️⃣ 执行要点**  
- 工作日下午拍，确保画面里没有其他顾客（如有路人需打码）
- 手机横屏或竖屏拍摄，开场用广角展示空间纵深
- 掀坐垫前确认这套沙发允许展示内部结构
- 口播语速放慢，配合动作（坐下、掀开、手摸），不要只站着说

## 选题2：节后这6000平的店，你走20分钟可能只碰到两三个人

**承接**：这条取自带来内容里的"6000平大店空荡荡拍出来更有冲击力"这一核心优势

**0️⃣ 视频目的**  
流量型——用6000平空荡荡的视觉震撼+走动实拍，让想安静看家具、怕被销售跟着的人看到"现在来不用担心被打扰"

**🅰 打法**  
36计·第32计 **换个视角**：不从卖家角度说"现在人少"，而是从顾客视角拍"你在店里走一圈是什么体验"——边走边拍空荡荡的走道、偶尔路过的顾客背影、安静的家具区

**1️⃣ 爆款元素**  
- **规模大**：6000平（约10亩）本身就是记忆点，空荡荡更有冲击
- **反差**：国庆挤不动的6000平 VS 现在走20分钟只碰到两三个人

**2️⃣ 开篇钩子**  
"节后这6000平的店，你走20分钟可能只碰到两三个人。"

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：用第一人称行走视角，实拍节后店内空荡荡的真实状态，让观众直观感受"安静、不被打扰"的体验
- **核心问题与观众价值**：节后家具城冷清是不是没人去？恰恰相反，想安静挑、不想被销售跟着的人，现在来正好——解决"怕被推销、想自己慢慢看"的心理
- **取材与内容推进**：
  1. 开场站在店门口或某个能拍到纵深的位置，口播"节后这6000平的店，你走20分钟可能只碰到两三个人"
  2. 手持手机边走边拍：经过新中式区、美式区、现代简约区等，镜头捕捉空荡荡的走道、安静摆放的家具、偶尔一两个顾客背影（打码）
  3. 走到某个家具前停下，口播"你想在这待多久都行,没人催你"
  4. 结尾回到宽阔的中央走道，强调"6000平，六大品类全覆盖，现在来能好好看每一种"
- **事实边界**：6000平、六大品类是真实信息；"走20分钟碰到两三个人"是节后工作日真实场景，拍摄时如实记录，不刻意避开或安排顾客
- **关键画面（3个）**：
  1. 行走镜头：手持拍摄，画面里是空荡荡的走道、远处的家具区、偶尔路过的顾客背影
  2. 停在某套家具前：镜头从走道推进到家具特写，你站在旁边不说话，静音3秒营造"安静"氛围
  3. 最后广角空镜：站在店中央,镜头拍到四周空荡荡的空间感
- **场景设置**：店内多个区域串联，工作日下午客流最少时拍摄

**4️⃣ 脚本结构**  
按36计公式走，配合**晒过程·过程展示**：  
- 提出体验（"走20分钟只碰到两三个人"）→ 边走边拍展示真实空间 → 停在家具前强调"没人催你"→ 评论区互动"你们喜欢人多还是人少的店"

**5️⃣ 结尾行动指令**  
"你们喜欢人多热闹的店,还是像现在这样安静能慢慢看的？评论区说说。"（要评论）

**6️⃣ 执行要点**  
- 手持手机拍摄,保持画面稳定（可用稳定器或放慢走动速度）
- 路过顾客时避开正脸或后期打码
- 行走路线提前规划：门口→新中式区→美式区→某套家具前停留→中央走道收尾,总时长控制在60-90秒素材内
- 背景音可保留店内真实环境音（脚步声、远处说话声），增强"安静"氛围

## 选题3：国庆时这个新中式区五六组客人挤着看，现在能一套一套给你讲工艺

**承接**：这条取自带来内容里的"国庆时这个新中式区五六组客人挤着看,现在能一套一套给你讲工艺"这一具体场景

**0️⃣ 视频目的**  
流量型——用"人多时讲不清 VS 现在能讲透"的对比,让想了解家具工艺、怕被糊弄的人看到"现在来能问清楚每个细节"

**🅰 打法**  
四大脚本·**教知识·拆解型**：开头点出"国庆人多时讲不清工艺"这个痛点 → 现在拿新中式家具举例,现场拆解榫卯、木材、漆面三个工艺点 → 强调"现在时间够,能一套一套给你讲明白"

**1️⃣ 爆款元素**  
- **反差**：国庆五六组人挤着看 VS 现在一套一套讲
- **专业强**：展示榫卯、木材、漆面等具体工艺,体现教师背景会讲解的人设

**2️⃣ 开篇钩子**  
"国庆那几天这个新中式区五六组客人挤着看，我想讲工艺都插不上话，现在正好，能一套一套给你讲明白。"

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：用新中式家具的三个工艺点（榫卯结构、木材材质、漆面处理）做演示,展示节后有时间能讲透的优势
- **核心问题与观众价值**：买新中式家具怕被糊弄、不懂工艺好坏？现在来人少,老板有时间现场拆解给你看——解决"想了解但没人耐心讲"的需求
- **取材与内容推进**：
  1. 开场站在新中式区,口播"国庆五六组人挤着看,想讲都插不上话"
  2. 走到一套新中式家具前,依次展示三个工艺点：
     - 榫卯：掀开某个可展示的部位（抽屉、椅子连接处）,手指指出榫卯结构,"传统工艺不用一颗钉子"
     - 木材：敲击实木部分,对比贴皮家具的声音差异,"实木是闷响,贴皮是脆响"
     - 漆面：手摸表面,讲解"这是生漆/木蜡油,环保但成本高,很多商家用的是普通油漆"
  3. 收尾强调"现在时间够,每套家具的工艺我都能给你讲清楚,不用担心人多插不上话"
- **事实边界**：新中式家具的工艺点需是真实可展示的(如确实有榫卯结构、确实是实木);不编造工艺参数,不懂的不讲
- **关键画面（3个）**：
  1. 掀开展示榫卯：手掀开抽屉或椅子连接处,近景拍榫卯结合部位
  2. 敲击对比声音：手敲实木部分,配合口播"听这个闷响"
  3. 手摸漆面：手在家具表面滑过,近景拍纹理和光泽
- **场景设置**：店内新中式区,选一套工艺能讲、允许展示内部的家具,工作日下午拍摄

**4️⃣ 脚本结构**  
**教知识·拆解型**：  
- 痛点开篇（国庆人多讲不清）→ 现场拆解三个工艺点（榫卯、木材、漆面）→ 每个点用动作+口播说清楚 → 收尾强调"现在有时间能讲透"→ 评论区互动

**5️⃣ 结尾行动指令**  
"你们买新中式家具还想了解哪些工艺？评论区告诉我。"（要评论）

**6️⃣ 执行要点**  
- 提前确认这套家具允许掀开展示榫卯结构
- 敲击对比时注意收声,确保能听到"闷响"和"脆响"的差异
- 三个工艺点每个控制在15-20秒,总时长不超过90秒
- 口播用大白话："不用一颗钉子""闷响就是实木""生漆环保但贵",不说专业术语

## 选题4：之前客人说想好好挑但人太多转不开身，现在整个美式区就你一个人

**承接**：这条取自带来内容里的"之前客人说想好好挑但人太多转不开身,现在整个区域就你一个人"这一真实客户反馈

**0️⃣ 视频目的**  
流量型——用客户真实吐槽"人多转不开身"引发共鸣,再展示现在空荡荡的美式区,让想好好挑、怕被挤的人看到"现在来正好"

**🅰 打法**  
四大脚本·**聊观点·观点正反**：提出观点"节后冷清不是坏事,是挑家具的最佳时机"→ 对比常见误区"人多=生意好=质量好"VS 正确看法"人少=能好好挑=体验好"→ 强化结论"想好好挑的人,现在来正好"

**1️⃣ 爆款元素**  
- **反差**：之前转不开身 VS 现在就你一个人
- **共鸣**：很多人有"想好好挑但人太多"的体验,开篇就能抓住

**2️⃣ 开篇钩子**  
"之前有个客人跟我说,想好好挑但人太多转不开身,现在正好,整个美式区就你一个人。"

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：用"客户吐槽人多转不开身"引发共鸣,再用现在美式区空荡荡的画面做对比,输出观点"节后冷清是挑家具的最佳时机"
- **核心问题与观众价值**：很多人觉得"人多的店才靠谱",但实际体验是挤、被催、看不仔细——现在来人少,能转得开、能坐下试、能问清楚,才是真正省心的选法
- **取材与内容推进**：
  1. 开场站在美式区入口,口播"之前有个客人跟我说想好好挑但人太多转不开身"
  2. 镜头慢慢推进美式区:空荡荡的走道、安静摆放的美式家具(沙发、餐桌、床)、没有其他顾客
  3. 走到一套美式沙发前,做几个动作展示"现在能做的事":坐下试软硬、掀开坐垫看填充、蹲下看沙发腿的实木材质、站起来从不同角度看整体搭配
  4. 口播"这些动作人多的时候根本没法做,现在就你一个人,能转得开、能蹲下、能坐多久坐多久"
  5. 收尾强调"节后冷清不是坏事,想好好挑的人现在来正好"
- **事实边界**："之前有个客人说"是真实反馈(如没有就改成"很多客人跟我说");现在空荡荡是节后真实场景;动作展示需真实可做
- **关键画面（3个）**：
  1. 空镜推进:镜头从美式区入口慢慢推进,拍到空荡荡的走道和远处的家具
  2. 动作组合:坐下试沙发→掀坐垫→蹲下看沙发腿→站起来看整体,连续完成不被打断
  3. 最后站在美式区中间,镜头拉远展示整个区域的空旷感
- **场景设置**：店内美式区,工作日下午客流少时拍摄,确保画面里没有其他顾客

**4️⃣ 脚本结构**  
**聊观点·观点正反**：  
- 提出观点("节后冷清是最佳时机")→ 对比误区(人多=好)VS 真相(人少=体验好)→ 用动作展示"现在能做什么"→ 强化结论 → 评论区互动

**5️⃣ 结尾行动指令**  
"你们挑家具喜欢人多热闹还是安静慢慢看？评论区说说。"（要评论）

**6️⃣ 执行要点**  
- 开场"客户吐槽"如果是真实反馈最好,如没有就改成"很多客人跟我说",不编具体对话
- 动作展示要连贯:坐→掀→蹲→站,一镜到底最有说服力
- 拍摄时确保美式区没有其他顾客,如有需打码或换时间段
- 口播语速放慢,配合动作节奏,不要只站着说

## 选题5：国庆排队结账的队伍从收银台排到门口,现在你挑完直接就能走

**承接**：这条取自带来内容里的"国庆挤不动"这一核心对比,延伸到"结账排队"这个被忽略的体验细节

**0️⃣ 视频目的**  
流量型——用"国庆排队结账"这个很多人有共鸣的糟糕体验,对比现在"挑完直接走"的省心,让怕麻烦、重视效率的人看到"现在来省时间"

**🅰 打法**  
36计·第36计 **冷知识**：反常识结论"节后买家具比国庆省的不只是挤,还有结账排队的时间"→ 证据(国庆排队从收银台到门口 VS 现在挑完直接结)→ 原理(人少=整个流程都快)→ 应用(想省时间现在来正好)

**1️⃣ 爆款元素**  
- **反差**：国庆排队到门口 VS 现在挑完直接走
- **成本**(时间成本)：强调节省的不只是挑家具的时间,还有结账、配送沟通的时间

**2️⃣ 开篇钩子**  
"国庆那几天排队结账的队伍从收银台排到门口,现在你挑完直接就能走。"

**3️⃣ 内容方向及目的(重中之重！)**  
- **核心内容方向**:用"结账排队"这个被忽略的体验细节做切入,展示节后人少带来的全流程省时优势
- **核心问题与观众价值**:很多人只想到"人多挤",但没想到挑完还要排队结账、排队约配送时间——现在来人少,挑完直接结账、直接约时间,整个流程快一半
- **取材与内容推进**:
  1. 开场站在收银台附近,口播"国庆那几天排队结账的队伍从这里排到门口"(手指出收银台到门口的距离)
  2. 镜头跟随你走到收银台,展示现在空荡荡的收银区"现在就我一个人,挑完直接就能结"
  3. 坐在收银台前(或站着),展示结账后的流程:翻开配送记录本/打开手机日历,"现在约配送时间也不用等,你想哪天送就哪天"
