1. **这是什么号**：本地实体店（A 类餐饮），南乐本地川味多品类店——**川味串串火锅、川味烧烤、川菜**三大品类都拍，地摊烟火气 + 9 年成都厨师背书

3. **人设标签**：成都来的川菜厨师，做了 9 年，在南乐地摊上给你做正宗川味
4. **主打内容**：流量 45% / 人设 25% / 变现 30%；主力形式是晒过程（最适合地摊场景、厨师手艺和烟火气），配观点做流量
5. **怎么赚钱**：看视频 → 团购下单 → 到店核销（火锅已上线）；看视频 → 评论问 → 私信 → 到店（烧烤待上线）

7. **最该避开的坑**：把三个品类合并成"川味馆"或只突出一个——每个品类都要拍到；只拍成品不拍过程——手艺和真材实料要看得见；口播讲川菜知识——起号期泛知识流量上限低，先用地摊场景和烟火气拿流量
8. **多久能看出跑没跑通**：20-30 条看数据分层——晒过程类完播和评论明显高于其他类型 = 主力形式跑通；有人问地址、问团购 = 变现型内容开始起作用

## 一句话定位

**成都来的川菜厨师，在南乐地摊上给你做正宗川味串串火锅、川味烧烤、川菜，9 年手艺一元火锅吃得到。**

（35 字，包含身份、地域、三大品类、核心卖点）

### 1. 人设定位

#### 原料在哪

档案里的真材料：
- **「主厨是成都来的川菜厨师，做川菜 9 年」**——这是最硬的背书，专业可信
- **「来南乐发展才半年」**——外来厨师 + 本地老板组合，既有手艺又接地气
- **「地摊式露天经营」**——不是高大上餐厅，是烟火气、真实感、街头场景
- **「这条街我们自带流量」**——本地已有知名度，不是新店冷启动

形容词原料（需要翻译成行为）：
- "真实、接地气、亲切朋友式"翻译过来是：**地摊场景里的真实操作 + 和老客的熟络互动 + 不端着的说话方式**

#### 人设标签句

**成都来的川菜厨师，做了 9 年，在南乐地摊上给你做正宗川味。**

（23 字，可复述，身份 + 经历 + 场景 + 价值）

#### 用了哪个入口

**痛点 + 职业 + 反差**的组合：
- 痛点：本地人想吃正宗川味，怕做得不地道、分辨不出好坏
- 职业：9 年成都川菜厨师，专业可信
- 反差：高手艺 × 地摊场景——不是高档餐厅的距离感，是街边就能吃到的真手艺

#### 在同类账号里的位置

同行餐饮号常见人设：
- **老板娘型**：亲切、会聊天、讲故事，但专业背书弱
- **大厨型**：西装、后厨、专业范儿，但距离感强、不够烟火气
- **探店型**：第三方视角，但缺人格记忆点

你这个的差异：**专业厨师 × 地摊烟火气 × 外来手艺本地化**——既有手艺背书（9 年成都川菜），又有真实感（地摊场景、露天操作），还有本地老板做信任桥梁。同行要么有手艺但端着，要么接地气但手艺说不清，你是两头都占。

#### 边界

**什么话一说人设就崩**：
- 不能说"我们是高档餐厅""精致环境"——地摊烟火气是标签，别自己打脸
- 不能承诺疗效（养生、去火、滋补）——只讲味道、口感、分量、手艺
- 不能说"欢迎大家来我店"这种广告腔——改成"团购上了，X 元能吃这些"
- 不能用"揭秘""最好""第一"——档案明确禁止

### 2. 用户定位

#### 一句话画像

**周末想和朋友撸串喝酒、发工资想犒劳自己、带朋友要有面子又不想花太多的本地年轻人（18-30 岁）和小镇中老年（认熟人口碑、信这条街老店的那批人）。**

#### 为什么是他们、不是另一批

**是他们的理由**：
- **小镇青年**：社交活跃、发圈打卡、看重颜值和特色体验——地摊烟火气 + 一元火锅概念 + 多品类选择（串串、烧烤、川菜）正好满足聚会场景
- **都市蓝领**：发工资犒劳、下班解压、重实惠和实在——性价比高、实在不坑、分量足是他们的核心需求
- **小镇中老年**：信熟人口碑、认这条街老店、家庭消费——"这条街我们自带流量"就是他们口口相传的结果

**明确不服务谁**：
- 追求高档环境、安静私密的商务宴请人群——地摊场景不匹配
- 只想在家点外卖、不愿出门的人——变现路径是到店，不做外卖主打
- 对辣度敏感、完全不吃川味的人——品类决定了受众范围

#### 什么时刻会想起你

**具体场景 × 时间点**：
- **周五下午 5 点下班前**：小镇青年、都市蓝领刷手机找晚上聚会的地方
- **发工资当天中午**：想犒劳自己、约朋友，刷到地摊烟火气 + 一元火锅会心动
- **周末晚上 7-9 点**：刷抖音看本地美食推流，看到熟悉的街景 + 热闹场面会种草
- **朋友问"今晚吃啥"的那一刻**：想起你的串串、烧烤、火锅——多品类覆盖不同口味的朋友

### 3. 内容定位

#### 长期提供什么价值

**让本地人看到真手艺、真材实料和地摊烟火气，知道哪些值得吃、怎么吃最划算。**

#### 内容方向

**多元四类打底 + 一个王牌栏目（晒过程·火车节）。**

理由：新号起步、还没发过内容，先用多元四类摸索哪种数据最好；但手上有天然优势——地摊场景 + 厨师操作 + 多品类可拍，这些都是源源不断的真实素材，所以**晒过程（火车节）** 作为王牌栏目优先跑通 20-30 条。等晒过程稳定拿流量和咨询后，再补观点（地域美食话题）、故事（厨师经历、老客故事）、知识（川味冷知识、怎么吃最值）。

#### 当前阶段配比

**作用配比：流量型 45% / 人设型 25% / 变现型 30%**

依据：
- **账号阶段**：0 粉新号，还没发过内容，处于起号期——流量型必须是最大的一块，拿到稳定曝光和正反馈是第一任务
- **用户目标**：档案里写了"让人长见识、让人有情绪、让人产生信任"——三种都要，对应流量、人设、变现三条线；没有说"只要精准客户不在乎播放"，所以流量型不能太少
- **变现路径已明确**：团购已上线（火锅）、烧烤待上线，变现型从第一周就要有，占 30% 铺信任内容

**每一块用什么形式做**：

| 作用 | 占比 | 主力形式 | 为什么 |
|---|---|---|---|
| **流量型 45%** | 最大块 | **晒过程（地摊场景 + 操作画面）+ 观点（地域美食话题、川味 vs 本地口味）** | 地摊烟火气 + 多品类操作天然有画面感和新鲜感，覆盖"爱吃、爱看美食、爱刷探店"的泛人群；观点类用川味话题（"南方人 vs 北方人吃火锅""一元火锅到底亏不亏"）做大流量入口 |
| **人设型 25%** | 第二块 | **讲故事（厨师经历、老客故事）** | 9 年成都川菜厨师 + 来南乐发展半年 + 本地已有知名度，这些是现成的故事素材；用故事立住"手艺人 + 有温度"的人设 |
| **变现型 30%** | 第三块 | **晒过程·火车节（进货 / 穿串 / 调锅底 / 上桌）+ 教知识·推荐型（怎么吃最值、三大品类怎么点）** | 手艺和真材实料要看得见才能转化——晒过程直接证明"实在不坑、质量好、专业强"；教知识类圈精准人群（想吃但不知道怎么点的） |

**题材：主赛道 60% + 目标人群兴趣 40%**
- 主赛道 60%：川味串串火锅、川味烧烤、川菜三大品类的操作、食材、场景
- 目标人群兴趣 40%：地摊文化、朋友聚餐、夜宵烧烤、美食探店、性价比——这部分是流量型内容的主要来源

#### 主力形式

**晒过程（火车节）。**

理由：
- **档案里"数据最好的内容类型"是"还没发过"**——没有历史数据参考，所以看真实资源和场景优势
- **这个号的天然优势就是可拍的真实场景**：地摊露天操作、厨师穿串、调锅底、烤串、上桌——每个环节都有画面、都能做钩子
- **晒过程是离变现最近的内容类型**：评论多是"在哪""多少钱""怎么去"——直接推动咨询和到店
- **起号快、涨粉快**：晒过程 + 烟火气 + 真实操作，抖音本地美食赛道最吃这一套

**不换它，先集中跑通 20-30 条晒过程，再补其他类型。**

#### 配比核验

1. **流量型是不是和账号阶段匹配（新号是不是最大的一块）？** ✅ 是。45% 占比最大，符合新号起号期逻辑
2. **主力形式是不是档案里数据最好的那一类？不是的话理由够不够硬？** ✅ 档案没有历史数据，主力形式按真实资源和场景优势判断——晒过程最匹配地摊场景和厨师操作
3. **用户要大流量的话,行业干货是不是没当主力?** ✅ 是。流量型 45% 里用的是晒过程（地摊场景）+ 观点（地域美食话题），不是川菜专业干货
4. **题材有没有给目标人群兴趣留出 30-40%?** ✅ 有。40% 给了地摊文化、聚餐、夜宵、性价比这些泛话题
5. **每个数字都能说出"为什么是这个比例"吗?** ✅ 能。流量 45% 因为新号起号期；人设 25% 因为有厨师经历和老客故事做素材；变现 30% 因为团购已上线、需要铺信任内容

#### 第一条该发什么

**变现型·晒过程·火车节，拍串串火锅上桌前的关键步骤（穿串 → 调锅底 → 涮串 → 一元火锅概念露出），落在"实在不坑"这个成交理由上。**

**为什么是它开场**：
- **新号第一条要同时完成三件事**：建立账号标签（抖音算法识别你是本地美食号）、给用户明确预期（以后能看到什么）、测试变现路径是否跑通
- **晒过程 + 火车节结构最适合第一条**：画面有冲击（地摊 + 火锅 + 串串）、钩子天然（"一元火锅到底能吃到什么"）、结尾自然引导团购
- **落在"实在不坑"这个成交理由上**：档案里客人最担心"怕质量有问题、分辨不出好坏"——第一条就要用真实操作画面打消这个顾虑

**用的哪套打法**：
- **四大脚本：晒过程·火车节**
  - 起因（钩子）：开场第一句"一元火锅能吃到啥？今天带你看"
  - 关键步骤：穿串（食材特写）→ 调锅底（厨师手法）→ 涮串（沸腾画面）→ 一元火锅概念露出
  - 结果：上桌画面 + 价格透明 + "团购 X 元，地址在 XX"
- **起号 36 计：第 10 计·情境还原**
  - 真实任务：给客人准备串串火锅的完整流程
  - 旁观学习：观众看到厨师怎么穿串、怎么调锅底、一元火锅是怎么做到的
  - 结果：上桌 + 引导到店
