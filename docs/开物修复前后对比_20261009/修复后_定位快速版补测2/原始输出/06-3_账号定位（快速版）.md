# 🎯 账号定位方案

## 📌 核心结论（先看这 8 条）

1. **这是什么号**：本地实体店（A类·餐饮食品），**成都川菜厨师在三线县城开的地摊川味馆，一元火锅+烧烤+川菜三大品类**
2. **给谁看**：县城打工族、学生、年轻情侣——月薪三千、下班后想找个热闹接地气的地方吃宵夜，预算50块以内要吃饱、吃好、发朋友圈有面子的本地年轻人
3. **人设标签**：**成都来的川菜师傅，在县城地摊上做了9年的正宗川味**
4. **主打内容**：流量型45% / 变现型30% / 人设型25%；主力形式**晒过程**（地摊烟火气、现场穿串备菜、顾客真实互动最容易拍、起号快），辅助泛知识（川味冷知识做流量）和故事（厨师经历做人设）
5. **怎么赚钱**：看视频 → 团购链接下单（一元火锅已上线）→ 到店核销；烧烤待账号起来后上线团购是变现加速节点
6. **第一条拍什么**：**变现型·晒过程·火车节**，拍"下午四点开始备菜穿串到晚上客人来的全过程"，落在**成本透明+质量好**两个成交理由上，结尾行动指令：到店地址
7. **最该避开的坑**：只拍成品不拍过程（像硬广）；口播讲川菜知识但镜头在店里站着讲（人景不匹配）；三个品类只拍其中一两个（定位模糊）
8. **多久能看出跑没跑通**：连续发20条晚高峰（18:00-21:00），**单条播放稳定过500、评论区有本地人问地址 = 起号成功**；没到就换开篇钩子和拍摄时段

## 一句话定位

**成都川菜师傅在三线县城摆地摊，教你一元火锅怎么吃最值、川味烧烤怎么点、正宗川菜怎么做**

### 1. 人设定位

**原料在哪**  
档案里「成都来的川菜厨师，做川菜9年，来南乐发展才半年」「门店在片区内已具备相当知名度」「地摊式露天经营，冬季有帐篷覆盖全年可营业」——这几句是真材料，能证明**手艺正宗+接地气**这两个卖点。档案里「真实、接地气、情感」是形容词，翻译过来就是**在地摊环境、用方言、和熟客聊天式的拍法**。

**人设标签句**  
**成都来的川菜师傅，在县城地摊上做了9年的正宗川味**（19字）

**用了哪个入口**  
**身份反差**：大众预期"成都厨师应该在正经川菜馆"，实际行为"在县城摆地摊、穿围裙现场穿串"。这个反差天然带记忆点，且场景自洽（地摊烟火气+手艺正宗，两个都能在画面里被验证）。

**在同类账号里的位置**  
同城餐饮号大多是**老板出镜讲优惠、或者只拍成品美食**；厨师出镜的账号通常走**专业正经路线**（后厨、白衣服、讲技法）。你这个号的位置是**手艺和烟火气同时拿到**——既能讲川菜冷知识（专业），又能拍地摊现场穿串、和熟客拉家常（接地气），两条腿都能走。

**边界**  
- 不能说"欢迎大家来我店"这类广告腔（档案禁忌）
- 不能承诺疗效（"吃了养胃""去火"）
- 不能拍后厨乱、生熟混放的画面（平台红线）
- 不能贬低同行（"隔壁那家都是冻货"）

### 2. 用户定位

**一句话画像**  
**县城打工族、学生、年轻情侣——月薪三千上下、下班后想找个热闹接地气的地方吃宵夜，预算50块以内要吃饱、吃好还能发朋友圈有面子，但怕踩坑（分辨不出质量、怕被宰），更信熟人推荐和"看得见的真材实料"**

**为什么是他们、不是另一批**  
档案里目标年龄18-40岁、职业覆盖学生/白领/蓝领/自由职业，兴趣是朋友聚餐/夜宵烧烤/地摊文化——这群人的共同点是**预算有限、社交需求强、愿意为烟火气和性价比买单**。明确不服务：追求精致环境的资深中产（你的场景是地摊，满足不了他们的面子需求）；外地游客（你是本地生意，流量型内容不追求全国曝光）。

**什么时刻会想起你**  
- 发工资那天，想犒劳自己或约朋友聚
- 下班路过你那条街，闻到烟火气、看到帐篷热闹
- 刷到你视频里"一元火锅"或者"XX串只要X块"这类性价比信息
- 朋友聚会前一天，在群里讨论去哪吃、有人转发你的视频

### 3. 内容定位

**长期提供什么价值**  
**教本地年轻人怎么用50块在地摊上吃到正宗川味、吃得值、吃得有记忆点**

**内容方向**  
**多元四类**（知识/故事/晒过程/观点都发）。理由：新号、资源有限（2-3人小团队、手机拍摄）、三个品类都要露出，单一主题（如"挑战100种川味"或"接受粉丝点菜挑战"）执行难度高且容易把某个品类漏掉。多元四类可以**灵活覆盖三个品类、快速测试哪类内容数据好、边拍边找记忆点**。

**当前阶段配比**  
**作用配比：流量型 45% / 变现型 30% / 人设型 25%**  
- 依据：新号起号期，档案里「还没发过」，首要任务是拿到稳定的本地流量和正反馈。流量型占最大头，但三类从第一周就都要有（代运营SOP）。用户目标是「让人长见识、让人有情绪、让人产生信任」，三种变化都要，对应流量/人设/变现三类内容
- **主力形式：晒过程**（占变现型30%的大部分 + 流量型里的一小部分）。理由：档案里「数据最好的内容类型：还没发过」，无历史数据参考，按**餐饮地摊号的行业规律**选——晒过程（备菜穿串、现场制作、顾客互动）**拍摄门槛低、真实感强、起号快**，且地摊烟火气本身就是视觉记忆点。辅助形式：**泛知识**（川味冷知识、怎么吃最值）做流量型，**讲故事**（厨师9年经历、为什么来县城）做人设型
- 题材配比：**主赛道（川味串串火锅+川味烧烤+川菜）60% / 目标人群兴趣（地摊文化、县城打工族共鸣、性价比生活）40%**。人群兴趣那40%主要服务流量型内容

**第一条该发什么**  
**变现型·晒过程·火车节**，拍"下午四点开始备菜穿串到晚上第一波客人来的全过程"  
- **结构**：起因（开篇钩子："一元火锅一天能卖X锅，今天带你们看我怎么准备的"）→ 关键步骤（洗菜切菜、穿串、调料、摆摊、客人来、点单、上菜）→ 结果（客人吃、老板收钱或者聊两句）
- **落在哪个成交理由上**：**成本透明+质量好**——拍洗菜、切菜、穿串的手部特写，让观众看见"食材是新鲜的、没藏东西"
- **结尾行动指令（只要一个）**：到店地址（"南乐XX街，下午五点开摊，认准这个帐篷"）
- **为什么是它开场**：变现型内容从第一条就要有（代运营SOP），**过程展示离成交最近**——评论区会直接问"在哪""多少钱"。且这一条同时验证**三个品类是否都能在一个场景里自然露出**（一元火锅、烧烤、川菜可以都摆在摊位上），拍完看数据，哪个品类评论多就知道后面重点推哪个

**配比核验**  
1. 流量型是不是和账号阶段匹配？**是**，新号、流量型45%占最大头  
2. 主力形式是不是档案里数据最好的那一类？**无历史数据，按行业规律选晒过程**，理由够硬  
3. 用户要大流量的话，行业干货是不是没当主力？**不适用**，档案未写要大流量，目标是本地精准客户  
4. 题材有没有给目标人群兴趣留出30-40%？**是**，40%给了地摊文化和县城生活共鸣  
5. 每个数字都能说出"为什么是这个比例"吗？**是**，上面每条都有依据
