## 一句话定位

**成都来的川菜师傅，在南乐地摊上做正宗川味串串火锅、烧烤、川菜，一元火锅让你吃出烟火气和面子。**

（30字内压缩版：成都川菜师傅南乐摆地摊，串串火锅烧烤川菜一元吃出面子）

### 1. 人设定位

#### 原料在哪
档案里的真材料是："主厨是成都来的川菜厨师，做川菜9年，来南乐发展才半年，是店内川味正宗的核心保障""门店在片区内已具备相当知名度"。形容词是"真实、接地气、情感、亲切朋友式"——这些需要翻译成具体行为。"接地气"翻译过来就是**地摊经营、露天帐篷、下午到深夜时段营业**；"朋友式"翻译过来是**老客户愿意出镜、能聊得起来**。

#### 人设标签句
**成都来的川菜师傅，在南乐地摊上做了9年的正宗川味。**

#### 用了哪个入口
**痛点+职业** + **地域反差**叠加。痛点是"怕质量有问题、分辨不出好坏、要真材实料、要价格透明"，职业是"9年川菜厨师"，地域反差是"成都师傅 × 南乐地摊"——这个组合天然自带信任（成都=川味正宗）和好奇（为什么跑到南乐摆地摊）。

#### 验证
**是否是高频真痛点？** 是。三四线城市吃川味串串火锅烧烤，客人最担心两件事：一是用料不正宗（油碟、底料是不是真川味），二是价格不透明（串串按签算、火锅按份算容易被坑）。9年川菜经验 + 一元火锅透明定价正好解决这两个痛点。

**能否持续讲细节？** 能。9年从业经验可以拆成:选料标准（什么肉能穿串、油碟怎么配）、川味技法（底料炒制、火候把控）、成都老店的故事、来南乐开店的决策过程。这些都是可反复证明的素材源。

#### 在同类账号里的位置
同行串串火锅烧烤账号大多是:**产品特写+音乐硬广**（只拍串、拍锅、拍吃播），或者**老板出镜喊话式**（"来我店吧便宜实惠")。这个号的差异是:**厨师人设 + 地摊场景 + 教你怎么吃**——不只是卖，而是带着成都经验教你识别好坏、教你吃法，同时地摊烟火气是天然差异化场景。

#### 证据链
- **晒过程**:备菜穿串、调油碟、炒底料、客人点单到上桌全程（证明手艺和用料）
- **教知识**:怎么挑新鲜串串、一元火锅怎么吃最值、川味油碟和普通油碟的区别、烧烤火候判断（证明专业）
- **讲故事**:为什么从成都来南乐、9年里印象最深的客人、地摊冬天帐篷里的温暖瞬间（证明人品和价值观）
- **聊观点**:地摊不丢人、一块钱也能吃出仪式感、年轻人为什么爱烟火气（证明三观一致）

#### 边界
**什么话一说人设就崩：**
- 不说"欢迎大家来我店"这类广告腔（档案明确禁止）
- 不承诺疗效（"吃了养胃""清火"之类不能说）
- 不诋毁同行（"隔壁那家用的都是冻肉"）
- 不说"揭秘""最好""第一"这类绝对化或容易被举报的词

### 2. 用户定位

#### 一句话画像
**18-40岁南乐本地年轻人和蓝领技工——下班路过想吃点热乎的、发工资那天想犒劳自己、周末约会或朋友聚餐要有面子又不想花大钱、爱拍照发圈、对"地摊"二字没有偏见反而觉得是烟火气的那批人。**

#### 为什么是他们、不是另一批
**选他们的原因：**地摊串串火锅烧烤的客单价（50元以下到50-200元）、时段（下午到深夜）、场景（露天帐篷、朋友聚餐、夜宵），天然匹配这个人群的消费能力、活动时间和社交需求。档案里"小镇青年、都市蓝领、新锐白领"的兴趣标签是"美食探店、朋友聚餐、夜宵烧烤、地摊文化"——这就是他们。

**明确不服务谁：**
- 对环境要求高、觉得地摊不体面的资深中产和银发族（他们要的是包间和安静，不是烟火气）
- 只想在家点外卖、不愿到店的宅家族
- 期待高端食材、精致摆盘的精致妈妈（一元火锅和地摊场景满足不了她们）

#### 什么时刻会想起你
- **时间节点：**发工资后的周五周六晚上、下班路上（下午5点到晚上10点是地摊黄金时段）、周末朋友约局、球赛夜（烧烤+啤酒场景）
- **情绪触发：**刷到视频看见热气腾腾的串串和地摊氛围，勾起"好久没吃烧烤了""今晚就想吃点热乎的"
- **决策场景：**不是提前几天规划，而是**当天临时决定**——刷到视频觉得馋了、看到团购划算、评论区有人说好吃，当晚就下单到店

### 3. 内容定位

#### 长期提供什么价值
**教你用一块钱的门槛，在地摊上吃到成都师傅的正宗川味，吃出烟火气和面子。**

#### 内容方向
**多元四类**（晒过程为主，搭配教知识、讲故事、聊观点）。理由:新号起步、团队2-3人、手机拍摄，不具备单一主题（如"接受100个挑战""探访30家老店"）的策划和执行成本。但地摊经营场景天然适合晒过程——备菜、穿串、客人点单、烤串翻面、调油碟，每天都在真实发生，素材源源不断。

#### 当前阶段配比

**作用配比：流量型45% / 人设型25% / 变现型30%**

依据:**账号阶段是0-1万粉、还没发过内容，处于起号期**。这个阶段核心任务是**拿到稳定流量和正反馈**，所以流量型必须是最大的一块（45%）。但实体店不能只做流量——变现型从第一周就要有（30%），让团购链接和地址尽早被看到；人设型占25%，让人记住"成都师傅在南乐摆地摊"这个标签。

档案里"想让观众发生的变化"勾了三项（认知、情绪、信任），没有明确要"大流量"或"只要精准"，所以按**过渡期账号的标准配比**（实体店默认:变现50%/人设20%/流量30%）微调:起号期流量型提高15个百分点（从30%到45%），变现型降20个百分点（从50%到30%），用流量先把账号推起来，待流量稳定后再逐步加大变现型比例。

**每一块用什么形式做：**

- **流量型45%（主力形式:聊观点 + 起号36计）**
  - 为什么:覆盖人群广、易引发评论和转发。观点方向:"地摊不丢人""一块钱也能吃出仪式感""年轻人为什么爱烟火气""南乐 vs 成都的串串差异"
  - 适合的36计:第31计·南北/地域差异（成都 vs 南乐的吃法/调料差异）、第29计·吐槽奇葩现象（吐槽假川味、吐槽串串按签坑人）、第25计·暴躁态度（"别再说地摊不干净了"）
  - 结尾行动指令:**关注或评论**（"你们那边一元火锅都吃啥？评论区说说"）

- **人设型25%（主力形式:讲故事）**
  - 为什么:建立深度信任，让人记住"成都师傅"这个标签。故事方向:为什么从成都来南乐、9年里最难的一关、地摊冬天帐篷里的温暖瞬间、第一个成为朋友的客人
  - 脚本结构:小有成就型（从成都来南乐的决定 → 水土不服/被质疑 → 第一批老客户认可 → 片区有了口碑 → 感悟）、平凡英雄型（某个下雨天/深夜客人的故事）
  - 适合的36计:第7计·一句话设定故事感（"凌晨两点,我在南乐的地摊上,给一个哭着的姑娘烤了20串"）、第8计·加入人物关系（老客户、合伙人、家人出镜）
  - 结尾行动指令:**关注**，或引导看主页

- **变现型30%（主力形式:晒过程 + 教知识）**
  - 为什么:晒过程是**离变现最近的脚本**（代运营SOP原话），地摊场景每天都在真实发生、拍摄门槛低。教知识用于解决客人的决策痛点（"怎么吃最值""怎么判断新鲜"）
  - 晒过程方向:备菜穿串全程、客人点单到上桌、一元火锅选串称重算账、烧烤师傅烤串翻面刷料、油碟调配过程
  - 教知识方向（解题型）:一元火锅怎么吃最值 → 选哪些串性价比高 → 操作步骤12345；怎么判断串串新鲜 → 看这三个地方
  - 适合的36计:第10计·情境还原（客人问"一块钱能吃饱吗" → 现场演示）、第15计·正确做法VS错误做法（错误吃法浪费钱 vs 正确吃法吃到撑）、第17计·互联网嘴替/替网友做（"有人让我试试一百块能吃多少"）
  - 成交理由:**性价比高、实在不坑、质量好、有特色**（每条变现型内容必须落在其中一个上）
  - 结尾行动指令:**到店（"导航搜锦园地摊串串"）或团购链接**，只选一个

**题材配比:主赛道（川味串串火锅、川味烧烤、川菜）60% + 目标人群兴趣（地摊文化、年轻人社交、夜宵氛围、性价比生活）40%**

为什么这样配:主赛道60%保证账号标签清晰（平台知道你是做川味餐饮的），人群兴趣40%用来拉流量——"地摊文化""一块钱的仪式感""深夜食堂"这些话题覆盖面比纯讲串串火锅烧烤广得多，能把不在南乐、但爱地摊烟火气的人也吸引进来（他们虽然不会来店里，但会点赞评论转发，帮你把视频推给本地人）。

#### 主力形式
**晒过程**（地摊经营全程、备菜穿串、客人点单到上桌）。

理由:档案里"数据最好的内容类型"是"还没发过"，所以没有历史数据支撑。但综合判断:**地摊场景天然适合晒过程**——露天经营、客人可见、操作过程透明、烟火气十足，这些都是晒过程的天然素材；团队2-3人、手机拍摄、专业后期，具备稳定生产晒过程类内容的能力；晒过程是**起号最快、离变现最近**的脚本类型（代运营SOP和知识库反复强调），适合0-1万粉阶段快速拿到正反馈。

待20-30条晒过程类内容发布后，根据数据（完播率、评论质量、团购点击）决定是否调整主力形式。

#### 每类内容管哪一段路

**从「不认识你」到「找你」的路径拆解：**

1. **刷到（曝光）** ← 流量型管这步:观点、地域差异、吐槽、冷知识，覆盖面广、易被推荐
2. **停下来看完（停留）** ← 所有类型的开篇钩子管这步:晒过程用盲盒型钩子（"今天发生了一件事"）、教知识用金钱型钩子（"一块钱能吃多少"）、观点用对抗型钩子（"我不认为地摊就low"）
3. **记住你（关注）** ← 人设型管这步:讲故事（成都师傅来南乐的经历）、固定的场景和语言风格（地摊、帐篷、"正宗川味"）
4. **信你能做成（专业信任）** ← 变现型管这步:晒过程（手法、用料、客人反馈）+ 教知识（9年经验教你识别好坏）
5. **联系你（成交）** ← 变现型的结尾行动指令管这步:每条视频只给一个指令（到店地址/团购链接/评论区回复），结合团购页和评论区引导完成转化

#### 三种视频各怎么拍

**流量型（45%）**

- **四大脚本**:聊观点·观点并列（提出观点"地摊是年轻人的深夜食堂" → 论据1:便宜 / 论据2:氛围 / 论据3:真实 → 总结强化"所以别瞧不起地摊"）。结尾行动指令:**评论**（"你们城市还有地摊吗？评论区说说"）
- **起号36计**:第31计·南北/地域差异:成都人吃串串的习惯（干碟为主、越麻越好）→ 南乐人的吃法（油碟、不太吃辣）→ 差异反应（有人不适应、有人觉得新鲜）→ 我的做法（两种碟料都备、客人自己选）。结尾行动指令:**关注或评论**

**人设型（25%）**

- **四大脚本**:讲故事·小有成就型:结果钩子（"半年时间,我在南乐这条街有了自己的江湖地位"）→ 阻碍1:刚来时水土不服、客人质疑"你一个外地人做的能正宗吗" → 转机1:第一批客人吃完说"就是这个味" → 阻碍2:冬天地摊太冷、客人少 → 转机2:搭帐篷、加暖风机、客人说"就喜欢这烟火气" → 感悟"南乐这个地方,认你这个人"。结尾行动指令:**关注**
- **起号36计**:第7计·一句话设定故事感:普通动作（我在地摊上烤串）+ 关系设定（这是我今晚接待的第120桌客人,其中有一对情侣让我印象很深）→ 故事期待。结尾行动指令:**关注**

**变现型（30%）**

- **四大脚本**:晒过程·火车节:起因带钩子（"有人问我一块钱的火锅能吃啥,今天我现场演示"）→ 关键步骤（选串:土豆片、海带、豆腐、素菜 → 称重:一块钱十几串 → 下锅煮 → 调油碟 → 开吃）→ 结果（"一块钱吃了十五串,这性价比你们那有吗"）。落在成交理由:**性价比高、实在不坑**。结尾行动指令:**团购链接**（"想吃的点下方团购"）
- **起号36计**:第10计·情境还原:客人问"一块钱真能吃饱吗" → 我说"你选串我给你煮" → 现场选串称重 → 下锅 → 客人边吃边说"没想到这么实在" → 我说"一块钱是门槛,吃好吃饱才是我的规矩"。落在成交理由:**实在不坑**。结尾行动指令:**到店**（"导航搜锦园地摊串串,南乐××路"）

#### 配比核验

1. **流量型是不是和账号阶段匹配（新号是不是最大的一块）？** 是。流量型45%,是三类中最大的,符合0-1万粉起号期的核心任务（拿稳定流量）
2. **主力形式是不是档案里数据最好的那一类？** 档案里"还没发过",无历史数据。选晒过程的理由:地摊场景天然适合、团队资源匹配、起号最快
3. **用户要大流量的话,行业干货是不是没当主力？** 档案未明确要大流量,但流量型45%里主力是观点和地域差异（覆盖面广）,教知识只在变现型那30%里用,没让行业干货当主力
4. **题材有没有给目标人群的兴趣留出30-40%？** 有。题材配比是主赛道60% + 人群兴趣40%（地摊文化、性价比生活、夜宵氛围）
5. **每个数字都能说出"为什么是这个比例"吗？** 能。流量45%因为起号期;人设25%因为需要"成都师傅"标签被记住;变现30%因为实体店从第一周就要让团购被看到;主赛道60%保证标签,人群兴趣40%拉流量

#### 第一条该发什么

**变现型·晒过程·火车节，拍一元火锅怎么吃最值。**

**具体怎么拍：**
- **开篇钩子**（金钱型,前3秒）:手机镜头对着一堆串串,字幕"一块钱能吃多少?今天我帮你试",口播"有人让我证明一下,一块钱的火锅到底能吃啥"
- **关键步骤**:
  1. 镜头切到串串墙,手拿着筐选串:土豆片、海带、豆腐、青菜、藕片(口播"素菜最划算,一块钱能选十几串")
  2. 选完称重,秤的特写,字幕显示重量和价格"1元"
  3. 下锅,热气腾腾的镜头,口播"锅底是我们成都配方,麻辣鲜香"
  4. 调油碟,手法特写:香油、蒜泥、香菜、小米椒,口播"油碟是灵魂,这是成都吃法"
  5. 煮好捞出,摆盘,数一遍"1、2、3…15串"
- **结果**:咬一口,表情满足,口播"一块钱十五串,吃到撑。你们那有这性价比吗?"字幕"👇点下方团购,到店就能吃"
- **时长**:45-60秒
- **落在成交理由**:性价比高、实在不坑
- **结尾行动指令**:团购链接（只要这一个,不同时要关注和评论）

**为什么是它开场：**
1. **新号第一条必须是变现型**:让团购链接和产品尽早被看到,测试平台会不会给本地流量
2. **一元火锅是门店核心卖点**（档案原话"一元火锅低门槛引流概念"),第一条就打这个点,直接圈本地目标人群
3. **晒过程是离变现最近的脚本**,火车节结构（起因→步骤→结果）完播率高、评论多是"我该怎么弄/在哪"
4. **金钱型钩子是最强开篇**（"一块钱能吃多少"),三四线城市用户对性价比极其敏感,这个钩子能让他停下来看完
5. **可复制**:第一条数据好,后面可以拍"五块钱能吃多少""十块钱能吃多少""一百块能吃成啥样",形成系列
