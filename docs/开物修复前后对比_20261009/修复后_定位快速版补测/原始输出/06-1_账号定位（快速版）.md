## 一句话定位

**南乐地摊上的成都川菜师傅，做正宗川味串串火锅+烧烤+川菜**

（身份：成都川菜师傅 + 特点:地摊经营、正宗川味 + 价值:三个品类都能吃到、一元火锅低门槛）

### 1. 人设定位

**原料在哪**

档案给的原料：
- "出镜人是成都来的川菜厨师,做川菜9年"——这是真材料,职业+年限可验证
- "老板是南乐本地人,门店在片区内已具备相当知名度"——这是老板的,不是出镜人的
- "地摊式露天经营"——场景真材料
- "正宗川味配方保障"——形容词,要翻译成具体行为:比如"怎么调料、成都怎么做我这就怎么做"

**人设标签句**

**成都来的川菜师傅,在南乐摆地摊做正宗川味**（18字）

**用了哪个入口**

身份反差（第37计·赠送:身份反差的逻辑）——川菜师傅（专业身份预期）× 地摊经营（接地气场景）× 南乐县城（地域下沉）→ 能力可信 + 价格不吓人

**验证**

- 环境是否逻辑自洽?是。地摊帐篷、烟火气、露天桌椅,和"师傅"身份不冲突,反而强化"手艺人不端着"
- 线下是否也能保持?是。他本来就天天在这干,不是人设包装
- 能否持续讲细节?可以。9年川菜经验可以拆成:调料配比、成都做法、食材处理、火候判断,每条都是素材

**在同类账号里的位置**

县城烧烤串串号常见人设:老板吆喝型(生意好、排队)、实惠大份型、夫妻店温情型。
这个号的差异:**专业川菜师傅身份 + 地摊场景 + 成都来的**——既有专业背书(做川菜9年),又有接地气场景(地摊),还有地域稀缺性(南乐县城的成都师傅)。同行大多只有其中一个,这个号三个都占。

**证据链**

- 变现型·晒过程:拍调料配比、穿串手法、成都做法演示(证明"师傅"是真的)
- 变现型·教知识:教怎么吃最值、怎么搭配、为什么成都人这么吃(专业判断)
- 人设型·讲故事:为什么从成都来南乐、第一次摆摊什么感受、9年里印象最深的事(立住"师傅"这个人)
- 流量型·聊观点:南北川菜差异、地摊和店面哪个更香、一元火锅为什么能赚钱(话题性)

**边界**

什么话一说人设就崩:
- 不能说同行的料不正宗、别家是假川菜(档案禁忌"不要揭秘、不要诋毁同行")
- 不能承诺"包你吃好""一定满意"(档案禁忌"不能承诺疗效或效果")
- 不能吹"全南乐最好""第一家"(绝对化用语)

### 2. 用户定位

**一句话画像**

**18-40岁南乐本地年轻人、打工蓝领、小情侣、学生党,下班或周末想撸串吃火锅、要烟火气氛围、又怕店面太贵、朋友圈发得出手的那批人**

**为什么是他们、不是另一批**

是他们:
- 小镇青年(朋友聚会、约会、发圈)——地摊烟火气 + 颜值能拍 + 价格不贵,三个都占
- 都市蓝领(发工资、下班解压)——实在接地气、性价比、一元火锅门槛低
- Z世代(探店打卡)——地摊特色 + 成都师傅噱头 + 三个品类选择多

**明确不服务谁**:
- 资深中产、银发族家庭聚会(他们要包间、要安静、要体面,地摊场景不符)
- 只吃一次就走的外地过路客(本地账号辐射半径有限,团购核销要到店)

**他们心里真正在想什么**

嘴上不会说的那句话:
- "想吃串串火锅,但店面动不动人均七八十,钱包遭不住"
- "地摊便宜是便宜,就怕料不行、吃完拉肚子"
- **你这个号要解决的就是这个矛盾**:用"成都川菜师傅9年"消除"地摊不靠谱"的疑虑,用"一元火锅"+"地摊"强化"实惠"

**决策链路**

刷到视频 → 看几条(判断是不是真师傅、环境干不干净)→ 刷到团购或问地址 → **当天或周末就去**(本地同城、低客单、朋友聚会场景决策快)
- 这决定:**前5-10条必须密集证明手艺和环境**,不能慢慢铺,因为用户不会等你发一个月再决定

**什么时刻会想起你**

- 下午5点下班路上,刷到你的视频,晚上就约人去
- 周五发工资,想犒劳自己
- 周末不知道去哪,刷到"南乐地摊"+"成都师傅"这个组合,决定试试
- 朋友问"哪有好吃不贵的串串",他转发你的视频

**他在平台上搜什么**

"南乐串串" "南乐烧烤" "南乐火锅" "南乐地摊" "南乐美食" "南乐夜市" "一元火锅"
(所以主页、合集、话题标签里这几个词要反复出现)

### 3. 内容定位

**长期提供什么价值**

**让南乐年轻人找到好吃不贵、有烟火气、手艺靠谱的地摊川味**

**内容方向**

**多元四类**(知识/故事/过程/观点都发)

理由:新号、0粉起步,策划和执行资源有限(2-3人小团队、手机拍摄),不具备单一主题IP的持续素材供给能力(比如"探访100家老店"需要大量外出拍摄)。多元四类可以在店内场景反复取材:进货是过程、教吃法是知识、师傅经历是故事、南北差异是观点。

**当前阶段配比**

**作用配比**(系统推荐,账号处于起号到过渡期):
- 流量型 45%
- 人设型 25%  
- 变现型 30%

依据:0-1万粉、还没发过、属于起号期,但档案目标明确(到店消费、团购核销),所以**流量型占最大**(拿到稳定曝光和正反馈),变现型从第一周就要有(不能等流量起来再转),人设型保底占比(让看过的人记住"成都师傅")。

**每一块用什么形式做**:

| 作用 | 形式 | 为什么 |
|---|---|---|
| **变现型30%** | **晒过程**(主力) + 教知识·解题型 | 地摊场景天然适合晒过程(穿串、调料、烤制全程可见),真实感强、离成交最近。教知识用来讲"怎么吃最值""怎么搭配",落在成交理由"性价比、实在不坑"上 |
| **人设型25%** | **讲故事**(小有成就、平凡英雄) | 讲师傅为什么从成都来南乐、9年里的手艺积累、摆地摊的真实感受,立住"成都川菜师傅"这个人 |
| **流量型45%** | **聊观点** + 晒过程(配合起号36计) | 观点:南北川菜差异、地摊vs店面、一元火锅为什么能开(话题覆盖广)。晒过程配合流量型的计(反向操作、南北差异、冷知识)拿自然流量 |

**题材**:
- 主赛道(川味串串火锅、川味烧烤、川菜)60%
- 目标人群兴趣(夜宵文化、朋友聚餐、地摊烟火气、成都vs南乐)40%

**主力形式**

**晒过程**(档案"数据最好的内容类型"是"还没发过",所以按行业规律+资源匹配来定)

为什么是它:
1. 地摊场景优势:操作全程可见(穿串、调料、明火烤制),天然适合晒过程,不需要搭景
2. 信任门槛低:用户最担心"地摊不靠谱",晒过程直接破疑虑(看得见才信)
3. 起号快:晒过程类视频完播和互动数据通常好于纯口播,适合冷启动
4. 资源匹配:2-3人团队、手机拍摄,晒过程比情景剧、多人剧情可执行性强

**每类内容管哪一段路**

用户从「不认识你」到「找你」的路径:

1. **刷到**(流量型):聊观点、冷知识、南北差异——覆盖"南乐美食""串串""地摊"等泛标签人群
2. **停下来看**(变现型·晒过程):一元火锅怎么吃、师傅穿串、调料特写——前3秒有吸引力、中段有干货
3. **记住**(人设型·讲故事):成都师傅为什么来南乐、9年手艺怎么练的——人物立住,区别于其他烧烤号
4. **信任**(变现型·教知识+晒过程):反复出现调料、手法、食材处理细节,证明"师傅"是真的、手艺靠谱
5. **联系**(变现型结尾行动指令):团购链接、评论区回复地址、引导到店

**三种视频各怎么拍**

**变现型**(30%):

**四大脚本**:
- 方向:一元火锅怎么吃最值、烧烤怎么点、川菜师傅教你搭配
- 脚本结构:**晒过程·火车节**(起因:一元火锅大家都说便宜但不知道怎么吃回本 → 关键步骤:师傅演示点菜公式、哪些菜必点、怎么搭配 → 结果:这样吃人均X元吃饱还能涮火锅)
- 结尾行动指令(只要一个):**团购链接下单,到店说抖音来的**

**起号36计**:
- 第10计·**情境还原**:真实任务(新客人第一次来不知道怎么点)→ 师傅对话("先拿这几样,火锅底料我给你调")→ 旁观学习(观众跟着学怎么点)→ 结果(客人吃完夸实惠)
- 第22计·**行业避坑**:点名坑(很多人吃串串火锅踩的坑:只点肉、不点菜,或者乱搭配)→ 后果(要么吃不饱、要么太腻)→ 识别信号(师傅教你看菜单)→ 替代方案(这样点性价比最高)

**人设型**(25%):

**四大脚本**:
- 方向:师傅为什么从成都来南乐、9年手艺怎么来的、摆地摊的真实感受
- 脚本结构:**讲故事·小有成就型**(结果钩子:在南乐摆地摊半年,现在片区都认识我 → 阻碍1:刚来时本地人不信成都师傅会摆摊 → 转机1:用手艺证明,回头客越来越多 → 阻碍2:X[待确认,比如天气、竞争] → 转机2:X[待确认] → 感悟:手艺在哪都不会亏待你)
- 结尾行动指令(只要一个):**关注我,每天分享成都师傅的地摊日常**

**起号36计**:
- 第37计·**赠送:身份反差**:身份预期A(川菜师傅应该在店里掌勺)→ 行为B(在南乐县城摆地摊、穿围裙、露天炒料)→ 环境自洽(地摊烟火气、帐篷、小板凳)→ 能力展示(调料手法、回头客认可)
- 第4计·**借物喻人**:物的事件(比如一把用了9年的炒勺、一罐成都带来的花椒)→ 双关对应(这把勺跟着我从成都到南乐)→ 情绪推进(每次用它就想起学徒时师傅教的那句话)→ 人生落点(手艺人走到哪,这些东西就跟到哪)

**流量型**(45%):

**四大脚本**:
- 方向:南北川菜差异、地摊vs店面哪个香、一元火锅为什么能开、成都人怎么吃串串

- 结尾行动指令(只要一个):**你们那边也有地摊文化吗?评论区说说**

- 第31计·**南北/地域差异**:同一任务(吃串串火锅)成都怎么吃vs南乐怎么吃 → 差异反应(成都人必蘸油碟、南乐人爱干碟)→ 原因/文化(气候、口味习惯)→ 交流(你们那边怎么吃?)

5. **每个数字都能说出"为什么是这个比例"吗**?**是**。上面已逐条说明依据

**第一条该发什么**

**变现型·晒过程·火车节:一元火锅到底怎么吃最值**

为什么是它:
- 目的:**变现型**(直接推动团购下单、到店)
- 人群:小镇青年、都市蓝领(价格敏感、要性价比)
- 钩子:一元火锅(档案强调"低门槛引流概念")+ 怎么吃最值(实用价值)
- 成交理由:性价比高、实在不坑(教你吃回本 = 站在用户这边)
- 可执行:地摊场景、手机拍、2-3人可完成(一人出镜讲、一人拍、一人配合演示菜品)
- 结尾行动指令(只要一个):团购链接在左下角,到店说抖音来的,师傅多送你一份小料

拍摄要点:
- 开篇钩子(前3秒):一元火锅大家都说便宜,但90%的人不会吃,今天师傅教你怎么吃回本
- 中段:师傅边穿串边讲(哪些菜必点、怎么搭配、为什么这样划算),调料、食材、明火画面切入
- 结尾:这样吃人均【X】元(待确认真实客单),火锅涮到饱,团购链接在这(手指左下角)
