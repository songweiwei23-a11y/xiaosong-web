## 一句话定位

**地摊烟火气川菜馆，串串火锅烧烤川菜一锅端，一元火锅撬动百元消费，成都师傅摆摊卖正宗川味。**

（30字压缩版：成都川菜师傅南乐摆摊，串串火锅烧烤川菜，一元火锅吃到爽）

### 1. 人设定位

#### 原料在哪
档案写了"成都来的川菜厨师，做川菜9年，来南乐发展才半年""门店在片区内已具备相当知名度"——这两句是真材料。"有特色""专业强"是形容词。翻译成具体行为：**一个在成都做了9年川菜的师傅，没在写字楼开店，跑到县城摆地摊，用正宗配方做一元火锅和露天烧烤**——身份、行为、反差都在这了。

#### 人设标签句
**成都来的川菜师傅，在南乐摆地摊卖正宗川味。**

#### 用了哪个入口
**身份反差** + **特殊经历**：川菜厨师（专业身份）× 地摊（反预期场景）；9年成都从业经历在县城是稀缺背书。

#### 验证
- 身份可见：每条视频露出地摊帐篷、露天桌椅、串串签子堆成山的画面，一眼确认"真在摆摊"
- 经历可讲：9年里接触过的食材、做法、成都同行的故事够拆成10+条人设内容
- 场景自洽：穿厨师服在露天灶台前讲川菜，比在装修店里讲更可信
- 线下也能保持：他本人就在那干活，不是为拍视频临时扮演

#### 在同类账号里的位置
本地美食号常见人设：店老板（强调年头久、回头客多）、探店达人（替观众试吃）、美食段子手（搞笑为主）。**这个号的差异在"身份来源地"**——不是本地人开本地店，是成都师傅带手艺来县城，自带"正宗"背书且有故事可讲（为什么来、怎么适应、本地人怎么看）。同行大多在店里拍，这个在露天摊拍，视觉区隔明显。

#### 证据链
接下来靠这4类内容持续证明：
1. 晒过程——备菜、穿串、调料、灶台操作，每个细节验证"会做川菜"
2. 讲故事·苦难经历——来南乐半年的适应过程（语言、口味调整、第一个月生意、本地人质疑到认可）
3. 教知识·拆解型——川菜冷知识、成都吃法 vs 本地吃法、怎么判断串串新鲜度
4. 观点·地域差异——南北火锅差异、为什么成都师傅做的和本地不一样

#### 边界
什么话一说人设就崩：
- 不能说"我们家祖传""在南乐开了X年"（他才来半年）
- 不能贬低本地同行"他们不正宗""用的料不行"（档案禁止诋毁同行）
- 不能承诺"保证好吃""吃了不满意退钱"（档案禁止承诺效果）

### 2. 用户定位

#### 一句话画像
**本地18-40岁年轻人——学生党三五个凑20块想吃饱、白领蓝领下班想撸串但怕踩雷、小情侣约会要有氛围但预算不到200、怕贵怕被坑、听过川味但没吃过正宗的、刷到"一元火锅"会停下来看是真是假。**

#### 为什么是他们、不是另一批
**不服务的人**：
- 只认高档装修、觉得地摊不卫生的（他们不会来露天摊）
- 追求极致便宜、连一元火锅都嫌贵的（客单价撑不起）
- 对川味无感、只吃清淡口味的（品类不匹配）

**是他们的原因**：档案写了目标人群兴趣"美食探店、朋友聚餐、夜宵烧烤、地摊文化"——这批人**愿意为氛围和新鲜感付钱，但价格要可控**。"一元火锅"是极低门槛诱饵，串串烧烤川菜组合能把客单做到50-200区间，覆盖学生到白领。

#### 他们心里真正在想什么
表面："这家看着不错，找时间去试试。"  
**心里那句**："一元火锅是噱头吧？去了会不会各种加钱？地摊干净吗？味道能比得上成都吗？"——**信任门槛是"怕被套路"，不是不想吃**。

#### 决策链路
刷到视频（停留看完"一元火锅"怎么回事）→ 翻主页看3-5条（确认不是纯广告号、真在做、有其他客人）→ 看团购页评价/问评论区"真的假的"→ **约朋友一起去试错成本低**（不是一个人去）→ 到店后如果体验好，当场拍视频/发朋友圈 → 复购或带新人来。**整个链路7-15天，需要5-8条内容铺信任。**

#### 什么时刻会想起你
- **周五下午5点后**：商量晚上去哪吃、刷本地推荐
- **发工资当天/第二天**：想犒劳自己、找性价比高的馆子
- **天气转暖/入夏**：露天烧烤旺季，搜"烧烤""夜市""地摊"
- **同学/同事聚会前一周**：找能坐十来个人、人均不贵、有特色的地方

#### 他在平台上搜什么
"南乐烧烤""南乐串串""南乐夜市""一元火锅""便宜好吃""朋友聚餐""南乐探店""地摊美食"

### 3. 内容定位

#### 长期提供什么价值
**让本地年轻人找到一个便宜、正宗、有烟火气、不怕踩雷的川味聚餐地。**

#### 内容方向
**多元四类**（不选单一主题）。理由：新号、团队2-3人、档案未标"数据最好的内容类型"，说明还没跑出稳定模式；单一主题（如"接受粉丝挑战探店""以物换物"）需要持续外部参与者，地摊场景不适合设计复杂任务。多元四类先把晒过程跑通，再用观点拉流量、故事立人设。

#### 当前阶段配比

**三层配比**：

**第一层·作用配比**：流量型45% / 人设型25% / 变现型30%  
**依据**：档案未填账号阶段、粉丝量级0-1万、"还没发过"——这是**新号起号期到过渡期**的配比。用户目标写了"让人长见识、让人有情绪、让人产生信任"三种变化都要，且勾了"对短视频帮助有疑虑"——说明**既要流量证明有用，又要尽快看到成交**。所以流量型占最大头（拿到稳定曝光和正反馈），变现型从第一周就要有（让老板看到咨询和到店），人设型保底25%（三个品类 + 地摊场景有大量人设素材，不用等后期补）。

**第二层·每一块用什么形式做**：
- **流量型45%**：主力**观点**（占流量型的60%）+ **泛知识·冷知识**（占40%）  
  为什么：观点覆盖人群广（南北火锅差异、地摊文化、年轻人消费观），易引评论；冷知识讲川菜门道、串串行业内幕，满足"长见识"。**不用行业干货当主力**（怎么挑食材、怎么调料——受众窄）
- **人设型25%**：主力**讲故事**（占人设型的80%）+ **一句话设定故事感**（占20%）  
  为什么：9年成都经历 + 来南乐半年的适应过程够拆10条故事；日常备菜、接待客人的片段用"一句话设定"（"凌晨四点进货，只为让你们六点吃上新鲜的"）制造故事感
- **变现型30%**：主力**晒过程·火车节**（占变现型的70%）+ **教知识·推荐型**（占30%）  
  为什么：晒过程离变现最近——拍客人从空桌到满桌串签、一元火锅涮菜到结账，评论多是"在哪""多少钱"；推荐型圈人（"学生党20块吃撑攻略""情侣约会人均百元以内"）直接推团购

**第三层·题材**：主赛道60%（串串火锅烧烤川菜本身）+ 目标人群兴趣40%（地摊文化、年轻人省钱、朋友聚餐、南北差异、夜宵场景）  
为什么：用户要"让人长见识、有情绪"，纯讲三个品类受众窄；40%讲人群兴趣的部分就是流量型内容的来源，覆盖"刷本地生活但不只看美食"的泛人群

#### 主力形式
**晒过程**（待20-30条后用数据验证）。理由：档案未标"数据最好的类型"，但地摊场景天生适合晒过程——露天灶台、客人围坐、串签堆成山、一元火锅现涮，**这些画面本身就是信任证据**，比口播"我们用料好"有说服力。同行美食号口播讲干货的多，晒真实服务过程的少，这是视觉区隔。如果前20条数据显示观点类完播更高,再调整为观点主力。

#### 每类内容管哪一段路
用户从「不认识」到「到店」分五步：
1. **刷到**：流量型·观点 + 泛知识（地域差异、冷知识）负责扩曝光
2. **停留看完**：变现型·晒过程·火车节（一元火锅怎么吃、客人结账画面）制造"这是真的"
3. **记住账号**：人设型·讲故事（成都师傅为什么来南乐、第一个月怎么熬过来）+ 记忆点（地摊帐篷、师傅口音、固定开场"成都XX来喽"）
4. **翻主页确认可信**：变现型·教知识·推荐型（学生党攻略、情侣套餐）+ 晒过程多条验证持续在做
5. **评论区问或下单**：结尾行动指令清晰（"团购页X元""评论区问地址"）

#### 三种视频各怎么拍

**流量型**（让更多本地新人刷到）：
- **四大脚本**：主力**聊观点·观点并列**（"为什么年轻人越来越爱吃地摊"→论据1便宜2氛围3真实→总结"烟火气回来了"）+ **教知识·冷知识**（"成都人吃串串的3个讲究，南乐人都不知道"→证据→应用"下次来试试"）| 结尾行动指令：**关注或评论**（"你们那也有地摊文化吗？评论区说说"）
- **起号36计**：第31计·**南北/地域差异**【流量型】：同一道菜（如毛血旺）成都做法 vs 本地做法 → 差异展示（辣度、配菜、吃法）→ 原因（气候、食材）→ 交流（"你们更爱哪种？"）| 也可用 第29计·**吐槽奇葩现象**（"有些人觉得地摊不卫生，但不知道…"→受害场景→为什么荒谬→建议）

**人设型**（让看过的人记住这个师傅）：
- **四大脚本**：主力**讲故事·苦难经历**（来南乐第一个月）：低谷（语言不通、本地人质疑口味、第一周只有三桌客人）→ 挣扎（凌晨四点进货、反复调试辣度适应本地口味）→ 顿悟（一个老客带十个新客、片区里开始有人认识"成都师傅"）→ 现在（"半年了,每天忙到凌晨"）| 结尾行动指令：**关注**（"关注我，看一个成都师傅在县城的手艺"）
- **起号36计**：第7计·**一句话设定故事感**【人设型】：普通动作（备菜、穿串）+ 设定（"凌晨四点的南乐，只有菜市场和我是醒的"）→ 故事期待（为什么这么早、在准备什么）| 也可用 第4计·**借物喻人**（一锅红油→"像我一样，成都来的，要在这扎根"）

**变现型**（推动团购下单和到店）：
- **四大脚本**：主力**晒过程·火车节**（一桌客人完整消费链）：起因带钩子（"这桌四个人，猜猜最后花了多少"）→ 关键步骤（一元火锅涮菜、点串串烧烤、师傅现烤、满桌签子）→ 结果（结账画面/客人说"才X元"）→ 落脚成交理由**性价比** | 结尾行动指令：**到店或团购**（"团购页X元，地址评论区置顶"）
- **起号36计**：第17计·**互联网嘴替/替网友做**【变现型】：征集问题（"粉丝问一元火锅是不是坑"）→ 选择任务（"今天替你们实测"）→ 亲测过程（真拿一元硬币、选菜、涮、计时）→ 结果与建议（"涮了X盘菜，真的只收一元，但串串烧烤另算"）→ 落脚成交理由**实在不坑** | 也可用 第10计·**情境还原**（客人问"辣不辣"→师傅解释"成都微辣和本地微辣不一样"→调整→客人尝→满意）

#### 配比核验
逐条过五个问题：
1. **流量型是不是和账号阶段匹配**？是——新号起号期，流量型45%占最大头
2. **主力形式是不是档案里数据最好的**？档案未标，推测晒过程（地摊场景适配），待20-30条数据验证
3. **用户要大流量的话，行业干货是不是没当主力**？是——流量型主力是观点和泛知识，不是"怎么调料""怎么进货"
4. **题材有没有给目标人群兴趣留出30-40%**？是——40%讲地摊文化、省钱、聚餐、南北差异
5. **每个数字都能说出为什么**？是——上面每层配比都写了依据

#### 第一条该发什么
**变现型·晒过程·火车节**——拍一桌客人（最好3-4个年轻人,符合目标人群画像）从空桌坐下到满桌串签的过程。

**结构**：
- 起因带钩子（0-3秒）："这桌四个学生，一元火锅随便涮，猜猜最后花了多少？"（金钱型钩子+盲盒型钩子叠加）
- 关键步骤（3秒-40秒）：一元火锅涮土豆片、藕片、青菜（字幕标"真的一元"）→ 点串串和烧烤（手在签子堆里挑）→ 师傅露天现烤画面→ 桌上签子堆成小山
- 结果（40-50秒）：客人结账（收银画面或客人说"才X元"）→ 师傅口播"一元火锅管饱，串串烧烤看你,学生党人均二三十"
- 落脚成交理由：**性价比**（档案卖点之一）

**为什么是它开场**：
1. 直接回应最大疑问"一元火锅是真是假"，破信任门槛
2. 完整消费链给足安全感（不是只拍菜不拍价格）
3. 晒过程 + 真实客人出镜 = 最强信任证据,比口播"我们便宜"有用一百倍
4. 目的单一：推动评论问地址、看团购页,结尾只要一个指令"地址评论区置顶,团购更划算"

**只担一个目的**：变现型（不在这条里讲人设故事、不追求病毒式传播,只要精准到店人群看到并行动）

**用的哪套打法**：四大脚本·晒过程·火车节（起因→步骤→结果,落在成交理由"性价比"上）
