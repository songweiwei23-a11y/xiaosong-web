# 🎯 账号定位方案

## 📌 核心结论（先看这 8 条）

1. **这是什么号**：本地实体店（A类·餐饮食品）｜南乐川味串串火锅、川味烧烤、川菜地摊店，成都9年川菜师傅坐镇，一元火锅引流

3. **人设标签**：成都来的川菜师傅，在南乐地摊上做正宗川味
4. **主打内容**：流量45% / 人设25% / 变现30%；主力形式晒过程（地摊场景天然有看点、起号快），配观点和故事
5. **怎么赚钱**：看视频 → 团购下单（火锅已上线）/ 评论区问 → 到店（烧烤）

7. **最该避开的坑**：地摊烟火气是优势不是劣势，别自卑着往"高端"拍；别把三个品类拍成三个号
8. **多久能看出跑没跑通**：连发20条晒过程（每天1条、3周出结果），有3条破500赞或10条稳定200+播放即通

## 一句话定位

**成都来的川菜师傅，在南乐地摊上做正宗川味串串火锅、川味烧烤、川菜，一元火锅随便涮。**

（29字｜身份清晰、地域明确、三品类全写、核心卖点都在）

---

### 1. 人设定位

#### 原料在哪

档案里真正的硬货是这几句（原话）：
- "出镜人是**成都来的川菜厨师，做川菜9年**，来南乐发展才半年，是店内川味正宗的核心保障"
- "老板是南乐本地人，门店在片区内已具备相当知名度，**'这条街我们自带流量'**"
- "**地摊式露天经营**，冬季有帐篷覆盖全年可营业"

档案里写的"真实、接地气、情感"是形容词，不是人设。翻译过来是：
- 真实 → 拍什么：现场备串、客人真实反应、帐篷下烟火气
- 接地气 → 怎么说话：大白话、师傅口音、不端着
- 情感 → 讲什么故事：成都师傅为什么来南乐、和本地老板怎么合作、老客人的故事

#### 人设标签句

**成都来的川菜师傅，在南乐地摊上做正宗川味**（17字）

这句话的每个字都能被验证：
- 成都来的 → 口音、手法、配方是证据
- 川菜师傅 → 9年经验、刀工、颠锅是证据
- 南乐地摊 → 场景就在那，每条视频都能看到
- 正宗川味 → 对比本地其他家、讲配方来源、客人反馈

#### 用了哪个入口

**反差人设**：身份预期A（成都专业川菜师傅）× 经营场景B（县城露天地摊）→ 环境自洽（师傅就在帐篷下现场操作）→ 能力验证（正宗川味、9年手艺）

这个反差天然自带话题：
- 观众好奇：成都师傅为什么来县城摆地摊？
- 观众期待：地摊能做出正宗川味吗？
- 观众验证：看手法、看食材、看客人反应

#### 验证

**这个人设立得住，因为：**
1. **场景是否逻辑自洽？** ✅ 是——地摊式经营在川渝本就是文化常态（成都苍蝇馆子、路边串串），师傅在地摊上做川味不违和，反而更真实
2. **能否持续证明？** ✅ 能——每天营业就是素材：备串、颠锅、调料、客人排队、老客人互动，9年手艺的细节可以拍几百条
3. **对方是否同意长期出镜？** ✅ 师傅是出镜主体，老板是本地人（利益绑定），档案写明"老客户愿意出镜"
4. **线下是否也能保持？** ✅ 能——人设不是编的，就是这个人在这个地方做这件事

#### 在同类账号里的位置

同行（本地餐饮）常见人设三类：
- **老板亲和型**："老板娘亲自xxx" → 人情味但专业度弱
- **探店达人型**：外人视角测评 → 流量大但转化弱（不是店家自己的号）
- **厨师专业型**：后厨展示、刀工特写 → 专业但距离感强

**你这个的位置**：专业手艺（9年川菜师傅）+ 地摊烟火气（去掉距离感）+ 地域话题（成都×南乐）。
- 和老板亲和型比：**你有技术背书**（9年经验、成都正宗），不只是人好
- 和探店达人比：**你是店家自己的号**，直接转化
- 和厨师专业型比：**你在地摊场景**，有人情味、有烟火气，不高冷

**同行没人占的空位**：外地专业师傅 × 本地地摊场景 × 三品类一锅端。这个组合在南乐大概率是独一份。

#### 证据链（接下来靠这4类内容持续证明）

1. **晒过程·手艺证明**（变现型）：备串、颠锅、调底料、刀工特写——9年手艺看得见
2. **讲故事·师傅经历**（人设型）：为什么从成都来南乐、和本地老板怎么合作、第一天摆摊的情况
3. **晒过程·客人反应**（变现型）：老客人互动、"这条街我们自带流量"的具体场景、客人排队等位
4. **教知识·川味科普**（流量型）：正宗川味和本地做法的区别、怎么吃串串最值、一元火锅怎么涮

#### 边界（什么话一说人设就崩）

结合档案禁忌：
- ❌ 不能说"揭秘同行黑幕""南乐其他家都不正宗" → 诋毁同行
- ❌ 不能说"欢迎大家来我店" → 硬广腔
- ❌ 不能编"成都某某大师传人""独家秘方" → 吹过了，师傅就是踏实手艺人
- ✅ 只讲自己怎么做、为什么这么做、成都那边怎么做的

### 2. 用户定位

#### 一句话画像

**18-40岁南乐本地的小镇青年、白领蓝领——晚上八九点刷手机、想叫上朋友找个地方聚聚、想吃夜宵又怕动辄人均六七十、觉得"地摊"比"店"更自在的那批人。**

不是服务"所有想吃川味的人"，是服务**晚饭后到深夜这个时段、把吃当社交场景、对价格敏感但愿意为氛围和正宗买单**的本地年轻人。

#### 为什么是他们、不是另一批

**你服务的是：**
- 小镇青年（朋友聚会、约会、发圈）——地摊场景天然适合拍照打卡、有话题
- 都市蓝领（发工资、下班解压）——一元火锅、串串自选，性价比极高
- 新锐白领（下班聚餐）——正宗川味是体验升级，地摊价格不心疼

**你明确不服务：**
- 资深中产、要接待父母/客户的——地摊场景不适合正式接待（他们去环境更好的店）
- 精致妈妈带孩子——露天、烟火气大、晚上时段，不适合亲子
- 银发族——老人晚上不出门、对辣度接受度低

**为什么这样排**：档案写明"下午到深夜时段与抖音本地美食黄金推流时段高度吻合"——你的场景优势在晚上，白天不营业；地摊烟火气是年轻人的社交货币，不是家庭聚餐的首选。

#### 他们心里真正在想什么

嘴上说的：
- "想吃串串火锅"
- "找个地方聚聚"

心里没说的（这才是内容要回应的）：
- "又想吃好的，又不想花太多"（一元火锅、串串自选解决）
- "去店里太正式了，随便吃个夜宵而已"（地摊场景解决）
- "县城那些川味馆做得地道吗？"（成都师傅背书解决）
- "我怎么知道你家好不好，先看看别人怎么说"（老客人出镜、排队场景解决）

#### 决策链路

从刷到你到到店，中间要经过：
1. **刷到视频**（晚上8-11点刷抖音）→ 停住看完（地摊场景 + 师傅手艺 + 一元火锅钩子）
2. **看主页翻几条**（确认不是偶然拍得好，是真的天天这样）→ 记住这家店
3. **某天晚上想吃夜宵** → 想起你 → 看团购 / 问朋友"去过吗"
4. **第一次试探**（可能先下团购单，低风险）→ 到店体验
5. **好了就复购、带朋友来** → 成为老客人、愿意出镜

**信任链路要铺多长**：本地餐饮的决策周期不长（不像装修、医美要比较一个月），但**需要反复曝光建立记忆**——刷到你3-5次、每次都是真实场景，就会记住。所以**高频更新**（每天1条或隔天1条）比偶尔爆一条更重要。

#### 什么时刻会想起你

**时刻**（具体到时间点和场景）：
- 晚上8点下班路上，刷手机刷到你在备串 → 馋了
- 周五晚上，朋友群里说"去哪吃" → 想起你家
- 发工资那天，想犒劳自己 → 刷到你的视频
- 刷到别人探店视频 → 评论区有人提"不如锦园"

**不会想起你的时刻**：
- 中午要吃工作餐 → 你下午才营业
- 要请长辈吃饭 → 不会选地摊
- 早上刷手机 → 看到你的视频但当时不饿，过了就忘

**所以内容策略**：视频发布时间对准晚上7-10点（他们下班刷手机的时段），钩子要戳中"现在就想吃"的冲动。

#### 他在平台上搜什么

真会打出来的词（按搜索习惯）：
- "南乐 串串"
- "南乐 烧烤"
- "南乐 火锅"
- "南乐 夜宵"
- "南乐 地摊美食"
- "南乐 川味"
- 偶尔有人搜"一元火锅"

**所以**：视频文案、话题标签要覆盖这些词，尤其是"#南乐美食 #南乐串串 #地摊美食"是必带标签。

### 3. 内容定位

#### 长期提供什么价值

**让南乐年轻人知道，地摊上也能吃到成都师傅做的正宗川味，串串火锅烧烤一条街搞定。**（35字）

#### 内容方向

**多元四类**（知识/故事/晒过程/观点都发），不走单一主题。

**理由**：
- 你不是"体验100种职业""接受粉丝挑战"那种需要持续外部任务的号，你是**每天营业就是素材**——备串是过程、师傅经历是故事、川味科普是知识、"一元火锅为什么不亏"是观点。
- 单一主题对策划和执行能力要求极高，你是2-3人小团队、刚起号，**多元四类更容易稳定生产**，每天拍营业过程就有内容。
- 等跑通20-30条、数据验证哪类最好之后,可以补一个固定栏目(如"师傅教你xxx"系列)当王牌，但不是现在。

#### 当前阶段配比（三层）

**第一层·作用配比**：流量型 45% / 人设型 25% / 变现型 30%

**依据**：
- 账号阶段：0-1万粉，刚起号，流量还不稳定 → **流量型必须是最大块**（45%），任务是让更多本地人刷到你
- 用户目标：档案写了"让人长见识、让人有情绪、让人产生信任"三种变化都要 → 流量/人设/变现三类每周都要有
- 变现路径已明确：火锅团购已上线、烧烤待上线 → **变现型从第一周就要有**（30%），但不能占主导（否则像广告号）
- 人设是长线资产：师傅经历、和老板的合作、和老客人的关系,这些故事早点讲，后面转化才有信任基础（25%）

**为什么这个比例适合你**：
- 你不是纯服务号（不是只给精准客户看），也不是纯流量号（要转化到店）→ 流量和变现都要，流量稍多一点保证曝光
- 你有真实的人物故事（师傅经历、地摊场景）→ 人设型25%能立住，不是硬凹
- 本地餐饮的决策周期短 → 不需要铺3个月信任才转化，30%变现型够用

**第二层·每一块用什么形式做**

| 作用 | 占比 | 主力形式 | 为什么 |
|---|---|---|---|
| 流量型 | 45% | **晒过程**（60%）+ 聊观点（25%）+ 教知识·泛科普（15%） | 地摊场景、备串、师傅颠锅、客人排队,这些过程天然有看点、覆盖人群广；"一元火锅为什么不亏""地摊和店有啥区别"是观点；"正宗川味和本地做法的区别"是泛知识 |
| 人设型 | 25% | **讲故事**（80%）+ 晒过程·关系细节（20%） | 师傅为什么来南乐、和老板怎么合作、第一天摆摊的情况,这些是故事；和老客人的日常互动、帮客人调辣度,这些是关系细节 |
| 变现型 | 30% | **晒过程·火车节**（70%）+ 教知识·解题型（30%） | 备串现场、客人点单、师傅现场操作、结果上桌,这是火车节（离变现最近）；"怎么吃串串最值""一元火锅怎么涮"是解题型 |

**主力形式**：档案里"数据最好的内容类型"写的是"还没发过" → **那就按这一行的规律来定**：
- 本地餐饮账号，**晒过程**是最容易起号、最容易拿流量、最容易转化的形式（有真实场景、有手艺展示、有客人反应）
- 你的场景优势极强（地摊、师傅现场操作、烟火气）→ **晒过程就是你的主力形式**
- 口播型（教知识、聊观点）是辅助，因为师傅可能不擅长对着镜头讲话，但**可以边做边说、自然口播**

**第三层·题材配比**

**主赛道60% + 目标人群兴趣40%**

- **主赛道60%**（川味串串火锅、川味烧烤、川菜）：
  - 串串火锅相关 25%（备串、涮法、一元火锅怎么吃）
  - 烧烤相关 20%（烤串、调料、师傅手法）
  - 川菜相关 15%（炒菜、颠锅、川味特色菜）
  - ⚠️ 注意三个品类**都要拍、穿插着发**，不要一个月只拍串串、下个月只拍烧烤——那样会让观众以为你只做一种
  
- **目标人群兴趣40%**（本地年轻人关心的）：
  - 地摊文化、烟火气、夜宵社交场景（15%）→ 流量型内容的主要来源
  - 性价比、怎么吃最值、一元火锅背后的逻辑（15%）→ 观点型、知识型
  - 师傅故事、成都×南乐的地域话题（10%）→ 人设型

**为什么这样配**：
- 60%保证账号标签清晰（平台知道你是做川味餐饮的）
- 40%拉宽流量入口（不只是想吃串串的人会看你，对地摊文化、对师傅故事感兴趣的本地人也会看）
- 用户要大流量的话往40%那头靠 → 你现在起号期,40%已经够了

#### 每类内容管哪一段路

从「不认识你」到「找你」,拆成四步：

1. **刷到**（流量型·晒过程 + 观点）：地摊场景、师傅手艺、一元火锅钩子 → 让本地人在推荐页停下来
2. **记住**（流量型 + 人设型）：反复刷到你（高频更新）、师傅标签清晰、地摊场景有辨识度 → 记住"南乐那个成都师傅摆的地摊"
3. **信**（人设型·讲故事 + 变现型·晒过程）：师傅经历、老客人反应、9年手艺细节、客人排队 → 相信是真的、手艺好
4. **联系/到店**（变现型）：团购链接、到店地址、"今晚X点开摊" → 转化

**哪类内容负责哪一步**：
- 流量型：负责1、2步（刷到、记住）
- 人设型：负责2、3步（记住、信）
- 变现型：负责3、4步（信、到店）

**为什么不能只发一种**：只发流量型 → 记住了但不信；只发变现型 → 曝光不够、新人刷不到；只发人设型 → 感动了但不知道去哪吃。

#### 三种视频各怎么拍

**（一）流量型：让更多本地人刷到你**

**四大脚本·聊观点**：
- 方向：地摊文化、性价比逻辑、成都×南乐的地域差异
- 结构：观点并列（"一元火锅为什么不亏" → 论据1薄利多销 / 论据2引流爆品 / 论据3回头客多 → 总结"地摊也能做正宗川味"）
- 结尾行动指令：**评论**（"你们觉得一元火锅能挣钱吗？评论区说说"）

**起号36计**：
- **第31计·南北/地域差异**【流量型】：成都串串 vs 南乐串串（同样是串串,成都那边怎么吃 → 南乐这边怎么吃 → 差异在哪 → "师傅教你成都吃法"）
- 结构：同一任务两地做 → 差异反应 → 原因/文化 → 交流
- 结尾行动指令：**评论**（"你们吃串串是成都派还是本地派？"）

**（二）人设型：让看过的人记住师傅、信这个人**

**四大脚本·讲故事**：
- 方向：师傅为什么从成都来南乐、第一天摆摊的情况、和本地老板的合作
