## 选题1：这小伙预算5000想配客厅,我带他直奔通货区

**承接**：这条取自带来内容里的「每条视频聚焦一个预算档（3000-5000），拍你接待这个预算客人的过程，重点是"他说预算多少→你问户型和风格→带他看对应价位的货→报价透明→他的反应"」

**0️⃣ 视频目的**
变现型——让同预算的观望者看到"5000也能配齐客厅"，推动"我这个预算能行吗"的人私信或到店

**🅰 打法**
晒过程·火车节：客人进店说预算 → 问户型和需求 → 带到通货区 → 讲材质报价 → 客人反应

**1️⃣ 爆款元素**
- 成本：预算5000,透明报价每件多少钱
- 人群:小两口刚装修完、预算紧张的年轻家庭

**2️⃣ 开篇钩子**
"小伙子进店第一句话,预算只有5000,问我能不能配齐客厅三件套。"

**3️⃣ 内容方向及目的（重中之重!）**
- **核心内容方向**:真实接待一位5000预算客人,从问需求到选货报价到客人反应的完整过程
- **核心问题与观众价值**:5000预算到底能不能在你店里配齐客厅?具体能配什么档次?观望的年轻人最怕"钱不够白跑一趟",看到真实案例会消除顾虑
- **取材与内容推进**:
  1. 等一位愿意配合拍摄的3000-5000预算客人进店(拍背影或打码)
  2. 客人说完预算后,你问"户型多大?喜欢什么风格?"(现场收声)
  3. 带客人走到通货区,边走边说"你这个预算我带你看性价比高的这边"
  4. 到沙发前掀开坐垫,讲材质"这个是XX填充,坐感怎么样"
  5. 报价环节:沙发X元、茶几X元、电视柜X元,加起来X元(拍客人手部或侧脸反应)
  6. 后期配音补全对话和你的判断:"他说预算紧,我就没带他去美式那边"
- **事实边界**:需现场等真实客人并征得同意;客人预算、户型、反应都用现场实际情况,不编造;报价用店内真实标价
- **关键画面(3个)**:
  1. 客人进门你问"预算大概多少"(拍背影,收声)
  2. 你掀开沙发垫讲填充材质(手部特写+你的讲解)
  3. 你报完价客人点头或说"考虑一下"(拍侧脸或手部)
- **场景设置**:店内通货区,自然光+店内照明,手机跟拍

**4️⃣ 脚本结构**
晒过程·火车节:
- 起因(带钩子):客人进店说预算5000,想配客厅
- 关键步骤1:你问户型和风格,判断需求
- 转场:带客人走向通货区(边走边说为什么选这个区域)
- 关键步骤2:到沙发前讲材质,掀坐垫给他看
- 转场:走到茶几和电视柜
- 关键步骤3:报价透明(每件单价+总价)
- 结果:客人反应(点头/说考虑/问能不能再便宜)+你的后期配音总结

**5️⃣ 结尾行动指令**
"你的预算能配什么,私信发我户型和预算,我帮你看。"

**6️⃣ 执行要点**
- 提前准备话术:客人进门就自然问预算和户型,别僵硬
- 征得拍摄同意:跟客人说"拍个背影做内容,不拍脸",不愿意就放弃这波
- 收声关键:你的问题和报价要说清楚,客人回答收全
- 一人操作:手机稳定器跟拍,或找角度架手机录一段,事后配音补全
- 时长控制:完整流程2-3分钟,后期剪掉重复和等待的部分
- 注意:报的价格必须是店内真实标价,客人反应用真实的,不摆拍夸张表情

**7️⃣ 成交理由**
- **体现的理由**:实在不坑(报价透明)、性价比(5000能配齐)、服务好(帮着挑不嫌预算少)
- **转化路径**:看到真实接待 → 评论"我也这预算" → 私信发户型 → 到店

## 选题2:预算8000的小两口,想配齐卧室和客厅,我给他们出了个主意

**承接**:这条取自带来内容里的「每条视频聚焦一个预算档(8000-1万),拍你接待这个预算客人的过程」

**0️⃣ 视频目的**
变现型——让8000预算想配两个空间的人看到"怎么分配预算更合理",推动同需求的人咨询

**🅰 打法**
晒过程·火车节:小两口说预算和需求 → 你判断预算分配 → 带他们看两个区域 → 报价+给建议 → 他们反应

**1️⃣ 爆款元素**
- 成本:8000预算配两个空间,钱怎么分
- 人群:刚结婚、预算有限想一次配齐的小两口

**2️⃣ 开篇钩子**
"这对小两口预算8000,想配齐卧室和客厅,我说你们得先做个选择。"

**3️⃣ 内容方向及目的(重中之重!)
- **核心内容方向**:真实接待一对8000预算想配两个空间的客人,重点是你帮他们分析预算怎么分配更合理
- **核心问题与观众价值**:8000预算配两个空间够不够?如果紧张该先配哪个?观望的小两口最纠结"钱不够是凑合买还是分两次买",看到专业建议会信任你
- **取材与内容推进**:
  1. 等一对愿意配合的8000左右预算、要配两个空间的客人
  2. 客人说完需求,你问"卧室和客厅哪个更着急用?"
  3. 你给建议:"如果都要,卧室选经济款,客厅选好一点的,因为客厅天天看;或者先配一个空间配好点的,另一个攒两个月再配"
  4. 带他们分别看卧室区和客厅区,报两套方案的价格
  5. 拍他们商量的过程(拍背影,收声"我们再商量商量")
  6. 后期配音:你的判断"很多小两口都这样,钱不够但想一次配齐,我一般建议他们先把常用的配好"
- **事实边界**:需现场真实客人;你的建议基于真实接待经验,不编造"90%的人都这样";客人选择用真实的
- **关键画面(3个)**:
  1. 小两口说"预算8000,想配卧室和客厅"(拍背影)
  2. 你带他们分别看两个区域,报价(跟拍)
  3. 他们俩商量"要不先配一个"(拍背影,收声)
- **场景设置**:店内卧室区+客厅区,手机跟拍

**4️⃣ 脚本结构**
晒过程·火车节:
- 起因(带钩子):小两口进店,预算8000,要配两个空间
- 关键步骤1:你问"哪个更着急",判断需求优先级
- 转场:你给建议(两种分配方案)
- 关键步骤2:带他们看卧室区,报价
- 转场:走到客厅区
- 关键步骤3:报客厅的价,总价算给他们听
- 结果:他们商量+你的后期配音总结

**5️⃣ 结尾行动指令**
"预算不够但想配齐,到店我帮你看怎么分配最合理。"

**6️⃣ 执行要点**
- 等合适的客人:真有这个需求的,不是随便拉一对凑数
- 你的建议要真诚:基于实际经验,别像背稿
- 拍他们商量的过程:这是真实感的关键,别催他们快点决定
- 后期配音:补充你的判断逻辑"为什么这样建议"
- 时长:2.5-3分钟
- 注意:不替客人做决定,只给建议,最后选择权在他们

**7️⃣ 成交理由**
- **体现的理由**:专业强(帮着分析预算分配)、服务好(不嫌预算少还给方案)、老板好(站在客户角度想)
- **转化路径**:看到真实建议 → 觉得"这老板靠谱" → 到店让你帮着看

## 选题3:这位老板来配办公室,预算2万,他最后选的不是最贵的

**承接**:这条取自带来内容里的「每条视频聚焦一个预算档(2万+),拍你接待这个预算客人的过程」

**0️⃣ 视频目的**
流量型——用"预算高但没选最贵"的反差吸引关注,扩大覆盖面,让更多人知道这个店

**🅰 打法**
晒过程·火车节+反差元素:老板说预算2万 → 你以为他要选轻奢款 → 他看中性价比款 → 你问为什么 → 他的回答(保留现场原话)

**1️⃣ 爆款元素**
- 反差:预算2万(高)但选的是性价比款(不是最贵)
- 头牌:办公室老板(有身份的人)

**2️⃣ 开篇钩子**
"这位老板来配办公室,预算2万,我以为他要选最贵的,没想到他看中的是这套。"

**3️⃣ 内容方向及目的(重中之重!)
- **核心内容方向**:真实接待一位预算充足的老板客人,重点是他没选最贵反而选性价比款,以及他的理由
- **核心问题与观众价值**:预算高的人怎么选家具?是不是一定选最贵?这个反差让观众好奇,评论区会讨论"有钱人反而更理性"
- **取材与内容推进**:
  1. 等一位预算较高(1.5万以上)、来配办公室或大户型的客人
  2. 客人说预算后,你带他看两个区域:轻奢款和性价比款
  3. 他看中性价比款,你追问"您预算够,为什么不选那边?"
  4. 保留他的现场回答(可能是"实用就行""办公室不用太贵""这个质量也不差")
  5. 报价环节:他选的这套总价是X,你给他讲材质和性价比
  6. 后期配音:你的感受"很多人以为有钱就选贵的,其实不是"
- **事实边界**:需现场真实客人;他的选择和理由用真实的,不编造台词;如果他就是选最贵的,这条不成立,换下一个
- **关键画面(3个)**:
  1. 老板说"配办公室,预算2万左右"(拍侧面或背影)
  2. 你带他看轻奢区,他摇头走向另一边(跟拍)
  3. 你问"为什么不选那边",他回答(拍侧脸,收声)
- **场景设置**:店内现代轻奢区+通货区,手机跟拍

**4️⃣ 脚本结构**
晒过程·火车节:
- 起因(带钩子):老板进店,说配办公室,预算2万
- 关键步骤1:你带他看轻奢款(你以为他要选这边)
- 转场:他走向性价比款区域
- 关键步骤2:他看中一套,你追问"为什么不选贵的"
- 关键步骤3:保留他的回答+报价
- 结果:成交或他说考虑+你的后期配音感悟

**5️⃣ 结尾行动指令**
"你们觉得买家具是选贵的还是选对的?评论区说说。"

**6️⃣ 执行要点**
- 等真实的反差案例:预算高但选性价比款,不是每个客人都这样,等到了再拍
- 追问要自然:别像采访,就是正常聊天"您预算够,怎么选这个?"
- 保留真实回答:他说什么是什么,别诱导他说"你们家性价比高"
- 后期配音:你的感受要真诚,别说教
- 时长:1.5-2分钟,节奏紧凑
- 注意:如果等不到这样的客人,换下一个选题,不摆拍

**7️⃣ 成交理由**
无(流量型不写成交理由)

## 选题4:预算4000的宝妈,带着孩子来挑儿童床,我多问了一句

**承接**:这条取自带来内容里的「每条视频聚焦一个预算档(3000-5000),拍你接待这个预算客人的过程」中的3000-5000档,结合儿童家具品类

**0️⃣ 视频目的**
人设型——通过一个真实接待细节,展示"当过老师、会多想一步"的人设,建立信任感

**🅰 打法**
讲故事·平凡英雄:普通接待(宝妈来买儿童床) → 你多问一句(孩子多大、会不会爬) → 提醒她注意护栏高度 → 她的反应(保留现场原话"还好你提醒")

**1️⃣ 爆款元素**
- 人群:宝妈、有孩子的家庭
- 服务细节:多问一句,帮客户避坑

**2️⃣ 开篇钩子**
"这位宝妈预算4000来挑儿童床,我多问了一句,她说还好你提醒我。"

**3️⃣ 内容方向及目的(重中之重!)
- **核心内容方向**:真实接待一位买儿童床的宝妈,重点是你基于当老师的经验,多问一句孩子情况并给出专业提醒
- **核心问题与观众价值**:买儿童床要注意什么?卖家具的人会不会只顾卖不管你家实际情况?这个细节让观众觉得"这老板靠谱,站在我这边想"
- **取材与内容推进**:
  1. 等一位带孩子或来买儿童床的宝妈客人
  2. 她说预算和需求,你问"孩子多大了?睡觉老实吗?"
  3. 根据她的回答,你提醒"孩子如果爱动,护栏要选高一点的""床角要圆弧别选直角"
  4. 保留她的反应(可能是"对哦我没想到""还好你提醒")
  5. 你带她看符合要求的款,报价
  6. 后期配音:你的想法"我当过5年老师,见过太多孩子睡觉不老实,多问一句没坏处"
- **事实边界**:需现场真实宝妈客人;你的提醒基于真实经验(当老师见过的情况),不编造"90%的宝妈都忽略这个";她的反应用真实的
- **关键画面(3个)**:
  1. 宝妈说"想买儿童床,孩子X岁"(拍背影或打码)
  2. 你问"孩子睡觉老实吗",她回答(收声)
  3. 你指着床的护栏讲"这个高度更安全"(手部特写+你的讲解)
- **场景设置**:店内儿童家具区,手机跟拍

**4️⃣ 脚本结构**
讲故事·平凡英雄:
- 普通人:一位宝妈带孩子来买床,预算4000
- 一件不普通的小事:你多问一句孩子情况,提醒护栏高度和床角安全
- 细节验证:她的反应"还好你提醒",你给她挑符合要求的款
- 感悟:后期配音"我当过老师,知道孩子安全最重要,多问一句是应该的"

**5️⃣ 结尾行动指令**
"关注我,买家具我帮你多想一步。"

**6️⃣ 执行要点**
- 等真实场景:真有宝妈来买儿童床,你真实提醒,不摆拍
- 你的提醒要自然:基于当老师的经验,别像背安全手册
- 保留她的反应:她说什么是什么,可能是感谢,也可能是"我知道",都真实
- 后期配音:你的感悟要简短真诚,别煽情
- 时长:1-1.5分钟,节奏紧凑
- 注意:不夸大风险吓唬客户,只是正常提醒

**7️⃣ 成交理由**
无(人设型不写成交理由)

## 选题5:预算1万想配新中式,这家人说的一句话让我印象最深

**承接**:这条取自带来内容里的「每条视频聚焦一个预算档(8000-1万),拍你接待这个预算客人的过程」中的8000-1万档

**0️⃣ 视频目的**
变现型——通过真实客户的一句话,体现"客户信任你、认可你的专业",推动同需求的人到店

**🅰 打法**
晒过程·火车节:客人说预算和风格 → 你带他们看新中式区 → 讲材质和搭配 → 他们说一句话(保留现场原话) → 成交

**1️⃣ 爆款元素**
- 成本:预算1万配新中式
- 共鸣:客户的一句话(可能是"听你的""就信你""你比我懂")

**2️⃣ 开篇钩子**
"这家人预算1万想配新中式,我给他们讲完材质,他们说了一句话让我印象最深。"

**3️⃣ 内容方向及目的(重中之重!)

  1. 等一家预算8000-1万、要配新中式的客人

- **关键画面(3个)**:
  1. 你带客人到新中式区,讲材质(手部特写+你的讲解)
  2. 客人说"听你的"或类似的话(拍侧脸或背影,收声清晰)
  3. 报价环节或成交后他们满意的表情(拍背影)
- **场景设置**:店内新中式区,手机跟拍

**4️⃣ 脚本结构**
晒过程·火车节:
- 起因(带钩子):客人进店,预算1万,要配新中式
- 关键步骤1:你带他们看货,讲材质和搭配

- 关键步骤2:他们说一句认可的话(保留现场原话)
- 关键步骤3:报价+成交或考虑
