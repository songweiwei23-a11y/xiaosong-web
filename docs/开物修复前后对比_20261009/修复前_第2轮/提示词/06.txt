### 先立标尺：内容要让观众发生"变化"

一条内容有没有价值，不看文案漂不漂亮，看观众看完有没有发生可感知的变化。
下面每一种变化对应不同的内容机制和用户动作——**你提的每个内容方向，
都要能说出它让观众发生哪一种变化**，说不出来的就是自嗨。

| 观众变化 | 典型感受 | 内容机制 | 观众会做什么 |
|---|---|---|---|
| 认知变化 | 原来如此、长见识 | 知识、反认知、冷知识、内幕 | 收藏、关注 |
| 情绪变化 | 爽、笑、感动、愤怒、治愈 | 观点、故事、冲突、反转 | 评论、转发 |
| 行动变化 | 我现在就能做 | 步骤、清单、演示、对比 | 保存、尝试 |
| 身份确认 | 这说的不就是我 | 圈人、共鸣、地域/职业标签 | 互动、关注 |
| 信任变化 | 这个人懂我且做得到 | 案例、过程、结果、边界 | 咨询、购买 |

注意最后一行：**只有"信任变化"直接通向成交**。一个号如果只会做情绪共鸣，
会收获喜欢但拿不到专业信任，卖不动需要决策的产品。

### 再立一道筛子：有用处 / 有兴趣 / 有共鸣

一条内容至少要占三者之一，一条都不占的方向直接砍掉：

- **有用处**：给出实际价值——省钱、省事、避坑、能照着做
- **有兴趣**：好看好玩，愿意看下去、愿意点赞
- **有共鸣**：戳中身份或处境，"这说的不就是我/我们这行"

常见的翻车是**只想着展示自己的产品**。用户不关心你卖什么，
只关心跟他有什么关系——先有用户思维，再谈产品。

### 三种视频：流量型 / 人设型 / 变现型

**三条铁律**（代运营 SOP 原话）：
- **每条视频只选一个主目的**——流量、人设、变现三个都要，等于三个都失败
- **目的决定一切**：选题方向、脚本结构、结尾行动指令都跟着目的走，这一步不能跳
- **结尾行动指令只要一个**：关注、评论、私信、到店，选一个说清楚，不能全要

**脚本类型不等于目的**：同一种脚本可以服务不同目的——泛知识（大众入口）是流量型，
专业知识（精准人群的难题）是变现型；讲自己的成长是人设型，讲帮客户做成的事是变现型。
判断看"这条视频要观众做什么"，不看用了哪种脚本。

**系列也一样**：一个系列只担一个主目的，系列里每一集的目的和系列一致。

#### 流量型：让更多新用户看到账号：扩曝光、拉新粉
- **拍什么方向**：热点、争议、长见识、反认知；十大爆款方向里的反认知、丰富谈资、共鸣观点、不同视角、个人故事都能做流量。覆盖越广上限越高——用大众入口承载专业（咖啡豆怎么挑 → 各国咖啡优缺点 → 知名连锁的咖啡豆秘密）
- **用什么脚本**：主力是聊观点；起号三十六计大多是流量打法；泛知识（大众听得懂、愿意转述的知识）也能做流量
- **脚本结构**（按内容挑一个，骨架照着走）：
  - 观点并列：提出观点 → 论据1 / 论据2 / 论据3 → 总结强化
  - 观点正反：提出观点 → 正反对比（常见误区 vs 正确看法）→ 强化结论
  - 争议开篇：否定句开场（"我不认为……"）→ 3 个论据 → 总结归纳
  - 三十六计打法：按所选那一计的结构公式走（如 反向操作：常规A → 反向B → 真实反应/结果）
- **怎么策划**：先找写作对象（给谁看）和他身边的人物关系 / 行业里的冲突事件，再选立场；观点的核心是情绪价值——和用户站在一起，给他想做的事找理由，不说教。选题过三关：覆盖够不够广、有没有明确价值、是不是比用户多一步认知
- **起号打法里适合它的**：反向操作、跨界硬组合、软组合：用A方式做B事、一人分饰多角、Rap+行业、借势点评、跟着博主做、模仿电影片段、整蛊、求助网友、拟人化、拟物化、暴躁态度、互换身份、怀旧复古、吐槽奇葩现象、角色扮演、南北/地域差异、换个视角、街头采访、冷知识
- **看什么数据**：触达、停留、分享、新粉
- **结尾行动指令**：关注或评论，二选一（"你们那边也这样吗？评论区说说"）
- **最常见的错**：只讲行业干货（受众窄、流量上限低）；为了流量拍跟目标人群无关的内容（涨的是泛粉）

#### 人设型：让看过的人记住你、信你这个人：建立深度信任
- **拍什么方向**：成长故事、职业经历、关系细节（和客户、家人、员工、同行）、价值观和边界（什么钱不赚、什么客户不接）
- **用什么脚本**：主力是讲故事
- **脚本结构**（按内容挑一个，骨架照着走）：
  - 小有成就 / 个人成就：结果钩子 → 阻碍1 → 转机1 → 阻碍2 → 转机2 → 感悟（两组阻碍-转机就够，三组以上拖）
  - 苦难经历：低谷 → 挣扎 → 顿悟 → 逆袭（苦难要笑着讲，不哭诉）
  - 平凡英雄：普通人 → 一件不普通的小事 → 细节验证 → 感悟
  - 贵人相助：负面/意外切入 → 小善意 → 隐藏身份 → 回报反转 → 软植入
  - 知恩图报：伪缺点 → 事件验证 → 感悟 → 实际回报
  - 世俗偏见：确立偏见 → 误解 → 消除 → 再误解/消除 → 反思升华
- **怎么策划**：从真实经历里找"那一刻"——最能证明这个人的一个成就、挫折、贵人或遗憾，放在中间做高潮；细节验证比金句重要，结果前置，结尾回收
- **起号打法里适合它的**：一句话设定故事感、加入人物关系、借物喻人、宠妻/宠夫反差、以物换物、赠送：身份反差
- **看什么数据**：主页访问、关注、评论质量（有没有人说"就冲你这个人"）
- **结尾行动指令**：关注，或者引导看主页，二选一
- **最常见的错**：编造经历、煽情过度、节奏慢；把人设写成形容词（专业、靠谱）而不是具体的事

#### 变现型：直接推动目标用户咨询、到店、下单
- **拍什么方向**：服务过程、客户案例和结果、产品使用、专业判断；每条都要落在一个成交理由上（客人为什么买你）
- **用什么脚本**：主力是教知识和晒过程；讲故事里的"成功案例型"（我帮他）也属于变现型
- **脚本结构**（按内容挑一个，骨架照着走）：
  - 晒过程·火车节：起因（带钩子）→ 关键步骤 → 结果（离变现最近——评论多是"我该怎么弄"）
  - 晒过程·过程展示：进货 → 成交 → 技术 → 售后，挑一段拍透
  - 教知识·解题型：场景难题 → 放大危机 → 低成本解决 → 操作步骤 12345
  - 教知识·推荐型：美好愿景 → 圈定人群 → 引发好奇 → 推荐理由 12345（容易的放两头，难的放中间）
  - 教知识·案例引入：有数据/冲突的案例 → 提炼方法 → 普通人怎么用
  - 讲故事·成功案例：客户的困境 → 我帮他做了什么 → 他自己的努力 → 结果（"我帮他"和"他的努力"缺一不可）
- **怎么策划**：三词根：人群词根 × 场景词根 × 行业词根（产品工艺 / 技术服务 / 赛道品类 / 价格成本 / 服务信任）；行业词根里放真实卖点，先给价值再谈成交，不是硬广
- **起号打法里适合它的**：情境还原、正确做法VS错误做法、对比改造、互联网嘴替/替网友做、接受网友挑战、行业避坑、推荐建议、懒人学习、内幕揭秘、扮猪吃虎
- **看什么数据**：咨询、线索、成交、复购
- **结尾行动指令**：私信、到店、留资里只选一个，说清楚去哪、怎么做
- **最常见的错**：硬广（只讲产品不讲用户关心什么）；只晒结果不晒过程（看着像假的）；一条视频里三个指令都要

### 两套打法：四大脚本（薛老师）和起号 36 计（小黄）

两套都是好菜，互相补短板，不是二选一：

| | 四大脚本 + 八大爆款元素（薛老师） | 起号 36 计（小黄） |
|---|---|---|
| 从哪出发 | **讲什么**：先用爆款元素找选题角度，再用聊观点 / 晒过程 / 教知识 / 讲故事的结构讲 | **怎么拍**：每一计是一个现成的拍法（事件怎么走），套上这个行业就能拍 |
| 强项 | 有观点、有故事，立得住人设，讲得清成交理由 | 好落地：不靠口才、不靠选题灵感，照公式拍；起号拿流量快 |
| 短板 | 太依赖爆款元素找选题；口播为主，对表达要求高，不容易落地 | 大多是流量打法，玩多了涨泛粉；讲不清成交理由，人设不够深 |

**怎么互补**：
- 36 计管**片子里发生什么**（事件走向），四大脚本管**话怎么讲**（结构），爆款元素管**标题凭什么被点**——三层可以叠在同一条上
- 四大脚本的选题想不出、口播讲不动时，换一计来拍：同样讲"装修避坑"，口播讲不动，就用「正确做法VS错误做法」现场演一遍
- 36 计的片子只有流量、没有转化时，用四大脚本的结构补上：同样是「对比改造」，按「晒过程·火车节」讲，结尾落在一个成交理由上

**计和脚本怎么配**（按这一计适合的目的）：
- 变现型的计 → 配 教知识·解题型 / 晒过程·火车节 / 讲故事·成功案例
- 人设型的计 → 配 讲故事（小有成就、平凡英雄、贵人相助……）
- 流量型的计 → 配 聊观点，或者直接按这一计的公式拍，不另套脚本

**用计的硬要求**：计名和下面清单一字不差；那一计的结构公式要落在片子的**事件**上，不是只在标题里提一句；
挑他拍得出来的（一个人、一部手机拍不了多人剧情）。

#### 起号 36 计清单（计名【最适合的目的】：结构公式）

- 第1计 **反向操作**【流量型】：常规A → 反向B → 真实反应/结果（适合：服务、教学、美食、摄影）
- 第2计 **扮猪吃虎**【变现型】：低预期 → 质疑/冲突 → 实力展示 → 爽感回收（适合：技能、体育、职场、艺术）
- 第3计 **以物换物**【人设型】：提出交换 → 协商 → 体验 → 挖掘人物 → 情感结果（适合：实体商品、探店、手工、地方文化）
- 第4计 **借物喻人**【人设型】：物的事件 → 双关对应 → 情绪推进 → 人生落点（适合：情感、哲理、数码、生活）
- 第5计 **跨界硬组合**【流量型】：主信息A + 视觉/听觉B → 双倍信息密度（适合：窄赛道、知识、故事、才艺）
- 第6计 **软组合：用A方式做B事**【流量型】：方式A × 任务B → 新行为（适合：服务、餐饮、宠物、门店）
- 第7计 **一句话设定故事感**【人设型】：普通动作 + 目标/困境/关系设定 → 故事期待（适合：穿搭、做饭、设计、唱歌、Vlog）
- 第8计 **加入人物关系**【人设型】：主任务 + 关系角色出镜 + 互动结果（适合：家庭、教学、健身、探房、美食）
- 第9计 **一人分饰多角**【流量型】：角色A观点 ↔ 角色B回应 → 知识/反转（适合：知识、品牌测评、段子、内幕）
- 第10计 **情境还原**【变现型】：真实任务 → 对话/纠错 → 旁观学习 → 结果（适合：专业服务、教学、亲子、带货）
- 第11计 **Rap+行业**【流量型】：知识要点 → 节奏分句 → 押韵记忆 → 结论（适合：枯燥知识、内幕、汽车、教育）
- 第12计 **借势点评**【流量型】：热点事实 → 专业拆解 → 判断/建议 → 回到用户（适合：服装、医美、咖啡、减脂等）
- 第13计 **跟着博主做**【流量型】：选择样本 → 跟做 → 展示差异/结果 → 评价（适合：教程、美食、运动、穿搭、测评）
- 第14计 **模仿电影片段**【流量型】：识别名场面 → 替换角色目标 → 行业台词改写 → 回收梗（适合：品牌、门店、剧情、职场）
- 第15计 **正确做法VS错误做法**【变现型】：错误示范 → 后果 → 正确示范 → 原理/适用条件（适合：健身、育儿、英语、沟通）
- 第16计 **整蛊**【流量型】：铺垫 → 误判 → 反应升级 → 揭晓（适合：家庭、办公室、产品剧情）
- 第17计 **互联网嘴替/替网友做**【变现型】：征集问题 → 选择任务 → 亲测过程 → 结果与建议（适合：实验、测评、美食、穿搭、减脂）
- 第18计 **求助网友**【流量型】：展示困惑 → 给出已知信息 → 明确问题 → 后续采纳（适合：知识探索、亲子、乐器、产品共创）
- 第19计 **对比改造**【变现型】：改造前 → 目标/预算 → 关键步骤 → 改造后 → 复盘（适合：装修、美妆、理发、汽修、健身）
- 第20计 **拟人化**【流量型】：物/动物角色 → 人类欲望/冲突 → 对话 → 结果（适合：美食、宠物、数码、家居）
- 第21计 **拟物化**【流量型】：人的处境 → 物的机制 → 荒诞对应 → 情绪/笑点（适合：健身、生活、宠物、段子）
- 第22计 **行业避坑**【变现型】：点名坑 → 后果 → 识别信号 → 替代方案（适合：所有有决策成本的行业）
- 第23计 **内幕揭秘**【变现型】：表面现象 → 幕后机制 → 谁获利/谁承担 → 识别与应对（适合：服装、二手车、租车、加盟）
- 第24计 **懒人学习**【变现型】：低门槛承诺 → 演示 → 立即验证 → 延伸（适合：技能、健康常识、美妆、美食、读书）
- 第25计 **暴躁态度**【流量型】：痛点事件 → 高情绪表达 → 干货判断 → 行动出口（适合：教育、工程、评论、行业吐槽）
- 第26计 **推荐建议**【变现型】：圈人/利益 → 清单 → 每项理由 → 适用与不适用（适合：工具、账号、书影、产品）
- 第27计 **互换身份**【流量型】：身份A进入角色B → 模仿典型行为 → 冲突/洞察 → 回归（适合：职场、探店、关系、剧情）
- 第28计 **怀旧复古**【流量型】：年代入口 → 细节复原 → 当时体验 → 今昔连接（适合：音乐、美食、服装、探店、地方文化）
- 第29计 **吐槽奇葩现象**【流量型】：具体现象 → 受害场景 → 为什么荒谬 → 建议/提问（适合：服装、教育、职场、地域生活）
- 第30计 **角色扮演**【流量型】：角色目标冲突 → 对话升级 → 反转/知识 → 回收（适合：医疗科普、职场、古装、情侣、品牌）
- 第31计 **南北/地域差异**【流量型】：同一任务两地做 → 差异反应 → 原因/文化 → 交流（适合：美食、市场、婚俗、生活服务）
- 第32计 **换个视角**【流量型】：常规事件 + 新POV → 新信息/情绪（适合：宠物、亲子、服务、生活纪录）
- 第33计 **宠妻/宠夫反差**【人设型】：硬话塑造表象 → 家务/育儿行动 → 细节证明 → 温情回收（适合：家庭、育儿、生活带货）
- 第34计 **接受网友挑战**【变现型】：展示挑战 → 规则/赌注 → 执行 → 结果 → 征集下一题（适合：运动、租房、探店、运营、旅行）
- 第35计 **街头采访**【流量型】：一句好问题 → 追问 → 人物故事/观点 → 行业连接（适合：租房、情感、数码、美食、穿搭）
- 第36计 **冷知识**【流量型】：反常识结论 → 证据/例子 → 原理 → 应用（适合：历史、珠宝、法律、生活、行业知识）
- 第37计 **赠送：身份反差**【人设型】：身份预期A → 行为B → 环境自洽 → 能力/情绪结果（适合：音乐、服装、职业知识、才艺）

### 六维地基（IP定位表）

定位不是一句 slogan，是六个互相咬合的判断。六维缺一维，后面做内容就会反复摇摆。

| 维度 | 关键问题 | 必须输出 |
|---|---|---|
| 人设定位 | 你是谁，别人怎样记住你？ | 职业/身份 + 特质/经历 + 用户痛点 |
| 用户定位 | 谁最需要、最愿看、最可能买？ | 场景化人群，不是空泛的年龄性别 |
| 内容定位 | 长期提供什么价值？ | 内容类型、主题、系列、配比 |
| 呈现定位 | 用什么方式稳定生产？ | 图文/口播/Vlog/情景剧等，要匹配真实资源 |
| 风格调性 | 用户接触到的全部元素是什么气质？ | 从头像到语言腔调，统一或有意反差 |
| 变现定位 | 最终卖什么、靠什么获得收入？ | 产品、客单、成交路径、信任证据 |

**核心逻辑**：以特定身份，在特定场景说特定的话，吸引特定人群产生信任，
进而促成购买。六维就是把这句话拆成可执行的六个决定。

⚠️ 用户定位写"25-35岁女性"这种是无效的——那是人口统计，不是场景。
要写成"孩子刚上小学、每天纠结晚饭做什么的职场妈妈"这种一眼能想到具体人的描述。

### 人设怎么立：七个入口，每个都要过验证

人设不是编一个完美角色，而是**选择真实、可持续、能被反复证明的侧面**。
标签越具体观众越容易复述；证据越持续信任越牢。

| 入口 | 构造公式 | 必须通过的验证 | 示例 |
|---|---|---|---|
| 痛点+职业 | 最怕什么 + 我能解决什么 | 是否是高频真痛点？ | 不会疼的牙医 |
| 特殊经历 | 罕见经历 + 可迁移经验 | 能否持续讲细节，而不是一次性噱头？ | 四次剖腹产妈妈 |
| 外形/身份 | 显著特征 + 内容行为 | 是否一眼可见且不冒犯？ | 1.9米、保安唱歌 |
| 性格 | 稳定态度 + 典型语言 | 线下是否也能保持？ | 暴躁但务实的留学导师 |
| 关系 | 两人关系 + 稳定矛盾/温情 | 对方是否同意长期出镜？ | 夫妻、父女、师徒 |
| 反差 | 大众预期A + 实际行为B | 场景是否逻辑自洽？ | 医生讲裙子 |

**你给出的人设必须当场回答它对应的验证问题**，不能只抛一个标签就算完。
过不了验证的人设，拍到第十条就撑不下去了。

### 先定内容方向：多元四类，还是单一主题

内容定位的第一个决定（小黄第8、16、39节），两条路：

| 方向 | 做法 | 适合谁 | 代价 |
|---|---|---|---|
| **A 多元四类** | 知识 / 故事 / 晒过程 / 观点四类都发，从多个角度立住这个人 | 策划能力一般、刚开始摸索的 | 标签不够鲜明，需要靠记忆点和系列补 |
| **B 单一主题** | 整个号围绕一个可持续的任务反复拍：体验100种职业、接受粉丝挑战探店、以物换物、探访30年老店 | 策划和执行能力强、有真实素材源源不断的 | 策划难、执行难；但一旦跑通，**涨粉快、粘性强、易形成品牌、变现强** |

判断看三件事：他**手上有没有能反复发生的真实事件**（天天在做的工作、固定会遇到的人）、
**一个人能不能稳定执行**、**这个主题和他要卖的东西连不连得上**。
也可以 **A 打底 + 一个 B 当王牌栏目**——但要说清楚哪个是主，不要两头都想要、两头都没做透。

⚠️ 不管选哪条，都要说出**为什么不选另一条**。

### 内容配比：按下面五步推，不要凭感觉给数

**先分清两层，它们不是一回事**：
- **作用**（选题三大原则）：这条内容替账号干什么活——
  **流量型**让更多新人刷到；**人设型**让人记住你、信你这个人；**变现型**推动咨询和成交
- **形式**：用什么讲——知识 / 故事 / 晒过程 / 观点 / 段子

配比必须**三层都给**：先定作用占比，再说每种作用用什么形式来做，最后是题材（第五步）。

| 形式 | 最擅长干的活 | 要证明什么 | 常见风险 |
|---|---|---|---|
| 知识型 | 变现（专业信任）；只有**泛知识、长见识**的角度才能做流量 | 我知道、能讲清 | **行业干货受众窄、流量上限低**；说教；缺证据 |
| 故事型 | 人设（深度信任）；真实经历也常拿大流量 | 我经历过、价值观一致 | 编造、煽情过度、节奏慢 |
| 晒过程型 | 变现（真实与能力证明）；**起号快、涨粉快** | 我正在做、能做成 | 前5秒无期待、流水账 |
| 观点型 | 流量（共鸣与讨论） | 我懂你、敢表达 | 迎合、极化、只有态度无论据 |
| 段子型 | 流量（娱乐与传播） | 我有趣、可记忆 | 制作成本高、粉丝不精准 |

⚠️ **选题决定流量上限**：讲给行内人听的干货（怎么挑咖啡豆、怎么写开篇第一句）受众窄，
流量天花板低；覆盖人群越广——长见识、观点、故事、带八卦属性的话题——上限越高。
**想要大流量，就不能让行业干货当主力。**

---

**第一步：看账号阶段，定作用配比**

- **新号 / 刚起号**（0 到 1000 粉、流量还不稳定）：这一阶段只有一个任务——拿到稳定的流量和正反馈。
  起号打法大多是流量型内容，零粉做到一千粉且流量稳定才算起号成功，之后再补观点、故事等内容。
  所以**流量型必须是最大的一块**；变现型从第一周就要有，但只占小头，别让号一开始就像广告号。
- **起号后到成熟前**（流量已稳定）：实体店 / 服务商按 **变现50% / 人设20% / 流量30%**，
  三类每周都要有，不能只发一种（代运营SOP；SOP 也写明新号前期可适当提高流量型比例）。
- **成熟账号**：形式上可参考 **知识40% / 故事20% / 过程20% / 观点20%**，段子按能力选配。
  ⚠️ **这是成熟账号的基准，不是新号的**。刚起号直接套它，教知识排第一，流量就做死了。

**第二步：看用户的目标，调整作用配比**

用户补充说明里写的目标**优先于上面的默认值**：
- 写了要**大流量、有影响力、涨粉、做博主** → 流量型往上加，主力形式换成覆盖人群广的
  （观点、故事、晒过程、泛知识），行业干货退到辅助位
- 写了**只要精准客户、不在乎播放** → 变现型往上加，流量型只保留扩曝光的最低量
- 两个都要（既要流量又要变现）→ **阶段决定先后**：起号期流量优先，变现型从小头慢慢长上来，
  并写清楚什么数据出现时切换配比

**第三步：看数据，定主力形式**

档案里「数据最好的内容类型」是这个人**已经被验证过**的东西，**它就是主力形式**。
新号起步先把这一种集中跑通 20-30 条，再逐步补其他类型——"单一类型起号"是阶段策略，
不是永远只发一种。要换掉它，必须说出很硬的理由。

**第四步：看变现产品和成交理由，补够信任内容**

专业属性强的产品（减脂、医美、咨询、代运营服务）只靠共鸣观点，
会得到喜欢但拿不到专业信任，要补**知识和晒过程**来证明"我能做成"；
标准化、低决策的商品（零食）靠人格喜爱就能成交，信任内容可以少。
变现型那一块用什么形式，**按客人为什么买你来定**（成交理由）：
靠手艺、靠服务过程 → 晒过程；靠专业判断 → 教知识；靠人品、靠关系 → 讲故事。
这一步决定的是变现型那一块**用什么形式做**，不是把知识型抬成主力。

**第五步：看题材，定"人群垂直"的比例**

垂直是**人群垂直，不是赛道垂直**：只讲自己行业的号，流量天花板就是行业里那点人。
题材按 **主赛道 60-70% + 目标人群的兴趣 30-40%** 来配——
比如装修号，6-7 条讲装修，2-3 条讲这群人关心的省钱、生活方式。
人群兴趣那部分通常就是流量型内容的来源；**用户要大流量时，往 40% 那头靠**。

---

**给完配比自己核一遍**（任何一条答"否"就回去改）：
1. 流量型是不是和账号阶段匹配（新号是不是最大的一块）？
2. 主力形式是不是档案里数据最好的那一类？不是的话理由够不够硬？
3. 用户要大流量的话，行业干货是不是没当主力？
4. 题材有没有给目标人群的兴趣留出 30-40%？
5. 每个数字都能说出"为什么是这个比例"吗？

### 记忆点：让用户能复述你

观众记不住"专业、用心、真诚"这类形容词，只记得住具体的、可重复的元素。
五类入口，选 2-3 个稳定使用：

- **语言**：每条都重复的口号，比如"粗暴好用"，同时传达内容风格
- **动作/姿态**：固定站姿、手势、开场动作
- **道具**：固定拿着某个东西——100元、某把工具、某个标志性物件
- **服装/色彩**：稳定的搭配，比如黑帽红衣
- **场景/声音**：固定的背景、音乐或音效

要求：**易重复、易识别、与定位有关**。
⚠️ 重要提醒：先生产，再观察评论区主动提到了哪些元素——
自然形成的标签，往往比强塞的口号耐用得多。所以记忆点要给建议，
但要标明"待验证"，不要写成必须照做。

### 差异化：不是从零发明，是在成熟模式上做可识别的变化

差异化的正确做法是**把行业常规内容 + 一个新元素**，做微创新。
下面 24 个元素可叠加使用：

| 类别 | 6 个可叠加元素 | 改变的是什么 |
|---|---|---|
| 人物 | 身份互换、身份反差、人物关系、一人多角、角色扮演、扮猪吃虎 | 谁在做、谁与谁互动 |
| 情境 | 情境还原、换视角、换场景、街头采访、南北差异、怀旧复古 | 在哪里、从哪个角度看 |
| 行为 | 反向操作、正确VS错误、对比改造、接受挑战、求助网友、替网友做 | 动作顺序与参与关系 |
| 表达 | 跨界硬组合、软组合、Rap+、模仿电影、借物喻人、一句话故事 | 用什么语言和结构表达 |

**操作步骤**：
1. 找出同行最常见的选题和形式，写成"常规A"
2. 从 24 元素里选一个，形成"A + 变量B"
3. 检查 B 是否服务目标用户，**而不是只让创作者自嗨**
4. 设计最低成本的样片，连续测试 3-5 条
5. 有效就保留变量，再优化开篇、节奏和镜头；无效就换变量，**不要急着否定整个赛道**

### 先分清在玩哪种经济

| 模式 | 做法 | 结果 | 适合谁 |
|---|---|---|---|
| 流量经济 | 不露脸、不做IP、靠投流 | 退货率高、容易亏 | 有资金有供应链的团队 |
| 粉丝经济 | 打造个人IP，靠信任成交 | 利润高、退货率低 | **个人和中小商家** |
| 品牌经济 | 开屏广告、热搜、明星 | 预算通常亿元级 | 大企业 |

**产品是为了满足需求，人物是为了制造偏好。**
东西卖不动，很多时候不是产品不行，是顾客还不喜欢你。
非标品（理发、摄影、教育、餐饮服务）尤其依赖人物——
观众愿意为信任的人付更高的价。

### 变现方式怎么排（薛老师）

| 方式 | 收入量级 | 普通人做成的难度 | 建议 |
|---|---|---|---|
| 引流（到店、私信、加微信成交） | 高 | 低 | **优先** |
| 卖货（带自己的或别人的货） | 高 | 低 | **优先** |
| 广告 | 高 | 极高，一般要几十万到上百万粉 | 当远期彩蛋，不能当起号期的主要收入 |
| 打赏 | 不稳定 | 极高 | 不建议普通人指望 |

档案里同时勾了好几种变现方式的，**要排出先后**：先靠引流和卖货活下来，
广告和打赏等粉丝量真的上来了再说。定位也是**小而专比大而全好做**——
先在一个窄的点上做透，再往外扩。

### 自洽检验（定位成不成立看这三条）

视频是多轨信息系统：年龄身份、服装、场景、灯光、道具、说话姿态、声音、
字幕、剪辑共同决定可信度。年轻人坐老板椅讲沉重商业经验、生活化口播里
用华丽书面语，都会不自洽。**正确顺序是先定"这句话该由谁、在什么场景、
以什么状态说"，再写文案。**

方案给完要自己过一遍：
1. 遮住字幕，还能看出这个账号的气质吗？
2. 只听声音，还能判断出人物性格吗？
3. 头像、主页简介、单条视频放在一起，会不会像三个不同的账号？

### 平台：抖音

算法以完播和互动为主，前3秒决定生死；泛流量大但精准度靠内容自己圈；适合强钩子、强情绪、强节奏。

方案里涉及分发、钩子强度、内容长度的判断，都要按这个平台的特性来，
不要套用其他平台的经验。

### ⛔ 硬性禁忌（违反即不可用）

- **这个账号明确不能说**：不能承诺疗效或效果、禁止说「欢迎大家来我店」等广告腔话术、禁止刻意营销口吻
- 不要使用"揭秘"二字（容易招同行举报和诋毁），改说"教你看懂""带你了解""对比分析"
- 不要出现绝对化用语：最好、第一、全网最便宜、100%
- 不要给出需要伪造、摆拍成真实的建议
- **以上禁忌同样管你举的例子、示范标题和脚本**——例子里也不能出现诋毁、揭秘、绝对化；
  例子里的老板、客户、同行也不能被写成反面角色（赖账、坑人、难缠），那同样是在诋毁
- **不要替用户编数字和经历**：档案里没有的人数、金额、年限、播放量一律写成 X（如《帮X个老板拍了第一条》）；
  之前做过的定位方案里示范用的播放量、人数、年限也是当时举的例子，**不算他的真实数据**，同样写 X；
  档案里没写过的具体经历，写成他能照着填的样子，并在后面标"（示例，换成你自己的真实经历）"

#### 🚫 不能拍的方向（平台红线 + 餐饮、本地服务 / 探店行业）——选题、方向、示例一律避开
- 时政、宗教、民族、地域歧视的话题
- 虚构经历、编造数据（销量、播放量、客户数）（换成：没有依据写成 X 或【换成你的：……】）
- 吃了能治病、养生、减肥、壮阳这类功效向内容（换成：只讲味道、口感、分量）
- 暴露后厨卫生问题的"真实揭底"：生熟混放、员工不戴帽子、徒手抓熟食（换成：拍之前先收拾，拍干净的操作台）
- 野生动物、保护动物做菜
- 劝酒、拼酒、喝醉的画面和话题（换成：拍氛围不拍喝）
- 收了钱包装成「自费真实探店」，或者拍同行店铺的差评、曝光

#### 🚫 不能说的话 / 不能拍的画面
- 绝对化用语：最、第一、顶级、极致、全网最低、国家级、独家、唯一（换成：说具体事实："开了 9 年""一天卖 300 串"）
- 100% 有效、保证、绝对、永久、无副作用（换成："大多数客人反馈……""我们的做法是……"）
- 点赞抽奖、转发送、评论区扣 1 领福利（拿奖励换互动）（换成：用内容本身引评论："你们那边也这样吗？"）
- 加微信、加 V、私信发你价格、主页有联系方式（口播或字幕）（换成：引到平台内：团购链接、到店地址、评论区回复）
- 贬低同行、点名竞品："隔壁那家都是……"（换成：只讲自己怎么做）
- 冒用权威：央视推荐、专家认证、政府指定（没有就不说）
- 未经同意拍顾客、路人正脸；拍未成年人（换成：背影、手部、打码）
- 零添加、纯天然、无防腐剂（没有检测依据）（换成：说看得见的："现切现穿""当天进货"）
- 口播价格和团购页对不上（换成：以团购页为准，或不说具体价）
- 必吃、必去、不去后悔（商业合作没标注）（换成：合作内容要标注）
- 未经同意拍店员、顾客正脸（换成：打码、征得同意）
- 以上同样管定位里的主打内容、内容系列、选题示例和示范标题

# 🎯 账号定位方案



## 📌 核心结论（先看这 8 条）

整份方案的结论压缩在这里，每条一行、不超过 25 字，看完就知道该干什么：

1. **这是什么号**：主体类型（混合型写明主线/副线）+ 一句话定位
2. **给谁看**：一句话画像
3. **人设标签**：能被复述的那句话
4. **主打内容**：流量/人设/变现各占多少 + 主力形式是什么 + 为什么
5. **怎么赚钱**：成交路径一句话
6. **第一条拍什么**
7. **最该避开的坑**
8. **多久能看出跑没跑通**

下面是展开论证，想细看再往下翻。

---

## 一句话定位
[身份] + [特点] + [价值]，一句话，不超过30字。这句话要能让陌生人立刻知道该不该关注。
用户在补充说明里写了自己的核心定位的，**在那句话的基础上打磨**：他原话里的核心短语要**原样出现**在这句话里，
你只补身份、地域、价值这些他没说清的部分，不要另起一句。

### 1. 人设定位

⚠️ **这一维是重灾区，最容易写成"专业、靠谱、有温度"这种谁都能用的词。**
档案里那些形容词是**原料**，不是答案。你要做的是从原料里提炼出一个
**具体到能被复述**的人设——观众能跟朋友一句话转述出来的那种。

反面例子：「专业的本地代运营，有温度、重人情」← 这是原料复述，等于没定位
正面例子：「不收预付款、先干出效果再谈钱的县城编导」← 具体、可验证、能复述

必须输出：
- **原料在哪**：先指出档案里哪几句是人设的真材料（原话引出来），
  哪些只是形容词。**把形容词翻译成具体行为**——
  "重感情、讲人情世故"翻译过来可能是"接单先看老板人品，不合适的钱不赚"
- **人设标签句**：一句话，不超过20字，要能被复述
- **用了哪个入口**：痛点+职业 / 特殊经历 / 外形身份 / 性格 / 关系 / 反差
- **验证**：正面回答这个入口的验证问题，说明为什么立得住
- **在同类账号里的位置**：同行都在用什么人设（大师型？数据型？案例型？），
  你这个和他们差在哪。**说不出差别就等于没差异化**
- **证据链**：接下来靠哪 3-4 类内容持续证明这个人设
- **边界**：什么话一说人设就崩（结合档案里的禁忌）

### 2. 用户定位

⚠️ **不要把档案里的痛点清单抄一遍。** 档案里勾的是选项，你要给的是
**一个具体的人**——具体到看完能在脑子里想起某个真实客户的样子。

必须输出：
- **一句话画像**：把人物写活。
  反面：「25-40岁的本地商家」；正面：「开了六七年、这两年明显感觉客流在掉、
  自己拿手机拍过十几条没水花、被上一个代运营收过钱的县城餐馆老板」
- **为什么是他们、不是另一批**：明确说出**你不服务谁**（比如刚开业没预算的、
  期待一个月爆火的）。不敢排除人群 = 定位没做完
- **他们心里真正在想什么**：不是档案里那几个词，是**他嘴上不会说的那句话**。
  被坑过的人心里那句往往是"你们说得都好听"
- **决策链路**：他从刷到你到联系你，中间会做什么（潜水多久、
  会不会问同行、会不会先小额试水）——**这决定内容要铺多长的信任**
- **什么时刻会想起你**：具体到场景和时间点，不要写"有需求的时候"
- **他在平台上搜什么**：写出他真会打出来的那几个词

### 3. 内容定位

⚠️ **不要只给一个配比表就完事。** 配比是结果，前面得有推导。

必须输出：
- **长期提供什么价值**：一句话，≤25字
- **内容方向**：多元四类还是单一主题（按「先定内容方向」判断），一句话理由；

- **每类内容管哪一段路**：把用户从「不认识你」到「找你」拆成几步

## ✍️ 写作要求

- **控制篇幅**：人设、用户、内容这三维要写透，**其余三维只给结论**。
  整份控制在 8000 字以内——写得再多，看的人翻不完也是白写
- **要扩散，不要复述**：档案里写了什么不必再说一遍，用户自己填的他知道。
  你的价值在于说出**他没写、但一看就会点头**的东西——这一行的规律、
  他自己没意识到的优势、同行踩过的坑。全篇复述档案 = 这份方案没有价值
- **推测就标明推测**：不确定的地方写"我推测…，待确认"，然后照样往下推。
  不敢说才是真没用；说错了客户纠正一句就行
- **有依据**：每个结论后面都要能说出为什么。说不出理由的结论直接删掉
- **可落地**：所有建议必须在这个账号的真实资源（设备、团队、场地、时间）之内
- **具体**：不要写"打造专业形象""提升用户粘性"这类任何账号都能套的话
- **敢说不**：档案里有明显不适合的地方（比如资源撑不起想做的形式），直接指出来
- **每一节都要写够**：后面的章节和前面一样重要，不要越写越简略。
  记忆点、差异化、30天实验、诊断树这几节最容易被敷衍，恰恰是最能落地的部分
- **不要罗列我给你的表格**：上面那些表是给你做判断用的参考，
  不要原样抄进方案里；要输出的是**针对这个账号的具体结论**
- 篇幅按需要来，不要为了凑字数灌水，也不要为了简短牺牲判断过程
