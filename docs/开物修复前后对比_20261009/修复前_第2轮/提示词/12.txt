# 方向拓展：晒节后真实到店客户

这个方向的核心是**用真实客人的存在带动观望者行动**——不是靠促销刺激，而是靠"别人也在买"的社会证明消除"我是第一个冤大头"的担心。能起量是因为它同时满足两类人：装修到后期准备买家具的人看到"节后也有人在挑"会觉得时机合适；已经观望一阵的人看到"别人都开始行动了"会被推一把。

**这个账号做它的最大优势**：6000平六大品类，客流基数大，哪怕节后冷清一天也有两三波客人，每波需求不同（看沙发/配卧室/挑办公桌），天然就是不重复的选题。李国才当过5年教师，会问会讲，接待过程本身就是内容。

**最大短板**：一人全包挤空档拍，没法每个客人都跟拍全程。需要提前和客人打招呼"拍个背影做内容"，部分客人可能不配合。解决办法是只拍愿意配合的那几波，或者事后复盘式配音（"今天上午来了位小伙子……"），用空镜+你的讲述还原场景。

---

### 方向1：按客人预算分档拍——让不同预算的人都觉得"有我这档"

- **对应目的**：拉回观望的人（让他们看到和自己预算匹配的真实案例）

- **为什么能达到目的**：观望的人最大顾虑之一是"不知道我这点钱能不能配齐"。看到你接待一个预算5000的客人，帮他配出客厅三件套，他会觉得"原来5000也能办"，比你喊"全场低价"管用。结合你六大品类全覆盖的优势，通货款、轻奢款、新中式各有价位，天然就有分档素材。

- **核心思路**：每条视频聚焦一个预算档（3000-5000 / 8000-1万 / 2万+ 三档轮着拍），拍你接待这个预算客人的过程，重点是"他说预算多少→你问户型和风格→带他看对应价位的货→报价透明→他的反应"。

- **可拍的选题示例**：
  - 国庆后第一个客人，预算5000想配客厅，我帮他挑了这三件
  - 小两口预算只有8000，问我能不能配齐卧室和客厅
  - 这位老板来配办公室，预算2万，最后选了现代轻奢这套

- **怎么拍**：手机跟拍，客人进店开始录（打码或拍背影），你问预算、问户型、带他走到对应区域、掀开沙发垫讲材质、报价（"沙发X、茶几X、电视柜X，加起来X"）、客人反应（点头/说考虑/直接交定金）。后期配音补全对话和你的判断（"他说预算紧张，我就没带他看美式那边，直接去了通货款性价比高的区域"）。出镜人是你，客人只拍背影侧脸手部。

- **开头示范**："国庆后第一天就有客人来，小伙子说预算只有5000，问我能不能配齐客厅。"

- **看什么数据**：完播率（看观众有没有看完你报价和客人反应）、评论区问预算的人数（"老板我预算X能配吗"这类留言越多说明方向对）、私信量。

- **难度**：中。需要提前和客人沟通"拍个背影做内容"，部分客人不愿意就放弃；需要你记住每波客人的预算和选择，事后配音时讲清楚。一周能拍2-3条（只拍愿意配合的那几波）。

**🅰 打法**
晒过程·火车节：客人进店说预算 → 问户型和需求 → 带到通货区 → 讲材质报价 → 客人反应

**1️⃣ 爆款元素**
- 成本：预算5000,透明报价每件多少钱
- 人群:小两口刚装修完、预算紧张的年轻家庭

**2️⃣ 开篇钩子**
"小伙子进店第一句话,预算只有5000,问我能不能配齐客厅三件套。"

**3️⃣ 内容方向及目的（重中之重!）**
- **核心内容方向**:真实接待一位5000预算客人,从问需求到选货报价到客人反应的完整过程
- **核心问题与观众价值**:5000预算到底能不能在你店里配齐客厅?具体能配什么档次?观望的年轻人最怕"钱不够白跑一趟",看到真实案例会消除顾虑
- **取材与内容推进**:
  1. 等一位愿意配合拍摄的3000-5000预算客人进店(拍背影或打码)
  2. 客人说完预算后,你问"户型多大?喜欢什么风格?"(现场收声)
  3. 带客人走到通货区,边走边说"你这个预算我带你看性价比高的这边"
  4. 到沙发前掀开坐垫,讲材质"这个是XX填充,坐感怎么样"
  5. 报价环节:沙发X元、茶几X元、电视柜X元,加起来X元(拍客人手部或侧脸反应)
  6. 后期配音补全对话和你的判断:"他说预算紧,我就没带他去美式那边"
- **事实边界**:需现场等真实客人并征得同意;客人预算、户型、反应都用现场实际情况,不编造;报价用店内真实标价
- **关键画面(3个)**:
  1. 客人进门你问"预算大概多少"(拍背影,收声)
  2. 你掀开沙发垫讲填充材质(手部特写+你的讲解)
  3. 你报完价客人点头或说"考虑一下"(拍侧脸或手部)
- **场景设置**:店内通货区,自然光+店内照明,手机跟拍

**4️⃣ 脚本结构**
晒过程·火车节:
- 起因(带钩子):客人进店说预算5000,想配客厅
- 关键步骤1:你问户型和风格,判断需求
- 转场:带客人走向通货区(边走边说为什么选这个区域)
- 关键步骤2:到沙发前讲材质,掀坐垫给他看
- 转场:走到茶几和电视柜
- 关键步骤3:报价透明(每件单价+总价)
- 结果:客人反应(点头/说考虑/问能不能再便宜)+你的后期配音总结

**5️⃣ 结尾行动指令**
"你的预算能配什么,私信发我户型和预算,我帮你看。"

**6️⃣ 执行要点**
- 提前准备话术:客人进门就自然问预算和户型,别僵硬
- 征得拍摄同意:跟客人说"拍个背影做内容,不拍脸",不愿意就放弃这波
- 收声关键:你的问题和报价要说清楚,客人回答收全
- 一人操作:手机稳定器跟拍,或找角度架手机录一段,事后配音补全
- 时长控制:完整流程2-3分钟,后期剪掉重复和等待的部分
- 注意:报的价格必须是店内真实标价,客人反应用真实的,不摆拍夸张表情

**7️⃣ 成交理由**
- **体现的理由**:实在不坑(报价透明)、性价比(5000能配齐)、服务好(帮着挑不嫌预算少)
- **转化路径**:看到真实接待 → 评论"我也这预算" → 私信发户型 → 到店
