# 开物创作原意承接修复验收

日期：2026-10-07。范围：产品现有的创作跳转、自动填表、作品刷新恢复、历史及收藏再取用。保留原来的界面风格和内容方法论。

## 承接规则

1. 用户这次明确修改的要求优先，其次是同一条内容已保存的目的、方向、人群、结构与限制。
2. AI 输出标签仅用于补缺，页面默认选项、通用档案和行业配比不能覆盖用户原意。
3. 每次跳转独立保存原始要求、当前方案、最新执行稿及生成设置；选新方案与仅改标题/开头分开处理。
4. 历史、收藏、刷新和自动资料修正都参与同一条承接链，不能仅靠正文猜目的。
5. 这些规则保证传递和优先级，不代表模型每次都完全服从、事实完全可靠。

## 发现的问题及修复

| 原因 | 使用后果 | 已落实的修复 |
| --- | --- | --- |
| 二创/选题成稿标签覆盖生成时用户选择 | 大众流量、人设稿跳走后被当成变现广告 | 保存的用户目的、人群、方向优先；AI 标签补缺，不覆盖明确选择 |
| 无完整根稿，只带短摘要 | 原稿尾部限制、最新改动和写作人群丢失 | 独立携带完整材料及原意；表单摘要与模型完整上下文分开 |
| 定位、成交理由、简报、创作方向未完整保存承接设置 | 中间绕一次运营板块后，下一次重新决定创作目标 | 给这些页面补齐输入、生成请求、历史保存和输出的完整承接链 |
| 默认目的、默认教知识模板被当成用户已选 | 自动接管把讨论写成教程，或把人设改成促销 | 默认目的不锁定；未指定脚本类型时按原意自动决策，手动选择仍优先 |
| 混合目的只认第一个 | 人设+变现只剩单一目的 | 保存完整混合目的，不强归成单一标签 |
| 选择方案2仍继承方案1题目和旧执行稿 | 选中的方案被另一份内容替换 | 明确选择优先，清除跨方案旧执行稿；另存分支；原来的目的和限制保留 |
| 标题/开篇和新方案用了同一种选择清理 | 只带标题去审稿，完整脚本丢失 | 局部修改保留完整稿；新方案分支清旧稿；收藏后继续也保留这一区别 |
| 标题页跳走时又套用了旧开头 | 改标题顺带改坏正文 | 只有实际开篇修改才替换开头 |
| 历史输出使用当前编辑器的根稿 | 旧记录A混上正在编辑的B | 按对应结果查其生成时输入，缺失时不混用当前另一条根稿 |
| 数据库 RPC 合并旧设置 | 清掉的旧目的/旧脚本刷新后复活 | 持久化显式空值，阻止旧值合并复活；读取仍使用设置白名单 |
| 刷新恢复把跳转前旧历史放到最新用户选择上面 | 刚选择的新目的、当前稿被旧版本盖掉 | 记录跳转时间，跳转前历史不能覆盖这次选择；之后的新生成可更新设置 |
| 收藏及全部产出只拿正文 | 再取用丢失原意、人群和设置 | 一并保存、读取生成时原意和设置；保持账号隔离 |
| 后续聊天要求未纳入连续原意 | 多轮明确修改到下一板块失效 | 后续用户要求随上下文保留，明确修改优先 |
| 正文目的正确，但后续建议偷换成卖课漏斗 | 用户“不卖课”只在正文临时生效 | 原意约束扩展至整篇输出、结尾和后续建议 |

## 尚存的质量限制

模型抽测仍有未提供依据的收入/房租数字、第一人称经历或观察场景，模型自称“没有虚构”不能当验收证据。这属于成稿事实依据问题；本次不能据此宣称所有输出质量已经完全达标。已加强原意与事实边界指令，现有资料核对和修正机制仍需使用。

旧记录如果当时没有存原始想法和设置，不能凭空恢复最初意图。新记录及可查到生成输入的旧历史会按其对应版本承接；完全缺失来源的旧收藏只能以已保存正文为依据，不混入正在编辑的另一条内容。

本次扫描覆盖产品实际提供的创作去向。知识库、素材库作为内容来源参与；前采录入、会员、账户等非成稿操作页面不按生成结果接续目标处理。

### 资料修正链二次发现并修复

实际页面验收还发现：自动资料修正把「县城返乡」误报为地名，再把返乡主题替换成「这个选择」。这直接影响具体主题的承接，因此已追加修复：核对来源加入用户明确主题、人群、行业、方向和完整原意；修正上下文先放本条要求，再放通用账号背景；修正上下文上限从4000扩展至20000字；普通词「县城、返乡、评论区」不当成具体地名，同时保留郑州市、南乐县等真实地名核对。AI 执行稿不作为事实证明。

新增3项回归覆盖上述误判、修正中的用户原意优先、长原始材料。最终2960项测试全部通过，TypeScript检查通过。未据此把一般模型事实可靠性判为通过。

### 刷新实测追加修复

页面实测发现作品显示标题「方案2：返乡选择」与实际主题「返乡选择」不同。脚本页误判为用户换题，把新稿保存进另一作品，地址仍指向旧作品，刷新后返回旧稿。修复：恢复时以承接的实际主题作为换题判断基线，显示标题不参与判断；真正换题并保存到新作品后，同步更新当前作品地址。新增对应版本与作品归属回归，全量最终2961项全部通过。
