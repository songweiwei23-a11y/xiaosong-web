2. 二创：保留并验收强制使用当前档案行业、经营品类的提示词和界面；有档案时取消另选行业来源。拆解素材仍可来自其他行业。
3. 成交理由：按档案预填、恢复、保存和合并卖点；生成请求携带实际档案编号。保存后通知已经挂载的上下文使用方刷新，不再只清缓存。
4. 历史：脚本、选题、分镜、审稿、标题、知识库、起号、开篇、拆解和二创按当前档案读取；服务端先过滤档案再限制条数。兼容历史输入中的 `profileId` 与 `profile_id`。全局历史页面仍可读取全部记录。
5. 保存：各生成入口记录生成时的档案；通用保存函数在异步读取登录状态前固定归属。生成期间切换档案不会把迟到的结果写到新档案界面，也不会用旧的历史刷新回调覆盖新档案。
6. 上下文：旧请求不回写新档案或重新填充已失效缓存；同一次档案切换只清缓存一次，保留并发请求合并。
7. 自由对话：背景与当前档案同步，对话列表按档案读取；增加未关联档案旧对话的查阅入口。旧对话保留为查阅状态，不自动认领到当前档案。
8. 测试：修复只识别单引号或旧函数写法的扫描检查，增加历史接口过滤与异步保存归属测试。
