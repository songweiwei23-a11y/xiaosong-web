# 开物首页宣传预览

本地预览地址：<http://127.0.0.1:3001/preview/landing>。

这次新增独立预览页面，未覆盖正式首页，未同步生产服务器。内容与交互使用预置样例，不调用生成、注册、支付或业务保存接口。预览顶部有明确标记，并提供当前正式首页的对照链接。

## 本次展示重点

- 首屏保留“一句话介绍自己的行业”，可切换六个行业样例。
- 四项产品优势：客户档案带入创作、编导方法可选、拆解接跨行业二创、成果按档案积累。
- 交互工作台展示档案、选题、口播脚本、镜头表与历史；选题可接脚本，历史可打开旧稿。
- 历史演示同时包括拆解爆款报告、跨行业二创方案，展示正文与设置的恢复形式。
- 二创演示提供现有的 11 个借用层次，可选择并查看方向示例。
- 展示实际存在的 100 条公式与句式、19 种脚本结构、17 个创作板块、153 篇资料与 5 个专题知识库。
- 套餐价格和额度取自项目现有配置，说明免费额度一次性、部分板块共享额度与人工核对开通流程。
- FAQ 说明实际产出、客户档案、视频分析前 3 分钟、历史保留与近期创作参考。

未使用未经验证的效果提升比例、成本节省比例、销量、人气、播放量或“秒级完成”承诺。

## 本地重启方法

当前预览服务正在运行。如果电脑重启或服务关闭，在项目目录执行：

```powershell
powershell -NoProfile -File .\scripts\preview-landing.ps1
```

脚本只启动绑定 `127.0.0.1:3001` 的本地服务；如果端口已被占用，不会结束其他进程。出现 `Ready` 后打开上面的地址。只在这台电脑可以访问，未对外发布。
