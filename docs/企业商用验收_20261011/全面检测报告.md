验收标准：`docs/企业商用验收标准_20261011/验收标准.md`。本报告只找问题，不改代码。

## 一、检测范围与方法

- **数据来源**：同一用户名下的 5 个档案的线上生成记录（真实输出，非新生成）。
  - 锦园地摊串串一元火锅（71 条）
  - 万客隆家具城·李国才（64 条）
  - 实体获客编导-不一（28 条）
  - 测试_青禾家具店_全板块验收（22 条）
  - 小张工作号·濮阳本地找工作服务（16 条）
- **另有 103 条记录没有档案 ID，无法归属到任何档案**，单独计数，不计入通过率。
- **检测方法**：
  1. 确定性扫描：绝对化用语、平台敏感词、内部泄漏词、截断、占位；
  2. 出处比对：每个档案用它自己的档案、定位、简报、访谈做比对；
  3. 人工复核：命中项读原文上下文确认，误报不计入结论。
- **覆盖板块**：19 类（18 个创作板块 + 自由对话），每个档案每板块取最近 5 条。
- **局限**：没有新生成样本，结论基于线上历史输出；人工复核是抽样复核，不是逐条；单人判断，没有双人复核。

## 五、确认的问题（按严重程度）

### P1 内部提示词泄漏到交付物（确认）

- 审稿优化（2026-10-11）：「作为审稿校对编辑，对照原稿与个人要求…」「根据本轮校对指令：‘审稿结果里没有材料依据的…’」「**按本轮校对要求的修正**：」。提示词原文直接进了交付稿，观众或编导看到的是系统指令。
- 脚本生成（2026-10-11）：标题为「【本轮内容落实规则确认】」「【本轮内容落实规则】」。
- 选题与分镜：「✅ 创作自检」「节奏自检」「【价值点应用自检】」。

这是最不可接受的一类：内部指令外露，等于把系统内部交给了企业客户。

### P2 编造事实（确认，面向观众板块）

- **客人原话与情节**：「昨天一桌客人说，冬天在地摊吃火锅」（脚本）；「客户说‘比预期还满意’」（脚本）；「有个客人说你们家火锅没海底捞好，…成了每周来三次的老客」（选题，已在上一轮报告记录）。
- **个人作息与经营做法**：「今天早上六点去市场」「早上六点从批发市场拉回来的鲜毛肚」（分镜、二创）；「我早上五点熬的牛油底料」（脚本）。
- **时令错配**：2026-10-11 是秋季，但脚本与选题里出现「冬天在地摊吃火锅」这类客人反应。时令锚点只修了创作方向，脚本与选题仍会沿用档案里的冬季内容。

### P3 断言式用语（确认，部分有争议）

- 面向观众的文案中：「没人告诉你怎么点最划算」（开篇）、「我告诉你怎么点最划算」（二创）、「今天什么最新鲜」（脚本、二创）、「入秋必吃必体验清单」（创作方向）。
- 这些是广告法里「最」「必」类断言的典型形式，企业客户直接发布会有合规风险。
- 有争议：「最划算」「最新鲜」是描述性的，不如「最正宗」「最好吃」明确；按企业标准，应统一改写。

### P4 平台敏感与站外引流（确认，数量少）

- 「加微信」作为客户行为出现在开篇与选题中（2026-10-06 记录，如「每桌客人都加微信」）。这是对运营动作的描述，不是行动指令，但在面向观众的文案里仍需避免。
- 「揭秘」「内幕揭秘」作为选题或开篇的类别标签（2026-10-09、10-01）；平台规则禁用此词。

### P5 档案隔离与数据治理（确认，产品问题）

- **103 条生成记录没有档案 ID**，无法归属。按产品设计，记忆按档案隔离，没有档案 ID 的记录会落到共享的「default」范围，存在串档风险。
- **同一用户下 5 个档案，业务跨度大**（家具、找工作、地摊火锅、实体获客）。一个档案的数据不应被另一个档案读取，这一点需要在产品层面确认隔离是否真的生效。
- **测试档案混在生产库里**（「测试_青禾家具店_全板块验收」），需要区分。

### P6 同一账号的时令与事实一致性（确认，部分）

- 同一档案的历史输出之间存在矛盾，例如「冬天」与「秋天」的时令、「老板」与「师傅」的出镜人。这说明档案的事实没有被统一约束到每一个板块。

## 六、误报与已排除

- E1 自动扫描的「第一」「最新」「最后」多为「第一招」「最后」这类非断言用法，已排除。
- 「加微信」「私信」在否定语境中（如「不在评论区引导加微信」）已排除。
- 「最强情绪波点」「最好在傍晚拍」是标注或拍摄建议，不是广告用语，已排除。
- E3 自动扫描中大量「顾客见证」是拍摄指令（「如果客人同意出镜说话」），不是客人证言，已排除。

## 七、没有覆盖的

- 没有新生成样本，所有结论基于线上历史输出；当前版本的表现可能已经好转（例如开篇人称、创作方向季节已修复），需要新生成复测。
- 103 条无法归属的记录未计入通过率，它们的质量未知。
- 自由对话只取了每个档案最近 2 条助手回复，样本偏小。

## 八、结论与建议（待你确认后再做）

**结论**：按企业商用标准，开物当前不可交付给企业客户直接使用。最严重的是内部提示词泄漏（P1）和编造事实（P2），这两类在面向观众的板块中都有发生。标题封面是唯一全部通过的板块，说明在约束清晰的单一任务上，系统能稳定输出合格内容。

**建议的优先级**：

1. **P1 内部泄漏**：在返回前统一剥离提示词痕迹与自检块，并加一条服务端检测，发现即拦截，不交付。
2. **P2 编造事实**：把出处检查扩展到客人原话、个人作息、经营做法，并在面向观众的板块启用生成后的自动修正（当前只有画布任务启用）。
3. **P3 断言用语**：把「最划算」「最新鲜」「必吃」等加入禁用词，面向观众的文案统一改写。
4. **P5 档案隔离**：确认记忆与历史按档案真正隔离；为无档案 ID 的记录补齐归属或停止写入；测试档案与生产档案分开。
5. **P6 时令与事实统一**：把时令锚点与档案关键事实统一注入全部板块，不只是创作方向。

每一条修复都需要用新生成的样本复测后，才能判定是否达到商用标准。
