# 选题策划页面优化方案

## 📊 当前版本功能清单（已稳定）

### ✅ 已有功能
1. **账号基础信息**

   - 3个自定义关键词输入框

5. **高级设置**
   - 竞品账号参考
   - 爆款案例参考
   - 生成数量（5/10/15/20）
   - 创意难度（3选1）
   - 开头钩子（开关）

6. **成交理由**
   - 17个成交理由（已定义但未完全集成到UI）

7. **AI智能推荐**
   - 根据账号阶段推荐风格
   - 根据账号阶段推荐难度

1. **模式切换**：快速模式 vs 自定义模式
2. **档案选择**：无法选择已保存的个人档案
3. **定位选择**：无法选择已保存的账号定位
4. **成交理由UI**：17个成交理由未在UI中完整展示
5. **选题类型判断**：未明确区分"变现选题"和"大流量选题"

## 🎯 用户需求分析

### 核心需求
1. **双模式切换**
   - 快速模式：选择档案+定位 → 自动填充所有字段
   - 自定义模式：保持当前手动填写方式

2. **档案+定位集成**
   - 从已保存的档案中选择
   - 从已保存的定位中选择
   - 快速模式下自动填充相关字段

3. **成交理由完整集成**
   - UI中完整展示17个成交理由（可多选）
   - 选择成交理由 = 变现选题
   - 不选成交理由 = 大流量选题

4. **高可玩性**
   - 自定义度高：每个选项都可以自定义输入
   - 质量高：结合档案+定位+成交理由生成精准选题

5. **UI优化**
   - 统一橙色系配色
   - 卡片化布局
   - 使用折叠面板优化长表单

## 🏗️ 技术架构分析

### API接口
- `/api/profiles` - 获取个人档案列表
- `/api/positionings` - 获取账号定位列表
- `/api/dify/stream` - 生成选题（POST）

### 数据流
```
用户选择 → 构建prompt → 发送到Dify API → 流式返回结果 → 展示
```

### 关键数据结构
```typescript
// 档案数据
interface Profile {
  id: string;
  industry: string;
  positioning: string;
  style: string;
  targetAudience: string;
  priceRange: string;
  city: string;
}

// 定位数据
interface Positioning {
  id: string;
  title: string;
  industry: string;

// 选题API请求
{
  mode: "quick" | "custom",

  profileInfo: string, // JSON字符串
  positioningInfo: string, // JSON字符串
  dealReasons: string[], // 成交理由ID数组
  // ... 其他字段
```

```typescript
const [mode, setMode] = useState<"quick" | "custom">("custom");

const [selectedPositioning, setSelectedPositioning] = useState<Positioning | null>(null);
const [profiles, setProfiles] = useState<Profile[]>([]);
const [positionings, setPositionings] = useState<Positioning[]>([]);
```

### Step 2: 加载档案和定位数据
```typescript
useEffect(() => {
  loadProfiles();
  loadPositionings();
}, []);

const loadProfiles = async () => {
  const res = await fetch('/api/profiles');
  const data = await res.json();
  setProfiles(data.profiles || []);
};

const loadPositionings = async () => {
  const res = await fetch('/api/positionings');
  const data = await res.json();
  setPositionings(data.positionings || []);
};
```

```typescript
const handleProfileSelect = (profile: Profile) => {
```
