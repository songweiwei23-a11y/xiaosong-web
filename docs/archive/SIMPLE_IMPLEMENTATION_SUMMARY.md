# ✅ 脚本类型约束功能实现总结（简化版）

## 📦 实现内容

### 1. 核心功能
- ✅ 保持原有的8种内容类型（教知识型、晒过程型、聊观点型、讲故事型、测评型、探店型、剧情型、混剪型）
- ✅ 添加脚本类型分配算法
- ✅ 优化流量型和变现型提示词

### 2. 工作原理

**用户操作：**
1. 在"内容类型"中选择1-3种脚本类型
2. 选择是否为变现选题（选成交理由）
3. 点击生成

**系统处理：**
- 如果用户选择了2个内容类型，生成10条选题
- 系统自动分配：5条类型A + 5条类型B
- 提示词中强制要求按此分配

**示例：**
- 选择：教知识型 + 晒过程型
- 生成10条选题
- 结果：5条教知识型 + 5条晒过程型

### 3. 提示词优化

**大流量选题（不选成交理由）：**
\\\
⚠️ 这是【大流量选题】，目标是涨粉和曝光！
- 核心手段：使用八大爆款元素（成本、反差、荷尔蒙、猎奇等）
- 内容特征：话题性强、容易引发讨论、追热点、做对比
- 示例：《20块的肥牛vs200块的差在哪》
\\\

**变现选题（选择成交理由）：**
\\\
⚠️ 这是【变现选题】，目标是获客转化和到店成交！
- 核心手段：围绕选中的成交理由
- 三词根公式：人群词根 × 场景词根 × 行业词根 = 变现选题
- 必须明确转化路径：观看→互动→到店/购买
- 示例：《带孩子吃烤肉,排酸牛肉是空运的》（质量好）
\\\

**脚本类型与流量/变现的关系：**
\\\
💡 【关键】
- 脚本类型 = 视频结构（怎么讲故事）
- 流量/变现 = 内容方向（讲什么内容）
- 同一脚本类型可同时服务于流量型和变现型

例如教知识型：
  · 流量用爆款元素：《20块vs200块的肥牛差在哪》
  · 变现用成交理由：《排酸牛肉怎么看好坏？老板教你3招》
\\\
