# ✅ 选题摘要功能 - 用户可见版本

## 🎯 新增功能

现在用户可以在账号定位工作台中：
1. ✅ 看到定位方案有**两个版本**
2. ✅ 随时切换查看**完整版**或**选题摘要**
3. ✅ 选题摘要可供选题策划和脚本策划使用

---

## 📋 功能详情

### 1️⃣ 保存时的提示

当用户生成并保存账号定位后，会看到：

\\\
✅ 定位方案已保存！

📄 完整版：包含所有战略、策略、执行细节
📋 选题摘要：已自动生成，供选题策划和脚本策划使用
\\\

### 2️⃣ 历史记录中的操作按钮

每个定位方案卡片上有三个按钮：

\\\
┌─────────────────────────────┐
│ 烤肉店老板账号定位          │
│ 2026-01-15                  │
│                             │
│ [💬] [✨] [🗑️]             │
│  ↑     ↑     ↑              │
│  持续  查看  删除            │
│  对话  摘要                  │
└─────────────────────────────┘
\\\

- 💬 **持续对话**：基于这个定位继续优化
- ✨ **查看选题摘要**：显示选题专用的干净版本
- 🗑️ **删除**：删除这个定位方案

### 3️⃣ 右侧展示区的版本切换

查看定位方案时，顶部有两个切换按钮：

\\\
┌────────────────────────────────────────┐
│ 🎯 烤肉店老板账号定位                  │
│                                        │
│ [📄 完整版] [📋 选题摘要]              │
│    (蓝色)      (灰色)                  │
│                                        │
│ （显示内容）                           │
└────────────────────────────────────────┘
\\\

点击切换按钮：
- **📄 完整版**：显示所有内容（战略+策略+执行）
- **📋 选题摘要**：只显示战略层信息

## 💡 使用场景

### 场景1：查看完整方案
用户想了解账号的整体规划：
1. 点击历史记录中的定位方案
2. 默认显示**完整版**
3. 可以看到所有战略、策略、执行细节

### 场景2：查看选题摘要
用户想知道这个定位适合什么选题方向：
1. 点击历史记录中的 ✨ **查看选题摘要**按钮
2. 或者在查看时点击顶部的 📋 **选题摘要**按钮
3. 只显示战略层信息，更清晰

### 场景3：选题策划使用
当用户在选题策划工作台选择定位时：
1. 系统**自动使用选题摘要**
2. 传给Dify的是干净的战略信息
3. 不会被"流量型60%"等配比误导

### 场景4：脚本策划使用（未来）
当你编写脚本策划功能时：
1. 也可以使用 \strategy_summary\ 字段
2. 避免把执行细节传给AI
3. 让AI专注于当前的脚本创作

## 🔧 技术实现

### 新增State
\\\	ypescript
const [viewMode, setViewMode] = useState<'full' | 'summary'>('full');
\\\

### 新增函数
\\\	ypescript
// 查看选题摘要
const viewSummary = (positioning: Positioning, e: React.MouseEvent) => {
  e.stopPropagation()
  if (positioning.strategy_summary) {
    setResult(positioning.strategy_summary)
    setViewMode('summary')
  } else {
    // 兼容旧数据：实时生成
    const summary = extractStrategySummary(positioning.full_content)
    setResult(summary)
    setViewMode('summary')
  }
  setSelectedPositioning(positioning)
}
\\\

1. **历史记录按钮**：Sparkles图标，蓝色主题
2. **版本切换按钮**：完整版（蓝色）vs 选题摘要（紫色）
3. **保存提示**：Alert说明两个版本的用途
