【方式一：双击启动】（推荐新手）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第 1 步：打开项目文件夹
  1. 按键盘 Win键 + E（打开文件管理器）
  2. 在地址栏输入：
     C:\Users\30430\Desktop\编导知识大全\小宋\xiaosong-web
  3. 按回车

第 2 步：找到启动文件
  找到文件：start-dev.ps1
  （图标是蓝色的，像个卷轴）

第 3 步：运行它
  右键点击 start-dev.ps1
  选择："使用 PowerShell 运行"
  
  ⚠️ 如果没有这个选项，选择："打开方式" → "Windows PowerShell"

第 4 步：等待启动
  会弹出一个黑色窗口，显示：
  
    ▲ Next.js 14.2.5
    - Local:    http://localhost:3000
    ✓ Ready in 3.2s
  
  看到这个就成功了！✅

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【方式二：手动启动】（如果方式一不行）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

第 1 步：打开 PowerShell
  按键盘：Win键 + X
  选择："Windows PowerShell" 或 "终端"

第 2 步：进入项目文件夹
  输入（可以直接复制）：
  
  cd "C:\Users\30430\Desktop\编导知识大全\小宋\xiaosong-web"
  
  按回车

第 3 步：启动服务器
  输入：
  
  npm run dev
  
  按回车

第 4 步：等待启动
  看到这些就成功了：
  
    ▲ Next.js 14.2.5
    - Local:    http://localhost:3000
    ✓ Ready in 3.2s

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

看到黑色窗口显示：

  ▲ Next.js 14.2.5

  ✓ Compiled successfully

这就是成功了！✅

         关闭了服务器就停了

【常见问题】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q1: 提示"找不到 node"？
A:  关闭窗口，重新打开一个新的 PowerShell 窗口

Q2: 提示"端口被占用"？
A:  换个端口：npm run dev -- -p 3001
    然后访问 http://localhost:3001

Q3: 窗口一闪就关了？
A:  用方式二，在 PowerShell 里手动输入命令

Q4: 提示权限错误？
A:  右键 PowerShell，选择"以管理员身份运行"

Q5: 页面打不开？
A:  1. 确认黑色窗口还开着
    2. 确认看到 "Ready in 3.2s"
    3. 重新输入地址：http://localhost:3000

【停止服务器】
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

不用的时候，在黑色窗口按：Ctrl + C
然后关闭窗口就可以了
