## ⚡ 性能优化策略

### 1. 数据库查询优化

#### 当前问题
```typescript
// ❌ 慢：每次都查询多个表
const profile = await supabase.from('user_profiles').select('*');
const quota = await supabase.from('user_quotas').select('*');
const subscription = await supabase.from('subscriptions').select('*');
```

#### 优化方案
```typescript
// ✅ 快：使用单次JOIN查询
const { data } = await supabase
  .from('user_profiles')
  .select(`
    *,
    user_quotas(*),
    subscriptions(*)
  `)
  .eq('user_id', userId)
  .single();
```

**性能提升**: 3次请求 → 1次请求（快3倍）

---

### 2. 缓存策略

#### 浏览器本地缓存
```typescript
// ✅ 缓存用户基本信息（5分钟有效）
const cacheKey = `user_data_${userId}`;
const cached = localStorage.getItem(cacheKey);
const cacheTime = localStorage.getItem(`${cacheKey}_time`);

if (cached && Date.now() - parseInt(cacheTime) < 300000) {
  // 使用缓存，立即显示
  setUserData(JSON.parse(cached));
  setLoading(false);
  // 后台刷新
  fetchUserData().then(data => {
    localStorage.setItem(cacheKey, JSON.stringify(data));
    localStorage.setItem(`${cacheKey}_time`, Date.now().toString());
  });
} else {
  // 缓存过期，重新加载
  const data = await fetchUserData();
  localStorage.setItem(cacheKey, JSON.stringify(data));
  localStorage.setItem(`${cacheKey}_time`, Date.now().toString());
}
```

**性能提升**: 0ms（使用缓存） vs 500ms（网络请求）

### 3. 并行加载

#### 当前问题
```typescript
// ❌ 慢：串行加载
await checkSession();      // 100ms
await loadProfile();       // 200ms
await loadQuota();         // 200ms
await loadSubscription();  // 200ms
// 总计: 700ms
```

#### 优化方案
```typescript
// ✅ 快：并行加载
const [session, profile, quota, subscription] = await Promise.all([
  checkSession(),
  loadProfile(),
  loadQuota(),
  loadSubscription()
]);
// 总计: 200ms（最慢的那个）
```

**性能提升**: 700ms → 200ms（快3.5倍）

## 🎨 加载动画使用原则

### 何时显示加载动画

1. **必须显示**（>300ms）
   - 页面首次加载
   - 数据库查询
   - API调用

2. **可以显示**（100-300ms）
   - 页面切换
   - 表单提交

3. **不应显示**（<100ms）
   - 本地计算
   - 缓存读取
   - UI交互

### 加载动画时长控制

```typescript
// ✅ 设置最小显示时间（避免闪烁）
const MIN_LOADING_TIME = 300; // 毫秒

const startTime = Date.now();
setLoading(true);

const data = await fetchData();

const elapsed = Date.now() - startTime;
if (elapsed < MIN_LOADING_TIME) {
  await new Promise(resolve => 
    setTimeout(resolve, MIN_LOADING_TIME - elapsed)
  );
}

setLoading(false);
```

**原理**: 如果加载太快（<300ms），用户会看到动画闪一下，体验不好。保持最小300ms让动画完整显示。

## 📊 性能监控

### 添加性能监控代码

```typescript
// 在关键操作中添加性能监控
const startTime = performance.now();

await loadUserData();

const endTime = performance.now();
console.log(`⚡ 加载用户数据耗时: ${(endTime - startTime).toFixed(2)}ms`);

// 如果超过阈值，记录警告
if (endTime - startTime > 1000) {
  console.warn('⚠️ 加载时间过长，需要优化');
}
```

### 性能指标

监控以下指标：
- **TTFB** (Time To First Byte): < 200ms
- **FCP** (First Contentful Paint): < 1s
- **LCP** (Largest Contentful Paint): < 2.5s
- **TTI** (Time To Interactive): < 3s
