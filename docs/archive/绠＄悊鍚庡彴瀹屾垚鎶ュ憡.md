### 2. 配额检查系统（100%完成）

#### 核心逻辑
```javascript
每次生成前 → 检查配额 → 扣减次数 → 允许/拒绝生成
```

#### 会员配额规则
| 会员等级 | 月价格 | 配额限制 |
|---------|--------|----------|
| 免费版 | 0元 | 定位1次、选题3次、脚本20次、对话20次 |
| 基础版 | 30元/月 | 所有功能150次/月 |
| 专业版 | 99元/月 | 所有功能500次/月 |
| 企业版 | 199元/月 | 无限使用 |

#### 功能映射
- `script` → 脚本生成
- `topic` → 选题策划
- `positioning` → 账号定位（免费版1次永久）
- `freeChat` → 自由对话
- `storyboard` → 分镜脚本
- `review` → 审稿优化
- `title` → 标题封面
- `dealReason` → 成交理由
