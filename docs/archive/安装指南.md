## 下一步：安装 Node.js 和依赖

### 第1步：安装 Node.js（必需）

**重要提示：Node.js 尚未安装，这是运行项目的前提！**

1. **下载 Node.js**
   - 访问：https://nodejs.org/zh-cn
   - 选择：LTS 版本（推荐 v20.x）
   - 下载：Windows 安装包 (.msi)

2. **安装 Node.js**
   - 运行下载的 .msi 安装包
   - 保持所有默认选项
   - 等待安装完成（约2-3分钟）

3. **验证安装**
   - 打开新的 PowerShell 窗口（必须是新窗口！）
   - 运行：
   ```powershell
   node --version
   npm --version
   ```
   - 应该看到版本号，如 v20.11.0 和 10.2.4

### 第2步：安装项目依赖

**在安装完 Node.js 后，在新的 PowerShell 中运行：**

```powershell
# 进入项目目录
cd "C:\Users\30430\Desktop\编导知识大全\小宋\xiaosong-web"

# 安装依赖（可能需要 5-10 分钟）
npm install

# 如果安装很慢，可以使用国内镜像：
npm config set registry https://registry.npmmirror.com
npm install
```

### 第3步：配置 Dify API 密钥

编辑 `.env.local` 文件：

```env
DIFY_API_KEY=app-你的真实密钥
DIFY_API_URL=https://api.dify.ai/v1
NEXT_PUBLIC_APP_NAME=小宋编导工作台
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

**如何获取 Dify API 密钥：**
1. 登录 https://dify.ai
2. 进入你的工作台
3. 点击「设置」→「API 密钥」
4. 创建或复制现有密钥

### 第4步：启动开发服务器

```powershell
npm run dev
```

浏览器会自动打开 http://localhost:3000

## 常见问题解决

### Q1: 找不到 node 命令
**解决方案：**
- 关闭当前 PowerShell 窗口
- 打开新的 PowerShell 窗口
- 重新验证安装

### Q2: npm install 报错
**解决方案：**
```powershell
# 清除缓存
npm cache clean --force

# 使用管理员权限运行 PowerShell
# 右键 PowerShell → 以管理员身份运行

# 重新安装
npm install
```

### Q3: 端口 3000 被占用
**解决方案：**
```powershell
npm run dev -- -p 3001
```
然后访问 http://localhost:3001

### Q4: API 调用失败
**解决方案：**
1. 检查 `.env.local` 中的 `DIFY_API_KEY` 是否正确
2. 确认 Dify 工作台已发布
3. 查看浏览器控制台（F12）的错误信息

### Q5: 页面空白或报错
**解决方案：**
1. 检查浏览器控制台（F12）
2. 查看终端的错误信息
3. 确认所有依赖都已安装完成
