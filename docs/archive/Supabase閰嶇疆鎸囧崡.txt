║                                                           ║
║  📋 下一步：配置 Supabase（5分钟）                        ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  第 1 步：注册 Supabase 账号                              ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  1. 打开浏览器，访问：                                    ║
║     https://supabase.com                                  ║
║                                                           ║
║  2. 点击右上角「Start your project」或「Sign up」        ║
║                                                           ║
║  3. 选择注册方式：                                        ║
║     • GitHub 账号（推荐，最快）                           ║
║     • 邮箱注册                                            ║
║                                                           ║
║  4. 完成注册并登录                                        ║
║                                                           ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  第 2 步：创建新项目                                      ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  1. 登录后，点击「New Project」                           ║
║                                                           ║
║  2. 填写项目信息：                                        ║
║     • Name: xiaosong-web                                  ║
║     • Database Password: 设置一个密码（记住它！）         ║
║     • Region: Northeast Asia (Seoul) - 最接近国内         ║
║                                                           ║
║  3. 点击「Create new project」                            ║
║                                                           ║
║  4. 等待项目创建（约 1-2 分钟）                           ║
║                                                           ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  第 3 步：获取 API 密钥                                   ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  1. 项目创建完成后，点击左侧「Settings」图标             ║
║                                                           ║
║  2. 点击「API」                                           ║
║                                                           ║
║  3. 你会看到三个重要信息：                                ║
║                                                           ║
║     【Project URL】                                       ║
║     https://xxxxx.supabase.co                             ║
║     ↑ 复制这个 URL                                        ║
║                                                           ║
║     【anon public】（在 Project API keys 下）             ║
║     eyJhbGc...很长的字符串...                             ║
║     ↑ 复制这个 Key                                        ║
║                                                           ║
║     【service_role】（在 Project API keys 下）            ║
║     eyJhbGc...另一个很长的字符串...                       ║
║     ↑ 复制这个 Key                                        ║
║                                                           ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  第 4 步：配置到项目                                      ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  1. 打开文件：.env.local                                  ║
║                                                           ║
║  2. 找到这几行：                                          ║
║                                                           ║
║     NEXT_PUBLIC_SUPABASE_URL=你的_Supabase_URL            ║
║     NEXT_PUBLIC_SUPABASE_ANON_KEY=你的_Supabase_ANON_KEY  ║
║     SUPABASE_SERVICE_ROLE_KEY=你的_Supabase_SERVICE_KEY   ║
║                                                           ║
║  3. 替换成你复制的值：                                    ║
║                                                           ║
║     NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co    ║
║     NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGc...              ║
║     SUPABASE_SERVICE_ROLE_KEY=eyJhbGc...                  ║
║                                                           ║
║  4. 保存文件（Ctrl + S）                                  ║
║                                                           ║

║  🚀 测试用户系统                                          ║

║                                                           ║
║  1. 重启服务器                                            ║
║     • Ctrl + C 停止                                       ║
║     • npm run dev 启动                                    ║
║                                                           ║
║  2. 访问：http://localhost:3000/login                     ║
║                                                           ║
║  3. 测试注册：                                            ║
║     • 点击「注册」标签                                    ║
║     • 输入邮箱和密码（至少6位）                           ║
║     • 点击「注册」                                        ║
║     • 检查邮箱，点击验证链接                              ║
║                                                           ║
║  4. 测试登录：                                            ║
║     • 验证邮箱后，返回登录页                              ║
║     • 输入邮箱和密码                                      ║

║     • 自动跳转到工作台                                    ║
