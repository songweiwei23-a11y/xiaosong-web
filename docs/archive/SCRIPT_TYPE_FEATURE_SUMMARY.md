## 📋 核心逻辑

### 脚本类型 vs 大流量/变现
- **脚本类型** = 视频结构（怎么讲故事）
- **大流量/变现** = 内容方向（讲什么内容）
- 两者独立但协作：
  - 脚本类型决定框架结构
  - 成交理由决定围绕什么卖点
  - 爆款元素决定吸引眼球的点

### 示例
用户选择：
- 脚本类型：解题型、故事型（2个）
- 成交理由：颜值高、性价比（变现选题）
- 生成数量：10条

结果：
- 5条解题型选题（围绕颜值高+性价比）
- 5条故事型选题（围绕颜值高+性价比）

## 🎯 关键约束

1. **必选1-3个脚本类型**
2. **平均分配**（余数给前面的类型）
3. **每条选题必须标注使用的脚本类型**
4. **推荐脚本结构必须从用户选择的类型中推荐**
