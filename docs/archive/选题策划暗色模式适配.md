## 🎨 暗色模式设计原则

### 颜色方案
- **背景**: slate-900/slate-950（深灰）
- **卡片**: slate-800/slate-900（中灰）
- **文字**: slate-100/slate-200（浅灰）
- **强调色**: orange-400/yellow-400（橙黄）
- **边框**: slate-600/slate-700（灰色）

### 透明度使用
- 提示框: `dark:bg-orange-900/20`（20%透明度）
- 按钮: `dark:bg-orange-900/30`（30%透明度）
- 悬停: `dark:hover:bg-orange-900/50`（50%透明度）

## 🎯 统一的暗色模式标准

### 基础类名模板
```typescript
// 背景
bg-white dark:bg-slate-900

// 卡片

// 文字

// 边框
border-slate-300 dark:border-slate-700

// 按钮（主要）
bg-blue-600 dark:bg-blue-500 hover:bg-blue-700 dark:hover:bg-blue-600

// 按钮（次要）
bg-slate-100 dark:bg-slate-800 text-slate-900 dark:text-slate-100
```

## 🔧 如何添加暗色模式

### 步骤1: 找到需要适配的元素
```bash
# 搜索没有暗色模式的类名
rg "className.*bg-white[^d]" xiaosong-web/app
```

### 步骤2: 添加dark:前缀
```typescript
// 在每个颜色类后添加对应的暗色版本
bg-white        → bg-white dark:bg-slate-900
text-slate-900  → text-slate-900 dark:text-slate-100
border-slate-300 → border-slate-300 dark:border-slate-700
```

### 步骤3: 测试验证
```
1. 切换到暗色模式
2. 检查所有元素是否清晰可读
3. 检查对比度是否足够
```
