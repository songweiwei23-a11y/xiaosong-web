#### 1.2 修改会员等级 ⭐核心功能
**功能**：管理员可以手动为任何用户设置会员等级

**操作步骤**：
1. 点击用户行的"👑"按钮
2. 选择会员套餐：
   - 免费版：定位1次 + 选题3次 + 脚本20次
   - 基础版 30元/月：所有功能150次

4. 点击"确定修改"

**效果**：
- 立即更新用户的`subscriptions`表
- 用户下次生成时按新等级的配额执行
- 记录管理员操作日志

#### 1.3 重置配额 ⭐核心功能
**功能**：清零用户的所有使用次数

**操作步骤**：
1. 点击用户行的"🔄"按钮

**效果**：
- 清零所有8个功能的used计数
- 重置周期开始/结束时间
- 用户获得新的配额额度

#### 1.4 封禁/解封用户
**功能**：禁止或恢复用户访问权限

**操作步骤**：
- 点击"🚫"按钮封禁用户

**效果**：
- 封禁：用户无法使用任何生成功能
- 解封：恢复正常使用

#### 1.5 查看用户详情
**功能**：查看用户的详细配额使用情况

**操作步骤**：
1. 点击"👁"按钮

**显示内容**：

### 2. 配额检查系统 ⭐核心逻辑

#### 2.1 API: `/api/quota`
**功能**：在每次生成前检查用户是否有剩余配额

**执行流程**：
```
1. 获取用户subscription（确定会员等级）
2. 根据会员等级获取对应的配额限制
3. 检查user_quotas中的使用次数
4. 判断是否超额：
   - 未超额：扣除1次，返回允许生成
   - 已超额：返回403，提示升级会员
```

#### 2.2 会员配额规则
```javascript
free: {
  positioning: 1,      // 账号定位只能用1次
  topic: 3,           // 选题策划3次/月
  script: 20,         // 脚本生成20次/月
  freeChat: 20,       // 自由对话20次/月
  others: 0           // 其他功能0次
}

basic: {
  all: 150            // 所有功能共150次/月
}

pro: {
  all: 500            // 所有功能共500次/月
}

enterprise: {
  all: -1             // -1表示无限使用
}
```

#### 2.3 周期管理
- 每个用户有`current_period_start`和`current_period_end`
- 周期结束时自动重置所有used计数（除免费版的positioning）
- 管理员可手动重置任何用户的配额

### 3. API接口完整列表

#### 3.1 用户管理API
```
GET  /api/admin/users?page=1&pageSize=20&search=
     - 获取用户列表（分页、搜索）

POST /api/admin/users
     Body: { userId, action: 'update_membership', plan, endDate }
     - 修改会员等级

POST /api/admin/users
     Body: { userId, action: 'reset_quota' }
     - 重置配额

POST /api/admin/users
     Body: { userId, action: 'ban_user' }
     - 封禁用户

POST /api/admin/users
     Body: { userId, action: 'unban_user' }
     - 解封用户

PATCH /api/admin/users
     Body: { userId, quota }
     - 更新配额（兼容旧代码）
```

#### 3.2 配额检查API
```
POST /api/quota
     Body: { userId, feature }
     - 检查配额并扣减
     - feature: script, topic, positioning, freeChat, etc.

GET  /api/quota?userId=xxx
     - 查询用户剩余配额
```

### 4. 数据库表结构

#### 4.1 user_quotas表
```sql
user_id UUID (主键)
script_used INTEGER       -- 脚本生成已用次数
topic_used INTEGER        -- 选题策划已用次数
positioning_used INTEGER  -- 账号定位已用次数
free_chat_used INTEGER    -- 自由对话已用次数
storyboard_used INTEGER   -- 分镜脚本已用次数
review_used INTEGER       -- 审稿优化已用次数
title_used INTEGER        -- 标题封面已用次数
deal_reason_used INTEGER  -- 成交理由已用次数
current_period_start TIMESTAMP
current_period_end TIMESTAMP
```

#### 4.2 subscriptions表
```sql
user_id UUID (主键)
plan TEXT                 -- free, basic, pro, enterprise
status TEXT               -- active, inactive
start_date TIMESTAMP
end_date TIMESTAMP
```

## ⚠️ 重要说明

### OpenAI余额问题
当前Dify API的OpenAI账户余额不足，会返回429错误。
这不影响配额管理系统的测试，因为：
- 配额检查在调用AI之前执行
- 即使AI调用失败，配额已经扣减
- 管理员仍然可以修改会员等级和重置配额

### 修复OpenAI余额后
系统将完全正常工作：
1. 用户生成 → 检查配额 → 调用AI → 扣减配额
2. 配额用完 → 提示升级会员
3. 管理员修改会员 → 用户获得新配额
4. 用户继续生成
