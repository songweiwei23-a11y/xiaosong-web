# 开物：即梦科技感宣传片提示词

目标：用真实的开物网页，生成约36秒的产品宣传片，突出高科技、酷炫切换、沉浸感和功能协作。

## 上传与生成方式

上传本文件同目录下 `即梦上传素材/开物_即梦参考_14秒.mp4`，将它作为产品外观与内容参考。原录屏约4分17秒，这份参考素材浓缩为14秒，去掉浏览器栏，并遮盖画面里的账号信息。它是参考素材，不是宣传片成品。

素材顺序：0–3秒品牌首页，3–6秒功能卡片，6–11秒真实AI对话，11–14秒沉浸工作台。视频为1280×720、24fps、无音轨；这些是上传参考的参数，不代表生成片参数。

优先使用支持参考视频的入口，例如页面提供的全能参考；具体名称与可用模型以账户页面为准。每次上传同一参考视频，依次生成下面三段，每段12秒，16:9。先用可用的低分辨率试第一段，确认风格后再继续。

提示词中的“视频1”指上传后的这段参考素材；如果页面要求插入素材引用标签，请通过页面选择对应视频。额外上传PNG时，明确它们的用途：品牌首页、功能卡片、AI对话、沉浸工作台。它们只作为补充视觉参考。

若当前入口不支持视频参考，则分别使用对应PNG作为图像参考；当前入口可选时长若不含12秒，先选择最接近的时长，最后调整成30–40秒总长。

公开模型说明：Seedance 2.0参考视频总时长不超过15秒，输出时长4–15秒。即梦各入口与其他模型限制可能不同，以页面提示为准。

## 第1段：进入开物，12秒

```text
参考视频1中真实的“开物”网页外观、品牌标志和功能卡片，生成一支高端AI软件宣传片的开场，时长12秒，16:9横屏。视频1仅提供产品外观和真实内容参考，请重新设计镜头运动、空间与光效。

整体是黑曜石色数字空间，深蓝背景，电蓝与青色细光，真实网页像精密的悬浮显示面板，边缘有少量玻璃反射和柔和辉光。界面内容保持不透明、清晰；空间深度主要通过面板前后距离、视差和光影表达。

0–3秒：从近黑画面开始，一条细蓝光掠过，照亮参考视频里的真实开物品牌和首页。镜头低角度缓慢靠近，建立高级科技感。
3–7秒：镜头向前加速，沿首页右侧斜切进入功能区，整个网页面板轻微倾斜，形成自然透视，边缘划出短促蓝色光轨。
7–10秒：从真实功能区提取“选题策划”“脚本生成”“分镜脚本”三张卡片，在空间中按前、中、后三层展开；镜头横向掠过，每张卡片成为视觉主体时短暂停留，让名称可辨认。
10–12秒：镜头推近中间一张功能卡片；其发光边框延展为一道竖直蓝光，蓝光从左向右扫过整个画面，作为接下一段的转场。

保持参考网页的品牌、配色、卡片布局和已有功能名称。运动快速但流畅，使用柔和缓动、真实视差、克制运动模糊。只在转场瞬间加速，主体展示时稳定清楚。不要新增页面、虚构功能、编造数据、改写中文、添加价格或宣传字幕；不要出现人物、机器人、城市、浏览器栏和账号信息。音频如支持，只生成轻微启动与掠过音效，无口播，无背景音乐。
```

## 第2段：AI响应与功能协作，12秒

```text
参考视频1中开物真实的AI对话画面和已有回答，生成高端AI软件宣传片的中段，时长12秒，16:9横屏。保持黑曜石色数字空间、深蓝背景、电蓝与青色细光、真实悬浮网页面板，与前一段风格一致。界面内容清晰不透明，玻璃质感只用于边缘和空间反射。

0–2秒：一道竖直蓝光从左向右扫过画面，光线退去后，出现参考视频里的真实AI对话界面。镜头轻微侧移并靠近，让观众进入工作台。
2–6秒：输入框出现柔和蓝色聚焦光，镜头由输入位置沿一条细光线移动到已有回答区域；参考视频中已有的回答按原顺序逐段显现，用视觉揭示体现AI响应，保留原内容，不编写新的回答。
6–9秒：镜头横移，真实回答面板与参考视频中的选题、脚本、分镜功能卡片形成三层悬浮构图，细蓝线连接它们，表现同一创作工作台里的功能协作。这里的连接线是宣传视觉，不要添加不存在的按钮和工作流程。
9–12秒：镜头围绕三层面板平滑移动约30度，再拉远露出整体；所有面板的边缘光收束成一道竖直蓝光，最后从左向右扫过画面，衔接下一段。

体现需求输入、AI响应和创作支持的关系。每个重点至少清楚停留一秒，运镜有速度变化但不晃动。保留真实品牌、UI和可见文字，不要让面板融化、变形、随机增生，不要用乱码代替中文，不要虚构成品或运营成果。无人物、无新增宣传字幕、无口播、无背景音乐；音频如支持，仅保留轻微输入、响应和转场音效。
```

## 第3段：沉浸工作台与品牌收束，12秒

```text
参考视频1中开物真实的工作台、白噪音工具、功能卡片和品牌首页，生成高端AI软件宣传片的结尾，时长12秒，16:9横屏。延续黑曜石色数字空间、深蓝背景、电蓝与青色细光。真实网页是画面主体，界面内容保持清楚、不透明。

0–2秒：一道竖直蓝光从左向右扫过，显露参考视频里的真实工作台。镜头从侧面平滑移动到正面，速度由快到慢。
2–5秒：镜头推近工作台中真实的白噪音与专注工具区域，柔和蓝光在控件边缘轻轻呼吸，背景有少量缓慢移动的光点，表现安静、专注的创作环境。
5–8秒：镜头拉远，真实工作台居中；参考视频中的选题、脚本、分镜功能卡片围绕它形成有序的前后层次，用少量细光线连接。表现丰富功能聚合在同一产品里，画面简洁，不堆满窗口。
8–10秒：外围卡片沿自然轨迹收拢，回到参考中的真实开物首页面板，镜头回到正面，蓝色边缘光缓慢减弱。
10–12秒：真实开物品牌和首页居中稳定停留，背景逐渐变暗，周围保留充足留白，形成干净的品牌落版。结束前不要再切镜，至少停留两秒。

整体酷炫、有空间感，同时让人看清真实产品。保留品牌标志和已有功能，不添加不存在的自动执行或视频生成功能，不展示价格、账号、网址和未经验证的数据。不要人物、机器人、宇宙飞船、强烈闪烁、界面变形、乱码和新宣传字幕。无口播、无背景音乐；音频如支持，仅保留柔和环境与收束音效。
```

## 合成与首次试片

三段按1、2、3顺序拼接，目标总时长36秒。整支片再统一配一条可用的电子氛围音乐，避免三次生成得到不同音乐。最后品牌画面可后期叠加：

开物
让创作有章法

先只试第1段；如出现中文变形，优先减少镜头旋转与卡片数量，将真实录屏作为后期叠加内容。提示词可以要求保留UI，但不能保证生成模型逐字还原。

若结果仍像普通录屏，可在对应提示词末尾加：

“强化面板的前后视差与镜头穿梭，让网页进入有深度的三维数字空间；增加侧向掠过、快速推进和光线贯穿的连续转场，同时稳定保留真实界面。科技感由镜头、层次、光影表现。”
