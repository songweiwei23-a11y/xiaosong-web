# SUMIF 和 SUMIFS 的区别

## 核心区别

**SUMIF**：单条件求和
**SUMIFS**：多条件求和

## 语法对比

```excel
SUMIF(条件范围, 条件, 求和范围)
```

```excel
SUMIFS(求和范围, 条件范围1, 条件1, 条件范围2, 条件2, ...)
```

注意：SUMIFS 的求和范围在最前面，SUMIF 的求和范围在最后面。

## 示例数据表

| 姓名 | 部门 | 销售额 |
|------|------|--------|
| 张三 | 销售 | 5000   |
| 李四 | 技术 | 3000   |
| 王五 | 销售 | 7000   |

假设数据在 A1:C4（含表头）

## 可复制公式

**SUMIF 示例**（求销售部门的总额）：
```excel
=SUMIF(B2:B4,"销售",C2:C4)
```
结果：12000

**SUMIFS 示例**（求销售部门且销售额>6000的总额）：
```excel
=SUMIFS(C2:C4,B2:B4,"销售",C2:C4,">6000")
```
结果：7000

## 记忆要点

- 只有一个条件用 SUMIF
- 两个及以上条件用 SUMIFS
- SUMIFS 求和范围写在最前面

## SUMIF 和 SUMIFS 的区别

**SUMIF**：单条件求和
- 只能设置1个判断条件
- 语法：`=SUMIF(条件区域, 条件, 求和区域)`

**SUMIFS**：多条件求和
- 可以设置多个判断条件（1个或更多）
- 语法：`=SUMIFS(求和区域, 条件区域1, 条件1, 条件区域2, 条件2, ...)`

## 3. 问题清单

### 【问题1·一级致命】
**原文**：「我们是全城最正宗的川味串串！」  
**为什么不行**：①「我们是」属于废话开场（一级致命）②「全城最正宗」是绝对化违禁词  
**改成**：「这锅牛油红汤，我从成都带到南乐，半年了，还是有人专门开车X公里来吃。」

### 【问题2·事实错误】
**原文**：「我在南乐干了18年」

**改成**：「我做川菜做了9年，半年前从成都来到南乐」

### 【问题3·违禁话术】
**原文**：「零添加，吃了养胃」  
**为什么不行**：①「零添加」属于违禁词（无检测依据不能说）②「养胃」属于功效承诺（餐饮不能说治病养生）

### 【问题4·违规指令】
**原文**：「加微信领优惠」  
**为什么不行**：「加微信/加V」属于明确违禁话术  
**改成**：「团购链接在左下角，到店说抖音来的」

### 【问题5·时长不足】
**原文**：全篇15秒，目标30秒
