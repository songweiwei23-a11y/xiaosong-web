# SUMIF 和 SUMIFS 的区别

**核心区别：**
- **SUMIF**：单条件求和（只能设置1个判断条件）
- **SUMIFS**：多条件求和（可以设置多个判断条件）

---

## 语法对比

**SUMIF：**
```excel
=SUMIF(条件区域, 条件, 求和区域)
```

**SUMIFS：**
```excel
=SUMIFS(求和区域, 条件区域1, 条件1, 条件区域2, 条件2, ...)
```

注意：SUMIFS 的求和区域在最前面，这是两者语法顺序的主要差异。

---

## 示例表格

| 姓名 | 部门 | 销售额 |
|------|------|--------|
| 张三 | 销售部 | 5000 |
| 李四 | 技术部 | 3000 |
| 王五 | 销售部 | 7000 |

---

## 可复制公式示例

**SUMIF（单条件）：**
```excel
=SUMIF(B2:B4,"销售部",C2:C4)
```
**结果：** 12000（销售部的总销售额）

---

**SUMIFS（多条件）：**
```excel
=SUMIFS(C2:C4,B2:B4,"销售部",C2:C4,">=5000")
```
**结果：** 12000（销售部且销售额≥5000的总和）

如果改成：
```excel
=SUMIFS(C2:C4,B2:B4,"销售部",C2:C4,">=6000")
```
**结果：** 7000（只有王五符合条件）

---

**总结：** 单个条件用 SUMIF，多个条件用 SUMIFS。
