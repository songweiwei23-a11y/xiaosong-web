### 问题

- 用户体验极差，看起来像卡死了

### 根本原因
```typescript
// 代码里有个判断
if (!topicTask) {  // 如果不是选题任务
    send({ answer: text, ... });  // 才发送流式数据
}

// "选题策划"被标记为NO_REPEAT_TASKS，所以根本不发送流式数据！
export const NO_REPEAT_TASKS = new Set(['选题策划']);
```

### 解决方案
移除了 `if (!topicTask)` 限制，现在选题也会发送流式数据

## 3. ✅ 选题去模板化 - 增加多样性和创意（部分部署）

### 问题
同一方向（如"地域差异"）生成的选题都像一个模板刻出来的，太同质化

### 原因
提示词强调"套公式"、"落在结构上"，导致AI机械套用

### 解决方案

#### 3.1 改进地域差异方向描述
```typescript
// 旧：同一件事两个地方不一样（A 地 → B 地 → 为什么 → 你那边是哪种）
// 新：文化冲突/方言误会/价格差异/习俗反差，让不同地域的人互动产生真实反应
```

#### 3.2 修改选题生成提示词
- 公式改为"创意起点"而非"固定模板"
- 要求每条有独特人物/场景/冲突
- 增加反模板化自检
- 强调多样性、意外性、具体场景化

#### 3.3 核心理念："方向 = 裂变地基，不是固定模板"
```
方向 → 选题：从地基裂变出多样化选题（✅ 需要裂变）
选题 → 脚本：执行选题，不再裂变（❌ 不需要裂变）
脚本 → 标题：提炼脚本，不再裂变（❌ 不需要裂变）
```

**只有"方向→选题"这一步需要裂变！后面都是执行！**

### 修改文件
- `lib/content-roles.ts` - 地域差异方向描述
- `lib/growth-tactics.ts` - 地域差异公式
- `lib/boards/topic-query.ts` - 选题生成提示词
- `lib/creation-continuation.ts` - 跨板块续作规则
