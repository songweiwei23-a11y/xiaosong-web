# 开物「越用越懂你」第一版方案（待产品方确认）

> 2026-10-04。目标：用户用得越多，开物写出来的东西越像他、越少要改，**而且用户自己能感觉到**。
> 不训练专属模型；做法是「从使用行为里总结偏好 → 写成一张用户看得见、改得了的偏好卡 → 每次生成自动带上」。

---

## 一、用户看到的样子

### 1. 创作偏好卡（核心）

每个账号档案一张，放在**个人档案页**「人设事实卡」下面，名字暂定**「开物对你的了解」**。

```
开物对你的了解                         最近更新：10月12日  [现在更新] [⚙]
从你最近 23 次修改、11 条收藏、6 条已发布内容里学到的

口吻用词
 ✓ 句子短、口语化，一句不超过 20 个字              依据：改稿 7 次   [改] [删]
 ✓ 不用「家人们」「宝子们」「绝绝子」               依据：改稿 5 次删掉
开头习惯
 ✓ 开头直接上结论或价格，不用反问开场               依据：改稿 4 次、发布 3 条
结构与长度
 ✓ 口播控制在 45 秒以内，结尾不喊「关注我」          依据：改稿 3 次
内容取向
 ✓ 偏爱「老板亲自讲后厨」这类真实过程               依据：收藏 6 条、发布 2 条

观察中（还没生效，再出现几次就会用上）
 · 可能喜欢在结尾留一个问题引评论                  依据：改稿 2 次   [现在就用] [不要学这条]

[+ 自己加一条]                          [清空重新学]
```

- 每一条都写**依据**（从几次修改、几条收藏里看出来的），用户知道它不是瞎猜的
- 每一条都能**改、删、「不要再学这条」**；也能自己手动加
- 「观察中」的不生效，攒够证据才用上；用户也可以直接点「现在就用」

### 2. 生成结果下面一行小字（让用户感觉到）

> 💡 已按你的偏好写：开头直接上结论 · 不用「家人们」 · 控制在 45 秒内　[调整]

### 3. 工作台首页一张小卡

> 🧠 开物最近又学到 2 条你的习惯　[看看对不对]

### 4. 「越来越懂你」的证据（第一版就做，最有说服力）

偏好卡顶上一行：

> 📉 最近 10 条内容，你平均改动的字数比刚开始少了 38%

用「改稿量越来越少」证明真的越来越懂。这个数字是从画布修改里实打实算出来的，不是编的。数据不够（少于 10 次修改）时这一行不显示。

## 二、从哪里学（第一版的四种信号，都已经存在库里，不用新加埋点）

| 信号 | 在哪里 | 学什么 | 分量 |
|---|---|---|---|
| **画布里的修改** | 各板块结果画布的改稿版本、自由对话的画布版本 | AI 原稿和改后稿逐句对比：删了哪些词、换成什么说法、开头怎么改、长度怎么变 | 最高 |
| **收藏、认可的好稿** | 素材库（AI 好稿 / 认可的好稿） | 他认可的内容长什么样 | 高 |
| **拍了、发了** | 创作进度里「已拍摄」「已发布」的作品最终稿 | 真正用出去的内容长什么样 | 高 |
| **常选的选题** | 选题批次里被带去写脚本、被收藏的那几条 | 内容取向 | 中 |

**第一版不学**：发布数据的好坏（放第二版和「拿你自己的好内容当范本」一起做）、「重新生成」（分不清是不满意还是想多看几版）。

## 三、怎么学

1. **程序先做对比，不全丢给 AI**：画布改稿用程序逐句对比，抽出「删掉的词」「新加的说法」「开头前后」「长度变化」。这样又准又省成本，AI 只看提炼过的差异。
2. **AI 总结**：把这个档案自上次以来的新证据和现有偏好卡一起交给 AI，让它输出「新增 / 加强 / 减弱」的条目，每条带依据次数。只学**表达和习惯**，不学事实。
3. **生效规则**：
   - 同一条偏好在 **3 个不同的内容** 里出现过才生效；1～2 次放「观察中」
   - 用户删掉或点了「不要学这条」的，以后不再学同一条
   - 一条偏好 60 天没有新证据，自动降回「观察中」（人的习惯会变）
   - 每张卡最多 12 条生效的，按证据多少排序，提示词里总长控制在 600 字以内
4. **优先级（不打架）**：用户明确填写的永远优先——
   `人设事实卡 / 禁忌 > 账号档案 > 正在采用的风格预设 > 偏好卡`
   偏好卡和前面任何一项冲突，这一条不用，并在卡片上标「和你的档案冲突，没有采用」。
5. **只学偏好，不学事实**：价格、店名、年限、人名一律不进偏好卡（那是事实卡的事）。如果改稿里反复改同一个事实（比如总把「10 年」改成「12 年」），在卡片上提示一句「要不要更新人设事实卡？」，由用户决定。
6. **什么时候学**：
   - 每晚自动跑一次（和现在的夜间质检同一个定时任务），只跑当天有新信号的档案
   - 偏好卡上有「现在更新」按钮，用户随时可以手动更新
   - 新账号前几次不学，攒够 5 个信号才开始

## 四、用在哪里

- 写稿类板块全部带上：选题、开篇、脚本、审稿、分镜台词、标题封面、起号、二创、自由对话
- 定位类（账号 / 商业 / 内容定位）**不带**：定位是战略问题，不该被「喜欢短句子」这种习惯影响
- 实现上接在现有的 `buildContextBlock` 里，和风格预设走同一条路，每个板块不用单独改

---

## 五、用户的控制权和隐私

- **总开关**：「让开物从我的使用中学习」，默认开启，在偏好卡右上角 ⚙ 里，一键关闭
- 关闭后：不再学习，已有的偏好卡停用（不删），可以选择「同时清空」
- **按档案隔离**：每个号学自己的，不会串；可以把某一条设为「所有档案通用」
- 学习只读这个账号自己的内容，不跨用户
- 偏好卡纳入「数据导出」；隐私政策加一句：「我们会根据你的修改、收藏和发布记录总结创作偏好，你可以查看、修改、关闭」
- 学习在后台跑，**不扣任何创作次数**

---

## 六、怎么证明它真的有用（上线后看）

- 改稿量变化：每个档案「平均每条改了多少字」随时间的曲线（同时给用户看，见第一节第 4 点）
- 偏好条目的保留率：用户删掉的比例越低，说明学得越准
- 夜间质检加一项：生成的内容有没有违反偏好卡里生效的条目

## 七、要改的地方（技术）

| 内容 | 说明 |
|---|---|
| 新表 `creator_preferences` | 每个档案一行：偏好条目、观察中的条目、被拒绝的条目、上次学习到哪、开关；只许本人读写 |
| 信号汇总 | 从画布改稿版本、素材库、作品进度、选题批次里按时间取新证据 |
| 改稿对比 | 程序逐句比较 AI 原稿和改后稿，算改动字数（同时用于「改稿量少了 38%」） |
| AI 总结 | 走现有的开物 Dify 应用，输出结构化 JSON，程序校验后合并 |
| 定时任务 | 接到现有每晚 3 点的定时任务；加「现在更新」接口 |
| 注入 | `buildContextBlock` 加偏好块，写稿类板块生效 |
| 页面 | 个人档案页偏好卡、生成结果下面的提示行、工作台首页小卡 |
| 测试 | 生效规则（3 次、60 天、拒绝不再学）、冲突处理、不学事实、档案隔离、开关、不扣次数 |

**难度**：中等偏低，大部分数据和通道都是现成的。主要功夫在「学得准不准」，上线前我会用合成的改稿数据跑一遍总结，看看学出来的条目靠不靠谱。

## 八、需要你拍板的

1. **默认开启还是默认关闭？** 建议**默认开启**，第一次生成偏好卡时弹一次说明，一键能关。
2. **新学到的偏好**：证据够了**直接生效再告诉用户**（建议），还是每条都要用户点「确认」才生效？
3. **偏好卡放哪**：个人档案页 + 首页提示 + 结果下面一行小字（建议三处都要），还是只放一处？
4. **谁能用**：建议**所有档位都有**，包括免费版——这是「越用越懂你」的核心体验，学习成本很低，不扣次数。
5. **名字**：「开物对你的了解」 / 「我的创作偏好」 / 「开物记住的你」，选一个或者你起一个。
6. **「改稿量少了 38%」这行**：建议做，它是「越来越懂你」最直观的证据。
