[31m+ ## ⚙️ 本次要求[39m
[31m+ 所有标题都承接同一具体主线、人群、立场与事实状态。尚未采访或观察时，用问题/计划式表达，不将假设写成已证实结论；不得为标题承诺的效果补编正文。[39m
[31m+ 标题要有**具体的东西**（一件事、一个处境、一个数字或一个人，不一定是商品细节）加一个**反差、冲突或悬念**，观众刷到第一眼就知道这条说的是什么、为什么跟他有关。不用「XX，怎么…」「别只…」「你知道吗」「XX 的 N 个技巧」「原来…」这类万能模板。标题不超过 20 个字，只有一个主句，不用分号把几句话连成一串。标题里不留占位符（X、某某、几元、XX 这类）：要么写出真的数字和东西，要么换一个不需要填空的说法。标题要读起来像一句人话，不硬拼两个不相干的名词或比喻（「压箱底的裤子，像怕被评价的人」这种就不通）。写完先把标题通读一遍，读不顺、看不出在说什么的就重写。写法对照（只学写法，不照抄）：平：「装修选材料，别被忽悠」（只有话题，没有东西，也没有冲突）；好：「同一面墙，两种漆，三年后差在哪」（具体的东西、一个对比、一个悬念）[39m
[31m+ 任何创作都必须符合现实的生活逻辑，有说服力才行。创作的来源只能是现实中真实存在、大多数人认可的事，不凭空编造。下面三类说法一律不写（括号里的例子只说明是什么类型，不是清单，类似的说法同样不写）：[39m
[31m+ - 太离谱：一件事改变整体、判若两人、几天就见效的保证（比如「收腰就能换风格」「换个头像粉丝就翻倍」「同一件外套两种人」「换个招牌字体，营业额就翻一番」）[39m
[31m+ - 太简单：一招搞定、一句话让客户当场签单、躺着就能赚（比如「一句话让客户当场下单」「躺着月入过万」）[39m
[31m+ - 太不科学：违背常识或没有依据的因果（比如「喝某种水就能瘦」「敷一下就能消炎」）[39m
[31m+ 一件事能带来的变化，要有它真实的条件、过程和代价。反差和看点要来自生活或镜头里看得见的具体变量，不靠硬切换人设、身份或结果。拿不准能不能成立，就写清楚前提和做法，不替事实下结论。一个小细节（一种做法、一个动作、一句话、一处调整）只能改变它直接作用的那一处，不能写成它让整件东西、整个人或整家店都变了。结论的范围也要和证据一样大：一次现场的反应只说明这一次，不能推成普遍的道理（比如一位客户换了靠垫说舒服，就说挑沙发都要试靠垫）。[39m
[31m+ 主角是这个号卖的东西（这条管变现型，以及任何要做对比、前后变化的内容）：观众看完要觉得「是这家的东西（或手艺）让人变好看、变好用、变好吃」，而不是学会一个技巧就不用来买了。[39m
[31m+ - 流量型也遵守对比变量规则：不是每条都要对比，但只要做反差、对比或前后变化，变的是卖的东西，人、场和动作保持一致；不为了满足规则把每条都拍成商品对比。流量型仍以用户感兴趣的看点为主，不硬推卖点[39m
[31m+ - 要做对比、反差、前后变化，变的那一样必须是这个号在卖的东西，其他条件不变：同一个人（同一个空间、同一桌人）先后用两样东西——这家卖的，和普通的、旧的或常见的——前后差别看得见，才证明是东西好。例：同一个人先后穿两套衣服，前后两种风格；同一个客厅换两张沙发；同一个人戴两副镜框[39m
[31m+ - 不做「同一件东西换个穿法、搭法、摆法、用法、吃法」的对比：卖的东西没变，差别只能归功于技巧，证明不了东西好，也给不出来买的理由[39m
[31m+ - 卖的就是手艺或服务的（剪发、验光、装修设计、厨师的做法），手艺本身就是货：同一个人剪前剪后、同一份食材我们的做法和普通做法，这类对比成立[39m
[31m+ - 穿法、搭法、用法这类技巧只能顺带一句，不能当一个方向或一条内容的看点；人设型可以以人为主角，但做对比时仍遵守上面的变量规则[39m
[31m+ - **标题围绕出发点和元素**：参考内容（选题或脚本）里写明的「爆款元素」就是这条标题要用的元素，用它的句式写，光看标题就认得出；标题也要落在人、货、场其中一个上（这条围绕的那个）。参考内容里没写元素的，标题就只按出发点写，不硬套句式[39m

[31m+ ## 🪝 钩子机制库（开篇 36 计）[39m

[31m+ **每个标题挑 1 张主卡**——堆钩子等于没钩子。[39m

[31m+ ## 📱 抖音的标题逻辑[39m
[31m+[39m
[31m+ - 推荐流场景：用户是被动刷到的，标题要在 1 秒内制造点击冲动[39m
[31m+ - 前 8 个字最重要——信息流里经常只显示这么多，钩子必须前置[39m
[31m+ - 善用数字、对比、反常识；疑问句比陈述句点击率高[39m
[31m+ - 长度 12-20 字为宜，太长会被截断[39m
[31m+[39m
[31m+ ## 🚫 违规与风险词[39m
[31m+[39m
[31m+ - **禁用「揭秘」**：容易招同行举报，也容易被判定为夸大。改用：教你看懂、带你了解、对比分析[39m
[31m+ - **禁用「震惊」**：典型标题党用词，平台会降权。改用：用具体数字替代情绪词[39m
[31m+ - **禁用「第一/最好/最强」**：绝对化用语违反广告法，会被限流。改用：说具体比的是什么（哪两样、差在哪一处）[39m
[31m+ - **禁用「100%/彻底根治」**：绝对化承诺，有违规风险。改用：说做法和条件（「先看这一处」「适合哪种情况」），不替出镜人写「我试过都有效」[39m
[31m+ - ⚠️ **卡名不是豁免**：钩子库里有「内幕揭秘」这张卡，指的是「用信息不对称制造价值感」这个机制，不是允许你在标题里写「揭秘」二字。机制照用，词要换——写成「干了十年装修，我只看这 3 个地方」，而不是「装修行业内幕大揭秘」。[39m

[31m+ ## 📏 每个标题的自查项（不达标就重写，不要输出不达标的）[39m
[31m+[39m
[31m+ 1. **前 8 个字是否已经有钩子**——信息流里经常只显示这么多[39m
[31m+ 2. **有没有一个具体的锚点**——数字、时间、身份、场景，四者至少占一个[39m
[31m+ 3. **是否避免了形容词堆砌**——「很棒」「超赞」「绝了」不算信息[39m
[31m+ 4. **换个人能不能用**——如果这个标题套在任何视频上都成立，它就太空了[39m
[31m+ 5. **是否命中风险词**[39m
[31m+ 6. **钩子卡是真用上了，还是只贴了个名字**——机制要能在标题里看出来[39m
[31m+ 7. **标题里的数字、结果、身份是否都有材料或档案支持**——没有就改成材料能证明的说法，或标注「待核实」，不写成既定事实[39m

  if (h < 6) return \"夜深了\";
  if (h < 12) return \"上午好\";
  if (h < 14) return \"中午好\";
  if (h < 18) return \"下午好\";
  return \"晚上好\";
}
