║  📌 方法一：自动配置（推荐，最简单）                      ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  1️⃣ 双击运行文件：配置API密钥.bat                       ║
║                                                           ║
║  2️⃣ 脚本会自动打开 Dify 网站                            ║
║                                                           ║
║  3️⃣ 在浏览器中：                                        ║
║     • 登录 Dify                                           ║
║     • 找到「小宋编导文案工作台」                          ║
║     • 点击右上角「发布」                                  ║
║     • 选择「API 访问」或「API」                           ║
║     • 复制 API Key（格式：app-xxxxx）                    ║
║                                                           ║
║  4️⃣ 回到配置助手窗口                                    ║
║     • 按任意键继续                                        ║
║     • 粘贴你复制的 API Key                               ║
║     • 按回车                                              ║
║                                                           ║
║  5️⃣ 完成！脚本会自动保存配置                            ║
║                                                           ║
╠═══════════════════════════════════════════════════════════╣
║                                                           ║
║  📌 方法二：手动配置                                      ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  第1步：获取 API Key                                      ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  1. 打开浏览器，访问：https://dify.ai                     ║
║                                                           ║
║  2. 登录你的账号                                          ║
║                                                           ║
║  3. 在应用列表中找到：                                    ║
║     「小宋编导文案工作台」                                ║
║     或「编导工作台」相关的应用                            ║
║                                                           ║
║  4. 点击进入该应用                                        ║
║                                                           ║
║  5. 点击右上角的「发布」按钮                              ║
║                                                           ║
║  6. 在弹出菜单中选择：                                    ║
║     「API 访问」或「API」                                 ║
║                                                           ║
║  7. 你会看到 API 密钥，格式类似：                        ║
║     app-aBcD1234eFgH5678                                  ║
║                                                           ║
║  8. 点击复制按钮，或手动选中复制                          ║
║                                                           ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  第2步：配置到项目                                        ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  1. 按 Win + E 打开文件管理器                            ║
║                                                           ║
║  2. 在地址栏输入：                                        ║
║     C:\Users\30430\Desktop\编导知识大全\小宋\xiaosong-web ║
║     按回车                                                ║
║                                                           ║
║  3. 找到文件：.env.local                                  ║
║     （如果看不到，在「查看」中勾选「显示隐藏文件」）      ║
║                                                           ║
║  4. 右键点击 .env.local                                   ║
║     选择「打开方式」→「记事本」                           ║
║                                                           ║
║  5. 找到这一行：                                          ║
║     DIFY_API_KEY=你的Dify_API密钥                         ║
║                                                           ║
║  6. 改成（把你复制的密钥粘贴进去）：                      ║
║     DIFY_API_KEY=app-aBcD1234eFgH5678                     ║
║                                                           ║
║  7. 按 Ctrl + S 保存文件                                  ║
║                                                           ║
║  8. 关闭记事本                                            ║
║                                                           ║
╠═══════════════════════════════════════════════════════════╣
║                                                           ║
║  ✅ 验证配置是否成功                                      ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  1. 重启开发服务器                                        ║
║     • 在黑色窗口按 Ctrl + C                              ║
║     • 运行：npm run dev                                   ║
║                                                           ║
║  2. 浏览器访问：http://localhost:3000                     ║
║                                                           ║
║  3. 点击「进入工作台」                                    ║
║                                                           ║
║  4. 选择任意功能（建议先试「知识库」）                    ║
║                                                           ║
║  5. 填写表单，点击生成按钮                                ║
║                                                           ║
║  6. 如果能看到 AI 实时生成内容 → ✅ 配置成功！           ║
║                                                           ║
║  7. 如果报错「API Key 无效」→ 检查密钥是否正确           ║

║  ⚠️ 常见问题                                             ║
║  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  ║
║                                                           ║
║  Q1: 找不到 .env.local 文件？                            ║
║  A:  在文件管理器中：                                     ║
║      • 点击「查看」                                       ║
║      • 勾选「隐藏的项目」或「显示隐藏文件」               ║
║      • 就能看到 .env.local 了                            ║
║                                                           ║
║  Q2: 不知道 Dify 工作台的名字？                          ║
║  A:  登录 Dify 后，在应用列表中找：                      ║
║      • 包含「编导」「脚本」「工作台」等关键词的应用       ║
║      • 或你之前创建/导入的应用                            ║
║                                                           ║
║  Q3: 找不到「API 访问」选项？                            ║
║  A:  不同版本界面可能不同，试试：                         ║
║      • 点击右上角「...」更多菜单                         ║
║      • 或在应用设置中找「API」相关选项                    ║
║      • 或在侧边栏找「API 密钥」                           ║
║                                                           ║
║  Q4: 配置后还是报错？                                     ║
║  A:  检查以下几点：                                       ║
║      1. API Key 是否完整复制（包括 app- 前缀）           ║
║      2. 是否有多余的空格                                  ║
║      3. 是否保存了文件                                    ║
║      4. 是否重启了服务器                                  ║
║      5. Dify 工作台是否已发布                            ║
║                                                           ║
║  Q5: API Key 在哪个 Dify 应用里？                        ║
║  A:  需要是你创建的「编导工作台」应用                     ║
║      如果还没创建，需要先在 Dify 中创建工作流            ║
║      参考你的 Dify_编导工作台交付包 中的教程              ║
║                                                           ║

║  .env.local 文件应该像这样：                              ║
║                                                           ║
║  # Dify API Configuration                                 ║
║  DIFY_API_KEY=app-aBcD1234eFgH5678iJkL9012               ║
║  DIFY_API_URL=https://api.dify.ai/v1                      ║
║                                                           ║
║  # App Configuration                                      ║
║  NEXT_PUBLIC_APP_NAME=小宋编导工作台                      ║
║  NEXT_PUBLIC_APP_URL=http://localhost:3000                ║
║                                                           ║
║  注意：                                                   ║
║  • DIFY_API_KEY= 后面直接跟你的密钥，没有空格            ║
║  • 不要有引号                                            ║
║  • 其他行保持不变                                        ║
