# 【本轮内容落实规则确认】

**核心任务**：为家具店老板老陈制作一条30秒街访对比视频，拍摄节后真实进店顾客，通过采访挖掘"为什么节后来看家具"，对比国庆期间与节后的人群差异，给观望者一个"现在来更合适"的理由。

**硬约束**：
- 只有老陈一人，用手机自拍，无演员
- 严格30秒（≈150字口播）
- 不降价、不促销、不打折
- 只用已有事实，无数据不编造
- 采访为未完成状态，需给采访执行方案

**事实边界**：
- 已知：国庆后进店人少了一半、店里冷清
- 未知：具体进店人数、顾客真实回答、节后与国庆客群差异
- 禁编：客户对话、经营承诺、价格优惠、复购数据

## 第1步：脚本策略卡

**核心问题**：节后来看家具的人和国庆来的人有什么不同？为什么他们选择这个时候来？

**用户目的**：引流到店——把"冷清"重新定义为"适合某类人的好时机"，吸引观望者和老客

**目标人群**：
- 国庆期间逛过但没买的观望者
- 觉得节假日人多、想避开高峰的理性购买者
- 本地有装修需求但不急于国庆下单的家庭

**所选形式**：街头采访 + 对比记录
- 老陈手机拍摄节后店内真实状态（空荡展厅、偶尔进店的顾客）
- 穿插国庆期间热闹画面（手机存档或监控截图）
- 现场采访3-5组真实进店顾客，主问统一，追问根据回答分支

**材料递进逻辑**：
1. 视觉对比：国庆热闹 vs 节后冷清（画面建立反差）
2. 采访挖掘：为什么节后来？和国庆比有什么不一样？（挖出时机差异）
3. 老陈总结：根据真实采访结果归纳"节后来的客人其实更……"（给观众行动理由）

**事实边界**：
- 可拍：店内真实状态、真实顾客（需同意出镜或拍背影/手部）
- 待采集：顾客真实回答、具体人数对比
- 不编造：顾客台词、消费决策、成交结果、价格信息

## 第4步：执行与优化建议

### 立即准备（拍摄前）
1. **采访话术演练**：老陈提前对着镜子练习主问和追问，确保自然不生硬
2. **素材整理**：找出国庆期间手机拍的店内画面或调取监控截图（3-4张），顾客需打码
3. **征得同意**：提前准备话术"我在拍视频记录店里的情况，能问您两个问题吗？"，明确告知会发抖音，询问是否同意露脸

### 拍摄执行（节后一周内，每天营业时间）
1. **拍摄时段**：选择有顾客进店的时段（通常上午10-12点或下午2-5点）
2. **采访目标**：至少采访5组真实顾客，确保有2-3组回答可用
3. **拍摄顺序**：
   - 先拍镜头1（开场）和镜头3（空荡展厅）
   - 等顾客进店后，边接待边寻找愿意受访的顾客
   - 每组采访完整录制（1-2分钟），后期剪辑选精华
4. **备用方案**：若当天无顾客或顾客不愿受访，延后1-2天继续拍摄，不编造顾客对话

### 剪辑要点
1. **时长控制**：严格30秒，采访段选最有代表性的2-3组回答（每组3-5秒）
2. **字幕**：给顾客回答加字幕，增强可读性；老陈旁白可不加字幕
3. **对比节奏**：国庆热闹画面（镜头2）快速切换，节后冷清画面（镜头3）拉长停留，强化反差
4. **结尾总结**：根据采访结果提炼1句话（10-15字），示例方向：
   - 若多数顾客提到"人少好沟通" → "节后来的客人其实更容易聊到细节"
   - 若多数顾客提到"不着急慢慢选" → "节后来的客人其实更清楚自己要什么"
   - 若多数顾客提到"时间充裕" → "节后来的客人其实更从容"

### 资料缺口与下一步
- **缺口1**：国庆与节后具体进店人数对比 → 如有数据可在后续视频中补充，本条不强求
- **缺口2**：顾客真实回答 → 采访完成后根据实际内容调整结尾总结
- **下一步**：
  - 采访完成后，将所有采访素材发给我，我帮你提炼最适合的结尾总结
  - 若本条数据好，可策划第2条：「节后来的客人都问了什么？和国庆大不一样」（深化采访结果）
  - 避免方向：不拍成"节后优惠""错过国庆再等一年"等促销向内容
