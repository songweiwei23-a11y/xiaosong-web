# 第 2 轮 · 跨行业二创（2 个方案）

# 原片火的核心机制与跨行业迁移价值

**核心机制**：这条视频用"直击痛点反问+正反对比示范+可落地改法+评论区钩子"的组合拳，在开头3秒用"你是不是练了一年还是这个体型？"精准圈住目标人群（健身但没效果的人），接着用左右分屏直观展示错误动作vs正确动作的差异，让观众瞬间get到"原来我错在这"，最后用"评论区留言领计划"把公域流量导向私域转化。

**为什么能跨行业借**：
1. **反问开篇是万能圈人公式**："你是不是XX了还XX？"——这个句式能让目标用户瞬间对号入座，川菜馆可以改成"你是不是吃了好几家火锅还是觉得不够味？"
2. **正反对比可视化**：健身教练用左右分屏展示动作差异,川菜馆可以用同样手法展示"错误吃法vs正确吃法""别人家的串串vs我家的串串"
3. **节奏快、信息密度高**：每3-4秒切一次景别,符合本地美食黄金推流时段(晚6-9点)用户的刷屏习惯——下班路上、等地铁、犹豫吃啥的时候,快节奏更抓眼球
4. **结尾钩子可迁移**：原片用"领计划"做转化钩子,川菜馆可以改成"评论区问地址""想知道一元火锅怎么吃最值,评论区扣1"

### 方案1：地摊火锅版"纠错"｜你是不是X块钱吃了个寂寞？

**一句话**：原片"练了一年体型没变→纠正一个错误动作" → 你的"吃了好几次火锅还觉得不值→纠正一个点菜误区"

**借了**：反问开篇圈人+正反对比可视化(左右分屏)+快节奏切镜(3-4秒一切)+评论区钩子  
**换成自己的**：出镜人换成四川师傅、场景从健身房换到地摊、教的内容从"动作纠错"换成"点菜纠错"、左右分屏展示"别人点的vs我教你点的"

#### 迁移对照

| 层 | 原片 | 你的版本 |
|---|---|---|
| **事件/主角** | 健身教练指出学员"练了一年没效果"的动作错误 | 四川师傅指出食客"吃了好几次还觉得不值"的点菜误区 |
| **开篇句式** | "你是不是练了一年还是这个体型?" | "你是不是X块钱在地摊火锅吃了个寂寞?" |
| **核心对比** | 错误动作(左屏) vs 正确动作(右屏) | 错误点法(左屏:只点贵的菜) vs 正确点法(右屏:师傅教你这样搭配) |
| **呈现方式** | 教练站在器械前口播+左右分屏示范 | 师傅站在地摊锅前口播+左右分屏展示菜品 |
| **镜头节奏** | 每3-4秒切景别(全景→中景→特写→分屏) | 同样每3-4秒切(地摊全景→师傅中景→菜品特写→分屏对比) |
| **结尾钩子** | "评论区留言领取计划" | "想知道一元火锅怎么吃最值,评论区问我" |

#### 开头(前3秒)

**第一句话**："你是不是X块钱,在地摊火锅吃了个寂寞?"

**画面**：师傅站在冒着热气的火锅前,背后是地摊的灯串和炭火,手里拿着一把串串,表情略带"我懂你"的无奈。画面有烟火气、有食物、有人,3秒内信息密度够高。

#### 口播全文

【开篇钩子·反问圈人】  
"你是不是X块钱,在地摊火锅吃了个寂寞?很多人第一次来,不会点。"

【指出错误·建立共鸣】  
"最常见的错误,就是只盯着菜单上那几个贵的点。毛肚、鸭肠、牛肉,一顿下来X块钱,吃完还没饱。"

【展示对比·左右分屏出现】  
"你看这桌(左屏),全是肉,X块钱。再看这桌(右屏),荤素搭配,师傅推荐的,同样X块钱,多吃三分之一。"

【讲原理·建立专业感】  
"地摊火锅要吃得值,记住一个公式:一元火锅打底,配三样师傅今天新进的菜,再来两串烤的。这样既能吃饱,又能尝到川味正宗的味道。"

【给方法·可落地】  
"一元火锅别看便宜,我们是真给料的。土豆片、白菜、粉条,你随便涮。再配上我们今天早上六点从批发市场拉回来的鲜毛肚,这一顿,X块钱就够了。"

【结尾行动指令·流量型只要关注或评论】  
"想知道今天哪三样菜最新鲜?评论区问我。"

*(时长约40秒,可根据实际拍摄节奏压缩到30秒)*

#### 分镜

**镜头1｜0-3秒**：地摊全景,冒热气的火锅+灯串+炭火烤串,师傅从左侧入画  
台词："你是不是X块钱,在地摊火锅吃了个寂寞?"

**镜头2｜3-6秒**：师傅中景,手里拿着菜单指给镜头看  
台词："很多人第一次来,不会点。最常见的错误,就是只盯着这几个贵的。"

**镜头3｜6-10秒**：特写·菜单上的毛肚、鸭肠、牛肉,手指点过去  
台词："毛肚、鸭肠、牛肉,一顿下来X块钱,吃完还没饱。"

**镜头4｜10-16秒**：左右分屏·左边一桌全是肉串,右边一桌荤素搭配+一元火锅  
台词："你看这桌,全是肉,X块钱。再看这桌,荤素搭配,同样X块钱,多吃三分之一。"

**镜头5｜16-21秒**：师傅中景,开始讲公式,背景是地摊忙碌的场景  
台词："地摊火锅要吃得值,记住:一元火锅打底,配三样今天新进的菜,再来两串烤的。"

**镜头6｜21-26秒**：特写·一元火锅里的土豆片、白菜、粉条,筷子夹起来  
台词:"一元火锅别看便宜,我们是真给料的。土豆片、白菜、粉条,你随便涮。"

**镜头7｜26-30秒**：特写·师傅手里拿着刚从冰柜取出的鲜毛肚(有冰渣或水珠,显示新鲜)  
台词:"再配上早上六点从批发市场拉回来的鲜毛肚,这一顿,X块钱就够了。"

**镜头8｜30-33秒**：师傅中景,对镜头,背后是地摊全景  
台词:"想知道今天哪三样菜最新鲜?评论区问我。"  
字幕:"📍南乐·锦园地摊串串"

#### 用你手上的资源怎么拍

**人员**：师傅出镜(主角)+1人拍摄+1人帮忙摆菜/充当"那桌客人"(可以是老板或员工,不用露正脸)  
**设备**：手机(稳定器最好,手持也行,关键是每3-4秒切一次,不会抖太明显)  
**场地**：地摊现场,选下午5点左右开始拍(天还没全黑,灯串刚亮,光线最好看)  
**道具**：  
- 一元火锅一份(装满土豆片、白菜、粉条,拍特写用)  
- 菜单一份(拍特写指菜名用)  
- 两桌菜品做对比:左桌摆X串肉串,右桌摆荤素搭配+一元火锅  
- 一份刚从冰柜取出的鲜毛肚(带点冰渣或水珠,显示新鲜感)

**拍摄流程**(约1小时):  
1. 先拍镜头1地摊全景(等客人还没来,画面干净)  
2. 再拍师傅口播部分(镜头2/5/8),一次性录完,后期切分  
3. 拍特写镜头(菜单/一元火锅/毛肚),每个多拍几条备用  
4. 最后拍左右分屏素材:让员工帮忙摆两桌菜,分别拍两个角度,后期合成左右屏

**后期**：用剪映左右分屏功能,把两桌菜的画面并排放;字幕用大号加粗,关键词(一元火锅/X块钱/评论区问我)变色强调

#### 注意

**原片学不来的部分**：  
- 健身教练有专业背景(器械、灯光、身材)做背书,你的专业背书在"四川师傅9年川菜经验+地摊烟火气真实场景"  
- 原片拍摄环境是室内健身房,光线稳定;你是露天地摊,要选黄昏时段(5-6点)拍,天光+灯串混合光最有氛围,太黑了拍不清,太亮了没烟火气

**这条不是搬运**：  
- 台词全是你店里的事:"一元火锅""早上六点批发市场拉回来""X块钱吃饱"都是你的真实场景  
- 画面全是你的素材:地摊、火锅、串串、师傅,没有一帧来自原片  
- 事件逻辑变了:原片是"动作错了导致没效果",你是"点菜错了导致不值";借的只是"反问开篇+正反对比+给方法"这个结构

### 方案2：烧烤版"纠错"｜你是不是烤串越吃越渴?

**一句话**：原片"练了一年体型没变→纠正错误动作" → 你的"吃烤串越吃越渴→纠正一个配菜误区"

**借了**：反问开篇+正反对比(但不用左右分屏,改用前后对比:先展示错误吃法的后果,再展示正确吃法)  
**换成自己的**：出镜人是师傅、场景是炭火烤串摊、教的内容从"健身动作"换成"烧烤怎么吃不上火"、对比从"动作"换成"配菜搭配"

#### 迁移对照

| 层 | 原片 | 你的版本 |
|---|---|---|
| **事件/主角** | 健身教练纠正学员动作错误 | 四川师傅纠正食客烧烤配菜误区 |
| **开篇句式** | "你是不是练了一年还是这个体型?" | "你是不是烤串越吃越渴,第二天嗓子冒烟?" |
| **核心对比** | 错误动作导致没效果 vs 正确动作有效果 | 只吃肉串上火 vs 配凉菜解腻不上火 |
| **呈现方式** | 左右分屏同时展示 | 时间线前后对比:先拍一桌只点肉的客人(喝了三瓶水),再拍配了凉菜的客人(吃得舒服) |
| **镜头节奏** | 每3-4秒切景别 | 同样快切,但增加炭火特写、翻面动作特写(增加沉浸感) |
| **结尾钩子** | "评论区留言领计划" | "想知道配哪几样凉菜最解腻?关注我,下条告诉你" |

#### 开头(前3秒)

**第一句话**："你是不是烤串越吃越渴,第二天嗓子冒烟?"

**画面**：炭火特写,串串在烤架上滋滋冒油,烟往上飘,师傅的手拿着刷子刷酱。3秒内有火、有烟、有动作,视觉冲击力强。

#### 口播全文

【开篇钩子·反问圈人】  
"你是不是烤串越吃越渴,第二天嗓子冒烟?很多人来吃烧烤,只点肉串。"

【指出错误·展示后果】  
"你看这桌,点了X串肉,喝了三瓶水,还是觉得干。为什么?因为没配凉菜。"

【讲原理·建立专业感】  
"川味烧烤,讲究一个荤素搭配。我们四川人吃烤串,肉串配凉拌菜,一口肉一口菜,解腻不上火。"

【展示正确做法·时间对比】  
"再看这桌,X串肉,配了三样凉菜。黄瓜、折耳根、拌海带,酸辣开胃。你看他吃得多舒服,一瓶水都没喝完。"

【给方法·可落地】  
"记住,地摊烧烤要吃得爽,肉串和凉菜的比例是3比1。三串肉,配一份凉菜,这样吃到最后一串,还是香的。"

【结尾行动指令·流量型】  
"想知道配哪几样凉菜最解腻?关注我,下条专门讲。"

*(时长约35秒,可压缩到30秒)*

#### 分镜

**镜头1｜0-3秒**：炭火特写,串串在烤,滋滋冒油,烟往上飘  
台词:"你是不是烤串越吃越渴,第二天嗓子冒烟?"

**镜头2｜3-6秒**：一桌客人面前摆满肉串,旁边三个空水瓶(可以是摆拍,不用拍客人正脸)  
台词:"很多人来吃烧烤,只点肉串。你看这桌,点了X串肉,喝了三瓶水。"

**镜头3｜6-10秒**：师傅中景,站在烤架前,手里拿着串,对镜头  
台词:"为什么还是觉得干?因为没配凉菜。川味烧烤,讲究荤素搭配。"

**镜头4｜10-15秒**：特写·三份凉菜(黄瓜、折耳根、拌海带)依次推进镜头  
台词:"我们四川人吃烤串,肉串配凉拌菜,一口肉一口菜,解腻不上火。"

**镜头5｜15-20秒**：另一桌,肉串+凉菜搭配,只有一瓶水(可以拍背影或手部,不露脸)  
台词:"再看这桌,X串肉,配了三样凉菜。你看他吃得多舒服,一瓶水都没喝完。"

**镜头6｜20-26秒**：师傅中景,用手比划"3比1"的手势  
台词:"记住,地摊烧烤要吃得爽,肉串和凉菜的比例是3比1。三串肉,配一份凉菜。"

**镜头7｜26-30秒**：师傅拿起一串刚烤好的肉,咬一口,再夹一筷子凉菜  
台词:"这样吃到最后一串,还是香的。"

**镜头8｜30-33秒**：师傅对镜头,背后是地摊烤架,炭火通红  
台词:"想知道配哪几样凉菜最解腻?关注我,下条专门讲。"  
字幕:"📍南乐·锦园地摊串串"

#### 用你手上的资源怎么拍

**人员**：师傅出镜+1人拍摄+1人帮忙摆桌(充当"那桌客人",只拍背影或手部)  
**设备**：手机  
**场地**：地摊烤串区,选晚上7-8点拍(客人开始多了,但还没到最忙的时候,能抽出10分钟)  
**道具**：  
- 两桌对比素材:第一桌摆X串肉+三个空水瓶,第二桌摆X串肉+三份凉菜+一瓶水  
- 三份凉菜(黄瓜、折耳根、拌海带,提前做好,拍特写用)  
- 一串刚烤好的肉(拍师傅吃的镜头用)

**拍摄流程**(约40分钟):  
1. 先拍两桌对比素材(趁客人还没来,摆拍两桌,多拍几个角度)  
2. 拍炭火特写(多拍几条,选烟最大、最有氛围的)  
3. 拍师傅口播(镜头3/6/8),一次性录完  
4. 拍凉菜特写(三份依次推进镜头,可以用手机慢动作拍,后期加速)  
5. 最后拍师傅吃的镜头(咬肉串+夹凉菜,多拍几条,选最自然的)

**后期**：快切剪辑,每3-4秒一个镜头;炭火特写可以放慢0.5倍速,增加沉浸感;字幕加粗,关键词(3比1/关注我)变色

- 原片用左右分屏同时对比,需要后期;你这条改用时间线前后对比(先拍错误的桌,再拍正确的桌),更简单,一人一机就能完成  
- 原片是室内,你是露天;要利用炭火、烟雾、灯光营造氛围,弥补场地的"不够精致"

**这条不是搬运**：  
- 台词是你店里的场景:"川味烧烤""折耳根""3比1配比"都是你的专业经验  
- 画面是你的素材:炭火、串串、凉菜、师傅,和原片的健身房、器械、教练完全不同  
- 事件换了:原片是"动作错了",你是"配菜错了";借的只是"反问+对比+给方法"的结构,内核完全不同
