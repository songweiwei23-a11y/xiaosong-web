# 小张工作号·濮阳本地找工作服务 · 内容定位

# 💎 内容定位方案

## 长期价值主张

让不懂流程、怕被坑的普通人知道去哪个厂、怎么去、路上有人管。

---

## 内容方向：多元四类还是单一主题

**选 A 多元四类**

**依据**：
你的核心价值是"让工人信任你、找你",信任需要多个角度建立——晒过程让他看到你真的在做,故事让他记住你这个人,知识让他觉得你专业。四类配合,比单一主题更适合你现在的阶段和资源。

**为什么不选 B（单一主题）**：
单一主题（比如「体验 100 种工厂」「接送 100 个工人」）需要极强的策划和执行能力,而且你的核心价值不是"带观众看工厂有多好玩",是"让工人信任你、找你"。你每天在跑、有接送素材,但单一主题需要每集都有新的故事线、新的冲突或反转,一个人全包很难持续出片。而且工人看账号不是追剧,他要看到的是"这个人真的在做、做得好、能帮我",这需要多类内容从不同角度证明,而不是看你送了多少人。

## 内容配比

### 作用配比

| 作用 | 占比 | 为什么 |
|---|---|---|
| 流量型 | 45% | 账号阶段：还没发过视频,属于新号。新号的首要任务是拿到稳定流量和正反馈,所以**流量型必须是最大的一块**。工人刷到你的视频才会知道有你这个人,没有流量就没有后续信任和成交 |
| 人设型 | 25% | 你的服务（接送）靠的是工人信你这个人——"小张这人实在、会帮人"。人设型内容让看过的人记住你、信你,是深度信任的来源。占比不能太低,否则观众只记住"濮阳有个找工的",记不住"小张这个人" |
| 变现型 | 30% | 你的服务（接送）天然就是变现内容,每一条接送记录都在推动咨询。新号如果一开始就只发变现型内容,会被平台判定为广告号,流量起不来,所以从小头慢慢长上来。但你不是纯流量号,要的是精准客户,所以变现型可以稍微多一点,占到 30% |

**什么数据出现时切换配比**：
- 前 20 条主要验证流量能不能起来（播放量是否稳定在 X 以上、完播率是否在 X% 以上）
- 20 条之后看私信量：如果每周有 X 个以上的人私信咨询岗位,说明变现型内容有效,可以调整为**变现 40% / 人设 25% / 流量 35%**
- 如果 20 条后播放量稳定但私信量很少（每周不到 X 个）,说明信任还没建立够,保持现在的配比,继续补人设型和服务细节

---

### 形式配比

| 形式 | 占比 | 负责哪种作用 | 为什么 |
|---|---|---|---|
| 晒过程 | 50% | 流量型 30% + 变现型 20% | **主力形式**。门槛低（不需要口播能力,只需要把接送过程拍下来 + 工人说话 + 你的回应）;信任强（工人看到真实画面才信,比你讲一百句"我们很专业"都管用）;素材多（你每天都在跑,天天有接送素材）;变现直接（每一条接送记录都在证明"我真的在做"）。档案里"数据最好的内容类型"写的是"还没发过",按行业逻辑和你的资源,**晒过程是最适合你的** |
| 讲故事 | 25% | 人设型 25% | 人设要让人记住你这个人,而不只是记住"濮阳有个找工的"。故事能让人看到你的温度、你的边界、你为什么这么做。不讲自己的创业史（观众不关心）,讲**你送过的工人里让你印象深的那几个** |
| 教知识 | 20% | 变现型 10% + 流量型 10% | 变现型的教知识：工人最常问的问题和你的回答（年龄过不了怎么办、工资被克扣了找谁、黑中介的套路）;流量型的教知识：带反认知、冷知识钩子的（"工厂最怕收这 3 种人""为什么有的厂专门要年龄大的"）。纯行业干货受众窄,所以只占 20%,不是主力 |
| 聊观点 | 5% | 人设型或流量型（看观点是否连着你的经历） | 观点必须连着你自己的经历,才立得起人设。比如"我不认为找工就该自己去,有人管才不会被坑"（连着你的服务）。但观点类内容只靠老粉看,拿不到大流量,所以只占 5%,作为人设型的补充 |

**为什么主力是晒过程**：
账号阶段：新号,没有已验证的主力形式。按行业逻辑,工人看到真实画面（车里、体检点、厂门口）才信,所以先用晒过程集中跑 20-30 条,建立"这个人真的在做"的信任。等有数据后,如果发现故事类或知识类视频数据明显更好,再调整配比。

**变现型那一块为什么是晒过程 + 教知识**：
客人为什么买你（成交理由）：便利性（上门接送）、服务好（全程跟进）、选择多（岗位信息多）、专业强（对务工人群和进厂流程更了解）。这些理由要靠两样东西证明：
- 晒过程：拍你去村口接人、陪工人体检、送到厂门口（证明便利性 + 服务好）
- 教知识：讲年龄怎么过、工资怎么结算、黑中介的套路（证明专业强）

### 题材配比

- **主赛道（找工 / 进厂）60%**：这是你的专业,也是工人关心的核心
- **目标人群的兴趣 40%**：这部分是**流量型内容的来源**,覆盖更广（不只是想找工的人,所有打工人、所有有父母在打工的人都会看）,而且容易引发共鸣和讨论,帮你拿到更多曝光

**人群兴趣具体是哪几类**：
1. **挣钱养家**：在外打工的人过年回家最怕被问什么、夫妻俩一起进厂一个月能攒多少钱、50 岁的人还能去哪挣钱
2. **务工生活**：工厂宿舍的真实样子、厂里的饭菜、工友之间的关系、第一天进厂的感受
3. **普通人的难**：年龄大了找工作难、不识字怕出门被骗、出去一趟家里没人管、在家闲着被嫌弃出去又怕被坑

---

### 配比核验

1. **流量型是不是和账号阶段匹配？** 是。新号,流量型占 45%,是最大的一块 ✓
2. **主力形式是不是档案里数据最好的那一类？** 档案写"还没发过",按行业逻辑和资源推断,晒过程是最适合的;等有数据后再调整 ✓
3. **用户要大流量的话,行业干货是不是没当主力？** 档案没写要大流量,但教知识只占 20%,主力是晒过程（接送记录）+ 带钩子的泛知识,不是纯行业干货 ✓
4. **题材有没有给目标人群的兴趣留出 30-40%？** 有,40% 讲打工人的难 / 挣钱养家 / 务工生活,不只讲找工进厂 ✓
5. **每个数字都能说出"为什么是这个比例"吗？** 能。流量 45%（新号要拿流量）/ 人设 25%（建立深度信任）/ 变现 30%（接送记录天然就是变现内容）✓

## 三种视频怎么拍

### 流量型：让更多陌生人看到账号

**拍什么方向**：
1. **工人视角的进厂全过程**：从工人坐在你车里往外看（第一视角）,配上工人的内心独白——村口 → 上车 → 高速 → 体检点 → 厂门口
2. **地域差异**：濮阳工人去安徽厂 vs 去江苏厂 vs 去山东厂,工资、吃住、工作时长有什么不一样

---

#### 四大脚本（薛老师）

**主力形式**：泛知识（大众听得懂、愿意转述的）+ 晒过程（接送记录但要有反差或冲突）

**脚本结构 1：晒过程 · 火车节**
- 骨架：起因（带钩子）→ 关键步骤 → 结果
- 套到这个号：大姐上车第一句话问"年龄真能过吗"（钩子）→ 你边开车边回答,大姐还是不放心,又问了好几次 → 到了体检点,你陪她下车,说"走,我带你进去"（结果）
- **叠哪个爆款元素**：人群（"48 岁的大姐"圈定年龄偏大的工人）+ 反差（担心过不了 vs 最后真的过了）

**示范**：
- 标题：《48 岁的大姐上车问了我 3 遍"年龄真能过吗"》（人群 + 反差）
- 怎么拍：运动相机固定在副驾驶位,拍你开车 + 大姐坐在后排。大姐上车第一句话就问"年龄真能过吗",你回答"能过,咱们送去的好几个都 50 多了",大姐还是不放心,又问"那我要是过不了呢",你说"过不了我再帮你找别的厂"。到了体检点,你陪她下车,画面定格在你俩走进体检点的背影

---

**脚本结构 2：泛知识 · 反常识**
- 骨架：反常识结论（"你以为……其实……"）→ 大众熟悉的常规做法 → 实测或反证 → 一句话收住
- 套到这个号：工人都以为年龄大了进不了厂（常规认知）→ 其实有 3 种厂专门要年龄大的（反常识结论）→ 为什么（厂里看重踏实、不跳槽）→ 具体是哪 3 种厂（食品厂、包装厂、某些流水线）
- **叠哪个爆款元素**：反差（年龄大反而有优势）

**示范**：
- 标题：《年龄大了进不了厂？其实有 3 种厂专门要年龄大的》（反差）
- 怎么拍：你站在厂门口或车里口播,开头直接说"很多人以为年龄大了进不了厂,其实不是",然后讲 3 种厂：食品厂（要手脚麻利的、年龄大的稳）、包装厂（不累、年龄大的能坚持）、某些流水线（厂里看重踏实）。结尾一句话收住："你多大岁数了？评论区说说"

---

#### 起号 36 计（小黄）

**第 32 计 · 换个视角**：
- 公式：常规事件 + 新 POV → 新信息/情绪
- 套到这个号：不拍你送人的视角,拍**工人坐在你车里往外看的视角**——从村口出发 → 上高速 → 到体检点 → 到厂门口,配上工人的内心独白（"第一次出这么远""不知道厂里啥样""小张说没事,我就信他了"）

**示范**：
- 标题：《第一次去厂里,坐在小张车里的 2 小时》
- 怎么拍：用第一视角（工人的视角）拍,画面是车窗外的路、高速、体检点、厂门口。配音是工人的内心独白（可以你自己配,模拟工人的语气）："村口上车的时候我还在想,这次能不能过""小张说能过,我就信他了""高速上看着外面的车,想着这次要是干长久了,过年回家就有钱了""到体检点了,小张说陪我进去,心里踏实多了""终于到厂门口了,希望这次能干长久"

---

**第 31 计 · 南北/地域差异**：
- 公式：同一任务两地做 → 差异反应 → 原因/文化 → 交流
- 套到这个号：濮阳工人去安徽厂 vs 去江苏厂 vs 去山东厂,工资、吃住、工作时长有什么不一样 → 差异对比 → 原因（不同地方的厂类型不一样、管理方式不一样）→ "你想去哪边?评论区说"

**示范**：
- 标题：《濮阳工人去安徽厂和去江苏厂,差别有多大》（地域差异）
- 怎么拍：你站在车里或路边口播,开头说"很多人问我去安徽好还是去江苏好,其实差别挺大的"。然后对比：安徽的厂（食品厂多、包吃住、工资 X、工作时长 X）vs 江苏的厂（电子厂多、不包住、工资 X、工作时长 X）。最后问"你想去哪边?评论区说说"

---

**结尾行动指令**：评论（"你们那边也这样吗？评论区说说" / "你多大岁数了？评论区说说" / "你想去哪边？评论区说说"）

### 人设型：让人记住你、信你这个人

**拍什么方向**：
1. **你送过的工人里让你印象深的那几个**：50 多岁的大哥、不识字的大姐、夫妻结伴的、老客户带新客户的
2. **你和工人的关系**：工人问了你什么、你怎么回答的、后来怎么样了

#### 四大脚本（薛老师）

**主力形式**：讲故事

**脚本结构 1：小有成就 / 个人成就**
- 骨架：结果钩子 → 阻碍 1 → 转机 1 → 阻碍 2 → 转机 2 → 感悟
- 套到这个号：一个 50 多岁的大哥要去厂里（结果钩子）→ 一开始他很担心年龄过不了（阻碍 1）→ 你说"试试,我帮你跟厂里说"（转机 1）→ 到了厂里,厂里一看他年龄说不收（阻碍 2）→ 你帮他跟厂里说"大哥人实在,干活不偷懒",厂里同意了（转机 2）→ 大哥后来干了 X 个月,走的时候说"小张,下次我还找你"（感悟）
- **叠哪个爆款元素**：反差（年龄大 vs 最后真的过了）

**示范**：
- 标题：《X 岁的大哥上车前问了我 3 遍"厂里到底收不收"》（反差）
- 怎么拍：你站在车里或路边口播,或者配音 + 接送画面。开头说"前几天送了个 X 岁的大哥,上车前问了我 3 遍'厂里到底收不收'"。然后讲故事：大哥担心年龄 → 你说试试 → 到了厂里厂里说不收 → 你帮他跟厂里说 → 厂里同意了 → 大哥后来干得很好。结尾一句话："他走的时候说'小张,下次我还找你',我说'好,随时找我'"

---

**脚本结构 2：平凡英雄**
- 骨架：普通人 → 一件不普通的小事 → 细节验证 → 感悟
- 套到这个号：一个不识字的大姐要去厂里（普通人）→ 体检表她不会填,慌了（不普通的小事）→ 你帮她念、帮她填,还教她怎么签名（细节验证）→ 大姐说"要不是你,我真不敢来"（感悟）
- **叠哪个爆款元素**：共鸣（很多不识字的人都有这个顾虑）

**示范**：
- 标题：《她不识字,体检表我帮她念了一遍又一遍》（共鸣）
- 怎么拍：你站在体检点门口或车里口播,或者配音 + 体检点画面。开头说"前几天送了个大姐,她不识字,体检表不会填"。然后讲故事：大姐拿着体检表慌了 → 你帮她念、帮她填 → 还教她怎么签名 → 大姐说"要不是你,我真不敢来"。结尾一句话："这就是我做这个的原因,帮一个是一个"

---

#### 起号 36 计（小黄）

**第 8 计 · 加入人物关系**：
- 公式：主任务 + 关系角色出镜 + 互动结果
- 套到这个号：一个老客户带着他老乡来找你（关系角色出镜）→ 老乡问"小张靠谱吗",老客户说"我上次就是他送的,放心"（互动）→ 你把他们俩一起送走（结果）

**示范**：
- 标题：《老客户带着老乡来找我,老乡问了他一句话》
- 怎么拍：你在车里或路边,拍老客户和老乡一起上车。老乡问老客户"小张靠谱吗",老客户说"我上次就是他送的,放心,他不会把咱扔半路"。你在旁边说"放心,我不收你钱,到了厂里好好干就行"。画面是你把他们俩一起送走

---

**第 3 计 · 以物换物**：
- 公式：提出交换 → 协商 → 体验 → 挖掘人物 → 情感结果
- 套到这个号：一个工人说"小张,我没钱,能不能先欠着",你说"不用,我不收你钱,你到了厂里好好干就行"（提出交换）→ 工人很感动 → 后来他介绍了 X 个老乡来（情感结果）

**示范**：
- 标题：《他说没钱先欠着,我说不用,后来他带了 X 个老乡来》
- 怎么拍：你站在车里或路边口播,开头说"前几天一个工人跟我说'小张,我没钱,能不能先欠着',我说'不用,我不收你钱'"。然后讲故事：工人很感动 → 后来他在厂里干得很好 → 介绍了 X 个老乡来。结尾一句话："我不是为了钱,是为了帮咱普通人"

---

**结尾行动指令**：关注（"关注我,看更多工人的故事" / "关注小张,每天带你看真实的接送日常"）

### 变现型：推动咨询、到店、下单

**拍什么方向**：
1. **服务细节**：你去村口接人、陪工人体检、送到厂门口、回访工人
2. **找工知识**：年龄怎么过、工资怎么结算、黑中介的套路、怎么分辨黑中介

#### 四大脚本（薛老师）

**主力形式**：晒过程（服务细节）+ 教知识（找工避坑、流程讲解）

**脚本结构 1：晒过程 · 火车节**
- 骨架：起因（带钩子）→ 关键步骤 → 结果
- 套到这个号：一个大姐问"工资几号发、不干了怎么结算"（钩子）→ 你掏出手机给她看之前工人的【换成你的：工资到账截图、结算凭证等证据】,跟她讲清楚结算规则（关键步骤）→ 大姐放心了,上车（结果）
- **落在哪个成交理由上**：服务好（你会提前跟工人讲清楚规则）+ 专业强（你对结算流程很了解）

**示范**：
- 标题：《她上车前只问了我一个问题：工资几号发》
- 怎么拍：你在车里,大姐上车前问"工资几号发、不干了怎么结算"。你掏出手机给她看【换成你的：之前工人的工资到账截图、结算凭证】,跟她讲清楚"这个厂每月 X 号发工资,不干了提前 X 天说,工资会在 X 天内结清"。大姐点点头,上车了。结尾一句话："想去的私信我,我帮你看有没有合适的"

---

**脚本结构 2：教知识 · 行业避坑**
- 骨架：点名坑 → 后果 → 识别信号 → 替代方案
- 套到这个号：很多工人被黑中介坑过（点名坑）→ 被收了押金、到了厂里发现工资不对、出了事找不到人（后果）→ 怎么识别：黑中介有 3 个特点（识别信号）→ 正确做法：找像我这样的,不收你钱、全程陪着、有问题帮你说话（替代方案）
- **落在哪个成交理由上**：专业强（你知道黑中介的套路）+ 服务好（你不收钱、全程陪着）

**示范**：
- 标题：《黑中介的 3 个套路,你一定要知道》

## ⚠️ 不要做什么

### 1. 不要天天发岗位广告

**为什么**：像微信群里的招工信息,没区别,观众会直接划走。而且平台会判定为营销号,流量起不来。

**正确做法**：岗位信息放在私信里发,视频里只拍真实的接送记录和工人故事。

---

### 2. 不要只拍接送画面,不拍工人的顾虑和你的回应

**为什么**：只拍画面（开车、高速、厂门口）,观众只会想"这个人在路上",记不住你解决了什么问题。而且看着像跑腿,不是服务。

**正确做法**：每条视频都要拍工人问了什么、你怎么回答的、到了体检点你陪他做了什么——**把服务过程拍出来,而不是只拍结果**。

---

### 3. 不要承诺"保证安排""全程无忧""来了就能挣到钱"

**为什么**：这是承诺型中介的话,你一说就和黑中介没区别了。而且工人被骗怕了,越是把话说得太满越不信。

**正确做法**：用事实说话——"咱们送去的 X 个人里有好几个都……""我会帮你跟厂里问""去之前我会跟你说清楚这个厂的情况,你考虑好了再去"。
