# 实体获客编导-不一 · 知识库查询

# 实体获客编导的开头，怎么在前 3 秒留住人？

你的账号定位是**专业编导 IP + 本土服务商**，目标客户是濮阳的实体老板。这类人刷到视频时，**心里默认的第一个问题是："这跟我有啥关系？"** 前 3 秒的核心任务不是展示专业，而是让他觉得**"这说的不就是我吗"**或者**"这话不对劲，得听听"**。

---

## 一、你的开头现在可能在犯的错

❌ **"大家好,我是不一,做短视频代运营的……"**  
→ 观众心理:广告,划走

❌ **"今天教大家怎么拍爆款视频……"**  
→ 观众心理:跟我没关系,我又不是搞这个的

❌ **"濮阳的老板们,想做短视频的看过来……"**  
→ 观众心理:太直白,像推销

**问题根源:**  
这些开头都在「自我介绍」或「讲道理」,没有给观众**停下来的理由**。

---

## 二、6 种开头钩子,对应你的 3 种视频目的

### 【变现型】目标:推动老板咨询、关注账号、约见面
**用这 2 种钩子:**

#### 1. **痛点切入(圈定人群)**
直接说出老板当下最头疼的事,让他觉得"你懂我"。

**公式:** 场景难题 + 后果 + 低成本承诺

**示例:**
- *"濮阳开店的老板,如果你拍了十几条视频,播放量还不到 500,先别急着找人做付费推广。"*
- *"实体店老板最怕的不是没客人,是客人来了一次再也不回头——今天教你用一个动作让他记住你。"*
- *"很多濮阳老板找代运营,花了钱拍了片,结果一条都没火——问题可能不在拍摄上。"*

**为什么有效:**  
前 3 秒里出现「濮阳」「开店」「播放量 500」这种**具体场景词**,目标客户会本能停住。

#### 2. **反常识 / 行业避坑**
否定一个老板「以为对」的常识,制造认知冲突。

**公式:** 常见误区 + "其实应该看 XX"

**示例:**
- *"很多人以为短视频起号要先养号、刷同行——其实这是最浪费时间的。"*
- *"找代运营千万别一上来就问「多少钱一条」,真正坑人的在报价单后面。"*
- *"濮阳实体店做抖音,别学郑州那套——本地获客和全国引流根本不是一回事。"*

**为什么有效:**  
**否定句 + 熟悉场景**,让人产生「我是不是做错了」的焦虑,必须看下去验证。

---

### 【人设型】目标:让人记住你这个人,建立信任
**用这 2 种钩子:**

#### 3. **身份标签 + 真实细节**
用一个「反差」或「具体经历」建立记忆点。

**公式:** 身份 + 特质/经历 + 用户痛点

**示例:**
- *"我在濮阳做了 X 年编导,见过最多的不是没预算的老板,而是花了钱被坑的老板。"*
- *"我这人有个毛病:接单之前一定要先去店里坐半天,不了解老板我拍不出东西。"*
- *"我也开过实体店,那时候没有短视频,全靠发传单——现在轮到我帮濮阳老板少走弯路。"*

**为什么有效:**  
**地域词(濮阳)+ 真实细节(去店里坐半天)**,让人觉得你不是流水线代运营,是个有温度的人。

#### 4. **讲一个小故事的开头**
用「那一刻」或「这件事」制造悬念。

**公式:** 时间 + 意外事件 + 情绪

**示例:**
- *"上周有个濮阳老板找我,说他已经换了三家代运营,每家都承诺能火——结果账号粉丝还不到 200。"*
- 【换成你接待的真实客户：拍摄时客户对自己表现不满意或突然不想拍的经历，以及你当时怎么处理的】
- *"有个濮阳开火锅店的老板,第一次见面跟我说:我不信短视频能带客——两个月后他主动给我发了条消息。"*

**为什么有效:**  
**具体时间(上周/昨天)+ 冲突(换了三家 / 不想拍了)**,观众会想知道「后来怎么样了」。

---

### 【流量型】目标:让更多陌生人看到,扩大曝光
**用这 2 种钩子:**

#### 5. **冷知识 / 拆解**
说一个大多数人不知道的行业真相。

**公式:** 反常识结论 + 证据

**示例:**
- *"很多人以为抖音播放量低是因为没买 DOU+,其实平台根本不看你花没花钱——它只看前 5 秒有没有人划走。"*
- *"濮阳本地商家做抖音,有个不少人都不知道的设置——改完之后同城流量能明显提升。"*
- *"短视频代运营行业有个潜规则:报价越高不代表效果越好,很多时候是因为中间商多了一层。"*

**为什么有效:**  
**数字(90%)+ 利益(翻 3 倍)+ 秘密感(潜规则)**,让人觉得「不看会亏」。

#### 6. **地域差异 / 对比**
用濮阳 vs 其他城市制造话题性。

**公式:** 地域 A vs 地域 B + 差异点

**示例:**
- *"郑州的实体店老板拍短视频,喜欢租棚、打光、配团队——濮阳老板更适合一部手机、一个人、拍真实的。"*
- *"在北京做代运营,客户最关心涨粉;在濮阳,客户第一句话是:能不能帮我带客人进店?"*
- *"同样是开饭店,郑州老板喜欢拍菜品特写,濮阳老板更适合拍老板跟客人唠嗑——因为本地获客靠的是人情。"*

**为什么有效:**  
**地域词(濮阳 / 郑州)+ 对比**,本地人会本能关注「说的是不是我」。

## 四、给你的 3 条实操建议

### 1. **变现型视频:开头必须圈濮阳 + 实体老板**
你的客户不是全国的内容创作者,是**濮阳本地有门店、想用短视频获客的老板**。开头不说「濮阳」「实体店」,就是在浪费流量。

**错误示范:**  
*"今天教大家怎么写短视频脚本……"*

**正确示范:**  
*"濮阳开店的老板,如果你不知道第一条视频拍什么,先别急着抄同行——今天给你一个最快起号的选题。"*

### 2. **人设型视频:多讲「我在濮阳遇到的老板」,少讲方法论**
你的差异化是**本土化 + 有温度**,不是教学能力。人设视频的目的是让人记住你、信你,不是让人学会。

**适合你的开头:**
- *"昨天有个濮阳老板跟我说……"*
- *"我这人接单有个原则……"*
- *"在濮阳做了这么多年,我发现……"*

### 3. **流量型视频:借「濮阳 vs 其他城市」制造话题**
你在本地做,这本身就是内容。用**地域对比 + 反常识**,能拿到更大的自然流量。

**示例:**
- *"郑州代运营报价动不动上万,濮阳老板更需要的是……"*
- *"一线城市做短视频卷剪辑特效,濮阳实体店其实更适合……"*

## 五、总结:前 3 秒的唯一任务

**不是展示专业,是让对的人停下来。**

- **变现型** → 痛点 + 濮阳 + 实体老板
- **人设型** → 真实故事 + 温度 + 本地细节
- **流量型** → 冷知识 + 地域对比 + 反常识
