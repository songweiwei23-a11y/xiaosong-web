## 🎯 主攻打法：第31计·南北/地域差异

### 为什么是你能拍的

- **团队资源匹配**：2-3人小团队，一部手机就够。拍法：左边画面（或前半段）展示成都吃法，右边画面（或后半段）展示南乐吃法，用画中画、分屏或前后对比剪辑即可完成，不需要多机位、不需要演员
- **真实素材充足**：成都厨子做川菜9年，来南乐半年，每天都在经历"成都吃法 vs 南乐吃法"的差异（客人点单、口味要求、吃法习惯）。这些都是真实场景，不需要编造，拍的时候自然发生
- **身份背书天然**：出镜人是成都来的川菜厨师，做川菜9年，这个身份本身就是"地域权威"——他说成都怎么吃，观众信；他观察到南乐怎么吃，也是第一手的
- **场地可用**：店铺（地摊场景）就是最好的拍摄场地。操作台、炉子、客人座位、串串火锅烧烤的成品——全都是现成的视觉素材
- **覆盖面广**：地域差异不只是本地人看，全国对川菜、串串感兴趣的人都会点进来（"原来成都是这么吃的""我们这边也是干碟"），适合冷启动拿陌生流量

### 结构公式（套到你这个号上）

**第31计·南北/地域差异**：同一任务两地做 → 差异反应 → 原因/文化 → 交流

**套到你这个号上**：
1. **同一任务两地做**：同一道菜/同一个吃法，成都怎么吃 vs 南乐怎么吃。画面：左边成都吃法（或前半段），右边南乐吃法（或后半段）
2. **差异反应**：成都厨子刚来南乐时，按成都吃法给客人配菜/调料/锅底，结果客人说"不习惯""不是这样的"
3. **原因/文化**：为什么会有这个差异？气候、口味习惯、历史原因（成都湿气重所以麻辣重，南乐偏辣不太麻）
4. **交流**：结尾不下结论"哪种对"，而是邀请观众参与："所以别问我'正宗川味是啥'，你吃着爽就是正宗。评论区说说，你们那边怎么吃？"

### 配什么脚本讲

**这一计管事件怎么走**（成都吃法 → 南乐吃法 → 差异反应 → 交流），**话怎么讲从四大脚本里配一个结构**：

**配：晒过程·火车节**（起因钩子 → 关键步骤 → 结果）

**为什么配它**：
- 地域差异本身是"过程"——不是口播讲知识，而是**拍两地真实的吃法、真实的客人反应**。过程 = 信任 = 变现
- 晒过程能自然导向变现：拍完成都 vs 南乐的差异后，结尾可以说"所以我们两种都准备，你们想怎么吃就怎么吃。地址评论区置顶，也可以团购"——既完成了流量（地域话题引评论），也为变现埋了钩子

**具体怎么讲**（叠加后的完整结构）：
1. **起因钩子**（对应"同一任务两地做"）：开篇一句话点出差异，比如"成都人吃串串和南乐人吃串串，差别有多大？"
2. **关键步骤**（对应"差异反应 + 原因"）：画面对比展示两地吃法，配旁白讲差异的原因。比如：左边成都吃法（油碟、干碟都有），右边南乐吃法（干碟+辣椒面）；旁白："刚来南乐时，我按成都吃法给客人配油碟，结果大家都说'不习惯'。后来我才知道，南乐人喜欢干碟+辣椒面，吃着更过瘾。现在我两种都准备，你们想怎么吃就怎么吃"
3. **结果**（对应"交流"）：成都厨子出镜总结："所以别问我'正宗川味是啥'，你吃着爽就是正宗。评论区说说，你们那边怎么吃？"

### 边界（什么不能碰）

从第31计·地域差异的边界里挑对你适用的：

1. **不能编造地域差异**：成都 vs 南乐的差异必须是真实的（成都厨子9年经验里见过的、来南乐半年真实经历的）。档案没写过的差异，标【换成你自己观察到的真实差异：……】，不能编
2. **不能贬低任何一方**：不能说"成都吃法高级、南乐吃法low"或"南乐吃法实在、成都吃法装"。正确做法：两种都是合理的、各有文化背景，结尾邀请观众参与"你们那边是哪种"
3. **不能只在标题提一句、正文不展开**：地域差异必须落在**画面对比**上（左边成都、右边南乐，或者前半段成都、后半段南乐），不能只是口播说"成都和南乐不一样"就过了
4. **不能拍成"知识科普"**：地域差异的核心是**真实反应**（客人说"不习惯""太麻了"），不是只讲知识（"成都湿气重所以麻辣重"）。知识可以讲，但必须连着真实的人和事
5. **不能违反档案禁忌**：档案写了「禁止刻意营销口吻」「不能承诺疗效或效果」——地域差异的结尾不能写成"所以我们家最正宗""来我们店就对了"，只能邀请评论"你们那边是哪种"

### 第36计·冷知识【流量型】

**什么情况下切过去**：
- 地域差异拍5条后，需要补充新的流量入口（地域差异的话题有天花板，不能一直拍"成都 vs 南乐"）
- 或者想扩大覆盖人群（冷知识不只是本地人看，全国对川菜、串串感兴趣的人都会点进来）

**一句话说明怎么套到你这个号上**：
反常识结论（"你以为川菜就是辣，其实……"）→ 证据/例子（成都厨子9年经验里的真实案例）→ 原理（为什么会这样）→ 应用（"所以下次吃串串，你可以……"）

**配哪个四大脚本结构讲**：
**冷知识结构**（反常识结论 → 证据/例子 → 原理 → 应用）——不另套其他脚本，直接按这一计的公式拍

**标题示例**：
《一元一串的火锅，老板能赚多少？》【爆款元素：成本】

---

### 第10计·情境还原【变现型】

**什么情况下切过去**：
- 流量稳定后（单条播放稳定在X以上，评论区有本地人问地址），需要加大变现型内容比例，推动团购和到店
- 或者评论区有很多人问"怎么点""50块够吗"——说明用户有兴趣但不知道怎么消费，情境还原可以解决这个障碍

**一句话说明怎么套到你这个号上**：
真实任务（第一次来的客人不知道怎么点）→ 对话/纠错（厨子："先来20串一元火锅打底，再看"）→ 旁观学习（其他客人看到，也跟着点）→ 结果（客人吃完说"这个方法好"）

**配哪个四大脚本结构讲**：
**晒过程·火车节**（起因钩子 → 关键步骤 → 结果）+ **教知识·推荐型**（美好愿景 → 圈定人群 → 引发好奇 → 推荐理由12345）——两个结构叠加：晒过程管画面（拍真实点单过程），教知识管话怎么讲（"第一步先来20串打底，第二步再点烧烤"）

**标题示例**：
《第一次来的客人，都不知道怎么点》【爆款元素：人群】

## 🧪 怎么测

### 一次只改哪个变量

- **第1-5条（主攻：第31计·地域差异）**：只测**选题角度**（成都vs南乐的哪个差异最能引发讨论）。开篇钩子、脚本结构、拍摄手法都固定不变——开篇都是"成都XX和南乐XX，差别有多大？"，结构都是"同一任务两地做 → 差异反应 → 原因 → 交流"，拍摄都是"左右对比或前后对比"
- **第6-10条（备选：第1计·反向操作 或 第36计·冷知识）**：如果第1-5条地域差异跑通了（评论区讨论热度高、本地人开始问地址），就继续拍地域差异；如果评论区讨论热度下降，就切到反向操作或冷知识。切的时候只改**事件走向**（地域对比 → 反向操作 或 冷知识），开篇钩子和结尾行动指令不变
- **第11-20条（加入变现：第10计·情境还原）**：流量稳定后，加大变现型内容。只测**变现型的脚本结构**（情境还原 + 晒过程·火车节 vs 情境还原 + 教知识·推荐型，哪个转化更好）

### 每计测几条、看什么指标

- **第31计·地域差异（流量型）**：测5条，看**评论区讨论热度**（每条评论数、评论里有多少人说"我们那边也是""我们那边不一样"）+ **非关注用户播放占比**（目标：70%以上）+ **分享数**（地域话题容易被转发）

- **第10计·情境还原（变现型）**：测5条,看**评论区"怎么点""50块够吗"这类咨询减少**（说明视频已经解决了这个问题）+ **团购订单增长**

## 📊 跑不通先查哪里

挑最可能出现的3种情况：

### 情况1：前5条曝光少（播放量X以下）

**优先怀疑**：
- 选题太窄（地域差异的话题只在"成都 vs 南乐"这一个维度，覆盖面不够）
- 账号标签不清（三个品类轮着拍：今天串串火锅、明天烧烤、后天川菜小炒，算法不知道该推给谁）
- 违规或低质（画面模糊、声音不清、违反平台规则）

**下一步做什么实验**：
- 换更广的入口：从"成都 vs 南乐"扩展到"成都 vs 全国其他地方"（比如《成都人吃串串和北京人吃串串，差别有多大？》），或者从地域差异切到冷知识（《一元一串的火锅，老板能赚多少？》）
- 连发同主题：前5条全拍"地域差异"，不要今天地域差异、明天反向操作、后天冷知识轮着来——让算法先认准你是"讲地域差异的"，标签清晰了才给流量
- 查合规：检查画面、声音、文案有没有违规（没有"拆解""曝光"""这类词；没有贬低同行；没有承诺疗效）

---

### 情况2：有曝光但前段流失（完播率X%以下）

**优先怀疑**：
- 首帧弱（第一帧画面不吸引人，比如只拍了一个操作台、没有人）
- 第一句空泛（开篇没有钩子，比如"大家好我是成都来的川菜厨师"——没人想听自我介绍）
- 承诺不清（看了3秒还不知道这条视频要讲什么）

**下一步做什么实验**：
- 重写5个开篇钩子：
  1. **金钱型**："一元一串的火锅，老板能赚多少？"
  2. **盲盒型**："今天有个客人点单，我愣了三秒"
  3. **对抗/反常识型**："我不认为地摊就是low"
  4. **验证解密型**："判断串串新不新鲜，不看颜色看这里"
  5. **地域差异型**："成都人吃串串和南乐人吃串串，差别有多大？"
- 结果或冲突前置：开篇第一句就说结果（"成都人吃串串和南乐人吃串串，差别有多大？"），不要铺垫半天才进入主题
- 首帧换成"人 + 动作"：不要只拍操作台，要拍成都厨子的脸 + 他在做什么（穿串、调锅底、和客人说话）

---

### 情况3：播放高但问地址的少（流量有了、转化没起来）

**优先怀疑**：
- 专业证据不足（只讲地域差异、没讲手艺和过程，客人觉得"有意思但不知道你做得好不好"）
- 承接入口不清（评论区没有置顶地址，客人不知道去哪）
- 变现型内容太少（前10条都是流量型，没有变现型内容推动到店）

**下一步做什么实验**：
- 补案例和过程：加大第10计·情境还原和第1计·反向操作的比例（每周3-4条变现型内容），拍真实的服务过程（客人点单 → 厨子穿串 → 客人吃 → 客人说"值"）
- 清晰主页引导：每条变现型内容结尾固定说"地址评论区置顶，也可以团购"；主页简介写清"地址：X，团购搜【店名】"
- 拍团购核销过程：证明"团购是真的、客人真的在用"（客人出示团购券 → 核销 → 吃的场景）
