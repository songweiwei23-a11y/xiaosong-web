# 🎯 账号定位方案

## 📌 核心结论（先看这 8 条）

1. **这是什么号**：本地服务商（to C）+ 濮阳本地帮找工人找进厂岗位、全程接送跟踪的小张
2. **给谁看**：30-50岁、想去工厂挣钱但不懂流程、怕被骗怕麻烦、在家闲着或刚失业需要重新找活的普通人
3. **人设标签**：自己开车跑全程、从村口接人到厂门口送到的濮阳找工人
4. **主打内容**：流量45% / 人设25% / 变现30%，主力形式是晒过程（接送记录 + 真实对话），因为门槛低、信任强、每天有素材
5. **怎么赚钱**：看视频 → 私信或电话 → 问岗位条件 → 匹配 → 接送上岗 → 后续回访（服务费来自工厂端，工人不付钱）
6. **第一条拍什么**：变现型·晒过程，车里接一个大姐去体检，大姐上车第一句话问"年龄真能过吗"，你边开车边回答，到了体检点送她下车——落在"便利性 + 服务好"两个成交理由上
7. **最该避开的坑**：天天发岗位广告（像中介）；只拍接送画面不拍人的顾虑和你的回应（看着像跑腿）；承诺"力求安排""来了就能挣到钱"
8. **多久能看出跑没跑通**：20 条之后看私信量和到第几条有人真找你——不是看播放量

## 🔍 先说这一行

**归口**：本地服务（to C），准确说是"劳务中介 + 陪同服务"的组合。但和传统中介的区别在于：传统中介是发岗位信息让工人自己去，你是全程接送 + 陪同体检 + 送到厂门口。

**这行的钱怎么赚**：
- 收入来自工厂端（工厂给中介的招工费，按人头结算），工人不付钱
- 毛利看工厂给的返费标准（短期工、长期工、不同地区不同），单人从几百到上千不等
- 获客成本：线下靠老客户带新客户（亲戚朋友、同村人），线上靠短视频和同城流量
- **关键卡点**：工人流失率高（到了厂里干几天就走，中介拿不到全额返费）；工厂端账期长（人干满一个月才结算）

**客人的决策链路**：
这个行业的特殊性在于**决策快但信任门槛极高**。工人看到视频后不会马上联系你，他会：
1. 先潜水看你发的其他视频（看你是不是真的天天在跑、送的人是不是真实的）
2. 问身边人"你认识这个人吗""他靠谱吗"（熟人口碑极重要）
3. 私信试探性地问"我这个年龄能过吗""工资真有那么高吗"（防骗心理很重）
4. 决定了才会打电话详细问，然后约时间接送

从看到视频到真联系你，**快的当天，慢的观察你一两周**。一旦建立信任，他会带亲戚朋友一起来——这就是你档案里说的"老员工愿意再次找他并带亲戚朋友"的逻辑。

**时间规律**：
- **旺季**：年后（正月十五到三月）、秋季开学后（九月到十月，家长要攒学费）、双十一前后（电商工厂招短期工）
- **淡季**：过年前一个月到正月十五（工厂不招人、工人要回家）、农忙时（麦收、秋收）
- **时段**：工人刷视频集中在晚上 7-10 点（干完活躺床上刷手机），早上 6-8 点（还没起床刷一会儿）
- **节点**：孩子开学前、过完年手里没钱了、家里有人生病急需用钱、在上一个厂干得不顺

**这行老板普遍会犯的错**：
1. **自嗨点 1**：觉得自己岗位资源多就是优势——其实工人根本分不清你对接的是哪个厂，他只关心"你能不能把我安全送到、路上会不会出幺蛾子"
2. **自嗨点 2**：拼命强调工资高、福利好——工人被骗怕了,越是把工资说得天花乱坠越不信,他更想知道"去的人后来怎么样了"
3. **自嗨点 3**：天天发岗位广告(今天招操作工、明天招包装工)——这和微信群里发招工信息没区别,看着像中介而不是服务者
4. **踩坑最狠的**：只拍接送画面(开车、高速、厂门口),不拍工人的顾虑和你的回应——观众看完只记住"这个人天天在路上",记不住你解决了什么问题

**同行现在都在拍什么**：
- **招工广告型**：每天发岗位(某某厂招工、工资 X、包吃住)——像牛皮癣,没人看
- **跑路 Vlog 型**：拍自己开车、拍高速、拍厂门口——画面是有了,但工人不关心你去了哪,他关心"我去了会怎样"
- **工资展示型**：晒工资单、晒银行卡到账——容易被平台判搬运或夸大宣传,而且工人会觉得"别人拿得到,我不一定"
- **为什么大多没效果**：没有建立"这个人真的在帮我"的信任。工人要的不是岗位信息(抖音上、微信群里到处都是),要的是"有人管我、不让我被骗、遇到事能帮我说话"——**这个空档就是你的机会**

## 🗣 我会先问老板的几个问题

- **你跑了多久了?送过多少人了?**
  - **我的推测**：从你能开车接送、对流程熟悉、老客户愿意带人来看,至少干了一两年,送过的人数应该在几十到上百之间(这个数字是信任证据,要确认)
  - 待老板确认

- **真正让工人愿意找你、而不是找别人的理由是什么?——不是你以为的,是工人嘴上说的那句话**
  - **我的推测**：档案里写了"上门接送、全程跟进",但我猜工人真正的话是"找小张放心,他不会把我扔半路""他会帮我问厂里""他送去的厂不坑人"——**这才是顾客感受到的差异化,不是"岗位信息多"(信息到处都有)**
  - 待老板确认

- **送去的工人里,有没有让你印象特别深的?为什么?**
  - **我的推测**：肯定有。可能是一个 50 多岁的大哥上车前反复问"年龄真能过吗",结果你帮他过了;可能是一对夫妻要求住一个宿舍,你帮他们跟厂里协调成了;可能是一个大姐不识字,体检表你帮她念、帮她填——**这些具体的事才是人设和内容的原料**
  - 待老板确认

- **工人最常问的三个问题是什么?你怎么回答的?**
  - **我的推测**：档案里写了"年龄能不能过、工资几号发、厂里累不累",但我想知道你当时是怎么回答的——是直接说"能过",还是说"咱们送去的 X 个人里有好几个都 50 多了,厂里看人实在就收"(后者更可信)
  - 待老板确认

- **你见过最坑工人的中介是怎么坑的?你和他的区别在哪?**
  - **我的推测**：可能是收了工人的"押金"然后消失;可能是把人送到厂里就不管了,工人被厂里克扣工资也找不到人;可能是夸大工资、隐瞒加班时长。你的区别应该是"不收工人钱、送到之后还会回访、有问题帮工人跟厂里说话"——**这个对比要在内容里反复讲,打消工人的防骗心理**
  - 待老板确认

- **老客户带新人来的时候,新人第一句话一般问什么?**
  - **我的推测**：新人会问老客户"你上次去的那个厂怎么样""小张这个人靠谱吗",老客户的回答就是你最真实的口碑——**把这些对话录下来,就是最好的信任证据**
  - 待老板确认

## 一句话定位

濮阳本地、自己开车从村口接人到厂门口、全程跟着不让你被坑的找工人小张

**说明**：这句话包含了地域(濮阳本地)、身份(找工人)、核心价值(自己开车接送 + 全程跟着不让被坑)。"从村口到厂门口"是具体动作,比"上门接送"更有画面感;"全程跟着不让你被坑"直接回应了工人最大的顾虑。

## 六维地基

### 1. 人设定位

**原料在哪**：
档案里这几句是真材料：
- "可以开车接送工人到集合点体检点厂区,全程跟进沟通匹配岗位到送达"——这是具体行为
- "老客户愿意再次找他并带亲戚朋友"——这是信任证据
- "对务工人群和进厂流程更了解"——这是专业性

但档案里这些是形容词,不是人设：
- "实用、接地气、专业"——任何账号都能说
- "亲切朋友式"——要翻译成具体行为

**翻译过来是什么**：
"亲切朋友式"可能是"工人在车上说家里的事,你会接话、会劝、会帮着出主意";"对务工人群更了解"可能是"你知道 50 岁的大哥最怕年龄过不了、夫妻结伴的最在意能不能住一起、不识字的大姐需要你帮她念体检单"——**这些具体的理解才是人设**。

**人设标签句**：
自己开车跑全程、从村口接人到厂门口送到的濮阳找工人

**用了哪个入口**：
职业 + 具体行为。不是"劳务中介",是"自己开车接送的找工人"——后者让人能想象出你在干什么。

**验证**：
- 是否可持续?可以。你每天都在跑,天天有接送素材,不是一次性噱头
- 线下能保持吗?能。你本来就是这么干的,不是为了拍视频装出来的
- 能被反复证明吗?能。每一条接送视频都在证明"这个人真的在跑、真的从村口接、真的送到厂门口"

**在同行里的位置**：
- 同行大多是**信息发布型**(只发岗位广告、工资待遇)或**跑路 Vlog 型**(只拍自己开车、拍高速)
- 你的差异在于**全程陪同 + 真实对话**：不只拍"我去送人了",要拍"工人上车问了什么、你怎么回答的、到了体检点你帮他做了什么"——**把服务过程拍出来,而不是只拍结果**

**证据链**：
接下来靠这 4 类内容持续证明：
1. **接送记录**(晒过程)：车里、体检点、厂门口的真实画面 + 工人的顾虑和你的回应
2. **工人故事**(讲故事 / 人设型)：印象深的工人、为什么你记住他、后来怎么样了
3. **找工知识**(教知识 / 变现型)：年龄怎么过、体检查什么、工资怎么结算、怎么分辨黑中介
4. **老员工回访**(变现型)：之前送去的人现在干得怎么样、工资拿到没、愿不愿意介绍老乡来

**边界**：
什么话一说人设就崩：
- "力求安排""来了就能挣到钱""全程无忧"——这是承诺型中介的话,你一说就和黑中介没区别了
- "全濮阳福利较高""我们专业"——绝对化用语,平台不让说,工人也不信
- 诋毁同行("那谁谁就是骗子")——档案明确写了不能诋毁,而且一诋毁别人,工人会觉得你也不干净
- **正确的说法是**："咱们这么做(具体描述你的服务)""我送去的 X 个人里有好几个都……(用事实说话)"

### 2. 用户定位

**一句话画像**：
30-50 岁、在家闲着或刚失业、想去工厂挣钱但不懂流程、怕被骗怕麻烦、老婆孩子在家等着用钱、可能不识字或识字不多、没出过远门或上次出去被坑过、听说进厂能挣钱但不知道找谁的濮阳周边普通人

**为什么是他们、不是另一批**：
- **不是年轻的厂妹厂哥**(18-25 岁)——他们自己会在网上找、不需要人接送、对你的服务不感冒
- **不是有稳定工作的人**——他们不需要进厂
- **不是完全没能力出门的**(60 岁以上、身体不好的)——工厂不收,你也送不进去
- **不是想挣快钱、不踏实干的**——这种人干几天就走,你拿不到返费,不如一开始就不接

**他们心里真正在想什么**：
嘴上问的是"年龄能过吗""工资几号发",心里想的是：
- "这个人会不会把我卖了"(被骗怕了)
- "我去了是不是就没人管了"(怕被扔半路)
- "万一厂里不给工资,我找谁"(怕维权无门)
- "我一个人去,人生地不熟,出了事怎么办"(缺安全感)
- **最深层的那句话是**："我就是想找个靠谱的人,带我去、别坑我、有事能帮我说话"

**决策链路**：
1. 刷到你的视频(可能是同城推荐、可能是搜"濮阳找工作")
2. 不会马上联系,先翻你主页看其他视频——看你是不是天天在发、送的人是不是真实的、有没有工人出镜说话
3. 可能会截图发给老婆 / 朋友问"你认识这个人吗"
4. 犹豫几天,或者看到你又发了新视频(接送记录 / 工人反馈),觉得"这人应该靠谱"
5. 私信试探:"我 48 岁了,能去吗""你说的那个厂在哪"
6. 你回复后,他可能还会再观察几天,或者直接打电话详细问
7. 约好时间,你去接他——**这个过程短则 1-3 天,长则一两周**

**这决定了内容要铺多长的信任**：不能只发一两条就指望工人来找你,要持续发、反复证明"我真的在做、我送去的人真的挣到钱了",才能打消他的顾虑。

**什么时刻会想起你**：
- 孩子开学,手里没钱了
- 过完年,存款花光了,要出去挣钱
- 在上一个厂干得不顺,被克扣工资,想换个地方
- 老婆 / 兄弟说"你也别在家闲着了,出去找个活干"
- 村里有人说"谁谁跟着小张去厂里了,听说还不错"
- **晚上躺床上刷手机,刷到你的视频,想起来"我也该出去了"**

**他在平台上搜什么**：
"濮阳找工作""濮阳进厂""濮阳招工""附近工厂招工""50 岁能进的厂""夫妻工""包吃住的厂"——**这些词要在你的视频标题、文案、话题标签里反复出现**

### 3. 内容定位

**长期提供什么价值**：
让不懂流程、怕被骗的普通人知道去哪个厂、怎么去、路上有人管

**内容方向**：
**多元四类**(知识 / 故事 / 晒过程 / 观点四类都发),不做单一主题。

**理由**：
单一主题(比如"体验 100 种工厂")需要极强的策划和执行能力,而且你的核心价值不是"带观众看工厂有多好玩",是"让工人信任你、找你"——信任需要多个角度建立:晒过程让他看到你真的在做,故事让他记住你这个人,知识让他觉得你专业,观点(如果有)让他觉得你懂他。四类配合,比单一主题更适合你现在的阶段和资源。

**当前阶段配比**：

**第一层 · 作用配比**：流量型 45% / 人设型 25% / 变现型 30%

**依据**：
- 账号阶段:还没发过视频,属于新号。新号的首要任务是拿到稳定流量和正反馈,所以**流量型必须是最大的一块**
- 用户目标:档案没写要大流量,说明你要的是精准客户,不是泛粉——但新号如果一开始就只发变现型内容,会被平台判定为广告号,流量起不来。所以**流量型先占大头,变现型从小头慢慢长上来**
- 为什么不是 50/20/30:因为你的服务(接送)天然就是变现内容,每一条接送记录都在推动咨询,所以变现型可以稍微多一点,占到 30%

**第二层 · 每一块用什么形式做**：

**流量型 45%**,主力形式是**晒过程**(接送记录 + 真实对话)+ 部分知识(带反认知、冷知识钩子的)
- **为什么是晒过程**:起号快、门槛低、每天有素材(你天天在跑)、信任强(工人看到真实画面才信)
- **为什么不是教知识**:纯行业干货(怎么挑工厂、怎么看合同)受众窄,流量上限低;只有带反认知、冷知识钩子的知识(比如"工厂最怕收这 3 种人")才能拿到大流量
- **流量型的晒过程怎么拍**:不只拍"我去送人了",要拍**工人的反应和你的回应**——比如大姐上车第一句话问"年龄真能过吗",你边开车边回答"咱们送去的好几个都 50 多了,厂里看人实在就收";到了体检点,大姐不识字,你帮她念体检单、帮她填表——**这些细节让陌生人看到"这个人真的在帮",而不只是"这个人在跑业务"**
- **起号 36 计里适合它的**:第 32 计 换个视角(工人视角看进厂)、第 35 计 街头采访(问刚下班的工人"在厂里干得怎么样")、第 31 计 地域差异(濮阳工人去安徽 / 江苏 / 山东,不同地方的厂有什么不一样)

**人设型 25%**,主力形式是**讲故事**(工人故事 + 你和工人的关系)
- **为什么是讲故事**:人设要让人记住你这个人,而不只是记住"濮阳有个找工的"。故事能让人看到你的温度、你的边界、你为什么这么做
- **人设型的故事怎么讲**:不讲自己的创业史(观众不关心),讲**你送过的工人里让你印象深的那几个**——比如 50 多岁的大哥上车前问了你 3 遍"年龄真能过吗",你帮他过了,他后来干了 3 个月,走的时候说"小张,下次我还找你";比如一对夫妻要求住一个宿舍,你帮他们跟厂里协调,最后厂里同意了,夫妻俩很感激——**这些故事让观众看到"小张这个人实在、会帮人",而不只是"小张会送人"**
- **脚本结构**:小有成就型(帮一个大哥过了年龄关 → 一开始厂里不收 → 你帮他跟厂里说 → 厂里看人实在就收了 → 大哥后来干得很好)、平凡英雄型(一个不识字的大姐 → 体检表她不会填 → 你帮她念、帮她填 → 她说"要不是你,我真不敢来")
- **起号 36 计里适合它的**:第 3 计 以物换物(用你的服务换工人的信任和口碑)、第 8 计 加入人物关系(工人和你的关系、老客户带新客户)

**变现型 30%**,主力形式是**晒过程**(服务细节)+ **教知识**(找工避坑、流程讲解)

### 5. 风格调性

**正向匹配还是有意反差**：
正向匹配

**理由**：
你的服务对象是普通打工人,他们要的是"靠谱、实在、能信得过",不是"高大上、很厉害"。所以从头像、语言到画面都要**接地气、真实、像朋友**,而不是包装成"专业机构""高端服务"——那样反而会让工人觉得"这不是给我们这种人用的"

**气质关键词**：
实在、接地气、有人情味

**会说的一句话 / 不会说的一句话**：

**会说**：
- "大哥,别担心,我送去的好几个都 50 多了,厂里看人实在就收"
- "到了给我打电话,有啥事我帮你问"
- "你先干着,不行咱再换,反正我这岗位多"

**不会说**：
- "我们公司专业从事劳务派遣业务多年"(太正式,像推销)
- "力求安排、全程无忧"(承诺型话术,像黑中介)

- 配音(工人口吻):"第一次出这么远,说不紧张是假的""小张说这个厂靠谱,我就信他了""到体检点了,小张说陪我进去,心里踏实多了""终于到厂门口了,希望这次能干长久"

**为什么服务目标用户而不是自嗨**：
工人刷视频的时候,看到"某某厂招工"会直接划走(到处都是,看腻了),但看到"一个和我一样的人坐在车里、第一次去厂里、心里也紧张"会停下来看——因为**这是他自己的处境,他想知道"去了会怎么样"**。这个视角让陌生人产生代入感,比你站在镜头前讲"我们服务好"有用一百倍。

---

**第二组**：

**常规 A**：
同行的接送视频大多是**跑路 Vlog 型**——拍自己开车、拍高速、拍厂门口,配音或字幕是"今天送了 X 个人""又是忙碌的一天",没有工人的声音和互动

**变量 B**：
从 24 元素里选**加入人物关系**(人物类)

**A+B 长什么样**：
接送视频里**让工人出镜说话**(征得同意、可以只拍背影或打码),重点拍**工人问了什么、你怎么回答的**——比如:
- 画面:大姐上车,坐在后排
- 大姐(画外音或背影):"小张,年龄真能过吗?我都 48 了"
- 你(边开车边回头说):"能过,大姐,咱们送去的好几个都 50 多了,厂里看人实在就收"
- 大姐:"那我要是过不了呢?"
- 你:"过不了我再帮你找别的厂,肯定给你安排上"
- 画面:大姐点点头,看向窗外

**为什么服务目标用户而不是自嗨**：
观众(潜在客户)看到这段对话,会想"这个大姐问的就是我想问的""小张的回答让我觉得靠谱"——**工人的顾虑 + 你的回应 = 信任建立**。而如果只拍你自己开车,观众只会想"这个人在路上",记不住你解决了什么问题。

---

**第三组**：

**常规 A**：
同行讲"找工知识"大多是**纯口播讲解型**——站在镜头前,一条一条列"进厂要注意什么""怎么挑工厂",像老师讲课

**变量 B**：
从 24 元素里选**正确 VS 错误**(行为类)

**A+B 长什么样**：
不只讲"正确做法是什么",先演示**错误做法 + 后果**,再演示**正确做法**——比如:
- 场景:找工人被黑中介坑
- 画面 1(错误做法):工人加了一个"招工中介"的微信,中介说"先交 500 押金,到了厂里退给你" → 工人转了 500 → 中介拉黑,钱要不回来
- 画面 2(后果):工人坐在路边,手里拿着手机,一脸懵
- 画面 3(正确做法):工人找到小张,小张说"我不收你钱,到了厂里你好好干就行" → 小张开车接他 → 送到厂门口
- 画面 4(对比结果):工人给家里打电话:"妈,我到了,这次没被骗"

**为什么服务目标用户而不是自嗨**：
工人被骗怕了,你光说"我不骗人"他不信——但你演示一遍"黑中介怎么骗、你怎么做",他看完会想"对,我之前就是这么被坑的,小张这么做才对"。**对比比讲道理有用。**

## 📇 账号五件套(可以今天就改)

**头像**：
你本人正面照(在车里、手扶方向盘、看镜头、表情自然),背景是车窗外的路

**为什么这么拍**：
- 真人出镜,建立信任(工人要看到你是真人,不是公司logo)
- 车是你的工作场景,一看就知道"这个人是开车接送的"
- 不要用证件照(太正式),也不要用生活照(比如旅游、吃饭),要用**工作场景里的你**

**昵称(给出 2-3 个备选)**：
1. 小张找工·濮阳接送(推荐)
2. 濮阳小张·找工接送
3. 小张·濮阳本地找工的

**为什么是这几个**：
- "小张"是你的真实称呼,接地气,工人好记
- "濮阳"是地域词,本地人搜"濮阳找工作"能搜到你
- "找工 / 接送"是关键词,说明你是干什么的
- 不要用"劳务""人力资源"这种正式词(像公司,不像个人)

**简介(直接写出来,≤60 字)**：
我是小张,濮阳本地的,专门帮咱普通人找进厂的活。从你家门口接你,送到厂门口,路上有啥问题我帮你问。不收你钱,你到了厂里好好干就行。想去的私信我

**为什么这么写**：
- 第一句"我是小张,濮阳本地的"——建立地域 + 身份认同
- 第二句"专门帮咱普通人找进厂的活"——圈定目标人群("咱普通人"让工人觉得"这是给我们这种人服务的")
- 第三句"从你家门口接你,送到厂门口"——核心服务,一句话说清
- 第四句"不收你钱"——打消顾虑(很多工人怕被收押金 / 中介费)
- 最后"想去的私信我"——行动指令

**背景图**：
一张图,左边是你在车里(侧面,手扶方向盘),右边是文字:
"从村口到厂门口 / 全程跟着 / 不收你钱"

**为什么这么设计**：
- 画面 + 文字,一眼看懂你是干什么的
- "从村口到厂门口、全程跟着、不收你钱"是你的三个核心卖点,反复强化

**置顶作品(等内容出来后)**：
置顶这 3 条:
1. **第一条(变现型)**:一个工人从上车到送到厂门口的完整过程(证明你真的在做)
2. **第二条(人设型)**:一个老客户带新客户来找你,新客户问"小张靠谱吗",老客户说"我上次就是他送的,放心"(口碑证明)
3. **第三条(知识型)**:黑中介的 3 个套路 + 怎么识别 + 正确做法(打消顾虑)

**为什么是这 3 条**：
新粉点进主页,前 3 条要让他看到:你真的在做(第一条)、之前去的人说你靠谱(第二条)、你能帮他避坑(第三条)——这 3 条看完,他基本就信了,会私信你

**现在过关吗?** 过关(前提是你按上面说的拍:车里 + 工人 + 真实场景)

**2. 只听声音,还能判断出人物性格吗?**

**能。**

- 比如你说"大姐,别担心,咱们送去的好几个都 50 多了,厂里看人实在就收"——这句话的语气是安抚、是承诺,不是冷冰冰地念台词
- 如果你的声音听起来像"欢迎致电XX公司,我们将竭诚为您服务"(客服腔),就不自洽了

## ⚠️ 这个号最大的风险

**风险 1:工人流失率高,导致你拿不到工厂返费,账期撑不住**

**为什么是风险**：
你的收入来自工厂端(工人干满一定时长,工厂才给你返费),但档案里说"工人流失率高(到了厂里干几天就走)"——如果 10 个人你送去 8 个,结果 6 个干了不到一周就走,你只能拿到 2 个人的返费,其他 6 个的接送成本(油费、时间)就白搭了

**怎么规避**：
- 内容里反复强调"去之前我会跟你说清楚:这个厂工作时长多少、累不累、适不适合你——你考虑好了再去,去了就好好干"(提前管理预期,减少冲动决策)
- 发一些"某某大哥在厂里干了 3 个月,工资拿到了,又介绍了 2 个老乡来"(正面案例,告诉观众"好好干是能挣到钱的")
- 后续服务:工人到了厂里,你要回访(拍回访视频),问"干得怎么样、有啥问题",让工人觉得"小张还在管我"(减少流失)

**风险 2:账号起来了,但私信的人大多是"问一嘴就不回了"或"条件不符合"的,转化率低**

**为什么是风险**：
你的服务有门槛(年龄、身体条件、能不能吃苦),但视频里如果只讲"我能帮你",不讲"什么人适合、什么人不适合",会吸引来一堆不符合条件的人——他们私信你,你回"你这个年龄 / 身体条件不太行",他们就不回了,你的时间被浪费了

**怎么规避**：
- 内容里明确圈人:"我这边对接的厂,大多要 18-55 岁、能站 8-10 小时、能接受两班倒的——如果你符合,私信我;如果你年龄太大(60 以上)或者身体不太好,我这边可能帮不上"(提前筛掉不符合的人)
- 简介里也写清楚适用人群,不要为了多拿咨询量而模糊边界
