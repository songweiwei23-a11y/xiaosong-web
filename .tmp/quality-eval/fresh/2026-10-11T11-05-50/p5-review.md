## 第1步：脚本策略卡

### 📋 核心问题
**这条视频要回答什么**：
让目标客户（装修到选家具阶段、怕被宰怕质量坑、希望有人帮着挑的本地家庭）看到"李国才在店里做的一件日常小事，能证明他靠谱、专业、不糊弄"。

### 🎯 目标与人群
- **视频目的**：变现型——让看到的人产生"这老板能信"的感觉，评论区问价或到店
- **目标人群**：装修到选家具这一步、预算3-10万、怕被宰怕质量坑、希望有人帮着挑的南乐/莘县/濮阳周边家庭
- **他们为什么要看**：家具决策焦虑——不知道怎么挑、怕买贵了、怕质量不好、怕买回去不合适。想找个"能帮我拿主意、不糊弄我"的店

### 🎬 形式与材料逻辑
**采用形式**：晒过程·日常切片（不是火车节，是截取一个日常动作）

**为什么选这个形式**：
1. 家具是"信任驱动"的生意，客人要看"你平时怎么做事"，不是听你讲道理
2. "日常"比"案例"更真实——案例可以包装，日常动作骗不了人
3. 30秒只够讲一个动作+为什么这么做，正好落在"晒过程"的节奏上

**材料递进**：
- **开头（0-5秒）**：抛出一个"大多数家具店不会做、但我每天都做"的动作
- **中段（6-20秒）**：展示这个动作的具体过程，能看到细节
- **结尾（21-30秒）**：说出为什么这么做（价值观/对客人的好处），自然收束

### ⚠️ 事实边界
**当前材料缺口**：
- 不知道李国才每天在店里实际做哪些事（开门第一件事、接待客人的固定流程、进货验货、售后处理）
- 不知道哪件事是"同行不做但我做"的
- 不知道哪件事的背后有"为什么这么做"的价值观

**不能写的**：
- ❌ "今天来了个客人说他去隔壁店被宰了"（没有真实客户提供）
- ❌ "我每次进货都亲自去厂里验"（不知道是不是真的每次都去）
- ❌ "我们店从不还价，标多少就多少"（档案没说价格政策）
- ❌ 任何具体价格、折扣、赠品承诺

## 第2步：候选方向（老板先选一个，再写完整脚本）

### 方向A：每天开门第一件事——擦一遍所有家具
**核心动作**：李国才每天早上开门，第一件事不是开电脑，而是拿抹布把前一天客人摸过、试坐过的家具再擦一遍

**为什么值得注意**：
- 6000平的家具城，这件事很费时间，大多数店不会每天做
- 能证明"我把这当自己家的东西在卖，不是糊弄你"

**需要确认的事实**：
- [ ] 你是不是真的每天都擦？还是只有客人多的时候擦？
- [ ] 擦的是所有家具还是展示区的？
- [ ] 为什么要这么做？（是你自己的习惯，还是客人反馈过"你家家具比别家干净"）

**30秒文案示意**（仅供参考，选定后再写正式版）：
```
我每天开门第一件事，
不是开电脑，是擦家具。
（画面：李国才拿抹布，从沙发扶手开始擦）
6000平的店，这一圈下来得一个小时，
但我必须擦。
（画面：擦茶几、擦床头柜、擦餐桌）
前一天客人摸过的、试坐过的，
我得让它跟新的一样。
（画面：擦完的家具在阳光下）
因为你买回家，
也得这么用好多年。
我不能让你摸到灰，
觉得这是别人挑剩下的。
```
**时长**：约27秒（135字）

### 方向B：接待客人时——先问三个问题，不先推荐
**核心动作**：客人进店，李国才不会先问"你要买什么"，而是先问三个问题：家里几口人、户型多大、喜欢什么风格

**为什么值得注意**：
- 大多数家具店是"客人问啥推啥"，李国才是"先帮你理清需求再推荐"
- 能证明"我不是为了卖货，是真的在帮你挑"

**需要确认的事实**：
- [ ] 你是不是真的每次都问这三个问题？有没有固定的接待流程？
- [ ] 问完这三个问题后，你下一步通常怎么做？（带他去对应区域？还是先讲预算？）
- [ ] 有没有客人反馈过"你家不一样，不上来就推销"？

**30秒文案示意**（仅供参考，选定后再写正式版）：
```
客人进店，我不先问你要买啥，
我先问三个问题：
（画面：李国才和客人站在店门口）
家里几口人？户型多大？喜欢什么风格？
（画面：客人回答，李国才点头记）
问完我才带你去看。
（画面：李国才带客人往展示区走）
因为家具不是买回去就行的，
得放你家里合适。
（画面：李国才指着一套沙发，比划尺寸）
你户型小，我推大沙发，你买回去堵门口；
你喜欢简约，我推美式雕花，你看着闹心。
（画面：客人笑着点头）
我不是为了卖货，
是真的在帮你挑。
```
**时长**：约28秒（140字）

### 方向C：售后环节——送到家不满意，现场帮调
**核心动作**：家具送到客人家里，客人觉得颜色/尺寸/摆放位置不对劲，李国才不会说"你自己看着办"，而是现场帮着调整，实在不行可以换

**为什么值得注意**：
- 大多数家具店"货一出门概不负责"，李国才做售后像做朋友
- 能证明"我对自己卖的东西有信心，不怕你挑刺"

**需要确认的事实**：
- [ ] 你是不是真的会跟车送货？还是只有特殊情况才去？
- [ ] 遇到过几次"客人不满意现场调"的情况？最后怎么处理的？
- [ ] 你们店的售后政策是什么？（多久内可以换？什么情况不能换？）

**30秒文案示意**（仅供参考，选定后再写正式版）：
```
我卖家具，最怕的不是你不买，
是你买回去不满意。
（画面：李国才跟着送货车）
所以每次送货，我都跟着去。
（画面：家具摆进客人家里）
摆好了，我问一句：
（画面：李国才站在客人家里）
"你看着行不行？"
（画面：客人皱眉，说"这颜色好像有点深"）
客人说颜色深了，
我现场就帮他调——
（画面：李国才和师傅把家具挪位置/调灯光）
换个位置、调个角度，
实在不行，我给你换一套。
（画面：客人露出满意的笑容）
因为我对自己卖的东西有信心，
不怕你挑刺。
```
**时长**：约29秒（145字）

### 方向D：进货环节——不要厂里推荐的，只挑本地人会买的
**核心动作**：李国才去厂里进货，厂家推荐的"爆款"他不要，只挑那些"南乐人、莘县人会买回家用"的款式

**为什么值得注意**：
- 大多数家具店是"厂里推啥我卖啥"，李国才是"我帮你筛过一遍"
- 能证明"我懂你们本地人的需求，不是瞎进货"

**需要确认的事实**：
- [ ] 你进货的时候真的会拒绝厂里推荐的款吗？还是厂里推啥你都进？
- [ ] 你怎么判断"本地人会买"？（是根据之前卖得好的款？还是问过客人反馈？）
- [ ] 有没有具体的例子：厂里推荐X款你没要，结果同行进了卖不动？

**30秒文案示意**（仅供参考，选定后再写正式版）：
```
我去厂里进货，
厂家推荐的"爆款"我不要。
（画面：李国才在家具厂展厅，厂家在介绍）
我只挑一种：
南乐人、莘县人会买回家用的。
（画面：李国才摸家具、看细节）
厂家说这款网上火，
我说网上火不代表我这儿能卖。
（画面：李国才摇头）
咱这边户型小、预算实在、
喜欢耐用不爱花里胡哨，
（画面：李国才指着另一款，点头）
我得挑这种。
（画面：一套简约耐用的家具特写）
因为你来我店里，
不是让我把网上的款搬过来，
是让我帮你筛掉那些不合适的。
```
**时长**：约29秒（145字）
