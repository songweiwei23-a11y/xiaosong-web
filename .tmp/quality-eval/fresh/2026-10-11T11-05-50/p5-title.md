# 万客隆家具城·李国才 · 标题封面

# 📱 5 个标题方案

### 1. 预算几千想配齐家,到底够不够?
- **字数**：13 字（不含标点和空格）
- **目的**：变现型
- **用的钩子**：直接提问
- **赌的动机**：恐惧——怕预算不够、怕被宰、怕配不齐。这类人正在装修选家具阶段,预算有限,点进来是想知道"我这点钱能干啥"
- **核心卖点**：性价比高 + 专业强(我能帮你在有限预算里配出完整方案)
- **埋的关键词**：预算、配齐、家具
- **适合场景**：目标客户就是预算3-10万、怕被宰的本地家庭,直接用数字圈人,点进来的都是精准用户

### 2. 6000平挑花眼?我教你3分钟锁定
- **字数**：16 字（不含标点和空格）
- **目的**：变现型
- **用的钩子**：直击痛点
- **赌的动机**：获得感——"挑花眼"是真实痛点原话,后半句给了时间承诺(3分钟)和解决方案(锁定)。这类人就是因为选择太多不知道怎么办
- **核心卖点**：便利性 + 专业强(规模大是优势,但我能帮你快速筛选)
- **埋的关键词**：家具、挑选、方法
- **适合场景**：当用户已经知道你家东西多,但担心"太多了反而不知道怎么选"时用,直接给解决方案

### 3. 小夫妻预算有限,我帮配了客厅加卧室
- **字数**：16 字（不含标点和空格）
- **目的**：变现型
- **用的钩子**：直接说具体的事
- **赌的动机**：好奇 + 省钱——预算有限够直观,客厅加卧室够具体,观众会想"预算不多能配成啥样""我家预算差不多,能不能也这么干"
- **核心卖点**：性价比高 + 服务好(真实案例证明我能在低预算里帮你配齐)
- **埋的关键词**：预算、客厅、卧室、家具
- **适合场景**：手上有真实客户案例时用,具体空间 + 服务过程 = 可信度高,适合第一条发

### 4. 新中式还是美式?3句话帮你定
- **字数**：13 字（不含标点和空格）
- **目的**：变现型
- **用的钩子**：对比·对立·区别
- **赌的动机**：获得感——风格选择是家具决策第一步,很多人卡在这。"3句话"降低门槛,给了速成承诺
- **核心卖点**：专业强(我有教师背景,能把复杂的讲清楚)
- **埋的关键词**：新中式、美式、风格、选择
- **适合场景**：当客户还没想清楚要什么风格、处于决策早期时用,帮他快速建立判断标准

### 5. 方圆30公里最大?关键是不用跑三家
- **字数**：16 字（不含标点和空格）
- **目的**：变现型
- **用的钩子**：负面事件切入
- **赌的动机**：省钱(省时间成本)——前半句可能让人以为要吹规模,后半句转到"不用跑三家"这个真实便利性上。这类人就是嫌麻烦、想一站解决
- **核心卖点**：便利性 + 规模大(把规模优势转化成客户能感知的省事)
- **埋的关键词**：家具城、一站式、全品类
- **适合场景**：当客户已经跑了好几家店、觉得累时用,直接击中"再也不想跑了"的心理

### 🎯 投放建议

- **首选**：标题3「小夫妻预算有限,我帮配了客厅加卧室」
  - **理由**：最符合定位方案里说的"第一条拍什么"(变现型·晒过程·火车节),具体空间 + 服务过程 + 结果,钩子在前8字就已经成立,具体可信,点进来的都是有预算焦虑的精准用户
  
- **备选**：如果标题3的完播率低于你前几条平均值,换标题2「6000平挑花眼?我教你3分钟锁定」
  - **判断指标**：观察5秒完播率和评论区问题。如果评论区都在问"预算多少合适""我家预算XX能配啥",说明标题3有效;如果评论区在问"你家在哪""都有啥风格",说明观众还没进入预算决策阶段,用标题2或4更合适
  
- **封面配合**：
  - 标题3用时,封面写：**客厅+卧室 / 预算有限也能配齐**
  - 标题2用时,封面写:**选择太多? / 3分钟教你挑**
  - (封面不重复标题原话,用更短的词补充视觉信息)
