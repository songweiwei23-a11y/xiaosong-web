# 锦园地摊串串一元火锅 · 内容定位

# 💎 内容定位方案

## 长期价值主张
让南乐本地人知道这有个成都厨子做正宗川味地摊，吃得实在、看得见过程。

## 内容方向：多元四类还是单一主题

**选 A 多元四类**

**依据**：
1. **真实素材充足但不适合单一主题**：你们每天备菜、穿串、开炉、接客，这些过程天天在发生，素材不缺。但"地摊餐饮"这件事本身不是任务型主题（不像探店、挑战、改造有明确的任务和结果），很难做成"每期一个目标"的系列
2. **执行能力和策划能力匹配**：2-3人小团队，主要精力在经营店面，没有专职编导天天策划"这周挑战什么、下周测评什么"。多元四类的优势是**不靠每天想新点子**——今天拍备菜过程、明天拍成都厨子的经历、后天拍怎么吃值，素材就在日常工作里
3. **和变现连得上**：晒过程（变现型，证明实在）、教知识（变现型，教怎么吃）、讲故事（人设型，立住成都厨子）——三类都能自然导向"地址评论区置顶，也可以团购"

**为什么不选 B 单一主题**：
单一主题需要**人为制造事件**（比如"每天接受粉丝挑战探店""每周以物换物"），而你们的优势是**真实场景**（地摊每天在营业、厨子每天在干活）。如果硬要做成"每天挑战一个川菜"或"每周测评一个成都小吃"，反而会让内容变成摆拍任务，失去地摊的烟火气和真实感。

单一主题适合有大量外部素材、或者愿意投入大量策划的账号；你们是**内容长在经营里**，多元四类更稳定可持续。

## 内容配比

### 作用配比

| 作用 | 占比 | 为什么 |
|---|---|---|
| 流量型 | 45% | **账号阶段决定**：0-1万粉、还没发过内容，处于起号期。这一阶段的首要任务是拿到稳定流量、让本地目标人群反复刷到你。流量型必须是最大的一块。覆盖面越广上限越高——用大众入口（地摊烟火气、一元火锅、成都vs南乐的反差、夜宵场景）承载你的专业 |
| 人设型 | 25% | **成都厨子的经历、和本地老板的关系、老客的故事**，这些内容让用户记住你这个人、信你。比例不是最大，但**每周必须有**，否则号只有流量、没有粘性。三线城市本地服务，信任 = 人，不只是手艺 |
| 变现型 | 30% | 从第一周就要有，但占小头。**地摊餐饮的决策链路短**（3-7天），变现型内容要持续输出，让用户"种草 → 记住 → 下单"。但比例不能太高，否则号一开始就像团购广告，平台不推、用户不信 |

**什么数据出现时切换配比**：
- **前20条看初始流量是否稳定**：非关注用户播放占比达到70%以上、单条播放稳定在X（看抖音给的初始流量池是多少，和你自己前几条比）、评论区开始有本地人问地址 → 说明流量型内容跑通了
- **流量稳定后调整为**：变现型 50% / 人设型 20% / 流量型 30%——这时重心转向推动到店，流量型退到维持曝光的位置

### 形式配比

| 形式 | 占比 | 负责哪种作用 | 为什么 |
|---|---|---|---|
| 晒过程 | 50% | **流量型 + 变现型** | **主力形式**。档案里"还没发过"无已验证数据，但按行业规律推荐晒过程：**地摊餐饮最适合晒过程**（备菜、穿串、开炉、接客天然有烟火气和真实感）。过程 = 信任 = 变现。门槛低、可持续，2-3人小团队一部手机就能拍 |
| 讲故事 | 20% | **人设型** | **立住成都厨子这个人**。为什么从成都来南乐、半年经历了什么、老客的认可——这些故事让用户记住你、信你。占比不大但每周必须有 |
| 教知识 | 25% | **变现型为主，少量流量型** | 变现型：怎么点划算、一元火锅怎么吃、锅底怎么调，解决"不知道怎么吃"的障碍，推动到店。少量流量型：川味冷知识（成都吃法 vs 南乐吃法）带反认知钩子，能拿流量。**不拿行业干货去冲大流量**（"怎么做川菜"只给同行看） |
| 聊观点 | 5% | **人设型** | 占小头，只作为人设的补充。观点必须连着自己的经历（"我不认为地摊 = low，我在成都做了9年，来这半年……"），才能立人设。**观点不是流量主力**，只给已有受众看 |

**为什么不选教知识当主力**：川菜知识、串串冷知识受众窄（只有美食爱好者和同行看），流量天花板低。知识型作为辅助（占25%），但不能当主力。

### 题材配比

**川味三品类（串串火锅、烧烤、川菜）60% + 目标人群兴趣（聚餐夜宵场景、地摊文化、本地生活）40%**

**为什么这样配**：
- **川味三品类 60%**：你的主赛道，必须占大头。但**不是平均分配**——按团购数据和客人点单频率调整每个品类的出镜频率。推测串串火锅是主力（可能占30%），烧烤次之（20%），川菜小炒（10%）。【待确认：需要老板提供实际点单比例】
- **目标人群兴趣 40%**：这是流量型内容的主要来源，覆盖的人群比"川菜知识"广得多：
  - **聚餐夜宵场景**（20%）：下班撸串、发工资请客、朋友聚会、深夜食堂——这些场景本地18-40岁的人都经历过，天然有共鸣
  - **地摊文化**（15%）：三线城市的烟火气、露天吃饭的松弛感、地摊老板的真实生活——和"精致餐厅"形成反差，有话题性
  - **本地生活**（5%）：南乐这条街的故事、本地人的口味习惯、外地厨子在县城的观察——地域标签能圈住本地用户

**人群兴趣具体是哪几类**：
1. **夜宵烧烤文化**：下班后约三五好友撸串、发工资请客、深夜治愈——这是18-40岁年轻人（学生、白领、蓝领）的高频场景
2. **地摊烟火气**：不是高大上餐厅、是接地气的真实生活，露天座位、炉子升起、烟雾缭绕——三线城市的独特体验
3. **省钱实惠**：一元一串、吃多少算多少、50块吃到撑——价格透明、性价比高，符合目标人群"要真材实料、要价格透明"的需求

### 配比核验

1. **流量型是不是和账号阶段匹配（新号是不是最大的一块）？**  
   **是**。流量型45%最大，符合0-1万粉、还没发过内容的起号期账号。

2. **主力形式是不是档案里数据最好的那一类？不是的话理由够不够硬？**  
   档案里"还没发过"，无已验证数据。推荐**晒过程**为主力，理由硬：地摊餐饮最适合晒过程（真实、烟火气、门槛低、可持续），且行业规律验证过"过程 = 信任 = 变现"。

3. **用户要大流量的话，行业干货是不是没当主力？**  
   **是**。档案里没写要大流量，但流量型45%里，晒过程（地摊场景、一元火锅、夜宵烟火气）和知识（川味冷知识）都是大众入口，不是窄的行业干货（"怎么做川菜"只给同行看）。

4. **题材有没有给目标人群的兴趣留出30-40%？**  
   **是**。题材配比是"川味三品类60% + 目标人群兴趣40%"。

5. **每个数字都能说出"为什么是这个比例"吗？**  
   **能**。上面每一块都写清了依据（账号阶段 → 作用配比；行业特点 → 形式配比；覆盖人群 → 题材配比）。

## 三种视频怎么拍

### 流量型（45%，每周5-6条）

**拍什么方向**：
1. **地摊烟火气 + 一元火锅的反差**：大众对地摊的第一印象是"便宜但可能不干净"，一元火锅听起来"便宜到不敢信"——这个反差本身就是钩子，覆盖所有想吃夜宵、又怕踩坑的本地年轻人
2. **成都 vs 南乐的地域反差**：成都厨子在三线县城做川味地摊，这件事本身有故事性。同一道菜成都怎么吃、南乐怎么吃，口味差异、文化差异——能引发评论区讨论"你们那边是哪种"

#### 四大脚本（薛老师）

**结构1：冷知识**（反常识结论 → 为什么 → 和每个人的关系 → 反问）  
适合：川味冷知识、地摊行业

**示范**：
- 标题：《一元一串的火锅，老板能赚多少？》【爆款元素：成本】
- 怎么拍：开篇钩子"很多人以为一元一串老板不赚钱"（反常识） → 拍备菜过程，旁白"一串成本X毛（肉+竹签+调料），卖一元，毛利X毛"（为什么） → "但我们靠的是量和复购，一桌客人平均点X串，一晚上X桌"（和每个人的关系） → 结尾"所以别问我赚不赚钱，你们觉得这个价实在吗？评论区说说"（反问，引评论）

**结构2：晒过程·火车节**（起因钩子 → 关键步骤 → 结果）  
适合：每天的备菜、开炉、接客过程

**示范**：
- 标题：《南乐这个地摊，下午4点就开始准备今晚的串串》【爆款元素：反差（地摊 vs 精致餐厅的时间差）】
- 怎么拍：开篇"下午4点，成都厨子开始备今晚的串串火锅和烧烤"（起因，画面：操作台上一堆肉、菜、竹签） → 穿串特写（手法）、调锅底特写（辣椒、花椒）、开炉（炉子点起来、烟火气）、第一波客人来了（坐下、点单、开吃）（关键步骤） → 客人吃完说"这个味儿正，下次还来"，画面：厨子收拾桌子（结果） → 结尾"一元一串，吃多少算多少，实在。你们那边也有这种地摊吗？评论区说说"

#### 起号36计（小黄）

**第31计·南北/地域差异**：同一任务两地做 → 差异反应 → 原因/文化 → 交流

**套到这个号上**：成都吃串串的方式（油碟、干碟都有，锅底麻辣，吃法讲究） vs 南乐本地吃法（大多数人只要干碟，锅底偏辣不太麻） → 差异反应（刚来南乐时按成都吃法给客人配油碟，结果大家都说"不习惯"） → 原因（气候、口味习惯） → "所以别问我'正宗川味是啥'，你吃着爽就是正宗。评论区说说，你们那边怎么吃？"

**示范**：
- 标题：《成都人吃串串和南乐人吃串串，差别有多大？》【爆款元素：地域差异】
- 怎么拍：开篇钩子"成都人吃串串和南乐人吃串串，差别有多大？" → 画面对比：左边成都吃法（油碟、干碟都有），右边南乐吃法（干碟+辣椒面） → 成都厨子出镜口播"刚来南乐时，我按成都吃法给客人配油碟，结果大家都说'不习惯'。后来我才知道，南乐人喜欢干碟+辣椒面，吃着更过瘾。现在我两种都准备，你们想怎么吃就怎么吃" → 结尾"所以别问我'正宗川味是啥'，你吃着爽就是正宗。评论区说说，你们那边怎么吃？"

**第1计·反向操作**：常规A → 反向B → 真实反应/结果

**套到这个号上**：常规A（别人家串串火锅按份卖、起步价50，客人不知道能吃几份、怕点多浪费） → 反向B（我们一元一串，想吃几串吃几串，吃多少算多少） → 真实反应/结果（客人的惊讶"一块钱一串？"和认可"这个方式好，不浪费"）

**示范**：
- 标题：《别人家火锅按份卖，我们一元一串》【爆款元素：反差】
- 怎么拍：开篇钩子"南乐很多串串火锅按份卖，起步价50，客人不知道能吃几份"（常规A） → 画面切到你们店，旁白"我们一元一串，想吃几串吃几串"（反向B） → 拍客人点单的画面，客人说"一块钱一串？那我先来20串试试"，吃完又加了10串（真实反应/结果） → 结尾"吃多少算多少，实在。评论区说说，你们那边串串怎么卖？"

**结尾行动指令**（两套打法共用）：**评论**（"你们那边也这样吗？评论区说说"）

### 人设型（25%，每周3条）

**拍什么方向**：
1. **成都厨子的经历**：为什么从成都来南乐、9年川菜经验怎么积累的、刚来时不适应什么、半年下来的变化——这些故事立住"成都厨子"这个身份，让用户记住你这个人
2. **和本地老板的关系、老客的故事**：本地老板 + 成都厨子两人搭档（手艺 + 人脉），老客一周来一次、带朋友来——这些关系细节证明"我在这扎根了，不是过客"

#### 四大脚本（薛老师）

**结构1：小有成就/个人成就**（结果钩子 → 阻碍1 → 转机1 → 阻碍2 → 转机2 → 感悟）  
适合：成都厨子在南乐半年的经历

**示范**：
- 标题：《在南乐做地摊半年，这条街的人都认识我了》【爆款元素：人群（本地）】
- 怎么拍：开篇"在南乐开地摊半年，这条街的人都认识我了"（结果钩子） → "刚来时语言不通（成都话 vs 南乐话），本地人不信外地厨子"（阻碍1） → "第一个老客带朋友来，说味道正，我才知道手艺是通的"（转机1） → "冬天生意淡，撑不撑得下去心里没底"（阻碍2） → "搭了帐篷继续干，老客还是每周来，他们说'你这味儿跑不了'"（转机2） → 感悟"在哪都是手艺人，干就完了。【换成你自己的真实经历】"

**结构2：观点立场**（亲身经历 → 我的判断 → 为什么这么看 → 邀请你怎么看）  
适合：讲对川菜、对地摊经营的看法

**示范**：
- 标题:《我不认为地摊就是low》【爆款元素:观点立场】
- 怎么拍:开篇"我不认为地摊就是low"(观点) → "我在成都做了9年川菜,见过精致餐厅也做过路边摊"(亲身经历) → "精致餐厅环境好,但很多客人吃完就走,没温度。地摊不一样,客人坐下来,老板和客人聊两句,老客带新客,这才是烟火气"(我的判断 + 为什么这么看) → 结尾"所以别觉得地摊low,真正的好吃,在街边。你们觉得呢?评论区说说"(邀请你怎么看)

#### 起号36计(小黄)

**第8计·加入人物关系**:主任务 + 关系角色出镜 + 互动结果

**套到这个号上**:主任务(备菜、开炉) + 关系角色出镜(本地老板出镜,和成都厨子互动) + 互动结果("老张管进货,我管手艺,搭档半年了")

**示范**:
- 标题:《成都厨子 + 南乐老板,搭档半年了》【爆款元素:人物关系】
- 怎么拍:开篇"我是成都来的川菜厨子,他是南乐本地老板,我们搭档半年了"(人物关系) → 画面:两人在操作台前一边备菜一边聊天。本地老板:"老李,你这锅底配方能不能教教我?" 成都厨子(笑):"你学了我就没饭吃了。不过我可以告诉你,这个辣椒是从成都带过来的,南乐买不到。" 本地老板:"怪不得这么多人说正宗。行,那我就负责进货,你负责手艺。"(互动结果) → 结尾:两人击掌,画面定格。旁白(配音):"成都手艺 + 本地人脉,就是这个味儿。想看我们每天怎么干活的,关注我"

**第37计·赠送:身份反差**:身份预期A → 行为B → 环境自洽 → 能力/情绪结果

**套到这个号上**:身份预期A(成都大厨,应该在高档餐厅) → 行为B(在南乐地摊穿串串) → 环境自洽(地摊场景、烟火气) → 能力/情绪结果("手艺还是那个手艺,但这里更自在")

**示范**:
- 标题:《成都做了9年川菜的厨子,现在在南乐穿串串》【爆款元素:身份反差】
- 怎么拍:开篇"我在成都做了9年川菜"(身份预期A),画面:厨子穿围裙在操作台前 → "现在在南乐穿串串"(行为B),画面:手穿串串的特写 → "有人问我,你在成都做得好好的,为什么来南乐做地摊?"(环境自洽) → "手艺还是那个手艺,但这里更自在。成都节奏快,南乐慢,客人坐下来能聊两句,这才是我想要的"(能力/情绪结果) → 结尾"想看成都厨子在南乐的故事,关注我"

**结尾行动指令**(两套打法共用):**关注**("想看成都厨子在南乐的故事,关注我")

### 变现型(30%,每周3-4条)

**拍什么方向**:
1. **服务过程 + 客人案例**:从备菜到接客的完整链路、客人点单的场景、团购核销的过程——证明"我们每天在营业、客人真的在吃"
2. **怎么吃划算 + 一元火锅怎么吃**:第一次来的客人不知道怎么点、怎么搭配值、锅底怎么调——解决"不知道怎么吃"的障碍,推动到店

#### 四大脚本(薛老师)

**结构1:晒过程·火车节**(起因钩子 → 关键步骤 → 结果)  
适合:服务过程、团购核销

**示范**:
- 标题:《一元火锅 + 烧烤,50块钱在南乐吃到撑》【爆款元素:成本】

- 评论区有人说"就冲你这个人""这个老板实在"(说明人设立住了)
- 团购开始有订单、或者评论区有人问"在哪""怎么去"(说明变现型内容在推动到店)

### 第21-30条:变现加码期

**目标**:人设立住、流量稳定后,加大变现型内容比例,推动团购和到店

**做哪个系列**:《50块钱在南乐吃什么》(5条) + 《地摊日常》(3条) + 《川味冷知识》(2条)

**主要用哪套打法**:
- **四大脚本的变现结构是主力**:教知识·推荐型(教怎么点)、晒过程·火车节(拍服务过程、团购核销)

**加什么**:

- 拍团购核销的过程(客人出示团购券、核销、吃的场景)——证明"团购是真的、客人真的在用"

**验收标准**:

## ⚠️ 不要做什么

### 1. 三个品类平均用力,拍成"菜单展示号"

**为什么不该碰**:今天拍川味串串火锅、明天拍川味烧烤、后天拍川菜小炒,每个都拍一遍,但每个都没讲透。用户看完记不住你到底是"串串店""烧烤店"还是"川菜馆",标签模糊 = 没标签。

**正确做法**:按变现数据排优先级(【待确认:需要老板提供团购数据、客人点单频率】)。推测川味串串火锅 > 川味烧烤 > 川菜小炒,那前20条里,串串火锅占50%,烧烤30%,川菜20%。**一个品类拍透了再拍下一个**:不要今天串串、明天烧烤轮着来,而是连续5-7条都拍串串火锅(从备菜、穿串、锅底、客人吃、怎么点最划算,多角度拍透),让用户先记住"这家串串火锅正宗",再慢慢引入烧烤和川菜。

---

### 2. 不敢拍地摊场景,怕"显low"

**为什么不该碰**:老板可能觉得地摊环境"不上档次",拍视频时刻意避开地摊场景(只拍成品特写、或者找个"干净"的角落拍),结果拍出来和精致餐厅没区别,失去了差异化。三线城市商家普遍有"自卑感",觉得地摊 = 低端,但其实**目标用户要的就是地摊的烟火气和实在感**。

**正确做法**:地摊场景就是你最大的资产。露天座位、炉子、烟火气、客人三五成群坐着吃,这些画面传达的是"松弛""热闹""实在",恰恰是精致餐厅给不了的。**"显low"的反面不是"显高级",是"显真实"**。用户不会因为你环境简陋而不来,只会因为你"看着像假的、不敢信"而不来。地摊场景 + 过程可见 = 真实 = 信任。

---

### 3. 把"成都厨子9年经验"当万能标签,每条都喊一遍

**为什么不该碰**:人设标签要靠**细节验证**,不是靠重复喊。如果每条视频开头都是"我是成都来的川菜厨师,做川菜9年",用户听三遍就烦了,第四遍直接划走。而且只喊标签、不讲具体事,用户心里想"你说9年就9年?拿什么证明?"

**正确做法**:用**具体的手艺细节、真实的经历、客人的认可**来证明"9年经验"这件事。比如:拍穿串串的手法特写,配旁白"这个手法,在成都做了9年";拍调锅底,说"这个辣椒是从成都带过来的,南乐买不到";拍老客吃完说"这个味儿正,就是成都那个味儿"。**让别人说你9年经验,比你自己说一百遍有用**。
