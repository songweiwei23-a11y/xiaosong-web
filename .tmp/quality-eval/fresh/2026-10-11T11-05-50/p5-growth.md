# 🚀 起号方案

## 📌 先说结论

- **建议主攻**：**第10计·情境还原**。家具决策链路长（从刷到视频到到店能拖一个月），客人最大的痛点是"不知道怎么选、怕挑花眼"——他们需要看到**你怎么帮别人挑的全过程**，才会信你、才会来。情境还原就是把你接待客人的真实场景（问需求、带去对应区域、讲解、算预算）拍下来，观众旁观学习、看到你的服务能力和专业判断。你一人全包、手机就能拍，跟拍客人挑货的过程，成本低、最真实、离变现最近

- **备选**：
  1. **第36计·冷知识**（流量型）：用"买家具千万别周末去""小户型别选深色家具"这类反常识知识拿陌生人流量，扩大曝光。什么情况下切：主攻的情境还原测5条后，非关注用户播放占比低于50%（说明流量没打开），就补2-3条冷知识拉新粉
  2. **第31计·地域差异**（流量型）：拍"南乐人和濮阳人买家具有啥不一样""县城和大城市买家具的区别"，拿同城流量、强化本地化标签。什么情况下切：主攻测5条后，本地播放占比低于40%（说明同城标签不够强），就补2-3条地域差异
  3. **讲故事·小有成就**（人设型）：讲你从教师转行做家具的经历、第一次接待客人、第一次被客人夸。什么情况下切：主攻测10条后，主页访问率低（说明看过的人不记得你），就补1-2条故事立人设

- **明确不做**：
  1. **第16计·整蛊、第9计·一人分饰多角、第30计·角色扮演**：这三个都要演、要剧本、要剪辑节奏，你一人全包时间精力有限（既要接待客人又要拍视频），做不到高频产出。且家具是严肃决策（客单价几千到几万），客人不会因为看到一个段子就来买家具——娱乐内容拿流量可以，但和到店转化连不上
  2. **第23计·内幕揭秘**：档案禁忌里明确写了"不能拍到顾客正脸（需打码）""不能拍同行店铺的差评、曝光"，而内幕揭秘的核心就是讲"行业里谁坑人、谁获利"——你拍不了同行的负面，就只能讲自己怎么做，但那不叫揭秘，叫行业避坑（第22计）。且揭秘容易被平台判定"抹黑同行"，有合规风险

- **多久能看出跑没跑通**：连续发20条（按你一周能拍2次、每次拍2-3条算，大概4周），看这三个指标：
  1. 私信量：评论区和私信里，有没有3个以上真实咨询（问价格、地址、预算X万怎么配）
  2. 到店人数：到店的客人里，有没有人说"我刷到你视频了"——这比播放量更直接
  3. 非关注用户播放占比：是否稳定在60%以上（说明流量开始稳定，不是只有老粉在看）

## 🧮 起号期内容配比

**起号期（到一千粉、流量稳定之前）**：
- **流量型 45%**：新号粉丝量级0-1万，流量还不稳定，必须是最大的一块。用**第36计·冷知识 + 第31计·地域差异**拿稳定曝光、拉新粉
- **变现型 30%**：从第一周就要有，用**第10计·情境还原**（晒你帮客人挑货的过程）证明能力和专业，推动到店咨询。档案里写"入户视频偶尔爆款"，说明过程类内容已验证跑得通
- **人设型 25%**：家具是大件、低频、高决策成本，客人不会看一条视频就来，决策周期至少1-2周。用**讲故事·小有成就**（教师转行、第一次接待客人）让看过的人记住你、信你这个人

**每一种用哪一计来拍**：
- **流量型**（45%）：主力用**第36计·冷知识**（"买家具千万别周末去""小户型别选深色家具"）+ **第31计·地域差异**（"南乐人和濮阳人买家具有啥不一样"）

- **变现型**（30%）：主力用**第10计·情境还原**（跟拍你接待客人的完整过程）
  - **脚本结构**：用**晒过程·火车节**（起因带钩子 → 关键步骤 → 结果）讲，补上**成交理由**（性价比、服务好、专业强）

  - **脚本结构**：结果钩子 → 阻碍1 → 转机1 → 阻碍2 → 转机2 → 感悟
  - **结尾行动指令**：关注（"想看我怎么帮客人挑家具的，关注我"）

- 调整为**变现40% / 流量35% / 人设25%**，变现型慢慢长上来

## 🎯 主攻打法：第10计·情境还原

### 为什么是你能拍的

逐条对照你的真实资源：

1. **团队：一人全包** → 情境还原就是跟拍你接待客人的真实过程，不需要演员、不需要多人剧情，手机架在柜台上或者稳定器跟拍就行。你正常接待客人，镜头记录下来，事后配音解说或者保留现场真实音
2. **设备：手机** → 情境还原不需要多机位、不需要打光（店里灯光就够），手机就能拍。客人来了，手机架在固定位置拍全景，或者拿稳定器跟着你俩走
3. **场地：店铺** → 情境还原就是在你店里拍，6000平、6大品类就是最好的视觉证据。你带客人从新中式区走到现代轻奢区、再走到卧室家具区，观众看到的是"选择多、种类齐全"这个核心卖点
4. **擅长：当过5年教师，会讲、能把复杂的说清楚** → 情境还原的核心是**你怎么帮客人分析**（"你家客厅不到20平，选两人位沙发就够了""你家有老人，选硬一点的床垫"），你的教师经验在这里是优势——能听懂客人需求、耐心讲解，客人反而更信任你
5. **已有数据验证** → 档案里写"入户视频偶尔爆款"，说明**晒过程类内容**（拍真实的服务过程和结果）已经跑通了。情境还原就是晒过程的升级版——从只晒结果（入户效果图），到晒完整过程（你怎么帮客人挑的）

### 结构公式（套到你这个号上）

**第10计·情境还原公式**：真实任务 → 对话/纠错 → 旁观学习 → 结果

**套到你这个号**：
- **真实任务**：今天来了【什么人】（小夫妻、三口之家、老板要买办公家具），说【什么需求】（预算X万、客厅小、家里有老人）
- **对话/纠错**：客人问"这款和那款有啥区别""新中式和现代轻奢选哪个""预算不够怎么办"，你现场讲解、帮他分析（"你家客厅小，选这款两人位沙发就够了""你预算紧张，可以先配客厅和卧室，餐桌后面再买"）
- **旁观学习**：观众看到你怎么问需求、怎么带客人去对应区域、怎么讲解每一款的适用场景、怎么帮他算预算——这就是**服务好 + 专业强**的证据
- **结果**：客人满意成交，说"李老师你比我朋友还上心"——落在一个成交理由上（性价比、服务好、专业强）

### 配什么脚本讲

这一计管**事件怎么走**（你和客人从见面到成交的全过程），话怎么讲从**四大脚本**里配一个结构：

**配 晒过程·火车节**：
- **起因（带钩子）**："今天来了一对小夫妻，说预算只有X万，要配齐全屋家具"
- **关键步骤**：你先问他们户型、风格、家里有没有老人小孩 → 带他们去对应区域 → 帮他们算预算、搭配款式 → 最后配齐
- **结果**："X万配齐客厅、卧室、餐厅，他俩说比预想的还满意"

**配了它补上的是什么**：
- **成交理由**：每一集落在一个成交理由上——"预算X万配齐全屋"落在**性价比**；"你帮他分析、带他慢慢挑"落在**服务好 + 专业强**；"6000平、6大品类一站配齐"落在**选择多 + 便利性**
- **和变现直接连上**：看这个内容的人，就是想买家具、想找人帮着挑的人。他们看完会想"我也想让李老师帮我挑"，然后私信你

### 前 3 条具体拍什么

**第 1 条**：  
**标题**：《预算X万，能配齐全屋家具吗？》（叠：**成本**）  
**拍摄要点**：
- 开篇钩子（前3秒）：你对着镜头说"今天来了一对小夫妻，说预算只有X万，要配齐全屋家具"
- 关键步骤（30-40秒）：你先问他们"户型多大、喜欢什么风格、家里有没有老人小孩"（5秒）→ 带他们去客厅家具区，你边走边讲"你们家客厅不到20平，选两人位沙发就够了"（10秒）→ 再带他们去卧室家具区、餐厅家具区（各10秒）→ 最后你帮他们算预算，拿手机给他们看搭配效果图（5秒）
- 结果（5秒）：你说"X万配齐客厅、卧室、餐厅，他俩说比预想的还满意"
- **关键画面**：你带客人走过6000平店面的镜头（证明规模大、选择多）；你蹲下来量尺寸、拿手机给客人看效果图的细节（证明服务好、专业强）
- **记得打码客人正脸**（档案禁忌）

**第 2 条**：  
**标题**：《客人问我：新中式和现代轻奢，选哪个？》（叠：**人群**——正在装修、不知道怎么选风格的人）  
**拍摄要点**：
- 开篇钩子（前3秒）：客人指着新中式家具区和现代轻奢区问"李老师,这两种风格有啥区别,我该选哪个"
- 对话/纠错（30秒）：你带客人去新中式区，边走边讲"新中式适合喜欢传统文化、家里装修偏中式的"（10秒，拍新中式家具）→ 再带客人去现代轻奢区，"现代轻奢适合年轻人、简约风装修"（10秒，拍现代轻奢家具）→ 你问客人"你家装修是什么风格"，客人说"简约风"，你说"那就选现代轻奥"（纠错）（10秒）
- 旁观学习：观众看到你怎么帮客人分析、怎么根据他家装修风格推荐
- 结果（5秒）：客人说"我本来想选新中式，听你一说才发现不适合"
- **关键画面**：你带客人在新中式区和现代轻奢区之间走的镜头（证明全品类覆盖）；你问客人家装修风格、帮他分析的细节（证明专业强）

**第 3 条**：  
**标题**：《客人说：我家客厅小，怕买大了放不下》（叠：**人群**——小户型、怕买错的人）  
**拍摄要点**：
- 开篇钩子（前3秒）：客人看着一款大三人位沙发说"李老师，我家客厅小，这款能放下吗"
- 对话/纠错（30秒）：你问客人"你家客厅多大"，客人说"不到20平"，你说"那这款太大了，我带你看两人位的"（纠错）（10秒）→ 你带客人去两人位沙发区，拿卷尺量给他看"你家客厅放这款刚好，还能留出走道"（10秒）→ 你拿手机给客人看他家户型图，"你看，放这个位置刚好"（10秒）
- 旁观学习：观众看到你怎么根据客人户型推荐、怎么量尺寸、怎么用手机辅助讲解
- 结果（5秒）：客人说"还好听你的，差点买大了"
- **关键画面**：你拿卷尺量沙发尺寸的细节（证明专业细致）；你拿手机给客人看户型图、讲解怎么摆放的画面（证明服务好）

### 边界

从第10计·情境还原的边界里挑对你适用的：

1. **必须真实场景**：不能找演员演、不能编客人的话。真实客人来了，你正常接待，镜头记录下来。如果当天没客人，就别硬拍——等有客人的时候再拍
2. **必须打码客人正脸**：档案禁忌写了"不能拍到顾客正脸（需打码）"。拍的时候可以拍客人背影、侧面、手部动作，后期剪辑时把正脸打码
3. **不能编数字**：客人预算是多少、最后花了多少钱，档案没给你的就写X（"预算X万配齐全屋"），或者后期配音时说【换成你接待的真实客户：预算是多少】
4. **不能替客人答应经营承诺**：比如"包送货上门""不满意包退""终身质保"，档案没写过的就别说——只讲你实际怎么做的（"我帮他算预算、带他慢慢挑"），不承诺具体售后政策

## 🧪 怎么测

### 一次只改哪个变量

**第1-5条（主攻·情境还原）**：固定结构（火车节：起因 → 关键步骤 → 结果），只改**客人类型和需求**（小夫妻预算紧张、三口之家有老人、老板买办公家具、客人不知道选什么风格）

**第6-10条**：如果前5条数据好（非关注用户播放占比超过50%、有真实咨询），继续拍情境还原，只改**拍摄角度**（从固定机位改成稳定器跟拍、从配音改成保留现场真实音）

**第11-15条**：如果前10条流量没打开（非关注用户播放占比低于50%），切到**备选1·冷知识**，测2-3条，看能不能拉新粉

### 每计测几条、看什么指标

- **情境还原（主攻）**：至少测5条，看这三个指标：
  1. **完播率**：晒过程类内容完播率通常在30-50%，如果你的低于30%，说明节奏太慢（关键步骤拖太长）或钩子不够强（开篇没说清客人什么需求）
  2. **评论区质量**：有没有人问价格、地址、"我也想让李老师帮我挑"——这比点赞量更重要
  3. **私信量**：有没有3个以上真实咨询

- **冷知识（备选1）**：测2-3条，看**非关注用户播放占比**是否超过60%（说明拿到了陌生人流量）

- **地域差异（备选2）**：测2-3条，看**本地播放占比**是否超过60%（说明同城标签起来了）

### 什么信号算"这计行"，什么信号算"换掉"

| 信号 | 算"这计行" | 算"换掉" |
|---|---|---|
| **情境还原** | 连续3条完播率都在30%以上 + 评论区有人问价格/地址 + 有1-2个真实私信咨询 | 连续5条完播率都低于25% + 评论区没有真实咨询（只有"加油""拍得好"这类客套话） |
| **冷知识** | 非关注用户播放占比超过60% + 评论区互动多（"原来如此""长见识了""你们那边也这样吗"） | 播放量低于前5条平均值的50% + 评论区冷清 |
| **地域差异** | 本地播放占比超过60% + 评论区有本地人互动（"南乐的""莘县的""濮阳的"） | 本地播放占比低于30% + 评论区没有地域标签相关的评论 |

## 📊 跑不通先查哪里

挑最可能出现的3种情况：

### 1. 有曝光但前段流失（前5秒就划走）

**先怀疑什么**：  
开篇钩子不够强——"今天来了一对小夫妻"这种开篇太平淡，观众不知道后面讲什么、为什么要看

**下一步做什么实验**：  
重写5个开篇，把**客人的需求/困境/冲突**前置：
- ❌ "今天来了一对小夫妻" 
- ✅ "今天来了一对小夫妻，说预算只有X万，要配齐全屋家具"（叠成本）
- ✅ "客人问我：这两款沙发有啥区别？"（叠困境）
- ✅ "客人说：我家客厅小，怕买大了放不下"（叠恐惧）

---

### 2. 完播率低（播放量有，但完播率低于25%）

**先怀疑什么**：  
节奏太慢、关键步骤拖太长——你带客人从问需求到配齐全屋，拍了2分钟，观众等不到结果就划走了

**下一步做什么实验**：  
删掉30%的内容，把关键步骤浓缩到30-40秒：
- **问需求**：5秒讲完（"你家多大、喜欢什么风格、有没有老人小孩"）
- **带去对应区域**：每个区域10秒（客厅家具区10秒、卧室家具区10秒、餐厅家具区10秒）
- **算预算**：5秒讲完（"X万配齐客厅、卧室、餐厅"）
- **客人评价**：5秒收尾（"他俩说比预想的还满意"）

加转折点：中间插一个"客人本来想选那款，听你一说才发现不适合"（纠错），制造情绪波点

---

### 3. 播放量高但咨询少（看的人多，但没人私信/到店）

**先怀疑什么**：  
专业证据不足、主页承接差——观众看完觉得"挺有意思"，但不信你能帮他挑、不知道去哪找你

**下一步做什么实验**：  
1. **补专业证据**：拍的时候多拍这些细节画面——你拿卷尺量尺寸、你拿手机给客人看效果图、你帮客人算预算（拿笔记本或手机计算器）。这些画面放在视频里，证明你专业、细致
2. **理清主页和行动入口**：
   - 简介里写清楚"我是谁 + 能帮你什么 + 联系方式"（≤60字，口语化）："南乐外兴，万客隆家具城老板。6000平、6大品类，帮你挑适合你家的家具。想来看的私信我"
   - 置顶1-2条数据最好的视频（情境还原系列里完播率较高、评论区咨询最多的那条）
3. **结尾行动指令改得更具体**：
   - ❌ "想来店里看看的，私信我" 
   - ✅ "想来现场看的，私信我发地址。南乐外兴，导航万客隆家具城"（地址 + 导航关键词都说清楚）
