# 万客隆家具城·李国才 · 创作方向

## 📌 这个方向的思路

你的目的是引流到店、卖团购，核心任务是让本地装修到选家具这一步的人看到你、信你、来找你。你的最大优势是6000平六大品类一站配齐+教师背景会讲，最大短板是一人全包、只能挤空档拍。

"秋天门店日常"这个想法**方向对，但落点需要调整**——不是拍"今天又上了新货、店里挺忙"这种流水账，而是把秋季这个时间点当**背景**，拍的还是"客人来了我怎么帮他挑"这件事。秋季是装修旺季尾声+过年前换新的前奏，客人心态是"抓紧定下来"，你的内容要匹配这个节奏：要么帮他快速决策（教知识、晒过程），要么让他记住你等需要时来找（人设型）。

这一批方向分三路：**变现型 3 个**（直接推动到店，占主力）、**人设型 1 个**（让人记住你这个人）、**流量型 1 个**（扩大本地曝光）。全部落在秋季场景，用你已验证数据好的"晒过程"做主力形式，配合教知识和讲故事。

## （小黄）：每个方向的拍法主要从这里挑

#### 清单（计名【最适合的目的】：结构公式）

- **反向操作**【流量型】：常规A → 反向B → 真实反应/结果
- **扮猪吃虎**【变现型】：低预期 → 质疑/冲突 → 实力展示 → 爽感回收
- **以物换物**【人设型】：提出交换 → 协商 → 体验 → 挖掘人物 → 情感结果
- **一句话设定故事感**【人设型】：普通动作 + 目标/困境/关系设定 → 故事期待
- **加入人物关系**【人设型】：主任务 + 关系角色出镜 + 互动结果
- **情境还原**【变现型】：真实任务 → 对话/纠错 → 旁观学习 → 结果
- **借势点评**【流量型】：热点事实 → 专业拆解 → 判断/建议 → 回到用户
- **正确做法VS错误做法**【变现型】：错误示范 → 后果 → 正确示范 → 原理/适用条件
- **互联网嘴替/替网友做**【变现型】：征集问题 → 选择任务 → 亲测过程 → 结果与建议
- **对比改造**【变现型】：改造前 → 目标/预算 → 关键步骤 → 改造后 → 复盘
- **行业避坑**【变现型】：点名坑 → 后果 → 识别信号 → 替代方案
- **懒人学习**【变现型】：低门槛承诺 → 演示 → 立即验证 → 延伸
- **怀旧复古**【流量型】：年代入口 → 细节复原 → 当时体验 → 今昔连接
- **南北/地域差异**【流量型】：同一任务两地做 → 差异反应 → 原因/文化 → 交流
- **宠妻/宠夫反差**【人设型】：硬话塑造表象 → 家务/育儿行动 → 细节证明 → 温情回收
- **街头采访**【流量型】：一句好问题 → 追问 → 人物故事/观点 → 行业连接
- **冷知识**【流量型】：反常识结论 → 证据/例子 → 原理 → 应用

## 🧭 内容方向

### 方向1：秋季赶工期客户帮挑实录系列
- **对应目的**：变现型（引流到店、促成团购转化）
- **内容类型**：情境还原
- **讲法**：晒过程——把真实接待客户、帮他挑家具的完整链路记录下来，从进门到定下方案，让观众旁观学习"原来是这么挑的"
- **内容方向**：拍秋季装修收尾、赶着入住的客户到店，你问预算、问户型、问喜欢的风格，然后带他去对应区域挑，现场对话+你的讲解，最后定下哪几件、为什么这么配。每条聚焦一个真实客户案例
- **为什么能达到目的**：秋季是装修旺季尾声，很多人赶着年底入住，正处于"必须定下来"的决策阶段。这类内容直接展示你的专业能力（会问、会配、会讲清楚为什么），观众看完会觉得"找他省心"，符合档案里客户真正想要的"要有人帮着挑、要省心省事"。你的教师背景让你比同行更会讲，6000平六大品类让你能现场配齐，这两个优势在这个方向里都用上了
- **核心思路**：不拍货，拍"我怎么帮客人挑货"这个过程
- **可拍的选题示例**：
  1. 【换成你接待的真实客户：比如这周来的预算有限、要配齐客厅卧室的年轻夫妻，你帮他们挑了哪几件、怎么配的】
  2. 这个客户装的新中式，但预算不够全买实木，我教他哪几件必须买好的
  3. 秋天赶工期的客户最怕选错，我用这三个问题帮他快速定下方案
- **怎么拍**：手机拍，你本人出镜。客人到店时征得同意后拍（拍背影或侧面、不拍正脸），记录你问问题、带他看货、讲解的过程。可以事后补拍一段对着镜头的总结（"今天这个客户的情况是……我给他的方案是……"）。需要准备：提前和客人沟通拍摄、打码工具
- **开头示范**：【换成你接待的真实客户：比如"这周来了位赶着年底入住的客户，预算X万要配齐客厅卧室，我问了他们三个问题就定下方案了"】
- **看什么数据**：私信量、评论区问"我家XX平、预算XX,能帮我配吗"的数量、视频播放后到店提"刷到视频"的人数
- **难度**：中。需要客人配合，但你已经有6000平门店和稳定客流，只是把日常接待过程拍下来
- **节奏**：第1-2周，优先做，这是你已验证数据好的"入户视频"的前置版本

### 方向2：秋季六大品类快速选购指南
- **对应目的**：变现型（引流到店、建立专业信任）
- **内容类型**：行业避坑
- **讲法**：教知识——针对秋季装修收尾、赶着定家具的人，拆解六大品类（新中式、美式、宋式、现代轻奢、通货大众款、办公）各自最容易踩的坑，给出识别信号和替代方案
- **内容方向**：每条聚焦一个品类，讲"秋天买XX家具，这三个坑千万别踩"。坑来自真实案例（客人买错了、或者你见过的同行套路），给出具体识别方法（看哪里、问什么、怎么判断），最后引到"不确定的可以来店里，我帮你现场看"
- **为什么能达到目的**：客人最担心"选择太多挑花眼、怕质量有问题、怕被宰"，避坑类内容直接命中这三个痛点。你的教师背景让你讲得清楚，15年行业经验（合伙人）让你有资格讲坑。秋季是定家具的集中期,观众搜索和刷到这类内容的概率高,看完会收藏、转发给家人,自然带来到店咨询
- **核心思路**：用"教你避坑"建立专业信任,同时植入"来店里我帮你现场看"的行动指令
- **可拍的选题示例**：
  1. 秋天买新中式家具,这三个坑踩了多花不少钱还不实用
  2. 办公家具别只看价格,老板们最容易忽略这一点
  3. 通货大众款家具怎么挑性价比较高的?我教你现场看这三个地方
- **怎么拍**：手机拍,你本人出镜,在店里对应品类区域拍。开篇直接说坑（"很多人买XX时会……结果……"),然后走到具体家具前,边指边讲识别方法,最后一句"不确定的直接来店里,我现场帮你看"。需要准备：提前列好每个品类最常见的3个坑
- **开头示范**：很多人秋天买新中式家具,只看样子好看就定了,结果搬回家发现尺寸不对、颜色也不搭
- **看什么数据**：完播率、收藏数、评论区问"XX情况算不算坑"的互动量、私信咨询量
- **难度**：低。不需要客人配合,你一个人对着镜头讲+指家具就行,符合"一人全包、挤空档拍"的条件
- **节奏**：第1-3周,和方向1交替发,力求每周有变现型内容

### 方向3：预算X万全屋配齐挑战系列
- **对应目的**：变现型（引流到店、展示性价比和一站配齐优势）
- **内容类型**：扮猪吃虎
- **讲法**：晒过程——接受观众或假想客户的预算挑战（"X万能配齐全屋吗"),从低预期开始,展示你在6000平六大品类里怎么挑、怎么搭,最后呈现超出预期的配齐方案
- **内容方向**：每条设定一个预算(如【待确认：填入你想演示的预算档位，比如3万、5万、8万】),你在店里实际走一遍选货流程:客厅选什么、卧室选什么、怎么在不同品类间平衡,最后加起来算总价、展示配齐的效果。重点展示"你以为X万配不齐,其实在我这能配成这样"
- **为什么能达到目的**：直接命中"性价比高"和"便利性"两个核心卖点。秋季装修收尾的人预算往往已经超了,会搜"X万能配齐吗""家具怎么省钱"这类问题。这个方向用真实挑货过程证明"你这一站就能配齐、而且不贵",观众看完会产生"我预算XX,要不去他店里看看"的冲动。扮猪吃虎的结构天然有爽感,利于传播
- **核心思路**：用预算挑战制造期待,用真实配货过程展示专业和性价比,用超预期结果收尾
- **可拍的选题示例**：
  1. 有人问我【待确认：填入具体预算】能配齐全屋吗?我在店里实际挑了一遍给你看
  2. 秋天预算不够怎么办?我教你【待确认：填入预算对比，比如"3万配出5万的效果"】
  3. 同样的预算,在我这能比别人多配这三件
- **怎么拍**：手机拍,你本人出镜。开篇抛出预算挑战,然后拿着手机边走边拍,在店里不同区域选货(实际指着家具说"客厅沙发选这款【待确认：填入实际价格】、茶几配这款【待确认：填入实际价格】……"),最后站在选好的家具前总结"【待确认：填入预算】配齐了客厅卧室X件,比你想的多吧"。需要准备：提前规划好几个预算档位的配货方案、标好价格
- **开头示范**：有人私信问我,秋天装修预算只剩【待确认：填入具体预算】了,还能配齐全屋家具吗?今天我就在店里实际挑一遍给你看
- **看什么数据**：播放量(这类内容话题性强,容易跑泛流量)、评论区问"我预算XX够吗"的互动、私信量、到店转化
- **难度**：中。需要提前规划配货方案和价格,但不需要客人配合,你一个人能拍完
- **节奏**：第2-4周,在方向1和方向2跑通后补充,丰富变现型内容的形式

### 方向4：教师转行卖家具的秋日门店观察
- **对应目的**：人设型（让人记住你这个人、建立情感连接）
- **内容类型**：一句话设定故事感
- **讲法**：讲故事——用秋天门店日常做背景,但不是流水账,而是给每个普通动作加上你的身份设定("当过5年教师的家具城老板")和内心想法,让观众看到你这个人的性格、价值观和对这行的理解
- **内容方向**：拍秋季门店里的真实片段:进货、整理库房、接待客人、送货,但旁白或对话里带出你的教师思维("以前教书时总说要因材施教,现在卖家具也一样,每个客人需求不同""秋天生意好,但我不催单,客人想清楚了再买")。每条聚焦一个日常场景+一个你的观点或故事
- **为什么能达到目的**：人设型内容的作用是让老粉更了解你、让新观众记住你。你的"5年教师经验"是同行没有的标签,这个方向把它用起来,让观众看到"这个老板不一样,他会讲、实在、不忽悠"。秋季门店忙碌的真实感配合你的表达,容易引发"这人靠谱"的信任。这类内容不直接促成交,但积累下来会让客人在需要时第一个想到你
- **核心思路**：用秋季门店日常做载体,用教师身份做人设钩子,用真实想法建立人格魅力
- **可拍的选题示例**：
  1. 秋天门店最忙,但我从不催客人下单,因为当老师时学会的第一件事就是……
  2. 今天又有客人问我为什么不还价,我说了一句话他直接定了
  3. 做了一年家具城,秋天是我最喜欢的季节,因为……
- **怎么拍**：手机拍Vlog,你本人出镜+旁白。拍你在店里干活的真实片段(【换成你实际做的事：比如整理家具陈列、和客人交谈的背影、开车去送货】),配上你的画外音讲那个场景下你在想什么、为什么这么做。可以对着镜头直接讲,也可以边干活边说。需要准备:提前想好几个你真实的想法或小故事
- **开头示范**：秋天是家具城最忙的时候,今天又来了好几拨客人,但我从来不催他们下单
- **看什么数据**：主页访问量、关注量、评论区"老板实在""这人靠谱"这类评价、私信里"看你好几条视频了"的表述
- **难度**：低。不需要客人配合,你一个人边干活边拍就行,符合"挤空档拍"的条件
- **节奏**：第2-4周,穿插在变现型内容之间,力求账号有人设温度

### 方向5：秋季南乐人买家具的习惯观察
- **对应目的**：流量型(扩大本地曝光、吸引同城新观众)
- **内容类型**：南北/地域差异
- **讲法**：聊观点——观察并总结南乐本地人秋季买家具的特殊习惯或地域差异,用对比、举例的方式讲出来,引发本地人共鸣和外地人好奇
- **内容方向**：每条讲一个南乐本地买家具的真实现象:秋天哪个时间段来的人最多、本地人喜欢什么风格、砍价习惯、会带谁一起来、对什么最在意。用"南乐人买家具都这样"或"我发现南乐人和XX地的人不一样"做切口,讲具体例子,最后抛观点或提问引评论
- **为什么能达到目的**:地域话题天然自带流量,本地人看到会觉得"说的就是我/我家人",外地人会好奇"他们那怎么这样",容易引发评论和转发。你的"本地化优势明显(南乐外兴人)"在这个方向里是核心资产。秋季是买家具高峰,这类内容话题性强,容易跑本地同城流量,给账号带新粉,后续再用变现型内容转化
- **核心思路**:用地域观察做流量入口,用真实细节建立"本地人"认同感
- **可拍的选题示例**:
  1. 我发现南乐人秋天买家具,不少人会……你们也这样吗?
  2. 在南乐卖了一年家具,发现本地人和濮阳市里的客人买家具习惯完全不一样
  3. 秋天最忙的时候不是周末,南乐人买家具都挑这个时间来
- **怎么拍**:手机拍,你本人出镜,在店里或店门口拍。开篇直接抛观点或现象,然后举几个真实例子(可以是你接待的客人、可以是店里观察到的),最后一句话抛问题给评论区("你们家买家具也这样吗?""外地的朋友说说你们那是不是这样")。需要准备:提前总结几个你真实观察到的本地买家具习惯
- **开头示范**:在南乐卖了一年家具,我发现本地人秋天买家具有个特别的习惯,不少客人都会这么干
- **看什么数据**:播放量(尤其是非关注播放占比)、评论区本地人互动量("哈哈哈说的就是我家""南乐人都这样")、新增关注数
- **难度**:低。不需要客人配合,你对着镜头讲观察就行,拍摄成本低
- **节奏**:第3-5周,在变现型和人设型内容稳定后补充,用于扩大曝光、拉新粉

- **为什么是它**:你的目的是引流到店、卖团购,这个方向最直接——观众看完就知道"找你能帮我挑、省心",符合客户真正想要的。你已经验证过"入户视频"数据好,这个方向是它的前置版,成功率高。秋季是装修收尾+赶入住的高峰,这类内容现在拍正当时。你的教师背景让你比同行更会讲,6000平六大品类让你能现场配齐,这两个优势在这个方向里都用上了。一人全包、挤空档的条件下,拍真实接待过程最省力,不用额外编剧本
- **第一周怎么开始**:
  1. 这周接待客人时,挑一个愿意配合的,征得同意后拍(只拍背影/侧面,不拍正脸),记录你问问题、带他看货、讲解的完整过程
  2. 拍完后补拍一段对着镜头的总结:"今天这个客户预算【待确认：填入实际预算】、要配XX,我给他的方案是……",剪进视频开头或结尾
  3. 发布时标题写"秋天赶工期的客户来了,我帮他【待确认：填入实际预算】配齐了客厅卧室",评论区置顶"你家装修到哪一步了?预算多少?评论区告诉我"
- **其他方向什么时候做**:方向2(避坑指南)第2周就可以开始,和方向1交替发,力求每周有变现型内容。方向4(人设日常)第2-3周穿插进来,让账号有温度。方向3(预算挑战)等方向1跑出几条后(第3-4周)再做,丰富形式。方向5(地域观察)放第4周后,用于扩大本地曝光、拉新粉

## ⚠️ 这次先别做的

- **不做纯货品展示**:只拍家具特写+纯音乐、没有人没有场景的那种。你的优势是会讲、能帮客人挑,这类内容把优势全浪费了,而且同行都在做,没差异化
