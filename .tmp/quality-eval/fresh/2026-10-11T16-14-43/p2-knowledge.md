# 实体获客编导/不一门店短视频前3秒留人方法

## 一、先看你的特殊情况

你卖的是**编导AI工具 + 短视频代运营**，这个赛道有个要命的问题：

**用户刷到你的视频时，本身就在刷短视频——他们对"教短视频"的内容天然免疫。**

所以你的前3秒，**不能让人感觉在上课**，要让他觉得在看一个"濮阳本地懂行的人，在说一件和他有关的事"。

---

## 二、前3秒的三层任务（缺一个都会被划走）

### 【层1】首帧画面：一眼看出"这是谁"
- ❌ 对着镜头摆拍、空镜头配音、纯文字开场
- ✅ **生活化场景出镜**：
  - 在濮阳街头走着说（识别度：本地人一眼认出那条路）
  - 在工位上盯着电脑屏幕说
  - 【换成你自己常出现的真实场景】

### 【层2】第一句话：圈出"这和我有关的人"
不是圈"想做短视频的人"——太泛了。
要圈**濮阳本地、有具体困境的老板**：

#### 六种高意向开头（任选一种）

**1. 地域+困境圈人（最适合你）**
```
濮阳的实体老板，如果你现在账号发了二三十条，
播放量还在两三百打转，先别急着换赛道。
```

**2. 身份反差钩子**
```
我一个在濮阳做代运营的，
今天被客户问：你们和郑州、北京那些大公司有啥不一样？
我说了三句话，他当场签了。
```

**3. 痛点场景还原**
```
昨天一个濮阳老板给我看他拍的视频，
我只看了三秒，就知道为什么没人看完。
```

**4. 反常识+利益**
```
濮阳很多老板以为，短视频做不起来是因为不会拍——
其实90%的问题，出在开头那句话上。
```

**5. 损失厌恶**
```
这条视频我犹豫了三天要不要发，
因为一说出来,濮阳至少X家同行要骂我。
```
*（X处填你估算的本地同行数，不确定就写"好几家"）*

**6. 身份自嘲+专业反差**
```
我一个濮阳本地的小编导，
上周帮客户改了个开头，播放量从300直接到了X万。
客户问我:你咋不早说？
```

### 【层3】前5秒：说清"你在等什么"
开完头后，必须立刻接上**这条视频要给什么**：

- "今天就拆给你看，问题到底在哪。"（教知识-拆解型）
- "我把那三句话说给你听。"（晒过程-案例型）
- "这个坑,我见太多濮阳老板踩了。"（行业避坑-变现型）

## 三、你最容易犯的三个"前3秒杀手"

### ❌ 杀手1：一上来就自我介绍
```
大家好我是不一，我是做短视频代运营的……
```
→ 用户心理：**广告，划走。**

✅ 改法：**先说事，身份藏在事里自然带出**
```
昨天一个濮阳老板问我，为啥他拍的视频没人看——
我看了三秒，问题全在开头。
（旁白字幕可加：不一 | 濮阳本地实战编导）
```

---

### ❌ 杀手2：开头讲方法论，没有具体场景
```
今天教大家短视频开头怎么设计钩子……
```
→ 用户心理：**又是讲课的，我刷着玩的。**

✅ 改法：**先扔一个他正在经历的困境**
```
你有没有发现，自己拍的视频，
家人朋友都说挺好，就是没播放量？
```

---

### ❌ 杀手3：濮阳特色没用上，和外地同行一个样
你的核心优势是**"濮阳本土化、对本地有深刻认知"**，
但如果开头和郑州、北京的编导说的一样，
**用户凭什么选你？**

✅ 用法：**把"濮阳"当作信任锚点，前3秒就钉进去**
- "濮阳老板做短视频，有个外地人不知道的难处……"
- "在濮阳,我见过太多这样的店……"
- "濮阳这地方，熟人经济还是主流，但短视频的逻辑不一样……"

## 四、实战脚本示范（3条方向，直接套用）

### 【方向1：流量型-地域差异切入】
**目的**：让濮阳本地老板看到"这人懂我们这儿"

**开头（前3秒）：**
```
濮阳的实体老板，你们做短视频有个外地人不懂的难处——
这地方熟人经济太重了，一拍视频就怕熟人看见笑话。
```

**中段（痛点+方法）：**
```
我见过最狠的，拍了十几条，一条没发，
全存在草稿箱——怕街坊说"你还拍这个玩意儿"。

但你想想，抖音推荐机制，
你不发，系统怎么知道推给谁？
你越怕熟人看，流量就越起不来。

我有个客户，理发店老板，一开始也这样，
后来我跟他说：第一条就拍"我决定拍视频了，丑话说前头"，
把担心的事先说出来，反而有X个本地人私信他。
```
*（X处填真实数据，没有就写"好几个"）*

**结尾金句+指令：**
```
在濮阳做生意，面子重要，但面子不能当饭吃。
关注我，专门讲濮阳本地老板怎么拍。
```

---

### 【方向2：变现型-案例引入】
**目的**：推动咨询/合作意向

**开头（前3秒）：**
```
昨天一个濮阳老板给我看他的账号，
发了二十多条，播放量较高的一条才X。
我问他：你开头那句话，自己信吗？
```

**中段（问题拆解+解决方案）：**
```
他开头是这么说的：
"大家好，我是XX店老板，今天给大家分享……"

我说，你这句话有三个问题：
第一，用户不认识你，凭啥听你分享？
第二，"大家"是谁？你想让谁看到这条？
第三，分享什么？用户要等到第10秒才知道。

我帮他改成：
【换成你服务客户的真实案例：包括改前开头、改后开头、以及数据变化】

改完第二天，这条视频播放量X，
有X个人私信问地址。
```
*（X处填真实数据，无数据写【换成你服务客户的真实案例】）*

**结尾指令：**
```
你的账号如果也是这样，
可以私信发我，我帮你看看问题在哪。
```

---

### 【方向3：人设型-身份故事】
**目的**：让用户记住"不一=濮阳本地懂行的编导"

**开头（前3秒）：**
```
我一个在濮阳做代运营的，
上周被一个郑州来的客户问：
你们本地的，能行吗？
```

**中段（反转+价值观）：**
```
我当时就笑了，我说：
郑州的公司，可能给你配一个刚毕业的实习生，
写的文案全是"匠心""深耕""赋能"这种词——
你自己说话都不这么说。

我在濮阳干了X年，
见过的店、认识的老板，可能比他们整个团队加起来都多。
你店门口那条路我走过，
你担心的那些事，我客户也担心过。

这就是我能给的——
我不仅懂短视频,我更懂濮阳的生意怎么做。
```
*（X年填你真实从业年限，档案没写就留【X】让自己填）*

**结尾金句：**
```
对比金钱，我更看重合作的人怎么样。
想聊的，主页有联系方式。
```

你的优势是**"濮阳本土化+实战派+有温度的IP"**，

停下来之后,你的专业、温度、人情世故才有用武之地。
