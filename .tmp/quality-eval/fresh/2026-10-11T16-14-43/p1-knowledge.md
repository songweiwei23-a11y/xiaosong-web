## 二、能留人的开篇：6种钩子 × 找工作场景

### 💰 金钱型钩子(适合流量型)
**公式**:具体数字 + 反差 + 为什么不一样

```
"濮阳这边进电子厂,为什么有人一个月5千,有人能拿7千?"
→ 第2秒:镜头切到厂区门口
→ 第5秒:"差别就在这三个细节"
```

```
【换成你接待的真实客户：比如某个工人刚进厂就出来了,具体是什么情况,他当时怎么说的】
→ 第2秒:工人坐副驾发愁的画面
→ 第5秒:"后来我问他,他说了X句话"
```

---

### 🎁 盲盒型钩子(适合流量型/变现型)
**公式**:今天发生了X / 刚接到一个电话 / 有个工人跟我说

```
"早上六点多,一个干了三个月的工人给我打电话——说厂里出事了。"
→ 第2秒:手机来电截图特写
→ 第5秒:"我问他怎么回事,他说……"
```

```
"刚把人送到厂门口,保安不让进——说这批招满了。"
→ 第2秒:厂区门口实拍
→ 第5秒:"这种情况我遇到过,但今天这个不一样"
```

---

### ⚔️ 对抗/反常识型钩子(适合流量型)
**公式**:我不认为 / 千万别 / 很多人以为X,其实Y

```
"濮阳找工作,千万别一上来就问包吃包住——真正要问的是这个。"
→ 第2秒:你在车上开着车说话
→ 第5秒:"为什么?因为……"
```

```
"我不认为进厂工资越高越好——有些厂给得高,但干不满一个月。"
→ 第2秒:镜头对着你,背景是厂区
→ 第5秒:"怎么分辨?看这三点"
```

---

### 🔍 验证解密型钩子(适合变现型)
**公式**:很多人不知道 / 判断XX好不好,应该看这里

```
"濮阳这边电子厂、食品厂、物流仓,哪个最适合四十多岁的?很多人选错了。"
→ 第2秒:三个厂区画面快闪
→ 第5秒:"我送了X年工人,今天告诉你怎么选"
```

```
"判断一个厂靠不靠谱,别光看招工广告——去厂门口看这个。"
→ 第2秒:厂区门口实拍
→ 第5秒:"我今天带你看"
```

---

### 🤝 送温暖型钩子(适合人设型/变现型)

```
"濮阳周边这几个厂,我送工人去了X年——今天说说哪些真管饭,哪些是坑。"

### 💔 共鸣型钩子(适合人设型)

```
"三十八岁那年,我在厂门口站了一下午——保安说年龄大了不要。"
→ 第2秒:你站在某个厂门口
→ 第5秒:"后来我想明白一件事"
```

```

## 三、开篇3秒配套动作(画面+声音)

| 时间点 | 画面要求 | 声音要求 |
|--------|---------|---------|
| **首帧(0秒)** | 你的脸/厂区门口/车内视角,**有主体** | 第一句话是钩子,**不是"大家好"** |
| **第2秒** | 画面切换/运镜推进/出现关键物 | 继续说钩子后半句,**建立期待** |
| **第3-5秒** | 交代"接下来你会看到什么" | 承诺兑现点("我今天告诉你""后来发生了X") |

## 四、你的账号专属建议(结合档案卖点)

你的核心优势是**便利性(接送)+ 服务好(全程跟进)+ 选择多(岗位匹配)**,开篇要体现这三个里的至少一个:

### ✅ 体现便利性的开篇
```
"濮阳找工作,为什么有人让你自己去厂里,我要开车送你过去?"
→ 体现接送这个差异化
```

### ✅ 体现服务好的开篇
```
【换成你接待的真实客户：比如某次送工人去厂里,到了之后你没走,具体因为什么情况】
→ 体现全程跟进
```

### ✅ 体现选择多的开篇
```
"濮阳周边X个厂,为什么我能给你推荐最合适的那个?"
→ 体现岗位匹配能力
```

## 五、3个立刻能用的开篇模板(可直接拍)

### 模板1:反常识 + 验证(流量型)
**开篇**:"濮阳找工作,千万别一上来就问多少钱——真正要问的是这个。"  
**第2秒**:你在车里,手搭在方向盘上  
**第5秒**:"为什么?因为很多厂给得高,但有这三个坑。"  
**中间**:讲3个坑(压工资/扣体检费/试用期辞退)  
**结尾**:"下次找工作,先问这三个问题。"  
**行动指令**:关注我,下期说怎么问

---

### 模板2:盲盒 + 故事(变现型)
**开篇**:"早上六点多,一个干了三个月的工人给我打电话——说不想干了。"  
**第2秒**:手机来电画面(可以是你拿着手机的镜头)  
**第5秒**:"我问他为什么,他说了X句话。"  
**中间**:还原对话,讲出真实原因(比如厂里承诺的没兑现/岗位不合适)  
**结尾**:"找工作不是找到就行,得找对。"  
**行动指令**:私信我,帮你匹配

---

### 模板3:送温暖 + 清单(变现型)
**开篇**:"濮阳周边这几个厂,我送工人去了X年——今天说说哪些真管饭,哪些是坑。"  
**第2秒**:你开车在路上,或者厂区门口  
**第5秒**:"第一个是XX厂,管两顿饭……"  
**中间**:列3-5个厂,每个说1句核心信息(管饭/不压工资/年龄放宽)  
**结尾**:"需要找工作的,我这边岗位多,能根据你情况推荐。"  
**行动指令**:私信我
