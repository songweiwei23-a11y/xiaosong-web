# 锦园地摊串串一元火锅 · 创作方向

## 📌 这个方向的思路

用户想拍"秋天到了，门店这个季节的日常"——目的是引流到店、卖团购。拆开看：**引流 = 让周边3-5公里还不知道的人看到店、知道位置和团购**；**卖团购 = 让看完视频的人产生"我要去试试"的冲动，直接下单或评论问**。

这个账号最大优势：**地摊烟火气 + 四川师傅手艺 + 火锅团购已上线**，秋天正是烧烤火锅的黄金季节，下班时段和抖音推流时段重合。最大短板：还没发过视频，不知道哪种内容观众买账，也不懂平台规则。

这一批方向的分工：**3个变现型（主力，直接推团购和到店）+ 1个流量型（扩曝光，拉新人）+ 1个人设型（让老客和新客都记住师傅）**。秋天的"日常"不能拍成流水账，要把"秋天适合吃什么、师傅怎么准备、客人怎么反应"这三件事拆开，每个方向解决一个问题。

#### 清单（计名【最适合的目的】：结构公式）

- **反向操作**【流量型】：常规A → 反向B → 真实反应/结果（适合：服务、教学、美食、摄影）
- **扮猪吃虎**【变现型】：低预期 → 质疑/冲突 → 实力展示 → 爽感回收（适合：技能、体育、职场、艺术）
- **以物换物**【人设型】：提出交换 → 协商 → 体验 → 挖掘人物 → 情感结果（适合：实体商品、探店、手工、地方文化）
- **借物喻人**【人设型】：物的事件 → 双关对应 → 情绪推进 → 人生落点（适合：情感、哲理、数码、生活）

- **一人分饰多角**【流量型】：角色A观点 ↔ 角色B回应 → 知识/反转（适合：知识、品牌测评、段子、）

- **正确做法VS错误做法**【变现型】：错误示范 → 后果 → 正确示范 → 原理/适用条件（适合：健身、育儿、英语、沟通）

- **互联网嘴替/替网友做**【变现型】：征集问题 → 选择任务 → 亲测过程 → 结果与建议（适合：实验、测评、美食、穿搭、减脂）

- **南北/地域差异**【流量型】：同一任务两地做 → 差异反应 → 原因/文化 → 交流（适合：美食、市场、婚俗、生活服务）

## 四大脚本（薛老师）：辅助，管话怎么讲
- **教知识**（涨粉）：课程里叫"抖音变现的碗"——粉丝最精准，是账号的地基
- **聊观点**（吸"真"粉丝）：靠观点和情绪价值建人物 IP，粉丝认的是人，不是内容

- **讲故事**（成交高客单）：靠困境、转机和情绪递进建立高信任，适合客单价高的生意

## 🧭 内容方向（勾选想做的方向，带去选题或脚本接着做）

### 方向1：秋天师傅开始备的这道菜（单品拆解建专业）
- **对应目的**：变现型——直接推火锅团购，让观众看完想下单
- **内容类型**：**情境还原**【变现型】
- **讲法**：晒过程 + 教知识。用师傅一道秋季菜品（比如萝卜牛腩、酸汤肥牛、羊肉汤锅底）从买料到端上桌的完整动作，边做边讲"秋天为什么要吃这个、四川人怎么做、和别家的区别"
- **内容方向**：拍师傅秋天开始准备的应季菜品或锅底，聚焦一道菜的完整过程。从采购（"今天去市场挑了X斤羊排"）、处理食材（"四川做法要先焯水去膻"）、调味（"清汤锅底只放这三样"）到成品上桌，用手艺细节建立"9年川菜师傅"的专业背书
- **为什么能达到目的**：秋天天气转凉，观众本身就有"想吃热乎的"需求，刷到这条视频正好踩在痛点上。师傅的手艺过程 = "实在不坑"的证据，看完自然想试。火锅团购已上线，评论区或结尾直接引导下单
- **核心思路**：用一道菜的真实制作过程，把"9年川菜师傅、正宗川味、秋天适合吃"这三个卖点自然带出来
- **可拍的选题示例**：
  - 四川师傅秋天炖清汤羊肉的规矩
  - 秋天的酸汤肥牛，师傅说要多加一味
  - 师傅说秋天吃火锅要先喝这碗汤
- **怎么拍**：师傅出镜，从下午4点开始备菜拍到晚上第一桌客人上桌。手机拍，重点拍手部动作（切、炖、调味）和锅里的状态（食材下锅、汤色变化）。需要准备：当天的真实食材、师傅的围裙或厨师服（强化身份）
- **开头示范**："秋天一到，四川师傅就开始炖这锅汤，9年的规矩一样都不能少"
- **看什么数据**：完播率（能不能看完整个过程）、评论区问"在哪""多少钱"的数量、团购链接点击率
- **难度**：低。师傅本来就要备菜，只是把过程拍下来；不需要额外成本
- **节奏**：第1周，起号第一条就可以拍这个

### 方向2：秋天地摊上的第一桌客人（用真实用餐证明"值得来"）
- **对应目的**：变现型——让观众看到真实场景和客人反应,产生"我也要去"的冲动
- **内容类型**:**情境还原**【变现型】
- **讲法**:晒过程。拍秋天第一批到店客人从坐下、点餐、上菜到吃的完整过程,不解说或少解说,让真实场景说话。可以抓客人的自然对话("这天儿吃火锅正好""师傅手艺没话说")
- **内容方向**:拍秋天晚上6-8点的真实营业场景,聚焦一桌客人的完整用餐体验。从客人进门、师傅招呼、点单、上菜、开吃到结账离开,用地摊烟火气 + 客人真实反应证明"口碑好、有特色、实在不坑"
- **为什么能达到目的**:真实场景比任何话术都有说服力。观众看到别人在吃、看到地摊的烟火气、听到客人说"好吃",会产生"我也想去"的从众心理。秋天天气舒适,地摊露天用餐的体验感更强,正是引流到店的好时机
- **核心思路**:不说"我家好",让客人的表情和动作替你说
- **可拍的选题示例**:
  - 秋天第一批客人来地摊吃火锅的全过程
  - 降温那天晚上这桌客人的反应
  - 师傅说秋天生意好是因为这桌老客
- **怎么拍**:手机拍,旁观视角。征得客人同意后拍背影或侧面(不拍正脸),重点拍:客人坐下的环境(地摊、炭火、烟雾)、师傅上菜的动作、客人夹菜吃的画面、客人之间的对话。需要准备:提前跟熟客打招呼同意拍摄,选择秋天天气好的傍晚(光线柔和、烟火气足)
- **开头示范**:"秋天一降温,地摊上第一桌客人6点就来了"
- **看什么数据**:完播率、评论区问"在哪""几点去"的数量、视频分享量(想发给朋友约着去)
- **难度**:低。不需要额外准备,只需要在正常营业时拍;难点是要提前跟客人沟通好拍摄
- **节奏**:第1-2周,和方向1交替拍(一条拍师傅、一条拍客人)

### 方向3:秋天吃火锅怎么点值(教点单拆解变现障碍)
- **对应目的**:变现型——拆解"选择太多、挑花眼"的障碍,直接教观众怎么点单,降低决策成本
- **内容类型**:**懒人学习**【变现型】
- **讲法**:教知识。用师傅或老板的视角,教观众"秋天来我们店吃火锅,这么点划算、好吃"。给出具体的点单公式(比如"锅底选X + 必点这三样 + 最后加一份Y"),让观众看完就知道怎么点
- **内容方向**:拍师傅或老板出镜,对着镜头教"秋天吃火锅的点单攻略"。从锅底选择(清汤还是红汤、秋天适合哪种)、必点菜品(哪些是招牌、哪些性价比高)、分量搭配(两个人点多少、四个人点多少)到吃的顺序(先涮什么后涮什么),把"怎么吃值"掰开了讲
- **为什么能达到目的**:档案里提到客人最担心"选择太多、挑花眼"。这条内容直接解决这个问题——看完视频就知道怎么点,降低决策成本,到店后不慌。同时植入"一元火锅、川味串串火锅"的具体菜品,让观众对团购内容有预期
- **核心思路**:把"怕不会点、怕点多了浪费"的顾虑提前化解掉
- **可拍的选题示例**:
  - 师傅教你秋天吃火锅的正确打开方式
  - 两个人来吃火锅,这么点刚刚好
  - 秋天吃火锅必点这三样,师傅说错不了
- **怎么拍**:师傅或老板出镜口播,站在店里或操作台前。手机拍,边说边指(指向锅底、指向菜品)。需要准备:提前列好点单公式(写在纸上或背下来),准备好要展示的菜品实物(摆在操作台上当道具)
- **开头示范**:"秋天来吃火锅,不少人不知道怎么点,师傅教你一招"
- **看什么数据**:完播率、评论区问"团购链接""在哪"的数量、收藏量(想到店前再看一遍)
- **难度**:中。需要师傅或老板能流畅口播,提前理清点单逻辑;如果师傅不擅长对镜头说话,可以用字幕 + 画面展示的方式
- **节奏**:第2-3周,在拍了几条"过程"内容后再拍这条(先让观众看到真实场景,再教怎么吃)

### 方向4:南乐入秋了,四川师傅和本地人的对话(地域差异拉流量)
- **对应目的**:流量型——用南北差异话题扩大曝光,让更多本地陌生人刷到这个店
- **内容类型**:**南北/地域差异**【流量型】
- **讲法**:聊观点 + 晒过程。用师傅(四川人)和老板或客人(本地人)的真实对话,展示"四川人眼里的秋天 vs 南乐人眼里的秋天"在吃这件事上的差异。比如"四川人秋天就想吃火锅,南乐人说还不到时候""四川人觉得这天儿不冷,南乐人已经加衣服了"
- **内容方向**:拍师傅和老板(或老客)的真实对话,聚焦"秋天吃什么"这个话题。从天气感受(四川vs南乐)、饮食习惯(四川秋天吃什么、南乐秋天吃什么)到门店的应季调整(师傅准备的秋季菜品、本地人的反应),用地域差异制造话题和笑点
- **为什么能达到目的**:地域差异是天然的流量话题,本地人看到会转发("说的就是我们这儿"),外地人看到会评论("我们那也这样")。师傅是成都来的、老板是南乐本地人,这个人设组合天然适合拍地域差异。流量起来后,评论区引导到店或团购
- **核心思路**:用"四川师傅 vs 南乐老板"的真实碰撞,把地域差异变成记忆点
- **可拍的选题示例**:
  - 四川师傅来南乐半年,说秋天必须吃这个
  - 南乐人说还不冷,四川师傅已经开始炖汤了
  - 师傅说四川人秋天这么吃,南乐老客笑了
- **怎么拍**:师傅和老板(或老客)同框出镜,对话形式。手机拍,可以在店里边干活边聊(比如师傅在备菜、老板在旁边帮忙),也可以坐下来面对镜头聊。需要准备:提前想好话题(列3-5个秋天相关的地域差异点),让对话自然不尴尬
- **开头示范**:"四川师傅来南乐半年,说秋天一到就该吃这个,南乐老板不服了"
- **看什么数据**:播放量(地域话题覆盖面广)、评论区互动量(本地人和外地人的讨论)、分享量
- **难度**:中。需要师傅和老板都能自然出镜对话,提前rehearse一下避免冷场;如果师傅或老板不擅长,可以改成旁白 + 画面对比的形式
- **节奏**:第2-3周,在拍了几条变现型内容后穿插(流量型内容用来扩大曝光,但不能只拍这个)

### 方向5:师傅来南乐半年,为秋天准备的这件事(人设故事建信任)
- **对应目的**:人设型——让观众记住师傅这个人,建立"9年川菜师傅、正宗川味"的长期信任
- **内容类型**:**一句话设定故事感**【人设型】
- **讲法**:讲故事 + 晒过程。用师傅的视角,讲"我来南乐半年,为了秋天这个季节准备了什么"。从师傅的经历(在成都做了9年川菜、为什么来南乐)、对秋天的理解(四川人眼里秋天该吃什么)到为这个季节做的准备(备了哪些应季食材、调整了哪些菜品),用故事感让观众记住这个人
- **内容方向**:拍师傅出镜,讲述"来南乐半年,为秋天做的准备"。从师傅的日常动作(去市场选应季食材、试做新菜品、调整锅底配方)到师傅的想法(秋天南乐人爱吃什么、我想怎么做),用真实细节把"9年川菜师傅"的专业和"实在不坑"的人品立起来
- **为什么能达到目的**:人设型内容的作用是让观众记住"这个人",而不只是"这家店"。师傅是门店"正宗川味"的核心保障,把师傅立起来 = 把信任建起来。这条内容不直接推团购,但看完的观众会记住"南乐有个四川师傅",下次想吃火锅自然会想到这家
- **核心思路**:用师傅的经历和准备,把"9年川菜师傅、来南乐半年、为秋天用心"这三个点串起来
- **可拍的选题示例**:
  - 四川师傅来南乐半年,为秋天准备的这些事
  - 师傅说秋天是川菜师傅最忙的时候
  - 做了9年川菜,师傅说秋天必须备这个
- **怎么拍**:师傅出镜,可以是口播(对着镜头讲),也可以是旁白 + 师傅干活的画面(比如去市场、在店里备菜、试菜)。手机拍,重点拍师傅的动作和表情(认真、专注)。需要准备:提前跟师傅聊,挖出真实的经历和想法(不要编),让师傅用自己的话讲出来
- **开头示范**:"我在成都做了9年川菜,来南乐半年,就等秋天这个季节"
- **看什么数据**:主页访问量(看完想了解更多)、关注量、评论区的情感反馈("师傅用心""想去试试")
- **难度**:中。需要师傅能自然出镜讲述,提前沟通好;如果师傅不擅长对镜头说话,可以用旁白 + 画面的方式,但要保留师傅的真实声音(哪怕是干活时的自言自语)
- **节奏**:第3-4周,在账号有一定粉丝基础后再拍(前期先用变现型内容跑通引流,再用人设型内容加深信任)

### 我推荐先做:方向1「秋天师傅开始备的这道菜」
- **为什么是它**:起号第一条最重要的是**跑通"看完想来"这个链路**。方向1直接拍师傅做菜的完整过程,把"9年川菜师傅、正宗川味、秋天应季"三个卖点自然带出来,观众看完能直观感受到"手艺好、实在不坑"。秋天天气转凉,观众本身就有"想吃热乎的"需求,这条内容踩在需求上,转化率高。火锅团购已上线,拍完直接引导下单,变现链路最短。拍摄成本低(师傅本来就要备菜,只是把过程拍下来),适合2-3人小团队 + 手机设备
- **第一周怎么开始**:
  1. **选一道秋季应季菜品**:跟师傅确认秋天店里主推哪道菜(比如清汤羊肉、酸汤肥牛、萝卜牛腩),选一道食材好拍、过程清晰的
  2. **拍摄当天下午4点到店**:从师傅备菜开始拍(买料、处理食材、调味、炖煮),重点拍手部动作和锅里状态,拍到晚上第一桌客人上桌为止。提前跟师傅说好拍摄,让他边做边说"为什么这么做、四川做法是什么"
  3. **剪辑 + 发布**:把完整过程剪成30-60秒(留完整版1-3分钟备用),开头用"秋天一到,四川师傅就开始炖这锅汤",结尾字幕引导"火锅团购已上线,评论区告诉你在哪"。发布时间选晚上6-8点(本地用餐黄金时段)
- **其他方向什么时候做**:方向2(拍客人)在第1-2周和方向1交替拍,一条拍师傅、一条拍客人,形成"手艺 + 场景"的组合。方向3(教点单)在第2-3周拍,等账号有一定播放量后再做(先让观众看到真实场景,再教怎么吃)。方向4(地域差异)在第2-3周穿插,用来扩大流量。方向5(师傅故事)在第3-4周做,等账号有粉丝基础后再深化人设

## ⚠️ 这次先别做的

- **别拍"秋天上新菜品"这种纯广告式内容**:直接说"我们上新了X道菜,快来吃",观众会当硬广划走。要拍就拍**师傅为什么要做这道菜、怎么做的**,用过程建立信任,而不是直接推销
- **别学网红店只拍氛围不讲手艺**:炭火、烟雾、灯串拍得再美,观众看完还是不知道"你和隔壁店有什么区别"。这个账号的核心优势是"9年川菜师傅 + 正宗川味",要把手艺拍出来,不能只拍环境
- **别让老板当主角**:老板是本地人、有人脉,但**川味的专业背书在师傅身上**。客人要看的是"这个四川师傅做得正不正宗",不是"老板人好不好"。老板可以出镜,但要作为配角(比如和师傅对话、帮忙上菜),不能抢师傅的戏
