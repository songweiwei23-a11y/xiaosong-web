# 实体获客编导-不一 · 创作方向

## 📌 这个方向的思路

用户的目的是**引流到店 + 卖团购/促销**，拆开来是三件事：1）让南乐县本地老板看到并记住你；2）让他们相信你能帮到他；3）让他们主动加你微信或私信咨询。

这个账号最大的优势是**濮阳本土化+老客户愿意出镜+讲故事/晒过程已验证有效**；最大短板是**一人全包+只能挤空档拍**，不能搞需要大量前期筹备或复杂执行的内容。

这一批方向的分工：**用秋天这个时间节点做切口**，流量型拍县城秋季真实场景（街景、老板状态、季节性生意变化），变现型拍你正在帮客户做的秋季营销案例，人设型讲你和南乐老板在秋天的真实互动故事。全部围绕"秋天到了，门店该怎么办"这个县城老板当下最关心的事展开。

## （小黄）：每个方向的拍法主要从这里挑

#### 清单（计名【最适合的目的】：结构公式）

- **反向操作**【流量型】：常规A → 反向B → 真实反应/结果（适合：服务、教学、美食、摄影）
- **扮猪吃虎**【变现型】：低预期 → 质疑/冲突 → 实力展示 → 爽感回收（适合：技能、体育、职场、艺术）
- **以物换物**【人设型】：提出交换 → 协商 → 体验 → 挖掘人物 → 情感结果（适合：实体商品、探店、手工、地方文化）
- **借物喻人**【人设型】：物的事件 → 双关对应 → 情绪推进 → 人生落点（适合：情感、哲理、数码、生活）
- **跨界硬组合**【流量型】：主信息A + 视觉/听觉B → 双倍信息密度（适合：窄赛道、知识、故事、才艺）
- **软组合：用A方式做B事**【流量型】：方式A × 任务B → 新行为（适合：服务、餐饮、宠物、门店）
- **一句话设定故事感**【人设型】：普通动作 + 目标/困境/关系设定 → 故事期待（适合：穿搭、做饭、设计、唱歌、Vlog）
- **情境还原**【变现型】：真实任务 → 对话/纠错 → 旁观学习 → 结果（适合：专业服务、教学、亲子、带货）
- **正确做法VS错误做法**【变现型】：错误示范 → 后果 → 正确示范 → 原理/适用条件（适合：健身、育儿、英语、沟通）
- **互联网嘴替/替网友做**【变现型】：征集问题 → 选择任务 → 亲测过程 → 结果与建议（适合：实验、测评、美食、穿搭、减脂）
- **对比改造**【变现型】：改造前 → 目标/预算 → 关键步骤 → 改造后 → 复盘（适合：装修、美妆、理发、汽修、健身）
- **行业避坑**【变现型】：点名坑 → 后果 → 识别信号 → 替代方案（适合：所有有决策成本的行业）
- **推荐建议**【变现型】：圈人/利益 → 清单 → 每项理由 → 适用与不适用（适合：工具、账号、书影、产品）
- **怀旧复古**【流量型】：年代入口 → 细节复原 → 当时体验 → 今昔连接（适合：音乐、美食、服装、探店、地方文化）
- **吐槽奇葩现象**【流量型】：具体现象 → 受害场景 → 为什么荒谬 → 建议/提问（适合：服装、教育、职场、地域生活）
- **南北/地域差异**【流量型】：同一任务两地做 → 差异反应 → 原因/文化 → 交流（适合：美食、市场、婚俗、生活服务）
- **街头采访**【流量型】：一句好问题 → 追问 → 人物故事/观点 → 行业连接（适合：租房、情感、数码、美食、穿搭）
- **冷知识**【流量型】：反常识结论 → 证据/例子 → 原理 → 应用（适合：历史、珠宝、法律、生活、行业知识）

## 四大脚本（薛老师）：辅助，管话怎么讲
- **教知识**（涨粉）：课程里叫"抖音变现的碗"——粉丝最精准，是账号的地基
- **聊观点**（吸"真"粉丝）：靠观点和情绪价值建人物 IP，粉丝认的是人，不是内容
- **晒过程**（促变现）：把一件事从头到尾记录下来，用真实过程换信任，离变现最近
- **讲故事**（成交高客单）：靠困境、转机和情绪递进建立高信任，适合客单价高的生意

## 🧭 内容方向（勾选想做的方向，带去选题或脚本接着做）

### 方向1：秋天街上的"三种生意"——南乐门店秋季真实观察
- **对应目的**：引流到店、卖团购/促销（流量型为主，带变现引导）
- **内容类型**：**街头采访**
- **讲法**：晒过程——用你的编导视角走街拍摄，记录秋天南乐街上不同门店的真实状态，穿插老板的一句话回应
- **内容方向**：秋天这个季节，南乐县街上哪些生意开始好做、哪些进入淡季、哪些不受季节影响。拍3-5家不同类型的门店（餐饮、服装、美容等），每家拍10-15秒真实场景+老板一句话。最后落到"不管哪种生意,秋天都得换打法"
- **为什么能达到目的**：县城老板最关心的就是"别人家生意怎么样"，这条内容直接击中他们的当下处境。看完会产生"我也得找人帮我调整"的念头,评论区会主动问你怎么做
- **核心思路**：不讲大道理，用真实街景+老板真话建立"我懂县城生意"的专业可信度
- **可拍的选题示例**：
  - 秋天的南乐，这三种老板状态完全不一样
  - 走了一圈南乐街，发现秋天生意分三类
  - 秋天到了，南乐哪些店开始忙、哪些店开始愁
- **怎么拍**：你手机拍，白天街景自然光即可。手持稳定器边走边拍，找3-5家你认识的老板（餐饮、服装、美容、汽修等不同类型）,每家拍门店外景5秒+问老板一个问题"秋天生意跟夏天比怎么样"，录真实回答10秒。最后你自己对镜头口播总结15秒
- **开头示范**：秋天的南乐街上，我发现生意开始分三种了
- **看什么数据**：完播率（能不能看完）、评论区有没有本地老板问"我是XX店的,也想调整"
- **难度**：低——只需要一部手机+半天时间走街拍摄，不需要复杂设备和布景
- **节奏**：第1周

### 方向2：帮一个老板做"秋季视频"的全过程记录
- **对应目的**：引流到店、卖团购/促销（变现型）
- **内容类型**：**情境还原**
- **讲法**：晒过程——从接到需求到拍摄执行到发布,完整记录你帮一个南乐老板做秋季短视频的真实工作流程
- **内容方向**：选一个你正在服务的客户（餐饮、美容、服装等）,记录你帮他策划秋季内容、拍摄、剪辑、发布的全过程。重点拍：老板的真实需求、你的方案思路、拍摄现场、视频上线后老板的反馈
- **为什么能达到目的**：潜在客户最想知道的是"你到底怎么干活的""能不能真帮到我"。这条内容直接展示你的工作能力和客户真实反馈,比任何宣传都有说服力。看完会产生"我也想试试"的冲动
- **核心思路**：用真实工作过程证明专业能力,用客户真实反馈建立信任,最后自然引导"我也能帮你"
- **可拍的选题示例**：
  - 帮南乐一个火锅店老板拍秋季视频，从策划到上线全记录
  - 一个美容店老板找我：秋天客人少了，怎么办
  - 用3天时间，帮南乐一个服装店老板做了秋季引流
- **怎么拍**：你手机拍，分4个场景：1）和老板沟通需求（拍对话）；2）你在门店拍摄现场（拍你工作状态+门店场景）；3）剪辑画面（手机屏幕录屏）；4）老板看到成品的反应（拍老板真实表情+一句话评价）。全程Vlog形式，你可以对镜头解说每个环节在做什么
- **开头示范**：这个老板找到我说,秋天来了客人明显少了,能不能帮他拍条视频试试
- **看什么数据**：播放量、评论区有没有人问"我也想找你做""怎么收费"、主页访问量
- **难度**：中——需要客户配合拍摄，时间跨度3-5天，需要剪辑多段素材
- **节奏**：第2-3周

### 方向3：县城老板"秋天焦虑"真心话采访
- **对应目的**：引流到店、卖团购/促销（流量型为主，带人设建立）
- **内容类型**：**街头采访**
- **讲法**：讲故事+晒过程——采访3-5个南乐老板，问他们"秋天到了最担心什么"，记录真实回答和情绪,最后你给出观点"其实他们担心的都是同一件事"
- **内容方向**：聚焦县城老板在秋季的真实处境和心理状态。选不同行业的老板（餐饮、美容、服装、汽修等）,问同一个问题"秋天到了,你最担心什么"。剪辑成合集，展现不同老板的真实回答，最后你总结共性+给出你的判断
- **为什么能达到目的**：县城老板看到"别人也在担心同样的事"会产生强烈共鸣,觉得你懂他们的处境。评论区会引发大量互动"我也是""说到心里了",自然建立信任,为后续咨询铺路
- **核心思路**：用老板真话建立情感共鸣,用你的总结建立专业判断,让观众觉得"这个人既懂县城生意,又真的关心我们"
- **可拍的选题示例**：
  - 问了5个南乐老板：秋天到了你最担心什么
  - 县城老板的秋天焦虑，其实都是这一件事
  - 秋天的南乐街上，老板们都在担心同一个问题
- **怎么拍**：你手机拍，白天街景或店内自然光。找3-5个你认识的老板（提前打招呼说要采访）,每人问同一个问题"秋天到了,你最担心什么",录真实回答15-20秒。拍完剪成合集，每个老板的回答10-15秒，最后你对镜头口播总结20秒
- **开头示范**：我在南乐街上问了几个老板，秋天到了最担心什么，发现他们说的居然都是同一件事
- **看什么数据**：评论区互动量、有没有本地老板留言"说出我心声了""我也是这样"、点赞数
- **难度**：低——只需要手机+半天时间采访，剪辑难度低
- **节奏**：第1-2周

### 方向4：南乐秋天的"冷清店"vs"热闹店"对比观察
- **对应目的**：引流到店、卖团购/促销（流量型+变现型混合）
- **内容类型**：**对比改造**（改造部分弱化，重点在对比观察）
- **讲法**：晒过程+教知识——拍两家同类型门店（比如都是餐饮或都是美容）,一家秋天生意好,一家秋天生意冷清。对比两家在秋季营销、门店呈现、服务细节上的差异,最后你给出判断"差距在哪"
- **内容方向**：选南乐县两家同类型但秋季状态完全不同的门店,拍摄它们在秋天的真实状态：门店客流、老板动作、营销方式。对比剪辑，让观众看到"为什么同样的季节、同样的生意,结果完全不一样"
- **为什么能达到目的**：对比内容天然有冲突感和传播性，县城老板看到会对号入座"我是哪一种"。评论区会引发讨论,自然产生"我也想变成生意好的那种"的需求,为后续咨询做铺垫
- **核心思路**：用真实对比建立反差,用你的专业判断指出关键差距,让观众觉得"找你能解决问题"
- **可拍的选题示例**：
  - 南乐两家火锅店，秋天一个满座一个空荡，差在哪
  - 同样是美容店，秋天一个忙不过来一个愁客源
  - 县城两家服装店的秋天：一个打折促销，一个自然满客
- **怎么拍**：你手机拍，白天自然光。分别去两家店，拍门店外景（客流状态）10秒、门店内景（装修、产品陈列）10秒、老板状态或工作场景10秒。采访每个老板"秋天生意怎么样""你做了什么"，录真实回答15秒。最后你对镜头口播总结"差距在哪"20秒
- **开头示范**：南乐这两家火锅店，秋天一个天天满座，一个冷冷清清，我去看了看发现差距在这
- **看什么数据**：完播率、评论区有没有人问"我是冷清那种，怎么办""能不能帮我分析一下"
- **难度**：中——需要两家店老板配合拍摄，需要跑两个地点，剪辑需要对比逻辑
- **节奏**：第2-3周

### 方向5：我和南乐老板的"秋天对话"——县城编导工作日常
- **对应目的**：引流到店、卖团购/促销（人设型为主）
- **内容类型**：**一句话设定故事感**
- **讲法**：讲故事——记录你和一个南乐老板在秋天的真实互动：他找你诉苦、你给建议、他的反应、后续变化。用故事形式展现你和县城老板的真实关系
- **内容方向**：选一个你正在服务或刚接触的客户,记录你们在秋季的真实互动。重点拍：老板找你时的状态（焦虑、迷茫、求助）、你们的对话内容、你给出的建议、老板的反应和后续行动。用Vlog形式讲述这个过程
- **为什么能达到目的**：人设型内容建立深度信任，县城是熟人社会，老板们想知道"你这个人怎么样""靠不靠谱""会不会真心帮我"。这条内容展现你和客户的真实关系、你的待人方式、你的专业判断，让潜在客户觉得"这个人可以信"
- **核心思路**：用真实互动故事建立人格魅力，用你的态度和做法证明"重感情、讲人情世故"这个核心卖点
- **可拍的选题示例**：
  - 一个南乐老板深夜给我发消息：秋天生意不行了，怎么办
  - 帮一个县城老板做秋季视频，他一开始不信能有用
  - 秋天的南乐，我和一个火锅店老板的三次见面
- **怎么拍**：你手机拍，分3-4个场景：1）你接到老板消息或见面场景（拍你看手机屏幕或两人对话）；2）你们沟通过程（拍对话场景，可以老板出镜也可以只拍你）；3）你工作过程（拍你在策划、拍摄）；4）老板后续反馈（拍老板真实反应或微信截图）。全程你对镜头讲述这个故事，穿插实拍画面
- **开头示范**：上周一个南乐老板给我打电话，说秋天来了客人少了一半，问我能不能帮他想想办法
- **看什么数据**：主页访问量、评论区有没有人说"你这个人不错""感觉靠谱"、私信咨询量
- **难度**：中——需要客户配合拍摄，需要记录多个时间节点，剪辑需要故事线索
- **节奏**：第3-4周

  4. **发挥你的本地化优势**——你对南乐县熟悉，认识各行业老板，拍这个内容有天然资源优势

- **第一周怎么开始**：
  1. **列出3-5家你认识的不同类型门店**（餐饮、美容、服装、汽修等），提前微信或电话打招呼说要拍县城秋天生意状态，问一句话"秋天生意跟夏天比怎么样"

## ⚠️ 这次先别做的
