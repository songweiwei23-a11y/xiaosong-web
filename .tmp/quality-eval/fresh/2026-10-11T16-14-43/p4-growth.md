**套到你这个号**（具体到能开机）：

### 配什么脚本讲

**具体怎么叠**：

#### 第1条（主攻）

**标题**：成都的回锅肉 VS 河南的回锅肉，差在哪？**（地域差异 + 反差）**

**拍摄要点**：
- **场景**：师傅在操作台前，背景是地摊现场（晚上灯光、串串、锅），下午备菜时段拍（自然光 + 店里灯光）
- **道具/食材**：五花肉、青椒、郫县豆瓣、蒜苗、豆豉，操作台上摆好
- **镜头安排**：
  1. 开场（3秒）：师傅正面中景，面前摆着五花肉和青椒，开口第一句："我在成都做了9年川菜，来南乐半年，发现这边的回锅肉和成都的不一样"
  2. 讲差异（10-30秒）：师傅边煮肉边讲（"成都的回锅肉，五花肉要先煮再切再炒……"），镜头切到锅里（煮肉的画面）→ 切肉的手部特写（灯盏片）→ 下锅炒的画面（肉片微卷）
  3. 讲原因（30-50秒）：师傅继续讲（"为什么要先煮再切？因为……"），镜头对着师傅 + 穿插锅里的画面（红油、肉片卷边、青椒下锅）
  4. 成品（50-55秒）：一盘红亮的回锅肉，特写（肉片微卷、青椒翠绿、有锅气）
  5. 结尾（55-60秒）：师傅最后一句："你吃过的回锅肉，是哪种？评论区说说"
- **字幕/文案**：开头打字幕"成都做法 VS 河南做法"，中段标注关键差异（"先煮再切 VS 直接切生肉""肉片微卷 VS 肉片平的"）
- **时长**：60秒左右（1分钟内，完播率好做）
- **为什么第1条选回锅肉**：回锅肉是川菜里最大众的一道（全国人民都吃过），选题覆盖面广；而且回锅肉的两地差异明显（煮 vs 不煮、肉片卷 vs 平），视觉上好展示

- **场景**：师傅站在一锅串串前（冷锅串串，锅底是凉的、串串穿好了放进去烫），地摊现场
- **道具/食材**：一锅串串（锅底、串串）、旁边摆一盘火锅菜品（对比用）
- **镜头安排**：
  1. 开场（3秒）：师傅站在串串锅前，开口第一句:"很多人以为串串就是火锅，其实不是一回事——我在成都做了9年，串串和火锅完全不同"
  2. 讲差异（10-40秒）：师傅指着串串锅讲（"串串是冷锅串串，锅底是凉的，串串拿签子穿好了放进去烫；火锅是热锅，菜都是论盘装的，自己涮"），镜头切到串串特写（签子、锅底）→ 火锅菜品特写（盘装）→ 对比画面
  3. 讲原因（40-55秒）：师傅继续讲（"成都人吃串串论签算钱，吃火锅论盘算钱，两回事"），镜头对着师傅 + 穿插串串和火锅的画面对比
  4. 结尾（55-60秒）：师傅最后一句："下次来我店里，你就知道怎么点了。评论区说说，你们那边叫串串还是叫火锅？"
- **字幕/文案**：开头打字幕"串串 ≠ 火锅"，中段标注关键差异（"冷锅 VS 热锅""论签 VS 论盘"）
- **时长**：60秒左右
- **为什么第2条选这个**：串串和火锅的差异是冷知识（很多人真不知道），覆盖面广；而且和你店里的"一元火锅"自然连接——评论区会有人问"你们店是串串还是火锅"，顺势引导到"我们两个都有，来试试"

#### 第3条（流量型）

**标题**：成都人吃火锅为什么不蘸麻酱？河南人为什么爱蘸？**（地域差异 + 冷知识）**

**拍摄要点**：
- **场景**：师傅在店里，面前摆着小料台（郫县豆瓣、香油、蒜泥、香菜、麻酱等）
- **道具/食材**：小料台上的各种小料，重点是麻酱（河南常见）和香油碟（成都常见）
- **镜头安排**：
  1. 开场（3秒）：师傅站在小料台前，开口第一句："很多河南人吃火锅爱蘸麻酱，但成都人从来不蘸——为什么？"
  2. 讲差异（10-40秒）：师傅边指小料边讲（"成都人吃火锅，小料就是香油 + 蒜泥 + 香菜，最多加点蚝油，从来不蘸麻酱；河南人、北方人吃火锅，麻酱是标配"），镜头切到香油碟特写 → 麻酱碗特写 → 对比画面
  3. 讲原因（40-55秒）：师傅继续讲（"为什么成都人不蘸麻酱？因为川味火锅的锅底本身就够香、够麻，麻酱会盖住锅底的味道。香油碟是用来降温、提鲜的，不是用来增味的"），镜头对着师傅 + 穿插小料的画面
  4. 结尾（55-60秒）：师傅最后一句："下次来我店里，我教你怎么调小料。评论区说说，你吃火锅蘸什么？"
- **字幕/文案**：开头打字幕"成都小料 VS 河南小料"，中段标注关键差异（"香油碟 VS 麻酱""降温提鲜 VS 增味"）
- **时长**：60秒左右
- **为什么第3条选这个**：小料是火锅的细节，很多人没注意过两地差异，这是冷知识；而且和你店里的"一元火锅"自然连接——评论区会有人问"你们店小料怎么配"，顺势引导到"来店里我教你"

### 边界（这一计什么不能碰）

从第31计·地域差异的原边界里挑对你适用的：

1. **不要编造差异、夸大对立** → 你讲的两地做法必须是师傅真实经历过的（他在成都学了9年、现在在南乐，两地确实不一样），不能为了流量编造"成都人从来不这么做""河南人都做错了"这种绝对化的话。差异要客观、具体（"成都的做法是先煮再切，这边很多店是直接切生肉下锅"），不要上升到地域攻击（"河南人不懂川菜""成都才是正宗"）
2. **不要只讲差异、不讲原因** → 地域差异的核心价值是"长见识"——不只是说"两地不一样"，还要讲"为什么不一样、哪种更合理"。只讲差异，观众看完觉得"哦，不一样"就划走了；讲清原理，观众觉得"学到了"，评论和分享才会来
3. **不要贬低本地做法、只夸成都做法** → 你的目标人群是南乐本地人，贬低本地做法（"河南人做的回锅肉不正宗""这边的火锅不行"）会引起反感。正确做法是**客观对比 + 尊重差异 + 强调自己坚持成都做法的原因**——"两地做法不一样，我是成都学的手艺，所以我们店坚持成都做法，想吃正宗川味的来试试"。这样既立住了"正宗"，又不得罪本地人
4. **不要只拍口播、不拍过程** → 地域差异的说服力来自"看到师傅怎么做的"——只有师傅对着镜头讲"成都的做法是这样、河南的做法是那样"，观众看不出区别、觉得像假的。必须**边做边讲**，把关键步骤（煮肉、切片、下锅、肉片卷边）拍清楚，观众才信
5. **不要每条都讲一样的差异** → 地域差异的选题库很大（回锅肉、鱼香肉丝、串串、火锅、小料、食材……），每条换一个角度，不要第1条讲回锅肉、第2条还是回锅肉。重复选题会让观众觉得"又是这个，没意思"，完播率和关注率都会掉

## 🔄 备选打法（2计）

### 备选1：第36计·冷知识【流量型】

**什么情况下切过去**：
- **地域差异拍了10条、评论区开始有人说"又是成都 VS 河南，能不能换点别的"** → 说明这个角度的新鲜感在降低，切到冷知识（川菜知识体系里的宝藏：郫县豆瓣为什么不能换、回锅肉为什么叫回锅肉、鱼香肉丝为什么没有鱼……），同样覆盖陌生人、长见识，但不再强调地域对比
- **你发现地域差异的完播率开始低于你自己前几条的平均水平** → 说明观众对"两地不一样"这个框架疲了，切到冷知识换个讲法

**一句话说明怎么套到你这个号**：师傅讲一个川菜、串串、火锅里大众不知道的冷知识（为什么川菜必须用郫县豆瓣、为什么回锅肉要先煮再切、串串和火锅为什么不是一回事），用"反常识结论 → 证据/原理 → 应用"的结构，结尾引导评论（"你家用的是哪种豆瓣酱？评论区说说"）

**配哪个四大脚本结构讲**：冷知识本身是完整的知识传达结构，不需要另套四大脚本。但可以叠加**教知识·反常识开篇**的开头技巧（"你以为……其实……"），让第一句话更抓人

**示范标题**（1条）：为什么川菜必须用郫县豆瓣，别的豆瓣酱不行？**（冷知识）**

### 备选2：第19计·对比改造（简化版，拍"做法改造"）【变现型】

**什么情况下切过去**：
- **流量型内容（地域差异、冷知识）拍了15-20条、曝光和完播率都还行，但评论区问地址的人不多、团购下单的人也少** → 说明流量起来了、但变现链路没接住，切到对比改造（晒师傅炒底料、穿串串、做川菜的完整过程），直接落在"专业强、质量好"的成交理由上，推动到店
- **你发现主页访问量在涨、但咨询和到店的人不多** → 说明观众知道你这个号了、但还不够信任"手艺是真的好"，切到对比改造，用过程建立信任

**一句话说明怎么套到你这个号**：师傅现场演示一个"很多人在家做川菜不香、少了哪一步"或者"我们店怎么炒底料、穿串串"的完整过程（改造前：常见错误做法 → 改造后:正宗做法 → 关键步骤演示 → 成品展示），结尾引导到店/团购（"想吃现成的，主页有地址"）

**配哪个四大脚本结构讲**：对比改造配**教知识·解题型**结构（场景难题 → 放大危机 → 低成本解决 → 操作步骤12345），补上成交理由——不只是演示怎么做，还要讲"为什么这么做才是正宗的、你在家也能用"

**示范标题**（1条）：为什么你炒的川菜不香？少了这一步**（对比改造 + 反认知）**

## 🧪 怎么测

### 一次只改哪个变量

起号期测试的核心原则是**一次只改一个变量**，否则你不知道是哪个因素起作用、哪个没用。

**第1-10条（主攻地域差异）**：
- **固定不变的**：都用第31计·地域差异，都是师傅边做菜边讲两地差异，都在店里操作台前拍，都是60秒左右，都是评论结尾
- **可以变的（单变量测试）**：
  - 第1-3条：测**选题角度**（回锅肉 vs 串串火锅 vs 小料），看哪个角度评论区更热闹、问地址的人更多
  - 第4-6条：测**开头方式**（原版"我在成都做了9年，来南乐半年，发现……" vs 升级版"你以为……其实成都的做法不是这样"），看哪种开头前3秒留存更高
  - 第7-10条：测**结尾行动指令**（"评论区说说你那边是哪种" vs "想吃正宗的主页有地址"），看哪种结尾评论多、哪种主页访问多

**第11-20条（补变现型）**：
- 地域差异继续拍（流量型，每周2条），但补1-2条对比改造（变现型，晒师傅炒底料、穿串串的完整过程），测**流量型和变现型的配比**——看加了变现型内容后，咨询和到店的人是不是变多了

### 每计测几条、看什么指标

| 打法 | 测几条 | 看什么指标（优先级从高到低） | 判断标准 |
|---|---|---|---|
| **第31计·地域差异**【流量型】 | 至少10条（第1-10条全用它） | ① 非关注用户播放占比（≥60% = 在拿新流量）<br>② 完播率（≥30% = 内容抓人）<br>③ 评论区热度（每条≥X条评论、且有人讨论"我们那边也这样/不这样"）<br>④ 分享（地域差异天然适合转述，分享多 = 覆盖广） | 10条里至少有5条非关注用户播放占比≥60%、完播率≥30%、评论区有X条以上讨论 = 这计行 |
| **第36计·冷知识**【流量型】 | 至少3条（第11-13条测试） | 同上（非关注用户播放、完播率、评论、分享） | 3条里至少有2条数据和地域差异持平或更好 = 这计行，可以替换掉一部分地域差异 |
| **第19计·对比改造**【变现型】 | 至少5条（第11-15条里补1-2条，第16-20条里补2-3条） | ① 评论区问地址/私信咨询的人数（每条≥X人）<br>② 主页访问量（和你自己前10条的平均值比）<br>③ 团购链接点击/下单（有就是好信号）<br>④ 完播率（晒过程的完播率通常比纯口播高） | 5条里至少有3条评论区有人问地址、主页访问量比前10条平均值高 = 这计行，继续加大变现型比重 |

### 什么信号算"这计行"，什么信号算"换掉"

#### 信号1：这计行（继续拍）

- **地域差异**：10条里至少有5条非关注用户播放占比≥60%、完播率≥30%、评论区有X条以上讨论"我们那边也这样/不这样"，且至少有1条评论区有人问"你们在哪"或者"想去试试" → **这计行，继续拍**。第11-20条里，地域差异仍然是主力（每周2条），但补其他类型
- **冷知识**：3条里至少有2条数据和地域差异持平或更好（非关注用户播放、完播率、评论）→ **这计行，可以替换掉一部分地域差异**。第11-20条里，冷知识每周1条，和地域差异轮着拍
- **对比改造**：5条里至少有3条评论区有人问地址、主页访问量比前10条平均值高 → **这计行，加大变现型比重**。第21-30条里，对比改造每周1-2条，推动到店和团购

#### 信号2：这计有问题（调整或换掉）

- **地域差异**：10条里超过一半（≥6条）非关注用户播放占比<50%、或完播率<20%、或评论区几乎没有讨论 → **不是计的问题，是执行的问题**。先查：
  - 开头是不是没钩子（第一句话太平、没有反差或冲突）→ 换成升级版开头（"你以为……其实成都的做法不是这样"）
  - 中段是不是只讲差异、不讲原因 → 补上"为什么要这么做"的原理部分
  - 画面是不是只拍师傅讲、没拍过程 → 必须边做边讲，把关键步骤（煮肉、切片、肉片卷边）拍清楚
  - 如果调整后再测3条、数据还是不行 → **换备选1·冷知识**
- **冷知识**：3条里有2条以上数据明显低于地域差异（非关注用户播放<40%、完播率<20%）→ **这计不适合你这个号**（可能是师傅讲冷知识的方式太枯燥、或者选题太窄），换回地域差异
- **对比改造**：5条里超过3条评论区没人问地址、主页访问量也没涨 → **不是计的问题，是选题或结尾的问题**。先查：
  - 选题是不是太泛（"教你做川菜"太宽，改成"为什么你炒的川菜不香、少了这一步"，落在具体难题上）
  - 结尾行动指令是不是不清晰（"想吃的来试试"太虚，改成"想吃正宗的，主页有团购链接，更划算"，明确去哪、怎么做）
  - 如果调整后再测2条、还是没人咨询 → 重审你的变现路径（是不是价格、位置、团购设置有问题），不是计的问题

## 📅 30天节奏

按你的真实产能排（2-3人小团队、手机拍摄、专业剪辑），**一周拍4次、每次拍1条，一周发4条**（周一、周三、周五、周日各发1条，每条间隔1-2天，给算法推流留时间）。

| 周期 | 任务 | 交付物 | 为什么这么安排 |
|---|---|---|---|
| **第1-3天<br>（定位与准备）** | ① 完成定位表（已定好的，你直接用）<br>② 竞品观察：搜"川菜""串串火锅""地摊美食"，收集至少20个同行同城账号，看他们的高赞视频TOP3、评论区在问什么<br>③ 建素材库：把竞品高赞视频的选题、开篇、金句记录下来（不是抄，是学结构） | ① 1页定位表（已有）<br>② 20个对标样本（截图 + 链接 + 分析记录）<br>③ 素材库表格（选题≥30条、开篇≥20条） | 磨刀不误砍柴工。前3天不拍，先把定位理清楚、把同行研究透，后面拍起来才不慌。竞品观察的重点是"他们拍了什么、为什么火、评论区在问什么"——这些都是你的选题来源 |

## 📊 跑不通先查哪里

挑最可能出现的3种情况（按你这个号的实际情况）：

### 情况1：有曝光但前段流失（前3秒、前5秒留存低）

**现象**：视频有曝光（几百、上千播放），但前3秒留存<40%、前5秒留存<30%，完播率<20%

**优先怀疑**：
1. **首帧不够抓人** → 师傅的表情、动作、背景太平淡，第一眼看不出"这是干什么的、为什么要看"
2. **第一句话没钩子** → 开口就是"大家好我是XX""今天教你做XX"，没有反差、冲突、反常识，陌生人不知道"这和我有什么关系"
3. **承诺不清晰** → 前5秒观众不知道"后面会讲什么、为什么要等"

**下一次实验**（单变量调整）：
- **调整首帧**：第一帧不要是师傅站着不动，改成**动作定格**（师傅炒菜的手部特写、锅里红油翻滚、肉片微卷的瞬间）+ 字幕（"成都做法 VS 河南做法"），第一眼就让人知道"这是在做菜、而且有对比"
- **重写开头3句话**：
  - 原版（没钩子）："大家好，我是成都来的川菜师傅，今天教你做回锅肉"
  - 升级版（有钩子）："你以为回锅肉就是五花肉炒青椒？成都的做法不是这样——我在成都做了9年，来南乐半年，发现这边很多店都做错了"
  - **为什么升级版更好**：第一句话就质疑大众认知（"你以为……其实不是"），制造冲突；第二句点明身份和经历（"成都9年"），建立可信度；第三句给出承诺（"很多店都做错了"），观众会想"错在哪、怎么做才对"，愿意往下看
- **前5秒给出明确期待**：开头3句话讲完后（前5秒内），加一句"今天就教你正宗成都做法，记住这3步"——让观众知道"后面会讲什么、有具体步骤"

**测几条看效果**：调整后拍3条，看前3秒留存有没有提升到50%以上、前5秒留存有没有提升到40%以上。有 = 这次调整有效；没有 = 继续查下一个问题

### 情况2：点赞高收藏低、播放高关注低（流量有了但转化弱）

**现象**：视频播放量还行（几千、上万），点赞也不少，但收藏很少、关注也少，评论区没人问地址、主页访问量不高

**优先怀疑**：
1. **情绪强但实用性弱** → 地域差异、冷知识讲得有意思（评论区热闹、点赞多），但观众看完觉得"哦，长见识了"就划走了，没有"我想去试试""我想学这个"的冲动
2. **人设弱、没有系列承诺** → 每条视频单独看都不错，但观众不知道"这个师傅是谁、后面还会讲什么、为什么要关注"
3. **变现链路不清晰** → 结尾只说"想吃的来试试"，观众不知道"去哪、怎么去、团购在哪"

**下一次实验**（单变量调整）：
- **加实用性、可执行的总结** → 地域差异、冷知识讲完后，加一段"你在家也能用"的应用（比如讲完"为什么回锅肉要先煮再切"后，加一句"记住这3步：煮肉8分钟、切灯盏片、大火快炒，你在家也能做出成都味儿"），让观众觉得"这个有用、我可以试试"，收藏就会多
- **固定栏目 + 强化身份标签** → 从第18条开始，每周1条"师傅教你做川菜"系列（变现型），片头加固定字幕（"师傅教你做川菜 · 第X期"），结尾加一句"关注我，每周教你一道正宗川菜"——让观众知道"这是个系列、后面还有、关注了就能学"，关注就会多
- **理清主页和行动入口** → 检查你的主页：简介里有没有写清楚"成都师傅 · 9年川菜手艺 · 南乐XX路XX号"？置顶作品有没有设置（等有内容后，选最能代表"手艺真、过程实在"的1-3条置顶）？团购链接挂了没有？如果这些都没做好，观众想找你也找不到

**测几条看效果**：调整后拍5条，看收藏、关注、主页访问量有没有提升。有 = 这次调整有效；没有 = 重审你的变现路径（是不是价格、位置、团购设置有问题）

### 情况3：粉丝多咨询少、团购下单少（涨粉了但变现接不住）

**现象**：粉丝已经涨到几百、上千，但评论区问地址的人很少、团购下单的人也少、到店的人更少

**优先怀疑**：
1. **人群不准** → 涨的粉丝不是目标用户（本地想吃川菜的人），而是泛人群（对地域差异、冷知识感兴趣的人、但不在南乐、或者不是你的目标客群）
2. **专业证据不足、信任还不够** → 观众看了流量型内容（地域差异、冷知识），觉得"这个师傅讲得有意思"，但还没看到"师傅的手艺是真的好"——缺变现型内容（晒过程、客户案例）
3. **主页承接差** → 观众想去试试，点进主页一看，没有团购链接、没有地址、没有置顶作品，不知道"怎么去、团购在哪"

**下一次实验**（单变量调整）：
- **重审用户和变现定位** → 检查你前X条视频的选题：是不是太偏地域文化（"成都人 vs 河南人"）、而不够落地（"你来我店里能吃到什么"）？如果是，调整选题方向：地域差异继续拍、但每条结尾必须落到"我们店就是成都做法，想吃正宗的来试试"；同时加大变现型内容比重（从30%提到40%），补"一元火锅怎么吃""50块钱能吃到什么""师傅教你做川菜"这些直接推动到店的选题
- **补案例和过程** → 拍2-3条变现型内容：① 晒师傅炒底料的完整过程（对比改造，"今天炒X斤底料，够卖一周"），让观众看到"手艺是真的、用料是真的"；② 老顾客案例（第8计·加入人物关系，"这个老顾客一周来X次"），用第三方背书建立信任
- **理清主页承接** → 立刻优化你的主页：
  - 简介改成："成都师傅 · 9年川菜手艺 · 川味串串火锅+川味烧烤+川菜 · 南乐XX路XX号 · 团购更划算👇"（60字内，口语化，把身份、卖点、位置、行动指令都写清楚）
  - 背景图换成：地摊现场 + 师傅做菜的画面 + 一元火锅的特写（不放文字墙）
  - 置顶作品设置：选3条（① 地域差异里数据较好的1条，证明师傅懂；② 对比改造里晒过程的1条,证明手艺真；③ 一元火锅怎么吃的1条，推动团购下单）
  - 团购链接挂上：火锅团购已上线的，链接挂在主页、每条变现型内容的结尾也引导"主页有团购链接"

**测几条看效果**：调整后发5条（变现型内容为主），看评论区问地址的人、团购下单的人、到店的人有没有变多。有 = 这次调整有效、变现链路接住了；没有 = 访谈没成交的人（评论区私信问"为什么没来"），找到真实障碍（是价格、是距离、还是其他）
