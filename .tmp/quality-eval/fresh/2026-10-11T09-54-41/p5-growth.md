# 万客隆家具城·李国才 · 起号方案

# 🚀 起号方案

## 📌 先说结论

- **建议主攻**：**第10计·情境还原**，因为你每周都有客户到店挑家具，一人一机拍真实对话（客人可以打码）就行，资源够、真实、离变现近
- **备选**：**第31计·地域差异**（南乐人莘县人买家具差别）拿本地流量、**第22计·行业避坑**（教客人不踩坑）建立专业信任、**第7计·一句话设定故事感**（拍你日常工作配画外音讲从教师到老板的故事）立人设
- **明确不做**：**第16计·整蛊**和**第30计·角色扮演**——你是一人全包，整蛊需要配合演员和多机位，角色扮演需要剧本、演技和后期，资源撑不住；家具是高客单决策品类，客人要的是专业和信任，不是段子和演技
- **多久能看出跑没跑通**：连续发 20 条（4 周），看私信里有没有人发户型图、问"你店在哪""我家 X 平适合哪款"，到店时有没有人说"刷到你视频了"——不是只看播放量。零粉到一千粉、视频流量稳定是参考线，但更重要的是精准咨询量

## 🧮 起号期内容配比

**起号期（到一千粉、流量稳定之前）**：流量型 45% / 人设型 25% / 变现型 30%

**为什么是这个比例**：
- 你现在是"有定位、需要内容方向、0-1万粉"，起号期必须把流量拉起来，所以流量型占最大头（45%）
- 变现型占 30%（比常规建议的 20% 高），因为你是本地实体店、辐射范围方圆 30 公里，要的是精准到店、不是泛粉，从第一周就要有变现型内容，不能等流量起来了再拍
- 人设型占 25%，你有 5 年教师经历、和合伙人（哥哥）的关系、从教师到老板的成长故事，这些能立住"实在、靠谱、会帮你选"的人设

---

**每一种用哪一计来拍**：

### 变现型 30%（用第10计·情境还原 + 第22计·行业避坑）

**主力：第10计·情境还原**（占变现型的 70%）
- **结构公式**：真实任务（客人来挑家具）→ 对话/纠错（你问户型预算、客人说需求）→ 旁观学习（观众看到"原来买家具要先问这几个问题"）→ 结果（客人选到合适的、满意）
- **配什么脚本讲**：**晒过程·火车节**（起因带钩子 → 关键步骤 → 结果）——你帮客人挑家具的完整过程就是最强的信任证据，观众看完会想"我也想让他帮我选"
- **结尾行动指令**（只要一个）："你家多大？发户型图、我帮你看看适合哪款，私信我"

**补充：第22计·行业避坑**（占变现型的 30%）
- **结构公式**：点名坑（"买家具千万别只看价格"）→ 后果（"买回家发现放不下、退货运费比货还贵"）→ 识别信号（"先量尺寸、再看预算、最后选款式"）→ 替代方案
- **配什么脚本讲**：**教知识·解题型**（场景难题 → 放大危机 → 低成本解决 → 操作步骤 12345）——建立专业信任，观众看完会觉得"这个老板懂、不会坑我"
- **结尾行动指令**："买家具前先看这个，不吃亏。你家多大？私信我、我帮你看看"

---

### 流量型 45%（用第31计·地域差异 + 第36计·冷知识）

**主力：第31计·地域差异**（占流量型的 60%）
- **结构公式**：同一任务（买沙发）→ 南乐人 / 莘县人 / 河南人 / 山东人的差异反应（南方人爱布艺浅色、北方人爱皮质深色）→ 原因/文化（气候、习惯）→ 交流（"你是哪边的？评论区说说"）
- **配什么脚本讲**：**教知识·拆解型**（同一任务 → 差异 → 原因 → 应用）——自带本地标签，精准辐射南乐、莘县、濮阳这几个地方的人
- **结尾行动指令**："你是南方还是北方？你家沙发啥颜色？评论区说说"

**补充：第36计·冷知识**（占流量型的 40%）
- **结构公式**：反常识结论（"你以为实木家具最贵？其实这种更贵"）→ 证据/例子（现场拍店里两张床对比）→ 原理（木材稀缺度、工艺复杂度）→ 应用（"下次买家具先看这个"）
- **配什么脚本讲**：**教知识·拆解型**（反常识开篇 → 讲清原理 → 操作示范）——大众听得懂、愿意转述，覆盖全国
- **结尾行动指令**："你们那边也这样吗？评论区说说"

---

### 人设型 25%（用第7计·一句话设定故事感 + 第8计·加入人物关系）

**主力：第7计·一句话设定故事感**（占人设型的 60%）
- **结构公式**：普通动作（你在店里整理家具、摆沙发、擦桌子）+ 目标/困境/关系设定（画外音"5 年前我还在讲台上、以为一辈子当老师，没想到现在每天在这 6000 平里帮客人挑家具"）→ 故事期待（观众想知道：为什么辞职？怎么开始做家具的？）
- **配什么脚本讲**：**讲故事·小有成就型**（结果钩子 → 阻碍1 → 转机1 → 阻碍2 → 转机2 → 感悟）——你从教师到老板的成长故事，立住"实在、靠谱"的人设
- **结尾行动指令**："后面继续讲我怎么从新手到现在的，关注我别走丢"

**补充：第8计·加入人物关系**（占人设型的 40%）
- **结构公式**：主任务（你在帮客人挑沙发）+ 关系角色出镜（合伙人/哥哥走过来说"这款不行、那家的预算不够，换这款"）+ 互动结果（你俩现场讨论、最后给客人换了个方案、客人满意）
- **配什么脚本讲**：**讲故事·小有成就型**（你和合伙人的关系细节）——观众看到：这俩人关系真实、哥哥经验丰富、弟弟会听建议
- **结尾行动指令**："关注我，后面继续讲"

**过线之后**（一千粉、流量稳定）：
- 把变现型往上调到 40%、流量型降到 35%，人设型保持 25%
- 补内容系列：把"帮客户配全屋"做成固定栏目（每周拍 2-3 个真实客户的挑选过程），强化"我能帮你选"这个核心价值

- 主系列是"帮客户配全屋"（变现型·晒过程）——第10计·情境还原拍的就是这个系列的每一集

## 🎯 主攻打法：第10计·情境还原

### 为什么是你能拍的

- **团队一人全包**：这一计只需要拍你和客人的真实对话，客人可以打码或拍背影，不需要演员、不需要多机位，你一个人、一部手机就能拍
- **有真实素材**：你每周都有客户到店挑家具（尤其是周末），这个过程本身就是最好的内容——拍下来就是"情境还原"
- **有 5 年教师经验**：你会讲解、能把"怎么选家具"这件事说清楚，教师思维用在服务客人上，客人会觉得"你和别的老板不一样"
- **离变现近**：观众看完你帮客人现场挑选的过程，会想"我也想让他帮我看看"，直接推动私信咨询和到店
- **能拍的场地**：店铺（6000 平、6 大品类），背景能看到家具、有真实场景感，不是白墙或家里

---

### 结构公式（套到你这个号上）

**真实任务** → 客人来店里挑家具（沙发 / 床 / 餐桌 / 全屋配齐）

**对话/纠错** → 你问："你家多大？几室？客厅朝向？有没有小孩？预算多少？"客人说需求，你根据他的回答纠正他的选择（"你家客厅 X 平、这款沙发太大了，放不下"）

**旁观学习** → 观众看到：原来买家具要先问户型、预算、家里几口人，不是上来就看价格；这个老板真的是在帮客人选、不是光想着卖货

**结果** → 客人选到合适的家具、满意（客人自己说"还好来你这、要不自己选得挑一整天"）

---

### 配什么脚本讲

**晒过程·火车节**（起因带钩子 → 关键步骤 → 结果）

**为什么配这个**：
- 这一计管的是"事件怎么走"（客人来 → 你问 → 挑选 → 成交），晒过程·火车节管的是"话怎么讲"（怎么开场、怎么推进、怎么收尾）
- 配了它，补上的是**成交理由**（专业强 + 服务好 + 性价比）——观众看完知道"这个老板会帮我选、不坑人"

**具体骨架**：
- **起因钩子**："今天来了一对小两口、新房 X 平、预算 X 万、老婆要新中式、老公嫌贵，我帮他们配了一套、预算内搞定"
- **关键步骤**：
  1. 我先问：你家多大？几室？客厅朝向？有没有小孩？
  2. 客人拿出手机、给我看户型图
  3. 我拉着他俩在店里走、边走边讲："你家客厅朝南、采光好，可以选深色；卧室小、选浅色显大"
  4. 挑了 3 套方案、让他俩选
  5. 最后敲定一套、现场算价格、在预算内
- **结果**：客人满意、说"还好来你这、要不自己选得挑一整天"

---

### 前 3 条具体拍什么

**第 1 条**：《新房 X 平预算 X 万，老婆要新中式老公嫌贵，我帮他们配了一套》（叠了**奇葩**——老婆要新中式、老公嫌贵，这个冲突就是"奇葩"）

**拍摄要点**：
- 在店里拍，客人可以打码或拍背影（提前征得同意）
- 完整记录"问户型 → 看图 → 现场挑 → 给方案 → 成交"这几个步骤
- 重点拍你问的那几个问题（"你家多大？几室？客厅朝向？"）和你给建议的细节（"你家客厅朝南、采光好，可以选深色"）
- 结尾客人说"还好来你这"，你说"你家装修了吗？发户型图、我帮你看看，私信我"

---

**第 2 条**：《单身女孩买家具，预算 X 万只够配卧室，我帮她省了【换成你帮她省的具体金额或具体做法，比如"我帮她换了这两件"】》（叠了**人群**——单身女孩）

**拍摄要点**：
- 同样拍真实对话，客人打码或拍背影
- 重点拍你怎么帮她调整方案（"这款沙发 X 元、卧室用不着这么贵的，换这款省 X、质量一样"）
- 结尾她说满意，你说"预算紧的朋友，发户型图、我帮你看看怎么配最省钱，私信我"

---

**第 3 条**：《父母帮儿子买婚房家具，两代人审美差太多，我这么调的》（叠了**反差**——两代人审美差）

**拍摄要点**：
- 拍父母和儿子（或儿媳）在店里的真实互动：父母想买深色实木、儿子想买现代轻奢，你在中间调和
- 重点拍你怎么找平衡点（"客厅用你们（父母）喜欢的实木、卧室用小两口喜欢的现代轻奢，两边都满意"）
- 结尾父母和儿子都点头，你说"两代人一起买家具，私信我、我帮你们看看怎么搭配"

---

### 边界

**这一计的边界**（对你适用的）：
- **必须真实**：客人必须是真实到店的，不能找演员摆拍——摆拍一眼假，观众不信
- **客人同意**：提前征得客人同意，拍背影或打码，不能拍正脸（你的硬性禁忌）
- **不能剪辑过度**：保留对话的真实感，不要配音乐、不要加字幕特效——原生感最重要
- **不能只拍结果、不拍过程**：观众要看到你怎么问、怎么挑、怎么给建议，不是只看客人说"满意"
- **不能所有客户都是"预算紧、老婆要贵的"**：每条换一个客户类型（年轻夫妻 / 中年家庭 / 单身 / 父母帮子女买），避免观众觉得"都是一个套路"

## 🧪 怎么测

### 一次只改哪个变量

**第 1-5 条**（测主攻打法·第10计·情境还原）：
- **定量**：都是拍客户到店挑家具的真实对话，结构都是"真实任务 → 对话/纠错 → 旁观学习 → 结果"
- **变量**：每条换客户类型（第1条年轻夫妻、第2条单身女孩、第3条父母帮儿子买、第4条中年夫妻、第5条老客户带朋友来）

**第 6-10 条**（测开篇钩子）：
- **定量**：还是拍第10计·情境还原，客户类型继续换
- **变量**：测试不同的开篇钩子（第6条用盲盒型"今天发生了一件事"、第7条用对抗型"客人张口就说'要便宜的'，我问了 3 个问题他愣住了"、第8条用验证解密型"判断家具好不好，很多人看价格——其实应该看这里"）

**第 11-15 条**（测备选打法·第31计·地域差异）：
- **定量**：都是拍地域差异，结构都是"同一任务 → 差异反应 → 原因/文化 → 交流"
- **变量**：每条换一个任务（第11条买沙发、第12条买床、第13条客厅布置、第14条颜色偏好、第15条尺寸差异）

### 每计测几条、看什么指标

- **主攻打法（第10计）测 10 条**：看私信量（有没有人发户型图、问"你店在哪"）、到店提"刷到视频"的人数、完播率、评论质量（有没有"能不能帮我也看看"这类精准咨询）
- **备选打法（第31计、第22计、第7计）各测 3-5 条**：看非关注用户的播放占比（流量型内容主要看这个）、评论区互动量（评论数、分享数）、主页访问量（人设型内容主要看这个）

---

### 什么信号算"这计行"，什么信号算"换掉"

**这计行**：
- 连续 3 条完播率都比你之前的视频高（说明观众愿意看完）
- 评论区出现精准咨询（"能不能帮我也看看""你店在哪""我家 X 平适合哪款"）
- 私信里有人发户型图、或者到店时说"刷到你视频了"

**换掉**：
- 连续 5 条完播率都低于你之前的视频（说明观众不愿意看完）
- 评论区只有"讲得好""学到了"这种泛互动、没有精准咨询（说明只有流量、没有转化）
- 拍了 10 条、私信里没有人发户型图、到店时没有人提视频（说明内容和变现脱节了）

## 📊 跑不通先查哪里

### 现象 1：曝光少（播放量只有几十、上不了 200）

**优先怀疑**：
- 选题太窄（"父母帮儿子买婚房家具"这类选题只有正在买婚房的人才看，覆盖面太窄）
- 账号标签不清（平台不知道你是做什么的，不知道推给谁）
- 违规或低质（视频里拍到顾客正脸没打码、或者画质太差）

**下一次实验**：
- 换更广的入口：从"父母帮儿子买婚房家具"换成"小户型客厅 X 平，沙发怎么选不压抑"（小户型是大众入口，覆盖面更广）
- 查合规：回看视频，顾客正脸有没有打码？有没有拍到门牌、小区名？
- 连发同主题：连续发 3 条"客户到店挑家具"的视频，帮平台确认"这个号是做家具的"

---

### 现象 2：有曝光但前段流失（播放量 500，但完播率只有 20%，前 5 秒就跑了一半）

**优先怀疑**：
- 首帧弱（画面是空镜、或者你背对镜头，观众不知道要看什么）
- 第一句空泛（"大家好我是 XX"、"今天给大家分享一个"，没有钩子）
- 承诺不清（观众看了 5 秒还不知道"这条视频讲什么、对我有什么用"）

**下一次实验**：
- 重写 5 个开篇钩子，选最强的一个：
  1. 金钱型："这对小两口预算 X 万，我帮他们省了【换成具体金额】"
  2. 盲盒型："今天来了一对客人，老婆要新中式、老公嫌贵，最后我这么帮他们配的"
  3. 对抗型："客人张口就说'要便宜的'，我问了 3 个问题他愣住了"
  4. 验证解密型:"判断沙发质量好不好，很多人看价格——其实应该看这 3 个地方"
  5. 共鸣型："X 平小户型，预算只有 X 万，能配齐全屋吗？今天这对小两口做到了"
- 结果或冲突前置：第一句话直接说"老婆要新中式、老公嫌贵"，不要铺垫"今天来了一对客人"

---

### 现象 3：前段好但完播差（前 5 秒完播率 60%，但整体完播率只有 30%）

**优先怀疑**：
- 节奏慢（中间有重复、有废话，观众等不下去）
- 钩子没接住（开头说"我帮他们省了 X"，但中间一直在讲怎么挑、没说到底省了多少，观众觉得被骗了）
- 信息重复（"你家多大？几室？客厅朝向？"这几个问题在中间又问了一遍）

**下一次实验**：
- 删掉 30% 的内容：把重复的问题、重复的画面全删掉，只保留关键步骤
- 加转折：中间加一个"没想到"的点（"我本来给他们推荐这套、但他们看中了另一套，我现场帮他们调了方案"）
- 提前兑现：开头说"我帮他们省了 X"，中间第 15 秒就要说到底怎么省的、省在哪

---

### 现象 4：点赞高收藏低（点赞 500，但收藏只有 50，评论区没有"能不能帮我也看看"）

**优先怀疑**：
- 情绪强但实用性弱（观众觉得"讲得好"，但不知道"我该怎么办"）
- 只晒结果、不晒过程（观众看到客人满意了，但不知道你是怎么帮他选的）

**下一次实验**：
- 加步骤、清单、可执行的总结："买家具千万别只看价格，记住这 3 步：先量尺寸、再看预算、最后选款式"
- 把"你怎么帮客人选"的过程拍清楚：你问了哪几个问题、你给了哪几套方案、你为什么推荐这套不推荐那套

---

### 现象 5：播放高关注低（播放 5000，但只涨了 10 个粉）

**优先怀疑**：
- 人设弱（观众只看到你在帮客人选家具，但不知道"你是谁、凭什么信你"）
- 没有系列承诺（观众看完一条就走了，不知道"关注你能看到什么"）

**下一次实验**：
- 固定栏目：每条视频开头加一句"这是我帮的第 X 个客户配全屋"，让观众知道"这是个系列、后面还有"
- 强化身份与下集期待：结尾加一句"我当了 5 年教师、现在每天在这 6000 平里帮客人挑家具，关注我、后面继续讲怎么选"

---

### 现象 6：粉丝多咨询少（粉丝 1000 了，但私信里没人发户型图、到店时没人提视频）

**优先怀疑**：
- 专业证据不足（观众只看到你在讲"怎么选"，但没看到"你帮客人选成功了"）
- 产品关联弱（观众记住了你这个人、但不知道"你卖什么、店在哪"）
- 主页承接差（观众点进主页，不知道"怎么联系你、怎么到店"）

**下一次实验**：
- 补案例和过程：多拍几条"客人到店挑家具、最后成交"的完整过程，让观众看到"你真的能帮人选成"
- 理清主页和行动入口：简介里写清"南乐 X 镇 X 路 X 号，私信发户型图、我帮你看看"，置顶一条"店里 6 大品类都有、这是地址"的视频
