# 小张工作号·濮阳本地找工作服务 · 内容定位

# 💎 内容定位方案

## 长期价值主张

让濮阳本地想进厂的人知道：找我，我能接你、跟你、送你到厂，不坑你

## 内容方向：多元四类还是单一主题

**选 A：多元四类**（知识 / 故事 / 晒过程 / 观点四类都发）

**依据**：
1. **这是新号，还没发过视频**——现在不知道哪一类数据最好，先用多元四类从多个角度立住"这个人靠谱、这个服务真实"，等跑通 20-30 条、看出哪类数据最好，再调整配比
2. **你的真实素材源源不断**：每天在接送工人，有大量真实过程（晒过程）；工人的故事和担心（讲故事）；进厂流程和避坑知识（教知识）；对这行的判断和边界（观点）——四类素材都不缺
3. **一个人的执行能力**：你一个人全包，单一主题（比如"体验 100 种职业""接受粉丝挑战"）需要很强的策划和执行能力，现实不够。先把多元四类跑通、建立信任，比追求"单一主题的爆款"更现实

**为什么不选 B（单一主题）**：
- 单一主题需要**每一集都有新的事件和反转**——你虽然每天都在接送，但不是每次都有足够强的戏剧性能撑起一个系列（比如"第 N 个工人的故事"容易拍成流水账）
- 单一主题要求**策划能力和剪辑能力都很强**——你现在一个人、基础剪辑，先把真实记录做好，等能力上来、数据跑通了，再考虑做一个主题型的王牌栏目（比如"濮阳 X 个工人的真实故事"）

**待第二阶段（1000 粉之后）考虑的主题方向**：
如果前 30 条里"车上采访工人"或"老工人带新人上车"这两类数据特别好，可以在多元四类的基础上，加一个**主题型王牌栏目**："濮阳 X 个工人的真实故事"（定量：车上采访 + 工人故事；变量：每期换不同年龄、不同处境的工人）——但现在不做，先把多元四类跑通

## 内容配比

### 作用配比

| 作用 | 占比 | 为什么 |
|---|---|---|
| **流量型** | 45% | **账号阶段决定**：新号，还没发过视频，处于起号期——这个阶段只有一个任务：拿到稳定的流量和正反馈。流量型必须是最大的一块，让本地陌生人第一次刷到你。<br>**这一行的特点决定**：工人决策周期极长（2-4 周），他要反复看到你才会信你，所以流量型内容（让更多人刷到你）很重要——流量型负责"让陌生人第一次刷到你" |
| **人设型** | 25% | **信任门槛决定**：这一行的信任成本极高——工人最怕"被骗、被扔半路、有事找不到人"。人设型内容（工人故事、老工人回访、转介绍）能让刷过几次的人记住你、信你这个人。占比不能太高（不能 40%），因为新号观众还不认识你，讲太多故事反而没人看 |
| **变现型** | 30% | **从第一周就要有私信进来**：你不是要做百万粉大 V，你要的是精准获客——让本地需要找工作的人看到你、信你、找你。所以变现型从第一周就要有（服务细节展示 + 进厂避坑），但不能太高（不能 50%），新号一上来就猛发变现内容，会被平台判定为"广告号"，流量起不来 |

**什么数据出现时切换配比**：
- **第一阶段（0-1000 粉，起号期）**：按上面这个比例（流量 45% / 人设 25% / 变现 30%）
- **第二阶段（1000 粉以上，流量已稳定、私信开始多了）**：调整为 **变现 40% / 流量 35% / 人设 25%**——变现型往上加（更多服务细节和案例），流量型降到维持曝光的量就够

### 形式配比

| 形式 | 占比 | 负责哪种作用 | 为什么 |
|---|---|---|---|
| **晒过程** | 50% | **流量型 + 变现型** | **这是你的资源优势**：档案里写了"每天真实跑现场有大量接送素材"——这是同行很少有的，要充分用起来。<br>**离变现最近**：晒过程（接送记录、服务细节展示）既能证明"我在做、不是摆拍"（建信任），又能推动私信（"我也想去，怎么联系你"）。<br>**流量潜力高**：真实画面（车、人、路）+ 工人故事，陌生人一看就懂、有画面感、有故事性 |
| **讲故事** | 25% | **人设型** | **建立深度信任**：工人的故事（53 岁大哥为什么还要出去、夫妻俩为什么要结伴）+ 老工人回访（他干完回来了、又带了亲戚来）——这些故事能让人记住你、信你这个人。<br>**转介绍是最强的信任背书**：新客户看到"老工人都带亲戚来找他"，会想"连干过的人都认他，说明这人不坑" |
| **教知识** | 20% | **变现型** | **证明专业**：进厂避坑、流程讲解（年龄怎么判断、体检查什么、工资怎么算）——证明"我懂、我专业"，打消"你靠不靠谱"的疑虑。<br>**占比不高的原因**：教知识只能证明"你懂"，不能证明"你在做"——工人不缺知识，他缺的是"有人带我去"。而且教知识受众窄（只有准备进厂的人会看），流量上限低 |
| **观点** | 5% | **人设型** | **补充人设的边界**：比如"我不接什么样的人""我为什么劝他别去"——敢说边界，反而是专业和负责的证明。<br>**占比很低的原因**：观点类内容主要靠已有受众，拿不到大流量；而且你现在是新号，观众还不认识你，讲太多观点反而没人看。等有了 1000 粉、有人认你了，再慢慢加 |

**主力形式就是晒过程（接送记录）**——档案里"已有的内容方向"明确写了"接送工人真实记录"，说明你自己也判断这是最该拍的。我选的主力形式和你的判断一致，不换。

**变现型那一块用什么形式**：按客人为什么买你来定——
- 档案里"核心卖点"写的是：便利性（上门接送）、服务好（全程跟进）、选择多（岗位信息多）、专业强（对务工人群和进厂流程更了解）
- 前三个卖点（便利性、服务好、选择多）要靠**晒过程**来证明：拍接送过程、服务细节、你对接的不同岗位
- 第四个卖点（专业强）要靠**教知识**来证明：讲进厂避坑、流程讲解

### 题材配比

- **主赛道（找工作 / 进厂相关）占 65%**：接送记录、工人故事、进厂避坑、岗位匹配、服务细节
- **目标人群的兴趣 占 35%**

**人群兴趣具体是哪几类**（这群人除了找工作之外还关心的话题）：
1. **挣钱养家的不易**：孩子开学要攒钱、老人生病要花钱、还账、夫妻俩结伴出去挣钱——这些是他们出去打工的**真实动机**，讲这些能引发共鸣
2. **务工人的生活**：在外打工的辛苦、想家、攒钱的目标、和工友的关系、厂里的真实情况（不是招工广告里说的那样）——这些能让他们觉得"你懂我们"
3. **本地人的共鸣**：濮阳本地的事、方言、熟悉的地标（XX 村、XX 路口）、本地人的生活方式——这些能让他们觉得"你是自己人"

### 配比核验

1. **流量型是不是和账号阶段匹配（新号是不是最大的一块）？**  
   ✅ **是**。流量型 45%，是三者里最大的，符合"新号起号期、流量优先"的原则

2. **主力形式是不是档案里数据最好的那一类？不是的话理由够不够硬？**  
   ✅ **是**。档案里"数据最好的内容类型"写的是"还没发过"，但"已有的内容方向"明确写了"接送工人真实记录"，说明客户自己也判断这是最该拍的。我选的主力形式就是晒过程（接送记录），和他的判断一致

3. **用户要大流量的话，行业干货是不是没当主力？**  
   ✅ **用户没说要大流量**（档案里没写"要做博主、要百万粉"），他的目标是"本地精准获客"。所以我给的配比是：流量型 45%（扩曝光，让本地人刷到你）+ 变现型 30%（推动私信）+ 人设型 25%（建信任）——**教知识只占 20%，不是主力**

4. **题材有没有给目标人群的兴趣留出 30-40%？**  
   ✅ **有**。题材配比：主赛道（找工作 / 进厂）65% + 目标人群的兴趣（挣钱养家、务工人的生活、本地共鸣）35%

5. **每个数字都能说出"为什么是这个比例"吗？**  
   ✅ **能**。上面每个比例后面都写了依据：为什么流量型是 45% 而不是 60%，为什么变现型是 30% 而不是 10%，为什么晒过程是 50%

## 三种视频怎么拍

### 流量型：让更多本地人、想进厂的人第一次刷到你

**拍什么方向**：
1. **真实接送记录 + 工人的反差故事**（53 岁还要出去、夫妻俩结伴、不识字的阿姨第一次出门）
2. **进厂冷知识**（为什么厂里要收手机、为什么体检要查这几项、哪些厂专门要大龄工人）

#### 四大脚本（薛老师）

**主力脚本：晒过程·火车节模型**  
**结构骨架**：起因（带钩子）→ 关键步骤 → 结果

**套到这个号上**：
- **起因（带钩子）**：早上 6 点出发，去 XX 村接一个 53 岁的大哥，他上车前问了我 3 遍"厂里真的收吗"
- **关键步骤**：我怎么回答他（"大哥你放心，我接过好几个 50 多岁的，厂里要的就是踏实能干的"）；路上他跟我聊家里情况（孩子要上大学、家里要花钱）；到了体检点，我陪他过每一关；到了厂门口，我把他交给带班的，跟他说"有事随时给我打电话"
- **结果**：他进去了，我站在车旁目送他走进去

**标题可叠爆款元素**：人群（大龄）+ 反差（53 岁还要出去）

**示范**：
- **标题**：《今天接的大哥 X 岁了，上车前问了我 3 遍厂里到底收不收》
- **怎么拍**：车内 + 车外两个机位。车内：手机架在中控台，拍你和大哥的对话（"大哥你放心，我接过好几个 50 多岁的"）；车外：拍你送他进厂门口、你站在车旁目送他走进去的背影。配音旁白："很多人以为 50 多岁了厂里不要，其实有些厂专门要大龄的，因为踏实、能吃苦。你放心，我全程跟你，有事随时找我"

---

**辅助脚本：教知识·冷知识**  
**结构骨架**：反常识结论 → 为什么会这样 → 和每个人的关系 → 一句反问

**套到这个号上**：
- **反常识结论**："很多人以为进厂不要 40 岁以上的，其实有些厂专门要大龄的"
- **为什么会这样**："因为大龄工人踏实、能吃苦、不乱跳槽，厂里用着放心"
- **和每个人的关系**："你如果 X 岁了，想去又担心年龄过不了，可以试试这几个厂：XX 包装厂、XX 食品厂，都收 45-55 岁的"
- **一句反问**："你们那边也有大龄的想出去吗？评论区说说"

**示范**：
- **标题**：《很多人不知道：有些厂专门要 X 岁以上的，为什么？》（叠了冷知识元素）
- **怎么拍**：口播。你坐在车里或者站在车旁，对着镜头说："很多人以为进厂不要 40 岁以上的，其实有些厂专门要大龄的，为什么？因为踏实、能吃苦、不乱跳槽。你如果 X 岁了，想去又担心年龄过不了，可以私信我，我告诉你哪些厂收"

#### 起号36计（小黄）

**主力：第 35 计·街头采访**【流量型】  
**公式**：一句好问题 → 追问 → 人物故事/观点 → 行业连接

**套到这个号上**：
- **一句好问题**：在车上问工人："大哥，你 X 岁了，为啥还要出来打工？"
- **追问**：他回答（孩子要上大学、家里要花钱）→ 你追问"家里人支持吗？"→ 他说"老婆说只要能挣钱、年龄大点没事"
- **人物故事**：他讲他的处境（上有老下有小、不出去不行）
- **行业连接**：镜头转向你，你说"很多大龄的来问我，我都会先问他身体行不行、家里人同意不，这两个过了，我才接"

**为什么选这一计**：你每天在车上接送工人，天然就是"移动采访现场"——不用额外策划，只需要在车上多问几句、把他的回答录下来。而且**工人的真实故事（为什么去、担心什么、家里什么情况）本身就是最好的内容**，陌生人一听就有共鸣

**示范**：
- **标题**：《问了个 X 岁的大哥：你都这么大了，为啥还要出来？》（叠了人群元素）
- **怎么拍**：车内。手机架在中控台，拍你和大哥。你问"大哥，你 X 岁了，为啥还要出来？"→ 他回答 → 你追问"家里人支持吗？"→ 他回答。最后镜头切到你，你说"很多大龄的来问我，我都会先问他身体行不行、家里人同意不。你如果也想去，可以先私信我，我帮你看看适不适合"

---

**辅助：第 31 计·南北/地域差异**【流量型】  
**公式**：同一任务两地做 → 差异反应 → 原因/文化 → 交流

**套到这个号上**：
- **同一任务两地做**：濮阳人进厂 vs XX 地（比如河南其他地方、或者安徽）的人进厂
- **差异反应**：濮阳人更看重"离家近不近、能不能照顾家"；XX 地的人更看重"工资高不高、能不能多挣点"
- **原因/文化**：濮阳这边上有老下有小、家里离不开人，所以更愿意去离家近的厂（比如安徽、南京），干几个月就能回来；XX 地的人年轻、没家庭负担，更愿意去远的、工资高的（比如广东、上海）
- **交流**："你们那边的人都去哪打工？评论区说说"

**示范**：
- **标题**：《濮阳人进厂和 XX 地人进厂，完全不一样》（叠了地域差异元素）
- **怎么拍**：口播 + 画面。你说"濮阳人进厂，第一句问的不是工资多少，是'离家近不近、能不能照顾家'；XX 地的人第一句问的是'工资多少、包不包吃住'。为什么？因为濮阳这边上有老下有小、家里离不开人，所以更愿意去离家近的厂。你们那边的人都去哪打工？评论区说说"

---

**结尾行动指令**：**"你们那边也有这样的吗？评论区说说"**（引评论，不要点赞、收藏、转发）

#### 四大脚本（薛老师）

**主力脚本：讲故事·平凡英雄型**  
**结构骨架**：普通人 → 一件不普通的小事 → 细节验证 → 感悟

**套到这个号上**：
- **普通人**：一个 X 岁的大姐，不识字，第一次出门打工
- **一件不普通的小事**：她特别害怕，上车前哭了；我全程陪着她过体检、到了厂里我把她交给宿舍的老乡
- **细节验证**：她不识字，体检表不会填，我一项一项教她；她担心"到了厂里我一个人都不认识"，我提前给她联系了同宿舍的老乡
- **感悟**：三个月后她干完回来了，给我发微信（语音）说"小张，谢谢你，我下次还找你"。其实我做的事不复杂，就是多陪她几步，但对她来说，这几步是最难的

**示范**：
- **标题**：《一个 X 岁、不识字的大姐，第一次出门打工》
- **怎么拍**：Vlog + 旁白配音。画面：你接她上车 → 她在车上哭 → 你安慰她 → 到体检点你陪她填表 → 到厂门口你把她交给老乡。旁白："她特别害怕，上车前哭了。我说'大姐你放心,我全程陪你'。体检表她不会填，我一项一项教她。到了厂里，我提前给她联系了同宿舍的老乡。三个月后她干完回来了，给我发微信说'小张，谢谢你，我下次还找你'。其实我做的事不复杂，就是多陪她几步，但对她来说，这几步是最难的"

#### 起号36计（小黄）

**主力：第 3 计·以物换物**【人设型】  
**公式**：提出交换 → 协商 → 体验 → 挖掘人物 → 情感结果

**套到这个号上**：
- **提出交换**：一个老工人干完回来了，我说"你这次干得咋样"
- **协商**：他说"还行，攒了 X 万多，够孩子开学了"。我说"下次还来吗"
- **体验**：他说"来，我还带我表弟，你到时候一起接"

### 2. 经历与故事（工人的故事、你的经历）

**具体来源**：
- **工人的真实故事**：每个工人背后都有故事——X 岁还要出去、夫妻俩结伴、不识字的阿姨第一次出门、孩子开学了必须挣钱、在家闲久了想出去、老工人带新人…每个都是选题

- **老工人的反馈**：他们干完回来说了什么、为什么还愿意找你、为什么带亲戚来——每个反馈都是选题

**举例**：

## 前 30 条节奏

### 第 1-10 条：集中跑通主力形式，建立"这个人靠谱"的初步认知

**目标**：让本地人第一次刷到你，知道"濮阳有个开车接人去厂里的"

**做哪个系列**：**系列 1《濮阳接送日记》**（真实接送记录 + 车上采访工人）

**主要用哪套打法**：
- **起号 36 计是主力**：第 35 计·街头采访（车上问工人问题）、第 1 计·反向操作（人都到车上了他突然说不去了）、第 31 计·地域差异（濮阳人进厂和 XX 地人进厂完全不一样）

- **完播率**：30% 以上（说明钩子和内容能留住人）

## ⚠️ 不要做什么

1. **不要拍成招工广告**  
   **为什么**：同行最常见的错——天天发"XX 厂招工、工资 X 元、包吃住、速来"，像电线杆小广告。工人看到的第一反应不是"真好"，是"又是骗子吧"。你的差异化就是"不只发广告，拍真实过程"——一旦退回到发广告，你和同行就没区别了，信任全塌

2. **不要只讲岗位、不讲人**  
   **为什么**：光说厂多好、工资多高，但工人真正担心的是"你这个人靠不靠谱""我去了你管不管我""出了事你跑不跑"。内容里必须有"人"（工人的故事、你和工人的互动、老工人对你的评价）——只讲岗位拉不到精准流量，也建不了信任

3. **不要为了流量拍和目标人群无关的内容**  
   **为什么**：比如拍段子、拍热点、拍濮阳本地的吃喝玩乐——可能会爆，但涨的是泛粉，不是想进厂的人。泛粉看热闹、不咨询、不成交，稀释了账号的精准度。你的目标是"让本地想进厂的人找到你"，不是"涨十万粉"——流量型内容（接送记录、工人故事、进厂冷知识）覆盖的人群已经够广了，不需要再往外扩
