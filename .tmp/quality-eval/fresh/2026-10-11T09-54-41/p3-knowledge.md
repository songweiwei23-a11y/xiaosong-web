# 家具店短视频前3秒留人公式

## 核心认知

家具店的困境：**开头说"我们是做家具的"= 直接告诉观众这是广告，立刻划走。**

前3秒的任务不是介绍自己，而是**用一个和目标人群强相关的场景/问题/反常识，让对的人觉得"这说的就是我"**。

---

## 六种钩子类型（按目的选）

### 【流量型】冷知识/反认知开头

**公式**:先抛出一个违背常识的结论 → 观众停下来等验证

```
❌ 错误示范:"大家好,我是青禾家具店老板"
✅ 正确示范:
"买沙发千万别只看坐感,90%的人都在这一步踩坑"
"为什么家具城的床比网上便宜一半,老板还说自己不赚钱?"
"衣柜做到顶和不到顶,五年后差距有多大"
```

**适用场景**:拍科普避坑、行业内幕、选购知识
**结尾指令**:关注/评论区告诉我你家踩过什么坑

---

### 【变现型】痛点场景开头

**公式**:用具体场景圈出正在为这件事头疼的人

```
"刚搬新家,沙发摆客厅总觉得空荡荡?"
"卧室不到10平,衣柜怎么摆都挡窗户?"
"想换床,但楼梯转角只有80公分宽,师傅说进不去"
```

**为什么有效**:场景越具体,目标人群越觉得"这不就是我家吗"
**结尾指令**:私信我你家户型图,我帮你看看怎么摆

---

### 【变现型】金钱型钩子

**公式**:直接说能省多少钱/多少预算能搞定

```
"3000块预算,能在青禾配齐客厅三件套吗?今天实测给你们看"
"同样的沙发,家具城X,网上X,我们店X,区别在哪?"
"这张床为什么比商场便宜【X】块,我带你们看看【换成你店里的真实做法】"
```

**注意**:价格数字必须是你真实在卖的,没有就写X让自己填
**结尾指令**:想了解具体价格的私信

---

### 【人设型】身份反差/小人物视角

**公式**:用"一个XX的日常"降低防备心,再自然植入专业

```
"一个开了X年家具店的人,周末逛宜家是什么体验"
"干家具15年,第一次有客人问我这个问题,我愣了"
"今天又有人问我'你们店为什么只卖3样',我决定说清楚"
```

**为什么有效**:不是"我要卖你东西",而是"我分享一个有意思的事"
**结尾指令**:关注我,下次带你们看【XX】

---

### 【流量型】盲盒悬念开头

**公式**:先说结果/情绪,不说原因 → 观众等揭晓

```
"今天来了个客人,说的这句话让我破例给他打了折"
"刚才发生了一件事,我现在手还在抖"
"这个沙发摆在店里三年没人要,今天被一个小姑娘一眼看中,她说的理由我第一次听"
```

**关键**:开头的"事件"在中间必须揭晓,不能只当标题党
**结尾指令**:评论区说说你买家具遇到过什么意外

---

### 【变现型】对抗/争议开头

**公式**:先说一个和大众认知相反的观点 → 引发"凭什么这么说"

```
"我不建议你买网上那种一千多的沙发"
"很多人觉得实体店贵是被坑,其实是你不会算这笔账"
"衣柜板材,颗粒板比实木板更适合普通家庭,不信你看"
```

**注意**:观点必须能自圆其说,中间用你15年经验讲清楚为什么
**结尾指令**:不认同的来评论区battle

---

## 四大禁区（碰了必死）

❌ **"大家好我是XX"** → 广告感拉满,0秒划走  
❌ **"今天给大家分享"** → 废话,没说任何有用信息  
❌ **"关注我不迷路"** → 开头就要关注 = 乞讨式开场  
❌ **"我们是XX年老店"** → 自卖自夸,观众不care

## 你的三大品类分别怎么开头

| 品类 | 流量型钩子 | 变现型钩子 |
|------|------------|------------|
| **沙发** | "为什么酒店的沙发坐着不累,你家的坐半小时腰疼" | "客厅沙发买大了还是买小了?今天教你一个公式" |
| **床** | "1.8米的床为什么睡着觉总往下滑,我拆开一张床给你们看" | "预算X,能买到什么样的床?【换成你店里的真实货】" |
| **衣柜** | "衣柜做到顶积灰,不到顶浪费,老师傅教你第三种办法" | "10平卧室,衣柜怎么摆能多挂20件衣服" |

## 最后提醒

**前3秒只干一件事:让对的人停下来。**

- 不要又想拿流量又想讲卖点 → 一条视频只选一个目的
- 流量型的钩子用完,结尾只能要关注/评论,别直接甩产品
- 变现型的钩子用完,结尾给一个明确动作(私信/到店/留资),选一个
- 数字、价格、做法,档案没给的就写X或【待确认】,别编

**和你自己前几条的完播率比,开头3秒留存低于前几条平均值就换钩子。**
