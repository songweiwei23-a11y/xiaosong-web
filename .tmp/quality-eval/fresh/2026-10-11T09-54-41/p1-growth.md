# 小张工作号·濮阳本地找工作服务 · 起号方案

# 🚀 起号方案

## 📌 先说结论

- **建议主攻**：第 35 计·街头采访，因为你每天车上接送工人，天然就是"移动采访现场"——不用额外策划场景，只需要在车上多问几句、把对话录下来。工人的真实故事（X 岁还要出去、夫妻俩结伴、担心年龄过不了）本身就是最好的内容，本地人一听就有共鸣
- **备选**：第 22 计·行业避坑（进厂前怎么避开被坑）、第 1 计·反向操作（人都到车上了他突然说不去了）、第 3 计·以物换物（老工人带新人上车）——什么情况下切过去下面会说
- **明确不做**：第 14 计·模仿电影片段、第 30 计·角色扮演——你一个人全包、基础剪辑，拍不了需要多人配合的剧情；第 23 计·内幕揭秘——档案明确写了不能用"揭秘"
- **多久能看出跑没跑通**：30 条内出现 3 条以上 1000+ 播放且有 3-5 条真实咨询（私信问具体问题：年龄、岗位、时间），就算跑通。否则第 15 条时就要调整钩子和场景

## 🧮 起号期内容配比

**起号期（到一千粉、流量稳定之前）**：
- **流量型 45%**：让更多本地想进厂的人第一次刷到你
- **人设型 25%**：让看过几次的人记住你、信你这个人
- **变现型 30%**：推动私信咨询

**为什么是这个比例**：
- 新号，还没发过视频，处于起号期——这个阶段只有一个任务：拿到稳定的流量和正反馈。流量型必须是最大的一块
- 这一行的信任成本极高（工人最怕被骗、被扔半路），所以人设型从第一周就要有（占 25%），让刷过几次的人开始信你
- 变现型从第一周就要有（占 30%），因为你不是要做百万粉大 V，你要的是精准获客——让本地需要找工作的人看到你、信你、找你

**每一种用哪一计来拍**：
- **流量型用 第 35 计·街头采访**（一句好问题 → 追问 → 人物故事 → 行业连接）+ 晒过程·火车节模型（起因带钩子 → 关键步骤 → 结果）；结尾行动指令：**"你们那边也有这样的吗？评论区说说"**
- **人设型用 第 3 计·以物换物**（老工人带新人上车）+ 讲故事·平凡英雄型（普通人 → 一件不普通的小事 → 细节验证 → 感悟）；结尾行动指令：**"关注我，下次带你看更多真实记录"**
- **变现型用 第 22 计·行业避坑**（点名坑 → 后果 → 识别信号 → 替代方案）+ 教知识·解题型（场景难题 → 放大危机 → 低成本解决 → 操作步骤）；结尾行动指令：**"想去的、不确定的，都可以私信我"**

**过线之后（一千粉以上、流量已稳定）**：
调整为 **变更型 40% / 流量型 35% / 人设型 25%**——变现型往上加（更多服务细节和案例），流量型降到维持曝光的量就够

**和已定的内容定位怎么对上**：
档案里"已有的内容方向"写的是"接送工人真实记录、找工作知识与进厂避坑、服务细节展示"——第 35 计·街头采访（车上采访工人）就是拍"接送工人真实记录"，第 22 计·行业避坑就是拍"找工作知识与进厂避坑"，第 3 计·以物换物（老工人带新人）就是拍"服务细节展示"。三计完全对上已定方向

## 🎯 主攻打法：第 35 计·街头采访

### 为什么是你能拍的

- **团队只有一个人**：街头采访只需要手机架在中控台，拍你和工人的对话，不需要第二机位、不需要别人配合
- **每天都在车上接送工人**：天然就是"移动采访现场"，不用额外找场景、不用约人、不用策划剧情——你每天在做的事，就是最好的素材源
- **工人的真实故事本身就是内容**：他为什么去（孩子开学要攒钱、在家闲久了）、他担心什么（年龄能不能过、厂里累不累、有没有人带）——这些故事陌生人一听就有共鸣，比你讲岗位信息更有传播力
- **手机 + 运动相机就够**：手机架在中控台拍车内对话，运动相机拍车外视角（早上出发、路上、送到厂门口），基础剪辑能完成

### 结构公式（套到你这个号上）

**公式**：一句好问题 → 追问 → 人物故事 → 行业连接

**套到你这个号上**：
- **一句好问题**：在车上问工人："大哥，你 X 岁了，为啥还要出来打工？"/"大姐，你第一次出门，家里人放心吗？"/"你上车前为什么问了我 3 遍厂里真的收吗？"
- **追问**：他回答（孩子要上大学、家里要花钱）→ 你追问"家里人支持吗？"/"你担心什么？"→ 他继续讲
- **人物故事**：他讲他的处境（上有老下有小、不出去不行；不识字、怕流程复杂；之前被中介坑过）
- **行业连接**：镜头转向你，你说"很多大龄的来问我，我都会先问他身体行不行、家里人同意不，这两个过了，我才接。你们那边也有这样的吗？评论区说说"

### 配什么脚本讲

这一计管的是**事件怎么走**（车上采访 → 工人讲故事），话怎么讲配 **晒过程·火车节模型**：
- **起因（带钩子）**：早上 X 点出发，去 XX 村接一个 X 岁的大哥，他上车前问了我 3 遍"厂里真的收吗"
- **关键步骤**：我怎么回答他（"大哥你放心，我接过好几个 X 岁的，厂里要的就是踏实能干的"）；路上他跟我聊家里情况（孩子要上大学、家里要花钱）；到了体检点，我陪他过每一关；到了厂门口，我把他交给带班的，跟他说"有事随时给我打电话"
- **结果**：他进去了，我站在车旁目送他走进去

**配了它补上的是什么**：晒过程·火车节能让这条片子既有工人的故事（人设），又有你的服务细节（变现），还能证明"我在做、不是摆拍"（建信任）

### 前 3 条具体拍什么

#### 第 1 条：《今天接的大哥 X 岁了,上车前问了我 3 遍厂里到底收不收》
**叠了元素**：人群（大龄）+ 反差（X 岁还要出去）

**拍摄要点**：
- **开场**：手机架在中控台，拍大哥上车的动作。你旁白："今天早上 X 点，去 XX 村接一个大哥，他上车前问了我 3 遍'厂里真的收吗'"
- **车上对话**：手机拍你和大哥的对话（只拍你正脸，大哥拍侧面或背影、或声音）。你问"大哥你为啥还要出来"→ 他说"孩子要上大学，家里要花钱"→ 你说"大哥你放心，我接过好几个 X 岁的，厂里要的就是踏实能干的"
- **送到厂门口**：运动相机拍你送他下车、你站在车旁目送他走进厂门口的背影
- **结尾**：镜头回到你，你说"很多大龄的来问我，我都会先问他身体行不行、家里人同意不。你们那边也有这样的吗？评论区说说"

---

#### 第 2 条：《一个大姐不先问工资,只问厂里能不能跟老乡住一起》
**叠了元素**：反差（不问工资问住宿）

**拍摄要点**：
- **开场**：手机拍你接大姐上车。你旁白："今天接的大姐，上车第一句话不是问工资多少，而是问'厂里能不能跟老乡住一起'"
- **车上对话**：你问"为啥这么问"→ 她说"一个人去陌生地方、我害怕，有老乡在我就放心"→ 你说"大姐你放心，我提前给你联系好了，同宿舍有两个濮阳的"
- **结尾**：镜头回到你，你说"很多人以为进厂就是看工资，其实他们更担心的是'一个人去、没人管、出了事找谁'。所以我接人之前，都会提前问清楚、安排好。想去的，私信我"

---

#### 第 3 条：《人都到车上了,他突然说不去了,原因我能理解》
**叠了元素**：反差（人都到车上了突然不去）

**拍摄要点**：
- **开场**：手机拍工人坐在车上。你旁白："今天早上，人都到车上了，他突然跟我说'小张，我不去了'"
- **车上对话**：你问"咋了大哥"→ 他说"家里老人昨晚摔了一跤，我得在家照顾几天"→ 你说"那你先照顾老人，等老人好了你再跟我说，我再给你安排"
- **结尾**：镜头拍他下车走了。你旁白："做这一行，遇到过很多这样的事。家里有事了、身体不舒服了、临时改主意了——我都理解。挣钱重要,但家里人更重要。你们遇到过这样的事吗？评论区说说"

---

### 边界

- **不能拍工人正脸**：档案明确写了"不能拍到工人正脸（未征得同意）"——车上对话只拍你正脸，工人拍侧面、背影或声音；如果工人同意了，可以拍正脸，但要提前问清楚
- **不能编造数字**：工资、年龄、人数，档案里没有的一律写成 X（如"X 岁的大哥""攒了 X 万多"）
- **不能承诺太满**："保证安排""全程无忧""来了就能挣钱"——这些绝对化承诺不能说，改成"我会全程跟你""有事随时找我"

## 🔄 备选打法

### 第 22 计·行业避坑【变现型】

**什么情况下切过去**：主攻打法（街头采访）拍了 10 条，私信量还是很少（每周不到 3 条）——说明观众觉得"这个人真实",但还不知道"他能帮我什么"。这时候切到行业避坑，直接讲"进厂前怎么避开被坑"，推动私信

**一句话说明怎么套**：拍你对着镜头讲"很多人被坑过,这三种坑最常见:第一种,说好的工资去了发现要扣这扣那;第二种,说包吃住去了发现住大通铺吃剩菜;第三种,干了一个月不想干了厂里说'不满三个月走扣一半工资'。怎么避开?第一,走之前问清楚'工资怎么算、扣哪些、几号发';第二,问清楚'住宿几人间、吃饭几个菜';第三,问清楚'最少要干多久、不干了工资怎么结'。如果你不会问,私信我,我帮你问"

**配哪个四大脚本结构讲**：教知识·解题型（场景难题 → 放大危机 → 低成本解决 → 操作步骤）——把"被坑"当作难题,把三种坑的后果当作危机,把"问这五个问题"当作解决方案

---

### 第 1 计·反向操作【流量型】

**什么情况下切过去**：主攻打法（街头采访）拍了 10 条,数据稳定了,但流量上限不高（单条播放量卡在 1000-2000）——说明需要一个"反常识"的钩子来扩大覆盖面。这时候切到反向操作,拍"人都到车上了他突然说不去了"/"我劝他别去了"这种反常识事件,能拿到更大的流量

**一句话说明怎么套**：拍"常规:接人去厂里 → 反向:人到车上了他突然不去了/我劝他别去 → 真实原因(家里有事/身体不行/我觉得他不适合) → 观众反应:理解/意外"

**配哪个四大脚本结构讲**：晒过程·火车节模型——起因(人都到车上了) → 关键步骤(他说不去了、我问为什么、他说原因) → 结果(他下车了/我送他回家)

---

### 第 3 计·以物换物【人设型】

**什么情况下切过去**：主攻打法（街头采访）和备选打法（行业避坑）都跑通了,私信量也起来了,但关注率不高（播放转关注低于 5%）——说明观众看完觉得"有用",但还不信你这个人。这时候切到以物换物,拍"老工人带新人上车",用老客户的真实反馈建立深度信任

**一句话说明怎么套**：拍"老工人干完回来了,我问'这次干得咋样' → 他说'还行,攒了 X 万多' → 我说'下次还来吗' → 他说'来,我还带我表弟' → 镜头拍他们俩上车,表弟问'哥你咋找到这个人的' → 老工人说'我之前跟过他一次,靠谱' → 结尾我说'老工人认我,你也可以信我。想去的,私信我'"

**配哪个四大脚本结构讲**：讲故事·平凡英雄型——普通人(老工人) → 一件不普通的小事(他干完回来还带亲戚来找你) → 细节验证(表弟问"你咋找到他的"、老工人说"靠谱") → 感悟("老工人认我,你也可以信我")

## 🧪 怎么测

### 一次只改哪个变量

- **第 1-5 条**：只测主攻打法（第 35 计·街头采访）,不换计、不换结构,只换不同的工人故事（X 岁大哥 / 不识字大姐 / 夫妻俩 / 老工人带新人）
- **第 6-10 条**：如果前 5 条流量稳定了,开始测开篇钩子——同样是街头采访,换不同的第一句话(结果前置 / 反常识 / 对话钩)
- **第 11-15 条**:如果前 10 条流量稳定、私信量还不够,切到备选打法(第 22 计·行业避坑),测 5 条
- **第 16-20 条**:如果私信量起来了、关注率还不高,切到第二备选(第 3 计·以物换物),测 5 条

### 每计测几条、看什么指标

- **每计至少测 3-5 条**——样本太少只能判断单条执行好坏,不能否定方法本身
- **看什么指标**:
  - **流量型**（第 35 计·街头采访、第 1 计·反向操作）:看非关注用户的播放占比、完播率、评论量（本地账号,单条 500-1000 播放 + 完播率 30% 以上就算正常）
  - **变现型**（第 22 计·行业避坑）:看私信量、咨询质量（有没有人问具体问题:年龄、岗位、时间）
  - **人设型**（第 3 计·以物换物）:看主页访问、关注率（播放转关注 5-8%）

### 什么信号算"这计行",什么信号算"换掉"

**算"这计行"**:
- 连续 3 条单条播放量稳定在 500-1000 以上（本地账号起号期这个量级就算正常）
- 完播率稳定在 30% 以上
- 评论区有本地人评论"我认识这地方""我也想去"——说明精准人群看到了
- 变现型的计:每周有 3-5 条私信,而且私信里有人问具体问题（不是"真的假的""要不要收钱"这种试探）

**算"换掉"**:
- 连续 5 条单条播放量都在 200 以下——说明选题太窄或开篇不行,切到备选打法
- 流量有了、私信没有（拍了 10 条,每周私信不到 3 条）——说明内容只有流量型、缺变现型,切到第 22 计·行业避坑
- 流量有了、关注率很低（播放转关注低于 3%）——说明人设不够深,切到第 3 计·以物换物

### 第 4-10 天:集中测主攻打法

**任务**:

**任务**:

**验收标准**:

- 如果私信量还是很少（每周不到 3 条）——说明变现型内容不够或内容不够精准,第 21 天开始加大变现型内容比例（从 30% 加到 40%）

### 第 21-25 天:分析数据 + 淘汰无效假设

**任务**:
- 看前 20 条数据,找出播放量最高的 3 条和私信量最多的 3 条——提取这些视频的共性:是哪一计、开篇是什么、讲的是什么故事

**交付物**:复盘表（前 20 条数据分析 + 有效模式提取）+ 下一阶段计划

- 如果还没跑通,按下面的"跑不通先查哪里"诊断

## 📊 跑不通先查哪里

### 情况 1:曝光少（单条播放量都在 100 以下）

**优先怀疑**:选题太窄（只有濮阳本地想进厂的人才看）、账号标签不清（平台不知道推给谁）、合规问题（拍了工人正脸、说了绝对化承诺）

**下一步做什么实验**:
- 换更广的入口:不要只拍"濮阳接送工人",换成"X 岁大哥为啥还要出来打工"（大龄打工是全国性话题,覆盖更广）
- 连发同主题 3-5 条:让平台明确知道你是做什么的（比如连发 3 条都是车上采访工人）
- 核查合规:检查有没有拍工人正脸、有没有说"保证安排""全程无忧"这类绝对化承诺——有就删掉重拍

---

### 情况 2:有曝光但前段流失（播放量有、完播率低于 20%）

**优先怀疑**:首帧弱（第一秒没抓住人）、第一句空泛（"大家好我是小张"）、承诺不清（观众不知道看完能得到什么）

**下一步做什么实验**:
- 重写 5 个开篇:结果前置（"今天接的大哥 X 岁了,上车前问了我 3 遍厂里到底收不收"）、对话钩（直接从对话开始:"'小张,我 X 岁了,厂里还收吗?''大哥你放心……'"）、反常识（"人都到车上了,他突然说不去了"）
- 前 5 秒必须让观众明确"我在等什么":等他为什么问 3 遍、等他为什么突然不去、等你怎么回答他

---

### 情况 3:流量有了、私信没有（单条播放量 1000+,但每周私信不到 3 条）

**优先怀疑**:内容只有流量型、缺变现型——观众看完觉得"有意思",但不知道"他能帮我什么"

**下一步做什么实验**:
- 加大变现型内容比例:从 30% 加到 40%,多拍第 22 计·行业避坑（"进厂前怎么避开被坑"）、第 15 计·正确做法 VS 错误做法（"找工作第一句别问工资多少,先问这五个"）
- 结尾行动指令要明确:"想去的、不确定的,都可以私信我"（不要写"有问题评论区留言"）
- 主页承接要清晰:简介里写清楚"我是谁 + 能帮你什么 + 怎么联系我"（"濮阳劳务小张,开车接你到厂门口,全程跟进,私信我"）
