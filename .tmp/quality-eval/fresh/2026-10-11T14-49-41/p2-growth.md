## 🧮 起号期内容配比

**起号期（到一千粉、流量稳定之前）**：流量型60% / 人设型25% / 变现型15%

**为什么是这个比例**：
- 流量型60%：你现在"刚起号、定位未确定、0-1万粉"，这一阶段只有一个任务是拿稳定流量和正反馈。起号打法大多是流量型内容，零粉做到一千粉且流量稳定才算起号成功。同时你变现方式里勾了"广告变现、带货佣金"，这两条需要大流量支撑
- 人设型25%：县城老板决策看人不看方案，档案里客人最担心的是"被同行坑过/有阴影"——他们第一反应不是"你专不专业"，是"你会不会坑我"。四分之一的内容用来讲故事、立观点，让老板看到"你是个什么样的人、和上一个代运营不一样"
- 变现型15%：第一周就有，但只占小头——既能让精准老板看到"你能帮他做什么"，又不会让账号像广告号。**等流量稳定后（1000粉、流量稳定），逐步把变现型比例提到30-40%**

**每一种用哪一计来拍**：
- **流量型（60%）用第35计·街头采访**：一句好问题 → 追问 → 人物故事/观点 → 行业连接。脚本结构：开篇直接抛问题 → 剪辑X个老板的不同回答（有反差）→ 追问其中一两个老板 → 最后一句落在"我就是专门帮他们解决这个问题的"。**结尾行动指令**："你们那边的老板也这样吗？评论区说说"（只要评论，不要点赞收藏转发）
- **人设型（25%）用第3计·以物换物**：提出交换 → 协商 → 体验 → 挖掘人物 → 情感结果。配脚本：贵人相助（负面/意外切入 → 小善意 → 隐藏身份 → 回报反转 → 软植入）或观点立场（亲身经历 → 我的判断 → 为什么这么看 → 邀请你怎么看）。**结尾行动指令**："关注我，每周分享一个真实案例"
- **变现型（15%）用第10计·情境还原**：真实任务 → 对话/纠错 → 旁观学习 → 结果。配脚本：晒过程·火车节（起因带钩子 → 关键步骤 → 结果）。**结尾行动指令**："你的店也这样吗？私信我，我帮你看看"（只要私信，不要到店、留资、加微信全要）

**过线之后**（1000粉、流量稳定）：
- 逐步提高变现型比例：从15%提到30%
- 开始叠一个王牌栏目：《每周帮一个濮阳老板拍第一条》，用第10计·情境还原做结构
- 流量型比例降到40%，但持续保持更新，不能断

**和已定的内容定位怎么对上**：
- 档案里"数据较好的内容类型"是"讲故事/讲经历的、拍工作过程的"——主力形式就是讲故事和晒过程，这两种形式对应人设型和变现型
- 已定的主系列是《问濮阳老板》（流量线）和《帮濮阳老板拍第一条》（变现线）——第35计·街头采访和第10计·情境还原就是为这两个系列设计的打法

## 🎯 主攻打法：第35计·街头采访

### 为什么是你能拍的

- **团队一人全包**：街头采访只需要一部手机、一个人，走到濮阳街头（或批发市场、商会、美食街）问老板问题，不需要第二机位、不需要搭档、不需要复杂拍摄
- **你有设备**：档案里写了"手机、灯光、收音设备、稳定器"——手机和收音设备就够了（街头采访主要靠环境音，收音设备力求老板的回答清晰）
- **你有场地优势**：档案里写"外景"——濮阳街头就是你的外景，不需要租场地、不需要搭景
- **你有地域优势**：档案里"差异化优势"写的是"濮阳本土化，实战派。对濮阳当地有着深刻的了解和认知"——你人在濮阳、对本地熟，知道哪条街老板多、哪个时间段适合拍、怎么和老板搭话，这是外地人做不到的
- **你擅长的内容形式**：档案里"数据较好的内容类型"是"讲故事/讲经历的"——街头采访就是收集老板的真实故事和经历，和你擅长的内容形式完全吻合
- **预算0-500元**：街头采访零成本，不需要花钱

### 结构公式（套到你这个号上）

**一句好问题 → 追问 → 人物故事/观点 → 行业连接**

具体到你这个号：
1. **一句好问题**：在濮阳街头问老板一个关于短视频的问题（"你拍短视频了吗""拍了效果怎么样""最大的困难是什么"）
2. **追问**：剪辑X个老板的不同回答（有的说没拍、有的说拍了没效果、有的说不知道拍啥），选其中一两个老板追问"那你觉得问题出在哪"
3. **人物故事/观点**：老板说出他的真实困境（"我不会说话""播放量只有几十""被上一个代运营坑过"）
4. **行业连接**：最后一句落在"我就是专门帮濮阳老板解决这个问题的，下一条我带你看我怎么帮他们拍"

### 配什么脚本讲

**这一计管事件怎么走**：你走在濮阳街头、问老板问题、收集回答、剪成一条视频

**话怎么讲从四大脚本里配一个结构**：不需要配四大脚本——街头采访的内容主要是老板的真实回答，你只需要在最后一句做行业连接（"我就是专门帮他们解决这个问题的"），不需要口播讲一段完整的知识或故事

**配了它补上的是什么**：补上**真实性**——老板的回答是他们自己说的，不是你编的，这比你自己讲"老板都有这些困难"更有说服力。同时补上**地域标签**——每一条都在强化"我在濮阳、我懂濮阳老板"

### 前3条具体拍什么

**第1条**：《问濮阳老板：你拍短视频了吗？》**（叠爆款元素：人群）**
- **拍摄要点**：去濮阳美食街或批发市场，找X个老板问同一个问题"你拍短视频了吗"。剪辑时保留有反差的回答（有的说"拍了"、有的说"没拍"、有的说"拍了但没效果"），最后一个老板说"我不知道怎么拍"，你说"我就是专门帮濮阳老板拍短视频的，下一条我带你看我怎么帮他拍"
- **设备**：手机竖屏拍摄，稳定器保持画面平稳，收音设备收老板的声音（如果环境嘈杂，后期加字幕）
- **时间**：下午3-5点（店不太忙的时候，老板愿意聊）
- **注意**：问之前先说"我在拍短视频，能问你一个问题吗"，征得同意再拍；拍不到正脸就拍侧脸或背影，避免侵犯肖像权

**第2条**：《问濮阳老板:拍短视频最大的困难是什么?》**（叠爆款元素:人群)**
- **拍摄要点**:同样去濮阳街头,问X个老板"你拍短视频最大的困难是什么"。剪辑时保留不同的困难(有的说"不会拍"、有的说"没时间"、有的说"不知道拍啥"、有的说"播放量低"),最后一句你说"这些困难我都能帮你们解决"
- **设备**:同第1条
- **时间**:同第1条
- **注意**:这一条比第1条更深一层——第1条是问"拍没拍",第2条是问"困难是什么",更能挖出老板的真实痛点

**第3条**:《问濮阳老板:被代运营坑过吗?》**（叠爆款元素:人群+奇葩)**
- **拍摄要点**:去濮阳街头,问X个老板"你被代运营坑过吗"。剪辑时保留有故事的回答(有的说"收了钱不管事"、有的说"拍了几条就不拍了"、有的说"承诺的效果没达到"),最后一句你说"所以我做代运营,第一件事是让老板看到我在做什么"
- **设备**:同第1条
- **时间**:同第1条
- **注意**:这一条触及"被同行坑过/有阴影"这个档案里的真实痛点——老板说出被坑的经历,你在最后一句给出你和上一个代运营不一样的地方("让老板看到我在做什么"=晒过程、透明),建立信任

### 边界

**这一计的边界**:
1. **真实性第一**:老板的回答必须是他们真实说的,不能提前编好台词让老板背——一旦被观众看出是演的,账号就废了
2. **不能诱导答案**:问问题时不能说"你是不是觉得X",要问开放式问题("你觉得X怎么样"),让老板自由回答
3. **肖像权边界**:拍之前必须征得老板同意,拍不到正脸就拍侧脸或背影,或者后期打码
4. **不能剪辑误导**:剪辑时不能断章取义——老板说"我拍了,但效果不好",你不能只剪"我拍了"这一句
5. **不能踩档案里的禁忌**:问题里不能出现"揭秘""爆黑料""诋毁同行"这些词;老板说了别的代运营坑他,你只能说"我的做法是X",不能说"他们都是骗子"

**对你适用的具体边界**:
- **不要在老板忙的时候拍**:档案里写"店里忙、没时间"是老板不配合拍摄的常见理由——街头采访也一样,饭点、周末高峰期不要去打扰老板
- **不要只拍失败案例**:如果X个老板都说"被坑过""没效果",观众会觉得"短视频这事根本不行"——要有1-2个正面案例("我拍了,效果还不错")做平衡
- **不要只拍一个行业**:如果X个老板都是火锅店,覆盖面太窄——要拍不同行业(火锅、美容、汽修、服装……),证明"短视频获客"这件事是跨行业的

## 🔄 备选打法

### 备选1:第31计·地域差异(濮阳vs郑州)

**什么情况下切过去**:第35计·街头采访拍了10条后,流量稳定但增长到瓶颈——说明"濮阳本地老板"这个标签已经打上了,但覆盖面还不够广。这时候切到地域差异,把覆盖面从"濮阳老板"扩到"关心县城vs大城市差异"的所有人

**一句话说明怎么套到你这个号上**:对比濮阳和郑州两地老板在短视频上的不同做法和思路("濮阳老板关心能来几个人,郑州老板关心播放量多少")

**配哪个四大脚本结构讲**:不需要配四大脚本——地域差异这一计本身就是完整的结构(同一任务两地做→差异反应→原因/文化→"你那边是哪种")。话怎么讲就按这个结构:开篇"同样是拍短视频,濮阳老板和郑州老板关心的事完全不一样"→对比两地做法→原因"县城是熟人社会,老板要的不是数据好看,是真的有人进店"→结尾"你那边的老板也这样吗?评论区说说"

### 备选2:第10计·情境还原(拍你帮老板的过程)

**什么情况下切过去**:流量稳定后(1000粉以上),评论区开始有老板私信咨询——说明精准人群已经圈到了,这时候需要补变现型内容,让老板看到"你能帮他做什么、怎么做"

**一句话说明怎么套到你这个号上**:拍"我正在帮某个濮阳老板拍第一条"的现场,还原真实对话——老板说"我想拍我的产品",你说"产品拍了没人看,要拍你这个人"

**配哪个四大脚本结构讲**:晒过程·火车节(起因带钩子→关键步骤→结果)。具体到这一计:起因"这个老板说他【具体困难】,问我能不能帮他"→关键步骤"我去他店里【做了什么】,发现【问题】,我说【解决方式】"→结果"重新拍了一条,【具体效果】"。配了晒过程·火车节补上的是**成交理由**(证明你能做成、专业强、效果好)

### 备选3:第1计·反向操作

**什么情况下切过去**:第35计·街头采访拍了20条后,流量开始掉——说明观众对"问老板"这个形式有审美疲劳。这时候切到反向操作,换一个完全不一样的形式拉回注意力

**一句话说明怎么套到你这个号上**:把行业常规动作倒过来——常规做法是"代运营教老板怎么拍",反向操作是"老板教代运营怎么拍"(找一个拍得好的老板,让他教你)

**配哪个四大脚本结构讲**:不需要配四大脚本——反向操作这一计本身就是完整的结构(常规A→反向B→真实反应/结果)。话怎么讲就按这个结构:开篇"今天反过来,我让一个老板教我怎么拍短视频"→过程(老板教你、纠正你)→结果"老板说的这几点,我自己都没注意到"

## 🧪 怎么测

### 一次只改哪个变量

**第1-10条(测试主攻打法)**:
- **定量**:第35计·街头采访的形式不变(在濮阳街头问老板问题)
- **变量**:每次只改一个问题——第1条问"你拍短视频了吗",第2条问"最大的困难是什么",第3条问"被代运营坑过吗"……
- **不要同时改**:不要第1条在美食街拍、第2条在批发市场拍、第3条在商会拍——场地变了、问题也变了,就不知道是哪个变量影响了数据

**第11-20条(测试变量)**:
- **定量**:第35计·街头采访的形式和问题都不变
- **变量**:测试不同的开篇钩子——第1-10条的开篇是"问濮阳老板:X",第11-20条可以测试其他开篇(比如"在濮阳街头问了X个老板:X""濮阳X个老板说了同一句话:X")
- **不要同时改**:不要开篇和结尾行动指令同时改——第1-10条结尾是"你们那边也这样吗?评论区说说",第11-20条也用这个,只改开篇

### 每计测几条、看什么指标

**第35计·街头采访**:至少测10条
- **看什么指标**:
  - **完播率**:和你自己前几条比,是不是稳定在一个区间(比如前5条完播率在X%-X%,后5条也在这个区间,说明稳定了)
  - **评论区互动**:有没有濮阳本地老板留言("我也遇到过""说的就是我""能不能帮我看看")——精准人群的互动比泛粉的点赞更重要
  - **主页访问量**:发完这10条后,主页访问量有没有上涨——说明有人点进来翻你其他视频了

**第31计·地域差异**:至少测5条
- **看什么指标**:
  - **分享量**:地域差异这一计的核心是"你那边也这样吗",如果观众想知道"我那边是不是也这样",会分享给同城的人——分享量是这一计的关键指标
  - **评论区地域标签**:有没有其他城市的人留言("我们这边也是""我们这边不一样")——说明覆盖面从濮阳扩到了全国

**第10计·情境还原**:至少测3条
- **看什么指标**:
  - **私信量**:变现型内容的核心指标是私信量——有没有老板看完后私信你"我也想拍""能不能帮我看看"
  - **评论质量**:评论区是不是从"说得对""有道理"(泛泛而谈)变成"我的店也是这样""我该怎么弄"(精准询问)

### 什么信号算"这计行",什么信号算"换掉"

**第35计·街头采访算"行"的信号**:
- 连续5条完播率稳定在你自己前几条的平均值以上
- 评论区每条都有3-5个濮阳本地老板互动
- 主页访问量从X涨到X(具体数字看你自己的基准)

**第35计·街头采访算"换掉"的信号**:
- 连续5条完播率持续下降(说明观众对这个形式有审美疲劳)
- 评论区互动少、而且大多是泛粉留言("拍得好""有意思"),没有精准老板询问
- 拍摄难度越来越大(老板不愿意配合、或者你找不到新问题问了)

## 📅 30天节奏

**你的真实产能**:档案里"一人全包""常用时长15-30秒、30-60秒、1-3分钟"——按你一人的产能,街头采访一次能拍X个老板的回答、剪成1-2条视频,**一周拍两次、产出3-4条**是合理节奏(不要排成每天一条)

**第1-3天(完成前期准备)**:
- **任务**:完成定位表(已经定好了,直接用)、竞品观察(在抖音搜"短视频代运营""实体店短视频",收集20个同行账号)、风险边界(列出你的硬性禁忌:不拆解、不诋毁同行、不诋毁老板)
- **交付物**:20个对标样本(截图+链接+分析"为什么这条火了、我能不能拍")

**第4-7天(建素材库,踩点)**:
- **任务**:去濮阳街头踩点(美食街、批发市场、商会,看哪里老板多、哪个时间段适合拍)、列问题清单(至少准备10个问题:"你拍短视频了吗""最大的困难是什么""被代运营坑过吗"……)、测试拍摄(找1-2个熟悉的老板先拍一遍,测试设备和流程)
- **交付物**:问题清单10个、测试样片1-2条(不发布,只用来检查画面、声音、剪辑节奏)

## 📊 跑不通先查哪里

### 现象1:曝光少(播放量一直在两位数、三位数)

**优先怀疑**:
- **选题太窄**:你问的问题只有濮阳老板关心,陌生人看不懂——比如问"你在X批发市场进货吗"(只有本地人知道X批发市场是哪),陌生人不知道你在说什么
- **账号标签不清**:前10条内容东一榔头西一棒子(今天拍街头采访、明天拍自己讲知识、后天拍段子),平台不知道该把你推给谁

**下一步做什么实验**:
- 换更广的入口:把问题从"X批发市场"改成"你拍短视频了吗"(所有老板都能听懂)
- 连发同主题:接下来5条都用第35计·街头采访、都问老板关于短视频的问题,让平台知道你的标签是"短视频代运营+濮阳本地"

### 现象2:有曝光但前段流失(播放量有,但完播率低)

**优先怀疑**:
- **首帧弱**:第一个画面没有人、没有动作、没有字——观众不知道这是什么、该不该停下来看
- **第一句空泛**:开场说"大家好我是X""今天我来到X"——观众不知道后面讲什么,直接划走
- **承诺不清**:问了问题但没说"后面会有什么"——观众不知道继续看能得到什么

**下一步做什么实验**:
- **重写5个开篇**:第一句话直接抛结果或冲突("在濮阳街头问了X个老板同一个问题,X个人的回答让我意外""今天问到一个老板,他说的这句话我从来没听过")
- **结果或冲突前置**:不要按时间顺序讲"我先去了哪、然后遇到谁、最后问了什么",而是先说结果("X个老板都说了同一句话"),再倒回去讲过程

### 现象3:完播好但点赞高收藏低

**优先怀疑**:
- **情绪强但实用性弱**:老板的回答很有共鸣("被坑过""不知道怎么拍"),但你没有给解决方案——观众看完觉得"说得对",但不知道"我该怎么办"

**下一步做什么实验**:
- **加步骤、清单、可执行的总结**:街头采访的最后一句不要只说"我就是专门帮他们解决这个问题的",而是说"我用3招帮他们解决这个问题:第一……第二……第三……私信我,我发给你完整版"
