# 实体获客编导-不一 · 内容定位

# 💎 内容定位方案

## 长期价值主张
教县城老板看懂短视频怎么做、用真实案例证明我能帮他做成

## 内容方向：多元四类还是单一主题

**选A多元四类** + 等素材稳定后叠一个B王牌栏目

**依据**：
- 档案里写了"没时间/只能挤空档拍"、团队"一人全包"——单一主题需要源源不断的真实素材和极强执行能力，现阶段撑不住稳定更新
- 数据较好的是"讲故事/讲经历、拍工作过程"——这两种形式对应多元四类里的故事型和晒过程型，不是单一主题能覆盖的
- 真实素材还不够稳定：老客户愿意出镜，但能不能每周拍到新案例、能不能持续说服新老板配合，都不确定。多元四类策划难度低、容易拆解执行、从多个角度立住这个人（知识证明专业、故事立人设、晒过程证明能力、观点圈共鸣）

**为什么不选纯B单一主题**：
- "接受粉丝挑战帮X个老板拍第一条"这类主题策划难、执行难，需要持续有新老板愿意配合拍、愿意把店暴露在镜头前——县城老板戒心重，前期信任不够时很难说服
- 一旦某一周素材断了，账号就停更，起号节奏被打乱

**等什么时候叠B王牌栏目**：
- 流量稳定（1000粉后）、每周能稳定接到1-2个新客户询单、老客户愿意持续配合拍摄——这时候可以叠一个主题型栏目《每周帮一个濮阳老板拍第一条》，用36计·第10计情境还原做结构（真实任务 → 对话/纠错 → 旁观学习 → 结果）

## 内容配比

### 作用配比

| 作用 | 占比 | 为什么 |
|---|---|---|
| 流量型 | 60% | 刚起号、定位未确定、粉丝量级0-1万——这一阶段只有一个任务是拿稳定流量和正反馈。起号打法大多是流量型内容，零粉做到一千粉且流量稳定才算起号成功。同时用户变现方式里勾了"广告变现、带货佣金"，这两条需要大流量支撑，所以流量型必须是最大的一块 |
| 人设型 | 25% | 县城老板决策看人不看方案，档案里客人最担心的是"被同行坑过/有阴影"——他们第一反应不是"你专不专业"，是"你会不会坑我"。四分之一的内容用来讲故事、立观点，让老板看到"你是个什么样的人、和上一个代运营不一样" |
| 变现型 | 15% | 第一周就有，但只占小头——既能让精准老板看到"你能帮他做什么"，又不会让账号像广告号。**等流量稳定后（1000粉、完播率稳定在X%以上），逐步把变现型比例提到30-40%** |

### 形式配比

| 形式 | 占比 | 负责哪种作用 | 为什么 |
|---|---|---|---|
| 晒过程 | 35% | 变现型（15%全用晒过程）+ 人设型（20%里用一半） | 档案里"数据较好的内容类型"是"拍工作过程的"，这就是主力形式。晒过程离变现最近（评论多是"我该怎么弄"），同时证明"我正在做、能做成"。变现型那一块全用晒过程（拍"我正在帮某个老板做第X条"的过程）；人设型里用晒过程展示和老板、客户的关系细节 |
| 讲故事 | 25% | 人设型（25%里用一半） | 档案里"数据较好的内容类型"另一半是"讲故事/讲经历的"。县城老板信人不信数，故事最能打动他们——讲你自己的成长（怎么做代运营的、踩过什么坑）、讲帮过的老板（从不信到信的过程）、讲你的判断和边界（什么样的老板不接） |
| 知识 | 30% | 流量型（60%里用一半） | 流量型的30%用泛知识（大众听得懂、愿意转述的知识）——不是讲"怎么写开篇第一句"这种窄赛道干货，而是"濮阳老板拍短视频常犯的X个错""90%的老板不知道的短视频冷知识"，带反认知、冷知识、长见识钩子的角度，覆盖陌生人 |
| 观点+其他计 | 10% | 流量型（60%里另一半） | 流量型的另外30%用36计里的流量打法：地域差异（濮阳vs郑州的实体店短视频玩法差异）、街头采访（问濮阳老板"拍了短视频没效果"的真实原因）、整蛊反转、借势点评——这些计最容易拍、流量上限高。观点类内容（"我不认为X""我觉得X"）不作为流量主力，只做人设的补充 |

### 题材配比

- **主赛道 60%**：短视频代运营、编导方法论、实体店获客——直接和你卖的产品/服务相关
- **目标人群的兴趣 40%**（往这头靠，因为要大流量）：档案里"目标人群的兴趣"写的是消费者兴趣，但你的目标人群是老板，他们真正关心的是：
  - **生意经**：濮阳这几年哪些店火了、哪些店倒了；县城老板最怕过年的三件事；开店X年的老板都懂的X个潜规则
  - **同行对比**：郑州的代运营和濮阳的代运营差在哪；大城市的老板和县城老板拍短视频的区别
  - **本地八卦**：濮阳某条街为什么火、某个商圈为什么冷清；濮阳人的消费习惯和外地有什么不一样

### 配比核验

1. **流量型是不是和账号阶段匹配（新号是不是最大的一块）**？**是**。流量型60%，是最大的一块，符合"刚起号先拿稳定流量"的阶段策略
2. **主力形式是不是档案里数据较好的那一类**？**是**。主力形式是"晒过程35% + 讲故事25%"，就是档案里"数据较好的内容类型：讲故事/讲经历的、拍工作过程的"
3. **用户要大流量的话，行业干货是不是没当主力**？**是**。流量型主力是地域差异、街头采访、冷知识、泛知识（大众入口），窄赛道干货（怎么写开篇、怎么找选题）只作为补充，占流量型的30%
4. **题材有没有给目标人群的兴趣留出30-40%**？**是**。主赛道60%，目标人群兴趣（生意经、同行对比、本地八卦）40%
5. **每个数字都能说出"为什么是这个比例"吗**？**是**。流量型60%（刚起号+要大流量）、人设型25%（县城老板决策看人）、变现型15%（第一周就有但占小头）；晒过程35%（数据最好+离变现最近）、讲故事25%（数据最好+立人设）、知识30%（流量型一半）、观点+其他计10%（流量型另一半）

## 三种视频怎么拍

### 流量型（60%）：让更多陌生人刷到

**拍什么方向**：
1. **地域差异 + 行业对比**：濮阳vs郑州的实体店短视频玩法差异；县城老板和大城市老板拍短视频的不同打法
2. **街头采访 + 真实痛点**：在濮阳街头/批发市场/老板聚集的地方问"你拍短视频了吗？效果怎么样？"收集真实痛点

**四大脚本（薛老师）**：
- **冷知识**：反常识结论 → 证据/例子 → 原理 → "你那边也这样吗"
  - **叠爆款元素**：成本（低成本就能验证）、奇葩（反常识）
  - **示范**：标题《90%的老板不知道：短视频播放量低不是因为拍得差》| 怎么拍：开篇"你以为播放量低是因为拍得不好看，其实是开头3秒没留住人" → 举例"我帮X个老板改了开头，别的不动，播放量从X涨到X" → 原理"平台推流看的是前3秒完播，不是全片质量" → 结尾"你的视频也这样吗？评论区发链接我帮你看"

- **反认知**：反常识结论 → 大众熟悉的常规做法 → 实测或反证 → 一句话收住
  - **叠爆款元素**：反差、奇葩
  - **示范**：标题《县城老板拍短视频，越"专业"越没人看》| 怎么拍：开篇"很多老板花钱请团队、租场地、打灯光，结果播放量还不如手机随手拍" → 常规做法"以为要像广告片一样精致才有人看" → 实测"我让一个老板用手机在店里随便拍，反而火了" → 收住"县城老板的客户要的不是广告片，是真实"

**起号36计（小黄）**：

**第35计·街头采访**：一句好问题 → 追问 → 人物故事/观点 → 行业连接
- **套到这个号上是什么事件**：拿着手机在濮阳街头（或批发市场、商会、美食街）问老板"你拍短视频了吗？效果怎么样？" → 收集到的答案大多是"拍了没效果""播放量几十""不知道拍啥""没时间拍" → 追问"那你觉得问题出在哪" → 最后一句落在"我就是专门帮他们解决这个问题的，下一条我带你看我怎么帮他们拍"
- **示范**：标题《在濮阳街头问了X个老板：你拍短视频了吗》| 怎么拍：开篇直接问第一个老板"你拍短视频了吗" → 剪辑X个老板的回答（有说没拍的、有说拍了没效果的、有说不知道拍啥的）→ 最后一个老板说"你能不能帮我拍" → 你说"可以，下一条我带你看我怎么帮他拍"

**第31计·南北/地域差异**：同一任务两地做 → 差异反应 → 原因/文化 → "你那边是哪种"
- **套到这个号上是什么事件**：同样是拍短视频，濮阳老板和郑州老板的做法完全不一样 → 濮阳老板更在意"能不能来人"，郑州老板更在意"播放量好不好看" → 原因是县城是熟人社会、决策看人不看数据 → 结尾"你那边的老板也这样吗？评论区说说"
- **示范**：标题《濮阳老板和郑州老板拍短视频，差别太大了》| 怎么拍：开篇"同样是拍短视频，濮阳老板和郑州老板关心的事完全不一样" → 对比"濮阳老板第一句话问'能来几个客人'，郑州老板第一句话问'能有多少播放量'" → 原因"县城是熟人社会，老板要的不是数据好看，是真的有人进店" → 结尾"你那边的老板也这样吗？评论区说说"

**结尾行动指令**：**"你们那边也这样吗？评论区说说"**（引导评论，不要点赞收藏转发）

### 人设型（25%）：让人记住你、信你这个人

**拍什么方向**：
1. **成长故事 + 贵人相助**：讲你刚做代运营那会儿、某个老板怎么信任你、给了你机会，你怎么帮他做出效果、他后来又怎么帮你转介绍——感恩的故事最能打动县城老板
2. **价值观和边界**：讲"什么样的老板我不接、为什么不接"——立边界就是立人设

**四大脚本（薛老师）**：

- **贵人相助**：负面/意外切入 → 小善意 → 隐藏身份 → 回报反转 → 软植入
  - **示范**：标题《我刚做代运营那会儿，被一个老板救了》| 怎么拍：开篇"我刚做代运营那会儿，接了第一个客户，拍完他说不满意不给钱" → 小善意"正好被隔壁店老板听到，他说'小伙子不容易，我先给你X块，你帮我也拍一条'" → 隐藏身份"后来我才知道，他是濮阳X商会的会长" → 回报反转"我帮他做出效果后，他介绍了X个老板给我" → 软植入"所以我现在接单，先看老板人品，钱不是第一位"

- **观点立场**：亲身经历 → 我的判断 → 为什么这么看 → 邀请你怎么看
  - **示范**：标题《什么样的老板我不接》| 怎么拍：开篇"有些老板找我，我直接拒绝" → 经历"上周有个老板说'我就想花X块拍一条，能不能火'" → 我的判断"这种单我不接，因为他要的不是效果，是赌一把" → 为什么"做不出效果他会说你骗他，做出效果他会说是他运气好，你永远赢不了" → 结尾"你们遇到过这种老板吗？评论区说说"

**起号36计（小黄）**：

**第3计·以物换物**：提出交换 → 协商 → 体验 → 挖掘人物 → 情感结果
- **套到这个号上是什么事件**：找一个濮阳老板，提出"我帮你免费拍3条短视频，你请我吃顿饭" → 拍摄过程中聊天，挖掘老板的故事（为什么开店、遇到什么困难、对短视频有什么期待）→ 最后一句"这顿饭吃得值，认识了一个真实的人"
- **示范**：标题《我用3条短视频，换了一顿濮阳老板的饭》| 怎么拍：开篇"我找到一个X（行业）老板，说'我帮你免费拍3条，你请我吃顿饭行不行'" → 协商"老板说'行，但你得真帮我拍出效果'" → 拍摄过程边拍边聊，挖掘老板的故事（为什么开这家店、最难的时候是什么） → 结尾"这顿饭吃完，我不光认识了一个老板，还听到了一个X年的故事"

**第37计·身份反差**：身份预期A → 行为B → 环境自洽 → 能力/情绪结果
- **套到这个号上是什么事件**：观众以为做代运营的都是包装成"大师"、满嘴专业术语的，结果你是一个在濮阳街头、和老板吃着烧烤聊天、说大白话的县城编导 → 环境自洽（你就在老板们开店的那条街上、和他们一样的人）→ 结果是老板愿意信你
- **示范**：标题《做代运营的，不一定都西装革履》| 怎么拍：开篇"很多人以为做代运营的都是西装革履、满嘴专业术语" → 画面切到你在濮阳街头、穿着普通、和老板在烧烤摊聊天 → "我不是，我就是一个县城编导，和你们一样的人" → 结尾"所以老板们愿意和我说真话，因为我懂他们"

**结尾行动指令**：**"关注我，每周分享一个真实案例"**

### 变现型（15%）：推动咨询、到店、下单

**拍什么方向**：
1. **晒过程 + 真实案例**：拍"我正在帮某个老板做第X条"的过程，从前采、选题、拍摄到发布——让老板看到"原来是这么做的"
2. **教知识 + 案例引入**：讲"这个老板的店流量掉了，我帮他用这3招拉回来"——先给案例，再给方法

**四大脚本（薛老师）**：

- **晒过程·火车节**：起因（带钩子）→ 关键步骤 → 结果
  - **示范**：标题《帮一个濮阳X（行业）老板拍第一条》| 怎么拍：起因"这个老板说他拍了十几条，播放量都是几十，问我能不能帮他" → 关键步骤"我去他店里看了一圈，发现他拍的全是产品，没有人。我说'你得拍你自己，让客户看到你这个人'" → 结果"重新拍了一条，开头改成他的故事，播放量从X涨到X，第二天来了X个客人咨询"

- **教知识·案例引入**：有数据/冲突的案例 → 提炼方法 → 普通人怎么用
  - **示范**：标题《这个老板的店流量掉了，我用了3招帮他拉回来》| 怎么拍：案例"X（行业）老板说他的店今年流量掉了X%，问我怎么办" → 提炼方法"我帮他做了3件事：第一，重新定位他的目标客户；第二，换了拍摄场景；第三，调整了发布时间" → 普通人怎么用"你的店也流量掉了，可以试试这3招：【具体步骤】" → 结尾"你的店也这样吗？私信我，我帮你看看"

**起号36计（小黄）**：

**第10计·情境还原**：真实任务 → 对话/纠错 → 旁观学习 → 结果
- **套到这个号上是什么事件**：拍"我正在帮某个老板拍第X条"的现场，还原真实对话——老板一开始说"我想拍我的产品"，你说"产品拍了没人看，要拍你这个人" → 老板说"我不会说"，你说"不用说得好，真实就行" → 拍完后老板说"原来这么简单" → 结果是这条视频播放量X、带来X个咨询
- **示范**：标题《帮一个不会说话的老板拍第一条》| 怎么拍：真实任务"这个老板说'我不会说话，能不能只拍产品'" → 对话/纠错"我说'产品拍了没人看，你得拍你自己。不用说得好，就说你为什么开这家店'" → 旁观学习"老板想了想，说了X句话【具体内容】，我觉得特别真实，就这么拍了" → 结果"发出去播放量X，评论区好多人说'老板真实'"

**第15计·正确做法VS错误做法**：错误示范 → 后果 → 正确示范 → 原理/适用条件
- **套到这个号上是什么事件**：同样是拍老板出镜，错误做法是让老板背稿子、摆拍，结果看着很假；正确做法是让老板说真话、随便拍，反而真实 → 原理是县城老板的客户要的不是广告片，是真实的人
- **示范**：标题《老板出镜，别这么拍》| 怎么拍：错误示范"很多老板拍短视频，让老板背稿子、打灯光、穿正装，结果拍出来特别假" → 后果"播放量低、评论区全是'一看就是广告'" → 正确示范"我帮老板拍，就让他在店里、穿平时的衣服、说真话，手机随便拍" → 原理"县城老板的客户要的不是广告片，是真实的人。你越真实，他们越信你"

**结尾行动指令**：**"你的店也这样吗？私信我，我帮你看看"**（引导私信，不要到店、留资、加微信全要）

## 内容系列（2-4个）

### 系列1：《问濮阳老板》（王牌栏目，流量线主系列）

**一句话讲清**：在濮阳街头问老板同一个关于短视频的问题，收集真实痛点和答案

**定量/变量**：

## 选题来源

### 1. 知识储备（行业里的门道、外行怎么避坑）

**能长期挖的具体来源**：
- **短视频编导方法论**：怎么写开篇、怎么找选题、怎么用36计、怎么判断一条视频为什么火
  - **举例**：《老板拍短视频最容易犯的X个错》《播放量低不是因为拍得差，是因为【具体原因】》
- **代运营行业避坑**：怎么判断一个代运营靠不靠谱、被坑过的老板都踩过什么坑、什么样的承诺是骗人的
  - **举例》：《找代运营，别信这X句话》《被代运营坑过的老板，都有这X个共同点》

### 2. 经历与故事（自己的、员工的、客户的）

**能长期挖的具体来源**：
- **你自己的成长故事**：刚做代运营那会儿、第一个客户、被质疑过、被某个老板帮过、踩过什么坑
  - **举例**：《我刚做代运营那会儿，被一个老板救了》《第一次接单，客户说不满意不给钱》

### 3. 热门话题与观点（同行高赞选题、热点事件）

**能长期挖的具体来源**：
- **同行高赞选题**：在抖音搜"短视频代运营""实体店短视频"，看同行点赞高的视频在讲什么，换个角度讲
  - **举例**：同行讲"怎么写开篇"，你讲"为什么90%的老板写不好开篇"；同行讲"怎么找选题"，你讲"老板找选题最容易犯的X个错"
- **平台规则变化**：抖音、快手、视频号的算法调整、新功能上线、政策变化
  - **举例**：《抖音新规：X月X日起【具体变化】，老板要注意【具体影响】》

### 4. 实操记录（正在做的事、做的过程）

**能长期挖的具体来源**：
- **帮老板拍摄的全过程**：前采、选题、拍摄、剪辑、发布、复盘——每个环节都能拍一条
  - **举例**：《帮一个老板做前采，他说了X句话让我印象深刻》《帮一个老板选题，X分钟选出X个》
- **和老板的真实对话**：老板问的问题、老板的担心、老板的顾虑、老板的反馈
  - **举例**：《老板问我：拍短视频多久能看到效果》《老板说：我不会说话能不能拍》

## 前30条节奏

### 第1-10条（冷启动期）

**目标**：拿到第一批稳定流量，验证主力形式（晒过程 + 讲故事）是否跑得通

**做哪个系列**：
- **主力**：系列1《问濮阳老板》，占6条——流量型主系列，覆盖陌生人，扩曝光
- **辅助**：单条流量型内容（不成系列的），占4条——用36计里的冷知识、地域差异、反向操作，测试哪种钩子留得住人

**主要用哪套打法**：
- **36计是主力**：第35计街头采访（系列1）、第36计冷知识、第31计地域差异、第1计反向操作——这几计最容易拍、流量上限高、一人一机就能完成
- **四大脚本只做补充**：用冷知识的结构（反常识结论 → 证据 → 原理 → "你那边也这样吗"）来讲知识型内容，但只占这10条里的1-2条

**验收标准**：
- **完播率稳定在X%以上**（和自己前几条比，不和别人比）
- **评论区开始有本地老板互动**（"濮阳XX这边也这样""我也遇到过这个问题"）
- **主页访问量开始上涨**（说明有人点进来翻你其他视频了）

### 第11-20条（流量稳定期）

**目标**：流量稳定后，开始补人设和变现内容，让精准老板看到"你是谁、能帮他做什么"

**做哪个系列**：
- **流量型**（占6条）：系列1《问濮阳老板》继续做（占4条）+ 系列3《濮阳vs郑州》开始测试（占2条）
- **人设型**（占2条）：系列4《老板不会说的X件事》开始测试
- **变现型**（占2条）：系列2《帮濮阳老板拍第一条》开始测试（前提是有老客户愿意出镜、或者有新客户询单）

**主要用哪套打法**：
- **36计仍是流量主力**：第35计街头采访、第31计地域差异继续用
- **四大脚本开始补人设和成交理由**：观点立场（系列4）、晒过程·火车节（系列2）——让老板看到"你是个什么样的人、你正在帮别人做什么"

**加什么**：
- **开始叠爆款元素**：系列1和系列3的标题里叠反差、人群；系列2的标题里叠奇葩、最差
- **开始固定结尾行动指令**：流量型固定"你们那边也这样吗？评论区说说"，变现型固定"你的店也这样吗？私信我，我帮你看看"

## ⚠️ 不要做什么

1. **不要把自己包装成"大师"、满嘴专业术语**
   - **为什么**：县城老板看不懂"完播率、DOU+、投流策略"这些词,他们只关心"能不能来人、多久能来"。你一说术语，他们第一反应是"这人和我不是一路的"，立刻就会流失。档案里写的人设是"接地气、实战派、有温度的IP"，包装成大师和这个人设矛盾，会让人设崩塌
   
2. **不要只晒数据截图、不晒过程**
   - **为什么**：播放量截图、涨粉曲线图看起来很厉害，但老板心里想的是"这是不是假的"（P图太容易了）。档案里客人最担心的是"被同行坑过/有阴影"，他们需要看到"你是怎么帮别人做的"，而不是只给结果。只晒结果不晒过程，拿不到信任，就转化不了
   
3. **不要为了流量拍跟目标人群无关的内容**
   - **为什么**：比如拍"火的X个短视频"、拍"明星同款X"，流量会很大，但涨的全是泛粉——他们不是老板、不会找你做代运营、也不会买你的工具。等你发变现型内容时，这批泛粉看不懂、不互动，账号标签会被打乱。流量型内容要用大众入口（地域差异、街头采访、冷知识），但话题必须落在"短视频、实体店获客、老板的生意"这些和你变现相关的方向上
