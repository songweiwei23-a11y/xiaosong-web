# 万客隆家具城·李国才｜前3秒留人开篇清单

**核心原则**：家具门店视频开头最怕"欢迎光临式开场"——用户一看就是广告立刻划走。前3秒要做的是**让正在找家具的人停下来，让不找家具的人也愿意看热闹**。

---

## 一、先判断这条视频的目的

每条视频开头怎么写，取决于你这条想干什么：

| 目的 | 开头策略 | 结尾只要什么 |
|------|---------|------------|
| **流量型**（让陌生人看到） | 用反常识、冷知识、地域差异、整蛊反转这类大众入口 | 关注或评论 |
| **人设型**（让人记住你信你） | 讲你自己的故事、和客人的关系细节 | 关注或看主页 |
| **变现型**（推动咨询到店） | 晒真实场景、客户案例、专业判断，落在一个成交理由上 | 私信或到店 |

⚠️ **一条视频只选一个目的**。三个都要 = 三个都失败。

## 二、12种可以立刻用的开篇钩子（按目的分类）

### 🔥 流量型开篇（适合扩曝光、拉新粉）

#### 1. 反认知型
**公式**：否定大家习以为常的做法 → 埋下"为什么"
```
❌ "买家具要货比三家"
✅ "买家具千万别一上来就问价格——真正坑人的在你看不见的地方"
```

#### 2. 地域差异型
**公式**：同一件事，这里和别的地方不一样 → 引发好奇
```
"在濮阳买家具和在郑州买，差的可不只是运费这点钱"
```

#### 3. 冷知识型
**公式**：一个反常识的结论 → 证据
```
"为什么同样一套沙发,家具城比网上贵2000，最后买的人还是选线下？"
```

#### 4. 整蛊反转型
**公式**：铺垫 → 意外反应 → 揭晓
```
"今天遇到个客人，进门第一句话把我问懵了——他说你们这儿能不能……"（镜头切到现场）
```

#### 5. 借势点评型
**公式**：热点事件 → 专业角度拆解
```
"最近网上都在说'年轻人第一套家具别买贵的'——我干了15年，今天必须说句不中听的"
```

---

### 🧍 人设型开篇（适合立人设、建信任）

#### 6. 具体的事型
**公式**：今天/刚才发生的真实事件 → 情绪钩子
```
"刚才那桌客人走了，桌上留了张纸条——我打开一看，手都抖了"
```

#### 7. 自我否定型
**公式**：我以前以为… → 后来发现…
```
"我刚开始卖家具的时候，以为客人最在意价格——干了5年才发现，他们最怕的是这个"
```

#### 8. 身份反差型
**公式**：身份预期A → 行为B → 为什么
```
"我教了5年书，现在在家具城——很多人不理解，但我今天想说清楚"
```

---

### 💰 变现型开篇（适合推动咨询、到店）

#### 9. 痛点开场型
**公式**：场景难题 → 放大危机 → 低成本承诺
```
"准备装修的注意了：买家具最容易踩的3个坑，不少人都中招"
```

#### 10. 案例引入型
**公式**：真实案例（带冲突或数据）→ 引出方法
```
【换成你接待的真实客户：比如预算有限要配全屋的小夫妻、要装新中式的新房客户等，把你当时怎么搭配的过程拍出来】（镜头扫货架）
```

#### 11. 推荐型
**公式**：圈定人群 → 美好愿景 → 引发好奇
```
"预算3万以内想装现代轻奢风的，我今天就把我店里这几款拿出来——第3个你肯定想不到"
```

#### 12. 晒过程型
**公式**：悬念钩子 → 关键动作 → 结果
```
"今天一早去仓库，发现这批新中式刚到——我打开第一个包装的时候，真没想到……"
```

## 三、家具行业专属开篇技巧（实战补充）

### ✅ 有效开篇的4个要素
1. **第一帧有人/物/动作**：不是空镜头，不是店门口
2. **第一句话带钩子**：不是"大家好我是李老师"
3. **前5秒让人知道在等什么**：建立期待感
4. **口语化 + 细节**：说人话，不说"匠心""精心"

### ❌ 家具门店最烂开篇（立刻改掉）
```
"有需要家具的朋友看过来"
"大家好，我是万客隆家具城的李老师"
"我们这里有6大品类，欢迎咨询"
"今天给大家介绍一款新中式沙发"
```
👆 以上开头等于提醒观众：广告来了，快划走。

## 四、针对你店的3条立刻能拍的开篇示例

### 示例1：变现型·规模大（晒场景）
**钩子类型**：验证解密型  
**开篇台词**：
```
"南乐周边买家具，很多人不知道这个地方——6000平，10亩地，从新中式到通货款全都有。今天带你们转一圈，看完再决定去哪儿买。"
```
**画面**：航拍或门口全景扫到货架 → 边走边拍

---

### 示例2：流量型·反认知（教知识）
**钩子类型**：对抗/反常识型  
**开篇台词**：
```
"买家具千万别只看款式——我合伙人干了15年，今天教你看这3个地方，能省一半冤枉钱。"
```
**画面**：对镜口播 → 切到细节特写

---

### 示例3：人设型·老板好（讲故事）
**钩子类型**：具体的事型  
**开篇台词**：
```
"今天有个客人，买完家具走到门口又回来了——不是落了东西，是专门回来说了句话。"
```
**画面**：回忆场景还原 → 后续揭晓那句话是什么

## 六、下一步怎么做

1. **先定目的**：这条是拿流量、立人设还是促成交？
2. **选一个开篇类型**：从上面12种里挑最适合的
3. **填入你店的真实细节**：不编客户故事、不编数字
4. **拍3版开头**：同一个选题，试3种不同钩子，数据会告诉你哪个最有效

**记住**：开头不是用来介绍自己的，开头是用来抢流量、做筛选、进人群的。前3秒的唯一任务，就是让人停下来。
