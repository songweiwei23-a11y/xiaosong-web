# 测试_青禾家具店_全板块验收20261008 · 创作方向

## 📌 这个方向的思路

目的拆解：引流到店、卖团购 = 让本地装修家庭看到视频 → 产生"我得去店里看看真货"的念头 → 到店 → 现场成交或买团购。核心是**把线上流量转化为到店动作**。

这个账号的最大优势：有真实样柜可演示，沙发能试坐、衣柜床能拉开看尺寸，这是线上图文做不到的；老板一人、手机拍摄，成本低、能持续。最大短板：秋天是装修旺季但也是竞争最激烈的时候，同城家具店都在发视频，内容同质化严重；一人操作限制了复杂拍法。

这一批方向的分工：**用秋季装修高峰这个时间节点做钩子**，一部分方向主打流量（让更多人看到店），一部分直接推动到店（给已经在看家具的人一个来的理由），再有一部分建立"这老板靠谱"的信任。全部围绕秋天这个时令展开，不跑题。

### 方向1：秋季装修旺季的尺寸避坑演示

- **对应目的**：引流到店、卖团购（变现型为主）
  
- **内容类型**：**正确做法VS错误做法**【变现型】

- **讲法**：教知识。结构是：错误示范（秋天赶工期，很多人只看柜门忘了量抽屉）→ 后果（买回去挡床、挡门）→ 正确示范（现场演示衣柜抽屉拉开占多少位置）→ 原理（卧室多大、床摆哪、过道留多宽才够用）

- **内容方向**：拍秋季装修旺季客人最容易犯的尺寸错误，每条选一个具体场景（主卧放衣柜、次卧放床头柜、客厅沙发离电视多远），用店里的样柜真实演示正确和错误的做法对比。素材来自：店里现有的沙发、床、衣柜样柜，配合手机测距或卷尺。

- **为什么能达到目的**：秋天是装修交房高峰，本地装修家庭正在选家具，最怕买错尺寸返工。你用真实样柜演示"错了会怎样、对了怎么做"，看完的人会想"我得去店里量量我家的尺寸"——这就是到店理由。评论区留"你家卧室多大?我帮你算算够不够"，进一步引到店或私信。

- **核心思路**：抓住秋季赶工期的焦虑心理，把"怕买错"转化为"来店里验证一下"的到店动作。

- **可拍的选题示例**：
  1. 《秋天装修赶工期,很多人衣柜只看柜门不看抽屉,买回去才发现挡床》
  2. 《国庆后交房的注意了,床头柜放左边还是右边?放错一边门打不开》
  3. 《秋季装修旺季,客厅沙发离电视多远不累眼?现场拉给你看》

- **怎么拍**：
  - 形式：老板出镜,手持拍摄
  - 在哪拍：店里展厅,选一组衣柜或床的样柜
  - 需要准备：卷尺或手机测距功能,提前标记样柜的抽屉打开后占地尺寸
  - 拍摄步骤：
    1. 开头对着镜头说话（3秒）
    2. 镜头转向样柜,先展示关闭状态（2秒）
    3. 拉开抽屉,用卷尺或身体做参照（"你看,拉开后我只能侧身过"）（10秒）
    4. 镜头拉远,展示整个空间布局（5秒）
    5. 回到镜头前总结,引导评论区互动（5秒）

- **开头示范**：
  "秋天装修的注意了,挑衣柜别只看柜门好不好看,抽屉拉开占多少地方你量过吗?"

- **看什么数据**：
  - 完播率（和你自己前几条比，有提升说明节奏对）
  - 评论区有没有人问"我家卧室XX平够不够""你们店在哪"
  - 主页访问量（看完后有多少人点进主页找地址）

- **难度**：低。一人、手机、店里现成样柜就能拍,15-30秒一条,一天能拍3-5条备用。

- **节奏**：第1-2周。秋季装修旺季正当时,这个方向要抢在国庆后第一波交房潮（10月中下旬）前铺开,越早越好。

### 方向2：秋天到货/上新款的真实到店过程

- **对应目的**：引流到店、卖团购（流量型+变现型）

- **内容类型**：**软组合：用A方式做B事**【流量型】

- **讲法**：晒过程。结构是：秋季新款到货（事件）→ 老板开箱、摆放、调试样柜的真实过程 → 展示成品 → 自然引出"今天就能看,店里现货"

- **内容方向**：拍秋天进货、上新款的真实过程,不摆拍、不表演,就是老板干活的日常。每条拍一个具体动作:拆包装、组装床腿、调试沙发靠背、摆放新样柜。素材来自:店里秋季真实到货的场景(如果最近没到货,就拍调整现有样柜摆放、清理展厅迎接秋季客流高峰的过程)。

- **为什么能达到目的**：秋天是家具店的传统旺季,很多店会上新款。你拍到货过程,一方面展示"我有真货、现货",另一方面"晒过程"天然真实,观众爱看。流量起来后,评论区引导"想看的来店里,今天就摆出来了",转化到店。

- **核心思路**：用秋季到货这个真实事件做内容载体,既拿流量又证明"店里有货、不用等"。

- **可拍的选题示例**：
  1. 《秋天新款沙发到了,老板一个人搬到二楼差点闪了腰》
  2. 《国庆后进了一批实木床,组装床腿的时候发现少了一颗螺丝...》
  3. 《秋季款衣柜今天摆进展厅,你们看看这个抽屉位置合不合适》

- **怎么拍**：
  - 形式：第一人称手持,或者找个角落把手机固定拍全景
  - 在哪拍：店里展厅、仓库门口、上货的楼梯
  - 需要准备：如果最近真的有到货就拍真实场景;如果没有到货,就拍调整现有样柜、打扫展厅、准备迎接秋季客流的过程(比如"秋天客人多,我把展厅重新摆了一遍")
  - 拍摄步骤：
    1. 开头:货到了/开始干活的画面,配音说"秋天XX到了"（3秒）
    2. 过程:拆包装、搬运、组装的连续动作,不剪太碎,保留真实感（15-20秒）
    3. 结尾:成品展示,说"今天就摆出来了,想看的来店里"（5秒）

- **开头示范**：
  "秋天新款沙发到了,我一个人搬上二楼,你们看看这腰..."

- **看什么数据**：
  - 播放量（晒过程类内容天然完播率高,看能不能突破你之前的平均播放量）
  - 转发/收藏（有人觉得真实、想分享给装修的朋友）
  - 评论区问"多少钱""店在哪"

- **难度**：低。真实场景,手机拍就行,不用设计台词,过程本身就是内容。唯一要求:必须是真实发生的事,不能为了拍视频假装到货。

- **节奏**：第1-3周。如果10月中下旬真的有到货就立刻拍;如果没有到货,就拍调整展厅、准备旺季的日常,也算秋季内容。

### 方向3：秋季装修客人的真实疑问解答

- **对应目的**：引流到店、卖团购（变现型）

- **内容类型**：**互联网嘴替/替网友做**【变现型】

- **讲法**：教知识。结构是:点名秋天装修客人常问的一个具体问题 → 老板现场演示/解答 → 给出判断标准 → 引导"你家情况不一样,来店里我帮你量"

- **内容方向**：收集秋季装修客人最常问的尺寸、材质、摆放问题,每条选一个真实问题做解答。素材来自:如果店里最近真有客人问过,就复述客人的问题;如果还没客人,就自己站在装修家庭角度提问(比如"秋天空气干燥,实木家具会不会开裂")。

- **为什么能达到目的**：秋天装修的人正在选家具,他们脑子里都是具体问题("卧室10平放得下1.8米的床吗""沙发要不要买能躺的")。你把这些问题拿出来,用店里的样柜现场演示解答,看视频的人会觉得"这老板懂、能帮我解决问题",自然想到店咨询。

- **核心思路**：把秋季装修客人的真实疑问当选题,用样柜演示当解答,建立"到店找我"的信任。

- **可拍的选题示例**：
  1. 《秋天装修的都在问:卧室10平放1.8米的床,衣柜还放得下吗?我拿样柜演示给你看》
  2. 《国庆后好多人问:客厅沙发要不要买能躺的?我把店里两款拉出来对比》
  3. 《秋季装修问得最多的:实木床和板式床,哪个更适合县城的房子?》

- **怎么拍**：
  - 形式:老板出镜对着镜头讲+样柜演示
  - 在哪拍:店里展厅
  - 需要准备:提前想好3-5个秋季装修客人可能问的问题(如果店里最近真有客人问过,就记下来;如果没有,就从"卧室多大、客厅多大、家里几口人、预算多少、喜欢什么风格"这几个角度自己提问)
  - 拍摄步骤:
    1. 开头:对着镜头复述问题(3秒)
    2. 转向样柜,演示或对比(15秒)
    3. 回到镜头前总结,给判断标准(5秒)
    4. 结尾:引导"你家情况来店里说,我帮你量"(2秒)

- **开头示范**：
  "秋天装修的都在问我,卧室10平放1.8米的床,衣柜还放得下吗?我拿店里的样柜演示给你看。"

- **看什么数据**：
  - 评论区互动量(有没有人接着问自己家的情况)
  - 私信量(有没有人直接私信问尺寸、约到店时间)
  - 团购链接点击(如果视频挂了团购链接,看点击率)

- **难度**：中。需要提前收集或设想问题,对老板的表达能力有一定要求(要能把问题讲清楚、把演示讲明白)。但因为是真实问题,不用编故事,难度可控。

- **节奏**：第2-4周。前1-2周先用方向1和方向2拿到一些播放量和评论,从评论区收集真实问题,再用这个方向做解答,形成互动循环。

### 方向4：秋天县城装修的地域差异冷知识

- **对应目的**：引流到店(流量型为主)

- **内容类型**：**南北/地域差异**【流量型】

- **讲法**：教知识+冷知识。结构是:抛出一个反常识的地域差异(县城和大城市/南方和北方选家具的区别) → 展示具体差异(尺寸、材质、功能) → 解释原因(房子大小、气候、生活习惯) → 回到本地(所以咱们县城选家具要注意XX)

- **内容方向**：拍县城和大城市、南方和北方在选家具上的真实差异,每条讲一个具体点(房子大小导致尺寸要求不同、气候导致材质选择不同、生活习惯导致功能需求不同)。素材来自:老板自己的观察或常识(比如县城房子多是80-120平小三居,大城市动辄150平以上;北方干燥实木容易裂,南方潮湿板式怕发霉)。

- **为什么能达到目的**：地域差异天然有传播性,本地人看了会转发("说的就是咱们这")、外地人看了会评论("我们那不一样")。流量起来后,视频自然推给本地装修人群,再用结尾引导到店。这个方向主打流量,为后续变现内容铺路。

- **核心思路**：用秋天装修旺季+地域差异做双重钩子,先拿流量、再筛选本地精准人群。

- **可拍的选题示例**：
  1. 《秋天装修才发现,县城和大城市选家具完全不一样:大城市人挑风格,县城人挑尺寸》
  2. 《南方人秋天买家具和北方人要求不一样:南方怕潮,北方怕裂》
  3. 《县城的房子秋天装修,客厅沙发千万别买3米的,你家客厅可能只有4米...》

- **怎么拍**：
  - 形式:老板出镜对着镜头讲,穿插样柜画面
  - 在哪拍:店里展厅
  - 需要准备:提前想好2-3个真实的地域差异点(基于常识,不要编数据)。如果拿不准,就从"房子大小、气候、价格预算"三个角度切入,肯定有差异。
  - 拍摄步骤:
    1. 开头:抛出反常识结论(3秒)
    2. 展示差异:拿样柜举例或用手比划(10秒)
    3. 解释原因:说清楚为什么不一样(7秒)
    4. 回到本地:总结"所以咱们县城选家具要XX"(5秒)

- **开头示范**：
  "秋天装修的注意了,县城和大城市选家具要求完全不一样,大城市人挑风格好不好看,咱们县城人得先挑尺寸放不放得下。"

- **看什么数据**：
  - 播放量(地域差异内容传播性强,看能不能突破你的平均播放量)
  - 评论区地域标签(有没有本地人评论"对对对""就是这样")
  - 同城流量占比(如果抖音后台能看,关注同城流量有没有提升)

- **难度**：中。需要老板有一定观察能力和表达能力,能把差异讲清楚、讲得有趣。但因为是基于常识,不用查资料,难度可控。

- **节奏**：第2-3周。前1-2周用方向1和方向2打基础,积累一些本地粉丝后,再用这个方向扩大流量、吸引更多本地人关注。

### 方向5：秋季装修日常的松弛感记录

- **对应目的**：引流到店(人设型为主)

- **内容类型**：**一句话设定故事感**【人设型】

- **讲法**：晒过程。结构是:普通日常动作(打扫展厅、整理样柜、等客人、关店) + 秋天装修旺季的时间/情绪设定 → 自然展示店里环境和样柜 → 不刻意推销,只是记录

- **内容方向**：拍秋天装修旺季老板在店里的真实日常,不刻意设计情节,就是随手记录。每条拍一个生活化场景:早上开店摆椅子、中午店里没人吃外卖、下午阳光照进展厅、晚上关店前整理样柜。素材来自:店里每天都在发生的事,用手机随手拍。

- **为什么能达到目的**：这个方向不直接推销,主打"真实、松弛、接地气"的人设。秋天装修旺季大家都在硬推,你反而拍日常、不着急,观众会觉得这老板不套路、可信。积累信任后,自然会有人主动问"店在哪""想去看看"。这是长线人设方向,为后续变现打基础。

- **核心思路**：用秋天装修旺季的时间节点做背景,拍松弛感日常,建立"真实、不套路"的人设,吸引认可你的人。

- **可拍的选题示例**：
  1. 《秋天装修旺季,店里今天一个客人没来,我一个人吃外卖》
  2. 《国庆后每天都有人来看家具,今天终于能坐下歇会儿》
  3. 《秋天下午的阳光照进展厅,突然觉得这沙发摆得还挺好看》

- **怎么拍**：
  - 形式:第一人称手持或固定机位,配音或不配音都行
  - 在哪拍:店里展厅、门口、休息区
  - 需要准备:不用特别准备,就是日常该干嘛干嘛,顺手把手机支起来或拿起来拍。可以提前在脑子里设定一个情绪或小目标(比如"今天秋天第一天开窗通风""国庆后第一周有点累"),让画面有一点点故事感,但不要刻意表演。
  - 拍摄步骤:
    1. 画面:日常动作(5-10秒)
    2. 配音或字幕:一句话点出时间(秋天)和情绪(3-5秒)
    3. 画面:展示店里环境或样柜(10秒)
    4. 结尾:自然收束,不强行引导关注

- **开头示范(配音)**：
  "秋天装修旺季,店里今天一个客人没来,我一个人吃外卖。"
  (或不配音,只打字幕,画面是老板坐在沙发上吃外卖、背景是展厅)

- **看什么数据**：
  - 完播率(松弛感内容观众愿意看完)
  - 评论区情绪(有没有人说"好真实""支持""在哪")
  - 主页访问量(看完后有多少人想了解这个老板、点进主页)

- **难度**：低。不用设计情节,不用准备台词,随手拍日常就行。唯一要求:得有一点点松弛感和生活气息,不能拍成监控画面。

- **节奏**：第1-4周穿插。这个方向不着急出效果,每周拍1-2条,和方向1、2、3穿插发,长期积累人设。秋天这个时间节点天然适合拍日常(阳光好、不冷不热),不要浪费。

### 我推荐先做：方向1「秋季装修旺季的尺寸避坑演示」

- **为什么是它**：
  1. 最符合你的目的:引流到店、卖团购。这个方向直接解决秋季装修客人的尺寸担心,看完会产生"我得去店里量量"的到店冲动,转化路径最短。
  2. 最匹配你的资源:店里有沙发、床、衣柜样柜,老板一人、手机就能拍,15-30秒一条,成本低、能持续。
  3. 时间紧迫:现在是10月中旬,秋季装修旺季正当时,国庆后第一波交房潮马上到,这个方向要抢在客人做决策前铺开,晚了就错过这波流量。
  4. 风险低:教知识+晒过程,不用编故事、不用演,只要老板能把话讲清楚、把样柜演示明白就行,试错成本低。

- **第一周怎么开始**：
  1. 第1-2天:选3个秋季装修客人最容易犯的尺寸错误(衣柜抽屉挡床、床头柜门打不开、沙发离电视太近/太远),每个写一个标题,拍一条15-30秒的演示视频,用店里的样柜真实拉开、测量。

- **其他方向什么时候做**：
  - **方向2「秋天到货/上新款的真实到店过程」**:第1-2周就可以穿插做,如果店里真的有到货就立刻拍,和方向1交替发(一条演示、一条日常),增加内容丰富度。

## ⚠️ 这次先别做的

1. **客户故事/案例类内容**：档案里没有给真实客户经历,需要等真的接待了秋季装修客人、有了真实案例再拍。可以用【换成你接待的真实客户:比如最近来看衣柜的年轻夫妻、问过床头柜尺寸的客人】这样的形式做准备,但现在别编"前两天来了一对夫妻""上周有个客人"这种具体情节。

2. **价格促销类内容**("秋季大促""国庆特惠""比网上便宜XX元")：档案里没有核实价格政策和优惠,现在拍促销内容,万一说的和实际不符,客人到店发现被骗,口碑就毁了。而且促销内容同质化严重,秋天每家店都在喊促销,你喊了也淹没在信息流里。先用方向1-5建立"这老板靠谱、店里有真货"的信任,后续再根据真实经营情况决定要不要做促销。

3. **复杂剧情或多人出镜类内容**：档案明确"一人全包""不安排顾客配合表演",现在设计需要演员配合的剧情(比如模拟客人和老板对话、夫妻俩挑家具的场景)拍不出来,强行拍会显得尬。先用老板一人能搞定的演示、日常类内容起号,等后续真有客人愿意出镜了,再考虑多人内容。
