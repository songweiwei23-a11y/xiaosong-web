## 🔍 先说这一行

### 归口
**B 类（服务商 / 代运营）+ C 类（个人 IP / 知识博主）混合型**，以 B 为主线、C 为副线。
主线收入靠接本地代运营服务，副线靠卖 AI 工具和影响力（广告、带货佣金）。

### 这行的钱怎么赚
- **收费模式**：月费制（通常 2000-8000/月）或打包制（3 个月 / 半年起），客单看服务内容（只策划 vs 策划+拍摄+剪辑）
- **成本结构**：人力成本占大头（一个人全包时就是时间成本），获客成本看路径——同城自然流量几乎免费，转介绍也免费但慢，投流和地推贵且不一定精准
- **利润点**：客户续费。一个客户签 3 个月能挣一笔人工费，续约半年到一年才是真利润
- **卡点**：获客难、信任门槛高、老板配合度低（不愿出镜、没时间拍）、效果见效慢导致续约率低

### 客人的决策链路
**极长，通常 1-3 个月**。不是看完就下单，而是：
1. 刷到你某条视频 → 看主页 → 不联系，先潜水观察
2. 反复刷到你，或者生意又淡了一个月 → 翻你所有作品
3. 私信问一句"多少钱" → 你报价 → 又不回了
4. 再过一两周，或者看到你又发了客户案例 → 才真正开始聊
5. 见面或视频聊 → 小项目试水（拍 5 条、一个月） → 才可能签长期

**核心原因**：被坑过。上一个代运营收了钱、拍了十几条没效果，或者根本没用心拍。所以决策的第一关不是"你专不专业"，是"**你是不是又一个来割韭菜的**"。

### 时间规律
- **淡季最急**：每年春节后（2-3月）、暑假后（9-10月），实体店生意明显下滑，老板最焦虑，最容易想起"要不试试抖音"
- **旺季最忙没空**：节假日前（国庆、春节前一个月），老板忙着接单，没精力拍视频
- **房租到期前**：很多老板会在租约快到期（提前 1-2 个月）时重新评估要不要续租、要不要加大投入做线上，这个时刻最容易下决心

### 这行老板普遍会犯的错
1. **自嗨式专业包装**：满嘴"完播率""DOU+""精准投流"，而老板只关心"能不能来人、多久来"
2. **晒数据截图**：播放量、涨粉曲线、后台数据——老板看不懂，也不信（截图太容易 P 了）
3. **做成"大师号"**：把自己包装成高高在上的导师，和县城老板的距离感太强
4. **只讲方法论不讲人**：教怎么写脚本、怎么开篇——同行爱看,老板看不懂也不关心,他要的是"你能不能帮我"
5. **承诺过满**：一个月爆款、力求多少播放——期待错位,做不到就流失

### 同行现在都在拍什么、为什么没效果
- **数据展示流**：晒客户后台、播放量曲线 → 老板不信(截图可以造假)
- **方法论教学流**：教脚本、教开篇、教投流 → 受众是同行不是老板,老板看不懂
- **高大上包装流**：团队照、办公室、设备展示 → 距离感太强,县城老板觉得"这不是给我们这种小店做的"
- **案例轰炸流**：连发十几条"又帮一个老板做到 XX 万播放" → 看多了麻木,且没有过程,像假的

**空档在哪**：**没人在好好讲"这个人是谁、为什么值得长期信任"**。县城是熟人社会,老板要的不是大团队,是一个能长期合作、靠得住的人。讲故事、讲关系、讲人情世故的号,现在极少。

## 六维地基

### 1. 人设定位

#### 原料在哪
档案里这几句是真材料:
- "我是一个有温度的 IP、不仅仅专业度强。重感情、讲人情世故。对比金钱、更看重合作的 IP 人怎么样"
- "濮阳本土化,实战派"
- "老客户愿意出镜"

**但这些都是形容词,观众记不住**。"有温度""重感情"要翻译成具体行为:
- 可能是:接单前先聊人,不合适的钱不赚
- 可能是:客户遇到困难(不是拍摄的事)也会帮忙出主意
- 可能是:不收预付款,先干出效果再谈长期合作
- 可能是:从不诋毁同行,即使客户被坑过也不添油加醋

#### 人设标签句
**濮阳县城里、会拍故事的编导——先看人再谈钱、长期干不玩虚的**
(20 字,可复述)

#### 用了哪个入口
**地域 + 性格 + 做事方式**的组合:
- 地域(濮阳县城)是显性标签,圈精准人群
- 性格(重感情、讲人情世故)通过"先看人再谈钱"这个行为具象化
- 做事方式(长期干、不玩虚的)对标同行的"收钱不干事"

#### 验证
- **地域是否真的是优势?** 是。县城是熟人社会,本地人做本地生意,信任成本低。外地团队很难拿下县城客户
- **"先看人再谈钱"能否持续证明?** 能。每次接新客户,都可以拍一条"今天见了个老板,聊完发现……我决定接 / 不接",把选择客户的过程拍出来
- **"长期干"能否被验证?** 能。老客户续约、老客户介绍新客户、客户出镜说"合作一年了",都是证据
- **线下能保持吗?** 能。这就是你真实的做事方式,不是为了拍视频演出来的

#### 在同行里的位置
- **同行都在用什么人设?** 大师型("我教你做抖音")、数据型("我帮客户做到 XX 万播放")、团队型("专业团队、一站式服务")
- **你和他们的差别**: 你不是大师,是**县城里一个靠谱的人**;你不晒数据,晒**客户的真实反馈和长期关系**;你不是团队,就是**一个人、能长期合作**

这个差别是巨大的。县城老板怕的就是"收了钱见不到人""团队换人、对接不上""说得好听、做得敷衍"。你一个人全包、长期在本地、重人情,恰好对冲了这些恐惧。

#### 证据链
接下来靠这 4 类内容持续证明:
1. **人设型·讲故事**: 你怎么从接不到活、到老客户主动介绍;某个客户从不信到续约的过程;你拒绝过什么样的客户、为什么拒绝
2. **变现型·晒过程**: 帮客户拍视频的全流程(前采、拍摄、改稿);和客户在现场聊天的片段
3. **变现型·客户现身**: 老客户出镜讲"一开始我也不信,后来……""合作一年了,他这个人……"
4. **流量型·地域内容**: 濮阳本地的人情世故、做生意的门道、哪条街上的店火了、为什么火(带地域标签圈本地老板)

#### 边界(什么话一说人设就崩)
- 不诋毁同行(档案禁忌)。客户被坑过,你也只说"之前可能是期待没对齐",不说"那些人就是骗子"
- 不诋毁老板(档案禁忌)。客户不配合拍摄、最后流失了,也不拍出来吐槽"有些老板就是不听劝"
- 不承诺绝对效果(平台红线 + 人设逻辑)。"长期干"的前提是实事求是,不画大饼
- 不能突然高大上、突然商务范。你的人设是县城里接地气的人,穿正装、用术语、摆拍办公室,都是反向操作

### 2. 用户定位

#### 一句话画像
**开了三五年、这两年明显感觉客流在掉、自己拿手机拍过十几条没水花、被上一个代运营收过钱(或者听说过同行被坑)、不敢再信"专业团队"、但又知道不做线上迟早撑不住的濮阳县城实体店老板**

(具体到能在脑子里想起某个真实的人)

#### 为什么是他们、不是另一批
**是他们**:
- 有实体店(开了几年、有一定积累),不是刚创业的
- 生意在走下坡(有痛、有预算、愿意试),不是现在正火的
- 被坑过或听说过被坑(对"专业团队"有阴影),需要一个能长期信任的人
- 在濮阳或周边县城(你的地域优势能覆盖到的)

**不是他们**(你明确不服务谁):
- 刚开业、没钱、想免费试试的(你的时间成本耗不起)
- 期待一个月爆火、要立竿见影效果的(期待错位,做不到就流失)
- 完全不愿出镜、也不配合拍摄的(你一个人全包,但素材得客户提供)
- 外地的、需要频繁出差对接的(你的资源撑不住)

#### 他们心里真正在想什么
嘴上说的:"多少钱?效果能保持多久?你们是团队还是个人?"

**心里那句不会说的话**:"你们说得都好听。上一个代运营也是这么说的,收了钱拍了十几条,播放量两位数,最后也不回我消息了。你凭什么让我再信一次?"

这句话决定了:你的内容不能只讲"我多专业",要讲"**我和那些人不一样在哪、我怎么证明我能长期干**"。

#### 决策链路(他从刷到你到联系你,中间会做什么)
1. **刷到你某一条**(通常是流量型内容,讲濮阳本地的事、或者行业避坑)→ 看主页
2. **不联系,先潜水观察**(翻你近期所有作品,看你是不是只会说、有没有真实案例、人靠不靠谱)
3. **反复刷到你**(可能隔一两周),或者生意又淡了一个月 → 私信问一句"多少钱"
4. **你报价 → 又不回了**(回去再想想、或者去问其他人)
5. **再过一两周**,或者看到你又发了老客户出镜的视频 → 才真正开始聊
6. **见面或视频聊**(要看人) → 小项目试水(拍 5 条、一个月) → 看你是不是真的用心做 → 才可能签长期

**这决定了**: 内容要铺得够长、够稳定,不能指望一条爆款就来人。人设型和变现型的内容要反复发,让他潜水的时候翻到的每一条,都在证明"这个人长期在做、靠得住"。

#### 什么时刻会想起你
- **生意最淡的那几天**:连着一周没几个客人,老板坐在店里刷手机,这时候刷到你
- **房租快到期**:提前一两个月,老板在算账,要不要续租、要不要加大投入
- **看到同行火了**:隔壁店 / 同行的抖音突然火了,老板心里着急
- **被同行提醒**:朋友聚会、同行聊天,有人说"你们店怎么不做抖音"
- **春节后、暑假后**(淡季刚开始的时候):这时候老板最焦虑

#### 他在平台上搜什么
- "濮阳 + 抖音代运营"
- "实体店怎么做抖音"
- "短视频代运营靠谱吗"
- "抖音涨粉"(但搜完发现全是教程,看不懂,还是想找人做)
- 不会搜"完播率""投流""精准获客"这些术语

### 3. 内容定位

#### 长期提供什么价值
**让濮阳县城的实体店老板看到:有一个本地的、靠谱的人,能长期帮他把店拍出去、拍出效果**
(25 字)

#### 内容方向:多元四类
**选择 A(多元四类):知识 / 故事 / 晒过程 / 观点四类都发,从多个角度立住这个人**

理由:
- 你现在是一个人全包、时间只能挤空档,做不了需要大量外出执行的单一主题(比如"探访 100 家濮阳老店""接受粉丝挑战")
- 你的数据最好的是"讲故事 / 讲经历、拍工作过程",说明你会讲、观众信这个,但还没形成一个可以反复做的任务
- 刚起号,需要先用多种内容测试,找到最稳定拿流量 + 最能转化的组合,再逐步收窄成 1-2 个王牌栏目

**但要补一个王牌栏目**(等前 20 条测出方向后):
- 可能是"老客户说"系列(每周请一个老客户出镜,讲合作过程)
- 可能是"帮老板拍第一条"系列(记录帮新客户从 0 开始的全过程)
- 具体做哪个,看前 20 条的数据和老客户配合度

#### 当前阶段配比

##### 第一步 & 第二步:作用配比(已定好,直接用)
**流量型 60% / 人设型 25% / 变现型 15%**

**为什么这个比例适合你?**
- 你现在是**刚起号、定位未确定**,这一阶段只有一个任务:拿到稳定的流量和正反馈。零粉做到一千粉且流量稳定才算起号成功
- **流量型 60%**(最大的一块):用大众入口的内容(濮阳本地的事、行业避坑、地域差异、冷知识)拉新,让更多本地老板刷到你
- **人设型 25%**(第二大):讲你自己的故事、和客户的关系,让看过的人记住你、信你这个人。县城是熟人社会,人设比专业更重要
- **变现型 15%**(最小但必须有):从第一周就要有,晒客户案例、工作过程、专业判断,证明"我能做成"。占比小是因为起号期不能像广告号,但每周必须有 1-2 条,免得观众以为你只会说不会做

**用户的目标有调整吗?** 档案里没写要大流量 / 有影响力,变现方式也是"私域引流、线下服务"为主,说明你要的是**精准客户,不是泛粉**。但刚起号必须先有流量,所以流量型现在是最大的一块;**等粉丝到 1000 以上、流量稳定了**,再把配比调成 **变现 50% / 人设 20% / 流量 30%**(这是服务商成熟账号的标准配比)。

##### 第三步:每一块用什么形式做

**流量型 60%(主力形式:地域内容 + 冷知识 + 行业避坑)**
- **不用行业干货当主力**。"怎么写脚本""怎么拍开篇"只有同行看,天花板低
- 用这些方向拿流量:
  - **地域内容**(第31计 南北/地域差异):濮阳和外地做生意的差别、濮阳哪条街火了为什么火、本地老板的人情世故。**这是你最大的优势**,外地同行拍不了
  - **冷知识**(第36计):短视频行业的反常识(比如"播放量高不等于来客人""粉丝少的号反而更赚钱")
  - **行业避坑**(第22计):实体店做抖音最常踩的坑、代运营行业的坑(不点名、不诋毁,只讲怎么避开)
  - **街头采访**(第35计):采访濮阳本地的店老板"你做过抖音吗?效果怎么样?"(真实反应 + 你的专业点评)
- 脚本结构:按上面每一计的公式走(地域差异:A 地做法 → B 地做法 → 差异原因 → "你那边是哪种";冷知识:反常识结论 → 证据 → 原理 → 应用)
- 结尾行动指令:**关注**(别要评论,评论区可能变成同行抬杠)

**人设型 25%(主力形式:讲故事)**
- 档案里"数据最好的是讲故事 / 讲经历",这就是主力
- 拍这些方向:
  - **个人成就**(小黄结构):你怎么从接不到活、到老客户主动介绍(结果钩子 → 阻碍1:一开始没人信 → 转机1:第一个客户 → 阻碍2:客户流失 → 转机2:调整做法、老客户续约 → 感悟)
  - **知恩图报**(小黄结构):某个客户对你特别好、或者某个老板在你困难时帮过你(伪缺点:我刚开始也不懂 → 事件:这个老板教我 / 信我 → 感悟:所以我现在也这么对客户 → 实际回报:他介绍了 X 个客户给我)
  - **关系细节**:和客户的日常互动(不是工作的事,是他遇到困难你帮忙出主意、或者他请你吃饭、逢年过节的人情往来)。**县城做生意就是做关系,这些细节最能证明"你是个重感情的人"**
- 脚本结构:按上面两个公式走,核心是**找到"那一刻"**(转折点),放在中间做高潮;苦难要笑着讲,不哭诉
- 结尾行动指令:**关注**,或者引导看主页

**变现型 15%(主力形式:晒过程 + 客户现身)**
- **晒过程**(火车节模型):帮客户拍视频的全流程
  - 起因(带钩子):"今天去帮一个火锅店老板拍第一条,他说之前找过人、花了三千块没效果"
  - 关键步骤:前采(问老板最自豪的是什么)→ 拍摄(现场怎么引导老板)→ 改稿(老板提意见、你怎么调整)
  - 结果:"这条发出去,X 个播放,老板说今天来了 X 桌客人问是不是抖音上那家"(结果用客户的真实反馈,数字让客户自己说,你别编)
- **客户现身**(你最大的信任证据):
  - 老客户出镜讲"一开始我也不信,后来……""合作一年了,他这个人……"
  - 脚本结构:不要让客户背稿,就让他聊天,你问他答,剪出最真实的那几句
- 脚本结构:晒过程按火车节走;客户现身就是采访式,不要有脚本感
- 结尾行动指令:**私信**(问价格 / 问怎么合作),别要"到店"(你不是实体店)

##### 第四步:看变现产品,补够信任内容
你卖的是**代运营服务**(专业属性强、决策周期长、客单价高),客户付钱的前提是"信你这个人 + 信你能做成"。所以:
- **人设型 25%** 解决"信你这个人"(讲故事、讲关系、讲你的做事方式)
- **变现型 15%** 解决"信你能做成"(晒过程、客户现身、真实案例)
- **流量型 60%** 解决"让更多人看到"(但流量型里也要带地域标签,圈本地人,不要涨泛粉)

你的成交理由(档案里写的):**效果好、专业强、有特色、重感情、讲人情世故**。
- "效果好"→ 变现型内容里,用客户现身证明(客户说效果,比你自己说管用一百倍)
- "专业强"→ 变现型内容里,晒工作过程(前采、拍摄、改稿的细节,证明你确实懂)
- "重感情、讲人情世故"→ 人设型内容里,讲关系、讲你怎么选客户、讲长期合作的故事

##### 第五步:题材配比(人群垂直,不是赛道垂直)
**主赛道(短视频代运营) 60% + 目标人群的兴趣(实体店老板关心的事) 40%**

- **主赛道 60%**:直接讲短视频、代运营、怎么帮客户拍、客户案例
- **人群兴趣 40%**:实体店老板关心的事(不一定是抖音)
  - 濮阳本地做生意的门道、哪条街火了、怎么和客户打交道
  - 实体店怎么省成本、怎么留住老客户
  - 生意淡季怎么扛过去

**为什么要给 40% 的题材偏离主赛道?** 因为只讲短视频,天花板就是濮阳想做抖音的那几百个老板;讲他们关心的其他事,流量上限更高,且能圈到"现在还没做抖音、但迟早要做"的那批人。

**用户要大流量时往 40% 那头靠**。你现在是刚起号,流量型占 60%,所以人群兴趣那 40% 就是流量型内容的主要来源。

#### 每类内容管哪一段路

把用户从「不认识你」到「找你」拆成五步,每类内容负责哪一步:

1. **刷到**(曝光):流量型内容(地域、冷知识、行业避坑、街头采访),让本地老板刷到你
2. **记住**(留下印象):人设型内容(讲故事、讲关系),让他记住"濮阳有个会拍故事的编导"
3. **信**(建立信任):人设型(讲你的做事方式、长期关系) + 变现型(晒过程、客户现身),让他相信"这个人靠得住、能做成"
4. **翻主页**(深度了解):他潜水观察时,翻你所有作品,看你是不是只会说、有没有真实案例。**这一步决定了内容要够稳定、够真实**,不能只发流量型
5. **联系**(行动):变现型内容里的行动指令(私信),或者他看到客户现身、主动来问

**配比逻辑**:流量型(步骤1)占最大头,把人拉进来;人设型(步骤2、3)让他记住并开始信;变现型(步骤3、4、5)促成最后一步。三类缺一类,路就断了。

### 4. 呈现定位

**主要形式**:口播(你对着镜头讲) + Vlog(拍工作过程、和客户互动的现场)

**为什么?**
- 档案里数据最好的是"讲故事 / 讲经历、拍工作过程",这两种都适合口播 + Vlog
- 你是一个人全包、没团队,口播 + Vlog 是低成本、最能稳定产出的形式
- 情景剧(多人出镜、有剧本)制作成本高,你的时间和资源撑不住

**产能**:一周 4 条(每 2 天 1 条)

**依据**:
- 档案里写了"短板:没时间 / 只能挤空档拍",说明你还有其他工作(接客户、拍摄、剪辑),不能全职做自己的账号
- 一周 4 条是代运营行业的标准更新频率(不算高,但能保证稳定)
- 按你的配比,一周 4 条 = 流量型 2-3 条(60%) + 人设型 1 条(25%) + 变现型 0-1 条(15%,两周 1 条也行)

**在哪拍**:
- **口播**:濮阳本地的街头、店门口、车里、家里(生活化背景,别在纯白墙前拍,太假)
- **Vlog**:客户的店里(现场拍摄、和客户聊天的过程)、你工作的地方(剪视频、写脚本)
- **避免**:摆拍的办公室、会议室、"专业团队"的样子(和你的人设不自洽)

## ⚡ 差异化:A + 变量 B

给 3 组,每组都按"常规 A → 变量 B → A+B 长什么样"的结构:

### 第一组:同行晒数据 → 你晒关系

**常规 A**(同行最常见的):
代运营同行现在都在晒客户后台截图(播放量、涨粉曲线)、或者发"又帮一个老板做到 XX 万播放"这种纯结果展示

**变量 B**(从 24 元素里选):
**人物关系**(第 8 计·加入人物关系):让客户本人出镜,讲他和你的合作过程、对你这个人的评价

**A+B 长什么样**:
不晒截图,晒客户现身。镜头里是客户在他店里,你问他"咱们合作多久了?""一开始为什么选我?""现在效果怎么样?",他自己说。
- **具体到能拍的程度**:你去客户店里,手机拍,客户对着镜头聊天(不要背稿,就是聊天),你在镜头外问,剪出最真实的 3-5 句
- **它服务的是目标用户**:观众(潜在客户)最怀疑的是"你说的是不是真的",客户现身一句话顶你自己说一百遍。且客户说"他这个人靠谱",比你自己说"我靠谱"可信一万倍

### 第二组:同行讲方法论 → 你讲濮阳本地的事

**常规 A**:
代运营同行都在讲"怎么写脚本""怎么做开篇""完播率怎么优化"(纯方法论,受众是同行,不是老板)

**变量 B**:
**地域切换**(第 31 计·南北/地域差异):把方法论落在濮阳本地的具体事上,用地域标签圈本地人群

**A+B 长什么样**:
不讲"怎么写脚本",讲"濮阳老板和郑州老板做抖音有什么不一样"。
- **具体内容**:濮阳老板更看重人(你是谁、能不能长期合作),郑州老板更看重数据(播放量、涨粉);因为县城是熟人社会,转介绍比广告管用;所以在濮阳做代运营,先做人、再做事
- **它服务的是目标用户**:本地老板刷到这条,会觉得"这个人懂濮阳、懂我们",比讲通用方法论有共鸣一百倍。且这条能拿地域流量(抖音会推给濮阳本地用户)

### 第三组:同行只拍结果 → 你拍过程

**常规 A**:
代运营同行发客户案例,都是"帮 XX 老板做到 XX 万播放",只有结果,没有过程

**变量 B**:
**过程展示**(晒过程·火车节模型):把帮客户拍视频的全流程拍出来(前采、拍摄、改稿)

**A+B 长什么样**:
不只说"帮一个火锅店老板做到 X 万播放",拍成:
- 开头:"今天去帮一个火锅店老板拍第一条,他说之前找过人,花了三千块没效果"
- 过程:前采(你问他"你这店最自豪的是什么",他说"我们家羊肉串是自己腌的")→ 拍摄(你让他现场腌,边腌边讲)→ 改稿(老板看完说"就这个,真实")
- 结果:"这条发出去,X 个播放,老板说今天来了 X 桌客人"
- **它服务的是目标用户**:观众(潜在客户)看完全流程,能判断"你是真的懂、真的在用心做",而不是只会说。且过程里的细节(你怎么引导老板、怎么找卖点、怎么调整),证明了你的专业

## ⚠️ 这个号最大的风险

### 风险 1:老客户不愿出镜 / 配合度低
**为什么是风险**:
你的变现型内容(客户现身)是最硬的信任证据,如果老客户不愿出镜、或者出镜了不愿讲真话(只背你写的稿、或者敷衍两句),这条内容就立不起来。

**怎么规避**:
- 第一周就去问老客户:"能不能帮我拍一条?就聊聊咱们合作的过程,你觉得效果怎么样"
- 如果他不愿意,就先用"晒过程"(你帮他拍视频的全流程)替代,等合作更久、关系更铁了再拍客户现身
- 实在不行,就用"匿名案例"(不露脸、打码,只讲故事)也行,但效果会打折

### 风险 2:一个人全包,时间和精力撑不住
**为什么是风险**:
你要接客户(前采、拍摄、剪辑、改稿)+ 做自己的账号(策划、拍摄、剪辑、发布、回复评论),一周 4 条听起来不多,但加上客户的活,很容易顾此失彼。做了两个月发现自己账号断更、或者质量下滑,前功尽弃。

**怎么规避**:
- 前 3 个月,把自己账号当第一优先级(每周 4 条雷打不动),客户的活排在后面。如果客户太多接不过来,宁可少接一个,也要力求自己账号稳定更新
- 用"工作过程"做内容素材:你在给客户拍视频的过程,直接拍成自己账号的内容(一举两得)
- 降低单条制作成本:口播 + 手持拍摄,别追求精致剪辑,真实比精致重要
