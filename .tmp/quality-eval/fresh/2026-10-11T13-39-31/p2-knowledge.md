# 实体获客编导-不一 · 知识库查询

实体获客编导这类门店的短视频开头，核心难点是**你在卖的不是可视化产品，而是专业能力和结果承诺**——观众划到你，看不见米面油、看不见烤串，只有一个人在说话。前3秒如果只讲"我是做编导的""我帮商家做短视频"，观众会觉得"跟我没关系"直接划走。

## 开头的核心任务(前3秒必须完成)

**不是自我介绍,而是让老板觉得"这说的就是我现在遇到的事"**

✓ 圈出具体场景里的具体人  
✓ 点出他现在卡住的那个点  
✓ 让他产生"后面可能有解决办法"的期待

---

## 六种适合你的开头类型

### 类型1:痛点场景直击(变现型首选)

**结构:具体场景+正在发生的困境**

```
❌ 错误示范:"濮阳的实体老板们,你们拍短视频遇到困难了吗?"
   → 太泛,没有画面感

✅ 正确示范:
"拍了二十多条,每条都是自己对着镜头讲,
播放量没过500,
老板自己看着都尴尬。"
```

**适用选题方向:**
- 拍了没流量的老板
- 想做但不敢开始的老板  
- 投了本地推但转化不好的老板

---

### 类型2:反认知+身份验证(流量型+建立信任)

**结构:否定常见做法+亮出专业身份**

```
"很多老板以为拍短视频就是
把店里产品摆一摆、拍一拍,
结果拍完根本没人看——
我做了X年编导,
见过最多的就是这种。"
```

**为什么有效:**
- 第一句话就否定了大多数人在做的事→制造好奇
- 后半句亮出身份→建立"我知道怎么破局"的专业感

---

### 类型3:数据/结果对比(变现型)

**结构:改之前vs改之后,用结果说话**

```
"同一个门店,
上个月拍的视频播放不到800,
这个月换了开头方式,
第一条就破了2万。"
```

**注意:**  
- 数字必须来自你真实服务过的客户
- 如果暂时没有,写成:【换成你服务客户的真实数据:改前播放X,改后播放X】

---

### 类型4:客户真实求助场景(人设型+变现型)

**结构:还原客户来找你时说的那句话**

```
"前两天一个餐饮老板加我微信,
上来第一句话就是:
'我自己拍了一个月,粉丝涨了30个,
有28个是我自己小号。'"
```

**为什么有效:**
- 具体到一句话→观众脑子里有画面
- 这句话里藏着同类老板的共同困境→产生共鸣

**⚠️ 交稿前检查:**  
如果你还没有这样的客户真实对话,就不要编。改成:
【换成你接待客户时他说的原话:……】

---

### 类型5:地域+身份筛选(濮阳本地化优势)

**结构:明确地域+圈定人群+点出问题**

```
"濮阳开店的老板,
如果你现在正想做短视频、
但又不知道拍什么能让本地人看,
今天这条可以听一下。"
```

**适合场景:**
- 本地推投放素材
- 面向濮阳本地商家的账号内容
- 强调本土化认知的差异化卖点

---

### 类型6:避坑型(流量型+专业背书)

**结构:点名大家正在踩的坑+后果**

```
"很多老板拍视频第一句话就是
'大家好我是XX',
这种开头,
观众连1秒都不会给你。"
```

**为什么有效:**
- 第一句话就在纠正大家正在做的事→立刻有用
- 暗示"我知道对的做法"→建立专业感

---

## 你的实际操作方式(3步)

### Step1:先定这条视频的目的

- **流量型:**让更多濮阳本地商家看到你(开头用反认知、避坑型)
- **变现型:**让正在为短视频发愁的老板私信你(开头用痛点场景、数据对比)  
- **人设型:**让人记住你是"懂濮阳、实战派、有温度"的编导(开头用客户故事、地域身份)

### Step2:从上面6种里选1个开头类型

**新号起步建议:**
- 第1-5条:痛点场景(类型1)+ 避坑型(类型6)轮换→先让人停下来
- 第6-10条:加入客户故事(类型4)→开始立人设
- 稳定后:数据对比(类型3)做变现收口

### Step3:写完后过3秒测试

- 静音看首帧,能看出"这是个人在说话、不是纯文字or产品展示"→ 合格
- 只听第一句话,能听出"这在说一件具体的事/一个具体的困境"→ 合格  
- 前3秒结束,观众能回答"我在等着看什么"→ 合格

## 你最容易踩的3个坑

### ❌ 坑1:开头先介绍自己

```
"大家好我是不一,
我是一名短视频编导,
今天跟大家分享……"
```

→ 观众不关心你是谁,只关心"这条视频能帮我解决什么"

### ❌ 坑2:问观众问题

```
"你是不是也遇到过拍视频没人看?"
```

→ 观众会在心里回答"是"或"不是",然后划走。**改成陈述句,直接描述场景。**

### ❌ 坑3:开头讲大道理

```
"短视频时代,
内容为王,
流量为王……"
```

→ 空话,没有画面感,观众秒划。

---

## 给你的3句实操建议

1. **你的第一句话,必须让濮阳开店的老板觉得"这说的就是我"**  
   → 不是"各位老板",而是"拍了二十多条播放不过500的老板"

2. **开头不讲你多专业,而是讲"你见过的老板在哪里卡住了"**  
   → 专业感来自"我见过你的问题",不是"我做了X年"

3. **前3秒只做一件事:让人停下来**  
   → 讲信任、讲方法、讲成交理由,都是5秒之后的事
