# 实体获客编导-不一 · 知识库查询

# 实体获客编导类账号 · 前3秒留人技术

这类账号的难点：**观众不知道自己需要编导/代运营，所以"我是编导"这个身份不是钩子，得先圈到有痛点的人。**

---

## 一、开头死法（立刻划走的3种）

❌ "大家好我是濮阳本地的短视频编导"  
❌ "今天教大家怎么做短视频"  
❌ "想做短视频的老板看过来"

**为什么死？** 观众不觉得和自己有关 + 像广告 + 没有新信息。

---

## 二、能留人的6种开头类型（按目的分）

### 【流量型】目标：让陌生人停下来
结尾只要关注或评论，不推服务。

#### 1. 反认知钩子
**公式：否定一个行业共识 → 抛出真相**

```
"濮阳90%的实体店，短视频都白拍了。"
"别再迷信爆款文案了，我看了200个濮阳本地号，火的都不是文案好。"
"做短视频最大的坑，不是不会拍，是拍了根本没人看。"
```

**画面配合：** 对镜直视 + 坚定语气，背景可以是你工作的地方或街边（生活化场景）。

---

#### 2. 冷知识/内幕拆解
**公式：点出一个大家不知道的机制**

```
"为什么你拍的短视频，濮阳本地人刷不到？今天说清楚。"
"同样的视频，为什么别人能上热门，你的就是500播放？"
"短视频有个隐藏逻辑，90%的人不知道——平台根本不会把你推给想推的人。"
```

**注意：** 你档案写了"不揭秘内幕"，那这类开头不用"曝光""揭秘"这种词，改成"说清楚""讲明白"。

---

#### 3. 地域差异/本地化钩子
**公式：濮阳 vs 外地 → 差异点**

```
"在濮阳做短视频，和郑州、北京完全不是一回事。"
"濮阳的实体店老板，别再学外地那套了。"
"濮阳人刷短视频的习惯，和你想的不一样。"
```

**为什么有效？** 你的核心优势是"濮阳本土化"，这个开头直接圈本地老板 + 建立差异化。

---

### 【变现型】目标：推动咨询/合作
结尾只要私信或留资，必须落在一个成交理由上。

你的核心成交理由：**效果好、专业强、有特色（本土化+实战派）、有温度的IP**

#### 4. 痛点直击型
**公式：具体场景的困境 → 低成本解决承诺**

```
"濮阳很多老板找我，都是同一个问题：拍了三个月，一个客户没来。"
"实体店短视频最怕的，不是没流量，是来的都是同行和看热闹的。"
"为什么你的视频有播放、有点赞,就是没人进店？今天说透。"
```

**画面配合：** 真实工作场景（和客户聊天、看数据、写脚本），不要纯口播。

---

#### 5. 案例引入型
**公式：真实客户的困境 → 你做了什么 → 结果**

```
"上周一个濮阳做【行业】的老板找我，说拍了50条视频，一个询问都没有。我看完他的号，三句话就找到问题了。"

"有个老板花了X块找外地公司代运营，三个月涨了X粉丝，但一个濮阳本地客户都没有。后来……"
```

⚠️ **这类开头必须是真事，没有就不写。** 需要案例的地方我会给你留【换成你接待的真实客户】占位。

---

#### 6. 行业避坑型
**公式：点名一个坑 → 后果 → 怎么避免**

```
"濮阳实体店做短视频，千万别犯这个错——找外地代运营。"
"很多老板以为短视频就是拍拍发发，其实第一步就错了。"
"做短视频最容易踩的坑，不是设备不行,是根本不知道拍给谁看。"
```

---

### 【人设型】目标：让人记住你这个人
结尾只要关注或看主页，讲你的经历/关系/价值观。

#### 7. 个人故事钩子
**公式：一个转折点 → 细节 → 感悟**

```
"去年这个时候，我还在给别人打工。今天我在濮阳做短视频代运营，接的都是本地实体店老板。"

"做编导这几年,我发现一个事：濮阳的老板不缺想法,缺的是有人把想法拍出来。"
```

**画面配合：** 生活化场景（走路、吃饭、工作日常），不要正襟危坐。

## 三、实战组合公式（可以直接套）

### 公式1：地域 + 痛点 + 承诺
```
"在濮阳做实体店短视频，最怕的是【具体痛点】。今天教你【解决方案】。"
```

**示例：**
"在濮阳做实体店短视频,最怕的是拍了没人看、看了没人来。今天说三个本地老板必须知道的事。"

---

### 公式2：反认知 + 真相预告
```
"很多人以为【常见误区】，其实【真相】。"
```

**示例：**
"很多濮阳老板以为短视频就是拍产品,其实平台根本不推产品视频。"

---

### 公式3：案例 + 冲突 + 结果预告
```
"【时间】一个【行业】老板找我，【困境】。我【做了什么】，结果……"
```

**示例（需要你填真实案例）：**
"上周一个做【行业】的老板找我,说拍了三个月一个客户没来。我看完他的号,发现了一个致命问题——【你发现的问题】。"

## 四、前3秒生存清单（每条都检查）

### 视觉层（首帧画面）
- [ ] **有人**：你的脸必须在首帧出现（不要logo/产品开场）
- [ ] **有动作**：走、拿东西、转头、手势——不要静止站着
- [ ] **有环境信息**：让人一眼看出"这是在哪/干什么"（街边、店里、工作台）

### 听觉层（第一句话）
- [ ] **是钩子**：用上面6种类型之一，不是"大家好"
- [ ] **有情绪**：坚定/质疑/惊讶，不要平铺直叙
- [ ] **短**：≤15字,一口气说完

### 信息层（前3秒传递的东西）
- [ ] **圈到人**：让濮阳实体店老板觉得"这说的是我"
- [ ] **建立期待**：观众能回答"我在等什么"（等答案/等方法/等故事结果）
- [ ] **不像广告**：不提"专业编导""找我合作",流量型和人设型视频结尾也不推服务

## 五、你的差异化开头方向（基于档案优势）

你的核心优势是**濮阳本土化 + 实战派 + 有温度的IP**，开头可以这样体现：

```
"在濮阳做短视频,和在郑州、北京完全不是一回事。濮阳人的刷视频习惯、消费决策路径、信任建立方式,都不一样。"

```

## 六、3个立刻能用的完整开头（含画面）

### 开头1：流量型·反认知
**台词：**  
"濮阳90%的实体店,短视频都白拍了。不是拍得不好,是根本没拍对人。"

**画面：**  
街边走路/店门口,对镜直视,语气坚定。

**后续内容方向：**  
→ 拆解"拍对人"是什么意思  
→ 给3个判断标准  
→ 结尾：评论区说你是什么行业,我告诉你该拍给谁看

---

### 开头2：变现型·痛点
**台词：**  
"濮阳很多老板问我:为什么我的视频有播放、有点赞,就是没人进店？今天说透。"

**画面：**  
工作场景(看手机数据/和客户聊天),自然状态,不看镜头。

**后续内容方向：**  
→ 点出问题:流量≠精准流量  
→ 讲清楚濮阳本地账号的3个必做动作  
→ 结尾:想让视频真正带客户,可以私信我

---

### 开头3：人设型·故事
**台词：**  
"去年这个时候,我还在给别人打工。今天我在濮阳做短视频代运营,服务的都是本地实体店老板。这一年我明白了一个事……"

**画面：**  
生活化场景(走路/吃饭/工作日常),松弛状态,可以不看镜头。

**后续内容方向：**  
→ 讲你做这件事的初心/转折点  
→ 濮阳老板的真实困境  
→ 你能提供的不只是技术,还有本土化理解  
→ 结尾:关注我,持续分享濮阳实体店短视频实战方法

## 七、避坑清单

❌ **不要上来就自我介绍**  
"大家好我是不一" → 观众不关心你是谁,先给个停下来的理由

❌ **不要泛泛圈人**  
"想做短视频的老板看过来" → 太宽泛,改成具体痛点场景

❌ **不要所有视频都推服务**  
流量型、人设型视频结尾不要"想合作私信我",先建立信任

❌ **不要用营销腔**  
"深耕短视频""赋能实体店""倾力打造" → 用大白话

❌ **不要编数字和案例**  
没有真实客户故事就不写"上周有个老板",用【换成你的真实案例】占位

---

## 总结：3秒留人的本质

**不是让观众觉得你专业,是让观众觉得"这事和我有关"。**

- 流量型：圈痛点/反认知/冷知识 → 大范围抓人
- 变现型：具体困境+解决承诺 → 筛选高意向客户
- 人设型：真实故事+价值观 → 建立长期信任

你的优势是濮阳本土化,所以开头里一定要有"濮阳"这个地域词,直接圈本地老板。
