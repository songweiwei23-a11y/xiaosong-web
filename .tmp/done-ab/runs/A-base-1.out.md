# 6条流量型选题方案

根据您的要求，以下6条**全部为流量型**选题，覆盖南乐本地25-35岁白领、宝妈人群，基于锦园地摊串串一元火锅的真实场景设计。每条都可以一人一机完成拍摄，成本低、易执行。

## 选题1：一元火锅到底能吃到啥？我替南乐人点了一遍

**0️⃣ 视频目的**
流量型——用"一元火锅"的价格反差制造好奇，让陌生人停下来看"一块钱能吃什么"，完播后评论区讨论。

**视频任务**
让南乐及周边从没听过"一元火锅"的人停下来，看完整个点菜-上桌过程，在评论区说"我们这没有"或"在哪"。

**🅰 打法**
36计·第17计 互联网嘴替/替网友做：征集问题（很多人问一元火锅是不是坑）→ 选择任务（替大家点一遍看看）→ 亲测过程（点菜-上桌-展示每样东西）→ 结果与建议（真实一元一串，份量、品类清单）

**1️⃣ 爆款元素**
成本（"一元"的价格锚点直接命中低成本心理）

**2️⃣ 开篇钩子**
"一块钱能吃火锅？今天替南乐人点一遍，看看到底有多少东西。"

**3️⃣ 内容方向及目的（重中之重！）**
- **核心内容方向**：用一元火锅的真实点菜过程，回答"一块钱一串到底是什么、能点多少种、份量如何"
- **核心问题与观众价值**：外地人没见过一元火锅，本地人听过但没来过的想知道是不是噱头；这条用真实点菜过程消除疑虑
- **取材与内容推进**：
  1. 开场交代"一元火锅"规则（哪些是一元、哪些不是）
  2. 现场点菜：从菜单里挑一元档的品类，一边点一边展示（毛肚、鸭肠、土豆片、藕片、豆腐等）
  3. 上桌后逐个展示：每串特写，数一数一盘几串、一串多少肉/菜
  4. 结尾算一笔账：点了X样、总共X元、够X个人吃
- **事实边界**：菜单真实、价格真实；上桌后的份量现场拍，不夸大也不贬低；结尾只说"够X个人吃"（按实际拍到的量），不编顾客反馈
- **关键画面（3个）**：
  1. 手指菜单特写，口播"这一排全是一元"
  2. 上桌后每串特写，边拍边数"一盘五串"
  3. 最后一个全景：桌上摆满的串串
- **场景设置**：店内点菜区+餐桌，白天或晚上营业时段

**4️⃣ 脚本结构**
按计的公式走（互联网嘴替结构）+ 晒过程·火车节：
- 起因（带钩子）：交代任务"替大家试一元火锅"
- 关键步骤1：点菜过程，边点边说品类
- 关键步骤2：上桌展示，逐个特写
- 结果：算账，给出"够几个人吃"的结论

**5️⃣ 结尾行动指令**
"你们那有一元火锅吗？评论区说说。"（引导评论）

**6️⃣ 执行要点**
- 提前准备：挑一个不太忙的时段（下午3-5点），菜单拍清楚
- 拍摄动作：点菜时手机固定拍菜单+手指，上桌后逐个特写（横屏拍，串串占满画面）
- 口播节奏：点菜时语速快一点制造期待感，上桌后放慢，每样都说清楚
- 注意：不拍其他顾客正脸，背景虚化或只拍自己桌

## 选题2：成都师傅在南乐开店半年，发现一个秘密

**0️⃣ 视频目的**
流量型——用"外地人视角看本地"的反差制造共鸣,让南乐本地人和外地人都想看"发现了什么"。

**视频任务**
让南乐本地人停下来看"外地师傅怎么看咱们",外地人看"南乐和成都的差异",完播后评论"我们这也是"。

**🅰 打法**
36计·第31计 南北/地域差异：同一件事两地做法 → 差异反应 → 原因/文化 → 交流

**1️⃣ 爆款元素**
反差（成都 vs 南乐,外地人视角）

**2️⃣ 开篇钩子**
"成都师傅在南乐开店半年,发现一个跟成都完全不一样的事。"

**3️⃣ 内容方向及目的（重中之重！）**
- **核心内容方向**：用一个具体的饮食习惯差异(比如南乐人吃串串更爱干碟、成都人爱油碟),展示地域文化不同
- **核心问题与观众价值**：本地人想知道"外地师傅怎么看我们",外地人好奇"南乐和成都哪里不一样"
- **取材与内容推进**：
  1. 开场抛出差异点(比如"南乐客人10个有8个要干碟")
  2. 回忆成都的做法(成都串串标配油碟、很少人要干碟)
  3. 展示南乐客人的真实场景(拍一桌干碟特写、或者口播"今天X桌客人X个要干碟")
  4. 分析原因(口味偏好、气候、饮食传统)
  5. 结尾互动"你们那边呢"
- **事实边界**：差异点必须真实(出镜人确认过的),不编造数据(比如"10个有8个"要么是真实统计、要么改成"大部分");没有顾客同意不拍正脸
- **关键画面(3个)**：
  1. 成都串串店的油碟照片/视频(如有),或者手绘对比
  2. 店内一桌客人的干碟特写(背景虚化,不拍顾客)
  3. 师傅准备干碟的过程(辣椒面、花椒面、盐)
- **场景设置**：店内后厨或餐桌区,白天或晚上营业时段

**4️⃣ 脚本结构**
按计的公式走(地域差异结构)+ 聊观点·观点立场：
- 亲身经历：来南乐半年的发现
- 我的判断：这是地域口味差异,不是对错
- 为什么这么看：成都湿冷、南乐偏干,饮食习惯跟着气候走
- 邀请你怎么看："你们那边吃串串用什么碟?"

**5️⃣ 结尾行动指令**
"你们那边吃串串用啥碟?评论区告诉我。"(引导评论)

**6️⃣ 执行要点**
- 提前准备：确认一个真实的差异点(和出镜师傅聊,他来南乐后最意外的细节)
- 拍摄动作：干碟特写用手机近距离拍,背景虚化;师傅准备干碟的手部动作特写
- 口播节奏：开场抛差异点要快,中间分析放慢,结尾抛问题
- 注意：不拍顾客正脸,只拍桌面、手、背影

## 选题3：川菜师傅做了9年,头一回在这儿看见这么吃

**0️⃣ 视频目的**
流量型——用"师傅都没见过"的反差制造好奇,让本地人和外地人都想看"到底怎么吃"。

**视频任务**
让观众停下来看"到底是什么吃法",完播后评论"我们这也这么吃"或"第一次见"。

**🅰 打法**
四大脚本·教知识·冷知识型(第36计冷知识)：反常识结论 → 证据/例子 → 原理 → 应用

**1️⃣ 爆款元素**
奇葩(外行人不知道的吃法) + 人群(针对"第一次吃川味串串的人")

**2️⃣ 开篇钩子**
"做川菜9年,头一回看见有人这么吃串串,一开始我还以为点错了。"

**3️⃣ 内容方向及目的（重中之重！）**
- **核心内容方向**：展示一个本地客人的"非常规吃法"(比如把串串涮完直接蘸白糖、或者烧烤和火锅一起点混着吃),用师傅视角讲"其实也合理"
- **核心内容方向**：展示一个本地客人的"非常规吃法"(比如把串串涮完直接蘸白糖、或者烧烤和火锅一起点混着吃),用师傅视角讲"其实也合理"
- **核心问题与观众价值**：新奇吃法制造话题,让本地人产生"我也这么吃"或"太奇葩了"的讨论欲
- **取材与内容推进**：
  1. 开场抛出"奇葩吃法"(比如"有客人把毛肚涮完蘸白糖")
  2. 展示这个吃法的画面(要么现场拍到、要么事后演示)
  3. 师傅分析"为什么也合理"(比如"白糖能中和辣味,四川也有甜皮鸭这种甜辣组合")
  4. 延伸互动"你们还见过什么吃法"
- **事实边界**：吃法必须真实发生过(出镜师傅确认),没有真实案例就用"我试过一种吃法"做实验;不编造顾客对话
- **关键画面(3个)**：
  1. "奇葩吃法"的特写(比如串串蘸白糖的瞬间,或者一桌同时摆烧烤和火锅)
  2. 师傅的表情反应(惊讶或思考)
  3. 师傅演示"其实也可以"(自己试一口,点头)
- **场景设置**：店内餐桌或后厨,白天或晚上

**4️⃣ 脚本结构**
冷知识结构：
- 反常识结论：开场抛出"奇葩吃法"
- 证据/例子：展示画面,说清楚谁这么吃、怎么吃
- 原理：师傅分析为什么也合理(味觉组合、地域习惯)
- 应用：邀请观众分享"你还见过啥吃法"

**5️⃣ 结尾行动指令**
"你还见过什么奇葩吃法?评论区说说。"(引导评论)

**6️⃣ 执行要点**
- 提前准备：和出镜师傅聊,确认一个真实发生过的"意外吃法";如果没有,就设计一个"师傅自己试验"的角度(比如"我试了一下白糖蘸毛肚")
- 拍摄动作：吃法特写要拍清楚(手、碟子、串串);师傅表情用前置摄像头自拍
- 口播节奏：开场语速快,抛出"奇葩"制造冲突;中间放慢,解释原理;结尾抛问题
- 注意：不拍顾客正脸;如果是演示,要在口播里说清楚"我自己试了一下"

## 选题6：一元火锅为什么只在北方有?今天终于搞明白了

**0️⃣ 视频目的**
流量型——用"为什么只在北方"的疑问制造好奇,让南方人和北方人都想看"到底为什么"。

**视频任务**
让观众停下来看"原因是什么",完播后南方人评论"我们这没有",北方人评论"我们这常见"。

**🅰 打法**
36计·第36计 冷知识：反常识结论 → 证据/例子 → 原理 → 应用

**1️⃣ 爆款元素**
奇葩(外行人不知道的商业逻辑) + 人群(南方人 vs 北方人)

**2️⃣ 开篇钩子**
"一元火锅为什么只在北方有?今天我终于搞明白了,跟气候有关系。"

**3️⃣ 内容方向及目的（重中之重！）**
- **核心内容方向**：用"一元火锅"的商业模式,讲清楚为什么这种模式更适合北方(气候、饮食习惯、消费心理)
- **核心问题与观众价值**：南方人好奇"为什么我们这没有",北方人想知道"原来是这个原因"
- **取材与内容推进**：
  1. 开场抛出疑问"一元火锅为什么只在北方"
  2. 展示一元火锅的画面(串串、锅底)
  3. 分析原因：
     - 气候：北方冬天长、冷,火锅是刚需,低客单价能吸引高频消费

  5. 结尾互动"你觉得对吗"
- **事实边界**：原因分析基于常识和行业经验,不编造数据(比如"北方火锅店数量是南方X倍");如果不确定,改成"我觉得可能跟X有关"
