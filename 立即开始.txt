⚠️ 常见问题速查

Q: 找不到 node 命令？
A: 关闭当前窗口，打开新的 PowerShell 窗口

Q: 端口被占用？
A: npm run dev -- -p 3001 （使用 3001 端口）

Q: API 调用失败？
A: 检查 .env.local 中的 DIFY_API_KEY 是否正确

Q: 页面空白？
A: 按 F12 打开开发者工具查看错误信息
