01  商务入场   签约前

01  客户需求摸底   必做

- 了解行业类型、门店规模、营业年限、现有团队人数
- 确认核心目标：引流 / 成交 / 品牌形象，哪个优先
- 老板是否愿意出镜、能配合拍摄的频率（次/月）
- 现有平台账号状态（有无账号 / 粉丝数 / 历史内容质量评估）
- 预算范围与合作周期确认（3个月 / 半年起步）
- ⚠  这些决定了后续定位方向，必须搞清楚再提方案
02  方案/合同确认   必做

- 明确交付物清单：脚本N条 / 拍摄 / 剪辑 / 发布 / 数据报告
- 约定更新频率：推荐每周4条，约每2天1条
- 发布平台明确：抖音 / 快手 / 视频号（初期选1-2个主攻）
- 约定验收标准与汇报节点：每2-4周出1次阶段报告
- 签订合同，明确分工边界与违约条款
03  分工确认   必做

- 编导（你）：策划 / 选题 / 脚本 / 发布 / 数据 / 阶段报告
- 客户方：出镜主体 / 场地配合 / 对接人 / 素材提供
- 拍摄剪辑：明确是否包含在服务内，不含则需单独确认
- 确定日常沟通方式（群）+ 响应时间承诺（24小时内）
02  调研入场   第1周

01  前采访谈   核心

- 提前准备前采问题清单，现场全程录音存档
- 老板背景：从业年限 / 创业经历 / 最自豪的事是什么
- 产品/服务亮点：真正的差异化在哪里（顾客感受到的，不是老板以为的）
- 目标客群：现在谁在来 / 想吸引谁来（越具体越好）
- 门店故事：有没有感人的 / 有趣的真实事件或特殊顾客
- 老板最想告诉新顾客的一句话是什么
- ⚠  录音回来整理成前采文字稿——这是后续所有脚本的核心原料
02  门店实地勘察   核心

- 盘点所有可拍场景：门头 / 工作台 / 产品展示 / 服务操作全流程
- 记录特色视觉点（独特的、有记忆点的画面优先标注）
- 采集原始素材：拍摄门店环境 / 产品 / 服务过程备用
- 找出最能代表门店价值的1-3个核心画面
- 评估拍摄条件：光线 / 噪音 / 可用空间 / 是否需要补光设备
03  竞品账号研究   必做

- 搜索同行同城 / 同类账号，收集至少20个样本
- 每个账号重点看：粉丝量 / 内容类型 / 高赞视频TOP3
- 提炼爆款机制：分析为什么这条视频会火，用了哪些技巧
- 找差异化切入点：他们没做的内容方向 / 做得不好的领域
- 整理进素材库（截图 + 链接 + 分析记录）
- 从起号36计中选1-2个适合本门店的起号打法
03  账号定位   第1-2周

01  IP定位表（六维地基）   核心

- ① 人设定位：你是谁 + 特质/经历 + 能解决谁的什么问题
- ② 变现定位：卖什么 → 成交路径 → 客单价 → 必须建立的信任证据
- ③ 用户定位：场景化人群（不是泛年龄段，是「什么人在什么场景」）
- ④ 内容定位：主类型 / 辅助类型 / 配比 / 系列主题
- ⑤ 呈现定位：口播 / Vlog / 情景剧 / 展示（根据客户资源选最易执行的）
- ⑥ 风格调性：3个气质词 → 从头像到语言腔调全部统一
- ⚠  六维必须全部填写完整才能进入下一步
02  账号五件套设置   必做

- 头像：真人出镜首选（清晰有辨识度），门店LOGO备选
- 昵称：真名+职业 或 店名+地域（要能被目标人群搜索到）
- 简介：我是谁 + 能帮你什么 + 联系方式（≤60字，口语化）
- 背景图：展示核心产品 / 门店特色 / 服务场景（不放文字墙）
- 置顶作品：等有内容后，选最能代表账号价值的1-3条设置置顶
03  平台策略确定   必做

- 抖音：主攻新客引流，算法推流强，内容偏信息密度高
- 快手：老铁文化，偏真实朴素，完播率和评论互动为王
- 微信视频号：适合私域导流，内容偏分享转发向
- 初期原则：最多主攻2个平台，不要全部同时铺
- 统一发布时间：17:00-18:00（下班流量高峰前置上传）
04  内容体系搭建   第2周

01  三词根选题库建立   核心

- 人群词根（8个）：小镇青年 / 精致妈妈 / 资深中产 / Z世代 / 新锐白领 / 都市蓝领 / 银发族 / 小镇中老年
- 场景词根（12-20个）：按行业定制——朋友聚餐 / 情侣约会 / 带孩子 / 接待父母 / 下班解压 / 发工资 / 节假日……
- 行业词根（5大类）：A产品工艺 · B技术服务 · C赛道品类 · D价格成本 · E服务信任（按门店真实卖点填写）
- 公式：人群词根 × 场景词根 × 行业词根 = 选题方向（理论可生成3000+不重复选题）
- ⚠  每次生成选题后过流量性+转化性双检清单，均通过才能进脚本
02  内容配比确定（50/20/30）   核心

- 变现型 50%：教知识 / 晒过程 → 直接植入门店卖点，推动咨询/到店
- 人设型 20%：讲故事 → 拉近情感距离，建立深度信任和人格魅力
- 流量型 30%：聊观点 / 挑战 / 热点 → 扩大曝光，引进新用户
- ⚠  三类内容每周必须都有，不能只发单一类型
- 新号策略：前期可适当提高流量型比例，待账号有粉丝基础后再调整
03  18条内容计划表   必做

- 规划前18条视频（每2天1条 = 约36天内容供给）
- 每条填写：序号 / 视频目的 / 选题标题 / 脚本类型 / 拍摄要点 / 发布日期
- 检查三类配比：变现9条 / 人设4条 / 流量5条（约50/20/30）
- 预排发布日历（精确到哪天发哪条，便于提前排拍摄时间）
- 与客户确认计划，提前排好所有拍摄时间节点
04  素材库初始化   必做

- 同行爆款收藏：按内容类型（教知识/晒过程/聊观点/讲故事）分类存档
- 行业关键词库：整理行业专业术语 / 客户常问问题 / 产品卖点词汇
- 开篇钩子库：收集适合本行业的前5秒开篇方式（6大钩子各备3-5个）
- 历史客户案例：好评截图 / 前后对比 / 数据记录（后续脚本的核心素材）
- 约定每周补充5-10条新素材，素材库要持续迭代
05  单条视频生产   每条视频·5步循环

①  确定视频目的   第一步·不可跳过

- 流量型：让更多新用户看到账号（扩曝光 / 拉新粉）
- 人设型：让老粉更了解IP主体 / 建立深度信任感
- 变现型：直接推动目标用户咨询 / 到店 / 下单转化
- ⚠  每条视频只选1个主目标，三个都要 = 三个都失败
- ⚠  目的决定选题/脚本框架/结尾行动指令，不可跳过这步
②  三词根选题（5步法）   第二步

- Step1：根据视频目的确定内容角色（变现 / 人设 / 流量）
- Step2：从8个人群词根选1个本次重点覆盖的人群（S级优先）
- Step3：从场景词根库选1个（贴近近期门店真实发生的情境）
- Step4：从行业词根选1个 + 匹配脚本模式（变现→A/B，人设→C，流量→D）
- Step5：套公式生成选题标题 → 过流量性+转化性双检 → 均通过才进脚本
③  脚本框架选择   第三步

- 教知识 → 解题型（场景难题+危机+低成本解决+步骤）/ 推荐型 / 揭秘型 / 案例引入型
- 晒过程 → 过程展示（进货→成交→技术→售后）/ 任务挑战 / 测评产品 / 事件体验
- 聊观点 → 争议性开篇（否定句优先）+ 3个论据类型 + 总结归纳
- 讲故事 → 成就型 / 成功案例型（帮客户）/ 平凡英雄型 / 苦难经历型
- ⚠  选框架不等于照抄模板，必须填入门店的真实细节才有生命力
④  文案写作   第四步

- 开篇：至少写3-5版，选最强（语言钩+事件钩+场景钩，三层叠加最强）
- 前2秒目标：首帧有人/物/动作，第一句话让人停住
- 前5秒目标：观众明确「我在等什么」（建立期待感）
- 正文要求：短句 / 口语化 / 一个点说完立刻下一个（不墨迹不推拉）
- 结尾行动指令：只选1个（评论/关注/私信/到店），不能全要
- ⚠  写完后过发布前自检清单（8项），全过才能进拍摄
⑤  拍摄清单输出   第五步

- 首帧镜头：明确是什么画面 / 谁出现 / 什么状态
- 主镜头：每段文案对应的画面（逐段列出）
- 补镜头（B-Roll）：细节 / 产品 / 环境 / 过程佐证画面
- 结果镜头：最终效果展示 / 成品 / 客户真实反应
- 声音备注：哪里需要收现场声 / 哪里需要配音
- ⚠  真实情境优先，减少摆拍；故事性强的内容少剪辑干预
06  拍摄·剪辑   每次拍摄

01  拍摄执行   必做

- 提前与客户确认拍摄时间 / 所需场景 / 参与人员
- 检查：服装 / 场景 / 道具是否与人设风格一致
- 收音检查：确认人声清晰，现场噪音可控
- 优先捕捉真实发生的情境（不强迫摆拍——真实 = 最大竞争力）
- 对照拍摄清单逐条执行，确保主镜 / 补镜 / 结果镜头都有
- 多拍备用素材：关键过程和结果镜头各多拍2-3条备选
02  剪辑制作（剪映Pro）   必做

- 按脚本文案顺序排列主镜头（先粗剪出整体节奏）
- 删冗余：只保留能推动理解/情绪递进的内容（宁短勿长）
- 插入B-Roll补镜：与台词内容配套，增强真实感和视觉节奏
- 字幕：无错字，字体大小统一，颜色清晰易读
- 音乐：不压台词，配合情绪不分散注意力（快手保守选流行/纯音乐）
- 首帧检查：静音状态能看懂主要内容（大量用户不开声音刷视频）
- ⚠  故事性强的真实素材：剪辑干预越少越好，不要过度加特效
07  发布   每次发布

01  发布前自检清单（8项）   必做

- 选题：一句话清楚 / 目标人群明确 / 有新增价值
- 开篇：首帧可读 / 2秒有变化 / 5秒有期待 / 承诺能兑现
- 脚本：事实准确 / 观点有论据 / 口语自然 / 不墨迹
- 画面：人物场景道具自洽 / 关键证据看得见
- 声音：人声清晰 / 音乐不压台词
- 剪辑：删冗余 / 字幕无错字 / 转场不抢内容
- 封面标题：与视频内容一致，不标题党
- 话题标签：行业标签 + 地域标签 + 热门活动标签（3-5个）
02  三平台同步发布   必做

- 发布时间：17:00-18:00（下班流量高峰，提前上传等候审核）
- 抖音：标题 + 3-5个话题标签 + 地址定位
- 快手：标题语气略调整（更朴实直接）+ 话题标签
- 微信视频号：标题 + 引导分享到朋友圈的文案
- 发布后30-60分钟内：回复评论区留言（提升初始权重）
- 将发布时间 / 标题 / 视频ID记录到运营台账
08  数据复盘   持续运营

01  单条数据监测   必做

- 看数时间节点：发布后24h / 48h / 72h 各看一次
- 抖音核心指标：5秒完播率 / 平均观看时长 / 分享量 / 关注转化
- 快手核心指标：完播率 / 评论互动量 / 粉丝新增数
- 视频号核心指标：分享数 / 在看数 / 好友转发
- ⚠  必须用每条视频的累计数据，不用账号日维度总数据
- 记录到台账：视频ID + 发布日期 + 各平台关键数据
02  数据诊断（复盘诊断树）   核心

- 曝光少 → 选题太窄/账号标签不清/合规问题 → 换更广入口/核查合规
- 有曝光但前段流失 → 首帧弱/第一句空泛/承诺不清 → 重写开篇5版
- 前段好但完播差 → 节奏慢/钩子未续/信息重复 → 删30%内容/增加转折
- 点赞高收藏低 → 情绪强但实用弱 → 加步骤 / 清单 / 可执行总结
- 播放高关注低 → 人设缺乏系列承诺 → 固定栏目/强化身份标签
- 粉丝多咨询少 → 专业证据不足/承接入口不清 → 补案例/过程类内容
03  阶段报告（每2-4周）   必做

- 各平台累计数据汇总（总播放 / 粉丝数 / 互动趋势）
- 本阶段播放量TOP3视频 + 每条火的原因分析
- 爆款视频共同特征提炼（选题方向 / 开篇方式 / 内容类型）
- 本阶段发现的问题 + 已做的调整说明
- 下阶段优化方向 + 新18条内容计划预览
- ⚠  报告格式保持简洁，让客户3分钟内看完核心结论
04  下阶段计划迭代   核心

- 保留：爆款视频的选题方向 / 开篇方式 / 内容结构
- 修改：前段流失率高的开篇类型 / 节奏过慢的剪辑策略
- 删除：连续3条以上数据差的内容方向（停止无效尝试）
- 补充：检查三类内容配比（50/20/30），缺哪类补哪类
- 素材库更新：重点从爆款视频评论区挖掘下一批选题方向
