本文档列出大流量、人设型、变现型三类目的下的内容方向。它是**参考范围，不是清单上限**：遇到不在这里的题材，先用三种目的的定义去判断它属于哪一类，再套用同类的方法。判断依据只有三条：观众是谁、要他做什么、成功看什么指标。

每个方向都给出：**第一句钩子**（视频开头怎么说）、**结构**（中段怎么走）、**为什么符合它的目的**。方向名称只是标签，关键是钩子和结构是否符合目的。

## 一、大流量（流量型）

判断标准：观众是从没关注过你的陌生人；话题覆盖面要广；陌生人一听就懂；结尾只留关注或评论。

### 1. 反认知
- **大众以为 A，我的结论是非 A**：你以为"吃烧烤最好配冰啤酒"，其实……（结构：常识 → 反证 → 原理 → 一句反问）
- **行业潜规则揭露（有事实支撑）**：餐饮行业都知道的一件事，顾客从来不知道（结构：现象 → 幕后原因 → 怎么识别 → 评论区说说你的经历）
- **"越贵越好"颠覆**：别人都说选贵的，我劝你先看这三点（结构：常识 → 三个反例 → 结论）

### 2. 冷知识
- **一个让人意外的事实**：烧烤的烟为什么总是往一个方向飘？（结构：事实 → 原理 → 和每个人的关系 → 反问）
- **食物/生活里的隐藏知识**：超市里的某样东西，为什么生产日期要这样印（结构：现象 → 解释 → 生活应用）

### 3. 借势热点
- **借热剧情节点评**：热剧里这顿饭的场景，我拆给你看哪里是真的（结构：剧情片段 → 专业拆解 → 判断 → 回到观众）
- **借节日/天气/季节事件**：下雨天吃什么最划算，我的建议是……（结构：当下场景 → 专业建议 → 一个可执行方案）
- **借热门话题**：最近很火的某个做法，厨师看了是怎么想的（结构：话题 → 厨师视角拆解 → 结论）

### 4. 地域差异
- **同一道菜两地做法**：北方烧烤和南方烧烤的第一口区别（结构：A 地做法 → B 地做法 → 差异原因 → "你那边是哪种"）
- **不同城市的饮食习惯**：去不同城市吃串串，点单方式为什么完全不同（结构：城市甲 → 城市乙 → 原因 → 评论区互动）

### 5. 街头采访
- **一个问题问很多人**：你最怕烧烤店的哪件事？（结构：问题 → 多人回答（有反差）→ 专业收尾）
- **"你觉得这道菜多少钱合理"**：路人报价与实际成本对比（结构：问题 → 答案集合 → 成本拆解 → 结论）

### 6. 整蛊反转
- **误判反转**：顾客以为是普通烤串，结果第一口……（结构：铺垫 → 误判 → 反应升级 → 揭晓）
- **"假装不懂"的反应**：假装不会点单，看服务员怎么接（结构：设定 → 反应 → 揭晓 → 一句反问）

### 7. 挑战
- **陌生人挑战**：让路人用一块钱点一串（结构：规则 → 过程 → 结果 → 留下下一个挑战）
- **评论区选题挑战**：网友说什么菜我就用一种方式做（结构：征集 → 执行 → 结果 → 结尾关注）

### 8. 怀旧与情绪共鸣
- **一代人的记忆**：小时候街边的烧烤摊是什么样（结构：年代入口 → 细节 → 今昔对比 → 评论区回忆）
- **大家都有过的经历**：第一次一个人吃火锅（结构：共同经历 → 细节 → 情绪 → 一个问题）

### 9. 吐槽现象（非针对个人）
- **普遍的消费现象**：烧烤店排队的人为什么总是等不到位（结构：现象 → 受害场景 → 为什么荒谬 → 建议）

**大流量的禁区**：只有立场没有事件的观点输出、需要前情才懂的专业难题、只为卖货而设计的剧情。这些归入人设型或变现型。

## 二、人设型

判断标准：内容必须连着你自己的经历、成长或判断；观众看完能回答"这个人是谁，为什么值得关注"；成功看主页访问和关注。

### 1. 成长故事
- **从一个学徒到自己开店**：9年前我第一次进厨房，连一道菜都炒不好（结构：起点 → 困难 → 转折 → 现在）
- **入行的一个决定**：我放弃了一份稳定工作，选择做烧烤（结构：当时的选择 → 犹豫 → 结果 → 今天的感受）

### 2. 观点立场（连着自己的经历）
- **我的判断**：我干了9年厨师，我认为好烧烤不靠调料多（结构：亲身经历 → 我的判断 → 为什么这么看 → 邀请你怎么看）
- **争议的经历论证**：我不认为"一元火锅"是低价竞争（结构："我不认为……" → 三个自己的经历 → 总结）

### 3. 幕后与日常
- **一天的开店日常**：凌晨四点我来到市场的样子（结构：时间线 → 关键细节 → 感受）
- **员工和家人**：我妈每天帮我剁料（结构：人物 → 关系细节 → 情感收尾）

### 4. 价值观与底线
- **拒绝一件事**：有人让我用冷冻肉做现烤，我拒绝了（结构：场景 → 我的选择 → 原因 → 立场）
- **长期坚持的一件事**：我十年来每天都会尝自己做的汤（结构：习惯 → 为什么 → 对顾客的承诺）

### 5. 能力与见识
- **自己的专业经历**：我在川菜后厨学到的一个火候判断（结构：经历 → 判断 → 原理 → 感悟）
- **踩过的坑**：我开第一家店时犯过的错（结构：错误 → 后果 → 教训 → 现在怎么做）

### 6. 讲故事（剧情型）
- **一个顾客的故事**：一个常客每周三来，我们聊了一年（结构：现状 → 冲突 → 转折 → 结局）

**人设型的禁区**：没有自己经历支撑的观点、纯粹的产品介绍、以"下单""到店"为结尾的内容。这些归入变现型。

## 三、变现型

判断标准：展示你为客户做的事，观众是正在找这类服务的人；内容要有真实过程和效果；结尾只选一个动作（私信、到店或留资）。

### 1. 服务过程
- **门店一套完整的出餐流程**：一份烧烤从点单到出餐要经过哪7步（结构：流程 → 关键细节 → 效果对比 → 结尾动作）
- **食材处理过程**：一根羊肉串从进货到上签（结构：起点 → 步骤 → 品质差异 → 到店体验）

### 2. 客户案例
- **帮客户做成的事**：某家店开业三个月，我们帮它做了什么（结构：客户原状 → 介入做法 → 结果 → 结尾动作）
- **商家改造**：一家老店从冷清到排队，改了哪三个地方（结构：改造前 → 改造步骤 → 改造后 → 结尾）

### 3. 产品与菜品使用
- **一道招牌菜的做法和价值**：这道串串为什么要用这个底料（结构：问题 → 做法 → 价值 → 到店点单）
- **套餐/组合推荐**：三个人吃哪一个组合最划算（结构：场景 → 组合 → 理由 → 适用人群）

### 4. 专业判断与避坑
- **行业避坑**：选烧烤店时，这三个信号说明食材有问题（结构：点名坑 → 后果 → 识别信号 → 替代方案 → 私信咨询）
- **内幕揭秘（有服务支撑）**：外卖烧烤为什么价格比堂食低，我们做的是哪一步（结构：现象 → 幕后机制 → 我们如何做 → 到店体验）

### 5. 对比改造
- **改造前后对比**：一家店的菜单和装修改造前后（结构：改造前 → 目标 → 关键步骤 → 改造后 → 到店）
- **效果对比**：同样的食材，我们的做法和普通做法的差别（结构：普通做法 → 我们的做法 → 差别 → 到店尝）

### 6. 教知识（解题型）
- **顾客常见问题**：烧烤怎么不焦不糊（结构：场景难题 → 放大危机 → 低成本解决 → 操作步骤 → 需要帮忙时私信）

**变现型的禁区**：没有具体服务、产品或成交理由的挑战和娱乐内容。它们归入流量型。

## 四、判断一个方向属于哪一类的办法

1. 看观众：陌生人为主，属于大流量；关注者为主，属于人设型；正在找服务的人，属于变现型。
2. 看结尾：只要关注或评论，属于大流量；关注或看主页，属于人设型；私信、到店或留资，属于变现型。
3. 看内容是否连着你：没有你的经历，观点只能是流量或变现内容的一部分，不能单独做人设。
4. 看指标：非关注播放占比，属于大流量；主页访问和关注，属于人设型；咨询、线索、到店，属于变现型。
5. 钩子和结尾不一致时以结尾为准：例如用反认知句式开头（「很多人以为川菜就是辣，其实……」），结尾却引导看主页，归人设型，不归大流量。
6. 变现型结尾只能选一个动作（私信、到店、留资选其一）。「留资或到店」这类双动作写法不合格，改成其中一个。

当一个方向同时符合两类时，以**结尾动作**为准决定最终归类。
