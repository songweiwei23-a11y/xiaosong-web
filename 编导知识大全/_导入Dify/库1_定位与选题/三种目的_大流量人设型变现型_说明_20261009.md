本说明统一解释三个概念：**大流量、人设型、变现型**。它们说的是一条视频**要达成的目的**，不是脚本类型。写选题、定方向、生成脚本时，先定目的，再选方法。遇到与之冲突的旧说法，以本说明为准。

## 一、三者的定义（一句话版）

| 目的 | 一句话定义 | 成功的标志 |
|---|---|---|
| 大流量（流量型） | 让从没关注过你的陌生人看到、停下来、看完 | 非关注用户的播放占比高，完播、分享、新增关注 |
| 人设型 | 让观众认识你这个人，建立"就冲你这个人"的信任 | 主页访问、关注、评论里有人说"想看你的更多内容" |
| 变现型 | 让目标用户主动咨询、到店、下单 | 咨询、线索、到店、成交、复购 |

三者的核心区别在于**观众是谁**：流量型面向陌生人，人设型面向"认识你、愿意了解你"的人，变现型面向"正在找这类服务"的人。观众不同，选题、开头、结尾都要不同。

## 二、大流量（流量型）

### 1. 什么是大流量
大流量指**非关注用户的播放**，即平台推给从未关注过你的人的那部分。它不是粉丝数，也不是某条视频"爆了"。

平台的推荐机制（来自第三方资料综合，平台没有公开阈值，只写方向）：新视频先推给一小批人，表现好（第一秒留住人、完播、点赞评论分享、带来新关注）才进入更大的推荐池。账号粉丝数对陌生人推荐影响很小。

### 2. 选题要满足什么
- **覆盖人群广**：话题和大量普通人有关（吃饭、通勤、地域差异、大家都遇到过的事）。这是课程第17节对流量型的明确要求："流量型选题尤其需要高覆盖率。"
- **陌生人一听就懂**：不需要前情、不需要行业术语，一句话说清在讲什么。
- **有钩子**：第一秒有反差、问题或冷知识。

### 3. 可直接套用的方法
每一条都要落在一个具体事件上，不能只在标题里提一句。

- **反认知（第4计）**：大众以为 A → 我的结论是非 A → 证据预告。例："你以为……其实……"
- **冷知识（第36计）**：一个让人意外的事实 → 为什么会这样 → 和每个人的关系 → 一句反问
- **反向操作（第1计）**：常规 A → 反向 B → 真实反应或结果
- **借势点评（第12计）**：热点事实 → 专业拆解 → 判断建议 → 回到观众。课程原例：咖啡博主借一部热剧的情节做互动模仿，服装博主点评剧中穿搭，家具博主分析剧中家装风格
- **地域差异（第31计）**：A 地的做法 → B 地的做法 → 差异原因 → "你那边是哪种"
- **街头采访（第35计）**：一个问题 → 多人回答（有反差）→ 专业收尾
- **整蛊反转（第16计）**：铺垫 → 误判 → 反应升级 → 揭晓

### 4. 结尾与指标
- 结尾只要一个动作：关注，或评论（"你们那边也这样吗？评论区说说"）。不放私信、到店、留资。
- 看非关注播放占比、完播率、分享、新增粉丝，不要只看总播放量。

### 5. 不能当作大流量的内容
- 只有立场、没有事件的观点输出（"我觉得……""我不认同……"）。观点主要被已经关注你的人看，陌生人没有理由停下来。
- 只有专业难题、需要前情才懂的内容。它们的覆盖面小，属于人设型或变现型。

## 三、人设型

### 1. 什么是人设型
人设型讲的是**你这个人**：你的成长、经历、判断、立场。目的是让观众记住你、信任你，愿意持续关注。

### 2. 选题要满足什么
- 内容必须连着**你自己的经历**。没有经历支撑的观点，只是立场，立不起人设。
- 观众看完能回答："这个人是谁，他为什么值得我关注？"

### 3. 可直接套用的方法
- **讲故事**：现状铺垫 → 困境冲突 → 转折 → 结局。课程原例：创业夫妻的真实历程，讲押上养老房借款、怀孕仍在工厂、陪喝到半夜签单等细节，塑造"搭档"形象。
- **观点立场**（观点必须连着经历）：亲身经历 → 我的判断 → 为什么这么看 → 邀请你怎么看
- **观点并列 / 争议开篇**（论据必须是自己的经历）：提出观点 → 论据 1/2/3 → 总结强化；"我不认为……" → 3 个论据 → 总结归纳

### 4. 结尾与指标
- 结尾可以是关注、看主页、看下一条。
- 看主页访问、关注转化、评论里"就冲你这个人"的反馈。

### 5. 与课程原文的说明
课程第17节把"人设型"定义为讲述 IP 的成长故事、工作经历，塑造个人形象，这与上面一致。观点类内容归入人设型，是因为它要靠经历立人设，而不是靠陌生人的覆盖面。

## 四、变现型

### 1. 什么是变现型
变现型展示**你为客户做的事**，目的是推动目标用户咨询、到店、下单。它的观众是"正在找这类服务的人"。

### 2. 选题要满足什么
- 展示的是**真实的服务过程、客户案例、效果对比**。
- 观众看完能回答："这个服务怎么做，效果怎么样，我要怎么找你？"

### 3. 可直接套用的方法
- **晒过程**：真实服务步骤 → 关键细节 → 结果对比
- **教知识（解题型）**：用户的具体问题 → 解决方法 → 注意事项 → 需要帮忙时怎么找你
- **客户故事**：客户原来的状况 → 介入的做法 → 变化结果（要真实，不编造）

### 4. 结尾与指标
- 结尾只选一个动作：私信、到店或留资。不要同时要三个。
- 看咨询、线索、到店、成交、复购。

### 5. 与课程原文的说明
课程原文把变现型定义为"展示为客户做的事情，讲客户的故事，促进转化"，与上面一致。课程原文的一个变现型案例是"挑战类"内容，它更接近流量打法，本说明不采用这一归类。挑战类内容要归变现，必须带出具体服务或产品。

## 五、三者怎么选

| 你的目标 | 选哪种目的 | 主力方法 | 结尾 |
|---|---|---|---|
| 让更多陌生人知道你 | 大流量 | 反认知、冷知识、借势、地域差异、街头采访、整蛊反转 | 关注或评论 |
| 让观众记住你、信任你 | 人设型 | 讲故事、观点立场 | 关注或看主页 |
| 让目标客户来咨询、到店 | 变现型 | 晒过程、教知识、客户故事 | 私信、到店、留资，只选一个 |

一个账号通常需要三者都有，但每条视频只能有一个主目的。新号前期可以多做大流量，积累基础数据后再增加人设和变现内容。

## 六、选题前的检验清单

1. 这条视频的目的是哪一个？（只能选一个）
2. 目标观众是谁？陌生人、粉丝，还是正在找服务的人？
3. 选题能不能一句话说清？陌生人能不能看懂？
4. 开头有没有对应目的的钩子？（流量：反差或冷知识；人设：经历；变现：问题或效果）
5. 结尾是否只做一个动作，并且和目的一致？

## 七、旧说法的处理

- 「流量型 = 聊观点」「流量型主力是聊观点」「模式D·聊观点型，主力流量型」：作废。
- 「聊观点（多为流量型）」：作废，观点类归人设型。
- 「争议性内容属于流量型」（课程第17节的概括）：有条件保留。只有反认知型的争议（颠覆大众常识、有事实支撑）属于大流量；单纯站队、没有事件的争议观点归人设型。
- 「三十六计大多是流量型」：保留，这是起号打法的整体归类。
- 「脚本类型不等于目的」：保留。同一种脚本，可以服务于不同目的。
