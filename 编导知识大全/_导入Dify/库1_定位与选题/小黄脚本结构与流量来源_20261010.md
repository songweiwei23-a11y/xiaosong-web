# 小黄脚本结构与流量来源

本文整理小黄编导方法论中，选题和脚本的主线：三种目的、十大爆款方向、脚本结构库。它是创作的主轴；薛老师的四大脚本只作为补充。

## 一、流量从哪里来

教知识本身不是流量。把行业干货讲得更细，受众窄、流量上限低。流量来自以下十大爆款方向（用户动力 → 可套问题）：

| 方向 | 用户动力 | 可套问题 |
|---|---|---|
| 解决痛点 | 立刻有用 | 用户最急、最频繁、最贵的问题是什么？ |
| 行业避坑 | 损失厌恶 | 新手最容易在哪一步吃亏？ |
| 反认知 | 惊讶与讨论 | 大众相信但证据不足的结论是什么？ |
| 丰富谈资 | 社交货币 | 什么知识能让用户转述给别人？ |
| 内幕揭秘 | 窥探欲 | 行业怎样运转、钱在哪里赚？ |
| 推荐建议 | 省时间 | 哪些工具、人、产品值得选？ |
| 变得更好 | 向往 | 怎样从当前状态到理想状态？ |
| 共鸣观点 | 被理解 | 目标人群想说却没说出口什么？ |
| 不同视角 | 新解释 | 换身份、收入、地域后结论如何变化？ |
| 个人故事 | 情感与信任 | 哪个成就、挫折、贵人或遗憾最能证明你？ |

判断标准：覆盖是否足够广；是否提供明确价值（有用、有趣、有共鸣、猎奇、长见识、情绪释放）；是否比用户多一步认知（新证据、新解释、新方法或新视角）。

## 二、三种目的

| 目的 | 典型选题 | 成功指标 |
|---|---|---|
| 流量型 | 反认知、冷知识、借势热点、地域差异、街头采访、整蛊反转 | 非关注播放占比、停留、分享、新粉 |
| 人设型 | 成长故事、职业经历、关系细节；观点立场 | 主页访问、关注、评论质量 |
| 变现型 | 客户过程、案例结果、产品使用 | 咨询、线索、成交、复购 |

受众扩展的做法：用大众入口承载专业解释。例如同一个咖啡专业内容，从「咖啡豆挑选」扩到「各国咖啡优缺点」，再到「连锁品牌的咖啡豆秘密」。扩大覆盖不是抛弃专业。

## 三、脚本结构库（小黄）

| 结构 | 骨架 | 适用 |
|---|---|---|
| 案例引入型 | 有数据或冲突的案例 → 提炼知识 → 普通人怎么用 | 变现型；抽象知识难懂时 |
| 痛点型 | 描述难题 → 低成本承诺 → 具体步骤 | 变现型；教程、解决方案 |
| 推荐型 | 利益/好奇/美好未来 → 推荐对象 → 理由与适用条件 | 变现型；工具、产品、账号 |
| 晒过程 | 钩子 → 关键步骤 → 明确结果 | 变现型；挑战、体验、改造、测评 |
| 个人成就 | 结果钩子 → 阻碍1 → 转机1 → 阻碍2 → 转机2 → 感悟 | 人设型；创业、成长、逆袭 |
| 贵人相助 | 负面或意外切入 → 小善意 → 隐藏身份 → 回报反转 → 软植入 | 人设型；探店、品牌故事 |
| 知恩图报 | 伪缺点 → 事件验证 → 感悟 → 实际回报 | 人设型；员工、客户、陌生人故事 |
| 世俗偏见 | 确立偏见 → 误解 → 消除 → 再误解/消除 → 反思升华 | 人设型；人物纪录、人文 |
| 观点并列 | 提出观点 → 论据1/2/3 → 总结强化 | 人设型；论据必须是自己的经历 |
| 观点正反 | 提出观点 → 正反对比 → 强化结论 | 人设型；争议话题，避免污名化 |

故事节奏：短视频通常两组「阻碍—转机」已足够，三组以上容易拖长。结果前置、细节验证、情绪起伏、结尾回收，比堆金句更重要。

## 四、36 计与目的的对应

- 流量型的计：反向操作、冷知识、借势点评、地域差异、街头采访、整蛊反转。直接按这一计的公式拍，结构落在事件上，开头要有反常识、意外或冲突。
- 人设型的计：讲故事类的计，配个人成就、贵人相助、世俗偏见；观点类内容归这里。
- 变现型的计：配案例引入、痛点型、推荐型、晒过程。

## 五、使用原则

1. 每条视频只选一个主目的，结尾只做一个行动。流量型结尾只能是关注或评论。
2. 教知识只放变现型。流量型只有带反认知或冷知识钩子时才用教知识的形式。
3. 观点不是流量。观点要连着自己的经历，归人设型。
4. 选题先从十大爆款方向找角度，再套 36 计的公式；四大脚本的爆款元素作为补充。
5. 不编造数字、客户故事和效果。缺的信息用待核实占位。
