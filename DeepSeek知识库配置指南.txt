# DeepSeek知识库配置完整指南

## 步骤1: 获取DeepSeek API Key（2分钟）

1. 打开浏览器访问: https://platform.deepseek.com/
2. 点击右上角"注册/登录"
3. 完成注册（支持手机号）
4. 进入控制台
5. 点击左侧"充值"，充值¥10（推荐¥50更划算）
6. 点击左侧"API Keys"
7. 点击"创建新密钥"
8. 复制API Key（格式：sk-xxxxx）

## 步骤2: 在Dify中配置DeepSeek（1分钟）

1. 在您的截图界面
2. 找到"深度求索"那一栏
3. 点击右侧的"添加我的 API Key"蓝色按钮
4. 粘贴刚才复制的API Key
5. 点击"保存"
6. 看到"已配置"标记

## 步骤3: 修改知识库使用DeepSeek（2分钟）

1. 点击Dify左侧菜单的"知识库"
2. 找到您的知识库（比如"编导知识库"）
3. 点击知识库名称进入
4. 点击右上角的"设置"或"⚙️"图标
5. 找到"Embedding模型"设置
6. 从下拉菜单选择"深度求索"
7. 如果有"Rerank模型"，也可以选择"深度求索"或"关闭"
8. 点击"保存"

## 步骤4: 测试（1分钟）

1. 回到您的应用
2. 测试知识库查询功能
3. 检查是否正常工作
4. 不再提示"AI消息已用尽"

## 常见问题

Q: DeepSeek支持哪些功能？
A: 支持文本生成、Embedding、知识库检索

Q: 如果余额不足怎么办？
A: 登录DeepSeek控制台充值即可

Q: 会影响生成质量吗？
A: DeepSeek的Embedding质量很好，特别是中文

Q: 已有的知识库需要重新向量化吗？
A: 不需要，只影响新添加的文档
