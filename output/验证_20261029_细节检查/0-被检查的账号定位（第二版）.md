## 🔍 先说这一行

- **归口**：A 类本地实体店中的**餐饮食品**，更准确说是“本地流动热菜摊”。它不是传统坐店餐馆，核心竞争不在环境和等位体验，而在“人在赶时间时，能不能快速买到一份看得见的热菜”。

- **这行的钱怎么赚**：  
  这类生意不是靠单次高客单，而是靠午餐、晚餐的高频复购，以及家庭打包带来的连带购买。成本压力通常卡在食材、人工、损耗和没卖完的菜；尤其流动摊位，菜做多了有损耗，做少了又会错过需求。  
  这家已有“销情上下架、滞销撤除、老客点名保留”的做法，说明它真正该拍的不是“菜很多”，而是“每天这批菜为什么留下、为什么撤掉”。

- **客人的决策链路**：  
  决策很短。白领午休和下班后的家庭用餐，往往是“刷到—记住—路过或需要时去找”的链路，不会像装修、医美一样反复比较很久。  
  但第一次到摊前仍有两个门槛：**这菜是不是现做的、买起来会不会麻烦**。所以视频先解决“看得见的新鲜和效率”，再谈消费。

- **时间规律**：  
  中午是工作餐场景：时间紧、选择快、倾向一荤一素；晚上是家庭带菜场景：选择更多、会看菜品搭配与是否方便。  
  秋季到年底，晚间家庭打包、下班热菜需求通常更容易被放大；但具体哪天卖得快、哪些菜容易售完，必须由老板用真实售卖记录确认，不能凭感觉写死。

- **这行老板普遍会犯的错**：  
  第一，把镜头对着一排菜拍到底，以为“菜多”就有吸引力；观众只会觉得像路过摊位，记不住。  
  第二，只讲“便宜、量大”，把自己拍成低价摊。这个客户明确不打价格战、不做引流款，不能走这条路。  
  第三，硬拍温情顾客故事。客户已经明确不想看煽情，这类内容既不匹配老板，也不匹配摊位的烟火节奏。

- **同行现在都在拍什么**：  
  同类内容常见做法是菜品扫镜头、价格字幕、出餐特写、顾客买菜片段。大多没效果，不是菜不好，而是前几秒没有一个观众能代入的场景。  
  这个号的空档应是：**把“午休赶时间”“下班不想做饭”“今天吃什么”的真实处境，装进现做热菜的现场里。** 菜是画面，人的选择困难才是入口。

## 🗣 我会先问老板的几个问题

- **问题**：最近一次有顾客觉得菜不合适，具体是什么菜、对方怎么说、最后怎么处理？
  - **我的推测**：可能不是口味争议，而是顾客对辣度、肥瘦、分量或菜品卖完有预期差。这个行业最能建立信任的，不是“从不出问题”，而是问题出现时摊主怎么当场回应。
  - 待老板确认。

- **问题**：哪一道菜曾经卖得不好，后来为什么撤了？哪位老客点名要留？
  - **我的推测**：红烧肉、酥鱼等有固定受众，滞销菜被撤下，说明老板不是为了凑菜品数量，而是根据真实购买在调整。这是“摊位每天活着”的内容素材。
  - 待老板确认。

- **问题**：顾客选择这里时，实际最看重的是什么？有没有顾客说过具体原因？
  - **我的推测**：需要通过顾客原话确认，他们更在意的是菜品本身、购买是否省事，还是其他具体原因。老板的专业背书和顾客实际感受到的价值，未必是一回事。
  - 待老板确认。

- **问题**：老板娘一天里最常被问的一句话是什么？原话是什么？
  - **我的推测**：中午可能集中在“怎么配一荤一素”“这个辣不辣”；晚上可能集中在“还剩什么”“这个适合带回家吗”。这些重复问题可以直接变成视频开头。
  - 待老板确认。

- **问题**：坚持不打价格战、不做引流款，具体是因为哪一次经历或哪种判断？
  - **我的推测**：这不是一句口号，背后应有真实的经营边界：宁可少做某种低价吸引，也不愿把现做现售热菜拍成只看低价的商品。
  - 待老板确认。

- **问题**：合伙厨师亲手做的哪一步最有辨识度？能拍到什么动作和结果？
  - **我的推测**：现做热菜的可信度，需要落在切、炒、焖、收汁、出锅等真实动作上；“合伙厨师从业10余年，持有行业资质奖牌”是背书，不能代替过程证据。
  - 待老板确认。
## 一句话定位

> **流动摊热菜老板娘：现做热菜、红烧肉、鸡爪、酥鱼、面筋、干煸豆角、毛血旺、麻辣香锅，替赶时间的人少操一顿饭。**

说明：8 个经营品类合计已占较多字数，无法同时满足“8 个品类原样出现”和“不超过 30 字”两项要求；这里优先满足品类完整这一硬约束。  
这句话的立场是：不替观众制造“今天吃什么”的麻烦，而是让赶时间的人看到一份可直接带走的现做热菜。

## 六维地基

### 1. 人设定位

- **原料在哪**：  
  有价值的真实材料是：  
  - “老板娘表示不打价格战、不做引流款，坚持货真价实的定价。”  
  - “菜品会根据销情上下架，滞销的撤除，有回头客点名的保留。”  
  - “合伙厨师从业10余年，持有行业资质奖牌。”  
  - “生活已经够压抑了，不想看煽情，也不要讲温馨故事。”  

  “轻松、幽默、接地气、真实有烟火气”是风格形容词，不是人设。  
  翻译成可见行为，就是：**不拿低价喊话，不拿煽情换眼泪，拿每天卖什么、撤什么、做什么说话。**

- **人设标签句**：  
  **不打价格战的流动热菜老板娘**

- **用了哪个入口**：  
  **性格 + 痛点与职业**。  
  性格是“有边界，不靠低价和煽情拉人”；职业是“流动热菜摊主”；对应用户痛点是“时间紧、怕麻烦、预算有限但要求不低”。

- **验证**：  
  这个标签能否成立，不看文案，而看后续视频能不能持续拍出三个事实：  
  1. 不用促销口号开头；  
  2. 菜品根据真实销情上下架；  
  3. 中午、晚上在摊位上解决不同人的一顿饭。  
  这些都能在真实经营里反复出现，因此比“专业厨师”“温暖老板娘”更能持续。

- **在同类账号里的位置**：  
  同类热菜账号常见的是“低价叫卖型”“菜品堆镜头型”“探店夸赞型”。  
  【待确认：这句需要用你的真实情况填写】**

- **证据链**：  
  1. **销情上下架**：今天为什么留这道、撤那道；  
  2. **现做过程**：出锅、装盒、摆摊前后的连续动作；  
  3. **时间场景**：午休、下班、家庭带菜；  
  4. **经营边界**：不打价格战、不做引流款的真实表达。  

- **边界**：  
  不说“全网最低”“最划算”“来晚就没了”这类强促销话；  
  不编顾客故事、不拍顾客正脸、不硬造感动；  
  不把合伙厨师的从业年限说成出镜老板娘的经历，更不能说成店龄。

### 2. 用户定位

- **一句话画像**：  
  **中午只有一段午休、脑子里还在想工作，走到摊前只想快速装一荤一素的本地白领；以及下班回家前不想再洗切炒、想带几样热菜回家的宝妈。**

- **主攻人群**：  
  **新锐白领 + 精致妈妈。**

  选新锐白领，是因为工作餐“一荤一素小份人均约18元”对应的不是炫耀型消费，而是有限时间里的快速决策。  
  选精致妈妈，是因为晚上近25道菜、家庭打包人均约25—30元，更适合“带菜回家、少做一顿饭”的场景。  

- **为什么不是另一批**：  
  不把小镇青年、Z 世代作为首攻对象，因为他们更容易被聚餐、打卡、颜值驱动；这个摊位的真实优势是解决一顿饭，不是制造社交打卡。  
  也不把高消费宴请人群当核心，因为当前产品、客单和流动摊位场景不对应这一类需求。

- **他们心里真正想的是**：  
  白领心里那句是：**“我不是不会吃，我是不想把午休耗在想吃什么上。”**  
  宝妈心里那句是：**“不是非得点外卖，但今天真没空从头做一顿。”**

- **决策链路**：  
  刷到视频后，他们不会立刻因为一条片子专程赶来；更常见是先记住摊位、记住菜的样子和中晚出摊场景。  
  到了某次午休赶时间、下班没空做饭时，才会想起“那个摊有现做热菜”。因此内容要连续铺“看得见的现做”和“明确的使用场景”，而非只赌单条转化。

- **什么时刻会想起你**：  
  - 午休快结束，还没决定吃什么；  
  - 下班路上，不想买菜、洗菜、炒菜；  
  - 家里临时要加一顿菜，但不想点整份外卖；  
  - 周末家人来家里，想补几样现成热菜。  

- **他在平台上会搜什么**：  
  待确认具体地域后，优先围绕：  
  **“【地域】热菜”“【地域】工作餐”“【地域】下班带菜”“【地域】红烧肉”“【地域】麻辣香锅”**。  
  地域未提供，昵称、字幕、话题暂不能写具体城市名。

### 3. 内容定位

- **长期提供什么价值**：让赶时间的本地人，省事选一顿现做热菜。

- **内容方向**：采用多元四类打底，不另起单一主题；摊位有真实出菜、装菜和售卖场景，能用过程、观点、知识和真实经历分别承接流量、记人和建立信任。

- **当前阶段配比**：
  - **作用配比：流量型70% / 人设型15% / 变现型15%。**按方案已定的起号期配比执行：先让同城陌生人看见摊位和吃饭场景，同时保留少量内容展示经营边界与现做现售过程。账号目前粉丝量和流量稳定情况未提供，阶段判断待核实；若已稳定起号，需结合账号数据重新评估。
  - **流量型70%：**主用晒过程型，辅以观点型、知识型。围绕午休赶时间、下班带菜、饭盒怎么搭配等大众场景，设计人群、成本或反差看点；知识内容要落在普通人能理解的吃饭选择上，不只讲行业细节。
  - **人设型15%：**用观点型和经营过程型，呈现老板娘真实的经营判断，例如菜品随销情上下架、不打价格战；不编故事、不煽情，也不把合伙厨师的从业经历安到老板娘身上。
  - **变现型15%：**以晒过程型为主，拍现做现售热菜、装菜和荤素搭配选择，突出有档案依据的理由：「现做现售热菜、荤素搭配自由选」。每条只讲清一个理由，结尾只引导到摊位看看。
  - **题材配比：主赛道75% / 目标人群兴趣25%。**主赛道围绕热菜、流动摊位和出菜过程；兴趣题材围绕红烧肉、鸡爪、家常菜，以及午休、下班、带菜回家等场景，不脱离目标人群的吃饭需求。

- **8个经营品类在内容里的位置**：现做热菜作为整体经营内容；红烧肉、鸡爪、酥鱼、面筋、干煸豆角、毛血旺、麻辣香锅轮换进入不同的吃饭场景。红烧肉可呈现「每天早上现买五花肉，纯肉无骨无配菜」；酥鱼可呈现「由老板做了多年，有固定回头客」，拍顾客前先征得同意或只拍手部；菜品上下架可呈现「菜品会根据销情上下架，滞销的撤除，有回头客点名的保留」。不要一条视频堆齐所有品类。

- **主力形式**：档案没有提供「数据较好的内容类型」，因此无法认定哪一种已被数据验证。起步可暂以视频配音Vlog加现场同期声测试，理由是中午、晚上摊位可拍，且不依赖早上采购跟拍；这只是资源适配的测试选择，不是数据结论。积累一批作品后，和自己前几条的停留、完播、评论反馈比较，再确认主力形式。

- **每类内容管哪一段路**：
  - **刷到：流量型。**用午休、下班、装饭盒等一眼能懂的场景吸引同城陌生人停留。
  - **记住：人设型。**用老板娘真实的经营选择和边界，让人记住这个摊位不靠低价喊话。
  - **信：变现型。**用现做现售和荤素搭配自由选的现场过程，证明产品与选择方式。
  - **找你：变现型。**交代中午、晚上流动摊位的实际消费场景，结尾只引导「到摊位看看今天现做什么」。

  - **流量型**
    - 四大脚本：以「午休快结束，饭盒怎么装完一顿饭」为方向，用晒过程结构，拍空饭盒、选择一荤一素、装盒；结尾：「你午饭最怕选哪道菜？评论说说。」

  - **人设型**

  - **变现型**
    - 四大脚本：以「红烧肉从早上现买五花肉到摊位售卖」为方向，用晒过程·火车节结构，拍五花肉、烹制及摊位售卖；只呈现档案提供的真实信息「纯肉无骨无配菜」；结尾：「中午或晚上到摊位看看。」
    - 起号36计：**第10计·情境还原**：拍一个真实的家庭带菜选择场景，展示顾客如何在摊位挑选现做热菜、搭配装盒；没有真实顾客配合时，由老板娘示范，不虚构顾客经历；结尾：「中午或晚上到摊位看看。」

- **第一条该发什么**：
  - **题目方向**：《午休快结束了，饭盒里这一荤一素怎么装？》
  - **目的：流量型。**
  - **打法：第32计·换个视角 + 晒过程结构。**
  - **拍摄：**从空饭盒POV开始，拍老板娘在摊位选择一荤一素、装入饭盒、合盖；用现场同期声保留摊位环境，不必拍顾客或早间采购。菜品按当天实际供应选择，不预先写死。

  - **为什么适合开场：**午休赶时间是目标人群能直接理解的场景，拍摄不依赖顾客配合或早间跟拍；看点是饭盒如何完成一顿饭，不把装菜动作本身当作噱头，也不把产品卖点塞进流量视频。

### 4. 呈现定位（只给结论，≤200字）

- **主要形式**：视频配音 Vlog + 少量现场同期声。摊位本身有热气、装盒、出锅、夹菜等画面，不需要硬站桩口播。  
- **产能**：建议一周稳定拍 **3—4 条**，每次中午或晚上出摊集中拍同一批素材；早上采购无法配合，就不把“每日早采”设成固定栏目。  
- **在哪拍**：只在中午、晚上流动摊位现场拍；镜头以锅边、菜盘、装盒台、出摊前后为主，避免白墙口播。

### 5. 风格调性（只给结论，≤200字）

- **正向匹配**：选正向匹配。流动摊位本来就有真实、快节奏、烟火气，不需要强行拍成精致餐厅，也不该硬造反差。  
- **气质关键词**：利落、松弛、接地气。  
- **会说的一句话**：  
  “午休别光站着纠结，一荤一素装好就走。”  
- **不会说的一句话**：  
  “今天全场低价，错过后悔。”  

### 6. 变现定位（只给结论，≤250字）

- **卖什么 + 客单价区间**：现做热菜、红烧肉、鸡爪、酥鱼、面筋、干煸豆角、毛血旺、麻辣香锅；单次消费在50元以下。  
- **成交路径**：同城刷到场景内容 → 记住中晚流动摊位 → 看到现做过程 → 到摊消费。  
- **最缺的信任证据是什么**：不是“菜好吃”的口头评价，而是现做过程、菜品当天状态、荤素搭配自由选和真实上下架逻辑。  
- 完整的变现拆解请用「商业定位」板块。

## 🧠 记忆点设计

1. **语言记忆点：待验证**  
   固定收句可用：**“这顿饭，别再想半天。”**  
   每条只在结尾或转场出现一次，和“替赶时间的人省事”有关，不喊口号式重复。是否保留，要看评论区是否有人主动引用。

2. **动作记忆点：待验证**  
   固定“空饭盒—夹一荤—夹一素—合盖”的四步动作。  
   这不是内容看点本身，而是每条工作餐场景的视觉收尾，观众更容易一眼认出账号。

3. **场景声音记忆点：待验证**  
   保留锅铲声、夹菜声、饭盒扣上的声音，不要全程覆盖吵闹音乐。  
   这比统一 BGM 更贴合“现做现售热菜”的可信度，也更容易形成烟火感。

## ⚡ 差异化：A + 变量B

### 1. 菜品扫镜头 + 换个视角

- **常规A**：同行把一排菜从左扫到右，再叠价格字幕。  
- **变量B**：情境类的“换个视角”。  
- **A+B 长什么样**：用一个空饭盒的第一视角拍“午休一荤一素怎么选”，观众看到的是自己的午饭选择，而不是老板在展示库存。  
  服务对象是赶时间白领，因为他关心的是“我这一顿怎么解决”，不是摊上总共有几道菜。

### 2. 出锅过程 + 销情上下架

- **常规A**：拍炒菜、出锅、摆盘。  
- **变量B**：行为类的“反向操作”。  
- **A+B 长什么样**：别人拍“今天又上新什么菜”，这个号拍“这道今天先撤下，为什么不硬留”。再带出一份新出锅的菜。  
  这不是制造稀缺焦虑，而是让观众看到：菜品不是固定摆样子，而是根据真实购买在变化。

### 3. 菜品介绍 + 一句话设定故事感

- **常规A**：介绍红烧肉、酥鱼、鸡爪的口味。  
- **变量B**：表达类的“一句话设定故事感”。  
- **A+B 长什么样**：  
  “今天这盒菜，不是给会做饭的人准备的，是给下班到家只想坐五分钟的人准备的。”  
  随后拍一份家庭打包的热菜组合。  
  服务的是宝妈和下班人群的时间焦虑，不是为了煽情。
