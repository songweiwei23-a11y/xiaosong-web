## 选题1：《刚下班的人，想吃夜宵时第一个想到谁？》

**【方向】**《地摊这顿饭，你记得什么》  
**【目的】**流量  
**【结尾动作】**评论  
**【成交步骤】**—  

**承接**：承接方向1的核心问题——“下班后想约人吃夜宵时，你第一个想到谁？”以及“顺着他提到的人或事追问一层”。

**0️⃣ 视频目的**  
流量型。用“下班以后先想到谁”这个多数成年人经历过的问题，带出真实关系故事，吸引观众停留和回答。

**🅰 打法**  
- **36计·第35计 街头采访**：夜宵现场抛出“刚下班的人，想吃夜宵时第一个想到谁？”→ 受访者回答 → 追问那个人和一顿饭的具体记忆 → 留下不同人的真实原话。

**1️⃣ 爆款元素**  
- **人群**：套用句式“刚下班的人”。直接圈定刚收工、刚下班、准备吃夜宵的成年人。

**2️⃣ 开篇钩子**  
刚下班的人，想吃夜宵时，你第一个想到谁？

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：在夜宵现场问刚下班的成年人：忙完一天后，最想把这顿饭留给谁。  
- **核心问题与观众价值**：弄明白“下班后第一个想到的人”背后，是真正想见的人、习惯约饭的人，还是很久没联系的人；让观众代入自己的夜宵搭子。  
- **取材与内容推进**：  
  - **访问对象**：自愿出镜的成年食客、刚收工的师傅；优先选择已经坐下吃饭、不急着离开的对象。  
  - **主问题（原目的）**：“下班后想约人吃夜宵时，你第一个想到谁？”  
  - **本条深入的问题**：“为什么偏偏会想到他／她？”  
  - **追问**：  
    1. “你们上一次一起吃饭，聊了什么？”  
    2. “你一般会主动约，还是等对方开口？”  
    3. “如果今天他／她没空，你还会想吃这顿夜宵吗？”  
  - 先保留受访者的直接回答，再根据回答追一段具体经历；只使用有细节、有完整表达的素材。  
- **事实边界**：夜宵现场、串串火锅、烧烤档口是已有场景；受访者想到谁、为何想到、是否有故事，都需现场采访获得。若回答简短，就保留为多人快答，不补写情节。  
- **关键画面（3个）**：  
  1. 炭火、串串下锅、烤串翻面的近景。  
  2. 提问卡或镜头外提问：“刚下班的人，想吃夜宵时第一个想到谁？”  
  3. 受访者半身回答，字幕标注“保留现场原话”。  
- **场景设置**：露天地摊餐桌旁、串串锅旁或烧烤档口附近；背景保留夜晚人声和烟火气，不刻意推菜。

**4️⃣ 脚本结构**  
- **街头采访结构：一个问题 → 追问 → 人物故事/观点 → 夜宵生活连接**  
  1. **问题前置**：炭火和上桌画面中，直接抛出主问题。  
  2. **保留不同回答**：剪入多位受访者的现场原话，不预设答案必须是家人、朋友或同事。  
  3. **挑一位有细节的对象追问**：追问“为什么是他／她”“上次吃饭聊了什么”。  
  4. **生活连接**：用一句旁白或字幕收住：“有的人下班是回家，有的人下班，是等一顿能把话说开的饭。”  
  5. **评论出口**：把问题还给观众。

**5️⃣ 结尾行动指令**  
你下班后最想约谁吃夜宵？评论区说说。

**6️⃣ 执行要点**  
- 两人即可：一人手机竖屏拍摄，一人负责沟通、提问和收音。  
- 开拍前先聊天，再明确说明视频会发布，征得成年受访者同意；不愿露脸可只拍手部、背影或不使用素材。  
- 手机尽量靠近受访者，避开炭火和音箱附近的嘈杂位置；回答较长时，可请对方重复一遍核心句。  
- 现场准备一张简短提问卡，避免提问绕来绕去。

## 选题2：《当年最火的夜宵搭子，现在还会约出来吗？》

**【方向】**《地摊这顿饭，你记得什么》  
**【目的】**流量  
**【结尾动作】**评论  
**【成交步骤】**—  

**承接**：承接原文“有些人白天不联系，晚上会约出来吃顿饭”以及“还记得和朋友吃的那顿夜宵吗？”这个怀旧方向。

**0️⃣ 视频目的**  
流量型。用“以前常约夜宵的人，如今还联不联系”唤起成年观众对老朋友、老同事、旧同学的共同记忆。

**🅰 打法**  
- **36计·第35计 街头采访**：问受访者以前最常约夜宵的人是谁 → 追问最近一次见面或失联原因 → 用不同状态的真实回答构成对照。

**1️⃣ 爆款元素**  
- **怀旧**：套用句式“当年最火的X”，把“夜宵搭子”作为成年人的共同记忆入口。

**2️⃣ 开篇钩子**  
当年最火的夜宵搭子，现在还会约出来吗？

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：采访夜宵现场的成年人，问他们曾经最常一起吃夜宵的人，现在是否还会见面。  
- **核心问题与观众价值**：让观众看到，夜宵不只是吃东西，也常常是朋友、同事和旧关系维持联系的一种方式；观众会自然想到自己的“夜宵搭子”。  
- **取材与内容推进**：  
  - **访问对象**：自愿出镜的成年食客、下班后的店内师傅；优先找看起来在等人、多人聚餐或独自吃宵夜的对象，但不对其关系作预设。  
  - **主问题（原目的）**：“以前最常和你一起吃夜宵的人，现在还会约出来吗？”  
  - **本条深入的问题**：“你最记得和他／她吃的是哪一顿？”  
  - **追问**：  
    1. “那时候你们通常为什么会约出来？”  
    2. “后来是一直保持联系，还是慢慢少见面了？”  
    3. “如果今天让你发条消息约他／她吃饭，你会说什么？”  
  - 根据现场回答，剪出“还常见”“偶尔见”“很久没见”几种真实状态；不把任何一种状态包装成普遍结论。  
- **事实边界**：受访者的关系、经历和联系频率均以现场原话为准；没有具体回忆的回答不强行煽情，可作为快剪回答使用。  
- **关键画面（3个）**：  
  1. 两只碗、几双筷子、桌上正在冒热气的食物。  
  2. 采访者提问：“以前最常和你吃夜宵的人，现在还会约吗？”  
  3. 受访者停顿、回忆或回答的现场状态，字幕写“保留现场原话”。  
- **场景设置**：露天地摊座位区；可选安静一些的桌边，避免对话被锅底沸腾声盖住。

**4️⃣ 脚本结构**  
- **街头采访结构：一句怀旧问题 → 不同真实状态 → 一段具体回忆 → 留白收束**  
  1. **怀旧入口**：从桌上多人餐具或正在等人的画面切入。  
  2. **主问题**：直接问“以前最常和你吃夜宵的人，现在还会约吗？”  
  3. **回答对照**：并列保留不同受访者的真实回答，不标榜哪种关系更好。  
  4. **深追一人**：追问“最记得哪顿饭”“那时为什么总约”。  
  5. **留白收束**：字幕或旁白：“有些人很久没见，但提起夜宵，还是会先想到他。”  

**5️⃣ 结尾行动指令**  
你以前的夜宵搭子，现在还联系吗？评论区聊聊。

**6️⃣ 执行要点**  
- 不要一上来就问私人关系，先说明是聊“夜宵记忆”的小采访，对方愿意再开机。  
- 若对方不愿提及具体姓名，可让其只说关系，如“老同学”“以前同事”。  
- 不追问分手、家庭矛盾等敏感隐私；对方主动提到也只保留其愿意公开的部分。  
- 画面以受访者半身和桌面细节交替，手机保持竖屏稳定。

## 选题3：《花小钱办大事：朋友聚餐前，预算该谁先开口？》

**【方向】**《地摊这顿饭，你记得什么》  
**【目的】**流量  
**【结尾动作】**评论  
**【成交步骤】**—  

**承接**：承接原文“聚餐前商量预算，你会怎么开口？”和“朋友聚餐，怎么提前说清每个人的预算？”。

**0️⃣ 视频目的**  
流量型。围绕朋友聚餐时“钱怎么开口才不尴尬”的共同处境，引发不同年龄层食客讨论自己的做法。

**🅰 打法**  
- **36计·第35计 街头采访**：在聚餐现场问“预算谁先提” → 追问受访者实际怎么说、是否有过尴尬 → 呈现不同人的沟通方式。

**1️⃣ 爆款元素**  
- **成本**：套用句式“花小钱办大事”，落在“聚餐前先把预算讲清楚，避免饭后尴尬”这一具体成本问题上。

**2️⃣ 开篇钩子**  
花小钱办大事：朋友聚餐前，预算到底该谁先开口？

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：采访正在聚餐或有聚餐经验的成年食客，聊朋友约饭前如何自然地把预算说清楚。  
- **核心问题与观众价值**：弄明白预算问题该不该提前聊、谁先提、怎么说不伤感情；观众能带走真实可参考的表达方式，而不是只看一句“AA就行”。  
- **取材与内容推进**：  
  - **访问对象**：自愿出镜的成年多人桌食客、刚下班来吃饭的同事或朋友；不拍未成年人，不在顾客正在点单或结账时强行采访。  
  - **主问题（原目的）**：“朋友聚餐前，预算一般是谁先开口？”  
  - **本条深入的问题**：“你会怎么说，才不会让大家尴尬？”  
  - **追问**：  
    1. “你遇到过大家都不好意思提，最后点多了或点少了的情况吗？”  
    2. “你们一般是提前说清、点菜时商量，还是吃完再算？”  
    3. “你觉得先谈预算，是扫兴还是更省心？”  
  - 剪辑时保留不同做法：有人提前讲、有人点菜时讲、有人不讲；再让受访者说出自己选择的理由。  
- **事实边界**：不问具体消费金额，不展示账单，不把任何受访者的做法说成标准答案；只记录他们愿意分享的沟通经验。  
- **关键画面（3个）**：  
  1. 多人桌上翻菜单、互相问“吃点什么”的手部画面。  
  2. 主问题字幕：“朋友聚餐前，预算谁先开口？”  
  3. 受访者讲具体做法，字幕保留现场原话。  
- **场景设置**：串串锅旁或多人夜宵桌附近；菜单只作为环境画面，不拍未核实的价格信息。

**4️⃣ 脚本结构**  
- **街头采访结构：现实处境 → 主问题 → 做法对照 → 一个具体经历 → 评论讨论**  
  1. **现实处境**：多人围桌、准备点菜的画面，字幕“朋友约饭，最怕谁都不好意思谈预算”。  
  2. **主问题**：问“朋友聚餐前，预算一般是谁先开口？”  
  3. **做法对照**：快剪不同受访者的现场原话。  
  4. **具体经历**：选一位回答清楚的对象，追问一次具体的沟通场景。  
  5. **边界收束**：字幕“没有统一答案，提前说清楚，也是在照顾彼此。”  

**5️⃣ 结尾行动指令**  
你和朋友聚餐，预算一般谁先开口？评论区说说。

**6️⃣ 执行要点**  
- 这条的核心是“如何开口”，不是拍价格；镜头避开菜单中可能与团购页不一致的价格信息。  
- 采访多人桌时必须逐一确认是否同意入镜；有人不同意就只拍同意者或拍手部。  
- 提问者语气轻，不评价“抠门”或“装大方”，避免把采访带向人际冲突。  
- 现场收声可让受访者稍微靠近手机说，后期保留锅底、人声作为环境氛围即可。

## 选题4：《第一次和新朋友吃夜宵的人，点菜是谁来商量？》

**【方向】**《地摊这顿饭，你记得什么》  
**【目的】**流量  
**【结尾动作】**评论  
**【成交步骤】**—  

**承接**：承接原文“第一次和新朋友吃饭，点菜是谁来商量？”以及“围绕下班后还没回家、刚收工、刚下班的成年食客或师傅”。

**0️⃣ 视频目的**  
流量型。抓住“第一次和新朋友吃饭”的微妙社交场景，让年轻白领、学生、蓝领技工等人群代入自己最不擅长的点菜时刻。

**🅰 打法**  
- **36计·第35计 街头采访**：问第一次和新朋友吃饭时谁先决定点什么 → 追问具体尴尬或默契瞬间 → 用真实回答呈现不同人的社交习惯。

**1️⃣ 爆款元素**  
- **人群**：套用句式“第一次体验X的人”，将“第一次和新朋友吃夜宵”作为具体体验场景。

**2️⃣ 开篇钩子**  
第一次和新朋友吃夜宵的人，点菜到底谁来商量？

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：采访成年人第一次和新朋友、同事或刚认识的人吃夜宵时，点菜这个小决定是谁先开口。  
- **核心问题与观众价值**：通过一个很小但真实的饭桌动作，聊清楚陌生关系里大家如何试探、照顾和表达；让观众获得社交代入感。  
- **取材与内容推进**：  
  - **访问对象**：愿意出镜的成年食客、店内师傅；优先采访有“第一次和新朋友吃饭”经验且愿意分享的人，不要求当天就是第一次见面。  
  - **主问题（原目的）**：“第一次和新朋友吃夜宵，点菜一般是谁先开口？”  
  - **本条深入的问题**：“你会先问对方什么，才敢开始点？”  
  - **追问**：  
    1. “你是会直接说自己想吃什么，还是先让对方选？”  
    2. “有没有一次因为点菜，后来反而聊开了？”  
    3. “你觉得点菜这件事，最容易看出对方什么？”  
  - 先收集多人短答，再选择有具体场景的一位展开；若多人回答相近，就继续追问“为什么大家都这样做”。  
- **事实边界**：只谈受访者愿意公开的社交经历；不追问姓名、单位、联系方式等私人信息；不把“点菜习惯”解释为人格定论。  
- **关键画面（3个）**：  
  1. 菜单摊在桌上，两个人互相谦让或翻看的手部特写。  
  2. 采访者问：“第一次和新朋友吃夜宵，谁先开口点菜？”  
  3. 受访者回答，字幕写“保留现场原话”。  
- **场景设置**：地摊餐桌旁、菜单附近；可拍串串锅或烧烤作为背景，但不把内容转成菜品推荐。

**4️⃣ 脚本结构**  
- **街头采访结构：社交场景 → 同一个问题 → 回答反差 → 一段具体经历 → 把问题交回观众**  
  1. **社交场景开场**：菜单、空筷子、等待对方先说话的桌面细节。  
  2. **主问题前置**：第一次和新朋友吃夜宵，谁先开口点菜？  
  3. **回答反差**：有人习惯先问口味，有人习惯让对方决定，有人直接点；都保留为现场原话。  
  4. **故事追问**：挑一位讲得具体的对象，追问“哪次点菜让你记住”。  
  5. **收束**：字幕“有时候一顿饭从谁先开口开始，也从一句‘你想吃什么’变熟。”  

**5️⃣ 结尾行动指令**  
第一次和新朋友吃饭，你会先点菜还是先问对方？评论区说说。

**6️⃣ 执行要点**  
- 不必等到真实的“第一次见面”现场；采访对象只要有相关经历即可，避免为了拍摄安排陌生人演戏。  
- 拍菜单时只拍翻页、手部和局部，不露出未核实的价格信息。  
- 受访者如不愿被拍正脸，可拍侧脸、背影和声音，并在发布前再次确认。  
- 采访者不要替对方总结“你很内向”“你很会来事”，只让对方自己表达。

## 选题5：《内向的人第一次约夜宵，最难开口的是哪一句？》

**【方向】**《地摊这顿饭，你记得什么》  
**【目的】**流量  
**【结尾动作】**评论  
**【成交步骤】**—  

**承接**：承接方向1中“下班后的孤单、放松、约朋友，是学生、白领、蓝领技工都经历过的场景”，并延伸“想约谁出来吃一口”的核心行动。

**0️⃣ 视频目的**  
流量型。以“想约人吃夜宵却不知道怎么开口”的社交难题切入，扩大对内向人群、刚到新城市工作的人群和普通夜宵食客的覆盖。

**🅰 打法**  
- **36计·第35计 街头采访**：问受访者想约人吃夜宵时最难发出的那句话 → 追问有没有真的发出去、对方怎么回应 → 保留不同人的真实表达。

**1️⃣ 爆款元素**  
- **人群**：套用句式“内向的人的X”，直接点名不擅长主动邀约的人群。

**2️⃣ 开篇钩子**  
内向的人第一次约夜宵，最难开口的是哪一句？

**3️⃣ 内容方向及目的（重中之重！）**  
- **核心内容方向**：在夜宵现场采访成年人，聊他们想约人吃夜宵时，最难说出口的话和真正会怎么发消息。  
- **核心问题与观众价值**：让观众看见“约一顿饭”背后的社交犹豫，获得可代入的话题和真实表达，而不是被要求必须外向。  
- **取材与内容推进**：  
  - **访问对象**：自愿出镜的成年独自食客、刚下班的师傅、朋友结伴而来的食客；不直接给人贴“内向”标签，先问是否愿意聊这个话题。  
  - **主问题（原目的）**：“如果你想约一个人吃夜宵，最难开口的是哪一句？”  
  - **本条深入的问题**：“你最后真的约出去过吗？当时是怎么说的？”  
  - **追问**：  
    1. “你最担心对方怎么回复？”  
    2. “如果不直接说‘出来吃夜宵’，你会换成什么说法？”  
    3. “你觉得约夜宵最重要的是吃什么，还是和谁一起吃？”  
  - 现场不逼受访者复述聊天记录，只请其概括愿意公开的表达；剪辑中保留不同人对“主动邀约”的真实态度。  
- **事实边界**：不预设受访者一定约成功，也不把未被回应包装成伤感故事；所有结果以现场原话为准。  
- **关键画面（3个）**：  
  1. 一个人坐在夜宵桌前、手机放在桌边的环境画面，不拍聊天内容。  
  2. 提问：“想约人吃夜宵，最难开口的是哪一句？”  
  3. 受访者的回答和停顿，字幕标注“保留现场原话”。  
- **场景设置**：露天地摊较安静的边桌；串串锅、烧烤架作为夜宵背景，避免拍到其他顾客正脸。

**4️⃣ 脚本结构**  
- **街头采访结构：一个社交难题 → 多种现场回答 → 具体表达 → 温和收束**  
  1. **问题开场**：先拍夜宵桌上未动的筷子和手机，再抛出主问题。  
  2. **多人短答**：保留不同受访者的原话，例如“难在第一句”“难在怕被拒绝”“不难，我会直接问”，不预设统一情绪。  
  3. **深入追问**：针对有细节的人，问“最后怎么开口”“最担心什么”。  
  4. **夜宵连接**：字幕收束：“有些夜宵不是饿了才想吃，是想找个人坐一会儿。”  
  5. **评论出口**：邀请观众分享自己的开口方式。

**5️⃣ 结尾行动指令**  
想约人吃夜宵时，你会怎么开口？评论区留一句你的版本。

**6️⃣ 执行要点**  
- 这条采访的是“邀约经验”，不是给受访者做性格测试；提问前先问对方是否愿意聊。  
- 不拍聊天记录、电话号码、社交账号等隐私内容；手机屏幕如入镜需避开或打码。  
- 若受访者回答很短，可用“你会直接约吗”“怕的是被拒绝还是怕冷场”帮助对方展开，但不要诱导特定情绪。  
- 两人配合即可：一人出镜提问，一人稳定持手机拍摄；选择晚间正常营业时段，避开过于拥挤、影响顾客用餐的时刻。
