# 创作逻辑整改方案（2026-10-29）

## 一、目标（验收标准，达不到就不算修好）

| # | 目标 | 怎么判断过没过 |
|---|---|---|
| G1 | 选题不同质 | 一批 5 条：爆款元素至少 3 种；同一个句式（如「A VS B」）最多 2 条；不能是同一件货换动作 |
| G2 | 方向展开不窄 | 展开出的 10 个方向：围绕人、货、场三样都要有；同一类看点（如「某个动作下的状态」）最多 2 个；同一件货最多 3 个 |
| G3 | 反差、对比都遵守「变的是货」（含流量型） | 任何板块做反差、对比、前后变化，变的是这家卖的东西，人、场、动作不变；不出现「站着 vs 坐下」「镜子 vs 本人」「同一件换穿法、换动作」 |
| G4 | 系列有用 | 每个系列：①变量不能只是动作、姿势、场景、机位；②看点不能是试穿、挑选、穿搭这类技巧（学会了就不用来店里）；③前 10 集标题至少 3 种元素、同一句式最多 3 个；④说得出陌生人为什么想看下一集 |
| G5 | 各板块尽到职责（按大纲） | 账号定位不再把「同件换穿法、换动作」定成主打或王牌栏目；各层出发点（人货场之一、三有之一、元素）都在；脚本用元素设计结构、结尾按目的；标题认得出元素 |

## 二、根因（都有证据）

1. **最上游在账号定位**：你现在在用的账号定位（10-25 生成）自己写着「王牌栏目：同一件，现场试两种穿法」「第一条：同一件外套两种穿法」「记忆点：站、坐、走三连试穿」。内容定位以它为底，系列就继承成了「试衣镜前，动起来再说」。
2. **规则缺口**：「主角是卖的东西」规则里写着「流量型不受换货对比约束」，等于允许流量型用动作做反差。
3. **「反差」被用错**：知识库的反差是「把两类人、两个时代摆在一起」（穷人 vs 富人、曾经 vs 现在），模型写成了「同一条裤子站着 vs 坐下」。提示词没有讲清反差两边该摆什么。
4. **系列立项检验是自评**：模型永远写「过」，没有「变量不能只是动作」「看点不能是技巧」「元素要多样」这些硬标准。
5. **选题元素被锁死（我上一轮引入的）**：「沿用方向元素」把整批 5 条都锁在同一个元素上。
6. **方向展开只要求守主题**：没要求人货场和看点要分散，10 条都成了「裤子在某个动作下」。
7. **选题批次没有多样性要求，检查也认不出**：质检只看「标题里有没有元素词」，认不出「对比的是动作」和「整批同一个句式」。

## 三、具体方案

| 编号 | 改哪里 | 改成什么 | 对应 |
|---|---|---|---|
| S1 | 「主角是卖的东西」规则（全站共用） | 删掉「流量型不受约束」。改为：不是每条都要做对比；但**只要用反差或做对比、前后变化，不管什么目的，变的都是这家卖的东西**，人、场、动作不变；不能变动作、姿势、穿法、场景、镜头 | G3 |
| S2 | 爆款元素「反差」的说明 | 写清反差两边摆什么：两类人、两个时代，或两样货；要证明东西好时，两边是同一个人用两样货；**不能是同一件东西的两个动作或状态** | G3 |
| S3 | 账号定位提示词 | 主打内容、第一条、王牌栏目不能定成「同一件换穿法、换动作、换场景」；记忆点可以是一个动作，但不能拿它当内容的看点 | G5 |
| S4 | 内容定位的系列设计 | 加「这几种系列不能立项」：变量只是动作或场景的、看点是技巧的、10 集同一句式或同一元素的。立项检验改成硬标准，有一条不过就换掉，不许写「过」凑数 | G4 |
| S5 | 选题 | 方向带来的元素只作**首选**，不锁死整批；加批次要求：至少 3 种元素、同一句式最多 2 条、不能同一件货换动作 | G1 |
| S6 | 创作方向（展开和新出都管） | 方向之间：人、货、场三样都要用到；同一类看点最多 2 个；同一件货最多 3 个 | G2 |
| S7 | 质检 | 新增两项提醒（不挡交付）：①对比的变量是动作而不是货；②整批选题元素太少或同一句式太多 | G1、G3 |

## 四、实施计划

1. 按 S1 → S7 改代码，每一项配测试守住（改坏了测试会报错）。
2. 全量单测和类型检查。
3. 干跑：只拼提示词、不调用模型，确认能跑通。
4. 真实核验一次（**6 次调用**）：账号定位 → 内容定位 → 内容规划 → 创作方向 → 选题 → 脚本，全部以新的账号定位为底。只存在本地，不写进你的账号。
5. 按 G1～G5 逐条核对：先用脚本统计，再人工逐条读。没过的就回到对应的 S 项再改；第二轮真实调用前先告诉你。
6. 报告结果。提交和部署等你说。

## 五、修完以后你需要做的
